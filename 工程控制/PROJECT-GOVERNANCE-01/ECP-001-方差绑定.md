## 1 要决策的一件事（单点）

## 2 为什么必须接线（证据锚）

1. 引擎侧接线**已经存在**：drizzle_engine.cpp:1909-1912 仅在 `varianceData != nullptr` 时取逐像素 `varianceValue`；:1555-1559 累加 `acc.sumVarNum += varianceValue·w²`（文件首行文档锚：SCI-DRZ-014 / ALG-DRZ-VAR，α²v 缩放律）；hp_drizzle_api.cpp:1018-1043 读输入帧 `variance` 块，注释即写「逐像素方差图，由 SNR 阶段 NoiseWeightModelV1 填充」。

## 3 单位与缩放（前置 ①：逐式，随实施同批交付）

### 3.1 全链逐式（输入侧不归一，归一只发生一次：writer）

| 步骤 | 式子 | 单位 | 代码锚 |
|---|---|---|---|
| N1 噪声模型逐像素 | `v_j = Var(空背景像元 j)`；`ivar_j = 1/max(v_j, floor)` | ADU²（信号单位²） | docs/science/NOISE_MODEL.md §1/§7/§9a；API `snr_noise_model_v1(_f64/_fill)` |
| N2 帧方差块 | `variance[j] = v_j`（**逐输入样本原始方差；不做面积归一、不做加权、不做 drizzle**） | ADU²/输入像元 | drizzle_engine.cpp:1910 取 `varianceValue = varianceData[y*width+x]`；:1559 `+= v·w²` |
| N3 drizzle 累加 | `sumVarNum_p = Σ_j v_j · w_jp²` | ADU²·w² | drizzle_engine.cpp:1555-1559；DRIZZLE.md §方差传播 |
| N4 writer 归约 | `variance_p = sumVarNum_p / covered_area_p²`；`ivar_p = 1/variance_p` | ADU²（面亮度一致）；1/ADU² | aio_hips_writer.cpp:795、:841-858 |
| N5 对照（同一 writer） | `signal_p = flux_sum_p / covered_area_p`（:10）；`support_p = covered_area_p / A_cell`（:11） | —— | 同文件 |

⇒ **结论性约定**：帧 `variance` 块必须是**未归一的逐样本 ADU²**，因为面积归一在全链中只发生一次（N4），与 `flux_sum → signal` 的处理完全对称。若在 N2 预先把 `v_j` 按面积归一，则 N4 会二次归一（错 α⁴/α² 级）。

### 3.2 缩放律（α²）与必须写清的三个分界

- 缩放律（SCI-DRZ-014 / drizzle_engine.cpp 首行文档锚）：`x → αx ⇒ var → α²·var`。
- 必须写清的分界（实施时必须逐条落成代码注释 + 门）：
  1. **噪声模型消费哪一帧**：raw 还是 calibrated？若消费 raw 而 drizzle 消费 calibrated（含 gain/flat/EXPTIME 的 α），则 `v_j` 必须按同一次缩放的 α² 同步缩放（或改为直接对 calibrated 帧估方差），二者必居其一且必须写明；
  2. **饱和/掩膜/边界样本**：`v_j` 是「按空背景模型外推的值」还是「置为不可用」——必须与 F-UNC-001（前置 ②）同批定；
  3. **floor 取值**：`ivar=1/max(variance,floor)` 的 floor 单位与数值必须写死并进门（禁止隐式默认）。

### 3.3 必须证明或显式给出的换算关系（前置 ① 的核心技术风险）

- §4a 写的是 `variance_p = Σ v_j·w_jp² / D_p²`（`D_p` = drizzle 分母），§12.2/writer 写的是 `variance = var_num_sum/covered_area²`。**两式相等当且仅当 `D_p ≡ covered_area_p`**（引擎逐像素分母 == writer 从 `view->covered_area` 读到的面积和）。
- 实施必须给出以下之一：(a) 数值 oracle 证明 `D_p == covered_area_p`（合成帧：已知 `w_jp` 与 `v_j`，比较引擎侧 `sumVarNum/D²` 与 writer 侧 `var_num_sum/covered_area²`，相对误差门 <1e-6）；或 (b) 显式换算因子及其条款依据。
- 未给出前不得接线（否则会出现「引擎方差」与「产品方差」两套数值而不自知——正是 §4a/§12.2 的交界风险）。

### 3.4 不得与另一条方差混淆

- `p1_snr.json` 的**帧级标量** variance/ivar 与 HiPS 逐像素 `variance/ivar` 是**两个不同量**（前者是相对质量/帧级噪声估计，后者是逐像素科学方差）。本项目禁止把帧级/local SNR 当科学方差（SCI-CW §1/§5；§20.3）。实施时必须在 manifest/文档中显式区分，禁止同名复用。

## 6 判据（受理与验收：前置 ④ —— 门必须双向可假）

1. **正例**：合成夹具（已知方差解析场）→ normalize → mosaic 默认（缺 `weight_mode` 键）端到端 rc=0；`p1_final.products=[signal,support,variance,ivar]`、`uncertainty_available=true`；mosaic `p2_final.weight_basis=per_sample_ivar`、`ivar_product_missing_frames=0`；
2. **数值判据**：逐像素 variance 对注入真值相对误差 <1e-3（决定性可复现夹具）+ `ivar·variance=1`（<5e-3）+ §3.3 的 `D_p ≡ covered_area_p` oracle（<1e-6）；NOISE_MODEL 层已有 numpy oracle 资产可复用；
3. **双向可假门（每条都要有对偶红臂）**：
   (a) 方差平面缺失 ⇒ 必须回到 fail-closed rc=2（既有门 + `ASTROCS_IVAR_FAULT=silent_fallback` 红臂）；
   (b) 方差平面被 support 顶替 ⇒ 必须判红（§20.3）；
   (c) α 缩放用错（应按 α² 却按 α）⇒ oracle 必须判红；
   (d) 无覆盖/无数据像素按「0 方差」伪装 ⇒ 必须判红（§30.1 禁伪 variance）；
   (e) `covered_area<=0` 与 §4a 的 0/NaN 语义不一致 ⇒ 必须判红（与 F-UNC-001 定论一致）；
4. **不得跌破**：`ninja` 0 FAILED；`ctest` 全绿且计数不降；锚点门 rc=0；p2001 既有 4d 门与新审计门、p1noise 现有判据、§20.3/§30.1 的禁伪判据**一条不得放宽**。
