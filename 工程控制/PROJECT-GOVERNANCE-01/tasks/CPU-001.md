## 步骤
1. 隔离三层 provider 并加 ISA 泄漏检查（baseline 目标不得含 AVX/AVX-512 指令或内建函数）。
2. benchmark 按 kernel 测误差/吞吐/扩展性/带宽/block/workers，统计量稳定且可复跑；输出 cpu_profile 到安装目录。
3. profile 绑定 CPU/OS/软件版本/provider hash；篡改或换机后判定失效并回退。
4. 无 profile 或坏 profile：回退 baseline + 保守并行，给出提示但**不阻塞**运行。
