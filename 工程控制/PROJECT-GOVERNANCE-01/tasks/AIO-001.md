# 任务：AIO-001 收敛唯一 AIO 与原子产品边界

状态：`NOT_STARTED`
层：L2　依赖：DATA-001, ARCH-001　文件域互斥组：S5-A

## 目标

把 FITS/HiPS/manifest 的读写收敛到唯一 `lib/infrastructure/aio`，实现临时路径→校验→原子 rename→incomplete 清理协议，使算法目录不再拥有 I/O。

## 基线状态（编制时实测）

- I/O 所有权分散：`lib/astro_image_io`、`lib/io`、`lib/hips`、`lib/hips_p2`、`lib/healpix_db`、`runtime/` 以及各阶段 writer（如 `lib/phase3_fits`）。
- 现有检查器 `tools/check_aio_ownership.py` 已存在并在 `ci/checks.json` 注册为 `AIO-OWNERSHIP`。
- ASTROCS_DESIGN §9 与 §6.3 要求：输出临时文件+原子提交，失败不得留下可被误认成正式产品的半成品；取消 → 关 writer → 写 incomplete manifest → 删/隔离临时产物 → exit 9。

## 步骤
1. 列出当前所有 FITS/HiPS/manifest 写点（文件+函数），判定归属：保留在 AIO 或迁移。
2. 在 AIO 实现统一入口：临时路径 → 写入 → fsync/close → 校验（尺寸/哈希/manifest 完整）→ 原子 rename；异常路径写 incomplete manifest 并清理。
3. 定义阶段间产品 manifest/hash/provenance 合同（引用 DATA-001 的 schema，不自造对象）。
4. 故障注入测试：写中途 kill、磁盘满模拟、取消信号；断言最终目录里没有看似完整的产品。
5. 让所有权检查在旧 writer 重新出现时失败（负例：在算法目录里写 FITS open 调用）。
