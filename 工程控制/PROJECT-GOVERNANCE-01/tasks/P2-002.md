# 任务：P2-002 治理按需逆方差与三科学目标权重

状态：`NOT_STARTED`
层：L4　依赖：P2-001　文件域互斥组：S7-P2

## 目标

从 frame_snr/稀疏层按需计算逆方差（不物化全图权重），并分离 extended-source GLS / point-source Q-W / psfsw_robust 三目标权重；分块与 worker 数变化不得改变结果。

## 基线状态（编制时实测）

- 现实现分散在 `lib/phase2_int`、`lib/phase2_samp`、`lib/phase2_rej`、`lib/phase2_upm`。
- UNIFIED_MODEL §2：`point_information = a²PᵀC⁻¹P = 1/Var(F_hat)` 是点源严格权重；`psfsw_robust_weight` 是复合权重**不是 ivar**；`source_snr`、`depth_m5` 不作权重。
- ASTROCS_DESIGN §4.3 规定 SNR 检测与逆方差叠加。

## 步骤
1. 自动检测稀疏 SNR 层存在性与采样规则，计算 frame×in-frame SNR（不落全图）。
2. 按用到的源像素转换为逆方差，验证峰值内存随 block 而非全图增长。
3. 分离三目标：extended-source GLS、point-source Q-W、psfsw_robust；各自权重来源与适用域显式声明。
4. 确定性验证：分块大小、worker 数、ISA 变化下结果一致（在冻结容差内）。
5. 负例：直接 SNR 加权必败。
