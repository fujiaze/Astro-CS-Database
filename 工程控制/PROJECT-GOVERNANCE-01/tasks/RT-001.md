# 任务：RT-001 收敛统一调度器、typed DAG 与线程预算

状态：`NOT_STARTED`
层：L2　依赖：DATA-001, ARCH-001　文件域互斥组：S5-B

## 目标

一个进程只有唯一 scheduler 与唯一线程预算源；三个命令各自独立 DAG 生命周期；队列有容量/背压/取消/超时/错误传播；禁止整阶段 Session 被多节点重复调用。

## 基线状态（编制时实测）

- 调度/管线分散在 `lib/orchestrator`、`lib/core`、`runtime/`、`cli/runtime_client.cpp`、各 `lib/phase*_session`。
- 现有检查器 `tools/arch/check_thread_budget.py`、`tools/check_pipeline_trace.py`、`tools/quality/check_pipeline_graph.py` 绑定旧结构。
- ASTROCS_DESIGN §7.3：每个生产 DAG 节点映射唯一真实 module/DLL/导出入口/算法操作；多个节点不得调用同一完整 Session。

## 步骤
1. 定义 typed artifact/port：每个端口的类型来自 DATA-001 的对象与 CFG-001 的配置 schema。
2. 建立唯一 executor 与线程预算：声明预算来源、分配算法、回收；模块不得自行创建长期线程。
3. 三个命令各自独立 DAG 生命周期（normalize/mosaic/export 分开），节点绑定唯一 entrypoint。
4. 为队列加容量上限、背压、取消、超时与错误传播，并给出无界队列负例。
5. 删除完整 Session 被多个节点调用的执行路径，并用检查器锁死。
