# 任务：P3-002 治理反向重采样、模式与流式 FITS 输出

状态：`NOT_STARTED`
层：L4　依赖：P3-001, AIO-001　文件域互斥组：S7-P3

## 目标

export 用输出像素→天球→HiPS 的反向映射（不正向散点留洞），显式支持 surface_brightness / point_source_flux / visualization 三模式并检查信息可用性，按行带流式写 FITS+WCS。

## 基线状态（编制时实测）

- 现实现：`lib/phase3_rsmp`、`lib/phase3_fits`、`lib/phase3_session`；文档 `docs/plugins/algorithms_phase3/15_resample.md`、`16_fits_output.md`、`docs/algorithms/PHASE3_RESAMPLE.md`、`PHASE3_FITS_IMPL.md`。
- ASTROCS_DESIGN §5.2 定义流程，§5.4 硬约束。

## 步骤
1. 实现反向映射：输出像素网格 → 天球坐标 → HiPS 采样；记录插值核与边界处理。
2. 三模式显式化：surface_brightness / point_source_flux / visualization；每模式声明所需输入对象，缺失时 fail-closed。
3. 按行带/块流式写 FITS，WCS 由生成参数计算并写入头；验证峰值内存有界。
4. 用独立 WCS/FITS 解析器（非本项目实现）验证产品可读且关键字正确。
