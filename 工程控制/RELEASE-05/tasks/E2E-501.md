# 任务：E2E-501 小批量端到端与预检矩阵

## 目标
用小批量合成/真实子集验证三命令串行全链可行、科学、性能无回归，预检交互语义全部正确。

## 步骤
1. 合成数据全链：normalize→mosaic→export 串行，manifest 链贯通，输出哈希与 Oracle 比对；
2. testdata 小子集（每数据集 3–5 帧）真实全链冒烟；
3. 预检矩阵（最高设计 §6.2）：
   - correct / warn（如暗场时间超容差可优化）/ error（滤镜不匹配、文件缺失）三类输入；
   × 直接 yes / -y(-yes) / -force 三种运行方式；
   断言：correct、warn 均需 yes 或 -y；error 阻断且 -y 不可越；-force 跳过整个检查步骤；
4. SIGTERM 中断原子性（无半成品、退出码 9）；磁盘满 exit 10；
5. 1/N worker 全链逐位一致；分段计时记录（为 PERF/VIS 提供基线）。

## 验收门
- [ ] 三命令串行 rc=0、manifest 链完整、数值在 Oracle 容差内；
- [ ] 预检矩阵 3×3 全组合行为正确（表格证据）；
- [ ] 中断/磁盘满测试通过；
- [ ] 产物落 output_dir、run/ 目录纪律遵守。
