# 任务：VIS-501 L4 两组成品帧与视觉验收

## 目标
用 testdata 两组真实数据跑完整流程，产出两张平面 FITS 与切块 PNG，agent 完成视觉自验后交负责人目检。

## 数据（仅 R 通道）
- M42：T2+T3 Red 300s 49 帧（暗场 600s K=0.5）；
- 银心：T4 panel1-3 Red 180s 32 帧（K=1）；
- 工作盘 ≥100GiB，TMPDIR 指源码树外可写目录。

## 步骤
1. 两组各自 normalize→mosaic→export 全链，HiPS→平面 FITS（单张整幅）；
2. 拉伸脚本自动拉伸输出 PNG；Python 切块脚本规则切块；
3. **agent 视觉自验**：逐块检查无黑洞、无异常亮斑、无接缝；分辨率不足处裁剪放大重读；接缝区域用 SCI-C 接缝度量（保留背景的帧间差）互证；
4. 发现问题：定位（科学/架构/IO）→回派修复→重跑，记录轮次；
5. 分段计时与资源记录（每阶段墙钟、RSS、CPU 利用率、读放大），热点已在 PERF-501 处理的给对照；
6. 两张 FITS + 切块 PNG + 自验记录作为审核包内容，状态置 READY_FOR_OWNER_REVIEW，**等负责人目检认可**，不自行发布。

## 验收门
- [ ] 两张整幅 FITS 与切块 PNG 产出；
- [ ] agent 逐块自验表（每块 pass/疑问/放大复查结论）；
- [ ] 接缝度量与视觉结论一致；
- [ ] 计时/资源表归档；
- [ ] 只做 R 通道；不触发 FIN。
