# 任务：PERF-501 探针驱动的编排性能优化（A 线，最后）

## 目标
在功能与数值正确闭环后，基于真实探针数据优化三阶段编排，消除 RELEASE-04 实测瓶颈：阶段串行段（1→16 worker 仅 2.37×、均值 3.92/16 核、p50 0.62 核）与约 3.9GB/帧读放大；在 GATE-501 的真性能门下达标。

## 权威依据

## 前置

## 步骤
1. 基线测量：16 帧合成 mosaic 全链，收集节点墙钟/排队/块生灭/RSS/I/O/worker 均衡/缓存命中；识别串行段、低利用窗、读放大来源；
2. 优化项（按证据排序，不限于）：normalize 帧并发与预取深度、Gaia 查询缓存复用、mosaic 窗口路由避免整帧读、窗口大小扫描、export 队列深度、I/O 与计算重叠、工作窃取；
3. 每改一项：同 registry SHA 下 N=1/2/4/8/16 扫描 + 逐位一致性 + 探针对比，禁止只凭推断；
4. 内存：峰值 RSS 给预算对照表（稠密 SNR 不驻留、块即时回收、窗口/子块流式）；
5. 出热点瀑布图与优化前后对照，写入报告证据。
