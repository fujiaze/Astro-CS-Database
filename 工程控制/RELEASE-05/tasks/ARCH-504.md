# 任务：ARCH-504 export 子块流式调度器（A 线）

## 目标
实现 export 阶段独立调度器：读子块→投影/重采样→写 FITS 的流式管线，有界队列+背压，不整幅驻留，I/O 与计算重叠。

## 权威依据
最高设计 §6、§8.3（export 行）。

## 改动范围
- 允许改：scheduler、`lib/infrastructure/cli/export/**`、projection/resample/fits_output 的流式调用面（算法内部不改）
- 禁止改：投影数学（TAN 冻结，SIN 缺陷未解决前不启用）、eng/

## 步骤
1. 输出平面按子块划分，HiPS 读取按子块范围路由；
2. 三级有界流水线（读/算/写）+背压；WCS 头、properties 在开写前组装；
3. 原子发布：临时目录→完整 FITS→原子 rename，磁盘满 exit 10（保持已修语义）；
4. RSS 与子块大小成正比、与总图大小无关（大图合成测试验证）；
5. 探针记录每子块耗时、I/O 等待、队列水位。

## 验收门
- [ ] 大图（合成 4×/16× 像素规模）RSS 不随总图增长，给曲线；
- [ ] 与整幅参考路径输出 FITS 逐像素一致（TAN，容差冻结）；
