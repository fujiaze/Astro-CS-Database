# 任务：ARCH-502 normalize 异步工作流调度器（A 线）

## 目标
实现 normalize 阶段独立调度器：帧内节点按 DAG 流水、多帧并行、资源空闲时异步启动独立工作流（预取下一帧、预解析星表、预建 PSF），I/O 与计算重叠。

## 权威依据
最高设计 §8.3（normalize 行）、§9；CONTRACT-501 调度器接口与探针合同。

## 改动范围
- 允许改：`lib/infrastructure/scheduler/**`、`lib/infrastructure/cli/normalize/**`、aio 预取/缓存接口（只加不改语义）
- 禁止改：科学算法、eng/、其他两阶段

## 步骤
1. 统一资源预算源：线程数、内存上限、队列深度从配置/资源门读取；模块不得私建线程池；
2. 帧内 DAG 流水 + 多帧并发：同一帧节点按依赖执行，独立帧并行；节点工作窃取；
3. 异步工作流：空闲 worker 触发预取（FITS 读、Gaia 同组查询合并与两级缓存复用、PSF 初值），预取结果以块形式入帧、可取消；
4. 探针：每节点墙钟、排队等待、块生灭、RSS、I/O、worker 利用率、缓存命中写事件流（JSONL）；
5. 确定性：固定 worker 数下归约顺序冻结，1/N worker 逐位一致（异步只影响顺序不影响结果，归约按帧/块 ID 排序）；
6. 取消：SIGTERM 原子落盘语义、退出码 9 保持。

## 验收门
- [ ] 合成多帧任务：N=1/2/4/8 worker 结果逐位一致；
- [ ] 预取命中率与 I/O 重叠有探针证据；无预取 vs 预取墙钟对比；
- [ ] 峰值内存受在途块集合约束（给帧并发度 vs RSS 曲线）；
- [ ] 取消/磁盘满路径测试；ctest 全绿。

## 禁止
- 性能调优（窗口/并发度最终取值）放 PERF-501；本任务只保证机制正确与探针齐全。
