# 任务：ACCEPT-501 独立验收（五一致性自迭代）

## 目标
由**未参与实现**的独立验收子代理，逐项核对科学-文档-合同-代码-测试五者一致且唯一；发现问题回派对应线修复并复验，直到收敛；无法裁决项成文。

## 权威依据
最高设计 §12；ACCEPTANCE_SPEC 全文；CONTROL_PACK_SPEC §7。

## 角色约束
- 验收者只读 + 出报告 + 派单，不改代码/文档/测试；
- 验收者不得是 ARCH/GATE/SCI 任务的执行者；前台统一调度回避。

## 验收清单（逐项映射，出五列对照表：科学口径/文档条款/合同 schema/代码 file:line/测试用例）
1. 测光链：积分公式、IRLS、引导检测、k_photo/m(x,y)、适用域 n≥100、降级路径；
2. SNR 链：σ_F 组成与 σ_sky 唯一口径（SCI-501 后无双计）、F_ref 锚定、稀疏层、消费时逆方差、三口径适用域；
3. UPM 链：纯加性假设、control_ivar、四要素、参考面表示能力、容差/状态机/近奇异处理（SCI-502）；
4. 排异五档、NaN 处理、面亮度端口、f64 累加、原子发布、aio 唯一 I/O；
5. 架构：三进程三调度器、块生命周期、无跨阶段内存、探针事件、退役代码处置（CHK-RETIRED-CODE）；
6. 门禁：fail-closed、性能门真判红、监控字段语义、空断言清零、合同双向对应；
7. 预检/退出码/版本纪律/目录纪律；
8. 三篇论文报告数字与 results/ 证据一致。

## 流程
1. 每项给"一致/偏差/缺失"结论与证据指针；
2. 偏差按线派单（A/B/科学），修复后复验，记录轮次；
3. 无法裁决（互斥科学观点、证据不足、双线争议）写入 `OPEN_QUESTIONS.md`：问题、双方证据、建议、影响面；
4. 出独立验收报告（任务状态、五一致性矩阵、复验轮次、残余风险）。
