# 任务：ARCH-503 mosaic 天球窗口并行调度器（A 线）

## 目标
实现 mosaic 阶段独立调度器：以天球窗口为调度单元并行，窗口内 UPM→排异→集成顺序固定，窗口间无共享可变状态；窗口大小显式权衡内存与 CPU。

## 权威依据
最高设计 §8.3（mosaic 行）、§5；CONTRACT-501 调度器接口合同。

## 改动范围
- 允许改：scheduler、`lib/infrastructure/cli/mosaic/**`
- 禁止改：UPM/排异/集成科学算法（SCI-502 已修）、eng/

## 步骤
1. 窗口划分：按 HiPS 层级把天区划成固定大小窗口（tile），窗口大小为配置参数并写 manifest；
2. 输入帧块按窗口路由（aio 只读必要切片，消除整帧读放大——RELEASE-04 实测约 3.9GB/帧）；
3. 窗口内固定顺序：coverage→UPM（SNR 加权稀疏采样）→排异→SNR² 集成；窗口间独立；
4. 稠密 SNR 现场求值：用到哪个像素算哪个（稀疏-稠密等价已证 3.1e-15），不预计算稠密面、不驻留；
5. 归约顺序冻结（窗口 ID、像素序），1/N worker 逐位一致；
6. 探针按窗口记录耗时/输入量/worker 均衡。

## 验收门
- [ ] 窗口大小参数扫描：RSS 随窗口线性、与总图大小解耦；给扫描表；
- [ ] N=1/2/4/8/16 worker 逐位一致；
- [ ] 读放大显著低于整帧基线（给每帧读取量对比）；
- [ ] 与单窗口参考实现数值一致（冻结容差，复用 SCI-B/C Oracle）。

## 禁止
- 不改变排异档位、不改变科学口径；最终并行度调优归 PERF-501。
