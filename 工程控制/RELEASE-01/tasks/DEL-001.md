# 任务：DEL-001 成品帧交付

## 目标

在 VIS-001 与 PERF-001 全部通过、无任何可继续优化项后，把 **两个成品帧平面 FITS（只做 R 通道）** 交付负责人检查。负责人认可后进入 FIN-001。

## 权威依据

- 负责人指示：将两个成品帧（不需要全通道都叠加，只做 R 通道）的 fits 交付检查
- ACCEPTANCE_SPEC L4（平面 FITS + WCS、整幅）

## 改动范围（文件域，互斥）

- 允许改：交付产物整理（成品 FITS、交付清单、README 级说明）
- 禁止改：科学口径、实现（除非负责人退回要求修正）

## 步骤

1. 从 E2E-001 全流程产物中选取 **M42 与 Galaxy Center 两组**各自的最终成品帧平面 FITS（R 通道，仅 R 通道叠加，不做 G/B 全通道）；
2. 核验成品帧完整性：schema 校验、WCS 头完整、单位/像素语义、manifest 字段、无半成品；
3. 生成交付说明：数据来源（testdata 路径/帧数/滤镜）、处理链（normalize→mosaic→export 参数）、坐标/尺寸/单位、校验摘要；
4. 前台将两个 FITS + 交付说明 + 对应的整幅拉伸 PNG 一并交付负责人（只交付检查，不推送发布）；
5. 等待负责人检查结论：认可 → 进入 FIN-001；退回（指出问题）→ 登记问题、转修复、重跑受影响层、重新交付。

## 验收门（可机器复跑）

- [ ] 两个成品帧均为 R 通道平面 FITS，schema/WCS/manifest 校验通过；
- [ ] 交付说明完整（来源、处理链、坐标尺寸单位）；
- [ ] 成品帧与 E2E-001 产物一致（无重建偏差）；
- [ ] 负责人检查结论记录在案（认可/退回及理由）。

## 边界

- 交付是检查性质，发布决定仍属负责人（最高设计 §12）；
- 负责人未认可前，FIN-001 不得启动。
