# 任务：E2E-001 全流程真实数据端到端

## 目标

在 AUD/SCI/BLD/TST/DOC-002 全部 PASS 后，用 `testdata/` 的 **M42 与 Galaxy Center 两组真实数据**完成 normalize → mosaic → export 全流程，验证可行性、科学性、性能、原子性。

## 权威依据

- ACCEPTANCE_SPEC.md L3（小批量端到端流程与验收内容）与 L4（M42 + Galaxy Center 产品生成链）
- 最高设计 §3（输入合同、预检三级、-y/-force 语义）、§4（mosaic）、§5（export）
- 各插件文档的合同与输出 schema

## 改动范围（文件域，互斥）

- 允许改：运行产物（run/ 目录）、运行 JSON、日志；为通过全流程的**必要最小修复**登记转修（不直接大改）
- 禁止改：科学公式、默认容差、契约 schema（除 SCI-001 已批准订正）

## 步骤

1. **数据准备**：从 testdata/ 确认 M42 与 Galaxy Center 两组完整数据块（亮场 + 对应 bias/dark/flat，构成完整数据块），记录数据清单（滤镜、帧数、望远镜、binning、格式）；
2. **L3 小批量先行**（正式全量前）：每组抽少量帧跑通三命令，核对：三命令退出码 0、预检三级提示与 `-y`/`-force` 语义、Phase1 输出 JSON 直接满足 Phase2 输入格式并串行承接、schema 校验通过；
3. **L4 全量**：两组全量帧 normalize（全滤镜或按数据块）→ mosaic 拼成一整张马赛克 → export 经 HiPS 导出平面 FITS（整幅，WCS 直接生成）；
4. 科学与质量抽检：产品 schema 校验、manifest 字段完整、WCS 与已知天区坐标对拍、星点定位/通量抽检、帧级 SNR（含稀疏帧内层若启用）参与叠加的权重链路可追溯、无半成品（原子性）；
5. 并行确定性：同批数据 1 worker 与 N worker 产品数值一致；
6. 记录全部日志、资源记录、产物路径到验收证据；产出结构化运行摘要。

## 验收门（可机器复跑）

- [ ] 两组数据三命令串行跑通，退出码均 0；
- [ ] 预检三级提示语义按最高设计 §3.3 生效（绿 correct/橙 optimize/红 error，`-y` 跳过确认、error 阻断、`-force` 语义正确）；
- [ ] Phase1 输出 JSON 直接满足 Phase2 输入格式并串行跑通；
- [ ] 产品通过 schema 校验、manifest 字段完整；无半成品（原子性验证通过）；
- [ ] 1/N worker 数值一致（容差按合同）；
- [ ] 运行日志/资源记录归档，供 VIS-001 与 PERF-001 复用。

## 边界

- 全流程**不改科学口径**；运行中发现的缺陷登记转修后重跑受影响层；
- 若数据块不完整（如缺校准帧），按最高设计预检规则处理（error 阻断并报告缺项），不强行绕过。
