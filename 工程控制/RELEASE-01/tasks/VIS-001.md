# 任务：VIS-001 视觉验证

## 目标

对 E2E-001 产出的两组数据（M42 与 Galaxy Center）做**整幅 + 逐块 + 可疑区域放大**的视觉验收，确认无黑洞、亮斑、接缝，全局观感正常。

## 权威依据

- ACCEPTANCE_SPEC.md L4 §5.2 视觉验收清单（无黑洞/亮斑/接缝/星点质量/背景几何/全局观感）
- L4 §5.3（agent 提交前自行逐块检查并修复，从受影响层重跑）

## 改动范围（文件域，互斥）

- 允许改：拉伸/切块/裁剪脚本（随验收证据归档）、验收图产物、登记修复任务
- 禁止改：科学公式与默认容差

## 步骤

1. **拉伸**：用固定参数的深空非线性拉伸脚本（如带遮罩的反正弦/对数拉伸）把整幅平面 FITS 拉伸为 PNG；参数固定、可复现，两组用同一套脚本；
2. **切块**：Python 脚本按固定网格切分整幅 PNG 为分块 PNG（保留行列编号 + 整幅缩略图）；
3. **逐块目检**：按 L4 §5.2 清单逐块检查——无黑洞（零值/死区/未填充孔洞）、无亮斑（宇宙线/伪影/饱和溢出亮点）、无接缝（帧间亮度阶跃/重影/重复星点）、星点圆锐无拖尾、背景均匀；
4. **可疑区域放大**：对分辨率不足或有疑问的区域（交界处、稀疏区、高动态区、疑似伪影处）**裁剪放大后再次读取**，必要时叠加 WCS 网格核对星点位置；不因整体观感正常而跳过局部检查；
5. 发现问题：登记（天区/块/坐标/现象）→ 修复对应层 → 从受影响层重跑 → 重新拉伸切块目检；迭代直至两组数据全部通过；
6. 归档验收证据：整幅 PNG、全部分块 PNG、裁剪放大图、拉伸/切块/裁剪脚本、检查记录表。

## 验收门（可机器复跑）

- [ ] M42 与 Galaxy Center 两组整幅 + 全部分块 PNG 均按 5.2 清单逐项目检通过；
- [ ] 可疑区域均有裁剪放大图并标注结论（无异常/已修复）；
- [ ] 脚本与参数随证据归档，两组用同一套；
- [ ] 修复过的层级已重跑并重新目检；
- [ ] 检查记录表（块号 × 检查项 × 结论）完整归档。

## 边界

- 视觉验收以"人看得到的问题"为准，也覆盖统计性异常（异常零值比例、梯度跳变）；
- 目检无法判断的局部异常（如疑似伪影）用裁剪放大 + 数值抽检（该区域 min/max/中位数）辅助判断。
