# 球面梯度科学验证

梯度模块必须证明三件事：能恢复已知低频差异、能降低真实接缝、不会明显损害星点通量和真实扩展结构。

机器指标：每条 overlap edge 样本数、校正前/后 median difference 与 MAD、拟合 RMS、场幅值分位数、控制点覆盖、外推区域、连通分量、求解条件数。

最低验收：

- 注入梯度的峰峰值恢复误差 ≤10%，残留 RMS ≤注入峰峰值的10%；
- 真实两个接缝的中位差绝对值至少降低50%；
- 稳定参考星校正前后通量比中位数在 [0.98,1.02]，p95 偏差≤5%；
- 不允许无约束外推覆盖天区；无重叠连通的面板必须失败。

若真实天体结构与背景不可分，必须提供 mask/稳健采样策略和注入测试，不得仅凭视觉平滑判定。
