# 任务：BLD-201 全量构建与机器门

## 目标

在全部 A 类文档订正与 B 类代码订正落地后，跑通全量构建、测试与全部机器门。

## 权威依据

- ENGINEERING_SPEC.md §6（构建/测试/CI 规则）
- CONTROL_PACK_SPEC.md §7.1（验收三层：机器门 / 证据核验 / 文档-代码一致性）
- ASTROCS_DESIGN.md §11（验证体系）

## 改动范围（文件域，互斥）

允许改：`build/**`（构建产物，不入库）、`ci/checks.json`（若新增判据需登记）
禁止改：`lib/**`、`docs/**`、`contracts/**`、`config/**`（本任务只验证不改）

## 步骤

1. `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release`；
2. `ninja -C build` ⇒ **0 警告**；
3. `ctest --test-dir build --output-on-failure` ⇒ **全绿 0 失败**；
4. `python3 ci/run_checks.py` ⇒ **全部机器门转绿**；
5. 新判据（FIX-201 的 I/O 边界、FIX-204 的排异路由、FIX-205 的投影注册表、FIX-208 的事件流 schema）**登记进 `ci/checks.json`** 并跑通 `--self-test`。
