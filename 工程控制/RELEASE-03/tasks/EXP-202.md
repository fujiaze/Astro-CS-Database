# 任务：EXP-202 实验：NaN 处置 传播 vs 掩膜

## 目标

判定 NaN 在重采样与集成中的处置规则，消除两处相反合同。

## 权威依据

- ASTROCS_DESIGN.md §9（产品无效值语义唯一口径：无覆盖/无数据 = NaN；NaN 处置规则必须唯一并写进产品内容证据；两处相反即违规）
- IFC-01.md 🔴R5（`NUMERIC_STANDARD.md:13`「禁止 NaN 传播为合法产品」vs `STANDARDS_REGISTRY.md:173,271` DISP-DRZ-004「值 NaN 经 F_p 传播、不掩膜」；最高设计原文 NaN 0 命中）

## 改动范围（文件域，互斥）

允许改：`run/RELEASE-02/实验/**`（**不入库**）
禁止改：`lib/**`、`docs/**`、`contracts/**`、`config/**`

## 步骤

1. 构造含 NaN 的输入（无覆盖 / 无信息 / 坏点），走 drizzle + 集成 + 投影全链；
2. 两支：**传播**（NaN 经重采样扩散）与**掩膜**（NaN 处不参与、输出另行标注）；
3. 判据事前冻结：① 无覆盖区域在最终产品里是否可被下游正确识别；② 有效像素是否被 NaN 污染；③ 与上游权威产物语义是否自洽；
4. 三种数据面各跑；≥5 轮独立复核；
5. 定案后写进「产品内容证据」块，并订正相反的两处文档。
