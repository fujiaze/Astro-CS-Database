# 任务：EXP-205 实验：SNR 三口径精度对比

## 目标

判定 SNR 重建三条口径（稠密 / 稀疏重建 / 仅帧级）的精度排序与适用域——**不得预设稀疏一定最好**。

- ASTROCS_DESIGN.md §3.4（稀疏 SNR 层：存相对比值、中位数为 1）

## 步骤

1. 三条口径各跑同一输入，与**真值 SNR 场**对比（合成数据面可真值；真实数据面用独立方法交叉验证）；
2. 判据 SP-0 事前冻结（含精度、偏差、计算代价三维）；
3. **关键**：稀疏层的 Δ（控制点间隔）与相关长度 ℓ 的关系要扫（Δ/ℓ 从 ≪1 到 ≫1），找出稀疏重建的**失效边界**；
4. 三种数据面；≥5 轮独立复核；
5. 定案后给出「何时用哪条」的适用域表，并据此订正默认值。
