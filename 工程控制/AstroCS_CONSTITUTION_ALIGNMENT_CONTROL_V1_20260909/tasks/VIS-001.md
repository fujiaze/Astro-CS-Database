# VIS-001｜M42 与银心固定参数图像初审（负责人代表性产品验收前置）

> 依据：`04_OWNER_DECISIONS_20260910.md` 指令 2 与宪章 §14（图像初审清单）。
> 前置：`REAL-001` 已产出两套数据集的 Phase2 马赛克产品。

## 目标

对两套代表性数据集的 Phase2 产品做**固定显示参数**的图像初审，产出负责人可直接审看的证据：

1. **固定拉伸参数**（冻结于 `run/realdata/vis_params.json`，全数据集统一）：
   - 每滤镜：STF 自动 stretched 后固定 black/white/mid 值写入参数文件，同一数据集内不许逐图改参；
   - 预览尺寸上限：单图 ≤2048px、JPEG/PNG ≤2MB；raw 数据不出库；
2. **产出物**（落 `reports/realdata/previews/` 与 `artifacts/realdata/previews/`）：
   - M42：4 滤镜马赛克全图预览 + 12 面板接触表（panel×telescope 网格）；
   - 银心：5 滤镜马赛克全图预览 + 3 面板接触表；
   - 每图标注：数据集/滤镜/输入帧数/nused/nrej/coverage 摘要；
3. **初审清单**（逐图勾选，结果写入 `reports/realdata/VIS-001-CHECKLIST.md`）：
   - 接缝（panel 边界亮度/梯度跳变）
   - 黑洞/零覆盖区
   - 条纹、卫星线/飞机线（应被排异或显式登记）
   - 背景连续性（跨面板背景水平）
   - support/coverage 结构合理性（无异常方形边界）
   - rejection 是否吞星核/吞结构
   - 资源利用记录核对（REAL-001 时序无长时间低利用率）

## 写入白名单

- `reports/realdata/**`、`artifacts/realdata/previews/**`、`run/realdata/vis_params.json`
- 禁写源码/合同/science 文档；禁写 testdata/Gaia 数据。

## 非目标

- 不做色彩合成成品图（非 Phase2 语义）；不做美学调参；
- 不因视觉问题改科学实现——视觉缺陷登记 finding（附图与参数）移交。

## 验收

- 参数文件先于预览生成且被预览脚本实际消费（复跑位图逐字节一致，除时间戳）；
- 清单逐项有结论（PASS/FINDING+图号）；发现项≥1 不阻塞（如实登记）；
- 预览仅含脱敏统计与图，无原始 FITS/路径外数据；
- 抽验 3 张图与对应 manifest 输入哈希一致。

## 返回证据

scope/acceptance/provenance 三检查 + 参数文件 + 预览清单 + 初审勾选表。
