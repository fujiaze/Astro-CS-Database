# 课题：R-005 drizzle pixfrac 默认值的权威出处

状态：NOT_STARTED
依赖：—　交付状态词：CONCLUSION_READY（待负责人批准）

## 问题陈述

为 drizzle 的 pixfrac 默认值（现实现 0.8）确定**权威出处或权威取值**：要么给出科学依据把它写进 docs/science/DRIZZLE.md，要么给出应取值的推导与替代建议。

## 现有事实与空缺（编制时实测）

- 语义权威**已有**：docs/science/DRIZZLE.md（pixfrac ∈ (0,1]，语义 half=0.5*pixfrac，量纲无量纲，非法值拒绝 NO_DATA）；docs/algorithms/DRIZZLE_GEOMETRY.md（严格校验 pixfrac∈(0,1]）。
- **数值默认 0.8 无权威出处**：只见 docs/development/CONFIG_SCHEMA.md（旧口径文档）与 lib/orchestrator/configs/stage1.template.json（实现默认，非科学权威）。
- 已知相关约束：GC 专用配置用 pixfrac=1.0（无收缩分支），说明 1.0 与 0.8 在覆盖/分辨率取舍上语义不同。

## 权威依据（只读）
- docs/science/DRIZZLE.md（pixfrac 语义与不变量，只读）
- docs/algorithms/DRIZZLE_GEOMETRY.md、docs/algorithms/HIPS_WRITER.md（收缩与落格几何，只读）
- docs/references/SCIENTIFIC_REFERENCES.md（Drizzle 原始文献：Fruchter & Hook 2002）
- CFG-001 的 config/defaults.json（消费方，标 pending_authority）

## 研究方法
1. 先确认 0.8 的来源性质：查实现与历史配置，判定它是「沿用 Drizzle 文献的常见选择」还是「本项目的经验值」；给出检索与结论。
2. 从科学侧论证默认值：pixfrac 对分辨率损失、覆盖完整性、相关噪声的影响；给出取值区间内的权衡曲线（可解析或数值实验）。
3. 给出建议：a) 若 0.8 可被文献/推导支持 → 提案把它写进 docs/science/DRIZZLE.md 作为默认（附依据）；b) 若不能 → 给出应有默认值的推导与替代建议，并说明与现实现默认不一致时的迁移后果。
4. 反例：pixfrac 过小（分辨率/SNR 损失、覆盖空洞）、过大（最近邻化、相关噪声与走样）。
