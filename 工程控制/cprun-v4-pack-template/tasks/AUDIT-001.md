# AUDIT-001 核对实现与规范差异

## 目标
产出一份差异清单：实现现状 vs 规范要求，逐条标注差距与修复建议。

## 输入
- 规范文档：`docs/spec.md`（示例，换成真实权威文档路径）
- 代码现状：仓库当前 HEAD

## 要做的事
1. 通读规范，列出每条可验证要求
2. 对照实现逐条核对：满足 / 部分满足 / 不满足
3. 对不满足项给出修复建议与影响面

## 产出
- 差异清单写入 `audit-report.md`（仓库根目录，只读审计的唯一允许产物）

## 验收条件
- report-diff：清单覆盖规范全部条目，每条有结论

## 禁止事项
- 本任务只读：除 `audit-report.md` 外不得修改任何文件
