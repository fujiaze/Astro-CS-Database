# V4 数值与性能门禁

## 数值门禁（沿用 V3 有效阈值并扩展 Phase3）

| 门禁 | 阈值 | 适用 |
|---|---|---|
| 合成 Oracle 对拍（Phase3） | 输出像素与解析期望相对差 ≤1e-5（fp32 主）/1e-9（fp64 对照，抽样） | C6-002/C6-010 |
| 恒等重投影 | 同网格恒等映射输出位级等于输入（浮点重排容差 0） | C6-010 |
| Phase1/2 既有数值锚 | phase2 合成门禁全过（1T==2T 位级一致维持） | C6-012 |
| TSan | 全门禁 0 新增 data race | C6-013 |
| 2R 真实数据 | 与 V3 审核包 B32/A32 诊断结构性一致（tiles/integrated/controls/obs 同级），偏差须溯源 | C8-005 |
| 32R | 诊断结构与 V2/V3 历史证据同级一致；层缺口须显式记录 | C9-002 |

## 资源门禁（强制，机器判定，缺一不得 PASS）

| 门禁 | 判定 | 依据 |
|---|---|---|
| 并行利用率 | 重计算阶段全程采样；均值核心利用率 ≥ min(affinity 核数×50%, 已配置并行度) 否则 FAIL | 规则 9；V3 实测 avg_cores 0.85 为反例基线 |
| 串行段 | 任一重计算阶段 >1s 串行即 FAIL | 规则 9 |
| 内存 | 序列无异常增长（斜率阈值：阶段末 >2× 阶段初且无释放路径即 FAIL） | C5-015 |
| 竞态 | 运行期检测到 race 证据（TSan 日志/运行时断言）→ FAIL | V3 TSan 债务 |
| 报告完整性 | CPU/内存/I/O/线程/阶段五类序列齐备；缺失 → 不得 PASS | 目标文本 |
| 动态线程 | 线程数 == 有效 affinity 推导值（日志证明）；硬编码 → FAIL | 目标文本 |

## 性能基准

- full benchmark：逐内核（backend 每个 kernel）在两平台各一次全套（禁止反复重跑）；
  profile 文件生成后供 backend 选择；无 profile → baseline backend（仍动态多线程）。
- 32R 墙钟参考（非门禁，仅趋势）：V3 A32=1651s/B32=1741s；修复后应显著低于该值且
  利用率达标，否则资源门禁 FAIL。
