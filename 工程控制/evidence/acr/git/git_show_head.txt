    feat(acr): UTF-8 safe SHA-256 manifest tool for evidence (F-fix 10)
    
    添加 lib/acr/ci/sha256_utf8.py：UTF-8 安全的 SHA-256 清单生成与验证
    工具，解决审计 #9（中文路径编码错误）。
    
    特性：
    - 递归收集目录下所有文件，跳过 .git
    - 路径强制 UTF-8 解码（含中文路径）
    - 同时输出 JSON + 文本格式清单
    - verify 模式复核每个文件哈希
    - generate-and-verify 模式一次完成
    
    用法：
      python sha256_utf8.py generate <dir> <out.json>
      python sha256_utf8.py verify <manifest.json>
      python sha256_utf8.py generate-and-verify <dir> <out.json>
