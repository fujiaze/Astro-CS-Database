    feat(acr): add CPU profiling, real utilization control and classic experiments
    
    Phase C + G + H 完整实现：
    
    Phase C（CPU 画像 Benchmark）：
    - 新增 qualification/benchmarks/：
      - stream_benchmark.cpp：STREAM 式 CPU 内存（Copy/Scale/Add/Triad，FP32/FP64，5 ISA，多线程）
      - arithmetic_benchmark.cpp：算术吞吐（add/mul/FMA/div/sqrt，FP32/FP64，5 ISA，依赖链 latency）
      - reduction_benchmark.cpp：归约（sum/dot/min/max/L2/mean/variance，多精度多输入模式）
      - thread_curve_benchmark.cpp：线程曲线（1/2/4/8/12/15/16 线程点）
      - numa_benchmark.cpp：NUMA 本地/远端带宽
      - benchmark_common.hpp + benchmark_main.cpp：Google Benchmark 集成
    - profile_generator 扩展：填充 DeviceProfile.arithmetic/memory/reduction 字段
    - 新增 tests/classic/e17_model_fit.cpp：模型拟合验证（median 相对误差 <=15%）
    
    Phase G（95% 资源控制，实际利用率读取）：
    - 重写 utilization/cpu_controller.cpp：读取实际 CPU 利用率（Windows GetSystemTimes）
    - 重写 utilization/gpu_controller.cpp：NVML 动态加载读取 GPU 利用率，不可用时队列预算估算并标记 estimated
    - 重写 utilization/memory_budget.cpp：GlobalMemoryStatusEx 读取实际可用内存
    - 新增 utilization/system_metrics.hpp/cpp：系统指标读取
    - 重写 utilization/actual_tracker.cpp：记录实际平均/p95/控制误差/worker 参与历史
    - 控制器不修改 hardware-profile（只读）
    - 50/80/95/100% 目标点测试
    
    Phase H（经典实验 E01-E21 扩展）：
    - 扩展 E04-E16（transpose/convolution/resample/histogram/scan/gather/mandelbrot/gemm/fft）
    - 新增 E18 动态 CPU+GPU 工作池（无 GPU 则 SKIPPED，不 CPU 模拟）
    - 新增 E19 资源利用率控制（50/80/95/100% 目标点）
    - 新增 E20 故障和回退（插件缺失/无画像/画像损坏/显存不足/launch失败/device lost）
    - 新增 E21 持续与并发可靠性（30秒持续 + 重复启动 + Event 生命周期）
    - 新增 tests/fault/sanitizer_actual.cpp：实际 sanitizer 验证（ASan 未开启时 SKIPPED）
    
    已知工具链限制：
    - MinGW g++ 16.1.0 不支持 ASan（缺 libasan），sanitizer_actual 测试 SKIPPED
    - Phase D CUDA backend 编译集成未通过（nvcc 11.8 vs MinGW host 不兼容），GPU 画像 SKIPPED
    - 这些限制已如实记录，符合"无硬件/工具链不可用时 SKIPPED"规范
