# DOC-101 最新文档包替换核验

## 目标

负责人随本控制包提供最新文档包 zip（36 篇，含 RELEASE-01 后的科学订正与 U-1/U-2 修复）。解压替换仓库文档集并核验。

## 步骤

1. 解压替换，记录 zip sha256 与逐文件哈希，更新 DOC_PACK_MANIFEST；
2. 运行文档核验器（verify_doc_pack.py）：篇数、索引、引用可达、Mermaid 可解析、无治理痕迹（治理 ID/日期/commit/历史叙事、文档头元信息块）；
3. 重点复验本轮变更：
   - `07_noise_snr.md` PSFSNR 公式为 `c3·(Σ_j f_j)²/(c4·σ_n²)`，含通量型/功率比口径澄清；
   - 研究包许可证表、COAAD I/II + ZOGY 书目；
   - `ENGINEERING_SPEC.md` §7 根条目含 ACCEPTANCE_SPEC.md；
   - `docs/ci/01_CHECKS.md` §2 含 CHK-E2E-REPRO、CHK-EXIT-CONSISTENCY；
4. 旧文档残留扫描（旧公式 √(Σf²)、旧天光措辞"不受天光影响/不漂移"、混引书目、旧许可证）。

## 验收门

- 核验器 PASS；ENG-CONSTRAINTS、CHK-REGISTRY-DOC-SYNC 转绿；
- CHK-E2E-REPRO、CHK-EXIT-CONSISTENCY 在注册表与文档 §2 双向一致；
- 残留扫描零命中（命中项逐条解释或清理）。
