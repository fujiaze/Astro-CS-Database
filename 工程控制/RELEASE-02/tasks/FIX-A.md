# FIX-A 天光面链（接缝根因，发布阻断）

## 目标

闭合 P0-08（star_mask/sky_samples 零实现）、P0-09（UPM 天光面 b_k(x) 缺失）、P0-10（g_k 乘法响应未接线），消除 VIS-001 的面板接缝与背景台阶。

## 背景证据

- RELEASE-01 VIS-001：两组成品帧水平接缝可见，面板交界行中位数跳变为天区内部典型行差的 17.2–22.4 倍（M42）、9.8–12.4 倍（GC）；
- 根因：生产 UPM 只有帧级加性标量 b_k（`upm.cpp:4-27`，v6 求解器 `upm.h:202-211` Jacobian=1.0），无空间天光面；
- 设计权威：`ASTROCS_DESIGN.md` §4.4、`docs/plugins/algorithms_phase2/10_sampling.md`、`11_upm.md`、`UNIFIED_MODEL.md`。

## 必须实现的设计（负责人锁定的方法）

1. **星点掩膜 star_mask**：先检测星点/饱和/高结构区域并掩膜，天光采样只取掩膜外的低结构像素；
2. **每帧稀疏天光采样点 sky_samples**：在掩膜外按规则密度取稀疏特征点（不是稠密网格、不是整帧一个数），每点记录天球坐标、天光值、该点 variance、点 SNR；
3. **采样点按点 SNR 加权**：点权重 ∝ 点 SNR²，低信噪比/光污染帧的采样点低权重，防止烂帧把参考面异常拉高；
4. **构建统一参考天光面 B_ref(x)**：用全部帧的全部采样点联合拟合一个稀疏表示的大尺度参考面（样条/低阶曲面/插值，具体基函数由子 agent 对照 SWarp back-coadd、SExtractor Background2D、Siril 背景模型研究后选定并给出依据）；
5. **每帧相对参考面的偏差 δ_k(x)**：b_k(x) = B_ref(x) + δ_k(x)，δ_k 为每帧稀疏系数；拟合目标是各采样点残差加权 RMS 最小；
6. **乘法响应 g_k**：同时求解每帧乘法响应并在生产链接线（v6 已有求解器，接 CLI 主链）；
7. **稀疏表示、按需求值**：不预建稠密天光面、不一次性载入内存；叠加分块进行（最小单元可到一个像素），用到哪个像素的 b_k(x)/g_k 就现场求值该像素；CPU 与内存权衡方案写入 `19_runtime.md` 同级设计说明；
8. phase2 自动检测稀疏 SNR 层：有则重建参与，无则按帧级权重（FIX-C 联动）。

## 研究前置（子 agent，AGENTS §8）

- 对照 SWarp（`src/back.c` 网格背景 + `RESCALE_WEIGHTS`）、SExtractor/SEP Background2D、Siril 背景建模、SCAMP（只做相对零点，不可作为天光面依据）的真实源码，确认：采样策略、面的阶数/节点密度、加权方式、边界与外推、与 drizzle 球面分块的兼容；
- 若研究表明负责人锁定方法的某一步在统计上不优（例如 δ_k 参数化过拟合/欠拟合），给出推导与改进方案，按 §3a 自决落地并留痕；方法方向性变更（不做天光面）才上呈。

## 验收门

- 合成数据：注入已知的大尺度梯度 + 面板间台阶 + 乘法响应差异，恢复面与注入面的残差 RMS 达到文档容差（容差由研究标定，写入 GATES_AND_TOLERANCES）；
- 合成数据：低 SNR/光污染帧不把参考面拉偏（加权前后对照实验）；
- 真实数据：重跑 L4 后，面板交界行中位数跳变降至与天区内部典型行差同量级（目标 ≤2×），4×4 分块与裁剪放大无可见台阶；
- 内存：天光面相关内存不随帧数/像素数无界增长（稀疏系数 + 按需求值，有实测数据）；
- 1 worker vs N worker 数值一致；
- 新增 Oracle 正例 + 负例（无采样点、采样点全被掩膜、单帧、外推区），fail-closed。
