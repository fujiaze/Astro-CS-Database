# E2E-102 L3/L4 全流程重跑（R 通道两组）

## 目标

在闭合后的代码上重跑小批量（L3）与全量（L4）端到端，确认可行性、科学性、性能路径全部正确。

## 数据（沿用 testdata v1.2）

- M42：T2 M1–M6 + T3 M1–M6，Red 300s，共 49 帧；无 300s 暗场，用 600s 暗场 K=0.5 缩放；
- Galaxy Center：T4 panel1–3，Red 180s，共 32 帧，有 180s 暗场 K=1；
- 仅 R 通道（负责人指示）；产物落 run/，不落 testdata；L4 前确认工作盘 ≥100 GiB。

## 步骤与验收

1. **L3 小批量**：两组各取 8 帧，三命令 rc=0；WCS 闭合 RMS 不劣于 RELEASE-01（M42 0.1028″、GC 0.3242″）；
2. **科学路径核查（关键差异）**：
   - p1 产品 `variance_available=true / ivar_available=true`（RELEASE-01 为 false）；
   - HiPS 头含 frame_snr 标量（F_ref/σ_F 口径）；
   - mosaic 日志/产品证明走的是逆方差/point_information 路径（不再是 weight_mode=1 显式等权降级）；
   - 天光面 b_k(x)=B_ref+δ_k 与 g_k 实际参与（有系数/残差证据）；
   - 输出含 variance/covariance；
3. **L4 全量**：两组全帧 normalize→mosaic→export（full + vis）rc=0；记录各阶段墙钟；
4. **1/N worker 一致性**：派生 workers=1 配置重跑同一科学配置，逐产物比对，canonical hash 一致（路径报告差异除外）；
5. **负例**：缺 ivar 时默认逆方差路径 rc=2（fail-closed）；weight_mode 非法值 rc=2；
6. export 官方模板直接可用（FIX-D 联动验证）。

## 证据

- 全量日志、p1/p2/p3 产品 JSON、WCS 闭合报告（closure_metric 独立 Oracle）、1/N 一致性报告、磁盘/资源 trace；
- 任何与 RELEASE-01 结果的数值差异给出科学解释（预期：加权方式与天光面改变后背景更平、深度略变，属正确变化）。
