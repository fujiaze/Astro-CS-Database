# TST-101 测试补齐与负例面

## 目标

闭合 RELEASE-01 TST-001 的 PARTIAL：46 个注册检查仅 11 项自带可执行负例；resample/benchmark/hips_browser 零模块级用例；6 个真实 HiPS 用例 fixture-gated；新功能（天光面、ivar 链、sparse layer、canonical weight_mode）需要完整测试。

## 内容

1. **负例补齐**：35 项缺可执行负例的检查，逐项补"注入错误必须判红"的可执行用例（不是人工说明、不是借壳）；19 项人工说明负例全部脚本化；
2. **零测试模块**：resample、benchmark、hips_browser 补模块级测试（acr 为 dormant，按 ACR-DORMANT 退出面处理）；aio 顶层测试零注册问题 RELEASE-01 已激活 5 个，复查剩余 3 个未注册的原因并闭合；
3. **fixture 解锁**：FIX-B 修复 frame_snr/HiPS snr 产品后，6 个写死 Windows 路径（已改环境变量）的真实 HiPS 用例必须从 SKIP 转执行并通过；
4. **新功能测试**（与 FIX-A/B/C 同步滚动）：
   - 天光面：梯度/台阶注入恢复、加权抗污染、稀疏/稠密等价、外推 fail-closed；
   - 方差链：校准/cosmetic/drizzle 每步方差传播解析对拍、缺方差 fail-closed；
   - 集成：point_information 方差最小性、sparse layer 开关两路径、weight_mode 词表正例/非法值负例；
   - 性能：RESOURCE-GATE-REAL 串行注入负例必须判红（已有 NEG 门，复核）；
5. **检查器质量**：每个检查器自身带 --self-test；CHK-EXIT-CONSISTENCY 复跑保持绿（防止新代码引入 fail-open）。

## 验收门

- 注册检查可执行负例覆盖率 100%（确有不可自动化项，显式登记理由并经前台复核）；
- 零测试模块清零（dormant 除外）；fixture-gated 6 用例全部执行；
- 新增测试本身经过变异验证（故意改错实现，测试必须红）；
- 全量 ctest 0 失败、0 充数 SKIP；TMPDIR 用源码树外路径。
