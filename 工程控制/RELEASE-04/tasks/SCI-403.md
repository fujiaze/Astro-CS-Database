# 任务：SCI-403 实验单元 SCI-C — 加性天光与无接缝叠加

## 目标
用实验证实或证伪创新点三（最高设计 §2.3）的核心猜想：信号校准到测光星等坐标系后真实信号帧间连续，帧间接缝全部来自可加性去除的天光；UPM 联合全部帧建立连续绝对天光参考平面、各帧多退少补（只扣 δ_k、保留公共面 B_ref）后，叠加结果天然连续无接缝。给出猜想成立的条件与失效边界；若乘性成分无法由 Phase1 空间增益吸收，带证据上呈并提出顶层修正方案。

## 步骤
1. **纯加性世界**：HST 模板当纯信号，注入已知加性天光（平缓梯度 + 散粒噪声，各帧不同 δ_k）、噪声与 PSF，多帧覆盖；UPM 后验证：任意覆盖子集边界加权阶跃恒为零（formulation 四要素：exclude-self 参考面、阻尼 α≈0.5、拟合/堆叠权重同源、末端残差场扣除）；
2. **乘性世界（关键张力）**：注入低阶空间乘性响应（平场残差 m(x,y)），验证经 Phase1 apply photometry 的 m(x,y) 扣除后残余归零、Phase2 保持纯加性（g_k≡1）；若残余中乘性成分不可被低阶增益吸收（历史实测帧间差曾达 1.56×），量化幅度、空间频率与来源，给出"纯加性猜想"成立条件，证据不足以上呈；
3. **多退少补与公共面**：验证 calibrated=raw−δ_k、B_ref 被保留（叠加产品仍带背景、无大面积负值）、gauge 约定承载零点；
4. **非退化接缝判据**：构造证明"全减背景后看帧间差"是退化判据（背景皆零时差值天然为零）；正式判据在保留背景前提下度量边界跳变与帧间一致性，并能对注入接缝灵敏（红/绿双向测试）；
5. **采样权重**：天光采样点 control_ivar 与候选权重（SNR²、uniform 等）对照，验证真实信号加权 RMS 最小；星点掩膜 + 稀疏采样（每帧都取）+ 联合参考面 + 梯度校准的完整链路；收敛判据无量纲、converged 枚举 0/1/2/3 行为对拍；
6. **内存等价**：验证稀疏参考面栅格值按需现场求值、不构建稠密背景栅格，数值与稠密数学表示等价（容差冻结）；
7. **真实数据衔接**：M42/银心小批量上计算接缝度量分布，与 VIS-401 切块目检建立对应（度量红的位置目检确有接缝）；
8. 独立审稿、八要素收口；若猜想被证伪，按 AGENTS §8 走顶层变更上呈，附替代方案（如加性+低阶乘性联合模型）的实验比较。
