# 任务：FIX-406 SIGTERM 退出码与 SIN 容差复核

## 目标
三阶段 SIGTERM 全部 exit 9（协作取消→关 writer→incomplete manifest→清理→退出）；SIN 投影往返容差经复核后冻结为科学合理值。

## 权威依据
- ASTROCS_DESIGN.md §7.2（退出码 9）、§6.3（投影）
- GAP_AUDIT G3-6、G3-15

## 改动范围
- 允许改：CLI 信号处理与三阶段取消路径、投影容差合同（经 SCI 复核）、测试
- 禁止改：投影算法实现本身（发现算法错误另开任务并走科学查证）

## 步骤
1. 三阶段（含 HiPS 写入、mosaic 长循环、export 流式写）注入 SIGTERM/SIGINT，验证统一 exit 9、incomplete manifest、临时产物清理；
2. Windows 等价路径（CTRL_CLOSE/CTRL_C）在双平台 CI 有对应测试或显式登记平台限制；
3. SIN 内核往返 2.5e-5px：用 WCSLIB/Astropy 独立 Oracle 判定该量级是算法真实精度还是实现缺陷；若 2.5e-5px 已远低于物理有意义尺度（像素/采样尺度），按实验结果冻结容差并写入投影合同；若可改进则修复；
4. 测试覆盖各阶段取消点（启动时、计算中、写盘中）。

## 验收门
- [ ] 三阶段 × 三个取消点 SIGTERM 均 exit 9 且无半成品；
- [ ] SIN 容差有 Oracle 依据并冻结进合同（给出实验表）；
- [ ] ctest/CLI 测试全绿。

## 禁止
