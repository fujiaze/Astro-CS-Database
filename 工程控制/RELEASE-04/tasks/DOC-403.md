# 任务：DOC-403 双向层级索引闭合

## 目标
建立最高设计 → 下级文档 → 合同的双向索引体系，任何机制都能从最高设计追溯到细节，任何下级文档都能回到上游条款；悬空索引由机器门拦截。

## 权威依据
- ASTROCS_DESIGN.md §0.2（详细文档层与双向索引）
- ENGINEERING_SPEC.md §8、§10（悬空即缺陷、机器门）

## 改动范围（文件域，互斥）
- 允许改：`docs/DOCUMENT_INDEX.yaml`、各下级文档抬头索引区、`ci/checks.json` 与对应检查器、`docs/ci/01_CHECKS.md`
- 禁止改：根文档正文（指针已在新版最高设计中写定，如发现指针目标缺失，补目标文档而不是改指针）、代码

## 步骤
1. 以最高设计每节末尾的索引指针为准，核对目标文件与章节存在；缺失的补建（内容由对应 DOC/SCI 任务提供，本任务只登记缺口）；
2. 每份下级文档抬头加"上游条款"区：列出本文档落实最高设计的哪几节（如 `上游：ASTROCS_DESIGN §5.4、§5.5`）；
3. 重写 `docs/DOCUMENT_INDEX.yaml` 为唯一索引地图：文档路径、职责一句话、上游条款、下游被引用处；
4. 新增/增强机器门 `doc-index`：
   - 最高设计与根文档中的每个 `docs/...` 链接目标存在；
   - 每份下级文档在 DOCUMENT_INDEX.yaml 有登记且抬头有上游条款；
   - 代码注释与文档中引用的 `docs/` 路径存在（与 FIX-404 的代码路径门共用数据）；
   - 检查器 fail-closed，配 `--self-test` 正例（合法索引）/负例（悬空指针、缺抬头、未登记文档）。

## 验收门（可机器复跑）
- [ ] `doc-index` 检查在干净仓库 rc=0；
- [ ] 注入一个悬空链接、删一个抬头、漏登一篇文档，三种负例分别判红；
- [ ] 最高设计全部索引指针 100% 可达（机器出表）；
- [ ] 下级文档抬头上游条款覆盖率 100%；
- [ ] `ci --all` 全绿。

## 禁止
- 不用"README 合集"代替索引地图；
- 不放过任何悬空指针（包括代码注释里的文档路径）。
