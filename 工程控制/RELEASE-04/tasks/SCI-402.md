# 任务：SCI-402 实验单元 SCI-B — 跨帧绝对 SNR 传递链

## 目标
用实验证实创新点二（最高设计 §2.2）：帧级 SNR 只计真实源信号与噪声（信号扣独立局部背景、天光只进散粒噪声项，天光升高 SNR 趋零），每帧产出帧级 SNR 标量 + 稀疏相对 SNR，Phase2 插值重建稠密并以逆方差（w=SNR²/F_ref²）参与信号层拟合与叠加；给出 dense/sparse/frame 三口径适用域图谱。吸收 EXP-205 已有结论并补齐物理仿真闭环。

## 步骤
1. **方法学对标**：研读 PixInsight PSFSNR 与 PSF Signal Weight 官方文档/可获得的开源实现，写清：PSFSNR 是功率比信噪比、PSFSW 是 SNR² 形式的权重；AstroCS 入库的是未加权原始 SNR、权重在 Phase2 消费时计算；给公式对照与差异说明；对标 Siril 加权、Horne 1986（σ_F⁻²=ΣP_i²/σ_i²）、Zackay & Ofek point information；
2. **物理仿真真值**：固定源信号、扫描天光水平（含天光散粒噪声）、读出噪声、暗流、不同 PSF，Monte Carlo 生成大量帧，统计帧级 SNR 经验真值，与定义式对拍；
3. **天光无关性负例（核心）**：固定真实源信号、仅抬升天光，帧级 SNR 必须单调下降并趋零；传统"信号含天光"口径作为对照必须显示失真；信号经独立局部背景估计扣除，验证背景估计偏差对 SNR 的影响边界；
4. **稀疏层与稠密重建**：稀疏相对场（中位归一、间隔 64px 默认，参数实验复核）+ 插值重建稠密 SNR，平滑噪声区/结构化噪声区分别给精度与预测方差；无稀疏层时帧级重建等权稠密；
5. **三口径适用域图谱**：在地面视宁度受限（testdata 三帧型）、HST 高对比结构、不同 Δ*/ℓ 条件下比较 dense/sparse/frame 的 RMSE 与存储代价，复核 sparse_reconstruct 默认值的适用域依据，给出失效边界；
6. **逆方差集成对拍**：独立帧验证 SNR_combined²=ΣSNR_k²；point information（Q/W）集成对解析解；拟合权重（1/σ²，可加 Huber）与堆叠权重（残差制造者方差含拟合协方差）分离验证；F_ref 固定参考星等（m_ref=6.0）锚定的跨帧可比性；
7. **传递到 Phase3**：方差经重采样 C_out=R C_in Rᵀ 传播、点源信息量按输出 PSF 重算的对拍；
8. **退化门审查**：确认 SP-0"帧级臂 RMSE 恒等于 s_field"类恒真门不充当证据；fail-closed 路径（污染/退化 SNR）对拍；
9. 独立审稿、八要素收口、实现修正清单转 FIX。
