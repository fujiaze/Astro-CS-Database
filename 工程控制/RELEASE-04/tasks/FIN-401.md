1. README 重写：项目是什么、三命令用法（含 --json/--template/--help/预检语义）、系统要求、构建、测试数据说明、当前能力与已知限制、文档集入口（从最高设计开始读）；

3. 发布包白名单（唯一 exe/ELF + dll/so + schemas + config + manifest），生成哈希清单与 SBOM（第三方组件+版本+许可证）；GPL 组件合规确认；
4. 四层验收证据与 ACCEPTANCE_REPORT 归档核对，发布门 §8 八项逐条打勾；
5. 控制包收口：RELEASE-04 的结论沉淀进正式文档后，按 CONTROL_PACK_SPEC §9 删除 `工程控制/RELEASE-04/`（过程留 git 历史）；run/ 临时产物确认不入库；
6. 最终 main 三 SHA 核对，输出交付清单，声明 READY_FOR_OWNER_REVIEW，等待负责人发布指令（agent 不自行发布）。
