小批量真实数据上三命令串行跑通（L3），预检三级与确认语义逐一对拍，并行确定性、取消语义闭合。

## 步骤
1. 从 testdata 抽小批量（每滤镜组少量亮场+全套校准帧，覆盖两台望远镜/两种滤镜）；
2. `normalize --json` → 输出 JSON 直接作为 mosaic 输入 → mosaic → export，三命令 rc=0，产品 schema/manifest 全过；
3. **预检语义对拍表**（自动化 CLI 测试）：
   - 全正确配置：显示页面、🟢 correct、等待 yes；无 yes 不运行；`-y`/`-yes` 跳过确认直接运行；
   - 暗场曝光差超容差：🟠 warn，显示页面、需 yes、运行不被阻塞；`-y` 可越过；
   - 文件缺失/未知滤镜/JSON 非法：🔴 error，显示页面并阻断；无 yes 入口；`-y`/`-yes` 仍阻断；`-force` 跳过整个检查步骤直接运行；
   - 磁盘余量不足：warn 不阻断；
4. 1 worker 与 N worker 同输入产品数值一致（合同容差）；
5. SIGTERM exit 9（与 FIX-406 联动复核）；
6. WCS 与已知天区坐标对拍、星点通量抽检；资源记录归档。
