- SCI-C 接缝度量（SCI-403 产出）作为定量判据

## 前置

## 步骤
1. 环境：工作盘 ≥100 GiB；TMPDIR 用源码树外可写目录（如 `/dev/shm/astrocs_tmp`）；benchmark profile 就位；
2. M42（T2+T3 Red 300s，49 帧；无 300s 暗场用 600s K=0.5 路径，预检应给对应提示）全流程；Galaxy Center（T4 panel1–3 Red 180s，32 帧，K=1）全流程；
3. export 输出整幅平面 FITS（WCS 直接计算生成）；
4. 固定参数拉伸脚本（带遮罩反正弦/对数）出整幅 PNG；Python 切块脚本按固定网格切块（带行列号与缩略图）；脚本与参数归档；
5. **agent 视觉初审**（提交负责人前必须自做）：按 ACCEPTANCE_SPEC §6.2 清单逐块检查——无黑洞、无亮斑、无接缝、星点圆锐重合、背景连续、WCS 吻合、全局观感；分辨率不足处裁剪放大再读；接缝度量（SCI-C）红区必须与目检一致并清零；
6. **分段计时**：三阶段逐节点墙钟/CPU/RSS/IOWait、worker 均衡，找热点并优化（每轮优化记录前后对比），直到无明显可做的优化；
7. 发现任何问题：登记 → 回对应层修复 → 从受影响层重跑（不只重导出）；
8. 验收包：两张平面 FITS、两组整幅+切块 PNG、脚本、三阶段日志、资源时序、计时热点报告、SCI-C 接缝度量结果。
