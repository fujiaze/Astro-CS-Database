# 任务：SCI-401 实验单元 SCI-A — 测光校准到测光星等坐标系

## 目标
用实验证实创新点一（最高设计 §2.1）：只对 Gaia DR3 XP 逆映射定位的星点测光，用 XP 光谱 × CCD QE × 滤镜透过率积分正向合成期望测光量并拟合，把整帧校准到测光星等坐标系、消除物理单位。实验通过后，结论订正进 `docs/science/PHOTOMETRY.md` 并指导 Phase1 实现修正。

## 步骤
1. **数据准备**
   - HST 物理仿真：以 `HST_M16/` F657N/F673N drz（带 PHOTFLAM）为纯信号模板，按完整前向过程生成仿真帧：星点注入已知星等（星表取 Gaia XP 光谱）、电子域 Poisson（源+天光+暗流）、读出噪声 Gaussian、增益/饱和/量化、平场乘性 m(x,y) 与天空梯度；固定 seed；
   - 纯代数合成：已知星等星场 + 已知 k_photo/m(x,y)，无噪声与多噪声两组，供不变量验证；
   - testdata：M42/银心小批量真实帧作底参照。
2. **正向合成验证**：XP 光谱 × QE × 透过率（+光学响应）积分合成的通带通量，与 HST PHOTFLAM 定标通量对拍（跨滤镜/跨星色），给出残差与色项；
3. **逆映射定位**：粗 WCS → Gaia 逆投影候选 → PSF/质心拟合，统计匹配率、虚警（拟合失败丢弃）、相对全图盲检测的算力节省（计时）；top 2–5 万上限与极限星等估计的合理性；
4. **标定拟合**：每帧独立拟合 k_photo（与低阶 m(x,y)），验证标定后星点星等对 Gaia 残差落在误差预算双边界（σ_floor/σ_ceiling，由各噪声项逐项推导）；不同透明度合成帧系数不同但残差分布一致；
5. **物理单位消除论证与负例**：证明产物只以星等表达、k_photo 绝对值无意义、物理闭合反推不出现（构造反推实验证明不可辨识）；注入平场残差/天光梯度时残差度量如实变大；真值无效应场景度量归零；
6. **apply photometry**：验证归一化落到像素后下游（drizzle/SNR）消费的是归一化像素；未启用路径显式 degraded_reason；
7. 独立子代理多轮审稿（审稿者非作者），按报告八要素收口；
8. 结论：成立/不成立/证据不足 + 适用域 + 对实现的修正清单（转 FIX 任务）。
