## 1. Phase1 测光：是整帧单标量，还是校准了渐晕残差？

### 1.1 结论：**是整帧单一标量乘法校准，不校准渐晕/平场残差**

**定义式**（`lib/algorithms/calibration/src/photometry_apply.h`，规范依据 `02_FROZEN_STAGE1_HISS_SPEC §7`）：

```
I_photo = k_photo · I_cal
k_photo = scale = 10^(−location)
location = Tukey-IRLS(c=4.685) 稳健位置( r_i = log10( F_instr,i / F_syn,i ) )
F_syn = ∫ S(λ)·T(λ)·Q(λ)·λ dλ      # Gaia XP 光谱积分
```

- **`k_photo` 是单一全局标量**：无空间项、无颜色项；
- 应用是**全帧统一相乘**（`photometry_apply.cpp:63` 单一 `for` 循环）；
- **⇒ 它只能消除「整帧」的乘性差，原理上无法消除空间相关的乘性残差（渐晕/平场）**。

### 1.2 合成证明（`q1_photometry_gradient/`）

**实验**：N=6 帧部分重叠，真值已知（`S0=1091.5 ADU`、`σ=5`、`a_k∈[0.80,1.20]`、加性梯度 `pp=4%·S0=43.7 ADU`）。

| 量 | 结果 |
|---|---|
| 单标量校准后「帧间差平滑 pp / 真值梯度 pp」 | **survival = 1.005**（纯加性版）/ **1.008**（被 `a_k` 调制版）⇒ **梯度 100% 残留** |
| 无梯度负例（真值梯度=0） | `smooth_pp` 2.54 ADU、`quad_pp` 0.28 ADU ⇒ **度量会归零**（证明残留是真信号） |
| 马赛克边界台阶 | 原始 **303.6** → 仅单标量 **19.06 ADU = 1.75% 背景** → 标量 + 真值加性校正 **3.18 ADU ≈ 噪声** |

**解析**：`y/a = s + g/a`（或 `s+g`）—— **除法只改整帧增益，去不掉空间加性项**。

### 1.3 真实数据证明（`phot_verify/`、`q3_additive_truth/`）

| 量 | 结果 |
|---|---|
| 扣掉帧级标量后，overlap 内 8×8 分箱 `log10(y_A/y_B)` 峰峰值 | xtel_m1 **0.067 mag**、xtel_m4 **0.078**、xtel_m5 0.052、within_m1 0.029 |
| 独立天光径向探测（扣平面后） | **±2–3%**（PTP 4–6%） |
| 扣掉帧级标量后，逐星比值 3×3 块中位峰峰 | 同镜 0.77–12.62%；**跨望远镜 8.72–9.93%** |
| 形态 | **线性梯度（平场大尺度残差）为主，不是径向渐晕**（`R²` 项中位 `|r2c|≈0.009–0.022` ≪ 线性项） |

**⇒ 空间乘性残差在扣掉单标量后依然存在，量级 0.05–0.08 mag（5–8%）。单标量校准不掉。**

### 1.4 可辨识性（关键限制，`q1_photometry_gradient/`）

`a(p)`（空间乘性）与 `g(p)`（加性梯度）在**背景上不可分离**：

```
变换  a → a + δ/s ,  g → g − δ   保持 y 不变
数值验证:  max|Δy| = 3.6e−12 ADU
背景上「纯加性(a=1,g=δ)」vs「纯乘性(a=1+δ/S0,g=0)」:  6.0 ADU  vs  梯度 pp 68.1 ADU  ⇒ 不可分辨
```

**只有星点能破缺**（流量比 `pp=3.1%`）。
**⇒ 正确做法：`a` 限为整帧标量（星点定）+ `g` 限为低阶多项式（背景定），才唯一。**

## 2. 接缝：无阶跃的正确 formulation（`fix_p2a_seam_oracle/`）

### 2.1 生产双重扣除是有害的（`c_delta_composition/`）

| 组合 | 帧间 std/M（中位） | 留一台阶/M（中位） |
|---|---|---|
| `raw`（不校正） | 13.454% | 8.113% |
| `raw − δ_k` | 2.799% | 2.100% |
| **`raw − C_k`** | **0.131%** | **0.098%** |
| **`raw − C_k − δ_k`（生产）** | **13.974%** | **9.479%** |

**⇒ 生产比完全不校正还差**；`raw−C` 单独压 100×。

### 2.2 无阶跃的代数条件

```
残留场  R(p) = Σ_{k∈S} w_k · g_k / W_S
无阶跃的充分条件:  g_k = ḡ（各帧校正量公共）
```

| formulation | 合成最大阶跃（无噪/含噪） |
|---|---|
| (a) 参考帧 gauge（旧生产） | 0.209 / 0.260 |
| (b) 全局均值零 gauge | 0.209 / 0.260（与 a 逐位相同） |
| **(c) 排除自身 + 阻尼** | **0.035 / 0.060（小 4–6×）** |
| (d) 全帧平均自反馈 | 4.91 / 4.93（发散） |

**重要**：naive Gauss-Seidel（α=1）在链式/二部覆盖图有特征值 **−1**，周期 2 振荡**永不收敛**，须阻尼 **α≈0.5**。

### 2.3 自洽方案

拟合权重与叠加权重**同源** → (c) 排除自身 + 阻尼 → 末端**用叠加权重本身**算残差场并从每帧扣除
⇒ `Σ w_k·g_k/W ≡ 0`，**任意覆盖子集 / 任意权重面，阶跃恒 0.0000**（实测）；
若 gauge 权重与叠加权重解耦，阶跃重现（0.4285）。

## 3. 信噪比传播（`fix_p2b_variance_oracle/`、`unc_propagation/`）

### 3.1 正确形式：残差制造者，**不是**朴素式

```
corrected = (I − H) y = P y          # P = 残差制造者
Var(corrected) = P Σ Pᵀ + J_out C_θ J_outᵀ
对角:  Var(corrected_i) = Σ_j P_ij² σ_j²  +  param_i
```

**错误形式** `σ² + Var(ĝ)` 漏掉交叉项 `−2ΣHᵀ`；最简例 `ĝ=ȳ`：
正确 `σ²(1−1/N)` vs 朴素 `σ²(1+1/N)`，**N=8 高估 1.2857×**。

### 3.2 权重序（实测翻转）

| 权重口径 | 排序 |
|---|---|
| `w=1/σ_raw²`（旧） | A > C > B > D |
| **`w=1/Var(corrected)`（正确）** | **A > B > C > D** |

Kendall τ=0.667；A/B 权重比 **6.76 → 1.69**（`g=2` 帧被压低 ~4×）。
真实 L4 控制级朴素/正确中位 **1.2591**、最大 **31.99**。

### 3.3 低 SNR 帧对公共面的污染

偏差以 `w_L/(w_H+w_L)` 漏入：**SNR 权 0.4% / 等权 20.5% / 反权 40.5%**（1:50:100）；
MC 噪声 RMS 等权是 SNR 的 **5.0×**。
