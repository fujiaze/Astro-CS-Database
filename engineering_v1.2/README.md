# AstroCS 下一阶段完整开发包 v1.2

本包用于接续已经完成的 CLI Core v1.1 工程基线。它不推翻既有 `engineering/`，也不重做 G0–G8；新增 G9–G16，集中解决四条主线：

1. 证明并修正 WCS 坐标约定闭环，恢复真实测光匹配和 SNR；
2. 读取 TestData 各子目录说明，整理 T1–T4 四套设备、滤镜和完整主校准帧映射；
3. 使用银心三片 Red 共 32 帧进行真实大尺度球面梯度、稳健叠加和 HCSD 验证；
4. 将球面浏览器从同步 CPU 全量重采样改为异步 Tile I/O + GPU Tile Renderer，并交付可直接查看的银心结果。

## 使用方式

用户只需把压缩包放到仓库根目录，并向 Agent 发送 `START_PROMPT.txt` 中的一句话。Agent 自动解压、读取入口、核对既有状态并持续执行。

## 关键边界

- 当前产品仍是原生 CLI 内核；GUI 后续通过 JavaScript/进程协议控制 CLI。
- Orchestrator 是算法模块、PipelineFrame、持久化格式和上层控制之间的连接核心。
- PlateSolve 的单次内部检测共享导出路径已经在主线；不得重复改回两次检测。
- WCS Y 轴/SIP 符号问题是高概率假设，但必须先通过真实星对闭环证据确认，不得盲改符号。
- Gaia 光谱解析与合成积分已有成功证据；测光当前主要阻塞在 Gaia→像素→PSF 的空间匹配。
- 用户确认 TestData 仅 T1–T4 四套设备并配齐全部主校准帧；若解析器报告缺失，应先修匹配规则。
- 银心三片马赛克是本阶段唯一正式大尺度科学验收数据集。
- 浏览器优化不能靠降低数据分辨率或预先转为 uint8 假装流畅。
