# eng/ci — 持续集成执行面

本目录承载持续集成（CI）的**执行面**：把各构建与测试步骤的原始输出收成结构化报告，
并按一份显式的**阻塞清单**给出退出码。

设计正本见 `run/GOVERN-08/审核包-R2/T12-持续集成设计.md`。

## 与门禁的关系

CI **不是门禁**。按 `standards/05_INDEPENDENT_TEST_SUITE.md` §4，
测试集接入 CI 以非阻塞为常态，只有科学口径错误才设为阻塞项。
本目录的退出码默认恒 `0`；`--enforce` 只对阻塞清单里的步骤生效，
而阻塞清单由设计正本逐条论证判别力后给定。

## 文件

| 文件 | 作用 |
|---|---|
| `collect_report.py` | 报告收集器：解析各层运行器 stdout，落 `report.json` + `summary.md` |
| `steps.yaml` | 步骤清单：每步的编号、车道、依据、阻塞与否、判别力论证 |
