# migration

文档重组批次的路径引用重写工具：机械、可审计、默认 dry-run。

## 职责边界

- 放：按批次规则对仓库文本文件做路径字符串重写，输出文件数、处数与样例。
- 不放：正文语义修改（只做路径级替换）、重写结果的验证门（在 `eng/tools/doccheck/`）、检查项注册表（在 `eng/ci/checks.json`）。

## 内容

- `rewrite_refs.py` —— 批次引用重写器：默认 dry-run 打印将改动的文件/处数/样例，`--apply` 才落盘；遍历跳过构建、产物与数据目录，只处理文本扩展名文件。

## 上游

- 本目录工具未注册于 `eng/ci/checks.json`（重组批次的辅助工具）。
- 本目录在 CI 门禁规范（工程正本内的检查项清单与门禁规范篇）无逐项对应篇；重写结果由文档一致性检查覆盖，条目见 `docs/engineering/01_CHECKS.md`。
