## §1 逐条结论

### 1.1 新 SNR 模型完整抄录（公式/符号/单位/适用条件/边界）

权威源：lib/snr_estimator/cpp/src/snr_science.cpp（新增 246 行；P8 起同时编入根图 astrocs_phase1_noise，根 CMakeLists.txt:495-498）。

(a) 逐源最优提取（Horne 1986）—— snr_source_snr_f64：

    轮廓  P_i = I_i / SUM_j I_j ,  I(r) = (1 + r^2/(2 sigma^2))^-4   （像素中心点采样, Moffat beta=4）
          I_i 在 (2*half+1)^2 单位像素网格取值; half = (profile_half_px>0)?该值:clamp(ceil(12*FWHM),30,256)
    尺度  sigma = FWHM / 1.230310                                    [SCI-PSF 各向同性不变量]
    方差  gain>0 : sigma_i^2 = sigma_sky^2 + (RN_e/gain)^2 + max(F*P_i,0)/gain   [ADU^2]
          gain<=0: sigma_i^2 = sigma_sky^2                                        [天空受限]
    通量  Var(F) = 1 / SUM_i (P_i^2 / sigma_i^2) ;  sigma_F = sqrt(Var(F)) ;  SNR_F = F / sigma_F
    辅助  SUM P_i^2 [1/pixel] ; snr_peak = F*P_center/sigma_sky （头注释:"仅诊断, 不得作科学输出"）

(b) 孔径路径（CCD 方程 + Moffat4 解析圈入分数）：

    r = aperture_radius_px>0 ? 该值 : 1.5*FWHM ;  n_pix = pi*r^2 ;  n_sky = (p.n_sky>0)?该值:n_pix
    f_in(r) = 1 - (1 + r^2/(2 sigma^2))^-3        （Moffat beta=4 解析 enclosed fraction）
    S_ap = F*f_in ;  Var_ap = n_pix*sigma_sky^2*(1 + n_pix/n_sky) + (gain>0 ? S_ap/gain : 0)
    SNR_ap = S_ap/sqrt(Var_ap) ;  sigma_F,ap = sqrt(Var_ap)/f_in ;  aperture_correction = 1/f_in

(c) 帧级科学基准（5sigma 点源深度）：F_5 = 5*sigma_F(ref) [ADU]，m_5 = ZP - 2.5*log10(F_5) [mag]；ZP<=0/非有限 → m5_mag = NaN。P8 的参考轮廓 = (有效源 FWHM 中位数, 帧级 sigma_sky, 参考通量=有效源通量中位数或配置值)，并在 p1_snr.json 的 snr_reference{profile,flux_adu,fwhm_px,snr_f,sigma_f_adu} 显式绑定。

(d) 零点标准误：sigma_location_se_dex = 1.253 * sigma_logflux_dex / sqrt(N)；sigma_location_se_mag = 2.5*该值（noise_model.cpp:288-296；P8 snr_frame_science.cpp:84-86）。

(e) 生产装配（snr_estimator.cpp:49-77 sourceSnrFromPsfRow）：控制点值 = SNR_F；sigma_sky_adu = residual_scale/0.7316727929211932（10–90% trimmed mean → 高斯 sigma）；flux 缺失兜底解析积分 F = 2*pi*A*sigma^2/3；gain 未知 ⇒ 一律天空受限（源码自陈）。稠密图 snr = snr_psf（=IDW(SNR_F)，不再乘帧级标量）；snr_extract_model{,_v2,_v3} 置 snr_phot = median_snr = median_source_snr = median(SNR_F)，使下游 snr_phot * IDW/median_snr ≡ IDW(SNR_F)（消费点 lib/healpix_db/healpix_drizzle/snr_evaluator.cpp:293/304/366）。

(f) 适用条件/边界（代码自陈 + 我补的）：仅点源；轮廓为各向同性 Moffat（忽略椭率列）；gain<=0 时无源泊松/读出噪声；m_5 依赖外部 ZP；gain>0 时 F_5 非自洽 5sigma 通量（§1.6-6）；P_i 为像素中心点采样而非像素积分（§1.6-3）。

### 1.6 我对新模型的独立判据（不以旧文档为依据）

先给结论：**新模型的科学骨架是对的**——我逐条独立复算通过（下列 1、2）；**残留 4 处系统性偏差 + 1 处估计量错配常数**（下列 3-7），均有我自己算出的数字。脚本：问题扫描/_verify/_v1_math{,2,3,4,5}.py（纯 stdlib，逐像素暴力积分/数值矩）。

1. Moffat4 恒等式复算通过：由半高条件 I(r_h)=I(0)/2 解得 FWHM/sigma = 2*sqrt(2*(2^0.25-1)) = 1.230308（代码 kMoffat4FwhmFactor=1.230310，相对差 1.6e-6，可接受）；数值二维积分 int I dA = 8.374175 vs 解析 2*pi*sigma^2/3 = 8.377580（sigma=2，r<=10sigma 截断内一致）；圈入分数三点抽样 numeric 与 f_in(r)=1-(1+r^2/2sigma^2)^-3 **9 位相同**（0.297668038 / 0.703703704 / 0.895786688）⇒ 孔径改正与 F 兜底积分不是抄来的，是对的。
2. 最优提取与连续极限吻合：解析 int P^2 dA = 9/(14*pi*sigma^2) ⇒ 天空受限 sigma_F = sigma_sky*sqrt(14pi)/3*sigma = 2.2105*sigma*sigma_sky。复算 FWHM=2.5 → 解析 0.04955799 vs 代码网格 0.04959859（+0.08%）；FWHM=4.0 → 0.01935859 vs 0.01935861（1e-6）⇒ **Horne 公式实现无误，网格足够时收敛到教科书值**。（对照：旧口径 (A-B)/residual_scale 与 1/(ln10*sigma_dex) 都没有这种收敛性——「改成对的」这一判据成立。）
3. 残留偏差 ①（点采样 vs 像素积分）：代码取像素中心值当 P_i，正确做法是对像素积分。我以 15x15（FWHM>=2.5）与 5x5/7x7（椭率检验）次像素积分复算同一 Moffat：

    FWHM[px]  SUM P^2(点采样)  SUM P^2(像素积分)  SNR_point/SNR_true  Dm_5[mag]
      1.407      0.17506140       0.13599914          1.1346          +0.1371
      2.500      0.04959859       0.04665370          1.0311          +0.0332
      4.000      0.01935861       0.01889710          1.0121          +0.0131
      5.000      0.01238951       0.01219889          1.0078          +0.0084

   ⇒ SNR_F 系统性偏高，欠采样端最严重；**1.407px 恰是本批测试自己钉住的真源 FWHM**（p1snr_science_test.cpp:150 kRealFwhm[0]=1.4072320071088888），即 +13.5%、m_5 偏深 0.137 mag。内建"参考实现"与 NumPy 锚复制同一采样方式 ⇒ **回归锁看不见这个偏差**。
4. 残留偏差 ②（各向同性假设，与设计意图冲突）：设计大纲 §6.3 冻结「椭圆 Moffat4 PSF」，PSF 块第 8 列即椭率、s.fwhm_px = 2.3548*0.5*(a+b)（长短轴均值）；新模型用单一 FWHM 的圆轮廓（sourceSnrFromPsfRow 只读列 1,2,5,6,7；P8 的 SnrSourceRow 只有 flux/fwhm）。复算（_v1_math5.py，同 FWHM 归一化）：轴比 1.0 → 残差 +3.10%（即纯点采样项，与第 3 条 FWHM=2.46 一致）；轴比 2.0（e=0.5）→ SNR 偏低 3.92%（椭率项约 -6.8%，与点采样 +3.1% 部分抵消）。⇒ 各向同性 + 均值 FWHM 是未登记的适用域收缩，直接抵触设计大纲 §6.3 与 SCI-CW §2a「sigma_F(ref) 必须显式绑定参考轮廓」。
5. 残留偏差 ③（增益已知时读出噪声双计）：sigma_i^2 = sigma_sky(empirical)^2 + (RN/g)^2 + S_i/g，而 SCI-NOISE §9a 明确生产 sigma_sky 基线是 empirical MAD（**已含**读出噪声），并把 var_ADU = max(signal,0)/gain + (rn/gain)^2 冻结为「仅诊断」的另一条互斥路线；两者相加即把 (RN/g)^2 计两次。复算（_v1_math3.py）：

    g=2,   RN=5e-,  sigma_sky=3 ADU     → 方差虚增 69.44% → SNR 低 23.18%
    g=2,   RN=5e-,  sigma_sky=10 ADU    → 方差虚增  6.25% → SNR 低  2.99%
    g=1.5, RN=10e-, sigma_sky=20 ADU    → 方差虚增 11.11% → SNR 低  5.13%
    g=1.5, RN=10e-, sigma_sky=260.86ADU → 方差虚增  0.065%→ SNR 低  0.03%

   现状休眠（生产/聚合默认 gain=0），但接口与文档宣称支持「CCD 方程（含 gain/读出噪声）」⇒ latent 科学错误。正确合成应为 sigma_i^2 = sigma_sky^2 + max(F*P_i,0)/g。
6. 残留偏差 ④（5sigma 深度非自洽）：gain>0 时 F_5 = 5*sigma_F(F_ref) 用的是参考源通量下的 sigma_F，不等于「SNR 恰为 5 的通量」。我解自洽方程 F = 5*sigma_F(F)（几何二分 200 步），sigma_sky=260.859、FWHM=3、ZP=22：F_ref=1e4 → 偏 0.001 mag；F_ref=1e5 → 偏 +0.024 mag，代码 F_5 的真 SNR=5.11（标 5sigma 实为 5.11sigma）。默认 gain=0 不触发；登记为边界缺说明。
7. 常数错配（零点标准误）：location 是 IRLS/Tukey 稳健位置（PHOTOMETRY.md:22；ALG PHOTOMETRIC_FIT.md:7 c=4.685），而 1.253=sqrt(pi/2) 是**样本中位数**的渐近标准误乘数。按 M 估计量渐近式 sqrt(E[psi^2])/E[psi']（psi=u(1-(u/c)^2)^2，dpsi/du=(1-t)(1-5t)，数值积分 120001 点，截断 ±9sigma）复算：

    c=4.685: E[psi^2]=0.60445, E[psi']=0.75778 → 乘数 1.0260（1.253/真值 = 1.221 → 高估 22.1%）
    c=4.0  : 乘数 1.0483（高估 19.5%） ;  c=6.0: 乘数 1.0096（高估 24.1%）
    对照   : 均值 = 1.0000 ;  中位数 = 1.2533

   ⇒ /sqrt(N) 这一步本身正确且必要（旧实现确为高估 ~11 倍），但常数应约 1.03（Tukey c=4.685，等价 95% 高斯效率）而非 1.253，且 N 应取有效内点数（DATA_SEMANTICS §14.2：out_n_matched = IRLS inliers 数）。snr_science.cpp:225-228 的自陈「高斯下 median 的标准误常数」即已暴露估计量错配。
8. 与负责人意图的关系：40_OWNER_DECISIONS A-01 的处方是「采 SCI 定义并改实现；若采实现，须按 §1.2 走宪章/SCI 变更流程**并登记偏差**」。本批实际是「改 SCI 以纳新实现」（NOISE_MODEL §9a 被改写为 signal/sqrt(variance) 只是逐像素探测显著性、源通量 SNR 须另行定义）。我判：科学上正确（对点源通量 SNR，匹配滤波才是对的），且负责人明示「需要把 SNR 改成对的」并批准改冻结文档 ⇒ **既不是"把旧错误口径改回去"，也不是越权**。缺的是 A-01 处方中「登记偏差」那条腿（无新 DISP-* 条目、A-01 状态未更新）——程序面待前台向负责人补认（§4 U-1），我不判为技术缺陷。
9. 一处需负责人终裁的真冲突（不是我该定的）：设计大纲 §6.3 末句与待确认清单 Q-5 明示「Phase1 SNR catalogue 现降为 legacy 诊断，终态去留〔问 5〕」。P5/P8 实际把它重新升格为承载科学 SNR_F 的交付量（snr_phot/median_snr/local_snr/snr_f/sigma_f_adu），并与 SCI-CW §4 保留的 support × snr_v^2 拼在一起 ⇒ 生产权重可能变成 support × (真 SNR)^2。方向上是「改对」，落点上跨了 Q-5 / A-02 两个待裁项。我**不建议**回退旧口径；建议把 Q-5/A-02 与本批绑定送负责人终裁（§4 U-2）。
