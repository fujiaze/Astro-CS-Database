## M7-A-201 SCI-DRZ §6 用「外接圆半径 1.25」去「覆盖」一条全对角 1.532，比较对象不同阶，句子按字面为假（L19-004 **改判**：原 P1 的核心结论被本代理几何重算驳倒，仅存表述缺陷）
- 位置 `docs/science/DRIZZLE.md::§6 假设`（复核时 :75，grep「覆盖赤道对角线」「1.532」「1.044」同处命中）
- 权威依据 宪章 §5.3、§12.3-1（科学定义须可复算）；Górski et al. 2005 HEALPix NESTED（赤道带每环 4·nside 颗、|z|≤2/3）
- 证据摘录
  > 球面裁剪外接圆半径 `1.25·hp_res` 覆盖赤道对角线 `1.532·res` 与极区最坏 `1.044·res` + 裕量。
- 问题说明（本代理独立重算，修正 L19 自身的推导错误）：以 `hp_res=√(π/3)/N` 为等面积平方根、赤道菱形全对角 `D_φ=2π/(4N)=π/(2N)`、`D_z=4/(3N)`（½D_φD_z=π/(3N²)=像素面积 ✓，长宽比 3π/8=1.178 与真实 HEALPix 像素形状一致），则
  - **全 φ-对角 /hp_res = (π/2)/√(π/3) = √(3π)/2 = 1.5350** ⇒ 文档的 1.532 就是**全对角**（尾差 0.2%），不是中心→角点半径；
  - 中心→角点（球面精确，逐纬度扫描）：赤道 **0.7675·hp_res**，|z|=2/3 边缘 **0.8796·hp_res** ⇒ 真正需要的像素外接半径 ≤0.88，**1.25 覆盖它并有 ≥42% 裕度**；
  - 实现侧同向自证：`lib/healpix_db/healpix_drizzle/spherical_overlap.cpp::HP_CIRCUMRADIUS_FACTOR` 的注释块（复核时 :27-42）写「解析上界（赤道带）≤1.0068×hp_res（半对角 Δz=2/(3nside)、Δφ·cos z=π/(4nside）」、「穷举 scan 全局最坏 1.043827×hp_res @dec≈−41.81°」、「取固定保守上界 1.25」——其**半对角取值与本代理一致**。
  ⇒ L19-004 的前提「每环 2·nside 颗 ⇒ D1=π/nside ⇒ 中心→角点=1.535·res」是行多重性取错（4N 误作 2N）；其结论「1.25 不覆盖、零漏选论证挂错层、L04 §6 猜测不成立」**不成立**。L04 §6 的猜测「1.532 为全对角、半对角 0.766≤1.25」**方向正确**。
  残留的真缺陷只有一处文字：§6 把**半径**（1.25）与**全对角**（1.532）并列作「覆盖」比较，按字面即 `1.25 ≥ 1.532` 的假命题，且未声明 1.532 是 φ 向全对角、未声明 1.044 与 0.7675/0.8796 的关系。
- 影响 该句的可读性/可核性；不改数值行为（1.25 确实够用），但 §10 把 1.25 冻结为不可轻改项时引用的正是这句错误论证。
- 建议处置 改写为「1.25·hp_res ≥ 最坏外接半径（赤道带解析 1.0068、极冠交界实测 1.044）+ 裕量」，并把 1.532 标注为「赤道菱形全 φ-对角 = √(3π)/2·res」；同步 L04 §6 待复核行（M2a 持有）。
- 置信度 高（几何式 + 球面数值扫描 + 实现注释三方一致）
- related **M2a 会签项**（本代理改判 L19-004 并支持 L04 §6 猜测；M2a 已定稿 L04 域，请据此订正 L04 §6 与 L04-004）、L20-006（→M7-A-141，推导缺失面另立）、L04-012（211076.3″ 同族复算）
- 四态判定 **仍成立（文本未变）＋改判降级 P1→P2（核心结论撤销）**
