### M3-A-007 「幂等归一」不变量与 I3 测试隐含未声明前提，多数像素被 floor 时存在数学反例
- 类别: A_SCI_DEF
- 建议优先级: P2
- 来源: L05-018
- 位置:
  - `docs/science/CALIBRATION.md::§7 独立不变量（幂等归一不变量）`（复核时点 :65）、`§11/§15`（:108、:134）
  - `lib/calibration/src/master_generator.cpp::generate_master_flat 步骤3`（复核时点 :233-252，关键语句 :248-250 `float v = out[i] / final_med; if (v < 0.1f) v = 0.1f;`）
  - `lib/calibration/tests/p1cal/p1cal_tests_core.cpp::I3 幂等归一`（复核时点 :271-290）
  - `docs/algorithms/CALIBRATION_ALGORITHMS.md::TEST-CAL-DESIGN-001 I3 行`
- 证据摘录（复核时点重读）:
  > - **幂等归一不变量**：对同一 `flat` 连续两次 `normalize_flat` 结果一致（median 已为 1.0，二次归一不变）。（SCI §7:65）
  >             float v = out[i] / final_med;（master_generator.cpp:248）
  >             if (v < 0.1f) v = 0.1f;（:249）
  >     // --- I3 幂等归一: 已归一 flat (median==1) 再跑 ALG-CAL-002 语义不变 ---（p1cal_tests_core.cpp:271）
  >         P1CAL_CHECK(cs, std::fabs(...twice[i]... - ...once[i]...) <= 1e-6, "idempotent_normalization");（:286-289）
- 权威依据: 宪章 §4.1（不变量必须无例外成立或显式声明前提）、§13.2（测试必须覆盖不变量声明的边界）；SCI-CAL-001 §7/§10
- 问题说明: 步骤 3 是「除以中位数 **后** 再逐像素夹 0.1 地板」，因此产物 median 严格等于 1.0 只在「无像素被地板抬高」时成立。当被夹像素占比 >50%（例如多数像素 <10% 中位数：严重遮罩、灰尘环、局部欠曝堆栈）时，`median(once)=0.1`，第二次 `generate_master_flat` 会把已归一母版整体乘 10，破坏 §7 声称的幂等性，且与 §10:99「改变 median=1.0 或 floor 0.1 语义」的禁令相冲突（不变量在自身声明域内不成立）。I3 测试使用的 fixture（`fix_cal_d_flat_frames`）不含被地板抬高的像素，故该反例落在测试域之外，属「不变量声明过强 + 测试覆盖过窄」。
- 影响: 合同层不变量文本存在未声明前提；退化平场产品的 median 语义可被二次处理改变而无任何告警。当前真实链不触发（母版一次生成）。
- 建议处置: 在 SCI §7 为该不变量补前提（「无像素被 floor 抬高时成立」）或把 floor 改成不参与中位数统计的语义；I3 增加「多数像素低于 floor」负面用例并显式断言现状行为。
- 置信度: 中高（数学反例成立性已复算；是否构成合同违背待负责人判）
- related: M3-A-003（同一 floor 语义）、M3-F-002（校准 Python Oracle 容差/抽样与冻结值不符）

- 问题说明: ① 算术断言为假：复算 `1.482602218505602 − 1.4826022185 = 5.602e-12`，不满足文档自述的「差 <1e-12」；「15 位截断」计数亦错（该常数为 16 位有效数字）。② 同一换算系数存在三套字面值：噪声侧 `×1.482602218505602`、测光侧 `÷0.6745`（其倒数 = 1.4825796…，相对真值偏差 1.53e-5）、孔径/坏点侧 `×1.4826`（4 位）。NOISE_MODEL:135 称二者「同源」，但未给换算关系、未说明容许截断，读者无法判定跨模块 dex↔σ 换算该用哪个值。③ 机器门用子串命中（`"1.4826022185" in nm` 因该串是长常数的字面子串而恒真），对常数被改动作不出判别。
- 影响: 冻结合同中的算术陈述为假；常数缺单一权威定义点，跨模块换算存在 1e-5 量级解释负担。不改变当前科学结论。
- 建议处置: 建唯一定义点（common 数学头 + SCI 字面登记表），把 0.6745/1.4826 升为全精度或在 SCI 明示测光侧容许截断与由此引入的相对偏差；订正「15 位/差<1e-12」文本；机器检查改为精确字面集合比对。
- 置信度: 高
- related: M3-A-004、M3-A-006、M3-D-006

### M3-A-009 SCI-CAL §8/§9a 用「FP32 饱和语义」描述浮点溢出，术语与 IEEE-754 行为相反且实现实为 inf/NaN 直传
- 类别: A_SCI_DEF
- 建议优先级: P2
- 来源: L05-019
- 位置:
  - `docs/science/CALIBRATION.md::§8 极端/退化条件表 t_light/t_dark 行`（复核时点 :77）与 `§9a saturation 行`（:93）
  - `lib/calibration/src/calibrator.cpp::ac::calibrate`（复核时点 :118、:122、:128-133）、`ac::calibrate_d`（:161、:165、:171-176）
  - `lib/calibration/src/master_generator.cpp::generate_master_flat 步骤1`（复核时点 :193-225）
- 证据摘录（复核时点重读）:
  > | `t_light/t_dark` 极端 | `K` 仍按比值应用，溢出由 FP32 饱和语义界定，不静默 clamp | `calibrate: k=k_init` 直通 |（SCI §8:77）
  > - **saturation**：FP32 饱和语义界定，不静默 clamp（§8 `t_light/t_dark` 行）。（SCI §9a:93）
  >             float v = raw[i] - dark[i];（calibrator.cpp:118）
  >             if (flat) v /= std::max(flat[i], 0.1f);（:122 —— 无任何溢出/饱和处理）
- 权威依据: 宪章 §5.3（校准路径精度与非合同裁剪条款）、§4.1（术语与量纲必须准确）；SCI-CAL-001 §8/§9a
- 问题说明: 「饱和（saturation）」在合同别处指探测器满阱电荷饱和（输入数据域问题），而本节把它用于描述**算术溢出**。IEEE-754 binary32 溢出行为是舍入到 ±∞（除零同理，`0/0` 得 NaN），不存在「饱和语义」这一数值界定；实现也确实不做任何处理（:118/:122/:161/:165 为裸浮点式），故实际后果是 inf/NaN 直传下游，与 §9a 另一条「不传播 NaN 为伪有效值」（:37）的口径在本节内自相冲突。读者据此会认为极端 K 会自动落在 FP32 上限（≈3.4e38）而「有界」，从而放弃在调用侧做上界校验。
- 影响: 合同术语错误掩盖真实数值行为（inf/NaN 传播）；极端曝光比配置的母版消费边界失去风险提示。不改当前常规数值。
- 建议处置: 把 §8/§9a 的该措辞改为「IEEE-754 溢出得 ±∞，本合同不 clamp；调用方须保证 `K` 与 flat floor 的数值域」，并与 §4:37 的 NaN 条款统一（明确 `cal` 层的 inf/NaN 是否视为合法产品值）；探测器饱和与算术溢出两个概念分开表述。
- 置信度: 高
- related: M3-A-003、M3-E-002 第 11 组（SCI 内部条款指向失效）
