## M1a-A-001 SCI 前向 WCS 公式把像素域 SIP 加在天球域中间坐标上，量纲不闭合，且同节自称"与实现一致"

- 类别: A_SCI_DEF
- 优先级: P0
- 来源: L01-001
- 位置: docs/science/ASTROMETRY.md::§5 连续定义（"前向 WCS (像素→天球)"代码块）；对照 lib/plate_solve/cpp/ipv/src/ipv_wcs.cpp::solve_pix2world_iterative（"4. 牛顿迭代"块）与 tests/unit/p1wcs/p1wcs_oracle.hpp::oracle_wcs_forward 头注

  > （ASTROMETRY.md:66）与 `lib/plate_solve/cpp/ipv/src/ipv_wcs.cpp:13-16,153-164,274-420,530-576` 及 `ipv_select.cpp:695,712` 一致。
  > （ipv_wcs.cpp:851-861）// 4. 牛顿迭代: 解 F(u) = u + A(u) = UV … const double fx = u + fu - uvx;  // F(u) - UV
  > （p1wcs_oracle.hpp:228）// 初版误将 f (px) 直接加到 CD·(u,v) (度) 上 (量纲错), F2 对拍捕获。
- 权威依据: SIP（Shupe 2005, 2005ASPC..347..491S）——畸变多项式在**像素域**修正后再经 CD 线性变换；SCI-WCS-001 §5/§5a；宪章 §12.3-3（公式唯一实现）、§12.3-15（单位/像素语义显式）、§13.1
- 问题说明: §5 把 `SIP_A/B(u,v)`（系数单位 1/px^{i+j−1}，输出为 px）直接加到 `CD·(xp−CRPIX)`（deg）上，并把自变量取为中间坐标 (u,v) 而非像素偏移——**量纲与定义域双错**（标准形为 ξ,η = CD·[(xp−CRPIX) + A(xp−CRPIX)]）。实现是正确的像素域形式（:851-861 解 u+A(u)=UV，UV=CD⁻¹·(ξ,η)）。:66 仍自称"与实现一致"，且所引行号区间（:274-420/:530-576）在当下树已不覆盖被对照的两段数学（实测网格/牛顿段在 :402-527/:851-872）。测试面自证记录（oracle :228）说明**同一量纲错曾在 oracle 初版出现过并被 F2 捕获**，但冻结 SCI 仍写着该错式。
- 影响: 以 SCI 为准的复算/第三方实现/教学性引用会得到 px 与 deg 混加的错误 WCS（1 px 尺度下偏差即数百分之一度量级）；SCI 与实现的"一致"声明失真，违反 §12.3-3；宪章 §17.1 发布门（SCI 与实现无冲突）不满足。
- 建议处置: 订正 §5 为像素域式（ξ,η = CD·[Δpix + A(Δpix)]），并订正 :66 一致性锚为符号锚（path::symbol）；§14 参考文献 Shupe 条目补"逐页核验"状态；与 L01-002/§5a:75 的导出口径句同批改。
- 置信度: 高
- related: L01-002（§5a:75 重复该式）、L01-004、F00-01（若前台有同类 SCI 量纲项）

## M1a-A-003 CAR/AIT 投影丢失 Paper II fiducial 偏移（CRVAL2 不进映射）且 Y=−θ 手性与 CD 合成北南镜像

- 权威依据（本轮 web 亲验 Paper II 原文，非二手）: Calabretta & Greisen 2002 (Paper II, A&A 395, 1077；arXiv:astro-ph/0207413) **§2.2**：
  > "…a fiducial celestial coordinate pair (α₀,δ₀) given by the CRVAL_ia will be associated with a fiducial native coordinate pair (φ₀,θ₀) defined explicitly for each projection. For example, **zenithal projections all have (φ₀,θ₀)=(0,90°), while cylindricals have (φ₀,θ₀)=(0,0)**.   > §2.2 续："In cylindrical projections, where θ₀=0, the default value for LONPOLE_α is 0 for δ₀ ≥ 0, but it is 180° for δ₀ < 0"，且该默认"**is the condition for the celestial latitude to increase in the same direction as the native latitude at the reference point**"。
  宪章 §7.3（逐投影六要素含合法 FOV/奇点/方向，禁静默 fallback）、§12.3-13、§18.1（TAN/SIN/CAR/AIT 四投影为已冻结裁决）
- 问题说明: 标准强制 (x,y)=(0,0) ⇔ (φ₀,θ₀) ⇔ CRVAL ⇒ 对柱面/伪柱面 **dec(CRPIX)=CRVAL2 且参考像素处 (ξ,η)=(0,0)**。实现把"native 纬度"直接当作"天球纬度"（θ=dec），等价于恒把 CRVAL2 当作 0°：① 参考像素解出 δ=0，与头里写出的 CRVAL2 相差 δ₀；像素偏差 = δ₀/s_out（CRVAL2=30°、s_out=0.5″/px ⇒ **216000 px**；即使 s_out=1″/px 亦 108000 px），且 :328 只校 |dec|≤85°、:342-350 四角守卫对 CAR 永不触发 ⇒ 静默出片；② 手性：Y=−θ 与默认 east_left 的 CD=diag(−s,+s)（:59-67）合成 **dec 随行号增大而下降**，而 :393 写出的 CD2_2=+s 与 CUNIT2/deg 向标准读者宣告相反方向（SCI §9a-4 冻结的"east_left ⇒ CD1_1<0"是水平方向，不含此镜像含义），ALG :400 却把该镜像称作与标准"偏差=无"的等价式（其引用的 wcslib cars2x `eta = r0*theta - y0` 中 theta 已是相对参考点的余纬差）。
- 影响: 对任意 CRVAL2≠0 的 CAR/AIT 帧，产品像素↔天球映射与自带头部互斥（错位 = CRVAL2/s_out 像素）；宪章 §12.3-13"四投影一致"与 §7.3 六要素声明不实。
- 可达性如实登记: **当前生产产品面不受损**——四投影 registry map 无生产消费方（全仓 grep 仅 selfcheck/CLI 展示与测试），生产路径为 TAN-only，且已核到 4 处独立强制点：p3_session.cpp:96-97（ACS_ERR_UNSUPPORTED）、p3_wcs.cpp:61-64 与 :208-209（非 TAN 不产 CTYPE）、module_adapters.cpp:4506-4513/:4547/:4617-4628（p3_op_wcs 硬校验 + 读回写死 "TAN"）、runtime_client.cpp:52-60。**前瞻不可当已免**：宪章 §18.1 已把四投影列为冻结裁决项，而 ALG §15.5 + 两套 oracle + 注册表已把错误口径固定化，一旦按 DISP-P3PROJ-001 接入生产即静默产出错位产品，且现有门（含"独立 Oracle"）结构上无法发现（见 M1a-F-001）。
- 建议处置: ①CAR/AIT 映射改为 native 纬度 θ_native = asin(sinδ·sinδ₀ + cosδ·cosδ₀·cos(α−α₀)) 形式（或等价 (φ,θ) 相对 fiducial），使 dec(CRPIX)=CRVAL2 严格成立；②X/Y 符号与 CD 手性统一（去掉 −θ 或在 g1_build_cd 侧补偿），并给"纬度同向"断言；③ALG §15.2/§15.5 撤销"FITS 实践一致"表述，改登记为偏差或按标准订正；④若裁决保留现口径，须在 make() 对 CAR/AIT 强制 CRVAL2==0（显式 PARAM 拒绝）而非静默。
- 置信度: 高（标准原文本轮亲验；aanda 站 403，取 arXiv/ar5iv 全文渲染版，A&A 与 arXiv 同文）
