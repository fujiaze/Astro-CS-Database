## M2a-A-2 面积/方差/信号单位声明链 px²↔sr 混用，variance 单位与公式维度不符，HiPS tile FITS 无 BUNIT

- 类别: A_SCI_DEF
- 优先级: P1
- 来源: L04-010（前台指令：与 L10-001 是同症状不同根因，**不得合并**）

  > （DRIZZLE.md:27）- `S,F,x`: ADU/e⁻；`D,a,A_drop`: px²（球面立体角等价）；`v,variance`: ADU²；`ivar`: ADU⁻²…

- 权威依据: 宪章 §4.1（signal/variance 单位须为平方一致且各 DATA 合同写明单位）、§4.3（manifest/产品须记录单位与像素语义）、§7.3（面亮度/每像素通量规则须明确）；FITS 4.0 §4.4.1 BUNIT 语义；SCI-DRZ-001 §3/§3a
- 问题说明: 实现全程以立体角为单位（Eriksson 球面面积、`A_cell = 4π/(12·nside²)`、`sup = area/ps->A_cell`），故 `S_p=F_p/D_p` 的量纲是 ADU/sr，`variance_p=Σv·w²/D_p²` 的量纲是 ADU²/sr²；而 SCI §3 把 D/a/A_drop 记作 px² 并用"（球面立体角等价）"一笔带过（px² 与 sr 之间差一个逐像素换算因子，不是"等价"），同表又把 variance 记 ADU²、ivar 记 ADU⁻²（§5 公式的维度是"信号单位²/面积单位²"，与 §4.1 要求的"variance 与 signal 单位平方一致"只在 signal 被记为无量纲时才成立）。DATA_SEMANTICS 侧把同一批量按 sr/ADU 混写，两份权威互不一致。产品面则完全没有单位声明通道：leaf tile FITS 头只写 NSIDE/FIRSTPIX/LASTPIX，`BUNIT` 零命中（properties 侧有 `astrocs_signal_dtype`/PIXTYPE 但无单位），故下游只能靠猜。
- 影响: 光度解释与跨模块组合（Phase2 ivar 加权、Phase3 方差传播、孔径测光流量闭合）缺统一换算基准；§4.1/§4.3 合规缺口；与 M2a-A-1 的 1/pixfrac² 因子叠加后，产品数值语义不可判定。
- 建议处置: ① SCI §3/§3a 统一为 sr 基准（或在 §5 显式引入并冻结 px²↔sr 换算因子），variance/ivar 单位改写为 `(ADU/px²)²` 口径与 signal 单位平方一致；② DATA §11.2/§12.2 单位列按公式维度改写；③ writer 在 signal/variance/ivar tile 头写 BUNIT（signal 用面亮度单位串，variance 用其平方），并在 metadata/properties 登记同一口径。
- 置信度: 高
- related: M2a-A-1、M2a-B-4（同为"声称符合但单位/语义维度不闭合"，根因不同不合并）、L04-007
