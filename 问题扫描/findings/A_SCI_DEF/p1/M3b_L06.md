### M3b-A-04 5σ 检测阈的 σ 取自原图、判决作用于 σ=2 平滑图，虚警预算不自洽
- 类别: A_SCI_DEF
- 建议优先级: P1
- 来源: L06-008（仍成立）
- 位置: lib/star_detector/src/sdet_api.cpp::sdet_detect_impl(:1736-1738 平滑、:1747-1754 bgnoise/median/threshold、:1818-1821 判决、:1802 locthreshold、:2047-2059 Ar/Ac 比较)；docs/science/STAR_DETECTION.md::§1(:15-18)/§5(:67)；docs/algorithms/STAR_DETECTION_ALGORITHMS.md::§2(:36)/§3(:87-93)
- 证据摘录:
  > - completeness / false positive (synthetic fields): 完备性与虚警由合成星场验收（召回 ≥99% @SNR≥10；虚警 ≤0.1/千像素，纯噪声场）……全局检测阈值为 `threshold = median(img) + 5.0·bgnoise`（5σ 语义）。
  （STAR_DETECTION.md:15-18）
  >             T pixel = smooth[(size_t)y * width + x];
  >             if (pixel <= threshold) continue;
  （sdet_api.cpp:1820-1821；threshold 由 :1747/:1750 在**未平滑** image 上算得）
- 权威依据: SCI-P1-STAR-001 §1（threshold 语义）/§5（「5σ 阈值中 σ 为背景噪声 ADU RMS」）；宪章 §5.3、§12.3
- 问题说明: 判决统计量与噪声标定量不在同一图上：bgnoise、median 取自原图，判决作用于 σ_k=2.0 的 YvV 平滑图（:1736-1738）。归一化 2D 高斯核使像元噪声缩为 σ_bg·‖k‖₂，‖k‖₂=1/√(4πσ_k²)=1/√(16π)≈0.1410，故「smooth > median + 5σ_bg」等效于平滑图上约 5/0.141≈35σ_smooth 的检验（复算自代码常数，未运行）——SCI 的 5σ 语义与虚警预算互不自洽：单侧 5σ 对应 ≈0.00029/千像素，而 ≤0.1/千像素对应 ≈3.1σ（Φ⁻¹(1−1e-4)≈3.72 为双侧/3.09 单侧量级——三个数无论取哪种约定都推不出 5σ）。局部显著性门 locthreshold=5·bgnoise(:1802) 同样与平滑图振幅 Ar/Ac(:2047-2059) 比较；候选 Sr/Sc 取自平滑图未做核展宽反卷积（:214 注释自认，无换算式）。ALG §2:36/§3:89 只复述公式，未记「判决作用于平滑图」半事实。
- 影响: 实际检测显著性未知（远高于标称 5σ），完备性/虚警声明不可检验；DISP-STAR-002 的漏检评估失去量化基准；纯噪声场虚警门数学上不可触发（永真门，另见 M3b-F-03）。真实数据路径受影响（IPV 路径 B 生产调用）。
- 建议处置: SCI/ALG 写明判决统计量的噪声标定（同图 σ，或显式核方差传递 σ_smooth=σ_bg·‖k‖₂），在同一域内重推阈值与虚警预算的自洽三元组；ALG §2/§3 与 DATA §17 补记「判决作用于平滑图」字面事实。
- 置信度: 高
- related: M3b-F-03、M3b-C-05、SCI-P1-STAR-001 §1/§5

### M3b-A-05 θ 消歧候选集不是 Moffat4 的对称群，SCI「旋转简并不变量」恒真不可证伪
- 类别: A_SCI_DEF
- 建议优先级: P1
- 来源: L06-009（仍成立）
- 位置: lib/dynamic_psf/src/dpsf_psf.cpp::moffat4_residual 二次型(:88-90)/::消歧(:389-401)/::fwhm 前算(:371-372)；docs/science/PSF.md::§6(:59)/§7(:63-65)；docs/algorithms/STAR_PSF_ALGORITHMS.md::§11.2(:175-176)/§3(:76)；lib/dynamic_psf/tests/p1psf/p1psf_oracle.hpp(:67-68)；lib/dynamic_psf/tests/p1psf/p1psf_tests_core.cpp::U1(:106-113)
- 证据摘录:
  > - **旋转简并不变量**：`θ` 四候选 `{θ,π/2−θ,π/2+θ,π−θ}` 中以 trimmed-mad 最小者消歧后，`fwhm_x/y` 与方向无关
  （PSF.md §7 :65）
  >     double thetas[4] = { theta, M_PI / 2.0 - theta, M_PI / 2.0 + theta, M_PI - theta };
  （dpsf_psf.cpp:389）
- 权威依据: SCI-PSF-001 §7/§11（不变量门为验收项）；宪章 §13.1（性质测试须能证伪、科学不变量测试必备）
- 问题说明: 代数核验（:88-90 闭式，复算不运行）：p2(π−θ)=−p2(θ)（sin2(π−θ)=−sin2θ），交叉项反号——π−θ 是镜像而非同一模型；p1(π/2−θ)=p3(θ) 且 p2(π/2−θ)=−p2(θ)，须同时交换 (sx,sy) 才等价。Moffat4 椭圆真实对称群是 θ→θ+π 与 (θ,sx,sy)→(θ+π/2,sy,sx)。代码 :392-401 只回选 θ、不交换 sx/sy、不回拟（README:100-101 亦自认「非重拟」），等于在**四个不同模型**中挑 trimmed-mad 最小者，可把收敛的 θ 换成他模型的 θ 而 sx/sy 不动 → 主轴/次轴归属（fwhm_x=1.230310·sx，:371）与真实位置角可不一致。又 fwhm_x/y 在消歧**之前**已算定，SCI §7「消歧后 fwhm_x/y 与方向无关」为构造性恒真（fwhm_x 本就不依赖 θ），不检验任何东西——违反 §13.1「不变量门可证伪」。p1psf_oracle.hpp:67-68「四元组生成逐元素相同的 M」前提同样不成立（Mxy(π−θ)=−Mxy(θ)，见 :71-78 自身公式），p1psf_tests_core.cpp:106-113 的 M 等价判据只在回选落入轴对齐族时偶然通过。ALG §11.2:176 锚「:358-368」实为 :389-401（漂移，另见 M3b-E-01）。
- 影响: 位置角与长短轴归属交付下游（椭率/形状、SCI-PSF §9a 椭率一阶 e,θ）不可靠；SCI 声明的不变量门失效。
- 建议处置: 消歧改两候选（θ 与 θ+π/2，同步交换 sx/sy 与 fwhm_x/fwhm_y）；SCI §7 改写为可证伪式 M(θ,sx,sy)=M(θ+π,sx,sy)=M(θ+π/2,sy,sx)；订正 ALG 锚与 oracle :67-68 注释；测试显式覆盖非轴对齐 θ。
- 置信度: 高
- related: M3b-H-02、M3b-I-01、M3b-F-03、宪章 §13.1
