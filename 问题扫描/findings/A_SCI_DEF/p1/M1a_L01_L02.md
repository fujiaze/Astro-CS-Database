- 权威依据: 宪章 §12.3-15（单位显式）、§13.1；SCI-WCS-001 §2/§3/§5/§10；ALG-WCS-001 F2

## M1a-A-010 TAN 半球界推导错误："r≥π/2 与 denom>0 数学等价"不成立，正反映射有效域不对称（真边界 ≈57.5° 而非 90°）

- 类别: A_SCI_DEF · 优先级: P1 · 来源: L02-009
- 位置: lib/phase3_session/p3_wcs.cpp::p3_wcs_pix2world / ::p3_wcs_world2pix；docs/contracts/DATA_SEMANTICS.md::§28.4；docs/algorithms/PHASE3_PROJ_IMPL.md::§9 与 §15.3
- 证据摘录:
  > （p3_wcs.cpp:162-163）const double r = std::sqrt(xi*xi + eta*eta);  if (r >= M_PI / 2.0) return P3_WCS_HEMISPHERE;    // 跨 TAN 半球
  > （p3_wcs.cpp:187-189）const double denom = sin(d0)*sin(dd) + cos(d0)*cos(dd)*cos(a-a0);  if (denom <= 0.0) return P3_WCS_HEMISPHERE;
  > （DATA_SEMANTICS.md:2189-2190）半球界 r<π/2（正映射）与 denom>0（反映射）**数学等价**；FOV 适用上限 20°（SCI §9a-12 冻结，超限非错误、由畸变语义约束）
- 权威依据: FITS WCS Paper II §5（gnomonic：r=tan d，d 为大圆距）；宪章 §12.3-13（四投影一致）、§12.3-3
- 问题说明: 前向以中间坐标半径 r 判界，而 r=tan d ⇒ r≥π/2 ⇔ d≥arctan(π/2)≈**57.519°**；反向 denom=cos d>0 ⇔ d<90°。两条件不等价：`d∈[57.5°,90°)` 的像素天球→像素成功、像素→天球被拒 ⇒ 同帧出现约 32.5° 宽的单侧不可往返环带。合同把它写作"数学等价"并把阈值当 90°。
- 影响: 半球守卫消息（"跨 TAN 半球"）在两向给出不同有效域，界外静默 continue（节点 :4842-4844）⇒ 该产品形态为大 FOV 时出现无告警的环带 NaN；并与 L02-002（FOV 无强制点）叠加。
- 建议处置: 前向改用角距判界（`atan(r) ≥ π/2`，或反向同用 denom），使两向严格互补；合同"数学等价"改为"仅在 r 定义为角距时等价"并给推导；补 d∈(57.5°,90°) 往返用例。
- 置信度: 高（复算 arctan(π/2)=57.5194°） · related: L02-002、L02-014、L02-001
