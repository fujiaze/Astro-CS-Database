# M7 · F_TEST_GAP（测试缺口）· P2

## M7-F-201 冻结容差以文字或占位充当，且「构造保证」在 FP64 下并非逐位命题（L20-026）
- 类别: F_TEST_GAP · 优先级: P2
- 位置 `docs/algorithms/PHASE3_RESAMPLE.md::§5c/§8`（复核时 :86/:105「构造保证」）、`docs/algorithms/PHASE3_FITS_IMPL.md::§/逐值精确`（:325）、`docs/algorithms/PHASE2_REJECTION.md::§11.4`
- 问题说明 三处以「构造保证 / 逐值精确 / 应无差异」替代数值容差 ⇒ 无在册用例可判红。其中「构造保证」在 IEEE-754 FP64 的四项乘加（bilinear `Σw`）下**不是逐位命题**（同族 M7-A-129②、M7-A-214），故该措辞既非有效容差、亦非可成立事实。
- 影响 三处验收面不可证伪；若有人据此写逐位断言，测试将在常数巧合下恒绿（或反向必红）。
- 处置 每处给数值容差 + 参照量（分 dtype）；「构造保证」改「按构造等于 1 ± k·ULP」并给 k，否则删；对应用例进 CTest（与 M2a-G-1「判定器不在册」并案）。
- related M7-A-129、M7-A-214、M7-G-001（家族第 1 类）、M7-C-201、M2a-G-1
- 四态判定 **仍成立**；置信度 高
