## M7-T-101 冻结完备性门「SNR≥10 召回≥99%」在文档自身阈值下数学不可达，且该门无在册用例（L20-008）
- 类别: F_TEST_GAP · 优先级: P1（本代理独立复算后**维持 P1 不升 P0**，理由见"判定"列）
- 位置 `docs/algorithms/STAR_DETECTION_ALGORITHMS.md::§11.4 F1`（复核时 :257，grep「SNR≥10 星召回」命中）、`::§3 阶段 2/3/4`（:86-93/:93）、`::§11.5`；对照 `docs/algorithms/STAR_PSF_ALGORITHMS.md::§3`（bkg+1.5σbg 第三套阈）
- 证据摘录
  > smooth = GaussianBlur_YvV(image, sigma=2.0) … thr = median + 5·bgnoise（bgnoise = 原始图 robust MAD σ）
  > 完整性: SNR≥10 星召回 ≥99%
- 问题说明（本代理独立复算，两步）①归一 2-D 高斯核作用于白噪声：σ_smooth = σ_raw·1/(2σ_k√π) = **0.14105·σ_raw**（σ_k=2）⇒ 阈 `5σ_raw` 在判决图上等于 **35.45σ_smooth**；②高斯源（宽 σ_p）经宽 σ_k 平滑后的峰值与其匹配噪声之比 = SNR_int · 2σ_pσ_k/(σ_p²+σ_k²)，该因子 **≤1**（仅 σ_p=σ_k 时取等）⇒ SNR_int=10 的源在判决图上的峰值**上界为 10σ_smooth**，恒低于 35.45σ_smooth ⇒ **无论 σ_p 取何值都检不出**，召回 99% 在任何实现下不可达（σ_p=1.5px 时实测约 9.6σ_smooth）。⇒ 门与阈值不可同真：要么阈值另有未登记的折算，要么该 F1 门一落地必红。
- 影响 Phase1 星表/plate solve 选星/测光参考星的入口条件；若按文档实现，可探测极限比声明差约一个数量级（漏暗星），而门不可达会诱发反向调参。
- 建议处置 ①owner 裁决"判决图与噪声估计图必须同域"（在平滑图上估 σ，或阈乘 2σ_k√π=7.09）；②补 SNR–召回曲线用例并写出 σ_k、核型、峰值折算式；③在册测试现状：本门无任何可执行用例 ⇒ 同时登记 F_TEST_GAP。
- 置信度 高（衰减因子与峰值上界均可由标准公式复算）
- related **M7-G-001（家族汇总与升档判定，本条为其最强成员）**、L20-015（→M7-A-136 电平敏感）、L20 §2 E7（原事实归 L06-008/L06-016，本条只取量化后果）、M3b 的 PSF 0.01px 门（家族成员，其级别归 M3b）、宪章 §13.1、§12.3 尾段
- 四态判定 **仍成立**；**级别裁定：不升 P0**——理由：①该门当前无任何在册可执行用例，不存在"已验证声明"被击穿（击穿无据声明才是 P0 典型）；②其直接后果是门必红而非静默错值，静默错值已由同篇的判决域事实（L06-008）在 M3b 域承担；③家族级判词由 M7-G-001（P0）统一承载，本条保持 P1 以免同一判词重复计 P0。

## M7-T-102 采样器 F1 用逐位断言锁死截断常数 1.4826，使 F3 的 control_variance 解析 oracle rtol 1e-12 自相矛盾（L20-014）
- 类别: F_TEST_GAP · 优先级: P1
- 位置 `docs/algorithms/PHASE2_SAMPLER.md::§/F1 与 F3 测试设计`（复核时 :50/:71/:161/:168 命中 1.4826）
- 问题说明 若 F1 逐位钉 4 位截断常数，则 F3 以全精度 1/Φ⁻¹(3/4) 推导的 control_variance 期望值与之相差 1.52e-5 相对量（本代理复算 1/0.6745=1.4825796887）⇒ rtol 1e-12 的解析 oracle 与逐位常数断言不可能同时满足；这是"冻结常数的截断位数被测试层固化"的形态。
- 处置 常数改引"唯一事实源"（M7-G-103 四元表），F1 只断言"取自已登记常数"，F3 用同一源推期望。
- related A-12、L07-022、M7-A-211、M7-G-103；判定 **仍成立**；置信度 高
