- 权威依据: 宪章 §13.1/§13.2（Oracle 与冻结容差为合同不可分割部分）、§12.3-4、§14.4（静默放宽）；SCI-CAL-001 §11/§15

### M3-F-003 SNR-006 测试注入 σ 梯度场并按相关性判定，无法兑现「平面系数 a,b,c 在 10% 内复现」
- 类别: F_TEST_GAP ｜ 优先级: P1 ｜ 来源: L07-012
- 位置: `docs/science/NOISE_MODEL.md::§11:115`、`§15:140`；`lib/snr_estimator/cpp/test/noise_model_science_test.cpp::test_variance_field_fit_snr006`（:274-308；关键 :283-:288 注入 `s = 3.0 + 3.0*(cx/wd + cy/ht)`、`sigma = 2.0*s`，断言 :304 `corr >= 0.98`、:307 `norm_rmse <= 0.05`）
- 证据摘录（复核时点重读）:
  > - **平面场恢复**：注入线性梯度 `var(x,y)=a+b·x+c·y` 场，拟合 `a,b,c` 在 10% 内复现（`SNR-006`）。（SCI §11:115）
  >     double s = 3.0 + 3.0 * ((double)cx / wd + (double)cy / ht);（测试:284 —— 注入的是 σ 线性梯度）
  >     double sigma = 2.0 * s;（:285）
  >     if (corr < 0.98) fail(…);（:304）/     if (norm_rmse > 0.05) fail(…);（:307）
- 权威依据: 宪章 §13.1/§13.2（测试必须实现合同规定的判据，不得以更弱的相关性替代系数复现）、§12.3-4；SCI-NOISE-001 §11
- 问题说明: 合同要求的判据是「系数 a,b,c 各在 10% 内复现」；实现（`snr_noise_model_v1` 与公共 API 均不输出 `a,b,c`）根本无从断言系数，测试于是改为「像素级预测方差与真值的相关性 ≥0.98 + 归一化 RMSE ≤5%」。同时注入的是 **σ** 的线性梯度（:284-285），而合同的场是 **variance** 的线性梯度，故注入的真值场本身不是平面 `a+b·x+c·y`（`σ=3+3u` → `var=9(1+u)²` 是二次面），相关性判据只是在容忍这一形状误差。另：ALG-NOISE:194-196 的 FIX-NOISE-B 把该判据表述为「拟合系数在 10% 内复现」，与该测试实际断言不一致（ALG 未记录降级为相关性的事实）。
- 影响: 平面 LS 的核心正确性（系数复现）无测试覆盖；若 `fit_plane_ls` 的归一化/选主元被改坏（如 M3-A-005 的 det 分支），相关性判据仍可能通过。
- 建议处置: (a) 在 SCI 或 ALG 增补系数导出（诊断 getter 或 `SnrNoiseModelV1.a/b/c` 输出），据此实现 10% 系数断言；或 (b) 由负责人把 §11 该条改写为「像素级预测场相关性/RMSE 判据」并明确注入场型（variance 线性）；两者都要修正注入式与合同场型的一致性。
- 置信度: 高 ｜ related: M3-A-005、M3-H-001、M3-F-001
