## M1a-F-001 CAR/AIT"独立 Oracle"与被测实现同源（解析式取自同一推导），错误口径被测试钉死为正确

- 类别: F_TEST_GAP · 优先级: P0（宪章 §12.3 末段独立性条款不成立，且该缺口是 M1a-A-003 长期未被发现的直接原因）· 来源: L02-001 强制配套条
- 位置: tests/unit/p3_projection_test.cpp::CAR/AIT oracle 段；tests/backend/test_p3_projection_oracle.py::car_*/ait_*；对照 lib/phase3_proj/p3_projection.cpp::car_pix2world / ::ait_pix2world
- 权威依据（前置断言，先读测试原文再下判）: 宪章 §12.3 末段"参考实现/Oracle **不得与被测实现同源**"；§13.2（验证独立性）；ALG-P3-002 §15.6"独立 Oracle 在位"（registry:64 亦以此判 CONFORMANT）
- 证据摘录（逐字）:
  > （p3_projection_test.cpp:212-217）// CAR oracle: θ₀=+90° 恒等旋转独立式 … const double ra_o = c.ra0 + xd; … **const double dec_o = -yd;**   ← dec0 未参与
  > （test_p3_projection_oracle.py:153-157）# θ₀=+90° 恒等旋转 … dec = -y_deg
  > （test_p3_projection_oracle.py:189-195）x_rad, y_rad = math.radians(dra), math.radians(**-dec**)
  > （p3_projection.cpp:198/:204）const double theta = -yd * kRad;   … *dec_deg = theta * kDeg;
  > （对照：同文件 TAN/SIN 分支）basis(ra0, dec0)  —— TAN/SIN 的 oracle 采用球面基向量独立推导，**未犯同类错**
- 问题说明: CAR/AIT 的两个 oracle（C++ 与 Python）把期望值写成 `dec = −y_deg`、`ra = ra0 + x_deg`，与实现 :198/:204 的映射**同一推导、同一符号**（连 Y 翻转都同源），CRVAL2/dec0 根本不进入期望式；测试以 `|dec−dec_o|<1e-9` 断言，等于用被测公式验证被测公式。对比同文件 TAN/SIN 分支使用独立球面基推导 → 证明"本可独立"而未做。故：①现有测试**结构上无法发现** fiducial 偏移丢失与北南镜像（M1a-A-003）；②registry 以"独立往返 Oracle 在位"判 CONFORMANT 的证据基础不成立；③往返自洽（world2pix∘pix2world <1e-6 px）同样无法发现该错——错映来自反一致。
- 影响: 四投影冻结项（宪章 §18.1）中 CAR/AIT 的正确性证据为零；一旦按 DISP-P3PROJ-001 接入生产，错误口径将带着"全过"的测试记录出厂。
- 建议处置: ①CAR/AIT oracle 改用独立推导（球面基/标准 wcslib 或 astropy 的 CAA/CAR 型对照，含 dec0≠0 用例），并对 CRPIX 处断言 `dec == CRVAL2`；②新增"参考像素处天球值 == CRVAL"专项断言（四投影一致，§12.3-13）；③在 oracle 独立性未被满足前，registry:64 的 CONFORMANT 与 §15.6 的"独立"字样须撤回或降为 DEVATION。
- 置信度: 高 · related: M1a-A-003、M1a-B-002、L02-001
