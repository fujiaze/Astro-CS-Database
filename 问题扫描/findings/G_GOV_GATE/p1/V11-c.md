### V11-N-06（P1）同一个 `struct_size` 判据在仓内有**三套互斥语义**，头规定的那套几乎没人用
- **A 尾部扩展兼容（头规定：`status_codes.h:12`「扩展只允许追加尾部字段」+ `lifecycle_v1.h:61-65` + `:147` 静态断言）= `peer >= self` 兼容**：只有头文字与测试副本（`abi002_lifecycle_probe.c:60-66`）；实现侧 `providers/cpu/{baseline.cpp:465,515,607; avx2.cpp:285,333,391; avx512.cpp:140}` 与 `runtime/module_loader/secure_loader.c:572/593/626` 用 `<` 拒绝式（**=A 的正确实现**）。
- **B 严格相等 `!= sizeof(X)` 即拒**：`p1_session.cpp:155`、`p2_session.cpp:57`、`p3_session.cpp:53`、`aio_abi.cpp:101`、`secure_loader.c:347/382/388/658`、`module_registry.c:579` ⇒ **与头相反方向**：一次合法的尾字段追加（**正是 `V2-N-01`/`V11-N-04` 的成因方向**）会让**三个 Phase 会话入口 + 装载器 4 处同时判 `ABI_MISMATCH`** ⇒ 宪章承诺的尾扩展兼容在这 7 个点不可用。
- **C `struct_size==0` 放行**：`runtime/io/fits_core.c:83`（`fio_check_head`）、`:94`（`fio_check_hooks`）、`runtime/io/hips_core.c:679` ⇒ 与头相反且**方向是放宽**：零初始化即通过握手，而 **ctypes 结构体默认就是零初始化** ⇒ 自描述对"忘填"这一种**最常见漂移完全失效**。今天三份 Python Fio 镜像确实主动填了（`test_fits_stream_contract.py:143-144`、`make_hips_fixture.py:103-104`、`hips_output_fixture.py:100-101`）⇒ 门**不是恒真**，而是「**对未来某个忘填的调用方恒真**」（V11 这句限定我原样保留）。
- **判词**：A/B/C 三者不可能同时对；权威在头 ⇒ **B、C 是实现偏离自订合同**，不属"与旧文档不一致"。

### V11-N-07（P1）唯一的 `struct_size` 机器门 `ABI-BOUNDARY`：**语料与被保护面 8/8 零交集**，且"扩语料即假绿"的陷阱已在门内
- **复刻**：V11 逐字复刻 `tools/check_abi_boundary.py`（`_v11_gate_corpus.py`）——其 `HEADERS` = `include/astrocs/common_abi_v1.h` + `lib/backend_host/*.h`（排除名含 `impl`/`inc`）⇒ **共 12 个头**；规则 1 原文「所有 C ABI 结构必须带 `struct_size` + `abi_version`」。
- **交叉比对**：被跨语言/跨 DLL 消费的结构所在 **8 个头**（`ipv_api.h`、`aio_hips.h`、`aio_pipeline.h`、`star_detector.h`、`dynamic_psf.h`、`gaia_client.h`、`fits_stream_v1.h`、`aio_abi_v1.h`）**8/8 全部不在语料内**（脚本逐行输出「不在 <<<」）⇒ 本轴全部镜像漂移与那 70 个无自描述结构，**都在这道三 profile、`waivable=false` 的"非豁免真门"之外**。
- **关键限定（防止把门误判成已假绿）**：该门对现有 12 个头**是有效的**（`common_abi_v1.h` 全用 tag 名），只是**覆盖面被高估**。但陷阱已埋好：两个正则都是 `typedef\s+struct\s+(\w+)\s*\{`（**要求 tag 名**），复刻实测在 `common_abi_v1.h` 扫到 11 个、按 typedef 名实际 12 个（差集 `[acs_status]`）；而本仓绝大多数公共结构写作**匿名** `typedef struct { ... } Name;`（`IpvParams`/`AioHipsSnrPoint`/`GaiaSpectrumStar` 全是）⇒ **只扩语料不换正则，门会一个结构都扫不到并继续报 PASS**。
- **建议处置**：正则改「`typedef struct` 块 + 其后 `} Name;`」提取；语料以**「被 ctypes/跨 DLL 消费的结构」为驱动**（可由 `_v11_exports.py` 的采集结果自动生成），而非固定头清单。
- **related** `M8-G-001`、簇 1（在册非豁免 ≠ 有效）、**`C-14`/E6**、`V11-N-01`
