  > （module_adapters.cpp:574）{"resampled", "DATA-P3-RES", false, UnitId::SURFACE_BRIGHTNESS, CoordinateFrame::PIXEL},  ← 语义**只存在于进程内端口描述符**

- 影响: 下游仅凭产品无法判别"面亮度/通量"与天球 frame ⇒ §7.3 明令不得混淆的两态在产品面不可分；§17.1 发布门该证据项缺失。
- 建议处置: ①FITS 头补 `RADESYS='ICRS'` + 语义注记（自定义键或 COMMENT 行，字面需裁决）；②p3_writer.json / p3_resampled.json / 会话 result JSON 增 `frame` 与 `sampling_semantics` 两键，值取既有 UnitId/CoordinateFrame 枚举（单一机器源）；③DATA §27 登记该两键。
