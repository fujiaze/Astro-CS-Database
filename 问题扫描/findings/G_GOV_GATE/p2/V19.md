### V19-N-10（P2）outputs 与 dirty_ignore 与 .gitignore 三面零联动：两条半登记产物既不能提交也不被忽略
- KNOWN-FAILURES-BASELINE 的 artifacts/KNOWN_FAILURES_BASELINE.json 与 WIN-PACKAGE-CANDIDATE 的 artifacts/candidate/AstroCS-candidate.zip：实测 git ls-files 零命中且 git check-ignore 零命中，而 run.py:777 恰让 outputs 自豁免 dirty 检测 ⇒ 每次跑都留下一个既不能提交也不被忽略的文件（违目录规范），前者还在三个 profile 上跑。改法：归位 run/ci 或显式 gitignore + R14 断言。related M5b-G-16、L12-021、V9-N-15、C-15

### V19-N-11（P2）glob 型输入零校验：CI-BINDING-TESTS 的 -p 模式若被改到匹配 0 文件，门永久绿且两个守卫都不触发
