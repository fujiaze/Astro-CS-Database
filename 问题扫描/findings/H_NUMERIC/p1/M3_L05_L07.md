### M3-H-001 `fill` 的非空间场分支不 apply `variance_floor`，退化模型可产出全帧 `variance=0` / `ivar=0`
- 类别: H_NUMERIC ｜ 优先级: P1 ｜ 来源: L07-009
- 位置: `lib/snr_estimator/cpp/src/noise_model.cpp::fill_impl`（复核时点 :371-418；关键 :401-408 空间分支 apply floor、:410-416 else 分支 `out_pixels[i] = w->variance[...]` 原样写出、:414 `ivar = (v>0)? 1.0/v : 0`）；对照 `::noise_model_impl`（:210 `max(vmed, floor)`、:235 `max(sig*sig, floor)`、:256-258 控制点 floor）与 `::collect_patch_sky`（:225-232 `rc=1` 时 memset 0）
- 证据摘录（复核时点重读）:
  >             double v = a + b * (double)x + c * (double)y;（:401）
  >             if (v < floor) v = floor;（:402-:403）
  >         } else {（:410）
  >             out_pixels[i] = w->variance[i < w->n_control_points ? i : 0];（:414 语义：按控制点表原样写入，无 floor）
  >             ivar_pixels[i] = out_pixels[i] > 0 ? 1.0 / out_pixels[i] : 0.0;（:415-:416）
  > 空间场: 最小二乘平面 …；负预测 clamp 至 variance_floor (1e-12)（SCI §5:49）
  > | `variance_floor` | 方差下界 `1e-12`（`max(var,floor)` clamp） | `default_config` |（SCI §2:21）
  > **Floor 夹逼不变量**：任何输出 `variance >= variance_floor`…（SCI §7:75）
  > `snr_noise_model_v1`：数据全 NaN/无合格 patch → rc=1（不产出伪 model）（SCI §8:88）
- 权威依据: 宪章 §5.3（校准/权重链不得有未合同化的数值突变）、§14.4（退化须显式）、§4.1；SCI-NOISE-001 §5/§7/§8
- 问题说明: SCI §7 的「任何输出 variance ≥ floor」不变量只对空间分支成立（:402-403）。当 `has_spatial_field=0`（关闭空间场、或 `n<4`、或 M3-A-005 的 det 退化）时，:410-416 直接把模型数组里存的值写进产品，**跳过 floor**：① 若这些值本身合法（`:210/:235/:256-258` 均 max 过 floor），产品仍 ≥floor，无问题；② 但当 `collect_patch_sky` 因无合格 patch 返回 1 时（:166-169 → 上层 :225-227 直接 `rc=1`，不产出 model），以及当调用方以 `snr_noise_model_v1_free` 前的半初始化 model（calloc 后 `variance[]` 全 0）走 `fill` 时，产品会得到 `variance=0`、`ivar=0` **整帧**，而 `fill` 返回 0（成功）。即「非空间退化路径」把「无信息」表达成「方差 0/权重 0」，而非退化码。③ 另有一处真实风险叠加：:415 的 `ivar = v>0 ? 1/v : 0` 在 v=0 时输出 0（正确），在 v 极小（未 apply floor 的 1e-300）时输出溢出 inf。
- 影响: 逐像素权重产品在最坏情况下整帧为 0（Phase2 侧表现为「无任何有效像素」而非「模型缺失」），或被误当作合法常量场消费；合同不变量与实现覆盖面不符。
- 建议处置: 在 `fill_impl` 的两条分支统一 `v = max(v, floor)`（或在非空间分支同样过 floor），并让「模型无有效控制点」时返回 `rc=1` 而非 0；同步 SCI §7 的不变量描述（「所有分支」）。
- 置信度: 高 ｜ related: M3-A-005、M3-C-003、M3-F-003

### M3-H-002 `snr_noise_scale_law` 无条件缩放 `variance`，只在 `α²>0` 且有限时缩放 `ivar` → 可产出 `variance>0` 而 `ivar=0` 的自相矛盾模型
- 类别: H_NUMERIC ｜ 优先级: P1 ｜ 来源: L07-011
- 位置: `lib/snr_estimator/cpp/src/noise_model.cpp::snr_noise_scale_law`（复核时点 :447-454，关键 :449 `*variance *= alpha*alpha;`、:451-453 ivar 条件式）；对照 `snr_estimator.h:::176-178`（注释只写「缩放 ivar」）与 `docs/science/NOISE_MODEL.md::§7 量纲一致`（:76）
- 证据摘录（复核时点重读）:
  > SNR_API int snr_noise_scale_law(double variance, double ivar, double alpha,
  >                                 double* out_variance, double* out_ivar) {
  >     if (!out_variance || !out_ivar) return 3;
  >     *out_variance = variance * alpha * alpha;（:449 —— 对 alpha 无任何校验）
  >     const double a2 = alpha * alpha;
  >     *out_ivar = (a2 > 0.0 && std::isfinite(a2)) ? ivar / a2 : 0.0;（:451-:453）
  > - **量纲一致**：`variance` [ADU²] → `ivar` [ADU⁻²] 倒数关系精确…（SCI §7:76）
  > // 缩放律: var' = var*α²；ivar'= ivar/α²（snr_estimator.h:176-177 区）
- 权威依据: 宪章 §4.1（同一对量必须保持定义关系）、§5.3、§14.4（参数无效域须显式）；SCI-NOISE-001 §5/§7/§8
- 问题说明: `alpha` 未做有限性与符号校验：`alpha=0` → `variance'=0` 而 `ivar'=0`（互倒关系丢失，产品出现「方差 0、权重 0」）；`alpha=NaN` → `variance'=NaN` 但 `ivar'=0`（条件式把 NaN 归 0）→ 输出一个 `var=NaN, ivar=0` 的自相矛盾对；`alpha=inf` → `var'=inf`、`ivar'=0`（此时关系勉强成立）；`alpha<0` → 与正 α 同果（合理但未登记）。而公共头注释只说「缩放 ivar」，未说明 `variance` 也被改、也未说明非法 α 时两者的不对称行为。合同 §7 的「ivar=1/var 精确」不变量在本函数下可被轻易破坏。
- 影响: 该函数是 legacy/diagnostic 通道，但公共导出且被 `p1noise_scale_law` 测试覆盖现状行为（ALG-NOISE:207-209 明确「断言现状行为」），因此任何未来的 α 标定/缩放链都会继承这处不闭合。
- 建议处置: 对 `alpha` 增加 `isfinite && alpha>0` 校验并返回退化码（对齐 §14.4），或在非法时同时把两个量置为不可消费值（都 NaN 或都 0）；把头注与实现及 SCI §7 不变量对齐。
- 置信度: 高 ｜ related: M3-A-004、M3-F-004、M3-H-001
