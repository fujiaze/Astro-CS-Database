### M2b-H-02 pix2ang_nest 对越界 ipix 静默返回 (0,0)（合法天球点），neighbors/xy 换算另有两处 shift 静默夹紧，均未登记偏差且被头注释写成约定
- 类别: H_NUMERIC
- 建议优先级: P2
- 位置: lib/common/healpix/healpix_core.h::pix2ang_nest 声明注释；lib/common/healpix/healpix_core.cpp::pix2ang_nest、::nested_local_to_xy、::xy_to_nested_local；docs/standards/STANDARDS_REGISTRY.md::D.healpix DEVIATION 字段
- 证据摘录:
  - 头注释（原文）:「// ipix 越界时 ra=dec=0 (与调用方约定一致)」
  - 实现（原文）:「void pix2ang_nest(uint32_t nside, uint64_t ipix, double& ra_deg, double& dec_deg) { ra_deg = 0.0; dec_deg = 0.0; require_valid_nside(nside); … if (ipix >= 12ULL * npface) return; }」（先置零再 return，故越界与「未写值」不可分）
  - 两处静默夹紧（原文）:「if (shift >= 32) shift = 31;」（nested_local_to_xy 与 xy_to_nested_local 各一处）
  - 注册表（原文）:「- DEVIATION: 无域内偏差（HEALPix 核心零偏差…）」且 D.healpix 各行偏差列写「无」
- 权威依据: 宪章 §13.5（禁静默夹紧/静默回绕）、§14.4（非法值 fail-fast）、DATA_SEMANTICS §2「非法值拒绝」与 §4 invalid 语义（NaN 或 support<=0）；STD-REG-001 §1.4（偏差须登记）
- 问题说明: (0°,0°) 是赤道与本初子午线交点上的**合法坐标**，调用方无法据返回值把「越界非法输入」与「真值恰好 (0,0)」区分；同一文件族的三处静默收口（1 处哨兵 + 2 处夹紧）与同文件其它路径「require_valid_nside 抛 invalid_argument（R9-B: 禁止静默向上取整）」的纪律自相矛盾。三处都写在注释里但未登记为偏差、无负面测试，故注册表「零偏差」结论与代码事实不符（此面与 M2b-B-07 的 order 无界同族，但事实与本条不同：本条是**已文档化的静默收口**，B-07 是**无界导致的回绕**）。
- 影响: 越界索引被翻译成看似有效的天球坐标，若被上游用作源位置/目标定位即产生静默科学错误（面积权重、匹配、指向）。当前生产主要经 ang2pix 正向路径，风险为潜在，故 P2。
- 建议处置: ① 统一为显式错误：pix2ang_nest 改返回状态（或越界抛 invalid_argument，与 require_valid_nside 同风格），头注释同步删除「约定」措辞；② 两处 shift 夹紧改为范围断言/错误；③ 若决定保留现状，则在 D.healpix 登记为 PROJECT_DEFINED 偏差并补负面测试（越界 ipix 必须可被调用方识别）。
- 置信度: 高
- related: M2b-B-07、M2b-G-04（同一文件族的静默收口与出处声明）、M2b-A-01、L03-015、L15-021（后者的注释卫生面）
- 来源: L03-015
