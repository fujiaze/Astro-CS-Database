- 影响: 交付面 CPU provider 的 kernel 合同（ISA 路由与 provider 数值自测的实际输入）。当有人按注释给 avx2/avx512 增删槽位或改 op 语义时，唯一「依据」是一份未在 L1 登记的注释表；而 provider manifest 里对 host 暴露的 science_contract_id 字面量指向编排层词汇，导致「科学定义=算法=接口=代码=测试」的链条在 CPU provider 边界上不可机器解析。当前不改变已产出数值（kernel 实现本身与 baseline 同式）。
