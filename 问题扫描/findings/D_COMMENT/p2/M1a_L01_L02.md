- 类别: D_COMMENT · 优先级: P2 · 来源: L01-018（**叶子原锚 lib/phase1/ups/build_upm.cpp 在仓内不存在 → 本轮按符号重锚，未因锚失效剔除**）

  > （PLATESOLVE.md:115）U = (det_x − cx, **−**(det_y − cy)) … 像素
  > （ipv_types.h:68-69）int order;      // 前向 SIP 阶数 (0=无 SIP, **2/3/4**)  int ap_order;   // 逆向 SIP 阶数 (0=无逆向 SIP, **2/3/4**)

- 问题说明: ①`StarPoint` 注释称角秒、原点在图像中心，而文档与实现传入的是**像素域**坐标（ALG:115 明确"像素"并带 Y 翻转）——若按注释传入角秒即 3600× 错；②SIP 阶数值域注释为"2/3/4"，实现冻结为 5（前向 AP/BP）与 7（APx/BPx）；③`apx_order` 注"上限 9"而实现常量为 7（数组容量 100 允许 9，属"可支持范围"与"实际生效值"未区分）；④另含一处未逐条复核的原锚（x00 日志单位），置信度记中。
- 影响: 单位与值域注释失真 → 复用/移植时直接触发量纲错误（本域已有 3600× 前科：M1a-A-004）。
- 建议处置: ①StarPoint 注释改"像素（原点在图像中心，Y 轴向上）"并给 px↔角秒的唯一换算点；②值域注释与实现常量对齐（或标"实现取 5/7，接口允许 2..4/0..9"）；③日志单位串随同订正。
- 置信度: 中-高（①②③为逐字复核；④沿用叶子观察未独立复现） · related: M1a-A-004、M1a-D-001、M1a-D-003
