- 证据摘录（逐字，复核时点现文）:
  > 复制站点 1（fits_reader.cpp:359-368）`// 无 CD 矩阵时, 尝试 CDELT + CROTA2 构造` → `double cosr = std::cos(crota2 * DEG2RAD);` / `double sinr = std::sin(crota2 * DEG2RAD);` / `cd[0] = cdelt1 * cosr;` / `cd[1] = -cdelt2 * sinr;` / `cd[2] = cdelt1 * sinr;` / `cd[3] = cdelt2 * cosr;`
  > 复制站点 2（hp_drizzle_api.cpp:564-571）同一六行逐字重复，含**独立的 DEG2RAD 字面量副本**：`wcs.cd[1] = -cdelt2 * sinr;` / `wcs.cd[2] = cdelt1 * sinr;`
  > 反证 1（同仓 vendored cfitsio 正向映射，wcsutil.c:47-58）`dx = (xpix-xrefpix) * xinc;` / `dy = (ypix-yrefpix) * yinc;` / `cosr = cos(rot * D2R); sinr = sin(rot * D2R);` / `temp = dx * cosr - dy * sinr; dy = dy * cosr + dx * sinr; dx = temp;` —— 展开即 `CD1_1 = xinc·cos, CD1_2 = −yinc·sin, CD2_1 = xinc·sin, CD2_2 = yinc·cos`，与本仓两站点**逐元一致**（xinc↔cdelt1、yinc↔cdelt2）。该函数入参注释（wcsutil.c:31）`f   rot     rotation (deg)  (from N through E)` 即 CROTA2 语义。
  > 反证 2（同仓 vendored cfitsio 逆向映射，wcssub.c:250-254）`/* there are 2 ways to compute the angle: */` / `phia = atan2( cd21, cd11);` / `phib = atan2(-cd12, cd22);` —— 把本仓构造代回：atan2(cdelt1·sin, cdelt1·cos)=θ 且 atan2(−(−cdelt2·sin), cdelt2·cos)=θ，**两式同角、自洽**；即本仓构造与该库的 CD↔(CDELT,CROTA2) 双向换算闭合，不存在镜像。
  > 口径未固定（合同面）：DATA_SEMANTICS:246 只写 `CDELT+CROTA2 构造 CD（api.cpp:538）`（无公式、无方向声明）；DRIZZLE_GEOMETRY:116 只有 `| 缺 WCS（CD 与 CDELT+CROTA2 均无） | 拒绝（帧通道返回 -9） |`；对 STANDARDS_REGISTRY.md 全文 grep `CROTA` → **0 命中**（D.fits 域无该映射的符合性行，亦无 DISP 偏差号）。
  > 零对照测试：对全仓测试面 grep `CROTA2` 的真源命中仅 `lib/core/src/module_adapters.cpp:2324`（写出恒为字面量 `"0"`）与两处构造块本身；无任一 fixture 赋非零 CROTA2 并做往返比对（在册 p1drz / p1hips / io 合同面均以 CD 矩阵为前提）。
  > 生产可达性（内证）：module_adapters.cpp:2321-2343 同时写 CD1_1..CD2_2 与 CDELT1/CDELT2/CROTA1/CROTA2，其中 CROTA2 为常量 `"0"`、CDELT1/CDELT2 被赋成 **CD1_1/CD2_2 的值**（:2343 与 :353 分支 `return std::string(b5); // CDELT1`、`return std::string(b8);  // CDELT2`）→ 我方帧永远带 CD，两处 CROTA2 构造块对自产数据不可达（且 CROTA2=0 时 sin 项恒零，构造退化为 diag(CDELT)，数值与 CD 对角一致）。附带观察（属 L01-016 族的**新站点**，本条不另立案、移交前台并档）：若源 WCS 带旋转（CD1_2/CD2_1≠0），该帧头同时断言「带旋转的 CD」与「CDELT1=CD1_1、CDELT2=CD2_2、CROTA2=0」这一**无旋转**表述，两者互斥。

- 问题说明: ①**同一份旋转→CD 代数在两个 TU 各写一遍**（含重复的 DEG2RAD 常量），无公共函数、无注释互指 → 任一处被改（例如负责人日后真裁决口径变更）即产生同仓两制；②**方向/符号口径在本仓任何规范面都不存在**：合同只说"构造 CD"、ALG 只说"缺 WCS 才拒绝"、注册表连 CROTA2 这个词都没有 → 读者无从判断本仓按哪种惯例解释 CROTA2，也无法判断与外部工具是否一致；③**零对照测试**：CROTA2=0 是全部在册数据的唯一取值，故 sin 项的正负在机器面前完全不可观测。④在此前提下，叶子给出的"本仓符号与 Paper I 相反（=把 CROTA2 按 −θ 解释）"这一子主张**不成立**：同仓 vendored cfitsio 的正向映射与本仓逐元相同，且其 CD→(CDELT,CROTA2) 逆向两式与本仓构造闭合自洽；要维持"相反"结论，必须证明 cfitsio 本身违反 Paper I——这已超出内证范围。故本条只登记"未固定/未登记/未测试"这一可自证的事实，标准原文归属仍须人工核对。
- 影响: ①当前**无科学数值影响**：自产帧恒带 CD 且 CROTA2 恒 "0"，两处构造块在生产链上不可达（内证）；②真实风险在**外部输入侧**：读入第三方老工具链产出的"CDELT+CROTA2 无 CD"头时，本仓按哪种方向解释没有任何文档与测试担保，一旦日后裁决为需订正，两副本会不同步改；③标准符合性追溯面缺失（D.fits 域对经典映射零登记）。
