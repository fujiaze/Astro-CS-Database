- 问题说明: 三件实测。①C++ `science_hash` 把两个运行/环境事实（created_utc、platform）混进自称「仅科学 payload」的摘要 ⇒ 同一科学结果在不同时刻/不同机器上摘要不同，直接违 DATA-004 :85-86；②同一仓的 Python 实现合规并被注册采集的真测试钉住（同仓正对照），⇒ 两侧对同一合同给出**不同摘要值与不同长度**（16 hex vs 64 hex），无任何交叉校验；③C++ 侧唯一测试用同一工厂构造两个对象（时间戳与平台字段恒等）⇒ 对「混入运行事实」这一缺陷零鉴别力（把 :62-63 删掉也照样绿），:71 只验 input_hash 变更。④全仓 `science_hash` 命中仅声明/定义/该测试（grep 实测 7 处），**零生产调用点** ⇒ 违宪摘要尚未污染产物，但一旦被接进发布/追溯链就会与 Python 侧结论互斥。
- 影响: DATA-004 的确定性 digest 语义在 C++/Python 两侧不成立且不互容（跨语言产物比对将必失配）；C++ 侧现有测试无法阻止回归。
