# B_STD_MISMATCH — 国际标准偏离

覆盖范围：FITS WCS Paper I/II + SIP、IVOA HiPS 1.0 + properties 1.4、HEALPix NESTED、Drizzle（Fruchter & Hook 2002）、Gaia DR3 data model、FITS 4.0 的实质偏离与登记缺口。

本目录下按优先级分档：

- `p0/`：P0（发布阻断：科学结果错误或产品不合规）
- `p1/`：P1（一致性/可验证性破坏，须尽快修）
- `p2/`：P2（表述与可维护性）

判定标准与证据要求见 `../../10_PROTOCOL.md` §1、§2、§3。定稿文件由第二层合并代理写入，命名为 `<slice码>.md`。
