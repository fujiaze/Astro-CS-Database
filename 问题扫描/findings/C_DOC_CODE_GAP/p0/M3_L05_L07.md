### M3-C-001 SCI-PHOT 冻结的参考星数门（`|r_consistent|>=3`/`|r_inliers|>=2`）在实现中不存在：一颗星即可定标整帧
- 类别: C_DOC_CODE_GAP
- 建议优先级: P0
- 来源: L07-001
- 位置:
  - `docs/science/PHOTOMETRY.md::§4 输入有效域（参考星数条）`（复核时点 :38）、`§8 极端/退化条件表`（:82）、`§5 定义`（:52/:60）、`§15 Acceptance`（:132-133）
  - `lib/photometric_calib/cpp/src/star_matcher.cpp::cleanAndScale`（一致集判据 `if (r_consistent.empty())` 复核时点 :462，退化早返回 :474；`if (!r_inliers.empty())` :553）
- 证据摘录（复核时点重读，三个可分别证明的事实）:
  > - 参考星数 `|r_consistent|>=3` 才进 IRLS，否则 `NO_DATA`；`|r_inliers|>=2` 才估计 `sigma_residual`，否则 `sigma_residual=0`（`552-559`）。（SCI-PHOT §4:38）
  > | 无星/星数不足 | 返回 NO_DATA，`scale=1.0`、`fit_used=0` | `star_matcher.cpp:478` 前校验（星数阈先于任何迭代） |（SCI-PHOT §8:82）
  >     if (r_consistent.empty()) {（star_matcher.cpp:462）
  >         double location = medianOf(r_consistent);（:479 —— 一致集仅 1~2 个元素时照常执行）
  >     double scale = std::pow(10.0, -location);（:528）
  >     if (!r_inliers.empty()) {（:553 —— 即 ≥1，非 SCI 的 ≥2）
  >     double sigma_residual = 0.0;（:552，:558 `mad_in>0` 才换算）
- 权威依据: SCI-PHOT-001 §4/§5/§8/§15；宪章 §4.1（有效域与值域分离）、§5.3、§11（不得留下看似成功的产品）、§14.4（禁静默降级）、§1.1
- 问题说明: **事实 A（缺失门，会改变输出）**：全函数唯一的大小判据是「非空」。当预过滤后只剩 1 颗星时，`MAD(r_consistent)=0 → S=0`（:484）→ IRLS 按 SCI §5:57 的 `S==0` 分支跳过、`location` 即该单星的 `r`（:479）→ `scale=10^(−location)`（:528）→ `pc_api.cpp` 立刻用它整帧乘算（复核时点 :140 / :1069 `out_pixels[i] = pixels[i] * scale;`）。合同要求的 `NO_DATA`/退化码在此路径不存在（唯一退化码只覆盖 `n_gaia<=0`/`n_psf<=0`，pc_api.cpp 复核时点 :279-290）。2 颗星同理（两点 MAD 亦可为 0）。**事实 B（阈值数值不符）**：`|r_inliers|>=2` 未实现，实现为 `!empty()`（≥1），故 1 个内点时 `sigma_residual` 由「单点对其均值的偏差」算得（该值恒 0）→ QA 报「零离散度」而非「不可估计」，并被 `snr_phot=1/(ln10·sigma_residual)`（snr_estimator）与帧级 QA 消费。**事实 C（锚点错位）**：SCI 为两条判据给的锚 `552-559` 落在 sigma_residual 计算块内、`§8:82` 的「:478 前校验」落在 IRLS 初值注释区，两处都不含任何星数阈；`§8:83`（`S==0` 跳过 IRLS）也把锚指向 :552，而真实分支在 :488-491。合同自称「与实现一致」（§5:65），故三条均为可独立证伪的事实，不依赖任一行号。
- 影响: 稀疏星场（小视场、高银纬/高消光区、Gaia 匹配仅 1-2 星）下整帧像素被**一颗星**的通量比缩放，且 QA 面报「散度为 0/已拟合」，无退化标记可查；真实数据路径直接可达（orchestrator → `pc_calibrate_simple_with_gaia*`）。P0 成立（复核时点成立）。
- 建议处置: 由负责人二选一：把 ≥3/≥2 门补入实现并给显式退化返回码（`fit_used=0` + 不写 scale），或按 §1.2 走 SCI 变更正式取消该门；同时把 §4/§8 的证据锚改指真实符号。不得维持「文档有门、代码无门」。
- 置信度: 高
- related: M3-C-002、M3-C-011、M3-E-002、DISP-PHOT-005

- 影响: 星团/银心等亮星密集真实帧高概率触发；全帧测光零点被截顶通量拉偏，且 QA 面无法归因（`rejected_quality` 只统计 status 无效数）。P0 成立。
- 建议处置: 公共 API 增 `const uint32_t* quality_flags` 入参并在有效域处过滤（推荐，配套补 §8 返回/计数语义），或按 §1.2 修订 SCI-PHOT §4/§10 并给出「PSF status 已隐含饱和排除」的上游合同证据（当前 dynamic_psf 侧证据恰好相反）。
- 置信度: 高
- related: M3-C-001、M3-C-011、M3-D-003、M3-E-002、DISP-PHOT-006
