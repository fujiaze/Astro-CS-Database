- 问题说明: 四处口径互斥且互不覆盖：①共享 vs 私有——ARCH 说共享缓存持锁加载，实现与 ALG §7 都是每 worker 私有；②LRU vs FIFO——ARCH §1 与 ALG-P3-003 伪代码写 LRU，实现无访问序更新，DISP-P3RSMP-002 只登记「ALG §3 伪代码」，未登记 ARCH §1 同名词条（偏差登记面不完整）；③内存上界式不含 worker 数——实际驻留 ≈ `n_workers·max_tiles·W²·4`（worker 数=budget.max_workers，可达数十），ARCH §3 的上界式与 :30 的「超出→MEM_BUDGET 诊断」按单缓存写，令守卫少算一个数量级；④「I/O 线程 1（异步预取深度=1）」与实现的「每 worker 自开 tile 读、无预取线程」相反 ⇒ 同一 tile 在 N 个 worker 下被打开/读取 N 次，这部分 I/O 与 RSS 不在任何声明里。
