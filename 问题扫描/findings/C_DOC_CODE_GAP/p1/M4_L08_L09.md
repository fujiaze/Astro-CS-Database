### M4-C-04 「单帧区 harmonic continuation 填」在 CLI 会话默认装配不可发生（P2 会话无 nodes、λs=0；λ0 又被置 0 加剧）
- 类别: C_DOC_CODE_GAP
- 定稿优先级: P1（来源 L08-005 原议 P1，成立）
- 位置: docs/science/PHASE2_UPM.md:88,134；lib/phase2/include/astro/phase2/upm.h:99-101；lib/phase2_session/p2_session.cpp::「rc = p2_upm_build」（复核时点 :204）；lib/phase2/src/upm.cpp::lambda 修补（复核时点 :245）；docs/algorithms/PHASE2_UPM_IMPL.md:356（§12 T7 现状列「测试实现 MISSING」）
- 证据摘录:
  > | 单帧区 | harmonic continuation 填 | `phase2` 域 |
  > 2. **退化路径**：无 ≥2 帧 clean coverage → harmonic continuation 填单帧区，标 `control_source=continuation`；
  > // ……数据项，由全局平滑/Laplacian 延拓得到 C（harmonic continuation）。
  > if (cfg.smoothing_lambda < 0.0) cfg.smoothing_lambda = 0.0;
- 权威依据: SCI-UPM-001 §8:88/§9a:134；ALG-P2-UPM-IMPL §12 T7
- 问题说明: continuation 需要（a）无观测几何节点在解空间（build_geo 的 nodes 输入）与（b）λs>0（Laplacian 耦合）。CLI 会话走 p2_upm_build（不传 nodes）且 λs 默认 0（仅 config 显式给 smoothing 键才 >0），无数据自由度在 λs=0（叠加 M4-C-02 的 λ0=0）下恒为初值 0——延拓不发生；stage2 工具（build_geo + smoothing auto→0.1，stage2_common.cpp:132-140 复核）才具备该行为。SCI 无条件断言「填」不成立。定稿校准：生产 IR 节点链走 build_geo（有 nodes），但 fit_upm 装配同样默认 λs=0（override 仅 config 给键时）——若运行配置未给 smoothing，节点链上无数据节点亦不延拓。ALG T7 自认测试 MISSING，无门暴露。
- 影响: 覆盖率不均真实数据的单帧/无观测区在产品路径得到 C=0 而非延拓场；用户按 SCI §9a 做的误差预算失真；control_source=continuation 标记面落空。
- 建议处置: 裁决 SCI §8/§9a 行改条件化表述（λs>0 且 geo 节点在场），或生产装配默认补 λs；T7 补可执行门。
- 置信度: 高
- 来源: L08-005
- related: M4-C-02（λ0 同装配面）、M4-F-01
