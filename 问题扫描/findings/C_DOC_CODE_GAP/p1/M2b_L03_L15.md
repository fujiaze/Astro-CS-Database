- 问题说明: 三个生产调用点都写着「AIO-002 原子发布原语内建」，实现面零 staging 原语——begin 直接 CreateDirectory 到最终路径、tile 用 remove+create 就地覆盖、properties/Moc.fits/metadata.fits 逐个直写、abort 只 delete 句柄；进程失败/退出后 out_dir 留下「有 properties、缺 tile」的半产品，且除 manifest 外无 COMPLETE 标记可判。**定档对象辨析**：DISP-HIPS-004 已诚实登记「缺原子发布能力」，故本条不重复登记该能力缺口，只登记**注释与实现的直接矛盾**——三句注释所做的正是 DATA_SEMANTICS §12.5 明文禁止的「以 writer 直写目录冒认 IO-003 原子语义」。同时原子实现确实齐备（stage_create/discard/tree_fsync/promote 四原语，唯一实现 lib/hips/src/aio_publish.cpp），只是被 M2b-A-01 描述的同一 IR 路由绕开 → 修法是接线而非新建。
