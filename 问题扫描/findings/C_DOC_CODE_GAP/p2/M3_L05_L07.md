### M3-C-013 `pc_calibrate_simple` 的返回码合同与实际返回值不符（`-3` 永不可达、同一条件两处不同码）
- 类别: C_DOC_CODE_GAP ｜ 优先级: P2 ｜ 来源: L07-023
- 位置: `lib/photometric_calib/cpp/include/photometric_calib.h::返回码合同`（复核时点 :101-104）；`lib/photometric_calib/cpp/src/pc_api.cpp::pc_calibrate_simple 退化分支`（:92、:105）、`::参数校验`（:74、:78）、`::pc_calibrate_simple_with_gaia 校验`（:204、:208、:212、:216）
- 证据摘录（复核时点重读）:
  > -1: 输出指针为空或图像尺寸无效；-2: Gaia 客户端句柄无效；-3: 无Gaia星/PSF星(退化scale=1.0)；其他非 0: 内部错误（photometric_calib.h:101-103）
  >         *out_scale_factor = 1.0; *out_n_matched = 0; *out_fit_used = 0; … return 0;（pc_api.cpp:84-92 退化块，结尾 `return 0`）
  >         if (width <= 0 || height <= 0) { … return -2; }（:78）
  >     if (width <= 0 || height <= 0) { … return -1; }（:208 —— _with_gaia 同条件返回 -1）
  >     if (gaia_client_handle == nullptr) { … return -2; }（:212）
  > | -3 | 无 Gaia 星 / PSF 星（退化，scale=1.0） | ALG-PHOT:158-160（DISP-PHOT-005 区） |
- 权威依据: 宪章 §12.3-1（接口文档陈述须逐符号命中）、§14.4（返回码是唯一机器可读错误通道）、§11
- 问题说明: 头文件承诺「-3 = 无 Gaia/PSF 星（退化）」，但退化在 `pc_calibrate_simple` 内被写成 `scale=1.0` + `return 0`（成功），全函数不存在任何 `return -3`（该码只在 `_with_gaia` 的星表拉取失败分支 :263 使用，语义也不同）。同时「尺寸无效」在 simple 里是 `-2`、在 `_with_gaia` 里是 `-1`，而 `-2` 在后者专指句柄无效 → 同一份头合同无法同时描述两个函数。ALG-PHOT:158-160 用「退化 scale=1.0」描述现状，等于承认头合同的 `-3` 行是死条款。
- 影响: 调用方按头文档判 `-3` 会永远走不到；同条件不同码使跨函数错误处理分叉。属接口文档缺陷（不改当前科学输出，因退化路径本身已在 ALG 登记）。
- 建议处置: 逐函数给出真实返回码集合（或拆表），把 `-3` 改为「星表查询失败」并删去与 `return 0` 冲突的退化描述；两函数的尺寸/句柄校验码统一。
- 置信度: 高 ｜ related: M3-C-012、M3-C-010
