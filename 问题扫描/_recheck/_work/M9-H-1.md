## M9-H-1 Gaia 模块 manifest 拼接：snprintf 返回「本应写入数」推进指针 + 转义函数无容量入参 → 512 字节栈缓冲越界写，且同一越界长度被回读进产品

- 类别: H_NUMERIC（主）；次挂 C_DOC_CODE_GAP、G_GOV_GATE
- 优先级: P0
- 来源: L24-001（前台代录，本代理独立复验成立，并补两项叶子未记的加重事实）
- 位置: lib/gaia_xpsd_client/src/module_entry.c::gaia_execute（head 缓冲与推进点）、::gaia_inspect（同型第二站点）、::json_append_escaped（无容量转义器）、::gaia_cfg（catalog_dir 尺寸源）
- 证据摘录（逐字，复核时点现文）:
  > （module_entry.c:384）`static void json_append_escaped(char** w, const char* s) {` — 签名只有写指针与源串，**无剩余容量入参**；体内 `*(*w)++ = '\\'; *(*w)++ = *s;` 逐字节自增，亦不写终止符。
  > （:738-741）`char head[512];` / `char* hw = head;` / `hw += snprintf(hw, (size_t)(head + sizeof(head) - hw),` —— 用 snprintf **返回值**（=本应写入的字符数）推进 hw。
  > （:766-768）`size_t schema_len = strlen(schema);` / `memcpy(hw, schema, schema_len);` / `hw += schema_len;` —— 无界 memcpy，长度由 schema 字面量决定（CONE 支 :751-753 实测 127 字节）。

- 权威依据: 宪章 §14.4（配置/CLI 输入属信任边界，须 fail-fast 返回明确状态码）、§8.6、§11（禁吞错后继续产出"看似成功"的产品）；同文件 :24-27 自述的两阶段输出合同（尺寸查询→写入→不足即 BUFFER_TOO_SMALL）**只覆盖出参 strbuf，未覆盖这两个内部栈缓冲**。
- 问题说明: 三重缺陷叠加，本代理逐段复算（口径=按 :738-777 各段字面上界求和，非实测）：①转义器逐字节无界写入；②snprintf 返回截断前的应写长度，故 :741/:770/:774 三处一旦触边即令 hw 越出数组；③算术：`'{'` + 固定前缀（含 module_id/op/布尔/整数字段）+ schema 字面量（≤127）+ spec 三字段 ≈ 300–390 字节，head 余量 120–210；catalog_dir 容 1023 字符、全需转义时膨胀为 2046 → **越界写最多约 1900 字节**（与叶子同量级，独立复算一致）。另两点为叶子未记：④**越界长度会被回读**——:808 用 (hw−head) 计 total，:857 再以同长度 `memcpy(big, head, …)`，故产品 manifest 会把栈上 head[512] 之后的相邻字节原样拷进交付 JSON（信息外泄，且 total 与实际有效内容不一致）；⑤**触发点前移到两阶段协议第一次调用**——:830-841 的"仅报尺寸"分支同样执行 :738-777 的整段拼装，即调用方按合同先问尺寸时，溢出与回读已发生。
- 影响: astrocs_catalog_gaia 为随产品发布的官方模块（Phase1/2 取参考星与光谱的必经路径），execute 与 inspect 分别是每次查询与 host 诊断的必经调用。触发条件仅为 catalog_dir 超过约 120 字符——Windows 深路径、网络盘、含空格目录即命中（本项目正式平台为 Windows amd64，宪章 §3.1）。后果为栈破坏（随机崩溃或经构造目录串操控返回地址）+ 交付 JSON 含栈内容 + inspect 侧的巨量 snprintf 写。属发布阻断级。
- 建议处置: ①`json_append_escaped` 增加剩余容量入参并返回是否溢出（越界即整次输出失败）；②所有推进点对 snprintf 返回值取 `min(返回, 剩余)` 夹紧，触边即返回 ACS_ERR_PARAM/INTERNAL 并停止产品提交（只在边界校验一次，不在 CLI/AIO/算法层重复）；③head/buf 改为「先按各段字面上界精确求和 → 一次性分配」，与同文件出参两阶段合同同口径（:101-105 的写法即现成模板）；④负向用例：catalog_dir 长度 119/120/121/1023 + 全引号反斜杠 + 控制字符，断言不越界、状态码明确、**且尺寸查询阶段也不得越界**（ASan 版 ctest 注册——注意本域该注册面本身失守，见 M9-F-1）。
