### L19-001 Y-down 翻转给前向 B 多项式多乘整体负号，与同段「CRVAL/CRPIX 不变」要求矛盾（Dec 畸变项符号错）
- 类别: A_SCI_DEF
- 建议优先级: P0
- 位置: docs/science/ASTROMETRY.md::§5「Y-up → Y-down 转换」代码块（复核时 60-63）
- 证据摘录:
  >   cd12, cd22 取反
  >   A'[i][j] = A[i][j]·(−1)^j,  B'[i][j] = −B[i][j]·(−1)^j
  >   AP/BP 同规则；CRVAL/CRPIX 不变, |det(CD)| 不变
- 权威依据: 宪章 §5.3；SCI-WCS-001 自身 §5/§7；Paper I：同一天体的中间坐标 (u,v) 不因像素轴翻转而变
- 问题说明（复算）: 翻转即 Δy*=−Δy（CRPIX2=(h+1)/2 是不动点，与 §7 一致）。世界坐标不变性要求 v = CD21Δx + CD22Δy + Σ B_ij Δx^i Δy^j = CD21Δx + (−CD22)Δy* + Σ B_ij(−1)^j Δx^i Δy*^j ⇒ 唯一解 B* = B·(−1)^j，无额外整体负号（A 侧推导完全对称、文档 A 侧正确）。多出的 −1 使 v 的全部 SIP 项反号：径向对称畸变（j 偶项为主，(−1)^j=+1）下 Dec 出现 O(A·r³) 反对称系统偏差。该 −1 仅当同时镜像 v 轴（翻转 CRVAL 语义）才成立，而同段明言 CRVAL/CRPIX 不变——两句互斥。「AP/BP 同规则」亦未考虑逆向含 §5「AP[1,0]-=1, BP[0,1]-=1（剔除单位线性）」平移约定，前向规则不可原样外推。
- 影响: 冻结 SCI 为权威层；按字面施工/复核者得错误 Dec 畸变改正；若实现取另一侧则 SCI↔实现互斥且无偏差登记。
- 建议处置: 数学 Owner 重推订正 §5（或补全使 −1 成立的存储/轴约定推导）；M1a 与 ipv_wcs/p3_wcs 现文本逐字核对：实现=B(−1)^j → 本条降 P1「冻结公式可证伪且与实现互斥」；实现=−B(−1)^j → 产品 WCS 带符号错误，维持 P0。
- 置信度: 高（推导闭合；残余不确定=文档未写明的存储约定）
- related: L01-001（同 §5 SIP 域错配）、L01-002/003（原点簇）、L15-011（LONPOLE 同族）

### L19-002 SCI-CW「量纲区隔不混用」被自身代数拆穿：snr²≡signal²·ivar，support×snr² 即把 support 用作科学权重且破坏加权均值无偏性
- 类别: A_SCI_DEF
- 建议优先级: P1
- 位置: docs/science/CONTROL_WEIGHT_SNR.md::§4 连续定义（复核时 42）与 §6 量纲区隔不变量（复核时 72）
- 证据摘录:
  >   weights[s] = support[s] × snr_v²                      # 禁止 snr=1.0 伪装 unknown
  > - **量纲区隔**：SNR（无量纲）与 variance/ivar（ADU²/ADU⁻²）不混用；
- 权威依据: 宪章 §6.3「support/coverage 不能作为 inverse-variance 或 SNR 权重」
- 问题说明（复算）: 对任何 SNR=x/σ：snr² = x²·ivar。「SNR 因子」与 ivar 不是两个不混用的权重语义，而是 ivar 再乘被加权样本自身信号平方——「区隔」在代数上不成立。后果：(1) 权重随样本值增大（w∝x²），E[Σwx/Σw]≠E[x]，含源 cell 被系统性放大（背景重建向亮端偏置）；(2) support 显式乘入逐像素排异/积分权重，冻结 SCI 自身命令违反 §6.3 红线。本条只读本文件即可证，独立于 L07-004 的跨文档口径之争。
- 影响: Phase2 控制/积分权重链的无偏性声明。
- 建议处置: 与 L07-004 并档；若保留 support×snr² 须补权重-信号独立性失效时的偏差界。
- 置信度: 高
- related: L07-004、L07-003、L09-003

  > - 解析不变量→SYN-003 转换：…estimator bias 与 ivar 边界（零/负/NaN→ivar=0）登记 SYN-003。

### L19-007 SCI-NOISE 全局兜底式 variance_bg_global = max(vmed_or_sig², floor) 量纲歧义：vmed 已是方差，再平方则 ADU⁴
