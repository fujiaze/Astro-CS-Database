### §1.3b 派发令第 2 步的逐类回答

- **A 类该不该被引用**：该。偏差登记（DISP）的语义是「实现与标准之间的已裁差异」，其唯一能证明"差异仍然成立"的消费者是门/waiver；实测 **ci/\*\* 与 tools/\*\* 与 scripts/\*\* 对 `DISP-` 族 0 字面命中**（`ci/checks.json` 只有 `UT-CPU-DISPATCH` 之类的检查项号，`ci/known_failures.json` 无 DISP 键），唯一的机器消费者是 docs 侧自证的 `docs/standards/checks/check_standards_registry.py:63-66`（`DEVIATION_ID_RE`，只验**格式与闭包**，不验任何代码/waiver 关联）⇒ 5 枚连范围锚都没有的 DISP 是缺陷，但整族的门脱钩按派发令交 §3。
- **B 类该不该被引用**：该。测试 ID 的运行时宿主是测试文件名/ctest 名/测试头注释；实测同族对照存在——`lib/snr_estimator/cpp/test/noise_model_science_test.cpp:5` 有 `// TEST-SNR-001: ...` 头锚，证明纪律可执行；而 TEST-UPMW/TEST-PR-UPM 系列 16 枚在 lib/**、tests/** 全零命中 → 缺陷（L28e-E-001）。
- **C 类**：16 枚（ARCHIVED/归档面）+ 19 枚（治理/评审/审计/owner 面，全 526 口径）**不该被引用**，本轴显式统计并排除，不计入缺陷规模。
- **D 类该不该被引用**：该（宪章 §12.3-3「算法实现引用有效 SCI/ALG」+ 五元组）。判定用正面标准而非感觉：①该 ID 在权威文档里**与具名符号或具名 descriptor 同段绑定**（例 `docs/science/PHASE2_UPM.md:113` `ALG-UPM-002` ↔ `p2_upm_calibrate_block`）→ 必须被代码侧引用；②该 ID 出现在 `docs/contracts/DATA_ARTIFACTS.md` §1 schema 表（该文件 :42-48 为另两枚 ID 明举 descriptor/registry.json/tests/MATRIX 四条代码侧证据，即该表自己的登记纪律要求代码锚）→ 必须被引用；③仅出现在标准文件的示例代码块内（`docs/standards/COMMENT_STANDARD.md:38`）→ 属 R-3 伪锚，判为示例造锚，另立 D_COMMENT。
