### L08-001 kcorr_lookup 把非均匀 pixfrac 网格当均匀插值，生产默认 0.8 列返回表外漂移值
- 类别: C_DOC_CODE_GAP
- 建议优先级: P0
- 位置: `lib/phase2/src/sampler.cpp:88-109`、`lib/phase2/src/sampler.cpp:78-82`、`docs/science/PHASE2_UPM.md:100`、`docs/algorithms/PHASE2_SAMPLER.md:405`
- 证据摘录:
  > static const double pf_grid[3] = {0.5, 0.8, 1.0};
  > const double wi = (pf - pf_grid[0]) / (pf_grid[2] - pf_grid[0]);
  > const double i0 = wi * 2.0, i1 = i0 + 1.0;   // 网格列
  > | F2 | kcorr_lookup 边界与角点：pf∈{0.5,0.8,1.0}×sc∈{300,600} 九值…… | 角点值 exact；插值点 rtol 1e-12 | 无（新建；表值 :91-94） |
- 权威依据: SCI-UPM-001 §10「改变 `k_corr` 默认 1.4……」为不可接受变化（`docs/science/PHASE2_UPM.md:100`）；ALG-P2-SMP-001 §11.3 F2「角点值 exact」；宪章 §6.3（常数须冻结可追溯）
- 问题说明: 插值代码假设 pixfrac 网格均匀（`i0 = wi*2.0` 把 [0.5,1.0] 线性映到 [0,2]），但网格是 {0.5,0.8,1.0} 非均匀。在表格节点 pf=0.8 处 wi=0.6→i0=1.2→返回 k[·][1]+0.2×(k[·][2]−k[·][1])：sc=300 得 1.4136 而非冻结表值 1.3925（+1.51%）；sc=600 得 2.9584 而非 2.8971（+2.1%）。pf=0.5/1.0 两端点恰好精确，掩盖了中间节点系统性错位；而 0.8 正是生产默认（:80 注释「pixfrac=0.8 生产默认」）。正确形式应为两段分段线性（0.5–0.8、0.8–1.0）或在 0.8 处直接命中表值。
- 影响: 凡帧 Drizzle provenance 给出 pixfrac≈0.8 的真实数据，`kcorr_f`（:839）→ `control_variance=kcorr·(π/2)σ²/N`（:840）系统性放大 1.5–2.1% → `control_ivar` 相应缩小 → UPM 生产权重（quality×control_ivar）与 Huber sigma_eff 全链偏移；直接违背 F2「角点 exact」冻结设计与 SCI §10 冻结面。无任何可执行测试能暴露（F2 现状「无（新建）」，见 L08-003/008）。
- 建议处置: 请科学负责人裁决修正插值段映射（或显式声明角点语义变更并走 §1.2/合同变更）；按 F2 设计落地角点测试并接入产品构建。
- 置信度: 高
- related: L08-003、L08-008；ALG-UPM-CONTROL-IVAR-001
