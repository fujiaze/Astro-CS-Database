### §0.3 判据（逐字抄 问题扫描/_cache/L28b.md §1.3，本轴不另立）

> 1. **R-6a 自报计数可复算**：注释中出现「N 个 / N 处 / 共 N / N 项」时，CI 必须能在同一文件用 AST 或 grep 复算该 N；复算不等 ⇒ 报 D_COMMENT-SELF-COUNT-MISMATCH。本域实测命中：3 处（reader/writer/aio_api 的异常屏障自述，L28b-D-003）+ 边界计数型 1 处（providers 的 12 kernel，与 :86 承诺同族）。
> 2. **R-6b 锚必须有宿主**：注释中出现 (line N) / :N / §N / 数字编号 ID 时，同窗口必须出现宿主名（文件名、符号名或登记面 ID）；缺宿主 ⇒ D_COMMENT-ANCHOR-HOSTLESS。实测命中面：8 处（全部在 sdet_api.cpp 一处文件，L28b-D-001）；空括号 [ ] 形态 5 命中其中真残留 1（假阳率 80%，须加「括号前无数值常量紧邻」限定，L28b-D-004）。
> 3. **R-6c 注释被指派为权威 = 必须回写 L1**：实现文件里出现「详见 … 注释」「(对照 ALG 权威; 详见 *.h 注释)」等**把权威外包给注释**的句式时，被指向的注释内容必须已在 docs/ 存在同名条款，否则报 D_COMMENT（并把该注释块列为待迁件）。实测命中：1 处（baseline_provider.cpp:28 → baseline_provider_v1.h:102-112，L28b-D-002）。

**本轴执行时的两条收紧（派发令第 2 点第③条＝单位/公式断言，落在 R-6c 的"注释承载断言"语义内）**
