### L01-001 SCI 前向 WCS 公式把像素域 SIP 加在天球域中间坐标上，量纲不闭合且与实现不一致
- 类别: A_SCI_DEF
- 建议优先级: P0
- 位置: docs/science/ASTROMETRY.md:45-49（另 :66 自述"与实现一致"）；对照 lib/plate_solve/cpp/ipv/src/ipv_wcs.cpp:869-872 与 tests/unit/p1wcs/p1wcs_oracle.hpp:60-61
- 证据摘录:
  > 前向 WCS (像素→天球):
  >   xp = x+1,  yp = y+1
  >   (u,v) = CD · (xp−CRPIX) + SIP_A/B(u,v)   # (u,v) 为 TAN 投影中间坐标
  >   (RA,Dec) = TAN^{-1}(u,v; CRVAL)
  > （ASTROMETRY.md:66）与 `lib/plate_solve/cpp/ipv/src/ipv_wcs.cpp:13-16,153-164,274-420,530-576` 及 `ipv_select.cpp:695,712` 一致。
- 权威依据: FITS WCS Paper I §2.1/§5 + SIP（Shupe 2005）：畸变修正施加在像素域（x′ = x + ΣA_ij x^i y^j，再乘 CD）；宪章 §7.3（WCS 以 Paper I/II 为准，科学定义不得由代码反推）。
- 问题说明: CD·(xp−CRPIX) 结果单位 deg；而按 §2:21 与 §9a:129 自己冻结的系数单位 1/px^{i+j-1}，SIP_A/B(u,v) 求和项单位是 px——两域直接相加是量纲错误。正确形如 (x′,y′) = (Δxp) + SIP_A/B(x′,y′) 之后 (u,v) = CD·(x′,y′)。实现与测试 oracle 均按像素域正确组合（F(u)=u+A(u)=CD⁻¹(ξ,η)，ipv_wcs.cpp:851-862）；p1wcs_oracle.hpp:60-61 注释自证病灶："初版将 f(px) 直接加到 CD·(u,v)（度）上……初版实现有两处此类量纲缺陷"。SCI §5:66 仍断言该公式"与 ipv_wcs.cpp 一致"。
- 影响: 以 FROZEN SCI 为唯一权威的实现者/复核者按 §5 做链路会产生像素量级数值错误；"科学=算法=代码"五方链在源头断裂；该缺陷曾真实显形（oracle 注释记录的初版两处量纲缺陷均逃过自洽门）。
- 建议处置: 按宪章 §1.2 流程修订 §5 前向公式为标准形（像素域加法后再 CD），同步订正 ALG §2/§3；:66 锚一并修正。
- 置信度: 高
- related: L01-004、L01-007；ALG F2/F3
