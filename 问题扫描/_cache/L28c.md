### §0.3 判据原文（逐字抄自 问题扫描/_cache/L28b.md §1.2/§1.3 的 D-TRACE-1，不另立判据）

- **R-1 单元定义**：以「声明单元」为审计对象（公共头中的函数声明 / 类型声明 / 结构体字段），窗口 = 上方连续注释块（间隔 ≤6 行）∪ 同行尾注 ∪ 下方 1 行注释。**不得**以 @brief 等标签为锚。
- **R-2 溯源三式**（满足任一即 T1「有溯源」）：①具体 ID 锚 = `(SCI|ALG|DATA|DISP|STD|ARCH|TEST|EVID|API|ABI|IO|AIO)-[A-Z0-9][A-Z0-9-]*-?[0-9]+` 且该 ID 在 docs 登记面可解析；②书目锚 = URL/DOI/arXiv/标准名（Paper I、IVOA、Górski、Fruchter、cfitsio、wcslib、HEALPix）或「作者 + 年份」；③散文锚 = 「来源/出处/依据/推导/公式/reference/derived」类词 **且** 同窗口内含可定位指针（docs/ 路径、.md、§、符号名）。
- **R-3 伪锚排除**：占位形（SCI-xxx/ALG-xxx/DATA-xxx）、通配形（ALG-PHOTOMETRIC-FIT-*、ALG-STAR-PSF-*，除非同窗口另给存在的路径）、废止编号形（ALG-0NN）不计为溯源。
- **R-4 三态**：NEED「该有」= 窗口内出现 ①物理量/单位词（deg、arcsec、pixel、adu、electron、Jy、sigma/variance/ivar、PSF/FWHM、RA/Dec、nside、tile、历元、通量、权重、support、coverage、曝光、容差…）或 ②公式/算法词（sqrt/pow/median/mean/clip/拟合/迭代/归一/归约/加权/奇异/收敛/插值/高斯/阶…）或 ③非常规数值（科学计数法、0.0xx、≥100 的整数阈）；且该文件不在 **G-1 白名单**（纯 I/O 胶水/日志/序列化/错误码表/句柄与线程原语 + 非生产面）。T1 有溯源 / T2 无溯源但域内无外部算法 / **T3 无溯源且该有**。
- **R-5 两档**：strict = 符号级（R-2 须命中在单元窗口内）；loose = 同文件前言块命中即豁免同头符号（仅作存量基线，不冒充达成率）。
- **R-6 反向危害**：窗口内出现**可交比断言**（计数「N 个/N 处」、返回值表「0=…, -1=…」、单位/量纲词、公式、行锚 (line N) 或 :N、空括号 [ ]）时，必须再加一致性检查。子式：**R-6a 自报计数可复算**、**R-6b 锚必须有宿主**、**R-6c 注释被指派为权威 = 必须回写 L1**。
- **本域 extractor 与 tier1 的唯一差异（诚实声明）**：L28b 的抽取器实现未落盘（只读纪律），本域按 R-1 文字定义重写抽取（花括号深度 + 声明形态正则），故**单元绝对数不可与 tier1 直接相加**；两堆可比的是**比例族**（有溯源%、被消费%、字段档%、文件级含 ≥1 具体 ID 头占比）与 R-6 命中实例。tier2 全堆无一行 ≥1990 字符（H-1 自查：81 文件程序内长度检查 = 0），故窗口抽取不受 read 截断影响。
