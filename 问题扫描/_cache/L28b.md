## §1 发现

### §1.1 宪章 §12.2 到底要求了什么（逐字，不重报 M6a-G-001）

§12.2 全文只有 4 行正文（宪章 :423-429）：标题「### 12.2 面向 Agent/机器的 L1–L3」+ 三条分层（L1: SCI/ALG/DATA/ARCH/API/ABI 规范；L2: 模块 README、manifest、函数合同、实现和测试说明；L3: AST/API/ABI 清单、调用图、Pipeline 图、运行 trace、追踪矩阵、静态分析、数值和性能报告），加一句注释规则（:429）逐字：

**关键判定（这是任务一的落点）**：§12.2 的注释条文是**内容清单式**（「只解释 X」+「禁止 Y」），**没有任何一句要求注释提供来源溯源**；溯源义务实际来自 §12.3-3（「算法实现引用有效 SCI/ALG」，注意主语是**实现**不是注释）与 L2 标准 COMMENT_STANDARD.md:10/:15/:17（「科学公式：变量/单位 + SCI/ALG ID」「unusual numeric constant 来源」「workaround 必须链接 issue/ADR」）。⇒ 负责人若要下「注释必须可溯源」的条款，**不能靠解释 §12.2 得到**，必须新增条文（草案见 §1.4）；否则机器门没有义务源，只能停在 COMMENT_STANDARD 的 L2 层，被 §1.1 权威分层压住。§12.2 零机器实现已由 M6a-G-001 定 P0，本域不重报（只在 §2.2 给一条订正）。

### §1.2 任务一：可机检的「注释溯源」判定式草案 D-TRACE-1 + 仓库现状实测

**判据（六条，全部可实现为 grep/AST 级检查，无需运行程序）**

- R-1 单元定义：以「声明单元」为审计对象（公共头中的函数声明 / 类型声明 / 结构体字段），窗口 = 上方连续注释块（间隔 ≤6 行）∪ 同行尾注 ∪ 下方 1 行注释。实测该窗口在 tier1 覆盖率良好（2,827 单元）。**不得**以 @brief 等标签为锚——本仓公共头 @brief 命中 = 0（grep，include=*.h，作用域 lib 与 include），@file/@brief 只出现在 .cpp（如 lib/star_detector/src/sdet_api.cpp:2-3）。
- R-2 溯源三式（满足任一即 T1「有溯源」）：①**具体 ID 锚** = (SCI|ALG|DATA|DISP|STD|ARCH|TEST|EVID|API|ABI|IO|AIO)-[A-Z0-9][A-Z0-9-]*-?[0-9]+ 且该 ID 在 docs 登记面可解析；②**书目锚** = URL/DOI/arXiv/标准名（Paper I、IVOA、Górski、Fruchter、cfitsio、wcslib、HEALPix）或「作者 + 年份」；③**散文锚** = 「来源/出处/依据/推导/公式/reference/derived」类词 **且** 同窗口内含可定位指针（docs/ 路径、.md、§、符号名）。
- R-3 伪锚排除（否则门必假绿）：三类不计为溯源——占位形（SCI-xxx/ALG-xxx/DATA-xxx）、通配形（ALG-PHOTOMETRIC-FIT-*、ALG-STAR-PSF-*，除非同窗口另给存在的路径）、废止编号形（ALG-0NN，仓内明文标注为「编排层占位词汇」）。实测三类合计 22 单元（18+2+2）。
- R-4 三态判定（派发令要求的核心）：**该有（NEED）** = 窗口内出现 ①物理量/单位词（deg、arcsec、pixel、adu、electron、Jy、sigma/variance/ivar、PSF/FWHM、RA/Dec、nside、tile、历元、通量、权重、support、coverage、曝光、容差…）或 ②公式/算法词（sqrt/pow/median/mean/clip/拟合/迭代/归一/归约/加权/奇异/收敛/插值/高斯/阶…）或 ③非常规数值（科学计数法、0.0xx、≥100 的整数阈）；且该文件不在 G-1 白名单内。**白名单 G-1「域内无外部算法」** = 纯 I/O 胶水/日志/序列化/错误码表/句柄与线程原语（按文件与符号名双匹配：logger|logging|json|dll|spill|monitor|admission|scheduler|status_codes|async_io|lifecycle|common_abi|host_api|module_api|io_adapter|trace.h|checkpoint 等），以及**非生产面**（lib/acr/** 依 §10.1，install-tree 外的独立 project）。三态：T1 有溯源；T2 无溯源但域内无外部算法（不要求，不立条）；T3 无溯源且该有（**这才是 finding**）。
- R-5 分级与阈值：strict 档（符号级，R-2 须命中在单元窗口内）用于新增代码与合同头；loose 档（同文件前言块命中即可豁免同头符号）用于存量整改基线。实测两档差距 = 66/94（loose 把 30% 的 T3 归为「头级已给锚」），故**建议**：新门以 strict 起报、按文件给白名单收敛，不用 loose 冒充达成率。
- R-6 反向危害附加判据（任务二用）：单元窗口内出现**可交比断言**（计数「N 个/N 处」、返回值表「0=…, -1=…」、单位/量纲词、公式、行锚 (line N) 或 :N、空括号 [ ]）时，除溯源外必须再加一条一致性检查（与自身文件或 L1 文档可复算比对）。本域 5 条 finding 全部落在 R-6 的形态上，而非「缺注释」。
