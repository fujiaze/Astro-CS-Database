### L20-001 per-control 归一化把 control_ivar 绝对量级消除，SCI 声明的 k_corr 缩放律与禁改条款在解算面不可观测
- 类别: A_SCI_DEF
- 建议优先级: P1
- 位置: docs/science/PHASE2_UPM.md::§5「科学权重 (V19R3 冻结 SCI-UPM-WEIGHT-001)」块（复核时 :46-49）、§7「k_corr 缩放」（:79）、§10（:100）；
  docs/algorithms/UPM_SOLVER.md::§2 F1/F2（:15-17）；docs/algorithms/PHASE2_UPM_IMPL.md::§6 F2「build 内」（复核时 :173-174）、§11「权重门 UPMW-001..007」
- 证据摘录:
  > w_UPM = quality_factor × geometric_reliability × control_ivar
  > raw = quality × control_ivar ; normalized = raw / Σraw · geom (per-control)
  > - **k_corr 缩放**：`control_variance` 随 `k_corr` 线性缩放，`N_eff` 反比缩放。
  > build 内: sums[ck] 按 control 聚合 raw；s>1e-12 → raw/sums×reliability
- 权威依据: SCI-UPM-WEIGHT-001（FROZEN）§5/§7/§10；宪章 §1.1（SCI 高于 ALG）、§6.3（integration 权重与不确定度传播）
- 问题说明: ①同一段 SCI 里 `w_UPM`（未归一乘积）与 `normalized`（per-control 归一）是两个**互不等价**的权重定义，ALG 只实现后者且未声明前者的适用面；
  ②代数可证：把 k_corr（或任一全局 ivar 标度）乘 α，则同一 control 内所有 raw 同乘 α，`raw/Σraw` **逐字不变** ⇒ M 更新、
  每帧 CG 的对角元（Σ_i w_norm,i = reliability）与 C 场全部不变。因此 SCI §7「control_variance 随 k_corr 线性缩放」在**产品解算面上不可观测**，
  SCI §10「改变 k_corr 默认 1.4」列为不可接受变化亦无对应可判定后果；k_corr 只剩一条间接影响路径——`σ_eff=max(|uncertainty|,σ_floor)`
  的 Huber 残差缩放（即影响的是鲁棒降权，不是权重本身）。③per-control 归一还把 **control 之间的精度信息**抹平：低精度 control
  （N_retained 小、σ_bg 大）与高精度 control 在 C 求解中同权，与 §46 声明的"科学权重 = ×control_ivar"相反。
  ④验证面错位：UPMW-002「control_ivar 1:4 → raw 比率精确 1:4」测的是 `p2_upm_raw_weight` 中间量，正是随后被 Σraw 除掉的那个量；
  归一化之后无任何门（§12 T1-T7 无一项对 ivar 标度不变性做正反对照）。
- 影响: UPM 是 Phase2 全部 calibrated 产品的加性校正场。SCI 的误差/精度模型（σ_bg、N_retained、k_corr、π/2）只作用于
  被丢弃的中间量，"control_ivar 感知权重"这一科学声明失去可观测证据；真实数据路径按 control 精度加权的结果与文档声称不同。
- 建议处置: 由负责人裁决——要么把 SCI:46 的 w_UPM 降为"诊断量"并在 §7/§10 删去 k_corr 缩放/禁改条款（改走 §1.2），
  要么让 F2 不做 Σraw 归一（保留绝对 ivar 权重，另定 λ0/λs 的量纲标定）；并补一条"标度不变性"正反对照门
  （同一数据 k_corr×4 → 模型 C 是否变化、变化多少）。
- 置信度: 高（纯代数结论，可手推复现）
- related: L08-008、L08-009（同族；本条不同事实：那条是 MAD=0 patch 的 floor 冲突，本条是归一化导致的标度消除）、DISP-P2UPM-003、ALG-UPM-CONTROL-IVAR-001

  SCI-UPM-001 §5（`C_f(p)=双线性(8×8 control cell, θ_f)` 为 FROZEN 连续定义）

- 置信度: 高（两份 ALG 文本自证；需 M 层确认的仅"stage2 是否确实透传该字段"，L08 §6 已把该联动列为待复核，本条把它定稿为 finding）
