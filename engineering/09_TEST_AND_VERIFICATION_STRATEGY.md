# 09 测试与验证总策略

## 1. 测试金字塔

### T0 静态检查

格式、schema、导出符号、依赖、文档链接、控制文件一致性。

### T1 单元测试

单函数/单算法，小规模、毫秒到秒级，无真实大数据库依赖。

### T2 契约测试

DLL ABI、PipelineFrame 块、HISS/HCSD round-trip、配置解析、CLI 输出。

### T3 模块集成测试

两个或三个模块连接，例如 detector→PSF、photometric→SNR、drizzle→HISS。

### T4 Stage 测试

Stage 1 单帧完整链；Stage 2 多帧完整链。

### T5 系统回归

固定真实数据集、全流程、性能与数值指标。

### T6 稳定性/故障注入

中断、损坏文件、缺 DLL、Gaia 查询失败、内存压力、重复恢复。

## 2. 测试标签

`unit`, `contract`, `integration`, `stage1`, `stage2`, `regression`, `performance`, `slow`, `requires_gaia`, `requires_qt`, `windows_only`。

根级测试入口按标签执行，默认不跑超大数据。

## 3. 必须记录的测试信息

- Git commit 与 dirty 状态；
- 工具链与 DLL 哈希；
- 数据集版本和输入哈希；
- 配置；
- 命令与超时；
- 退出码；
- 数值指标与阈值；
- 日志与失败样本；
- 运行时间和峰值内存。

## 4. 浮点比较

禁止统一使用一个 `1e-6`。按物理语义定义：

- 坐标：像素或角秒；
- 通量：相对误差；
- 背景：绝对+相对误差；
- SNR：相对误差；
- 图像：分位数、RMSE、结构化残差；
- HEALPix：覆盖与能量守恒。

阈值必须来自理论、数值精度或基线实验，不能为了通过而临时放宽。

## 5. 黄金数据与性质测试

### 黄金数据

验证真实结果是否回归。

### 性质测试

验证算法不依赖某一张图：

- 输入乘常数，测光 scale 的关系；
- 常量图经 Drizzle/Stack 的不变性；
- 帧顺序改变，结果应在容差内不变；
- 无重叠帧不应相互污染；
- 增加极端离群帧，Winsorized/sigma clip 应抑制；
- SNR 增大时权重单调增大；
- 相同输入重复运行结果确定。

## 6. 缺陷修复规则

每个缺陷至少新增一个能在修复前失败、修复后通过的测试。缺陷报告必须写：

- 最小复现；
- 根因；
- 影响范围；
- 修复策略；
- 回归测试；
- 是否影响数据格式/ABI。

## 7. CI 门禁建议

### 每次提交

T0 + T1 + 快速 T2。

### Pull Request

全部 T1/T2 + 受影响 T3。

### 每夜

T4 + 固定数据回归 + 内存/性能摘要。

### 发布候选

T0-T6 全部适用项 + 干净机重建。
