# 08 真实数据集与追溯规范

## 1. 数据集分层

- Smoke：1 张小图或裁剪图，验证进程和格式。
- Stage1 Canonical：至少 3 张真实 Light，覆盖正常、弱星场、高背景/高动态范围；配套真实 Master。
- Stage2 Canonical：至少 5–10 份有重叠的真实 HISS，包含质量差异和可识别异常。
- Stress：高分辨率、宽视场、大量 HISS。

## 2. 数据登记

每个样本登记：文件 hash、大小、尺寸、位深、设备、焦距、像元、滤光片、曝光、时间、温度、目标、先验坐标、校准组、来源与许可。

原始数据不得复制进 Git；注册表保存逻辑 ID 和本地相对定位规则。

## 3. 预期结果

不能只保存“应该成功”。至少保存：

- 检测星数范围；
- WCS 中心、尺度、旋转和 RMS 范围；
- PSF 成功率/FWHM/偏心率范围；
- 测光匹配数、scale、sigma 范围；
- SNR 控制点数；
- HISS nside、n_pix、有限值比例与能量/面积检查；
- Stage2 覆盖、拒绝率、权重和输出统计。

## 4. 防止测试污染

参考值必须由锁定版本生成并经人工/独立工具复核。Agent 修改算法后不能直接用新结果覆盖参考值；更新必须通过 ADR 和差异报告。
