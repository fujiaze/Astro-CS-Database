# P00-001 仓库与环境事实基线

- 阶段：P00
- 依赖：无
- Gate：G0

## 目标

盘点仓库、分支、工作树、编译工具、真实数据、DLL、源码与现有输出；不改业务代码。

## 执行步骤

1. 列出实际源码树和模块 commit/hash。
2. 检查 Git 状态、分支、远端和未提交改动。
3. 检查构建工具、第三方依赖和现有 DLL 导出。
4. 定位真实数据、Gaia、Master 与已有 HISS/HCSD。
5. 生成 baseline_inventory，不修改业务代码。

## 必需交付物

- 代码/文档差异与原子提交建议；
- 自动化测试和真实数据证据；
- 兼容性、回滚和残留风险；
- `evidence/P00-001/` 下四份标准报告。

## 验收

- 依赖任务均已通过；
- 本任务目标有可复现证据；
- 相关回归全部运行；
- 独立复核以 `VERDICT: PASS` 结束；
- 更新任务注册表、当前任务和项目状态。

## 通用执行规则

- 开始前记录 commit、工作树和入口条件。
- 先复现旧行为，再做最小修改。
- 外部进程、数据库和可能阻塞操作设置明确超时。
- 不覆盖用户未提交修改，不强推或重写历史。
- 所有接口/格式变更同步更新契约和测试。
- 产出 TASK_REPORT、TEST_REPORT、EVIDENCE_INDEX、REVIEW_REPORT。
