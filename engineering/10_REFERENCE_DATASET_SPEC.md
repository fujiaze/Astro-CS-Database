# 10 参考数据集 Spec

## 1. 数据集分组

### DS-SYN：完全合成

无需外部数据库，可精确知道真值。

- 常量图；
- 点源/高斯/Moffat 星场；
- 已知 WCS/SIP；
- 已知全局 scale；
- 已知线性、径向和低阶球面梯度；
- 已知噪声和 SNR 空间变化；
- 可注入 cosmic ray、坏点、饱和、NaN、缺失区域。

### DS-MINI：最小真实链

2–5 张小尺寸真实 FITS + 小范围 Gaia 子集，保证本地快速运行。

### DS-STAGE1：单帧代表集

覆盖不同焦距、FOV、滤镜、曝光、星密度、背景梯度和 WCS 难度。

### DS-STAGE2：多帧镶嵌集

至少包括：

1. 两帧大重叠、无梯度；
2. 两帧已知加性梯度；
3. 三帧链式重叠；
4. 多帧环形重叠；
5. 一帧低 SNR；
6. 一帧含强离群值；
7. 不连通覆盖分量；
8. 宽 FOV 跨 RA=0°；
9. 高赤纬区域；
10. nside<64 和高 nside 边界测试。

### DS-FULL：全量回归

790 帧板解算集和未来大规模马赛克，只在夜间/发布候选运行。

## 2. Dataset Card

每组数据使用 `templates/DATASET_CARD.md`。真实数据不进入 Git 时，Git 中仍需保留：

- manifest；
- SHA-256；
- 下载/复制说明；
- 许可；
- 预期输出摘要；
- 缺失时测试应 skip 还是 fail。

## 3. 黄金结果生成

黄金结果不能由待测代码在同一次任务中生成后直接作为正确答案。必须：

- 使用独立参考实现；或
- 由理论真值计算；或
- 在稳定基线经人工审核并冻结；
- 记录生成 commit、配置和审核人。

## 4. 数据最小化

优先裁剪足以复现问题的最小区域，降低测试时间和数据泄漏风险。大数据只用于系统回归。
