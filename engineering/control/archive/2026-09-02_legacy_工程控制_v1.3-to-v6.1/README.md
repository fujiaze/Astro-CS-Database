# AstroCS v1.3 修复与续开发指导包

本包用于解决 P11-004 的错误 Gate 设计，并继续执行 v1.2 尚未完成的全部科学链、马赛克和球面浏览器任务。

## 本次关键结论

P11-004 当前失败不构成 WCS 生产端缺陷证据。诊断工具用全星表 kd-tree 最近邻重建了新的匹配集合，而 IPV RMS 来自 RANSAC/Umeyama 的权威 inlier 集，两者不能直接比较。

正确做法不是只相信内部 RMS，也不是继续盲改 CRPIX/CD/SIP，而是：固定求解器 inlier 对，使用最终写出的标准 WCS/SIP 独立回投，验证序列化和下游消费链。

- v1.2 的全部 Spec、Tasks、Checklist、Agent 协议和未完成路线；
- P11-004 审核决策与 WCS Gate v2；
