# 浏览器视觉与交互验收

使用最终银心 HCSD，固定 1920×1080（或记录实际）、同中心/FOV/STF，交付：全景、panel1–2 接缝、panel2–3 接缝、梯度关闭/开启成对截图。

性能最低门：

- HCSD 元数据打开 p95 < 0.5 s 或相对基线提升≥10倍；
- 冷缓存首个可交互画面 ≤2 s；
- 热缓存拖动 p95 frame time ≤33 ms，p99≤50 ms；
- I/O 期间 GUI 线程单次阻塞≤50 ms；
- 静止后高 LOD 收敛≤1.5 s；
- 无持续内存增长，缓存遵守预算。

若基线硬件无法达到绝对门限，可同时提交硬件归一化证据和 ADR，但不得只取消门限。
