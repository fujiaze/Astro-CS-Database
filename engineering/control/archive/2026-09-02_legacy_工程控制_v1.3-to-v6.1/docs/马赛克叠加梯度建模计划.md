# 光度马赛克梯度校正设计

> 历史设计溯源文档：当前生产权威为 `docs/science/PHASE2_UPM.md` + `docs/algorithms/UPM_SOLVER.md` + `docs/algorithms/PHASE2_SAMPLER.md`（单一 UPM 全局加性场，覆盖 union 全量控制点 + 单帧区 harmonic continuation），本计划的每帧独立 g_i TPS 仅作设计演进溯源，不作当前算法权威。

> "背景中位数 + 星拒绝 + 曲面样条"方法，在 HEALPix 球面坐标系下实现多帧梯度校正，使加权叠加结果平滑无缝。
> 
> 本模块属于 `healpix_db/healpix_stack` 子模块，与球面叠加同步进行。复用 `healpix_io` 的 DLL 接口读写 `.hiss`/`.hcsd`。`.hiss` 为不可变球面原始数据，梯度校正不落盘修改。

## 一、背景与问题

### 1.1 断层来源

每帧实际观测 = 真实天体 + **梯度偏移 g_i(ra,dec)** + 噪声。梯度偏移来自：

- 光害梯度（不同指向、不同夜晚，空间分布不同）
- 渐晕（光学固定，但每帧覆盖不同天区）
- 平场残差
- 天光背景变化（月光、晨昏蒙影）

加权叠加：`stack(p) = Σ w_i·(sky + g_i) / Σ w_i = sky + Σ w_i·g_i / W`。在帧覆盖边界，参与帧集合突变，`Σ w_i·g_i / W` 跳变，产生**断层**。

### 1.2 校正目标

拟合每帧的梯度场 g_i(ra,dec)，叠加时扣除，使 `Σ w_i·g_i / W` 趋近 0，覆盖边界不再突变。

**目标语义**：加权叠加结果平滑（方案 II）。校正 c_i 通过权重耦合联立求解，非"帧间一致性"或"相对参考帧"。

### 1.3 三大约束

1. **权重耦合**：校正目标是"加权叠加结果平滑"，校正通过权重联立，非各帧独立
2. **SNR 隔离**：低 SNR 区域不能污染梯度曲面、抬高高 SNR 帧光度 → 拟合按 SNR 加权
3. **星点隔离**：星点会污染梯度估计 → 不能低通滤波，需显式星拒绝 + 背景中位数

### 1.4 尺度与全局 scale 解耦

- 全局 scale（s_i，来自星测光）归 `photometric_calib`，已存在
- 梯度场（g_i，来自背景）归本模块
- 两者解耦：scale 错了不影响梯度形状，梯度错了不影响绝对通量

### 1.5 适用范围

- 支持 2000mm 长焦（FOV~0.5°，如 M42）到 200mm 广角（全天马赛克）
- 支持不同网格精度（0.5"/px 到 3"/px）
- 每帧独立自适应密度，帧间可不同

## 二、核心算法思路

严格分离两类测量：

1. **星测光 → 全局 scale**：孔径测光 + 线性最小二乘（对应本项目的 photometric_calib）
2. **背景中位数 → 梯度曲面**：
   - 重叠区按 bin 分块，每 bin 测两帧背景中位数
   - 星拒绝：bin 中心落在星拒绝圆内丢弃
   - z = `tgtMedian × scale - refMedian` 喂给 SurfaceSpline（薄板样条）

**本方案迁移到球面**：

- 控制点 = HEALPix 网格点
- 邻域 = query_disc 球面圆盘
- 背景中位数 + Gaia 星拒绝（比 PMM 像素空间更准）
- 球面 TPS 拟合（测地距离核函数）
- SNR 加权 + 迭代拟合（处理多帧耦合）

## 三、架构总览

### 3.1 模块定位

- 光度马赛克梯度校正属于 **healpix_stack** 子模块（healpix_db 下）
- 与球面叠加、sigma-clip 同属一个子模块
- healpix_io 提供 .hiss/.hcsd 读写 DLL 接口，复用
- .hiss 为不可变球面原始数据，校正不落盘

### 3.2 数据流（三阶段）

```
N 个 .hiss（不可变）+ Gaia 星表 + 测光结果(s_i)
        │
        ▼
┌─────────────────────────────────────┐
│  阶段1: 采样（逐帧流式）              │
│  for each frame i:                   │
│    读 frame_i.hiss (10-200MB)        │
│    在 frame_i 的控制点网格采样        │
│    背景中位数（Gaia星拒绝）           │
│    → 样本表 (cp_ra, cp_dec, frame_id, │
│              bg_median, snr, leaf)   │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  阶段2: 迭代拟合（内存）              │
│  初始化 g_i = 0                      │
│  repeat (Gauss-Seidel):              │
│    for each frame i:                 │
│      ref(p) = Σ_{j≠i} w_j(bg_j-g_j)  │
│               / Σ w_j                │
│      diff_i(p) = bg_i(p) - ref(p)    │
│      g_i = SNR加权球面TPS(diff_i)    │
│    gauge fixing: 加权均值归零         │
│  until converge                      │
│  → N 个 g_i 球面TPS模型（内存）       │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│  阶段3: 校正叠加（逐帧流式）          │
│  for each frame i:                   │
│    读 frame_i.hiss                   │
│    for each ipix:                    │
│      corrected = pixel - g_i(ra,dec) │
│    → sigma-clip 加权累加             │
│  → .hcsd（梯度校正后的叠加结果）      │
└─────────────────────────────────────┘
```

### 3.3 内存特性

| 阶段  | 内存占用                                           | 是否持有全部帧 |
| --- | ---------------------------------------------- | ------- |
| 采样  | 1帧 .hiss（10-200MB）+ 样本表（~400KB）+ Gaia 星表（按区域查） | 否，逐帧    |
| 拟合  | N 个 TPS 模型（~100系数×N×8B ≈ N×800B）+ 1帧样本         | 否，逐帧    |
| 叠加  | 1帧 .hiss + 输出 .hcsd 累加器（取决于马赛克总面积）             | 否，逐帧    |

关键：**逐帧流式，不同时持有全部帧**。单帧 200MB 在 64GB 上无压力。

### 3.4 尺度自适应

每帧独立选择 nside_i，由自身 FOV 决定：

```
nside_i = 最小的 2^k，使 frame_FOV 内 HEALPix 像素数 ≥ K_target（默认100）
```

| 帧 FOV            | nside_i | 间距    | 帧内点数 |
| ---------------- | ------- | ----- | ---- |
| 0.5°（2000mm M42） | 2048    | 1.7'  | ~100 |
| 2°               | 512     | 6.9'  | ~100 |
| 5°（200mm）        | 256     | 13.8' | ~100 |
| 20°（广角）          | 64      | 55'   | ~100 |

各场景自动适配，覆盖 2000mm 到全天。控制点 nside_i 与 .hiss 的 nside（drizzle 精度）独立。

## 四、采样设计

### 4.1 控制点网格

每帧独立 nside_i，控制点 = 该帧 FOV 覆盖的 nside_i 网格点。

### 4.2 采样过程（逐帧）

```
for each frame i:
    1. 读 frame_i.hiss（healpix_io DLL，全读）
    2. 读 Gaia 星表中 frame_i FOV 内的星（ra, dec, phot_g_mean_mag）
       ── 接口扩展点：当前 Gaia 客户端按天区查询，
          需扩展"按 HEALPix 子叶查询"以降低开销 ──
    3. 确定控制点：frame_i FOV 覆盖的 nside_i 网格点
    4. for each control point p (ra_p, dec_p):
         a. query_disc(p, radius=2×pixel_size_i) → 邻域 ipix 列表
         b. 星拒绝：丢弃邻域内距任一 Gaia 星角距离 < R_reject 的 ipix
            R_reject = starRejectBase + growthRate × flux
            （类比 PMM: base=1, growthRate=0.25，按星等换算 flux）
         c. 零值拒绝：丢弃值为0的 ipix（边缘/无数据）
         d. bg_median = median(剩余 ipix 像素值)
         e. snr = 待定（开放问题，见第六节）
         f. 写样本表: (cp_ra, cp_dec, frame_id=i, bg_median, snr, leaf_ipix_nside64)
    5. 释放 frame_i.hiss
```

### 4.3 降采样（宽帧在高 nside_i 下）

若帧控制点数 > maxSamples（默认500）：

- 用 NESTED Morton 位运算合并：`ipix_coarse = ipix >> 2k`，k=降采样层级
- 每组合并：bg_median 取子点中位数，位置取质心，snr 取最大
- 保证 TPS 可解（n≤500，n³≈1.25E8，秒级）

### 4.4 样本表格式

```
| cp_ra | cp_dec | frame_id | bg_median | snr | leaf_ipix_nside64 |
```

leaf_ipix_nside64 用于按块索引。表大小：1000点×10帧×40B ≈ 400KB，全驻内存。

## 五、迭代拟合

### 5.1 球面 TPS 模型

每帧 g_i(ra,dec) 用球面薄板样条表示：

```
g_i(p) = Σ_k w_k · K(γ(p, p_k)) + c₀ + c₁·Y₁₀(p) + c₂·Y₁₁(p) + c₃·Y₁₋₁(p)
```

- γ(p,p_k)：测地距离
- K(γ)：球面双调和 Green 函数（核函数）
- c₀ + 一阶球谐：零空间（常数+线性趋势），保证确定性
- λ 正则项控制平滑度（同 PMM 的 smoothing，smoothing=10^logSmoothing）

线性系统结构（同平面 TPS）：

```
[K + λI    P] [w]   [z]
[P'        0] [v] = [0]
```

K_ij = K(γ(p_i,p_j))，P 是球谐设计矩阵，z = diff 样本值。Eigen SparseLU 求解。

### 5.2 迭代流程（Gauss-Seidel）

```
初始化: g_i = 0, ∀i

repeat (最多 max_iter=10 轮):
  for each frame i:
    # 1. 在帧 i 的控制点 p 上计算参考场（排除自身）
    for each control point p of frame i:
      ref(p) = Σ_{j≠i, j covers p} w_j(p) · (bg_j(p) - g_j(p)) / Σ w_j(p)
      # w_j(p) = 帧j在该点的权重（SNR，待定接口）
      # bg_j(p) = 帧j在p的背景（若p在j的网格上，直接取；否则评估j的TPS）
      # g_j(p) = 评估帧j的当前TPS在p处

    # 2. 计算残差
    diff_i(p) = (bg_i(p) - g_i(p)) - ref(p)

    # 3. SNR加权拟合
    g_i_new = 球面TPS拟合(diff_i, weights=snr_i)
    g_i = g_i_new

  # 4. 规范化（gauge fixing）：加权平均归零
  g_i -= Σ_i (Σ_p w_i·g_i(p)) / Σ_i (Σ_p w_i)
  # 平移使加权均值为0，消除全局偏移自由度

  # 5. 收敛检查
  if max_i max_p |g_i_new(p) - g_i_old(p)| < ε:
    break
```

### 5.3 收敛性

- Gauss-Seidel 在 TPS 正定核下通常收敛
- 实际 3-5 轮收敛（梯度是缓变场，初始 g=0 已是好的起点）
- ε = 0.1% × 典型背景值

### 5.4 非重叠帧处理

- 帧无任何 overlap → ref(p) 无定义 → g_i = 0（不校正）
- 部分重叠：重叠区正常拟合，非重叠区 TPS 外推（球面 TPS 自然外推）

### 5.5 跨帧 TPS 评估

帧 i 的控制点 p（nside_i 网格）需评估帧 j 的 g_j(p)：

- j 的 TPS 在 j 的网格（nside_j）上拟合
- 评估任意 (ra,dec)：O(n_j) 计算（核函数+求和）
- n_j≈100，帧 i 有 ~100 控制点，~10 帧覆盖 → 每轮 100×100×10 = 10^5 次评估，快

## 六、开放问题与接口扩展点

### 6.1 Gaia 星表按子叶查询（接口扩展点）

当前 Gaia 客户端按天区（圆形/矩形）查询。采样阶段需对每帧 FOV 内所有控制点做星拒绝，若每点独立查询 Gaia 开销大。

**扩展方向**：增加"按 HEALPix 子叶（nside=64 的 49152 块）批量查询"接口，一次返回子叶内所有星。采样时按子叶批量获取，内存缓存（复用 plate_solve 阶段的 60s TTL 缓存机制）。

### 6.2 SNR 估计方法（开放问题）

.hiss 已移除 weight 通道，无法直接取 SNR。候选方案：

- **测光星等不确定度**：用 Gaia 测光不确定度反推该区域 SNR（用户倾向，方法待定）
- median / (1.4826 × MAD)：鲁棒但与星等解耦
- mean / std：对星点残留敏感

**决策**：暂记为开放问题，实现时由用户确定。SNR 仅作拟合权重，不影响算法结构，接口预留 `snr` 字段。

### 6.3 .hiss 按子叶读取（性能优化点）

当前 `hiss_read` 全读单帧（10-200MB）。若未来需优化内存，可扩展 `hiss_read_leaf`（当前仅 .hcsd 支持）。当前单帧 200MB 在 64GB 上无压力，暂不需要。

## 七、校正叠加集成

### 7.1 应用点

梯度校正 g_i 在叠加阶段应用，与球面叠加、sigma-clip 同属 healpix_stack 子模块。

```
for each frame i:
    读 frame_i.hiss
    for each ipix:
        (ra, dec) = pix2ang(ipix)
        corrected_pixel = pixel_value - g_i(ra, dec)
    → corrected_pixel 进入 sigma-clip 加权累加
输出 .hcsd（梯度校正后的叠加结果）
```

### 7.2 与现有管线关系

```
CALIBRATE → PLATESOLVE → PSF → PHOTOMETRIC(应用s_i) → DRIZZLE → .hiss(不可变)
                                                                      │
                                                          healpix_stack:
                                                          ├── 采样（阶段1）
                                                          ├── 迭代拟合（阶段2）
                                                          └── 校正叠加（阶段3）→ .hcsd
```

- DRIZZLE 输出 .hiss 不变
- photometric_calib 的全局 scale 已在 DRIZZLE 前应用
- healpix_stack 内部增加梯度校正，对外接口不变（输出 .hcsd）

## 八、与 PMM 对照

| 维度    | PMM            | 本方案                  |
| ----- | -------------- | -------------------- |
| 帧数    | 2 帧（ref + tgt） | N 帧                  |
| 坐标系   | 图像像素           | 球面（HEALPix）          |
| 拟合坐标系 | 平面 TPS         | 球面 TPS（测地距离核）        |
| 控制点   | 固定 20 像素 bin   | 每帧自适应 nside_i，~100 点 |
| 数据源   | 原始 FITS        | .hiss（球面，不可变）        |
| 星拒绝   | 检测星像素位置        | Gaia 星表（ra,dec,flux） |
| 尺度来源  | 星对最小二乘         | 复用 photometric_calib |
| 权重耦合  | 无（两图）          | 加权叠加平滑（迭代拟合）         |
| 参考场   | 单个 ref 帧       | 所有帧加权平均（排除自身）        |
| 输出    | 直接合成图像         | 校正叠加 → .hcsd         |
| 内存    | 全部加载           | 逐帧流式                 |
| 适用范围  | 两图马赛克          | 2000mm 到全天           |

## 九、验证标准

1. **合成数据**：N 帧已知梯度差，拟合后残差 < 0.1% peak
2. **真实数据**：
   - 叠加结果在 overlap 区无可见断层
   - 校正前后全局通量偏差 < 5%
   - 低 SNR 帧不抬高高 SNR 帧光度
3. **性能**：10 帧 × 4096×4096，MOSAIC_GRADIENT 阶段 < 60s
4. **回归**：现有测试集成功率不下降
