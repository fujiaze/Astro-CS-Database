# 依赖分析与并行规则

## 强制顺序

在分配子 Agent 前先冻结共同接口：WCS 坐标约定、T1–T4 数据档案字段、HISS/HCSD v1 兼容边界、浏览器 Tile 读取接口。多个 Agent 不得同时修改同一接口或同一源文件。

## 推荐并行轨道

- 轨道 A（科学链）：P10 → P11 → P12 → P13 → P14。
- 轨道 B（浏览器）：P15 → P16；P15 可在 P10 数据清单完成后与 P11–P13 并行。
- 轨道 C（独立复核/工具）：为 A/B 提供只读复核、数据统计和性能测量，不修改生产代码。

## 合并约定

1. 先由接口负责人提交契约和测试骨架；
2. 子 Agent 基于固定 commit/worktree 工作；
3. 每个子任务交付单一职责提交；
4. 合并前运行对应 contract test；
5. 主 Agent 负责跨模块集成和最终真实数据测试。

## 冲突处理

出现接口冲突时暂停后续实现，记录 ADR；不得让两个模块各自定义一套 Y 轴、滤镜别名、Tile key 或错误码。
