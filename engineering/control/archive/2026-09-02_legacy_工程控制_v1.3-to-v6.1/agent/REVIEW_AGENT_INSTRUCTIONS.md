# 独立复核 Agent 指令

复核 Agent 不接受实现者的结论作为事实，必须从任务入口、代码 diff、原始日志、机器可读报告和输出文件独立判断。

重点检查：

- 测试是否真的覆盖任务声明的数据；
- 是否有静默跳过、fallback 或门限降低；
- WCS 闭环是否使用标准导出 WCS，而非内部拟合坐标；
- Photometric 是否有足够唯一匹配、有限残差和稳定拟合；
- 银心是否确实包含 panel1/2/3 的 32 张 Red；
- 梯度验证是否包含非零真实差异与已知注入；
- 真实 Stage2 是否使用 `has_snr=true` 数据；
- 浏览器性能是否在固定硬件、数据、视角和 STF 下测量；
- GUI 线程是否仍有磁盘、解压、ud_grade 或大数组构建；
- 用户可见截图是否来自优化后的真实 HCSD。
