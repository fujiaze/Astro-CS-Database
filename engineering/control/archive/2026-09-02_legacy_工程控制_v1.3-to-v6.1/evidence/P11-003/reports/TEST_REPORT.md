## 1. 测试方法

### 1.1 双重验证架构

本测试采用 **PlateSolve 求解 + astropy WCS 独立诊断** 的双重验证架构，确保诊断结果不依赖 PlateSolve 自身的变换实现：

| 阶段 | 工具 | 说明 |
|------|------|------|
| 求解 | PlateSolve (内置) | 生成 WCS + SIP order=3 多项式，写入 FITS header |
| 诊断 | astropy WCS + Gaia DR3 | 独立从 FITS header 读取 WCS，与 Gaia 星表比对 |
| 匹配 | scipy.spatial.cKDTree | 双向最近邻匹配，max_dist=3.0 px |
| 闭环 | PS→Sky→PS / Sky→PS→Sky | 验证 SIP 多项式写入/解析无损 |

### 1.2 独立性保证

- `tool_independent_of_platesolve_transform = true`：诊断阶段不调用 PlateSolve 的坐标变换函数，仅使用 astropy WCS 进行 sky↔pixel 转换
- Gaia DR3 星表独立查询，不依赖 PlateSolve 内置星表

## 2. 门限规则

gate 通过条件（三项必须全部满足）：

| 条件 | 门限 | 说明 |
|------|------|------|
| median ≤ 0.75 px | 残差中位数 | 反映系统偏差水平 |
| p90 ≤ 1.5 px | 90 分位残差 | 反映大部分星点精度 |
| p99 ≤ 3.0 px | 99 分位残差 | 反映极端离群值 |

> 门限设计依据：亚像素级精度要求（9μm 像素的 0.75 倍 ≈ 6.75μm），适配后续叠加/配准需求。

## 5. 关键失败帧分析

### 5.1 T3_LUM_NGC55（最严重失败帧）

| 指标 | 值 | 说明 |
|------|-----|------|
| median | 0.897 px | 远超 0.75 门限 |
| p90 | 1.284 px | 超限 |
| x_median_abs | 0.218 px | X 方向精度良好 |
| y_median_abs | **0.848 px** | Y 方向严重偏差 |
| n_matched | 702 | 匹配星数充足 |

**分析**：Y 方向残差（0.848 px）是 X 方向（0.218 px）的 **3.9 倍**，存在显著的 Y 方向系统误差。匹配星数 702 并不少，失败不是星数不足导致，而是 Y 方向系统偏差未被 SIP order=3 建模。

### 5.2 T2_BLUE_LDN43（solve RMS 最高帧）

| 指标 | 值 |
|------|-----|
| solve RMS | 0.288 px（16 帧中最高） |
| median | 0.880 px |
| p90 | 1.153 px |
| p99 | 1.718 px |
| x_median_abs | 0.526 px |
| y_median_abs | 0.699 px |
| n_matched | 1941 |
| quadrant_counts | Q1=429, Q2=438, Q3=469, Q4=664 |

**分析**：蓝色滤镜透过率低，星点信噪比差，PlateSolve 求解 RMS 偏高（0.288 px），但匹配星数最多（1941），说明暗星噪声影响质心精度。Y 方向残差（0.699 px）大于 X 方向（0.526 px），符合全局 Y 方向偏差模式。象限分布显示 Q4（664）显著多于 Q1（429），存在方向性不对称。

### 5.3 T2_RED_LDN43（median 最高帧）

| 指标 | 值 |
|------|-----|
| median | 0.960 px（16 帧中最高） |

**分析**：红色滤镜匹配星数最多（1945），但 median 残差最高（0.960 px），进一步印证"星数多 ≠ 精度高"，暗星噪声拉低了整体质心精度。Y 方向残差（0.794 px）远大于 X 方向（0.524 px），是 Y 方向偏差最严重的 T2 帧之一。象限分布 Q4（609）最多，Q1/Q2 较少，与 T2_GREEN/BLUE 呈现相同的方向性不对称模式。
