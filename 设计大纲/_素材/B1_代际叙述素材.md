# B1 代际叙述素材

本文件是对外报告的代际叙述草稿素材，为七代控制包各写一段叙述，逐段覆盖包清单形态、用户入口、任务规模与台账口径、门禁与验收、派发与回报协议、废止方式、执行留痕与本代缺口八个方面，并在每代末尾列出与相邻代的差异要点。全部数字、SHA、seq、条款号只从下列已读文档原样抄录：主源为设计大纲/reports/packs/ 目录下的 00_OVERVIEW.md（总览：§1 完整谱系表、§2 口径演进序列、§3 包与历史提交对接结论、§4 与任务一八阶段对照表）与 STAGE-01.md 至 STAGE-07.md 七份代际归纳报告；细节下钻自同目录十六份组报告 P-G01 至 P-G16；事件与提交锚核对自 pack_events.md、coverage.md、digest_verify.md；seq 与短哈希的映射逐条经设计大纲/_evidence/commits/index.jsonl 双向复算确认。任务一的历史阶段表与 seq 区间取设计大纲/reports/history/00_OVERVIEW.md §1（八阶段，拓扑序 seq 1 至 1988）。

先交代三条口径。其一，代际划分与 packs 下 STAGE-01 至 STAGE-07 一一对应，每代首行标明其收纳的组（G0x），组报告与代际报告是同一事实的细目与归纳两层。其二，"身份"指包名层登记对象，"实例"指同一身份的存形态个数（zip 原件、解包件工作树、仅存 git 历史复原件、归档容器内成员、影子树等），形态口径见 packs/00_OVERVIEW.md §0；复原实例的文件数按含注入 _PROVENANCE.json 计，跨形态比较须还原（digest_verify.md 观察 O-1）。其三，提交锚写作 C<seq>｜<sha8>，seq 以 index.jsonl 复算为准；文档之间互不一致处照抄两值并标注"口径冲突"，不自行裁断。本代与任务一历史阶段的 seq 区间为同期交叠关系（例如代一只覆盖任务一阶段一的后半窗，任务一阶段三整段无包），引用时保持交叠事实、不强行线性化；命中率类论断须与采集方法四项局限同读（packs/00_OVERVIEW.md §3）。
