## 主线① 科学算法与数值口径

这条线从"科研小工具的算法更替"长成了"合同先行、逐面委托、审计收尾"的科学口径体系。STAGE-01 日期窗内七个上游 lib 模块以 Python/C++ DLL 双栈起步——双栈在导入面就能看见：C2｜802becc2 先以纯 Python 库形态首入图像 IO，C20｜48396682 才补上 C++ 原生实现加绑定层，定标侧到 C44｜ddf17ca3 才把管线数据路径切到 DLL 而仍留 Python 适配器，管线框架本身在 C45｜e27ff13d 独立成库。第一个真正的科学转折点是检测器代际切换 C17｜8c0762ca：Gaussian PSF 取代 Moffat4、GSL 信任域 LM 取代手写 LM，新增符号与删除符号在卡面成对可核。栈的收束由测光定标示范：C42｜bc894de2 把它重写为 C++ DLL 并把定标简化为"中位通量比"这一单一路径、梯度拟合路线显式弃用，C46｜2767c66b 再清掉最后一批被替代的 Python 实现。

双栈真正终结于 STAGE-02：C310｜23d07ed4 一次删掉 32 个生产 Python 封装并开 FP32/FP64 双精度模式、禁止静默转换；C327｜bd036f3e 把双精度做成跨八个模块的 ABI 并新建 common 公共模块；C322｜8653bd54 以跟踪面净删 16079 行为 Python 生产层封口，留下的非生产工具逐件挂"仅工具"标记。

Phase1 的冻结与输出换代是一组带摆动的转折点：C481｜30293051 判旧格弃用、AIO 为唯一写入器；C498｜5d5be0ac 导入第三方 CFITSIO 并落地 HiPS 直写；C529｜21a5dc5d 用外部 Hipsgen Oracle 冻结标准 tile 排列，删除私有线性约定；C530｜b7c4d458 把重叠系数 0.8 定成权威缺省。冻结叙事本身在 C422｜8629b408 宣告 Final Freeze 后，于 C437｜0f451b28 反转为 NOT_SYNCED，再到 C542｜f55e7846 干脆移除"已冻结"字面量、只说不宣称完整冻结——口径从"宣布冻结"退回到"缺外部数据即记阻断"（C524｜b686df73）。

Phase2 线在 STAGE-03 展开：C553｜1a38f400 首建 lib/phase2 并冻结 UPM 与排异接口；数值诚实性由 C660｜ed7a544d 定调——非有限的权重与支持度一律判非法输入，绝不返回"通过加 NaN"；C655｜ef6ab2fa 立归一化策略并给负值取百分位设护栏，C688｜f6727773 铺三层噪声模型（弃用误称的 MAD 并给出稳健尺度换算），C690｜eb48cefe 用 ivar 权重退役原始信噪比平方项，C710｜1752e8ca 把控制变量权重与相关噪声放大系数按蒙特卡结果冻结为保守值。STAGE-04 的 B 批不再改语义而是挂锚：C745｜24bd3bc2 把校准文档改成与代码一致的双分支、并把"除零显式拒绝"订正为"静默夹持继续流水"，C826｜10fc2e12 给 Huber 系数与迭代阈值补文档锚而数值一字未改，C860｜0751d34f 三面锚定帧绑定契约。

其后是三段"不动语义"的制度化：STAGE-05 合同冻结（C1047｜cc64ba1a 至 C1053｜7895a584 逐域科学合同、C1054｜199b21e2 算法合同 V5 重验），STAGE-06 的 P1/P2/P3 迁移与 V6.1 重做（C1298｜fe92b6e5 九步合同化、C1415｜9e8ba103 把极区可用条件统一为绝对值不大于 85 度并同步科学文档），STAGE-07 的模块独立化（C1762｜948dfcba 以唯一导出符号做成独立共享模块、逐操作错误状态加诊断码）。W1 冻结波以"控制包 k/140"计数推进，C1600｜7c3d66e2、C1652｜3cbd5fd7、C1704｜f506ef7f、C1714｜3d876fa3、C1726｜d74c1a90 逐域锁合同并把偏差如实登记为 DISP 项，源码语义零改动。STAGE-08 转为宪章逐面委托：C1790｜99713034 先冻不确定度合同并声明实现不得先行，C1798｜439f9f20 把七个节点改为唯一真实操作委托，C1806｜9953f103 落四投影注册表。

转折点序列：C17｜8c0762ca → C42｜bc894de2 → C310｜23d07ed4 → C327｜bd036f3e → C498｜5d5be0ac → C542｜f55e7846 → C660｜ed7a544d → C710｜1752e8ca → C826｜10fc2e12 → C1053｜7895a584 → C1415｜9e8ba103 → C1762｜948dfcba → C1790｜99713034 → C1852｜a6449610 → C1980｜0e4cee72。

## 主线② CLI 与用户入口

入口这条线是"从工程内部的调试壳，一路被削成宪章口径下唯一的薄入口"。STAGE-01 尚无面向用户的入口概念，编排以库与调试面板形态存在：C76｜127c4a96 的建仓提交里已同时装了命令行壳、REPL、检查点与逐模块 Python 适配器，自述九节点管线；C82｜7c7df79f 把它升级为两阶段十节点的 C++ 管线设计，并处理两个阶段共享同一动态库句柄以避免重复释放。

第一个真转折点是 C320｜85fa651c：删 REPL、删掉一批旧命令与四级配置优先级、删手写 JSON 合并解析器，改写为"一个可执行文件加一份阶段配置"的唯一入口，同提交引入严格 Schema 校验并修掉输出键名拼写缺陷。此后入口并没有立刻收敛成一个，而是繁殖：STAGE-03 里 Phase2 自带 astrocs-stage2（C563｜305dd1bd，自述科学语义全部来自库、瓦片读写走唯一 IO 层），同窗还有 HiPS 浏览器战役与其命令行栅格基准（C616｜42c801de，附一键启动脚本与目视验收待决字面量）；到 STAGE-06，入口壳一度直接长出叠加子命令去补产线缺口。

单一 astrocs 目标的确立在 STAGE-05：C1088｜07bc18b9 新建 cli/main.cpp 与 cli 构建脚本，帮助十三行做成黄金样本、版本走单源、其余命令一律以退出码 2 桩住；C1090｜d484f7c5 统一解析器、JSONL 事件协议、协作取消令牌与退出码唯一源；C1113｜c5629be6 与 C1125｜bcc6cb7b 把三个 Phase 以进程内会话接入（自述 CLI 不复制算法、无子进程硬证、错误映射固定），C1128｜91c92f51 实现跨相真编排与"续跑时工件哈希不匹配必失败"，C1130｜1fb0d06b 用安装树机器门钉死"恰好一个用户可执行文件"、禁止旧阶段工具与外部脚本混入。

分层在 STAGE-06 完成：C1379｜84191084 把入口文件从 1538 行削成壳，拆出命令实现、参数解析、运行时客户端三个独立编译单元与一个命令行运行时静态库，模块接口被移出公共头、生产可达图同提交重算；拆分理由直接写在文件头注释里（可达性检查只扫入口文件）。C1380｜90cad495 补运行图子命令与真实装配（含临时目录路径脱敏）。

三 Phase 隔离的收束点是 STAGE-07 的删除式重构：C1514｜10a59723 先铺统一命令面骨架与契约，C1519｜de2d6d7f 净删 294 行，删掉跨相旗标、删掉整条连续管线与运行图命令，使两者在顶层解析即失败并退出码 2，同时把三阶段各自的运行前置校验恢复到同一层；C1520｜257ae1f4 用十六项黄金样本把语义钉住——浅校验零科学执行、零产物且不改修改时间、不完整的运行永不可核验。宪章第 8.1 条的薄 CLI 最终由 C1811｜026717fd 落成正式命令面（三阶段各四子命令加配置与会话族、旗标白名单未知即拒、计划文档含配置哈希与资源预算），并由 C1810｜59fdeab3 在安装面与产品清单侧对齐（交付单元从 5 增到 11，哈希不伪造、骨架不冒认完成）。

转折点序列：C76｜127c4a96 → C320｜85fa651c → C563｜305dd1bd → C616｜42c801de → C1088｜07bc18b9 → C1090｜d484f7c5 → C1130｜1fb0d06b → C1379｜84191084 → C1519｜de2d6d7f → C1520｜257ae1f4 → C1811｜026717fd。

## 主线③ 构建、CI 与机器门

这条线的形状是：先什么都没有，然后把"人说的话"逐条换成"机器能判的东西"，最后发现机器本身也要被审。STAGE-01 日期窗内没有成体系的 CI 门禁证据（分片报告在片尾明确登记"无控制包、无 CI/机器门、无任务编号族"），治理只能靠事后回归：C33｜07795923 移除硬编码线程数与静态链接项，C47｜312dd8ad 又把并行编译链接项加回并证实前者曾致并行失效——两次都只有消息自述，没有门可拦。

机器门的雏形出现在 STAGE-02 的加速底座工程：C296｜b482a21b 把路径守卫纳入统一证据集合并为它加工具临时件排除、引用代理规范条款；C308｜038db00a 新增构建期净化器选项（默认关闭，开启即挂地址与未定义行为探测器）作为合并前硬门禁，同时把三个"名实不符"的测试改名（自述并未真开净化器、并非真实利用率验证）。同窗还有一次反转：C353｜7c67328a 一次性删除仓内全部 19 个证据文件、策略改为"证据在仓库外生成"，此后所有测试通过数都退化为消息自述——这是本线最大的取证口径断层，后续报告凡引计数都标注未证实。

检查器体系从 STAGE-03 起步：C698｜729bc3b9 在全仓盘点里落第一批 tools/quality；STAGE-04 的收口压缩提交把它一次性做成体系（C965｜535e7387，工具质量目录 52 文件全新增、十一个合同检查器各配正反夹具）；STAGE-05 把治理文本也变成门：C1043｜15720f5e 用检查器按十项治理要素校验代理入口文件并同提交重写该文件，C1045｜45e64640 定六层追溯声明格式与链规则，C1074｜7818e663 用静态检查器加五个变异测试钉"单一线程预算"，C1182｜ea1145fb 把文档与代码的签名一致性做成可失败的门。

真正的 CI 化在 STAGE-07：C1527｜0acfb514 建唯一检查注册表（首版 70 项）并配校验器；C1528｜459da629 建唯一确定性执行器（参数数组执行杜绝命令注入、工作区前后对比、豁免计数分离、退出码语义固定）并配 29 用例的测试面自测；C1532｜c583e59d 建影响映射，C1540｜9b3fe93e 建自托管节点候选链。C1670｜0ef34a5e 把"工作区漂移"改判为"运行产物"并要求显式登记豁免键。台账侧的换轨同样关键：此前账本靠"补登追赶"（C1604｜e4bcef83 属该形态，含合并冲突旁支与暂存快照入库），C1668｜b05288b8 换成三条非递归不变量（哈希须存在于提交日志、四字段齐、主题与实际一致）并当场修八条错位行，同型补登此后归零；C1669｜4e91ca2e 把日期全量对齐提交者时间，消除"按台账排序会假性回退"的隐患。

## 主线⑥ 测试与验证方法

测试线的主语从"能不能跑通"变成"证据能不能被证伪"。起点是模块自带测试：STAGE-01 各上游链的测试与代码同仓共存、无门可观；加固动作也带方法论，例如 C268｜0f6239c4 把容器头大小不一致从警告改硬失败、删掉伪造的默认值，把"看起来通过"变成"必须失败"。

方法学上第一次飞跃是独立 Oracle：C440｜a50a97a2 在修候选安全的同时新增一个"不调用生产候选与重叠路径"的独立 Oracle，用采样点归属与半平面包含在多种层级上穷举，自述修复前两百余漏选、修复后全绿；C480｜3a0b0c15 把生产合成通量函数移植成数组参考并以 C++ 交叉验证，C487｜863a8490 把坐标契约的六项不变性做成逐项量化门禁；C652｜77879c72 把 Oracle 的边界断言对齐非法输入契约。到 STAGE-05，Oracle 成为一等交付物：C1164｜607b37e3 用"不调库的第一性原理参考"覆盖校准域，输入是无随机数的解析场、断言全是手工可推的闭式值，并附单线程与四线程逐位一致自证；C1180｜2743ae0a 把三阶段端到端合成链做成同一范式；C1098｜1761491b 让基线内核逐个与参考实现比对。

契约测试的"文档与测试同构"是 STAGE-06/07 的形态：C1486｜caee3e67 起，每族改动以"合同头加实现加自测加契约测试加机器门"五件连排（该条是接口文档与 Python 契约测试同提）；C1130｜1fb0d06b 把"安装面恰好一个可执行文件"做成断言。锚点回归是第三条腿：STAGE-04 起把常数与阈值挂到权威文档锚（C826｜10fc2e12），审计期则把锚本身当被测对象——C1910｜12dcb8f4 定五档处置强度，C1939｜539626f0 与 C1946｜df93a9ea 给出全仓锚的量化现状。
