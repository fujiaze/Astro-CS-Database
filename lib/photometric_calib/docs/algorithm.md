# 鲁棒流量校准 - 算法内核设计

> 模块名称: `photometric_calib`
> 文档版本: 1.0
> 日期: 2026-07-09
> 状态: 已实现

---

## 1. 问题定义

### 1.1 目标

对单帧天文图像进行全局流量校准，消除空间缓变梯度（残留渐晕、月光、光害、大气消光、大气辉光），使图像内任意像素的相对亮度与 Gaia DR3/SP 星表系统一致。输出为校正后的图像，所有像素统一到 Gaia 参考信标基准。

### 1.2 梯度的物理来源

| 类型 | 物理来源 | 数学性质 | 校正方式 |
|------|---------|---------|---------|
| 乘性 | 残留渐晕、大气消光、色差 | 与信号成正比，随空间缓变 | 除以比值曲面 R(x,y) |
| 加性 | 月光、光害、大气辉光 | 与信号无关，随空间缓变 | 减去背景曲面 S(x,y) |

### 1.3 核心约束

- 不需要 airmass、消光系数、渐晕多项式阶数等预设物理参数
- 不需要孔径测光（复用 dynamic_psf 的 PSF 拟合结果）
- 单帧独立校准
- 输出归一化到 Gaia 参考星系统（非物理绝对单位）

## 2. 数学模型

### 2.1 图像信号模型

图像中位置 (x, y) 处的像素值 I(x, y) 可分解为：

```
I(x, y) = [I_star(x, y) + I_nebula(x, y)] × M(x, y) + S(x, y) + noise
```

其中：
- `I_star(x, y)`: 星点信号（大气顶光子流量）
- `I_nebula(x, y)`: 星云/星系连续信号
- `M(x, y)`: 乘性梯度场（渐晕 × 大气消光 × 色差）
- `S(x, y)`: 加性梯度场（月光 + 光害 + 气辉）
- `noise`: 随机噪声

校准目标：估计 M(x, y) 和 S(x, y)，然后：

```
I_cal(x, y) = (I(x, y) - S(x, y)) / M(x, y)
```

### 2.2 双通道分离原理

PSF 拟合对每颗星输出两个独立观测量：

| 观测量 | PSF 参数 | 物理含义 | 编码的梯度 |
|--------|---------|---------|-----------|
| 星通量 F_instr | `flux` 字段 | 孔径测光式积分（减背景） | 乘性梯度 M(x,y) |
| 局部背景 B | `B` 字段 | PSF 拟合的局部天空水平 | 加性梯度 S(x,y) |

**关键洞察**：PSF 拟合同时解耦了星信号（A, flux）和局部背景（B），这两个量天然编码了不同物理性质的梯度。

### 2.3 dynamic_psf 的 flux 计算

dynamic_psf 模块的 `flux` 字段采用孔径测光式计算：

```cpp
double flux = 0;
for (int i = 0; i < m; i++) {
    if (samples[i].val > B) flux += samples[i].val - B;
}
```

通量从采样像素直接计算，而非 PSF 振幅积分，对 PSF 模型误差更鲁棒。

## 3. 合成测光（Synthetic Photometry）

### 3.1 原理

对每颗 Gaia 参考星，利用其 光谱数据 + 仪器响应曲线，正向计算"如果这颗星在当前滤光片/CCD 系统下拍摄，应该测到多少流量"。

### 3.2 合成流量公式

对第 i 颗 Gaia 星，其合成仪器流量为：

```
F_syn,i = ∫ S_i(λ) × T(λ) × Q(λ) × λ dλ
```

其中：
- `S_i(λ)`: Gaia DR3/SP 提供的光谱采样数据，uint8[343] (0-255) 量化值，无量纲；绝对标度在 F_syn/F_instr 比值中消去，可直接作为 S(λ) 输入
- `T(λ)`: 滤光片透过率曲线（从 `data/response_curves/filters.json` 加载）
- `Q(λ)`: CCD 量子效率曲线（0-1，可选，默认为 1）
- `λ`: 波长（nm）

**波长加权 `λ`** 的原因：Gaia 光谱数据源自 BP/RP 能量流量密度光谱，经量化存储为 uint8，而 CCD 探测器计量的是光子数。光子能量 E = hc/λ，因此单位波长间隔的光子数与 λ 成正比。转换常数 1/(hc) 对所有星相同，在 F_syn/F_instr 比值中消去，故省略。

### 3.3 数值积分

- **插值**：Akima 子样条插值，避免过冲
- **积分法则**：Simpson 1/3 复合公式
- **步长**：0.1 nm
- **积分范围**：[λ_min, λ_max]，取滤光片、光谱、QE 曲线三者的重叠区间（Gaia 光谱数据覆盖 336-1020 nm）

### 3.4 合成星等

```
m_syn,i = -2.5 × log10(F_syn,i) + C
```

其中 C 为任意常数（在比值计算中消去，无需确定）。

### 3.5 数据来源

| 数据 | 来源 | 格式 |
|------|------|------|
| Gaia 光谱数据 | `gaia_xpsd_client` 模块 (Gaia DR3SP) | uint8[343] 数组，336-1020nm，步长 2nm |
| 滤光片透过率 T(λ) | `data/response_curves/filters.json` | JSON (波长,透过率对) |
| CCD QE 曲线 Q(λ) | `data/response_curves/qe_curves.json` | JSON (波长,QE对)，可选 |

Gaia DR3SP 光谱以 uint8 (0-255) 存储，积分时转换为 float64 直接作为 S(λ) 输入。绝对标度在 F_syn/F_instr 比值中消去，故无需标定转换系数。

## 4. 乘性梯度拟合

### 4.1 比值定义

对每颗匹配的 Gaia 星 i（位置 (x_i, y_i)），定义乘性比值的对数：

```
r_i = log10(F_instr,i / F_syn,i)
```

其中：
- `F_syn,i`: 合成测光流量（第 3 节）
- `F_instr,i`: dynamic_psf 的 `flux` 字段（实测仪器流量）

取对数的原因：乘性梯度在对数域变为加性，便于多项式拟合；同时压缩动态范围，提高稳健性。

**物理推导**：图像模型 `I = I_star × M + S` 中 M 为渐晕因子，`F_instr = I_star × M`，`F_syn = I_star`，故 `r = log10(F_instr/F_syn) = log10(M)`。拟合曲面 `r(x,y)` 即为 `log10(M(x,y))`，`M = 10^r = M_true`，校正 `I_cal = (I-S)/M = I_star`（正确）。

### 4.2 星-图匹配

1. 从 plate_solve 获取 WCS 解
2. 对每颗 Gaia 星 (α, δ)，用 WCS 投影到像素坐标 (x_gaia, y_gaia)
3. 在 star_detector 输出的星表中搜索最近邻（阈值 3 像素）
4. 排除饱和星（star_detector 的 saturated 标志）
5. 排除 PSF 拟合失败的星（status != OK）

### 4.3 离群点预处理

在拟合前执行初步清洗：
- 排除 `r_i` 超出 [median - 3σ, median + 3σ] 的点（σ 用 MAD 估计）
- 排除 Gaia 星等过暗（G > 阈值）或过亮的星

### 4.4 2D 多项式曲面拟合

乘性梯度曲面建模为 2D 多项式：

```
r(x, y) = Σ_{j+k ≤ P} a_{jk} × x^j × y^k
```

其中 P 为多项式阶数，由 LOOCV 自动选择（第 6 节）。

坐标归一化：将 (x, y) 归一化到 [-1, 1] 区间，改善条件数：

```
x' = (2x / W) - 1
y' = (2y / H) - 1
```

### 4.5 稳健求解：IRLS + Tukey biweight

使用迭代重加权最小二乘（IRLS）配合 Tukey biweight 权函数：

```
权重 w_i = {
    (1 - (u_i / c)²)²    if |u_i| < c
    0                      if |u_i| ≥ c
}
```

其中：
- `u_i = r_i - r(x_i, y_i)`: 残差
- `c = 4.685 × MAD(residuals) / 0.6745`: 调节常数（95% 渐近效率）
- MAD = median(|u_i - median(u_i)|)

迭代流程：
1. 初始拟合：普通最小二乘（OLS）
2. 计算残差 → 估计 MAD → 计算 Tukey 权重
3. 加权最小二乘重新拟合
4. 重复步骤 2-3 直到收敛（系数变化 < 1e-8 或迭代 50 次）

### 4.6 乘性梯度曲面

拟合得到系数 {a_{jk}} 后，全图像素 (x, y) 的乘性梯度为：

```
M(x, y) = 10^r(x, y)
```

## 5. 加性梯度拟合

> **[已封存 2026-07-12]** 本节描述的加性梯度（S_map）天光校正已封存。
>
> **封存原因**：S_map 的经验多项式拟合存在根本缺陷——PSF 拟合的局部背景 B 值包含 ISL+DGL+气辉+黄道光+星云目标信号，在银河等区域缓变星云信号会被当作天光误减，破坏真实目标；且采样稀疏（仅星点位置），多项式在星点之间无物理约束。
>
> **当前状态**：photometric_calib 仅做乘性流量定标（M_map），校正公式为 `I_cal = I_float / max(M_map, _MIN_M)`，天光作为低频残差保留。
>
> **后续方案**：天光一致性由后续马赛克背景匹配模块处理（借鉴光度马赛克方法，多帧共享最小残差低频背景）。
>
> **代码保留**：所有 S_map 相关代码（fit_additive, GradientSurface, 加性曲面评估）以注释方式封存，取消注释即可恢复。以下内容为算法参考，保留供未来参考。

### 5.1 背景采样值

对每颗 PSF 拟合成功的星 i（不要求匹配 Gaia），取其 `B` 字段作为局部天空背景采样值：

```
b_i = B_i
```

这些采样点在视场内空间分布，编码了月光、光害、气辉的加性梯度。

### 5.2 采样点加密

PSF 拟合的星点分布可能稀疏（尤其在星少的天区）。为提高曲面拟合精度，可选地添加网格背景采样：
- 在图像上生成均匀网格（步长 = 图像短边 / 20）
- 每个网格点取局部 15×15 像素窗口的中位值
- 排除含有星点的窗口（用 star_detector 的星点掩码过滤）

### 5.3 2D 多项式曲面拟合

加性梯度曲面建模为 2D 多项式：

```
s(x, y) = Σ_{j+k ≤ Q} b_{jk} × x'^j × y'^k
```

其中 Q 为多项式阶数，由 LOOCV 自动选择。

### 5.4 稳健求解

与乘性通道相同：IRLS + Tukey biweight。

加性梯度通常比乘性梯度更平滑（月光、光害为极低频信号），因此 Q 通常 ≤ P。

### 5.5 加性梯度曲面

```
S(x, y) = s(x, y)
```

## 6. LOOCV 自动选阶

### 6.1 动机

多项式阶数 P/Q 是唯一需要确定的超参数。为满足"不需要调参"的需求，使用留一交叉验证（LOOCV）从数据中自动选择最优阶数。

### 6.2 算法

对阶数候选集 P ∈ {1, 2, 3, 4, 5}：

1. 对每个留出样本 i：
   - 用剩余 n-1 个样本拟合 P 阶多项式
   - 计算留出样本的预测残差 e_i = r_i - r_{-i}(x_i, y_i)
2. 计算 LOOCV 误差：

```
CV(P) = (1/n) × Σ w_i × e_i²
```

   其中 w_i 为稳健权重（来自上一轮 IRLS）。

3. 选择 CV(P) 最小的 P* 作为最优阶数。

### 6.3 防过拟合保护

- 最小样本数约束：要求 n ≥ (P+1)(P+2)/2 × 3（3 倍自由度）
- 单调性检查：如果 CV(P) 在 P* 后连续上升 2 阶，确认 P* 为全局最优
- 阶数上限：P_max = 5（天文梯度极少超过 5 阶多项式）

### 6.4 计算优化

LOOCV 的朴素实现需要 n 次拟合。利用帽子矩阵（hat matrix）的性质：

```
e_i = (r_i - r̂_i) / (1 - h_ii)
```

其中 h_ii 为帽子矩阵对角元素。这使 LOOCV 误差在一次拟合内完成，复杂度从 O(n²·p) 降为 O(n·p²)。

## 7. 图像校正

### 7.1 校正公式

最终校正图像：

```
I_cal(x, y) = (I(x, y) - S(x, y)) / M(x, y)
```

其中：
- `S(x, y)`: 加性梯度曲面（第 5 节）
- `M(x, y)`: 乘性梯度曲面（第 4 节）

### 7.2 数值实现

- 在全图网格上评估 M(x, y) 和 S(x, y)（利用多项式系数直接计算）
- 输出类型：float32（保留动态范围）
- 防溢出：M(x, y) 的下限钳位为 0.01，避免除以过小值

### 7.3 输出归一化

校正后图像乘以全局缩放因子，使所有 Gaia 参考星的平均校正通量等于其平均合成通量：

```
scale = median(F_syn,i / F_cal,i)  （在乘性梯度校正后）
I_final(x, y) = I_cal(x, y) × scale
```

其中 `F_cal,i = F_instr,i / M(x_i, y_i)` 为校正后仪器流量。

这确保输出图像与 Gaia 星表系统在同一基准上。

## 8. 误差分析

### 8.1 误差来源

| 来源 | 量级 | 缓解措施 |
|------|------|---------|
| 合成测光不确定性 | ~1-3% | Akima 插值 + 0.1nm 积分精度 |
| PSF 拟合噪声 | ~1-5% | 稳健回归 + MAD 清洗 |
| Gaia 光谱数据噪声 | ~1% | 仅用高信噪比星（G < 16） |
| 滤光片曲线不确定 | ~2-5% | 使用校准曲线数据 |
| 星-图匹配误差 | 极低 | WCS 精度 < 1 像素 |
| 多项式过拟合 | 取决于阶数 | LOOCV 自动选阶 |

### 8.2 残差评估

校正后对每颗 Gaia 参考星计算残差：

```
residual_i = log10(F_syn,i) - log10(F_cal,i)
```

其中 F_cal,i 为校正后图像上第 i 颗星的通量。

健康指标：
- `median(|residual|)` < 0.02 mag（~2% 精度）
- `std(residual)` < 0.05 mag（~5% 精度）
- 无系统性空间趋势（残差 vs 位置无相关）

### 8.3 质量诊断输出

模块输出诊断报告：
- 匹配星数、排除星数及原因
- 乘性/加性梯度曲面参数（阶数、系数）
- LOOCV 误差曲线
- 残差统计（median, std, 最大残差）
- 梯度曲面预览图（可选）
