# 规范 02 · 文档书写与论文引用

本规范规定全部文档的书写方式与外部资料引用格式。

## 1. 书写总原则

- 只写现行设计要怎样，用自然语言把设计讲清楚，配必要的 mermaid 流程图、结构图。
- 一份文档围绕一个主题，按「是什么、为什么、怎么做」组织，标题层级清晰。
- 同级文档的结构、术语、符号与单位保持一致。

## 2. 文档中不出现的内容

- 开头无元信息块：文档 ID、状态、版本锚、纪律声明一律不写；
- 正文无日期、无版本号、无任务流水编号（如 RELEASE/FIX/EXP 前缀）、无 commit、无哈希；
- 无历史叙事：「旧版、作废、废止、留痕、曾、原 xx、负责人某日裁决」等表述不写；
- 无元话语：「本节不复制数值」「（正向约束）」「教训」等面向写作过程的注释不写。

需要保留的语义澄清用正向陈述句表达，例如直接写「入库的是信噪比，权重在 mosaic 现场换算」，不写成对历史说法的纠正。

## 3. 公式、数值与细节的位置

- 最高设计只放顶层结论与核心关系式；完整推导、常数表、容差、源码行号放 science 或 detail。
- 公式给出符号定义与单位；同一量在全文档符号一致。
- 实验过程数据、台账、逐行号引用放实验单元，由正本引用。

## 4. 论文引用格式

外部资料按数字编号引用：

- 正文中在引用处用方括号编号标注，如「逆方差最优集成见 [3]」；
- 文末设「参考文献」列表，按编号顺序给出完整条目：作者、年份、标题、出版物、卷期页、DOI 或 arXiv 号；
- 同一文献全文使用同一编号；编号连续。

参考文献条目示例：

```text
[1] Horne K., 1986, An optimal extraction algorithm for CCD spectroscopy,
    Publications of the Astronomical Society of the Pacific, 98, 609–617, DOI: 10.1086/131801
[2] Zackay B., Ofek E. O., 2017, How to COADD Images …,
    The Astrophysical Journal, 836, 187, DOI: 10.3847/1538-4357/836/2/187
```

## 5. 引用质量要求

- 被引文献真实存在：DOI/arXiv 可解析，作者、年份、标题核对无误；
- 引用内容与原文一致，引用论点确实在原文中，适用域与本主张匹配；
- 关键结论引一手论文，教科书与综述只作背景；开源代码记录项目、版本、文件位置；
- 不存在的文献、错误 DOI、张冠李戴的结论判为严重问题。

## 6. mermaid 图

- 用 mermaid 表达流程、依赖、结构与状态，图中文字简短、与正文口径一致。
- 一张图表达一个关系；图随正文内容更新，不保留已失效的图。

## 7. 完成判据

- 文档正向、自解释，无第 2 节所列内容；
- 引用编号连续、文献真实相关、条目完整；
- 公式、符号、单位与图表一致。
