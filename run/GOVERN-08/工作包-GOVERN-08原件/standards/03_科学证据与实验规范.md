# 规范 03 · 科学证据与实验

本规范规定科学结论的证据要求、实验单元组织，以及支撑创新点的小论文如何产出。

## 1. 科学结论的三类证据

每条进入生产的科学结论具备三类一手证据，三者齐备：

| 证据 | 要求 |
|---|---|
| 论文或标准 | DOI 或 arXiv 可解析，核对被引内容与原文一致 |
| 开源科学代码 | 项目 + 版本 + 文件:行，并回到其引用文献核对 |
| 仓内实验 | 固定 seed、复现命令 + 实测输出 |

- 暂时没有外部来源的结论，给出严格、详细、自洽的说明：定义、推导、假设、适用域与验证方式。
- 证据可复核；「我觉得」「惯例如此」不算证据。

## 2. 实验单元结构

每个创新点对应一个实验单元，位于 `实验/<单元名>/`：

```text
实验/<单元>/
├── README.md            单元说明
├── REPORT_paper.md      定稿小论文（支撑创新点）
├── REPORT_experiment.md 实验报告
├── refs.md              文献台账
├── code/                固定 seed、可复跑的实验代码
└── results/             结果数据与图表
```

- 只保留代码与结果数据，不保留可重新生成的中间大数据；需要时由代码复跑生成。
- 单元自包含：独立读者按 README 与复现命令能复核全部结论。

## 3. 两类合成数据

科学链路用两类合成数据加真实数据相互印证：

1. **哈勃物理仿真成像**：以 HST 真实数据（本仓 M16，带 PHOTFLAM 定标）作为纯信号模板，按完整物理前向过程生成采样帧——源、天光、暗流在电子域做 Poisson 抽样，读出噪声在电子域做 Gaussian，电子经增益、饱和与量化转为 ADU，加入平场空间响应与天空梯度；再做重建验证。
2. **纯生成代数合成数据**：真值完全已知的构造数据，用于科学不变量验证与「真值无效应 ⇒ 度量归零或报警」负例；天光对信噪比的影响通过散粒噪声体现，不用算术加常数代替。
3. **真实数据**：testdata 中 M42 与银心的端到端验证。

三类结论一致才判定创新点成立；分歧作为定位问题的线索。

## 4. 实验报告要素

实验报告含：可证伪假说、方法（公式与判据）、数据来源与生成方式、结果（真实数字、不确定度、正负对照）、可判定结论（成立/不成立/证据不足）、诚实边界（适用域、反例、未验证部分）、复现命令、佐证来源。

## 5. 定稿小论文

- 每个创新点产出一篇小论文，论文式书写：问题、方法、推导、实验、结果与误差、结论、参考文献。
- 小论文给负责人审阅，不堆砌原始数据，用图表与关键数字支撑结论；原始数据放 results 并引用。
- 小论文的引用按规范 02，文献真实存在且相关；推理链完整、误差可解释。
- 小论文与 science 正本口径一致：正本给权威公式，论文给论证与证据。

## 6. 可复现与判据

- 实验代码固定随机种子，提供一键复现命令；代码实现的方法与论文描述一致。
- 每个度量具备非退化判据：正确情形给出预期结果，注入缺陷被捕获，真值无效应时归零或判红。
- 结果台账数字可由代码复现，抽样重算一致。

## 7. 完成判据

- 五个实验单元结构完整、两类合成数据与真实数据齐备、小论文定稿；
- 每条科学结论三类证据可核，负例与复现通过。
