# 任务 G08-11 · 目视验收与发布收口

## 目标

全绿且成品帧就绪后，请求负责人目视验收；认可后完成发布收口。

## 依据

- 规范 08；最高设计 §13

## 步骤

1. 准备成品帧（本版 R 通道）与拉伸、切块视觉材料；
2. 状态置 READY_FOR_OWNER_REVIEW，通知负责人目视；
3. 目视确认无黑洞、亮斑、接缝，星点正常、全局正常；
4. 负责人认可后更新 README 等面向用户文档、按负责人确认写版本号、整理发布说明；
5. 标记 alpha 预览版。

## 交付

- 目视验收请求与成品帧；发布收口材料。

## 验收

- 负责人目视认可、发布材料齐备。

## 边界

- 发布决定只属负责人，未经认可不标记发布。
