# 任务 G08-04 · 实验单元治理

## 目标

整理五个实验单元，补齐两类合成数据，删除中间数据，产出支撑创新点的定稿小论文。

## 依据

- 规范 03

## 步骤

1. 按规范 03 统一五个单元结构（README、小论文、实验报告、文献台账、code、results）；
2. 删除可重新生成的中间大数据，只留代码与结果；
3. 补齐哈勃 M16 物理仿真：M16 纯信号模板，完整模拟 Poisson、天光、读出噪声、增益量化、平场与梯度；
4. 补齐纯生成代数合成数据与「真值无效应 ⇒ 归零/报警」负例；
5. 固定 seed、提供一键复现命令；
6. 据实验结果撰写/订正五篇定稿小论文，引用真实文献。

## 交付

- 五个实验单元；五篇定稿小论文；两类合成数据与复现入口。

## 验收

- 单元结构完整、证据三类齐备、结果可复现、小论文定稿。

## 边界

- 科学结论的对抗性审稿在 G08-05 进行；实验先做全、材料备齐。
