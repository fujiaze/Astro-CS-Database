# 任务 G08-07 · 代码与注释审查修正

## 目标

据 detail 对全部代码与注释做极详细审查修正，使代码与文档一致。本任务不编译、不跑测试。

## 依据

- 规范 06

## 步骤

1. 按模块分片逐文件逐函数审查，登记问题；
2. 核对功能、端口、生命周期、错误处理、并发、I/O、资源与边界；
3. 处置硬编码、死代码、重复实现、占位与静默回退；
4. 审查并订正注释，使其解释为什么且与代码同步；
5. 按片订正并汇总报告。

## 交付

- 订正后代码；代码审查报告与处置台账。

## 验收

- 代码与 detail 逐条一致，无死代码/静默回退，注释同步。

## 边界

- 不编译测试；改名与动态运行整改在 G08-08 进行。
