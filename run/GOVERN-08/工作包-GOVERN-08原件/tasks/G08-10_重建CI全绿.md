# 任务 G08-10 · 重建 CI 门禁并 GitHub 全绿

## 目标

依据定稿文档重建 CI 与门禁，双平台流水线 GitHub 全绿。

## 依据

- 规范 08 §4、§5

## 步骤

1. 逐条门禁映射定稿文档条款，补正负例与 fail-closed 口径；
2. 配置单元、模块、合同、集成、端到端、视觉、发布分层与快速/集成档位；
3. 配置 Windows 与 Linux 流水线、采样隔离与性能门真判红；
4. 运行全部流水线至全绿，记录运行链接。

## 交付

- CI/门禁落地；GitHub 全绿证据。

## 验收

- 双平台门禁全绿、判据有判别力、映射闭合，红灯无 waiver。

## 边界

- 全绿以实际流水线输出为准，平台受限项如实说明。
