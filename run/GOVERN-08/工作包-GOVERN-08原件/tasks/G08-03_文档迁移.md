# 任务 G08-03 · 文档迁移到 docs 三文件夹

## 目标

把全部文档按主题迁入 docs/science、docs/engineering、docs/detail，完成历史清理与索引。

## 依据

- 规范 01；规范 02

## 步骤

1. 盘点仓库全部 md，按科学/工程/细节分类，列迁移映射；
2. 同主题多份合并为一份正本，去重、保留最新口径；
3. 科学主题迁入 science（算法推导入 science/algorithms），工程主题迁入 engineering；
4. 迁移时清除日期、版本、任务编号、裁决与历史叙事，引用改为论文编号格式；
5. 删除根旧 spec、独立审计、工程控制与空目录，有用口径先吸收；
6. 每个文件夹补极简 README；更新 DOCUMENT_INDEX 与文件树一致；
7. 为每份文档标上游条款、补最高设计下级索引。

## 交付

- 迁移后的 docs 三文件夹；迁移映射与历史清理记录。

## 验收

- docs 结构符合规范 01，主题唯一、双向可追溯、README 齐备、索引一致。

## 边界

- detail 分册的完整推理在 G08-06 进行，本任务先迁移现有内容并归类。
