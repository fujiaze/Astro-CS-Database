# 任务 G08-05 · 十轮以上对抗性审稿

## 目标

对定稿前文档与实验单元做十轮以上对抗审稿，消除不严谨处，使文档集定稿。

## 依据

- 规范 04

## 步骤

1. 按规范 04 的轮次焦点逐轮亲自阅读，不用脚本替代；
2. 核对引用真实性、推理链、误差预算、覆盖与复现；
3. 红队构造反例、盲复算、跨文档与开源对照；
4. 问题分级登记：直接订正，或补实验后据结果订正；
5. 十轮后未收敛则追加轮次，直到连续两轮无须修问题。

## 交付

- 审稿记录与问题闭环台账；定稿的一级文档与小论文。

## 验收

- 阻断/须修项全部闭环复审；论文、正本、实验、结果一致。

## 边界

- 本任务只审文档与实验材料；代码治理在定稿后进行。
