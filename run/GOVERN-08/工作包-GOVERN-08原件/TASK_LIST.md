## 3. 顺序纪律

- 先删门禁，再替换正本、迁移文档与治理实验；
- 文档与实验审稿定稿后推理 detail，再做代码治理；
- 治理全部完成前不编译；编译清警告后重建 CI；
- 全绿后请求负责人目视，发布决定只属负责人。
