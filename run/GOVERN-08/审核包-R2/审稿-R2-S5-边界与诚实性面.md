#### **R-4 · P3 的 M2 oracle 指数由 2 改为 3/2，与 gnomonic 雅可比的解析式不符；据此撤回的 ½ρ² 律须重新裁决**

- **位置**：`实验/healpix-polar/results/audit/sim/exp_sim01_m16_forward_conservation.json` → `/M2_drop_area_chart_vs_exact/definition`
- **现状**（逐字）：
  > `(pi/3)*A_chart/A_exact - 1，A_exact 是 gnomonic 精确积分 （被积函数 (1+xi^2+eta^2)^{-3/2}）。被测的是 chart 直线多边形相对大圆足迹的弦-曲线偏差，不是闭式 0.5*rho^2。`

  提交 `0235fbcf`（"G08-05 P3 闭环：**oracle 指数改 3/2**"）据此撤回了旧版实测律 `(π/3)·A_chart/A_exact − 1 = ½ρ²`（系数 0.49978、416 点、分辨率无关散差 1.5e-07），改为「chart 侧项对 ρ² 的斜率 **−1.22e-09**（绝对展度 5.92e-08）」。
- **应为**：撤回一个已实测的物理律，必须先证明**新 oracle 才是对的**；否则是「用一个错误换掉一个正确」。
- **证据（推导腿，规范 03 §1 允许「暂时没有外部来源的结论，给出严格、详细、自洽的说明：定义、推导、假设、适用域」）**：
  gnomonic（TAN）投影把切平面 (ξ, η) 映到单位球，立体角元为

      dΩ = dξ dη / (1 + ξ² + η²)²

  故半径 ρ 的 gnomonic 圆盘（ξ = r cosφ, η = r sinφ, dξ dη = r dr dφ）的精确立体角为

      Ω₂(ρ) = ∫₀^{2π}∫₀^ρ r dr dφ /(1+r²)² = π·(1 − 1/(1+ρ²)) = πρ²/(1+ρ²)

  指数 **2**。若按仓内现用的指数 3/2 积分，则得

      Ω_{3/2}(ρ) = ∫₀^{2π}∫₀^ρ r dr dφ /(1+r²)^{3/2} = 2π·(1 − 1/√(1+ρ²)) = πρ²/( (1+ρ²) + √(1+ρ²) )

  两者之比

      Ω₂ / Ω_{3/2} = ( (1+ρ²) + √(1+ρ²) ) / (1+ρ²) = 1 + 1/√(1+ρ²) ≈ 2 − ρ²/2

  即 **ρ→0 时两者相差约 2 倍**；在实测上限 ρ = 10000″ = 4.848e-2 rad（`rho2_rad2 = 0.0023504430539097883`，同 JSON `/M2…/scan_rows[-1]`）处仍相差约 0.5%。因此「指数 2 → 3/2 的改正」**不是同一物理量的精度订正，而是把 `A_exact` 整体改了约 2 倍**。
