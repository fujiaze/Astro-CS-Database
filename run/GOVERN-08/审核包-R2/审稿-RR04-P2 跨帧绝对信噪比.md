## 1. 本轮结论

**判定：阻断。** P2 的立身主张「跨帧绝对信噪比」被实验单元**自己的 6 帧实测表**证伪；符号 `SNR` 在顶点与一级正本内并存两套互斥定义；裁掉争议的 SCI-P2-1 代数证明是循环的；机器 schema 仍保留被宣称已废除的 `group` 口径枚举。

### 最重的 3 条

1. **【阻断 B1】`SNR = F_ref,k/σ_F,k` 不跨帧可比，而这是 P2 的唯一头条主张。**
   `实验/absolute-snr/docs/frame-snr-canon.md:511-520` 的 `t3_m4_red` 六帧实测：帧 `20251212` 的 `σ_F = 80.923`，帧 `20251211` 的 `σ_F = 116.744` —— 前者测**同一颗 `m_ref` 星**精确 **1.443×**；但它落盘的 `snr_f = 21.364` 比后者的 `27.620` **低 22.7%**。逐帧 `F_ref,k = 10^(-0.4(m_ref − ZP_k))` 把该帧的测光零点偏差 **1:1 乘进分子**，隐含 `ΔZP = -0.6768 mag`。全表 Spearman `ρ(σ_F, snr_f) = 0.2571`（n=6，Σd²=26），两列秩**仅 1/6 一致**。即：帧级 SNR 的跨帧序**由测光零点散布主导，而非噪声性能**。同一文件 `:108` 却逐字宣称「可跨帧直接比较」。

2. **【阻断 B2】顶点与一级正本对同一符号 `SNR` 给出两套互斥定义，且在同一份正本内 132 行自相矛盾。**
   形 A `SNR = F/σ_F`（分子=被测源自身通量）：`docs/ACSD_DESIGN.md:124`、`docs/engineering/UNIFIED_OBJECTS.md:37`、`docs/science/CONTROL_WEIGHT_SNR.md:20,52`。
   形 B `SNR = F_ref/σ_F`（分子=参考通量）：`docs/ACSD_DESIGN.md:329`、`docs/science/CONTROL_WEIGHT_SNR.md:214`、`docs/engineering/data/DATA-002_PHASE_PRODUCT_EXCHANGE.md:102-103`、`eng/contracts/schemas/unified/sparse_snr_layer.schema.json:375`。
   致命处在**同一文件**：`docs/science/CONTROL_WEIGHT_SNR.md:94`（§2b 逐像素「规范形式」）写 `SNR(x,y) = S_src(x,y)/sigma_w(x,y)` 且 `:171` 把「分子只含源 `Σ_i F_hat_i·P_i`」列为**不变量**；而 `:214`（§8a 第 7 条）写控制点存 `SNR_c = F_ref/σ_F,c`，`:243`（§8c）把这个 `SNR(x,y)` 直接送进定权式 `w = SNR²/F_ref² = 1/σ_F²`。**形 A 代入定权式不成立**（`w = S_src²/(F_ref²σ_F²)`，差 `(S_src/F_ref)²` 倍，6 等跨度即 251²≈6.3×10⁴ 倍）。

3. **【阻断 B3】裁掉 SCI-P2-1 的「代数证明」是循环论证。**
   `docs/engineering/UNRESOLVED_REGISTER.md:385` 逐字：「`w_k = SNR_k²/F_ref,k² · g_k²`，而 `SNR_k ≡ F_ref,k/σ_F,k`，代入后 **`F_ref,k` 完全相消** ⇒ … 权重链对 `F_ref` 的定义域无偏好」。
   该证明**预设了形 B**（`SNR_k ≡ F_ref,k/σ_F,k`）——而形 B 恰是被争议项本身。取形 A 则 `F_ref,k` **不消**，权重对口径**敏感**。该证明回答的是**权重链**问题（答案：权重链确实无关），却被静默平移为**SNR 跨帧可比性**问题（答案：恰恰相反）。这是本轮最典型的推理跳步。

### 阻断（4 条）

#### B1【阻断】`SNR = F_ref,k/σ_F,k` 不跨帧可比 —— P2 头条主张被实验单元自己的表证伪

- **位置**：`实验/absolute-snr/docs/frame-snr-canon.md:108`（主张）、`:511-522`（反例数据）、`:485`（G11「已闭合」）
- **现状**：`:108` 逐字宣称「`F_ref,k` 因此恒等于参考源在本帧仪器标度（ADU）下的读数，`SNR_frame(k)` 恒等于**同一颗参考源在本帧的点源 SNR**——逐帧独立、与组内其他帧无关、**可跨帧直接比较**」。紧邻的 `:511-520` 六帧实测表显示：`F_ref,k` 跨度 2.14×（由逐帧 `ZP_k` 差驱动），`snr_f` 跨度 21.364–27.620。
- **应为**：要么（i）承认 `frame_snr`/`sparse_snr_layer` 的「绝对 SNR」不是跨帧可比量，把 P2 的立身主张改写为对 **`σ_F`（或等价的 `w = 1/σ_F²`、或 `m_5`）** 的跨帧可比性——这三者确实可比且确实已被权重链使用；要么（ii）若坚持要一个跨帧可比的 SNR，其分子必须是**组内公共且不含逐帧零点误差**的量，并显式承担「组内公共 F_ref 会随帧集增删整体平移」这一已知代价（`canon.md:145-146`）。
- **证据**（逐字抄自 `canon.md:511-520`，我已独立复算）：

  | 帧 | `F_ref` [ADU] | `sigma_F` [ADU] | `snr_f` |
  |---|---|---|---|
  | …20251126@060505 | 3140.94 | 118.150 | 26.584 |
  | …20251211@032428 | 3224.51 | 116.744 | 27.620 |
  | **…20251212@035745** | **1728.85** | **80.923** | **21.364** |
  | …20251228@040115 | 3700.67 | 136.182 | 27.174 |

  复算（只读算术，非实验/构建）：
  - C1 复算通过：六帧 `F_ref/σ_F` 与表记 `snr_f` 偏差 ≤ 4.4e-4。
  - 帧 `20251212` 相对帧 `20251211`：`σ_F` 比 = 116.744/80.923 = **1.4427**（前者测同一颗 `m_ref` 星**精确 1.443×**）；但 `snr_f` 比 = 21.364/27.620 = **0.7735**（反而**低 22.7%**）。真值应给 1.4427 的 SNR 比，实得 0.7735，**误差因子 1.8651**，恰等于 `F_ref` 比 3224.51/1728.85 = 1.8651，即隐含 `ΔZP = -2.5·log10(1.8651) = -0.6768 mag`。
  - 全表 Spearman `ρ(σ_F, snr_f) = 0.2571`（n=6，Σd²=26）；`σ_F` 秩 `[3,5,2,1,4,6]` vs `snr_f` 秩 `[2,3,6,1,5,4]`，**秩一致仅 1/6**。

## 4. 反例构造

> 本节是红队审稿的核心：不是通读结论，而是**主动构造**用来推翻现行结论的输入或推导。

### 反例 A（主反例，推翻 P2 头条主张「跨帧可比」）

**构造**：不合成新数据，直接取实验单元**自己登记**的 `t3_m4_red` 六帧实测表（`canon.md:511-520`），并只保留物理上无争议的两个量：`σ_F`（由图像噪声与 PSF 推出，不含 `ZP_k`）与 `snr_f`（落盘产品值）。

**推导**：`σ_F` 是「该帧把**同一颗** `m_ref` 星测得多准」的**定义域内**度量（`canon.md:117-121`：同一 `m_ref`、`m_ref` 由 `reference_mag` 固定、组内 `distinct reference_mag = {6.0}`，见 `canon.md:506`）。若 `snr_f` 真如 `:108` 所称「恒等于同一颗参考源在本帧的点源 SNR」且跨帧可比，则 `snr_f` 的序必须与 `σ_F` 的序**反向**（更小 `σ_F` ⇒ 更大 `SNR`）。

**证伪结果**：

- 帧 `20251212`（`σ_F = 80.923`）与帧 `20251211`（`σ_F = 116.744`）：前者 `σ_F` 小 30.7%（即精确 1.4427×），理应 `snr_f` **大** 1.4427×；实得 `21.364 / 27.620 = 0.7735`，**反而小 22.7%**。
- 全表 `ρ(σ_F, snr_f) = 0.2571`，秩一致 1/6。
- 偏差精确等于 `F_ref` 之比 1.8651（`ΔZP = -0.6768 mag`）⇒ 偏差 100% 由逐帧测光零点进入分子所致。

**结论**：`SNR = F_ref,k/σ_F,k` 的跨帧序由 `ZP_k` 散布支配，**不由噪声支配**；它不是跨帧可比的绝对 SNR。**P2 的头条主张在此被实验单元自己的数据推翻。**

**加固（独立第二证据）**：`frame_snr.schema.json:322` 的机器合同自己写「`SNR_k(F_ref) = F_ref/σ_F,k` **只有在参考通量统一时帧间才可比**」。逐帧 `F_ref` ⇒ 不统一 ⇒ 按 schema 自述不可比。**两条互相独立的证据（实测表 / 合同文本）指向同一结论。**

### 反例 B（推翻 G3「天光受限」判据的绿灯）

**构造**：不合成新数据，在 `b2_noise_terms.json` 已有的 `source_flux_e` 扫描上，**取该门未取样的亮端**。

**推导**：`G3_sky_limited_check` 只取 `F_e = 10, 30`（`:1691-1705`），得 `max_rel_diff = 0.01075` ⇒ 绿。但同一扫描的 `F_e = 10000`（`:1108-1143`）：`σ_f_def = 91.2484`、`σ_limited_pred = 35.7776` ⇒ 相对差 **60.8%**；`source_term_dominance = 13.75`。

**结论**：G3 的绿灯**完全来自取样选择**。把同一文件已有的第三个点纳入，该门即红 56 倍。规范 04 §3「验证判据能红能绿；恒真、空断言…判据判无效」⇒ 该门在亮源域**无证据资格**。

### 反例 C（推翻 `exp06_sky_monotonicity` 的「门能红」主张）

**构造**：读该文件的负对照实现。

**推导**：`:48` 计算 `snr_frozen`（冻结 `σ_sky` 于 `B=100` 值）后，`:49-53` 输出的三项**全是字面量**，`snr_frozen` 从未被引用。且冻结 `σ_sky` 的物理后果是 SNR **持平**（斜率 0），不是 `:51` 声称的 `snr_rises_instead_of_falls = True`。

**结论**：该「负对照」既未执行注入，其声明的结果方向也与物理相反。它满足规范 04 §3 列举的「恒真、空断言」特征。**但**：其试图复核的主证据 `b1_sky_scan.json` 独立成立，故本反例的杀伤面限于审计分片本身（见 S2 定级说明）。

### 反例 D（推翻 SCI-P2-1 的代数证明）

**构造**：把该证明的前提换成形 A 重做一次。

**推导**：`:385` 的证明取 `SNR_k ≡ F_ref,k/σ_F,k`，得 `w_k = g_k²/σ_F,k²`（`F_ref` 消）。改取 `SNR_k = F_k/σ_F,k`，得 `w_k = F_k²·g_k²/(F_ref,k²·σ_F,k²)`（`F_ref` **不消**）。

**结论**：同一证明对两种形给出**相反**结论 ⇒ 它预设了形 B，不是对争议的裁决。且它答的是权重链问题，不能移作 SNR 可比性问题的答案。
