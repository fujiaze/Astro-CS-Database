## 7 最重的一条

**【最重 · 甲】R2-01 · `PSF.md` 的 `bkg0` 来源被写成「窗口外 / 上游提供」，代码实为窗内暗像元的稳健中位数**

1. **同时污染四处语义**：`:62`（假设）、`:229`（§5.2 硬拒判判据）、`:218`（§5.1 负例构造）、`:252`（§6 **输入合同**）。`DPSFFitParams` 只有 `{fitRadius, maxIter, tolerance}`，**公开 API 没有任何背景入参**，这四条里描述的输入在代码里根本不存在。

**【最重 · 乙】R2-04 · `DRIZZLE.md:151`「两条守恒同时成立 ⇒ 唯一配对」是假命题**

理由：① 我用**两个夹具**（含一个不等 `A_pixel` 的非退化版）独立构造了三条**非 canonical** 核，它们**全部**同时满足不变量 1 与不变量 2；② 机理清楚——`S_p` 是 `B_j` 的加权平均，常量场下对**任意非负核**都返回 `B₀`，不变量 1 只要求 `Σ_p w_jp = 1`，两条合起来对 `w` 的解空间是**一族**；③ **文档 `:131-143` 的推导链自己已经证明了这一点**（它先写「不变量 2 只把解空间定成一参数族」），`:151` 又反过来说两条守恒给唯一性，**同一册内前后互斥**；④ 唯一性真正靠的第三条（`S_p` 取交叠面积加权均值）从未被列入约束清单，`:12-13` 的「核心不变量有两条，且只有这两条能同时成立」也是同样的误述。
