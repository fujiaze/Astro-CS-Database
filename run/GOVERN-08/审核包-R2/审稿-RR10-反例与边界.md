#### 【阻断-1】P3 守恒门的剔除计数器被硬写为 0，该门结构上无法判红

- **位置**：`实验/healpix-polar/code/audit/sim/exp_sim01_m16_forward_conservation.py:492`、`:498`、`:568-570`、`:613-614`、`:727`
- **现状**（我逐行 read 原文）：
  - `:492` `outside = int(np.count_nonzero(~drop_single))` —— 真实跨面 drop 计数在此算出；
  - `:498` `outside = 0` —— **隔 6 行、无条件、裸赋值、无注释**地覆盖上一行结果；
  - `:494-497` 四个数组用 `np.empty` 分配，`:503-505` 的 `a_drop_chart[i,j]` **只在 `if drop_single[i,j]` 内赋值** ⇒ 跨面 drop 该值是未初始化内存；
  - `:568-570` 主循环 `ad = a_drop_chart[i,j]; if not (ad > 0.0) or not np.isfinite(ad): continue` ⇒ 跨面 drop 被静默剔出**分子** `Fs`；
  - `:613` `x_tot = float(np.sum(r * a_pix_vos))`，而 `a_pix_vos` 在 `:506-507` **无条件赋值**、`r` 取自 `:434` `sig`（信号像面）⇒ 分母含全部像元通量；
  - `:614` `closure = float(np.sum(Fs)) / x_tot - 1.0` ⇒ **分子不含被剔除的 drop，分母含**。
- **追加证据（我亲验，构成第 1 条的加重项）**：归档 JSON 的自述 note `:724-725` 写「跨面界的 drop 被 fail-closed 剔除…**不参与 Σw 与闭合判定**」——**这句话与代码行为相反**。剔除的 drop 其通量经 `x_tot` **确实参与**闭合判定（作为分母）。故本条不只是「计数器被钉死为 0」，而是**归档读数主动陈述了一条关于该门行为的错误事实**，下游读 JSON 者会被误导以为该门已把域外缺口排除在外。
- **应为**：删除 `:498`；`M1_closure_le_1e-12` 在剔除数非零时显式判红（或按剔除后分母结算）；订正 `:724-725` 的 note；补一个「面界穿越视场」的守恒缺口实验。
- **证据强度**：全部由我本人 read 原文确认，非转述。
- **注**：论文 `:240` 已诚实写明「权重和逐位为 1」的适用域是**同一叶内**，故本条**不推翻论文已声明的域**；但它推翻了 apex `:136`/`:118`「通量绝对守恒 / 构造闭合」的**无条件读法**——因为该域外缺口在主实验腿里**被计数器钉死为 0 而不可见**。

## 4. 反例构造（本轮核心）

> 规范 04 §23：「构造反例：极端输入、低信噪比、光污染、高对比、奇点邻域、覆盖缺口，尝试推翻结论。」以下 4 条中 **3 条成功推翻、1 条未推翻**。

### CE-1（最强 · 成功推翻）结构主导天光场 ⇒ 推翻 apex 的无条件单调性

- **被推翻的主张**：`docs/ACSD_DESIGN.md:126`「天光越亮信噪比越低、趋于零」。
- **构造**：取一颗星云核心（M42 本体，延展发射源）所在帧。结构 rms 30 000 e⁻/px，天光跨两个十倍程，读出噪声 10 e⁻。
- **推导**：`SNR_frame = F_ref·√ΣP² / σ_hat`，而 σ_hat 由**整帧两轮裁剪 RMS** 估出，作用域含大尺度结构 ⇒ σ_hat 被结构主导、与天光几乎无关。实测 `d ln SNR/d ln B = −0.0001`，理论律为 −0.5，**差三个量级**。即：天光亮 100 倍，SNR 几乎不动；它量的是**星云结构幅度**，不是天光。
- **推翻成立**：主张写的是无条件律，实测在**本仓真实数据的运行域内机制失效**。`UNRESOLVED_REGISTER.md:473` 明写「这不是外推角落，而是本仓真实数据的运行域」。
- **文档是否承认**：**单元层承认且已修**（`frame-snr-canon.md:17` 带域、`:216` 列结构主导行）；**apex 层零承认**，且 `UNRESOLVED_REGISTER.md:456` 状态仍是「待裁决」。

### CE-2（成功推翻）跨面 drop ⇒ 推翻 P3 守恒门的可判红性
