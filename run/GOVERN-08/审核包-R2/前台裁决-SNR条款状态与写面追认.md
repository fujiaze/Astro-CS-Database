却让状态字面停在「待签署」，等于把已知为假的信号原样留给下游。
「改了会触发红灯」不是不改的理由 —— **红灯本来就是正确信号**。

## 二、车道独立重推的结论：前台采信

车道重推得：`SNR_comb² = Σ_k SNR_k²` **不成立**。
- 读法 A（各帧 SNR 分子同为一个共同信号 F）：两者相等**当且仅当 F̂ = F** —— 是关于数据的
  条件，不是关于实现的恒等式；
- 读法 B（各帧用自身估计 F̂_k）：由 Cauchy–Schwarz 得
  `Σ SNR_k² − SNR_comb² = Σ_k W_k(F̂_k − F̄)² ≥ 0`，**等号仅在零散度退化情形成立**
  ⇒ 一般情形是**严格小于**，不是相等。

独立帧下真正无条件成立的只有**方差可加** `Var(F̂) = (Σ_k W_info,k)⁻¹`，而那正是实现里
`w = w_sum` 的定义式重述 —— **与被检验量同源，不构成独立验证**。

另：门实际测的是 `W = Σ_k W_info`，而条款 subject 写的是 SNR 平方和，**不是同一个命题**。

⇒ 处置正确：撤判据、在条款本体写实推导、删除或改标注那个会被读成「已验证」的产品字段。
