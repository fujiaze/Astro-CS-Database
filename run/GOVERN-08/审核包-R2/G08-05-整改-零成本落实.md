### 2.4 但双向体检查出**相反**的病：exp10 有恒真门与浮点侥幸门

任务书的判别依据只有一条：**期望量能否追回到被检验量自身的输出字段**。据此对 exp10 逐门体检：

| 门 | 三型归属 | 判据 |
|---|---|---|
| `idw.max_abs_dev_at_control_points < 1e-9` | **恒真门 · 往返自证型** | `idw()` 自身带 `:90-93` 的 `hit` 短路：`d2 < 1e-30 → return ctrl_vals[hit[0]]`。在控制点处查询自身，返回值**按位等于**输入。该门测的是 IDW 在数据点处的**插值精确性**——而这是 `idw` 自己声明的合同，期望量可完整追回到被检验量的输出字段 ⇒ 结构上无判别力。阈值 `1e-9` 比双精度 epsilon 高 7 个数量级，除「查询机制本身坏掉」外**不可能红** |
| `negative_control.max_abs_dev_from_constant < 1e-12` | **恒真门 · 代数恒等式型** | 常数场 × 权重和为 1 ⇒ 结果恒为该常数。实测 `2.66e-15` 就是 `7.0` 的浮点噪声，任何正确实现都必绿 |
| `flux_closure < 1e-12` | 近乎不可判别 | 实测**精确 0.0**。`x_tot` 量级 O(1)、修正项 O(1e-15)，该差在双精度下被吸收 |
| `sum_p_w < 1e-12` | ✅ **有效** | 见 §2.3，有实测红→绿史 |

**更严重的一层：`0.0` 是浮点侥幸，不是恒等保证。** 对 `qd·qd` 逐点探针（按 `:197-198` 原式重建控制方向，落在叶心 `(gi+0.5)/4096`）实测：

```
gi=3070 gj=3070  qd·qd−1 = −1.110e-16  d2 = 2.220e-16  hit = False
gi=3071 gj=3071  qd·qd−1 = +0.000e+00  d2 = 0.000e+00  hit = True
……  36 个叶心中 6 个 qd·qd = 1 − 1.11e-16  ⇒ d2 = 2.22e-16 ≫ 1e-30  ⇒ 短路不触发
```

`arccos` 的最小非零输出约 `sqrt(2×1.11e-16) ≈ 1.49e-8`，故 `d2` 的最小正值是 `2.22e-16` —— **`d2 < 1e-30` 实质上就是 `d2 == 0` 的逐位相等测试**，伪装成连续阈值。若某个控制点落到 `qd·qd = 1 − 1.11e-16`，它会掉进加权分支：自权重 `1/2.22e-16 = 4.5e15`，邻叶权重 `≈1.7e7`，归一化后自身权重亏损约 `4.1e-8`，在 ctrl 值跨度 O(1) 时偏差约 `5e-8 > 1e-9` ⇒ **该门会翻红**。

实测 `max_abs_dev = 0.0` 说明当前这 12 个控制点**全部**命中逐位相等。**这是浮点运气，不是设计保证。**

**它掩盖了什么（危害单独立项）**：

1. **`1e-30` 阈值名不副实**：`hit` 短路宣称的「精确命中」实为逐位相等测试，代码未把这一语义写出来，下一个改 `RA0/DEC0/NSIDE/footprint` 的人会踩中。
2. **exp10 全链 SNR 是纯噪声商，量纲上不成立**：

```
SCALE (2 arcsec, rad)   = 9.69627362219072e-06
A_pix (sr)              = 9.401772215639154e-11
x = SB·A_pix (ADU)      = 9.401772215639154e-08
sigma_pix = sqrt(max(x,1)) = 1.0        ← 被 :119 的 max(x,1.0) 地板钳死
噪声 sd = 0.05·sigma_pix = 0.05
逐像元 SNR = x/噪声 = 1.8803544431278309e-06
噪声/信号 = 5.32e+05
```

`:119` 的 `np.maximum(x, 1.0)` 地板使光子项永不主导：信号 `9.4e-8` 比地板 `1.0` 小 7 个数量级。实测 `idw.reconstruction_range = [−0.6854641756369254, +0.5101469195807716]`。IDW 权重全正、是 ctrl 值的**凸组合**，故 `min(rec) = −0.685 < 0` ⇒ **至少一个「SNR 控制点」为负**。SNR 不可为负 ⇒ exp10 输出的稀疏控制点**不是合法 SNR**。
3. **三重恒真门叠成全绿**：I4（恒真）、I5（恒真）、I2（近乎不可判别）**没有一门能发现第 2 条**。门全绿与「SNR 为负」并存，正是「恒真门把真实缺陷藏在绿灯里」的标准形态。

> 按纪律**未改任何阈值、未加 epsilon、未动 `exp_sim01`**。exp10 的 SNR 地板属**物理建模口径**（需重定义 `sigma_pix` 并重跑、重锚 KEY_RESULTS/REPORT 的全部读数），非零成本，登记移交（§4）。
