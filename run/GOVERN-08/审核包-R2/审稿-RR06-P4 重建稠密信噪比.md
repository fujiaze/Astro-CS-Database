## 4. 反例构造（红队核心）

### 反例 R1（最强）　「GAIN 取倒数时 E 门全绿」——用单元自己的归档数值定量化

**构造**：`g = 1.3 e⁻/ADU`（`code/route1/exp_p4_04_brightness_forward.py:50`），取倒数 `ĝ = 1/g = 0.769231`，相对误差 `δ = ĝ/g − 1 = −0.408284`，`δ² = 0.166696`。`E_eff` 对纯缩放 0 次齐次，`v̂` 与 `v` 的比值 `a = (σ_slow² + S/g)/(σ_slow² + S/ĝ)` 只在 `σ_slow = 0` 时为常数，故 `E_eff = ⟨a⟩⟨1/a⟩ − 1 > 0`，但**二阶小**。用单元自己归档的 `E8` 数值表插值（`F6_gain_sensitivity.json::numeric_table_log_uniform`）：

| δ | `E_eff` | `E_eff/δ²` |
|---:|---:|---:|
| −0.2308 | 4.364e-3 | 0.0819 |
| **−0.4083（真倒数，本构造）** | — | **≈0.104（内插）** |
| −0.5 | 2.895e-2 | 0.1158 |

⇒ **`E_eff(δ=−0.4083) ≈ 0.104 × 0.166696 ≈ 1.7e-2`**。

**对照单元自己判红的臂**：`shuffled` 0.6335（`fix01` JSON `lock_arms[2]`）、`flat` 0.2905（`lock_arms[3]`）、route3/exp02 错臂 0.3137（`P2_degenerate_zeroing.E_flat_truth_wrong_arm`）。
⇒ 倒数增益的 `E_eff` 比任一「红」臂**小 17–37 倍**。任何以 E 幅度定阈（10⁻²…10⁻¹ 量级）的门都判绿。

**再加上两条独立退化**（均用单元自己的数据）：
- 源主导区（`σ_slow = 0`）：`E_eff ≤ 4.4e-16`（`F6::sigma_slow_zero_prediction_check`）⇒ **完全为零**，我独立推出同一结论（`a` 为常数 ⇒ `⟨a⟩⟨1/a⟩ = 1`）。
- fix01 自身 `G = 1.0`（`:107`）⇒ 「取倒数」在该脚本上是**恒等映射**，此问在 fix01 上根本无法实测。

**结论**：争议①在**效果上确认**，但机制比线索更精确——不是「E 对 GAIN 完全盲」，而是「E 对 GAIN 的响应是二阶小量（`E ≈ 0.09δ²`），落在所有已实现门的判定盲区里；且唯一按物理式抓这一类缺陷的门 `variance_map_matches_physical_model`（`exp_p4_04:400`）不在存档中」。**这条同时把「量纲颠倒」拆成两半**：`v` 的全局缩放对**任意** `w` 都不可观测；`v → 1/v` 只在**等权臂**不可观测（等权下 `E = (Σv)(Σ1/v)/N² − 1` 关于 `v ↔ 1/v` 对称），一般权下可观测——仓库 `:397-399` 的表述在等权臂上是对的，我不推翻它。

### 反例 R2　「Δ 上界守卫是 fail-closed」——构造一个它必绿的场

**构造**：取胞内 100:1 阶跃方差场 `v(x)`。其二阶导在阶跃处是 δ 函数，**a.e. 处 `q = 0`** ⇒ `delta_guard` 走 `:27-28` 的 `d_err = float("inf")` 分支 ⇒ `d_max = min(ℓ/2, min(W,H)/4)` ⇒ **任意 Δ 判 PASS**。

### 反例 R3　「算子公理已验证」——构造一个过 A2∧A3∧A4 但非线性的算子

**构造**：`R[v](x) = Σ_k w_k(x)·h(v_k)`，`h(v) = v·(1 + ε·tanh(ln(1+|v|)))`，`ε ≪ 10⁻⁶`。
- **A2 正齐次性**：`h(a·v) = a·v(1+ε tanh(ln(1+a|v|)))`，对 a>0 不等于 `a·h(v)`？—— 更严格地取 `h(v)=v·(1+ε·ln(1+|v|)/(1+ln(1+|v|)))` 亦可构造同阶；关键是 `h` 可取**零次齐次**形式 `h(v)=v·(1+ε·ψ(|v|))`，则 `h(av) = av(1+εψ(a|v|)) ≠ a h(v)`。⇒ **该构造不满足 A2**。修正：取 `h` 与标度无关是不可能的（非零齐次非线性必然破坏精确齐次），但**可构造 `ε→0` 极限下同时过 A2 数值门（1e-8）与 A3（1e-6）而严格非线性的算子**：令 `h(v) = v + ε·φ(v)`，`φ` 为零次齐次（如 `φ(v)=v·sin(ln|v|)`），则 `h(av) = a[v + εφ(v)] = a·h(v)` **精确成立**（因 `v·sin(ln|v|)` 在 `v→av` 时 `av·sin(ln a + ln|v|)` ≠ `a·v·sin(ln|v|)`，除非 `φ` 取 `φ(v)=c·v`）。⇒ **取 `h(v) = v·(1+ε)` 为常系数即线性**；真正的障碍是：`h` 精确零次齐次 + 非常数 ⇒ 在 `v>0` 上只能 `h(v)=c·v`（因为 `h(av)=a h(v)` 对一切 a ⇒ `h(v)/v` 沿 v 连续 ⇒ 常数）。
- **因此我修正自己的构造**：在**逐点连续**假设下，A2 精确成立已排除连续非线性点态函数；剩下的漏洞是**权依赖于被重建值**（本例中 `w_k(x)` 依赖 `v_k`），而 A2/A3/A4 **都不检验权的这种依赖**。构造：`w_k(x) = 1 + ε·tanh(v_k)/max|v|`，`ε=10⁻⁹` ⇒ 节点处 `R[v](x_k) = (1+ε tanh(v_k)/max|v|)h(v_k)`，与 `v_k` 的偏差 `~ε|v_k| < 10⁻⁶` ⇒ 过 A3；`R[av]` 中 `w_k` 不变而 `h(av)=a h(v)` ⇒ `R[av] = a R[v] - a·ε·tanh(v_k)·…` ⇒ 正齐次性被破坏但幅度 `~ε·a·|v_k|`，在 a≤137、阈值 1e-8 下需 `ε < 1e-11` ⇒ **可构造 `ε=10⁻¹²` 的算子同时过 A2 数值门与 A3，且严格非线性**（`w` 依赖 `v`）。
- **结论（修正后仍然成立）**：A2∧A3∧A4 **不足以断定线性**，因为没有一条公理约束「权不得依赖被重建值」。这与冻结默认算子因钳制（`exp05:50-51`）而**实际就是这种情形**一致——钳制边界 `vals.min()/vals.max()` 正是依赖被重建值的权。**该结论由子代理提出、由我独立复核并把原构造的错误（`h` 破坏齐次性）修正后成立。**
