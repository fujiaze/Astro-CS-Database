## 1. 第 1 条：Phase2「独立帧 SNR 恒等式」的唯一判据恒等于零

### 1.1 独立推导（这是本单的主项，先重推结论，不只看门坏没坏）

**本仓的量（本推导所依据的生产定义，逐条给 file:line）**

| 量 | 定义 | 位置 |
|---|---|---|
| 帧级信息量 | `W_info,k = a_k² · P_kᵀ C_k⁻¹ P_k` | `lib/algorithms/noise_snr/cpp/src/information_weight.cpp:103`（`finish_from_x`） |
| 帧级 Q | `Q_k = a_k · P_kᵀ C_k⁻¹ d_k` | 同上 `:104` |
| 帧级通量与方差 | `F̂_k = Q_k/W_k`，`Var(F̂_k) = 1/W_k` | `lib/algorithms/noise_snr/cpp/src/information_weight.cpp:312-313` |
| 独立帧组合 | `W = Σ_k W_info,k`，`Q = Σ_k Q_k` | `lib/algorithms/integration/phase2_integrate/src/phase2_integrate.cpp:867-871` |
| 组合通量与方差 | `F̂ = Q/W`，`Var(F̂) = 1/W` | 同上 `:952-953` |

单位：`W_info` 为 `ADU⁻²`（`phase1_product.cpp:687` 写 `units: "ADU^-2"`），`F̂` 为 `ADU`，`Var(F̂)` 为 `ADU²`。
⇒ **量纲不是障碍**：`SNR_comb²` 与 `Σ SNR_k²` 都是无量纲。障碍是纯统计的，以及实现根本没检验这个 subject。

**推导 A（合同条款的字面读法）：各帧 SNR_k 的分子是同一个共同信号 F**

P2 的定义是「跨帧可比的**绝对** SNR」，`SNR_k = F/σ_F,k`，同一个源在同一坐标系下对各帧有同一个真通量 `F`，
于是

```
SNR_comb      = F̂ / σ_F,comb ,   σ_F,comb² = 1/W_tot ,  W_tot = Σ_k W_info,k = Σ_k 1/σ_F,k²
SNR_comb²     = F̂² · W_tot
Σ_k SNR_k²    = Σ_k (F/σ_F,k)² = F² · Σ_k 1/σ_F,k² = F² · W_tot
```

⇒ `SNR_comb² = Σ_k SNR_k²  ⟺  F̂² = F²  ⟺  F̂ = F`（估计无偏）。

这是一个关于**数据**的陈述（"这次数据恰好没有偏差"），**不是关于实现正确性的陈述**。
实现把 `F̂` 算错、把 `W` 算错、把 `Q` 算错，都不会让这个等式更不成立或更成立；
而实现对错恰恰是判据该管的事。⇒ 该式**不能**作为正确性判据，无论用什么参照量。

**推导 B（"每帧各自测一次"的读法）：由 Cauchy-Schwarz，一般是严格不等式**

若 `SNR_k` 的分子取各帧**自己的**估计 `F̂_k`（这才是"忽略帧间不一致直接平方相加"的口径）：

```
Σ_k SNR_k² = Σ_k F̂_k² · W_k
SNR_comb² = ( (Σ_k W_k F̂_k)/W_tot )² · W_tot
```

用加权方差分解（`F̄ = Σ_k W_k F̂_k / W_tot`）：

```
Σ_k W_k F̂_k² = W_tot · F̄² + Σ_k W_k (F̂_k − F̄)²
⟹ Σ_k SNR_k² − SNR_comb² = Σ_k W_k (F̂_k − F̄)²  ≥ 0
```

等号成立 **当且仅当所有 F̂_k 相等**。右边正是加权均值的 χ² 型散布量（自由度 K−1）。
⇒ 恒等式只在 **χ² = 0 的零散度退化情形**成立；而"各帧测出来完全一样"恰恰是**没有信息**的情形。
（这与项目已有的判据纪律同形：`docs/science/PSF_SIGNAL_WEIGHT.md:129` 的 §7a.6，把「帧级臂 RMSE ≤ K·s_field」类
判据登记为对任意真值场恒真、**证据资格 = 空**。）

**推导 C：实现里的门根本没检验条款的 subject**

门实际算的是 `|w − Σ_k f.view.w_info| / w`（改前 `:955`），即 `W` 与 `Σ_k W_info,k` 相对差。
这只是**方差可加** `Var(F̂) = (Σ_k W_info,k)⁻¹` 的定义式重述 —— 而 `W` 在 `:871` 就是被赋成 `w_sum` 的。
条款 subject 写的是 `SNR_combined² = Σ_k SNR_k²`；门写的是 `W = Σ_k W_info,k`。**两者是不同的命题**，
即使门不同源也判不到 subject 上去。这是独立于「同源」的**第二个**缺陷。

**结论（三条一句话）**

1. `SNR_combined² = Σ_k SNR_k²` **不是恒等式**。读法 A 下它等价于"估计无偏"，读法 B 下它等价于"各帧零散度"。
   两者都是关于**数据**的条件陈述，实现是否正确无法由它判定。
2. 独立帧下真正无条件成立的结论只是**方差可加**：`Var(F̂_comb) = (Σ_k 1/Var(F̂_k))⁻¹`，
   即 σ 按平方根相加、**信息量 W 按线性相加**。这是组合的定义本身，不是可判的命题。
3. 实现里的门既测错了 subject（缺陷 C），又用同源量当参照（缺陷 A）。
   ⇒ 条款 subject 不成立、门无鉴别力，**两者都要处置**，不能只把门改成「同源以外的东西」了事。

### 1.2 为什么原门在任何可达路径下都不判红（复核确认）

- `:867-868` `for (const auto& f : fs.frames) { q_sum += f.view.q; w_sum += f.view.w_info; }`
- `:871` `double q = q_sum, w = w_sum;`
- 改前 `:953-954` `double sum_w = 0.0; for (const auto& f : fs.frames) sum_w += f.view.w_info;`

同循环、同字段（`f.view.w_info`）、同顺序、同初值 `0.0`、同累加运算 ⇒ `sum_w` 与 `w_sum` **逐位相同**（IEEE754 确定）。
故 `snr_rel ≡ |w − sum_w|/w = 0`，且 `0 > kSnrIdentRtol(1e-9)` 恒假 ⇒ 分支永不进入。
改前 `:914` 是唯一改写 `w` 的分支，且同行置 `joint_used = true`，与 `:956` 的 `!joint_used` 互斥
⇒ 相关帧路径上该门同样不进（`snr_rel` 在相关帧下非 0，但被 `!joint_used` 短路掉）。

## 2. 第 2 条：`weight_chain.cpp:219` 的 `dimensional_identity` 同形

### 2.1 代数推导

生产定义（同一函数内）：

```
weight_chain.cpp:104   w0 = (snr/reference_flux) * (snr/reference_flux)
weight_chain.cpp:197   w  = w0                       （经 weight_from_snr）
weight_chain.cpp:200   w *= g * g
weight_chain.cpp:219   dimensional_identity = w*F_ref² − layer_snr²·g²      ← 改前
```

代入 `w = (layer_snr/F_ref)²·g²`：

```
w·F_ref² = (layer_snr/F_ref)²·g²·F_ref² = layer_snr²·g²
⟹ dimensional_identity ≡ layer_snr²g² − layer_snr²g² ≡ 0
```

浮点上不是**精确** 0（`fl` 的运算次序与结合律不同），但只剩**数个 ulp**的舍入，量级 `~1e-16·layer_snr²g²`。
判据容差写的是 `1e-15`（selfcheck `:302`）与 `1e-15·max(1, |w|F_ref²)`（`:819`）——**恰好卡在舍入噪声之上**。

**它能检出什么**：只能检出 `w` 的赋值被改成**另一个公式**。而那时它已经不是判据，是 bug 本身。
**它检不出的（本应检出的）**：重建算子选错、层语义错（绝对 vs 相对）、`F_ref,k` 配对错、`g` 用错 ——
因为 `layer_snr`、`ref_flux_k`、`g` 在两边**同时**出现，任何一个错，两边一起错，差仍是 0。

### 2.2 为什么这句话本身是错的

改前 `weight_chain.h:426-431` 的公开注释：

> 逐像素面的**量纲/口径自证**（可被调用方与门直接断言）：… `dimensional_identity = weight * reference_flux_k² - layer_snr² * gain²`
> 后式应恒为 0（相对残差 ≤ 1e-15），即 w[ADU^-2]·F_ref[ADU]² = SNR²[1]·g²。

量纲一致性**不是**这样保证的。`w`、`F_ref`、`SNR`、`g` 的单位是**声明**（`weight_units`/`snr_units`/
`reference_flux_units` 三个词面），而上述等式的成立**只**依赖"同一个函数刚用同一个式子算过一遍 w"。
它保证不了单位——把 `w` 的单位标错、把 `F_ref` 从 e⁻ 换成 ADU，两边同时错，等式照样成立。
真正的保证是：(i) 三个单位词面被逐字核对；(ii) 函数**签名**里只有层值一个 SNR 输入、根本不存在帧级 SNR 参数，
口径错已从接口面排除（`weight_chain.cpp:131-136` 的权威锚注释）。

### 2.3 处置

同一测试函数 `:204-220` **已经**算好了独立 Oracle：`p3oracle::build_S` → 稠密 `C_y` → 自有 Cholesky 消元

```cpp

  P3_CHECK_NEAR(res.var_F_hat, 1.0 / res.W, 1e-15);
```

**改后**：

```cpp
  const double F_or = Q_or / W_or;
  const double var_or = 1.0 / W_or;
  P3_CHECK_NEAR(res.F_hat, F_or, 1e-9 * std::fmax(1.0, std::fabs(F_or)));
```
