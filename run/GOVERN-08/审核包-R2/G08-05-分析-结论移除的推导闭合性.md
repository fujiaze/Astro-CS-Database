## 2. 问一与问二：闭合性 + 替代结论

### 2.0 三种读法的真值（这是全部争议的根源）

同一串符号 `SNR_k`、`SNR_comb`，仓内实际存在三种读法。真值各不相同：

**读法 ①（`F_ref` 组内公共）— 精确恒等式**
各帧用同一 `F₀` 作分子：`SNR_k² = F₀²/σ_F,k² = F₀²·W_k`，故 `Σ_k SNR_k² = F₀²·W_tot`；`SNR_comb² = F₀²·W_tot`。**恒等，且它就是方差可加乘以 `F₀²` 的定义式重述。**
仓内两处 oracle 用的正是这一读法（都拿 `fref` 当公共分子）：
- `lib/algorithms/integration/phase2_integrate/oracle/weight_chain_oracle.py:333` — `rel_close(sum_w * fref * fref, sum_snr2)`
- `lib/algorithms/integration/phase2_integrate/oracle/weight_chain_selfcheck.cpp:263` — `close(sum_w * fref * fref, sum_snr2, 1e-12)`

**读法 ②（`F_ref` 逐帧，本仓生产口径）— 不是良定义式**
科学正本**逐字写死了这个口径**：`docs/science/PSF_SIGNAL_WEIGHT.md:126`（§7a 第 3 条）
「**F_ref 锚定**：`F_ref,k=10^(-0.4(m_ref−ZP_k))`、`m_ref=6.0`、**逐帧独立**、**必须同帧配对**」
⇒ `F_ref,k` 是 `ZP_k` 的函数，跨帧一般不等（这正是 §16 裁决的由来）。
令 `F_ref,k = F₀·r_k`（`r_k` = 逐帧残差，`r_k=1` 当且仅当 `ZP_syn,k` 组内齐次）。则
```
Σ_k SNR_k² = F₀²·Σ_k r_k²/σ_F,k²   而   组锚 SNR_comb(F₀)² = F₀²·Σ_k 1/σ_F,k²
比值 = Σ_k r_k²/σ_F,k² / Σ_k 1/σ_F,k²   ← 这是 r_k² 的一个 σ 加权平均
```
`r_k` 一般 ≠ 1 ⇒ 不等。**而这不是「算错了」，是把锚在不同参考通量上的平方相加 —— 表达式在组内无公共锚时不构成任何单一绝对 SNR 的平方。** 该残差正是 `docs/engineering/UNRESOLVED_REGISTER.md:105` 记录的实测区间（多帧产品偏差 0.023–0.533）与 `:414` 记录的 0.7%–5.2% 残余。

**读法 ③（分子为逐帧估计 `F̂_k`）— 严格不等式**
`F̂ = Σ_k W_k F̂_k / W_tot`（加权均值），则
```
Σ_k SNR_k² − SNR_comb² = Σ_k W_k(F̂_k − F̂)² ≥ 0
```
这是**精确的加权平方和分解**（把 `F̂ = ΣW_kF̂_k/W_tot` 代入展开即得），等号当且仅当全部 `F̂_k` 相等（χ²=0 的退化情形）。
⚠️ **对前台转述的两处订正**：(a) 该式**不只**是柯西–施瓦茨的推论，CS 只给出不等号，方程本身是**恒等式**；(b) 读法 ③ 的分子 `F̂_k` 对应的是 `source_snr = F_hat/σ_F,src`，而 `docs/ACSD_DESIGN.md:125` 明写该对象**不直接作帧权重**，拿它当 `frame_snr` 会「偏一个量级因子」。**读法 ③ 不是 P2 的口径。**

### 2.2 问二：方差可加是否真的无条件成立？——**独立推导，成立**

设第 k 帧对目标通量的线性统计量 `A_kᵀ d_k`，噪声 `n_k`，`E[n_k]=0`，`Cov(n_k)=C_k`。
独立帧 ⇒ `Cov(n_j,n_k)=0`（j≠k）。
GLS 组合 `F̂ = (Σ_k W_k)⁻¹ Σ_k A_kᵀC_k⁻¹(d_k − …)`，其中 `W_k = A_kᵀC_k⁻¹A_k`。则

```
Cov(F̂) = (Σ_k W_k)⁻¹ ( Σ_k A_kᵀC_k⁻¹C_kC_k⁻¹A_k ) (Σ_k W_k)⁻¹
        = (Σ_k W_k)⁻¹ ( Σ_k W_k ) (Σ_k W_k)⁻¹
        = (Σ_k W_k)⁻¹
```

中间的**交叉项全部为零**——这正是「帧间噪声独立」这一条前提所贡献的全部内容。除此之外不依赖任何东西：不依赖 `F̂` 是否无偏，不依赖 `F_ref` 的定义域，不依赖 SNR 如何组合。

**成立条件清点（诚实标注）**：
- **A1 帧间噪声独立 —— ⚠️ 本单自我更正：是「默认假定 + 接口可选校验」，不是产品保证。**
  我先前把它标成「P2 产品实际保证」，**这是错的**。直读生产代码：`phase2_integrate.cpp:870-874` **无条件**执行 `q_sum += f.view.q; w_sum += f.view.w_info;` 并 `w = w_sum`；联合 `C` 分支只在 `:883` 的 `if (joint.provided && joint_offdiag)` 命中时才走。⇒ **调用方不提供 joint covariance 时，跨帧相关性从不被检出，直接按独立处理。**
  ⇒ 正确表述：**方差可加在本仓是「默认路径的定义式」，其前提 A1 由接口是否提供 joint `C` 决定，而不是被产品强制保证的条件。**
- **A2 `C_k` 正确 —— 理想化。** 逐帧 `W_info` 由 MAD 估计方差 + Poisson 源项 + **自估增益**算出；仓内已如实登记：Phase1 不落盘逐像素 `sigma2`，`calibration_covariance` 仅为摘要，VARIANCE 面是 drizzle 后的面亮度方差 ⇒ 本仓**拿不到 `W` 之外的参照量**（`phase2_integrate.cpp:971-978`）
- **A3 设计矩阵正确 / A4 无偏（背景扣除正确）—— 理想化**，域外静默破坏由 `docs/ACSD_DESIGN.md:127-128` 自陈

⇒ **结论（更正后）：方差可加在「帧间噪声独立 + 噪声模型等于真值 + 模型正确 + 无偏」四条下成立。其中 A1 在本仓是默认假定而非保证，A2–A4 是理想化。它同时是一条定义式重述（独立路上 `w := w_sum` 按构造成立），不能当实现正确性判据。**

⚠️ **另一条独立的构造性事实**：`phase2_integrate.cpp:874` 直接 `w = w_sum`，所以独立路径上该式**在代码层面按构造成立、任何可达路径都无法违反**——这正是原门恒绿的机制。

### 2.2b 更强的替代命题：有鉴别力、且能判红

独立重推车道提出一条**比方差可加更适合充当替代**的命题，我复核后**采纳**：

> **`Σ_k SNR_k² ≥ SNR_comb²`，等号 ⟺ 帧间噪声独立（`C_kl = 0`）。**

**推导**（同一定义口径 `SNR_k = F_ref,k/σ_F,k`、公共 `F_ref`）：
`Σ_k SNR_k² = F_ref²·Σ_k W_k`，而 `SNR_comb² = F_ref²·W_comb`，故间隙 = `F_ref²·(Σ_k W_k − W_comb) ≥ 0`。
其中 `W_comb = aᵀC⁻¹a ≤ Σ_k a_kᵀC_kk⁻¹a_k = Σ_k W_k` 由 **Schur 补主块单调性**给出（`S_kk := C_kk − C_klC_ll⁻¹C_lk ⪯ C_kk ⇒ (C⁻¹)_kk = S_kk⁻¹ ⪯ C_kk⁻¹`），等号 ⟺ 交叉块对 `a_k` 的投影贡献为零。**无条件定理，与数据无关。**

**为什么它比方差可加更适合当判据**：
- 相对间隙 `R_SNR := (Σ_k SNR_k²)/SNR_comb² − 1 = (Σ_k W_k)/W_comb − 1 = corr_ratio − 1`，而 `corr_ratio` **已实现**（`phase2_integrate.cpp:940` `res.corr_ratio = w_naive / w_joint`）。
- 它**有外生于被检量的参照量**：`W_comb` 由 `C⁻¹` 算、`Σ_k W_k` 由对角 `C_kk` 算，**两者不同源** ⇒ **能判红**（`C_kl` 填错/漏填会使间隙符号或量级错）。
- 对比：方差可加在独立路上 `W_comb := Σ_k W_k` 按构造 ⇒ 同源自证 ⇒ **不可判**。

**诚实的边界**：独立路径上间隙恒 0，该路仍不可判；这条只在**相关帧联合 `C` 路**上有鉴别力。它把「原先被证伪命题想承担的功能（一个关于帧间独立性的可检验陈述）」用一个**正确的**形式补上了。

### 2.3 除方差可加外，独立帧下**真正无条件成立**的结论

1. **帧内权重换算恒等 `w_k = SNR_k²/F_ref,k² ≡ g_k²/σ_F,k²`**
   `F_ref,k` 完全相消 ⇒ **对 `F_ref` 的定义域无偏好**（读法 ① 与 ② 都成立）。这是 §2.0 的关键，也是 P2 权重链全部推导的地基。
2. **组合永不劣化**：`Var(F̂) = 1/W_tot ≤ 1/W_k = Var(F̂_k)` 对每个 k 成立（`W_tot ≥ W_k`）。无条件。
3. **单调性**：`W_tot` 增 ⇒ `Var(F̂)` 减 ⇒ 固定信号下 SNR 增。无条件。
4. **有效帧数**：`N_eff = (Σ_k W_k)² / (Σ_k W_k²) ∈ [1, K]`。无条件（Cauchy–Schwarz）。
5. **相关帧下简单求和必被拒**：块对角近似 `W_naive = Σ_k A_kᵀC_kk⁻¹A_k` 满足 `W_naive ≥ W_joint = AᵀC⁻¹A`（块 Schur 补论证），故 `1/W_naive ≤ 1/W_joint`，**朴素求和系统性低估方差（过度乐观）**，等号仅当 `C` 的帧间块在该二次型上解耦。
   ⇒ 这条正是 `FZ-AP2PT-CORR-RATIO-MIN` 门的内容，**在生产中是活的非退化门**：`phase2_integrate.cpp:939-948`，`corr_ratio = w_naive/w_joint` 是两次**真正不同**的计算（块逆 vs 全联合逆），参照量来自被检验量之外。

**证不了的不写**：本仓无法给出「`W = Σ_k W_info,k` 是否算对」的独立机器参照（§2.2 已述）。这是**登记在案的能力缺口**，不是我可以用推导补上的。

### 2.4 为什么仓内的「实验验证」结构上无法证伪这条

`实验/absolute-snr/code/b4_integration.py:90-96`：

```
# 定义式恒等：SNR_combined² = Σ SNR_k²（同一真实 F 下）
F_adu  = FRAMES[0]["F_e"] / GAIN          # 固定确定性真值，非估计
snr_k  = [F_adu / sigF_k]                 # 分子 = 真值
snr_comb_from_sigma = F_adu / sig_comb    # 分子 = 同一个真值
ident_rel = |snr_comb_def / snr_comb_from_sigma - 1|
```

**该实验连「让被证伪读法失败」的机会都没有**：`:36-42` 的 `FRAMES` **五帧 `F_e` 全部是 `1500.0`**，`:84` `snr_at_F = (cfg["F_e"]/GAIN)/sigF` 取的永远是同一个数。
两端分子都是**同一个常数真值**，`F/sqrt(Σ1/σ²) ≡ sqrt(Σ(F/σ)²)` 纯代数 ⇒ 任何 σ 序列、任何帧数都恒过，**零鉴别力**；`gates["H1_identity_lt_1e-12"]`（`:371`）是**结构性不可红的门**，测到的 2.2e-16 只是浮点舍入。

科学正本已如实自标（`docs/science/CONTROL_WEIGHT_SNR.md:213-214`：`is_tautology: true`、`evidence_eligible: false`）。
但 `实验/absolute-snr/REPORT_experiment.md:35` 与 `docs/DOC_CORRECTIONS.md:94-99`（孤儿 #2/#3）**仍把它当独立证据腿引用**。

**这才是撤销判据的真正理由**，与「式子是不是恒等式」无关。

## 6. 我推翻的既有判定
