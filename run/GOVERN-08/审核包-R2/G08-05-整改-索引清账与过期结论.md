### 3.2 `sig = 1e-9` 到底是什么语义 —— 独立判定

**判定：它是「反例夹具」，不是给当前实现定地板。保留是正确的。**

四条独立证据：

1. **生产码自证**：`star_detector.cpp:129-133` 把旧写法 `if (!(*sigma > 0.0)) *sigma = 1e-9;` 判为静默降级，并**点名本脚本为反例**。生产码明确说「这条写法已被判死」，故脚本里还留着它只能是「复现被否证的写法以量化危害」。
2. **数值自洽**：脚本 `:71` 打印 `SNR overestimate = 1.0 / (sh / true_sigma)`。`const_frac ≥ 0.40` 时 `true_sigma ≈ 20`，若 `sigma_hat` 返回地板 `1e-9`，则 `sh/true_sigma ≈ 5e-11`，高估倍数 `≈ 2×10¹⁰` —— 与 `star_detector.cpp:132` 写死的「约 2×10¹⁰ 倍」逐位吻合。⇒ 该分支的**存在目的**就是产出这个倍数。
3. **正本口径**：`实验/absolute-snr/docs/frame-snr-canon.md:217` 逐字写「`sigma_hat` **不被置成 1e-9** …… **该地板值只作反例量级读，不是现行行为**」。
4. **脚本自述**：`:1` 标题即「适用域**反例**」。

⇒ 派单给的二分（「如果它其实是在复现『如果门被写成那样会怎样』的反例，那保留是对的」）**成立，取前者**。

**是否判据代码：是。** 它是被测对象本身（the subject under test），改动即改 §2.7 实测数字。按派单约束**一个字未动**。
