# 前台裁决 · 「证据面已随归档移除」的读数怎么处置

车道提问：撤掉证据载体指针后，正文里的数字要不要一并撤下或标为不可复现？

**裁决：数字保留，不撤、不标「不可复现」。**

理由：
1. 负责人裁定是「实验域只留**正向代码与报告**」——报告要留，读数是报告的内容，
   撤数字等于删报告。
2. 负责人同一句给出的理由是「**代码和报告不是都入库而且可复现吗**」——
   即**可复现性由代码 + 报告共同承担**，不依赖归档。代码在仓内、固定 seed，
   读数可由复跑重新取得。称其「不可复现」与该裁定直接矛盾。
3. 因此正确表述是：**该读数的离线核验方式为按固定 seed 复跑对应入口并读对应字段**，
   而非「该读数不可核验」。

处置口径（供车道与后续车道统一）：
- 撤掉指向已删归档的**载体指针**，保留正文数字；
- 在该处注明核验方式（跑哪个入口、读哪个字段）；
- **不得**因此把结论降格或删掉——结论的有效性由对抗性审核的重新推导与反例构造
  判定，与是否有一份归档文件无关；
- **不得**为保住一个指针而指向未跟踪文件或编造替代承载行。
