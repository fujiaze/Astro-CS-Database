#### 3-1　守恒映射方差漏项的**误差方向**　→　**已改**（本单最重）

**审稿原判**：方向说反。`k = D_p/N_p = pixfrac² ≤ 1` 位于**分子**，漏掉它必然使结果**变大**。`pixfrac = 0.8` 时正确值 0.409600、漏项值 1.000000，比值 2.441406 = `1/pixfrac⁴`。

**我的重推（不采信，直接从 `N_p` 的定义起算）**

```
D_p = sum_j a_jp            命中面积          （GLOSSARY.md:12、DRIZZLE.md:89）
N_p = D_p / pixfrac²        归一分母          （同上，逐字）
⇒ k := D_p/N_p = pixfrac² ≤ 1
两种参数化：correct = S/N_p²  与  rewritten = S·k²/D_p²
因 N_p = D_p/k ⇒ N_p² = D_p²/k² ⇒ S/N_p² = S·k²/D_p²    （代数恒等，两式数值相同）
漏掉 k² ⇒ missing = S/D_p²
missing/correct = (S/D_p²)/(S·k²/D_p²) = 1/k² = 1/pixfrac⁴
```

#### 3-10　平场增益回归：加性偏置只平移截距　→　**已改**

**审稿原判**：`:90`「斜率与截距同时有偏」中斜率那一半是错的。建议本身对、理由错。

**我的重推**（用本册自身模型 `V = σ₀² + S/g`，`:90`）

```
未扣偏置的测量电平 X = O + S  ⇒  S = X − O
V = sigma_0² + (X − O)/g = (1/g)·X + ( sigma_0² − O/g )
⇒ dV/dX = 1/g   【严格不变】    截距: sigma_0² → sigma_0² − O/g
```

**我的实测**（`σ₀² = 625`、`g = 3.7`、`1/g = 0.27027027027027023`，8 个信号档线性回归）：

| 偏置 `O` | 回归斜率 | 斜率误差 | 回归截距 | `σ₀² − O/g` | 截距残差 |
|---|---|---|---|---|---|
| 0 | 0.2702702702702702 | −5.551e-17 | 625.000000 | 625.000000 | −2.3e-13 |
| 500 | 0.2702702702702703 | +5.551e-17 | 489.864865 | 489.864865 | −1.1e-13 |
| 2000 | 0.27027027027027023 | 0.0 | 84.459459 | 84.459459 | +3.3e-13 |

斜率误差全部落在 `1e-16`（双精度舍入）量级且**与 `O` 无关**；只有截距按 `−O/g` 平移。加性偏置只是自变量的平移，回归斜率对自变量平移严格不变。

**改前逐字**（`:90`）：
> 获取绝对增益需要平场对或可信的帧头增益，并且**平场对之前必须先扣除偏置**，否则斜率与截距同时有偏。

**改后逐字**（现行 §2.3）：
> 获取绝对增益需要平场对或可信的帧头增益，并且**平场对之前必须先扣除偏置**——但扣除偏置的原因是**截距**有偏，不是斜率有偏。设未扣偏置的测量电平为 `X = O + S`，则 `V = sigma_0² + (X − O)/g = (1/g)·X + (sigma_0² − O/g)`，即 `dV/dX = 1/g` **严格不变**，只有截距从 `σ₀²` 平移到 `σ₀² − O/g`。因此**增益估计不受加性偏置扣除精度影响**，而读出噪声基准 `σ₀²` 受 `O/g` 的扣除残差直接影响。只有当偏置误差是**乘性**的、工作点接近饱和或响应非线性、或裁剪阈值依赖于被偏置抬高的样本中位数时，斜率才会被偏置。

**推导链**

1. **样本中位数各 `N` 精确无偏**：`X ↦ −X` 保持分布 ⇒ `median(−X) = −median(X)` ⇒ `median` 的分布关于中心对称 ⇒ `E[median]` 等于中心，对每个 `N` **精确**成立（不是近似）。它不可能是偏置来源。
2. **有偏的是 MAD 尺度估计量，方向是低估**：`N = 3` 时解析可证 —— `MAD = min(x₍₂₎−x₍₁₎, x₍₃₎−x₍₂₎)`，恒小于总体中位绝对偏差。`N = 5` 中位口径 `median(MAD·κ)/σ = 0.74605` 与 `PHASE2_SAMPLER.md:332` 登记的「N=5 时中位 MAD/σ = 0.746」**逐位吻合**；`E[(κMAD)²]|_{N=5} = 0.907` 与 `PHASE2_UPM.md:92` 的 `E[σ̂²]/σ² = 0.906 (N=5)` **逐位吻合**。两个独立上游正本都站在「MAD 低估」这一边，**算法册对、本册错**。
3. **审稿 O-9 把一个正确的数改成了错误的数**。子代理原报的 `0.8230`（`MAD/κ`）**本身就是** `E[MAD·κ]/σ|_{N=5} = 0.8225`——标签写错、数值正确。审稿员信了标签、宣布数值作废，「纠正」成 `+5.8%`；而它给的 `1.0831/1.0576/1.0346` 正是另一口径 `κ·median(|X|)`（关于**零**、不减样本中位数）跑出来的数——该统计量对 `N(0,1)` 的期望**精确等于** `d = 0.6745`（由 `P(|X| ≤ m) = 2Φ(m) − 1 = 1/2`），故 `κ·median(|X|)` 恒为 1 的阶，**不含任何 MAD 偏置**。整条 O-9 是把一个正确结论翻成了错误结论。
4. **审稿 ③ 的读数符号反了**：`Var(median)/(πσ²/2N)` 在生产域 `N ∈ [3, 121]` **全程 < 1**（上表最右两列），从 0.862 单调趋近 1。审稿称的 `N=64 → 1.043` 距我的 `0.978` 约 7σ，不可复现。
