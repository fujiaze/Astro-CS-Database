### 4-1 【重要】`PSF.md:96` 与 `:228`｜`fwhm_x = 1.230310·sx` 的成立条件写成 `θ≡0` **或** `π/2`，而 `π/2` 处两式互换

**原文（`:96`）**：「把它们写成面元方向的 `fwhm_x = 1.230310·sx`、`fwhm_y = 1.230310·sy`，只在坐标轴与主副轴对齐时才成立，即 `θ ≡ 0`（主轴沿面元 x）**或** `θ ≡ π/2`（模 π）。」
**原文（`:228`）**：「轴对齐（`θ ≡ 0` 或 `π/2`）时两侧都取到真值，判定精确。」

**我的独立推导**。由 `:43` 的 `p₁ = cos²θ/(2sx²) + sin²θ/(2sy²)`：
- `θ=0` ⇒ `p₁ = 1/(2sx²)` ⇒ `FWHM_x = 1.230307652590102/√(2p₁) = 1.2303·sx` ✓
- `θ=π/2` ⇒ `p₁ = 1/(2sy²)` ⇒ `FWHM_x = 1.2303·sy`，而 `FWHM_y = 1.2303·sx`（**两轴对调**）

**实算**（`sx=3.1, sy=2.3`，用闭式 `F_sig/√(2p₁)`）：

```
θ=0.0000  FWHM_x=3.813954  FWHM_y=2.829708 | 1.2303·sx=3.813954  1.2303·sy=2.829708
θ=1.5708  FWHM_x=2.829708  FWHM_y=3.813954 | 1.2303·sx=3.813954  1.2303·sy=2.829708
```

⇒ `θ≡π/2` 处 `fwhm_x ≠ 1.230310·sx`。**文档自己的 `:111` 表格在 `θ=π/2` 处给出 `+34.78%`**，与 `:228` 的「两侧都取到真值，判定精确」直接打架。

**建议改法**：`:96` 改为「`θ ≡ 0`（主轴沿面元 x）时 `fwhm_x = 1.230310·sx`、`fwhm_y = 1.230310·sy`；`θ ≡ π/2`（主轴沿面元 y）时两者互换，`fwhm_x = 1.230310·sy`、`fwhm_y = 1.230310·sx`」；`:228` 删「或 `π/2`」或改为「轴对齐时面元方向恒等于某一个半轴方向，但归属随 `θ` 互换」。

### 4-3 【重要】`PSF.md:208` vs `:186`｜「归约…`sx`、`sy`、`fwhm_x`、`fwhm_y`、`flux` 均不受影响」与同文归轴步互斥

**原文（`:208`）**：「归约是**重参数化**，模型值逐点不变，因此 `sx`、`sy`、`fwhm_x`、`fwhm_y`、`flux` 均不受影响」
**原文（`:186`）**：「`sx < sy` 时**交换两轴**并令 `θ → θ + π/2`」

**我的推导**。`:186` 的归轴步把 `(sx,sy)` 换序，`sx` 的**报告值**随之改变；`:93` 定义 `fwhm_x` 对应 `sx`，故 `fwhm_x` 报告值同样改变。只有 `flux = 2π·A·sx·sy/3` 依赖**乘积**，不变。

**实算**（`A` 固定，`(sx,sy)=(2,3) → (3,2)`）：`fwhm_x = 1.2303×2 = 2.460620 → 1.2303×3 = 3.690930`（`fwhm_y` 反向），`flux` 逐位不变。

**建议改法**：改为「归约是重参数化，模型值与 `flux` 逐点不变；但归轴那半步会置换 `sx`/`sy` 两个**标签**，`fwhm_x`、`fwhm_y` 的报告值随之互换，故只有 `flux` 在整个归约下不变」。

### 4-6 【重要】`DRIZZLE.md:151` + `:12-13`｜「两条守恒 ⇒ 唯一配对」是假命题（我构造了反例）

- `w̃ ≠ a_jp/A_drop,j` ✔

⇒ 存在无穷多组满足两条守恒的 `(w, N)`。**唯一性实际由 `:131` 的第三条设计要求钉死**——「要让 `S_p` 对**任意** `B_j` 都等于面积交叠的加权均值 `Σ_j B_j a_jp/Σ_j a_jp`」，这是一个**插值性质**，比不变量 2（只对常量场成立）强得多，而它在 `:125`/`:131` 被当作推导的前提使用、**从未被列入 `:12-13` 的约束清单**。
