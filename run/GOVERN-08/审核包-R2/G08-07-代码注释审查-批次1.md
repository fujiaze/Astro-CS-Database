### A2 · `coverage/src/block.cpp:51-54` → 类 D/G

- **原状**：`if (per_px <= 0.0) { out->micro_chunk_required = 1; out->status = 0; return 0; }` —— 不可行却标 `status=0`（可行），**不写错**。
- **新状**（`block.cpp:86-101`）：改 `status = 1` + 写入可 grep 的 `error`，`block_pixels = 1`，并附推导注释。
- **依据**（推导，非猜测）：三项输入全为无符号 ⇒ `per_px == 0` ⇒ `N_B = 0` 且两项 scratch 均为 0 ⇒ `sample_work`/`per_pixel_scratch`/`per_sample_scratch` 全为 0 ⇒ `peak ≡ fixed_overhead`。既然走到这里说明 `peak > budget`，即 `fixed_overhead` 本身超预算，而该项**与块大小无关**，micro-chunk 救不了。

### A3 · `coverage/src/block.cpp:20` → 类 D
