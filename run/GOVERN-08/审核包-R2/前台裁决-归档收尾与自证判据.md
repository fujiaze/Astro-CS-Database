# 前台裁决 · 归档收尾锚失配 + Phase2 自证式判据

## 一、`m42-realdata/code/run_all.sh` 冻结锚失配 —— 裁决：批准重锚，须留记录

车道正确地**没有自行重锚**：该脚本 `:30-36` 明写锚「任何脚本、任何人都不得由
复现动作重写」，且 `sha256sum -c` 确已失败。

**裁决：批准重锚，但必须留记录，且必须由人执行。**

理由：该条款禁止的是**「复现动作自行重写锚」**——即脚本跑一遍就把锚跟着自己的
产出一起刷新，使锚结构上只能判绿（这正是前一车道已删掉的那类自愈锚）。而本单
的改动是**治理性的一次性代码修改**（补建输出目录），不是复现动作的副作用。
两者性质不同，不能混为一谈。

**执行要求**：
1. 重锚 `实验/m42-realdata/code/ANCHOR.sha256` 第 1 行；
2. **在交付件与本裁决记录里写明**：改了什么（补了哪几个目录创建）、为什么
   （干净克隆上该目录不存在，脚本无法落盘）、谁批准（本条裁决）、批准时间点；
3. 重锚后 `sha256sum -c` 须全绿；
4. **不得**顺手把该单元其他已失配的项一起重锚——逐条单独判。

## 二、Phase2「独立帧 SNR 恒等式」的唯一判据代数恒等于零 —— 裁决：按科学结论失据处理

前台已独立复核属实：
- `:867-868` 以循环累加得 `w_sum = Σ f.view.w_info`；
- `:871` `double q = q_sum, w = w_sum;`（非 joint 路径下 `w ≡ w_sum`）；
- `:952-954` **重跑同一循环、同一个字段、同一顺序**得 `sum_w`，
  于是 `snr_rel = |w − sum_w| / w = |x − x| / x` **精确为 0**；
- `:914` 是唯一改写 `w` 的分支，且同行置 `joint_used = true`，与 `:956` 的
  `!joint_used` **互斥** ⇒ 门在任何可达路径上都不会触发；
- `:745` 把 `snr_identity_rel_err` 写进**每一个** Phase2 产品的扩展字段。

**裁定**：这**不是「一个需要修正的门」，而是一条从未成立过的科学结论被当作已验证
写进了产品**。处置方向：
1. 该条款 `FZ-AP2PT-SNR-IDENT-RTOL` 的签署状态回退，**不得**以「门通过」为据；
2. 写进产品的 `snr_identity_rel_err = 0.0` **必须删除或改标注为「无鉴别力」**——
   审计方读到 0.0 会认为恒等式已验证；
3. 该恒等式本身是否成立，**要靠重新推导与构造反例判定**，不得靠这条门；
4. 同族的 `weight_chain.cpp:219` 的 `dimensional_identity` 同理
   （`w = (layer_snr/F_ref)²·g²` 代入恒为零），它是某条对外发布的量纲一致性保证
   的全部依据。
