### R2-4 §3.5 「`k_corr > 1` 的两个来源都是大于 1 的项，其乘积在有限 `N` 下严格大于 1」在非高斯边际有反例（**我核过，订正残留**）

`:427`/`:430` 给出 `k_gauss = 渐近中位数方差因子 × 1/median(MAD·κ)²`，`:430` 据此断言乘积**严格大于 1**；`:432` 的适用域只写「样本独立同分布且块内无未分辨空间结构」——**没有写高斯**。而 `Var(median) = πσ²/(2N)`（`:414`）本身是**高斯边际**推导。

我的实测（每档 1.5e5 次重复，`1/median(MAD·κ)²` 恒取自高斯同口径以便对比）：

| 边际 | N | `VarFac` | `1/median(MAD·κ)²` | 乘积 |
|---|---|---|---|---|
| normal | 5 / 25 / 121 | 0.9098 / 0.9800 / 1.0004 | 1.7894 / 1.0988 / 1.0181 | 1.6279 / 1.0767 / 1.0185 |
| **laplace** | **25** | 0.4283 | 2.0086 | **0.8602** |
| **laplace** | **121** | 0.3683 | 1.9176 | **0.7063** |
| uniform | 25 / 121 | 1.7719 / 1.8885 | 0.7151 / 0.6272 | 1.2671 / 1.1845 |

即 `k_gauss` 在非高斯边际下**可以小于 1**（laplace 0.71–0.86），uniform 下两个因子**各自都换号**。
`:427` 的「样本中位数自身的方差对渐近基线的有限 `N` 比值**恒 ≤ 1`**」同样缺边际限定（uniform 下该比值为 1.36–1.89，**大于 1**）。

**这是坑二（「严格/恒」断言模式）的复发**：第 1 轮 3-5② 明确要求删「取值域严格大于 1」，订正者**只改了机制归因、保留了严格界**。
**建议改法**：`:432` 的适用域补「**且边际为高斯**」；`:430` 的「严格大于 1」改为「在高斯边际内由 `Var(median) = πσ²/(2N)` 保证；域外不保证，须实测」；`:427` 的「恒 ≤ 1」补「（高斯边际内）」。**跨篇**：`PHASE2_UPM.md` 与 `PHASE2_SAMPLER.md` 同写「定义域 `1 < k_corr`」，需同批登记。

### R2-14 §2.3 「对 `θ_i` 有 `∂μ/∂θ_i = ∂V/∂θ_i = t`」推导写错（第 1 轮漏掉，**我核过**）
