### 1.1 我复核的浮点事实（实测输出）

复算在 `/tmp` 用独立脚本做，**不依赖任何判据脚本、不读仓内结果**。

```
$ python3 /tmp/fp_check.py
python float check (IEEE-754 binary64)
repr(1.0-1e-20) = 1.0
(1.0-1e-20)==1.0 -> True
hex(1.0-1e-20)  = 3ff0000000000000  hex(1.0) = 3ff0000000000000
1.0+eps/2 == 1.0 -> True  nextafter = 1.0000000000000002
sys.float_info.epsilon = 2.220446049250313e-16
1.0 - 2**-53 = 0.9999999999999999  == 1.0 -> False
ratio 1e-20/2**-53 = 9.007199254740992e-05
threshold 1.0-1e-20 is bit-identical to 1.0 -> True
max a/(a+b) over 2e5 random positive pairs = 1.0  all <=1: True
a/(a+b) with b=1e-300, a=1.0 -> 1.0
1.0 > 1.0 -> False  share>1.0 unsatisfiable when share<=1.0 provably
```

逐条读法：

| 事实 | 实测值 | 含义 |
|---|---|---|
| `1.0 − 1e-20` 是否精确等于 `1.0` | **`True`**；十六进制两侧同为 `3ff0000000000000` | **不是「很接近 1.0」，是逐位相同** |
| 1.0 之下最近的可表示值 | `1 − 2⁻⁵³ = 0.9999999999999999`（`== 1.0 → False`） | 减法必须至少跨过这个台阶才留得下痕迹 |
| 1e-20 相对该台阶的大小 | `1e-20 / 2⁻⁵³ = 9.007e-5` | 1e-20 只有 **1e-4 个 ulp** ⇒ 整个减法被舍掉（不是「小四个数量级」这么含糊） |
| 机器 epsilon | `2.220446049250313e-16` | 1e-20 比 eps 小约 **4 个数量级**，比「1.0 之下一格」还小 1e4 倍 |
| `nextafter(1.0, 2.0)` | `1.0000000000000002` | 1.0 之上最近的可表示值（任务书给的事实，复核成立） |
| `a/(a+b) ≤ 1` | 20 万组跨 600 个数量级的随机正数对，**最大恰为 `1.0`，无一 > 1** | 份额型量在 binary64 下**取不到 >1**（含 `b=1e-300` 的极值档，直接返回 `1.0`） |

⇒ **谓词 `share > 1.0 − 1e-20` ≡ `share > 1.0`，对任意有限正 `a,b` 无解 ⇒ 恒红，不是「恰好红」。**

### 4.3 为什么新立 `tautology_checks` 而不是全塞进 `identity_checks`

`identity_checks` 的语义是**代数恒等式自检**（`meta.n_algebraic_identity_checks` 会按这个名上报）。
G5d 不是代数恒等式，它是「谓词恒真」；把两件事混进同一本，会让
`n_algebraic_identity_checks` 这个名字**说错话**——这正是本单要修的那类毛病。
⇒ 新立**同级**的 `tautology_checks`，并同样**移出门计数、分开上报**。

### 4.4 门数上报的变化（静态计数，改前/改后逐条核对）

静态用 `ast.parse` 枚举（只解析，不执行、不产 `.pyc`）：

```
BEFORE(HEAD): X.gate(gates,...) 调用点 = 21 | identity_checks 条目(含note) =  8 | tautology_checks = 0
AFTER       : X.gate(gates,...) 调用点 = 17 | identity_checks 条目(含note) = 15 | tautology_checks = 5
```

| 计数 | 改前 | 改后 | 变化 |
|---|---|---|---|
| `meta.n_gates`（运行期值） | N | **N − 4** | **−4**（四条被移出的调用点每次运行各执行一次，均不在循环内 ⇒ 门位**恰好**减 4） |
| `meta.n_algebraic_identity_checks` | 7 | **14** | +7（G1b×3、G1c×3、G1d×1 条读数） |
| `meta.n_tautology_checks` | **不存在** | **4** | 新增（G5d、G1d 重复、两条重复合取项登记） |
| `meta.isolated_fail` | 不存在 | `[]`（预期） | 新增 **fail-closed 守卫**，见下 |

**⇒ 门数不再自报**：改前 G1c 与 G1d 是同一个布尔量被计了两次；改后该重复登记在
`tautology_checks.G1d_duplicates_G1c_verbatim`，**不占门数**。

**「判红就如实报红」的守口**：移出门表的 4 条其原谓词若为假，会被记进
`meta.isolated_fail`（非空即说明「恒真」前提被打破，这些条目必须退回 `gates`）。
本单**未改任何门的行为**，只是让「它们不该算证据」这件事在计数上不再撒谎。
