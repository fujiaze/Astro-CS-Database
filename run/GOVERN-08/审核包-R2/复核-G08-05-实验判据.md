## 4. 新判据是否仍是恒真门（逐条判定）

### 4.1 B1 门① `absolute_scale_matches_archived_first_hand` —— **不是恒真门，但存在 fail-open 空比较**

- **参照量是否不同源**：是。参照在磁盘归档 JSON（另一次执行），不在本进程重算 ⇒ 不共享 `GAIN`。共谋实验（变体 E）证明它是**回归锁**：归档被注入态产物覆盖后 23 项逐位相同 ⇒ 门① **判绿**，只有门②抓住。这与作者盲区 1 一致（但作者没做这个实验）。
- **恒真门判定**：**否**（变体 A/B/F/I 各自使其转红）。
- **新发现的 fail-open（未登记）**：变体 D —— 归档**可读**但 `arms` 里 8 个键全被改名/删除时，24 行全部走 `skipped` 分支，**比较 0 项**，`replay_ok` 保持初值 `True` ⇒ **门绿**。交付件 `:48` 与代码 `fail_closed_note` 写的是"归档缺失或不可读 ⇒ 判红"，**没有覆盖"可读但 schema 不匹配"**。判据重活只有 24 行循环，一次键名漂移即可让门空转。
- **附带**：变体 C（两个参照文件互换）不是受控判红，而是未捕获 `KeyError: 'arms'` 崩溃；`load_json` 只包了文件读取，没包内容访问。

### 4.2 B1 门② `gain_matches_independent_archived_reading` —— **不是恒真门，是溯源锁**

- 参照在**另一实验单元**的归档（`absolute-snr/results/exp06_e4_gates.json` 的 `detail.G7_gain_recovery[*].gain_true`）⇒ 不同文件、不同单元。判红率 5/8。
- 但**参照量本身是另一个单元的冻结常量**（= 1.3），不是从第一性原理导出；变体 G 证明只要把两个单元的 `gain_true` 同时改，链路自洽。作者已如实登记（盲区 2），此处确认。

### 4.3 B1 门③ / B6 三条新 verdict —— **是恒真门（常量型 / 自检型），本单新引入**

### 4.4 B3 G6a —— **绝对臂是恒真门；整体是单边阈值门**

- **绝对臂**：`def _sigma_from_abs(x): return 1.0 / X.recon_absolute(x)`，而
  `recon_absolute ≡ represent_absolute ≡ 1/s` ⇒ `_sigma_from_abs(x) = x` **逐位**。

  它唯一的非平凡内容是"若 `recon_absolute` 被改成带逐帧因子则判红"，这是对**库函数定义**的检查，不是对本实验数据的检查。
