## 4 分母是什么、当前是多少、缺什么

### 4.1 分母的定义

按 `轮次台账.md:11-18`，收敛度量的分母是**审查主体的总行数**：

> 审查主体 = `docs/` + `lib/` + `eng/` + `实验/`（`轮次台账.md:11` 明确列出四棵树）
> 另两项**排除**：第三方 vendor、巨型生成 JSON

由此：

```
一遍所需车道数 = 审查主体总行数 ÷ 11,000 行/车道      （轮次台账.md:15-16）
十遍底线       = 10 × 上述车道数                      （轮次台账.md:6）
收敛           = 再加「连续三轮零发现」的复核轮         （轮次台账.md:7）
```

## 5 「禁止在分母修好前报『还差 N 条』」—— 这条约束的来源与依据

### 5.1 约束的来源

本单**不新设**这条约束，它是仓内三处既有裁定的合并后果：

| 来源 | 原文 | 出处 |
|---|---|---|
| 负责人裁定 | 「十遍是底线。」 | `轮次台账.md:6` |
| 负责人裁定 | 「**既往产出不计入遍数。**」 | `轮次台账.md:46` |
| 恒真门登记表的强制条款 | 「**任何对外引用本表数字的地方，必须写明「口径 III / 整改分母」**；只写「共 N 处恒真门」而不写口径的，**视为未完成登记**。」 | `实验/TAUTOLOGY_REGISTER.md:0.5.4` |
| 登记表自陈局限 | 「口径 III 的 36 …**不由 AST 自动判定**；AST 只负责口径 I/II。」 | `实验/TAUTOLOGY_REGISTER.md:0.5.5-3` |
| 登记表自陈局限 | 「口径 II 的 **191 是下界，不是精确值**。」 | `实验/TAUTOLOGY_REGISTER.md:0.5.5-1` |
| 审稿编制纪律 | 「计数一律**从各审稿件原文读到**……读不到写「该件未给」，**绝不估算**。」 | `审稿-总账.md:6-7` |

`实验/TAUTOLOGY_REGISTER.md:0.5.4` 与 `:0.5.1` 是最直接的两条：前者把「不写口径的引用」判为**未完成登记**；后者明写「**为什么分母必须是 III 而不是 I**……用 I 当分母会把整改量**高估约 3 倍**」。

### 5.2 为什么这条约束在本单必须生效 —— 三条实测依据

1. **口径 I 与 III 的差已被量化过**：绝对 SNR 单元 I=108 / II=64 / III=36，I→III 差 **3.00 倍**（`实验/TAUTOLOGY_REGISTER.md:0.5.3`）。⇒ 用错口径报出的「还差 N 条」可以差 3 倍，且**方向是系统性高估**（拿 I 当分母会把剩余量说少、拿 I 当分子会把完成量说多）。
2. **分母的覆盖缺口更大**：口径 III 只覆盖 `实验/` 的 1/8 单元（§4.5），`docs/`+`lib/`+`eng/` 是**零分母**。在这三棵树上报「还差 N 条」，等于在一个**空集合**上做差。
3. **分母本身现在连自测都过不了**：登记表的 333/191/968/575 在其**自己当时的基线**上就复现不出（实测 359/220/965/780，§4.5），因为脚本未入库。⇒ 当前**没有任何一个权威数字是可复现的**，用它做减法的结果同样不可复现。

**具体危害已经发生过一次**：前一轮的「全域 **246** 条」在登记表两个规则下都复现不出，登记表 `:0.5.5-2` 自己把它作废了（「该数字的原始定义已不可考，本表不再引用它」）。再报一次「还差 N 条」而不给口径与脚本，就是**重演同一个错误**。

### 5.3 禁止的具体含义

在 §4.4 的 **D1 / D2 / D3** 三项与 §4.5 的口径 III 三项缺口修好前：

| 禁止 | 允许 |
|---|---|
| ❌「还差 N 条须修闭环」（不写口径） | ✅「口径 III 分母在 `absolute-snr` 为 36，其余 7 单元与 `docs`/`lib`/`eng` **未给**」 |
| ❌「还差 N 条车道」（用 63 车道/遍） | ✅「HEAD 实测主体 1,747,625 行 ÷ 11,000 = 159 车道/遍；63 片划分已丢失（`/tmp/r3/` 为空），不可复现」 |
| ❌「已完成 N 遍」 | ✅「完成 **0 遍**；已读 8/63 片、24 份 / 80,449 行（占 HEAD 主体 4.60%）」 |
| ❌「覆盖率 X%」（用 670,713 作分母） | ✅「按 HEAD 实测分母 1,747,625 计 **4.60%**；按台账旧分母计 11.99%，**旧分母已过期**」 |
| ❌ 引用 `审稿-总账.md` 的 81 / 131 / 55 作结论 | ✅ 引用 `00-台账订正.md` §5 的订正值（50 / 127 / 57）并注明原值 |

## 6 在什么条件下才能报「还差 N 条」

按依赖顺序，**必须**依次满足：

### 6.1 先修分母（否则后面全无意义）

| 条件 | 判据 | 当前 |
|---|---|---|
| **C1** | 重算并冻结审查主体分母（份数 + 行数），写明 `docs`/`lib`/`eng`/`实验` 各自的计入方式 | ❌ 台账值低估 160.6% |
| **C2** | **定死排除口径**：vendor 怎么剔、巨型 JSON 是排除还是单独立项、阈值取多少行。分母必须收敛到**单一数字** | ❌ 三个候选分母相差 2.1 倍 |
| **C3** | **重建 v3 片划分并存档**（不再放 `/tmp`）。`轮次台账.md:31` 的「全程不再改动」只有配合可复现的清单才成立 | ❌ `/tmp/r3/` 为空 |
| **C4** | 片清单冻结后，用 `/tmp` 之外的路径存放并登记路径 | ❌ |

⇒ **C1–C4 全部满足前，「还差 N 条车道」不可报。**

### 6.2 再修口径 III（决定「还差多少**条**」）

| 条件 | 判据 | 当前 |
|---|---|---|
| **C5** | 把 `tautology_measure.py` **入库**并锁定版本，使 `:0.5.2` 的数字可复现 | ❌ 仓内无脚本，实测复现不出 |
| **C6** | 补齐 **其余 7 个实验单元**的口径 III 数字 | ❌ 只有 1/8 |
| **C7** | 对 `docs/` + `lib/` + `eng/` 建立**门位普查 + 口径 III 分类**（前四项 AST 可判，后一项须逐条语义判定） | ❌ 零分母 |
| **C8** | 明确「须修闭环」的判定规则：什么算闭环？改完即算，还是须复审通过？（`审稿台账.md` §3 的「全部阻断与须修项闭环、**复审通过**」是唯一现存表述，但它没有可执行定义） | ❌ 无可执行定义 |

⇒ **C5–C8 全部满足前，「还差 N 条须修闭环」不可报。**

### 6.3 满足后可以报什么

| 满足 | 可报 |
|---|---|
| C1–C4 | 「还差 **N** 条车道 / **M** 遍」，且每个 N 都可由 `分母 ÷ 11000 − 已派车道数` 复算 |
| C1–C8 | 「还差 **N** 条须修闭环」，且必须同时给出**口径 III 分母**与**分子（已闭环数）**，缺一不报 |
| 全部 + 连续三个**完整的遍**零发现（`轮次台账.md:7`） | 才可报「**已收敛**」 |
