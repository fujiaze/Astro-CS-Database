### CE-2 · 白噪声传播对空间光滑平场残差的低估反例（攻击 M-01）

**构造**：设逐像素乘性平场场 `m(x,y) = 1 + δ(x,y)`，`std(δ) = s_flat`。PSF 拟合通量 `F̂ = Σ P_i·F·m_i / Σ P_i`。则

```
Var(F̂)/F² = s_flat² · Σ_iΣ_j P_i P_j ρ_ij
```

- **仓内采用**（`scia_common.py:442` 前提「δ 逐像素独立」⇒ `ρ_ij = δ_ij`）：`= s_flat²·Σ P_i² = s_flat²/N_eff`
- **空间光滑场**（相关长度 ≫ FWHM ⇒ `ρ→1`）：`= s_flat²·(Σ P_i)² = s_flat²`，即 **`s_flat` 而非 `s_flat/√N_eff`**

代入 `N_eff = 15.566`（`step5_calibration_gate.json:96`），`√N_eff = 3.945`：
- 同 `s_flat = 0.0032`：应 **0.003474 mag**，代码给 **0.000881** ⇒ **低估 3.95×**
- 1% 平场误差（a = 0.01）：应 **0.010857 mag**，按代码口径计 **0.000881** ⇒ **低估 12.3×**

**为何它静默**：唯一真实帧在 `sigma_flat = 0` 时**已经判红**（CE-1），故 3.95× 的低估在该帧上不改变判定 ⇒ **用现有数据观测不到这个缺陷**。这正是「残差小 ≠ 模型对」的教科书案例（规范 §3「验证判据能红能绿」）。

**且自相矛盾**：留下的预算项叫 `σ_flat,`**hf**（高频），却用白噪声推导；而仓内自认主项是低频大尺度残差且**判不了**（`PHOTOMETRY.md:366`、`step8_real_frame.py:191`）。

### CE-3 · 线性标度不足以建立「统一测光星等坐标系」的反例（攻击 M-04）

**构造**：设第 `j` 帧的真实观测

```
F_instr,i,j = C_j · ∫ F_λ,i(λ)·T(λ)·Q(λ)·T_atm,j(λ)·η_j(λ)·λ dλ + 噪声
F_syn,i     = ∫ F_λ,i(λ)·T(λ)·Q(λ)·λ dλ                    （模型通带不含 T_atm、η）
```

令 `A_i,j ≡ ∫F_λ,i·T·Q·T_atm,j·η_j·λ dλ / F_syn,i`，则

```
r_i,j = log10 C_j + log10 A_i,j
location_j = log10 C_j + median_i(log10 A_i,j)
scale_j = 1/(C_j · 10^{median(log10 A_i,j)})
```

施加后 `I_photo = scale_j · F_instr ≈ F_syn · 10^{median(log10 A_i) − log10 A_i}`。

**两条推论**：
1. **标量部分确实被吸收** ⇒ `I_photo` 落在 W·m⁻²·nm 的 F_syn 刻度上，相对量 ≈ 1。**所以「线性标度 ⇒ 统一坐标系」并非全错**，这一点必须如实承认，不能为了红队效果而夸大。
2. **但残差项 `10^{median(log10 A) − log10 A_i}` 是 SED 依赖的** ⇒ 它**不被任何标量零点吸收**，直接进 `sigma_residual`，且 `A_i,j` 随 `T_atm,j`、`η_j` 逐夜变化 ⇒ **同一颗星在两帧的残差偏移不同**，而 `PHOTOMETRY.md:15-16,263` 明令帧间一致性**不是门禁**、`:370` 明令消光**按不加处理**。

⇒ **「统一测光星等坐标系」的成立条件是「未建模项在带内谱平坦且逐帧稳定」，而该条件既未建模、未测量、也未设门**。设计顶点 `:113` 的无条件断言因此缺一个前置限定，且该缺口的量化读数（每夜 `sigma_residual` 波动）仓内**不存在**。

### CE-4 · 两窗等价性反例（核销前台线索 1，并确认其已被正确裁决）

**构造**：取两颗星，G 相近但色不同（`BP−RP` 差 0.3 mag），同一帧同一通带。
由 `delta_i = −2.5·r_i − C_i`、`C_i ≡ G_i + 2.5·log10 F_syn,i`：
- `G_i` 近似相同 ⇒ `C_i` 的差异**全部来自 `F_syn,i`**；
- `F_syn,i = ∫F_λ,i·T·Q·λ dλ` 随 SED 谱形变化，蓝星与红星的积分差可达数倍（同一通带内 `λ` 加权使蓝星权重更大）；
⇒ `C_i` 是**逐星量**，`|delta_i − median(delta)|` 与 `|r_i − median(r)|` 的**中心与展宽不同源**。

⇒ 前台线索 1 的**结论正确**（两窗不等价），但**仓内已由 G08-04 正确裁决并写入三处报告**（`README.md:72`、`REPORT_paper.md:63`、`REPORT_experiment.md:20`）。真正残留的问题在推导腿（**B-04**），不在结论本身。

### CE-5 · σ_flat 判据对「量级」无判别力（空断言方向）
