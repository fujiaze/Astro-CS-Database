T10 §5.1 写「`RETIREMENT_FIELDS` 豁免**永远匹配不到任何东西**」。**这条断言是错的**，我独立复现如下。

### 1.2 真正的缺陷：对报告的净影响是**零**

`continue` 在结构化扫描循环内，而**逐行扫描**（路径 token 那一路）在它**之前**跑完、且完全不知道豁免表的存在；`:879` 的 `emitted` 只是从已完成 findings 取快照，只能抑制结构化那一路的重复报。

**决定性 A/B（清空豁免表重跑全仓，逐条 diff）：**

```
A 组：豁免表原样              findings = 4888   retirement_fields_skipped = 121
B 组：RETIREMENT_FIELDS = ()  findings = 4888   retirement_fields_skipped = 0
  只在「无豁免」组出现 = 0 ；只在「有豁免」组出现 = 0
```

⇒ **豁免表发了 121 次火，最终报告一条都没变。** 那 121 条指向的路径全部解析成功，`abs` 形态又已被逐行扫描抢先报过。

最小实验（`/tmp` 假仓树，真跑 `scan()`）也能看出 `raw_reference` 形态：逐行扫描的 raw 以路径原样开头，结构化的 raw 以 `键名: ` 开头；实验里被豁免的条目全部是前者。

### 1.3 三个真实缺陷（与派单说的不完全相同）

| # | 缺陷 | 证据 |
|---|---|---|
| A-1 | **豁免压不掉逐行扫描已报出的条目** | `:876` 结构化段在 `:747` 逐行路径循环之后；A/B 实测净影响 0 |

### 1.4 修法

1. **豁免判定移到扫描之后**：`apply_retirement_exemptions()` 在 `_collect_untracked` 之后跑，按「值里含该令牌、且首次出现位置离该发现行号最近」把发现归属到 JSON 叶子，再决定是否豁免。
2. **归一化 + 整段相等**：`norm_jpath()` 把数组下标折叠成 `[]`，`_exemption_reason()` 按归一化 jpath **整段相等**匹配（`*` 只在段边界间展开）。两个毛病一起消掉，且不再有段边界连坐。
3. **不再按 `REF_KEYS` 采集**：`json_leaf_index()` 收**全部**字符串叶子 —— 豁免要判的是「这个路径记的到底是什么」，与字段名在不在引用键集里无关。早先只按 `REF_KEYS` 采集，正是 `from`/`old_path`/`note` 压根进不了豁免判定的直接原因。

### 2.1 `§N` 是章节号，不是条款号（五条实测证据）

1. 805 条全量的 `§N` 取值范围 **0–96**（92 个不同值）。
2. **决定性反证：`§0` 出现 4 次**。`ALG-HIPS-001 §0` 的承载文档 `HIPS_WRITER.md:28` 真有 `## 0. 范围界定`。**条款编号不会从 0 起。**
3. 形态学与工具 `SEC_RE`（`^\d+(?:\.\d+)*[a-z]?\.?(?:\s|$)`）逐字同构。
4. 全索引 54 份承载文档的**最大标题号只有 17**。
5. 根因是工具自己 `check_anchors.py:173-175` 记过的坑：「路径修了锚没修」—— `DATA_SEMANTICS.md` 由 §1–§31 重写为 §1–§7，路径全改了、章节号一个没改。

### 2.2 修法：两级，ID 判「登记」、§N 判「章节」，分开定级

- 查表规则**逐字写进代码注释**：只允许 `self.by_id.get(cid)` 一次字典查表。**禁止** `.upper()` / `.lower()` / `.strip()` / `startswith` / 去前导零 / 正则模糊。
- **未覆盖的必须仍报「未登记」，不猜、不用相似编号顶替**。形近实测：无一例大小写差异、无一例前导零差异；裸前缀（`SCI-P3` vs `SCI-P3-001`）87 条里 **2 个多候选**（`ALG-P2-HIPS` 有 4 个、`API-P3` 有 3 个）⇒ 顶替必错。
- **加载失败退化成空表**（文件不存在 / 缺 PyYAML / 解析失败），此时每条都报未登记 —— 工具宁可说不知道。
- 同 id 重复：保留首条并记 `self.dup`，**不替人选**。
- **退役对象的空 path 不报硬缺陷**：`status: OBSOLETE` 且 `path` 为空 ⇒ 无承载文档是退役登记意图（`DATA-OBJ-PSFSW-ROBUST-WEIGHT-001` 正是这一类）。判据用**表自己的 status 字段**，不靠字段名猜。

⇒ 是否升级为硬闸**登记为 UNRESOLVED，见 §7**。
