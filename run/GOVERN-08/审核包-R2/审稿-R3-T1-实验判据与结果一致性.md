## 4. 我主动构造的反例

### 4.1 反例 1（最强）· 构造「覆盖率层出具肯定结论」能否推翻 `frac=0.3` 的 PASS

- **期望推翻什么**：推翻「`prod_verdict=PASS` 足以支撑「这条边没有接缝」」。
- **构造**：取归档自带的无噪/带噪对照臂，配上现行 `seam_gate_coverage.py:191-200` 的 `thr` 公式。带噪臂 `σ_pix=20 @ BG=300`，`thr = max(3·MAD(ctrl), 0.5·gate·bg)`。按 README `:392-393` 的文字值 `ctrl_mad ≈ 22` ⇒ `thr ≈ 66 ADU` ⇒ `detection_floor_rel = 66/300 = 0.22`，是 `gate = 0.01` 的 **22 倍**。
- **算**：真台阶 `12 ADU < 66 ADU` ⇒ 边上前 30%（360 点）的真台阶**一个都进不了覆盖计数**。实测 `cov=0.0075`（9/1200）与 `f=1.0` 那行的 `cov=0.0075`（9/1200）**完全相同** ⇒ 读数已被噪声底接管，与被测台阶无关。零台阶对照 `cov_null=0.005`（6/1200），零假设 `E=6, σ=2.443`，观测 9 ⇒ `z=1.23`，`P(X≥9|Bin(1200,0.005)) = 0.152` ⇒ **不显著**。
- **是否推翻**：**是，完全推翻**。`f=1.0`（全覆盖、4% 台阶）与 `f=0.3`（30% 覆盖、4% 台阶）给出**同一个** `cov`，说明该诊断量在带噪臂已完全失明；而存档仍把它归入 `zone="none"`＝「真无台阶」并**原样保留 PASS**。这不是空判，是**主动出具错误的肯定结论**，直接违反 `README.md:111`。
- **我没能推翻的**：`rel_step` 的门阈判定本身（`0.00917 < 0.01`）是对的——生产门没有误判，错误只发生在覆盖率层。
