### 5.1 ① `seam_gate_coverage.py:172`「测不了」判成「真无台阶」——**已修并注入验证** ✅

**危害等级：全域最高**——这是**主动出具错误的肯定结论**，不是恒真门。

**复现**（`/tmp` 副本逐位复现存档读数）：

```
frac=0.30  真实 4% 台阶(12 ADU)  σ_pix=20
rel_step = −0.0091718     (门阈 0.01 ⇒ 生产 PASS)
cov      = 0.0075 ≤ cov_null_hi
原判决: zone="none"（注释「真无台阶：中位读数 0 是有效结论」）⇒ 原样保留 PASS
```

**根因（实测定量，非推测）**：`cov` 是**逐样本**判据，样本要进入计数须 `|seam−lv| > thr`，
所以幅度为 `a` 的台阶被抓到必须 `a·bg > thr` ⇒ **最小可检相对幅度 = `thr/bg`**。

| 夹具 | `ctrl_mad` | `thr` | 检出限 `thr/bg` | 相对门阈 |
|---|---|---|---|---|
| 无噪 | 0.000 | 1.5 ADU | 0.005 | **0.50×**（比门灵敏 2 倍） |
| 带噪 σ_pix=20 | ≈22 | ≈66–70 ADU | **≈0.22** | **21.6–23.0×**（比门瞎 22 倍） |

⇒ **比门瞎 22 倍的诊断量给出的是「看不见」，代码却写成「没有」。**

**修法**（加前置条件，不是放宽阈值）：

1. `coverage()` 新增 `detection_floor_rel = thr/bg`、`blind_to_gate`、`blind_ratio`；
2. `edge_with_coverage()` 增**第四区 `unresolved`**：`blind_to_gate 且 cov ≤ cov_null_hi` ⇒ 测不了；
3. 新增判决值 **`UNRESOLVED`**——证据不足，**既不计通过，也不谎称有台阶**；
4. `n == 0` 退化分支由 `cov=0.0` 改为 fail-closed 的 `blind_to_gate=True`
   （原先无样本时会因 `0.0 ≤ cov_null_hi` 落进 `none`，是又一处 fail-open）；
5. **顺带纠正反方向**：原实现在 `frac=1.0` 带噪臂上把生产的 `FAIL` 覆盖成 `FAIL_COVERAGE`
   （真实台阶被改记成「覆盖率不足」）。现定优先级 **`FAIL > FAIL_COVERAGE > UNRESOLVED > PASS`**。
