## 1 本轮结论

**需修。** 无「必须停工」级缺陷，但有 **2 条阻断**——它们都落在**验收判据本身不可满足**这一类，不是实现错误；实现侧（面积分档、权重归一、零漏选）经本轮阅读未发现站得住的科学缺陷。

最重的 3 条发现：

### B-1（阻断）面积守恒闭合判据在正本自己强制的最小尺度位置上**恒真失效**

`docs/science/algorithms/DRIZZLE_GEOMETRY.md:350-351` 的逐 drop 判据是
`|Σ_j a_jp − A_drop,p| ≤ max(τ_rel·A_drop,p, ε_abs)`，`τ_rel=1e-6`、`ε_abs=1e-15 sr`。
当 `A_drop ≤ ε_abs = 1e-15 sr` 时，该门**允许 Σ_j a_jp = 0**（即该 drop 的交叠面积 100% 丢失）而判绿。
换算到源像元尺度：`A_drop ≤ 1e-15 sr ⟺ 像元线性尺度 ≤ 0.00652″/px`（pixfrac=1）。
生产侧接受下限是 `A_drop ≥ 1e-20 sr`（`DRIZZLE_GEOMETRY.md:38`、`:217`），**真空带跨 5 个数量级**。

而 `DRIZZLE_GEOMETRY.md:354` 明写位置集「**必须齐备，缺一即门不成立**」，`:365-366` 引的实测端点正是
**0.005″/px**（`A_drop = 5.876e-16 sr`，已在本轮用 `EXP-07-POLAR.md:477` 的表内数字独立核算）。
该位置上相对容差 = `1e-15/5.876e-16 = 1.70`（pf=1）/ `2.66`（pf=0.8）。
⇒ **正本强制覆盖的端点位置，恰好是判据失效的位置。** 规范 04 §3「恒真、空断言…判据判无效」直接命中。

### B-2（阻断）§9 位置集要求的 `nside=2^23` 在生产中不可达，位置集形式上不可满足

`DRIZZLE_GEOMETRY.md:356` 要求位置集含「HST 真实尺度（0.04″/px、**nside=2^23**）」；
`DRIZZLE_GEOMETRY.md:172` 的钳位是 `[NSIDE_MIN, NSIDE_MAX] = [16, 4194304 = 2^22]`，
`drizzle_engine.cpp:726`/`:794` 证实 `NSIDE_MAX = 4194304` 并硬钳位。
`2^23 = 8388608 > 4194304`。且按 `drizzle_engine.cpp:724` 的口径 `nside=2^22 ⇒ hp_res ≈ 0.0503″`，
对 0.04″/px 已是 **1.26× 欠采样**，与 `DRIZZLE_GEOMETRY.md:173-176` 自述的「1–2× 过采样目标」冲突。

### M-A（须修，本轮最强新证据）用来作废正本的那组数字，**自身第三点差 10×**

`实验/healpix-polar/docs/EXP-07-POLAR.md:29` 与 `:494` 两次声称接缝绝对亏空为
「**2.9e-17 / 5.2e-17 / 1.05e-16 sr**（跨 40 倍尺度只变 3.6 倍）」，并据此判 `p ≈ −0.83 ≠ −1`。
本轮用同文件 `:475-477` 的 seam_ref 原表独立核算：

| 档 | A_ref（表内 4 列同值） | A_prod | \|rel\| | 正确绝对亏空 = A_ref·\|rel\| |
|---|---|---|---|---|
| 0.2008″ | 9.477137e-13 | 9.476846e-13 | 3.074e-05 | **2.913e-17 sr** |
| 0.0400″ | 3.760709e-14 | — | 1.383e-03 | **5.201e-17 sr** |
| 0.0050″ | 5.876108e-16 | 5.980505e-16 | 1.777e-02 | **1.044e-17 sr**（非 1.05e-16） |

第三点比文档值**小 10 倍**。改正后绝对亏空为 `2.91e-17 / 5.20e-17 / 1.04e-17`——
**非单调**（先升后降），极值比 5.0× 而非文档所称「只变 3.6 倍」的单调上升。
⇒ 支撑 p=−0.83 的**机制叙述**（「绝对亏空 ∝ A_drop^{+0.17}」）不成立。
**注意：`p=−0.83` 这个数字本身不受影响**（本轮从 `|rel|` 与 `A_drop` 直接重拟合得 −0.849，见 §5），
差 10× 的是它背后的绝对量叙述。

## 3 发现清单

### 3.1 阻断

#### B-1 面积守恒闭合判据在强制端点位置上恒真失效
- **位置**：`docs/science/algorithms/DRIZZLE_GEOMETRY.md:350-351`（判据）、`:354`（位置集必须齐备）、`:365-366`（端点 0.005″/px）、`:38`/`:217`（生产接受下限 `A_drop ≥ 1e-20 sr`）
- **现状**：逐 drop 容差 `max(1e-6·A_drop, 1e-15 sr)`。`A_drop ≤ 1e-15 sr` 时绝对项完全支配，门允许 `Σ_j a_jp = 0`。端点位置 0.005″/px 的 `A_drop = 5.876e-16 sr`（pf=1），相对容差 **1.70**（pf=0.8 时 **2.66**）。判别力崩塌边界 `0.00652″/px`（pf=1）低于端点位置。
- **应为**：判别力必须挂在**有相对判别力的判据**上。可行三条（择一或并行）：① 把位置集的最小端点上移至 `A_drop ≥ 1e-13 sr`（≈0.065″/px），并**明写** 0.005″/px 档「绝对项不可判」而不是声明已覆盖；② 给逐 drop 判据补一条**相对下限**（如 `tol ≤ min(ε_abs, 0.1·A_drop)`，越界即判红）；③ 在该带另立**非闭合类**判据（例如与独立高精度 oracle 的逐叶比对，用 :318-319 已有的 1e-5 相对门），把 :354 的位置集绑到它而不是绑到恒真门。
  **注意**：不能简单收紧 `ε_abs`——`:362-371` 已证明那是**几何/表示地板**，long double 不降，提精度无效（`:370-371` 明写「改变冻结口径，需变更流程」）。
- **证据**：`A_drop = (px/206265)²·pixfrac²`；`0.005″/px → 5.876e-16 sr`，与 `EXP-07-POLAR.md:477` 表内 `A_ref = 5.876108e-16` **逐位吻合**（互证）。真空带下界：生产 `A_drop < 1e-20 sr` 拒绝（`DRIZZLE_GEOMETRY.md:38`）。规范 04 §3「恒真、空断言…判据判无效」。

#### B-2 §9 位置集含生产不可达的 `nside=2^23`
- **位置**：`DRIZZLE_GEOMETRY.md:356` vs `:172`；`lib/algorithms/drizzle/healpix_drizzle/drizzle_engine.cpp:726`、`:794`、`:724`
- **现状**：位置集要求 `nside=2^23 = 8388608`；`compute_auto_nside` 钳位 `NSIDE_MAX = 4194304 = 2^22` 并硬钳。且 `2^22` 下 `hp_res ≈ 0.0503″`，对 0.04″/px 为 **1.26× 欠采样**，`oversample > 1`，与 `:173-176` 自述的判读规则冲突。
- **应为**：三选一并同步正文：① 位置集改为 `nside = 2^22` 并**同时**写明该档为欠采样、其读数不得与「1–2× 过采样」结论混用；② 把 `NSIDE_MAX` 上提到 2^23（属科学口径变更，须走变更流程，且须复核 `nside` 在 `u64`/`int` 上的承载——`HEALPIX_MAPPING.md:18` 允许 order ≤ 29，2^23 在其内）；③ 明确 `2^23` 仅作为**几何门**的位置集参数、绕过 `compute_auto_nside` 直接构造，并在 §3 注明该路径不经钳位。**当前状态是三者的混合：要求了一个自己声明不可产的值。**
- **证据**：`drizzle_engine.cpp:726` `static const int NSIDE_MAX = 4194304;  // 2^22`；`:794` `if (nside > NSIDE_MAX) nside = NSIDE_MAX;`。位置集 `:354` 「缺一即门不成立」⇒ 形式上不可满足。

## 4 反例构造（红队核心）

### X-1（最强）用正本自己的判据 + 正本自己的位置集，构造一个必然通过的空断言

**构造输入**：源像元 0.005″/px、pixfrac = 1.0，位于 `u+v=1` 接缝上（`DRIZZLE_GEOMETRY.md:355` 明列的位置），drop 半张角 `max_angle ≈ 1.71e-8 rad`。
**注入缺陷**：把该 drop 与目标叶的交叠面积 `a_jp` 置 0（等价于**该 drop 的通量 100% 丢失**，一次完全静默的漏累加）。
**代入正本判据**（`:350-351`）：
```
A_drop = (0.005/206265)² × 1.0² = 5.876e-16 sr
容差   = max(1e-6 × 5.876e-16, 1e-15) = max(5.876e-22, 1e-15) = 1e-15 sr
|Σ_j a_jp − A_drop| = |0 − 5.876e-16| = 5.876e-16 sr  ≤  1e-15 sr   ⇒ 判绿
```
**结论**：在正本「必须齐备、缺一即门不成立」所列的端点位置上，**该门无法区分「0.1% 缺陷」与「100% 通量丢失」**。相对容差 1.70（pf=0.8 时 2.66）。判别力崩塌边界 0.00652″/px（pf=1）**低于**端点位置，故端点必落在崩塌区内。
**加固（为什么不能靠别的门兜住）**：
- 帧级门（`:352`，`≤1e-4`，纯相对比值）**不会**兜住——`:323-324` 自认「求和型判据对逐叶错注入无判别力，只作辅判据」；
- 验收主判据 `:318-319`（逐 leaf 1e-5 相对门）**有**判别力，但**没有绑定任何位置集**——位置集（`:354`）绑的是闭合门（`:349-353`）。
⇒ **有判别力的判据不承担强制覆盖，强制覆盖挂在无判别力的判据上。** 这是 B-1 的完整构造。

**目标**：证明 `:1370` 的无条件 VOS 在 `max_angle < 1e-3` 时**不可达**，从而 §35.1 是误报。
**推导**：

2. `:1370` 要求 `tri_inside`（`:1359-1368`）⟸ `center_in_drop`（`:1346-1352`）⟸ **像素中心落在 drop 内**。
3. 若像素中心在 drop 内，则 drop 四角距像素中心 ≤ `dist(中心, drop中心) + max_angle ≤ 2·max_angle`（drop 四角都在 `g.center_d` 的 `max_angle` 球内，drop 凸且含像素中心）。

### X-4 推翻「实验侧实测足以作废正本」—— **成功**

**第一步：查作废证据自身的算术。** 用 `EXP-07-POLAR.md:475-477` 的 seam_ref 原表（表内 4 个参考列同值）核算绝对亏空：
```
0.2008″: 9.477137e-13 × 3.074e-05 = 2.913e-17 sr   （文档 2.9e-17 ✓）
0.0400″: 3.760709e-14 × 1.383e-03 = 5.201e-17 sr   （文档 5.2e-17 ✓）
0.0050″: 5.876108e-16 × 1.777e-02 = 1.044e-17 sr   （文档 1.05e-16 ✗ 差 10×）
```
⇒ 改正后绝对亏空 `2.91e-17 / 5.20e-17 / 1.04e-17`，**非单调**，极值比 5.0×，而文档称「跨 40 倍尺度只变 3.6 倍」（单调上升）。
**第二步：重拟合指数。** 直接用 `|rel|` 对 `A_drop` 做 log-log 最小二乘（不受上一步影响）：**−0.8494 ± 0.1599（1σ, df=1）**，`−1.0` 距拟合值仅 **0.94σ**；拟合残差（ln）为 `[−0.384, +0.682, −0.298]` ⇒ **相对散差 98%**。
⇒ `p = −0.83` 与 `p = −1` 在 1σ 内**不可分辨**，且三点根本拟合不出干净幂律。
**第三步：查该机制的自身诊断。** `EXP-07-POLAR.md:23` 的 T22（RC3，`相对误差 ≈ 2.2e-16/θ_pole²`）：0.028″→3.74e-3、40″→1.41e-6、226″→1.41e-8。
```
0.028″→40″  : θ 比 1429, A 比 2.04e6, rel 比 2652 ⇒ p = ln2652/ln(2.04e6) = −0.543
40″→226″   : θ 比 5.65, A 比 31.9, rel 比 100   ⇒ p = ln100/ln31.9     = −1.330
```
⇒ **同一机制在两个子区间给出 −0.54 与 −1.33。** 该关系不是幂律。
**第四步：查操作收益。** 正本 `:375` 的阈值「`A_drop ≲ 1e-9 sr` 一律以绝对项判」= `τ_rel·A_drop ≤ ε_abs` = `1e-6 × A_drop ≤ 1e-15 ⟹ A_drop ≤ 1e-9 sr`。**该阈值与指数无关**，p 取 −0.83 还是 −1 都得出同一阈值。
⇒ **作废该句没有任何操作收益；且作废所依据的证据本身有 10× 算术错、指数在 1σ 内不可分辨、机制诊断自相矛盾。** M-2 的裁决方向由此确定。

### X-5（正例性反例）检验「切平面 vs VOS 跨档不连续」的量级是否真的够格成为缺陷
在档边 θ=1e-3 rad：切平面单向下偏 `−5.0e-7`，VOS 噪声按 `exp_sim01:224-227` 的机理为 `~1e-16/θ² = 1e-10`（而非代码注释 `:1009-1011` 的 `1e-4~5e-5`）。
⇒ 按实验侧机理，档边处 VOS 噪声（1e-10）**低于**切平面系统偏差（5.0e-7）一个量级；此时切平面分支并非「更准」，而是「用 5.0e-7 的确定偏差换掉 1e-10 的随机噪声」。
这条**不构成缺陷**（5.0e-7 低于 :351 的 τ_rel=1e-6，方向恒负、可作系统项扣除），但它说明 **`:1009-1011` 的噪声归属若不订正，「必须保留切平面分支」的论证基础就是错的**——论证应改为「以可预测的单向系统偏差替代不可预测的随机噪声」。⇒ 升级为 A-5。
