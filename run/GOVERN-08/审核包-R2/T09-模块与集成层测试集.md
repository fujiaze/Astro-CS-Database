| 量类 | 冻结取值 | 来源 | 本单落点 |
|---|---|---|---|

| 归约 | `γ_n = n·u/(1−n·u)`，门限 `C·γ_n·Σ|terms| + atol`，`C ≤ 4` | `TEST.md:49`、`:64` | `PΣPᵀ` 对拍 |
| 并行等价 | 上述三档；整数/掩膜/索引/计数/端口精确一致 | `TEST.md:50` | 本单未涉及（需真实调度） |

**单位舍入 `u`**（`TEST.md:58-59`）：binary64 = `2⁻⁵³` = `1.1102230246251565e-16`；binary32 = `2⁻²⁴` = `5.9604644775390625e-08`。
⚠️ `TEST.md:61` 逐字警告「混用（f64 数据按 f32 的 `u` 判）把门限放宽约 `2²⁹` 倍，属判据失效」；`TEST.md:62` 逐字「`n` 取该次归约的**实际项数**，不是数据总像素数」——两条均已在归约判据中显式实现。

**可满足性下限**（`TEST.md:73`）：绝对容差只有在 `atol ≥ 1 ulp(scale)` 时才可判，冻结绝对容差必须同时声明适用量级域 `scale`。
⇒ 每条数值判据断言前显式检查该下限（`test_variance_propagation.py` A7/A8）。

**NaN/Inf 语义**（`TEST.md:75-83`）：非有限值与缺失的**位置集合**逐项精确一致；「缺失」是与 NaN **并列的第三态**，不得由 NaN 兼表；比较器不得把非有限值折叠成 `0` 或哨兵值；非有限值**不受**三档浮点容差约束。

### 3.1 容差非装饰的自证

集成层代理发现：用小整数做注入时残差**恒等于 0**，归约档门限从未被触发 ⇒ 容差表在该条上退化成装饰
（违反 `TEST.md:26`「恒真的比较没有证据资格」）。处置：另加**不可精确表示**的第二组注入值
（`0.1`、`1/3`、`7/11`、`e`、`13/7`、`101/17`、`1e-3`），实测最大残差 `2.220e-16`（相对 `3.346e-16`），
实测/门限最紧处 `0.003`，并断言 `worst > 0`，否则判「容差退化成装饰」红。

### 7.5 「子集语义」为什么让 n2 仍然有效

A2 用 `hit_expectations(errors, must_match)` 判定，语义是**子集**（只要求 `must_match` 命中，不要求错误集恰好相等）。
n2（target schema = `variance`）除本来的违规外还会多报一条 `/correlation_kernel[required] missing='oracle_ref'`（见 §9-1）。
**这不影响 n2 的有效性**：判红理由由 `must_match` 的 3 个指针决定，额外错误与之无关。
docstring 已显式钉住该语义，并有守护断言 `len(hit) == len(must_match)` 防止 0 命中蒙混。

### 7.6 一个自曝的退化（由判据 A4 抓出，值得记）

集成层代理第一版自研校验器把 `if`/`not`/`anyOf` 子模式的错误混进主错误表，且**子模式失败不向上传播布尔值**，
导致「条件为假时 `then` 分支照样报错」，14 个正例里 13 个各带 15–21 条**假错误**。
**这条退化正是 `A4 ValidatorSelfCheckNonVacuous` 防的那一类，由 A4 抓出来**（`VALIDATION_EVIDENCE.md:193` S6 的实证价值）。
