**⇒ 门禁设计的边界结论（必须写进设计）**：
- 可选门禁**不得**对「文档一致性 / 文档写法 / 文档索引 / 锚存活」四面产出机器 PASS/FAIL（B1+B2+B3 三处正本条款正面约束）；

- 这条区分**不是**本件的裁量，而是负责人裁定第 丙 条已经划定的边界。可选门禁的输出物是**缺漏登记**，不是**判决**。
