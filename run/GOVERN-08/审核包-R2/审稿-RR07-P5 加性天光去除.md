### 阻断-2 权威顶点规定的 P5 定权 `w = 1/σ_F²` 是一个**没有指称对象**的陈述；正本不仅未定义它，还**明文禁止**它

- `docs/ACSD_DESIGN.md:156`：「P1 已统一信号平面、P2/P4 已给出稠密精确信噪比，因此**天光平面拟合与叠加定权使用逆方差权重 `w = 1/σ_F²`**」。
- 而 P5 正本 `docs/science/PHASE2_UPM.md:80` 用的是 `w_UPM = quality_factor × control_reliability × control_ivar`，`control_ivar = 1/(k_corr·(π/2)·σ_bg²/N_retained)`（`UNCERTAINTY_AND_COVARIANCE.md:42-43`）。二者不是同一量。
- **本人逐字核实的四条独立反证**（使本条从「公式冲突」升级为「陈述无指称」）：
  1. **σ_F 在天光采样点上不存在**：采样点在星点掩膜之外（`ACSD_DESIGN.md:157`「星点掩膜之外每帧取稀疏背景采样点」），该处没有星，故没有 σ_F；且 `docs/science/CONTROL_WEIGHT_SNR.md:44` 明写 `sigma_F` = 「逐源通量不确定度（…PSF 拟合协方差或 CCD 方程，**当前实现不产出**）」。
  2. **正本明文禁止**：`docs/science/PHASE2_UPM.md:123`「`# 禁 production 乘 star SNR / snr²/(1+snr²) / support^p；support 仅 eligibility/coverage`」；`:292` 列入「§10 不可接受变化」。`UPM_SOLVER.md:17` 与 `PHASE2_UPM_IMPL.md:167` 逐字重复该禁令。
  3. **量纲差 22 dex**：σ_F 是 ADU（`CONTROL_WEIGHT_SNR.md:120`）⇒ `1/σ_F²` = ADU⁻²；而全链权重面是 (ADU·sr⁻¹)⁻²。`PHASE2_SAMPLER.md:80-85` 自己量化了这个坑：「按 ADU·sr⁻¹ 标度换算（因子 Ω_px² = 5.2859e-22）…**若单位为裸 ADU，推出值应为 0.594，与生产实测相差 22 dex**」。
  4. **P5 自己的实验判定 SNR² 臂更差**：`PHASE2_UPM.md:384`「`control_ivar` 臂的伪影漏入与噪声 RMS 均为三臂最小（`uniform` 与 `SNR²` 两臂更大）」。
- **顶点自身下一行已自我否定**：`:157`「星点掩膜之外每帧取稀疏背景采样点，**采样点带噪声逆方差权重**」。`:156` 与 `:157` 在同一节内互斥。
- 按 AGENTS.md §3 权威链，最高设计为准 ⇒ **但这不是可对齐的漂移，是缺失的定义**：正本从未写过 SNR 加权的定义，只写了禁令。**没有第二份文档可以拿来对齐。**

## 4. 反例构造（本人主动构造，用于推翻现行结论）

### R1（对阻断-3）几何反例：门测不到定义它自己分辨率的那条带

设某产品的法向重叠带宽 `W`、指向间距 `P`（均以像素计）。

- 正本规则 2（`PHASE2_UPM.md:222-224`）给出 `h ≤ min(W, P)/2`，故失效肘点 `2h ≤ min(W, P)`。
- 接缝门要求 `margin_px ≥ ctrl_shift = 200 px`，两侧合计即法向带宽 `W ≥ 399 px`（`seam_footprint.py:83-86` + `README.md:352` 实测阶梯：200/64/20 ⇒ 排除，399/400/401/800 ⇒ 计入）。
- 故障域 = 「`2h ≤ min(W,P)`」；测盲域 = 「`W < 399 px`」。

**构造**：取完全普通的镶嵌几何 `W = P = 300 px`。

- 规则 2 ⇒ `h ≤ 150 px`，肘点 `2h = 300 px`（失效最强的尺度）。
- 门 ⇒ `W = 300 < 399`，**该产品的每一条足迹边界都是 `not_interior`，无一条进入判据**。
- ⇒ 定义 h 的那个量（重叠带宽度）恰好落在门不测的区间；「叠加天然无接缝」在该产品上**没有任何判决面**。

**为什么现行结论扛不住**：`PHASE2_UPM.md:504` 把这条规则表述为「足迹外缘或贴数据边界的边界不进判据」，读者会当成「极边缘情形」；而 300 px 的重叠带是常规 mosaic dither 的产物，不是边缘。两条正本条款（§7a 规则 2 与 §17 适用域）**从未交叉引用**，`ctrl_shift` 的 399 px 阈值也从未进正本。

**公平性说明**：门在 `W < 399 px` 时**不判绿**，它声明「未测量」（`seam_footprint.py:357-360` 的 `exclude` 语义、`README.md:352-354` 明写「不得读作这条边没有接缝」）。所以本反例**不是**指控门造假，而是指控：**P5 的交付主张「无接缝」在 W < 399 px 的产品上无法兑现，而这一点没有任何正本条款告知下游**。修法是补正本，不是改门。

### R2（对阻断-1）构造：门对 P5 自身特征失效的衰减，把头条比值压掉一个量级

- 门是法向 ±d（d = 2 px）一阶差分。`PHASE2_UPM.md:498-500` 漏检面 ③ 已自陈：对过渡宽度 `w > 2d` 的平滑接缝，**只看到 `Δ·2d/w`**，等效门限抬高 `w/2d` 倍。
- P5 的残余接缝**按构造就是平滑的**：它来自「`B_ref` 不可表示且沿向相干」的分量（`PHASE2_UPM.md:213`），A10 夹具注入的波长是 1600/800/400/200/100/50 px（`README.md:151-155`）——**七个点全部 ≫ 2d = 4 px**。
- 于是残余接缝的**真实幅度 = 度量值 × w/(2d) = 度量值 × w/4**。

代入头条：`w = 50 px ⇒ ×12.5`、`w = 100 px ⇒ ×25`、`w = 200 px ⇒ ×50`、`w = 1600 px ⇒ ×400`。

而头条 12.5× 比较的是「未校正 4.80 e⁻（锐利，覆盖子集突变是突变）」与「残余 0.383 e⁻（平滑）」——**两者用同一个只对锐利阶跃忠实的度量**。在 w = 50 px 处，残余真值可放大到 `0.383 × 12.5 = 4.8 e⁻`，**恰等于未校正接缝本身**，即「12.5× 压缩」在该尺度上可整体消失。

**为什么这是构造而非猜测**：两个输入都是仓内明文（③ 是正本自陈的漏检面；波长带是 P5 自己的 A10 表），我的贡献只是指出**这两条从未被相乘**。§17.3 的 ③ 谈的是「权重斜坡/羽化平滑过的接缝」，其物理来源被限定为羽化；P5 的平滑残余来源是天空场的不可表示分量，机制不同但形状相同，正本未做这一推广，也未声明不推广。

**这条反例不能单独定 BLK-1 的级**——它需要一个夹具把残余接缝的宽度独立指定出来才能定量（这与 `README.md:386-390` 已登记的未决项同源）。但它足以说明：头条 12.5× 在 `w = 50 px` 处不是稳健结论，而 12.5× 已被写进 `PHASE2_UPM.md:220`。

### B2 k_gauss 口径复算（本人独立，未先看任何文档判定）

做法：只读 `实验/healpix-polar/results/audit/kcorr/{direct_char,g3b_gauss_ref}.json` 的原始数值，自行检验是否存在能把 1.6370 与 1.6620 同时算出来的统一公式。

```
direct_char.json n=5: var_over_asymptotic = 0.911253585449302
                      median_MAD_scale   = 0.7460866525726195
重算 va/mad²                       = 1.6370453440780806
文件所载 k_gauss                    = 1.6370453440780806   → 16 位逐位吻合

g3b_gauss_ref.json n=5: sigma_bg = 7.406225070115457（即 σ̂/σ = 0.74062）
用同一公式 va/(σ̂/σ)²  = 0.911253585449302 / 0.7406225070115457²
                      = 1.6612899525236469
文件所载 k_corr       = 1.661965273147573 → 相对差 0.041%
```

**判读**：两个文件用**同一个公式**
`k_gauss(N) = [Var(median) / ((π/2)σ²/N)] ÷ [median(MAD)/σ]²`。
该式在解析上**必须**含 MAD 因子，不可能由任何「纯 iid 参考」给出。纯 iid 值是 `1/var_over_asymptotic = 1.0974`（与 `REPORT_experiment.md:64` 的精确积分 1.0953 一致），与 1.637 相差 **1.494×**。

进一步，两个同口径读数的差是纯 MC 噪声：1.6620 来自 nmc=4000，1.6370 来自 nmc=400000；`tables.md:9` 给出 3×40000 的 MC SE = 0.007 ⇒ nmc=4000 的 SE ≈ 0.022；实测差 0.0250 ≈ **1.1σ**。
