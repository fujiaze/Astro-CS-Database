## 2. 必修 1：两条自我重复引用（本车道引入的缺陷）

### 2.1 复核指出的现象

`docs/DOCUMENT_INDEX.yaml` 两条登记的 `upstream` 现值都是
`docs/ACSD_DESIGN.md §0（文档权威与索引）、§0（文档权威与索引）`——同一引用写两遍，
`§0.1` 槽位被静默丢弃。C4 对「重复引用」结构性无感（两个 ref 各自合法），五条判据全看不见。

### 2.2 去 `docs/ACSD_DESIGN.md` 确认 `§0` 与 `§0.1` 的真实标题与职责分工

| 节号 | 真实标题 | 位置 | 职责 |
|---|---|---|---|
| `§0` | **文档权威与索引** | `docs/ACSD_DESIGN.md:5` | 权威链、冲突裁定、每份下级文档标注上游、双向可追溯、唯一索引地图（`:24`、`:27`、`:28`） |
| `§0.1` | **文档写法** | `docs/ACSD_DESIGN.md:33` | 只写现行设计、退役设计不进文档、引用格式（`:35`-`:37`） |

**HEAD 原值两处都更差，不予恢复**：

- `§0.1（唯一权威链）`——`唯一权威链` **不是** `§0.1` 的标题（真标题是 `文档写法`）；
- `§0.2（详细文档层与双向索引）`——`§0.2` **在 HEAD 的 `docs/ACSD_DESIGN.md` 里根本不存在**
  （`git show HEAD:docs/ACSD_DESIGN.md | grep '^#\{2,3\} 0'` 只有 `:5 ## 0. 文档权威与索引` 与 `:31 ### 0.1 文档写法`）；
  `详细文档层与双向索引` 同样不是任何真实标题。

所以「唯一权威链 → §0.1」与「详细文档层与双向索引 → §0.2」这两个 HEAD 括注是**杜撰标题**，
第一轮把节号改指到真实章节的**方向是对的**，错的只是把两槽都塌成了同一个 `§0`。

### 2.3 正确 upstream 判定

两份文档各自确有两个**互不重叠**的上游义务，因此**恢复 `§0.1` 槽位**而不是并成一槽：

- `AGENTS.md`：`§3 权威文档链`（读文档顺序、上层优先）→ `§0`；`§5 文档维护`（只写现行设计／无元信息块／论文引用格式／每目录 README）逐条对应 `§0.1` 的三个 bullet → `§0.1`。

**新原文（两处逐字相同，与仓内既有双槽惯例一致：`docs/DOCUMENT_INDEX.yaml:3`、`:60`）：**

```yaml
      upstream: "docs/ACSD_DESIGN.md §0（文档权威与索引）、§0.1（文档写法）"
```

落点：

| 位置 | 文件:行 |

| `AGENTS.md` 登记 | `docs/DOCUMENT_INDEX.yaml:74` |
| `docs/engineering/PROJECT_SPEC.md` 登记 | `docs/DOCUMENT_INDEX.yaml:792` |

### 3.1 根因

v1 的判定是 `fired = not c.get("ok")`（交付件 `:590`）——**只看绝对状态，不看增量**。
凡基线本就红的判据，这个判定必然输出「红 ✓」，与注入是否生效无关。

## 5. 必修 4：C4 剩余数的口径与真实漏检

### 5.1 v1 的两处结构性盲区

| 盲区 | v1 写法 | 后果 |
|---|---|---|
| 固定字符窗 | `read(...)[:4000]` 当「抬头」 | 抬头不是位置近似。`docs/science/DATA_SEMANTICS.md:3341` 的「上游：」行落在窗外，7 个裸节号一条红都不进 |
| 预筛比解析器窄 | `re.search(r"ACSD_DESIGN\.md\s*§", ...)` | ① 反引号包裹的 `` `docs/ACSD_DESIGN.md` §0/§1 `` 整类漏掉——**复核点名的那一行正是这一类**，窗口再大也扫不到；② `ACSD_DESIGN.md 附录 A（术语）` 这种不带 `§` 的合法引用形态整类漏掉 |

实测（全量 186 份 docs 文档）：

| 预筛 | 命中处数 | 命中文件数 |
|---|---|---|
| v1 `ACSD_DESIGN.md §` | 168 | 149 |
| v2 `ACSD_DESIGN.md`（与解析器接受面对齐） | 409 | 172 |

窗口 + 预筛两项合计，v1 对 **121 处**落在 4000 字符之后的高价值引用结构性无感。

**但复核方「全量 168 处引用中有 8 处落在窗外」这个统计本身是用 v1 的窄预筛做的**，
所以 8 只是「v1 口径下的窗外数」，不是真实漏检面。按 v2 口径重扫，
`docs/science/DATA_SEMANTICS.md` 一份就有 22 处待判（复核方按窄预筛只数到 4 处）。

### 5.2 修法

- 扫描面：**全文**，不设固定字符窗；
- 预筛：只要求行内出现 `ACSD_DESIGN.md`，与 `parse_design_refs()` 的接受面**对齐**；
- 行守卫：去掉 `"§" not in line`，附录形态 `附录 A（术语）` 不再被排除；
- **另修一处解析器作用域缺陷**（复核未列，本轮自检时暴露）：片段内一条引用枚举只允许被
  `、，,;；/` 续写，遇别的字符即断。现场反例 `docs/science/DATA_SEMANTICS.md:1216` 的
  「（ACSD_DESIGN.md §2.1）；…配置中出现该键 ⇒ 拒绝（§31.8）」，那个 `§31.8` 是
  DATA_SEMANTICS **自己**的节，不加断点会被算成「最高设计无 §31.8」的假红。
  修后「节号悬空」从 12 条降到 8 条，4 条假红消除。

# C3：能检出重复键的 YAML Loader（yaml.safe_load 单独使用会静默吞并重复键）
# ---------------------------------------------------------------------------
class DuplicateKeyError(Exception):
    pass


def load_yaml_strict(text: str):
    """返回 (data, dup_list)。dup_list 元素 = (mapping 路径, 键, 首值行号, 末值行号)。

    实现要点：SafeLoader 默认的 construct_mapping 是 `dict[k] = v`，重复键末值静默覆盖首值。
    这里改成先扫节点内所有 (key_node, value_node) 对，命中重复即记录并报出两侧行号，
    再按 PyYAML 语义（末值胜）构造数据，保证返回结构与 safe_load 一致、只多出重复键报告。
    """
    import yaml

    class StrictLoader(yaml.SafeLoader):
        pass

    dups: list[tuple[str, str, int, int]] = []

    def _construct_mapping(loader, node, deep=False):
        seen: dict[str, tuple[int, object]] = {}
        for key_node, value_node in node.value:
            key = loader.construct_object(key_node, deep=deep)
            if key in seen:
                first_line = seen[key][0]
                dups.append((_node_path(loader, node), str(key), first_line,
                             key_node.start_mark.line + 1))
                # 末值胜：与 PyYAML 原行为一致
                loader.construct_mapping(node, deep=deep)
            else:
                seen[key] = (key_node.start_mark.line + 1, value_node)
        return yaml.SafeLoader.construct_mapping(loader, node, deep=deep)

    def _node_path(loader, node) -> str:
        # 尽力给出映射的可读位置；拿不到就退回行号
        return f"<mapping@line {node.start_mark.line + 1}>"

    StrictLoader.add_constructor(
        yaml.resolver.BaseResolver.DEFAULT_MAPPING_TAG, _construct_mapping)
    data = yaml.load(text, Loader=StrictLoader)
    return data, dups

def design_sections(design_text: str) -> dict[str, str]:
    """节号 -> 标题。覆盖 ## / ### 两级；附录按「附录 A」「附录 B」分别建键，
    否则两个附录会塌成同一个键而少计一节。"""
    out: dict[str, str] = {}
    for line in design_text.splitlines():
        m = re.match(r"^(#{2,3})\s+(.*)$", line)
        if not m:
            continue
        rest = m.group(2).strip()
        ap = re.match(r"^(附录\s*[A-Z])\.?\s+(.*)$", rest)
        if ap:
            out[ap.group(1).replace(" ", "")] = ap.group(2).strip()
            continue
        num, _, title = rest.partition(" ")
        num = num.rstrip(".、")
        title = title.strip()
        if num:
            out[num] = title
    return out


def norm_title(s: str) -> str:
    """去空白后逐字比较（§4.5）。"""
    return re.sub(r"\s+", "", s or "")


# 扫描面预筛：只要求行内出现文档名本身。
# v1 用 `ACSD_DESIGN\.md\s*§` 预筛，比 parse_design_refs 的实际接受面更窄，于是
#   (a) 反引号包裹的路径 `` `docs/ACSD_DESIGN.md` §0/§1 `` 整类漏掉——现场
#       docs/science/DATA_SEMANTICS.md:3341 的「上游：」行带 7 个裸节号，一条红都不进；
#   (b) `ACSD_DESIGN.md 附录 A（术语）` 这种不带 § 的合法引用形态整类漏掉。
# 预筛必须 ⊇ 解析器接受面，否则判据对自己能解析的东西结构性无感。
DESIGN_MENTION_RE = re.compile(r"ACSD_DESIGN\.md")
# 两种合法引用形态：§8.4（顶层结构）与 附录 A（术语）。
# 数值节号必须带 § —— 否则正文里的 "MSVC v143" 之类裸数字会被误读成节号。
_NUM = r"\d+(?:\.\d+)*(?:\s*/\s*§?\s*\d+(?:\.\d+)*)?"
_SEC_HEAD_RE = re.compile(
    r"(?:§\s*(?P<num>" + _NUM + r")|附录\s*(?P<apx>[A-Z]))"
)


def _balanced_title(text: str, start: int):
    """从 start（指向「（」）起按全角括号配平取出标题，返回 (标题, 结束位置)。

    最高设计 §5.4 的真实标题是「天光平面（UPM）」，本身含全角括号；
    非配平的正则会把它截成「天光平面」，导致逐字比对假红。
    """
    if start >= len(text) or text[start] != "（":
        return None, start
    depth = 0
    for i in range(start, len(text)):
        if text[i] == "（":
            depth += 1
        elif text[i] == "）":
            depth -= 1
            if depth == 0:
                return text[start + 1:i], i + 1
    return None, start


def parse_design_refs(upstream: str) -> list[tuple[str, str | None]]:
    """从 upstream 串中抽出指向最高设计的 (节号, 括注标题|None)。

    两种路径形态都算：带 `docs/` 前缀与裸名 `ACSD_DESIGN.md`。裸名在 docs/ 内是正确写法
    （DOCUMENT_GOVERNANCE.md §4.1.2「裸名 ACSD_DESIGN.md 在 docs/ 外带 docs/ 前缀、
    在 docs/ 内保持裸名」），只认带前缀的形式会漏掉整片抬头。

    只取从 ACSD_DESIGN.md 起到下一个文档路径引用为止的片段，避免把
    docs/science/... §1 这类指向别的文档的节号误判为最高设计节号。

    片段内还要再断一次：一条引用枚举（§0/§1/§2、§0（标题）、§0.1（标题））只允许被
    分隔符 、，,;；/ 续写。遇到别的字符就停。现场反例——docs/science/DATA_SEMANTICS.md:1216
    的「（ACSD_DESIGN.md §2.1）；…配置中出现该键 ⇒ 拒绝（§31.8）」，那个 §31.8 是
    DATA_SEMANTICS 自己的节，不是最高设计的；不加这道断点会被算成「最高设计无 §31.8」
    的假红。断点只在分隔符处放行，散文中间的裸节号一律不认。
    """
    refs: list[tuple[str, str | None]] = []
    parts = re.split(r"(?=(?:docs|eng|lib|artifacts|实验|testdata)/[\w./-]*[\w/])",
                     upstream)
    for part in parts:
        mm = re.search(r"(?:docs/)?ACSD_DESIGN\.md", part)
        if not mm:
            continue
        seg = part[mm.end():]
        pos = 0
        while True:
            m = _SEC_HEAD_RE.search(seg, pos)
            if not m:
                break
            # 跳过 § 与节号之间的空白
            tpos = m.end()
            while tpos < len(seg) and seg[tpos] in " \t":
                tpos += 1
            title, nxt = _balanced_title(seg, tpos)
            if title is None:
                nxt = m.end()
            if m.group("apx"):
                base_nums = ["附录" + m.group("apx")]
            else:
                base_nums = [n.strip() for n in re.split(r"\s*/\s*§?\s*", m.group("num"))]
            for n in base_nums:
                refs.append((n.replace(" ", ""), title))
            pos = nxt
            # 只有被分隔符续写的下一条 § 才继续算同一组引用
            k = pos
            while k < len(seg) and seg[k] in " \t":
                k += 1
            if k >= len(seg) or seg[k] not in "、，,;；/":
                break
            pos = k
    return refs

def header_region(text: str) -> str:
    i = text.find("\n## ")
    return text if i < 0 else text[:i]


def read_doc(root: str, rel: str) -> str:
    """读文档正文；读不到返回空串。

    文档侧扫描面必须对「索引里有、磁盘上已删」的文件容错——那正是 C1 要报的缺陷，
    不该在这里抛异常把整轮判据打断。索引与最高设计两个**输入面**仍是 fail-closed
    （缺文件在 run_checks 开头就判红），这里只是扫描面的读取不许崩。
    """
    try:
        return open(os.path.join(root, rel), encoding="utf-8").read()
    except OSError:
        return ""


def design_ref_set(text: str) -> set[tuple[str, str | None]]:
    """一段文本里出现的全部最高设计引用，归一化成可比对的 (节号, 标题) 集合。"""
    out: set[tuple[str, str | None]] = set()
    for line in text.splitlines():
        if not DESIGN_MENTION_RE.search(line):
            continue
        for num, title in parse_design_refs(line):
            out.add((num, norm_title(title) if title is not None else None))
    return out


def design_num_set(text: str) -> set[str]:
    """一段文本里出现的全部最高设计**节号**集合（不含标题）。

    同源判据只比节号集合：两侧引的是同一个 §、但把标题写歪了，那是双要素判据
    （标题错位）的活，已经单独判红。同源判据只负责**结构性**分歧——两侧指向的
    节根本不是同一批（抬头多给一条 / 少给一条）。两件事都报会把一条缺陷记两次。
    """
    out: set[str] = set()
    for line in text.splitlines():
        if not DESIGN_MENTION_RE.search(line):
            continue
        for num, _title in parse_design_refs(line):
            out.add(num)
    return out


# ---------------------------------------------------------------------------
# duty 退化（§索引抬头规则 1：duty 字段语义是「职责一句话」）
# v1 只认「逐字等于自身路径」且只认带双引号的写法，两处都过窄：
#   · 写成不带引号的 YAML（duty: docs/foo.csv）→ 文本正则要求 `"`，整类漏检；
#   · 写成 duty: "本文件"                        → 判据只比字面路径，语义退化整类漏检。
# ---------------------------------------------------------------------------
DEGENERATE_DUTY_SELF = {
    "本文件", "本文", "本文档", "本件", "本说明书", "自身", "自身路径", "自己", "自己路径",
    "同上", "见上", "见本文", "如上", "self", "thisfile", "thisdocument", "sameasabove",
    "n/a", "na", "none", "null", "nil", "tbd", "todo", "-", "—", "无", "空", "待补",
}
# 裸路径样（无空格、无 CJK、含 / 或文档扩展名）⇒ 只登记了位置，没写职责
_BARE_PATH_RE = re.compile(r"^[A-Za-z0-9_.\-+]+$")
_DOC_SUFFIX = (".md", ".rst", ".txt", ".yaml", ".yml", ".csv", ".json")


def _unquote_scalar(raw: str) -> str:
    """取 YAML 标量的字面值：带引号去引号，不带引号的去掉行尾注释。"""
    s = raw.strip()
    if len(s) >= 2 and s[0] == s[-1] and s[0] in "\"'":
        return s[1:-1].strip()
    return re.split(r"\s+#", s, maxsplit=1)[0].strip()


def duty_degenerate_reason(value: str, own_path: str | None) -> str | None:
    """duty 退化的成因；不退化返回 None。"""
    v = value.strip()
    if not v:
        return "duty 为空"
    nv = re.sub(r"\s+", "", v)
    if own_path and nv == re.sub(r"\s+", "", own_path):
        return f"duty 直接写成自身路径「{own_path}」"
    if own_path and nv in (re.sub(r"\s+", "", own_path).lstrip("./"),
                           re.sub(r"\s+", "", own_path).rsplit("/", 1)[-1]):
        return f"duty 写成自身路径（去前缀形态）「{v}」"
    if nv.lower() in DEGENERATE_DUTY_SELF:
        return f"duty 退化为自指代词「{v}」，未描述职责"
    if _BARE_PATH_RE.match(v) and ("/" in v or v.lower().endswith(_DOC_SUFFIX)):
        return f"duty 是裸路径「{v}」，未描述职责"
    return None

def run_checks(root: str) -> dict:
    res: dict = {"root": root, "checks": {}}

    index_rel = "docs/DOCUMENT_INDEX.yaml"
    design_rel = "docs/ACSD_DESIGN.md"
    contracts_rel = "docs/contracts/INDEX.yaml"

    tracked = set(tracked_files(root))
    reports: dict[str, dict] = {}

    # ---------------- fail-closed 前置 ----------------
    missing_inputs = [p for p in (index_rel, design_rel, contracts_rel)
                      if p not in tracked]
    if missing_inputs:
        res["checks"] = {k: {"ok": False, "error": f"输入面缺失: {missing_inputs}"}
                         for k in ("C1", "C2", "C3", "C4", "C5")}
        return res

    index_text = open(os.path.join(root, index_rel), encoding="utf-8").read()
    design_text = open(os.path.join(root, design_rel), encoding="utf-8").read()

    # ---------------- C3：映射键唯一（先跑，其余判据依赖解析结果） ----------------
    try:
        index_doc, dup_keys = load_yaml_strict(index_text)
    except Exception as e:  # fail-closed
        res["checks"] = {k: {"ok": False, "error": f"索引解析失败: {e}"}
                         for k in ("C1", "C2", "C3", "C4", "C5")}
        return res

    di = (index_doc or {}).get("doc_index") or {}
    active_entries = di.get("active") or []
    archived = di.get("archived") or []
    entries = [("active", i, e) for i, e in enumerate(active_entries)]
    entries += [("archived", i, e) for i, e in enumerate(archived)]

    def ent_path(e):
        return (e or {}).get("path")

    reports["C3"] = {
        "name": "yaml-mapping-unique",
        "ok": not dup_keys,
        "detail": f"active 条目 {len(active_entries)} 条，archived 条目 {len(archived)} 条；"
                  f"检出重复映射键 {len(dup_keys)} 处",
        "violations": [
            {"where": f"docs/DOCUMENT_INDEX.yaml:{dl}", "issue":
                f"重复映射键「{k}」：同一条目内首值在第 {fl} 行，被第 {dl} 行的值静默覆盖"
                f"（PyYAML 末值胜 ⇒ 首值被吞并）",
             "key": k, "first_value_line": fl, "duplicate_value_line": dl}
            for (w, k, fl, dl) in dup_keys
        ],
    }

    # ---------------- C1：索引 path 无悬空 ----------------
    v = []
    for zone, i, e in entries:
        p = ent_path(e)
        if not p:
            v.append({"where": f"DOCUMENT_INDEX.yaml doc_index.{zone}[{i}]",
                      "issue": "条目无 path 键", "path": None})
            continue
        if p not in tracked:
            v.append({"where": f"DOCUMENT_INDEX.yaml doc_index.{zone}[{i}]",
                      "issue": "path 悬空：不在 git 跟踪集内", "path": p})
        elif not os.path.exists(os.path.join(root, p)):
            # 跟踪集 ∩ 工作树实存，两个条件缺一不可。只取 git ls-files 的话，
            # 「文件从磁盘删掉但索引里还留着」（未 git rm）会被判绿——索引指向一个
            # 谁也读不到的路径，索引与文件树的一致性（§4.1.4）就已经破了。
            v.append({"where": f"DOCUMENT_INDEX.yaml doc_index.{zone}[{i}]",
                      "issue": "path 悬空：在 git 跟踪集内但工作树磁盘上不存在"
                               "（文件已删未 git rm，或检出不完整）", "path": p})
    # path 全索引唯一
    seen: dict[str, list[str]] = {}
    for zone, i, e in entries:
        p = ent_path(e)
        if p:
            seen.setdefault(p, []).append(f"{zone}[{i}]")
    for p, locs in seen.items():
        if len(locs) > 1:
            v.append({"where": ", ".join(locs), "issue": f"path 在索引内重复登记 {len(locs)} 次",
                      "path": p})
    reports["C1"] = {
        "name": "index-path-alive",
        "ok": not v,
        "detail": f"登记条目 {len(entries)} 条，判红 {len(v)} 条",
        "violations": v,
    }

    # ---------------- C2：文件树无漏项 + 非空 upstream ----------------
    # 文档层对象：docs/ 下的 .md/.rst/.txt（DOCUMENT_GOVERNANCE.md §4.2 文档层）
    DOC_EXT = (".md", ".rst", ".txt")
    doc_layer = sorted(p for p in tracked
                       if p.startswith("docs/") and p.lower().endswith(DOC_EXT))
    indexed_paths = {ent_path(e) for _, _, e in entries if ent_path(e)}

    excl_re = re.compile(EXCLUSIONS[0]["pattern"])
    excluded = [p for p in doc_layer if excl_re.match(p)]
    judged = [p for p in doc_layer if not excl_re.match(p)]

    v = []
    for p in judged:
        if p not in indexed_paths:
            v.append({"where": p, "issue": "文件树漏项：跟踪集内文档未登记进索引", "path": p})
    # 非空 upstream（全登记面；最高设计自身在索引里显式写明无上游，文本非空即合规）
    for zone, i, e in entries:
        up = (e or {}).get("upstream")
        p = ent_path(e)
        if up is None or not str(up).strip():
            v.append({"where": f"DOCUMENT_INDEX.yaml doc_index.{zone}[{i}]",
                      "issue": "upstream 缺失或为空（双向可追溯断链）", "path": p})
    # duty 退化：duty 写成自身路径或自指代词 ⇒ 等于没有职责描述。
    # 必须按**文本**逐行取 duty，不能用解析结果：重复映射键下 PyYAML 末值胜会把真实的
    # 退化 duty 换成后一条目的值而把它掩盖（现场实例：production_call_paths_stage2.csv 的
    # 退化 duty 被紧随其后的孤儿字段块吞并，safe_load 完全看不到）。
    # 取值必须同时吃带引号与不带引号两种 YAML 标量写法（仓库里两种都真实在用：
    # 200 条 duty 中 191 条带引号、9 条不带）。
    cur_path = None
    for ln_no, raw in enumerate(index_text.splitlines(), 1):
        mp = re.match(r'^\s*- path:\s*(.*?)\s*$', raw)
        if mp:
            cur_path = _unquote_scalar(mp.group(1))
            continue
        md = re.match(r'^\s*duty:\s*(.*?)\s*$', raw)
        if md and cur_path:
            why = duty_degenerate_reason(_unquote_scalar(md.group(1)), cur_path)
            if why:
                v.append({"where": f"DOCUMENT_INDEX.yaml:{ln_no}",
                          "issue": f"duty 退化：{why}",
                          "path": cur_path})
    reports["C2"] = {
        "name": "tree-coverage",
        "ok": not v,
        "detail": f"文档层对象 {len(doc_layer)} ＝ 判定对象 {len(judged)} ＋ 排除面命中 {len(excluded)}；"
                  f"判红 {len(v)} 条",
        "exclusion_surface": [
            {"pattern": x["pattern"], "reason": x["reason"], "evidence": x["evidence"],
             "hits": len(excluded) if x is EXCLUSIONS[0] else 0}
            for x in EXCLUSIONS
        ],
        "violations": v,
    }

    # ---------------- C4：upstream 双要素（节号存在 + 标题逐字相符） ----------------
    sections = design_sections(design_text)
    if not sections:
        res["checks"]["C4"] = {"ok": False,
                               "error": "fail-closed：未从最高设计解析出任何节号，"
                                        "判据输入面为空（DOCUMENT_GOVERNANCE.md §4.3 非空断言）"}
        sections = {}
    v = []
    v_idx = 0
    for zone, i, e in entries:
        up = (e or {}).get("upstream")
        if not up:
            continue
        for num, title in parse_design_refs(str(up)):
            base = f"DOCUMENT_INDEX.yaml doc_index.{zone}[{i}] ({ent_path(e)})"
            v_idx += 1
            if num not in sections:
                v.append({"where": base, "side": "index",
                          "issue": f"节号悬空：docs/ACSD_DESIGN.md 不存在 §{num}",
                          "sec": num, "title": title})
                continue
            if title is None:
                v.append({"where": base, "side": "index",
                          "issue": f"只给号不给标题：§{num} 缺「（该节标题）」双要素",
                          "sec": num, "title": None})
                continue
            actual = sections[num]
            if norm_title(title) != norm_title(actual):
                v.append({"where": base, "side": "index",
                          "issue": f"标题错位：§{num} 括注「{title}」≠ 实际标题「{actual}」",
                          "sec": num, "title": title, "actual_title": actual})
    # 文档抬头的双要素同样校验（§4.5：文档抬头与索引条目同源；标题错位类缺陷住在抬头里）
    #
    # 扫描面口径（v2 订正，v1 两处结构性盲区）：
    #   1. v1 取 read()[:4000] 固定字符窗当「抬头」。这不是抬头，是位置近似——现场
    #      docs/science/DATA_SEMANTICS.md:3341 的「上游：」行（带 7 个裸节号）落在窗外，
    #      一条红都没进。v2 扫全文，不再用固定字符窗。
    #   2. v1 预筛 `ACSD_DESIGN.md\s*§` 比解析器窄：反引号包裹的 `` `docs/ACSD_DESIGN.md` §0 ``
    #      与不带 § 的 `ACSD_DESIGN.md 附录 A（术语）` 两类合法/现实形态整类漏掉。
    #      v2 预筛只要求出现文档名，与 parse_design_refs 的接受面对齐。
    hdr_hits = 0
    hdr_files = 0
    for p in doc_layer:
        txt = read_doc(root, p)
        if not DESIGN_MENTION_RE.search(txt):
            continue
        hdr_files += 1
        # 抬头区 = 首个 `## ` 之前的整段前言；其后为正文散引。
        # 两者都判（口径是全文，不设固定字符窗），但分开计数：§4.5 的「文档抬头」
        # 指的是前者，正文散引是覆盖面更广的附加读数，不是同一件事。
        cut = txt.find("\n## ")
        cut = len(txt) if cut < 0 else cut
        for ln_no, line in enumerate(txt.splitlines(), 1):
            if not DESIGN_MENTION_RE.search(line):
                continue
            off = sum(len(x) + 1 for x in txt.splitlines()[:ln_no - 1])
            region = "header" if off < cut else "body"
            for num, title in parse_design_refs(line):
                hdr_hits += 1
                base = f"{p}:{ln_no}"
                if num not in sections:
                    v.append({"where": base, "side": "header", "region": region,
                              "issue": f"抬头节号悬空：不存在 §{num}",
                              "sec": num, "title": title})
                elif title is None:
                    v.append({"where": base, "side": "header", "region": region,
                              "issue": f"抬头只给号不给标题：§{num} 缺「（该节标题）」双要素",
                              "sec": num, "title": None})
                elif norm_title(title) != norm_title(sections[num]):
                    v.append({"where": base, "side": "header", "region": region,
                              "issue": f"抬头标题错位：§{num} 括注「{title}」≠ 实际标题「{sections[num]}」",
                              "sec": num, "title": title, "actual_title": sections[num]})
    # §4.5 第三条：文档抬头与索引条目给出的双要素必须同源，不一致即判红。
    # v1 完全没有实现这条（复核反例 CE-6：抬头比索引多给一条合法 §，两侧不同源，判绿）。
    # 比对面只取「抬头区」（首个 `## ` 之前）与本条目自己的 upstream 字段，
    # 不拿正文散引去判抬头——那会判错对象。节号集合相等即同源；标题层面的分歧
    # 由上面的双要素判据单独报，不在这里重复记一次。
    same_src_checked = 0
    for zone, i, e in entries:
        p = ent_path(e)
        if not p or p not in doc_layer:
            continue
        hdr_set = design_num_set(header_region(read_doc(root, p)))
        if not hdr_set:
            continue
        idx_set = design_num_set(str((e or {}).get("upstream") or ""))
        if not idx_set:
            continue
        same_src_checked += 1
        if hdr_set != idx_set:
            only_hdr = sorted(hdr_set - idx_set)
            only_idx = sorted(idx_set - hdr_set)
            v.append({"where": f"{p} ↔ DOCUMENT_INDEX.yaml doc_index.{zone}[{i}]",
                      "side": "same-source", "region": "header",
                      "issue": "抬头与索引双要素不同源（§4.5 第三条）："
                               f"抬头多给 {only_hdr or '无'}；索引多给 {only_idx or '无'}",
                      "header_only": only_hdr, "index_only": only_idx})
    reports["C4"] = {
        "name": "upstream-two-element",
        "ok": not v,
        "detail": f"设计节号表 {len(sections)} 节；"
                  f"索引侧命中 {v_idx} 处引用（{len(entries)} 条登记）；"
                  f"文档侧全文扫描 {hdr_files} 份文件、命中 {hdr_hits} 处引用"
                  f"（口径＝全文，不设固定字符窗）；"
                  f"同源比对 {same_src_checked} 对；判红 {len(v)} 条"
                  f"（索引侧 {sum(1 for x in v if x.get('side') == 'index')} "
                  f"＋ 抬头区 {sum(1 for x in v if x.get('region') == 'header')} "
                  f"＋ 正文散引 {sum(1 for x in v if x.get('region') == 'body')}）",
        "violations": v,
    }

    # ---------------- C5：跨文档合同 ID 存在于 docs/contracts/INDEX.yaml ----------------
    try:
        cdoc, _ = load_yaml_strict(open(os.path.join(root, contracts_rel),
                                        encoding="utf-8").read())
    except Exception as e:
        res["checks"]["C5"] = {"ok": False, "error": f"合同索引解析失败: {e}"}
        cdoc = {}
    known = set()
    for c in ((cdoc or {}).get("contracts") or []):
        if isinstance(c, dict) and c.get("id"):
            known.add(str(c["id"]))
    legacy = ((cdoc or {}).get("legacy_contract_id_map") or [])
    if isinstance(legacy, dict):
        known |= {str(k) for k in legacy}
    elif isinstance(legacy, list):
        for item in legacy:
            if isinstance(item, dict) and item.get("legacy_id"):
                known.add(str(item["legacy_id"]))
    if not known:
        res["checks"]["C5"] = {"ok": False,
                               "error": "fail-closed：合同注册表解析出 0 个 ID，判据输入面为空"}
        known = set()

    # 引用面：正式文档层（docs/**/*.md，排除索引自身与目录招牌件）
    scanned = [p for p in doc_layer if p != index_rel and not excl_re.match(p)]
    refs: dict[str, set[str]] = {}
    for p in scanned:
        for ln_no, line in enumerate(read_doc(root, p).splitlines(), 1):
            for tok in CONTRACT_ID_RE.findall(line):
                if tok in known or tok.endswith(PLACEHOLDER_SUFFIX):
                    continue
                refs.setdefault(tok, set()).add(f"{p}:{ln_no}")
    v = [{"issue": f"合同 ID「{k}」被引用 {len(s)} 处，但不在 docs/contracts/INDEX.yaml "
                  f"（contracts[].id ∪ legacy_contract_id_map[].legacy_id）",
          "id": k, "where": sorted(s)[:3], "occurrences": len(s)}
         for k, s in sorted(refs.items())]
    by_layer: dict[str, int] = {}
    for x in v:
        lay = str(x["id"]).split("-", 1)[0]
        by_layer[lay] = by_layer.get(lay, 0) + 1
    reports["C5"] = {
        "name": "contract-id-alive",
        "ok": not v,
        "detail": f"在册合同 ID {len(known)} 个（注册面 docs/contracts/INDEX.yaml）；"
                  f"引用面扫描 {len(scanned)} 份文档；"
                  f"悬空合同 ID {len(v)} 个，按层 {dict(sorted(by_layer.items()))}",
        "id_grammar_source": "docs/engineering/TRACEABILITY_SPEC.md §3（八层注册正则）",
        "violations": v,
    }

    for k in ("C1", "C2", "C3", "C4", "C5"):
        reports[k]["check_id"] = k
    res["checks"] = reports
    return res

# 自检：注入已知缺陷，验证判据真的会红（不是恒真）
#
# v1 的判定是 `fired = not c.get("ok")`，只看绝对状态不看增量。凡基线本就红的判据，
# 这个判定必然输出「红 ✓」，与注入是否生效完全无关——实测把 C1/C4/C5 的注入整段
# 删掉，自检仍原样打印「红 ✓」。v2 改为**断言增量**：
#     fired = 注入后 violations 数 > 注入前（同一临时仓、同一判据）的 violations 数
# 基线必须在**纯净的临时仓**里测，不能拿真实工作树当基线：临时仓只含 docs/，
# 对象集与真实仓不同（AGENTS.md/README.md/VERSION 都不在其中）。
# ---------------------------------------------------------------------------
SELF_TEST_DEFECTS = {
    "C1": "把某条 path 改成不存在的悬空路径",
    "C2": "C2a 删掉一条文档的索引登记 / C2b 把 duty 改成自身路径",
    "C3": "在一条正常条目后追加无 path 键的孤儿字段块",
    "C4": "把 upstream 的节号改成设计里不存在的节号",
    "C5": "把 INDEX.yaml 里的某条合同 id 改名",
}


def self_test(root: str) -> int:
    """注入缺陷 → 判据的 violations 必须**增加**。

    在临时的最小仓（只含 docs/，git init + add，足够支撑 `git ls-files` 派生对象集）
    里做注入，不碰真实工作树：并行车道随时在读这些文件，就地改会污染它们的读数。

    返回 0 = 每条子测试都观测到正增量（判据有判别力）；1 = 有子测试增量为 0
    （判据对这条注入恒真，自检判自己红）。
    """
    import shutil
    tmp = tempfile.mkdtemp(prefix="g08_03a_selftest_")
    try:
        work = os.path.join(tmp, "repo")
        os.makedirs(work)
        shutil.copytree(os.path.join(root, "docs"), os.path.join(work, "docs"),
                        symlinks=True)
        subprocess.run(["git", "init", "-q"], cwd=work, check=True)
        subprocess.run(["git", "add", "-A"], cwd=work, check=True)
        idx = os.path.join(work, "docs/DOCUMENT_INDEX.yaml")
        cidx = os.path.join(work, "docs/contracts/INDEX.yaml")
        text = open(idx, encoding="utf-8").read()
        ctext = open(cidx, encoding="utf-8").read()

        def nviol(key: str) -> int:
            return len(run_checks(work)["checks"][key].get("violations", []))

        # 纯净临时仓基线：一切增量都相对它算，不相对真实工作树
        pre = {k: nviol(k) for k in ("C1", "C2", "C3", "C4", "C5")}
        print("纯净临时仓基线（增量断言的参照系，不是真实工作树）：")
        for k in ("C1", "C2", "C3", "C4", "C5"):
            print(f"  基线 {k}: violations={pre[k]}")

        trials: list[tuple[str, str, str]] = []   # (key, sublabel, 注入说明)

        def trial(key: str, sublabel: str, desc: str, new_text: str | None = None):
            """写入注入 → 读增量 → 还原。返回 (key, sublabel, desc, delta)。"""
            if new_text is not None:
                open(idx, "w", encoding="utf-8").write(new_text)
            post = nviol(key)
            open(idx, "w", encoding="utf-8").write(text)
            delta = post - pre[key]
            trials.append((key, sublabel, desc, delta))
            return delta

        # C1 注入：把 path 改成不存在的悬空路径（既不在跟踪集也不在磁盘）
        t1 = text.replace('- path: "docs/GLOSSARY.md"',
                          '- path: "docs/__NO_SUCH_FILE__.md"', 1)
        assert t1 != text, "C1 注入锚点未命中"
        trial("C1", "C1a", "path 改成不存在的悬空路径", t1)

        # C1 注入（第 2 条）：文件仍在 git 索引内、但从磁盘删掉（未 git rm）。
        # 这一条专打 v1 只取 git ls-files 的漏洞。
        victim = "docs/GLOSSARY.md"
        victim_abs = os.path.join(work, victim)
        stash = victim_abs + ".stash"
        os.rename(victim_abs, stash)
        try:
            d = nviol("C1") - pre["C1"]
        finally:                      # 还原必须无条件执行，且不许掩盖增量读数
            if os.path.exists(stash):
                os.rename(stash, victim_abs)
        trials.append(("C1", "C1b", "文件从磁盘删除但仍在 git 索引内", d))

        # C2 注入 (a)：删掉一条 docs 文档的整条索引登记 ⇒ 文件树漏项
        keep, skip = [], False
        for ln in text.splitlines(keepends=True):
            if '- path: "docs/detail/common.md"' in ln:
                skip = True
                continue
            if skip:
                if ln.startswith("    - path:") or ln.startswith("  archived:"):
                    skip = False
                else:
                    continue
            keep.append(ln)
        t2a = "".join(keep)
        assert t2a != text, "C2a 注入未生效：删登记没删掉任何行"
        trial("C2", "C2a", "删掉一条文档的索引登记（应报文件树漏项）", t2a)

        # C2 注入 (b)：把一条 duty 改成自身路径（退化 duty，带引号形态）
        m = re.search(r'^(\s*)- path:\s*"([^"]+)"$(.*?)^\s*duty:\s*"([^"]+)"\s*$',
                      text, re.M | re.S)
        assert m, "C2 duty 注入锚点未命中：索引里没有 path+duty 配对"
        t2b = text[:m.start()] + (f'{m.group(1)}- path: "{m.group(2)}"'
                                  + m.group(3) + f'{m.group(1)}  duty: "{m.group(2)}"') \
            + text[m.end():]
        assert f'duty: "{m.group(2)}"' in t2b, "C2b duty 注入未生效"
        trial("C2", "C2b", "duty 改成自身路径（带引号）", t2b)

        # C2 注入 (c)：退化 duty 写成**不带引号**的 YAML —— v1 文本正则要求双引号，整类漏检
        t2c = text[:m.start()] + (f'{m.group(1)}- path: "{m.group(2)}"'
                                  + m.group(3) + f'{m.group(1)}  duty: {m.group(2)}') \
            + text[m.end():]
        assert f'duty: {m.group(2)}\n' in t2c, "C2c duty 注入未生效"
        trial("C2", "C2c", "duty 写成自身路径（不带引号的 YAML 标量）", t2c)

        # C2 注入 (d)：duty 写成自指代词「本文件」—— v1 只比字面路径，语义退化整类漏检
        t2d = text[:m.start()] + (f'{m.group(1)}- path: "{m.group(2)}"'
                                  + m.group(3) + f'{m.group(1)}  duty: "本文件"') \
            + text[m.end():]
        assert 'duty: "本文件"' in t2d, "C2d duty 注入未生效"
        trial("C2", "C2d", 'duty 写成自指代词「本文件」', t2d)

        # C3 注入：孤儿字段块（无 - path: 键；PyYAML 末值胜会静默吞并首值）
        t3 = text.replace(
            '      downstream: "CMakeLists.txt、docchk002_claims_fixture.csv、test_linux_release.py 等 9 处"',
            '      downstream: "CMakeLists.txt、docchk002_claims_fixture.csv、test_linux_release.py 等 9 处"\n'
            '      status: ACTIVE_INFORMATIVE\n'
            '      duty: "注入的孤儿字段块"\n'
            '      upstream: "docs/ACSD_DESIGN.md §8（软件架构）"\n'
            '      downstream: ""', 1)
        assert t3 != text, "C3 注入锚点未命中"
        trial("C3", "C3a", "追加无 path 键的孤儿字段块", t3)

        # C4 注入 (a)：索引侧节号改成设计里不存在的节号
        t4 = text.replace('upstream: "docs/ACSD_DESIGN.md §13（版本与发布权）"',
                          'upstream: "docs/ACSD_DESIGN.md §99.9（不存在的节）"', 1)
        assert t4 != text, "C4a 注入锚点未命中"
        trial("C4", "C4a", "索引 upstream 节号改成不存在的节", t4)

        # C4 注入 (b)：抬头悬空引用挪到**第 4000 字符之后** —— 打 v1 的固定字符窗
        hdr_victim = "docs/GLOSSARY.md"
        hpath = os.path.join(work, hdr_victim)
        htext = open(hpath, encoding="utf-8").read()
        pad = ("\n填充段落，用于把抬头推到第 4000 字符之后。\n" * 200)
        new_htext = htext + pad + "\n> 上游：ACSD_DESIGN.md §99.7（窗外悬空节）\n"
        open(hpath, "w", encoding="utf-8").write(new_htext)
        d4b = nviol("C4") - pre["C4"]
        open(hpath, "w", encoding="utf-8").write(htext)
        trials.append(("C4", "C4b", "抬头悬空引用落在第 4000 字符窗外", d4b))

        # C4 注入 (c)：抬头比索引多给一条**合法** §，两侧不同源（§4.5 第三条）
        # 找一份抬头与索引当前同源的文档，往抬头里加一条真实存在的节
        idx_doc, _ = load_yaml_strict(text)
        di = (idx_doc or {}).get("doc_index") or {}
        allents = list(di.get("active") or []) + list(di.get("archived") or [])
        same_src_victim = None
        for ent in allents:
            p = (ent or {}).get("path")
            if not p or not p.startswith("docs/") or not p.endswith(".md"):
                continue
            ap = os.path.join(work, p)
            if not os.path.exists(ap):
                continue
            t = open(ap, encoding="utf-8").read()
            hdr = design_ref_set(header_region(t))
            if hdr and hdr == design_ref_set(str(ent.get("upstream") or "")):
                same_src_victim = (p, ap, t)
                break
        assert same_src_victim, "C4c 注入锚点未命中：找不到抬头与索引当前同源的文档"
        sp, sap, st = same_src_victim
        new_st = st.replace("## ", "> 上游：ACSD_DESIGN.md §7.3（错误传播与日志）\n\n## ", 1)
        assert new_st != st, "C4c 注入未生效：抬头区插入锚点未命中"
        open(sap, "w", encoding="utf-8").write(new_st)
        d4c = nviol("C4") - pre["C4"]
        open(sap, "w", encoding="utf-8").write(st)
        trials.append(("C4", "C4c", f"抬头比索引多给一条合法 §（{sp}）", d4c))

        # C5 注入：改掉一个在册合同 ID
        t5 = ctext.replace("  - id: SCI-SCOPE-001", "  - id: SCI-SCOPE-XXX", 1)
        assert t5 != ctext, "C5 注入锚点未命中"
        open(cidx, "w", encoding="utf-8").write(t5)
        d5 = nviol("C5") - pre["C5"]
        open(cidx, "w", encoding="utf-8").write(ctext)
        trials.append(("C5", "C5a", "改掉一个在册合同 ID", d5))

        print("\n自检判定：注入后 violations 必须**多于**注入前（断言增量，不看绝对状态）")
        bad = 0
        for key, sublabel, desc, delta in trials:
            fired = delta > 0
            print(f"  {sublabel} [{key}] 注入「{desc}」→ "
                  f"{'增量 ✓ +' + str(delta) if fired else '增量 0 ✗（判据对这条注入恒真！）'}")
            if not fired:
                bad += 1
        print(f"  合计 {len(trials)} 条子测试，{len(trials) - bad} 条有判别力，{bad} 条恒真")
        if bad:
            print("  ⇒ 自检判红：上述子测试的注入没有让判据变红，判据存在恒真盲区")
        return 1 if bad else 0
    finally:
        shutil.rmtree(tmp, ignore_errors=True)

def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description="索引与双向可追溯五判据校验器")
    ap.add_argument("--root", default=".", help="仓库根（默认当前目录）")
    ap.add_argument("--json-out", help="把完整报告写到此 JSON 文件")
    ap.add_argument("--quiet", action="store_true", help="只打印总判定与计数")
    ap.add_argument("--self-test", action="store_true", help="注入缺陷验证判据判红能力")
    a = ap.parse_args(argv)

    root = os.path.abspath(a.root)
    if a.self_test:
        return self_test(root)

    try:
        res = run_checks(root)
    except Exception as e:
        print(f"内部错误（fail-closed）: {e}", file=sys.stderr)
        return 2

    if a.json_out:
        with open(a.json_out, "w", encoding="utf-8") as f:
            json.dump(res, f, ensure_ascii=False, indent=2)

    if not a.quiet:
        for k in ("C1", "C2", "C3", "C4", "C5"):
            c = res["checks"].get(k, {})
            if "error" in c:
                print(f"[{k}] {c.get('name', k)}: ERROR {c['error']}")
                continue
            mark = "PASS" if c["ok"] else "FAIL"
            print(f"[{k}] {c['name']}: {mark} — {c['detail']}")
            if not c["ok"]:
                for i, x in enumerate(c["violations"][:60], 1):
                    print(f"    {i}. {x.get('where')} :: {x.get('issue')}")
                if len(c["violations"]) > 60:
                    print(f"    … 其余 {len(c['violations']) - 60} 条见 --json-out")
            if k == "C2" and not c["ok"]:
                for x in c.get("exclusion_surface", []):
                    print(f"    排除面 {x['pattern']} reason={x['reason']} 命中 {x['hits']}")
    else:
        for k in ("C1", "C2", "C3", "C4", "C5"):
            c = res["checks"].get(k, {})
            print(f"{k} {c.get('name', k)}: "
                  f"{'PASS' if c.get('ok') else 'FAIL'} "
                  f"({len(c.get('violations', []))} violations)")

    all_ok = all(res["checks"].get(k, {}).get("ok") for k in ("C1", "C2", "C3", "C4", "C5"))
    print("TOTAL:", "PASS" if all_ok else "FAIL")
    return 0 if all_ok else 1


if __name__ == "__main__":
    sys.exit(main())
