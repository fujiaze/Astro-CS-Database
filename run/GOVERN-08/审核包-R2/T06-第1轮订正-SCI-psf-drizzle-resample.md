## 2 本车推翻的审稿判定（保留原判不抹除）

### 2.1 【R7-10】「恒真门、零判别力」定性过重 —— 改判为「L2 不在式子里」

审稿原判：「该门在 `A_drop,j = pixfrac²·A_pixel,j` 这一支上恒等于 0 —— 字面读法下**恒成立，零判别力**」。

**反证**：本车逐行复核三跳链属实，但 `expected = pixfrac²·A_pixel_j = pixfrac²·(drop_area/pixfrac²) = drop_area`，而左端 `sum_a_jp` 是**逐叶裁剪累加**来的：

```cpp
// spherical_overlap_science.cpp:112
for (const OverlapHit& h : out->hits) sum += h.a_jp;
```

与 `drop_area` 无代数耦合。⇒ 该门**确实**在检验「drop 面积是否被其覆盖的叶精确分完」，**不是恒等于 0**，有判别力（`n_area_rejected` 与 `overlap_area_deficit`/`overlap_exceeds_drop` 都挂在它上面）。

**精确表述**：文档原判据是**单等式** `Σ_p a_jp = pixfrac²·A_pixel,j`，其右端**本身就是 L1**。所以正确说法不是「第二个合取项自动成立」（会留下一个会被后人误引的「合取项」模型），而是：**该门等价于 L1；L2 从来不在式子里。**

**处置**：审稿原判**保留在本节**，文档按修正后的表述落地。审稿的「两条路径对同一关系给出相反处理」「违反 `ACSD_DESIGN.md:497` 恒真门无证据资格」两点**成立且已落实**。

### 2.2 【R6-23】审稿员给的孔径方差反例数值不可复现

审稿原判：反例 `a = [−0.6481,−0.9747,0.6215,−0.9987]` ⇒ `exact = 0.9037677 < diag = 1.12779331`。

**反证**：审稿包**未给该组 `a_p` 对应的 `c_jp` 与 `v_j`**，数值不可复现（DRIZZLE 车道用自选的 `c`/`v` 代入得 `exact = 4.08436 > diag = 2.81181`，不成立）。

**处置**：**机理判定正确且已落实**（补 `a_p ≥ 0` 前提），但**数值弃用**，改用自建的最小反例 `a_p=[1,−1]`、`c_jp=[0.6,0.4]`、`v_j=[1]` ⇒ `exact = 0.04 < diag = 0.52`，并量化：200000 组随机带号 `a_p` 有 54.5% 违反下界，`a_p ≥ 0` 时 0/200000。

### 2.3 【R7-11】审稿员的不等号方向反了

审稿原判：「相对误差 `≤ 0.5/q ≤ 0.5/255 = 1.96e−3 > 1e-3`——即使全覆盖叶也吃满 0.2%」。

**反证**：`q ≤ 255` ⇒ `0.5/q ≥ 0.5/255 = 1.96e-3`。`1.96e-3` 是**最好情形（全覆盖叶 `q=255`）的下界**，不是上界；`q` 越小界越松（`q=4` → `12.5%`、`q=1` → `50%`）。且全覆盖叶 `S=1 ⇒ q=255 ⇒ signal/S_p = 1`，**误差恰为 0**，不存在「吃满 0.2%」。

**处置**：审稿原判保留，文档按更强的正确表述落地。结论（`1e-3` 必红、产品级容差 ≥ `2e-3`）不变。

### 2.4 【R6-13】阈值常数 `825.06″/px` 错

审稿原判：「分歧条件 `s_out > 2√(π/3)/W = 825.06″/px`」。

**反证**：`2√(π/3)/512 = 0.003997369952915971 rad/px = 824.5167388361774″/px`。审稿值差 `6.5e-2`。

**处置**：文档取复算值。另补审稿与上游都没说准的半句：未取整的 `log₂` 在 `s_out > √(π/3)/W = 412.258″/px` 就变负，但 `⌈⌉` **只在** `s_out > 824.517″/px` 才变负（因 `⌈−0.5⌉ = 0`）；阈值处 `log₂ = −1.0` 精确、`ceil = −1`。
