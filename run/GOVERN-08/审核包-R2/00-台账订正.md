## 3 `文件:行` 引用在 HEAD 下的重定位核对

### 3.1 方法

不凭猜测平移行号。对每条 `(文件, 行号)` 引用：

1. 用 `git show 1208d5a0:<path>` 逐字读出**基线那一行**；
2. 用 `git show HEAD:<path>` 逐字读出**当前那一行**；
3. 两者归一化（折叠空白）后**逐字符比对**；
4. 不同则在该文件的 HEAD 全文中**搜索基线该行的原文**：唯一命中 ⇒ 给出新行号；无命中 ⇒ 用 `difflib` 找全文件最相似行判定是「就地改写」还是「内容已不存在」；
5. 文件在 HEAD 不存在 ⇒ 查 `git ls-files` 的 basename 候选，排除「引用写的是缩写路径」造成的误判。

裸文件名（如 `REPORT_experiment.md`）按 `git ls-files` 的 basename 索引解析，避免把缩写误判成「文件已删」。
