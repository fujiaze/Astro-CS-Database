⇒ 本单的落法**不是靠纪律，而是靠机器**：

| 规范要求 | 可执行落法 | 位置 |
|---|---|---|
| 非阻塞为常态 | `harness.verdict()` **恒返回 `warn`**，不存在返回 `red` 的分支 | `eng/tests/unit/harness.py:255-265` |
| 不产出流水线判决 | `run_unit.py` 默认退出码**恒为 `0`** | `eng/tests/unit/run_unit.py:135-142` |
| 两者不得被悄悄改掉 | `meta.verdict_is_non_blocking_even_with_failures` 造一个全红结果集，断言 `verdict == "warn"` 且 `exit_code == 0` | `test_criterion_meta.py` |

即：想把这套测试改成「有红项就 red / 退出码非 0」的改动，会让那条测试立刻变红
（消融 A5 已实测，见 §5.2）。

`--exit-code` 开关是**开发期自查**用的（本单用它自证负例能红），它不进 CI；

## 3. 容差冻结表（写测试前冻结，逐条带来源）

冻结发生在写任何用例之前（`TEST.md` §3 逐字「容差在写用例前冻结，取值见第 4 节」）。

### 3.1 通用档（`TEST.md` §4 逐字）

| 量类 | 取值 | 本层是否用到 |
|---|---|---|
| 元数据、掩膜、计数、索引、端口、选择结果 | **精确一致** | ✅ 路由枚举、计数、支持数、`ipix`、tile_shift |
| 双精度非归约 | `rtol = 1e-12`，`atol = 1e-13 × scale` | ✅ 面积、立体角、往返角距 |
| 单精度产品非归约 | `rtol = 5e-6`，`atol = 1e-6 × scale` | ✅ 单精度产品面 |
| 归约 | `γ_n = n·u/(1−n·u)`，门限 `C·γ_n·Σ|terms| + atol`，`C ≤ 4` | ✅ |
| `u`(f64) | `2⁻⁵³` = 1.1102230246251565e-16 | ✅ |
| `u`(f32) | `2⁻²⁴` = 5.9604644775390625e-08 | ✅ |
| 并行等价 | 上述三档等价，**不是**逐位一致 | 本层未涉及 |

**`C` 冻结为 4**（取约束上界，理由写在 `tolerances.py` §2：单元层核函数的归约项数 ≤ 64，
没有需要收紧放大预算的结构；取上界保证不会因冻结了偏紧的 C 而把合格实现判红）。
**`C` 与 `u` 不得跨 dtype 混用**：`TEST.md` §4.1 逐字「混用（f64 数据按 f32 的 `u` 判）把门限放宽约 `2²⁹` 倍，**属判据失效**」。本层把它做成了可执行判据
（`meta.dtype_u_mixing_widens_the_bound_by_2_to_the_29`，并给出**解析式**的精确比值
`[u32/(1−n·u32)]/[u64/(1−n·u64)]`，而不是正本那句「约 `2²⁹` 倍」的粗口径）。

- **不用 max，用 median + p95**（`gaia.quant_rel`）：8-bit 量化残差分布长尾由个别离群样本决定，
  max 随样本集漂移、不构成可复现门限。正本给的就是 median/p95 两个统计量，
  `TEST.md` §4「统计量显式、阈值一律与统计量同写」的精神要求两者同写。
- **绝对容差必须可满足**（`TEST.md` §4.3）：`atol < 1 ulp(scale)` 时该容差不可判。
  本层把它做成了**运行期硬检查**——`harness.close()` 在 `atol < ulp(scale)` 时直接判红
  （不是事后发现）。这一条在开发过程中真的抓到过我自己写错的两个调用点。

## 5. 负例有效性自证（逐条，双向消融）

### 5.1 消融方法

两种消融都做，**不只在文件里做，运行后立即还原并用 sha256 校验**：

- **A 系列 · 抽掉守卫**：把被测守卫/判据从骨架里去掉（如重复 id 检查、atol 的 1-ulp 下限、
  非有限值检查、非阻塞裁决词），负例必须变红。
- **B 系列 · 撤掉注入**：把负例注入的缺陷改回正确形态，负例必须变红
  —— 这才证明它的「通过」**完全来自那个注入的缺陷**，而不是恒真。

| **S6 的预算项逐项数值**（光子噪声 / PSF Fisher / 平场 / 天光 / 颜色 / XP / 量化） | 这些项在仿真帧上逐项由本帧推导，真实帧上 `σ_color`/`σ_gaia` 正本逐字写「不可自算、如实标 `null`」。单元层只能测**判定序与作用域**，不能造出「本帧预算」。 |
| **P1–P4 性能判据**（平均/p50/逐样本占比/低利用窗） | 它们需要**真实重计算负载的采样序列**，属基准/集成层。单元层只吸收了与负载无关的纯函数面（P5 分母解析、P7 队列前置、P10/P11/P12 的算法形状）。 |

| **E2/E7/E8/E10/E11/E12/E14/E15** | 全部是**集成层**（指纹改动面、缺陷注入接线、全仓扫描、人工对抗审核、模板推广）。T02 §2.4 自己标的就是「集成层」。 |
| **`wcs_lib.py` 的差分测试** | T02 §3.4 第 2 名推荐，但它是 `phot_verify` 的**集成层**差分测试（对照真实产品 WCS 输出）。本单写域是单元层；已在 §10 移交给其它车道。 |
| **`c_delta_composition/` 整组** | T02 §3.5 已整组否决（生产代码已推翻其结论 + 判据本身退化）。本单复核该否决**成立**，不吸收。 |

### 9.2 吸收了但**改成另一种形态**的（附理由）

| 原判据形态 | 改成 | 理由 |
|---|---|---|
| S5 → T02 建议「集成层·负向注入断言」 | **单元层·表驱动边界断言** | 三道门是 `ipv_wcs.cpp:731-769` 里三个顺序 `if`，无状态、无 I/O、无外部依赖。且 T02 自己给 S5b 的建议就是「科学单元层」——**若 S5 落集成层、S5b 落单元层，就物理上不可能同批同文件，直接违反 S5b 行逐字要求**。（W4 提出，本单采纳。） |
| S12/S13 的「解码往返容差断言」 | 期望值改用**闭式解析值**、正本读数改作**门限** | T02 给的是**统计量读数**（median 0.21% / p95 1.8%），那是门限不是期望值。两者在用例里必须分开写。 |
| P11「须以已知红登记」 | **特征化测试 + 退化检测负例**两分解法 | 直接写一条恒红的用例会训练人忽略红项。锁住缺陷 + 证明检测器有牙齿，既暴露又不制造噪音。 |
