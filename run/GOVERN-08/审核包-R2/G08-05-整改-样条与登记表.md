## 1 独立验证：哪个 b 系数是对的

**没有照抄审稿结论。** 三条互相独立的证据链，全部自建。

### 1.1 证据一：代数推导（从 Hermite 条件硬推）

段内多项式 `S_j(x) = y_j + b_j·t + c_j·t² + d_j·t³`，`t = x − x_j`，节点等距 `h`。

用到的条件：
1. 端点值 `S_j(x_{j+1}) = y_{j+1}`：`y_j + b_j h + c_j h² + d_j h³ = y_{j+1}`
2. 一阶连续 `S_j'(x_{j+1}) = S_{j+1}'(x_{j+1})`：`b_j + 2c_j h + 3d_j h² = b_{j+1}`
3. 二阶连续 `S_j''(x_{j+1}) = S_{j+1}''(x_{j+1})`：`2c_j + 6d_j h = 2c_{j+1}`

由 (3) ⇒ `d_j = (c_{j+1} − c_j)/(3h)` —— **四份副本的 d 系数一致，且与推导相符**。
把 (3) 代回 (1)：

```
b_j = (y_{j+1} − y_j − c_j h² − d_j h³)/h
    = (y_{j+1} − y_j)/h − c_j h − (c_{j+1} − c_j) h/3
    = (y_{j+1} − y_j)/h − h·(2c_j + c_{j+1})/3
```

⇒ **`b_j = (y_{j+1} − y_j)/h_j − h_j·(c_{j+1} + 2c_j)/3`，`h_j` 不可省。**

**量纲判据**（最快的反证）：`Δy/h` 是**斜率**（量纲 y/px）；`h·c` 也是斜率（`c ~ y/h²`）。
而 sim 腿原式减的是 `(c_{j+1}+2c_j)/3 ~ y/h²`，那是**曲率**。
**原式把曲率从斜率里减掉，两项量纲不同** ⇒ 必然错。

### 1.3 证据三：生产 C++ 实现（上游，不是实验副本）
