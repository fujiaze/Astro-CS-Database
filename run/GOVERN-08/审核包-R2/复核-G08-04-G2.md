### 4.2 我的独立推导（不引用作者）

记 `E(w, v) = [Σ_i w_i² v_i / (Σ_i w_i)²] / [1/Σ_i (1/v_i)] − 1`，`eligible` 取全 True。

代入 `w_i = 1/v_i`（即 `w_used` 与 `v_true` 是**同一个数组** `v_pix`）：

- 分子：`Σ_i w_i² v_i = Σ_i (1/v_i)²·v_i = Σ_i (1/v_i)`
- 分母：`Σ_i w_i = Σ_i (1/v_i)`
- 故 `var_w = Σ_i(1/v_i) / (Σ_i(1/v_i))² = 1 / Σ_i(1/v_i)`
- 而 `var_opt ≡ 1 / Σ_i(1/v_i)`

⇒ `var_w ≡ var_opt`（**精确相等，非近似**）⇒ `E ≡ 0`。

**这个推导对 `v` 的内容、尺度、动态范围、单调性一无所求**——只用到「所有 `v_i > 0`」以保证 `1/v_i` 有限。**代数恒真，确认。**

```python
def stack_usecase(rec_snr, agg, seed, n_px=3000, mu_true=50.0):
```

```python
def f_syn(spectrum, wl_nm, T=None, T_wl=None, Q=None, Q_wl=None, mag_g=None):
    """...
        F_syn = ∫ F_λ(λ)·T(λ)·Q(λ)·λ dλ    # 单位 W·m⁻²·nm；**不含** 10^(-0.4·G)
        F_λ   = 外部定标 XP 采样谱（W·m⁻²·nm⁻¹）

    v = simpson_integrate(wl, S * tr * qr * wl)      # ← 逐星 SED 积分 I_i
```
