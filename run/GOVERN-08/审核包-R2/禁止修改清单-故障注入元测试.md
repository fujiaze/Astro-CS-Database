# 禁止修改清单 · 故障注入元测试（**全仓 10 个**）

## 为什么有这份清单

这批文件里出现 `1 == 1` 这类**字面恒真谓词**，机械横扫会判成「自证式判据」并去"修"它。
**修它会摧毁一组可用的反向对照。**

## 机理

它们的结构是三段式：
1. **基线必须全通过**；
2. **子进程在指定故障名环境变量下必须失败**；
3. `1 == 1` 是**检查宏的谓词实参，故意取永真**，使失败计数的唯一来源是
   **故障名分发本身**而不是谓词。

周围的三态断言（失败计数 / 故障已上报）**才是真判据**。永真谓词在这里的作用是
「让这条路径恒不失败，从而把失败归因唯一地钉到故障名分发上」。
