## 1. P0-1 恒真门降级：完整改法与下游影响面

### 1.1 恒等式证明（代码级，非估计）

`code/route1/exp_p4_04_brightness_forward.py`：

```python
# :271-272
v_pix        = agg["sw2_map"].ravel()[pick]
w_oracle_full = 1.0 / v_pix
# :275
"E_oracle_full": efficiency(w_oracle_full, v_pix, np.ones(len(pick), bool)),
# :123-128
def efficiency(w_used, v_true, eligible):
    w = w_used[eligible]; v = v_true[eligible]
    var_w  = np.sum(w**2*v) / np.sum(w)**2
    var_opt = 1.0 / np.sum(1.0/v)
    return float(var_w/var_opt - 1.0)
```

代入 `w = 1/v`：

```
var_w = Σ((1/v)²·v) / Σ(1/v)² = Σ(1/v) / Σ(1/v)² = 1/Σ(1/v) = var_opt
⇒ E = var_w/var_opt − 1 ≡ 0
```

**对任意正方差数组成立**，与数组内容、尺度、动态范围无关。`v_true` 收到的就是构造权重所用的同一数组 ⇒ 这是**自证恒等式**，不是测量。

### 1.2 数值复核（独立复算，未写回 `results/`）

以 `efficiency()` 原式、`seed 0`，对五组差异极大的正方差数组：

| 数组 | E | ulp | 门 `<1e-12` |
|---|---|---:|:-:|
| 常数 1 | `0.0` | 0 | True |
| lognormal 10⁻³–10³ | `0.0` | 0 | True |
| **面积×10⁹ 注入（10⁹–10¹²）** | `2.22e-16` | **1.00** | True |
| 极小 10⁻³⁰–10⁻¹² | `0.0` | 0 | True |
| 极大 10¹²–10³⁰ | `0.0` | 0 | True |

注入面积量级 ×10⁹ 的缺陷后 E 仍为 **1 ulp**、门照样通过。

> **G2 复核订正（重要）**：本节**不足以**支持「无判别力」的结论，理由是**注入方式同义反复**：上表全程固定 `w = 1.0/v`（`:95` 硬写死），只改 `v`；而 `E` 的恒等性来自「`w` 与 `v_true` 是同一数组」这一**结构事实**，改 `v` 的内容/尺度/量级在代数上**不可能**改变 `E`。⇒ 这是缺陷注入，是把同一个恒等式换了一批自变量重算。**本节结论降级为「`E_oracle_full` 是不具实验证据资格的自证恒等式」**（该结论成立、且已落地降级），**「该门无判别力」的判词已撤回**——真正应注入的是 `w` 的**公式**，见 §1.3。

### 1.3 门判别力的正确复算（G2 复核新增；注入 `w` 公式而非 `v`）

`efficiency()` 逐字取自 `exp_p4_04_brightness_forward.py:123-128`（除法原式），`seed 0`，固定同一个异质方差场 `v = 10^U(−3,3)`、`n = 4000`，**只改权重律 `w`**：

| 注入的权重律 | `E` | 门 `<1e-12` |
|---|---:|:-:|
| `w = 1/v`（正确实现） | `0.0` | True |
| `w = 1` | `5.23e+3` | **False** |
| `w = 1/√v` | `2.44` | **False** |
| `w = v` | `3.59e+5` | **False** |
| `w = 1/v^0.99`（幂次错 1%） | `1.01e−4` | **False** |
| `w = 1/v^1.01`（幂次错 1%） | `9.68e−5` | **False** |

复现（**不写回 `results/`**，仅 `/tmp`）：

```bash
python3 - <<'PY'
import numpy as np
def efficiency(w_used, v_true, eligible):      # 逐字 exp_p4_04_brightness_forward.py:123-128
    w = w_used[eligible]
    v = v_true[eligible]
    var_w  = np.sum(w ** 2 * v) / np.sum(w) ** 2
    var_opt = 1.0 / np.sum(1.0 / v)
    return float(var_w / var_opt - 1.0)
rng = np.random.default_rng(0)
v = 10.0 ** rng.uniform(-3, 3, 4000)          # 异质方差场，固定
for name, w in [("w=1/v", 1.0/v), ("w=1", np.ones_like(v)),
                ("w=1/sqrt(v)", 1.0/np.sqrt(v)), ("w=v", v.copy()),
                ("w=1/v^0.99", v**-0.99), ("w=1/v^1.01", v**-1.01)]:
    E = efficiency(w, v, np.ones(v.size, bool))
    print(f"{name:14s} E={E:12.5e}  gate={abs(E)<1e-12}")
PY
```

```bash
# 逐字取自 exp_p4_04_brightness_forward.py:123-128，不做任何代数化简
def efficiency(w_used, v_true, eligible):
    w = w_used[eligible]
    v = v_true[eligible]
    var_w  = np.sum(w ** 2 * v) / np.sum(w) ** 2
    var_opt = 1.0 / np.sum(1.0 / v)
    return float(var_w / var_opt - 1.0)
rng = np.random.default_rng(0)
for name, v in [("const", np.ones(4000)),
```
