- `:422`（§4.1 链路）`-> cat.background / cat.noise_sigma (= 1.4826*MAD, 整帧 sigma-clip 2 轮)`
- `:484`（G1）`` `noise_sigma` = 整帧 1.4826×MAD（sigma-clip 2 轮） ``
- `:133`（§2.3 符号表）`由**帧本身**稳健估计（MAD×1.4826）`

生产码逐字（`star_detector.cpp:113-119`）：

```
115:  *bg = nth_value(scratch, kn, kn / 2);
117:  double sum = 0;
118:  for (...) sum += (keep[i] - *bg) * (keep[i] - *bg);
119:  *sigma = std::sqrt(sum / static_cast<double>(kn > 0 ? kn : 1));
```

`1.482602218505602 * mad`（`:103`）**只作裁剪窗尺度**，不进入输出值。生产码自述佐证两处：
- `star_detector.cpp:31`：`:67 的裁剪后 RMS，即 StarCatalog::noise_sigma`
- `module_adapters.cpp:7360-7361`：`**整帧 2 轮 median±3*1.482602218505602*MAD 裁剪后 RMS**`

且 canon 自己的 §2.7 结构主导行（`:216`）已写对"裁剪 RMS"，§3 的实验脚本（`rt_sigma_hat_applicability.py:32`）也算的是残差 RMS ⇒ 原文三处与本文自身证据**互相矛盾**。已统一为"裁剪后残差 RMS（`1.4826·MAD` 只作裁剪尺度、不作输出值）"，并同步修正 G4（`:487`）的"整帧 MAD"。

**这一修正不触碰任何实验数据**：P8/P8b/P8c/P9/P10/P12/P13/P14 的全部数值表与判据**逐字未动**。
