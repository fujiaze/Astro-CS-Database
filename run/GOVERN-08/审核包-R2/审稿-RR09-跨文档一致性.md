## 1. 本轮结论

**判定：阻断（6 条阻断，须前台裁决后方可定稿）。**

本轮结论与前台线索的偏差集中在三处：① 退出码争议的**定性错了**——「acsd-stage2 以裸整数占用枚举码值空间」只是表层，真问题是**生产面身份四方互斥**，它使整个退出码域的定级悬空；② 数据对象争议的**广度窄了**——断链不是 2 处，是权威顶点自身的三处互不自洽（§3.1 / 附录 A / GLOSSARY）；③ **前台完全没有交办符号口径这一层，而它藏着本轮唯一一处「最高设计 3 行内自相矛盾」的错误**——`ACSD_DESIGN.md` §2.2 的 SNR 分子，前台列为争议的只有计数与退出码。

### 最重的 3 条发现

**B5（阻断）`ACSD_DESIGN.md` §2.2 在 3 行内自相矛盾：SNR 的分子是 `F` 还是 `F_ref`。**
`:124` 定义「逐源 `SNR_F = F/σ_F`，`F` 为已扣独立局部背景的拟合域通量」（分子 = 实测 `F`）；`:127` 紧接着写「叠加权重…`w = SNR²/F_ref² = 1/σ_F²`」——该恒等式代数上要求分子 `SNR = F_ref/σ_F`。`:329`（§5.3）则写「同一物理量 `SNR = F_ref/σ_F`」。⇒ **顶层从未声明 `F` 与 `F_ref` 是同一量或不同量**；取不同值时权重差 `F_ref²/F²`（见 §4 R4 反例，实测可达 **400 倍 / −2.60 dex**）。

**B1（阻断）生产面身份四方互斥，两份一级正本直接对撞。**
`docs/engineering/CLI_PROTOCOL_V1.md:97` 写「生产面 `classification=production` 的行**恰一 = `acsd`**」；`docs/engineering/PUBLIC_API.md:1081-1082` 写「**生产入口 = stage2 工具**（`stage2.cpp main :112`）」。两者同为 `docs/engineering/` 一级正本，同层冲突按 `AGENTS.md` §3 无法自行裁决。这一条决定 B2 与争议点②其余全部发现的定级（见 §4 R1）。

**B2（阻断）`AstroCsExitCode` 是第三套进程退出码语义表，11 个码值里 9 个与正本语义相反，且真从 `main()` 返回。**
`lib/infrastructure/pipeline/orchestrator/cpp/include/orchestrator.h:143-166` 定义 `AstroCsExitCode`，与 `lib/infrastructure/cli/exit_codes.h:8-18` 的 `acsd::ExitCode` 在 9 个码值上语义相反（例：`2` 在正本是 `ARGS`「CLI 参数或配置错误」，在 `AstroCsExitCode` 是 `DLL_LOAD_FAILED`）。`main.cpp:391` `return exit_code;` 原样把该值作为**进程退出码**返回。`orchestrator.h:196` 写好了 `is_process_exit_code()` 闸，**全仓零调用点**。

**B3（阻断）权威顶点自身三处互不自洽，`GLOSSARY.md` 更把一个现行 canonical 对象宣告为退役别名。**
`docs/ACSD_DESIGN.md:174`（§3.1）列 11 个对象；同文件 `:666`（附录 A）只列 10 个且多出 `control_ivar`；`docs/GLOSSARY.md:5` 自称「唯一术语权威」却只覆盖 13 个对象中的 4 个，并在 `:16` 把 `coverage → support` 列为 legacy alias——而 `coverage` 是 `ACSD_DESIGN.md:174` 明列的独立对象、`:175` 规定「端口只接同一种对象，接错判红」。触发 `ACSD_DESIGN.md:657` 的发布候选条件「追溯无断链」。

### R4 —— 把 `ACSD_DESIGN.md` §2.2 代入它自己的推导，权重差 400 倍

这是本轮**最强的反例**，因为它只用顶层三行就能构造，不需要任何下级文档或实验数据。

**构造**：取一帧，`F_ref = 1000 ADU`（逐帧参考通量）、`σ_F = 10 ADU`（逐源通量不确定度）、该源**实测**通量 `F = 50 ADU`。这三者取值在该帧上完全合法（`F_ref` 是逐帧固定参考电平，`F` 是逐源实测，差一个 `F_ref/F = 20` 的因子）。

| 取法 | SNR | 按 `:127` 的 `w = SNR²/F_ref²` | 按 `:127` 的 `w = 1/σ_F²` |
|---|---|---|---|
| `:329`（§5.3）分子 = `F_ref` | `1000/10 = 100` | `100²/1000² = 1.000e-2` | `1/100 = 1.000e-2` ✓ **恒等式成立** |
| `:124`（§2.2）分子 = `F` | `50/10 = 5.0` | `25/1e6 = 2.500e-5` | `1/100 = 1.000e-2` ✗ **差 400 倍** |

- 两条路径的比值 = **1/400**，权重偏小 400 倍 = **−2.60 dex**。
- **纯代数**：不涉及任何实现细节、任何门、任何运行，只要 `:124` 与 `:127` 两行都成立，推导就自相矛盾。
- **根因不是笔误**：`:124` 的 `F` 是**已扣独立局部背景的实测拟合域通量**（有物理含义），`:329` 的 `F_ref` 是**逐帧参考通量**（另一物理量）。两者在 `docs/detail/UNIFIED_MODEL.md:45` 中被明确写成两个不同对象承载的「同一物理定义、同逐帧参考通量 `F_ref`」——**顶层把两个物理量塞进了同一个符号的分子**。
- **实验层独立撞名**：子代理取证 `实验/absolute-snr/REPORT_paper.md:118-121` 用的是**第三种分子** `SNR(x,y)=S_src/σ_w`（该像素自身源电平）。代入正本冻结定权式 `w=SNR²/F_ref²` 得 `S_src²/(σ_w²F_ref²)`，要恒等于 `1/σ_F²` 须 `S_src≡F_ref`，而 `F_ref` 是逐帧固定量、`S_src(x,y)` 逐点变化 ⇒ 恒等式在该口径下**不成立**。（此项为子代理结论，本轮未逐行复核，归属 P2 实验轮。）

**这条反例推翻的现行结论**：`ACSD_DESIGN.md:329` 那句「三者都产出**同一物理量** `SNR = F_ref/σ_F`」被当作全链 SNR 口径已闭合的证明。它只证明了**三种重建方式之间**同口径，**没有证明 §2.2 与 §5.3 之间**同口径——而 `:124` 恰恰用的是另一个分子。
