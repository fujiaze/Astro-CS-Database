**复算二：`SNR²/F_ref² ÷ 1/σ_F² − 1` 的最大偏差**

逐行算 `ident = ((F/σ)²/F²) / (1/σ²) − 1`：
`2.22e-16 / 0 / 0 / 0 / −1.11e-16 / −2.22e-16` ⇒ **最大 2.22e-16 = 1 ulp**（`ulp(1.0) = 2.220446e-16`）。
归档自报 `pairing_identity.max_rel_dev = 4.44e-16 = 2 ulp`（其探针点不同），量级一致。
⇒ **偏差只有浮点舍入，1–2 ulp。恒等式没有破裂。**

**复算三：漂移来自哪里（机理）**

归档件自带冻结方差组成式：`σ_i² = σ_sky² + F·P_i/g`（gain > 0），`σ_F² = 1/Σ(P_i²/σ_i²)`。
`σ_i²` **显含 `+F·P_i/g`** ⇒ `σ_F` 是 `F_ref` 的函数 ⇒ `w = 1/σ_F²` 必然随 `F_ref` 变。

实测印证：

```
m_ref=4 : F_ref=2.56351e+08  σ_F=14044.1809  1/σ_F²=5.069991e-09
m_ref=9 : F_ref=2.56351e+06  σ_F= 1408.9809  1/σ_F²=5.037207e-07
σ_F 变化 9.9676×   F_ref 变化 100.0000×   1/σ_F² 变化 99.3534×
```

最小二乘拟合 `σ_F² = 1.887412e+04 + 7.693460e-01·F_ref`（最大残差 5.88e+03，机器精度量级）——
**常数项 = 天光+读出，线性项 = 源光子散粒**，证实 `σ_F²` 对 `F_ref` 线性。

**对照组（决定性）**：天光受限臂 `gain = 0` ⇒ `σ_i² = σ_sky²` 与 `F` 无关 ⇒ `σ_F` 为常数 ⇒
`mref_drift_rel = 4.44e-16`（逐位不变）。源主导臂 `gain = 1.3` ⇒ `mref_drift_rel = 0.0383`（3.83%）。
**两个臂的唯一差别就是 `gain`，即源光子散粒项。** 这是一条干净的假判据，且它翻红在源主导臂。

### 2.2 判定

复核的机理**成立**（我独立复算逐项印证）：实测 3.83% 漂移来自 `1/σ_F²` **自身随 `F_ref` 变**，
不是恒等式破裂；且该数字出自一个自标 `evidence_eligible: false` 的门。

**原 `:291-293` 的三重缺陷**：
1. 相邻两行自相矛盾（同段先称「代数恒等」，紧接着称「只近似成立」）；
2. 归因错误——把漂移说成「归一不再与 SNR 完全抵消」，而 `F_ref` 的归一**任何时候都精确相消**；
3. 据此推出的适用域限制（「跨帧比较必须限同一 `m_ref` 档」）挂在一个**并不存在的适用域限制**上。

### 2.3 处置（改前 → 改后逐字）

**`docs/science/DISPUTE_RESOLUTION.md` §27 终裁：**

改前：
> `w` 对 `m_ref` 的不变性是**代数恒等**（SNR 与 `F_ref` 同源，归一在 `w = SNR²/F_ref²` 中相消）：天光受限臂实测逐位不变（相对偏差 ≈ 4e-16），**生产组成臂（σ_F² 含源光子散粒项）只近似成立**，实测 `m_ref` 档漂移 1.9%–4.2%；亮端 1 mag ⇒ SNR × 2.512 仅是记录口径。

改后：
> 权重换算式 `w = SNR²/F_ref² = 1/σ_F²` 是**代数恒等**，在任意噪声组成下都精确成立（分子 `F_ref` 与分母 `σ_F` 随 `m_ref` 同步变化，归一在 `SNR` 中相消）。但 `w` **不是**对 `m_ref` 不变的量：逐像素方差含源光子散粒项 `σ_i² = σ_sky² + F·P_i/g`，故 `σ_F² = 1/Σ(P_i²/σ_i²)` 是 `F_ref` 的函数，`w = 1/σ_F²` 随参考电平单调变。天光受限臂（`gain = 0`，`σ_i²` 与 `F` 无关）实测 `w` 逐位不变（相对偏差 4.44e-16）；源主导臂（`gain = 1.3`）实测 `m_ref` 档漂移 3.83%（档区间读数 1.9%–4.2%）。漂移是**被加权量随源亮度变化**的结果，不是恒等式破裂。

**依据**：复算一至四（上文）；冻结组成式 `σ_i² = σ_sky² + F·P_i/g`（归档件自带）。

**`docs/science/CONTROL_WEIGHT_SNR.md` §8a 第 3 条（被污染的传播面）：**

改前（**错误的机理句**）：
> **机理**：σ_F² 含源光子散粒项，源主导时 F_ref 的归一不再与 SNR 完全抵消。

改后：
> **机理**：逐像素方差 `σ_i² = σ_sky² + F·P_i/g` 含源光子散粒项，故 `σ_F² = 1/Σ(P_i²/σ_i²)` 是 `F_ref` 的函数；同件 `sigma_F_adu` 随 `F_ref` 由 14044.18 降到 1408.98（99.35×，对应 `F_ref` 的 100.00×），`w = 1/σ_F²` 因而随参考电平单调变。**漂移是被加权量随源亮度变化的结果，不是归一相消被破坏。**

同时改掉同条上半句的**同源错误**：
- 改前：「`w = SNR²/F_ref²` 对 `m_ref` **逐位不变**……变更 `m_ref` 只改记账口径不改权重」
- 改后：「权重换算式 `w = SNR²/F_ref² = 1/σ_F²` 是**代数恒等**……恒等式在任何噪声组成下精确成立」＋「**`w` 的适用域**：`w` 对 `m_ref` 不变当且仅当 `σ_F` 与 `F_ref` 无关」
