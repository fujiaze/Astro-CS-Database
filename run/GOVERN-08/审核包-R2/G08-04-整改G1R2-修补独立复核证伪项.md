## 3. 全局泊松增益盲区：**补判据 C6**（不是登记了事）

### 3.1 复核的反证与机理

`n_e = 1.01 × Poisson(lam_e)`（等效整体量子效率错 1%）在**全部 17 个用例上全绿**，`1.06×` 才被 A2 生产臂抓住。机理（复核与我一致）：C1 用 `lam ≡ 0` 完全不经过泊松；C4(a)(b) 走 `MODE_MEAN_ONLY` 跳过泊松；C4(c) 的 m² 比值对同乘缩放不变；唯一能看见绝对光子上限的 A2 生产臂与 C5(b) 闭合都吃 5% 容差 ⇒ **≤2.5% 的全局泊松增益盲区**。作者只在 §5.2 为 P4 的 E 度量登记了同构的「全局缩放盲区」，**噪声链侧未登记**。

### 3.2 为什么只有一阶矩能看见它（本轮的关键论证）

把泊松抽样整体乘 k（`n_e = k·Poisson(lam)`）时：

```
E[n_e] = k·lam        Var[n_e] = k·lam        ⇒    Var/E ≡ 1（恒成立）
```

⇒ **任何纯方差类判据**（比值、对解析预测的闭合、二阶矩对 `lam + σ_R²`）在**数学上不可能**看见 k。唯一不变量是**均值本身**：它必须等于 `lam_e = t·(src+sky)·m + t·D(T)` 这个**独立解析期望**。这与 E 对 `v` 的齐次盲区同构，但解法不同——E 无外部绝对锚点，而光子上限**有**（`lam_e` 由入参解析算出）。
