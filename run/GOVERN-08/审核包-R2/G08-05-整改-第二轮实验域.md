## 6. B5 — P3 的 oracle 撤回本身没被反例检验（独立推导）

单据要求「独立推导，必须自己算，不许照抄」。以下推导全部由我从第一性原理做出，
**未查阅仓内任何既有结论**；随后才回头核对实现。

### 6.1 推导 1 —— gnomonic 雅可比（向量场法）

gnomonic（TAN）投影：平面点 `(ξ,η)` 是过球心、方向 `(ξ,η,1)` 的射线与单位球的交点，故其单位法向为

```
n(ξ,η) = (ξ, η, 1) / sqrt(1 + ξ² + η²),      记 R = 1 + ξ² + η²
```

单位向量场的立体角元：`dΩ = | n · (∂n/∂ξ × ∂n/∂η) | dξ dη`。逐项算：

```
∂n/∂ξ  = ( 1+η²,  −ξη,  −ξ ) / R^{3/2}
∂n/∂η  = ( −ξη,  1+ξ²,  −η ) / R^{3/2}
(∂n/∂ξ × ∂n/∂η) = R · (ξ, η, 1) / R³
n · 上式 = R^{1/2} · R / R³ = R^{−3/2}
```

⇒ **J_GNOMONIC = dΩ/dA = (1 + ξ² + η²)^{−3/2}，指数 3/2。**

（这一步我第一次算错成 `R^{+1/2}`——漏了 `n·(ξ,η,1)` 里那层除法；用独立有限差分复核后改正。）

### 6.2 推导 2 —— 极坐标法（独立复核）

`r = √(ξ²+η²)`，`tanθ = r`，故 `θ = arctan r`。`dΩ = sinθ dθ dφ`，`dA = r dr dφ`。
`sinθ = r/√(1+r²)`；`dθ/dr = 1/(1+r²)`（**注意是 1/(1+r²)，不是 (1+r²)**——符号方向搞错会
把指数翻成 +1/2）。于是

```
dΩ/dA = [r/√(1+r²)] · [1/(1+r²)] / r = (1+r²)^{−3/2}      ✓ 与推导 1 一致
```

积分得圆盘总立体角 `Ω(ρ) = 2π(1 − 1/√(1+ρ²))`。

**数值验证**（6 个采样点，解析 vs 对单位法向场的中心差分）：相对误差 `1.0e-12 … 1.9e-11`。

### 6.3 推导 3 —— 各向同性蒙特卡洛（不假设任何雅可比）

抽样各向同性方向（归一化高斯 ⇒ 均匀立体角），保留 gnomonic 半径 `√(ξ²+η²) ≤ ρ` 的，
乘以 2π（只采了北半球）得 Ω：

|---|---|---|---|

| 0.5 | 0.66333352 | 0.66274481 | 8.9e-04 |
| 1.0 | 1.84030237 | 1.83760846 | 1.5e-03 |

| 5.0 | 5.05095129 | 5.05093614 | 3.0e-06 |

（在 MC 噪声内吻合。）

### 6.4 判决 —— 半球极限（与雅可比约定无关的物理判据）

gnomonic 圆盘半径 ρ 对应角半径 `θ₀ = arctan ρ`。**ρ → ∞ 时该帽趋于整个半球 = 2π sr。**

| ρ | Ω（指数 2 版） | Ω（指数 3/2 版） |
|---|---|---|
| 1e2 | 3.141278526 | 6.220356595 |
| 1e6 | 3.141592654 | 6.283179024 |

**指数 3/2 版趋于 2π sr，正是半球 ⇒ 正确。**
