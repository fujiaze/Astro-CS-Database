# 全局 SNR² 加权加性梯度规范

## 数学目标

对所有同滤镜 HISS 的有效稀疏控制点，联合求解全局共识曲面 `T(p)` 与每帧加性校正面 `C_i(p)`，使 `I_i(p)+C_i(p)` 在局部 SNR²/逆方差和质量权重下相对 `T(p)` 的稳健偏移总体最小。

- 总曲面不要求是真实天光绝对低频亮度；
- 不选择单一参考帧；
- 采用全体帧 SNR² 加权零均值规范消除整体自由度；
- 只允许加性校正，禁止乘性项；
- 曲面目标、排异目标和最终融合目标独立，但都可使用质量信息。

## 控制点

- 仅从真实覆盖、support有效区域采样；
- 暗天空可采样，无覆盖区绝不采样；
- 动态星点/饱和/星晕/异常掩膜；
- 采用局部窗口的稳健位置与方差，不取单像素；
- 结构边缘和配准敏感区降权；
- 每帧、每HEALPix区域设置密度上限。

## 求解器

优先紧支撑球面 RBF、分层 B-spline 或 HEALPix 分区 surface spline，使用稀疏矩阵和稳健迭代。重叠图不连通时分量独立求解。

## 验证

- 已知加性梯度注入；
- 高/低SNR组合；
- 不同覆盖与边缘；
- 星点污染和异常；
- 恢复误差、高SNR保护、曲面连续性和真实结构保持。
