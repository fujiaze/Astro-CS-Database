# 变更控制

## 变更等级

- C0：文档/注释，不改变契约；
- C1：模块内部实现，外部行为不变；
- C2：配置、CLI、接口或数据 schema 的兼容扩展；
- C3：破坏性 ABI/格式/流程变更；
- C4：系统架构变更。

## 要求

| 等级 | 必需内容 |
|---|---|
| C0 | task report + 文档检查 |
| C1 | 失败测试 + 单元/回归 |
| C2 | 契约测试 + 注册表更新 + 兼容说明 |
| C3 | ADR + 迁移工具/兼容层 + 版本升级 |
| C4 | ADR + 原型证据 + 分阶段迁移 + 回退方案 |

任何 Agent 在任务中发现更高等级变更需求，应停止实现，提交变更建议，不得自行扩大范围。
