# 12 Stage 2 系统调试与验证 Spec

## 1. 为什么单独设阶段

Stage 2 同时包含球面几何、背景建模、重叠图、稳健统计、SNR 权重和大规模 I/O。仅凭“生成了 HCSD”无法证明正确。必须先用可控合成数据逐层验证，再进入真实马赛克。

## 2. 调试顺序

### S2-0：输入与格式

- 所有 HISS 格式版本兼容；
- nside/nested/单位一致；
- 输入哈希和元数据可追溯；
- 损坏 HISS 立即失败；
- 不允许混合不兼容测光坐标系而无警告。

### S2-1：无梯度、无离群、等权

输入两帧相同常量或已知图像，重叠区结果必须等于输入；非重叠区不改变。先禁用所有复杂功能。

### S2-2：覆盖与重叠图

验证：

- overlap graph 边；
- 不连通分量；
- RA=0、高赤纬；
- 子叶索引；
- nside<64 与 nside≥8192；
- 帧顺序不影响覆盖结果。

### S2-3：已知加性梯度

注入可解析梯度，验证：

- 样本提取；
- 星拒绝；
- 梯度模型恢复误差；
- gauge fixing；
- 非重叠区外推行为；
- 是否真正迭代以及收敛日志。

### S2-4：SNR 模型与权重

验证局部 SNR：

- IDW 角距离与单位；
- SNR² 权重；
- 高 SNR 帧贡献更大；
- 低 SNR 控制点不污染梯度；
- 无 SNR 模型时的明确策略；
- 极端/零/NaN SNR。

### S2-5：离群值剔除

分别验证 standard 与 winsorized：

- 单个 cosmic ray；
- 单帧整体异常；
- 样本数 1/2/3/多帧；
- 分位数参数；
- 回退路径不得静默丢参数；
- 拒绝统计可导出。

### S2-6：完整组合

已知梯度 + 局部 SNR + 离群值 + 部分覆盖，同时开启全部功能，验证模块组合不发生顺序错误。

### S2-7：真实多帧

使用 DS-STAGE2，比较：

- 校正前后接缝指标；
- 背景差；
- 恒星通量比；
- 噪声；
- 覆盖边界；
- 视觉检查。

## 3. 核心量化指标

### 3.1 接缝指标

在每条帧边界两侧取带状区域，计算：

- 中位数差；
- MAD/RMSE；
- 一阶梯度跳变；
- 95/99 分位绝对差。

Gate 阈值由 DS-SYN 真值和真实基线实验冻结。

### 3.2 通量保持

对非饱和恒星比较校正前后孔径流量比。梯度校正不应系统性改变星体通量比例。

### 3.3 权重正确性

对只有噪声不同的相同真值帧，输出方差应接近理论 SNR² 加权结果。

### 3.4 离群抑制

注入离群值后，输出误差和被拒绝比例必须符合预期；不能仅证明“程序没崩”。

### 3.5 确定性

改变输入文件顺序、线程数、重复运行，结果应在定义容差内一致。

## 4. Stage 节点设计决策

当前代码把完整输出放入 `GRADIENT_SPHERE`，`STACK` 仅返回成功。P06 必须选择并记录：

- A：代码仍合并，但架构只暴露一个 Stage 2 节点，删掉伪节点；
- B：拆分为真正的 gradient 与 stack 两阶段，并定义中间模型；
- C：保留两个逻辑阶段但单 API，编排器报告内部子阶段。

不允许继续保留“空节点成功”而文档声称执行了算法。

## 5. 通过 Gate G6 的最低证据

- 以上 S2-0 至 S2-7 全部适用测试；
- HISS 输入与 HCSD 输出契约测试；
- 接缝、通量、权重、离群、确定性指标；
- 至少一个不连通覆盖和一个高赤纬/RA=0 案例；
- 回退路径测试；
- 峰值内存与大规模运行；
- 独立复核报告。
