## P1 通量积分拟合（测光校准到星等坐标系）

### 论文核心主张
以 Gaia XP 绝对分光刻度锚定的模型通带 T(λ)·Q(λ)·λ 积分建立测光星等坐标系，用 Tukey biweight IRLS（c=4.685）稳健拟合逐帧零点：k_photo 的零点平移不变量逐位成立、MAD→σ 常数为解析恒等式（二分复算差 1.6e-16），星等窗口径差被量化为最高 0.032 mag 的系统差源——P1 输出的每 dex 精度直接成为下游 SNR 链的误差底座。

### 吸收的证据源
- **路线1**: c(n=64) 推导腿闭合 √1.361=1.1666、MC 渐近 1.170（+0.3% 登记）；mag_tolerance 边际保护 ≈0（S4）；H1 锚 STALE（:227/:355）；S12 场形弯曲度是科学量；arXiv 号自纠 2208.00211。
- **路线2**: c=4.685 ARE=0.9499974（statsmodels 4.685065 六位一致，exp1）；σ_residual=0.0493 dex / k_photo=1.00156 / ZP_syn=28.9358 mag 端到端用例；24 处锚仅 1 处内容不符（D-06 判误判）；新发现 1.4826 四位截断、mag_max_arr 耦合。
- **路线3**: 锚 15/15 真实（S00）；Kafadar 1983 一手锚（S01）；n=3 时 MAD 偏差 1.49×、渐近式 1.2533/√n 在 n=3 高估 7.4%（S11）；k_photo 平移不变量逐位（S04）；σ_residual=0∧fit_ok=true 不可估计（S05）；1.0 dex 粗筛门非恒真（0.055/1.110，S12 相关）；max_stars=5000 ⇒ σ_ZP=6.36e-4（S 链）；FOV 缓冲/钳位冲突（S07）。
- **定量主数**: c=4.685（ARE 0.9499974）；0.6744897501960817 / 1.4826（解析恒等式）；c(n=64)≈1.152（MAD-σ̂ 相对 SE，归 P2 链）；ZP 窗平移 ≤0.032 mag；匹配半径 2.0px 正确率 ≥0.996、歧义 ≈r² 理论。

### 链条接口数值
- **上游给 P1**: F_instr（ADU，PSF 域解析通量，禁 5×5 盒和 N-25 口径）；F_syn = ∫F_λ·T·Q·λ dλ（W·m⁻²·nm，Gaia XP 336–1020nm @2nm，G<15 限制）；G_Gaia（仅进 delta/ZP 诊断）；质量位（饱和预排除）。
- **P1 给下游**: k_photo = 10^(−location) [F_syn 单位]/ADU；I_photo = k_photo·m(x,y)·I_cal；sigma_residual（dex）/ sigma_mag = 2.5·sigma_residual（mag）；ZP_syn；zero_point_scatter_mag；ivar′ = ivar/α²（α = k_photo·m）给 P5。
- **精度约定**: r_i（dex）与 delta_i（mag）不共用容差；σ_residual=0 ∧ fit_ok=true 的帧不可估计（P4 须按非完美控制点处理）；门①（n<3）⇒ NO_DATA、scale=1.0/σ=0/fit_used=0，下游按未标定分支；n=3 时 sigma_mag 系统性下偏（MAD 有限样本偏差 1.49×）→ P2 低星数帧零点不确定度被低估；ZP_syn 三星下限的抽样误差是 n≈2338 满载的 25.7 倍。

稀疏控制点到稠密 SNR 场的重建以自然三次样条＋值域钳制（natural_bicubic_spline_clip_v1）为生产默认（节点复现 ≤3.6e-15，Δ/ℓ≲1 可分辨域内精度最优），定权恒等式 w = SNR²/F_ref² = 1/σ_F² 以机器精度成立且 γ=2 由定义唯一确定（γ≠2 等价放弃 GLS 最优：γ=1 效率 3.73、等权 104.58）——控制值是否携带亮度（源项）决定 P5 权重是否最优（丢失源项效率损失最劣 12 倍）。
