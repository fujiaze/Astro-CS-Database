### D-01 P3 外接半径：路线1 实测 1.1284（极冠、随 N 单调降）vs 路线2/3 的 0.9941→1.0415（单调升、与台账逐位吻合）

- **涉及**: P3守恒映射算子/路线1/report.md:114-131（S7）、:186-187（相左第4/5条）；路线2/report.md:189-200（exp06）、:202-217（exp07）；路线3/report.md:17。
- **分歧一句话**: 两路对 HP_CIRCUMRADIUS_FACTOR=1.25 所包的最大"像元中心→边界角距/hp_res"给出趋势相反、数值不同的全天穷举结果。
- **双方证据**:
  - 路线1（中心=相邻 ring 纬度中点，边界=4 角点+每边 7 点，N=4→64）: max r_circ/hp_res = 1.13233 / 1.12936 / 1.12862 / 1.12844 / 1.12839，最坏 dec +73.40°→+88.97°（极冠 ring 1），单调降，收敛 ~1.1284；"N=4 时 ring-1 像元中心→极点 = acos(0.9583) = 1.133·hp_res"；并判"审查员 1.04 档覆盖不了极冠像元""单调性应为降"。
  - 路线2（全天穷举 N=4→64，真像元中心→角点）: max(R_c/hp_res) = [0.9941, 1.0196, 1.0322, 1.0384, 1.0415]，单调升收敛 ~1.0415，最坏在赤道带缝附近；最小裕量 1.25/1.0415 = 1.2002（≥20%）；经纬对照格反例 4.516 击穿 1.25（HEALPix 特化性证明）。与 02 台账逐位吻合。路线3 采 1.0415 作控制点上球的 1.05·hp_res 安全封装（实测控制点角距 ≤0.5941·hp_res）。
  - **闭合判据（本轮对账补几何）**: 路线1 的收敛值 1.12839 与闭式 2/√π = 1.1283792 五位一致；2/√π = √2·ρ₁/hp_res，其中 ρ₁ = arccos(1−1/(3N²)) ≈ √(2/3)/N（极冠内环角距），√2·ρ₁ = (2/√3)/N 恰为极冠 apex 叶（chart 方块 [0,1/N]²，极点为一角）外角 (1/N,1/N) 的极角——即路线1"相邻 ring 纬度中点"取心法在 apex 叶上把中心放到了叶外角纬度 z = 1−2/(3N²)（其自报的 acos(0.9583)@N=4 即此值），实测对象实为"极点→极冠叶远角"的叶对角尺度，不是外接半径。apex 叶真实中心 (1/2N, 1/2N) 到边界最远约 0.69·hp_res，不构成更坏点。
- **裁决**: **两者量的对象不同，数值各自内部自洽；台账口径以路线2/3 为准。** 路线2/3 量的是"HEALPix 像元中心→像元角点外接半径/hp_res"的全天 sup（→1.0415，与台账逐位一致，单调升系从下方收敛）；路线1 的 1.1284 是"极冠叶对角（极点→远角）/hp_res = √2·ρ₁/hp_res = 2/√π"这一几何常数（单调降系曲率高阶项收敛），其取心法在极冠 apex 叶上失效，1.1284 不得记作外接半径。统一口径结论：以"像元中心→边界最远点角距/hp_res"计的全天 sup ≈ 1.0415（N=64 实测），HP_CIRCUMRADIUS_FACTOR=1.25 安全裕量 ≥20.0%；两个口径下 1.25 均安全（1.0415 或 1.1284 均 < 1.25 ≪ 经纬格 4.516），故豁免结论（结构性安全缓冲、非科学量）三路一致维持。
- **影响文档**: 02_已确立的算法与验证程序.md §1（外接半径表，维持）；路线1 report 的 S7 结论表述须按本条改写（1.1284 改记为 √2·ρ₁/hp_res = 2/√π 几何常数）；P3 论文采用 1.0415 + 裕量 20% 表述，可附 2/√π 作为极冠叶对角常数。

### D-02 depth-8 残差超预算幅度：路线3 "15%"（1.153e-6 vs 1e-6）vs 路线2 "3.15 倍"（3.15e-6·hp_res）＋矢高单位应为 ρ₁

- **涉及**: P3守恒映射算子/路线3/report.md:131-135（R3-07）；路线2/report.md:207-210（exp07）、:287-292（§4-④ 单位归属）。
- **分歧一句话**: 极冠边弦矢高在 depth=8 细分后的残差对 1e-6·hp_res 预算的超幅，三处读数为 15%、23%（02 台账）与 3.15 倍，且矢高常数 8.094e-2 的单位标注存疑。
- **双方证据**:
  - 路线3（实测梯子，细分比 3.651→3.999 十层渐近 4.0）: depth_needed = 7.971（Górski 口径 sag0 = 6.30e-2）；depth=8 残差 = 1.153e-6·hp_res，超 1e-6 预算 15%；台账 1.234e-6 = 8.094e-2/4⁸ 在其自身 sag0 下算术自洽；两支均 >1e-6，定性结论与口径无关。
  - 路线2（实测梯子，渐近收敛因子 0.275/层，慢于解析 1/4）: 达到 1e-6·hp_res 需 7.98 层；depth=8 残差 = 3.15e-6·hp_res，超阈 3.15 倍；并发现 02 §1.2 的 "8.094e-2·hp_res" 数值实际与 ρ₁ 单位匹配（实测 0.08012·ρ₁ ≈ 0.066·hp_res；ρ₁ ≈ √(2/3)/N），"hp_res" 标注疑似笔误；02 的"超阈 23%"即由 8.094e-2 误作 hp_res 单位＋精确 1/4 律推得。
- **裁决**: **统一单位（残差与阈值同以 hp_res 计）后，名义幅度为超预算约 15%**（路线3 实测 1.153e-6，与台账解析 1.234e-6 同档——后者仅是 sag0 单位错标下的解析值，量级不受影响）；路线2 的 3.15 倍降级为**保守上界**（其梯子早期层收敛比 3.65 显著慢于解析 1/4，属更保守的细分日程，不是名义幅度）。矢高常数记账统一为：sag0 = 8.094e-2·ρ₁（ρ₁ = arccos(1−1/(3N²)) ≈ 0.8165/N）≈ 0.066·hp_res，与两路实测 0.0630–0.0639·hp_res 一致。**max_depth 结论**：三路定性一致——depth=8 不能稳妥清偿 1e-6·hp_res 极冠矢高预算；**depth=9 在全部三处读数下清偿**（最保守 3.15e-6/4 = 0.79e-6 < 1e-6，名义 1.153e-6/4 = 0.29e-6），建议 max_depth 取 9 以上；若维持 8，须把预算放宽至 2e-6·hp_res 并如实登记。与路线1 S10 的工程事实合并：生产 spherical_overlap.cpp:857 的 WCS_ADAPTIVE_MAX_DEPTH = 12（cpp 是行为事实源，05 §11 写 8 应改 12）——12 ≥ 9，生产实现已满足矢高预算，需订正的是文档而非代码。
- **影响文档**: 02 §1.2（8.094e-2 单位改 ρ₁）；02/05 的"超阈 23%"表述（改为"+15%（实测）/上限 3.15×（保守梯子）"）；05 §11 depth 8→12（以 cpp 为准）并注明矢高预算需 ≥9；P3 论文采用"depth=8 残差 1.15e-6·hp_res（超 15%），depth=9 清偿"。
