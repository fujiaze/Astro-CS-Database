## 0. 结论摘要（供快速引用）

1. **k_corr 不是普适常数，也不含于 Fruchter & Hook (2002)**：该文全文（arXiv:astro-ph/9808087v2 子串级检索）不含 1.3883、1.4、k_corr、covariance 等字样；其唯一的定量相关噪声量是 noise correlation ratio R=σc/σp（§7 式(8)–(10)），唯一数值例 R=1.662（p=0.6, s=0.5，均匀充满 dither 假设）。
2. **1.3883 可被独立复现为「正本标定几何专属值」**：按原 MC 唯一几何记录（单帧 20×20 源图、源像素 300″/px、HEALPix nside=512 输出 412.26″/px、pixfrac=0.8、全 touched patch N≈225–251、σ_bg=逐实现 MAD 取跨实现中位）建立平面受控 MC，16 相位 × 8 seed（每点 NMC=2000）得 k_corr = 1.3445 ± 0.0416（相位间 sd），range [1.273, 1.425]。1.3883 落在该 range 内（上沿）；相位 ⊕ MC 合成不确定度 ≈ ±0.06。故 1.3883 的正确身份是：**该几何配置 + 该估计器口径下的单次 MC 实测值**，不是可解析常数。
3. **正确定性/定量表述（建议 P5 按此消费）**：control_variance = **k_gauss(N_retained) × k_geo(几何) × (π/2)·σ_bg² / N_retained**，即把冻结单数 k_corr 拆成两个物理上独立的因子：
   - **k_gauss(N)**：iid 高斯样本在「正本估计器口径」（逐实现 MAD → 跨实现中位）下对渐近基线 (π/2)σ²/N 的有限 N 修正：N=5: 1.63、N=9: 1.26、N=17: 1.14、N=25: 1.08、N=49: 1.05、N≥121: ≈1.00（表 T3）。它**与 drizzle 无关**（恒等几何直接定征 400k 实现：k_gauss(5)=1.6370）。
   - **k_geo(几何)**：drizzle 输出像素相关的纯几何因子 = k_corr/k_shape。正本几何下紧凑 patch k_geo ≈ 1.27 ± 0.03（N=9..169），全 touched patch（含边界混合）≈1.43–1.45；空间分散 patch ≈1.00；几何扫描全域 1.00–5.0（表 T4）。非高斯边际形状效应 ≤±5%（N≥9），可忽略。
4. **N=5 判定（定义域下沿）**：正本几何下正确值为 k_corr(5, 紧凑) ≈ 2.05 ± 0.09（=1.66×1.23）。冻结值 1.4 在 N=5 处**低估 control_variance 约 32%（标准误低估约 14%）**；空间分散采样（远散 patch）时为 1.54。**「N=5 时配套 k_corr=1.4」不成立。**
5. **标定域内部的 2 倍变化**：k_corr 查表域为源像素角尺度 [300,600]″/px（输出固定 nside=512→412″）。ρ=输出/源尺度比从 1.374（源 300″）降到 0.707（源 ≈583″）时，k_corr 从 ≈1.37 升到 2.5–3.0（表 T4）——**即使冻结 1.4 在其声明标定域内也不保守**；逐帧查表必须按 (ρ, pixfrac) 双参数标定，而不是单常数。
6. **文档措辞勘误候选（证据登记，裁决权在负责人）**：PHASE2_UPM.md §5 称「N=5 时渐近式低估 8.5%」。直接定征（400k 实现）：Var(median, n=5)/渐近式 = 0.9113，即渐近式**高估** 9.6%（与文献值 Var(X_(3),n=5)=0.2868σ² 一致）；小 N 处 k>1 的真实机制是 **MAD 尺度估计器的有限 N 偏置**（median MAD/σ = 0.746 @N=5）。文档的实用结论（小 N 需要修正）方向正确，机制描述方向相反。

## 1. 假说

审计前提（既有独立复算只证得 k>1、N_eff≈1.56 量级，1.3883 无法从已文档化信息复现）指向三个互斥假说：

- **H1（常数说）**：k_corr≈1.3883 是某种几何不变量（类似 F&H 的 R），对 N 与几何配置普适；
- **H2（配置说）**：1.3883 是正本 MC 特定几何配置 + 特定估计器口径的实测值，可复现但随 (N, 几何, 口径) 变化；
- **H3（伪相关说）**：1.3883 主要不是输出像素相关，而是 drizzled 值边际分布非高斯形状（或估计器偏置）的伪影。

本实验设计为三者可判：受控 MC 复现正本几何（判 H2）、N 扫描与几何扫描（判 H1）、效应分解（判 H3）。

## 2. 方法

### 2.1 正本几何溯源（k_corr=1.3883 的全部已存记录）

| 来源 | 记录内容 |
|---|---|
| lib/algorithms/drizzle/healpix_drizzle/tests/control_median_mc_test.cpp（唯一几何记录） | 单帧 20×20；源像素 300″/px（deg_per_px=300/3600，:56）；nside=512 NESTED；pixfrac=0.8；NMC=2000；seed=20260816+r；σ=10 ADU；patch=首个 tile 全部 touched leaf（sumArea>0），N_retained 跨实现中位 =251；σ_bg=逐实现 1.482602218505602×MAD 取跨实现中位；k_corr=Var_emp(median)/[(π/2)σ_bg²/N]；合理门 [0.98, 2.0] |
| docs/science/PHASE2_UPM.md §4/§5/§14 | 冻结 1.4；定义域 1<k_corr；标定域 = pixfrac∈[0.5,1.0] × 源像素角尺度 [300,600]″/px；「N=5 时渐近式低估 8.5%」（§5 注） |
| docs/science/UNCERTAINTY_AND_COVARIANCE.md:48-49 | 「MC（pixfrac=0.8，2000 实现）k_corr=1.3883，N_eff≈181/251」 |
| docs/algorithms/PHASE2_SAMPLER.md §5.4 | k_corr 定义式（本实验的被检对象）与适用域三要素声明要求 |

**定义式（本实验的被检对象）**：

    k_corr = Var_MC(median of patch) / [ (π/2)·σ_bg² / N_retained ]            (1)
    σ_bg   = 跨实现中位( 1.482602218505602 × MAD(patch − median(patch)) )       (2)

N_retained 在原 MC 中 = patch 输出像素数（≈251），即 **N 是 patch 内样本数（输出像素），不是帧数**；原 MC 为**单帧** drizzle（相关仅来自单帧源像素向多输出像素分裂），任务书中「N=2..10」若读作帧数则不适用于该量的标定面——本实验按 N_retained 语义扫描（5..289 全域），并另行给出 1/2/4 帧变体（T5）。

### 2.2 平面受控 MC（本实验模型）

drizzle 是线性算子，输出值（正本测试 :115/:160 的取值口径 sumFlux/sumArea）为

    v_p = Σ_j (a_jp / D_p) · x_j / A_drop,   D_p = Σ_j a_jp                (3)

a_jp = drop_j（pixfrac×源像素的收缩方形 footprint）与输出像素 p 的交叠面积；权重对 j 凸组合归一。平面方形网格下式 (3) **解析精确**；球面实现的面积残差 δ = A_drop/(pixfrac²A_pixel)−1 = 1.9e-7（θ=300″/px, pixfrac=0.8；DRIZZLE_GEOMETRY.md §10 DISP-DRZ-009 段），对二阶统计的影响 O(δ) ≪ MC 统计噪声（≥3%），故平面模型是正本几何的忠实实现（差异主要来自 HEALPix 像素形状/邻接拓扑与相对相位，见 §5 诚实边界）。

实现：code/mc_kcorr.py（交叠面积解析广播、(n_out×n_src) 算子矩阵、逐实现 patch median/MAD、k_corr 及 8 段 batch SE）。全部 seed 写死为具名常数（SEED_BASE=20260816 与正本同基；各实验组独立基见代码头）。纯 Python+numpy，不 import 仓库任何代码。

### 2.3 效应分解设计

对同一几何同时跑三臂：

- **全臂**：v = M·x，x~N(0,σ²) 逐实现 → k_corr（式 1）；
- **形状臂**：从全臂 patch 值的**合并边际经验分布** iid 重采样同规模样本 → k_shape（隔离非高斯边际形状 + 有限 N 偏置）；
- **参考臂（恒等几何）**：M=I（pixfrac=1.0、输出=源网格、phase=(0.5,0.5) 逐位对齐）→ k_gauss(N)（纯 iid 高斯参考，隔离估计器有限 N 偏置）；
- 分解恒等式：**k_corr = k_shape × k_geom**，且 k_shape ≈ k_gauss(N) × (边际形状超额)。
- 交叉验证：由算子精确计算 patch 协方差（高斯输入下精确）→ 最近邻平均相关系数；按 F&H 2002 式(8) 逐像素数值复核 R=σc/σp（G7）。

## 4. 结论：k_corr 的正确定性/定量表述（供 P5 control_variance 按消费 P3 产物引用）

**(a) 定性**：k_corr 是**几何与估计器口径的条件量**，= 「iid 高斯有限 N 修正 k_gauss(N)」×「drizzle 输出像素相关因子 k_geo(几何)」。它不是普适常数；F&H 2002 不含它（其对应量 R=σc/σp 是均值型/块和估计量层面的修正，且闭式 (9)(10) 以均匀充满 dither 为前提）。

**(b) 定量（正本标定域内）**：
- 源 300″/px、nside=512、pixfrac=0.8、单帧、全 touched patch（N≈225–251）：k_corr = 1.34±0.04（相位 sd），单次 MC 值可到 1.38–1.43——**1.3883 与冻结 1.4 属同一配置带**；
- 同几何紧凑 patch：k_corr(N) = k_gauss(N)×(1.27±0.03)，N≥9；N=5（紧凑）≈2.05±0.09，N=5（远散）≈1.54±0.04；
- 源 583–600″/px（查表域另一端）：k_corr ≈ 2.5–3.0（pixfrac 0.5–1.0）⇒ **冻结 1.4 在声明标定域内即不保守（低估 2 倍）**。

**(c) 消费规则（建议 P5 采纳）**：任何引用 control_variance = k_corr·(π/2)·σ_bg²/N_retained 的陈述必须同时声明 ① 所用 k_corr 的 (ρ=s_out/s_src, pixfrac, 帧数/dither, patch 构成) 标定元组；② N_retained 档位（N≤25 时 k_gauss(N)>1.08 不可忽略，N=5 时必须 ≥1.6）；③ 若借用 1.4，必须验证其标定元组与本产品几何一致——否则按 fail-closed 拒绝或现场重标（MC 成本 ~秒级，本实验 code/ 即可复用）。

**(d) 与 F&H 2002 的关系（哪一步解析、哪一步经验）**：式(3) 单输出像素方差（F&H 式(7)）在输入像素噪声独立假设下**解析精确**——本算子按式(8) 复核 R 与其闭式同量级（T6）。**F&H 明确否定**「输出像素独立」：相邻输出像素相关是其 §7.1 的开门论点。因此「输出像素 iid ⇒ Var(median)=πσ²/2N」这一步是被文献否定的近似；k_corr 就是把该被否定步骤修正回来所必需的因子，其数值**只能由受控 MC 或逐几何解析（式 3 + 相关矩阵 + 中位数渐近理论）给出**，是经验标定量，不是可从文献抄录的常数。1.3883 与 F&H 的 R=1.662 数值接近属巧合（不同估计量、不同几何、不同口径）。

## 5. 诚实边界

1. **平面模型 vs 球面 HEALPix**：交叠面积球面残差 δ≈1.9e-7（可忽略）；未建模的差异是 HEALPix 像素形状（非正方形）、邻接拓扑（可变中心距）与 NESTED 寻址。原 MC 正本 N_retained=251，本平面模型 225（相位 0.3,0.55）；该 ~11% 差异源于像素化形状，对 k_corr 的影响含在 ±0.04 的相位/几何带内，未单独分离。
2. **相对相位不可复现**：原 MC 的 HEALPix 网格相对帧 WCS 的相位无记载，本实验以 16 相位扫描量化其影响（sd=0.0416）；**1.3883 的逐位复现不可能，也不必要**——它在复现 range 内即完成归属判定。
3. **估计器口径**：本实验沿用正本 MC 口径（逐实现 MAD → 跨实现中位）。生产 σ_bg 是单实现 patch 的稳健尺度，其有限 N 偏置方向相同（N=5 时中位 MAD/σ=0.746 的直接定征即为单实现量），但生产口径的精确系数未另行标定（见 UNRESOLVED-4）。
4. **G0b 单次 N=5 档（1.767）与收敛值（1.634）差 ~2.7σ**：小 N 档 k_corr 的 MC 波动大（SE≈0.05@NMC=4000），已用 3×40000 收敛值与 400k 直接定征锁定；报告一律引用收敛值。
5. **多帧变体只做了等权、整数亚像素 dither**（1/2/4 帧）：生产 dither 场形更多样，未扫描；结论只到「多帧不消除相关」的定性层。
6. **文献**：F&H 2002 全文以 arXiv v2（PASP 发表版预印本）核验；PASP 正式排版页未单独抓取（DOI 10.1086/338393）。Serfling (1980) 未逐页核验（UNRESOLVED-5）。
