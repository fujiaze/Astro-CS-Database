  但对整个 drop 的相对偏差实测为 **+0.5ρ_max²（居中）到 +1.5ρ_max²（偏置）区间**，

- **求和型 vs 逐叶判据**：恰在保总量注入下，求和判据偏差落在双精度求和地板（多例**精确为 0**），

- **链条用例**：P1 帧 → P3 精确分割 drizzle → 12 个球面 SNR 控制点 → P4 IDW 稠密重建全链贯通：

## 1. 【链条位置】

P3 = **平面到球面的通量守恒映射算子**，位于五点科学链的正中：

    P1 通量积分拟合 ──> P2 跨帧绝对 SNR ──> 【P3 守恒映射算子】 ──> P4 重建稠密 SNR ──> P5 加性天光/无接缝
       (帧: 线性面亮度      (跨帧 SNR 传递、         (④ 面积交叠与分配:              (稀疏控制点上球后的       (球面叠加、
        ADU/sr, 方差)        控制点选择)               drop/leaf 交叠面积、            IDW/核插值稠密化)         天光尺度分离)
                                                      w_jp 归一、通量守恒、
                                                      SNR 控制点携带上球)

**上游给什么**（P1→P3）：线性格子帧——每像素面亮度 S_j（ADU/sr）与方差 σ_j²，
像素角点经 WCS（本实验用 TAN，Calabretta & Greisen 2002 §5.1.3 式 (54)）落到天球；
pixfrac 收缩后的 drop 多边形是 P3 的交叠原语。

**P3 做什么**：把每个源像素 drop 的球面足迹精确分割到 HEALPix 叶上（本仓创新：chart 平面
精确分割 + 逐边大圆裁剪），权重 w_jp = a_jp/A_drop 保持面亮度（F&H 2002 式 (2)–(5) 的 s² 因子），
通量守恒 Σ_p F_p = Σ_j x_j；同时把 P2 的稀疏 SNR 控制点**携带上球**
（叶中心单位方向 + SNR + 方差约定）。

**下游拿去做什么**（P3→P4）：P4 以球面上稀疏控制点重建稠密 SNR 图（本实验以 IDW 复现其
插值语义）；P4→P5 再以稠密图支撑天光尺度分离。因此 P3 的量纲约定
（通量 ADU、SNR 无量纲、方向单位矢量/弧度）与精度约定（分割精确性 ⇒ 权重和=1 的逐位性）
直接约束 P4/P5 的正确性——exp10 用一个贯通用例锁定这些接口。

**本清单 10 项在链条中的位置**：F-01/F-02/F-03 是叶几何（P3 的球面基底）；
F-04 是权重归一（P3 的通量守恒核）；F-05/F-06 是自适应细分（P3 的精度-算力旋钮）；
F-07 是 coverage 量化（P3 输出落盘的表示层）；F-08/F-09/F-10 是三条数值路径的误差预算
（球面逐边裁剪 / gnomonic 平面支 / 切平面支）；R2# 附加项（VOS/l'Huilier 互校、
禁抄值、判据类型分离）分别锁定 P3 的面积原语、常数与验收判据。

## 3. 逐项结果（F-01 … F-10 与附加项）

### exp01 — F-01：A_leaf = π/(3N_side²)（文献腿 + 恒等式 + 负例）

- **文献腿**：Górski et al. 2005 (ApJ 622, 759) §5 开篇原句 "A HEALPix map has
  Npix = 12 N_side² pixels of the same area Ωpix = π/(3N_side²)"（refs.md §1，arXiv 全文核验）。
  理论推导腿：02 §1.1 L16–43 的 chart 推导（|J|=π/3 解析恒等 ⇒ 每基面 π/3、每叶 π/(3N²)），
  本路以有限差分雅可比独立重算（面 0/4/8 三类支全部 |J|/(π/3)−1 ≤ 2.2e-16 量级）。
- **实验**（code/exp01_leaf_area.py，无随机）：三写法恒等
  a1 = π/(3N²) ≡ a2 = 4π/(12N²) ≡ a3 = 4π/Npix 对 N ∈ {4,16,64,256,1024} **逐位相等**（|Δ|=0.0）；
  面类型中点积分（400² 采样）闭 4π。
- **负例**：真值 π/(3N²) 时 metric_true = 0.0；错候选 π/(4N²) 时 metric = 0.25 ≠ 0（判据非退化）。
- **结论**：F-01 三腿齐备。PASS。

### exp02 — F-03：含极像元极限亏缺 −9.968368384e-2 与绝对亏缺律 0.104369/N²

- **理论腿**：02 §1.3 闭式推导：极叶 A_quad·N² → 2√2/3 = 0.9428090，
  A_quad/A_leaf → 2√2/π = 0.9003163161，极限相对亏缺 −9.968368384e-2。
- **实验**（code/exp02_polar_pixel.py，无随机；真实边界 K=96 段采样）：
  N ∈ {8,…,256} 极叶（面 0 叶 (N−1,N−1)）四角弦四边形 vs 真实边界面积：

  | N | 弦四边形 rel | 绝对亏缺 ×N² |
  |---|---|---|
  | 8 | −9.7128e-2 | 0.101712 |
  | 64 | −9.9644e-2 | 0.104347 |
  | 256 | −9.9681e-2 | **0.104386** |

  极限 −9.96812e-2（N=256）与闭式 −9.968368e-2 差 2.5e-7（绝对）；绝对亏缺律收敛值
  0.104386 vs 声称 0.104369（差 1.6e-4 相对，来自弦采样的 O(1/N²) 修正项）。
- **结构性发现**：全天弦四边形拼接**精确闭 4π**（N=16 全天和 |Σ/4π−1| = 8.9e-16）——
  相邻叶共享同一大圆弦边，弦-四边形铺分无缝无叠，故弦模型的逐叶偏差在求和层面自消。
  这解释了为什么"弦四边形总面积"不能作为逐叶 ALE 的替代判据。
- **负例**：真实边界采样自身度量 = −1.3e-5（极叶边界曲率 N 无关 ⇒ 采样地板恒定），
  比被测亏缺小 7600 倍且不随 N 收敛，不可能模仿被测的 N-收敛律；门控要求亏缺/地板 > 1000。
- **结论**：PASS（−9.968e-2 与 0.104369/N² 均独立确认）。

### exp03 — F-04：w_jp = a_jp/A_drop 归一与通量守恒构造（文献腿补齐）

- **文献腿**：Fruchter & Hook 2002 §2：式 (2)/(3) 迭代含 "where a factor of s² is introduced
  to conserve surface intensity"；式 (4)/(5) 权重和 W = Σ a·w（refs.md §2 全文核验）。
  02 §2 L199–216 的构造与 DRIZZLE_GEOMETRY.md 的 w_jp = a_jp/A_pixel,j 面亮度保持陈述
  与 F&H 一致（s = pixfrac）。
- **实验**（code/exp03_flux_conservation.py，无随机）：TAN 8×8 网格（2″/px，pf=0.8）映射进
  面 4 chart 平面（dΩ = dz dφ 精确，|J| = π/3），drop 四边形被 (z,φ) 网格矩形精确分割：

  | 量 | 实测 | 理论 |
  |---|---|---|
  | max |Σ_p w_jp − 1|（drop 归一） | **0.0** | 0（构造精确） |
  | mean Σ_p w'_jp（A_pixel 归一） | 0.6400000000064 | pf² = 0.64 |
  | S_p/B0（N_p 分母，正确） | max dev **0.0** | 0（常数面亮度 fixture 归零） |
  | S_p/B0（D_p 分母，错误） | 1.56249999998 | 1/pf² = 1.5625（+56.25%） |
  | Σ_p F_p / Σ_j x_j − 1 | **0.0** | 0（通量守恒） |

- **负例（pf=1 退化）**：drop 角点 = pixel 角点 ⇒ 两种分母重合，全部偏差度量归零（语义写入 json）。
- **背景数复核**：1/pf²−1 = 56.24999999999998%，1/pf⁴−1 = 144.14062499999994%，
  2.5·log10(1/pf²) = 0.48455006504028186 mag —— 与 02 表逐位一致。
- **结论**：F-04 三腿齐备。PASS。

### exp04 — R2#：VOS vs l'Huilier 互校 + 解析锚 + 归一化负例

- **实验**（code/exp04_area_operators.py，无随机，全天穷举 N=2..64 每叶对角三角剖分）：
  (i) 八分体三角解析面积 π/2：VOS 与 l'Huilier 相对偏差均 **0.0**（逐位）；
  (ii) 全天逐叶互校最坏相对偏差 **2.50e-12**（N=64），与审查记录的 ≤3.3e-12 同量级；
  (iii) 全天弦四边形面积和闭 4π：|Σ/4π−1| < 1e-12（N=2..64 全部）；
  (iv) 负例：原始（未归一）顶点放大 1.064 倍使 VOS 偏移 **+3.947e-2**，
  而归一化后 l'Huilier 偏移**精确 0.0** —— l'Huilier 的自由自检确实免疫长度缩放。
- **诚实边界**：02 声称该注入下 VOS 偏移 "~9.6%"；本路对八分体三角实测 3.95%
  （解析可验证：VOS(1.064,0,0;0,1,0;0,0,1) = 2·atan(1.064)，相对 π/2 为 +3.95%）。
  "~9.6%" 数值未见复现（见 §4-②）。
- **结论**：PASS。

### exp05 — F-09/F-10：gnomonic +3ρ²/2 与切平面 −θ²/2 预算

- **实验**（code/exp05_projection_budgets.py，seed=20260927 仅用于 200 个随机取向）：

  **gnomonic（TAN）支**：
  - 局部面积元定律 dA_plane = dA_sphere/cos³ρ ⇒ +3ρ²/2 **逐点精确**；
  - 圆盘级（对盘内 ρ' 平均）：(tan²ρ/2(1−cosρ) − 1)/ρ² = **0.7500**（= 3/4，非 3/2——
    盘面积权重偏向小 ρ'，⟨ρ'²⟩/ρ² = 1/2）；
  - 多边形级：居中 quad 的 bias/ρ_max² = **+1.0**；离切点 ρ_c=2e-3 的 quad =
    **+1.4**。即 bias/ρ_max² ∈ [0.5, 1.5]，随几何在区间内变化；
  - 符号：**正**（平面高估球面），单向，与 02 判断一致。

  **正交切平面支**（复现生产 planar_polygon_area_n：垂直于中心方向投影 + 有向叉积和）：
  - 200 随机取向方 quad：bias/θ_half² = **−1.0000**（θ ∈ {1e-4,…,1e-2} 全部）；
  - 换算到"最远顶点角距 θ_max"约定：bias = **−θ_max²/2**（θ_max=1e-3 ⇒ −5.0e-7），
    **单向负偏**（200 例全部 < 0），θ→0 负例度量 = 0.0（精确归零）；
  - 注释 "4e-8" 与"对称 ×(1+O(θ²))"两句确认错误（差 12.5 倍 + 缺符号）。

- **负例**：gnomonic 在 ρ=1e-7 的解析比值触到 1−cos 的浮点相消地板（实测 +8e-4 假偏差）——
  这正是 02 所说"球面 VOS 的 det 在 θ~1e-7 相消"的镜像现象，作为诚实边界记录；
  干净的归零负例由正交支 θ=1e-9（偏差 0.0）承担。
- **结论**：PASS（对 02 的确认与细化见 §4-③）。

### exp06 — F-02：HP_CIRCUMRADIUS_FACTOR = 1.25（豁免论证 + 实证腿）

- **为什么它不是科学量（豁免理由）**：1.25 是 drop/叶配对剪枝用包围圆半径的安全裕量，
  其真值由 HEALPix chart 几何唯一决定，不含可变化的物理输入；它是**工程常数**而非科学量。
  但审计纪律要求它不能是"拍脑袋"：本实验给出其实证腿与反例。
- **实验**（code/exp06_circumradius_margin.py，无随机，全天穷举 N=4..64）：
  max(R_c/hp_res) = [0.9941, 1.0196, 1.0322, 1.0384, 1.0415]（N=4→64），
  **单调递增**、收敛于 ~1.0415，最坏叶在赤道带缝附近——与预测区间 [0.994, 1.0415] 一致；
  最小裕量 1.25/1.0415 = **1.2002**（≥20%）。
- **反例（判据非退化）**：同叶数的经纬对照格（lat-lon），最坏 R_c/√A = **4.516**，
  彻底击穿 1.25 —— 证明 1.25 是 HEALPix chart 特化的，不具网格无关普适性。
- **结论**：PASS（豁免成立 + 实证锁定）。

### exp07 — F-05/F-06：极冠矢高尺度不变性、细分深度梯子、禁抄值 211034.6

- **实验**（code/exp07_polar_sagitta_ladder.py，无随机）：
  (1) 极叶外边（z=1−s²/3, s∈[1/N,2/N]）相对大圆弦的矢高：
  N=64/256/1024 实测 0.06391/0.06394/0.06394 ×hp_res —— **尺度不变性确认**（散布 2.5e-5）；
  (2) 细分梯子（边二分 k 层）：矢高按 ~1/4 每层收敛（实测渐近因子 0.275/层）；
  达到 1e-6·hp_res 阈值需 **7.98 层**；depth=8 残差 = **3.15e-6·hp_res**，超阈 **3.15 倍**
  —— depth 上限 8 不能在极冠边清偿 1e-6·hp_res 阈值（F-06 不足性确认，
  且比 02 的"超阈 23%"更严重，见 §4-④）；
  (3) 禁抄值：211034.6″ vs 真值 √(π/3)·(180/π)·3600 = 211076.28514206142″，
  相对误差 −1.9706e-4；**整数 NSIDE 阶梯演示**：目标尺度 211034.6″ 时
  错常数接受 NSIDE=1（等号），真值要求 NSIDE=2 —— 一个 nside 档 = 线性分辨率差 2 倍。
- **单位归属发现**：02 §1.2 写 "8.094e-2·hp_res"；实测常数为 **0.08012·ρ₁**
  （ρ₁ = arccos(1−1/(3N²)) ≈ √(2/3)/N，差 1% 以内）或 0.0639·hp_res。
  "8.094e-2" 的数值与 ρ₁ 单位匹配，"hp_res" 单位标注疑似笔误（见 §4-④）。
- **结论**：PASS（尺度不变性与 depth-8 不足性两判据成立；数值单位归属修正）。

### exp08 — F-07：coverage 量化步 1/255

- **实验**（code/exp08_coverage_quantization.py，随机部分 seed=20260927）：
  生产语义（C lround 半远离零）：q = lround(255S)，Ŝ = q/255。
  细网格（510×4000+1 点）全枚举：
  - **S/Ŝ−1 最坏 = −0.5**（在 S=1/510，q=1，Ŝ=2S）—— "−50%" 确认；
  - q=254 格 sup |S/Ŝ−1| = **0.5/254 = 1.968504e-3** —— 02 表 "+1.9685e-3" 确认
    （注：该值是 S/Ŝ−1 约定下 sup，审查员原判"舍入约定矛盾"实为约定混用，见 §4 尾注）；
  - S < 1/510 ⇒ q=0 ⇒ 相对误差无定义（实测 3999 个网格点不可表示）—— 半个 LSB 以下的
    coverage 无法表示，为文档化边界；
  - 方差律：SNR² 放大 (1+r)²−1 = 2r+r²，最坏点 = **−0.75**（"−75%"，SNR 减半）确认。
- **负例**：step → 0 序列 {1/255, 1/510, 1/1020, 1/2040} 最坏 |r| 单调下降趋于 0
  （无量化时度量恒 0）。
- **语义风险（诚实记录）**：banker's rounding（numpy.round）在 S=1/510 给 q=0——
  同一 S 下整像素静默丢失；"−50%" 最坏值仅存在于半远离零约定下。
- **结论**：PASS。

### exp09 — R2#：求和型 vs 逐叶判据（15 数量级分离）

- **实验**（code/exp09_sum_vs_per_leaf_criteria.py，seed=20260927）：
  N=512 chart、2048 叶随机正值；三类**恰保总量**注入（成对交换 / 反对称扰动 / 全局零和扰动）

### exp10 — 链条用例：P1 → P3 → P4 接口贯通

- **实验**（code/exp10_chain_usecase.py，seed=20260927）：
  P1：64×64 TAN 帧（2″/px，中心 z=1/3 面内），线性面亮度 + 高斯核、逐像素方差；
  P3：pf=0.8 drop 多边形经 (z,φ)→(u,v) 逆 chart 精确分割到 N=4096 叶
  （|dΩ/du dv| = π/3 精确），w_jp = a_jp/A_drop；
  控制点：12 个叶中心（单位方向 + SNR + 方差传播约定）上球；
  P4：IDW（power=2）稠密重建于 100 个球面查询方向。
- **接口锁定结果**：
  - Σ_p w_jp 偏差 = **4.44e-16**（双精度地板；实现注记见下）；
  - 通量闭合 Σ_p F_p/Σ_j x_j − 1 = **0.0（精确）**；
  - 控制点处 IDW 重建偏差 = **0.0（精确）**；
  - 负例：控制点全常数 ⇒ 重建偏差 ≤ 2.66e-15 ≈ 0（权重和=1 ⇒ 常数场精确复现）。
- **量纲/精度约定（写入 json 的 units 块）**：帧 = ADU/sr + ADU²；叶通量 = ADU；
  SNR 无量纲；方向 = 单位矢量（角度弧度）。精度约定：权重和的逐位性来自
  精确分割构造，任何破坏它实现都应判红。
- **实现注记（诚实边界）**：权重和的残差对坐标量级极其敏感——drop 多边形顶点在
  O(0.75) 绝对坐标下做 O(1e-5) 尺度求积时，shoelace 与 S-H 边界插值
  （t = sp/(sp−sc)）会把双精度舍入放大 ~1e5 倍（实测 1.16e-5）。
  修复：shoelace 前平移到质心 + 裁剪在质心坐标系进行，残差降到 4.4e-16。
  **这一发现对生产代码是可检验的风险点**（见 §5 建议）。
- **结论**：PASS。

## 4. 与审查员结论相左之处（4 项）

1. **F&H 2002 pinpoint 已取得**。审查记录称"Fruchter & Hook 节号 pinpoint 未到位"。
   本路取 arXiv:astro-ph/9808087v2 全文核验：式 (2)/(3) 迭代式的 s² 因子
   （"where a factor of s² is introduced to conserve surface intensity"）与式 (4)/(5)
   权重和定义在 §2，pinpoint 完整可引（PASP 114, 144, DOI 10.1086/338393）。
2. **Górski §5.3 "边界非测地线" 可核**。审查认为该 pinpoint 不可核；
   本路在 arXiv:astro-ph/0409513 全文 §5.3 首句直接核得
   "Pixel boundaries are non-geodesic"。pinpoint 成立。
3. **gnomonic "系数错 3 倍"需要限定**。审查（及 02 §3.5）称注释 "相对误差 ~ρ²/2 ≈ 2e-6"
   系数错 3 倍（应为 +3ρ²/2 = 6e-6）。本路实测：+3ρ²/2 是**逐点面积元**定律（精确），
   但对整个 drop 的相对偏差依赖几何：居中 drop 实测 **+0.5·ρ_max²**（此时注释的 2e-6
   恰好正确），偏置 drop 可达 +1.4·ρ_max²，圆盘级平均 +0.75·ρ_max²。
   **结论**：作为"误差预算上界"，6e-6 是保守正确值；但"系数错 3 倍"的表述过强——
   注释值在居中情形是准精确的，错的是把一个几何依赖量写成了单一常数。
   （符号单向为正、需上界化预算这两点与审查员一致。）
4. **极冠矢高 8.094e-2 的单位归属 + depth-8 超阈幅度**。02 §1.2 "8.094e-2·hp_res"：
   实测常数为 0.08012·ρ₁（ρ₁ ≈ √(2/3)/N，即极叶内环角距）而 0.0639·hp_res——
   "8.094e-2" 的数值与 ρ₁ 单位匹配到 1% 内，"hp_res" 标注疑似笔误。
   连带地，depth=8 残差：按 02 的 8.094e-2 与精确 1/4 律推得"超阈 23%"；
   本路实测残差 3.15e-6·hp_res，**超阈 3.15 倍**（渐近收敛因子 0.275/层而非 0.25）。
   定性结论一致（depth 8 不足以清偿阈值），幅度需修正。
   另：审查记录的"顶点缩放 1.064 ⇒ VOS ~9.6%"未复现，八分体三角解析值为 +3.95%
   （2·atan(1.064) 与 π/2 之比，可解析验证）。

**尾注（非相左，属澄清）**：02 量化表 "+1.9685e-3 = 0.5/254" 是 S/Ŝ−1 约定下
q=254 格的上确界（S=253.5/255 处），与 lround 半远离零约定自洽；"-50%"（S=1/510）
与 "+1.9685e-3" 分属两个约定（S/Ŝ−1 与格内 sup），审查记录的"舍入约定矛盾"实为
两约定并存的表述问题，数值本身全部复现。
