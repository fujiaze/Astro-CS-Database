## 【链条位置】P3 在 SCI 链上的接口（含贯穿用例）

链条：**P1 通量积分拟合（根基）→ P2 跨帧绝对 SNR → P3 守恒映射算子（本模块）→ P4 重建稠密 SNR → P5 加性天光去除与无接缝叠加**。阶段间只经磁盘产品 + manifest + 哈希交换。

P3 的三对接口，每一对都在本路线实验中被实际走过一次：

1. **上游 P1→P3（输入量）**：P1 交付每帧标定像元值 `x_j [ADU]`、方差 `v_j [ADU²]` 与 WCS。E4 的合成就是按这个合同供给的（`x = B0 * A_pixel`、`v_in = 4.0`），并验证了方差二次律 `v→α²v ⇒ Var_out→α²Var_out`（α=3 实测比值恰 9.000000）。
2. **上游 P2→P3（控制点上球）**：P2 的跨帧绝对 SNR 是帧域量，必须经 chart 分配映射到球面 leaf 才能进入 P3 的球面累加。E1 第 7 节实现了该接口的可验证内核：控制点 `(φ, z)` → 等面积 chart 逆映射 `(u, v)` → leaf id（赤道支菱形域内 3661 个采样点往返误差 ≤ 1.1e-16，128 网格 leaf id 一一点位稳定）。量纲约定：P2 交出的 SNR 是无量纲量，控制点坐标是 `(φ, z=sin δ)`（弧度、无维）。
3. **下游 P3→P4（输出量）**：P3 产出的 per-leaf 累加器 `(sumFlux, sumNorm, sumArea, sumVar)` 由 P4 取去重建稠密 SNR：`SNR_leaf = F_p/N_p / √Var_p`。E4 验证了这组累加器在 drop 归一口径下的全部代数性质（守恒、表面亮度复现、负例判决）。leaf 物理面积由 S1 的 `A_leaf = π/(3N²)` 提供（E1 双法互校到 ≤ 9.1e-11 相对偏差），P4/P5 的 per-steradian 换算依赖它。
4. **nside 决策（P3 对整个链的下游分辨率供给）**：`finest_arcsec → nside` 的换算由 `HEALPIX_SCALE_PER_NSIDE_ARCSEC` 决定（S2/E1b）。P4 的稠密图分辨率与 P5 的接缝尺度都继承这一决定——禁抄值 211034.6 会在每个倍频程窗口内少取一阶 nside（E1 实测：finest=105527.7″ 时正确 nside=4，禁抄值给 2，**丢 2 倍分辨率**）。

贯穿用例（一个控制点的全程）：帧域标定像元 (P1) → 控制点绝对 SNR (P2) → `(φ,z)` 逆 chart 分配到 nside=256 的某个 leaf（E1，往返 1.1e-16）→ 该 leaf 以 `w_jp = a_jp/A_drop,j` 参与多帧 drizzle 累加（E4：S_p=F_p/N_p 精确复现 B0，守恒残差 ~1e-14）→ leaf 面积 824.516739″ 见方（`211076.28514206142/256`，E1）→ P4 以 `(F_p, Var_p)` 重建稠密 SNR → P5 以稠密 SNR 加权去天光。P3 是唯一同时接触"通量守恒"与"球面度量"的环节——这正是 05 规格里被审查的科学量集中地。

## S1 `A_leaf = π/(3N²)`（三腿补齐；幻觉锚 DRIZZLE.md:44-50 一并处置）

- **假说**：H1 等面积 chart 两支的 Jacobian 恒等 `|J| = π/3`，故 leaf 精确面积 `A_leaf = π/(3N²) = 4π/(12N²)` sr；H2（负例）扰动 chart（注入 |J| 偏移 ε=5e-4）必须使度量脱离零。
- **文献腿**：Górski et al. 2005 §5 明文（refs.md R1）：Ω_pix = π/(3N_side²)。**一手已核。**
- **实验腿（E1，`code/e1_leaf_area_and_scale.py`）**：有限差分 |J|（赤道支 1089 点、极支 527 点）+ (φ,z) 鞋带真面积（N∈{16,64,256}，每档 4000 leaf）+ VOS 弦模型对照 + 扰动负例。
- **结果**（`results/e1_leaf_area_and_scale.txt`）：

  | 检验 | 数值 |
  |---|---|
  | 赤道支 max||J|/（π/3）−1| | 1.711e-10 |
  | 极支 max 偏差 | 9.197e-10 |
  | N=16/64/256 max|A_true/A_analytic−1| | 2.5e-13 / 6.3e-12 / 9.1e-11 |
  | 同上 vs 4π/(12N²) | 完全一致（同值） |
  | 弦模型偏差（N=16→256） | 1.60e-3 → 7.1e-6（~1/N² 收缩，喂给 S3） |
  | **负例** ε=5e-4 注入 | 正确 chart 度量 6.3e-12，扰动 chart 度量 5.000e-4 ≠ 0 ✓ |

- **结论**：A_leaf = π/(3N²) 三腿齐备（文献一手、实验双锚、自含推导见 chart 定义）。DRIZZLE.md:44-50 的锚错位（内容实为 w_jp/通量公式而非 A_leaf）应改锚至 05 §11 或本文 E1。
- **诚实边界**：真面积经 (φ,z) 鞋带（chart 直边精确）；弦模型偏差非零且随 N 二阶收缩，其绝对形式即 S3 的对象。

## S5 gnomonic 面积预算 +3ρ²/2（细化审查员结论）

- **假说**：H1 逐点面积元律 `dA_plane = dA_sphere·sec³ρ`（sec³ρ−1 = +3ρ²/2 + O(ρ⁴)），符号恒正；H2 方形 patch 积分比 ≈ 0.5·ρ_max²（形状相关，+3ρ²/2 为保守上界）。
- **文献腿**：C&G 2002 §5.1.3 式(54)（refs.md R3，一手）；Snyder pinpoint UNRESOLVED（R7）。
- **实验腿（E5a，`code/e5_projection_budgets.py`）**：VOS 真值 vs TAN 平方面积扫描 h∈[1e-4, 2e-2]；独立环域求积（2e5 采样）对照逐点 sec³ 均值。
- **结果**（`results/e5_projection_budgets.txt`）：逐点 sec³ 律精确成立（pointwise/(1.5ρ_max²) = 1.000000 全段）；方形积分/(ρ_max²) = 0.5000（ρ_max<1e-2 段）；积分比 log-log 斜率 1.949→2；ρ=2e-3 处逐点预算 6.00e-06、方形积分 4.00e-06；环域求积 plane/sphere = 1.000075 vs 均值 sec³ = 1.000050（一致到 2.5e-05，差异来自常数密度假设）。
- **结论**：审查员的逐点 6e-6 数字正确；代码头注释的 2e-6 若指方形 patch 积分比则恰好正确（0.5·ρ²），若指逐点上界则错 3 倍——**注释措辞必须写明口径**。+3ρ²/2 作为上界预算保留，符号恒正（平面高估）确认。
- **诚实边界**：积分比系数 0.5 为方形 patch 专属；其他形状在 (1/6, 1/2)·ρ_max² 区间内。
- **复现**：`cd code && python3 e5_projection_budgets.py`
