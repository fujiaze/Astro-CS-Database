## 【链条位置】P1 在五点科学链上的角色与接口

P1（通量积分拟合）是全链根基：把每帧的仪器流量统一标定到**锚在 Gaia XP 绝对分光刻度的模型通带 T(λ)·Q(λ)·λ** 的测光星等坐标系（PHOTOMETRY.md §1 定标语义）。

- **P1 接收（上游输入）**：` F_instr `（ADU，PSF 域解析通量）、` F_syn = ∫F_λ·T·Q·λ dλ `（W·m⁻²·nm，Gaia XP 采样谱 × 滤镜 × QE，式-1）、` G `（Gaia G 星等）。量纲约定：` r_i = log10(F_instr/F_syn) ` 单位 dex（有量纲比值取对数）；` delta_i ` 单位 mag。**两者不共用容差**。
- **P1 产出（下游消费）**：` k_photo = 10^(−location) `（[F_syn 单位]/ADU，施加链最后一个因子 ` I_photo = k_photo·m(x,y)·I_cal `）；` sigma_residual `（dex）/ ` sigma_mag `（mag）；` ZP_syn `（绝对合成星等零点，mag）；` zero_point_scatter_mag`。
- **贯穿用例（exp8 S14 节实现）**：上游给 2000 颗星的 XP 型谱与 G → P1 产出 ZP_syn=28.9358 mag、k_photo=1.00156 [F_syn]/ADU、sigma_residual=0.0493 dex → 下游 P2（跨帧绝对 SNR）拿 sigma_kappa,stat ≈ 1.253·sigma_residual/√N = 0.00138 dex（零点统计误差）与 m_5 = ZP − 2.5·log10(5·σ_F) = 27.19 mag（5σ 深度）作为跨帧 SNR 链的输入。**有效性约定**：k_photo 绝对值无物理意义（吸收增益/口径/曝光），唯一有效判据是尺度无关的测光一致性；跨帧 k 不同是正常态（PHOT-GATE-DROP-001）。
- P1 的每帧 ` k_photo·m(x,y) ` 乘数直接决定 P3 上球的通量值域、P4 的 ivar 缩放（ivar′ = ivar/α²）与 P5 的 SNR 加权。P1 失帧（NO_DATA）⇒ 该帧从 photometry_applied 面缺失 ⇒ 下游全部对该帧降级。

## S1 · ` tukey_c = 4.685 `（Tukey biweight 形状参数；01/C11"书目缺"）

**假说**：c=4.685 不是任意数，而是使 biweight 位置 M 估计在正态样本下达到 95% 渐近效率（ARE=0.95）的标准调参值；该值可由闭式数值积分独立解出。

**方法**（` code/exp1_robust_constants.py `）：M 估计渐近方差 V = ∫ψ²φ / (∫ψ′φ)²，对 ψ(x)=x(1−(x/c)²)²（|x|<c）在 [−10,10] 均匀细网格（2×10⁶ 点）梯形求积；效率 = 1/V（均值估计量为基准）。负例：ψ(x)=x 恒等 ⇒ 效率必须=1。

**数据**：纯解析（无外部数据）；20001 点 Gauss–Legendre 与 2×10⁶ 点梯形两套求积互证（两次运行值一致到 7 位）。

**结果**（` results/exp1_robust_constants.json `）：

| 量 | 实测 | 参照 |
|---|---|---|
| ARE(c=4.685) | **0.9499974** | 名义 0.95 |
| 解 ARE=0.95 的 c | **4.6850649** | statsmodels ` _tables.py `：4.685065（6 位一致） |
| ARE(3.882662) / ARE(5.182361) | 0.9000000 / 0.9661624 | statsmodels 表 0.90 / 0.966162 行 |
| 负例 ψ=x 的效率偏差 | **1.4×10⁻¹²**（求积噪声底） | 真值无效应⇒归零 ✅ |
| P(|z|>4.685) | 2.80×10⁻⁶ | 截断点拒绝率 |

**结论**：c=4.685 是"正态 95% 效率"调参值，书目锚齐备（Beaton & Tukey 1974；Holland & Welsch 1977 权函数表；statsmodels robust/_tables.py 逐字核验）。**边界**：95% 效率只对"尺度已知"严格成立；本层 S 固定一次估计（先验尺度路线），若改"每轮重估尺度"必须把 c 与重估策略成对变更（崩溃点 11.9% vs 50%；Huber & Ronchetti 2009 §6.5；R MASS rlm.R 源码逐字核实 k0=1.548 阈值）。
**复现**：` cd code && python3 exp1_robust_constants.py `。**文献**：refs.md A1/A2/A3/A6。

## S2 · ` 0.6744897501960817 = Φ⁻¹(3/4) ` 与 ` 1.482602218505602 `（MAD→σ 常数）

**假说**：MAD 对正态的一致性常数 = 标准正态 3/4 分位数；其倒数即 1.482602218505602。

**方法**：erf 二分法求 Φ⁻¹(0.75)（200 次对分，无 scipy），与代码字面量比对；σ=0 负例并入 exp6。

**结果**：二分值 0.674489750196081**6** vs 代码 0.674489750196081**7**，相对差 **1.6×10⁻¹⁶**（双精度末位）；倒数相对差 1.5×10⁻¹⁶。

**新发现（审查两清单之外）**：` frame_photometry_fit.cpp:292 ` 的 ` zero_point_scatter_mag = 1.4826 * zmad ` 使用 **4 位截断值**（相对差 1.496×10⁻⁶），而 NOISE_ESTIMATION.md:213 明令"4 位 1.4826 只作约等于语境…与本层冻结值不可互换"。数值影响在 1e-6 相对量级（远小于产品精度），属**条款一致性缺陷**而非产物错值。

**结论**：常数正确且为解析恒等式（理论推导腿闭合）；ZP 侧截断写法违反冻结条款，建议按条款改写（不改判据方向）。
**复现**：同 exp1。**文献**：refs.md A4。

## S3 · ` irls_tolerance_dex=1e-6 `、` irls_max_iterations=50 `（求解器收敛档；02 V-8/D3）

**假说**：收敛容差与步数上限是数值求解器设置，其科学内容是"结果对进一步收紧不变"，而非物理量。

**方法**（exp1 S3 段）：200 星合成残差场（σ=0.05 dex），干净场与 20% 污染场（+0.8 dex）各 2000 帧，tol ∈ {1e-2, 1e-6, 1e-9, 1e-12} 全套重跑 IRLS/Tukey（S 固定一次，复刻 star_matcher.cpp:538-590 口径），比较中位 location 与迭代数；负例设计：污染场下松容差应可改变结果（能红）。

**结果**（诚实报告——负例未触发）：

| 场 | tol=1e-2 中位 loc (dex) | tol=1e-12 中位 loc | 跨度 | 最大迭代数 |
|---|---|---|---|---|
| 干净 | −1.77e-5 | +1.75e-4 | 1.93e-4 | 17 |
| 20% 污染 +0.8 dex | +1.73e-4 | +3.22e-5 | 1.41e-4 | 14 |

50 步上限在任何一档、任何一场均未触及（最多 17 步）；松到 1e-2 中位 location 的变化 ~2×10⁻⁴ dex（≈0.0002 mag），低于产品精度。**判红失败原因**：biweight 固定尺度 IRLS 在本设计下线性收敛极快，容差早在 1e-2 档就进入不动点邻域。

**结论与豁免建议**：` 1e-6/50 ` 在一维位置 IRLS 上属**数值收敛实现选择**（结构性），不是科学量——审查员把它列为"待确认常数"过重；应登记为"求解器设置 + 不变性实验为凭"。**边界**：不自动外推到空间增益 IRLS（多项式基 + 1e-9 档，01/C2 的 50 步截断问题在那一层）。
**复现**：同 exp1。

## S4 · ` mag_tolerance = 3.0 mag `（星等一致性预过滤窗）

**假说**（复刻 PHOTOMETRY.md:219-220 正向声明）：3.0 mag 窗是粗预过滤（等价通量比 10^1.2≈15.85×），作用是放走数量级级错配；鲁棒性由其后 IRLS/Tukey 承担；窗宽对整体乘性标度严格不变。

**方法**（` code/exp2_mag_prefilter.py `，500 帧/档）：每帧 500 星，真标定散度 σ_r=0.05 dex + 逐星颜色噪声 0.2 mag；10% 错配星 r 偏移 +0.8 dex。管线复刻 式-2→式-3：拒绝 ` |delta−median(delta)|>tol ` → IRLS/Tukey → location/sigma。扫 tol ∈ {0.5,1,2,3,5,∞}。不变性负例：全体 F_instr×10^0.5（=r 平移 +0.5 dex）后，内点集必须逐元素相同、location 平移精确、sigma 逐位相同（度量归零）；负对照：非平移不变窗口规则必须改变内点集（能红）。

**结果**（` results/exp2_mag_prefilter.json `）：

| tol (mag) | 中位 location (dex，真值 0) | p90\|loc\| (dex) | 中位 σ_residual (dex) | 中位 n_consistent | 中位 n_inliers |
|---|---|---|---|---|---|
| 0.5 | +6.33e-4 | 4.51e-3 | 0.0487 | 434 | 434 |
| 1.0 | −1.43e-4 | 4.26e-3 | 0.0497 | 450 | 450 |
| 2.0 | −1.28e-4 | 4.27e-3 | 0.0497 | 478 | 450 |
| **3.0** | **−1.03e-4** | **4.20e-3** | **0.0497** | **500** | **450** |
| 5.0 | −1.03e-4 | 4.20e-3 | 0.0497 | 500 | 450 |
| ∞ | −1.03e-4 | 4.20e-3 | 0.0497 | 500 | 450 |

（设计注记：错配星 r 偏移 +0.8 dex ⇒ delta 偏移 ≈2.0 mag，故 tol≥2.0 档 500 颗全进预过滤、由 IRLS/Tukey 拒掉 50 颗错配；tol≤1.0 档预过滤已把部分错配与正常尾星一并剔除。）不变性负例：location 平移偏差 **0（构造精确）**、内点集**逐元素相同**、scale 比值偏差 **0.0**、无效应度量 **0.0**；负对照（非不变窗口规则）内点集改变 ✅。3.0 mag ⇒ 通量比 15.84893 ✅。

**复现**：` cd code && python3 exp2_mag_prefilter.py `。

## S5 · FOV 缓冲 1.2、钳位 [1.0, 10.0] deg、条件窗 30.0（05 A-4b；01/C7）

**假说**：` fov = pixel_scale·√(W²+H²)/2 ` 是像素**边缘**约定下的精确外接半径；缓冲 1.2 等价于 WCS 径向误差预算 (1−1/1.2)≈16.7%·R；钳位窗与星数阈值/查询成本联动；现行"条件钳位"在 (1,30) 开区间内放行任意大 FOV。

**方法**（` code/exp4_fov_geometry.py `）：2000 组随机 (W,H,scale) 验证半径恒等式（真值无效应⇒偏差为 0）；预算换算像素；用 exp3 的 Gaia 计数模型给钳位窗成本敏感度；负例：真值半径已在窗内且 WCS 零误差 ⇒ 钳位不引入额外改变（度量 0）。

**结果**（` results/exp4_fov_geometry.json `）：

| 项 | 实测 |
|---|---|
| 半径恒等式（边缘约定） | 2000 组全部**精确为 0**；像素中心约定差 ≤0.71 px 当量（亚像素） |
| 1.2 缓冲误差预算（1″/px, 3000²） | R=0.589°，裕量 0.098° = **354 px**（真实 SIP 残差 ≲1 px） |
| 下钳位 1.0° 的作用 | 0.5°→1.0° 星池 ×4（547→2187 颗），2187≈**恰过 2000 阈值的 1.09 倍** |
| 上钳位 10.0° 的作用 | 查询成本封顶 7.5×10⁷ 字节谱（天空平均 2.2×10⁵ 星） |
| 条件窗 30.0 泄漏 | 现行代码 fov=20 **不钳位**（成本 4×于 10°）；fov≥30 才钳到 10 |
| 负例 | 真值半径 2.0°、WCS 零误差 ⇒ 钳位后 2.4°（缓冲项生效）、无效应度量 0 ✅ |

**结论**：三个数都是**工程选择**而非科学量（文献腿查无出处，refs.md B 表），但各自有可量化的保守方向：1.2 缓冲对现实 WCS 误差（≲数 px）有 2 个数量级裕量；下钳 1.0° 与 2000 星阈值在天空平均密度下**恰好咬合**（1.09×）——比"任意值"强得多的自洽性证据；上钳 10° 是成本封顶。05 把"条件钳位"改"无条件钳位"的实质效果 = 堵住 (10,30) 开区间泄漏（4-9× 成本）与 (0,1) 下侧放行（星池只有阈值 27%）——建议 05 明写这两条差异与方向。**边界**：计数模型为天空平均；拥挤场下 1.0° 早超阈值，下钳只影响贫星场。
**复现**：` cd code && python3 exp4_fov_geometry.py `（计数模型已内联）。
