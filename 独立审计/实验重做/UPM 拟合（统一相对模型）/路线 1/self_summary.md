## 四、关键发现摘要

### 4.1 最严重缺陷：D-01 零尺度伪方差

**危害等级**: 🔴 **P0 - 生产级静默污染**

**机理**:
```
patch 内≥50% 同值 ⇒ MAD=0 ⇒ s0 地板 1e-12 
  ⇒ cvar = 7.609e−27 (错误)
  ⇒ civar = 1.314e+26 (错误)
  ⇒ per-control 归一化后权重占比→100%
  ⇒ UPM 解被退化观测独占
```

**证据**:
- Serfling 1980: Var(median) = 1/(4N f(m)²) 要求 f(m)>0；全同值⇒f(m) 无穷大⇒无信息
- 实验复算：civar 高估 26 数量级（1e+26 vs 正确值 0）
- UPM 注入测试：该观测权重占比>99%

**修复方案**:
```cpp
// sampler.cpp:864
if (sigma_bg == 0.0) {
    out->control_ivar = 0;
    out->control_variance = std::numeric_limits<double>::quiet_NaN();
    return rc_no_scale_info;
}

// sky_plane.cpp:296 (同样修复)
if (s0 > 0) {
    sigma = s0;
} else {
    out->ivar = 0;
    return rc_no_scale_info;
}
```

**验收标准**:
- ✅ 文献支撑：经典稳健统计共识
- ✅ 实验验证：闭式复算证明错误
- ⏳ 代码整改：需在 sampler.cpp:864 + sky_plane.cpp:296 两处应用
- ⏳ 回归测试：补正例（零尺度 patch）与负例（正常尺度）

### 4.2 融合面洞察：UPM ↔ mosaic 的方差预算接口

**假说**: UPM 参数协方差应当能正确传播到最终马赛克的方差图

**实验设计 F1**:
- 构造已知背景的叠加场景（n_frames=10, n_pixels=1000）
- 运行简化 UPM 拟合→提取参数协方差
- 通过 Jacobian 传播参数不确定度到像素级方差
- 对比预测方差 vs 实测残差方差

**关键公式**:
```
Var(output_p) = Var_direct_p + J @ V_theta @ J^T
J = ∂(output)/∂θ （对 δ_k 的导数为 −1）
```

**预期指标**:
- 均匀覆盖区：误差 < 5%
- 边缘覆盖区：误差 < 15%

**状态**: 代码草稿完成，等待集成到完整 pipeline 测试
