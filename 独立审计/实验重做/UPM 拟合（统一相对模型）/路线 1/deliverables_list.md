## 🔄 三、融合面实验 F1 的发现

### 3.1 实验目的

验证 UPM 参数协方差能否正确传播到马赛克方差图（特别是边缘区域）。

### 3.2 实验设计

**输入**: 
- n_frames=10, n_pixels=1000
- 已知背景场 B_true（正弦起伏）+δ_k（逐帧偏移）+ 噪声σ=10

**流程**:
1. 生成合成帧
2. 模拟 UPM 加权最小二乘拟合
3. 提取参数协方差矩阵 V_theta
4. 通过 Jacobian 传播参数不确定度到像素级方差
5. 对比预测方差 vs 实测残差方差

### 3.3 实验结果

```
Predicted variance (mean): 90919.088320
Empirical variance: 1368.169173  
Ratio (pred/emp): 66.4531
Error: 6545.31%
Verdict: FAIL
```

### 3.4 重要发现

⚠️ **重大偏差**：预测方差比实测方差大 66 倍！

**可能原因**:
1. **Jacobian 计算有误**：当前假设 ∂output/∂δ_k = −1，但未考虑 UPM 的 gauge 约束与连通分量结构
2. **协方差缩放错误**：V_theta 的单位可能与预期不符（未正确计入权重 w）
3. **简化模型缺陷**：合成的均匀覆盖与实际 edge 区域的 coverage 差异未被体现
4. **参数相关性忽略**：实际 δ_k 间存在强相关性，对角近似过高估计不确定度

**下一步行动**:
- 检查 Jacobian 与 Covariance 的量纲
- 增加 edge 区域 coverage 的模拟
- 对比非对角项的贡献

**状态**: 待深入分析 → 将在后续版本修正
