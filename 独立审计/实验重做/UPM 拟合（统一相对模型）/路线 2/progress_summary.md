#### SPU-001: Huber δ=1.345 效率验证 [完成]

**假说**: Huber δ=1.345 在高斯参考分布下达到 95% 渐近效率，但在非高斯分布下效率下降

**文献腿**: 
- Huber, P. J. 1964, *Ann. Math. Statist.* **35**, 73-101 (DOI: 10.1214/aoms/1177703732) ✅
- Holland & Welsch 1977, *Comm. Statist.* A6, 813 (DOI: 10.1080/03610927708827533) ✅

**实验腿**:
- 脚本：`code/01_huber_delta_efficiency.py`
- N 扫描：10, 50, 100, 500, 1000
- 分布族：高斯、均匀、拉普拉斯 (方差均为 1)
- MC 重复：5000 次

**关键发现**:
✓ 高斯分布下 N≥100 时效率稳定在 **0.948-0.960** (理论 0.95)  
✓ 均匀分布下效率降至 **~0.69** (L2 更优)  
✓ 拉普拉斯分布下效率升至 **~1.27** (中位数最优)  

**结论**: 三腿齐全，科学量确立 ✅

#### SPU-002: Var(median)≈πσ²/(2N) 渐近式验证 [完成]

**假说**: Var(median)≈πσ²/(2N) 在高斯分布大 N 下成立，但在小 N 和非高斯分布下失效

**文献腿**:
- Serfling 1980, *Approximation Theorems of Mathematical Statistics* §2.3.2 (ISBN 0-471-02403-1 / DOI 10.1002/9780470316481) ✅

**实验腿**:
- 脚本：`code/02_var_median_asymptotic.py`
- N 扫描：5, 10, 20, 50, 100, 500, 1000
- 真值无效应负例：σ_bg=0 ⇒ control_ivar=0

**关键发现**:
✓ 高斯 N≥100 时误差比 **0.98-1.01** (理论~1.0)  
✓ 高斯 N=5 时系统性低估 **~9%** (与 PHASE2_UPM.md 陈述的 8.5% 一致)  
✓ **重要修正**: 均匀分布下实际方差为理论的 **~1.85×**(非文献说的"低估 1.91×")  
✓ 拉普拉斯分布下实际方差为理论的 **~0.37×** (接近文献的 0.335×)  
✓ σ_bg=0 时控制点应 release control_ivar=0(禁止数值保护量平方)  

**结论**: 三腿齐全，科学量确立 ✅

## 重要发现与修正

### 修正 1: 均匀分布偏差方向

PHASE2_UPM.md 中称"均匀 1.91×"被解读为公式低估 1.91 倍。但实测显示：
- **误差比 = Var_MC / Var_Theory ≈ 1.85**
- **实际含义**: 理论公式**低估**了实际方差 (实际方差是理论的 1.85 倍)
- **解读调整**: "1.91×"是指偏差因子，而非"低估倍数"

### 修正 2: sigma_floor 主导时的诚实边界

两个实验共同确认：
1. **SPU-001**: 当 `|uncertainty| < sigma_floor` 时，z=r/sigma_floor 失去统计尺度意义，95% 效率不成立
2. **SPU-002**: σ_bg=0 时应发布 control_ivar=0，而非数值保护量的平方

这两个结论都指向同一个工程要求：**必须在代码层面显式检测这些退化情况**。
