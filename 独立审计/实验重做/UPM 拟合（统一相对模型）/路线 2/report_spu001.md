## 实验腿

### 方法设计

**目的**: 验证 Huber δ=1.345 在不同分布族下的渐近效率

**构造方法**: 解析代数合成 (纯 Python+numpy)

**配置**:
- 固定随机种子：SEED=42
- 蒙特卡洛重复次数：n_replications=5000
- N 扫描：[10, 50, 100, 500, 1000]
- 分布族：
  - **高斯**: N(0, 1) — 预期~0.95 效率
  - **均匀**: U(-√3, √3) — 方差=1，预期~0.70 效率
  - **拉普拉斯**: Laplace(0, 1/√2) — 方差=1，预期~1.27 效率

**度量定义**:
- **效率比**: `Eff(Huber/L2) = Var(Sample Mean) / Var(Huber Estimator)`
- L2 (样本均值): 最优无偏估计器 (高斯假设下)
- Huber estimator: IRLS 实现，trimmed mean 初始值

**负例设计**: 
- 若高斯假设不成立，则 95% 效率应显著偏离
- 均匀分布：L2 更优 ⇒ Eff < 1
- 拉普拉斯分布：中位数最优 ⇒ Eff > 1

### 实现细节

**Huber 权重函数**:
```python
def huber_weight(x, delta=1.345):
    abs_x = np.abs(x)
    return np.where(abs_x <= delta, 1.0, delta / abs_x)
```

**IRLS 迭代**:
```python
mu_new = np.sum(weights * y) / np.sum(weights)
```

**收敛判据**: `|mu_new - mu| < tol` (tol=1e-10)

## 结果

### 实测效率比

| 分布 | N=10 | N=50 | N=100 | N=500 | N=1000 | 渐近值 |
|---|---|---|---|---|---|---|
| **高斯** | 0.9660 | 0.9574 | 0.9483 | 0.9596 | 0.9518 | ~0.95 ✓ |
| **均匀** | 0.8032 | 0.7244 | 0.7082 | 0.6960 | 0.6923 | ~0.69 |
| **拉普拉斯** | 1.2163 | 1.2726 | 1.2681 | 1.2579 | 1.2929 | ~1.27 |

### 关键发现

1. **高斯分布**: N≥100 时效率稳定在 0.948-0.960，确证 95% 渐近效率
2. **均匀分布**: 效率随 N 增大降至~0.69，L2 远优于 Huber
3. **拉普拉斯分布**: 效率升至~1.27，Huber 劣于中位数但仍优于 L2

### 统计显著性

- **高斯 N=100**: Eff=0.9483 ± SE ≈ 0.01 (5000 次 MC)
- **偏离检验**: |0.9483 - 0.95| = 0.0017 << 0.01 ⇒ 与理论一致
- **非高斯边界**: 均匀分布偏离 95% 达 26%，拉普拉斯偏离 34%

## 结论

### 主结论
✓ **证实假说**: Huber δ=1.345 在高斯参考分布下确实达到约 95% 渐近效率

✓ **适用域确认**: 当分布偏离高斯假设时，效率显著变化：
- 均匀分布：效率降至 69% (L2 最优)
- 拉普拉斯分布：效率升至 127% (中位数最优)

✓ **理论自洽**: 实测渐近值与 Serfling 1980 的理论预测高度吻合

### 诚实边界
- **小样本效应**: N<50 时效率波动较大 (高斯 N=10 时 0.966 vs N=1000 时 0.9518)
- **极端厚尾**: 未测试柯西等无限方差分布
- **delta 优化**: δ=1.345 仅对高斯最优，其他分布需重新标定

### 工程启示
1. **sigma_floor 警告**: 当 `|uncertainty| < sigma_floor` 时，z=r/sigma_floor 失去统计尺度意义，95% 效率不成立
2. **分布适应性**: 若数据明显非高斯，应考虑自适应 Huber 或替代稳健估计器
3. **N 下限**: 建议 N≥50 以保证渐近理论的有效性
