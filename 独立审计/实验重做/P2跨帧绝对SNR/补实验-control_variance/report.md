# 补实验报告：control_variance 渐近式（π/2 系数）的有限 N 偏差方向、幅值与口径归属

单元归属：**P2 跨帧绝对 SNR / 稀疏 SNR 控制点（控制点方差语义）** · 独立审计补实验 · 固定 seed · 纯 Python+numpy

被审对象：`docs/algorithms/PHASE2_SAMPLER.md` §5.4 与 `docs/science/PHASE2_UPM.md` §5 中

```text
control_variance = k_corr × (π/2) × σ_bg² / N_retained      （kPiHalf=1.5708, k_corr=1.4）
```

的 (π/2) 渐近系数警告：**"N=5 时渐近式低估 8.5%，属保守方向"**（PHASE2_UPM.md:79；PHASE2_SAMPLER.md:267-274、:274 "N = min_samples = 5 时偏差 −8.5%，属保守方向"）。本实验在 P2 语境下以解析 + MC 双路把它做实或推翻；任务来源 = 独立审计补实验指令（P5 加性天光去除路线2 E1 的 1.4373 vs π/2 结果需交叉比对）。

---

## 1 假说

- **H1（方向）**：文档的比值 `0.9149（N=5）` 是"实测/公式"，即实测低于公式 ⇒ 公式对真方差是**高估**而非"低估 8.5%"；其自结"属保守方向"（权重偏小）只有在高估下方成立，文档内部方向词与保守性判断自相矛盾。
- **H2（口径）**："8.5%"属于 **σ 已知的纯公式口径**（已知 σ 的 MC 真值 vs 渐近式）；生产 `σ_bg = 1.4826·MAD`（同 patch plug-in）自带小样本向下偏，会把端到端偏差抵消到百分位级——把 8.5% 引用为生产风险是**口径混用**。
- **H3（渐近条件）**："N≥65 误差 <1%"的域声明本身正确（渐近条件没有被误用）；错的是域内方向陈述与跨口径引用。
- **H4（前提破坏的量级）**：公式前提是"patch 样本 = 同一正态的重复测量"；含结构信号的像素集（线性梯度）造成的偏差比有限 N 修正大 1–2 个数量级，方向恒为发布方差偏大。

## 2 方法

三条独立路径，全部固定 seed、不 import 仓库任何 Python：

1. **解析路径（无 MC）**：奇数 N=2k+1 的样本中位数 = 第 k+1 阶序统计量，密度 `f(x) = n!/(k!k!)·Φ(x)^k(1−Φ(x))^k·φ(x)`；Gauss–Legendre 600 节点在 [−12,12] 数值积分给出**精确**有限 N 常数 `κ_exact(N) = N·Var(median)/σ²`（标准正态 σ=1）。渐近极限 = π/2。
2. **MC 路径（seed=20260601，numpy default_rng 单流）**：N∈{5..201} 奇数全扫 + 偶数 {20,40,100} + 锚 {289}，R=4×10⁶（N≤21）→4×10⁵（N≥161）次/点，20 块 jackknife 标准误。三臂：
   - **B1 纯公式口径**：`ratio_A = 实测 Var(median) / ((π/2)σ²/N)`（= 文档 0.9149 的同口径）；
   - **B2 端到端口径（无裁剪理想化）**：`σ̂ = 1.482602218505602 × MAD(同 patch)`（与生产同一常数与中心化约定），`ratio_B = E[(π/2)σ̂²/N] / Var(median)`；
   - **B3 结构臂**：样本 = 线性梯度 `b·(i−(N−1)/2)` + σ=1 噪声，b∈{0,0.05,0.1,0.3,1.0}/sample，N∈{5,17}。
3. **生产链忠实臂（seed=20260605）**：逐句复刻 `sampler.cpp:837-878`（亮端 3σ 迭代裁剪 iters=3、裁剪后 MAD、n_retained、发布 `cvar=(π/2)σ̂²/n_ret`、被估量 y=裁剪后中位数），量 `E[cvar]/Var(y)`。
4. **独立 seed 复核（seed=20260602/03/04）**：对主实验 |z| 最大的点（N=201、N=5）与偶 N 锚（N=20、N=100）三 seed 重跑。

- 方向：**全域恒为高估**（ratio_A < 1），随 N 单调收敛到 1；经验一阶形式 `κ(N) ≈ π/2 − a(N)/N`，a 从 N=5 的 0.683 缓降到 N=289 的 0.673（收敛慢，含高阶项）。
- 文档自己的 MC 锚 `0.9149 (N=5) / 0.9722 (N=17) / 0.9938 (N=65)` 与精确值 0.9130/0.9745/0.9934 在其 MC 误差（√(2/4×10⁵)≈0.22%）内一致——**数值没错，方向词错了**："实测比公式低 8.5%"（1−0.9149）被写成了"渐近式低估 8.5%"；正确读法是**公式高估 9.3%（按其 MC）/ 9.53%（精确）**。
- 1% 边界实际在 **N≈45–49**（N=41 时 +1.06%、N=49 时 +0.89%），文档的 "N≥65 <1%" 成立且保守。

## 4 结论

1. **"N=5 时渐近式低估方差 8.5%" 被推翻，方向相反**：σ 已知的纯公式口径下，渐近式 πσ²/(2N) 对真方差**恒为高估**——精确值 N=5 **+9.53%**（κ_exact=1.4342 vs π/2=1.5708）、N=17 +2.61%、N=65 +0.67%、N≥129 <0.4%。文档自己的比值 0.9149 正确，但"低估"一词是方向反转（正确读法：实测比公式低 8.5% ⇔ 公式高估 9.3%）；其"属保守方向"的结语恰与高估（方差偏大→ivar 偏小→权重偏小）自洽——**文档内部方向词与保守性判断互相矛盾，本实验以解析路径定谳为高估**。
2. **"8.5%" 主要是口径混用**：该数属于 σ 已知的纯公式口径；生产端到端口径（σ_bg=1.4826·MAD 同 patch plug-in）中 MAD 小样本向下偏（E[σ̂²]/σ²=0.906@N=5）与之抵消，端到端偏差 N=5 仅 **−0.6%（≈−1%，与 P5 实测一致）**，奇 N 全域 |偏差|≤1.5%。把 8.5% 引用为 N=5 的生产风险高估了一个数量级。
3. **"渐近条件误用"不成立**：公式在其声明域（iid ∧ 高斯 ∧ N≥65）内偏差 +0.67% <1%，域声明正确；错在域外方向词与跨口径引用，不在渐近条件本身。
4. **生产链（含 3σ 亮端裁剪）下的端到端偏差为 −0.8%（N=5，不触发裁剪）至 −3.2%（N=9）**，且被估量实为裁剪后中位数（奇 N 裁剪触发时保留集变偶、中位数奇偶翻转，其真方差高于无裁剪中位数）——发布 cvar 低估 1.3–3.2%（N≥9 奇）。**N 的有效范围**：纯公式口径 |偏差|<1% ⟺ **N≥49（奇）**；端到端/生产链口径 N≥5 即百分位级，但**偶 N_retained 另有 +1%~+5% 高估**（N=20 实测 +5.0%，独立 MC 复核 +5.0%）；若门禁要求 |端到端偏差|≤1%，需避开偶 N 或按奇偶修正。
5. **量级排序（P2 控制点方差的真实风险序）**：结构分量（+14%~+674%）≫ 非高斯域（3–6 倍，文档已载）> 偶 N 奇偶效应（+1~5%）> 生产链裁剪效应（−1~3%）> 有限 N 修正（纯公式口径 ≤9.5%，端到端 ≤1.5%）。有限 N 修正是该公式**最小**的误差源。

## 5 诚实边界

- **MC 统计误差**：主实验各点 SE（20 块 jackknife）0.07%–0.4%；N=201 主 run 点偏低 0.7%（z=+3.0），已用独立 3-seed（R=10⁶）复核并确认精确值，主 run 该点按低波动标注，不影响任何结论。
- **口径保真**：端到端口径用 `1.482602218505602`（生产常数）；P5 E1 用 `1.4826`，差 <10⁻⁶ 相对，不影响比对。裁剪链按 `sampler.cpp:837-878` 逐句复刻（含 |nr|<min_samples 不更新、收敛分支不更新 s0、s1≤0 不更新等分支语义），但未覆盖 k_corr（置 1，隔离 (π/2) leg）与 provenance 回退路径。
- **被估量语义上呈**：生产链臂把 Var(y)（裁剪后中位数）当 control_variance 的目标被估量——这是"控制点估计统计方差"的最自然读法，但 PHASE2_SAMPLER §5.4 未写明 y 是否即该估计；若合同意图是无裁剪中位数，生产链偏差应按 Var(全样本中位数) 重算（方向会整体上移约 1–3%，仍为百分位级）。此语义缺口已登记上呈（refs.md UNRESOLVED-4）。
- **未建模**：σ-clip 对渐近系数的 C(a)=1.0196 解析修正（DATA_SEMANTICS §25 已载，属裁剪后中位数的另一口径）；天光/读出噪声的非高斯成分（结构臂只覆盖线性梯度）；k_corr 的 Drizzle 相关放大（P5 路线2 E2 已审，本单元不重复）。
- **结论来源**：本报告全部数字出自本单元自己的实验（code/ 三脚本 + results/ 三 JSON）；P5 E1 与 e1e2_domain.json 仅作交叉比对与出处考证，未借用其结论。
