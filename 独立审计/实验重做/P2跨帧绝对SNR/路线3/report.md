## 【链条位置】（最高设计 §2 五创新点中的 P2）

全链：P1 通量积分拟合（测光星等坐标系）→ **P2 跨帧绝对 SNR（本模块）** → P3 守恒映射算子（稀疏 SNR 控制点上球）→ P4 重建稠密 SNR → P5 加性天光去除。

- **上游输入（P1 → P2）**：逐帧测光零点 `ZP_k`（mag，测光星等坐标系产品）。P2 消费它生成 `F_ref,k = 10^(−0.4·(m_ref−ZP_k))` [ADU]（EXP-04 `upstream_P1.zp_k`）。
- **P2 产出**：① 帧级无量纲 `frame_snr`；② 逐源 `σ_F`/`SNR_F`（Horne 1986 方差组成式，EXP-05 H2 验证）；③ 帧内稀疏绝对 SNR 控制点（无量纲，Δ=64 px 网格）；④ 叠加权唯一换算口径 `w = SNR²/F_ref² = 1/σ_F²`（量纲 ADU⁻²）。
- **下游消费（P2 → P3/P4）**：P3 把稀疏控制点同经球面映射上球并消费 `w` 做 drizzle；P4 用 IDW 从控制点重建稠密 SNR 场。EXP-04 H3 以 Δ=64、控制点噪声 1.5%（恰为 P-CST-08 预算 N_sky=9216 的口径）做了贯穿演示：重建误差由 IDW 离散化主导（归一化 RMS 0.229），控制点噪声仅使其通胀 1.06 倍 ⇒ **1.5% 的控制点精度约定完整穿过接口、量纲（无量纲 SNR）与精度约定跨级一致**。
- **有效性约定**：`frame_snr` 依赖 `m_ref`（EXP-04 H1：每 mag 单调降 2.51189 倍），故 `m_ref` 必须随产品落盘、跨帧比较必须在同一 `m_ref` 档内；而换算权 `w` 的**逐帧比值**对 `m_ref`/`ZP` 完全不变（EXP-04 H2，rel dev ≤ 3.3e-16）——这是"跨帧可用、不依赖参考帧"的全部数学根据。

## 1. P-CST-03：MAD→σ 尺度常数 1.482602218505602

- **假说**：κ = 1/Φ⁻¹(3/4)；高斯样本上 κ·MAD 渐近无偏，σ=0 时度量归零。
- **方法**：EXP-01（`code/exp01_mad_sigma_budget.py`，seed=20260926）：二分法求 Φ⁻¹(3/4)（numpy 无 erfinv，自实现，避免 scipy）；n∈{64,1024,9216} 蒙特卡洛（60000/8000/2400 试验）。
- **结果**：κ_closed = 1.4826022185056023 vs 冻结字面量 rel diff **1.50e-16**（机器精度，理论腿闭合）。有限样本偏差：n=64 时 **−1.23%**，n=1024 时 −0.11%，n=9216 时 −0.02%（随 n→0，渐近无偏成立）。负例：常数字场输入 σ̂=0 恒成立（`metric_is_zero: true`）。
- **诚实边界**：n=64 的 −1.2% 系统偏差是《已确立》明文"不采用有限样本校正 b_n"的直接代价，登记面应保留该数字；本路 MC 功效对 1% 级偏差的分辨力约 ±0.3%（n=64 档）。
- **文献腿**：Rousseeuw & Croux 1993（JASA 88, 1273–1283，DOI 已核）；Croux & Rousseeuw 1992（DOI 已核，即《已确立》§3 指认的正确归属）；Huber 1981 monograph（DOI 已核，页码未核）。
- **复现命令**：`python3 code/exp01_mad_sigma_budget.py`（结果 `results/exp01_mad_sigma_budget.json`）。

## 9. P-CST-11：读噪双计偏差 +14.5009% / +38.2524%

- **理论腿（新结论：闭式存在）**：σ_F⁻² = Σᵢ Pᵢ²/vᵢ（Horne 1986，DOI 已核）。正确臂 v_corr=(B+D+RN²+F·Pᵢ)/g²；双计臂 v_emp=v_corr+(RN/g)²（经验总 σ_sky 已含读噪再补一次）。bias(RN)=√(ΣP²/v_corr ÷ ΣP²/v_emp)−1。
- **结果**（EXP-05 H1，b2 冻结配置：Moffat4 σ_psf=1.5、half=30、F=1000e、B=100e/px、D=0.5e/px、g=1.3）：**六个 RN 点全部逐位复现存档值，最大相对差 2.35e-14**——含基准点 RN=10 → **+14.500914320209946%** 与最坏点 RN=50 → **+38.252382643948457%**。ΣP²=0.0926840874616503 亦与存档一致（同时反推确认 moffat4_grid 采用 α=√2σ 约定+离散归一）。
- **MC 腿**（EXP-05 H2）：正确臂 |z|≤1.8（方差组成式成立）；双计臂的**报告 σ_F** 相对实际散布虚高（z=−6.8/−18.8），虚高幅度=闭式偏置——即双计不改变估计器实际效率，而是**虚高报告的不确定度**（SNR 低估）。负例：RN=0 ⇒ 两臂恒等、偏置=0。
- **结论**：05/`《已确立》` 的"seed 无关闭式"标签**错误**（审查-3"需找到闭式推导"的判断方向正确）；登记面应改"公式导出（闭式），存档值逐位同"。

## 14. P-CST-21：权重幂次 γ=2（α=2/β=1/γ=2/δ=1）
