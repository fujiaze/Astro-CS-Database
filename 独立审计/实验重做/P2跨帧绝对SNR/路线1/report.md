## 0. 执行摘要（关键裁决）

1. **1.152 vs 1.144 之争裁决为 1.152**。单 patch MAD-σ̂ 的相对标准误系数 c(n=64) 实测 **1.1508**（exp01，M=200k 行）与 **1.1542**（exp03 c1，M=1200 行），与《正向规格》主张 1.152 相对偏差 +0.19%；而"1.144 支"的天光预算 9216→5811 实为 **5816.6**（exp03 精确复算 (1.152×1.25/0.015)² = 5816.6，文档写 5811 属数字漂移）。9216 = (1.44/0.015)² 精确成立。
2. **管线级 1.44 获实验支持**：exp03 c4（patch 方差取中位再开方的完整管线）实测 c_eff = **1.4751 ± 0.023**，与主张 1.44 相差 +2.4%（≈1.1σ MC 误差），方向与量级一致；理论链 1.152×1.2533 = 1.444 恰为实测中心。
3. **双计偏差登记值精确复现**：exp04 用 Moffat4（σ=1.5 px）轮廓逐位复现《b2_noise_terms.json》全 6 个 RN 扫描点（最大偏差 3.3e-7）、dark 扫描（≤4.6e-7）、增益不变性（精确）；并确认 ΣP² = 0.092684087…（half=30）与 §1.2 收敛值（half=12: 0.09268653；half=60: 0.09268408）。
4. **《已确立》§3 不是幻觉锚**：`02_已确立的算法与验证程序.md` 行 108–130 确有常数表存在，行 1–6 与 05 引用逐项吻合，行 7/9–15 存在 +2/+3 行偏移但内容均在。审查路 1 的"系统性幻觉锚"定性过重（详见 §6 分歧①）。

6. **36.3% 对角欠估 = 精确闭式解**：exp10 给出 Var_exact/Var_diag = 1 + ρ(M_eff−1)，在 ρ=0.19、均匀 4-tap 下欠估 = 0.19×3/(1+0.19×3) = **36.31%**，与登记值 36.3% 精确吻合；23.3% 对应 ρ=0.101（4-tap）或 M_eff=2.6（ρ=0.19）；公式 1+0.75ρ̄ 给 12.5%，与两者皆非——P-OPEN-02 的三个值裁决完毕。

## 1. 【链条位置】上游 P1 → 本模块 P2 → 下游 P3/P4/P5

本模块在科学链中的接口（量纲/精度/有效性约定）与一个贯穿用例：

```text
P1（测光星等坐标系）                    P2（本模块）                          P3/P4/P5（下游）
ZP_k, k_photo,k, m_ref=6.0   →   F_ref,k = 10^(-0.4(m_ref-ZP_k))   →   控制点 sparse_snr = F_ref/σ_F
  [mag/无量纲]                    [e]；恒等式 F_ref,k·k_photo,k = F0      [无量纲] + 预测方差 [1]
                                  σ_F² = 1/Σ(P_i²/σ_i²) [e²]              P4: 稠密重建（Δ=64 网格、钳制）
                                  w = SNR²/F_ref² = 1/σ_F² [1/e²]         P5: SNR_comb² = Σ SNR_k² 加权去天光
```

贯穿用例（exp04/05/07/09 逐环验证）：设某帧 ZP_k 使 F_ref = 1000 e（P1 交给 P2 的量，量纲 e），Moffat4 σ=1.5 px、sky=100 e/px、dark=0.5 e、RN=10 e⁻、gain=1.3，则 exp04 精确给出 ΣP² = 0.092684087、σ_F = 37.95 e（rn=0 基准）、若把经验总 rms 误当纯 shot-noise 喂入则 σ_F 虚高 **+14.5009%**（rn=10 基准点）至 +38.2524%（rn=50）——即 P2 交给下游的控制点 sparse_snr 会被系统性低估 12.7%–27.7%。下游用例：该控制点连同预测方差以 (x, y, sparse_snr, var) 四元组、按 Δ=64 px 单元中心上球（P3）；P4 用 IDW/双线性重建稠密 SNR（exp09：节点复现 ≤1e-9、预测方差覆盖中位比 0.998、样条类必须钳制）；P5 组合时 SNR_comb² = Σ SNR_k²（exp07：≤1.4 ulp）。任何一环的量纲错位（e vs ADU vs e/g）都会使 SNR 偏一个 gain 因子——exp04 的增益不变性检验（bias 对 gain 精确不变）锁定了正确的量纲约定。

|---|---|---|
| 双线性 | **0.2806** | 0.0（精确）|
| IDW p=1 K=8 | 0.9165 | — |
| IDW p=2 K=16（登记）| 0.9845 | 7.1e-14 ✓ |
| IDW p=2 K=256 | 2.0777 | — |
| IDW p=1 K=256 | 5.1989 | — |

方差覆盖（p2/K16）：emp/pred 中位 0.9977、IQR [0.952, 1.050]；IDW 在 2D 棋盘上最小预测 1.108 ≥ 控制最小值 1（凸组合，**不可能下冲**）；1D 自然样条棋盘中点最小值 **−111268**（剧烈下冲 ⇒ 钳制必需）。
- **结论**：P-CST-24 的 Δ=64 与节点复现 ≤1e-9 成立；**IDW (p=2,K=16) 不是 CV 最优**（双线性 RMSE 优 3.5 倍；IDW 族内 p=1/K=8 略优）；钳制对样条类必需、对 IDW/双线性按构造为空操作——P-ALG-09 的钳制条款对 IDW 路径是"无害冗余"，对样条路径是必需品。
- **诚实边界**：CV 结论限于本光滑真值场族与 2% 控制噪声；真实天空控制点分布（成团/缺测）未模拟。
- **复现命令**：`python3 code/exp09_reconstruction_cv_and_clamp.py`。
- **佐证**：refs.md R5（Shepard 1968 书目；Fruchter & Hook 2002）。

### EXP10（P-CST-22、P-OPEN-02）对角近似协方差欠估

- **假说**（理论推导腿）：等相关输入下 Var_exact/Var_diag = 1 + ρ(M_eff−1)，M_eff = (Σc)²/Σc²。
- **方法**：闭式推导 + 逆演（哪个 (M_eff, ρ) 生成 23.3%/36.3%）+ 等相关 MC 交叉验证 + AR(1) 随机 4-tap MC + 负例 ρ=0。
- **结果（数字表）**：

| 场景 | 欠估 | 判定 |
|---|---|---|
| 均匀 4-tap，ρ=0.19 | **36.31%** | = 登记值 36.3% ✓✓ |
| 均匀 4-tap，ρ=0.1013 | 23.3% | 登记值 23.3% 对应此操作点 |
| M_eff=2.6，ρ=0.19 | 23.3% | 另一等价解释 |
| 1+0.75ρ̄（ρ=0.19）| 12.5% | 与两者皆非 ✓（审查员质疑成立）|
| ρ=0 负例 | 0 | 归零 |
| AR(1) 滞后-1 ρ=0.19 随机权重 | 14.8% | 4-tap 命中相邻 lag，有效 ρ<0.19 |

- **结论**：**36.3% = 精确闭式解（ρ=0.19、均匀 4-tap）**；23.3% 与 36.3% 互斥的谜底 = 两个不同的 (M_eff, ρ) 操作点或两种权重约定；1+0.75ρ̄ 公式确与两者皆不符。P-OPEN-02 的三个数由一条公式统一裁决。
- **复现命令**：`python3 code/exp10_covariance_diagonal_approx.py`。
- **佐证**：refs.md R5（Fruchter & Hook 2002：相关性来源）。

### EXP11（P-CST-15、P-ALG-04）星掩膜半径 vs σ_bg 偏差

- **假说**：r_local 使源面亮度降到 k·σ_bg（k=0.1）；r≥r_local 时偏差 ≤0.5%；固定 r=10 px 偏差随 F 增长（+0.02%→+2.29%，对数律）。

### EXP12（P-CST-21）权重幂指数 γ=2 的推导

- **假说**：γ=2 不是待标定参数，而是 w = 1/σ_F² 恒等式（α=2, β=1, δ=1 已定）的唯一解。
- **方法**：1e4 随机 g_k∈10^±0.5 下对比 γ∈{1,2} 的 w/ivar；负例 g≡1。
- **结果**：γ=2：w/ivar max dev = **4.44e-16（2 ulp，恒等成立）**；γ=1：残差因子 ∈ [0.316, 3.162]（=1/g_k，权重比畸变 ×3.16）；g≡1 负例：任意 γ 偏差 0。
- **结论**：γ=2 由恒等式**导出**（g_k^(2−γ) 因子的唯一任务是抵消 SNR_k = g_k·(F_ref/σ_F)_0 的 g_k 因子），"缺标定记录"以推导+数值验证满足；建议规格把 P-CST-21 从"待标定"改为"恒等式导出，见本报告"。
- **复现命令**：`python3 code/exp12_gamma_weight_scale.py`。
- **佐证**：无外部文献（代数恒等式）。

### EXP13（P-CST-20、P-CST-17）ΣP 归一容差与控制点条件数

- **假说**：|ΣP−1|≤1e-9 使 σ_F 变化 O(tol)；λ_lo/λ_hi ≥ 1/16 是良态边界。
- **方法**：保归一定向扰动（峰像素 +tol，其余按 P² 加权补偿，ΣPδ=0 精确）；加权平面拟合系数误差 vs λ 比（κ=1/2/4/8，2000 rep）。
- **结果**：σ_F 相对变化 = **0.549·tol**（tol=1e-9 → 5.5e-11 ≤ tol ✓；均匀扰动在重归一下精确抵消——已从设计排除）；条件数：x 斜率误差比 = 1.0/2.02/4.09/8.10（κ=1/2/4/8），y 斜率平坦（1.01–1.04）；1/16 边界处最差系数误差 ≈κ×基线且有界，1/64 再降 ~2 倍。
- **结论**：P-CST-20 成立（σ_F 受 ΣP 容差保护在 O(tol) 水平）；P-CST-17 的 1/16 判据为最后一个良态档（公式推导 + 数值支持，无需外部文献）。
- **复现命令**：`python3 code/exp13_normtol_and_conditioning.py`。
- **佐证**：无（线性代数标准结果）。
