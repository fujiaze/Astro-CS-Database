## 【链条位置】

P2 是五点科学链的**第二环**：P1 通量积分拟合（根基）→ **P2 跨帧绝对SNR** → P3 守恒映射算子（HEALPix drizzle + 稀疏 SNR 控制点上球）→ P4 重建稠密 SNR → P5 加性天光去除。本路 12 个实验把上下游接口全部数值贯通了一遍：

1. **上游 P1 → P2**（输入）：P1 逐星产品行（psf 块 `row[2]`=通量 F、`row[5]`=FWHM）与帧零点 `ZP_k`。消费点：
   - exp08 消费 `(F_i, FWHM_i)` 算局部掩膜半径 `r_i = max(1.5, 0.75·FWHM_i)·(F_i/F_med)^0.1`（量纲 px，精度 float64）——FWHM 错一位，掩膜面积错 ~2.25 倍，天空预算直接爆；
   - exp01 消费 `ZP_k` 算 `F_ref,k = 10^(−0.4(m_ref − ZP_k))`（量纲 ADU）。
2. **P2 → 下游**（输出，本路逐项验证其数值语义）：
   - 逐源 `σ_F = σ_bg·√ΣP²`（ADU）、`SNR_F`（无量纲）；
   - 帧级 `frame_snr = F_ref/σ_F,c`（无量纲）；
   - 稀疏控制点 `sparse_snr_layer`（05 §3.8：`sparse_snr_value = F_ref,k/σ_F,c`）＋ `F_ref`（ADU）。
3. **P2 → P3 → P4**：P3 把控制点上球（drizzle），P4 在球面上做 IDW 重建（`idw_power=2.0, K=16, γ<1e-10`）。exp11 用 P2→P4 的**真实接口形状**（Δ=64 px cell 中心、64 控制点 → 非节点测试点）做了敏感性网格：节点重合恢复误差 0.0（接口无损）、常场负例 1.4e-14。
4. **P2 → P5**：P5 的加性天光去除与无接缝叠加按逆方差权 `w = SNR²·g²/F_ref²` 合成。exp12 证明该式只有在 γ=2 时恒等于 `1/σ_F²`（共同尺度），γ=1 时帧权偏差 = |g|⁻¹。
5. **量纲/精度/有效性约定**（贯穿性声明）：ADU 域为 pixel 值域（ADU² 进方差）；SNR 无量纲；所有门限比较用 float64 绝对/相对之分显式登记（exp05 证明 1e-9 归一门在 float32 下必红）；三态（正常/降级/不可用）与掩膜降级必须具名登记，不静默——exp08 的预算负例（`n_sky < 9216 ⇒ 拒收`）就是该约定的可执行形式。

**一个用例走全链**：m_ref=6、ZP_k=25 的合成帧（σ_bg=5 ADU、Gauss FWHM=3、窗 30px、ΣP²=5.0985）→ exp01：`F_ref=10^7.6` ADU、`frame_snr=3.526e6`、每 mag 降 0.39811；该帧的 64 个 cell 中心控制点进 exp11 的 IDW（power=2, K=16）重建非节点 SNR（RMSE 1.219，σ_field=5.464）；同一 σ_F 进 exp12 的权重（γ=2 恒等式偏差 2.2e-16）。全链无一处需要临时改约定。

## 逐项报告

### P-CST-01 星等系数 2.5

- **判定**：定义常数。Pogson (1856) 定义 1 mag 间隔 = 光度比 100^(1/5)，2.5 是其对数斜率。它不是测量量，无实验腿可言（硬凑只会稀释证据），文献腿给一手溯源。
- **A 文献腿**：R1（Pogson 1856, MNRAS 17, 12–15, DOI `10.1093/mnras/17.1.12`，Crossref 逐字段核验）。
- **B/C 实验**：exp01 往返恒等 `m = ZP − 2.5·log10(F) ↔ F = 10^(−0.4(m−ZP))`，200k 随机点最大 |Δm| = **1.78e-15**（纯双精度舍入级）；负例：ΔF=0 ⇒ Δm ≡ 0.0（逐位）。
- **D 数据**：Pogson 步长 F→F/100 ⇒ Δm = **5.000000000**（解析恒等）。
- **复现**：`python3 code/exp01_mag_scale_identities.py`

### P-CST-02 反推系数 −0.4

- **B/C 实验**：exp01 中 `INV = −0.4` 与 `−1/K_MAG` 在所有 200k 点上数值恒等（`rel_diff == 0`）。

### P-CST-03 MAD→σ 系数 1.482602218505602

- **B/C 实验**：exp02，N=64 与 N=9216 两档 MC（各 2000 次重复）。
- **D 数据**：

### P-CST-05 Moffat β=4 FWHM/σ = 1.230310

- **假说**：β=4 时 σ = α/√(β−2) = α/√2、FWHM = 2α√(2^{1/4}−1)，故 FWHM/σ = 2√2·√(2^{1/4}−1)。
- **A 文献腿**：R4（Moffat 1969, A&A 3, 455，ADS bibcode 1969A&A.....3..455M；题名经二手页逐字确认）。
- **B/C 实验**：exp04。**本路独立闭式给 1.2303076526，登记值 1.230310 相对它偏 +1.908e-6——与《已确立》§3 自己记载的"复算 +1.908e-6"精确一致**（6 位手抄舍入所致，非幻觉锚）。数值积分（log 网格）给 1.2303154，其与闭式差 +6.3e-6 为求积误差，即 05 所记 "+1.91e-6 量级"的真正来源是闭式 vs 登记值的差。
- **D 数据**：闭式−登记 = **+1.908e-6**；高斯/Moffat4 因子比 = **1.9140091**（《已确立》§3 的 1.9140 ✓）；**负例**：β=2 时二阶矩积分随 rmax 无界增长（2.0→4.0→8.0 px² 线性发散），确认 β>2 适用于域的前提。
- **复现**：`python3 code/exp04_moffat4_sigma.py`

### P-CST-13 恒等门 2.22e-16

- **B/C 实验**：exp05 cst13：10⁶ 随机 (F_ref, σ_F) 对拍 w 两序求值：ε_double = 2.220446049250313e-16；max rel dev = **6.66e-16 = 3ε**；p99.99 = 4.44e-16；**42.2% 的随机输入超过字面 2.22e-16 门**。负控：注入 1e-15 差异 ⇒ 检出（1.665e-15）。

### P-CST-21 权重幂次 α=2/β=1/γ=2/δ=1

- **假说（本路核心新证据）**：帧值按 g_k 线性标度（x_frame = g_k·x_common，透明度/曝光归一）时，所有帧侧量（σ_sky、RN(ADU)、σ_F、ZP 拟合的 F_ref）同乘 g_k，SNR 不变。于是共同尺度最优权 w* = 1/σ_F,common² = g_k²/σ_F,frame²，而公式 w_γ = SNR²·g_k^γ/F_ref² = g_k^γ/σ_F,frame² ⇒ **w_γ/w* = g_k^{γ−2}：γ=2 是使公式恒等于逆方差的唯一指数**。
- **结论**：γ=2 **不是待标定量，而是推导量**——05 的"唯一待确认的是 γ 的标定证据"可以被更强地回答：不存在 γ=2 之外的取值使权重语义自洽；γ=1 使 g=2 的帧权重系统性翻倍/减半。建议 05 把 P-CST-21 从"待确认"改为"推导锚（本推导）+ 数值回归锁定"。
- **B/C 实验**：exp12：γ=2 恒等最大偏差 **2.22e-16**；γ=1 偏差 = g^{−1}−1：**+1.000（g=0.5）/ −0.5（g=2）/ −0.75（g=4）**，与预测逐点一致；**负例 g=1 ⇒ 全部 γ 偏差为 0**。
- **A 腿**：推导 + R5/R12（权重与方差传播的通行约定）。
- **复现**：`python3 code/exp12_weight_gamma.py`
