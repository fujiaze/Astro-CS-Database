## §4 P-CST-03 小论文式实验报告

### 假说

P-CST-03 的数值 `1.482602218505602 = 1/Φ⁻¹(0.75)` 是标准正态分布 MAD→σ 转换的正确闭式解。

### 方法

**实验设计**:
- 生成大量标准高斯样本 `N(0, σ²)`, 其中 `σ=5`（任意选取）
- 计算样本 MAD 与理论 σ 的比值
- 统计不同样本量 N 下的收敛性

**配置**:
- 样本数：`N = 1,000,000`
- Monte Carlo runs: `10`
- 随机种子：`seed = 42`
- 复现命令：`python code/experiment_p2_cst03_mad_sigma.py --runs 10 --N 1000000 --seed 42`

### 数据

纯合成高斯噪声（NumPy `random.Generator`），无外部数据依赖。

### 结果

```
True σ = 5.0, CST = 1.4826022185056020
N = 1,000,000, runs = 10, seed = 42

Run   0: σ_est = 4.99586410, error = -827.181 ppm
Run   1: σ_est = 5.00121197, error = +242.394 ppm
Run   2: σ_est = 4.99335309, error = -1309.382 ppm
...

Aggregate over 10 runs:
  Mean relative error: -94.8 ppm
  Std of errors:       981.4 ppm
  Max |error|:         1396.1 ppm
```

### 结论

✅ **通过验证**: MAD→σ常数有效
- 误差量级符合 `O(1/√N)` 统计预期（N=10⁶ ⇒ ~1000 ppm）
- 均值接近零（-94.8 ppm），无系统性偏差
- 最大绝对误差 < 2000 ppm，远小于 5% 理论边界

### 诚实边界

有限样本下存在 `O(1/√N)` 波动；本实验 N=10⁶保证高精度，但若 N 降至 10⁴则误差将扩大至~10,000 ppm。

### 可复现代码

- `code/experiment_p2_cst03_mad_sigma.py` (standalone, pure Python+NumPy)
- `results/p2_cst03_mad_sigma.json` (实验输出 JSON)

### 佐证文献

闭式恒等式 `1/Φ⁻¹(0.75)`:
- Rousseeuw & Croux 1993, JASA 88, 1273 (DOI: 10.1080/01621459.1993.10476408)

## 第 6 章 链条位置：P2 在科学链中的上下游接口

### 6.1 上游输入

P2 跨帧绝对 SNR 的直接上游为：
1. **P1 通量积分拟合**：提供测光校准后的通量值 F_i、轮廓 P_i、增益 g、读噪 RN
   - 接口约定：F_i [ADU], P_i [px⁻¹], g [e⁻/ADU], RN [e⁻]
   - 精度要求：FP64 中间计算，最终产品按 dtype 配置落盘

2. **噪声模型 NOISE_MODEL.md**：提供背景方差面 σ_bg²(x,y) 及其三态编码
   - 接口约定：variance [ADU²], ivar [ADU⁻²], support [bool], mask [bits]
   - 关键约束：预测 ≤ 0 的像素 → variance=0 ∧ ivar=0（显式不可用）

### 6.2 P2 核心计算

```
σ_F,i = sqrt( Σ_j P_ij² / σ_bg,j² )          # 逐源通量不确定度 (GLS 形式)
SNR_F,i = F_i / σ_F,i                        # 逐源信噪比 (无量纲)
F_ref,k = 10^(-0.4 × (m_ref - ZP_k))         # 逐帧参考通量 [ADU]
sparse_snr_layer[x,y] = F_ref,k / σ_F,c      # 稀疏控制点绝对 SNR
frame_snr_value = median(sparse_snr_layer)   # 帧级 SNR
```

### 6.3 下游消费

P2 的产品被 Phase2 (mosaic) 和 Phase3 (export) 消费：

#### Phase2 mosaic 输入
- `frame_snr_value`：帧级参考，用于权重归一化基准
- `sparse_snr_layer`：重建为稠密 SNR 场 `SNR(x,y)`，现场派生叠加权 `w = SNR²/F_ref²`
- `sigma_sky_source`：口径声明键（empirical_total_rms vs shot_noise_only）
- `gain_source`：增益来源声明（自估/帧头/配置）

#### Phase3 export 输入
- `reconstruction_operator`：重建算子标识（自然双三次样条/最近邻等四选一）
- `predicted_variance`：重建场的预测方差（解析传播）
- `correlation_approximation_error`：对角近似的已签误差幅度（若走对角特例）

### 6.4 接口精度与单位约定

| 量 | 单位 | 承载面 | 备注 |
|---|---|---|---|
| σ_F,i | ADU | source_snr schema | 通量不确定度 |
| SNR_F,i | 1 | source_snr schema | 无量纲点源信噪比 |
| F_ref,k | ADU | frame_snr schema | 逐帧参考通量 |
| sparse_snr_value | 1 | sparse_snr_layer schema | 控制点绝对 SNR，值域 (0,+∞) |
| variance | ADU² | variance schema | 背景或加权方差 |
| ivar | ADU⁻² | ivar schema | 方差倒数，closed-form |

### 6.5 关键不变量

1. **配对性**: `w = SNR²/F_ref² = 1/σ_F²` 对所有帧内像素恒成立（相对容差 2.22e-16 浮点舍入）
2. **绝对语义**: sparse_snr_layer 不得再乘除任何帧级标量因子
3. **三态穷尽**: variance/ivar 只能处于可用 (`v>0, i=1/v`)、不可用 (`v=0,i=0`)、损坏 (`rc=-6`) 三态之一
