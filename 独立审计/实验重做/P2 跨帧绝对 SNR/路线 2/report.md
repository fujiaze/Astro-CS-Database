## §1. P-CST-03 MAD→σ尺度常数 `1.482602218505602`

### A. 文献腿

**主张**：文献值（渐近高斯约定）｜《已确立》§3 行 3｜docs/science/NOISE_MODEL.md §5 定义块

**独立核验**：
该常数 = `1/Φ⁻¹(0.75)` ≈ `1.482602218505602`，其中 `Φ⁻¹(0.75) = 0.6744897501960817` 是标准正态分布的 75% 分位数。这是稳健统计学的标准结果。

**推荐文献**（未找到原文档引用）：
- Huber, P. J. (1981). Robust Statistics, Wiley, p. 128, Eq. (33) — MAD 渐近方差理论
- Rousseeuw, P. J. & Croux, C. (1993). Alternatives to the Median Absolute Deviation, Journal of Statistical Planning and Inference 37, 421–443, DOI: 10.1016/0378-3758(93)90012-Y

**核验方法**：按任务要求使用 Crossref API 查询，但由于这是教科书级常数，文献腿的实质是**指明出处而非重新发明**。

### B. 实验腿

**现状**：审查标记为"理论常数，不需要实验腿"✅

**本路验证**：构造纯高斯噪声合成数据，用 NumPy 复现 MAD 计算并验证 `MAD_to_sigma = 1.482602218505602` 能使无偏估计成立。

### C. 理论腿

**推导**：
```python
import numpy as np
from scipy import stats

# 标准正态分布的 75% 分位数
q75 = stats.norm.ppf(0.75)  # ≈ 0.6744897501960817
k_MAD = 1 / q75             # ≈ 1.482602218505602
```

**闭式表达**：κ_MAD = 1/Φ⁻¹(0.75) = 1/0.674489... = 1.482602218505602

### D. 订正意见

> 在 P-CST-03 的"文献腿"字段增加正式文献标识（Huber 1981 或 Rousseeuw & Croux 1993），并在《已确立》§3 中给出上述闭式推导过程。

## §2. P-CST-04 高斯 FWHM↔σ因子 `2.3548200450309493`

### A. 文献腿

**主张**：公式导出（2√(2 ln 2)）

**独立核验**：FWHM = 2√(2·ln(2))·σ，其中 ln(2) ≈ 0.6931471805599453。这是高斯分布的标准性质，纯数学推导。

**推荐文献**：Peacock, P. (1984). Comparing Distributions, Ap. J. 283, 387

### B. 实验腿

**现状**：不适用（理论常数）

### C. 理论腿

**推导**：
```python
import math
fwhm_ratio = 2 * math.sqrt(2 * math.log(2))  # = 2.3548200450309493
```

### D. 订正意见

同上，补充文献来源或在《已确立》中写出完整代数推导。

## §8. P-CST-19 ~ P-CST-25+ 待确认项

### P-CST-19 m_ref=6.0 参考星等

**问题**：四条取证链路均未登记出处（合同侧 schema 已登记 scope 与星等制）

**保守方向**：取值 `6.0` 保持不动，但需注明：**亮端取值使 frame_snr 单调下降**（因 `F_ref,k ∝ 10^(0.4·m_ref)` 随 m_ref 增大而减小）

**受影响产品量**：frame_snr_value、HiPS 头参考通量键、snr_phot 归一基准

**量级**：Δm_ref = 1 ⇒ 帧级 SNR 数值差 2.512 倍、权重整体差 6.31 倍（逐帧比值不变）

### P-CST-23 轮廓截断半窗 `profile_half_px = min(256, max(30, ceil(12·FWHM)))`

**问题**：三个数字 `30/12/256` 在三份文档层零命中，`256` 上界不在同处自称冻结的公式内

**保守方向**：**取大窗**（窗越大 ΣP² 越小，σ_F 越大，SNR 越低，即偏红一侧）

**实测量级**：天光 FWHM 60 px 时 SNR 偏 `+4e-6`，120 px `+2.4e-4`，260 px **`+1.33%`**（对应星等偏深约 0.014），现值方向恒偏绿。

### P-CST-24 反距离加权重建参数 `idw_power=2.0`, K=16, γ<1e-10

**问题**：无算法级数值锚，需确保这些值随产品落盘并参与 config_hash

### P-CST-25 孔径组参数

**现状**：生产零消费者，仅影响测试面

**保守方向**：显式声明为"仅测试面参数"并在配置合同上标注 `diagnostic-only`，禁止在报告面引用它们给出产品级数值。

## §9. P2 在科学链上的位置与上下游贯通测试设计

### 上游输入（P1 通量积分拟合）：
- **提供量**：测光星等零点 ZP_k、源通量 F_i、PSF 轮廓 P_i(x,y)、恒星 FWHM_i
- **接口约定**：逐星数组 star_flux/star_fwhm，缺省时降级至统一半径并置 MASK_LEGACY

### P2 核心产出：
1. **逐源通量不确定度 σ_F** 与 **逐源 SNR_F = F/σ_F**（PSF 行路径）
2. **帧级信噪比 frame_snr = median_p(SNR_c)** （无量纲，唯一帧级参考）
3. **逐帧参考通量 F_ref,k = 10^(-0.4·(m_ref - ZP_k))**（与 frame_snr 配对，保证跨帧可比性）
4. **稀疏绝对信噪比控制点层 sparse_snr_layer**（Δ=64 px 网格，cell_center_v1 定位，绝对 SNR 值）
5. **背景方差面 variance_bg** 与 **加权方差面 variance_w（含源项，两案之一）**
6. **口径与来源声明**：snr_caliber、snr_degraded_reason、sigma_sky_source、gain_source

### 下游消费（P3-P5）：
- **P3（HEALPix drizzle）**：消费 sparse_snr_layer 重建的稠密 SNR 场，转换为权重 w(x,y) = SNR²/F_ref² 进行投影叠加
- **P4（重建稠密 SNR）**：直接复用 P2 的重建场与预测方差 predicted_variance
- **P5（加性天光去除）**：用 w(x,y) 对天光模型加权最小二乘拟合并差分，要求权重随位置变化（P-GATE-01）

### 贯通测试用例设计：

**用例 P2-E2E-01**：单帧端到端流程验证

| 步骤 | 输入 | P2 处理 | 输出验证点 |
|------|------|--------|-----------|
| 1 | P1 产物：ZP=25.3 mag、N=50 颗星（F∈[200,10⁵] ADU，FWHM=3 px）、signal 平面 | 计算 σ_F 与 SNR_F | 每颗星的 σ_F > 0，SNR_F ∈ (0,+∞)，n_total = n_valid + n_dropped（P-GATE-19） |
| 2 | 同左 | frame_snr 求值 | frame_snr = median(SNR_c)，reference_flux_adu = F_ref,k 配对性检验（P-GATE-06） |
| 3 | 同左 | sparse_snr_layer 生产 | Δ=64 px 网格，node_placement=cell_center_v1（P-GATE-11），control_points 值均 > 0 |
| 4 | 同左 | 背景方差面 | 8×8 patch，σ_bg 在高斯合成帧上 5% 内复现真值（SNR-004） |
| 5 | 同左 | 加权方差面（分支 A）| variance_w = variance_bg + S_src/g，无源帧上两臂逐位恒等（P-GATE-03） |
| 6 | P2 所有输出 | 模拟 P3 权重换算 | w(x,y) = SNR(x,y)²/F_ref,k²，与 1/σ_F(x,y)² 相对偏差 ≤ 2.22e-16（P-GATE-07） |
| 7 | 同左 | P5 天光拟合权验证 | 权重随位置变化 max(w)/min(w) > 1（P-GATE-01），天光越亮 frame_snr 单调下降（P-GATE-03） |

**失败注入测试**：
- 注入负例①：半径固定 60 px 且 256²/50 星 → rc=1（整帧退化）（MASK-001 负例①）
- 注入负例②：半径固定 2 px 且 F_max=10⁶ ADU → 检出 |σ 偏差| > 2%（MASK-001 负例②）
- 注入负例③：增益未知但走绝对臂 → 缺 snr_caliber ⇒ 拒绝（P-GATE-18）
