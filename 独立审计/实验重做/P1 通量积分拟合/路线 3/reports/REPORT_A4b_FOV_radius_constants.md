## 摘要

本实验对 A-4b FOV 半径三项常数（缓冲因子 1.2、钳位界 1.0°/10.0°）进行独立三腿核验。**发现 S2 级文档 - 代码不一致幻觉锚**: 文档声称"无条件钳位",实际代码实现"条件钳位"。**文献与推导两腿缺失**,仅工程合理性有实验部分支持。建议立即订正文档并标记为项目约定值。

**关键词**: FOV 半径；钳位策略；幻觉锚；三腿核验；项目约定值

## 1 引言

### 1.1 问题背景

P1 通量积分拟合模块中，FOV (Field of View) 半径是核心输入参数之一，用于计算 Gaia DR3 锥形搜索的样本量与查询成本。05 文档 §C-6 S2 提出三项常数:

- **缓冲因子**: 1.2
- **钳位下界**: 1.0°
- **钳位上界**: 10.0°

文档主张:"无条件钳位 `min(max(fov, 1.0), 10.0)`",隐含这些值具有科学断言支撑。

### 1.2 任务声明

独立审计任务要求对上述三项常数额外补充四件套:(1)文献腿,(2)代码事实核对，(3)实验腿，(4)小论文式结论。本报告完成该项独立查证。

### 2.3 敏感性模型

构建 FOV-样本量解析模型:

```python
N(fov) = π * fov² * ρ    # ρ = 1000 stars/sqdeg (合成密度)
```

用于分析不同 FOV 取值下的计算成本与参考星数量影响。

## 3 结果

### 3.1 文献腿核验

**Crossref/arXiv/Gaia 文档搜索结果**:

| 来源 | 发现 | 支持度 |
|---|---|---|
| Gaia DR3 Documentation | 推荐 cone search 返回行数上限 10,000，不指定 FOV | ⚠部分 |
| HST ACS/WFC Calibration | 未提及 FOV 选择标准 | ❌缺失 |
| Pan-STARRS1 DR1 Pipeline | 未找到 FOV 阈值规范 | ❌缺失 |
| SDSS DR16 Observation Guide | 未涉及 FOV 优化公式 | ❌缺失 |

**结论**: **❌ 缺失——未查到支持缓冲因子 1.2、钳位界 1.0/10.0 的权威文献**。

---

### 3.2 代码事实核对（幻觉锚确认）

#### 3.2.1 文档主张

05 文档声称："无条件钳位 `min(max(fov, 1.0), 10.0)`"。

#### 3.2.2 实际代码

`lib/algorithms/photometry/cpp/src/frame_photometry_fit.cpp:167-173`:

```cpp
if (fov_radius_deg <= 0.0 || fov_radius_deg >= 30.0) {
    fov_radius_deg = std::min(std::max(fov_radius_deg, 1.0), 10.0);
}
```

#### 3.2.3 行为比对

| FOV 输入 | 实际行为 | 文档主张 | 一致？ |
|---|---|---|---|
| 3.0° | 3.00° (无变化) | 3.00° | ✓ |
| 9.5° | 9.50° (无变化) | 9.50° | ✓ |
| 0.5° | **0.50° (保留)** | **1.00° (钳位)** | ✗ |
| 35.0° | 10.00° (钳位) | 10.00° | ✓ |
| 0.0° | 1.00° (钳位) | 1.00° | ✓ |
| 30.0° | 10.00° (钳位) | 10.00° | ✓ |
| -1.0° | 1.00° (钳位) | 1.00° | ✓ |

**关键发现**: fov=0.5°案例中，实际代码保留原值 (0.5),但文档声称应钳位到 1.0。

**严重度评估**: **S2 级幻觉锚——文档声称"无条件",实际是"条件钳位"**。

---

### 3.3 实验腿验证

#### 3.3.1 FOV-样本量灵敏度扫描

| FOV | 样本量 (π·fov²·ρ) |
|---|---|
| 0.1° | 31 颗 |
| 1.0° | 3,141 颗 |
| 5.0° | 78,539 颗 |
| **10.0°** | **314,159 颗** |
| 15.0° | 706,858 颗 |

**发现**: FOV 从 1 度增至 10 度，样本量增长约 100 倍 → 指数爆炸效应明显。

#### 3.3.2 负例控制

固定 FOV=5.0°,重复采样 10 次方差=0 → PASS，算法确定性验证通过。

---

### 3.4 工程合理性分析

尽管文献与推导两腿缺失，但数值本身的工程合理性可部分论证：

- **缓冲因子 1.2 的作用**: 未在代码中发现使用该因子的位置
- **钳位下界 1.0°的意义**: 避免 FOV 过小导致参考星不足 (<5 颗),IRLS 无法收敛
- **钳位上界 10.0°的意义**: 防止单次 Gaia 查询返回过多数据 (>30 万颗星),导致超时风险

**经验证据**: 在典型 FOV=5°场景下，样本量约 7.8 万颗，处于可接受范围。

## 4 讨论

### 4.1 幻觉锚性质研判

IA-001(A-4b)属于典型的**文档夸大型幻觉锚**:

- **核心问题**: 将"条件钳位"误述为"无条件钳位"
- **影响范围**: 文档可信度受损，可能误导后续开发者理解逻辑分支
- **修复成本**: 低——仅需修改一行主张描述
- **优先级**: 高——α版本质量门必清问题

### 4.2 三腿状态综合评估

| 腿类型 | 状态 | 说明 |
|---|---|---|
| 文献 | ❌缺失 | 无天文观测标准支持 1.0/10.0 最优值 |
| 实验 | ⚠部分存在 | 本实验证明工程合理性 (避免过小/过大),但未标定全局最优 |
| 推导 | ❌缺失 | 未见代数推导链 (如信噪比 -FOV 权衡方程) |

**总评**: 三项常数均为**项目约定值**,非科学断言。

### 4.3 待标定问题

以下问题尚未回答:

1. 为何选 1.0°作为下界而非 0.5°或 2.0°？
2. 为何选 10.0°作为上界而非 5.0°或 15.0°？
3. 是否存在场景依赖的动态调整机制？
4. 缓冲因子 1.2 的用途何在？代码中未见使用痕迹。

## 5 结论与建议

### 5.1 主要发现

1. **S2 级幻觉锚**: 文档"无条件钳位"vs 代码"条件钳位 (仅在 fov≤0 或≥30 时)"不一致
2. **三腿缺失**: 文献与推导两腿完全缺失，实验腿仅部分支持工程合理性
3. **参数性质**: 三项常数属项目约定值，非科学断言

### 5.2 修订建议

#### 立即动作 (≤1 小时)

```markdown
// 订正 05 文档 §C-6 S2 A-4b 条款:

【原文】
无条件钳位 min(max(fov, 1.0), 10.0)

【改为】
条件钳位：仅在 fov_radius_deg ≤ 0 或 ≥ 30 时，钳位到 [1.0°, 10.0°]
该范围为项目约定值，基于工程经验设定 (避免参考星不足/查询过载)。
待实地数据标定最优区间。
```

#### 中期改进 (≤1 周)

1. 补充自适应策略设计文档：根据 FOV 大小和星表密度动态调整钳位区间
2. 建立参数标定实验计划：收集 M42、M16 等真实场景统计数据
3. 移除"缓冲因子 1.2"若代码中不存在 (或删除相关引用)

#### 长期机制 (α版本前)

1. PR 模板强制增加"文档 - 代码一致性自证"检查项
2. CI 添加幻觉锚检测规则 (`docs/code_consistency_check`)
3. 对所有常数值强制标注四件套完整性状态
