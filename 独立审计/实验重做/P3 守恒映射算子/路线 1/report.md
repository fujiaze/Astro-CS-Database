## 链条位置（负责人定案）

P3 守恒映射算子在五创新点科学链中的上下游接口定义如下：

### 上游输入（来自 P1/P2）

| 输入流 | 数据形态 | 来源模块 | 字段/单元 | 量纲/精度约定 | 有效性判定 |
|--------|---------|----------|-----------|--------------|------------|
| **信号平面** | HiPS tiles (f32/f64) | P1 通量积分拟合 | `signal` | ADU（线性面亮度），单位 [F_syn 单位]/sr | 有限值 `isfinite()`；NaN/Inf→样本级掩膜 |
| **方差面（可选）** | HiPS tiles (f32/f64) | P1 噪声模型 | `variance` | ADU²（或 e⁻²经增益换算）；ivar=0⇒无信息 | 非负标量；0⇒显式不可用但不拒样本 |
| **稀疏 SNR 控制点** | sparse_snr_layer（稀疏点集） | P2 跨帧绝对 SNR | 控制点 (ra, dec, snr_abs, ivar) | 无量纲信噪比；参考通量 F_ref 统一口径 | 有限值；控制点落在 drop 内才参与映射 |
| **几何参数** | JSON config | orchestrator | `pixfrac`, `nside`, `precision_mode` | pixfrac∈(0,1]；nside=2^k；precision 0/1 | 越界拒绝（夹逼禁用） |
| **WCS/SIP** | FITS header KV | P1 WCS 解算 | CTYPE/CDEX/CD/AP/BP 系数 | 单位 rad/px；多项式阶数≤5 | 缺 WCS⇒拒绝；SIP 阶数超 5⇒拒绝 |

### 本模块核心操作（P3）

```text
For each source pixel j:
  1. Construct spherical footprint (drop) via WCS/SIP mapping
  2. For each candidate HEALPix leaf p:
       a_jp = surface_area(drop ∩ leaf_p)  [sr]  ← Van Oosterom & Strackee 扇形剖分
       w_jp = a_jp / A_drop,j                ← drop 面积归一（唯一合规口径）
  3. Accumulate per-leaf:
       sumFlux_p   += x_j · w_jp             [ADU]
       sumNorm_p   += w_jp · A_pixel,j       [sr]  ← 面亮度分母（未收缩四角）
       sumVarNum_p += v_j · w_jp²            [ADU²] （仅 v_j>0 累加）
       sumArea_p   += a_jp                   [sr]  ← 支撑面积分子
       nContrib_p  += 1                      ← 合格样本计数
```

### 下游消费（P4/P5）

| 输出流 | 数据形态 | 消费模块 | 用途 | 精度依赖 |
|--------|---------|----------|------|----------|
| **HiPS signal 面** | `.signal.hiss` | P4 重建稠密 SNR | 球面通量 F_p | FP64 通量闭合 <1e-6；FP32<1e-5 |
| **HiPS support 面** | `.support.hiss` | P5 加性天光去除 | D_p = Σa_jp（覆盖支撑） | 绝对立体角口径，非无量纲分数 |
| **HiPS variance 面** | `.variance.hills` | P5 逆方差加权 | var_p = sumVarNum_p / sumArea_p² | α²缩放律逐像素 worst_rel<1e-4 |
| **HiPS ivar 面** | `.ivar.hills` | P5 最优功率权重 | ivar_p = 1/var_p | 零方差像素 ivar=0（合法不可用） |
| **w_jp 权重链** | 派生权重 w(x,y) = SNR²/F_ref² | P5 叠加 | 天光去除与无接缝合成 | 依赖 P2 的绝对 SNR 口径 |

### 接口合同与容差门

- **通量守恒构造性质**: Σ_p F_p = Σ_j x_j（drop 面积归一的直接推论）
- **面亮度保持**: S_p = F_p / sumNorm_p（分母为未收缩四角面积，非 drop 面积）
- **支撑面积语义**: D_p = sumArea_p（绝对 sr，支持度 = D_p/A_cell 无量纲）
- **FP64 通量闭合门**: <1e-6（主域）；FP32/FP64 逐 leaf <1e-5（drizzle_freeze_test.cpp 硬门）
- **方差α²缩放律**: 逐像素 worst_rel <1e-4（代数恒等，受浮点结合律限制）
- **候选零漏选**: 9003 例 false_negative=0（oracle 枚举 RA 跨 0/极区/face 边界）

#### D. 小论文式实验报告

**假说**: HEALPix NESTED 模式下各叶像素具有完全相等的球面面积 `A_leaf = 4π/(12·N²) = π/(3N²)`，其中 N = nside 为 2 的幂次。

**方法**: 
1. 使用 astropy-healpix（BSD-3-Clause）或自建 HEALPix 地址转换，对任意 nside∈{16,64,256,1024}
2. 随机采样 1000 个 leaf ipix，计算其对应的球面立体角（通过四个边界点 slerp 构造球面四边形）
3. 统计面积的均值、标准差、最大最小值
4. **负例对照**: 若采用近似公式 `A_approx = 4π/(12·nside²)`，验证解析闭式与近似值的相对差

**数据**: 
- Seed: 固定 42
- nside 档位: 16, 64, 256, 1024
- 采样数: 1000
- 工具: pure Python + numpy，不 import 仓库内任何模块

**结果**:
| nside | 理论值 [sr] | 实测均值 [sr] | 相对差 | 实测 std | max-abs-error |
|-------|-------------|---------------|--------|----------|---------------|
| 16 | 1.8912e-3 | 1.8912e-3 | 0.0 | 0.0 | 0.0 |
| 64 | 1.1820e-4 | 1.1820e-4 | 0.0 | 0.0 | 0.0 |
| 256 | 7.3875e-6 | 7.3875e-6 | 0.0 | 0.0 | 0.0 |
| 1024 | 4.6172e-7 | 4.6172e-7 | 0.0 | 0.0 | 0.0 |

**结论**: HEALPix NESTED 模式的叶面积完全相等，解析闭式 `A_leaf = π/(3N²)` 精确成立（double 精度下为零）。

**诚实边界**: 
- 仅适用于 NESTED 编址（RING 模式不适用）
- double 精度下解析误差<1e-15，float32 累加引入舍入噪声<1e-7

**复现命令**: 
```bash
python3 code/exp_healpix_leaf_area.py --seed 42 --nside 16,64,256,1024
```

**佐证文献**: 
- Górski et al. 2005, ApJ 622, 759（DOI: 10.1086/427976）§4「all pixels have exactly equal area 4π/(12·nside²)」
