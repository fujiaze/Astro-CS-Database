## 2. 【链条位置】

P5 在五点链上居末端：P1 通量积分拟合（测光星等坐标系，根基）→ P2 跨帧绝对 SNR → P3 守恒映射算子（HEALPix drizzle + 稀疏 SNR 控制点上球）→ P4 重建稠密 SNR → **P5 加性天光去除与无接缝叠加**。

**上游输入（P1–P4 → P5）**：
- P1 提供乘性归一后的面亮度样本（raw，ADU·sr⁻¹，BUNIT 冻结集）；P5 的纯加性决议（g_k≡1，PHASE2_UPM §14a）以此为前提——帧间乘性差必须已在 Phase1 吸收（11_upm 实测乘性比偏离 1 仅 5.89e-4）；
- P2/P4 提供观测权重的全部原料：control_ivar = 1/control_variance、control_variance = k_corr·(π/2)·σ_bg²/N_retained（M1）、quality_factor 与 N_retained。**量纲约定：w_UPM 为 (ADU·sr⁻¹)⁻² 绝对逆方差量，跨标度混用前必须先声明 Ω_px 换算（PHASE2_UPM §3）**；
- P4 的稠密 SNR 场为 UPM 拟合的 per-observation 权重提供插值面（M6 的 w = qf·reliability·ivar 消费的就是它）。

**P5 的下游消费（P5 → 叠加/导出）**：
- UPM 输出 per-frame 加性校正场参数（8×8 control cell 的 C_f = B_ref + δ_k），**实际施加量 = δ_k（保留 B_ref）**，施加归一化后的帧进入叠加；
- 下游叠加的方差 = 1/Σw（E6 链条用例实测 stacked_variance = 5.93e-2，权重来自上游 ivar）；
- 无接缝证据面 = 接缝门槛 max|rel_step| ≤ 1e-2（M3），这是 P5 对链条的交付判据：它保证 δ_k 校正后帧间电平差落在门槛下，从而叠加产品无假结构。

**贯穿上下游的用例（本路线实验内实现）**：E1 生成两个 control 的 ivar（比值 1:4，来自 k_corr·π/2·σ_bg²/N 公式，即 P2/P4 的量）→ E6 把它们作为 UPM 观测权重的输入（w = qf·reliability·ivar），演示基准 qf 抵消、比值起效、以及 share/absolute 两种求解口径在 ivar 跨 control 变化时的 14.8% 相对差（PHASE2_UPM §5 性质 iii）→ 下游叠加方差 1/Σw。该用例覆盖"上游给什么量、下游拿去做什么、量纲/精度约定"三要素。

**有效性约定**：control_ivar 必须有限且 >0，否则 p2_upm_raw_weight rc=2（fail-closed，PHASE2_UPM §4）；S=0 时 ivar 必须 =0（M10）；k_corr 必须带标定域与适用域陈述（M2）。

## 3. 逐项报告（每项：假说/方法/数据/结果/结论/诚实边界/复现命令/佐证文献）

### M1 control_variance = k_corr·(π/2)·σ_bg²/N_retained（E1）

- **假说**：高斯 iid 下 Var(median) 的渐近式 πσ²/(2N) 成立，N≥65 时近似良好；非高斯分布的比值（均匀 ≈1.91×、拉普拉斯 ≈0.335× 高斯值）可复现；等相关把方差放大 k 倍（N_eff = N/k）；σ→0 时一切归零。
- **方法**：解析代数合成。固定 seed=20250926，纯 numpy；三分布（高斯/均匀 σ=1/拉普拉斯 σ=1）× N∈{5,20,65,289}，MC 重复 2 万–40 万次测 Var(median)；等相关用 z=√ρ·c+√(1−ρ)·e（ρ∈{0,0.05,0.2}，N=65）；另做端到端腿：σ_bg 用同 patch 的 1.4826·MAD 估计（采样器实践）后按公式发布 control_variance，与真值 Var(median) 比。
- **数据/结果**（results/e1_control_variance_median.json）：

| 分布 | N=5 | N=20 | N=65 | N=289 | 渐近预测 |
|---|---|---|---|---|---|
| 高斯 ratio | 1.4373 | 1.4671 | 1.5687 | 1.5808 | π/2=1.5708 |
| 均匀 ratio | 2.1407 | 2.5945 | 2.9074 | 2.9792 | 3.0 |
| 拉普拉斯 ratio | 0.8789 | 0.6693 | 0.6001 | 0.5488 | 0.5 |

  - 均匀/高斯渐近比实测 1.8966（文档声称 1.91 ✓）；拉普拉斯/高斯实测 0.3494（文档 0.335，渐近精确值 0.3183——两者间，收敛慢，定性成立）。
  - 等相关：ρ=0.05 时中位数方差放大 3.02 倍 vs 均值放大 4.20 倍；ρ=0.2 时 9.08 vs 13.77。**中位数的方差对等相关的敏感度低于均值**——把按均值口径标定的 k_corr 直接套进中位数公式是近似而非恒等。
  - 端到端腿（σ_bg=MAD 估计）：N=5 时发布值/真值 = 0.990（≈−1%），纯公式/真值 = 1.096（**+9.6%，高估**）；N=65 时 1.002/1.005。
  - **负例（真值无效应⇒度量归零）**：ρ=0 时 k_eff−1 = −0.0054（MC 误差内归零）；σ=0 时 Var(median) = 0.0 精确归零（对应 S=0 ⇒ ivar=0 的冻结发布口径）。
  - 链条用例：两 control σ 差 2 倍 ⇒ ivar 比 4.0 = 预期 1:4 ✓。
- **结论**：公式本体（渐近系数 π/2、N≥65 适用域、k_corr 放大方向）三腿齐、成立。**但文档两处陈述不成立**：(a) "N=5 时渐近式低估方差 8.5%"——纯公式对真 σ 是**高估 9.6%**（1.4373 vs 1.5708），方向相反；(b) 端到端（含 MAD 小样本偏差）在 N=5 仅 −1%，也非 8.5% 低估。见 §7 相左清单。
- **诚实边界**：MC 统计误差 ~0.5%；端到端腿的 MAD 估计器约定（1.4826·median|x−med|）未必逐字等于 sampler.cpp 的实现（后者被审计报告标为待整改点，本路线不读实现只对文档口径）；"8.5%"的原始测量若基于不同的 σ_bg 估计器约定，可能仍自洽——但按其文档给出的公式与常数无法重构该数。
- **复现命令**：python3 code/e1_control_variance_median.py（输出 results/e1_control_variance_median.json）。
- **佐证文献**：refs.md R3（Serfling 1980，书目级）、R10（Φ⁻¹(3/4) 恒等式）。

### M2 k_corr 定义域与冻结值 1.4（E2）

- **假说**：drizzle 重采样使控制 patch 内样本相关 ⇒ Var(median) 超过 iid 公式 ⇒ k_corr>1；冻结默认 1.4（声称 MC 实证 1.3883，pixfrac=0.8、2000 次）。
- **方法**：纯合成物理前向。独立重实现 drizzle（输入像素格 + 输出过采样因子 F∈{2,3,4}、pixfrac=0.8 的收缩足迹重叠加权、通量守恒归一）；2000 次迭代；控制 patch = F² 个相邻输出像素（恰一输入像素面积）；k_corr_est = Var(median_patch)/((π/2)·σ_bg²/N)，σ_bg 为稳健尺度（1.4826·MAD）。seed=20250926。
- **结果**（results/e2_kcorr_drizzle_mc.json）：

| F | N_retained | k_corr_est | lag-1 相关 | N_eff |
|---|---|---|---|---|
| 2 | 4 | 2.55 | 0.53 | 1.56 |
| 3 | 9 | 5.77 | 0.76 | 1.56 |
| 4 | 16 | 10.26 | 0.82 | 1.56 |

  - **负例**：无重采样的原始输入像素中位数（无相关）k_corr_est−1 ≈ 0（iid 恒等式归零）✓。
- **结论**：定性主张 **k_corr>1 成立**（任何相邻 patch 定义下都 >1）；但 **1.3883 不可从已文档化信息复现**——本独立实现的 k_corr_est 依赖 patch 几何与 σ_bg 口径（2.55–10.26，而 N_eff ≈1.56 稳定）。原 MC（control_median_mc_test）的 patch 定义、dither 设置、σ_bg 口径均未在 docs 中给出到可复现程度。
- **诚实边界**：本实现无 dither（单指向）；drizzle 归一化采用面积权重直接归一；F 与 patch 定义是本路线选择，非原 MC 的复原。若负责人要求定案 1.4 的可复现性，需先补记 control_median_mc_test 的 MC 几何（该测试的注册状态在 PHASE2_UPM §9/§11 有两种陈述，本路线未核其构建面）。
- **复现命令**：python3 code/e2_kcorr_drizzle_mc.py（输出 results/e2_kcorr_drizzle_mc.json；约 2 分钟）。
- **佐证文献**：refs.md R5（Fruchter & Hook 2002——支持相关性存在，**不含 1.4/1.3883 数值**）。

### M3 接缝门槛 1e-2 与确定性下限 1.005%（E3）

- **假说**：(a) 噪声→0 时 rel_step = Δ/(L+Δ/2)，门槛穿越点 Δ/L = gate/(1−gate/2) = 1.0050%；(b) M42 噪声（σ_pix/bg=1.0703e-2）下受影响边数 n_s=1,2,4 的检出曲线接近 §17.3（1.00% 处 n_s=4 → ~97%）；(c) 反向梯度可把确定性判红的台阶抵消为绿（D-57 机制）；(d) 解析式 √2·σ/bg 高估单边噪声。
- **方法**：合成图像 512×512，L=1，垂直边界，d=2，N_e=256 采样点，30 seed × 9 档幅度；114 条适用边（多重性取 max）。seed=20250926。
- **结果**（results/e3_seam_gate_1e-2.json）：

| Δ/L | n_s=1 | n_s=2 | n_s=4 |
|---|---|---|---|
| 0.90% | 0.10 | 0.20 | 0.40 |
| 0.95% | 0.20 | 0.43 | 0.63 |
| 1.00% | 0.43 | 0.77 | 0.90 |
| 1.05% | 0.70 | 0.83 | 1.00 |
| 1.50% | 1.00 | 1.00 | 1.00 |

  - 确定性下限：Δ/L=1.005% 处 rel_step=0.0099998，穿越公式精确成立 ✓。
  - 梯度抵消：2% 台阶（无梯度时 rel_step=0.0198，确定性判红）+ 反向梯度 2d·g=−Δ ⇒ rel_step **精确 =0**（绿）；纯梯度实测 −0.0200 = 预测 4g/bg ✓（D-57 机制证实）。
  - 零假设 σ(rel_step)=1.22e-3（M42 实测 1.187e-3 同量级）；解析 √2σ/bg=0.01514 vs 单边实测均值 0.01210（高估 1.25×，文档"解析式高估"方向 ✓，倍数因采样插值约定而异）。
  - **负例**：零效应（无台阶无梯度无噪声）rel_step = 0.0 精确归零 ✓。
- **结论**：门槛 1e-2 的两条腿（闭式推导 + 实测标定）独立复算成立；多重性下的检出曲线与 §17.3 一致（1.00%、n_s=4：实测 0.90 vs 文档 96.7%，差在几何与 seed 结构）；梯度抵消盲区是真实漏洞，与 D-57 判定一致。
- **诚实边界**：整数像素采样（无亚像素双线性），故解析高估倍数（1.25×）不同于文档的 1.59×；检出曲线用独立边近似代替真实帧足迹的多边形邻接结构；未复算 §17.2 的 Clopper–Pearson 区间数值。
- **复现命令**：python3 code/e3_seam_gate_1e-2.py（输出 results/e3_seam_gate_1e-2.json）。
- **佐证文献**：refs.md R6（Clopper–Pearson 1934，虚警率区间口径）、R3（中位数标准误 √(π/2) 系数）。

### M4 方差比诊断量（E4）

- **假说**：电平阶跃不改变各侧块内方差 ⇒ 方差比对电平接缝失明；块常数伪影与噪声放大则可由方差面捕捉——判据量之间互为盲区，故方差比只能作渲染伪影粗筛、帧间无接缝证据必须取 rel_step 门槛（PHASE2_UPM §9a、11_upm §4.1）。

2. **max_nodes_absolute**：资源预算，不进入任何科学判据的分子分母；其多头不一致（8192/2048/4）是工程缺陷（D-64），非科学缺口。
3. **IRLS 停止容差**：数值停止规则，只要满足"无量纲、相对化"的冻结要求（11_upm §4.6）即不承载科学语义；1e-8 与 1e-6 的不一致是登记面问题。
4. **1e-12 保护量本身**：它是"无信息"的哨兵值，其数值唯一正当用途是触发 fail-closed（ivar=0），发布其平方属缺陷（D-01）而非常数缺腿。
