## 【链条位置】P4 在五点科学链中的角色与端到端用例

P1 通量积分拟合给出逐源通量与通量不确定度（根基）→ P2 把单帧测光提升为**跨帧绝对 SNR**（稀疏控制点上存储绝对 SNR，语义 = absolute_flux_type_snr：`sparse_snr_value = F_ref/σ_F,c`，分子固定为参考通量）→ P3 把通量与控制点经通量守恒映射算子上球 → **P4 把球面/帧面上稀疏控制点重建为稠密 SNR 场，供逐像素定权** → P5 在该权重场下做加性天光拟合去除与无接缝叠加。

**端到端用例（本报告 EXP-P4-04 实测）**：输入帧（256² px，Moffat β=2.5 源 25 个，σ_slow² 平面缓变）上，P2 在 8×8 控制格（Δ=32 px，cell_center_v1）写入绝对 SNR 控制值 `SNR_c = F_ref/√(σ_slow²+S_src/g)`（g=1.3 e⁻/ADU）；P4 以自然三次样条（natural_bicubic_spline_clip_v1）重建稠密 SNR 场；P5 侧按唯一权重公式 `w = SNR_hat²/F_ref² = 1/σ̂_w²`（P-ALG-10）逐像素定权做异质方差均值估计：μ̂ 相对误差 4.5e-3，效率损失 E = 7.4e-4（相对逐像素真方差）；若 P2 口径丢失源项（背景受限 σ），同一链路 E 恶化到 1.7e-3（极端对比场景 0.037 → 0.433，12 倍）；若退化为帧级常数（frame_reconstruct 口径），动态范围保持比从 0.99 掉到 0.75。**P4 的质量直接决定 P5 叠加与天光拟合的效率上限；控制值是否携带亮度（源项）决定权重是否最优**。

维度与精度口径：控制格间距 Δ ∈ {16,32,64,128} px 实测覆盖；重建在节点处精确到机器精度（<=3.6e-15，容差 1e-9，P-CST-12 自检）；有效域为"在 >= Δ 尺度上平滑的场"（见 I8 诚实边界）。

## I1 定权幂次 2：w = SNR²/F_ref² = 1/σ_F²（P-ALG-10）

**假说**：逆方差权 w ∝ 1/σ² 是异质方差测量的唯一最优权；且"SNR 的平方除以 F_ref²"恒等于逆方差（同一物理量的两种写法，不是两种权）。

**理论腿**：对独立无偏测量 x_k ~ N(μ, v_k)，加权均值 Var[μ̂_w] = Σw_k²v_k/(Σw_k)²。由 Cauchy–Schwarz，(Σw_k)² <= (Σw_k²v_k)(Σ1/v_k)，等号成立当且仅当 w_k ∝ 1/v_k。SNR = F_ref/σ_F ⇒ SNR²/F_ref² = 1/σ_F²：幂次 2 是"平方 SNR = 逆方差"这一恒等式的直接推论，不是自由参数。

**实验腿（EXP-P4-01，`code/exp_p4_01_weight_optimality.py`，seed 20260926，0.5 s）**：

| 检验 | 结果 | 判据 |
|---|---|---|
| 恒等式 SNR²/F_ref² vs 1/σ²（n=2000 随机 σ） | 最大相对偏差 5.55e-16 | < 1e-12 ✅ |
| SNR 传播恒等式 1/SNR_comb² = Σc_k²/SNR_k²（单一 F_ref,c） | 相对偏差 0.0 | < 1e-12 ✅ |
| 异质方案对比（n=8，40000 次）：逆方差 E | **-0.0077** | 基准 ✅ |
| 同上：等权 E | 84.84 | 应大 ✅ |
| 同上：w ∝ SNR（幂次 1，正权未归一）E | 0.956 | 应大 ✅ |
| 同上：w ∝ SNR² E | -0.0077（= 逆方差） | 恒等式复现 ✅ |
| 负例：真值零效应（所有 σ 相等 ⇒ 一切正权最优） | max E = 0.0049（≈0，蒙特卡洛噪声） | 归零 ✅ |

（E = Var_w/Var_opt − 1；负值系 Var_opt 分母抽样涨落，量级为 MC 噪声。）

**文献腿**：Zackay & Ofek 2017（ApJ 836, 187/188；摘要逐字"sum the images with the appropriate weights...that maximize the signal-to-noise ratio"）；Horne 1986（PASP 98, 609，逐源最优提取 σ_F 口径）；Naylor 1998（MNRAS 296, 339）。核验记录见 refs.md L2–L4。

**结论**：幂次 2 成立，且 P-CST-21 的四指数（α=2/β=1/γ=2/δ=1）与 P4 的逆方差指数 2 **不是同一科学量**（见 I7 判定）。与 P-ALG-10、07_noise_snr.md §4、CONTROL_WEIGHT_SNR.md §2b 一致。

**诚实边界**：E 的符号在 MC 涨落下可为小负数；恒等式检验假设高斯性与独立性，未测相关噪声。

**复现**：`cd 独立审计/实验重做/P4重建稠密SNR/路线1/code && python3 exp_p4_01_weight_optimality.py`（输出 ../results/exp_p4_01_weight_optimality.json）

## I2 重建算子三性质与钳制（P-ALG-09，natural_bicubic_spline_clip_v1）

**实验腿（EXP-P4-02，`code/exp_p4_02_interpolators.py`，seed 20260926，6.7 s）**：512² 帧，40 个高斯斑合成 SNR 真值（相关长度 48 px），Δ ∈ {16,32,64,128}，评估逐 4 像素网格。**过程诚实记录**：本路首版代码曾把节点 0 放在原点 0 而 cell_center_v1 节点在 i·Δ+(Δ−1)/2，整体错位 (Δ−1)/2 px（Δ=32 即 15.5 px）——恰是审查强调的相位约定问题在自己代码中的复现；修正后 node_placement 对比臂量化了该错位的代价。

## I3 IDW 参数（P-CST-24：idw_power=2.0, K=16, γ<1e-10）

**假说**：p=2 是合理默认；IDW **不是**默认重建算子（默认 = natural_bicubic_spline_clip_v1，05_forward P-ALG-09）；K=16（4×4 节点邻域）与 γ=1e-10（重合点数值守卫）可复现。

**实验腿**：EXP-P4-02 的 idw_p1/p2/p4 列即幂次扫描（K=16、γ=1e-10 实现）：Δ=32 处 dex-RMSE 0.0687/0.0430/0.0345（p=1/2/4），Δ=64 处 0.1311/0.0985/0.0837——p 越大越接近最近邻、在光滑场上小 p 的"平台化"偏差更重，与 Lu & Wong 2008（Comput. Geosci. 34, 1044）指出的 IDW 对 p 敏感、需按数据密度适配的结论方向一致；Shepard 1968 原文即 p=2 起家（refs.md L1/L6）。IDW 与样条的 E 差距随 Δ 增大而缩小（Δ=128 处 IDW p=2 的 E 反而低于样条）——IDW 无过冲、样条高曲率代价，属真实权衡而非某一方全优。

**判定与豁免**：γ=1e-10 是浮点重合守卫（数值卫生），非科学常数，**豁免三腿**（同 1e-9 节点容差）；p=2 与 K=16 的"最优性"依赖场形态，规格只冻结取值不作最优性主张，本路按"可复现 + 敏感性已测"处理。**未决**：P-CST-24 的锚定状态为"待确认"（owner 未签），本路不改判，仅确认参数可实现且行为符合文献预期。另注：N-27（snr_phot = median_snr 恒等式 ⇒ 重建 ≈ IDW(绝对SNR)）是**估计量路径**陈述，05 规格的算子词表中确无 IDW 条目——两文档口径存在未收口的张力，登记为跨文档一致性问题（不改冻结定义）。

## I5 控制点几何判据 λlo/λhi >= 1/16（P-CST-17）

**假说**：判据作用于**中心化 2D 点云散布矩阵**（2×2，常数列不进矩阵），λhi/λlo 即点云轴比，κ = √(λhi/λlo) 为轴比平方根；阈值 1/16（κ<=4）是充分（保守）的良态条件。

**理论腿**：κ = √(λhi/λlo) = 点云长短轴比——纯几何恒等式（均匀压扁点云实测 κ = 轴比，偏差 <=0.03%：轴比 1/2/4/8/16 ⇒ κ = 1.000/1.999/3.999/7.998/15.995，N=2e5，EXP-P4-03 theory_check）。

| 0.00 | 0.7565 | 1.15 | 0.149 |
| 0.50 | 0.5469 | 1.35 | 0.138 |
| 0.875 | 0.1464 | 2.61 | 0.139 |
| 0.9375 | 0.0747 | 3.66 | 0.150 |

- **负例（零噪声）**：系数恢复相对误差 8.1e-15 ✅
- **各向同性控制**：随机云最小 λlo/λhi = 0.330（N=200 次实现）≫ 1/16，永不误红 ✅

## I6 三口径同一物理量：dense / sparse_reconstruct / frame_reconstruct

**假说**：三口径是**重建方式**（同一控制值网格的三种还原粒度），不是三种定权口径；权重只有一条公式 w = SNR²/F_ref²。

**实验腿（EXP-P4-04 臂对比，EXP-P4-01 恒等式）**：EXP-P4-04 中 frame_reconstruct 臂 = 中位数控制值平铺（frame_scalar_snr = 0.177），与 sparse_reconstruct（样条重建）共用同一权重公式，仅精度不同：dex-RMSE 0.0295 vs 0.0058，动态范围保持比 0.75 vs 0.99，E 0.018 vs 0.0007——三口径的差异**全部表现为同一权公式下的重建保真度差**，无一改变权本身。EXP-P4-01 的恒等式（w ∝ SNR² ≡ w ∝ 1/σ²，偏差 5.6e-16）说明"SNR 权"与"逆方差权"也是同一物理量的两种写法。`snr_path_effective`（选择有效重建路径）不引入新量，与 N-27 的估计量路径陈述相容。

**结论**：I6 成立。审查条目按"权重口径混用"表述的部分不成立；按"三口径名称易被误读为三种权"的文档清晰性批评成立。

## I8 亮度正向约束：重建量必须携带源项（S_src/g）

**假说**：σ_w² = σ_slow² + S_src/g 中源项不可丢：控制值 = F_ref/√(σ_slow²+S_src/g)（absolute_flux_type_snr 语义）⇒ w = SNR²/F_ref² 恰为最优权；丢源项（背景受限口径）⇒ 亮源处权重被系统性高估 ⇒ E > 0。

**实验腿（EXP-P4-04，seed 20260926，2.7 s）**：256² 帧，Moffat(β=2.5, FWHM=6) 25 源，σ_slow² 平面缓变；控制值取 8×8 cell 聚合模型量（表示域 >= Δ=32 px）。

**Oracle 信息检验（隔离"信息内容"，无重建噪声）**：

| 权来源 | E（n=4000 像素，真方差含源项） |
|---|---|
| 含源项 SNR ⇒ w = 1/σ_w²（代数最优） | **2.22e-16（机器零）** ✅ |
| 丢源项（背景受限）⇒ w = 1/σ_slow² | 1.31e-3 ✅（> 0） |
| 等权 | 1.78e-2 |

**重建臂（主场景，2-dex cell-SNR 对比度）**：A_full dex=0.0058 / E=7.2e-4 / 动态范围保持 0.989；A_bglimit dex=0.0097 / E=1.7e-3 / 0.966；A_frame_recon dex=0.0295 / E=1.8e-2 / 0.753。**极端场景（4-dex 对比度，边界发现不入门）**：A_full E=0.037 vs A_bglimit E=0.433（12×）vs A_frame_recon E=0.408——对比度越大，丢源项的代价越爆炸。

**负例（零源）**：无源时含源项/背景受限两控制格逐像素恒等（max dev = 0.0），E_full = E_bglim = 3.3e-4——"亮度携带收益"精确归零 ✅（这是本实验的正确非退化形式：收益只在有源时存在）。

**下游佐证（P5 侧）**：(a) 叠加估计 μ̂ 相对误差 4.5e-3（3000 像素异质方差抽样）；(b) P5 式天光平面拟合中，SNR 派生权在天区样本上**自动复现**背景逆方差（w = SNR²/F_ref² = 1/σ_slow²，b0 相对误差 0.0020 vs 真 ivar 0.0028）——即两方差面之别在于 σ 取"含源/不含源"，而非"SNR 权不能用于天区"；文档中"两方差面不混用"的实质是源项开关，本实验给出数值界定。

**诚实边界（重要）**：逐像素 PSF 尺度的 SNR 与 cell 聚合目标的偏差中位 3.8 dex（p99 5.7 dex）——**稀疏控制格不表示 PSF 尺度结构**，稠密重建的有效域是"在 >= Δ 尺度上平滑的场"；PSF 尺度归逐源测光（P1）与结构感知估计器（07_noise_snr.md §4.5 的 mesh_median 分支）管辖。本实验全部度量在 cell 表示域内定义。
