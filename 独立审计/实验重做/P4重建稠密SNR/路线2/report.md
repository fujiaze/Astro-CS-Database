## 1. 【链条位置】

P4 在科学链中的位置与三腿证据的接口含义（依据 ASTROCS_DESIGN §2.4、NOISE_MODEL §5a/5b/5c、CONTROL_WEIGHT_SNR §2a/2b、weight_chain.cpp:91,153-155、snr_evaluator.h:109,113）：

```
P1 通量积分拟合(星等坐标)
   │  frame 级：F_ref、PSF 归一、σ 标定
   ▼
P2 跨帧绝对 SNR ──► sparse_snr_layer（稀疏控制点：位置、snr_value、snr_err、frame_snr、F_ref_k）
   │                                          │
   ▼ P3 平面→球面通量守恒 drizzle             │ 磁盘产品 + manifest + 哈希（阶段间唯一交换方式）
   │                                          ▼
   │                            P4 重建稠密 SNR（本模块）
   │                            · frame 域默认算子 natural_bicubic_spline_clip_v1
   │                              （weight_chain.cpp:153-155；备选 bilinear）
   │                            · drizzle/球面侧评估器 IDW（snr_evaluator.h:109,113：
   │                              idw_power_=2.0、K=16、γ<1e-10 数值门）
   ▼                                          ▼
P5 加性天光去除与无接缝叠加 ◄── w = SNR²/F_ref² = 1/σ_F²（weight_chain.cpp:91）
```

**接口约定（量纲/精度/有效性）**：
- 量纲：控制点 snr_value 无量纲（§2a 参考电平定义 snr = F_ref/σ_F）；权重 w = (snr/F_ref)² 数值上等于 1/σ_F²（E01-A 逐位验证），帧集内 F_ref² 为公共尺度因子，跨帧相对定权不受其影响；
- 精度：节点复现自检门 1e-9（P-CST-12，工程性）；本路实测 FP64 节点复现残差 3.6e-15（E02），控制点 2% 噪声下重建 RMSE 0.08 dex（E07）；
- 有效性（判据非退化）：接口两侧都挂"真值无效应⇒度量归零"负例——P4 侧零源⇒稠密场 max|SNR|=0 精确成立（E07）；P5 侧零源帧两个权重臂逐位恒等（E06）。

**跨接口用例**（I-07 的端到端迷你链）：P1 语义（源面 + 天光电平 + 噪声模型）→ P2 语义（Δ=64 控制点上的绝对 SNR ± 2% 测量噪声）→ P4（IDW p=2,K=16 稠密重建）→ P5（两帧 σ 比 3× 的定权堆叠 vs 等权）。该用例同时验证三件事：亮度跟随（通量×10 ⇒ SNR×√10，重建场跟随而非复制方差图）、零源归零、定权增益闭合（实测 1.0428 vs 同口径理论 1.0444）。

## 3. 逐项报告（假说/方法/数据/结果/结论/诚实边界/复现/佐证）

### 3.1 I-01 权重恒等式与 γ=2（P-CST-21）

- **假说**：§2a 参考电平口径（snr = F_ref/σ_F）下，w=(SNR/F_ref)² = 1/σ_F² 逐位恒等；异方差堆叠中按 SNR^γ 定权的最优 γ=2。
- **方法**：A 腿 FP64 恒等式验证（含逐帧不同 F_ref_k 变体）；B 腿 24 帧 σ∈[5,160] ADU 对数均匀、20000 次试验的 γ∈{0,…,3} 扫描；同方差负例（γ 判据必须失效归一）。
- **数据**：results/exp01_weight_identity_gamma.json（seed 20260926）。
- **结果**：
  - A：max_rel_dev = 4.44e-16（变体 5.55e-16）——恒等式逐位成立；
  - B：异方差 stack 相对方差在 γ=2 处最小（6.458e-06），oracle 逆方差 6.543e-06 同水平；最差 γ=0 比 γ=2 差 26.3×；
  - 负例：同方差场景 gain = 1.0125 ≈ 1 ⇒ 判据非退化。
- **结论**：四指数中 α=2/β=1/δ=1 是数学必然，γ=2 的物理内容 = 逆方差定权（R-03 方向佐证）。**γ=2 不是待标定的自由参数，而是有严格理论内容的量**。
- **诚实边界**：B 腿以"测量 SNR 无偏且其平方 ∝ 1/σ²"为前提；若帧内 SNR 估计有系统偏差，γ=2 的最优性 transfers 到偏差修正后的量。
- **复现**：`python3 code/exp_P4R2_01_weight_identity_gamma.py`
- **佐证**：R-03。

### 3.2 I-02 IDW 参数（P-CST-24）

- **假说**：idw_power=2.0、K=16、γ 门 1e-10 是否有实验/理论支撑。
- **方法**：1024²、Δ=64 控制格、真值=平面+弱曲率；p∈{0.5,1,1.5,2,2.5,3}×K∈{4,8,16,32,all}×噪声{0,2%,6%} 全扫描；节点复现负例（无噪声时插值器必须在控制点归零）；γ 门的浮点余量分析；bilinear 参照。
- **数据**：results/exp02_idw_params.json（seed 20260927）。
- **结果**（rmse_rel，越小越好）：

  | 噪声 | IDW 最优 | bilinear 参照 |
  |---|---|---|
  | 0 | p=2.0,K=4 → 1.639e-3 | 1.027e-3 |
  | 2% | p=0.5,K=16 → 6.827e-3 | 1.481e-2 |
  | 6% | p=0.5,K=32 → 1.414e-2 | 4.056e-2 |

  节点复现残差 3.55e-15（负例归零成立）。γ 门：γ→1e-10 时 w^max=1e20，距 DBL_MAX 尚有 ~288 个数量级余量 ⇒ 门是防"两控制点重合 ⇒ 1/γ^p 上溢 inf"的**数值稳定门（结构性）**，非科学量。
- **结论**：
  1. IDW 是精确插值器，RMSE 全部来自控制点噪声与 K 近邻截断；
  2. **登记值 idw_power=2.0 在含噪（现实）状态下并非最优**：2%/6% 噪声下最优 p≈0.5–1（更平的权重=更强邻域平均压噪），p=2 差 2–3×；无噪声状态 p=2 才占优；
  3. K=16 处于"无噪偏小 K、高噪偏大 K"的中间，是可辩护的折中；
  4. p=2.0 与 K=16 均无标定记录（审查-1 判定"无算法级数值锚"成立）。
- **诚实边界**：真值面是平滑平面+弱曲率；真实 SNR 场有源核陡梯度，p 的最优值会向大偏移；本扫描只证明"p=2.0 不是普适最优"，不给出"应改为 X"的定论（那是重标定任务）。
- **复现**：`python3 code/exp_P4R2_02_idw_params.py`
- **佐证**：R-01（p 为应用参数的原始出处）、R-04。

### 3.3 I-03 Δ=64 控制网格（P-CST-16）——结构性参数裁定

- **假说**：Δ 是科学量还是结构性/工程参数。
- **方法**：2048²、双线性-格重建，真值分平面（双线性精确复现）与弱二次 q·x²（插值偏置 ∝ qΔ²/8）两情形；内域求值排除边界外推伪效应；曲率=0 为负例。
- **数据**：results/exp03_delta_grid.json（seed 20260928）。
- **结果**：负例（平面）Δ 依赖性 max/min = 1.087 ≈ 1（PASS）；零噪声偏置行 128/64 = 4.06（理论 4）、256/16 = 280（理论 256）——确定性偏置随 Δ² 增长。
- **结论**：Δ 不进入物理模型，只决定采样密度与存储；其影响是**确定性插值误差**，幅度由场景曲率决定，可用"重建 RMSE 门"管控而非靠三腿标定。**裁定：Δ=64 为结构性/工程参数，豁免科学量三腿；登记面应为 config_hash（schema:466 已含负责人 2026-09-19 裁决与 GAP_AUDIT §9.45 记录）**。
- **与审查-1 相左**：审查-1 推测 Δ = tile_width/8（并按 tile=4096 算出 512）——不成立。schema 原文是"复用 Phase2 UPM 的 8×8/tile 控制网格"的**密度口径**，不存在从 tile_width 导出 Δ 的计算链；"64 可以了"是负责人裁决记录本身。
- **诚实边界**：若未来场景方差面曲率显著增大（如强星云梯度），Δ 的偏置项会上升，届时应复评 Δ 而非默认豁免继续适用。
- **复现**：`python3 code/exp_P4R2_03_delta_grid.py`

### 3.4 I-04 平面条件数阈值 1/16（P-CST-17）

- **假说**：控制点几何判据 λlo/λhi ≥ 1/16 对应最坏方向梯度 SE 放大 √(λhi/λlo) = 4×，是数值稳定性设计值。
- **方法**：64 控制点、特征值比 {1, 1/4, 1/16, 1/64}，4000 次试验测梯度系数 SE **沿特征向量方向**的各向异性；精确共线负例（λlo=0，门必须 100% 触发）。
- **数据**：results/exp04_plane_conditioning.json（seed 20260929）。
- **结果**：实测放大 1.007 / 2.025 / 3.956 / 7.980 vs 理论 1/2/4/8（0.5% 内吻合）；共线触发率 1.000（必须=1，判据非退化）。
- **结论**：1/16 是可解析推导的数值稳定性设计值（理论腿自足，无需外部文献）；实测腿与理论腿 0.5% 内闭合。
- **诚实边界（重要）**：SE 各向异性必须**沿设计协方差矩阵的特征向量方向**测量；若沿坐标轴测量会严重低估（本路初版即犯此错：坐标轴读数 1.0–1.19 vs 特征向量读数 2.0–8.0）。任何复现件与验收判据都应写明测量方向约定。
- **复现**：`python3 code/exp_P4R2_04_plane_conditioning.py`

### 3.5 I-05 方差图缓变律（§2b/§5b）

- **假说**：①随机项空间白 ⇒ 一阶差分 lag-1 = −1/2；②relspread(σ²图)/relspread(电平)：散粒 1×、乘性 2×；③指纹 log-log 斜率：散粒 1、乘性 2、常数 0，且无效应时判据退化。
- **方法**：512² 三种随机项（高斯/量化/泊松）；relspread 律用 64px 块 × 40 独立副本压低块方差估计自身的采样噪声（关键设计：单副本块估计的采样噪声 ~7% 会淹没 3.4% 的电平散布——§2b 的 2.0% 实测若未做此处理可能混入估计噪声）；指纹斜率 12 个电平 × 12 副本。
- **数据**：results/exp05_whiteness_variance_map.json（seed 20260930）。
- **结果**：
  - 白性：raw lag-1 全部 |ρ|<0.01；一阶差分 lag-1 = −0.5007 / −0.4995 / −0.4984（解析 −0.5；§2b 实测 −0.4985 落在带内）；量化方差 1/12 相对误差 3.05e-3；
  - relspread：散粒比 0.924（律预言 1）、PRNU 比 1.911（律预言 2）；
  - 指纹斜率：1.000 / 2.000 / 0.000（预言 1/2/0）。
- **负例（含一条方法论发现）**：电平恒定时 log-log 斜率**数学上不可定义**（自变量无扫动，polyfit 病态）——正确行为是判据显式报"不可测"而非输出数值；可量化的负例是 readout-only 场景跨电平斜率 = 0.0004 ≈ 0。
- **结论**：§5b 解析律与 §2b 的数值声明独立复核成立；P4 把分母当缓变方差面处理的物理前提（分子是源、分母是慢变噪声）有实验支撑。
- **诚实边界**：relspread 比值 0.924/1.911 与 1/2 的残差来自块估计残余采样噪声与 MAD 稳健偏差（κ 因子在有限块上的偏置），未完全归零；若把 §2b 的 2.0% 读数当作高精度判据，建议补做副本平均。
- **复现**：`python3 code/exp_P4R2_05_whiteness_variance_map.py`
- **佐证**：R-06、R-07（方向性）。

### 3.7 I-07 亮度约束 + 零源负例端到端（§2.4）

- **假说**：P4 重建的是带亮度信息的 SNR 场（通量×10 ⇒ SNR×√10，方差图不变），且零源输入⇒稠密场精确为零；下游 P5 用 P4 权重获得优于等权的堆叠方差。
- **方法**：512² 迷你链：8 源（通量 1e3–1e5 ADU）+ 噪声模型（背景高斯 + 源散粒，与加权方差面口径一致）；Δ=64 控制点 ±2% 噪声；IDW(p=2,K=16) 稠密重建；P5 两帧堆叠（σ 比 3×）。空控制格用最近控制格值填充（nearest_control_point 语义）——**空格≠零 SNR**，否则会污染重建（本路初版即犯此错并修正）。
- **数据**：results/exp07_luminance_chain_negative.json（seed 20261002）。
- **结果**：
  - 重建质量：控制源处 RMSE 0.0795 dex，Pearson r=0.9952；
  - 亮度跟随：通量×10 ⇒ 真 SNR 比 3.1968、重建 SNR 比 3.19698 vs √10=3.1623（+1.1% 来自 2% 控制噪声，判 PASS）——重建场跟随亮度而非复制方差图；
  - 零源负例：稠密场 max|SNR| = 0.0、median = 0.0（精确归零，度量非退化）；

### 3.8 I-08 MAD→σ 1.4826 与 9216 预算链（P-CST-03 + P-CST-08）

### 3.9 I-09 Moffat4 FWHM/σ = 1.230310（P-CST-05，审查-1 方案 B 路径）

- **假说**：β=4 Moffat 的 FWHM/σ 因子可解析推导（方案 B），登记值 1.230310 与闭式一致。
- **方法**：由 β=4 Moffat 的 FWHM = 2α√(2^{1/4}−1) 与 2D rms 半径 σ² = α²/2 ⇒ FWHM/σ = 2√2·√(2^{1/4}−1)；数值 2D 径向积分交叉验证；高斯轮廓负例。
- **数据**：results/exp09_moffat4_factor.json（无随机性，未用 seed）。
- **结果**：解析 1.230307653、数值积分 1.230307793、登记 1.230310（相对差 1.79e-6，与 PSF.md:63 记录的 +1.91e-6 同量级，PASS）；高斯负例（同 2D rms 口径）= 1.6651 = 2√(2ln2)/√2——常数随轮廓族**与 σ 口径**双重变化，判据非退化。
- **结论**：**审查-1 的"方案 B（改理论推导）"路径闭合**：无需找回 SCI-PSF-001 实验件，1.230310 可改登记为闭式推导值（附 1.8e-6 数值积分验证）。
- **诚实边界（含一处对审查材料的订正）**：FWHM/σ 依赖 σ 口径——仓库口径是 2D rms 半径（σ²=α²/2），高斯在同一口径下是 1.6651 而非教科书逐轴 σ 口径的 2.3548；本路初版曾把 1.6651 误判为与 2.3548 矛盾，实为口径差异。任何把 2.3548（P-CST-04）与 1.230310 并排登记的地方都必须写明各自口径。
