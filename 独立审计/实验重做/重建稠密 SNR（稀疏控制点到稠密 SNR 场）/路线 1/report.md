本报告针对**P4：重建稠密 SNR（稀疏控制点到稠密 SNR 场）**模块进行独立科学验证。该模块是 ACSD 科学链五个创新点中的第四个，上游承接创新点②（跨帧绝对 SNR），下游为创新点⑤（加性天光去除）提供权重。

1. **三腿缺失**：
   - 文献腿：重建算子（自然三次样条、双线性、最近邻）的科学依据未逐字核验

2. **幻觉锚**：
   - `"dense"`口径无生产者却声称"精度基准"
   - 三条口径"输出同一物理量"无实验证据
   - 重建算子返回"预测方差"无实现与验证

## 1. 链条位置

> 【负责人定案·链条定位】本模块在五条创新点链上的上下游接口必须写成实验设计的一部分。本节描述上游输入与下游消费的量纲/精度/有效性约定。

### 1.1 上游输入（创新点②：跨帧绝对 SNR）

| 产品 | 载体 | 量纲 | 精度 | 数据结构 |
|-----|------|-----|-----|---------|
| 帧级 SNR 标量 | HiPS 文件头 | 无量纲（SNR） | FP64 双精度 | 单 float64 |
| 稀疏控制点绝对 SNR | `sparse_snr_layer` | 无量纲（SNR） | FP64 双精度 | 结构体数组 `{x, y, snr, ivar}` |
| 参考通量 `F_ref` | Phase1 manifest | ADU | FP64 双精度 | 单 float64 |

**关键约定**：
- 控制点值冻结为 `SNR_c = F_ref/σ_F,c`（**绝对 SNR**，不存相对因子）
- 不得乘除帧级 SNR 作为尺度基准（合同明文禁止）
- 每帧独立标定到同一测光坐标系，不同帧的 `F_ref` 因零点不同而各异

### 1.2 下游消费（创新点③/⑤：加权叠加与加性天光去除）

| 消费者 | 用量 | 计算式 | 精度要求 |
|-------|-----|--------|---------|
| 阶段二叠加权重 | `w(x,y)` | `w = SNR²/F_ref² = 1/σ_F²` | FP64，要求逆方差最优权 |
| UPM 天光平面拟合 | 背景域样本权 | `civ ∝ n_ret/(k_corr·π/2·σ²)` | FP64，凸包内非负约束 |
| 误差棒估计 | 积分方差 | `Var(μ̂) = 1/Σw`（对角特例） | FP64，需标记交叉项省略误差 |

**关键约定**：
- 重建算子**必须返回预测方差**（用于消费侧误差传播）
- 稠密场在控制点处**必须精确复现**节点值（插值基线）
- 消费侧无权落盘，由现场派生 `ivar = 1/variance`

### 1.3 链条贯通实验设计

本报告的实验设计**至少包含一个贯穿上下游接口的用例**：

```python
# 伪代码示意
上游输入：sparse_control_points [{x, y, snr_abs}, ...], F_ref
      ↓
P4 重建：dense_SNR, dense_Var = reconstruct(sparse_control_points, method="sparse_reconstruct")
      ↓
下游消费：weights = dense_SNR**2 / F_ref**2
         integrated_flux = sum(weights * signal) / sum(weights)
         variance_estimate = 1 / sum(weights)
      ↓
验收判据：weights 与完整四叉树 drizzle 权重相对差 ≤ X%；variance_estimate 与解析解误差 ≤ Y%
```

## 2. 符号与定义

| 符号 | 含义 | 单位 | 来源 |
|-----|------|-----|-----|
| `SNR_c` | 稀疏控制点绝对 SNR | 无量纲 | ASTROCS_DESIGN §2.2 |
| `SNR(x,y)` | 稠密 SNR 场 | 无量纲 | 本模块产出 |
| `F_ref` | 参考通量（星等 m=6.0 反算） | ADU | CONTROL_WEIGHT_SNR §6 |
| `w(x,y)` | 叠加权重 | ADU⁻² | `w = SNR²/F_ref²` |
| `σ_F` | 通量不确定度 | ADU | `σ_F = F_ref/SNR` |
| `ivar` | 逆方差 | ADU⁻² | `ivar = 1/variance` |
| `Δ` | 控制点间距 | pixel | 取决于星点密度 |
| `ρ` | 重建误差相关系数 | 无量纲 | 本模块输出 |

**重建算子枚举**：
- `dense`: 使用 Phase1 输出的稠密帧内 SNR 面（**实际不可达**，见 D-09）
- `sparse_reconstruct`: 默认口径，由稀疏绝对 SNR 控制点重建为稠密场
- `frame_reconstruct`: 帧级标量铺满（无稀疏层时的回退）

**验收阈值（待定）**：
- 节点精确复现容差：`|SNR_reconstructed - SNR_control_point| ≤ 1e-9`
- 三口径一致性：`max|SNR_a/SNR_b - 1| ≤ ε`（待实验确定）
- 预测方差非零：真值场方差不为零时，`Var > 0`
