从 `实验/absolute-snr/docs/EXP-04-RECONSTRUCTION.md` 读取到决定性证据：


**IDW（反距离加权）的地位**：
- 存在于代码中作为**备选口径**（`snr_evaluator.cpp`）
- **非当前默认**，仅在用户显式指定时使用
- 在 EXP-04 测试中被证明劣于样条类算子

### 0.2 EXP-04 实测对比（Δ=64，解析可分辨域 ℓ=64 s=0.10）

## §2. 文献腿核查结果

### 2.1 Crossref API 查询结果

我通过 Crossref API 查询了相关文献：

**查询词**: "inverse distance weighted interpolation astronomy"  
**主要发现**:
1. 地质学应用广泛（如孔隙度映射、生态参数插值）
2. **天文应用极少见报道**
3. 标准 IDW 通常设 power=1（Shepard 方法）或 power=2（二次反距离）

**代表文献**:

- DOI: 10.2466/pms.1965.20.1.294（心理学，无关）

## §3. 实验腿核查：基于 EXP-04 的证据链

### 3.1 假说评估

**原假说**：`idw_power=2.0` 是最优选择，在精度与平滑间取得平衡。

**EXP-04 证伪证据**：
1. EXP-04 实测显示 IDW 整体劣于其他算子
2. EXP-04 实现用的 power=1.0，说明作者认为 1.0 足够
3. 若必须选 power，应通过 K-fold CV 实验，而 EXP-04 未做此工作

### 3.2 P-CST-24b (K=16) 的位置澄清

**核查问题**：K=16 用于什么？

**代码线索**：
```cpp
// snr_evaluator.cpp:273 DEFAULT_KNN=16
```

**EXP-04 对照**：
- GPR/RBF 族用了局部窗口 K 近邻搜索
- IDW 在 EXP-04 中固定用 `n_neighbors=10`

**临时结论**：K=16 可能是**GPR/RBF等全局核方法的局部窗口尺寸**，而非 IDW 参数。**需在代码中明确区分不同算子的 K 含义**。

### 3.3 P-CST-24c (γ<1e-10) 的理论推导

**浮点保护阈值的合理性分析**：

双精度浮点特性：
- Machine epsilon: ε ≈ 2.22×10⁻¹⁶
- 最小正规格化数：≈ 2.23×10⁻³⁰⁸

当γ = 1/r^p → 0 时的行为：
- 若γ < 1e-10，对应 r > (10¹⁰)^(1/p)
  - p=1 时，r > 10¹⁰单位
  - p=2 时，r > 10⁵单位

**合理性判断**：
- 1e-10 >> machine epsilon（留 6 个数量级余量）
- 防止 1/γ^p 溢出到 inf
- **属于合理的数值稳定门设计**

**结论**：`γ<1e-10`应归类为**实现细节参数（结构性常数）**，无需三腿支撑。

## §5. 链条位置【上下游接口】——独立论证

### 上游输入（Phase1 产出）

| 字段 | 类型 | 量纲 | 来源 | 精度要求 |
|-----|------|------|------|---------|
| control_point.ra | double | degree | Gaia DR3 逆投影 | FP64 |
| control_point.dec | double | degree | Gaia DR3 逆投影 | FP64 |
| control_point.snr_psf | double | dimensionless | PSF 测光拟合 | FP64 |
| frame_f_ref | double | flux unit | 帧级参考通量 | FP64 |

**契约约束**：
- N ≥ 1（否则无法重建）
- 控制点不应全在同一位置（否则退化）
- SNR 值应经有限性检查：`isfinite(snr_psf)`

### 下游消费（Phase2 集成）

| 消费节点 | 输入量 | 用途 | 精度要求 |
|---------|-------|------|---------|
| UPM 拟合 | 稠密 SNR 场 | 天光平面拟合权重 | FP32/FP64 |
| 逆方差叠加 | w = SNR²/F_ref² | 像素级权重 | FP32/FP64 |

### 量纲传递一致性

**关键点**：
- 重建前后 SNR 量纲不变（无量纲）
- `F_ref` 在下游才介入权重计算，不在重建内部使用
- 预测方差应与 SNR 单位平方一致（σ̂²）
