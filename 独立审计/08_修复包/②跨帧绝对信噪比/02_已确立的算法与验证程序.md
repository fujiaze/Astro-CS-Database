### 1.2 逐像素噪声组合与 `σ_F`（本链代数核心，已独立复算成立）

```text
σ_i²  = σ_sky,i² + (RN/g)² + F·P_i/g        —— 读噪只出现一次
σ_F⁻² = Σ_i P_i²/σ_i²                        ⇒ σ_F = (Σ_i P_i²/σ_i²)^(−1/2)
```

- **量纲闭合（复算）**：`σ_sky²`、`(RN/g)²`、`F·P_i/g` 三项同为 ADU²（把计数转方差的因子恰为 `1/g`）⇒ `ΣP²/σ²` 为 ADU⁻² ⇒ `σ_F` 为 ADU、`SNR` 无量纲。
- **未发现重复计入**；暗电流无独立项（由经验总 rms 吸收，由写死 `EMPIRICAL_TOTAL_RMS` 与 `p1snr_science_skysource` 负例共同挡住双计）。
- **截断不构成误差源（复算）**：`Σ_i P_i = 1` 在**截断网格**上成立，故 `σ_F` 是"该网格内通量"的不确定度；`ΣP²` 随半宽收敛极快（`half = 12 → 60`：`0.09268653 → 0.09268408`，稳定到 `14.501%` 相对量级）。
- **一阶近似要写明**：`σ_i²` 内用**实测** `F` ⇒ 权重依赖数据 ⇒ `Var = 1/ΣP²/σ²` 是一阶近似（现文未写，补文不补式）。
- 定义式对经验散度的闭合（①物理仿真两组异源参数，各 4000 次）：`46.0332` vs `45.8528`（z=+0.35）、`16.8812` vs `17.2179`（z=−1.75）；归档扫描 max|z| = 2.06（天光）/2.68（噪声项），全在 3σ 内。
- **不要动**：`snr_science.cpp:139-143/:177/:198-202/:209/:214-215` 的单位取位与对角累加形式；`P_i` 的归一约定（窗内 `Pi = v[k]/sum`）。

### 1.3 逐像素 SNR 的分子与天光的去向（正向约束）

```text
背景方差面  σ_bg²(x,y) = Var[N_local] + S_sky(x,y)/g
加权方差面  σ_w² (x,y) = σ_bg²(x,y) + S_src(x,y)/g
逐像素 SNR  SNR(x,y)   = S_src(x,y) / σ_w(x,y)     —— 分子只有源
```
像素测量值 `I = O + N_e/g + N_read`、`N_e = N_src + N_sky + N_dark`（`I`、`O` 为 ADU，`N_*` 为电子，`g` 为 e⁻/ADU；文献的倒数约定 `g' = 1/g`，混用使源项差 `g²`）。
天光只经其散粒噪声进分母 ⇒ 固定真实源通量、天光由 0 扫到 10⁶ e⁻/px 时本链 SNR **单调趋零**（斜率 −0.4879 亮源／−0.4972 暗源，端点比 2.11%／1.07%）；"信号含天光"的传统口径在同一批仿真帧上**上升**三个数量级（×3.42e3／×1.03e5），"不扣局部背景的整帧口径"再高一截（×8.04e3／×2.41e5）。差别不在精度，在分子里装了什么。**缓变的是方差图、不是噪声实现** ⇒ 据此把方差降为逐帧标量不属本口径。

### 1.4 最优权的分母是谁的方差（只写已定侧）

对同一目标的 `n` 个独立观测做线性无偏估计 `μ̂ = Σw_i x_i / Σw_i`：

```text
Var(μ̂) = Σ w_i² v_i / (Σ w_i)²  ≥  1 / Σ(1/v_i)
取等条件（Cauchy–Schwarz，唯一）：w_i ∝ 1/v_i，且 v_i 必须是第 i 个样本【自身】的总方差
```

本链的样本是落进该天球像素的校准后像素值，`v_i = σ_bg² + S_src/g`。

- 已定：`1/σ_bg²` 与 `1/v_i` 相等**只在两情形** —— 掩膜外像素（`S_src ≡ 0`）与背景受限（`S_src/g ≪ σ_bg²`）。故"以背景逆方差定权"的正确陈述只能是**背景受限域的最优权**；无条件写成定义＝拿带适用域的近似当定义。一手：photutils `calc_total_error` 逐字 `σ_tot = √(σ_bkg² + I/g_eff)` 且把 `σ_bkg` 名为 **background-only**；Z&O **II** 标题自带"…Optimal for Any Purpose **in the Background-dominated Noise Limit**"；Z&O I 正文式 (3) 逐字 `V[ε_j] = B_j + (F_j T) ⊗ P_j`（`B_j` = 位置无关噪声方差）。
- 已定（另一侧同向）：天光建模的样本按 §5b 排异只取掩膜外 ⇒ 其 `v_i = σ_bg²` **严格成立**，那里用背景逆方差作权是**正确的**。此结论用于收窄 D-01 的范围：争的是**叠加侧**，不含天光建模侧。
- 已定：**逆方差严格优于等权与"按 SNR 加权"**（4000 次实现）——组合方差 1213.08／8263.45／1732.58，解析 1207.06／8149.74／1712.57，相对逆方差 1.00／6.81／1.43。
- 已定：过权倍数是构造式而非实跑读数——`R = w_used/w_opt = 1 + S_src/(g·σ_bg²)`；自建 Moffat4（σ_px = 1.4863 px、FWHM = 3.5 px ⇒ 峰值占比 `P_0 = 0.215914`）、σ_bg = 5 ADU、g = 1.3，`S_src` = 10³/10⁴/10⁵/10⁶ ADU 给 ×7.6/×67/×665/×6.6e3，并对背景尺度一次方敏感（同 `S_src`=10⁴：σ_bg=1 ⇒ ×1662，σ_bg=20 ⇒ ×5.2）。叠加功率损失 `E = Var_w/Var_opt − 1`（F=10⁴ ⇒ 7.16 @n=8／16.36 @n=2）。
- 已定：误差棒被低估是**构造**后果——产品按 `variance = 1/Σw` 出误差棒而真值是 `Σw²σ_true²/(Σw)²`，同一算例之比在 `S_src`=10³/10⁴/10⁶ 处为 1.8/4.3、9.3/34.2、831/3323。
- 已定：`w = SNR²/F_ref² ≡ 1/σ_F²` 的代数恒等在 SNR 定义为 `F_ref/σ_F` 时按机器精度成立（最大相对偏差 `3.01e−16`，四组异源参数；归档门 `2.22e−16`）。**该恒等式的前提是分子取 `F_ref`**，它只保证换算代码不出错，**不保证生产写入的分子真的是 `F_ref`**。
- **不在本件**：以何种产品面承载含源项的权重（新增第二张面／改判现面）与"排除自身"是否另含"从 σ² 里减源项"这一要求 —— 见 D-01 与 E-1，需负责人裁。

### 1.5 无增益臂（上界口径）的正确写法

`gain ≤ 0` 时含 `1/g` 的源项无法求值，退化为天空受限口径 `σ_F² = σ_sky²/ΣP²`。该臂给**上界**且必须具名登记 `snr_caliber = upper_bound_no_gain` ＋ `snr_degraded_reason`；用途仅限上界诊断。偏差方向：SNR 单调偏高、权重偏高，随源亮度**无界增长**；帧级 `SNR(F_ref)` 用 `F_ref` 而非真实源亮度 ⇒ 该偏差以参考星等档计量，不随帧内具体源变化，方向仍为偏高。

- 上界倍数的**唯一已定形式**：`φ = 源方差 / 总方差`，比值 `= 1/√(1−φ)`（φ=0.5 ⇒ 41.42%，φ=0.95 ⇒ 347.21%，复算逐位命中）。
- **不得**使用 `√(1 + F/σ_bg²)` 这一写法：量纲不齐（加数单位 `ADU⁻¹`），且缺的是 `1/g` **与** `ΣP²` 两个因子（只丢 `1/g` 的上界是 `√g`，g=1.3 ⇒ 1.14，解释不了数倍量级；`√(g/ΣP²) = 3.742` 才对上 `3.717`）。更要紧的是该分支的进入条件恰是 `gain ≤ 0` ⇒ 带 `1/g` 的补正在其唯一触发条件下不可求值。

### 1.6 参考通量与帧级 SNR

```text
frame_snr = F_ref / σ_F(ref profile)            —— 与天光无关、跨帧可比的未加权原始 SNR
F_ref,k   = 10^(−0.4·(m_ref − ZP_k))，m_ref = 6.0，随本帧零点逐帧而变
```
`σ_F(ref)` 必须**显式绑定**参考轮廓/孔径/背景。配对性只要求同帧内同源；方向性单向（`frame_snr := median_p(SNR_c)`），反向乘回会把帧级偏差乘进每个控制点且不可逆。`m_ref = 6.0` 那个星等档多在线性区外，用途只是**参考电平**。
`F_ref` 与测光侧 `k_photo` 是同一条换算的两端（`F_ref` 由 `ZP` 从星等档反算回 ADU；`k_photo` 把 ADU 载到 `[F_syn]` 刻度）⇒ "ADU ↔ 合成通量刻度"的唯一换算式只写一次、两处引用。

### 1.7 合同冻结的稀疏控制点语义

控制点值冻结为 `SNR_c = F_ref/σ_F,c`（`sparse_snr_semantics = "absolute_flux_type_snr"`，schema 里是 const），**不存相对因子、不得乘除帧级 SNR**。按相对值解释（`SNR(x,y) = frame_snr × v(x,y)/median(v)`）该差异必须被判红。叠加时由控制点重建稠密 `SNR(x,y)` 并现场换算 `w = SNR²/F_ref²`，**无口径分支**。稀疏控制点层是参考层，schema **明文禁止**该层携带 `variance/sigma2/ivar/w_info` 类键——要求预测方差的是**消费侧重建算子**（`DATA-002:99`）与独立的 `variance`/`ivar` 产品面（`DATA_SEMANTICS §4a`），两件事不得混写成一条。

### 1.8 重建算子

三算子（自然三次样条／双线性／最近邻）须在控制点精确复现节点值、并返回**预测方差**（FP64 求值）。双三次样条与 mesh 中值的每一处常数都可在 `07_noise_snr.md` §4.5 找到同文 ⇒ 已按文献值/公式导出归类，**不要动**。

## 2. 传播二次型：一般式与特例式的适用域（已定侧）

```text
一般式（允许多个输入像素相关）：  var_out(i) = [ R C_in Rᵀ ]_ii
展开：                          Var(y_i) = Σ_j R_ij²[C_x]_jj + 2·Σ_{j<k} R_ij R_ik[C_x]_jk
对角特例（仅当 C_in = diag(u_k)）： var_out(i) = Σ_k c_k² u_k
```

- 已定：`Σ c_k² u_k` **等于假设 `C_in` 对角**；该式的适用域 = `C_in` 对角。只写特例式而输入非对角 ⇒ **系统性低估**输出方差。
- 已定（方向可钉死的情形）：丢掉的交叉项是 `2Σ_{j<k}R_ij R_ik[C_x]_jk`；在**正相关**（drizzle 后 `Cov(S_p,S_q) = Σ_j c_jp c_jq v_j`，`ρ > 0`，nside=512 合成帧 mean|ρ|≈0.19、max|ρ|≈0.57）下丢掉的是**正项** ⇒ Var 只会偏小 ⇒ `ivar = 1/var` 只会偏大 ⇒ 判据一律偏绿。
- 已定（不可钉死方向的，就别钉）：在 `P_ii > 0、P_ij < 0` 的残差传播里，(i,j) 配对的被丢交叉项为负、(j,k) 配对为正，**净号不定** ⇒ 该处只可报"既无实现也无从表达 + 无完备性标记"，**不得**报"误绿"。
- 已定：表示法本身在本仓有显式 REJECT 门的语义 —— `G-P3-COV-01`：`variance_diagonal_only ∧ ¬correlation_kernel_present ∧ ¬correlation_approx_error_available ⇒ 拒`；`DiagonalOnly` 枚举注释"仅对角（须相关核/近似误差，否则 REJECT）"；`FZ-GATE-PIXIVAR-APPROX` 的 fail_closed："像素 ivar 近似无误差门声明，或未报告 `R̃ C_in R̃ᵀ` 与 `Var_approx/Var_GLS` ⇒ REJECT"。
- 已定：线性化下 `corrected = (I − H)y = P y`，`Var(corrected_i) = Σ_j P_ij² σ_j²`（**该式仅在 Σ 对角时成立**）；朴素形式 `var = σ_i² + Σ_{j≠i} coeff² σ_j²` 漏 `−HΣ − ΣHᵀ` 交叉项，等权 N 帧解析比 `(1+1/N)/(1−1/N)`（N=8 ⇒ 高估 **1.2857×**）。朴素式**只作对照与审计，生产权重禁用**。

## 4. "留一／排除自身"的准确主语（三种主语不得互换，也不得互相顶替）

| # | 名称 | 主语（**它到底是什么**） | 数学内容 | 它**不**是什么 |
|---|---|---|---|---|
| L-1 | 校正场估计子的留一 | **残差制造者**：第 i 帧不进入**它自己的**校正场 `ĝ_i` | `ĝ_i = Σ_j H_ij y_j`，`H_ij = w_j/W₋ᵢ`、`H_ii = 0`；`corrected_i = y_i − ĝ_i`；其方差里 `σ_i²` 以 `(1−H_ii)² = 1` **全额计入**，`σ_j² (j≠i)` 以 `w_j²/W₋ᵢ²` 计入 | **不是**"从权重/方差里剔掉被估计量自身的散粒项"：σ² 向量在该模块从未被改写 |
| L-2 | 口径位 `include_self` | 换的是**用于求残差的交叉检验模板**，不换噪声模型 | 两值之差恰为留一引入的膨胀因子：等权 N 帧下 exclude-self 给 `σ²·N/(N−1)`、include-self 给 `σ²(N−1)/N`（N=2 相差 **3 倍**） | 不是"是否计入源散粒"的开关 ⇒ 不要用它去回答 E-1 |
| L-3 | 设计四要素里的"排除自身" | **参考平面如何构造**（`ASTROCS_DESIGN.md:411`：参考平面用其他帧的加权组合） | 现载体是**包含本帧的联合加权最小二乘**（Schur 消元只消未知量、不排除贡献）⇒ 该要素在天光面载体里不存在 | 与 L-1 **不是同一件事**：仓库唯一叫"排除自身"的实现做的是叠加侧残差制造者的分母 |

配套已定口径：

- **拟合权 ≠ 堆叠权**：带杠杆 `h` 的拟合值方差为 `σ²h`，**不能**按 `1/σ²` 堆叠。
- 逐像素权重与信号独立这一性质，**在天光建模侧成立是构造性的**（掩膜把源剔除 ⇒ 与源无相关），不能升为"叠加权不必含源项"的保证。
- `11_upm.md:72` 的 `w = 1/σ² = SNR²/F_ref² ∝ SNR²` 那个 `∝` **以固定参考通量 `F_ref` 为前提**；天光控制点的被估量本身在变 ⇒ `SNR²` **不是**有效逆方差代理，SNR 在那条链上只作 veto/质量门。
- 设计"任意覆盖子集上的加权阶跃恒为零"的主语是**叠加权重链**，不是 UPM 控制点权重：`civ ∝ n_ret/(k_corr(π/2)σ²)` 里没有 `1/σ_src²`。把该主张指到 UPM 侧是**指认错位**，不是缺陷。
- 留一的动机是消除自相关、不是消除源散粒 ⇒ 不要因为看到 `include_self` 就认为 D-01 已被满足（同族误读已在 `通读-CR-23` CR-23-19 与 `通读-CR-61` CR-61-6 各命中一次）。
