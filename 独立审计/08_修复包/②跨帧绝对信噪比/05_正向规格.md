# ②跨帧绝对信噪比 · 正向规格

本件只写**正向约束**：实现必须长成什么样、无效输入必须走哪条具名分支、产品字段必须叫什么、判据读哪个对象。
已核的式子与推导不在本件重述（式子与验证程序见《已确立的算法与验证程序》，本件一律以其编号引用）；
缺陷事实、档位与取证成稿锚见《缺陷清单》；施工次序见《修复顺序与验收判据》。

## 0. 范围、写法与判据符合性

### 0.1 范围

本规格覆盖"跨帧绝对信噪比"这一条链的全部实现面：

- 逐源通量不确定度 `σ_F` 与逐源信噪比 `SNR_F` 的求值与出口；
- 帧级信噪比 `frame_snr` 与逐帧参考通量 `F_ref,k`；
- 帧内稀疏绝对信噪比控制点层 `sparse_snr_layer` 的生产、载体、重建与预测方差；
- 叠加权重的唯一换算口径（信噪比 → 逆方差）；
- 两张方差面（背景方差面与含被估量自身散粒项的加权方差面）的生产、消费与登记；
- 噪声组合中天空项的来源声明、增益来源与口径降级声明；
- 方差/协方差在导出与重采样侧的传播形式选择与相关表示声明；
- 上述各面在产品字节、manifest、provenance、配置合同与登记面上的落点。

不覆盖：天光平面（UPM）自身的构造与接缝恒零证明（属"加性天光"点）、测光星等零点标定链（属"测光星等坐标系"点）、
Drizzle 通量闭合与投影面积分配（属叠加几何）。跨点共用的字段只在"本点如何消费它"的范围内写。

### 0.2 写法约定

- **条目标识**：`P-CST-*` 常数、`P-ALG-*` 算法步骤、`P-FLD-*` 产品字段、`P-MIS-*` 缺失与无效表示、
  `P-WIR-*` 接线、`P-GATE-*` 判据、`P-REG-*` 登记面、`P-OPEN-*` 裁项依赖。
  标识只在本件内用于互引，与《缺陷清单》的对应集中在 §10。
- **式子**：只引用《已确立》的编号（形如"见《已确立》§1.2"），不在本件重述或重推。
- **规范的上位出处**：每条正向约束后面用"依据"给出它来自哪一份权威文档的哪一节；
  本件不复述上位文档的原文（层级向下、口径唯一），需要原文时按"见 `<文件> §<节>` 那句"指过去。
- **锚的性质分两类，写法不同**：
  ① `docs/**` 与 `eng/contracts/**` 的条款锚 = 本件直接读取并核对后写出；
  ② `lib/**`、`eng/**` 的代码行锚 = 转写自《缺陷清单》《已确立》的登记（本路按被审仓库只读纪律不执行构建与脚本，

- **待确认常数的写法**：来源档取 `待确认` 时，必须同时给出保守方向取值、受影响的产品量、偏大/偏小方向与量级（五件套第 5 项），不留空。

## 1. 对象与术语登记

### 1.1 本链在册的 UNIFIED 对象（canonical schema 逐字）

| 对象名 | canonical schema | 本链职责 |
|---|---|---|
| `frame_snr` | `eng/contracts/schemas/unified/frame_snr.schema.json` | 一帧一个的**无量纲**信噪比标量，唯一帧级参考；它本身不是权重 |
| `sparse_snr_layer` | `eng/contracts/schemas/unified/sparse_snr_layer.schema.json` | 帧内稀疏控制点上的**绝对**信噪比，帧内精细参考；不是权重、不是 variance/ivar |
| `variance` | `eng/contracts/schemas/unified/variance.schema.json` | 逐像素方差；量纲随承载面 |
| `ivar` | `eng/contracts/schemas/unified/ivar.schema.json` | 同承载面 variance 的严格互倒 |
| `point_information` | `eng/contracts/schemas/unified/point_information.schema.json` | 点源通量的信息权重 `W_info = 1/Var(F̂)`，单位 `ADU^-2` |
| `source_snr` | `eng/contracts/schemas/unified/source_snr.schema.json` | 逐源信噪比 |
| `depth_m5` | `eng/contracts/schemas/unified/depth_m5.schema.json` | 5σ 深度，摘要量 |
| `support` / `coverage` / `validity` / `rejection` / `provenance` / `signal` | 同目录各自 canonical 文件 | 门/承载/元数据对象，按 `docs/contracts/UNIFIED_OBJECTS.md` §2 表 |

依据：`docs/contracts/UNIFIED_OBJECTS.md` §2（13 对象表，含单位、无效值、可否作权重三列）；
`object_weight_capability`／`object_weight_verdict` 两 const 字段的判定只取自该表原文。

**本点不变量（正向）**：一个对象只承载一个含义；`frame_snr` 与 `depth_m5` 各自独立取值、互不填对方的键；
`sparse_snr_layer` 只承载绝对信噪比，**层内不得出现** variance / sigma / ivar / w_info / Fisher / support / coverage 语义的键
（守卫落点：两份 canonical schema 的 `propertyNames.not.enum`，`docs/contracts/DATA_SEMANTICS.md` §31.7/§31.8）。

### 1.2 术语（唯一记法）

| 记法 | 含义（一句话） | 它不是什么 |
|---|---|---|
| **绝对信噪比 / PSF 信号信噪比** | 分子为**已扣独立局部背景**的源通量、分母为该通量的不确定度 `σ_F` 的无量纲比值 | 不是面亮度 SNR、不是未扣背景的原始比值、不是权重 |
| `F_ref,k` | 第 k 帧的**逐帧参考通量**，由固定参考星等 `m_ref` 与本帧测光零点导出 | 不是本帧实际测到的某颗星的通量、不是组内共享标量 |
| `F0`（`reference_flux_common`） | 跨帧恒等的**物理公共锚**合成通量 | 不得用来反推增益／口径／曝光 |
| **背景方差面** `σ_bg²` | 星点掩膜外像元上稳健估计的**空背景**随机分量方差（缓变场） | 不含源散粒项；不是叠加与拟合的逐像素科学权重的来源面 |
| **加权方差面** `σ_w²` | `σ_bg²` 加被估量自身散粒项后的逐像素总方差 | 与背景面同量纲、异对象、互不代用（《已确立》§1.1） |
| **重建场** `SNR(x,y)` | 由稀疏绝对控制点经显式声明的算子重建的稠密信噪比场 | 不是"帧级标量 × 帧内相对因子"的复合量 |
| **生效权重** `w(x,y)` | 由重建场现场换算的逆方差叠加权 | 不是落盘对象；权重不落盘（依据 `docs/plugins/algorithms_phase1/07_noise_snr.md` §4.6） |
| `snr_path_effective` | 实际生效的稠密信噪比**重建方式**标识 | 不是权重口径标识；不存在可选的权重口径 |
| `snr_caliber` | 该 SNR 数值的质量口径 | 缺失即不得署"绝对" |

依据：`ASTROCS_DESIGN.md` §2.2（同一对象两个名字：PSF 信号信噪比 = 绝对信噪比）；
`docs/design/PHASE2_DETAILED_DESIGN.md` §2/§114（三条口径是重建方式的选择，不是权重口径的选择）；
`docs/science/CONTROL_WEIGHT_SNR.md` §2b/§5/§8c。

### 2.3 常数的载体纪律（正向）

- **P-CST-26 单一事实源**：凡本表列出的数值，代码里必须有且只有一个权威定义点（`inline constexpr` 一处、或从合同/配置读取）。
  同一数在 N 处各写一份字面量 ⇒ 该常数未被登记在案。独立期望侧（oracle、Python 复算）**不得**与被检实现共享同一手抄值；
  共享 ⇒ 该恒等判据对该常数零判别力，并把"改用闭式精确值"这一正确修复判红（实例：`1.230310` 六处副本、`1.253` 截断值）。
- **P-CST-27 容差与不确定度相称**：每条恒等/对拍判据的容差必须登记"该容差覆盖什么误差来源"。
  `1e-12` 一类的机器精度容差只能覆盖浮点舍入，不得用来覆盖"手抄常数与闭式之差"这一真实不确定度（`1.230310` 与闭式差 `+1.91e-6`、`1.253` 与 `√(π/2)` 差 `−2.5065e-4` 都要用与之相称的容差并给出处）。
- **P-CST-28 阈值的算出而非写死**：任何由公式导出的门槛（如 P-CST-08 的预算阈），实现必须由该公式求值并记录入参（`1.44`、`0.015`），不得写死结果整数；
  配置面可覆盖入参时，覆盖值参与 `config_hash`。
- **P-CST-29 注释与条文同批**：一处常数的注释若给出推导，其推导式与代码所用的支必须一致；
  发现不一致 ⇒ 在同一次改动内把注释、条文、代码三处收敛为一支，并保留被弃支的"不使用"说明。

## 3. 算法步骤规格

每个步骤固定四栏：**输入域（形状＋类型）／输出值域／无效输入的具名行为（可区分的状态码或具名分支）／精度档**。
"具名行为"的底线要求：**不得返回看起来合法的好值**。三种实例形态一律判违规——取不到返回 `0`、缺失写 `1.0`、空集判通过。

### 3.1 P-ALG-01 逐源通量不确定度 `σ_F` 与逐源信噪比 `SNR_F`（PSF 行路径）

- **输入域**：
  - PSF 轮廓行 `P[0..n-1]`，`double`，截断窗内归一（`ΣP` 满足 P-CST-20 的绝对判据）；窗由 `profile_half_px` 给出（P-CST-23）并**随产品落盘**；
  - 逐像素方差 `σ_i²`，`double`，长度与 `P` 同，单位 `ADU²`、与同帧 `data` 面同标度；
  - 源通量 `F`，`double`，单位 ADU（同帧标度），必须为正；
  - 增益 `g`（e⁻/ADU）与读出噪声 `RN`（ADU），或"不可得"的显式声明（P-ALG-03）；
  - 天空尺度 `σ_sky`（ADU）＋其**来源声明** `sigma_sky_source`（P-ALG-02）。
- **输出值域**：
  - `σ_F > 0`，单位 ADU；`SNR_F = F/σ_F ∈ (0, +∞)`，无量纲；
  - 通量估计方差与权重的恒等关系按《已确立》§1.2 的 `σ_F^{-2} = Σ P_i²/σ_i²`；
  - 量纲闭合（三项同为 `ADU²`）由逐位取位手检程序复核（《已确立》§5 V-6）：任何改动噪声组合的实现都要重跑该手检并留痕。
- **无效输入的具名行为**（逐条独立分支，不得合并为一个通用错误）：
  | 情形 | 必须的行为 |
  |---|---|
  | `σ_i²` 非有限 | 该源判不可估计，具名状态 `NONFINITE_PIXEL_VARIANCE`，并计入"损坏"类计数（与"方差不可用"分列） |
  | `σ_i² ≤ 0`（**含等于 0**） | 该源判不可估计，具名状态 `NONPOSITIVE_PIXEL_VARIANCE`；**不得**把 0 当"零噪声"计入求和 |
  | `F ≤ 0` 或非有限 | 具名状态 `NONPOSITIVE_SOURCE_FLUX`；该源进入丢弃账目（P-ALG-16） |
  | `ΣP` 不满足归一判据 | 具名状态 `PSF_PROFILE_NOT_NORMALIZED`，整条轮廓拒用；**不得**就地重归一后继续 |
  | `σ_F` 求值非正或非有限 | 具名状态 `FLUX_UNCERTAINTY_UNBOUND`，该源不出 SNR |
  | 增益不可得 | 按 P-ALG-02 决策树走**具名降级臂**并携带口径声明，不得静默用上界臂冒充绝对值 |
- **精度档**：全链路 `double`（FP64）；求值顺序固定为"先逐像素 `P_i²/σ_i²` 累加、再取倒数开方"；
  与解析参考的对拍容差按 P-CST-13 取相对 `2.22e-16` 量级并登记来源（浮点舍入），不得用该容差去覆盖物理近似误差。
- 依据：《已确立》§1.2（噪声组合式、读噪只计一次、截断非误差源、一阶近似须写明）；
  `docs/plugins/algorithms_phase1/07_noise_snr.md` §4.1（红线：信号已扣独立局部背景、天光只进 `σ_F`）；
  `docs/science/NOISE_MODEL.md` §9（FP64 全链路）。

### 3.2 P-ALG-02 天空尺度 `σ_sky` 的来源声明与口径决策树

- **输入域**：整帧背景统计（`double`）、空白天光像元集（`double` 数组，经掩膜后）、逐源拟合残差数组（`double`）。
- **输出值域**：`σ_sky > 0`，单位 ADU（同帧标度）；随其输出必须同时输出**来源枚举** `sigma_sky_source`，取值只允许
  `{ SNR_SIGMA_SKY_FRAME_BACKGROUND_RMS, SNR_SIGMA_SKY_BLANK_SKY_ROBUST_SCALE }` 两种合法语义（各自定义见 `docs/science/NOISE_MODEL.md` §9a ①）。
- **具名行为**：
  - 来源声明与实际喂入的数据**不同源** ⇒ 具名拒绝（`SIGMA_SKY_SOURCE_MISMATCH`）并 fail-closed；
    "逐星拟合残差"作为来源**不在**合法枚举内 ⇒ 出现即拒；
  - 决策树的分支选择由**声明面**（配置/provenance）驱动，不由接线层写死；接线层不得把 `sigma_sky_source` 无条件赋成某个常量枚举；
  - 走"无增益上界臂"时（分支 3）：产品**必须**同时落 `snr_caliber = upper_bound_no_gain` 与 `snr_degraded_reason`（具名原因串），
    两键缺一 ⇒ 该数值不得署"绝对信噪比"，出口处具名拒绝（依据 `docs/plugins/algorithms_phase1/07_noise_snr.md` §4.2a 第 3 条）。
- **精度档**：`double`；`1.2533141373155001`（P-CST-07）取闭式；两种合法语义**互不代用**，不得在同一帧内混用（混用即读噪双计或漏计）。
- **上界口径的唯一形式**：见《已确立》§1.5（`φ = 源方差/总方差`，倍数 `1/√(1−φ)`）；
  `φ = 0.5 ⇒ +41.42%`、`φ = 0.95 ⇒ +347.21%`；
  形如 `√(1 + F/σ_bg²)` 的写法**不使用**（该式量纲不闭合，且其进入条件 `gain ≤ 0` 使带 `1/g` 的补正不可求值——《已确立》§1.5）。
  登记/注释/报告引用面上凡给出倍数数值，一律引 `φ` 形式并附 `φ` 的定义与样本面。

### 3.3 P-ALG-03 增益与读出噪声的来源与自估主路径

- **输入域**：本帧科学像素 `S`（ADU）与对应方差 `V`（ADU²）；或帧头关键字 `GAIN/RDNOISE/EGAIN`；或显式配置值。
- **输出值域**：`g > 0`（e⁻/ADU）、`RN ≥ 0`（ADU），或显式的"不可得"声明。
- **来源三级（优先级固定）**：① **本帧自估**（`V = σ0² + S/g` 的斜率–截距回归，正式数据面上的主路径）
  ② 帧头关键字（**仅交叉校验**，不作主路径） ③ 显式配置。依据：`docs/science/NOISE_MODEL.md` §5c。
- **具名行为**：
  - 自估回归的**可辨识性判据**不成立（杠杆臂不足：亮源样本缺失或 `S` 动态范围过窄）⇒ 具名状态 `GAIN_NOT_IDENTIFIABLE`，
    并**显式降级**到 P-ALG-02 分支 3 的上界臂＋口径键；不得静默取默认增益、不得取上一次的估计值；
  - 光子转移曲线拟合前必须先减 bias 电平（`docs/science/NOISE_MODEL.md` §5b）；
  - 增益约定恒为 **e⁻/ADU**；引用外部公式前先确认其约定并换算（`ASTROCS_DESIGN.md` §2.2 增益约定）；
  - `snr.gain_e_per_adu` 必须在 `defaults.json` 与出厂模板**两侧都登记默认值**（有默认 ⇒ 缺键行为可判定；无默认 ⇒ 缺键即拒），二者取一，不许"缺键时靠 memset 得 0"。
- **精度档**：`double`；回归系数与截距的报告位数、协方差随 `variance_audit` 一并落盘。
- **单位分面的硬约束**：`variance = σ_sky² + (RN/g)² + F·P_i/g` 三项同为 `ADU²`；任何"漏 `1/g`"或"漏 `ΣP²`"的实现都改变倍数尺度
  （实测：只漏 `1/g` 的上界倍数 `√g`，g=1.3 ⇒ `1.14`；同时漏 `ΣP²` ⇒ `√(g/ΣP²) = 3.742`）。出处：《已确立》§1.2/§1.5。

### 3.4 P-ALG-04 背景方差面的构造与填充（`σ_bg²`）

- **输入域**：帧的 `signal` 平面（`float32`/`float64`）、`support` 平面、星点掩膜、饱和阈（或"无饱和元数据"声明）；
  控制网格 8×8 patch（本仓冻结），逐 patch 输出 `var` 观测与几何合法性标志（P-CST-17）。
- **输出值域**：
  - 平面场 `var(x,y) = a + b·x + c·y`（P-CST-09 的 5σ 裁剪、P-CST-03 的 MAD 尺度），量纲 `ADU²`；
  - 逐像素 `variance ≥ 0` 或**显式不可用**（`variance = 0 ∧ ivar = 0`），无覆盖为 `NaN`——三态表见 `docs/contracts/DATA_SEMANTICS.md` §4a；
  - `floor` 只作用于**可用**方差；`variance_floor` 必须有限且 `> 0`，否则 build 与 fill **两侧都拒**（`SNR_FLOOR_UNBOUND = −10`）；
  - 预测值 `≤ 0` ⇒ `variance = 0 ∧ ivar = 0`（显式不可用），不回退 floor、不外插。
- **具名行为**：
  - 未提供饱和元数据 ⇒ 必须写 `NOISE_SATURATION_FILTER=DISABLED_NO_METADATA`，不得静默关闭该过滤；
  - 无可行裁剪半径 `s` ⇒ `rc = 1`（具名失败），不落平面；
  - 全无覆盖 tile ⇒ `rc = −5`，不落盘（显式失败而非空产品）；
  - 非有限或负的方差分子 ⇒ `rc = −6` 硬失败，**禁止** clamp 或静默跳过。
- **审计面（必落字段，正向清单）**：`variance_audit` 必须携带
  `ctrl_variance_range`、`plane_a`、`plane_b`、`plane_c`、`hull_nonpositive_frac`、`n_structure_rejected_patches`、

### 3.6 P-ALG-06 帧级信噪比 `frame_snr` 的求值

### 3.9 P-ALG-09 重建立算子与逐像素预测方差

- **算子词表（冻结，四值，取值不在词表内 ⇒ 消费侧具名失败，不回退默认）**：
  | 标识 | 语义 | 适用域 |
  |---|---|---|
  | `natural_bicubic_spline_clip_v1` | 可分离自然边界双三次样条（先 y 后 x）＋ 钳到有效控制值值域 | 默认（地面/seeing-limited） |
  | `natural_bicubic_spline_clip_mesh_median_v1` | 同上，样条前插入 3×3 mesh 中值滤波（边界 replicate，无条件替换） | 高对比域（HST/空间高分辨率、cell 内含未分辨亮源） |
  | `bilinear_regular_grid_v1` | 规则网格双线性 | 对照/回退 |
  | `nearest_control_point_v1` | 最近控制点 | 散点层 |
  **一个标识同时承载"是否开 mesh 中值前置滤波"**：滤波与值域钳制不是可自由组合的独立开关；
  未实测的组合（双线性＋滤波、无钳制的样条）在合同层不可表达。
  钳制是正值与有界性的**必要条件**（去钳制后光滑插值类在病态控制网格上权重效率损失 `E` 由 `1.007` 升到 `1.44e4`，并会给出负 `sigma`）；
  中值滤波在默认目标域有害、只在高对比域必需。
  选型按**数据来源**决定（`sparse_recon_operator_for_source()`），不由配置自由指定。
  依据：`docs/plugins/algorithms_phase1/07_noise_snr.md` §4.5；实验单元 `absolute-snr` EXP-04 §2.7/§4.1/§4.5。
- **算法三步（正向）**：① NaN → 最近有效填充，等距并列时取平均；② 可分离自然边界双三次样条，先 y 后 x；③ 钳到 `[min, max]`（有效控制值值域）。
  非 NaN 的非有限值与 `≤ 0` 值按非法值处理（P-ALG-08），不进入填充。
- **四条与算子选型无关的约束（必须全部满足）**：显式声明、正齐次性、节点上精确复现、域外 fail-closed。
- **输入域**：`double` 控制网格 `g[m][n]`（`m,n ≥ 1`）、查询坐标 `(x,y)`（像素中心，`double`）、定义域矩形。
- **输出值域**：`SNR(x,y) > 0`、有限；**逐像素预测方差** `Var[SNR](x,y) = Σ_k a_k(x,y)² · Var(SNR_k)`（解析传播），单位与所乘量一致（无量纲比的方差），
  `a_k` 为算子的线性权重核；预测方差是合同要求的出口（`DATA-002` 要求重建"返回预测方差"），字段名 `predicted_variance` 随层与产品内容证据块一并登记。
- **无效输入的具名行为**：
  - 查询点越出层定义域 ⇒ 具名状态 `OUT_OF_LAYER_DOMAIN`（不外推、不回退帧级）；
  - `n_control_points < 4` ⇒ 重建不可信，具名状态 `TOO_FEW_CONTROL_POINTS` ⇒ RED（守卫必须显式存在）；
  - 声明算子与层形态不符（例如声明 mesh 滤波支但网格无高对比结构标记）⇒ 具名拒绝；
  - 未识别算子标识 ⇒ 具名拒绝，**不得**回退默认算子。
- **精度档**：求值一律 `double`（《已确立》§1.8：三算子须在控制点精确复现并返回预测方差）。
- **自检与精度证据的分离（正向）**：
  - `operator_node_selfcheck_max_abs`（由 `node_reproduction_max_abs` 改名）：语义保持为"算子在其所用节点上的自复现残差"，容差 `1e-9`（P-CST-12），
    **不作精度证据**；自检必须对**原始输入控制点值**（NaN 填充与 mesh 滤波**之前**）复现，或另设"滤波前后保真度"门，并写明 `nearest_valid_fill` 与自检的先后关系；
  - `recon_error_vs_independent_reference`（新增）：参考场必须与构造算子所用节点数组**不同源**，采样点必须**非节点**；
    守卫 `n_control_points < 4 ∨ n_ref_samples == 0 ∨ 参考场方差 == 0 ⇒ RED`；
  - 二者各自的字段语义在 manifest 与文档面**只写一次**，不得对同一字段给"重建误差"与"应 ~0"两种互斥定性
    （恒 0 的字段对外宣称"重建误差"不具证据资格——《已确立》§5 V-5）。

### 3.10 P-ALG-10 叠加权重的唯一换算口径

- **唯一式**：`w(x,y) = SNR(x,y)² / F_ref,k² = 1/σ_F(x,y)²`（《已确立》§1.4；
  `docs/science/CONTROL_WEIGHT_SNR.md` §5；`docs/plugins/algorithms_phase2/13_integration.md` §4.0）。
  对逐源/逐帧标量形式：`w_k = 1/σ_F,k² = SNR_k²/F_ref,k²`。
- **输入域**：重建场 `SNR(x,y)`（`double`）、该帧 `F_ref,k`（`double`，`has_reference_flux` 为真）、该帧标度因子 `g_k`（P-CST-21）。
- **输出值域**：`w > 0`，量纲 `1/ADU²`（与该承载面的信号量纲互为平方倒数）；权重是**现场派生量**，不落盘。
- **正向禁止（口径）**：不存在权重口径选择键、口径枚举或口径配置项；三条重建口径（`dense`/`sparse_reconstruct`/`frame_reconstruct`）
  是**重建方式**的选择，都产出同一物理量的稠密表示、都走同一条换算式；越界 token ⇒ fail-closed。
  依据：`docs/design/PHASE2_DETAILED_DESIGN.md` §114；`eng/contracts/data/v6_clause_registry_v1.json`
  （`weight_modes.production_input_surface_facts`：`integration.weight_mode`／`legacy_allow_weight_fallback` **出现即拒绝、键已删除**；`a44_deprecation`）。
- **无效输入的具名行为**：
  - `has_reference_flux` 为假 ⇒ 具名拒绝 `kUnclosedInvalidReferenceFlux`（P-ALG-07），不换算、不取组标量；
  - `SNR(x,y)` 非正或非有限 ⇒ 该点权不可导出，具名状态并计入 `n_rejected_*`；
  - 层存在但不可重建 ⇒ 显式失败（**不是**"无稀疏层"，两者读数可区分）；
  - 无稀疏层 ⇒ 按帧级执行，但必须显式记 `snr_path_effective = frame_reconstruct` 并计数（不静默）。
- **精度档**：`double`；换算恒等式对拍相对容差按 P-CST-13。
- **消费前资格门（逐像素，三条，缺一即具名拒绝）**：见 P-ALG-11 的 `point_information` 三条前置确认；权重消费面同样适用"估计域一致"要求。

### 3.11 P-ALG-11 `point_information` 作权重消费的三条前置确认

- **输入域**：`W_info = 1/Var(F̂)`（`double`，单位 `ADU^-2`）、目标产品类型标识、相关核标识 `correlation_kernel_id`、`k_corr`、承载面单位声明。

- **具名行为**：`product_family = phase2_point_source` 而写入的是 SB 平面 ⇒ 具名拒绝 `DOMAIN_MISMATCH`；
  `correlation_kernel_id` 为空 ⇒ 补核或拒（**不得**只在 provenance 写一个 `representation = "full_matrix_unavailable"` 字符串了事）。
- **对角近似的义务（正向）**：产品恒走对角近似时，必须报 `c̃ᵀC c̃` 与 `Var_approx/Var_GLS` 两个字段，
  比值判据 `≤ 1 + ε`（ε 见 P-CST-22）；`c̃` 必须是**已归一**的估计权重（守卫 `|a·Pᵀc̃ − 1| ≤ tol` 拒未归一输入），
  否则该比值随缩放任意变化、被 `≤ 1+ε` 门读成偏绿。
  依据：`eng/contracts/data/v6_clause_registry_v1.json#FZ-GATE-PIXIVAR-APPROX`、`FZ-COND-WHITENOISE`、`FZ-FORMULA-WINFO`。

### 3.12 P-ALG-12 阶段间载体（磁盘交接结构）的字段义务

- **要求**：被声明为"Phase2 消费面最小集"的跨阶段视图结构必须携带本链消费所需的全部字段（逐字段对应 `docs/plugins/algorithms_phase2/13_integration.md` §3 的输入清单）：
  `frame_snr` ＋ `has_frame_snr`、`reference_flux` ＋ `has_reference_flux`、稀疏层句柄（`sparse_snr_layer` 或其视图）、
  SNR 单位项、`snr_caliber`、`snr_degraded_reason`、`reconstruction_operator`、`sigma_sky_source`、`gain_source`。
- **正向规则**：**字段先于接线**——载体缺字段时不得以"接线待补"作为不补字段的理由；
  新增消费点必须能指出其入参来自该结构的哪一个具名键，而不是来自全局配置或默认值。
- **无效输入的具名行为**：句柄为空但产品声称有层 ⇒ `sparse_layer_absent` 与 `sparse_layer_not_wired` 二选一具名登记；
  单位项缺失 ⇒ 量纲判定不可进行 ⇒ 具名拒绝（不得默认 `dimensionless`）。
- **精度档**：视图结构内一律 `double`；落盘精度按配置。

### 3.13 P-ALG-13 方差/协方差传播：一般式与对角特例的选择

- **两条式的适用域（正向）**：
  - 一般式 `C_out = R · C_in · Rᵀ`，取 `[·]_ii` 为输出方差；输入携带非对角结构时用此式（《已确立》§2）；
  - 对角特例 `Σ_k c_k² u_k`：**仅**在 `C_in` 对角时成立。
- **本仓输入的现实**：drizzle/mosaic 产物的相邻输出像素非严格独立（`mean|ρ| ≈ 0.19`）⇒ 该输入**被本仓自证为相关**，
  因此导出侧的方差出口**必须**二选一：（a）走一般式；（b）给相关核入口（最小可用形态 = `K(Δpix, σ)`）；
  （c）在 `p3_output`/provenance 写死 `representation = "diagonal_variance"` **且** `correlation_approximation_error = <已签值>`。
  三者都不做即违规（现状是静默走特例、无声明）。
- **具名行为**：带门的语义 = `variance_diagonal_only ∧ ¬correlation_kernel_present ∧ ¬correlation_approx_error_available ⇒ 拒`（`G-P3-COV-01`）；
  该门必须落在**生产节点**上（`p3n_*` 内），并补**逐格**判据而非求和闭合。
  依据：`lib/.../p3_rsmp_failclosed.cpp:170-175` 登记的拒判语义（代码行锚按 §0.2 第 ② 类转写）。
- **方向性（判据书写用）**：正相关输入丢交叉项 ⇒ 输出方差**单调偏小** ⇒ 判据**偏绿**；
  ρ = 0 的构造输入下一般式与特例式必须**逐位恒等**（正例判据，见 P-GATE-15）。
- **禁用修法**：不得把文档改成"输入视为不相关"以自证现状。
- **精度档**：`double`；低估幅度的容差待裁（`P-OPEN-02`），未裁前**不得**据任一登记数定容差，只报实测比值。

### 3.14 P-ALG-14 样本资格、剔除计数与两平面一致性（叠加/重采样侧）

- **合格样本定义（逐字取正本）**：值有限（`isfinite(x_j)`）**且**几何覆盖该输出像素（`w_jp > 0`）；
  **方差是否可用不参与合格性判定**。依据：`docs/interfaces/data/DATA-002_PHASE_PRODUCT_EXCHANGE.md`（"合格样本"行）。
- **三类分列（正向，各给独立计数键）**：
  | 类别 | 判据 | 处置 | 计数键 |
  |---|---|---|---|
  | 方差可用 | 合格 ∧ `V_j` 有限 ∧ `V_j > 0` | `V_j` 计入 `Var_p` | — |
  | **有覆盖但无方差信息** | 合格 ∧ `V_j` 有限 ∧ `V_j ≤ 0` | 信号与几何权重**照常计入** `F_p`、`W_p`；方差项**不计入** `Var_p`；`V_j` 取原值，常数/地板/哨兵一律不参与 | — |
  | **方差面损坏** | `V_j` 非有限 | 按不合格剔除 | `n_rejected_nonfinite_variance`（类别恒为"损坏"，与上一行分列） |
  | 值非有限 | `¬isfinite(x_j)` | 剔除 | `n_rejected_nonfinite_value` |
  | 权重非正 | `w_jp ≤ 0` | 剔除并**强制计数** | `n_rejected_nonpositive_weight` |
  零替代**禁止**（`zero_substitution = forbidden`）；计数**强制**（`rejection_counting = mandatory`）。
- **`w = 0` 的退化填充点（正向）**：象限为空时以 `nearest_pt` 重复填充可产生恰为 `0` 的几何权；
  该样本**不是**合格样本（违反 `w_jp > 0`）⇒ 合格判据实现为 `isfinite(vv[k]) && wg[k] > 0.0`；
  信号侧、方差侧、计数侧对同一样本必须给出**同一个**资格结论；
  改动前须先自证"现网 `u=0/v=0` 退化像素的 `val` 不变"（被剔除项原本权重 0、贡献 0），否则会把正确修法误判成回归。
- **被剔除槽位的写出（正向）**：`weights[]` 与 `leaf_ipix[]` 的写法必须对称——**无条件四写** `weights[k] = 0.0`；
  方差侧掩膜判据从值判据 `w == 0.0` 改为**独立有效性出参**（值判据遇 `NaN` 时 `w == 0.0` 为假 ⇒ NaN 值配 OK 状态）。
- **分母符号（正向，逐分支）**：`D_p = Σ_j a_jp`（covered_area，量纲 `sr`）只用于 Phase 1 drizzle 全链；
  Phase 2 帧间集成与 Phase 3 重采样的分母是权重和 `W_p = Σ_合格 w`（量纲随 `w`）；
  同一式内二者各自独立、各自具名，混用相差 `A_cell²`。依据：`docs/contracts/DATA_SEMANTICS.md` §4a"符号唯一性（强制）"。
- **面亮度归一的样本集一致性**：分子与分母必须用**同一样本集**；长度不一致 ⇒ 与同文件硬失败入口同形地**硬失败**（不得逐帧截断放行）。
- **精度档**：`double`；`ivar = 1/var` 只在同一承载面内成立，跨承载面先按标度律换算。

### 3.15 P-ALG-15 无效值三态在产品字节上的编码

- **variance/ivar 三态（唯一口径表，逐字取 `docs/contracts/DATA_SEMANTICS.md` §4a）**：
  方差可用 ⇒ `vnum/area²` 与 `1/variance`；有覆盖但方差不可用 ⇒ `variance = 0 ∧ ivar = 0`（显式不可用，**禁 NaN**）；
  无覆盖 ⇒ `NaN`（与 `signal = NaN ∧ support ≤ 0` 同态、二者互推）；损坏 ⇒ `rc = −6`。
- **IVAR 平面折叠（正向要求）**：实现 `(variance > 0) ? 1/variance : 0` 会把"无数据/方差坏/方差为零"三种语义压成同一个 `0`，
  与记录自声明的 `invalid_policy = "nan_or_support_le_0"` 冲突 ⇒
  **必须**二选一：（a）写盘前校验 `isfinite(signal) ∧ isfinite(variance) ∧ variance > 0`，否则按声明写 `NaN` 并记 `n_invalid_pixels`；
  （b）把 `invalid_policy` 改为 `zero_ivar` 并同步记录与门——两处同批改，否则改一侧即与另一侧判红。
- **重开门（发布前检查）的正向要求**：不得只看 header/位深/长度；必须校验数值面（能捕获 `VARIANCE = NaN ∧ IVAR = 0` 的组合）。

### 3.16 P-ALG-16 逐源丢弃、中位基准与评估接口的账目

- **丢弃当场具名（正向）**：逐源信噪比计算失败的星必须在**跳过的同一处**记录原因（原因入产品或诊断键）；
  调用侧**不得**用另一套独立重分类反推"未丢弃"；产品统计必须满足恒等式
  `n_total = n_valid + n_dropped`（该恒等式本身是一条判红的判据）。
- **中位归一基准 `median_snr` 的校验（正向）**：入口处对 `snr_phot`、`median_snr`、`idw_power` 施加
  `isfinite` 与 `median_snr > 0` 硬校验，任一非法 ⇒ 构造返回 false（**不得**把非法基准换成 `1.0`）；
  从上游块裸拷字节的路径在拷贝后同样校验，或以 `build = false` 走"无 SNR 模型"分支（该分支**不写** SNR 子块）。
  依据：该字段是从上游产品块裸拷 8 字节直透进来的，中间无合法性检查即为缺口；`snr_phot = median_snr` 的**恒等对**是绝对语义的实现方式（见 P-REG-06）。
- **公开评估接口（正向）**：`evaluate(...)` 必须携带有效性出参（`bool` 或 `NaN` 出参）；
  未构造／无邻域／权重和 `≤ 0` 三种情形一律返回 **`NaN`**（与"无覆盖用 NaN"同态），不得返回 `0.0f`
  （`SNR = 0` 是合法物理下限，与"模型缺失"语义正交）。
- **零点标准误（正向）**：callee 与 consumer 的"可用/不可用"判据收敛为**同一份**常量（引用同一函数/常量，遵循"生产者／校验者／测试引用同一份"纪律）；
  C ABI 返回值必须配伴生状态位；"无零点"的参数面编码与产品面编码（产品面 = `null`）逐处登记，
  `zero_point_mag` 的判定在两个头文件里必须同形（对 `ZP < 0` 的结论必须一致）。

### 3.17 P-ALG-17 帧级深度与宽度口径的唯一权威实现

- **正向要求**：帧级深度只由 `snr_frame_depth_f64` 一个实现体产出；同 TU 内的第二个求值体必须（a）改为组装 `SnrSourceResult`
  （`sigma_f_optimal_adu = med_sigma/√ΣP²`）后调用该权威实现，或（b）把 legacy 帧级深度字段置 `NaN` 并注明"该通道不提供帧级深度"。
- **宽度口径**：同一产品面内不得同时走"PSF 块因子 `1.230310`"与"检测块列 `2.3548200450309493`"两套轮廓口径（两者属不同轮廓，差 `1.9140` 倍）；
  选用哪一套必须随字段具名登记。
- **改前核对义务（正向）**：动该处前必须核对 HiPS 头 `ASTROCS_FRAME_SNR` 的取值来源与 `frame["frame_snr"]` 两处键的实际消费者；
  同名不同物必须先消歧（这是字节改动的先决条件，见 P-GATE-20 的 R-4 项）。
- **依据**：`docs/science/CONTROL_WEIGHT_SNR.md` §2a（`m_5 = ZP − 2.5·log10(5·σ_F(ref))`）；本 TU 自称"SNR 科学量唯一权威实现、禁止用整帧标量替代"的注释与该注释一致化。

### 3.18 P-ALG-18 `[N,9]` PSF 块列序（跨边界 ABI）

- **正向要求**：块列序在跟踪面立**唯一列序表**并带版本号（`psf_params:v2`）；
  生产者与消费者各出一位静态或运行时断言，**同一份枚举常量**引用，禁止字面下标；
  ABI 探针把 9 列语义纳入 lock JSON（现有探针只锁结构体首部偏移与 `sizeof`，不锁列序），
  探针内定义未使用的断言宏要么实际使用、要么删除。
- **具名行为**：列序校验失败 ⇒ `P1NOISE_ABI_COLUMN_ORDER_MISMATCH` 一类具名状态、不落产品；
  不得以"当前供料方与消费方同约定"替代守卫（供料方一旦换成 psf 模块批 API，掩膜半径会吃 `flux = cx / fwhm = sy`，
  后果是天空样本混源 ⇒ 背景方差面与逐像素 ivar 全错）。
- **对账前置**：本处存在两份相反读数（"列序在三处一致，非缺陷"对"三份书写互斥"），实施前先在《二次核对》的互斥对账项下定案，再按定案写守卫。

## 7. 判据

每条三件：**读哪个对象／期望方向（不等式含取等号的一侧）／注入什么必红**。
本件不写门的实现方式、不写注册表条目；判据的"现在判不到什么"见《修复顺序与验收判据》。
凡"恒真"形态（判据不接触被测实现、或两侧同源）一律不具备证据资格，`P-GATE-*` 的期望方向都写成**可被注入打破**的形式。

| ID | 判据 | 读哪个对象 | 期望方向（含取等号侧） | 注入什么必红 |
|---|---|---|---|---|
| P-GATE-01 | 叠加权随位置变化 | 该 mosaic 组的逐像素权重面（或其采样摘要）＋ `weight_source` | `max(w) / min(w) > 1`（同一帧内）；恒 1（取等）⇒ **红** | 把权重输入的查询坐标都设成同一值 ⇒ 红 |
| P-GATE-02 | 背景逆方差不得当逐像素科学权重 | 叠加权来源面标识 | 来源 = 含被估量自身散粒项的面（或已裁为改判时的等价声明）；来源 = 背景面 ⇒ **红** | 在有亮源的合成帧上用背景面当叠加权 ⇒ 红 |
| P-GATE-03 | 无源恒零 | 含源项臂与背景臂在同一**无源帧**上的 variance 平面 | 同 seed 下**逐位恒等**（比字节，不比统计量）；不等 ⇒ **红** | 在无源帧上让两臂给出不同字节 ⇒ 红 |
