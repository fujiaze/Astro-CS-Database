## 1 球面像元与投放区交叠的正确表示

### 1.1 等面积坐标卡（成立，可直接引用）

记 `z = sin δ`（无量纲）、`φ` 赤经 [rad]、`(u,v) ∈ [0,1]²` 基面内坐标、`f` 基面号（0–3 北、4–7 赤道、8–11 南）、`N = N_side`。

**赤道带支**（面 4–7 整方格、面 0–3 的 `u+v ≤ 1`、面 8–11 的 `u+v ≥ 1`）

```text
z = (2/3)(u+v−1)      φ = (π/4)(u−v+2(f−4))
∂z/∂u = ∂z/∂v = 2/3   ∂φ/∂u = π/4   ∂φ/∂v = −π/4
|J| = |(2/3)(−π/4) − (2/3)(π/4)| = π/3
```

**极帽支**（面 0–3 的 `u+v > 1`，南面同理），令 `s = 2−u−v ∈ (0,1]`

```text
z = 1 − s²/3          φ = (π/2)f + π(1−v)/(2s)
∂z/∂u = ∂z/∂v = 2s/3  ∂φ/∂u = (π/2)(1−v)/s²   ∂φ/∂v = −(π/2)(1−u)/s²
|J| = (2s/3)(π/2)[(1−u)+(1−v)]/s² = (2s/3)(π/2)·s/s² = π/3
```

**结论（解析恒等，与 `u,v,f,N` 无关）**

- 两支各自 `|J| = π/3`；`dΩ = |dz dφ|` [sr] ⇒ 每面 `π/3`、`12·(π/3) = 4π` 闭合。
- 一叶占 `1/N²` 方格 ⇒ `A_leaf = π/(3N²) ≡ 4π/(12N²)`；与第三方实现 `4π/npix` **逐位相等**（`N = 16…4096`）。
- `hp_res = √(π/3)/N`；`HEALPIX_SCALE_PER_NSIDE_ARCSEC = √(π/3)·(180/π)·3600 = 211076.28514206142″`。
  **`211034.6` 与 `2110960/…` 一类手写抄值都是禁抄值**（前者相对差 −1.97e−4，会使 nside 决策在每个倍频程的
  `finest ∈ (211034.6/2^k, 211076.285/2^k)` 窗口内少取一阶）。常数必须由公式求值。
- **唯一失效点是 `s = 0`（极点本身）**：`φ ∝ 1/s` 发散、方向折叠 ⇒ 卡在该点**不可逆**。
  `|J|` 的表达式不含 `1/s` ⇒ 这是可逆性失效，**不是面积口径失效**。极点需要的是"方向特判"，不是"面积特判"。
- 全天逐点有限差分 44652 点实测：`|J|/(π/3) − 1` 最坏 `5.14e−4`，且最坏点恰是南极点本身 ⇒ 与上面的解析结论一致。
- 方格 ↔ NESTED 像素双射：`N=16` 3072 格 ↔ 3072 个互异 id、每格 9 个采样点全落同一像素（`cells_straddling_pixels = 0`）；
  `N=64` 49152/49152、跨格 0。⇒ 卡内叶轴对齐这一前提成立（第三方库互证）。

### 1.4 环序角点与解析真面积（自校基准，可直接抄）

电平（`j = 0…4N`）与每环像元数：

```text
北极冠 1 ≤ j ≤ N      : z_j = 1 − j²/(3N²)
赤道带 N < j < 3N     : z_j = (4/3)(1 − j/(2N)) = 2(2N−j)/(3N)
南极冠 3N ≤ j ≤ 4N−1  : z_j = −1 + (4N−j)²/(3N²)
端点                 : z_0 = +1（北极）, z_{4N} = −1（南极）
每环像元数 S_j = 4j (j≤N) / 4N (N<j<3N) / 4(4N−j) (j≥3N)   ⇒ Σ S_j = 12N²
```

顶点网格：第 `k` 电平的方位格点间距 `w_k = 2π/S_k`，偏移 `o_k = 0`（冠区）／`o_k = 0 (k 偶)、w_k/2 (k 奇)`（赤道带）。
像元 `(j,m)` 中心 `φ_c = o_j + (m+½)w_j`，四角（循环序 N,L,S,R）：

```text
N = ( 电平 j−1 网格上离 φ_c 最近的格点 , z_{j−1} )
L = ( φ_c − w_j/2 , z_j )      R = ( φ_c + w_j/2 , z_j )
S = ( 电平 j+1 网格上离 φ_c 最近的格点 , z_{j+1} )
```

**顶点必须按"离 `φ_c` 最近的格点"取**，不是"按 `m` 奇偶在 `φ_c` 与 `φ_c±w/2` 间交替"——后者在 `N=2` 恰好正确、`N≥4` 即错。

解析真面积（单位球 `dA = dφ dz` ⇒ 球面面积＝像元在 `(φ,z)` 平面足迹面积）：
带界由"自上极累计等面积"定 `z_bd(j) = 1 − j(j+1)/(3N²)`（冠区），环宽 `Δz_j = 2j/(3N²)`、带面积 `2πΔz_j`、单格

```text
A_true(环 j) = 2π·Δz_j / S_j = 2π(2j/3N²)/(4j) = π/(3N²)
（赤道带 Δz = 2/(3N)、S = 4N ⇒ 同值）
```

实测按环求差对 `π/(3N²)` 的最大相对偏差 ≤ 3.6e−12（N=256）⇒ **解析真面积与等面积构造闭合**。
极区小投放盒的解析面积：`Δλ_eff · Δsin δ`（用于合法极区夹具的期望值，见 §3.4）。

- drop 由任意 WCS（含 SIP）给出；TAN 为 gnomonic，径向函数 `R_θ = (180°/π)·cot θ` ⇒ **直边映射成大圆弧**
  ⇒ drop 多边形是**测地多边形**，其细分段数**不是误差自变量**。
- 不依赖基面归属的球面精确构造（leaf 真曲线 K=16/24、drop 大圆弧细分、S-H 半空间裁剪＋扇形面积、Richardson 真值）实测：
  `seg = 1→64` 逐叶误差**不变**（纯浮点噪声地板）——跨缝 `+2/3` 位形 `3.23e−8…4.94e−8`(N=2048) 与 `2.43e−7…2.86e−7`(N=8192)；
  "近缝不跨缝"对照同量级（1.4–2.0e−8）⇒ **缝本身无可识别的额外误差、无平台**。
  ⇒ 任何"缝上收敛到 8.5e−6 平台"的叙述都**不得**登记为几何性质（它只来自特定 face 归属实现选择下的 chart 侧折线）。

## 2 两条闭合恒等式在哪个分支互斥

两条恒等式（对外主张，成文于守恒式登记面）：

```text
(I)  每格各叶之和 = 投放面积        Σ_p a_jp = A_drop,j
(II) 每叶各格之和 = 叶面积          Σ_j a_jp = A_leaf,p
```

**互斥发生在同一个函数的两条分支上**：

| 分支 | 位点 | 返回值 | 是哪个几何 |
|---|---|---|---|
| leaf 完全落在 drop 内 | `spherical_overlap.cpp:1239-1242` | `PI / (3.0·nside²)` | **真** HEALPix 像元面积（解析） |
| leaf 被部分覆盖（`nb == 4`） | `spherical_overlap.cpp:1283-1294`，边界来自 `:1372-1375 get_healpix_boundary4` | 四角**大圆弧**四边形经 S-H 裁剪后的球面多边形面积 | **偏小的模型**面积；含极像元低 9.9684% |

⇒ 两条分支**不是同一个几何**。对含极点叶：走 (I) 侧要满足守恒就得把 0.9003 的缺口摊给别的叶，
走 (II) 侧则"满覆盖 ⇒ 真值、部分覆盖 ⇒ 低 9.97%"两者混在同一叶上 ⇒ **(I) 与 (II) 在极点像元处不可能同时成立**，
差值达像元面积的 10%。同时这**否证**了 `spherical_overlap.h:137` 的"极区一角可能退化（退化角会重合，不影响凸性）"——
该"不影响"无任何推导，实际影响是一阶面积误差。

**求和型恒等式的证据资格（必须随引用一起写）**

- `Σ_p a_jp = (π/3)|D∩face|`、`Σ_p A_leaf = 4π`、`Σ_out = Σ_in`、`Σ(support·A_p) = A_drop` 全属**求和型**：
  正当资格 = **完备性与全局标度**（抓得住漏候选、漏 face、量纲错、量级错），**不含逐叶正确性**。
- 实测分离：在 `N=512` 真实逐叶分配向量上做三型保总量注入（索引整体错位／一叶 ×2 其余按比例吸收／相邻两叶互换），
  4 个位形下注入前后 `Σ` 相对变化 ≤ **4.4e−16**（浮点最后一位），而同一注入在逐叶度量上是 **`1e0 … 3.2e2`** ⇒ 相差 **15 个数量级**；
  基线求和闭合 `1.49e−3 … 2.11e−4` 在注入后**逐位不变**。
- 漏一个候选叶的量级对照（同一归档表）：V0 弦路径 `6.63e−4`、改进候选 `2.25e−7`、oracle `8.81e−15` ⇒ 求和型**对量级/漏选会红**，
  不是"一无是处的恒真门"，但也不能当几何正确性证据。
- 恒等往返型的两条要单独点名：`Σ(support·A_p) = A_drop` 里 `support = a_jp/a_p` ⇒ 被加数 ≡ `a_jp`，恒等往返；
  `全天总面积 = 4π` 实测残差 0.0，恒过。
- `Σ_p a_jp` 在归档实现里就是**被发布的那一次 `area2` 的结果**，发布用它、校验也用它 ⇒ 与被检对象同源。

**下游口径（成立，可直接实现）**

```text
w_jp        = a_jp / A_drop,j                        ⇒ Σ_p w_jp = 1
N_p         = sumNorm = Σ_j w_jp · A_pixel,j
D_p         = sumArea = Σ_j a_jp
S_p         = F_p / N_p                               [ADU·sr⁻¹]（发布面亮度）
k           = D_p / N_p = pixfrac²·(1+⟨δ⟩)            （发布折算因子）
variance_p  = sumVarNum / N_p²                        （k 的幂次：signal +1、variance +2）
support     = D_p / A_cell，A_cell = 4π/(12·nside²)
```

- **唯一实现口径是按 drop 面积归一 `w_jp = a_jp/A_drop,j`**；FROZEN 正本 `docs/science/DRIZZLE.md §10` 逐字禁止把核权重写回
  `a_jp/A_pixel,j`（`FZ-COND-FLUX-CONSERV` 判红）。`w'_jp = a_jp/A_pixel` 只作为**等价参数化**成立，
  且必须同时换分母（`N'_p = Σ w'·A_pixel = D_p`）。发布 `S_p` 与 `variance_p` 对两种参数化**不变**（分子分母各乘 `pf⁴` 相消）；
  但 `Σ_p w_jp = 1`（⇒ `Σ_p F_p = Σ_j x_j`、`flux_conservation_factor ≡ 1`）**只在 drop 归一下成立**，
  用 `A_pixel` 分母时 `Σ_p w'_jp = pf²` ⇒ 同一句"通量守恒"在两种写法下数值相差 `pf²`（0.8 ⇒ 0.64）。
  **裁口径时必须把量名钉死**（"输出通量"指 `sumFlux` 还是"发布 signal 面"）。
- `flux_conservation_factor ≡ 1` 与"`Σ_out = Σ_in` 与 `pixfrac` 无关"是**定义性推论**（核归一选择的恒等式），
  **不是**被验证的经验命题，**不构成面积分配正确性证据**。分配正确性由逐叶判据把门。
- `k` 的表达式写 `= pixfrac²` 是缺项，应为 `= pixfrac²·(1+⟨δ⟩)`（θ=2″ 时 `⟨δ⟩ ≤ 1.8e−10`、θ=300″ 时 `≈ 1.9e−7`）。

### 3.6 门判据的代数结构（已确立，别再用错处方）

常量面亮度夹具（`x_j = B0·A_test,j`）下发布信号与 `B0` 之比：

```text
记 c_jp = a_jp / A_drop,j ≥ 0，δ_j = A_test,j / A_prod,j − 1

S_p/B0 = Σ_j A_test,j c_jp / Σ_j A_prod,j c_jp
       = 1 + [ Σ_j (A_prod,j·c_jp)·δ_j ] / [ Σ_j (A_prod,j·c_jp) ]              … (★)

⇒  min_j δ_j  ≤  S_p/B0 − 1  ≤  max_j δ_j                                       … (■)
```

- (★)：`a_jp` **只出现在权子里** ⇒ 判据残差是 `δ_j` 的正权加权平均。
- (■)：可达集合被夹在 `[min δ_j, max δ_j]` 内，**该区间只由"夹具面积式 vs 生产面积式"之比给出，与 `a_jp` 的任何数值无关**；

- `δ_j ≡ 0`（同式＋同输入＋同分支）时 (★) 恒等于 1：任意逐对缩放、整体错 10%、把含极叶乘 0.9003、整批候选置零
  （只要 leaf 非空且和有限），`S_p/B0 − 1` **精确为 0**（实测，不是"量级小"）。
  本批门的实测 `δ_j`：夹具与生产同走球面 VOS 支 ⇒ **逐位为零**。
- `A_drop,j` 同现于分子与分母的同一个权 `c_jp` ⇒ 逐对相消，**不进 `δ_j`**。⇒ "生产侧 `drop_area` 走了另一个分支"这类错
  **不会**被打开 `a_jp` 通道的方式抓到。能打开的只有：分母口径被换、`sumNorm` 不再含 `A_prod,j`、非有限/空集合。
