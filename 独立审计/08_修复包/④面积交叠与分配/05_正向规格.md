## 1 范围与定义

### 1.1 目标产品与字节

本规格覆盖以下三阶段的出货产品字节：

- **normalize 阶段**（drizzle engine）：
  - `SIGNAL`：面亮度发布 `S_p` [ADU·sr⁻¹]
  - `VARIANCE`：方差 `variance_p`
  - `IVAR`：信噪倒数平方 `ivar_p = 1/variance_p`
  - `SUPPORT`：覆盖比例 `D_p / A_cell`
  - `COVERAGE`：布尔有效覆盖标志
- **mosaic 阶段**（drizzle tiled accumulation）：同上，按 tile 聚合
- **export 阶段**（p3 resample）：
  - `bsig`、`bvar`：重采样后的信号/方差
  - `coverage`：支持度
  - `provenance.kernel_id`：实际使用的重采样核 ID

### 1.2 术语表

| 术语 | 定义 |
|---|---|
| `leaf` | HEALPix 基本像素单元，由 `(face, u, v, N)` 标识 |
| `drop` | 源像元在目标投影上的投放区域（测地多边形） |
| `a_jp` | leaf `j` 与 drop `p` 的重叠立体角 [sr] |
| `A_leaf,j` | leaf `j` 的真实面积 `π/(3N²)` [sr] |
| `A_drop,p` | drop `p` 的立体角（测地多边形分割累加） [sr] |
| `w_jp` | 核权重 `a_jp / A_drop,p`（归一化到 drop） |
| `support` | 覆盖比例 `D_p / A_cell`，`D_p = Σ_j a_jp` |
| `k` | 折算因子 `pixfrac²·(1+⟨δ⟩)` |
| `δ_j` | 测试侧面积式与生产侧面积式的相对偏差 `A_test,j / A_prod,j − 1` |

### 1.3 适用范围与边界

- **适用**：HEALPix 网格（NESTED 编号），`N_side = 2^k`，`k ∈ [4, 22]`
- **适用**：任意 WCS/SIP 投影的 drop 多边形
- **不适用**：极点的方向特判（`|dec| ≥ 90°−ε` 显式失败，不进入面积计算）
- **不适用**：crossing hemisphere 多边形（API 返回 NaN）

## 2 几何模型与像元表示

### 2.1 HEALPix 叶的真曲线边界

**必须使用真曲线边界**。`[x,y] ∈ [0,1]²` 单位方格的边在 `(φ,z)` 平面是直线段 ⇒ 球面上是**真曲线边**（既非大圆弧也非等纬度小圆弧）。

- **赤道带支**（面 4–7 整方格、面 0–3 的 `u+v ≤ 1`、面 8–11 的 `u+v ≥ 1`）：
  ```text
  z = (2/3)(u+v−1)      φ = (π/4)(u−v+2(f−4))
  |J| = π/3（解析恒等）
  ```
- **极帽支**（面 0–3 的 `u+v > 1`，南面同理）：
  ```text
  s = 2−u−v ∈ (0,1]
  z = 1 − s²/3          φ = (π/2)f + π(1−v)/(2s)
  |J| = π/3（解析恒等）
  ```

**结论**：`dΩ = |dz dφ|` ⇒ 每面 `π/3`、`12·(π/3) = 4π` 闭合；一叶占 `1/N²` 方格 ⇒ `A_leaf = π/(3N²)`。

**调用点**：`subdivide_healpix_edge`（`spherical_overlap.cpp:506-617`）必须被生产路径调用，不得旁路。

### 2.2 drop 多边形表示

drop 由任意 WCS（含 SIP）给出；TAN 为 gnomonic，径向函数 `R_θ = (180°/π)·cot θ` ⇒ **直边映射成大圆弧** ⇒ drop 多边形是**测地多边形**，其细分段数**不是误差自变量**。

- **顶点输入**：`(ra_i, dec_i)` 必须严格按球面坐标给，禁止用 flat-sky 近似 `ΔRA = size/cos(dec)` 用在 `|dec| > 89°`。
- **奇性守卫**：`half_ra > 90°` ⇒ 显式失败（具名错误码 `INVALID_GEOMETRY`），禁止静默降级为"只判 `>0 ∧ finite`"。

### 2.3 含极像元的特殊处理

含极像元（极点邻接的 ring 1 与 ring `4N−1`）的四角大圆弧四边形模型面积系统性偏小，且不随分辨率收缩：

```text
极限相对误差 = 2√2/π − 1 = −9.968368384e−2   （−9.9684%）
绝对亏缺律   = 0.104369 / N²
```

**必须用真曲线细分覆盖含极像元**。从极冠边偏差 `0.0809·hp_res` 起算、逐层 ÷4，降到自身阈值 `1e−6·hp_res` 需 `d > log(8.09e4)/log(4) = 8.15` 层，而 `HP_ADAPTIVE_MAX_DEPTH = 8` ⇒ **极点邻边触底截断，残差 `1.234e−6·hp_res`（超阈 23%）**。

**回退路径**：若无法保证细分深度，该像元走保守回退路径（扩大候选半径至 `3.0×hp_res`），并记录触底像元数与残差上界。

### 2.4 自适应边细分路径

`subdivide_healpix_edge` 例程的注释自述"对所有 NSIDE 统一使用自适应边细分"，生产调用点必须与此一致：

- **nside < 256**：走自适应细分腿（`compute_overlap_area` → `compute_overlap_area_g_ctx`）
- **nside ≥ 256**：**不得**直接取 4 角弦（`get_healpix_boundary4`），必须启用细分路径（或至少对触点像元与冠界像元强制走细分）

**接线要求**：当前 `nside ≥ 256` 时旁路细分是缺陷。修复后两条腿（自适应 vs boundary4）必须在登记容差内一致。

## 3 重叠面积计算

### 3.1 Van Oosterom & Strackee 扇形三角剖分

**唯一生产面积算子**（`spherical_overlap.cpp:230-259`）：

```text
Ω_tri = 2·atan2( a·(b×c),  1 + a·b + b·c + c·a )
多边形面积 = 扇形三角剖分有符号累加，最后整体取 |·|
```

- **输入域**：严格单位化的三维向量 `a,b,c,... ∈ ℝ³`（`‖v‖ = 1`），顶点按循环序排列，多边形严格含于开半球内
- **输出值域**：`[0, 2π)` [sr]（单位球立体角）
- **无效输入行为**：
  - 向量未单位化 ⇒ 返回 `NaN` 并设错误码 `VECTORS_NOT_NORMALIZED`
  - 最大角距 `max_ang ≥ π/2 − 1e-12` ⇒ 返回 `NaN` 并设错误码 `POLYGON_TOO_LARGE`
  - 顶点数 `< 3` 或退化输入 ⇒ 返回 `0.0` 并设错误码 `DEGENERATE_POLYGON`

### 3.2 Sutherland-Hodgman 球面裁剪

**球面多边形裁剪**（`spherical_overlap.cpp:1283-1338`）：
- 输入：leaf 真曲线多边形（经边细分）、drop 大圆弧多边形
- 输出：裁剪后的球面多边形顶点序列（循环序）
- **凸性前提**：leaf 与 drop 均为凸多边形（HEALPix 叶与测地多边形均满足）
- **顶点上限**：凸输入下 16 顶点不可达（实际≤8），溢出改 `-1` 并 fail-closed

### 3.3 l'Huilier 法定位校验

**两套式互校**（交付计算路径必须实现）：

```text
三角形边：a = atan2(|b×c|, b·c)
tan(E/4) = √[ tan(s/2)·tan((s−a)/2)·tan((s−b)/2)·tan((s−c)/2) ]，s = (a+b+c)/2
四边形 = (v0 v1 v2) + (v0 v2 v3)
```

- **用途**：仅用于 self-test 与 oracle 交叉验证，不进出货路径
- **预期精度**：两式逐像元最大相对差 ≤ `3.3e−12`（`N=2…256` 穷举）

### 3.4 输入域与输出值域

**`compute_overlap_area_g_ctx` 函数**：

- **输入**：
  - `center`: leaf 中心 `(ra, dec)` [rad]
  - `boundary4` / `subdivided_edges`: leaf 边界表示（4 角或细分段）
  - `drop_polygon`: drop 顶点序列（已单位化）
  - `nside`: HEALPix 分辨率
  - `target_geom_cache`: 可选缓存指针（`nside ≥ 256` 时用）
- **输出**：
  - `area`: 重叠立体角 `[sr]`（有限正数）
  - `ok`: 布尔成功标志
  - `error_code`: 具名错误码（`NONE` / `NO_INTERSECTION` / `GEO_ERROR` / `SUBDIV_TIMEOUT`）
- **输出值域**：`area ∈ [0, A_leaf]`，`A_leaf = π/(3N²)`

### 3.5 无效输入的具名行为

| 输入情形 | 返回值 | 错误码 | 日志等级 |
|---|---|---|---|
| 向量未单位化 | `NaN` | `VECTORS_NOT_NORMALIZED` | ERROR |
| 多边形跨半球 | `NaN` | `POLYGON_TOO_LARGE` | ERROR |
| 顶点数 < 3 | `0.0` | `DEGENERATE_POLYGON` | WARN |
| 无交叠 | `0.0` | `NO_INTERSECTION` | DEBUG |
| 细分超最大深度 | 当前弦面积 | `SUBDIV_TIMEOUT` | WARN（记录残差） |
| 极区 half_ra > 90° | `0.0` | `INVALID_GEOMETRY` | FATAL（拒绝该帧） |

**关键原则**：不得返回"看起来合法的好值"掩盖无效输入。

## 4 核权重与通量分配

### 4.1 核权重分母口径

**唯一合规口径**（FROZEN 正本与代码事实）：

```text
w_jp = a_jp / A_drop,j
```

- **值**：无量纲
- **来源**：`docs/science/DRIZZLE.md §10`（禁止写成 `/A_pixel`）、`drizzle_engine.cpp:1617`
- **锚**：`ASTROCS_DESIGN.md:209`（订正为 `/A_drop,j`）、`spherical_overlap.h:93`（订正）
- **含义**：核权重归一化到 drop 面积，使 `Σ_p w_jp = 1`（通量守恒构造性质）

**等价参数化**（仅作为数学等价存在）：
```text
w'_jp = a_jp / A_pixel,j    （须同时换分母 N'_p = D_p = Σ_j a_jp）
```
但 `Σ_p w'_jp = pf² ≠ 1`，故对外主张"通量守恒"时必须用 `w_jp` 口径。

### 4.2 通量守恒构造

```text
sumFlux = Σ_j x_j · w_jp        （x_j 为源像元通量）
N_p     = Σ_j w_jp · A_pixel,j  （名义支撑面积）
D_p     = Σ_j a_jp              （真实覆盖立体角）
k       = D_p / N_p = pixfrac²·(1+⟨δ⟩)
S_p     = sumFlux / N_p         [ADU·sr⁻¹]
```

- **flux_conservation_factor ≡ 1**：当且仅当 `w_jp = a_jp / A_drop,j` 时成立（构造性质，非经验命题）
- **⟨δ⟩ 项**：`δ_j = A_test,j / A_prod,j − 1` 的平均值，`θ = 2″` 时 `⟨δ⟩ ≤ 1.8e−10`、`θ = 300″` 时 `≈ 1.9e−7`

### 4.3 发布信号与方差

```text
S_p = sumFlux / N_p                        [ADU·sr⁻¹]
variance_p = sumVarNum / N_p²              [ADU²·sr⁻²]
ivar_p     = 1 / variance_p                [sr²·ADU⁻²]
```

- **pixfrac 幂次**：signal `+1` 次、variance `+2` 次
- **背景偏移**（pf = 0.8）：`1/pf² − 1 = 56.25%`、`1/pf⁴ − 1 = 144.14%`、`2.5·log10(1/pf²) = 0.484550` mag

### 4.4 支撑因子 support

```text
support = D_p / A_cell
A_cell  = 4π/(12·N²) = π/(3N²)            [sr]（真 HEALPix 叶面积）
```

- **分子分母同表示**：`D_p` 与 `A_cell` 必须同为真曲线积分（步骤 4 修好后不再相差 10%）
- **缺失表达**：`D_p = 0` ⇒ `support = 0`
- **钳制规则**：`support > 1` 时钳到 `1.0`（过覆盖属数值误差，非真实物理）
- **计数要求**：按 profile 分支各自新增计数点 `support_clamped_pixels_{0,1}`（原计数器只在 profile=0 触发）

## 5 量化与非数档

### 5.1 profile=0 直写端

- **行为**：不量化，直写 double
- **信号**：`sig = F_p · k / D_p = S_p`（精确，与 pixfrac 无关）
- **优势**：无量化误差，适合科学分析链路消费

### 5.2 profile=1 量化端（255 档）

**8 位量化映射**（`hips_profile=1`）：
```text
q = round(255 · S)                         （S = D_p / A_cell）
D_p_quant = (q/255) · A_cell               （分母采用量化后的支撑）
sig = S_p · (D_p_quant / D_p)             （回补量化偏差）
```

- **信号相对偏差的严格界**：`|r| ≤ 0.5/q`
- **全档最坏情况**：
  - `S = 1.0` ⇒ `q = 255` ⇒ `rel_dev = 0`（邻域最坏出现在 `S = 254.5/255`，`+1.9685e−3`）
  - `S = 0.05` ⇒ `q = 13` ⇒ `rel_dev = −1.9231e−2`
  - `S = 1/510` ⇒ `q = 1` ⇒ **`rel_dev = −0.500`（−50%）**（全映射最坏）
  - `S < 1/510` ⇒ `q = 0` ⇒ **按无覆盖发布，信号为 NaN**

- **方差偏差**：严格为 signal 的 2 倍，`(1+r)² − 1 ≈ 2r`

**接线要求**：provenance 必须写 `signal_precision_limit = 0.5/q`，并把 u8 位深语义登记进 `DATA_SEMANTICS §11`。

### 5.3 NaN 传播与计数

**两套互斥口径（待负责人裁决，保守默认）**：

| 口径 | 行为 | 计数 |
|---|---|---|
| **掩膜＋重归一＋计数**（保守默认） | NaN 样本被剔除，合格集重归一，记 `n_rejected_nan` | 必须计数 |
| 传播不掩膜（作废） | NaN 直接传播，该 leaf 发布 `signal = NaN` | 原报告称已作废 |

**下游处置**（`render_vis.py` / `seam_footprint.py`）：
- 不得填 0 后直接进度量
- 必须**计数**（`n_coverage_lost`）或**拒**（fail-closed）

**判定**：`S < 1/510` ⇒ 必须出现具名 `n_coverage_underflow` 计数，不得只在产品面留 NaN。

## 6 导出腿重采样核

### 6.1 kernel_id 选择与注册核查

**生产选路必须查 registry**：
- `NeighborhoodSet` 携带生成它的 `kernel_id`
- `build_*_normalized` / `admit` 核对不一致即 `REJECT`
- 给 `production_science_default` 接真实判据（非默认核用于生产 ⇒ REJECT），或删该字段

**registry 字段有效性复核**：
- `err_over_bound == max_interp_err / analytic_bound`（自洽）
- `err_over_bound < 1.0`（界成立）
- `oracle_id` 指向**跟踪面存在**的 Oracle 件/测试名（不得指 `run/`）
- 六个硬编码常数从源码搬到 Oracle 结果件（`实验/` 或 `artifacts/evidence/`），源码只留 id 引用

### 6.2 面积精确核的实现要求

**`bilinear_area_overlap_exact` 核**（registry 声明为 `production_science_default = true`）：

**必须真正实现**，不能仅是标签：
- 实现 `q11` 坐标参与权重（一般四边形面积坐标／或直接做输出像素足迹与输入 leaf 的多边形裁剪重叠）
- 权重 = 重叠面积分数 `w_ij = Area(output_i ∩ input_j) / Ω'_i`
- 误差界必须有实验产生载体的数值（`max_interp_err`、`analytic_bound`、`err_over_bound`）

**负例注入**：把 `ExportInputs::kernel_id` 设为 `"bilinear_area_overlap_exact"` 而实现仍是 4 象限双线性 ⇒ **必 RED**（现白拿"误差为 0"）。

### 6.3 四象限双线性核的语义限定

**维持现算子时的限制**：
- `ALG-P3-003 G4` 的"面积重叠分数 (投影线性化)"必须改名为"**轴对齐合成矩形双线性（UnitSum）**"
- `PHASE3_RESAMPLE.md:188` 的双线性出处条目相应改
- 登记面的"面积重叠"措辞必须摘除，改为"合成矩形上的双线性插值"

**权重的真实计算**（`p3_resample.cpp:409-418`）：
```text
四角权重 (1−u)(1−v) …（不含中心像元坐标、不含 q11 坐标）
```
这是**以两条边定出的轴对齐合成矩形上的双线性**，**不是登记面所说的面积重叠分数**。

## 8 容差与精度档

### 8.1 逐对面积断言容差

**逐对判据**（步骤 1 的核心）：
```text
|max_p |a_jp^prod / a_jp^oracle − 1||       （逐叶最大相对偏差）
Σ_p |a_jp^prod − a_jp^oracle| / (2·A_drop) （总变差距离型）
逐对断言：|a_jp^prod − a_jp^oracle| ≤ tol · A_leaf
```

**容差档**（取决于 oracle 类型）：

| oracle 类型 | 能力上限 | 建议登记容差 | 依据 |
|---|---|---|---|
| 平面 gnomonic 型原语 | `1e−5` 相对 @ nside=512 | `1e−5` | gnomonic 预算 `+3ρ²/2` |
| 真曲线球面精确构造（VOS×l'Huilier 互校） | `1e−10` 量级 | `1e−9` | 双式互校 ≤3.3e−12 |
| astropy_healpix 校准 | `1e−10` 量级 | `1e−9` | 异源第三方库 |

**注意**：登记面上的 `rtol 1e−9` 用平面 gnomonic oracle**不可能满足**，要么换 oracle、要么按变更流程改档，二者择一。

**必红注入**：
- 人为把某 `(j,p)` 对的 `a_jp` 乘 `0.9003`（含极像元真实模型偏差量）⇒ **必红**
- 把 oracle 换成与被检路径同源 ⇒ 该门必须被静态检查判为"oracle 未异源"（配 `--self-test`）

### 8.2 求和型闭合容差

**资格范围说明**（必须在 `DRIZZLE_GEOMETRY.md §9` 与 `docs/science/DRIZZLE.md` 明写）：
- **正当资格**：完备性与全局标度（抓得住漏候选、漏 face、量纲错、量级错）
- **不含**：逐叶正确性

**容差档**（求和型门不混入逐叶判据）：
```text
Σ_p a_jp / A_drop − 1   ≤ 1e−6      （FP64 通量闭合）
Σ_p a_jp / A_drop − 1   ≤ 1e−5      （FP32 通量闭合）
```

**错分负例必须同堂**：把索引整体错位／一叶 ×2 其余按比例吸收／相邻两叶互换 三型保总量注入 × 4 位形 ⇒ **逐叶判据必红，求和判据可能绿**（15 个数量级分离）。

### 8.3 量化带界

**parity 全档断言**（`drizzle_pf_sb_gate` 的 parity 项）：
```text
|sig0/sig1 − 1| ≤ 0.5/q + ε
```
- **取样**：`q ∈ {0..255}` 全档＋格点中点（共 511 例）
- **带界**：`ε ≈ 1e−7`（浮点噪声地板）
- **必红注入**：
  - 把 `lround` 改 `floor`/`ceil` ⇒ 在 `q = 163` 档必红（现 `q = 64` 档是浮点巧合，测不到）
  - 注入 `D_p = (q+0.5)·a_cell/255`（格点中点）⇒ 现 tol `1e−5` 必红（预测 `q=1` 档 0.5、`q=64` 档 7.8e−3）

**回退分支覆盖**：
- `sumNorm ≤ 0 ⇒ k = 1.0` 回退档（注入 `sumNorm ≤ 0` 必红）
- `S < 1/510` 档（注入 `S = 1/1020` ⇒ 必出现 `n_coverage_underflow` 计数）

## 9 判据与制门读法

### 9.1 逐对判据读对象/方向/必红注入

**判据名称**：`DISP-DRZ-009`（逐对面积断言）

| 要素 | 内容 |
|---|---|
| **读对象** | `a_jp^prod`（生产输出的逐叶交叠面积）vs `a_jp^oracle`（异源 oracle 计算的期望值） |
| **期望方向** | `|a_jp^prod / a_jp^oracle − 1| ≤ tol · A_leaf`（`tol` 依 oracle 类型定） |
| **必红注入** | 1. 人为把含极叶 `a_jp` 乘 `0.9003`<br>2. 少裁 1 格 / 少 1 个候选<br>3. 一叶 ×2 其余按比例吸收（索引错位） |

**Oracle 要求**：
- **异源**：不得与被检路径共用同一折线或同一弦
- **可实现**：真曲线边界＋细分收敛外推（Richardson），或第三方库的亚像素偏移
- **极区处理**：顶点直接按球面坐标给（`radec_to_vec(ra_i, dec_i)`），禁止 flat-sky 近似

### 9.2 求和型判据资格范围说明

**判别力范围**：
- **有效**：候选漏选（V0 `6.63e−4`、REC-1 `2.25e−7`、oracle `8.81e−15`）、量级错、量纲错
- **无效**：逐叶错分（保持总量不变的注入下 `Σ` 相对变化 ≤ `4.4e−16`，而逐叶错分可达 `1e0…3.2e2`）

**制门读法**：
- **读对象**：`Σ_p a_jp` / `A_drop` 与 `Σ_j a_jp` / `A_leaf`
- **期望方向**：相对残差 ≤ `1e−6`（FP64）
- **必红注入**：索引整体错位（总量不变但分配错）⇒ **求和判据绿，逐叶判据红**（证明二者不可互相顶替）

### 9.3 极区夹具正确性判据

**夹具构造合法性**（`test_spherical_overlap.cpp:352 makeRectDrop`）：

| 错误形态 | 检测方式 | 必红条件 |
|---|---|---|
| flat-sky `ΔRA = size/cos(dec)` 在 `|dec| > 89°` | 计算 `cos(dec)` | `cos(89.99°) = 1.7453e−4` ⇒ `half_ra = 286.5°`（绕极点 1.6 圈） |
| `dec + half > 90°` | 角度加法 | `89.99 + 0.05 = 90.04°` 越出定义域 |
| `half_ra > 90°` | 守卫判据 | 必须显式失败，不得静默降级 |

**期望值**：极区小盒解析面积 `= Δλ_eff · Δsin δ`（`Δλ_eff` 为考虑 RA wrap 后的有效经度跨度）

**取样域扩充**：现有逐叶面积断言从"低 nside 单个赤道中心像素"扩到**极冠／face 角点邻域**，容差收到与冻结预算同量级。

### 9.4 parity 全档断言

**断言形态**（`drizzle_pf_sb_gate.cpp:242-250`）：
- **旧态**：`q = 64` 档 parity tol `1e−5`（浮点巧合，`255·S₆₄` 精确回到 64 ⇒ `lround=floor=ceil`）
- **新态**：全档扫描 `q ∈ {0..255}` ＋ 格点中点，断言带界 `|sig0/sig1 − 1| ≤ 0.5/q + ε`

**必红注入**：
