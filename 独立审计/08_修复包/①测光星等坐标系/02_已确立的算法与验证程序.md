## 1. 现行式子（口径的唯一写法）

### 式-1 合成参考通量

```text
F_syn = ∫ F_λ(λ) · T(λ) · Q(λ) · λ dλ                [W·m⁻²·nm]
F_λ   = byte · flux_mul + flux_min                    [W·m⁻²·nm⁻¹]
```

- 正本：`docs/science/PHOTOMETRY.md §2a.1/:44`（式与单位）、`§2a.1/:55`（**不含** `10^(−0.4·G)`）；
  权威条目号 `PHOT-FSYN-CANON-001`，公共头同述 `lib/algorithms/photometry/cpp/include/photometric_calib.h:126-131`。
- 符号约定：被积函数取官方 VEGAMAG 平均能量谱通量的同一分子（`S(λ) ↔ T(λ)·Q(λ)`）而**去掉归一化分母**；
  分母在同一帧内与星无关 ⇒ 逐帧常数 ⇒ 在 `r_i` 里只是 `location` 的平移。由此得到贯穿全链的区分：
  **绝对归一化不可辨识，通带形状必须正确**（`docs/algorithms/PHOTOMETRIC_FIT.md §2`）。
- `λ` 因子恰进一次，不可多亦不可无：探测器计量光子数，`dN_γ = F_λ·T·Q·(λ/hc)·dλ`，
  故 `F_syn ≡ hc·N_γ = ∫F_λ·T·Q·λ dλ`，`hc = 1.98644586e−16 J·nm`；`1/(hc)` 与星无关、被零点吸收。
  绝对谱情形下星等因子进 **0 次**（亮度已在谱的幅度里）。三路同向：官方字段单位（E1）＋官方式 (5.41)（E2）＋第一性推导（E10）。
- 量纲与适用域：模型通带 = `T·Q·λ`，**不含**光学系统透过率与大气消光（显式未建模项，跨帧会成为帧间系统差）；
  有效波长域 336–1020 nm @2 nm，通带必须被该覆盖**完全包含**，网格外 `T·Q` 置 0 而**不外推**（`PHOTOMETRY.md:230`）。
- 实现位点（生产积分核）：`lib/algorithms/photometry/cpp/src/spectrum_integrator.cpp:350`
  （`weighted_wl = wl · filter_trans · q`）、`:446-447`（`f = byte·flux_mul + flux_min`；`integrand = f · weighted_wl`）。
- 前提须显式化（目前无锚的正是这条前提，见 V-1 的取证边界）：`λ` 成立 ⟺ 解码后的 `F_λ` 为**能量**谱辐照度；
  容器若给光子谱通量（`ph·s⁻¹·m⁻²·nm⁻¹`）则必须去掉 `λ`。该前提的判定证据尚未落库（`01` 的 D2）。

### 式-2 逐星对数残差与预过滤

```text
r_i     = log10(F_instr,i / F_syn,i)                  [dex]
delta_i = −2.5·log10(F_instr,i) − G_Gaia,i            [mag]
预过滤   拒绝 i 若 |delta_i − median(delta)| > mag_tolerance
有效域   F_instr,i > 0 ∧ F_syn,i > 0 ∧ r_i 有限；饱和/质量异常星在进入匹配与定标之前即排除
```

- 正本：`PHOTOMETRY.md §5/:197`（`r_i`）、`§5/:200`（`delta_i`）、`§5/:202`（预过滤）；
  排除时点在 `star_matcher.cpp:415-418`：「含 `PC_QF_SATURATED|PC_QF_HAS_SATURATED` 的星**不进入**匹配与定标（不是"拟合后再剔除"），并计 `rejected_quality`」。
- 归一化与不变量：**零点平移不变量**是代数恒等 —— 全体 `F_instr` 同乘 `k` 时 `r_i → r_i + log10 k`，
  位置随之平移、`k_photo` 相应除 `k`、`sigma_residual` 与好星集合不变。3.0 mag 窗等价于通量比 `10^1.2 ≈ 15.85×`，
  作用是放走错配与污染，**不是**标定质量判据，且对整体乘性标度严格不变。
- 量纲提醒：`delta_i` 是 **mag**、`r_i` 是 **dex**，两者不共用容差；`r_i` 是"有量纲比值取对数"。
- 适用域：拟合用星集（`|delta_i − median| ≤ 3.0` 且质量位通过者）；参考星 `G ≲ 15` 为官方采样表示口径、本仓实测一致性到 `G ≲ 18`。

### 式-3 稳健位置与尺度（IRLS／Tukey biweight）

```text
初值      location₀ = median(r)；S = MAD(r)/0.6744897501960817      [dex]
IRLS      u_i = (r_i − location)/(c·S)，c = 4.685
          w_i = (1 − u_i²)²  (|u_i|<1)，否则 0；location ← Σw·r/Σw
          迭代至 |Δlocation| < 1e−6 或 ≤50 步；S = 0 ⇒ location = median(r)，不迭代
输出      k_photo = scale = 10^(−location)              [F_syn 单位]/ADU
```

- 正本：`PHOTOMETRY.md §5/:205-210`（迭代式）、`:29`（`scale = 10^−location`）、`:31` 表行（`c = 4.685`）；
  冻结门 `:191`；`§16.5/:400`（星数不作准入判据）。推导层 `docs/algorithms/PHOTOMETRIC_FIT.md:299/:303`、`§2.3/:96-97`。
- 归一化：尺度 `S` 在迭代内**固定一次**（`star_matcher.cpp:540` 附近）。收益是 `location` 继承 MAD 的 50% 崩溃点；
  代价是 95% 渐近效率只对已知尺度严格成立 ⇒ **`c` 与"尺度是否重估"必须成对变更**，不得单改。
- 权重口径：本层是**等权 × Tukey**（无逐星方差进入）。锚文档 §2.3 要求的逆方差权重属阶段 3（见 `01` 的 B10），不要与本式混用。
- 求解前提：`|r_consistent| ≥ 3` 才进 IRLS，否则 NO_DATA —— 它回答"这次拟合有没有产出标度"，**不是**"星数够不够"的准入判据；
  不成立时走拟合失败路径上报（无零点、无星等、具名降级原因），不另立星数门槛。
- 有限样本边界（必须随附）：MAD 型尺度对 σ 的期望在 `n` 小时系统性偏低（`n=3` 偏低约 1.49 倍），
  `|r_consistent| ≥ 3` 恰落在偏差最大处，本层**不做**有限样本修正 ⇒ 低星数帧 `sigma_mag` **下偏**。

### 式-4 精度承载量

```text
sigma_residual = MAD(r_inliers)/0.6744897501960817，r_inliers = {i | w_i > 0}   [dex]
sigma_mag      = 2.5 · sigma_residual                                           [mag]
sigma_cal_rel  = ln10 · sigma_residual                                          [无量纲相对量]
```

- 正本：`PHOTOMETRY.md §5/:213-214`、`:33`；`PHOTOMETRIC_FIT.md:31`（"n<20 下偏、实现不修正"的同一锚）。
- 估计资格：`|r_inliers| ≥ 2` 才估计，否则不产出（`:191`）。注意"不可估计"当前被编码成 `0.0`，与"实测零散度"不可区分——
  这是判据缺陷（`01` 的 A2），**不是**本式的错；本式与其系数（`2.5`、`ln10`）已核过为正确。
- 语义边界：`sigma_mag` 是逐星定标散度（系综量），不含参考端与逐源测量误差 ⇒ 作单源精度使用会低估。
- 消费口径（② 链的接口，勿沿用旧式）：现行有效式是零点标准误 `sigma_kappa,stat ≈ 1.253·sigma_residual/√N`；
  旧 `snr_phot = 1/(ln10·sigma_residual)` 已被上位判为"非 SNR"（跨 3 个数量级），见 `lib/algorithms/noise_snr/cpp/include/snr_estimator.h:295-296`。

### 式-5 施加面与数据形态

```text
I_photo = k_photo · m(x,y) · I_cal            （纯乘性，逐元素）
order = 0 ⇒ m ≡ 1（委托同一条乘法通道）
方差变换  x′ = α·x ⇒ Var′ = α²·Var，ivar′ = ivar/α²
硬界      max|log10 m| ≤ 1.0 dex（约定值，见 01 的 C3）
```

- 正本：`PHOTOMETRY.md:13`（施加式）、`:126`（`k_photo` 为线性标度、施加后仍是线性面亮度、星等只在派生/展示时换算、不落盘）、
  `:14`（标定因子绝对值无物理意义，唯一判据是尺度无关的测光一致性）、`§16.1⑤`。
- **本件确立的边界**：只到"施加是逐元素乘、`order=0 ⇒ m ≡ 1`、方差按 α² 变换"这一层。`m(x,y)` 的基函数、中心化规范式与取负号
  **不在本件**（其唯一载体是代码注释、科学侧无一条式子），列在 `01` 的 C19，动它之前先按 `03` 的 ㉕ 把式子写进 §16.1。
- 量纲：`k_photo` 是 `[F_syn 单位]/ADU` 的**有量纲**乘子，只有在显式声明参考通量单位后才可称其为无量纲乘性因子
  （`docs/contracts/DATA_SEMANTICS.md:687`）；`m(x,y)` 无量纲（对数以 dex 计）。
- 数据形态：载体始终是线性面亮度；`sigma_mag` 与帧级零点是定标面的元数据与 QA。把像素当星等相加会直接破坏加性天光扣除与逆方差加权。
- 门只有一个：本帧标定是否可信。跨帧 `k_photo` 不同是正常且正确的；为它设绝对数值窗口、或反推增益/口径/曝光，属不可接受变化
  （欠定、不可证伪、把未测量量写入产品；`PHOTOMETRY.md §10`）。
- 施加顺序：本层只承担最后一个因子。`SCI-CAL-001 §3` 明写"逐帧测光标度 `x′=α·x`（标度类别 `photo_scaled_adu`）由下游 photometry 节点施加，本层不施加"；
  生产落点 `module_adapters.cpp:6044`（读 `p1_calibrated_path`）→ `:6082`（写 `p1_photoapplied_path`），与正本顺序（bias → dark(×K) → flat → 测光标度）一致。

### 式-6 零点与星等换算（派生侧）

```text
mag      = ZP_syn − 2.5·log10 F_syn
ZP_syn   = median_i( magG_i + 2.5·log10 F_syn,i )      [mag]
m_5      = ZP − 2.5·log10 F_5
```

- 正本与推导：`frame_photometry_fit.h:132-133`（由 `mag = ZP_syn − 2.5 log10 F_syn` 取 `mag = magG` 反解）；
  实现 `.cpp:273` 逐符号照此式算、未写死数值。Pogson 系数 `2.5` 是星等标度定义常数。
- `m_5` 约定的正确锚：`lib/algorithms/noise_snr/cpp/src/snr_science.cpp:241`（`out->m5_mag = p->zero_point_mag − 2.5·log10(out->flux5_adu)`）、
  `:249`（注释式 `F_5 = 5·sigma_F(ref) [ADU]; m_5 = ZP − 2.5·log10(F_5) [mag]`）、`:261`；合同行 `docs/contracts/DATA_SEMANTICS.md:576`。
  （仓内注释里的 `snr_science.cpp:234` 是错锚，见 `01` 的 C13。）
- `ZP_syn` 的定性：它只依赖（滤镜, QE, 天区星族）而**与帧无关**，故在 `rc≠0`／NO_DATA 路径上不被清零属设计自洽；
  它是"星等 ↔ 合成通量"的换算锚，不是仪器参数反推的产物。
- 跨链对表（唯一换算式只写一次）：`F_ref,k = 10^(−0.4(m_ref − ZP_k))`（`m_ref = 6.0` 逐帧取）与 `k_photo` 是同一条换算的两端
  —— `F_ref` 由 `ZP` 从星等档反算回 ADU，`k_photo` 把 ADU 载到 `[F_syn]` 刻度；`m_ref` 与本链极限星等初值式里的裸 `6.0` 是两个不同角色（见 `01` 的 C10）。

### 式-7 `F_instr` 的口径（唯一许可的写法）

```text
F_instr = PSF 拟合域解析通量 = 2πA·s_x·s_y/3   （Moffat β=4，已扣独立局部背景）   [ADU]
```

- 正本：`docs/science/PSF.md:23,67,85`（"对任意 `sx,sy,θ` 成立"）＋ `docs/algorithms/STAR_PSF_ALGORITHMS.md:65`
  （导出式 `∫∫A/(1+Q)^4 = πA/(3√det M)`，`det M = 1/(4 s_x² s_y²)`）；`PHOTOMETRIC_FIT.md:232` 记为项目自定义解析积分（可用 SciPy/sympy 复算）。
- 禁止口径：检测域 `5×5` 盒和。禁令的量化依据（跟踪面标定件）：`seeing 2.0→4.0 px ⇒ 0.50 mag 假帧间差`、`孔径扫描 M_seeing 1.35 mag`，
  出自 `实验/absolute-snr/code/reverse_verify/f_instr/exp3_seeing_null.py:6-8`（判据：孔径无关口径 ≤0.010 mag ⇒ 绿；生产盒和口径 ≥0.200 mag ⇒ 必须 FAIL）。
  同一对数字在 `module_adapters.cpp:5323-5324` 复述。

### 式-8 稳健离群阈值与内点判据（可用于负例设计的闭式）

- Tukey 接受阈闭式：`|r − location| < c·S = 4.685 · MAD/0.6744897501960817 = 6.945 · MAD(r)`。
  由此可推出两条**恒成立的结构性事实**（本件据此设计夹具，不据此改判据）：
  ① `|r_consistent| = n ≥ 3` 时按 MAD 的半数性质必有 `|r_inliers| ≥ ⌈n/2⌉ ≥ 2` ⇒ 门 ② 的 else 分支在该调用面不可达（`01` 的 A3）；
  ② 构造"过预过滤但被 IRLS 拒"的离群星需同时满足 `2.5·Δdex < 3.0 mag`（不被预过滤）与 `Δdex ≫ 6.945·MAD`（必被拒），
    例如 `Δdex = 0.8 ⇒ Δmag = 2.0 < 3.0`，与 `c·S ≈ 0.069` 分离约 12 倍 —— 该构造已复算成立，是有锚的夹具设计式。
- 尺度扰动闭式：`±0.02` 均匀的逐星扰动给出 `MAD ≈ 0.01 ⇒ c·S ≈ 0.069 > |dev| ≤ 0.02` ⇒ 内点全收且 `S > 0`，
  这是"保证不落入 `S=0` 退化分支"的最小扰动幅推导（`通读-CR-02 §4 :143` 行）。
