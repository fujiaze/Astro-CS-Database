## 1. 复核口径（判据与纪律）

| 项 | 口径 |
|---|---|
| 独立性 | 复核者**不得**读原始通读成稿的结论段后再判断；先按本件的"复核要点"自行取证得出事实，再与本包现判比对。前一轮已实证"未溯源就照抄判语"会把错误一并继承（同一类常数在两份台账里各自判反过） |
| 取证方式分档 | ①**盲复算**：凡本包给出数值或不等式方向的（式子、常数、闭式、量级），复核者自己算一遍，不看前手脚本与结果件；②**重取锚**：凡本包引 `文件:行` 或条款号的，重新打开该位置逐字读，核"该行是否真的含该值/该式"；③**重走链**：凡本包给"触发路径逐跳"的，按跳重走一遍（每跳给命令与命中数），缺跳必须自己写明缺哪一跳；④**可达性复算**：判 S1/S2 的分界靠调用点计数，复核者自己跑 `git grep`/`git ls-files` 并记录检索式与命中数，不接受"看起来能到" |
| 判定三态 | `确认`＝事实、档位、触发路径三项均成立；`降级`＝事实成立但档位或范围要收（必须写收哪一档、为什么）；`推翻`＝事实或方向不成立（必须给反证行号与原文）。只有 `确认`/`降级` 进最终工单；`推翻` 项要同时回填到 `01`/`02`，防止后续节点重复上报 |
| 档位规则 | S1 要求"到产品字节的每一跳都有原文"；任一跳缺失即降 S2 并具名缺哪跳；仅注释/登记面失真为 S3；"待复测"与"不可复核"是**证据状态**不是档位，不得互相顶替 |
| 判据资格 | 复核任何"门有判别力"的结论时，必须自己构造一次"真值无效应"输入，看门是否归零或判红；恒真门一律判"无证据资格"（本包 N-24 的资格规则本身也在待核列表内） |
| 取证预算 | 单条 ≤5 条取证命令；命令一律带 `timeout`，日志落审查工作区（不落被审仓库）；只读，零 git 写、零 `git config` 写、不跑构建/ctest/任何 `eng/**` |
| 回填格式 | 每行补四格：`判定`／`复核者独立取到的事实（一句）`／`取证检索式与命中数`／`对本包措辞的修改建议`。缺格的行视为未复核 |
