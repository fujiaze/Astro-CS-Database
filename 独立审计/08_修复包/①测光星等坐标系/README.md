# 修复包 · ①测光星等坐标系

本目录是**给开发节点的一次性作业面**：缺陷、已确立的正本、修复顺序与验收判据、二次核对结果四件齐备，
修这一处不需要再回仓库重新推导。四件的作用固定：

| 文件 | 里面是什么 | 用来做什么 |
|---|---|---|
| `01_缺陷清单.md` | 逐条：编号／事实／档位／触发路径（到产品字节的逐跳）／取证成稿锚 | 看要改什么 |
| `02_已确立的算法与验证程序.md` | **已经核过的**式子、常数来源、独立验证程序与判据方向；含"核过为合规、不要动"的清单 | 照它实现，不要重推；也防止把对的一侧改错 |
| `03_修复顺序与验收判据.md` | 依赖排序的整改步骤；每条给"怎么算修好"的正例＋负例 | 提交前自证 |
| `04_二次核对.md` | 独立复核对每条的判定（确认／降级／推翻）与理由 | 决定进不进最终工单 |
| `05_正向规格.md` | 主程序要照它写的正向规格：科学量的定义／单位／坐标系／归一化／适用域／精度，常数的四档来源，不变量与「违反时报什么」，退化与未测的表示，生产入口与参数下发路径 | 不看缺陷清单也能写对 |
| `06_文档订正意见.md` | 文档不清或多说处的**可直接替换订正文本** | 文档侧一并收口 |

口径：本目录只写"现行要怎样"，不写日期、任务编号与过程流水。

> 本轮优先级：先程序科学性与正向规格；**门禁只记录不设计**（门禁按定稿后的正向规格另行独立制作）。
