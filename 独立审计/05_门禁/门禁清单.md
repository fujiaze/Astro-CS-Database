# 门禁清单（D7 三件之一）读者件

**正本数据是同名 CSV `门禁清单.csv`（64 数据行 × 13 列）**，本件只给它自己的读法、分母、口径与缺口，不复述行内容。逐条门的检验对象、命令、判据、正例、负例都在 CSV 里。

- 被审基线 HEAD=`c8f64e9a`；本节点为只读审查节点，未跑构建/ctest/门禁/端到端。
- 上位设计在《门禁体系设计.md》（层次、分档、触发、入口、fail-closed 语义、结果纪律），旧门逐项结论在《门禁现状与旧门禁处置.md》。三件互不重复正文：**判据正文只活在 CSV 一处**，设计与处置件引用门 ID，不抄判据。
- 复算脚本：`独立审计/复算件/xref/gate_list_stats.py`（分布与空列普查）、`gate_list_normalize.py`（主键规范化，附改前备份 `门禁清单.原样备份.csv`）、`gate_list_rows.py`（逐列抽样）。

## 1 列义（13 列）

| 列 | 含义 | 口径约束 |
|---|---|---|
| `名称` | **一行一个主键**。新门取 `GATE-*`；沿用既有门取其在册 ID；批量族行取 `BATCH-B<n>`；动作行取被点件的路径 | 规范化后主键零重复、零"一格两身份" |
| `处置` | 新增／改造／替换／拆分／合并／退役／保留／纳入注册／改名／定案／批量族 | 由原"名称行内括注"抽出成列，便于机器分拣 |
| `关联既有 ID` | 该行牵动的其它在册 ID（原来挤在名称格里用 `/` 分隔） | 一对多认领实测 **0** 个 |
| `检验对象（真实对象）` | 该门真读的对象（注册表字段、产物、文档表、磁盘件），不是它自述的范围 | 标准 05 §2：读不到真实对象即无资格 |
| `命令` | 复跑入口（含参数） | 3 行是"动作行"，该列为叙述并明写"不是命令" |
| `判据` | 判红的充要条件 | 只写现行要怎样 |
| `正例（正确实现下判绿）` / `负例（注入什么必红）` | 能绿能红的两边 | 缺任一边即该门无证据资格 |
| `层次与档位` | 六层之一 × quick/measure | 退役/拆分行取 `不适用（处置）` |
| `对应文档条款` | 该门承载的标准/规范条款 | 64 行**全部非空** |
| `是否替换现有门（被替换 ID）` | 与现状的映射 | 含"保留＋订正"类表述，不参与主键判定 |
| `落地成本档` | S/M/L | S 29／M 27／L 8 |
| `原名称（逐字留存）` | 规范化前的名称格原文 | 防止订正变成无痕改写 |

## 3 本件自己的缺口（登记，不静默丢弃）

1. **批量族 5 行的单元数不是划分，不得相加当总数。** 行内读数 116（ctest 目标族）＋45（unittest 族）＋183（单脚本直跑族）＋98（文档/一致性族）= 442，**大于注册表执行单元全集 370** ⇒ 族间必有交集（一条 `check_*.py` 单元既可归"单脚本直跑"又可归"读 docs"）。交集大小未登记，派工前须由开发节点按各族成员清单复算并回填一行"族间交集"。在此之前，任何"批量族覆盖 X% 单元"的表述都不成立。
2. **三行的负例列不出现"红"字样**：`GATE-ZERO-EFFECTIVE`（写作 `⇒ rc≠0`，语义等价、措辞不合本列口径）、`CHK-REGISTRY-DOC-SYNC`（退役行，明写"不适用"，合口径）、`CHK-SANITIZER`（须逐行确认是否真给了可注入样本）。前两条属表述归一问题，第三条属实质待核。
3. **三行的正例列不出现"绿"字样**：`GATE-ZERO-EFFECTIVE`、`CHK-REGISTRY-DOC-SYNC`、`CHK-FAILCLOSED-SURVEY`、`CHK-COVERAGE`（四行含上一行重叠）。同为表述口径，不改判据强度。
4. **主键为路径的 4 行是"动作行"不是门**（`check_p1_symbol_map.py`＋README §7 退役双删；三件孤儿检查器定案；`select_candidate.py` 纳入注册；三件 `check_*` 改名与补齐）。它们没有门 ID，落地后各自由其主门校验；按"门数"统计时必须排除（已含在 §2 的 57/64 口径差里）。
5. **全表口径依赖 `c8f64e9a` 的注册表现值**（370 单元、150 顶层项、`inputs` 10/370、`outputs` 空 157/370）。这些数来自 `独立审计/工具脚本/AUD-501/census*.py`，属第①层机械计数；其**逐条结论的复核态**在《门禁现状与旧门禁处置.md》文末登记，注册表若在上游漂移，本表 `判据` 里引用这些读数的行须整批复算。
