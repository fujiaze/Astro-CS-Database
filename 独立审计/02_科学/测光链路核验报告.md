**该链路在最高设计中的条款**：`ASTROCS_DESIGN.md` §2.1（创新点一：测光校准到星等坐标系）；
`:126`（`k_photo = 10^(−location)` 为线性标度，施加后仍是线性面亮度，星等只在派生/展示时换算、不落盘）、
`:127`（阶段二加性天光与逆方差加权必须消费线性数据）；
算法推导层 `docs/algorithms/PHOTOMETRIC_FIT.md`；星点定位侧 `docs/plugins/algorithms_phase1/03_star_detection.md`、
`docs/science/STAR_DETECTION.md`；Gaia 取谱侧 `docs/algorithms/GAIA_QUERY.md`。

**现行口径**（正本 = `docs/science/PHOTOMETRY.md`，条目号 SCI-PHOT-001，状态 FROZEN）：

```text
F_syn      = ∫ F_λ(λ)·T(λ)·Q(λ)·λ dλ                [W·m⁻²·nm]      §2a.1 / :44
             F_λ = byte·flux_mul + flux_min          [W·m⁻²·nm⁻¹]    XPSD 线性解码
             **不含** 10^(−0.4·G)                                       §2a.1 / :55
r_i        = log10(F_instr,i / F_syn,i)              [dex]           §5 / :197
delta_i    = −2.5·log10(F_instr,i) − G_Gaia,i        [mag]           §5 / :200
预过滤      |delta_i − median(delta)| > mag_tolerance(=3.0) ⇒ 拒       §5 / :202
IRLS/Tukey  S = MAD(r)/0.6744897501960817；u = (r−loc)/(c·S)，c = 4.685；
            w = (1−u²)² (|u|<1) 否则 0；loc ← Σw·r/Σw；≤50 步，tol 1e-6   §5 / :205-210
scale = k_photo = 10^(−location)   [F_syn 单位]/ADU；I_photo = k_photo·m(x,y)·I_cal  §5/:212, §16.1⑤
sigma_residual = MAD(r_inliers)/0.6744897501960817；sigma_mag = 2.5·sigma_residual  §5/:213-214
```

冻结门：`|r_consistent| ≥ 3` 才进 IRLS，否则 NO_DATA；`|r_inliers| ≥ 2` 才估 `sigma_residual`（§4/:191）。
生产积分核：`lib/algorithms/photometry/cpp/src/spectrum_integrator.cpp:350`（`weighted_wl = wl·filter_trans·q`）、
`:446-447`（`f = byte·flux_mul + flux_min`；`integrand = f·weighted_wl`）。

**符号、单位、坐标系与精度**

| 量 | 单位 | 归一化/坐标系 | 精度归属 | 有效域 |
|---|---|---|---|---|
| `F_λ` | W·m⁻²·nm⁻¹（能量谱辐照度，官方字段单位） | XP 采样网格 336–1020 nm @2 nm，343 点 | 采样表示层 | 官方声明的采样均值谱适用域 |
| `F_syn` | W·m⁻²·nm | 乘性通带 `T(λ)·Q(λ)·λ`；不含光学透过率与大气消光 | 与 `F_λ` 同级 | 模型通带内；不含带外色项 |
| `r_i`、`location`、`sigma_residual` | dex | 逐星对数比，无坐标系 | 标量（元数据侧） | 拟合用星集 |
| `sigma_mag` | mag | `2.5·sigma_residual` | 标量 | 同上 |
| `k_photo`、`m(x,y)` | 无量纲乘子（把 ADU 载到 `F_syn` 刻度） | 帧级标量 × 低阶空间多项式 | 稠密大面为 FP32，标量 FP64 | `max|log10 m| ≤ 1.0 dex` 硬界 |
| `I_photo` | `F_syn` 刻度、线性面亮度 | 像素域线性 | 稠密大面 FP32 | 阶段一产品面 |
| 零点换算 `mag = ZP_syn − 2.5·log10 F_syn` | mag | `ZP_syn = median_i(magG_i + 2.5·log10 F_syn,i)` | 标量 | 星等↔合成通量换算，非仪器参数反推 |

**本层对"λ 因子为何必须在"的独立复算口径**（先独立推导、后与正本比对，两路同值）：
探测器计量光子数，`dN_γ = F_λ·T·Q·(λ/hc)·dλ`，故 `F_syn ≡ hc·N_γ = ∫F_λ·T·Q·λ dλ`；
`hc = 1.98644586e−16 J·nm`；`λ` 恰进一次（与"能量通量"表述的比值 = 带内 `λ_eff`，实测 649.5），
不可多亦不可无；`1/(hc)` 与星无关，可被 `location` 吸收。绝对谱情形下星等因子进 **0 次**
（同温度、ΔG = 1 mag 两颗星的 `F_syn` 比值实测 `0.3981071705534978`，理论 `10^−0.4 = 0.3981071705534972`）。
`λ` 因子成立的**前提**是解码后的 `F_λ` 为能量谱辐照度；若容器给的是光子谱通量
（ph·s⁻¹·m⁻²·nm⁻¹），`λ` 必须去掉——该前提在正本里未被写成显式约束（见 §5 偏差 DEV-01、DEV-02）。

## 6. 诚实边界

**适用域**

- 本报告全部结论限定于：模型通带 = `T(λ)·Q(λ)·λ`，不含光学系统透过率与大气消光；XP 采样网格 336–1020 nm @2 nm；
  参考星 `G ≲ 15`（采样表示官方口径）／本仓实测一致性到 `G ≲ 18`；
  E12/E10 类结论的样本为 n=1050、`G∈[10.15,15.00]`、`BP−RP∈[0.124,7.311]`，不外推到其它通带或窄带。
- 凡引"色项幅度"必须同时给通带与 SED 族：官方 G 通带与生产相机通带相差 19 倍（`0.2708` vs `0.0145 mag`），
  样本色跨（p5–p95 = 0.833…4.984）比黑体网格可达色跨（≤1.62）更红，把两者直接相除不构成任何裕度。
- 本报告不主张 XPSD 容器单位约定已被判定；主张的是"该判定目前无仓库内证据"。

**反例与已知偏差方向**

- 单位约定误取（能量↔光子互换）的可判别量是 **≈7 mag 的整体平移**（我算得 G 带 −6.86…−7.13、
  RP 带 −7.19…−7.25、生产带 −7.009…−7.023 mag），不是色项；能担事的锚是容器解码谱上的 `median(m_syn−G)`，
  其证据件不入库 ⇒ 不可复核。
- 色项型缺陷（`λ` 单位误取）在生产通带下的变化部分仅 `0.0131–0.0145 mag` 量级 ⇒ 即使发生也被零点大部分吸收，
  剩余部分只在色轴显形；现行锚不看色轴。
- `sigma_residual = 0` 的虚报方向 = "标定完美"（假绿），不是 fail-closed。
- 死键的后果方向 = 文档让人以为可配，实际改配置不改任何计算。

**未验证部分**

## 7. 结论

- **成立**（口径正确、无需订正公式）：
  ①`F_syn` 不含 `10^(−0.4·G)`、`λ` 因子恰进一次的现行正本口径（E1＋E2＋E10 三路同向）；
  ②量纲链闭合与线性数据形态——`k_photo` 全程线性乘性、像素恒为线性面亮度、星等只在派生侧换算（§4 第 1 行）；
  ③物理闭合（无任何一处用标定系数反推增益/口径/曝光），但其"负例拦截"缺机器门，登记为判据空档；
  ④稳健常数 `0.6744897501960817`/`4.685` 的**数值**（独立推导复现，1 ulp 与 `eff=0.95000`）。
- **不成立，须订正（根因＋订正见 §5）**：
  常数溯源面（DEV-05/DEV-06，1 条登记即错＋4 条锚漂移＋两条门空转）；
  `sigma_residual` 的假绿表示与门（DEV-07/DEV-08）；
  非正本通量式的残留与虚报可达（DEV-04）；
  绝对刻度锚的证据资格范围被说过（DEV-02/DEV-03）；
  以及 DEV-09…DEV-16 各条文档/登记缺口。
- **证据不足，列入 UNRESOLVED**：XPSD 容器单位约定与绝对刻度、D1 物理仿真与端到端读数、
  质心门现状、`c=4.685` 的书目侧、色项阈值推导、真实帧零离散度概率。
- **按三类数据相互佐证的口径判定**：②代数合成与③真实归档对拍两路只支撑到"积分核与实现忠实性"；
  ①物理仿真档未复算、③生产端到端读数不可复核 ⇒ **本链路未达 standard 02 §2 的三方一致**，
  链路成立性目前只由"代数合成 ＋ 一手官方文档 ＋ 只读代码事实"支撑，端到端项全部以**需复测**结转到下一轮。
