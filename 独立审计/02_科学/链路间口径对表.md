# 四条科学链路共享量口径对表

本表把四份核验报告里**被多条链路共享的量**并列到一张面上，逐格判定"一致／措辞差异／真互斥"，
并指出该分歧落在哪几处。判定的落点一律给文件:行或正本合同条款；每条读数保留其**入库状态**。

**三态定义**

| 态 | 含义 | 处置 |
|---|---|---|
| 一致 | 各报告口径同一，可互相引用 | 无需动作 |
| 措辞差异 | 指称、记法或限定语的宽窄不同，所指为同一对象/同一结论 | 批量订正，不占裁决额度 |
| 真互斥 | 对同一量给出不能同时成立的取值、分母、语义或资格 | 须一次定案（改文档或改实现，二选一，不得并存） |

入库标记沿用四份报告：**入库**／**包内复算件**／**不可复核**（原始产物在 `run/*`，跟踪面无副本）／**需复测**。

## 2. 方差组成：四张不同的"variance"

四条链路各自消费的方差面互不相同，且历史上被同一词"variance/ivar"混指。

| 面 | 定义 | 生产者 | 合法用途 | 出处 | 入库 |
|---|---|---|---|---|---|
| `σ_bg²`（背景方差面 = 产品 `variance`） | 星点掩膜外 patch 的 blank-sky 稳健方差，场式 `var(x,y)=a+b·x+c·y`，**按构造不含源项** | `module_adapters.cpp:8100,:8155` ← `snr_noise_model_v1_fill`；`snr_estimator.h:116` 头注 | 天光建模与 UPM 控制点拟合的权重（该样本集只取掩膜外 ⇒ 其总方差即 `σ_bg²`）、误差报告与诊断、背景受限域的叠加权**近似** | `NOISE_MODEL.md:328`（句内有歧义，见下） | 入库 |
| `σ_w²`（加权方差面） | `σ_bg² + S_src/g`，`S_src = Σ F̂_i P_i` | **未实现为独立产品面** | 阶段二逐像素**科学权重**的唯一来源 | `NOISE_MODEL.md §5c`；`ASTROCS_DESIGN.md:171-174` | 入库（条款）／面无产品 |
| `σ_i²`（逐像素噪声组合） | `σ_sky,i² + (RN/g)² + F·P_i/g`，**读噪只出现一次** | `snr_science.cpp:200-202`（受 `:177` 的 `sigma_sky_source` 门控） | `σ_F = (ΣP²/σ²)^(−1/2)` 的求值 | `NOISE_MODEL.md:324`；`07_noise_snr.md:110` | 入库 |
| `cvar`/`civar`（控制点方差） | `kcorr_f·(π/2)·σ²/n_ret`，σ 来自 patch MAD×1.4826… | `sampler.cpp:872-877`（第二处同族 `sky_plane.cpp:296,:306-307`） | UPM 观测权 `raw = qf·civ`（`upm.cpp:1980-1987`） | `PHASE2_UPM.md:84-85` | 入库 |

| 判定 | 内容 |
|---|---|
| **真互斥（指称）** | `NOISE_MODEL.md:9`（§1 目的句）与 `:328`（§11）把 `σ_bg²` 的倒数**命名为"Phase2 逐像素科学权重"**，与 `ASTROCS_DESIGN.md:156-158,:171-174`、`CONTROL_WEIGHT_SNR.md §2a/§8c`、以及 `NOISE_MODEL.md` 自己 §5b/§5c/§10 的实质条款互斥。裁决：**不是两篇打架**——越界只在指称、不在数学；`ivar` 对 UPM 拟合样本集是正确权重（`PHASE2_UPM.md:21,:76`）。订正 = 给两句补适用域（见《SNR》DEV-10 的可替换文案），**不上呈裁决** |
| **真互斥（取值）** | 现状 `w(x,y) = 1/σ_bg²`（`module_adapters.cpp:11936`，赋值即权重、无 `SNR²/F_ref²` 换算步骤）vs 应为 `1/σ_w²` ⇒ 亮源过权 `R = 1 + S_src/(g·σ_bg²)`（F=10³→×7.6、F=10⁶→×6.6e3 @σ_bg=5,g=1.3，**包内复算件**），且 mosaic `variance = 1/W` 使误差棒偏小 1–3 个数量级（F=10³→1.83/4.32 倍，F=10⁶→831/3323 倍）。产品面实况需 R-1 复测 |
| **措辞差异** | 天光无缝报告把 `civar` 归为"控制点逆方差"、SNR 报告把 `ivar` 归为"背景面逆方差"：二者是同一族 patch-MAD 方差在**不同消费者**上的两份实例，不是同一张面 ⇒ 记法上须区分 `control_ivar`（稀疏控制点）与 `ivar`（稠密背景面），正本已有此分（`PHASE2_UPM.md:21` vs `DATA_SEMANTICS §30.1`），文档引用时不得互换 |
| 共同缺陷（零/退化表示） | `cvar` 与 `sigma_residual` 都把"不可估计/无信息"编码成**有限值**：前者 `1e-12` 钳位 ⇒ `civar = 1.314165e+26`（闭式复刻，**包内复算件**；文档登记值 `7.609e−27/1.314e26`，原始件在 `run/` ⇒ **不可复核**）；后者 `sigma_residual = 0.0`。两处都需要"具面值哨兵＋下界/退化侧守卫"，修法同族 ⇒ **建议合案**（一个工单，两处代码：`sampler.cpp:863-877`＋`sky_plane.cpp:296/306-307`；`star_matcher.cpp:615-621`＋`module_adapters.cpp:5747`＋`orchestrator.cpp:3030`） |

| 因子 | 表达式 | 数值/幂次 | 出处 | 跨链关系 |
