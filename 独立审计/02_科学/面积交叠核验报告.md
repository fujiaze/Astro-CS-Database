**HEALPix 基面 chart（设计主张层，非生产路径）**：`实验/healpix-polar/code/polar_common.h:136-196`
（`chart_uv_to_ang`，face 0–3 北、4–7 赤道、8–11 南，`z = sin dec`）

```text
赤道支（|z| ≤ 2/3）：z = (2/3)(u+v−1)，phi = (π/4)(u−v+2(f−4))
                     ⇒ |d(z,phi)/d(u,v)| = |det[[2/3,2/3],[π/4,−π/4]]| = π/3   （常数）
极冠支（face 0–3 的 u+v>1）：s = 2−u−v，z = 1−s²/3，phi = (π/2)f + π(1−v)/(2s)
                     ⇒ |J| = (2s/3)(π/2)[(1−u)+(1−v)]/s² = (2s/3)(π/2)·s/s² = π/3   （常数）
⇒ 两支各自 |J| = π/3 严格成立；dΩ = |dz dφ| 与 |dΩ/du dv| = |J| 恒等 ⇒ 12 个单位方格面各面积 π/3，
  12·(π/3) = 4π 闭合；叶 = 1/N² 方格 ⇒ 叶面积 π/(3N²) = 4π/(12N²)（与等面积式一致）。
唯一失效点：极点 s = 0（chart 的 (1,1)/(0,0)），phi ~ 1/s 发散 ⇒ 方向折叠点，不是坐标可逆点；
  这是设计 §2.4 奇点条款①的解析落点，**不是**面积口径失效（|J| 表达式不含 1/s）。
```

**生产实现口径**（与 chart 无关；`astro_sphere_sink.h:38-52`、`drizzle_engine.cpp:1610-1650`）：

```text
w_jp    = a_jp / A_drop,j                       （drizzle_engine.cpp:1617；DISP-DRZ-009 正向）
N_p     = sumNorm = Σ_j w_jp · A_pixel,j         （:1644  sumNorm += overlap_area·(pixel_area/drop_area)）
D_p     = sumArea = Σ_j a_jp                     （:1639-1641）
S_p     = F_p / N_p                              （发布面亮度；docs/science/DRIZZLE.md §5:50,§5:83 冻结）
k       = D_p / N_p = pixfrac²·(1+⟨δ⟩)           （发布折算因子；⟨δ⟩ 见 DEV-09）
variance_p = sumVarNum / N_p²                     （:1646-1650  sumVarNum += v·weight²）
叶面积分母（发布 support）A_cell = 4π/(12·nside²) （astro_sphere_sink.cpp:330-332；aio_hips_writer.cpp:1212）
```

**每个科学量的五件事**

| 量 | 单位 | 归一化/坐标系 | 精度归属 | 有效域 |
|---|---|---|---|---|
| `a_jp` | sr（绝对立体角） | 球面多边形面积 × 核权 | 稠密大面 FP32 累加、FP64 求值 | 弦四边形表示（生产现状，见 DEV-05） |
| `A_drop` | sr | `pf²·A_pixel·(1+δ)` | 同上 | 平面 drizzle 的 drop 足迹 |
| `w_jp` | 无量纲 | **按 drop 面积归一** ⇒ `Σ_p w_jp = 1` | 同上 | 等价参数化须同时换分母（DEV-09） |
| `N_p`、`D_p` | sr、无量纲 | 见上式 | 同上 | `sumNorm ≤ 0 ⇒ k = 1.0` 回退分支存在且未被任何门取样 |
| `S_p` | 面亮度（ADU·sr⁻¹ 侧） | `F_p/N_p` | 稠密 FP32 | 幂次守恒：signal +1、variance +2 |
| `support` | 无量纲 | `D_p/A_cell`，u8 量化在 `hips_profile=1` | u8 | 低 support 侧会归零（DEV-11） |
| `δ` | 无量纲 | 每源球面残差，按 `a_jp` 加权 | 标量 | 分支由 `max_angle < 1e-3 rad`（=206.3″）决定（DEV-09） |

## 6. 诚实边界

**适用域**

- 本报告一切数字属**几何/算术层**（球面多边形面积、chart 映射、量化映射），与观测条件、波长、噪声模型无关；
  不涉及 SNR 定权语义与 UPM 求解，但 DEV-09/11/12 已登记为与权重/variance 链的**接线一致性**缺陷。
- 逐叶误差与矢高是"全格点扫 nside=16…1024"的实测；量化界是确定性映射的全枚举；两者均不含 C++ 实现。
  ⇒ 生产 `compute_overlap_area_*` 的行为只由调用点行号证实，其数值需 R1 复测。
- chart 侧的 seam 数字（8.5e−6、2.7% 错配）依赖特定实现选择，**只作量级不作定值**（本报告不将其登记为几何性质）。
- θ≲10″ 的 `δ` 在双精度下**测不出**（噪声地板 ~1e−7 ≫ δ），该域文档值只能视为解析式外推。

**反例与已知偏差方向**

- 弦四边形面积在极点/face 角点邻域**系统性偏小**（−9.97%），若干极冠叶偏大（最正 +0.61%），全天空求和恰为 4π（互相补偿）
  ⇒ 表现为"通量在相邻叶之间错分"，不表现为总通量漂移；常量面亮度场的 `S_p` 不受影响。
- **不成立的推论（明确登记）**：本报告**不**得出"生产产品光度零点有 10% 误差"——`S_p` 在常量场下分子分母同源相消；

## 7. 结论

- **成立**：chart 前提中等面积与轴对齐部分——12 面单位正方形等面积、`|J| = π/3` 为解析恒等（两支各自成立）、
  叶在 chart 内轴对齐且与标准 HEALPix 布局双射（3072/3072，第三方库互证）；极点只是方向折叠点、非面积口径失效；
  `Σ_p a_jp = (π/3)|D∩face|` 作为**完备性/全局标度**判据有效；`k = D_p/N_p` 与幂次守恒（+1/+2、−2/−4/+4）自洽且实测成立；
  核按 drop 归一的实现口径正确且发布量对该参数化不变；加速比陈述方式合规。
- **不成立，须订正**：把"构造闭合 1e−15"当逐叶正确性证据（DEV-07/DEV-08）；生产 leaf 的弦表示违反冻结 arc-chord 预算
  2–5 个数量级且为全天空现象（DEV-05）；support 的分子分母不同源（DEV-06）；三处文档对核权重分母与代码相反（DEV-09）；
  两 profile 末端不等价、量化界 `0.5/q`、NaN 档与过覆盖档无 provenance 计数（DEV-11）；pixfrac 门的 parity 失明
  与"无在册逐叶门"（DEV-12）；chart 路径未落地却被写成已落地（DEV-01）；`a_jp/A_pixel` 与 `δ` 的适用域、
  "零超越"作用域、注释与调用点相反等（DEV-02/03/04/10）。
- **降级后仅以收窄范围成立**：chart 缝位形的 8.5e−6 平台（DEV-13）——不得作为几何事实登记。
- **证据不足，列入 UNRESOLVED**：见 §6 末表。
- **按三重数据佐证判定**：本链路目前**只由"②代数合成（两路异源实现）＋一手文献的书目/摘要层＋只读代码事实"支撑**；
  ①物理仿真与③真实数据端到端**未做** ⇒ 按 standard 02 §2 **未达三方一致**。
  可写入论文的边界：只可主张"该分配格式在全天求和意义上精确守恒（残差 0.0，属构造性质而非验证结果）"；
  在异源逐叶 oracle 落地前，**不得**把"构造闭合 1e−15"写成面积分配正确性的证据，也**不得**主张"逐叶面积精确"。
