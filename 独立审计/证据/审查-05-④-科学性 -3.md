## 2. 幻觉锚对抗（逐条）

### FINDING-09: `gnomonic_budget_rho_max = 2e−3 rad` 系数错 3 倍且符号说反

05§11 表中该预算引用来源档 `p1drz_geom.hpp:150-151`，并在 05§8.1 表中用于 gnomonic 型原语容差档。

**三腿核查**：
1. **文献值腿**：`p1drz_geom.hpp:150-151` 注释写着"适用 θ ≲ 2e−3 rad，相对误差 ~ρ²/2 ≈ 2e−6"。**但该系数错 3 倍且无方向**：真值应为 `+3ρ²/2`（平面高估球面），ρ=2e−3 ⇒ 6e−6，而非 2e−6。**→ 文献值腿无效**。
2. **实验标定腿**：`02 §3.5` 第 335–342 行给出 gnomonic 中心投影的面积元预算，明确相对误差 = **+3ρ²/2**（平面系统性高估球面），能力上限 ≈ 1e−5 相对 @ nside=512。这是独立核算结果，**但仍未以独立实验单元件形式呈现**。→ **实验腿不完整**。
3. **理论推导腿**：应引 `02 §3.5` 第 338–340 行的推导（dA_plane = dA_sphere / cos³ρ），05 仅在§8.1 简略提及且系数错误。**→ 理论链断裂且系数错误**。

**订正意见（可直接粘贴替换 05§11 对应行及 05§8.1 容差档表第一行）**：
> "`gnomonic_budget_rho_max = 2e−3 rad` 为平面 gnomonic 型原语的适用角距上界。其面积元预算见 `02_已确立的算法与验证程序.md §3.5` 第 335–342 行：相对误差 = **+3ρ²/2**（平面高估球面），ρ=2e−3 ⇒ **6e−6**（而非注释所写的 2e−6，系数错 3 倍且缺符号）。能力上限 ≈ 1e−5 相对 @ nside=512。建议将该预算写入合同面（GATES_AND_TOLERANCES 或 DRIZZLE_GEOMETRY §9），并注明其为单向偏差（平面高估）。"

### FINDING-10: `max_angular_radius_for_tan = 1e−3 rad` 缺少单向偏差说明

05§11 表中该阈值引用来源档 `spherical_overlap.cpp:998`，并在 05§2.4 与 05§3.1 中作为切平面/球面分支判阈。

**三腿核查**：
1. **文献值腿**：该值为实现硬编码分支判阈，**无需外部文献**；但 05 未说明"为何选 1e−3 rad"。**→ 例外理由缺失**。
2. **实验标定腿**：`02 §3.5` 第 325–333 行给出了切平面支 vs 球面支的单向偏差律 `|planar/spherical − 1| = θ²/2`，且为**单向下偏**（平面低估球面？需核实原文）。θ = 1e−3 ⇒ −5.000e−7。这是独立核算结果，**但仍未以独立实验单元件形式呈现**。→ **实验腿不完整**。
3. **理论推导腿**：应引 `02 §3.5` 第 328–330 行的推导，05 仅在§11 表中简略提及且未说明单向性。**→ 理论链断裂**。

**订正意见（可直接粘贴替换 05§11 对应行及 05§2.4 相关段落）**：
> "`max_angular_radius_for_tan = 1e−3 rad = 206.26″` 为切平面/球面分支判阈（实现见 spherical_overlap.cpp:998）。其面积元预算见 `02_已确立的算法与验证程序.md §3.5` 第 325–333 行：相对偏差律 `|planar/spherical − 1| = θ²/2`，且为**单向下偏**（θ = 1e−3 ⇒ −5.000e−7；注释里的"< 4e−8"与"对称 ×(1+O(θ²))"两句都错：真实值 5.0e−7，差 12.5 倍且单向）。建议将该单向偏差登记进合同面（KNOWN_LIMITATIONS 或 GATES_AND_TOLERANCES）。"
