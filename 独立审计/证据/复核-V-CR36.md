# 1 复算① · CR-36-01：4 角大圆弧四边形面积 vs 像元真实球面面积

## 1.1 我的定义与式子

**(a) 环序角点（我自己的转写，来源＝公开定义，不来自仓库代码）**

电平（Górski–Hivon–Wand 2005 的 HEALPix 环序标准式，即任务书提示的 `cosθ = 1 − i²/(3n²)` 一族），j = 0…4n：

```
北极冠 1 ≤ j ≤ n      : z_j = 1 − j²/(3 n²)
赤道带 n < j < 3n     : z_j = (4/3)(1 − j/(2n)) = 2(2n−j)/(3n)
南极冠 3n ≤ j ≤ 4n−1  : z_j = −1 + (4n−j)²/(3 n²)
端点                 : z_0 = +1（北极）, z_{4n} = −1（南极）
每环像元数 S_j = 4j (j≤n) / 4n (n<j<3n) / 4(4n−j) (j≥3n)   ⇒ Σ S_j = 12 n²
```

顶点网格：第 k 电平的方位格点间距 `w_k = 2π/S_k`，偏移 `o_k = 0`（冠区）／`o_k = 0 (k 偶)、w_k/2 (k 奇)`（赤道带）。像元 (j,m) 的中心 `φ_c = o_j + (m+½)w_j`，四角（循环序 N,L,S,R）：

```
N = ( 电平 j−1 网格上离 φ_c 最近的格点 , z_{j−1} )
L = ( φ_c − w_j/2 , z_j )      R = ( φ_c + w_j/2 , z_j )
S = ( 电平 j+1 网格上离 φ_c 最近的格点 , z_{j+1} )
```

即"上下顶点是与上/下邻格共用的那个格点"。⇒ 冠区像元交替出现一条子午线边（N–L 或 N–R），赤道带像元是关于 φ_c 对称的菱形，北极恰被 4 个像元以一角占据（j=1 的 N 顶点 z₀=+1 即北极）。（我第一次转写把朝极/朝赤道顶点写成"φ_c 与 φ_c±w/2 按 m 奇偶交替"，在 n=2 上恰好正确、n≥4 即错——被 §1.3 的 `Σ=4π` 自检抓出，改为上述"最近格点"式后全 nside 通过。）

**(b) 像元真实球面面积（解析，极冠内按环求差）**

单位球上 `dA = dφ dz`（z=cosθ）⇒ 球面面积＝该像元在 (φ,z) 平面足迹的面积。带界由"自上极累计等面积"定：`z_bd(j) = 1 − j(j+1)/(3n²)`（冠区），故环 j 带宽 `Δz_j = 2j/(3n²)`、带面积 `2π Δz_j`、单格

```
A_true(环 j) = 2π·Δz_j / S_j = 2π(2j/3n²)/(4j) = π/(3 n²)     （赤道带 Δz=2/(3n)、S=4n ⇒ 同值）
```

我程序里对每一环独立算了这个值并与 `π/(3n²)` 比较：最大偏差 **≤3.6e-12 相对（n=256）** ⇒ 解析真面积与"等面积构造"闭合 ✓（`s1.py` 的 `按环求差解析面积 vs π/(3n²) 最大偏差`）。

**(c) 两套独立的球面多边形面积式（互校）**

l'Huilier：三角形边用大圆弧长 `a = atan2(|b×c|, b·c)`，`tan(E/4) = √[tan(s/2)tan((s−a)/2)tan((s−b)/2)tan((s−c)/2)]`；四边形 = `(v0v1v2)+(v0v2v3)`。
Van Oosterom & Stricker：`Ω_tri = 2·atan2(a·(b×c), 1 + a·b + b·c + c·a)`，扇形有符号累加后整体取 `|·|`。
两者我都独立实现（`hpx_ring.py`），逐像元互校：

| nside | max\|A_lh − A_vos\|/A |
|---|---|
| 2 / 4 / 8 / 16 | 1.5e-15 / 1.8e-15 / 3.0e-15 / 8.6e-15 |
| 32 / 64 / 128 / 256 | 4.5e-14 / 1.7e-13 / 7.2e-13 / **3.3e-12** |

⇒ 两套式在所有 12·nside² 个像元上一致到 ≤3.3e-12 ⇒ 下面任一式的结论都不依赖实现选择 ✓

## 2.2 我的推导（可复核代数式）

记 `c_jp = a_jp / A_drop,j ≥ 0`，`δ_j = A_test,j/A_prod,j − 1`。由 `x_j = B0·A_test,j`：

```
S_p/B0 = Σ_j A_test,j c_jp / Σ_j A_prod,j c_jp
       = Σ_j A_prod,j(1+δ_j) c_jp / Σ_j A_prod,j c_jp
       = 1 + [ Σ_j (A_prod,j c_jp) δ_j ] / [ Σ_j (A_prod,j c_jp) ]            … (★)
```

即 **S_p/B0 − 1 是 δ_j 的加权平均，权 `A_prod,j·c_jp` 为正** ⇒

```
min_j δ_j  ≤  S_p/B0 − 1  ≤  max_j δ_j        （对一切 {a_jp} 与任意逐对缩放 a_jp → λ_jp a_jp，λ_jp>0）  … (■)
```

两点推论：

1. **δ_j ≡ 0（两式同形且同输入 ⇒ 逐位相同）时，(★) 恒等于 1**：任意逐对缩放、整体错 10%、按 CR-36-01 把含极 leaf 的 a_jp 乘 0.9003、整批候选置零（只要 leaf 非空且和有限），`S_p/B0 − 1` **精确为 0**。此时 P 判据的字面不变性成立（不只是"量级小"）。
2. δ_j ≠ 0 时，判据的**可达集合**被 (■) 夹在 `[min δ_j, max δ_j]` 内——这个区间只由"夹具面积式 vs 生产面积式"之差给出，与 a_jp 的**任何**数值无关；a_jp 只能在区间内选点。要判红需 `max|δ_j| ≥ 1e-3`。

注意 `A_drop,j` 同现于分子与分母的同一个权 `c_jp` ⇒ 它逐对相消，不进 δ_j；所以"生产侧 drop 面积走了另一个分支"（CR-36-16 的混模带）**不会**打开 a_jp 的通道。能打开的只有：分母口径被换（历史缺陷 `S_p=B0/pf²`）、`sumNorm` 不再含 `A_prod,j`、非有限/空集合（`gate:102-105` 确实能红）。
