### CR-39-1.1 · 反向用例把 `sumFlux`（通量口径）当 `leaf_signal` 喂入，而被测实现与合同要求的是面亮度 `S_p=sumFlux/sumNorm` ⇒ 该文件两条核心期望值（均值=1000、Σout=Σin）在现实现下数学上不可能成立
- 轴：C（上下级一致）为主，兼 D
- 位点：`reverse_drizzle_test.cpp:56` `sig.push_back((double)t.pixels[local].sumFlux);`
- 上位依据：
  - `drizzle_engine.h:70-74`：`sumFlux = Σ_j x_j·w_jp ⇒ Σ_p sumFlux_p = Σ_j x_j（与 pixfrac 无关）`，并另列 `sumNorm = Σ_j w_jp·A_pixel,j（面亮度归一分母 ⇒ S_p = sumFlux/sumNorm = Σ_j B_j a_jp / Σ_j a_jp，与 pixfrac 无关）`；
  - `reverse_drizzle.cpp:218-219`（被测侧契约）：`// 面亮度加权平均：分子 Σ B_j·a_jp、分母 Σ a_jp（契约 DATA_SEMANTICS §11.2）。禁用 ov/drop_area 归一——那是 a_jp/A_drop,j，输出会随源 nside 变化而非面亮度。`
  - `tests/CMakeLists.txt:291-295`（DRZ-PF-CORRECT-01）：「已把 oracle 期望式改为科学正本口径（S_p=sumFlux/sumNorm、var_p=sumVarNum/sumNorm²；docs/science/DRIZZLE.md §5:50/83）」。
- 现状：测试自建正向 `forward()` 后取 `sumFlux` 原值作 `rin.leaf_signal`；反向实现把它当 `B_j` 做面积加权平均（`reverse_drizzle.cpp:235 s = acc.signal/acc.weight`）。
- 差在哪：反向算子对**常值场**是保值的（所有 s_p 相等 ⇒ out=s_p），所以 `out ≈ sumFlux 的局部均值`；而对 6.3″/px 图幅与 nside=65536（hp 像元 3.22″）这一组合，均匀场 x=1000 的 `sumFlux_p = x·A_hp/A_img = 1000·0.261`，于是 `mean ≈ 261`、`Σout ≈ 0.261·F`。这正是 `reverse_drizzle.cpp:219` 明令**禁用**的旧 `ov/drop_area` 口径下才会得到的期望（旧口径下 out=B=1000、Σout=F）——即该测试的期望值仍钉在改口径之前的行为上。
- 后果：该文件 5 条断言里 `[:98]` 均匀恢复与 `[:137]` 通量闭合两条为红；文件头自称的「Sphere → Plane 真面积 Drizzle 验证（通量闭合）」四项主张中两项不成立。因该 exe 只 `add_executable` 未 `add_test`（`tests/CMakeLists.txt:171` 在 `DRZ_EXTRA_TESTS` 段，段注 :154-156 明确「只编入不注册」），红灯从不暴露 ⇒ 掩盖的是「反向面亮度口径变更已贯穿全部消费方」这一主张。
- 定级：S2（缺运行时触发路径：生产反向入口 `lib/algorithms/drizzle/src/module_entry.cpp:1188` 的 `leaf_signal` 来自 manifest `leaf_signal_base64`，与本测试无关，故不牵动产物字节；且本件不在任何门内）
- 怎么算修好：`forward()` 改取 `sumFlux/sumNorm`（同批必须一起改：`:98` 的期望均值仍是 1000、`:137` 的 Σ 闭合在 A_img=1 单位下仍成立，无需调阈值）；若 `sumNorm==0` 需显式跳过而非产出 inf；改完把该 exe 注册进 ctest（或明确删除并说明由 `reverse_drizzle_science_test` 覆盖），否则修了也没人跑。
- 置信：PARTIAL（定义层冲突为 CONFIRMED：两侧口径原文均已逐字核对；数值后果 0.261 为解析推得 r=4π/(12·nside²)/(6.3″)²，缺实跑确认——本批纪律禁止构建/运行）

### CR-39-1.2 · `[FP32 vs FP64]` 那条判据在数学上恒真，且真实 FP32 累加器分支一次都没被走到
- 轴：R（运行时正确）为主，兼 D
- 位点：`reverse_drizzle_test.cpp:151-161`
  ```
  rin.output_fp64 = false;  ReverseDrizzleOutput rout32;  rdz.run(rin, rout32, err);
  double r = std::fabs((double)rout32.signal_f32[i] - rout.signal[i]) / std::max(std::fabs(rout.signal[i]), 1.0);
  CHECK(max_rel < 1e-5, msg);
  ```
- 上位依据：`reverse_drizzle.h:13`「FP32 输入→FP32 输出使用真实 float 累计器 (非 double 伪装)」；`DRIZZLE_GEOMETRY.md:307`「FP32/FP64 逐 leaf <1e-5」。
- 现状：`rin.leaf_signal`（f64）非空、`leaf_signal_f32` 全程为空 ⇒ `reverse_drizzle.cpp:369 const bool true_fp32 = has_f32 && !in.output_fp64;` 为 false ⇒ 两次 run 都走 `run_typed<double>`；两次输出同值 `s`，`signal_f32[i]=(float)s`（`reverse_drizzle.cpp:244`）。
- 差在哪：不等式方向已钉死——`|(float)s − s| ≤ 2^-24·|s|`，而分母 `max(|s|,1.0) ≥ |s|` ⇒ `r ≤ 2^-24 = 5.96e-8 < 1e-5` 对**任意**输入、任意实现都成立，与 `ReverseDrizzle` 是否正确无关；这是一条恒真断言（派单 §2 轴 R 的「恒真断言」形态）。同时 `run_typed<float>`（真 float 累加）在本文件覆盖为零。
- 后果：文件头主张 3)「FP32/FP64 输出一致性」为空背书；float 累加路径若发生精度崩塌/溢出/NaN，本判据依然绿。
- 定级：S2（缺生产触发路径；本件不在门内。若被注册并当门引用则升 S1）
- 怎么算修好：改 `rin.leaf_signal_f32.assign(...)` 且清空 `leaf_signal` 以真正走 `run_typed<float>`；分母改为全图 `max|signal|`（或 `max(|v|, 1e-3·vmax)`）使「相对差」名副其实；`1e-5` 阈值保持不变（float 累加噪声确需该量级）。
- 置信：CONFIRMED（判据恒真由浮点定义复算得，不依赖实跑）

### CR-39-3.1 · 注册门的极区用例（4.3）用的是几何上无效的 drop：`half_ra=286.5°` 绕极点多圈、`dec+half=90.04°` 越出定义域，而该组判据只判「面积>0 且有限」⇒ 极区面积数值正确性在门内不可红
- 轴：R 为主，兼 S

- 上位依据：`docs/algorithms/DRIZZLE_GEOMETRY.md §9:317`「负面矩阵: §5 表逐行断言（…）**极区**…」；§5 表与 `:113-114` 的候选缓冲预算都以 `hp_res` 为尺度；DEC 域锚 `reverse_drizzle.cpp:293-295`「`crval[1] < -90.0 || crval[1] > 90.0` → 硬失败」。
- 现状：`makeRectDrop` 用 flat-sky 近似 `ΔRA = size/cos(dec)` 构造四角。dec=89.99° ⇒ cos=1.7453e-4，half=0.05 ⇒ `half_ra = 286.5°`（总 RA 跨度 573°，>1 整圈），且 `dec+half = 90.04°`。四个顶点因此绕极点在 RA 上转 1.6 圈并有一个顶点越过极点；本组对该多边形只判 `area>0`、`isfinite`，以及「候选非空 / 全部重叠有限」。极区另外两组的求和判据容差为 10%（:326/:346）。
- 差在哪：判据方向钉死——无效几何仍产出正的有限面积 ⇒ 断言为真；而真实极区面积误差（例如 `cos(dec)` 因子漏乘、RA wrap 处理错）只改变数值大小，`>0 ∧ finite ∧ Σ≈A_drop(±10%)` 三条对它**没有任何一侧敏感**（误差 10% 以内 ⇒ 绿；超 10% ⇒ 红，但 4.3 连求和判据都没有）。守卫阈值 1e-10 与失效点 2.8e-4 差 6 个数量级，形同无守卫。
- 后果：`drizzle_spherical_overlap` 是**在册门**，其对外主张「极区测试: 源像素在极区附近不产生异常」（本文件头 :8）与 §9 负面矩阵的极区行，实际由一个自造无效几何 + 只判正/有限的断言支撑；生产 mosaic 在高赤纬帧上的逐格交叠面积若出错，本门不会红。
