### AUD203-03 control_ivar 零尺度伪方差未修（内容 c，缺陷）——σ_bg=0 仍发布有限大 ivar，违反设计禁令

- `对象`：`sampler.cpp:863-877`：`sigma = (s0 > 0.0) ? s0 : 1e-12;` → `cvar = kcorr·(π/2)·(1e-12)²/n_ret`（≈7.6e-27，有限）→ `civar = 1/cvar`（≈1.3e26，有限且巨大）→ `unc=sqrt(cvar)`。常数 patch（≥半数像素同值，`median(|v−m0|)=0`）走此路径；`bfrac`、`n_retained` 门都不拦（clip 阈值 `m0+3·0=m0`，等值像素 `v≤m0` 全保留）。
- `权威依据`：`docs/science/PHASE2_UPM.md:85,§8`（"σ_bg_raw=0 ⇒ control_ivar **必须为 0** 且 control_variance 标为**无尺度信息（非有限）**；禁止以数值保护量生成有限方差发布"）；`PHASE2_SAMPLER.md §11.2 DISP-P2SMP-007`。
- `现状 → 应为`：现状=以 1e-12 数值保护量的平方生成**伪有限方差**并以 ~1e26 权重进 UPM 加性面求解（`p2_upm_raw_weight` 只拒 `civ≤0`，放行 1.3e26）；应为=`civar=0`、`cvar` 置非有限、以 quality_flags/计数标"无尺度信息"。命中伪地板的观测会**主导**其 cell 的 M/C，反向放大噪声。
- `改法`：`sampler.cpp:863-877` 增零尺度分支：`s0<=0` 时 `cvar=+inf`（或 quality_flags 置位）、`civar=0`、`unc=+inf`，与 §5.4"无尺度信息"发布口径对齐；补 §11.3 F5(b) 正/负例门（≥50% 同值触发、<50% 不触发）。
- `证据级别`：A（实现事实，代码路径唯一）+ 二手复算（见 AUD203-09 复算 C 量化权重污染）。
- `置信`：高（代码事实明确；"命中即主导"的量级经复算 D 佐证）。
- `复算命令或推导`：`run/SCI-FIX-PHASE2-01` 实测该伪方差=7.609e-27、伪 civar=1.314e26（`PHASE2_SAMPLER.md §5.4`）；本节点纯 Python 复算见独立审计/复算件/aud203。
