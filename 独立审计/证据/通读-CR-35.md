**面积近似（焦点①结论，非缺陷）**：本模块为**平面近似**——先把两多边形经 gnomonic(TAN) 投到局部切平面，S-H 求交，Shoelace 算切平面面积。切平面面积对真实立体角的畸变因子为 `sec^4(c)`（c=到切点角距）。因源像素与其覆盖的 HEALPix 像素角尺度均在弧分级，c≪1 ⇒ 畸变 <1e-6 量级且在同一源像素内近似抵消。此为头注释 `:37` 已声明的"近似"，量级可忽略，**不报为缺陷**（列于文末"不报的核过项"）。退化/共线/零面积：`n<3`→返回 0；共线点 Shoelace 自然给 0；`subject` 空→返回空。

### CR-35-1 · gnomonic 发散被"有限哨兵 1e6"伪装成合法投影坐标，且保护阈值近乎失效
- 轴：R（主轴）/ S
- 位点：`poly_clip.cpp:63` `const double BIG = 1e6;` 与 `poly_clip.cpp:60` `if (std::fabs(cosc) < 1e-12) {`
- 现状（引原文）：cos(c) 触阈时 `out.x = sign_x * BIG; out.y = sign_y * BIG; return out;`，返回**有限** 1e6 而非 NaN/inf；且 `1e-12 < |cosc| < 1e-6` 时不进该分支，`out.x = cdec*sdra/cosc` 直接吐出 ~1e6–1e9 的坐标而不受任何保护。
- 上位依据：条文面零提及。检索式：`git grep -n "gnomonic\|切平面\|tangent\|cos(c)\|发散\|1e-12" -- docs/ lib/`；`docs/science`、`docs/algorithms` 中未见对投影奇异点处置的规定（见 F-2 追加核）。
- 差在哪：一个几何上不可投影（投影发散/落在切平面背面）的点被赋一个"看起来正常"的有限坐标，下游 Shoelace 会把它当真实顶点计入 → 交集面积被放大到荒谬值；同时阈值 1e-12 太小，保护窗口几乎不覆盖实际会爆炸的 `cosc` 区间，形同虚设。
- 后果：若可达，重叠面积/加钻权重错值（偏大）。**但已确证该函数的整条路径在生产里零调用点**（见 CR-35-5），故当前不触碰任何产物字节；仅当未来把 PolyClip 接入权重路径才成为活缺陷。**缺运行时触发路径**，据此定 S3。
- 定级：S3（值错仅在"被接线"后成立；当前为未部署代码；但保护阈值失效属实现缺陷，接线即升 S1）。
- 怎么算修好：发散/背面点应返回可识别坏值（NaN）并由调用侧显式剔除，或改用相对阈值 `|cosc| < k·machine_eps` 且 `cosc<=0` 也判奇异；若维持 1e6 需在调用侧加"越界即剔除"。
- 置信：CONFIRMED（代码事实 + 调用点已用 `git grep` 穷举）。

### CR-35-7 · `leaf_support` 只缩放 coverage、不进入 signal 权重，掩膜(support=0) leaf 仍注入面亮度（语义存疑）
- 轴：C（主轴）/ D
