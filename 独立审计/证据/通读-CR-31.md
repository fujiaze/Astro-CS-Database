### CR-31-4 · `sdet_compute_bgnoise` 用 0 同时表示"测不到"和"零噪声"，全局阈值因此退化成帧中位（方向：偏松）
- 轴：R（主轴）+ S
- 位点：`sdet_api.cpp:452` `if (width < 2 || height < 1) return 0.0f;`；`:486-487` `if (clipped.size() < 2) { row_stdevs[y] = T(0); }`；`:503` `return med_stdev * T(0.70710678);`；消费面 `:1772` `T bgnoise = sdet_compute_bgnoise<T>(...)` → `:1779` `T threshold = img_median + T(5.0) * bgnoise;` → `:1846` `if (pixel <= threshold) continue;`；第二道门 `:1827` `const double locthreshold = 5.0 * (double)bgnoise;` → `:2083` `... || maxArAc < T(locthreshold)) continue;`
- 上位依据：`docs/algorithms/STAR_DETECTION_ALGORITHMS.md:275` "median+5·bgnoise 全局阈值"；同文档 :55-58 明确 `threshold_sigma` 是"未平滑原图噪声的倍数"，并要求引用 5σ 时**必须声明 σ 属于哪幅图**；`docs/contracts/DATA_SEMANTICS.md:920-922` 把 `sigma_bg` 钉为"背景噪声 RMS = bgnoise（行差分 FnNoise1 族）"。条文没有"bgnoise 可为 0 / 无定义时怎么办"的任何条款 ⇒ 降级登记面零提及。
- 现状：三种"测不出噪声"的路径（帧宽 <2、行被 5σ 剪到 <2 像元、逐行 stdev 全为 0）都返回 **0.0f**，与"这帧真的没有噪声"不可区分；无任何 `sdet_log(SDET_LOG_WARN, ...)`、无返回码、无 manifest 登记。逐行 stdev 数组直接进 `sdet_robust_median`（:497-502），0 值行**按正常样本参与中位数**。
- 差在哪：阈值 = median + 5·0 = 帧中位 ⇒ 判据方向钉死：`bgnoise` 单调进入 `threshold` 的加项，`bgnoise ↓ ⇒ threshold ↓ ⇒ 通过 :1846 的像元数 ↑`；同时 `locthreshold ↓ ⇒ :2083 的振幅门更易通过`。**两个门同向变松**，因此任何 bgnoise 的低估都是**偏绿/偏松**（不可能造成漏检），这与"检测阈值"应有的保守方向相反。
