### 先答本批重点问题 1：两种写入形态是否给出同一物理输出

本文件内的两形态（`drizzle_engine.cpp:1911` `shared_vertices = (config.pixfrac == 1.0)` 决定走 `:2089` 共享顶点支或 `:2100` 通式支）**在本文件内是自洽的、给出同一物理输出**，逐条：

| 累加量 | pixfrac==1 支（`:2089`，`pixel_corners_v=nullptr`） | pixfrac<1 支（`:2100`→`:1385-1403`） | 是否同式 |
|---|---|---|---|
| `weight` | `:1617` `overlap/drop_area` | 同 `:1617` | 同 |
| `sumFlux` | `:1639` `+= x·weight` | 同 | 同 |
| `sumArea` | `:1640` `+= overlap` | 同 | 同 |
| `pixel_area` | `:1535` `= drop_area`（此时 A_drop≡A_pixel） | `:1537` `polygon_area_consistent(未收缩四角)` | 同（恒等在 pixfrac=1 成立） |
| `sumNorm` | `:1644` `+= overlap·(pixel_area/drop_area)` = `overlap·1.0` ⇒ **与 sumArea 逐位相同** | `:1644` `+= overlap·(A_pixel/A_drop)` | 同式 |
| `sumVarNum` | `:1649` `+= v·weight²` | 同 | 同 |

我独立复算了配对的正确性（未照抄注释）：`sumFlux = Σ x_j a_jp/A_drop = Σ B_j A_pixel a/A_drop = Σ B_j u_j`，`u_j = a_jp A_pixel,j/A_drop,j`；`sumNorm = Σ u_j` ⇒ `S_p = Σ B_j u_j/Σ u_j` 是面亮度的加权平均；其方差 `= Σ u_j² (v_j/A_pixel,j²)/N_p² = Σ v_j a_jp²/A_drop,j² /N_p² = sumVarNum/N_p²` —— 与 `:1649`+`:1645` 的实现**逐因子一致**，也与 `docs/science/DRIZZLE.md:63-64,87-89` 的"两种参数化给出逐位相同 variance"的断言一致。**⇒ 分母口径（面积/权重分母）在本文件没有缺陷**；`a_jp/A_drop,j` 的出处为 `docs/science/DRIZZLE.md:21,45`（`F&H 2002 §7.2 式(7)` 下方原文，见 `:1608-1612` 与 `tests/CMakeLists.txt:10-12`），面亮度分母 `N_p` 的出处为同文 `:22,49`。

派单所述"其中一种除以按 8 位格点量化的支撑面积"**不在本批 6 个文件的任何一个里**：本文件不含任何 8 位/`255` 量化，也不做"除以支撑"的发布归一（`:1266-1269` 明写"不在这里除面积"，归一在 sink）。量化支撑与"支撑极低⇒按未覆盖发布、信号为非数"的位置在我这批之外，代码自己给了指针：`:1646`「归一在 sink/writer finalize（`astro_sphere_sink.cpp:100`）」、`:3`「归一在 `astro_sphere_sink.cpp:100` / `aio_hips_writer::finalize_tile`」。⇒ **本批对该重点的产出是排除性结论 + 指位，不复述也不推翻已结案的 profile=1 定量界。**

### findings

#### CR-10-04 · 累加循环里五处"整块跳过源像素"不进任何强制计数，通量守恒不变量可以在无人看见时破
- 轴：R（主）/ S
- 位点：`drizzle_engine.cpp:1375-1376`、`:1398-1399`、`:1487`、`:1518-1520`、`:1538-1540`
  ```cpp
  if (!std::isfinite(ra) || !std::isfinite(dec))
      return;                       // :1375-1376  (Step 2 逐角映射)
  ...
  if (drop_corners.empty()) return; // :1487       (自适应构形失败)
  if (drop_area < Scalar(1e-20)) { return; }        // :1518
  if (pixel_area < Scalar(1e-20)) { return; }       // :1538  注释自称"fail-closed, 不产伪权重"
  ```
  以及 `:1558` `if (candidates.empty()) { return; }`
- 上位依据：本文件 `:2025-2032` 自己逐字引的冻结合同——`docs/interfaces/data/DATA-002_PHASE_PRODUCT_EXCHANGE.md §2a`（rule_id `NAN-SAMPLE-MASK-COVERAGE-NAN`）：「不合格样本 → 样本级掩膜（从分子 F_p、分母 D_p、方差项 Var_p 三项一并剔除 ⇒ 重归一自动成立…）**强制计数**：被剔除样本按原因分类计数（禁静默剔除）」。该文件在跟踪面（`git ls-files docs/interfaces` 命中 6 份）。`DrizzleStats` 亦按此登记三个互斥计数（`drizzle_engine.h:150-160`）
- 现状：三处 `return` 只出现在 `!isfinite` 的**角点**（不是像素值）、`drop_corners.empty()`、两个 `1e-20` 面积上；`counters.rejected_nonfinite_value/variance/nonpositive_weight` 一个都不加（这三处对应的样本 `x_j` 完全有限、方差有效、权重为正）。`candidates.empty()` 一支同样不计
