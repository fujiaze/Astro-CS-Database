### 6.2 findings

#### CR-54-23 · `optimize_dark_k` 的返回类型对"成功"与"连回退值都非法"给出**同一个 float 域**，退化信息只活在引用出参里；`BAD_K_INIT` 分支会把 NaN/0/负 k 原样返回
- 轴：R（静默回退 + 退化返回不可判）
- 位点：`:97-99` 逐字 `float optimize_dark_k(const float* light, const float* bias, const float* dark,\n                      const float* flat, int w, int h, float k_init,\n                      hiss::Stage1Diagnostics& diagnostics) {`；`:113-118` 逐字 `    // k_init 本身必须为正有限值，否则连回退都无法给出合理值，但仍按规范返回 k_init` / `    if (!(k_init > 0.0f) || !std::isfinite(k_init)) {` / `        fallback_to_exposure(diagnostics, "BAD_K_INIT",` / `                             "k_init non-positive or non-finite");` / `        return k_init;` / `    }`
- 上位依据：`docs/algorithms/CALIBRATION_ALGORITHMS.md:266-272`（F5.4）把 `BAD_K_INIT` 与其它码并列为"失败→回退 k_init"的一种；`docs/science/CALIBRATION.md:96` 规定 `K = t_light / t_dark`（合法域为正实数）。
- 现状：`PARAM`（`:108-112`）与 `BAD_K_INIT`（`:114-118`）两条分支都 `return k_init`，而后者是在**已判定 `k_init` 非正/非有限**的前提下返回它；函数返回类型无错误通道（`float`），失败与成功只能从 `diagnostics.fell_back/success/code` 读，而这三者是**引用出参的字段**（`set_diag:73-83`），且 `:104` 预置为"未回退"。
