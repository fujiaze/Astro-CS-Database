## Findings

### CR-282-001 · pixfrac 默认值与配置读取不一致
- **轴**: C (上下级一致)
- **位点**: orchestrator.cpp:3340
- **上位依据**: CFG-001 注释"省略时生产默认 0.8"，但代码 `pixfrac = stage1_cfg_->drizzle.pixfrac` 直接读 cfg
- **现状**: `double pixfrac = stage1_cfg_->drizzle.pixfrac;` 未提供 fallback default
- **差在哪**: 若 cfg 中 pixfrac 字段缺省（如 struct 初始化留零），则传给 drizzle 的是 0.0 而非 0.8
- **后果**: Drizzle 像素分数为 0 → drizzle kernel 退化、叠加产品亮度失真；对外主张"生产默认 0.8"不成立
- **怎么算修好**: 增加 fallback：`double pixfrac = stage1_cfg_->drizzle.pixfrac; if (pixfrac <= 0.0) pixfrac = 0.8;`
- **置信**: PARTIAL (需确认 Stage1Config 的 pixfrac 默认构造函数是否显式初始化为 0.8)

### CR-282-002 · sigma_residual 默认值 0.1 来源不明
- **轴**: S (支撑)
- **位点**: orchestrator.cpp:4392
- **上位依据**: docs/science/SCI-PHOT-001(光度残差定义) 或 docs/algorithms/ALG-PHOT-XXX(σres 标定)
- **现状**: `double sigma_residual = 0.1;` 作为 KV 读取不到的兜底值
- **差在哪**: 0.1 是经验猜测值还是文献/实验标定？无锚
- **后果**: SNR 模型提取的噪声权重对 σres 敏感；用错 0.1 可能放大低信噪星影响，导致 ivar 系统偏大/偏小
- **怎么算修好**: 查 SCI-PHOT 定 σres 合理范围（如从 photo_stats/KV 先读 frame-level 估计，再 fallback）；或改为 WARN+SKIPPED_NO_SIGMA 硬失败
- **置信**: UNPROVEN (需要核查 SCI-PHOT-001)

### CR-282-003 · a_cell 公式疑似错误（HiPS 象元面积）
- **轴**: S (支撑)
- **位点**: orchestrator.cpp:3957, 3976
- **上位依据**: HEALPix 标准：单象元立体角 Ω = 4π/(12×NSIDE²)，a_cell 应为 Ω
- **现状**: `const double a_cell = 4.0 * 3.14159265358979323846 / (12.0 * (double)nside_leaf * nside_leaf);`
- **差在哪**: nside_leaf = 1 << (order+9)，drizzle 阶段输出的 nside 是 leaf nside 吗？需核对 drizzle 写入 HiPS manifest 的 hips_order 与此处推导一致性
- **后果**: F = signal*support*a_cell 计算流量单位失真，若 a_cell 偏差×k，则最终流量偏差×k
- **怎么算修好**: 追踪 drizzle 阶段写出的 hips_order，验证 leaf nside 是否为 order+9；或用 manifest 中的 nside 直接计算
- **置信**: PARTIAL (需核对 drizzle write path 与 HIPS_VERIFY 读 path 的 nside 传递)
