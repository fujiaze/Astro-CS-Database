## 2B findings

### CR-16-06 · oracle 对非法 `variance_floor` 静默回退为 0，合同规定该情形必须报 `SNR_FLOOR_UNBOUND(-10)` 且"不静默回退"
- 轴：C（主轴）+ R
- 位点：`p1noise_oracle.hpp:112`
  ```
  const double floor_v = cfg.variance_floor > 0.0 ? cfg.variance_floor : 0.0;
  ```
- 上位依据：`docs/algorithms/NOISE_ESTIMATION.md:25` 原文：「（floor 默认 1e-12 ADU²；非有限或 ≤0 一律 `SNR_FLOOR_UNBOUND(-10)`，**不静默回退**）」；`:197` DISP-NOISE-002 原文：「build 入口（`noise_model.cpp:369-371`）与 fill 入口（`:818`）用同一注册表与同一判据（非有限或 ≤0 ⇒ `SNR_FLOOR_UNBOUND(-10)`），两阶段不再有不同下界」。

### CR-16-03 · FIX-NOISE-H 的通量分布是 log-uniform（dN/dF ∝ F⁻¹），不是 SCI §11 冻结的 F⁻²
- 轴：C（主轴）+ S
- 位点：`p1noise_fixtures.hpp:356`
  ```

  ```
  自述见 `:330`「亮度幂律: `F = f_min·(f_max/f_min)^u` (u~U(0,1); 截断幂律, 亮端稀疏)」。

- 差在哪：指数取错一档（−1 对 −2），且注释把 log-uniform 称作"截断幂律/亮端稀疏"，与条文分布不是同一件事。
