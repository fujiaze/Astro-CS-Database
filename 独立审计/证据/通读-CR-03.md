# 本批最高危三条（只挑不复述）

1. **CR-03-1-06** — oracle 的 SIP 前向/逆向把已修正的 `dx` 喂给 B 多项式，与生产实现（`wcs_transform.cpp:194-197/:224-227`）和条文写法（同文件 `:185` 的 `dx'=dx+A(dx,dy), dy'=dy+B(dx,dy)`）都不同；唯一对拍门以天球度上的 `rtol 1e-9` 判（等效 `6.4e-4 px`），比该口径差（`~3e-9 px`）宽约 5 个数量级 ⇒ "前向正确性由 oracle 对拍严控"不成立。
2. **CR-03-5-02** — 同一 C ABI 家族里 `−3` 有三个互斥登记（无 Gaia/PSF 星退化／锥搜失败／`pc_api.cpp:37/:508` 又重复一遍），实现对该条件返 `0`（`pc_api.cpp:547-572`），`README.md:129-131` 与 `DATA_SEMANTICS.md:671` 记 `rc=0`，`−2` 亦两义（尺寸／句柄）；negative 组把两通道的异码当作正确逐条写死，而唯一与头部声明冲突的那一行（直通通道 `n_gaia=0`）**无任何用例**。
3. **CR-03-6-01 与 CR-03-5-01 合看** — 两条对外主张由"与被测无耦合"的断言承担：鲁棒门 `<0.1 dex` 断的是 oracle 自身 location 幅值（条文 `SCI:237/:277` 定义的是两次运行之间的**变化量**）；negative 组的退化恒等值断言用整组共享、不复位的 `nm/sc/sg`，可被上一次调用的残留值满足。两者方向都是偏绿。

### CR-03-3-01 · 同一合同式 `γ_n=n·u/(1−n·u)` 在本组取 `u=2^-52`，在投影模块取 `u=2^-53`，本侧门宽一倍（偏绿）
- 轴：C（主）／R
- 位点：`:61` `constexpr double kUlpF64 = 2.220446049250313e-16;  // 2^-52`
- 上位依据：`docs/contracts/TEST_MATRIX.md:24`「归约: `γ_n = n·u/(1−n·u)`, 门限 `C·γ_n·Σ|terms| + atol`, `C≤4` 事前冻结」——条文给式**不给 u 的值**。对照面：`lib/algorithms/projection/p3_wcs.cpp:225` `constexpr double kUnitRoundoff = 1.1102230246251565e-16;   // 2^-53`；`lib/algorithms/projection/tests/p3wcs/p3_projection_registry_test.cpp:500` `const double u = 1.1102230246251565e-16;       // 2^-53`。

### CR-03-6-01 · O1 的"冻结鲁棒门 0.1 dex"断的是 oracle 自身 location 的幅值，条文规定的是两次运行之间的**变化量** ⇒ 与被测无关的恒真门

- 上位依据：`docs/science/PHOTOMETRY.md:237`「**鲁棒性**：注入 20% 离群 `r` 时 IRLS `location` **变化** `<0.1 dex`（Tukey 权重截断）」；`docs/science/PHOTOMETRY.md:277`「**鲁棒门**：注入 20% 离群点，`location` **偏差** `<0.1 dex` 且离群权重为 0」；`ALG:265` 把同一门写成「F2（`perturb_amp=0.02` ⇒ `S>0`）的 `|Δlocation|<0.1 dex`（宽松门）」。三处都是 **Δ/变化/偏差** 语义。
