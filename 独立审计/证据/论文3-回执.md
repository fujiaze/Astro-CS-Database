## 3 还缺哪条证据、会让哪一节站不住

1. **§6.1（多退少补语义）与 §5.2 的"证据面只能是保背景臂"**：目前靠 gauge 赋值 + 恒等式静态判定 + 归档合成算例。缺一份产品级读数（同一产品分别跑 `delta` 与 `c` 模式、比产品中位电平）。若产品实现里份额式权重（丢弃跨 control 精度、λs>0 时改变估计量）使 `Σw(y−C−G)/Σw ≡ M` 只在 λs=0 域内成立，则"两种模式都保背景"的对称表述要收窄为"末端 gauge 域内成立"。
2. **§6.3 其二（门的可信度）**：缺两例进 `REQUIRED_SELFTEST_CASES`——"相干梯度无台阶必须绿"与"反号台阶+梯度必须红"；缺 §17 事后标定件的可重跑证据。这两项不补，论文关于检测限只能主张闭式的 1.005%，不能给虚警率/检出概率，也不能主张"门能区分天体结构"。
3. **§6.4（收敛四态）**：缺 `converged=2` 的夹具级实测记录（`kStallPatience`/`kObjImproveFloor` 是函数体内 const，配置面驱动不了）。不补则"四态可达"只能主张到"代码四个出口都能赋"，不能主张"经验可达"。
4. **§3.2 与 §5.1（权重与方差）**：缺生产尺度（≈1″/px）上 `k_corr` 的标定证据（标定域 300–600″/px，`control_median_mc_test` 的实证 1.3883 不在该尺度）；缺零尺度分支修复后的正/负例门（`PHASE2_SAMPLER §11.3 F5(b)`）。不补，任何 `control_variance` 的绝对数值都只能带"域外保守取值"这条声明使用。
5. **§3.3（自适应与表示能力）**：缺真实产品 manifest 里 `sky_plane_node_adaptive_used` / `n_node_refinements` 的"曾触发"读数；缺"节点间距≤目标可表示尺度/2"在生产几何上的逐产品实测。不补，规则 3 的自适应对真实数据只能按"未触发=未实现"登记，表示能力边界一节只剩代数论证。
6. **§5.4 与 §6.3 的表**：数字取自复核节点的自复刻（输入为我方可控的合成结构），不是产品读数；把它当"出厂门在真实天体结构上的表现"来引用会过头——已在文中限定为"合成结构夹具"。
7. 采样模块对**暗端离群无判别面**（`bfrac` 与 clipping 都只作用亮端，`PHASE2_SAMPLER §5.5`）。论文未展开这一点；若要主张"采样点干净"，这条会立刻站不住，需补上游坏列/暗斑掩膜的证据链。
