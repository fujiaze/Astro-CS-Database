### CR-36-01 · 触点（极点）像元的 4 角大圆弧模型比真 HEALPix 像元小 9.97%，且不随 NSIDE 收缩，与同函数解析快路径互斥
- 轴：S（主轴）＋ R
- 位点：cpp:1283-1294 `if (nb == 4) { … sutherland_hodgman_spherical_fixed(hp_boundary, 4, drop_clip_normals, intersection, 16); … spherical_polygon_area_n<double>(intersection, ni); }`，其 `hp_boundary` 来自 cpp:1372-1375 `get_healpix_boundary4<double>(…)`；对照 cpp:1239-1242 `if (leaf_fully_inside_drop) … return Scalar(PI / (3.0 * (double)nside * (double)nside));`
- 上位依据：DRIZZLE.md:25 定义 `hp_res = √(π/3)/nside`（等面积像元）；DRIZZLE.md:96 "目标边界: NESTED leaf 4 角（赤道菱形/极区退化）"；h:137 "极区像素一角可能退化 … 但仍返回 4 个顶点（退化角会重合, **不影响凸性**）"。条文面**没有**任何一处规定"leaf 用 4 角大圆弧多边形代替真实 HEALPix 边界"是可接受近似，也没有给该近似的适用域。
- 现状：生产路径（nside≥256）把 leaf 表示为过 4 角的**大圆弧**四边形；完全覆盖分支返回**解析**球面面积 π/(3n²)（真 HEALPix 像元面积），部分覆盖分支返回**四边形**面积。我的复算（穷举 12·nside² 个像元的 V0 扇形面积）：相对偏差 `max|A_quad−A_an|/A_an` = 5.6e-2(n=2)→8.9e-2(4)→9.7e-2(8)→9.90e-2(16)→9.95e-2(32)→**9.96e-2(64)**，且 `|相对偏差|>1%` 的像元数在 n=32/64/128 **恒为 16 个**，最负者 `−0.0997 @ bighp 0-3 的 (Ns−1,Ns−1) 与 bighp 8-11 的 (0,0)` —— 即 8 个含极点的像元；赤道带 bighp 4-7 的 max 相对偏差 → 0（n=64 为 1e-4，n=128 为 0）。同复算另证 `Σ_quad = 4π` 到 1e-13 ⇒ 该四边形族确实无缝拼满球面。

### CR-36-02 · 切平面分支的精度主张 "<4e-8" 复算为 −5.0e-7，偏 12.5 倍
- 轴：S
- 位点：cpp:1001-1005 `// 球面面积 = 切平面有向叉积和 × (1 + O(θ²)), θ=max_angle。/ θ < 1e-3 rad 时偏差 < 4e-8`（阈值活用于 cpp:1091、1288、1331、1892）
- 上位依据：条文面零提及 ——`git grep -n "1e-3\|206" docs/science/DRIZZLE.md docs/algorithms/DRIZZLE_GEOMETRY.md` 只命中 DRIZZLE.md:146 与 DISP-DRZ-005（登记"该分支必须保留"），均未规定偏差上界数值。
