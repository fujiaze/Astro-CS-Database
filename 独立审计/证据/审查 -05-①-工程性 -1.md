### F1-06 [W-10:83]
**原文**: "不得降级为'只做标量'"

### F1-07 [W-11:84]
**原文**: "空间项**不得**另立秩/条件数判据或阈值"  
**问题**: 禁止类表述 ("不得")  
**订正句**: "空间项**只使用** `spatial_gain.h:31-41` 的 `p2_identifiability_assess` 作为唯一判据面，不新增秩/条件数计算路径"

### F1-10 [W-20:93]

**问题**: 禁止类表述 ("不得")  
**订正句**: "运行级判红的输入是 manifest 的 `n_frames_failed > 0` 与 `frame_errors[]`；**必须同时产出**产品与 manifest"

### F1-11 [W0-1:101]
**原文**: "不得保持现状"  
**问题**: 禁止类表述 + 裁决语气 ("不得")  
**订正句**: "二选一：**(a)** 删除该 public 入口；**(b)** 在签名尾部追加 `const uint32_t* quality_flags` 并以 A-6/A-7 的有效域路径转调 `matchWithKdTree + cleanAndScale` 的 `quality_flags` 重载。维持现状即违反 §3.7 的有效域要求——一旦有人调用即静默产出未做饱和过滤的 `k_photo`"

### F1-12 [W0-2:102]
**原文**: "本规格**禁止**新增调用点"  
**问题**: 禁止类表述 ("禁止")  
**订正句**: "新调用点：**无**——两个符号移出公共头（或改名为 `*_noncanonical_*` 并在声明处具名'式 -1 的非正本口径，禁止生产与禁止作 oracle 期望源'）。可达性由 G-24 守"

### F1-13 [W0-4:104]
**原文**: "不得并存"  
**问题**: 禁止类表述 ("不得")  
**订正句**: "二选一：**(a)** 新调用点 = `frame_photometry_fit.cpp` 的请求装配处；**(b)** 出处只写活载体…… 两者同时存在 ⇒ `eng/ci/prod_wiring_baseline.json` 报红 (ERROR_DEAD_CONFIG_KEY)"

### F1-14 [W0-5:105]
**原文**: "新调用点：**无**" + 注释中旧式引用  
**问题**: 否定陈述需配替代动作  
**订正句**: "消费式替换要求：`star_matcher.h:59` 的该行替换为 `02` 式 -4'消费口径'段的现行式引用（`1.253·sigma_residual/√N`），并由 G-25 锁住'注释与唯一消费式同源'"

### F1-15 [M-1:174]
**原文**: "禁止'取 first range 长度'的前缀式比较"  
**问题**: 禁止类表述 ("禁止")  
**订正句**: "比较前**先核长度**：`lhs.size() == rhs.size()` 且逐字符大小写不敏感相等，才判命中；**否则立即返回未匹配哨兵**"

### F1-16 [M-2:175]
**原文**: "不查表、不返回任何库键"  
**问题**: 双重否定 ("不…不…")  
**订正句**: "入参为空串 ⇒ **立即返回未解析哨兵** (`kNotResolved`)，不调用查表函数且返回值恒为哨兵常量"

### F1-17 [M-4:177]
**原文**: "别名表……全部禁止"  
**问题**: 禁止类表述 ("禁止")  
**订正句**: "本函数**只认库内键**：别名表、大小写折叠、空白折叠、Unicode 归一**不作为解析规则**（`filters.json#lookup.resolution_rule` 与 `docs/contracts/CONFIG_CONTRACT.md §4` 同一合同的文档化说明）"

### F1-18 [M-5:178]
**原文**: "禁止在注释里声明近似而产品面无痕迹"  
**问题**: 禁止类表述 ("禁止")  
**订正句**: "安装不可判别性……若库内无对应曲线……**必须**由 §3.2 的装载分支具名拒绝，并在 `docs/` 的 `KNOWN_LIMITATIONS` 登记该安装组合'当前按 X 曲线近似'或缺失，使产品在字段 `passband_identity.degraded_reason` 显式记录"

### F1-19 [2.4:186]
**原文**: "**禁止**作为 `psf_flux` 来源" + "**禁止**'把无效行送进去再靠下游剔'"  
**问题**: 两处分歧 ("禁止")  
**订正句**: "检测域 `5×5` 盒和（`star_detector.cpp:151 s.flux = m00`）**不是有效 `F_instr` 来源**；无效星 (`psf_status[i] != 0`) 在 A-1 截断时排除，**不传入**A-6/KD-tree 匹配"

### F1-20 [A-2:211]
**原文**: "**必须**改成'缺即拒'" + "禁止让未声明通带类别的曲线参与式 -1 积分"  
**问题**: 混合使用 ("必须"/"禁止")  
**订正句**: "`channel` 字段非空校验是 `load_curve` 的第 5 步……库内曲线的 `channel` 为空串或字段缺失 ⇒ 新增状态 `kCurveChannelUnspecified`，清空出参并返回；状态名称同步补名（`:76-87`）"
