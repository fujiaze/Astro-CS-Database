### 与成稿差异

1. **成稿把"1e-15"说成恒真门的证据，我给它补一条限定**：归档 T12 同一张表里 V0 弦路径是 6.63e-4、
   REC-1 是 2.25e-7、oracle 是 8.81e-15 ⇒ 该度量**对"候选漏选/量级错"有判别力**（成稿 AUD204-10 负例
   "人为漏一个候选叶 ⇒ 该和红"与此一致），只是**对"面积在叶间错分"零判别力**。因此正确的结论不是
   "该门恒真、无证据资格"，而是"**该门的证据资格范围 = 完备性与全局标度，不含逐叶正确性**"。
   我按此把判定定为"确认（口径订正后）"。
2. **成稿说"生产 leaf 表示下闭合 = 4π 恰为 0"**：我独立复现（nside=16/64 均 0.0），并补 nside=16 这个

3. **成稿的逐叶误差数字**（−9.97%/+0.54%）我用自己的代码 + astropy 角点重算得 −9.905%/+0.612%（N=16）与

   而是**把已有逐叶判据的取样域扩到极冠/face 角点邻域并把容差收到与冻结预算一致**。

### 缺什么证据（要变成有证据资格需要什么）

1. **逐叶 oracle**：`max_p |a_jp / a_jp^oracle − 1|` 与 `Σ_p |a_jp − a_jp^oracle| / (2·A_drop)`，
   oracle 必须**异源且不含同一折线/弦表示**：候选 =（i）真曲线边界（`subdivide_healpix_edge` 或 astropy 亚像素
   偏移）+ 收敛外推，（ii）第三方库的 `nside_to_pixel_area` 恒等式用于满覆盖叶。现有 `test_spherical_overlap.cpp`
   的逐叶断言需扩到极冠/角点邻域并把 1% 收紧到与预算同量级。
2. **守恒型门的定位句**：`docs/algorithms/DRIZZLE_GEOMETRY.md` §9 与 `docs/science/DRIZZLE.md` 的闭合门须明写
   "本门度量 = 完备性/全局标度，不约束面积落在哪一叶"，否则读者会继续把 1e-15 读成几何正确。
3. **求和型门 + 错分负例同堂**：把"一叶 ×2、邻居吸收"这类保总量注入登记为**必红**的负例夹具（当前任何求和型
   门都放过它，我的数在 15 个数量级上证明这点）。
4. 本条不需要重跑 C++ 即可定案（结构 + 恒等 + 盲区三项都由只读代码事实与本机纯 Python 复算支撑）；
   需要重跑的是 W2 的 R1（生产 `compute_overlap_area_*` 与真曲线逐叶对拍）。

## 小论文第四篇可以主张到哪一步

**"构造闭合"与"逐 leaf 正确"是两件不同的事**：前者只是等面积划分 + 同一面积算子的可加性
（`Σ_p a_jp ≡ (π/3)·|D ∩ face|`、`Σ_p 弦叶面积 ≡ 4π`）之代数恒等，实测残差 0.0 也不提供任何几何信息；
后者要求每个叶拿到它与该 drop 的**真实球面交叠**，只能由**异源逐叶 oracle**（真曲线边界或第三方库
亚像素偏移）逐叶对照来支撑。**论文只能主张已被独立 oracle 支持的那件**：即"该分配格式在全天求和
意义上精确守恒（残差 0.0，属构造性质而非验证结果）"，并可主张"逐叶守恒的误差预算由 X 界定"仅当
X 那条逐叶 oracle 真的跑出来；在逐叶 oracle 落地之前，不得把"构造闭合 1e-15"写成面积分配正确性的证据，
也不得主张"逐叶面积精确"——本节点实测生产弦表示的逐叶面积误差达 −9.9%…+0.6%，而全天空求和残差 0.0。
