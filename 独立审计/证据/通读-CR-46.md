## 5 `lib/algorithms/platesolve/wrapper_phase1/wcs_tan.cpp`

### 前置结论：投影/去投影式与一手定义一致（本批独立复算，非凭记忆）

复算脚本与两路独立推导见文首"本批复算途径"。结论：

1. **正向（sky2pix，:47-58）** 与 FITS-WCS Paper II 的 TAN 标准式一致：
   `ξ = cosδ·sin(Δα)/D`，`η = (cosδ0·sinδ − sinδ0·cosδ·cosΔα)/D`，`D = sinδ0·sinδ + cosδ0·cosδ·cosΔα = cos c`（c 为球面角分离）。
   即 `den`（:51）**就是球面角分离的余弦**，`ξ/η` 是 `tan c·sinφ / tan c·cosφ` 的无量纲形式乘 `180/π` ⇒ 度域投影平面坐标。代码注释 :47-48 写的式子与实际算的式子逐字符一致（我按表达式核对，非按注释采信）。
2. **逆向（pix2sky，:28-33）** 与经典 gnomonic 去投影代数等价：令 `ρ = atan R`，则 `cosρ = 1/√(1+R²)`、`sinρ/R = 1/√(1+R²)`，
   `dec = asin(cosρ·sinδ0 + η·(sinρ/R)·cosδ0) = asin((sinδ0 + η cosδ0)/√(1+ξ²+η²))`；
   `Δα = atan2(ξ sinρ, R cosδ0 cosρ − η sinδ0 sinρ) = atan2(ξ, cosδ0 − η sinδ0)`（两参同乘 `√(1+R²)/R > 0`，角不变）。
   在切点正交基 `{r0, e东, n北}` 上 `s ∝ r0 + ξe + ηn` 独立重推，得同一对式子。
3. **数值对拍**（A=逐式移植、B=独立向量基，7 组 WCS × 网格）：最大角度差 **5.09e-14 deg**；往返（A 后接 sky2pix）最大 **5.74e-9 px**（极区参考 5.74e-9，其余 ≤3.7e-10），合同 1e-6 deg 余量充足。
4. **退化点处理实况**（本批实测，不凭记忆）：
   - 参考点（切点）：`R < 1e-12` 分支（:24-26）必需——否则 `η·sinρ/R` 为 `0/0` = NaN；该分支返回 CRVAL，误差量级 2e-7 arcsec，远低于 1e-6 deg 合同 ⇒ 合规。
   - **极区**：`dec0 = 90°` 时通式仍正确（`dec = 90° − ρ`、`Δα = atan2(ξ, −η)`），**无需也不应特判**；代码未特判 ⇒ 正确。天北极入射 `sky2pix` 时 `cosδ ≈ 6.1e-17`（浮点下不严格为 0）⇒ ξ 微小非零，无奇异。
   - **反子午线（RA 0/360 接缝）**：`sky2pix` 对 `Δα` 做 `while` 归一（:44-45）⇒ 任何 ±360k 输入映射回同一像素（实测同一像素两写法 x 均 450.5），**这是正确性所需**，但使往返判据对"输出 RA 落在哪个域"完全零鉴别力（→ CR-46-17）。
   - **切点半球之外（c ≥ 90°，`D ≤ 0`）**：无有效性出口（→ CR-46-18）。实测：c=89.99° → x = −1.31e9 px；c=90.00°（`D≈1e-17` 舍入）→ x = **−3.74e21 px**；c=90.01° → 符号翻转为 **+1.31e9 px**；c=179° → +4050 px。
