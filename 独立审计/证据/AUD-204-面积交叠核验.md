## 1. 链路口径与公式（我独立推导后的口径，非文档抄录）

HEALPix 基面 chart（`实验/healpix-polar/code/polar_common.h:136-196` 的 `chart_uv_to_ang`，face 0-3 北、4-7 赤道、8-11 南，`z=sin dec`）：

- 赤道支（`|z|<=2/3`，face 4-7 全方格 + face 0-3 的 `u+v<=1` 三角 + face 8-11 的 `u+v>=1` 三角）：
  `z = (2/3)(u+v-1)`（赤道面），`phi = (pi/4)(u-v+2(f-4))` ⇒
  `|d(z,phi)/d(u,v)| = |det[[2/3,2/3],[pi/4,-pi/4]]| = pi/3`（常数）。
- 极冠支（face 0-3 的 `u+v>1`）：`s = 2-u-v`，`z = 1-s^2/3`，`phi = (pi/2)f + pi(1-v)/(2s)` ⇒
  `dz/du = dz/dv = 2s/3`；`dphi/du = (pi/2)(1-v)/s^2`，`dphi/dv = -(pi/2)(1-u)/s^2` ⇒
  `|J| = (2s/3)(pi/2)[(1-u)+(1-v)]/s^2 = (2s/3)(pi/2)(s)/s^2 = pi/3`（常数）。南面同理。
- 结论：**两支各自 `|J| = pi/3` 严格成立**；`dOmega = |dz dphi|` 与 `|dOmega/du dv| = |J|` 恒等 ⇒
  12 个单位方格面各面积 `pi/3`，`12*(pi/3)=4pi` 闭合；叶 = `1/N^2` 方格 ⇒ 叶面积 `pi/(3N^2) = 4pi/(12N^2)`（与 Górski 等面积式一致）。
- 唯一失效点：极点 `s=0`（chart 的 `(1,1)`/`(0,0)`），`phi ~ 1/s` 发散 ⇒ 该点不是坐标可逆点（方向折叠），
  这正是设计 §2.4 奇点条款①的解析落点，**不是**面积口径失效（`|J|` 表达式不含 `1/s`）。

生产实现口径（与 chart 无关）：`w_jp = a_jp/A_drop,j`、`N_p = sumNorm = Σ_j w_jp·A_pixel,j`、
`D_p = sumArea = Σ_j a_jp`、`S_p = F_p/N_p`、发布因子 `k = D_p/N_p`（`astro_sphere_sink.h:38-52`）。

## 我证伪了任务书的哪个前提

1. **核验内容 1+2 的"现状"前提被证伪**：任务书要我"核验 chart 坐标域…交叠退化为二维轴对齐裁剪+鞋带"，其措辞把这当作**在跑的链路**。事实：`lib/` 全仓 `chart/face/natural_face/kJacobian` **零命中**，生产唯一面积路径 = 球面 S-H 裁剪 + Van Oosterom（`DRIZZLE_GEOMETRY.md:128-132` 自述"唯一命名"），且该文档 `:331` DISP-DRZ-008 自证平面 S-H/鞋带件 `poly_clip.h` 生产零调用。⇒ 核验对象只能是**设计主张 + 只读原型**，不是生产链路（AUD204-01）。前提(a)(b) 中"等面积/Jacobian 恒 π/3/leaf 轴对齐"本身**成立**（AUD204-02），被证伪的是"这是现状"。
2. **验收门"快速路径构造闭合在 1e-15 量级"作为证据资格被证伪**：该量是划分恒等式的浮点残差（我在全格点上独立复现 `Σ_p 弦面积 − 4π = 0.0…−1.8e-15`，且在逐叶误差 0.84 的灾难位形下恒等式仍 3e-14 绿），归档实现更是把逐格面积算完丢弃（`chart_native.h:339-365`）⇒ **验证与真值同源 = 恒真门**，不能"支撑权重分母与逐 leaf 通量闭合门"（AUD204-05）。
3. **核验内容 6 的公式被证伪（两处：正本与实现同向、任务书反向）**：任务书与 `ASTROCS_DESIGN.md:209`、`DATA_SEMANTICS.md:47`、`DRIZZLE_GEOMETRY.md:43/337-346` 写 `w_jp = a_jp/A_pixel`；代码 `drizzle_engine.cpp:1617` 是 `weight = overlap_area / drop_area`，且 **FROZEN 正本** `docs/science/DRIZZLE.md:44-50` 同为 `/A_drop,j`，其 §10 禁止项逐字写着"把核权重写回 `a_jp/A_pixel,j`（…FZ-COND-FLUX-CONSERV 判红）"⇒ 任务书沿用了陈旧锚（AUD204-09）。
4. **核验内容 4"leaf 边界非大圆按 Górski 2005 §5.3 处理"里的"处理"被证伪为不精确**：(i) §5.3 节号不可核（全文不可得），事实由 C&R 2007 §1 支撑；(ii) 仓库对该事实的既有"处理"**不是精确边界，而是放宽收敛阈值**——`spherical_overlap.cpp:558-562` 自述"旧口径 `hp_res·1e-12` 对非大圆弧的 HEALPix 边永不收敛，已废弃"，改为 `1e-6·hp_res`，且真曲线细分件 `subdivide_healpix_edge` 在生产 nside 域被调用点旁路（`:1372-1382`，且其自述"对所有 NSIDE 统一使用"与调用点相反）⇒ 任务书"存在精确处理"的隐含前提不成立（AUD204-06）。
5. **步骤 3"快速路径与球面裁剪路径逐位对照"当前无对照对象**（生产只有一条路径）；且"回退不丢面积"在唯一存在的原型里被证伪：极点无角点路径时 `Σ_p a_jp^chart/A_drop − 1 = 0.811`（丢 81%），同位形生产弦路径逐叶 3.1e-12 无损（AUD204-07）。

## 诚实边界（含需复测清单）

- **适用域**：本报告一切数字属"几何/算术层"（球面多边形面积、chart 映射、量化映射），与观测条件、波长、噪声模型无关；不涉及 SNR 定权语义（AUD-202）与 UPM 求解（AUD-203），但 AUD204-09/11/12 已按分片约定登记为与权重/variance 链的**接线一致性**缺陷。
