## 1. 链路口径与公式（现行正本，逐条列出）

现行正本 = `docs/science/PHOTOMETRY.md`（SCI-PHOT-001，状态 FROZEN）。核心式：

```text
F_syn      = ∫ F_λ(λ)·T(λ)·Q(λ)·λ dλ                       [W·m⁻²·nm]     §2a.1 / :44
             F_λ = byte·flux_mul + flux_min                 [W·m⁻²·nm⁻¹]   XPSD 解码
             **不含** 10^(−0.4·G)                                            §2a.1 / :55
r_i        = log10(F_instr,i / F_syn,i)                     [dex]          §5 / :197
delta_i    = −2.5·log10(F_instr,i) − G_Gaia,i               [mag]          §5 / :200
预过滤      |delta_i − median(delta)| > mag_tolerance(=3.0) ⇒ 拒           §5 / :202
IRLS/Tukey  S = MAD(r)/0.6744897501960817; u=(r−loc)/(c·S), c=4.685;
            w=(1−u²)² (|u|<1) else 0; loc ← Σw·r/Σw; ≤50 步, tol 1e-6      §5 / :205-210
scale=k_photo=10^(−location)   [F_syn 单位]/ADU;  I_photo=k_photo·m(x,y)·I_cal  §5/:212, §16.1⑤
sigma_residual=MAD(r_inliers)/0.6744897501960817; sigma_mag=2.5·sigma_residual  §5/:213-214
```

冻结门：`|r_consistent| ≥ 3` 才进 IRLS，否则 NO_DATA（§4/:191）；`|r_inliers| ≥ 2` 才估 `sigma_residual`（§4/:191）。

**任务书引用的公式与正本不同**：任务书与派单文字把 `F_syn` 写成 `∫S(λ)T(λ)Q(λ)λ dλ × 10^(−0.4·mag_G)`。该写法在现行正本里被**显式否定**（`:24`、`:55`、§2a.6），并且在代码里仍然存在、只是被标注为"非生产通道"（见 AUD201-001）。

### AUD201-002 `λ` 因子：来源、量纲与单位约定**成立**（正本无需订正）

- **对象**：`lib/algorithms/photometry/cpp/src/spectrum_integrator.cpp:350` → `cache.weighted_wl[i] = cache.spectrum_wl[i] * cache.filter_trans[i] * q;`；被积 `:447` → `integrand[i] = f * cache.weighted_wl[i];`

- **现状 → 应为**：一致，无偏差。`λ` 不是"约定俗成多写一个因子"，而是**能量谱辐照度→光子计数率**的换算核；因 `F_λ` 确为能量单位（官方声明），`λ` 因子**必须**在，去掉它才是错。量纲闭合：`W·m⁻²·nm⁻¹ × nm × nm = W·m⁻²·nm`，且 `F_syn = hc·N_γ`（`hc=1.986445857e−16 J·nm`），与光子计数率只差与星无关常数 ⇒ 被 `location` 吸收的论证成立。
- **改法**：不订正公式。仅在 `docs/science/PHOTOMETRY.md` §2a.2 把"λ 因子即光子计数约定"的**成立前提**写成显式约束：`λ` 因子成立 ⟺ 解码后的 `F_λ` 为能量谱辐照度；若容器给出的是**光子**谱通量（ph s⁻¹ m⁻² nm⁻¹），`λ` 必须去掉（见 AUD201-003）。
- **证据级别**：A 论文/官方 + 独立推导。
- **置信**：CONFIRMED。
- **推导过程**：`N_γ = ∫ (F_λ/E_γ) T Q dλ = ∫ F_λ λ T Q dλ /(hc)` ⇒ `hc·N_γ = ∫F_λ T Q λ dλ`。数值：`hc = 6.62607015e−34 × 2.99792458e8 = 1.98644586e−25 J·m = 1.98644586e−16 J·nm`。

## 我证伪了任务书的哪个前提

1. **任务书第 1 项的公式写错了，且错在方向相反的一侧。** 任务书与派单文字给的是 `F_syn = ∫S(λ)T(λ)Q(λ)λ dλ × 10^(−0.4·mag_G)`。现行正本 `docs/science/PHOTOMETRY.md:24`、`:55` 明确"**不含** `10^(−0.4·G)`"，并把它列为变更 claim `PHOT-FSYN-CANON-001` 的冻结口径。我独立推导站在正本一侧：XP 采样均值谱的**绝对幅度本身已编码星的亮度**，再乘 `10^(−0.4G)` 是把亮度计入两次，会给逐星 `r_i` 加 `+0.4·G_i` dex，单标量 `location` 吸收不掉。⇒ 任务书这条前提**不成立**；被否定的写法仍以 `compute_f_syn` / `compute_f_syn_cached` 两个公共函数存活并被 3 处测试/工具调用（AUD201-001）。
2. **派工范围里的 `lib/infrastructure/gaia/` 不存在**（0 跟踪文件），真实活载体是 `lib/infrastructure/gaia_xpsd_client/`（15 跟踪文件）。AGENTS.md §7 同源笔误。（AUD201-018）
3. **"逐常数核对出处"这一前提隐含"常数有出处"——对 6 个测光常数不成立**：它们的"配置键出处"是 CI 自己登记的 **dead key**，真值在代码里是字面量；而注册表给出的权威回链 **4/6 指向错行**。⇒ 该前提的可达版本不成立。（AUD201-008 / AUD201-017）
4. **部分证伪我自己先前的一个假设**：我曾假设"`sigma_residual` 取 `r_inliers` 子集会引入截断偏差"。独立算 `P(|z|>4.685)=2.80e−6` 后**这个假设被否定**——在 c=4.685 下截断只切 2.8 ppm，MAD(inliers) 是高斯模型下的一致估计。如实记录（AUD201-016）。
5. **未证伪**：任务书第 4、5、6 项的前提（线性数据形态、NO_DATA 语义、物理闭合）经核**成立**，我没能证伪它们；只在第 5 项内部找到一个真实的判据空档（`sigma_residual=0` 假绿，AUD201-011），那不是前提错误。
