### CR-12-02 · "代表性 SIP order 3" 夹具的下标与 SIP 求值映射错位，三阶项实际为零
- 轴：S（主）/ C
- 位点：`:101–:108`，逐字：`w.sip.order = 3;` / `w.sip.a[0] = 1.0e-6;        // dx` / `w.sip.a[6] = 1.5e-6;        // dx^2` / `w.sip.a[12] = -2.0e-8;      // dx^3` / `w.sip.b[1] = -1.2e-6;       // dy` / `w.sip.b[7] = 1.0e-6;        // dy^2` / `w.sip.b[14] = 1.5e-8;       // dy^3`
- 上位依据：`lib/algorithms/drizzle/healpix_drizzle/wcs_sip.cpp:73-76` "下三角: i+j <= order … 公式: result = Σ_{i+j<=order} coeffs[i*6+j] * dx^i * dy^j"（i=dx 幂、j=dy 幂、行步长 6）。
- 现状：order=3 时求值可达下标集为 {0,1,2,3, 6,7,8, 12,13, 18}。据此：`a[0]`=(0,0) 常数项（非 dx）、`a[6]`=(1,0) 一次 dx（非 dx²）、`a[12]`=(2,0) 二次（非 dx³）、`b[1]`=(0,1) dy（唯一正确）、`b[7]`=(1,1) dx·dy（非 dy²）、`b[14]`=(2,2) 总阶 4，**`evalSipT` 的 `j<=order-i` 循环永不读取**。
- 差在哪：名为三次畸变的夹具里没有任何三阶项；实际扰动是常数偏移（1e-6°≈3.6 mas 的等效 CRPIX 位移）+ 一次项（1.5e-6、−1.2e-6 与 CD 矩阵线性相关，等效改像元尺度）+ 二/混合项，`b[14]` 是纯死值。
- 后果：Gate P1 "含代表性 SIP" 变体的证据含义不成立——任何只在三阶项（或 SIP 系数下标语义）上出错的生产实现都能通过本门；同批 `p0_sip_order_guard_test`/`mini_sip1000` 的越界负例也不补这个洞。
- 定级：S2（测试夹具，不改产品字节；"SIP 变体已覆盖"主张不成立）
- 怎么算修好：按映射重写下标（三次位应为 `a[18]`(3,0)、`a[13]`(2,1)、`a[8]`(1,2)、`a[3]`(0,3)，`b` 同位），把一次/常数项移出"畸变"夹具或显式标注为 CRPIX/尺度扰动，删除 `b[14]`；改后 :12 的 1e-6(SIP) 门须同时重跑核。
- 置信：CONFIRMED（下标映射与可达集已按 :89 的循环复算）

### CR-12-03 · 面积门取 9 例均值判绿，且参考非数/为零被记为"误差 0"计入均值
- 轴：R
- 位点：`:290 double rel_ref = (reference > 1e-300) ? std::fabs(computed - reference) / reference : 0.0;`（:292 对 `rel_ov` 同形）→ `:294 sum_rel_ref += rel_ref;` → `:314 CHECK(mean_ref < gate_ref, msg);`
- 上位依据：本文件头注 :12 以逐 drop 语义写门（"per drop 记录 … Gate: |computed-ref|/ref < 1e-6"）；AGENTS.md §5 "判据必须非退化：真值无效应时度量归零或判红；恒真门没有证据资格"。
