# 引用文献核验派单前言（CIT 批次共用）

先完整读本文件，再读派单给你的批次清单。你的批次号在派单里给出，记作 `<B>`。

## 0 第一个动作（防全损）

**先建文件再取证**：写 `独立审计/证据/核验-CIT-<B>.md`，内容＝文件头（基线 `c8f64e9a`、网络手段清单）＋ 你分到的每条一行
`## <序号> · <引用件题名略> —— 核验态：未核` ＋ `<!-- PROGRESS: 0/N -->`。骨架未落盘不许开始联网。
**每条最多 3 次网络查询、2 次仓库读取**；用不完就把该条记 `UNPROVEN` 并写明用过哪些标识符、走过哪些途径。每核完 3 条 append 一次。

## 1 每条要给的三个字段（缺一不可，不许并列存疑）

1. **存在性**：`已核` ／ `不存在` ／ `UNPROVEN`。已核必须给**可复核依据**（ DOI→出版社或 Crossref 记录；arXiv→官方 API 回包的 id＋版本号；图书→出版社页或馆藏记录）。
2. **关联性**：该引用在本仓被挂在哪句断言上（批次清单给了代表位点，必须**打开那句原文**），它是否真的支撑那句断言：`关联对`／`关联错`（写错在哪）／`角色错绑`（文献真实存在但被派了它不做的活，例如把专辑文章当"内容总括"）。
3. **版本**：被引内容是否在所指版次里。三种典型错法：同名再版内容不同（量化噪声项 `+1/12` vs `g²/12` 那类）、只有 v2/v3 才有被引内容、概念 DOI 会漂到最新版。给 `版本对`／`版本错（应指 <具体版次/年份>）`／`未钉版次`。

## 2 硬禁令

- **不得凭记忆断定文献存在，不得编造卷页、DOI、arXiv 号、URL。** 解析不到就 `UNPROVEN` 并附你实际用过的标识符——这是合格的交付，不是失败。
- 不得把"标题看起来相关"当作关联对的证据；必须读到该断言所指向的具体章节/公式/表格，或在全文不可得时明确降级为 `关联性 UNPROVEN`。
- 不得修改 `整改/out/文献台账.csv`（共享台账，多路争写）。你的结论只写进自己的成稿，由前台回写。
- 不得写仓库、不得跑构建或门禁；仓库侧只读（`git grep`、`Read`）。

## 3 已验证可用的查询途径（按标识符类型选）

| 标识符 | 途径 | 注意 |
|---|---|---|
| arXiv 号 | `https://export.arxiv.org/api/query?id_list=<id>` | 官方 API 不拦；回包给版本号 |
| DOI | `https://api.crossref.org/works/<doi>` | 会议文集常 400／无记录，改走下一行 |
| ASP Conf. Ser. 会议论文 | `https://aspbooks.org/custom/publications/paper/<卷号>-<页码>.html` | ADS 需 token、Simbad 常 NO_REF、Crossref 400、OpenAlex 403 时**这条路能走通**，给 Author/Title/Parent/Series/Page 逐字段 |
| ADS / Simbad | 浏览器途径 | ADS 需 token；`sim-ref` 对 ASPC 常回 NO_REF |
| 图书／专著 | 出版社页或馆藏记录 | 同名再版务必记年份与版次 |

本环境 shell **有外网**（实测 `curl` 可直取 Crossref／arXiv，比联网工具稳且可批量）⇒ 优先用 `curl`；长回包会被截断，**每次只问一个极小问题**。网关偶发 403 不是目标站拒绝，**重试一次**再下结论。**取回的件一律显式 `-o` 到 `产出/tmp/<批次号>/`，禁止落在仓库目录内**（本轮曾有一次 `curl` 未带 `-o`，把外部件写进仓库根，虽随后删除，却污染了同轮其它路"仓库零改动"的证据）。

## 4 高危形态（这些必须专门查）

① **不存在的标识符**（真号只差末位／I/II 与 arXiv 末位序号绑反，如 `ZO17I/ZO17II` 卷页配对）；
② **伪托节号**（"某手册 §3.3 明示…"而该节实际内容相反，或章节号属另一篇）；
③ **版次未定**（同一作者同一主题的两个版次内容不同）；
④ **按首字母反推的助记**（给论文造出全文 0 命中的"三步法"名）；
⑤ **作者年组合不存在**或年份漂移。

## 5 文末必给

`本批三态计数`（存在性／关联性／版本各档几条）、`UNPROVEN 清单`（附用过的标识符与途径，供下轮换路）、
`新发现的缺陷形态`（本批独有、前面没登记过的）、`覆盖率自报`（已核条数/分配条数）。
