## 2 四条审查轴（每条 finding 必须落进一轴）

| 轴 | 问的是什么 | 典型成立形态 |
|---|---|---|
| **S 支撑** | 这个科学量/常数/公式/容差，凭什么？ | 值写成字面量，`docs/science`、`docs/algorithms`、根设计里没有任何一处规定它；或规定了但**数值与条文不一致**；或条文自己也没有文献/推导/标定来源 |
| **D 设计符合** | 最高设计与上位文档说要做的事，这里做了吗？做法一致吗？ | 设计点名的能力在此只有接口没有实现；实现了但**接的是另一套定义**（如权重用了被上位排除的量）；设计禁的东西在此发生了 |
| **C 上下级一致** | 同一件事，代码／合同／schema／科学文档／登记面说的是同一个吗？ | 合同拒绝的键实现静默接受；两处入口对同一阈值取不同值；注释自称"权威默认"而权威配置里是另一个数 |
| **R 运行时正确** | 这段逻辑在真实输入下会得到什么？ | 静默回退、非数被当 0 计入、除零返回 0 伪装成 0%、判据方向反了、恒真断言、门只看夹具不看产品 |

## 2.5 每个数值的处置表（**本任务的硬验收项，不可省略**）

工作包 AUD-402 的验收门是"常数扫描覆盖源码与配置，**逐个有处置标注**"。因此每个文件读完，除 findings 外**必须先交一张处置表**，逐行列出该文件里出现的**每一个**数值常数、阈值、缓冲系数、截断窗、收敛参数与默认配置值：

```
| 位点(文件:行) | 符号或键 | 现行值 | 它是什么（一句话用途） | 处置 | 依据锚 | 待确认时给保守方向与影响范围 | 置信 |
```

**处置只有五档，必须选一个**：
1. `文献值` —— 给文献标识＋章节/式号（本仓已核文献池可查）；
2. `公式导出` —— **写出导出式**，并说明代码是否真按式算（算则合规，写死则同时报一条 S/D 轴 finding）；
3. `实验标定` —— 给标定件路径与结果位（必须落在跟踪面，指 `run/` 即判不合格）；
4. `结构性不适用` —— 数组维度、枚举基数、位移量、缓冲区尺寸、循环上界、单位换算定义常数等**不进科学语义**的；必须附一句"为什么它不是科学量"，不许空标；
5. `待确认` —— 显式标注，并给保守取值方向与影响范围（这条同时喂 UNRESOLVED）。

**硬禁令（来自工作包 AUD-402 §禁止）**：不许改动任何代码；**不许把经验值默认标为正确**——没有锚就落 `待确认`，不许写"看起来合理"。
同族同值可合并成一行（例：多处 `1e-6`），但要列出被合并的全部位点。宁可表长，不可漏项：**漏一个数值＝该文件未完成**。

## 3 每条 finding 的固定字段（缺字段即无效）

```
### CR-<B>-<序号> · <一句话结论>
- 轴：S / D / C / R（可多选，写主轴）
- 位点：文件:行（必须逐字贴出该行或该表达式）
- 上位依据：哪份文档哪一条说了什么（引原文短句；查不到就写"条文面零提及"并附你搜过的检索式）
- 现状：代码实际怎么做（引用你读到的原文，不许转述成结论）
- 差在哪：为什么这是错的（一句话，不许写"可能有问题"）
- 后果：会让哪个对外主张/判据/产品字节失真；写不出后果即降级为 S3
- 定级：S1（可致产物错值或对外主张不成立，且你**写得出从生产入口到此的触发路径**）/ S2 / S3
- 怎么算修好：改哪几处、必须同批改的东西（防"改对反而判红"）
- 置信：CONFIRMED（自己复算过）/ PARTIAL（缺一角证据，写明缺什么）/ UNPROVEN
```

**判 S1 的硬门槛**：必须能沿生产调用路径逐跳写 `文件:行`。写不出触发路径的最高只能定 S2，并注明"缺运行时触发路径"。
**判 fail-open / 误绿的硬门槛**：先把不等式方向定下来（丢一项只会让秩变小⇒偏红还是偏绿？）。方向没定的"误绿"指控一律作废。

以及**你自己没读完上下文就下的判断**——同一文件里前后各说一遍不算自相矛盾，先确认是不是两个适用域。
