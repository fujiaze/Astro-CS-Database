# 文档现状审计台账（AUD-101 D1 合并件）

本件是 AUD-101 各分片成稿的**装配产物**：一行一份文档，360 份齐；判定原文照登不改写，只在同一文档被多份成稿登出不同判定时**并列双方**。主表是 CSV，本文件承载口径、派生表与自证。

- 主表：`文档现状审计台账.csv`（UTF-8 BOM、全字段加引号、一行一份、`\r\n` 换行）
- 行数：**360**（= 台账口径全集 360 份，逐份有条目，缺项 0）
- 复算命令（行数与列名）：

  ```bash
  python - <<'PY'
  import csv
  rows=list(csv.reader(open(r'独立审计/01_文档\文档现状审计台账.csv',encoding='utf-8-sig')))

  PY
  ```

## 1 口径

### 1.1 列定义

主表列＝AUD-101 前言 §4 的 14 个登记字段（`路径｜标题｜行数｜角色｜主题｜上游｜下游｜是否正本｜重复或重叠对象｜元信息块｜写法违规｜悬空引用｜与上位冲突｜处置建议`）＋`来源成稿`＋`来源条目号`＋`备注`。
`来源条目号` 形如 `DB-03:1.1`（成稿短名 : 该成稿内的小节号或表行号），追溯由这两列承担，正文不写批次叙事。

### 1.2 去重键与路径归一

去重键＝**规范化后的仓库全路径**。归一规则（依次）：取反引号内的首个串；反斜杠→正斜杠；
去盘符与仓库名前缀；去 `./` 前缀；去 `:行号` 与 `:12-34` 后缀；去尾部括号注解（`（仓库根）`一类）；
`docs/docs/…` 对照写法并回 `docs/…`；残短路径（`tasks/X.md`、`.../X.md`）按**唯一后缀/唯一文件名**
在 360 份全集内归位，归位不唯一或归不上的不合并。归一后仍与登记原样不同的，原样留在 `备注` 列。

| 归一结果 | 实例数 |
|---|---|
| exact | 427 |
| 唯一后缀归位 | 10 |
| 唯一文件名归位 | 12 |

被归一改写的登记原样共 22 条（全部是控制包任务书的相对路径与省略写法），逐条见主表 `备注` 列：`python -c "import csv;[print(r['备注']) for r in csv.DictReader(open(r'独立审计/01_文档\文档现状审计台账.csv',encoding='utf-8-sig')) if r['备注'].startswith('登载原样')]"`

### 1.3 合并与并立判

同一文档的多条实例逐字段合并：同值取一；**异值不择一**，主表单元格内以 `〔成稿·载体〕… ⟂ 〔成稿·载体〕…` 并列双方，
并把该字段计入 `备注` 的「并立判字段」。判定列（角色／是否正本／处置建议）的**跨成稿**分歧另立第 3.4 表逐条并列。
同一成稿自带两种载体（一行一份的横向合并表 + 逐份登记块）时两式都取：逐份块作主值；横向表文字被主值包含的
（一览式缩略）不再重复并列，文字确有分歧的仍并列，这类记为 `同稿双式`，不混入跨成稿分歧。

| 分歧类型 | 条数 | 涉及文档数 |
|---|---|---|
| 批间不一致 | 556 | 36 |
| 同稿双式 | 276 | 48 |

### 3.2 处置分布表（处置 × 目录）

处置类别由主表 `处置建议` 列的**首个命中词**定（在 保留/合并/删除/迁移 四类中取出现位置最前者；
四类都不命中记 `其他`，空列记 `未登记`）——组合动作（如「迁移＋降级」「保留＋拆分」）按主处置计一次，
完整原文仍在主表列内。

复算命令：

```bash
python - <<'PY'
import csv,collections
D=['保留','合并','删除','迁移']
def cls(t):
    p=[(t.find(k),k) for k in D if k in t]
    return min(p)[1] if p else ('其他' if t.strip() else '未登记')
def dk(p):
```
