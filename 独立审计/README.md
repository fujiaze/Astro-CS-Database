# 独立审计

本目录是独立审计交付件的存放处：审查报告、随包取证成稿、批次清单与复算件集中在这里，整体为只读参照件。

## 职责边界

- 放：分领域的交付物（01_文档/ 至 08_修复包/）、证据成稿、批次清单、复算与取证脚本、派单规程、运行时辅助件、交接与排查工作区。
- 只读性质：不被代码消费，不被构建与门禁当作判据输入，不参与产品落位。
- 不放：正式文档条款（docs/）、门禁注册表（eng/ci/）、验收证据（artifacts/）。
- 条目构成与阅读顺序以本目录 00_总目录.md 为准。

## 内容

- 00_总目录.md —— 总目录：随包构成、阅读顺序、交付物与来源分片、状态登记。
- 01_文档/ —— 文档现状台账、目标文档架构与迁移合并清单。
- 02_科学/ —— 四条科学链路核验报告、链路间口径对表与常数公式算法总台账。
- 03_小论文/ —— 四篇论文式核验报告（测光、绝对信噪比、天光无缝、面积交叠）。
- 04_代码/ —— 架构对齐报告、经验参数与硬编码清单、注释与 README 审计报告。
- 05_门禁/ —— 门禁清单、门禁体系设计与门禁现状报告。
- 06_实施/ —— 实施任务总览与依赖图、tasks/ 任务书、审查附件。
- 07_未决/ —— 未决问题清单。
- 08_修复包/ —— 按主题分组的修复包与修复包索引。
- 证据/ —— 逐批通读、文献核验与独立复核成稿。
- 批次清单/ —— 每批的文件清单与机械台账（覆盖率的分母）。
- 复算件/ 与 工具脚本/ —— 独立复算、汇编与分片取证脚本及其数据表。
- 派单规程/ —— 派单前置件，写明各分片的判据口径。
- 实验重做/ —— 实验重做的对账件与分歧台账。
- 运行时/ —— 审计运行的监控、排队、验收与恢复指引脚本。
- 交接/ 与 排查/ —— 交接说明与全仓排查工作区。
