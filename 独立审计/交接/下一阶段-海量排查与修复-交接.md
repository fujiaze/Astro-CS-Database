**检查员的检查面（四面）**：
1. **科学性**：常数/公式/单位/量纲/适用域——与 `分歧台账.md` 终裁值及五单元论文对数；负例与判据非退化。
2. **行文逻辑**：论证链断裂、单文档前后矛盾、订正注记新旧两说、UNRESOLVED 混入正文。
3. **跨文档冲突**：同一量在不同文档的口径；权威链五方（L1↔docs↔实验↔修复包↔源码）主张兼容性。
4. **幻觉与锚**：文献题录 web 核验（DOI/arXiv 抽验）；file:line 锚逐条实开文件/源码核对；**「文档说有、代码没接」专项**——文档声称的行为/配置键/合同字段在源码里是否真实存在并接线（含配置死键、静默旁路、schema 与文档漂移）。

**问题清单格式**：编号/严重级(红=必须改/黄=建议改/绿=可不改)/文件:行/问题描述/证据（对照来源，含反方核验）/建议改法。红黄必须附证据；禁止为凑数报琐碎；每片末尾写明"已查无问题面"。**只查不改，零 git 写。**
