# Schema边界

现有JSON Schema负责envelope、CLI输入形状、资源和事件；typed对象字段/签名以contracts.hpp唯一拥有，science-input/cli-science/manifest按既有生成器同步。合法形状不等于单位/index/PSD/支持/身份/闭包语义有效。

本轮仅改文档，不修改schema。API的E01—E07实施清单与目标诊断策略/执行选择需在后续声明和decoder修订时逐字段接入；当前schema不得被描述为已接受execution/diagnostics或设备配额。运行时设备句柄、容量arena与指针不进入科学wire；开发记录与科学协议分别验证。未知字段、未支持operation必须具名拒绝。
