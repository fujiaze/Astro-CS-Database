feat(WP-H): CLI+Browser 接入新 HISS Reader/Writer (步骤14)

WP-H 步骤14 集成实现: 将新 HISS Reader/Writer 接入 CLI 和 Browser。

CLI stage1 命令扩展 (cli_command.cpp/.h):
- 新增参数: --nside/--pixfrac/--dark/--flat/--bias/--photscal/--apply-photometry/--threads
- 支持位置参数 <input.fits> -o <output.hiss> 和旧形式 --frame/--output
- 输入验证: pixfrac (0,1]、nside 2的幂 [16,4194304]、文件存在性
- 诊断输出: NSIDE/pixfrac/Tile count/文件大小/处理时间 (调用 aio_hiss_inspect)
- 参数合并到 config_json 传给 run_stage1

HISS C API 新增 (aio_healpix_io.h/.cpp):
- aio_hiss_inspect: 只读 Header+Tile目录 (不加载像素), 供 CLI 诊断和 Browser 首次打开
- aio_hiss_read_tile_signal/support/snr: 按 Tile parent_ipix 读取子块数据
- aio_hiss_query_pixel: 通过 ra/dec 查询像素值 (与 HissReader 一致)

Browser 后端集成 (browser_backend.h/.cpp):
- 新增 HissHeader/HissTileData 结构体
- load_hiss: 只读 Header+Tile目录, 不加载整文件
- read_tile_signal/support/snr/query_pixel: 调用 C API
- 修复 open_file: 识别新 HISS 格式 magic "ACSH" (8字节 "ACSHISS\0" 的前4字节)
  旧格式 "HISS" 和新格式 "ACSH" 均由 aio_hiss_read 统一处理

Browser UI (main_window.cpp/.h):
- HISS Tile 浏览面板: Tile 列表 + 图层选择 (signal/support/SNR) + 2D 渲染 + ra/dec 查询
- setup_hiss_tile_panel: 左侧 Dock, 默认隐藏, 打开 .hiss 时显示
- on_tile_selected: 读取 Tile signal/support 并渲染灰度图
- on_query_pixel_clicked: ra/dec 查询像素值

集成测试 (test_wph_cli_browser.cpp):
- 13/13 通过: inspect/read_tile_signal/read_tile_support/read_tile_snr/query_pixel
- CLI 参数验证: pixfrac/nside/文件存在性 返回正确错误码 (28/8/1)
- browser_cli 成功加载新 ACSH 格式 HISS 文件 (4.2ms)

已知限制:

  (非 WP-H 缺陷, 是测试数据问题)
