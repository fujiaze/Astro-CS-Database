# 裁决台账 —— 五个实验单元的跨单元分歧终裁

本文件是科学链 P1–P5 实验重做对账的**跨单元裁决落点**。凡正文中以 `D-xx` 引用的裁决，
全文条款在此；逐单元裁决 `A-P1-xx` / `A-P2-xx` / `A-P3-xx` / `A-P4-xx` / `A-P5-xx`
分列于各单元的 `docs/DISPUTES.md`；其中改变科学正本公式、常数取值或判据口径的部分，
同步件见 `docs/science/DISPUTE_RESOLUTION.md`。

## 编号与读法

- `D-xx` 是**条款 ID**，不是流水号：条款一经落定即以该 ID 被各单元正文引用，ID 不重排、不回收。
- 每条给出四段：**冲突**（分歧的两种或多种说法）、**终裁**（现行取值与口径）、
  **依据**（一手文献 / 上游开源实现 / 仓内实测读数）、**落点**（本条在仓内的承担面）。
- 依据只写可核面。凡本轮对账未给出可核锚的，条目内写「**依据未给，待补**」，
  并在 §5 汇总；不补造依据。
- 裁决一律按**现行条款**表述：写「终裁为 X」，不写变更过程。

## D-01 HEALPix 像元外接半径口径

- **冲突**：
  - 说法甲（全域穷举，N=4…64，真像元中心→角点）：`max(角距/hp_res) = [0.9941, 1.0196, 1.0322, 1.0384, 1.0415]`，随 N 单调升、收敛 ~1.0415，最坏在赤道带缝附近。
  - 说法乙（极冠 ring 逐环取心，N=4→64）：`max = 1.13233 / 1.12936 / 1.12862 / 1.12844 / 1.12839`，随 N 单调降、收敛 ~1.1284，最坏 dec +73.40°→+88.97°（极冠 ring 1）。
  - 附带读数：控制点上球角距 ≤ 0.5941·hp_res。
- **终裁**：以「**像元中心 → 边界最远点角距 / hp_res**」计的全天 sup = **1.0415**（N=64 实测）。
  `HP_CIRCUMRADIUS_FACTOR = 1.25` 的安全裕量 **≥ 20.0%**（1.25/1.0415 = 1.2002）。
  数值 **1.1284 = √2·ρ₁/hp_res = 2/√π**（ρ₁ = arccos(1−1/(3N²)) ≈ √(2/3)/N）是**极冠 apex 叶的对角尺度**
  （极点 → 叶远角），**不是外接半径**，不得记作外接半径。
  两个口径下 1.25 均安全（1.0415 与 1.1284 均 < 1.25 ≪ 经纬对照格反例 4.516），
  故 `HP_CIRCUMRADIUS_FACTOR` 判为**结构性安全缓冲、非科学量**的豁免结论维持。
- **依据**：说法甲、丙为全天穷举实测（固定 seed 存档读数，固化于 `实验/healpix-polar/results/audit/`）。
  说法乙的收敛值 1.12839 与闭式 `2/√π = 1.1283792` 五位一致；`√2·ρ₁ = (2/√3)/N` 恰为极冠 apex 叶
  （chart 方块 [0,1/N]²，极点为一角）外角 (1/N,1/N) 的极角。apex 叶真实中心 (1/2N,1/2N) 到边界最远
  约 0.69·hp_res，不构成更坏点。最小裕量 1.25/1.0415 = 1.2002（≥20%）。经纬对照格反例 4.516 击穿 1.25，
  证明该系数的 HEALPix 特化性。
- **落点**：本条；`实验/healpix-polar/docs/DISPUTES.md` A-P3-08（depth 面相邻）与
  `docs/science/DISPUTE_RESOLUTION.md` §1（正本落点 `docs/science/DRIZZLE.md`、
  `docs/science/algorithms/DRIZZLE_GEOMETRY.md`）。

## D-02 极冠边弦矢高残差幅度与矢高常数单位

- **冲突**：
  - 说法甲（实测梯子，细分比 3.651→3.999，十层渐近 4.0）：`depth_needed = 7.971`（Górski 口径 `sag0 = 6.30e-2`），
    `depth = 8` 残差 = **1.153e-6·hp_res**，超 1e-6·hp_res 预算 **15%**；解析值 1.234e-6 = 8.094e-2/4⁸ 在其自身
    sag0 下算术自洽。
  - 说法乙（实测梯子，早期层收敛因子 0.275/层，慢于解析 1/4）：达到 1e-6·hp_res 需 7.98 层；
    `depth = 8` 残差 = **3.15e-6·hp_res**，超阈 **3.15 倍**。并判矢高常数 `8.094e-2` 的「hp_res」单位标注存疑
    （实测 0.08012·ρ₁ ≈ 0.066·hp_res）。
  - 冲突焦点：残差与阈值是否同以 hp_res 计，以及 3.15 倍与 15% 哪一个是名义幅度。
- **终裁**：
  1. 残差与阈值**统一以 hp_res 计**后，depth = 8 的**名义幅度为超预算约 15%**（实测 1.153e-6·hp_res）；
     **3.15 倍是保守上界**（其梯子早期层收敛比 3.65 显著慢于解析 1/4，属更保守的细分日程）。
  2. 矢高常数记账为 **`sag0 = 8.094e-2·ρ₁`**（ρ₁ = arccos(1−1/(3N²)) ≈ 0.8165/N）**≈ 0.066·hp_res**。
  3. **`max_depth` 须取 9 以上**方能稳妥清偿 1e-6·hp_res 极冠矢高预算（depth = 9 在全部读数下清偿：
     最保守 3.15e-6/4 = 0.79e-6 < 1e-6，名义 1.153e-6/4 = 0.29e-6）。生产实现取 **12**，已满足；
     若取 8，须把预算放宽至 2e-6·hp_res 并如实登记。
- **依据**：说法甲、乙均为实测细分梯子；两路实测矢高 0.0630–0.0639·hp_res；
  ρ₁ ≈ √(2/3)/N。生产 `spherical_overlap.cpp:857` 的 `WCS_ADAPTIVE_MAX_DEPTH = 12` 为行为事实源。
- **落点**：本条；`实验/healpix-polar/docs/DISPUTES.md` A-P3-08；
  `docs/science/DISPUTE_RESOLUTION.md` §2（正本落点 `docs/science/algorithms/DRIZZLE_GEOMETRY.md`）。

## D-04 MAD–σ̂ 相对标准误系数 c(n=64) 的取值

- **冲突**：
  - 说法甲：c = **1.152**（天光预算链取值）。
  - 说法乙：c = **1.144**（审查方数字）。
  - 三路分别给出「支持 1.152」「<1σ 不可分辨」「来源未定」。
- **终裁**：**值取 1.152**。天光预算按 `(1.152×1.25/0.015)² = 5816.6` 记；复合口径
  `1.44 = 1.152×1.2533`、`N_sky ≥ 9216 = (1.44/0.015)²` 维持。
  **登记义务保留**：`c = 1.152` 的原始标定记录须补入常数表（见 §5 待补项 REG-01）。
- **依据**：20 万次 MC 直接测量 c(64) = 1.1508（M = 20 万行）与 1.1542（M = 1200），
  相对 1.152 偏差 +0.19% —— 唯一有单值裁决力的证据；1.144 支的唯一历史正支撑算术有漂移
  （预算 5811 应为 5816.6；9216 = (1.44/0.015)² 精确成立），无独立正向证据；
  合并支 MC c ≈ 1.148(n=9216) / 1.165(1024) / 1.168(64)，MC 误差 ±0.02，闭式渐近 1.1664，
  1.152 与 1.144 在其 MC 功效内 <1σ 不可分辨，而该路的**直接管线测量** c ≈ 1.449（n=9216）⇒
  N_min ≈ 9321，与 9216 预算差 1.2%，支持 `1.152×1.25 ≈ 1.44` 复合口径；
  管线级 c_eff = 1.4751 ± 0.023。
- **落点**：本条；`实验/absolute-snr/docs/DISPUTES.md` A-P2-01 相邻面；
  `docs/science/DISPUTE_RESOLUTION.md` §4（正本落点 `docs/science/NOISE_MODEL.md` §5a）。

## D-05 IDW 默认衰减指数

- **冲突**：
  - 说法甲：默认 `idw_power = 2`（无噪光滑场上 p=2 显著优于 p=1）。
  - 说法乙：含噪工况下最优 p ≈ 0.5–1，p=2 差 2–3 倍，且 p=2.0 与 K=16 均无标定记录。
- **终裁**：**默认 `idw_power = 1.0`**（取含噪最优带 0.5–1 的上端）。
  口径固定为三句：
  1. **p = 2 是无噪／光滑极限最优**；
  2. **生产含噪默认 p = 1.0**；
  3. p* 随噪声档与场曲率变化，**不冻结单一「最优值」**——`idw_power` / `K` 配置化，
     每次重建在日志输出实测 p*（argmin）、K 与噪声档。
  IDW 整体保持**备选口径**；生产默认重建算子见 D-10。
- **依据**：参数全扫 p ∈ {0.5…3} × K ∈ {4,8,16,32,all} × 噪声 {0, 2%, 6%}，
  1024² 场、Δ = 64：无噪 p=2.0/K=4 最优（1.639e-3）；2% 噪声 p=0.5/K=16 最优（6.827e-3）；
  6% 噪声 p=0.5/K=32 最优（1.414e-2）。独立对照（512² 光滑高斯斑真值、无噪）显示
  IDW p=1 显著劣于 p=2/p=4。生产控制点值携带 ±2–6% 量级测量噪声。
  诚实边界：真实 SNR 场的源核陡梯度会使 p* 向大偏移。
- **落点**：本条；`实验/dense-snr-reconstruct/docs/DISPUTES.md` A-P4-03；
  `docs/science/DISPUTE_RESOLUTION.md` §5（配置面，见 §6 待执行项 CFG-01）。

## D-07 有限 N 下中位数方差渐近式的偏差方向

- **冲突**：
  - 说法甲：N = 5 时渐近式 `k_corr·(π/2)·σ_bg²/N` 对 Var(median) **低估 8.5%**。
  - 说法乙：N = 5 时**高估 ≈9.6%**（端到端口径则 ≈ −1%）。
- **终裁**（三口径现行表述，四路一致）：
  1. **纯公式口径**：N = 5 时渐近式对 Var(median) **高估 ≈9.5%**（精确阶统计量积分 9.53%），
     偏差方向**保守**（权重偏小）；
  2. **端到端口径**（σ_bg 由同 patch MAD 估计）：偏差 **≤ ±1.5%**；
  3. **生产链亮端裁剪臂**：**低估 1.3–3.2%**（亦为保守）。
  公式本体与 **N ≥ 65 适用域（偏差 < 2%）** 维持。
- **依据**：精确阶统计量积分 —— N=5 个标准正态的中位数即次序统计量 x₍₃₎，
  密度 `f(x) = 5!/(2!·2!)·Φ(x)²·(1−Φ(x))²·φ(x)`，数值积分 Var(x₍₃₎) = 0.286834，
  渐近式 π/2/5 = 0.314159，比值 1.0953。端到端臂：纯公式/真值 = 1.096，端到端 = 0.990。
  另一路实测 true = 0.913 × formula（2M MC 双证）。补实验三口径定稿，另 κ 四点
  rel −0.86% ~ +0.19%，均在 MC 误差内。
- **落点**：本条；`实验/additive-sky-seamless/docs/control-variance-adjudication.md` §2（推导与实验腿）；
  `实验/absolute-snr/docs/DISPUTES.md`；`docs/science/DISPUTE_RESOLUTION.md` §6
  （正本落点 `docs/science/algorithms/PHASE2_SAMPLER.md` §5.4）。

## D-08 k_corr 的身份与取值口径

- **冲突**：
  - 说法甲：`k_corr = 1.4`（声称 MC 1.3883）是**普适常数／可跨几何复现的标定值**。
  - 说法乙：1.4 不可复现，属**几何专属实测值**，冻结 1.4 在其声明域内不保守。
- **终裁**：
  1. **身份**：`k_corr = 1.4` 是**正本标定几何专属的单次 MC 实测值**，不是普适常数。
     标定几何 = 源 300″/px、nside=512 → 412.26″/px、pixfrac = 0.8、全 touched patch
     N ≈ 225–251、逐实现 MAD 取跨实现中位。标称「MC 1.3883」的现行表述为
     **「标定几何专属 MC 实测带 1.27–1.43（中心 1.34±0.04），1.3883 为该带内一次实现」**。
  2. **公式面**：`k_corr = k_gauss(N_retained) × k_geo(几何)` 两因子式 ＋
     (ρ = 输出/源尺度比, pixfrac, 帧数/dither, patch 构成) 几何查表。
     代码默认 1.4 是**实现记录**，不是普适常数。
  3. **冻结 1.4 在其声明标定域（pixfrac ∈ [0.5,1] × 源 [300,600]″/px）内不保守**：
     N = 5 端 `k_corr(5,紧凑) ≈ 2.05 ± 0.09` ⇒ 1.4 低估 control_variance **32%**
     （标准误低估 14%；空间分散 1.54）；源 583–600″/px 端 `k_corr ≈ 2.5–3.0` ⇒ 低估约 **2 倍**。
  4. **引用义务**（任何引用 `control_variance` 的陈述必须同时声明）：
     ① 标定元组与 N_retained 档位（N ≤ 25 时 `k_gauss(N) > 1.08` 不可忽略；
     N = 5 紧凑 patch 须 ≥ 1.6、分散 1.54）；② 几何不匹配时 **fail-closed 拒绝或现场 MC 重标**。
- **依据**：Fruchter & Hook 2002 全文子串级检索**无** 1.3883 / 1.4 / k_corr；
  该文唯一定量相关噪声量为 `R = σc/σp = 1.662`（§7 式(8)–(10)，p = 0.6、s = 0.5 例），
  属不同估计量、几何与口径，数值接近属巧合。受控复现（16 相位 × 8 seed）
  1.3445 ± 0.0416，range [1.273, 1.425] 含 1.3883（上沿）。
  `k_shape`（非高斯边际形状）N ≥ 9 时 ≤ ±5%，可忽略，不进公式面。
  `k_geo` 扫描：紧凑 patch ≈ 1.27±0.03、全 touched ≈ 1.43–1.45、空间分散 ≈ 1.00、
  几何扫描全域 1.00–5.0；多帧 1/2/4 帧 = 1.424 / 1.338 / 1.328。
- **落点**：本条；`实验/additive-sky-seamless/docs/control-variance-adjudication.md` §3
  （推导与实验腿）；`实验/healpix-polar/docs/DISPUTES.md`；
  `docs/science/DISPUTE_RESOLUTION.md` §7
  （正本落点 `docs/science/UNCERTAINTY_AND_COVARIANCE.md` 与 `docs/science/DATA_SEMANTICS.md`）。

## GA-02 不存在「权重模式」概念

- **终裁**：
  1. **全程的科学量是 SNR**，不是权重。HiPS 内**存**：帧级 SNR ＋ 稀疏的相对 SNR 比值。
  2. **权重不是被存的东西**，是阶段二消费 SNR 时**按该位置上像素对应的帧集合现场算出来的**派生量，
     **不是配置项**。
  3. 三套键名一并作废：`weight_mode`（CLI `{1,2}`）/ `algorithm_weight_mode`（schema 三词）/
     `weight.default_mode = psf_information_weight`（defaults）。
  4. 变量名直接叫 `weight`；设计层与详细层的一切「权重模式」「权重档位」「mode0/mode1/mode2」
     表述不成立。
  5. 阶段一/阶段三**不产生、不消费权重**。
- **依据**：负责人裁决（逐字）：「在 HiPS 里面存的是帧级 SNR 和稀疏的相对 SNR 比值。全程都是 SNR 才对。
  只有阶段二消费 SNR 的时候，根据这个位置上像素对应的集合计算权重，其他时候哪里有权重？」
  机器判别面见 `docs/engineering/01_CHECKS.md` 的 `CHK-NO-WEIGHT-MODE` 族与
  `docs/science/DATA_SEMANTICS.md` 的禁用键行（配置出现该键 ⇒ 具名 fail-closed 拒绝）。
- **落点**：本条；`docs/ASTROCS_DESIGN.md` §3.1；`docs/science/DATA_SEMANTICS.md` §31.8；
  实现锚 `lib/algorithms/coverage/src/stage2_common.cpp` 与
  `lib/infrastructure/scheduler/src/module_adapters.cpp` 的具名拒绝分支。

## GA-05 合成测试必须模拟真实物理实现

- **终裁**（适用于**全部**合成/注入类实验）：
  1. **必须模拟噪声物理过程**，不是算术地改像素值：源、天光、暗电流各自 Poisson（电子域）；
     读出噪声 Gaussian（电子域）；增益/量化（电子 → ADU 的 g、饱和、量化）；
     平场/响应 `m(x,y)`；天空梯度/加性天光的空间分布。
  2. **天光对 SNR 的影响必须通过散粒噪声体现**：`B`↑ ⇒ `σ²_pix ⊃ B/g` ↑ ⇒ `σ_F` ↑ ⇒ SNR ↓。
     **不得**用「加常数」代替「加天光」。
  3. 优先用**真实数据作底**叠加模拟噪声过程，使合成数据具备真实星场、PSF 与背景结构。
  4. **合成测试必须能红能绿**：负例（真值为「无效应」）下度量必须归零。
- **依据**：负责人方法论纠正（逐字）：「实际拍摄天光影响信噪比是因为光子散粒噪声。而如果你只是用加法增加做实验，
  那没有区别……合成测试必须模拟真实物理实现。」反例：固定源通量、算术地给像素加常数当作「加天光」时，
  已扣背景的 `F̂` 与 `σ_F` 都不变，测不出任何东西。
- **落点**：本条；`实验/absolute-snr/docs/snr-propagation-design.md` §2.1.3 与 §13；
  `实验/shared/data/README.md`。

## GA-06 测光标定消除物理单位，只使用星等

- **终裁**：
  1. 标定目标是**真实测光坐标系（星等）**，手段 = 星点光通量积分 ＋ Gaia ＋ CCD QE ＋ 滤镜透过率；
  2. **消除物理单位，只使用星等**；
  3. `k_photo` 的绝对值**无物理意义**（它把增益/口径/曝光等未知量全部吸收），
     **不得**用任何物理闭合式（`k = g·h·c·1e9/(A·t)` 之类）反推仪器参数或论证其合理性；
  4. 有意义的判据只有两个，且**均尺度无关**：
     - **测光一致性**：施加后星点星等与 Gaia 的残差（散度/MAD）必须小；
     - **帧间一致性**：各帧 `k` 必须落在同一测光体系（组内一致性）。
  5. **不存在有意义的 `k_photo` 绝对窗口**（绝对值依赖未知仪器参数）。
- **依据**：负责人纠正（逐字）：「正是因为 fits 文件头里面没有办法获得 adu，口径之类的具体数据……
  所以我才要求使用星点光通量积分和 gaia 数据库 + CCDQE 和滤镜透过率曲线，将图像标定到真实测光坐标系，
  消除物理单位，只使用星等。」
- **落点**：本条；`docs/science/PHOTOMETRY.md`（k_photo 正本）；
  `实验/photometric-magnitude/docs/fsyn_convention.md`。

## GA-07 阶段二默认消费稀疏 SNR 层

- **终裁**：
  1. 阶段一**默认产出**稀疏层（Δ = 64 px）；
  2. 阶段二**默认消费**稀疏层（`snr_path = sparse_reconstruct`），**不按 SP-0 判据决定是否消费**；
  3. 三条路径全部保留（`dense` / `sparse_reconstruct` / `frame_reconstruct`），JSON 可显式指定，
     供论文精度对比；
  4. **SP-0 保留为诊断量**（输出实测 `Var_p` 比值），**不作为默认开关** ——
     其否定结论只在共模场景（同条件、完全重叠帧）成立。
- **依据**：共模权重误差完全免费（`Var_approx/Var_opt = 1 + Var_p(δ)` 在共模下实测比值恰 1.000000），
  只有帧间空间形状差异才起作用；马赛克＝不同指向/不同夜晚，帧间空间形状差异大，共模抵消不成立。
  单帧 SNR 重建 RMSE(log SNR) 实测：64 px 稀疏重建 **0.12307** < 帧级标量 **0.13666**。
- **落点**：本条；`docs/science/CONTROL_WEIGHT_SNR.md`；`实验/absolute-snr/docs/`。

## GA-08 论文工作区按「数据类型」组织真实 ＋ 合成测试

- **终裁**：
  1. 论文工作区内**按「数据类型」分布测试**，覆盖真实数据 ＋ 合成数据两条腿；
  2. 合成数据必须满足 GA-05（电子域 Poisson ＋ Gaussian ＋ 增益量化 ＋ 平场乘性 ＋ 天空梯度），
     **严禁纯加性天光**；
  3. 测试矩阵至少覆盖：按目标（亮星云核心/一般星场/稀疏场）、按指向（同指向重叠 / 不同指向马赛克）、
     按条件（seeing、天光水平、曝光）、按仪器（口径/像素尺度/增益）、按波段（R/G/B/Ha/OIII）；
  4. 每类数据都要有**真实数据实例 ＋ 可复跑的合成数据配方**；
  5. 每类都要**能红能绿**（负例：真值「无效应」时度量归零）。
- **依据**：负责人令（逐字）：「论文那个文件夹内应该分布测试真实数据和合成数据
  （必须是真实物理噪声过程，不能是纯加性天光）来测试不同数据类型」。
- **落点**：本条；`实验/shared/data/README.md`；`实验/additive-sky-seamless/code/reverse_verify/data_matrix/`。
