## C1（建议订正）σ_floor 的下界在 `n ≤ 12.236` 时**不存在**，过裁剪样本不得静默 PASS（**P1-M07 订正版**）

- **判据原文**：`sigma_floor = (1 − 3·1.166/√n)·sigma_fit(白)`。
- **问题**：`1 − 3·1.166/√n` 在 `n ≤ (3·1.166)² = 12.236` 时**非正** ⇒ 3σ 下包络在数学上不存在（统计事实，不是缺陷）；缺陷在于**处置方式**。
  于是**把样本裁剪到只剩同质星**（σ_obs 单调下降）时，σ_obs 仍高于 floor ⇒ 判据不判红；
  若再按历史建议把它 clamp 成 `max(rho_lo, 0)`，则下界恒为 0 而 `σ_obs ≥ 0` 恒成立 ⇒ **恒真门**。
- **实测**（`step7_negatives.json → N5`，复现 `python3 实验/photometric-magnitude/code/step7_negatives.py`）：
  对帧 A 的**实测**通量按 `|r − median(r)| < tol` 逐步裁剪：

| 裁剪 tol | n | σ_obs [mag] | σ_floor | 判定（**订正后**） |
|---|---|---|---|---|
| 不裁剪 | 48 | 0.04534 | 0.00964 | PASS |
| 0.05 | 45 | 0.03803 | 0.00859 | PASS |
| 0.01 | 22 | 0.01976 | 0.00293 | PASS（`rho_lo = 0.256 > 0`，作用域仍 `two_sided`） |
| 0.002 | 5 | 0.00356 | −0.00491 | **`LOWER_BOUND_UNDEFINED`（作用域 `upper_only`，不再记 PASS）** |

- **后果**：该判据的下界对"把样本做干净"没有判别力。**但**历史用 `max(rho_lo, 0)` 夹逼把它掩成"PASS"，是**双重缺陷**：下界既不可验、又恒真。
- **建议（已订正，原建议撤回）**：下界**不得**改用 `max(rho_lo, 0)·sigma_fit`——clamp 之后下界恒为 0，而 `σ_obs ≥ 0` 恒成立 ⇒ 下界**永不触发**，比原缺陷更隐蔽，属**恒真门（无证据资格）**，违反 `AGENTS.md` §5「判据必须非退化」。
  正确做法是**显式最小样本规则**：`rho_lo ≤ 0` ⟺ `n ≤ (3·1.166)² = 12.236` 时，判据作用域降级为 `upper_only`、状态词返回 **`LOWER_BOUND_UNDEFINED`（不记 PASS）**，并把 `n`/`gate_scope` 一并报出。
  对「把样本裁到只剩同质星」的判别力来自**上界与状态词**，不来自被 clamp 的下界。
  **已落地**：`code/scia_common.py → Budget.lower_bound_defined / gate_scope / gate_verdict`；`results/step7_negatives.json → N5` 负例；正本 `docs/science/PHOTOMETRY.md` §16.5 第 3 条已同步。

## C2（建议订正）σ_psfsys 的「PSF vs 大孔径」估计量在强星云场被结构污染，可达真值 10 倍

- **原文口径**：用 PSF 域通量与独立孔径通量之比的中位绝对偏差作为 σ_psfsys。
- **实测**（`step5_calibration_gate.json → items_measured`，复现 `python3 实验/photometric-magnitude/code/step5_calibration_gate.py`）：

| 帧 | r=10 px 孔径估计 | r=4 px 孔径估计 | 真值口径 |
|---|---|---|---|
| A（HST M16 模板，透明 1.0） | 0.2574 mag | **0.0250** mag | 0.0256 mag |
| B（透明 0.62） | 0.2557 mag | **0.0401** mag | 0.0344 mag |
| C（拥挤扩展星场） | 1.3775 mag | **0.1061** mag | 0.0394 mag |

  在拥挤场仍高估 ~2.7×（保守方向，判据偏松不偏紧）。
- **建议**：明确 σ_psfsys 的孔径口径为"小孔径 + 低背景星子样本"，并登记拥挤场的 2.7× 上偏。

## C3（能力边界，建议写进文档）σ_obs 双边界判据对**算术相加的确定性天光结构**不敏感

- **实测**（`step7_negatives.json → N2.arithmetic_gradient_control`）：
  对帧**算术相加** `gx·(x−W/2)`（无散粒噪声）：
  gx = 0 → 0.4 ADU/px 时 σ_obs 0.04534 → 0.04897（**1.08×**），始终 PASS。
- **机理**：PSF 拟合自带局部常数背景，确定性加性结构只通过背景扣除残差进入误差，量级远低于光子噪声。
- **对照（物理口径）**：把天光抬升**经 Poisson 前向重画**（`sky×1/2/4`）：σ_obs 0.0252 → 0.0481 → 0.0734
  （**2.91×**，4× 时判红）。⇒ **判据对散粒噪声敏感、对确定性加性图样不敏感**。
- **后果**：该判据不能认证天光**扣除**质量；能认证的是天光**噪声**是否被正确预算。
- **建议**：把这条写进判据的适用域，并另设天光扣除残差检查。

## C8（已核验，无需订正）Horne 解析式与"自由背景"精确 Fisher 式的差别不是文档错误

- `run/RELEASE-02/parallel/06.md` §2.2（第 100 行）给的是 **Horne 1986 最优提取结构**
  `σ_F/F = sqrt(1/(g·F) + N_eff·σ_pix²/F²)`，它假定**背景已知、无自由背景参数**；
  `06.md` §2.1 的 `σ_fit = 0.0140` 是生产拟合器 **200 次重复拟合的实测值**，不是该解析式的取值。
- 本实验的 `psf_fit_variance_exact` 多了一个**自由常数背景**参数，因此多出 H01 交叉项，方差更大。
  两者之差就是"自由背景简并"的代价（实测 1.13–2.15×），**不是文档错误**。
- **结论**：无需订正。仅建议在文档里补一句说明"解析式与生产实测值的口径差异来自自由背景项"。

## C9（**blocker，已订正**）σ_flat 取用与被测统计量同源的 `delta_after_m` ⇒ 上界自指、判据失去判别力

- **问题**：`calibrate()` 返回的 `delta_after_m` 是**同一批星、同一条残差链**上「去掉多项式模型」后的散度；
  它与 `sigma_obs = 2.5·MAD(r_inliers)/0.6744897501960817`（去掉常数模型）只差所拟合的模型，是同一个估计量。
  把它当作 `σ_ceiling` 的独立预算项 ⇒ **上界随被测统计量同步膨胀**；真实帧上该项占上界方差 **47.6%**
  （`delta_after_m = 0.019561` mag，其余项合成上界 = `sigma_flat_sweep` 的 `σ_flat = 0` 档 `0.020541` mag
  ⇒ `0.019561²/(0.020541² + 0.019561²) = 0.476`，自指口径 `σ_ceiling = 0.028366` mag）。
  表现：仿真帧 A/B/C 与真实 M42 帧**全部 PASS**，且该 PASS 不能证伪。
- **反例化**（`step7_negatives.json → N6`，复现 `python3 实验/photometric-magnitude/code/step7_negatives.py`）：
  对帧 A 实测通量乘 `10^(0.4·amp·N(0,1))`（逐星独立、**与空间平场无关**），同一批通量并行跑两种口径：

  | 注入散度 [mag] | 自指口径 `σ_ceiling` | 自指判定 | 独立口径 `σ_ceiling` | 独立判定 |
  |---|---|---|---|---|
  | 0.00 | 0.0562 | PASS | 0.0483 | PASS |
  | 0.02 | 0.0792 | **PASS** | 0.0481 | PASS |
  | 0.05 | 0.0967 | **PASS** | 0.0479 | **ABOVE_CEILING（判红）** |
  | 0.10 | 0.1605 | **PASS** | 0.0481 | **ABOVE_CEILING（判红）** |

  ⇒ 自指口径**对与平场无关的逐星散度完全无响应**（恒 PASS）；独立口径在 0.05 mag 判红。
- **订正**（变更 claim `PHOT-SIGMAFLAT-INDEP-001`）：
  ① 仿真帧取**真值**逐像素平场散度经 `N_eff` 折算——`σ_flat = (2.5/ln10)·s_flat/√N_eff`，
     `N_eff = 1/ΣP_i²`（`code/scia_common.py → sigma_flat_independent`），只依赖仪器/仿真真值与 PSF 形状；
  ② 真实帧取**仓内约定常数** `σ_flat,hf = 0.0007 mag`（活出处 `code/scia_calib.py:31` 的字面量 `SIGMA_FLAT_HF_CANONICAL`；**一手出处未取得**，被归给的 `docs/detail/registry/astrocs.phase1.photometry.md`「数值落地口径」（内的「测光一致性判据（单帧、尺度无关、双边界）」 与 `docs/science/PHOTOMETRY.md` §16.4 对应行在当前树均不存在）；
  ③ `delta_after_m` 降级为**诊断字段** `delta_after_m_diagnostic` / `delta_after_m_role = diagnostic_only`（JSON 中显式标注），**不得**再进 `σ_ceiling`。
- **后果（如实）**：真实 M42 帧判定由 **PASS 翻为 `ABOVE_CEILING`**：
  `σ_obs = 0.026520 mag` vs `σ_ceiling = 0.020561 mag`（n=157，inlier 151；`σ_floor = 0.006008`）；
  仿真口径（σ_flat = 0.000881）下 `σ_ceiling` 收紧为 0.04847/0.07010/0.14815，三帧仍 PASS。
  使真实帧翻绿的临界 `σ_flat = 0.013057 mag` = 该约定值的 **18.7 倍**。
  ⇒ 本单元三类数据结论**不一致**，按审查标准 §6 记创新点**不成立（待修）**；该判红只可归到「未消系统项超预算」这一层，
  **具体归因（平场 / PSF / 颜色 / 探测器非线性）不可由该门给出**——`sigma_obs_mag` 在 `m(x,y)` 之前算，门对成因失明（见 `README.md` §6 第 20 条）。
- **诚实边界**：0.0007 mag 的一手出处**未取得**（仓内唯一活着处是代码字面量），只能作仓内约定常数引用、不得称权威常数；
  它是 L4 高空间频项的**折算**口径，其向本单元逐星预算的换算链**未独立核证**；
  但取仿真口径（0.000881 mag）判定同样为红，结论对该换算不敏感。
