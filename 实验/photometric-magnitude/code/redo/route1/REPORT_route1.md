## 【链条位置】本模块在五创新点链上的接口

P1 是全链根基：把每帧信号统一到**测光星等坐标系同一平面**。

- **上游输入（谁给什么）**：
  1. PSF 域解析通量 `F_instr` [ADU]（式-7，5×5 盒和禁止——N-25）；
  2. `F_syn = ∫ F_λ·T·Q·λ dλ` [W·m⁻²·nm]（式-1；XP 官方场 `flux` 单位 W·m⁻²·nm⁻¹，R5/A33 摘要原句 "directly tied to a flux in physical units" 佐证物理刻度）；通带 = 滤镜 T(λ)＋探测器 Q(λ)（R5/A33 正文 "passbands…combination of…filter…the sensitivity curve of a photon-counting detector"，与 PHOTOMETRY.md §2a.1 同口径）。
- **P1 产出（量纲/精度/有效性约定）**：
  - `location` [dex]；`scale = k_photo = 10^−location` [[F_syn 单位]/ADU]——**绝对值无物理意义**（PHOTOMETRY.md §16.3：欠定+不可证伪），有效性=单帧测光一致性 `sigma_residual` [dex]（`sigma_mag = 2.5·sigma_residual` [mag]）；
  - `ZP_syn`（绝对合成星等零点）、空间增益 `m(x,y)`（无量纲乘性场）。
- **下游消费（拿去做什么）**：
  - **P2 跨帧绝对 SNR** 消费 `sigma_kappa_stat = 1.253·sigma_residual/√N`（02 式-4 口径）作为零点统计不确定度，进入跨帧 SNR 传递链；
  - **P3/P4** 消费 `photoapplied_<base>` 像素（`I_photo = k_photo·m(x,y)·I_cal`，标度 `photo_scaled_adu`，量纲约定 `x′=α·x ⇒ Var′=α²·Var, ivar′=ivar/α²`，PHOTOMETRY.md §1/§16.1⑤）与 `p1_phot.json` 侧车（帧级 scale/zero_point/sigma_residual）；
  - **P5** 在 SNR 加权去天光时以帧级 `sigma_residual` 定权。
- **链条贯穿用例**（exp2 `chain_case`，seed=20260927）：上游给 800 星 `F_instr`[ADU]+`F_syn`=1.0e-11 [W·m⁻²·nm]，P1 恢复 `scale`=3.7053e6（真值 3.7e6，相对误差 1.44e-3，与 σ/√800 量级一致）、`location`=−6.56882 dex（IRLS 5 步收敛）、`sigma_residual`=0.01833 dex；下游 `sigma_kappa_stat`=8.12e-4 dex [P2 接口]。量纲约定：上游 ADU/能量通量 → 位置量 dex → 施加因子无量纲×m(x,y) → 下游像素保持 `photo_scaled_adu`。**有效性约定**：`|r_consistent|≥3` 才出标度（NO_DATA 路径无零点、无星等，PHOTOMETRY.md §16.5/:400）。

## S1 · Tukey biweight 形状参数 c=4.685

**假说**：c=4.685 不是任意数，而是"对正态 95% 渐近效率"的解；仓内数值与该解在标定精度内一致。
**方法**：exp1 以稠密梯形网格（180001 点，∫f dΦ）计算 biweight 的渐近效率 eff(c) = (∫ψ′dΦ)²/(∫ψ²dΦ)，ψ(x)=x(1−(x/c)²)²·1[|x|<c]；扫描 c∈[3,6] 反解 eff=0.95；再以 MC（seed=20260926，N=4000×n=200）测 biweight location 对样本均值的经验效率。负例：ψ(x)=x 自检必须给 eff=1；常值输入（真值无效应）必须 S=0、迭代 0、度量归零。
**数据/结果**：

| 量 | 值 |
|---|---|
| eff(c=4.685)（解析积分） | **0.949997** |
| eff=0.95 反解 c* | **4.68508** |
| ψ=x 自检 | 1.0000000（通过） |
| P(\|z\|>4.685) | 2.80e-6 |
| MC 经验效率（n=200） | 0.9458（有限样本下略低于渐近 0.95，符合方向） |
| 负例：常值输入 | S=0.0、iters=0、location=median、sigma_residual=0 ✔ |

**结论**：c=4.685 ≡ c*(0.95)=4.68508（差 8e-5）——三腿闭合。文献腿一手出处为 R3（Kafadar 1983 原句显式给出 c=4.685↔95%），出处文献 R1（Beaton & Tukey 1974）。02 C11 的"书目 UNPROVEN"升级为 CONFIRMED。
**诚实边界**：MC 经验效率 0.9458 略低于渐近值——渐近效率对"已知尺度"严格成立，而生产实现 S 固定一次且有限样本（02 式-3 已附该边界）；本实验未模拟尺度重估路径。
**复现**：`python3 code/exp1_robust_constants.py` → `results/exp1_robust_constants.json`。
**佐证文献**：[Kafadar 1983, DOI 10.6028/jres.088.006](https://pmc.ncbi.nlm.nih.gov/articles/PMC6768164/)；[Beaton & Tukey 1974, DOI 10.1080/00401706.1974.10489171](https://api.crossref.org/works/10.1080/00401706.1974.10489171)。

## S2 · MAD→σ 一致性系数 0.6744897501960817

**假说**：该 17 位常数 = Φ⁻¹(3/4)，且在双精度意义下与代码字面量一致；其逆 1/系数 = 1.4826 亦一致。
**方法**：exp1 用 math.erf 自写二分求 Φ⁻¹(0.75) 至 double 收敛，与代码字面量做位级比较；逆值与 1.482602218505602 比较。
**数据/结果**：

| 量 | 值 |
|---|---|
| 自算 Φ⁻¹(3/4) | 0.6744897501960816 |
| 代码字面量 | 0.6744897501960817 |
| 位级相等 | 否（差 1 ulp），相对差 **1.65e-16** |
| 逆值 | 1.482602218505602（相对差 **0.0**，位级相等） |

**结论**：推导腿闭合（Φ⁻¹(3/4) 的定义性推导）；1 ulp 差异属分位数求解的末位舍入自由度，远低于任何判据分辨率——与 02 V-2"复算自证"结论一致。文献腿 R2（MAD 估计量族的正态效率/一致性属 Rousseeuw & Croux 1993 主题）。
**诚实边界**：位级不等不等于不一致；任何要求位级复现的断言应改锚到逆常数 1.4826（位级相等）。
**复现**：同 S1。
**佐证文献**：[Rousseeuw & Croux 1993, DOI 10.1080/01621459.1993.10476408](https://wis.kuleuven.be/stat/robust/papers/publications-1993/rousseeuwcroux-alternativestomedianad-jasa-1993.pdf)。

## S4 · 星等一致性预过滤窗 mag_tolerance = 3.0 mag

**假说**：3.0 mag 窗在 delta 域 ⇔ 1.2 dex ⇔ 15.85× 通量比，是放走错配的第一道粗筛；对整体乘性标度不变；不能作质量门。
**方法**：推导：`delta_i = −2.5·log10 F_instr − G`，而 `G = −2.5·log10 F_syn + C` ⇒ `delta_i = −2.5·r_i − C`（常数项在 median 差中消去）⇒ \|delta−median(delta)\| = 2.5\|r−median(r)\|，3.0 mag ⇔ 1.2 dex。exp2（seed=20260927）：2000 星、r~N(0,0.018 dex)，污染率 f∈{0,2%,5%,10%}×偏移 {0.8,1.2 dex}，测预过滤拒绝数与 ZP 偏差（有/无预过滤）；负例 f=0 下扫 tol∈{1,2,3,5}。
**数据/结果**：

| f | 偏移 [dex] | 预过滤拒绝数 | ZP 偏差(有筛) [dex] | 筛增益 [dex] |
|---|---|---|---|---|
| 0 | 0.8/1.2 | 0 | 5.8e-4 / 4.6e-4 | 0 |
| 2% | 0.8 | 0 | −4.8e-4 | 0 |
| 2% | 1.2 | 23 | 7.77e-4 | −3.0e-6 |
| 10% | 1.2 | 85 | −3.47e-4 | −7.3e-6 |

负例（无污染）：tol∈{1,2,3,5} 全部拒绝数=0，location 波动 ≤7e-4 dex（纯 MC 噪声）。
**结论**：①预过滤只在偏移≥3.0 mag 时拦截；②在 IRLS/Tukey 已就位的前提下，预过滤对 ZP 偏差的**边际保护量 ≈0**（Tukey 权已把离群星归零）——它的真实作用面是控制进入拟合的样本族（错配星不污染 S 的初值尺度），不是精度门。支持 02 式-2"作用是放走错配与污染，不是标定质量判据"，并给出量化。
**诚实边界**：文献腿 UNRESOLVED——正本明言不引文献为窗宽背书（项目冻结值）；本路亦未找到任何一手文献支持 3.0 这一取值。
**复现**：`python3 code/exp2_mag_window_match.py` → `results/exp2_mag_window_match.json`。
**佐证**：PHOTOMETRY.md:34/:200-202；02 式-2 注记（15.85×）。
