## 3 失败尝试与订正（必须留档）

### 3.1 失败：按「自明」的模型重建残差，对不上

我最初假设 `log10 m = +Σ coef·B̃`、且基序按自己 `for deg / for i` 的枚举顺序
（我的枚举产出 `[ỹ, x̃, ỹ², x̃ỹ, x̃²]`）。复算结果：

```
产物 sigma_spatial_residual_dex = 0.012203707890100375
我的重建（r = loc − logm）= 0.055771
我的重建（r = loc + logm）= 0.025432
```

两者都不等于产物值。**判定：无效**，原因是我把一个**未读文档的**符号与基序约定当成了自明的。

### 3.2 订正：读实现头，取唯一约定

读 `spatial_gain.h` 得唯一约定：`log10 m = −Σ_j coef[j]·B̃_j`、基序 `[x̃,ỹ,x̃²,x̃ỹ,ỹ²]`、
`center = 加权均值`。据此 `r_pred = location + Σ_j coef[j]·B̃_j`。复算：

```
重建残差 MAD      = 0.012203708
产物 sigma_spatial = 0.012203708
相对差            = 2.232e-14
```

**逐位一致（2e-14）**。全 49 帧复算与产物最大相对差 **6.8e-3**（少数帧因我取普通中位数居中、
产物取 Tukey 加权位置而略差）。

### 3.3 失败：想用「无权重 LSQ / IRLS-Tukey」反解产物系数，只对上一部分

用 dumped 样本独立反解系数（同一基、居中、含截距）：

| 方案 | 与产物 `coef` 的对比 |
|---|---|
| 无权重 LSQ | `[0.00667, 0.03001, 0.04396, 0.00259, 0.04524]` vs 产物 `[0.00501, 0.03019, 0.04346, 0.00014, 0.04431]`：仅 3 项吻合 ~1%，`x̃` 差 1.33×、`x̃ỹ` 差 18× |
| IRLS-Tukey（c=4.685） | `[0.00268, 0.02938, 0.04535, −0.00235, 0.04417]`，亦不吻合 |

但两者都复现了**整体量**：设计阵条件数 2.205 vs 产物 `kappa` 2.241；
残差 MAD 0.012328(LSQ)/0.011633(IRLS) vs 产物 0.012204。

**判定：产物 `coef` 的逐系数无法用 dumped 样本离线反解**（生产求解器在系数协方差/
列均衡/权重细节上的约定未随产物落盘）。这是一个**证据缺口**，登记。
影响：**不能用"按产物 coef 之外的方式重解"来做阶数实验**；阶数实验必须走
「按实现约定复现残差」这条路（3.2 已通）。

## 5 与派单方案的第 1 处分歧（先报，不擅自做）

派单把「**升阶 `m(x,y)`（现为 order=2）**」列为首选候选。但仓内已有**明确负面登记**：

- `spatial_gain.h` 文件头逐条写明：基函数阶 **∈ {1,2}**，**「order ≥ 3 不启用」**，
  依据是 `实验/photometric-magnitude/docs/p1-spatial-gain.md` §3.4 的实测；
- 该文件 TL;DR 第 2 行：**order 3 的负例噪声底为 5.40%（order 1 为 1.23%、order 2 为 2.72%）**，
  均值 12.8%；并注明「order 3 的负例噪声底是真值信号的 1.3×，**明确有害**」；
- 即：order 3 在合成负例上**拟合出来的假信号超过真信号**，属过拟合，不是改进方向。

⇒ **「升阶」在现约定下不是可用候选**，除非先推翻 §3.4 的登记（需新证据）。
当前生产已是 order=2（该文件称「order 2 只在星多且覆盖好时开」），本轮 49 帧全部
`order_requested=2 → order=2` 且 `identifiable=1`，说明门是通的。

## 6 与派单方案的第 2 处分歧（更根本，先报）

`p1-spatial-gain.md` §4.5.2 有一个**决定性负面结果**：

- 同一帧对在 r=3/4/6/10 px 上测得的「乘性空间残差」峰峰为
  **7.78% / 4.93% / 3.81% / 4.25%** —— 纯乘法增益**不可能**随孔径这样变；
- 用它拟合出的 `m` **只在拟合孔径上有效**（r=4：4.93%→1.96%），换到 r=6 复核
  **4/4 代表帧对全部变差**；
- 结论：**真实数据上测得的空间结构主要由孔径/PSF 系统差主导，不是乘法增益**；
  §4.6 因此明确「不能把 §4.3 的 in-sample 数字当实现效果上报」。

**但**：那轮实验的 `F_instr` 是 **r=4 px 小孔径测光**；而**本轮 49 帧的 `F_instr` 已是
PSF 域解析通量**（`psf_analytic_flux_2pi_A_sx_sy_over_3`）。这恰好是旧文档 §4.5/§6
列为「**前置**：`F_instr` 必须换成 PSF 稳健口径并做**孔径无关性验收**」的那一项。

所以：
- 旧结论（空间结构不是乘法增益）**不能直接沿用到本轮**，因为前提已变；
- 但该「孔径无关性验收」**在本轮新口径上是否重做过，我在只读产物里没有找到证据**；
- 因此**当前主判据（余差/噪声底 4.74–9.86×）究竟读的是「乘性场阶数不够」还是
  「非乘性的 PSF/孔径系统差」，是一个尚未判定的问题**。

⇒ 在判定这一条之前谈「升阶/加项」有把系统差吸进 `m` 的风险（旧文档 §4.6 的根因正是这个）。

## 8 第 2 步方案（待确认，尚未动手）

按可行性排序，**先判别归因，再改模型**：

**P-A（建议先做，纯判别，不改产物）**：把「余差/噪声底 4.74–9.86×」按来源分解。
在单帧内用 `samples` + `p1_flux.json` 做三项读数：
1. **按星等/信噪比分箱**重算空间场后残差：若大残差集中在低 SNR/暗星端 → 是逐星测光噪声而非空间场；
2. **按星径（Gaia 投影位置到 PSF 域）与星点密度分箱**：混叠/拥挤区是否主导；
3. **把 `r` 的散度拆成「空间光滑分量」与「逐星随机分量」**（后者用同帧内近邻星对的

   判据：若空间分量 ≪ 噪声底，则主判据的"倍数"是**逐星噪声**而非空间场不足，升阶无意义。

**P-B（稳健化，独立于 A，低风险）**：选星与权重。
现状 `n_outliers=0`（全部 49 帧），即 Tukey 剔除几乎没触发；可试：
`used` 之外补一道 **SNR 下限**（用 `p1_flux.json` 的 `flux/flux_error`）与
**饱和/边缘/混叠**剔除，然后用同一约定重解并比较空间场后残差。
（注意：这一步只调"进拟合的样本集"，不动模型阶数；且必须报"对逐帧独立性与并行度的影响"。）

**P-C（`k_photo` 精度）**：在 P-A/P-B 之后，检查全局 IRLS 的
`location` 与 `sigma_residual_dex` 是否被少数样本主导（用 `samples.r` 复算中位数/双权收放）。

**不列入**：升阶到 order 3、加"电平相关项"。
理由见 §5（order≥3 已登记有害）与 §6（在归因未判定前加项有吸收 PSF 系统差的风险）。
若负责人要求仍要试，我会把它当**待证伪实验**执行：在合成负例（真值 m≡1）上先量
"拟出来的假场幅度"，只有假场幅度 ≪ 真值幅度时才在真实帧上试。

# 附录 A：P-A 判别诊断的实测（本次新增，2026-10 追加）

## A.1 逐星光子噪声底（`code/p1fix/photon_floor.py`）

`noise_floor_dex` 只含**空间场系数估计**的统计误差；把 `p1_flux.json` 的
`flux/flux_error` 换成 dex 域逐星噪声 `0.4343·σ_F/F` 作独立参照：

| 比值 | min | median | max |
|---|---|---|---|
| `sigma_post / sigma_photon` | 3.12 | **5.24** | 8.00 |
| `sigma_photon / noise_floor` | 0.79 | **1.38** | 2.36 |

读数含义（只报读数）：逐星光子噪声与解析噪声底同量级（中位 1.38×）；
而**空间场后残差仍比逐星光子噪声高 3.12–8.00×（中位 5.24×）**。
⇒ 「4.74–9.86×」**不是**纯口径产物：确实存在超出逐星光子噪声的额外散度（另见 A.2 判其性质）。

## A.2 残差还剩多少空间结构（`code/p1fix/residual_structure.py`）

对 order=2 拟合后的残差 `e`，在该帧星点内部两两配对，按归一化像面间距分箱，
算 Pearson 相关 `rho` 与结构函数比 `D/2Var`（=1 表示无空间相关）：

| 间距（归一化像面） | `rho` 中位 | `rho` 范围 | `D/2Var` 中位 |
|---|---|---|---|
| [0.00, 0.05) | **+0.0285** | −0.1503 … +0.1489 | 0.9969 |
| [0.05, 0.10) | +0.0112 | −0.0446 … +0.0795 | 0.9801 |
| [0.10, 0.20) | +0.0082 | −0.0513 … +0.0586 | 0.9709 |
| [0.20, 0.40) | +0.0053 | −0.0164 … +0.0440 | 0.9848 |
| [0.40, 0.80) | −0.0066 | −0.0171 … +0.0026 | 0.9909 |
| [0.80, 2.00) | +0.0007 | −0.0062 … +0.0095 | 1.0042 |

单帧星数 431–968 ⇒ `rho` 的标准误 ≈ 1/√n ≈ 0.033–0.048。
**实测 `rho` 在近间距也只有 +0.0285（≈1σ），远间距归零；`D/2Var` 全档 ≈ 1。**

**判定（读数直接给出，非推断）**：order=2 的空间场已经把逐星残差里**空间相干**的成分
基本吃干净；剩下的散度**在空间上不相关**。

## A.3 A.1+A.2 合起来的含义（待前台裁决，本文只登记）

- 「空间场后残差 ÷ 噪声底 = 4.74–9.86×」**不能**读作「乘性场阶数不够」：
  A.2 显示没有剩余空间结构可供更高阶去拟合；A.1 显示多余散度是**逐星**量级的。
- 因此**升阶（或加空间项）在本数据上不可指望**——这与 §5 中 order≥3 的既有负面登记**方向一致**，
  且给出了它在本轮数据上的独立、定量的解释。
- 剩余散度的归属（PSF 拟合系统差 / 拥挤混叠 / 星表错配 / 逐星通量口径）
  **落在 `F_instr` 逐星级，不在空间场**；要动就该动那一层。

## A.4 与旧实验（§6）的关系

旧 `p1-spatial-gain.md` §4.5.2 用**多孔径探针**判定「空间结构不是乘法增益」，其根因归于
`F_instr` 是 r=4 px 小孔径测光。本轮 `F_instr` 已是 PSF 域解析通量，前提已变，
故旧结论**不直接沿用**；而 A.2 给出了**不依赖多孔径**的独立判据：
在 PSF 域通量上，order=2 之后**已无空间相干残留**。
两者不冲突：一个说"这些结构随孔径变、不是乘性"，一个说"在 PSF 口径下乘性场已拟合到位"。

## A.5 仍未做的判别

- 残差与**星等/信噪比/星径/局部密度**的分箱关系（P-A(1)(2)）尚未做，用于把逐星散度
  进一步归因（PSF 系统差 vs 混叠 vs 错配）。
- 「孔径无关性验收」在 PSF 域口径上的重做：只读产物内**无多孔径通量**，做不了（见 §7）。

# 附录 E：单帧内 PSF 域 `F_instr` 口径的可压余量

## H.4 判定

**③ 不成立。** 判据：
1. **结构性**：规范把 `m` 约束为零均值，`k_photo` 承担全局项；实测"去掉空间场"对逐帧帧级标度的
   影响 |Δ| 中位仅 5.7e-5 dex，是帧间散度的 **1/773** ⇒ **空间项没有、也不能进入帧级标量**。
2. **判别性**：(b) 的散度/标准误仍是 **40–99 倍**、χ²_red≈3740；剔除离群帧后仍 **36–45 倍** ⇒
   去掉空间场后散度**不收敛**到标准误量级。
3. **无相关**：空间场幅度与帧级标度不显著相关（p=0.126）。

⇒ 帧级散度的来源**不是**空间项混入帧级标量。本单给出的下一步唯一线索：
**尾部集中在 M4 与低匹配星数帧**（M4 的 n_used 437 vs M6 856，|dev| 相差 4.6 倍），
即散度随"每帧可用匹配星数"系统性变化 —— 这与 P5 侧 ②「检出完备性/选择偏差」的方向一致，
但**本轮不宣称 ② 结案**（本单判据只针对 ③）。
