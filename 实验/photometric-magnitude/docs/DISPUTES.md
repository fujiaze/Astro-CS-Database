## 条款清单

### A-P1-01 `1.166` 的解释标签

- **冲突**：说法甲把 `1.166` 标为「SD(MAD)/MAD 正态渐近常数」；说法乙指出文献值是**标准化方差 1.361**，
  `1.166 = √1.361` 是 **σ 估计量的 SD 因子**，按字面式展开应为 `1.729/√n`。
- **终裁**：`1.166` 的解释标签为 **σ 估计量的 SD 因子**（= √1.361）；
  字面式按 `1.729/√n` 书写。**数值 1.166 本身可用**。
- **依据**：文献值取自路线 refs 台账 R2 Table 2（标准化方差 1.361）。

- **冲突**：MC 渐近读数 **1.170**；文档登记 **1.166**（偏差 +0.3%）。

### A-P1-03 `mag_tolerance` 预过滤的作用面

### A-P1-05 场形弯曲度/阶数是否科学量

- **冲突**：说法甲把场形弯曲度/阶数（S12）判为「非科学量」；说法乙判为**科学量**。
- **终裁**：**判为科学量**（保留在科学面，不进豁免清单）。**但其数值内容未被证据确定**：
  支撑实验 `code/redo/route1/exp4_spatial_gain.py` 的 `design()` 对 `order ∈ {0,1}` 返回**同一 3 列设计矩阵**
  （线性项无条件加入），故 `order0_rms_dex` 与 `order1_rms_dex` 在全部 N 档**逐位相同**（退化读数），
  "order 1 vs order 2" 这一真正需要判别的比较**从未被评估**；且 `../../absolute-snr/docs/REVERSE_VERIFY_CANON.md` §1-2
  的定案是"**order 1 为默认；order 2 只在星多且覆盖好时开**"，与"order ≤ 2 + 六降级门槛"不等价。
  ⇒ 本条款**只裁定"场形/阶数属科学面"这一分类**；`order ≤ 2` 这一具体取值与六个降级阈值
  **不得**作为已验证科学常数引用，引用时须标注为"数据相关的偏差-方差工作点，仅有合成白噪证据"。
- **依据**：`code/redo/route1/REPORT_route1.md` §S12（why-not-structural 论证：场形弯曲度是物理量、
  阶数上限是偏差-方差折中、order3 全档过拟合）＋ `【复现：实验/photometric-magnitude/code/redo/route1/exp4_spatial_gain.py 生成的 exp4_spatial_gain.json】`；
  退化读数与反向定案由审查员在 `design()` 上独立复算（order 0/1 均为 3 列、RMS 逐位相同）。

### A-P1-11 两套星族不一致的 ZP 级影响

- **冲突**：说法甲认为两套星族不一致构成 ZP 级（mas 级）影响；说法乙判其影响为 **μmag 级**。
- **终裁**：影响为 **μmag 级（仅在所用模型内）**；真正的问题在**适用域**（G ≥ 15 域外谱），
  不在星族一致性本身。**该数值不得作为"两套星族不一致影响为 μmag 级"的实测证据引用。**
- **依据**：测算过程存在（`code/redo/route3/exp_S09_mag_minmax.py`，
  读数 `【复现：bash 实验/photometric-magnitude/code/run_all.sh 重跑后读 exp_S09_mag_minmax.json；该读数需重跑取得，当前不可离线核验】`）：该族 `n_G_15_16 = 2527` / `25788 ≈ 9.8%`，
  `[6,15)` 与 `[6,16)` 两族中位数之差 `−9.298e−6 mag`，阶梯早停于 G=14 的情形 `+1.718e−5 mag`。
  **但该测算的输入是参数化噪声律** `noise = 0.01 + 0.02·clip(G−15,0,None)²`（脚本第 36 行字面量），
  且 `F_syn` 由 `m_syn` 反解得到、`m_syn − G = −zp_true + noise` 恒成立 ⇒ 读数是**该噪声律上的中位数差**，
  不是流水线真值上的星族不一致量；真实管线的两套星族不一致未被测量。
  该脚本的 `H9b.pass` 为 `bool(zp_fit == zp_16)`（两族掩码逐位相同 ⇒ 恒真）、
  `negative_zero_check.same_family_delta = zp_16 − zp_16`（字面量），
  按规范「恒真门无证据资格」二者**不构成判别力证据**。
  ⇒ 按 AGENTS 科学自治「证据须可复核」，本条的**模型条件**必须随数值一同引用。

### A-P1-13 小 N 渐近式的可靠性

- **冲突**：说法甲主张渐近式 `1.2533/√n` 可为小 N 背书；说法乙实测 n = 3 处渐近式**高估 7.4%**，
  并与「n = 3 时 MAD 偏差 1.49×」互证。
- **终裁**：**任何用该渐近式为小 N 背书的做法不可靠**。n = 3 的 MAD 有限样本偏差为 **1.49×**；
  n = 3 处渐近式对 SE 的超出量为 **8.03%**（**单一读数，7.4% 写法作废**）。
- **依据**：`code/redo/route3/exp_S11_zp_sample_floor.py → exact_n3` 的闭式求积给出
  `SE_exact(n=3) = 0.6698291607404145`（`∫x²·6Φ(x)(1−Φ(x))φ(x)dx`，即 X(2) 的方差开方），
  渐近值 `1.2533/√3 = 0.7235930923753581`；两者之比给出
  **「渐近值相对精确值的超出比例」= 0.7235930923753581 / 0.6698291607404145 − 1 = 0.080265（8.03%）**。
  审查员以独立求积（2400001 点梯形、seed 987654321/20260927 的 MC）复算得同一组数
  （8.0265% 与 8.03% 逐位一致）。
  7.4% 对应的是**另一个分母**的量 `1 − 0.9256987 = 0.0743`，即「精确值占渐近值的比例之亏」；
  「X 高估 Y p%」的通行读法是 `(X − Y)/Y`，故单一正确读数是 **8.03%**。
  同一读数在 `code/redo/route2/REPORT_route2.md`（S9 表）与 `REPORT_paper.md` §7-4 一致采用。
