## 条款清单

### A-P1-01 `1.166` 的解释标签

- **冲突**：说法甲把 `1.166` 标为「SD(MAD)/MAD 正态渐近常数」；说法乙指出文献值是**标准化方差 1.361**，
  `1.166 = √1.361` 是 **σ 估计量的 SD 因子**，按字面式展开应为 `1.729/√n`。
- **终裁**：`1.166` 的解释标签为 **σ 估计量的 SD 因子**（= √1.361）；
  字面式按 `1.729/√n` 书写。**数值 1.166 本身可用**。
- **依据**：文献值取自路线 refs 台账 R2 Table 2（标准化方差 1.361）。

### A-P1-02 MC 渐近读数与登记值的微小不一致

- **冲突**：MC 渐近读数 **1.170**；文档登记 **1.166**（偏差 +0.3%）。
- **终裁**：登记为**微小不一致**，不影响 3σ 门；两值并存，正文引用时标注读数腿。
- **依据**：MC 渐近读数 1.170（固定 seed 存档，路线 1）。

### A-P1-03 `mag_tolerance` 预过滤的作用面

- **冲突**：说法甲把 `mag_tolerance` 预过滤判为「非质量判据」；说法乙判其在 IRLS/Tukey 就位后

- **终裁**：采说法乙并加一层 —— `mag_tolerance` 预过滤的价值域是**初值尺度 `S` 的样本族控制**，
  不是 ZP 偏差的质量防护。
- **依据**：**依据未给，待补**。对账只给「边际保护 ≈ 0」的数值结论，未给脚本名、文件:行或 DOI。

- **终裁**：**改判数值求解器设置 ＋ 不变性实验对象**，不进科学常数表、不进豁免清单的科学量面。

### A-P1-08 `1.4826` 的字面截断与 `mag_max_arr` 耦合

- **冲突**：说法甲认为实现与冻结条款一致；说法乙实测两处实现面缺陷。
- **终裁**：两处**条款性缺陷收录**（非错值）：
  1. `frame_photometry_fit.cpp:292` 用**4 位 1.4826**，违反 MAD→σ 冻结条款（要求 1e-6 量级）；
  2. `mag_max_arr` 长度与 `i < 5` 循环上限**巧合耦合**，使第 6 档的改动静默失效。
- **依据**：`frame_photometry_fit.cpp:292`（代码实际行为）；MAD→σ 冻结条款在噪声估计正本。

### A-P1-12 FOV 缓冲与钳位下界的优先语义

- **冲突**：FOV「缓冲 1.2」与「钳位下界 1.0」在小画幅端**互相冲突**，而 A-4b 未定义优先语义。
- **终裁**：该冲突为**订正清单项** —— A-4b 必须显式定义两者的优先语义，否则小画幅端取值不唯一。
- **依据**：规格文本自身冲突（对账未给行号锚，**行号待补**）。

### A-P1-13 小 N 渐近式的可靠性

- **冲突**：说法甲主张渐近式 `1.2533/√n` 可为小 N 背书；说法乙实测 n = 3 处渐近式**高估 7.4%**，
  并与「n = 3 时 MAD 偏差 1.49×」互证。
- **终裁**：**任何用该渐近式为小 N 背书的做法不可靠**。n = 3 的 MAD 有限样本偏差为 **1.49×**。
- **依据**：实测渐近式在 n = 3 处高估 **7.4%**（对账终裁值）。
  单元内路线报告另记 **8.03%** —— 两个读数并存，**须由前台以固定 seed 复跑裁定单一值**；
  在裁定前正文须同时标注两个读数，不得只引其一。
