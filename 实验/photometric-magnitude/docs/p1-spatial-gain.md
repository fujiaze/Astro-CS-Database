## 2 ① 方案设计

### 2.1 模型与归一化约定（与现有 `k_photo` 严格兼容）

    I_photo(x,y) = k_photo · m(x,y) · I_cal(x,y),      mean_stars( log10 m ) = 0

设逐星观测量

    r_i = log10( F_instr,i / F_syn,i )     [dex]

对 r 做低阶多项式曲面拟合 surf(p)（基函数见 §2.2），则

| 量 | 定义 | 说明 |
|---|---|---|
| `mean_surf` | `surf` 在**参与拟合的星集合**上的加权均值 | 与 `k_photo` 的现有定义同源 |
| `k_photo` | `10^(−mean_surf)` | **order=0 时严格等于现有** `10^(−location)`（Tukey-IRLS 稳健位置） |
| `m(p)` | `10^(−(surf(p) − mean_surf))` | 星集合上 `log10 m` 均值为 0 ⇒ 与 `k_photo` 不重复 |
| `gain(p)` | `k_photo · m(p) = 10^(−surf(p))` | 实际乘到像素上的总因子 |

**为什么这样归一化**：① 保证 order=0 退化时行为与现有生产路径**逐位一致**（可做回归对照）；② 加 `m` **不改变**由星集合决定的帧级测光零点，避免与 Phase1 的绝对定标打架；③ 星集合的 log 均值为 0 是**可检验**的（不是「帧足迹均值为 0」这种在星分布不均时无法保证的口径）。

> **符号提醒（容易搞反）**：`m` 是**校正因子**，与被测的**仪器空间乘法响应** `m_true` 互为倒数：`m ≈ 1/m_true`。合成实验里报的 `shape RMS vs 1/m_true` 就是这个意思。

### 2.2 阶数选择依据

基函数（像素坐标归一化到 [−1,1]，避免病态）：

| 阶 | 项数（含常数） | 项 |
|---|---|---|
| 0 | 1 | `1`（= 现有标量 `k_photo`） |
| 1 | 3 | `x, y` |
| 2 | 6 | `x², xy, y²` |
| 3 | 10 | `x³, x²y, xy², y³` |

**选择依据（三条独立证据）**：
1. **物理形态**：Q3 实测真实数据的乘性空间残差**以线性梯度为主、不是径向渐晕**（二次径向项系数中位 |r2c| ≈ 0.009–0.022，远小于线性项）。线性基直接对应「平场大尺度残差」。
2. **统计精度**：拟合出的 m 自身有噪声底，且**底随阶数迅速上升**（负例实测，N=200、σ_int=0.010 dex）：order 1 中位 1.23%、order 2 中位 2.72%、order 3 中位 5.40%（均值 12.8%）。真值 pp 只有 7% ⇒ order 3 的信噪比 **<1**，属于纯过拟合。
3. **可复现性**：真实数据分半一致性（用一半星拟合的 m 与另一半比较）：order 1 的 corr 中位 **0.997**（min 0.861）；order 2 只有 **0.929**（p10 0.41，min 0.30）。order 2 已经明显不稳定。

⇒ **默认 order 1**；order 2 仅在「匹配星数足够多（≳200 且覆盖好）」时开启；**order ≥3 不启用**（「不管高阶」）。

### 2.3 拟合方法

**加权 Tukey-IRLS 低阶曲面拟合**（在现有 `cleanAndScale` 的 inlier 集合上做第二阶段）：

1. **观测量**：r_i = log10(F_instr,i / F_syn,i)，逐星位置 (x_i, y_i)（生产 `StarMatch` 已带 `x,y`，`star_matcher.h:26-34`）；
2. **权重**：逆方差 w_i = 1/σ_r,i²，σ_r,i 由测光误差传播（本工作区用 σ_r = √2·σ_ap/(ln10·F)，与 Q1.2 同口径）；
3. **稳健化**：初值加权最小二乘 → S = MAD(r)/0.6745 → Tukey biweight u = r/(4.685·S)，w ← (1−u²)²（|u|≥1 置 0），迭代至 Δc < 1e−6 或 ≤50 次；
4. **输出**：`coef[0..P−1]`（P = 1 + n_term）+ 归一化参数 (x0, sx, y0, sy) + `sigma_residual` + `n_inlier`。

### 2.4 离群剔除（现有 Tukey-IRLS 如何扩展）

现有链是**两级**：① 星等一致性 3.0 mag 预过滤（`star_matcher.cpp:486-501`）；② Tukey-IRLS 稳健**位置**（`:552-586`）。扩展为**三级**，前两级**原样保留**：

| 级 | 现有 | 扩展后 |
|---|---|---|
| 1 | 星等一致性 3.0 mag | **不变** |
| 2 | Tukey-IRLS 稳健位置（标量） | **不变**，其结果作为空间拟合的**初值**与 inlier 掩膜 |
| 3 | — | 在 inlier 集合上做**曲面** Tukey-IRLS：残差 r_i − surf(p_i) 的 MAD 重新定标，二次重加权 |

关键点：第 2 级的 inlier 掩膜被第 3 级**继承**，因此不会出现「标量阶段剔掉的星在空间阶段又回来」的不一致。真实数据实测第 3 级剔除率：order 1 为 5.5%（4925/89361）、order 2 为 6.7%（6004/89361），量级正常。

### 2.5 星数不足 / 分布不均的退化处理（**fail-closed**）

| 条件 | 行为 | 依据 |
|---|---|---|
| 匹配星数 N < 3 | **完全退化到现有行为**（NO_DATA，k_photo=1.0，不施加） | 主线冻结门 SCI-PHOT-001 §4/§8，**不动** |
| 3 ≤ N < N_min(order) | **只做标量**（order 0），m ≡ 1，provenance 记 `spatial_gain=degraded_scalar` | 见下 |
| 覆盖不足（3×3 分块中 <6 块含 ≥5 星，或星位置包围盒 <50% 帧幅） | **只做标量**，provenance 记 `spatial_gain=degraded_coverage` | 聚集分布实验（§3.5） |
| 曲面拟合失败 / 系数非有限 / sigma_residual 超门 | **整组不施加**（与 FIX-P1 的 `photscale_incomplete` 同语义） | 部分归一化比不归一化更糟（FIX-P1 §2.2） |

**N_min 的定量依据（合成负例噪声底 vs N，σ_int=0.010 dex）**：

| N | order 1 底（均值） | order 2 底（均值） | 真值 pp 7% 的信噪比（order1 / order2） |
|---|---|---|---|
| 20 | 5.91% | 26.58% | 1.2 / 0.26 |
| 50 | 3.16% | 9.83% | 2.2 / 0.71 |
| 100 | 1.67% | 4.59% | 4.2 / 1.53 |
| 200 | 1.38% | 3.58% | 5.1 / 1.96 |

⇒ 建议 N_min(1) = 50、N_min(2) = 200。低于阈值时**降级到标量**而不是硬拟合（诚实优先：宁可不做，不做错）。

### 2.6 可辨识性：加了 m 之后 a 与 g 还能分开吗？

模型 y(p) = a(p)·m_true(p)·s(p) + g(p)（s = 真实天区信号，含星）。

**(a) 背景上精确退化（构造性反例，数值证明）**：对任意 δ(p)，

    m_true → m_true + δ/(a·S0),     g → g − δ

给出**同一个** y（背景上 s ≈ S0 为常数）。本工作区数值验证：max|Δy| = **2.27e−13 ADU**（机器精度），而梯度自身 pp = **69.0 ADU**。
**(b) 纯加性 vs 纯乘性在背景上不可分辨**：max|Δy| = 2.27e−13 ADU。
**(c) 星点破缺退化**：同一对模型在星点上给出流量比 pp = **9.78%**（局部天光扣除天然消掉光滑 g，星只测乘性）。

**结论（对方案的三条硬约束）**：
1. **空间乘法必须用星点估**，不能从背景拟合（与负责人指令「把主要残差去掉」一致，但实现路径唯一）；
2. **限阶本身不破缺退化**：若 δ 也限制在同一低阶多项式空间，则 m_true + δ/(a·S0) 仍是低阶 ⇒ 背景上仍不可分辨。**破缺退化的只有星点测量**，不是「低阶」这个约束；
3. 因此 m（星点估）与生产 Phase2 的加性面 δ_k（背景估，`sky_plane.cpp`）**不重复计数**：星点对光滑加性梯度是**盲**的。定量上：g 的 pp 为 4% S0 时，环带中位天光扣除残留约为 0.5·(d²g/dx²)·r² ~ 1e−2 ADU，相对 1e4 ADU 星流量为 1e−6 量级。

### 2.7 与 PMM 的对照

| 维度 | PMM（PhotometricMosaic v1.0） | AstroCS 本方案 |
|---|---|---|
| 输入 | **两张**已配准平面图 | **单帧**（对 Gaia 绝对定标），逐帧独立 |
| 乘性项 | **整图一个标量**（星点测光定） | **逐帧低阶空间曲面 m_k(x,y)**（星点测光定） |
| 加性项 | 平面**曲面样条**（高自由度） | 不在本方案内（Phase2 球面 B 样条 + δ_k，`sky_plane.cpp`） |
| 坐标 | 平面像素 | 像素（本方案）/ 球面（Phase2 加性面） |
| 定标锚点 | 参考图（相对） | Gaia F_syn（绝对，逐帧） |
| 交互 | 交互式、一次性 | 自动、可复现、可 provenance、fail-closed |

**借鉴**：乘性/加性**严格分离**（乘性只用星点）；**不借鉴**：平面两图框架、乘性项无空间自由度、加性项的高自由度样条（与「低阶、不管高阶」相反）。

## 3 ② 合成实验（已知真值）

### 3.1 场景与真值（`实验/shared/synthetic/synth_gain.py`）

    y_k(p) = a_k · m_k(p) · (T(p) + S0) + g_k(p) + n_k(p)

| 量 | 取值 |
|---|---|
| 帧 | 1024×1024；S0 = 1000 ADU/px；噪声 σ = 5 ADU/px（Q1 同口径） |
| 星 | 1000 颗池，对数均匀流量 1e3–1e5 ADU，PSF σ=2 px；取最亮 N 颗（与生产 `max_stars` 同口径） |
| 测光 | 固定孔径 r=6 px + 环形局部天光 10–16 px（**在真正渲染的像素上做孔径测光**，自动含加性梯度泄漏） |
| m_true | log10 m 为低阶多项式，**线性为主**（二次项幅度 = 线性的 0.20 倍，对应 Q3 实测 |r2c| 远小于线性项），pp = 7% |
| g_k | ≤2 阶多项式，pp = 4% S0 |
| 逐星内禀散差 | σ_int = 0.010 dex（对应 Q3 实测干净天区 0.006–0.014 dex） |
| 帧级响应 | a_A = 1.0，a_B = 10^U(0.05, 0.15) |
| MC | 150 次/配置（`--quick` 为 40） |

### 3.2 恢复误差与对照（N=200 均匀，150 MC，均值）

| 阶 | m 形状 RMS vs 1/m_true | oracle 投影下界 | **帧间残差场 PTP** | 逐星残差 RMS | 拟合 m 幅度 |
|---|---|---|---|---|---|
| **0（仅标量 = 现状）** | 1.534% | 1.534% | **9.363% → 9.363%（0% 下降）** | 1.821% → 1.821% | 0% |
| **1** | 0.482% | 0.285% | **9.363% → 2.302%（−75.4%）** | 1.821% → 0.431% | 6.17% |
| **2** | 0.619% | 0.000% | **9.363% → 0.191%（−98.0%）** | 1.821% → 0.196% | 7.18% |
| **3** | 1.293% | 0.000% | 9.363% → 0.421%（−95.5%） | 1.821% → 0.196% | 11.71% |

- **纯线性真值**（pp 7%，m 只含 1 阶）时 order 1 把残差场打到 **0.092%**（几乎完美），order 2 反而 **0.209%**（更差）⇒ 高阶无收益。

### 3.3 负例：真值 m ≡ 1（度量必须归零）

| 配置 | order 1 | order 2 | order 3 |
|---|---|---|---|
| **m 拟合幅度**（σ_int=0.010 dex） | **1.396%**（中位 1.244%，p95 2.52%） | 3.659%（中位 2.723%，p95 5.19%） | 12.826%（中位 5.396%，p95 24.93%） |
| **m 拟合幅度**（σ_int=0，纯噪声底） | **0.447%** | 0.922% | 4.916% |
| 校正后帧间残差场 PTP（σ_int=0.010） | 0.095% | 0.189% | 0.417% |

**读法（诚实版）**：
1. 负例下拟合出的 m **不是严格 1**，而是收到一个**统计噪声底**：约 σ_int/√N 量级的系数不确定度投影到曲面上。N=200、σ_int=0.010 dex 时 order 1 的底是 **1.24%（中位）**，相对真值 7% 小 **5.6×** ⇒ **不是过拟合**，是精度极限。
2. **底随 N 下降**（order 1 均值）：5.91%（N=20）→ 3.16%（50）→ 1.67%（100）→ 1.38%（200），近似 N^(−1/2) ⇒ 证明它是统计噪声而不是系统性过拟合。
3. **重要副作用（必须登记）**：负例下的伪 m 是**帧间共模**的（来自同一批星的目录/光谱失配，两帧共享），所以它**在帧间比值里抵消**（校正后残差场仅 0.095%），但**会扰动绝对测光**（位置相关的约 1.2% 误差）。⇒ 生产上必须**限制阶数 + 用足够多的星**，否则「帧间一致」会掩盖「绝对测光被空间调制」。

### 3.4 阶数扫描结论

| 判据 | order 1 | order 2 | order 3 |
|---|---|---|---|
| 帧间残差场 PTP（正例，越小越好） | 2.302% | **0.191%** | 0.421% |
| 负例噪声底（中位，越小越好） | **1.23%** | 2.72% | 5.40% |
| 信噪比 = 真值 pp / 底 | **5.7×** | 2.6× | 1.3× |
| 真实数据分半一致性 corr（中位） | **0.997** | 0.929 | — |
| 聚集星分布下的形状 RMS（N=100） | 2.93% | **24.4%（崩）** | — |

**结论**：
- 若只按「帧间残差最小」选，order 2 最好（0.191%）；**但它的自噪声底已接近真值信号（信噪比 2.6×），且在真实数据上分半不可复现（corr 0.929 / p10 0.41）、在聚集星分布下直接崩掉（24% 形状误差）**。
- **order 1 是稳健的甜点**：吃掉 75% 的帧间乘性残差场，自噪声底只有信号的 1/5.7，跨半样本可复现（corr 0.997）。
- order 3 **明确有害**（信噪比 1.3×，负例 p95 底 24.9%）。
- 这与负责人「低阶、去掉主要残差、不管高阶」一致，**且是本工作区独立判据得出的，不是迎合**。

### 3.5 星数 / 分布敏感性

正例（m_true pp 7%，均匀 vs 聚集：σ = 0.13×帧幅的高斯聚集）：

| N | 分布 | 残差场 PTP（o1） | m 形状 RMS（o1） | 残差场 PTP（o2） |
|---|---|---|---|---|
| 20 | 均匀 | 8.97% → **2.55%** | 1.43% | **0.83%** |
| 20 | 聚集 | 9.55% → **4.43%** | **12.54%** | 5.15% |
| 50 | 均匀 | 9.88% → 2.16% | 0.88% | 0.39% |
| 50 | 聚集 | 9.86% → 2.96% | 6.38% | 3.50% |
| 100 | 均匀 | 9.56% → 2.16% | 0.57% | 0.27% |
| 100 | 聚集 | 9.60% → 2.78% | 2.93% | **13.18%（比不做还差）** |

## 4 ③ 真实数据实验（49 帧 / 12 板块 / 2 台望远镜）

### 4.1 数据与代理测量口径

| 项 | 内容 |
|---|---|
| 数据 | `run/RELEASE-02/L4-rebuild/norm/<tile>/`：49 帧 `calibrated_*.fts` + `p1_flux.json`（孔径测光，r=4 px 口径）+ `p1_wcs.json`（TAN+SIP） |
| **重要事实** | 这批 L4 产物 `photometry_applied=false`、`photscal=1.0`（FIX-P1 之前）⇒ 帧间乘性失配是**未做任何标量校准**的原始失配 |
| 星匹配 | 用 WCS 投到天球，KD-tree 互匹配 ≤0.7″；流量比裁剪 |x|<8；3 轮 MAD 粗剔；MIN_FLUX=2e4 ADU、MIN_SNR=50；每对 ≥40 星 |
| 帧对 | **398 对**（same-tile 91 / adjacent-panel 126 / cross-tel 181） |
| 逐星覆盖 | 每帧亮星中位约 **850**（min 342、max 1053）；3×3 分块（≥5 星）中位 **9/9**、**100% 的帧 9 块全满**；8×8 分块（≥3 星）平均约 **90%** |
| 拟合观测数 | 89361 条逐星比值 |

**代理测量的口径与局限（诚实登记）**：L4 产物里**没有** Gaia F_syn，所以不能逐帧做绝对拟合。本工作区用**帧间差分联合拟合**作为代理：

    z_AB,i = log10( f_A,i / f_B,i ) = surf_A(p_A,i) − surf_B(p_B,i) + ε

gauge：对每个基函数 j 令 Σ_k c_k,j = 0。**生产链不存在这个局限**：它每帧独立对 Gaia 拟合，有绝对锚点（合成实验 §3 已证）。

### 4.2 逐帧 m 幅度：**不可辨识**（关键登记）

| τ_spatial（先验，dex） | order 1 的 m 幅度（中位） | order 1 的 m 幅度（max） |
|---|---|---|
| 无先验 | 66.7% | 200.1% |
| 0.05 | 66.6% | 199.4% |
| 0.02 | 65.7% | 195.6% |
| 0.01 | 62.6% | 183.5% |
| 0.005 | 52.6% | 147.7% |

**诊断**：同一 tile 内所有帧几乎得到**完全相同**的大幅空间图案（例：`t2_m4` 三帧 m pp = 94%/115%/98%，y 向梯度 73%/91%/94%），且 `t3_m4` 也有同量级的 y 梯度。这类「同指向共模」图案在**帧间差里抵消**，因此对帧间比值几乎无影响（见 §4.3：3×3 指标对 τ 不敏感），但它的**绝对幅度由数据几乎不可约束**（只靠 dither 的二阶效应）。

⇒ **结论**：**帧间相对空间增益可辨识且稳定；逐帧绝对空间增益在「只有帧间差」的数据上不可辨识。** 生产链因为每帧对 Gaia 独立拟合，**有**绝对锚点，不受此限（合成实验 §3 用的是逐帧独立拟合，恢复误差 0.48%）。
⇒ **因此本节的逐帧 m 幅度不作为结论**；真实数据的可信结论是 §4.3 的**相对** before/after。

### 4.3 before / after（**in-sample**：在与拟合同一口径 r=4 上）

#### 4.5.2 孔径探针（决定性）：空间结构**不是**乘法增益

若残差是真正的乘法增益（平场），则**任何孔径**测得的帧间比值都应被**同一个** m 吃掉。`aperture_probe.py` 对同一帧对在 r = 3/4/6/10 上分别测光：

| 帧对 | 孔径 r | 3×3 before | 3×3 after（用 r=4 拟合的 m） | 模型 m 的 pp |
|---|---|---|---|---|
| M1 T2×T3（跨镜） | 3 | **7.775%** | **3.403%** | 7.932% |
| M1 T2×T3（跨镜） | 4 | 4.928% | **1.957%** | 7.932% |
| M1 T2×T3（跨镜） | 6 | 3.807% | 4.857%（变差） | 7.932% |
| M1 T2×T3（跨镜） | 10 | 4.249% | 5.735%（变差） | 7.932% |
| M3 T3（同镜） | 3 | 1.166% | 0.875% | 1.621% |
| M3 T3（同镜） | 4 | 0.601% | 0.493% | 1.621% |
| M3 T3（同镜） | 6 | 0.409% | 1.039%（变差） | 1.621% |
| M3 T3（同镜） | 10 | 0.464% | 1.327%（变差） | 1.621% |

**三条事实**：
1. **同一帧对的「乘性空间残差」随孔径从 7.78%（r=3）单调降到 3.81%（r=6）再回升到 4.25%（r=10）**。纯乘法增益**不可能**有这种依赖（比值会被同一个因子缩放，峰峰不变）。
2. **m 只在它被拟合的那个孔径上有效**（r=4：4.93% → 1.96%，−60%），换孔径就失效甚至反向。
3. **模型 m 的 pp（7.93%）是 r=6 实测结构（3.81%）的 2.1 倍** ⇒ 小孔径测光把结构**放大**了，典型的**孔径/PSF 依赖系统差**特征（小孔径对 seeing 更敏感；环带 6–10 px 在 M42 星云区还叠加天光污染）。

⇒ **判定：真实数据上测得的空间结构主要由孔径/PSF 系统差主导，不是乘法增益。** 因此 §4.3 的 in-sample 改善**不能**作为「真实数据已被校准」的证据。

### 4.6 对下游的影响（诚实结论）

**可以说的**：
- 在**拟合口径内**（r=4），跨望远镜帧间乘性差 7.10% → 4.74%、接缝 7.66% → 5.90%、同镜 3.74% → 2.50%，70% 的帧对改善；
- 拟合出的空间结构**可跨独立半样本复现**（corr 0.997），且把逐星残差 σ 从 0.01464 dex 压到 0.01120 dex（−23%）；
- **按星数分箱**（`analyze_real.py`）显示：星越多越有效 —— 3×3 中位比值 order 1：n<100 → 0.83、n 100–200 → **1.03（变差）**、n 200–400 → 0.78、**n>400 → 0.62（86% 帧对改善）**。这**独立支持 §2.5 的按星数 fail-closed**。

**不能说的（关键）**：
- **不能**声称「真实数据的跨望远镜 8.7–9.9% 乘性差已被显著压低」：在**与拟合无关的孔径（r=6）**上复核，代表帧对**全部变差**（§4.5.1）；
- **不能**声称已测得逐帧 m 形态（§4.2 不可辨识）；
- **不能**把 §4.3 的 in-sample 数字当成"实现效果"上报。

**根因（一句话）**：L4 产物里可用的 `F_instr` 是**小孔径（r=4 px）测光**，它对 PSF/seeing 与星云天光污染敏感；**空间拟合会优先吸收这些系统差**，因为它们在空间上光滑、且远大于真实平场残差。这与 Q1 的 P1-3 登记（现用检测等照度 flux，跨望远镜可达约 0.5 mag 偏差；建议改固定孔径/PSF 总通量）**同源**。

### 5.3 与 FIX-P1 的兼容性

- FIX-P1 的 `photoapplied_<base>` 产物路径、完整性门（全帧齐备才施加）、`photscales` 逐帧标量、drizzle 消费逻辑**全部保留**；
- **默认 `spatial_gain_order=0` 时行为与 FIX-P1 逐位一致**（`apply_photometry` 原路径），因此可用现有 p1001 用例做**绿/绿回归**；
- 新增红/绿用例建议：① 合成帧 + 已知 m ⇒ 断言 `photoapplied` 的逐像素比值等于 `k_photo·m`（≤1e−6）；② m≡1 负例 ⇒ 断言 `spatial_gain` 系数全接近 0（≤噪声底）且 N<50 时 `m_order` 被记为 `degraded_scalar`；③ 覆盖不足负例（星聚成 1 块）⇒ 断言降级；④ 缺星/缺 WCS ⇒ 断言整组不施加（沿用 FIX-P1 语义）。

### 5.4 与 `p1_photscale.json` sidecar 通道的关系

sidecar（`DATA-P1-PHOTSCALE-001`）目前只有逐帧标量。若要支持空间项，建议**扩展 schema 而非替换**：每帧增可选 `spatial: {order, coef[], norm[4]}`，缺失时按标量处理（向后兼容）。**本轮不改 schema**（属主线数据合同变更，需前台裁决）。

## 6 ⑤ 局限与未决

0. **【最高优先，阻塞实现】真实数据的 m 被孔径/PSF 系统差污染**（§4.5.2）。**在 `F_instr` 换成 PSF 稳健口径之前，不建议在生产上开启空间增益**：否则它会把 PSF/seeing 系统差当成平场残差吸收掉，且**在帧间指标上看起来是"改善"**（in-sample），却在独立口径上变差。
   **验收前置条件（建议写进实现任务）**：
   - (a) `F_instr` 改为**固定大孔径（≳2×FWHM）或 PSF 总通量**，并保持逐帧同一物理口径；
   - (b) 空间拟合必须通过**孔径无关性验收**：在 r=4/6/10 三个口径上分别测帧间 3×3 峰峰，要求 `after < before` **在三个口径上同时成立**；
   - (c) 通过 (b) 之前，`spatial_gain_order` 默认保持 **0**（= 现行 FIX-P1 行为）。
1. **真实数据的逐帧绝对 m 不可辨识**（§4.2）。本轮的 before/after 是**相对**结论，对马赛克接缝是充分的；但「每帧的 m 长什么样」必须由生产链（Gaia 绝对锚点）给出，本工作区**没有**该锚点，**不宣称**已测得逐帧 m 形态。
2. **真实数据的 F_instr 用的是 `p1_flux.json` 的 r=4 px 孔径测光**，而 Q1 已证 `p1_sources[].flux`（检测等照度通量）有强视宁度偏差。若生产接线时用后者，空间拟合会被 PSF 系统差污染。**建议生产侧用固定孔径或 PSF 总通量**（与 FIX-P1 的 P1-3 登记一致）。
3. **星云区天光污染**：孔径局部天光在 M42 星云区不可靠，会伪造空间结构。本轮用亮星 + 逆方差权重 + Tukey 抑制，但**未**做「按星云亮度分层」的残差检查。未决。
4. **order 1 只吃掉 1/4–1/3 的真实残差**。剩余项的性质（更高频平场？测光噪声？天光污染？）**未分解**。本方案按指令「不管高阶」，但「剩下的是什么」应登记为未决。
5. **C3/C5 两条预先写定的判据未达标**（§3.6），未放宽。
6. **C++ Oracle 与 Python 的噪声底量级差 1.5–1.7×**（C++ 中位 0.87%/1.72%/3.17% vs Python 中位 1.23%/2.72%/5.40%，N=200）：两者 RNG/噪声实现不同，且统计量（中位/均值）不同。**未做**逐位对齐的交叉验证，登记为未决。
7. **未验证**：空间项与 Phase2 加性面 δ_k **联立**时的相互影响（本工作区只验证了「星点对加性梯度是盲的」这一单向性质）。
8. **未做**：多波段/颜色项（本方案明确不含颜色），以及跨夜透明度时变的高阶建模。
9. **未做（但已给出方法）**：把 `F_instr` 换成 PSF 总通量后**重跑**本工作区的全部真实数据实验。这是本轮**唯一**能把「真实数据也能校准」从「方法可行」变成「已验收」的路径。
10. **未做**：逐帧 PSF 尺寸（seeing）空间图与 m 的相关性检查 —— 这是验证 §4.5.2 根因假设的**直接**实验（若 `m` 与 `FWHM(x,y)` 强相关，根因坐实）。
