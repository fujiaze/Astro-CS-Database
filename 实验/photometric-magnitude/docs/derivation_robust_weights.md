## D1 dex 与 mag 的容差分离（r_i 与 delta_i 不共用容差）

**记号（订正 P1-M03：统一 delta 定义、量纲显式）**：本单元与实现（`code/scia_calib.py:123-126`）约定

```
delta_i := −2.5·log10 F_instr,i − G_i        # 单位 mag；G 已在该定义内被减去一次
r_i     := log10(F_instr,i / F_syn,i)        # 单位 dex
G_i      = −2.5·log10 F_syn,i + C          # C 与星无关（参考刻度零点）
```

代入即得 `delta_i = −2.5·r_i − C`；对中位数取差后 C 消去：

```
|delta_i − median(delta)| = 2.5·|r_i − median(r)|        # mag ↔ dex
```

⇒ 阈值 **3.0 mag**（作用在 `|delta_i − median(delta)|` 上）严格等价于 **1.2 dex**（作用在 `|r_i − median(r)|` 上，3.0/2.5 = 1.2；通量比 10^1.2 ≈ 15.85）。

**两域量纲不同，容差不得混用**：同一数字「3.0」在 mag 域是门阈值、在 dex 域对应的是 1.2。这是两套门参数必须分立记账的推导依据。
**历史表述错误（已订正）**：论文与 README 曾把该窗写成 `|r − median(r)| ≤ 3.0`（r 为 dex）又在同句注「= 1.2 dex」，自相矛盾；实现一直是 `|delta_i − median(delta)| ≤ 3.0 mag`。
**不得**把「3.0」理解成「delta 之外再减一次 G」——那会与实现差一个 `G_i` 量级。

## D2 零点平移不变量（k_photo 尺度无关，逐位）

设全体 `F_instr,i → a·F_instr,i`（a > 0），则 `r_i → r_i + log10 a`。

1. 预筛窗：`|r_i − median(r)|` 逐元素不变（平移在差分中消去）⇒ 内点集逐元素相同；
2. IRLS：`u_i = (r_i − location)/(c·S)` 与 `S = MAD(r)/0.6745` 均只依赖 r 的差分 ⇒ 权 w_i 逐位不变；
3. 每步不动点 `location → location + log10 a`，`k_photo = 10^(−location) → k_photo/a`；
4. `sigma_residual = MAD(r_inliers)/0.6745` 逐位不变。

⇒ 零点平移不变量成立（浮点上为加性常数吸收，实测量级为机器精度级；[实验:code/redo/route3/exp_S04_mag_tolerance.py] 实测逐位成立、[实验:code/redo/route2/exp2_mag_prefilter.py] 平移负例 metric 归零）。这就是"标定系数不得含绝对数值窗口"的可证伪点 4 的数学内容：任何绝对窗口都破坏 a-等价类。

## D3 MAD→σ 常数是解析恒等式

正态分布 `N(0,σ²)` 下 `MAD = σ·Φ⁻¹(3/4)`，故一致性常数

```
0.6744897501960817 = Φ⁻¹(3/4)
1/0.6744897501960817 = 1.482602218505602
```

为分布常数（非拟合量）。erf 二分复算与代码字面量的相对差 1.6×10⁻¹⁶（双精度末位）[实验:code/redo/route2/exp1_robust_constants.py]。**按台账 A-P1-08**：`frame_photometry_fit.cpp:292` 的 `1.4826` 四位截断（相对差 1.496×10⁻⁶）违反 `NOISE_ESTIMATION.md:213` 冻结条款，须按条款改写（数值影响 1e-6 相对量级，不改判据方向）。

## D4 Tukey biweight c = 4.685 的 ARE 恒等式

M 估计的渐近方差（尺度已知路线）

```
V(c) = ∫ψ² dΦ / (∫ψ′ dΦ)²,   ψ(x) = x·(1 − (x/c)²)², |x| < c；否则 0
```

以均值为基准的渐近相对效率 `ARE(c) = 1/V(c)`。数值解 `ARE(c) = 0.95` 得 c* = 4.6850649（**归因订正 P1-m05：数值根只由 route2 承载**——`route2/exp1_robust_constants.py` 内两套求积互证到 7 位；`route3/exp_S01_tukey_c.py` 的 `numeric_root_c_star = 4.6853179` 只与它 4 位小数一致，根求解精度较低，**不得作数值锚**，该路线的角色仅是一手文献锚核验与 ARE 表复算），与 statsmodels `robust/_tables.py` 的 4.685065 六位一致 [实验:code/redo/route2/exp1_robust_constants.py]；一手文献锚为 Kafadar 1983（refs.md V1，台账 D-06 判锚有效）。负例：ψ(x)=x 恒等时效率 = 1（偏差 1.4×10⁻¹²，求积噪声底）。

**边界**：95% 效率只对"尺度已知"严格成立；若改为"每轮重估尺度"（Huber 型），崩溃点从 50% 降到 ~11.9%，c 与重估策略必须成对变更——本层 S 固定一次估计，属前者。

## D5 判据因子 1.166 = √1.361 的解释标签（按台账 A-P1-01 订正）

Rousseeuw & Croux 1993 Table 2 给出 MAD_n 在高斯数据下的**标准化方差** `V(MAD_n/Φ⁻¹(3/4)) ≈ 1.361·σ²/n`（n=∞ 行，refs.md V5）。因此

```
1.361 = 渐近标准化方差（无量纲系数）
1.166 = √1.361 = σ̂ 的相对标准差因子（√n 折算前）
```

`sigma_floor = (1 − 3·1.166/√n)·σ_fit`、`sigma_ceiling = (1 + 3·1.166/√n)·σ_ceiling,raw` 中的 `3·1.166/√n` 即"σ 估计量自身抽样涨落 ±3σ_σ̂"的保守包络。**订正**：历史正本把 1.166 标为"SD(MAD)/MAD"是不准确的表达——准确读法是"σ̂（由 MAD 归一）的相对标准差因子，√1.361"。

**归一化适用域（审查补充量化，2026-10）**：Kafadar 1983 的仿真表取尺度 `1.5×MAD`（fixed），而本单元取 `S = MAD/Φ⁻¹(3/4) = 1.4826022×MAD`（σ 一致口径，与 statsmodels `mad()` 同）。两者差 1.2% ⇒ 等效 c 从 4.685 变 4.631，`ARE` 变化 < 1×10⁻⁴ 量级，**不影响任何读数**；但引用「c = 4.685 ⇔ ARE = 0.95」时必须同时标明所依据的尺度归一化（本单元 = `MAD/Φ⁻¹(3/4)`）。

## D6 中位数标准误与有限样本偏差

- 渐近：`SE(median) = √(π/2)/√n ≈ 1.2533/√n`（正态）；
- 有限样本：n=3 时 MAD 型尺度的实测偏差因子 ≈ **1.49×**（[实验:code/redo/route3/exp_S11_zp_sample_floor.py]），而渐近式 1.2533/√n 在 n=3 处对 SE **高估 8.03%**（**订正 P1-M04**：历史写的 7.4% 是 `1 − 比值` 的误读，即 `1 − 0.9256987 = 0.0743`；正确读法是「渐近值相对精确值的超出比例」= `0.7235930923753581/0.6698291607404145 − 1 = 0.08028`）；
- 推论（下游约定）：`ZP_syn` 三星下限的抽样误差是 n≈2338 满载的 **25.7 倍**；`n=3` 帧 `sigma_mag` 系统性下偏 ⇒ P2 的低星数帧零点不确定度被低估，消费侧须按非完美控制点处理。

## D7 反方差口径与稳健权的分工（Aitken 1935 定位）

项目的加权估计约定为**反方差加权**（`w ∝ 1/Var`），经典出处为 Aitken 1935（refs.md V11；负责人已批，P1/P2 涉及权重处引用）。本单元的两处权重语义分立：

1. **IRLS 稳健权** `w_i = (1−u_i²)²·[|u_i|<1]`：这是稳健统计权（降权离群），不是反方差权——它吸收的是错配/污染，不是测量方差；
2. **量纲变换的反方差权**：施加 `I_photo = k_photo·m(x,y)·I_cal` 后，`x′ = α·x ⇒ Var′ = α²·Var`，故 `ivar′ = ivar/α²`（`α = k_photo·m`），该口径交由 P5 的 SNR 加权消费。

两族权重**不得混写**：稳健权改变样本有效集合，反方差权改变统计最优性；前者服务无偏性，后者服务效率（Aitken 意义下的 BLUE）。

## D8 Simpson 求积收敛阶（F_syn 积分约定的误差界）

复合 Simpson 1/3 在 [a,b] 上对 C⁴ 被积式有 `O(h⁴)` 全局误差；本单元 2 nm 网格下，解析检查用例 D/E 相对连续积分的偏差 0.66%/1.34% 全部归因于网格离散（同一网格上生产实现与复合 Simpson 逐位一致，rel=0），其中 uint8 量化只贡献 0.025%（`docs/fsyn_convention.md` §2.2）。

**适用域（订正 P1-m03，2026-10）**：0.66%/1.34% 的被积函数含**顶帽不连续点**，因此它是**不连续通带的最坏界**，**不是**该流水线的常规网格误差。同一 343 点网格上：① 光滑被积函数（Planck × 高斯带通）相对连续积分为 **7.9×10⁻¹⁵**（审查员独立复算）；② 真实谱 × Baader R × KAF QE 体系下，Akima 重建 vs 线性重建差中位 **2.0×10⁻⁴**。⇒ 引用该数字时必须写明被积函数的连续性前提（fail-safe 方向：不连续用例给出的是上界）。被积式含 |x| 型折点（区间外填 0）时收敛阶退化——这是"末尾奇数区间用 3/8、n==1 退梯形"守卫之外的精度语义，`n_int ≥ 1` 守卫拒绝空区间（S14，[实验:code/redo/route1/exp5_integration_gates.py]）。
