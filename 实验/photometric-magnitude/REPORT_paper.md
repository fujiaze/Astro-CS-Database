# P1｜基于 Gaia DR3 XP 合成测光的天文图像逐帧光度标定：模型、误差预算与真实数据失效域

> 科学论文修订稿（方法与实验方案已校订；真实数据结论尚未通过独立复算验收）。本稿取代同路径的历史审计流水式论文；旧读数与引文可由 Git 历史、`REPORT_experiment.md` 和本单元实验脚本追溯。与本篇配套的完整一手文献及 BibTeX 见 `../shared/references/CORE_REFERENCES_VERIFIED.md`。以下“代理报告”表示来自 `实验/engineering-evidence/acsd-science-docs-p5/HANDOFF_REPORT.md` 的结果，并非本次人工独立重跑。

## 摘要

面对曝光、增益、通带和大气透过率信息不完全的天文 FITS，本文研究如何使用 Gaia DR3 BP/RP（XP）外定标光谱，将多个观测帧校准到定义一致的**线性光度尺度**，并定量区分合成通量可计算性、星点测光残差及最终校准可信度。方法以源光谱与滤镜/量子效率响应卷积得到参考合成通量，通过逐星对数残差的稳健估计求取帧级尺度系数，可选低阶空间响应。我们将理论可辨识性、合成天区真值恢复、物理前向成像与真实观测三类证据分开。代理报告显示真实帧残差 `σ_obs=0.02651984 mag` 大于所用上界 `0.020561 mag`；该上界包含未经独立标定的平场预算假设，不能据此定位全部误差来源。颜色残差趋势明确，但去趋势后仍不达旧门。本篇不主张开创 Gaia XP 合成测光，也不宣称 ACSD 已达到毫米星等精度。

**关键词**：Gaia DR3 XP；合成测光；稳健回归；测光零点；空间平场；误差预算；可辨识性。

## 1 科学问题与相关工作

Gaia Collaboration / Montegriffo 等给出 Gaia DR3 XP 的外定标光谱与合成测光框架 [R01]；Xiao 等已将 XP 合成测光用于 CMOS 精密光度定标并取得重复观测结果 [R02]；Padmanabhan 等的重叠观测全局校准说明了相对零点与绝对锚的区别 [R03]。因此 ACSD 可检验的论文贡献应收窄为：对不完备 FITS 元数据的实际链路建立可计算参考通量、帧级标度与空间修正的明确单位接口，并以独立预算和真实帧反证来界定成功/失败的适用域，而非把这些成熟基础方法宣称为首次提出。

研究问题：H1 在已知通带/响应的情况下，逐帧尺度系数可在未知仪器常数时相对辨识；H2 模型在有真值的合成和物理前向图像上无偏且可校准；H3 真实帧散度和置信区间能由**独立**预算解释；H4 低阶空间增益不以过拟合消除真实颜色或 PSF 系统项。

## 2 观测模型、单位与可辨识性

设第 k 帧第 i 颗星的扣背景实测积分通量 `f_ki>0`，其中饱和、混叠、坏点与失配源须在拟合前排除；Gaia 给出的光谱辐照度 `F_lambda,i` 单位可写为 W·m^-2·nm^-1，波长网格需转换成与 `hc` 一致的 SI 单位。对于**光子响应**，理想参考光子通量满足

```text
q_i = integral F_lambda,i(lambda) * T(lambda) * Q(lambda) *
               [lambda/(h*c)] d(lambda)
```

其中 `T` 和 `Q` 无量纲；在 `F_lambda` 和 `lambda` 均使用一致 SI 量纲后 `q_i` 为光子·m^-2·s^-1。代码如省去常数 `1/(hc)`，定义的是`Qproxy_i=integral F_lambda*T*Q*lambda d(lambda)`，**不得把 proxy 的数值和单位误写为真实光子通量**，也不得跨不同积分/波长单位约定直接比较。G 星等不应再次乘在已经包含绝对通量的 XP 谱上。

相对响应模型写成 `f_ki = c_k · m_k(x_i,y_i)^(-1) · q_i + e_ki`，`c_k` 合并曝光、口径、透过率和探测器换算等不可分离的正系数。无独立仪器标定时这些物理乘子**仅积可辨识**；以 `m_k` 的空间均值或参考位置固定为 1 确定规范，从 `r_ki=log10(f_ki/q_i)` 的稳健位置估计 `mu_k` 求 `k_photo=10^(-mu_k)`。输出 `I_photo=k_photo*m_k(x,y)*I_cal` 仍是线性光度图像；星等 `m=ZP-2.5log10(f)` 只作为派生展示。对于跨滤镜产品，不存在可不加色彩变换直接比较的单一物理通量。

稳健位置采用 Tukey biweight/IRLS，要求独立报告初值、固定/更新尺度的区别、损失函数、收敛、样本数与离群过滤。空间增益模型以零阶作为基线，最多试低阶多项式；阶数由留出恒星和空域覆盖决定，不能仅因训练残差降低便接受。

## 3 误差传播与判据

以星等残差 `d_ki=-2.5log10(f_ki/q_i)` 的留出散度为被估量，分解（至少）光子/读噪、Gaia XP 绝对谱、通带响应、背景拟合、PSF/光圈、空间平场、色差与探测器非线性。各项需说明是**帧内随机量、逐帧共同项还是跨帧系统项**；共同误差不能直接假设相互独立并逐颗平方相加。未独立估计的项以 `UNKNOWN` 记录。任何依赖受检残差自身的 `sigma_flat` 不能回灌阈值形成自指通过。

复现旧门时同时保留 `sigma_obs`、`sigma_ceiling`、具体预算分量和计算代码；新论文只在独立测量验证其预算与检测功效以后，才把统计上界用于通过/失败裁决。特别是 `sigma_flat=0.0007 mag` 暂为**仓内未验证的预算假设**，不应被称为来自一手文献的标定常数。对小匹配星数同时报告有效自由度、稳健估计量有限样本误差及 `NOT_IDENTIFIABLE` 状态。

## 4 三层实验设计与受控消融

| 实验 | 数据和控制 | 关键指标 | 能证明/不能证明 |
|---|---|---|---|
| P1-A 解析 oracle | XP 光谱、封闭式平坦/高斯/已知多项式响应，0 噪/已知噪；单位与常数谱积分反例 | `k_photo` 相对误差、积分守恒、残差分布、色彩斜率 | 算法代数正确；不等于真帧通过 |
| P1-B HST 结构前向 | 保持固定 HST 大尺度天体信号，注入已知星通量、PSF、泊松、读噪、通带/空间增益、饱和 | 零点偏差、95% 区间覆盖、场残差、光学位置偏差 | 模型在已声明前向世界有效；不证明真实探测器线性 |
| P1-C 真实帧 | `testdata/` 中按 `AGENTS.md` 第 13.1 节枚举和 WCS/CRVAL 断言的 M42 等实际帧 | `sigma_obs`、颜色/星等/位置分层残差、留出星预测差、重复帧对照 | 直接否证预算；不因单一门值就给出具体物理成因 |
| P1-D 负对照 | 错滤镜/QE、重复施加 G、颜色项截断、过拟合空间场、近饱和源、错误 FITS 标度 | 检出功效、误拒率、是否失败关闭 | 验证门不是恒绿；不能利用调松门获得成功 |

分别输出星点数量与抽样方式（训练/留出）、通带信息、拟合参数、bootstrap 置信区间、残差诊断图、探测器线性有效区间。星点按物理观测单元分组以免同一对象同时进入训练和验证。真实帧不得靠文件名子串选取数据集。

## 5 现有证据及其等级

交接报告称合规重跑的两帧 `sigma_obs=0.0265198375`、`0.0268530867 mag`，旧 `sigma_ceiling=0.020561 mag`；颜色轴斜率 `-0.024451±0.002296 mag`（该量的自变量定义和单位需由原始脚本恢复），扣颜色后 `sigma_obs=0.021801 mag`，多项同时扣后约 `0.021612 mag`，仍高于旧上界。**证据等级：AGENT_REPORTED，未在本次连接中取得逐颗星残差与代码执行哈希。** 不得将颜色轴已解释的变化写作“剩余误差已知成因”，或把所用旧上界当成已独立标定的发布门。

此前“解析与 HST 仿真通过、真实帧失败”的证据结构可保留为不同层的观察，但没有共同输入与独立噪声预算闭合，不得宣布整体创新点在真实数据上成立。修订实验代码的 ADU 方差量纲必须重新跑旧/新两个版本，提供差分读数和可追踪 commit。

## 6 讨论、结论与可发表贡献边界

目前可成立的是**方法定义与部分可复算构造**，不成立的是“真实相机数据已经符合独立误差预算”的结论。可能的论文主张是：在 Gaia XP 已知先例下，ACSD 将相对规范、单位传播、空间场可辨识及三类观测反例结合为面向大规模球面归一化的接口与验证框架。能否把该主张写成“达到 X mmag”必须等待独立数据的结果、样本数量与可信区间。

需要完成的最小实验：独立测量 `sigma_flat`；输出真帧源逐条残差；分层验证非线性与色差；复核 Gaia XP 能量/光子响应的单位；合规重跑前向三臂；使真实帧预算门可由另一个操作者独立复现。
