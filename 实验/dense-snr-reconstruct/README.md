## 本单元的验收责任

本篇先证明科学被估量的单位和可辨识性，再以独立 Oracle 验证数值，再测生产算法的红/绿判别力，最后使用合规真实数据或 HST 物理前向模板。对失败的科学命题保持明确 `FAIL`，对未运行/不能独立核对的量保持 `NOT_RUN` 或 `UNVERIFIED`，不得因机器测试退出码为零直接升级为论文科学通过。

论文涉及的共用量只引用上游真实定义：P1 线性光度标度、P2 点源条件参考精度、P3 球面积分与协方差、P4 支持域重建、P5 连通分量及加乘性差模。各单元不得复制另一篇未确认的实验读数并以“已在上游证明”作为替代证据。
