## 一句话结论

**重建以自然三次样条钳制算子（natural_bicubic_spline_clip_v1）为生产默认（节点复现 ≤3.6e-15、可分辨域 Δ/ℓ≲1 内最优、收敛阶 −4 闭合），定权恒等式 w = SNR²/F_ref² = 1/σ_F² 机器精度成立且 γ=2 由定义唯一确定；逐像素定权面上控制值必须携带源项亮度（丢源项 → P5 效率最劣损失 12 倍，适用域 = 场在 Δ 尺度上平滑）；IDW 为备选口径，终裁默认 idw_power=1.0（台账 D-05），drizzle 侧求值器已生效、Phase1 估计器路径仍为 2.0；稠密重建的有效域是「方差场在 Δ 格上可表示」（J_Δ ≪ 1）且不含 cell 内未分辨结构的三因子联合判据；稀疏控制格不表示 PSF 尺度（3.8 dex）。**

## M16 物理前向仿真腿

本单元第一次拿到**逐像素绝对 SNR 真值**：真实 HST M16 F657N drz 帧作纯信号模板，经共享物理链
（源/天光/暗流电子域 Poisson、读出电子域 Gaussian、增益+饱和+量化、平场、天空梯度）生成仿真采样帧，
用物理链的逐像素期望量给出 SNR_true = (S_e/g)/√((S_e+B_e+D_e)/g² + RN²/g² + 1/12)。

结论：在 M16 这样的真实结构场上，**三口径排序 E_frame < E_cell < E_dense 在 6/6 个对比度档全部成立**
（跟踪得越少越好），稠密口径的失效来自样条欠冲（负值像素占比 2.5%–22.6%），值域钳制守卫把它从 2.58e4
压到 4.54。**「真方差动态范围 1.78–235」不是有效域判据（被否证）**——窗口内稠密口径照样失效。替代口径 =
**Δ-格可表示性 `J_Δ = E_eff(cell-oracle)`**（只用真值、与算子无关、与方差动态范围无关、随 Δ 单调增）；
`J_Δ` 的已知盲区是 cell 内未分辨点源，完整判据见 `docs/science/CONTROL_WEIGHT_SNR.md` §8b 的三因子联合判据。
本腿的 dense 臂是**未钳制**样条、非生产默认算子（见 REPORT_experiment.md §6 第 16–17 条）。因噪声相关性边界（真实 drz 噪声已相关化、仿真帧逐像素独立），IDW 最优幂、Δ² 偏置
系数、白性判据与 E_eff 绝对值外推**一律不在本腿定标**，取舍表见 REPORT_experiment.md §4.1。

## 链条接口速览

- **上游（P2→P4）**：绝对 SNR(x,y) + F_ref,k + 控制点几何（Δ=512/8=64 结构派生，A-P4-01）；SNR_c = F_ref/√(σ_slow²+S_src/g)（亮度携带义务）。
- **P4 变换**：冻结算子词表（默认 natural_bicubic_spline_clip_v1；bilinear=对照/回退；IDW=备选 p=1.0/K=16/γ<1e-10，配置化+日志 p*）；节点复现门 1e-9（浮点性质，实测 3.6e-15）；值域钳制必要；fail-closed 覆盖域；空格≠零。
- **下游（P4→P5）**：w = SNR²/F_ref² = 1/σ_F²（γ=2 恒等式）；`m_ref` 仅记录参考电平——不变性是代数恒等，**天光受限臂精确成立（≈4e-16），生产组成臂只近似成立（`m_ref` 档漂移 1.9%–4.2%、源主导臂 3.83%）**，跨帧须限同一 `m_ref` 档（`docs/science/CONTROL_WEIGHT_SNR.md` §8a）；k_corr 两因子查表归 P3 单元承载（D-08）。

## 判据的地位：自身绿不构成证据

本单元 `code/` 下的判据实现与门判决序是**计算数据的正向代码**，随实验单元保留在库。
但**判据自身绿不构成该单元结论的证据资格**：门绿只说明实现与其自身阈值自洽，不说明结论为真。

结论的有效性由**对抗性审核**给出，不由门判决给出。审核须做三件事：对齐质疑、尝试**重新推导**该结论、
并**构造反例**（注入已知缺陷看门是否判红；真值无效应时是否归零）。判红也不是自动的证伪，
须由审核重新推导其成因，区分「预算或口径不完整导致的判红」与「结论确实不成立」。

本单元因此**不设**任何常驻机器门来保证归档与代码同步或代替上述审核。运行结果归档层已移除：
`results/` 只是运行期暂存目录，产物不入库；报告档案与图表素材在 `docs/`。

## 诚实边界速览

- **控制点退化 ⇒ 稠密臂退化为常数场、与帧级臂逐位相等且无错误信号**：单节点轴 1×3、16 点共线、控制点全落噪声主导区三族 `E_dense == E_frame`（1.083e−1 / 1.230e−1 / 4.382e−1），`J_Δ` 报 0.0397–0.0462 **不告警**；2×2 / 3×3 的域外查询点占比 0.750 / 0.438。生产的 `nx>=2 && ny>=2` 只挡单节点轴，挡不住 2 节点轴各向异性与共线（论文 §7-19）。
- **胞内点源下默认算子把重建面压成常数平台，误差方向是乐观的**：Δ=64 px、控制点取真值、FWHM 3–20 px 胞内点源下重建峰恒 = `max(node)`，`SNR_rec/true` = 0.675…0.008 ⇒ **权重被高估 2×–1.5×10⁴ 倍**（亮像素过度加权），与「丢源项最劣 12.6 倍」的保守方向相反；钳制不是机制（论文 §7-21）。
- **`J_Δ` 对胞内结构只抓方差侧**：胞内点源 0.0462 vs 光滑场 0.0397（几乎不动），胞内 100:1 阶跃 0.4190；效率读数 `E_dense` 点源 1.859 vs 帧级 0.438、阶跃 154.4 vs 24.5（论文 §7-20）。
- **预测方差的绝对值不可用**：`Var_opt` 以噪声独立为前提（ρ=0.1/0.3/0.6 时 GLS 可达方差/`Var_opt` = 1.31/1.67/1.72）；重建量自身的 `Σa²Var` 在 ρ=0.195 下 K=16 低估 3.93×、K=64 低估 13.3×，控制格边缘再叠加 1.4–2.0×（论文 §7-22、`docs/derivations.md` §7）。
- **`w` 对 `m_ref` 的不变性有适用域**：天光受限臂精确（≈4e-16），生产组成臂近似（漂移 1.9%–4.2%、源主导臂 3.83%）⇒ 跨帧须限同一 `m_ref` 档（论文 §2.2）。
- 其余边界（Δ 上界与域绑定、H4 逐像素化、真方差动态范围非判据、合成数据面、标注级文献锚、项目约定豁免）见 `REPORT_paper.md` §7（22 条）与 `REPORT_experiment.md` §6（22 条）。
