# P4｜稀疏参考信噪比场的稠密重建：估计目标、空间插值与不确定性校准

> 科学论文修订稿。原长篇 `REPORT_paper.md` 的历史读数可由 Git 版本及 `REPORT_experiment.md`、`docs/derivations.md` 追溯。本文区分信噪比参考场与真实场景源通量 SNR，并将“插值表现好”与“生产权重科学正确”分开判定。本次未独立重跑服务器数据。

## 摘要

为避免在每个天球像元都执行昂贵的 PSF 与噪声建模，ACSD 拟从逐帧稀疏控制点重建空间连续的参考信噪比场，并在多帧马赛克时现场得到相应精度权重。本文先对“稠密 SNR”的统计被估量进行约束：固定 `F_ref` 时，空间变化可由背景、PSF、覆盖与响应导致的参考通量估计标准差 `sigma_F(x)` 表达；若被估量换成实际天体场景的逐像素强度，则分子也必须变成位置相关的 `F_scene(x)`，不能继续把 `SNR²/F_ref²` 认作精确逆方差。本文设计结合解析噪声场、复杂物理结构与生产真实控制点的验证方案，将自然三次样条、双线性、IDW、常数/分块退化策略置于同一交叉验证框架，特别检验过冲、无控制区外推和叠加权重误用。现有代理报告中的结构场对照显示 `dense` 模式并不普遍占优，因此最佳方法须由预定义风险函数与留出误差决定。

**关键词**：稀疏到稠密；信噪比场；异方差；自然三次样条；插值过冲；外推；交叉验证；逆方差权重。

## 1 科学问题与先例

自然/平滑样条属于成熟的统计数值方法，Wahba [R08] 对拟合平滑程度和偏差-方差权衡有系统论述；Fritsch 与 Carlson [R14] 已提出单调三次插值的具体限制条件；Hyman [R09] 所讨论的形状保持三次 Hermite 插值**不是**一般自然三次样条的无过冲保证。Zackay & Ofek [R05] 对叠加估计目标和噪声特性构成背景。P4 不能以“发明稀疏插值”主张原创；需要实证的贡献是：将固定参考通量的 SNR 对象在 HEALPix 稀疏/稠密表示间转换，在非均匀分布与支持域缺失时使物理单位、误差判据及低内存现场求值保持一致。

本文独立研究四个问题：Q1 究竟重建什么物理量；Q2 哪类场和采样几何下哪些插值法误差最小；Q3 外推与钳制引入何种统计偏差；Q4 重建误差会怎样改变下游 P5 权重与产品的真实误差。

## 2 固定参考通量与信号相关方差的边界

令每帧 k 的参考通量 `F_ref,k` 在对应滤镜和参考星等档 `m_ref` 下固定，控制点 x 的参考通量预测方差为 `V_ref,k(x)>0`，定义：

```text
SNR_ref,k(x) = F_ref,k / sqrt(V_ref,k(x))
W_ref,k(x)   = SNR_ref,k(x)^2 / F_ref,k^2 = 1/V_ref,k(x)
```

两式是定义和代数恒等式，只有在 `F_ref,k` 保持同一参考口径、`V_ref` 真是要加权的**同一个被估量的方差**时，才有下游统计最优性。若噪声包含源泊松项，控制点上的 `V_ref` 须声明使用的是 `F_ref` 对应的参考 PSF 还是实际场景 `F_scene(x)`；不能同时假设 `F_ref` 固定、源项由实际 `F_scene` 改变且仍称同一个严格参考统计量。

定义场景 SNR 另为 `SNR_scene(x)=F_scene(x)/sqrt(V_scene(x;F_scene))`；这是不同对象。后者用于天体局部检测/诊断时，不能直接替代参考 SNR 承载相同下游权重。对弥散源面亮度，权重必须根据该面亮度估计量的像素方差定义，参见 P2 小论文 `../absolute-snr/REPORT_paper.md`。

**几何支持是物理对象的一部分**：控制点的球面位置、分辨率、nside、mask 与有效半径、参考星等和 PSF、标度类别及 `variance`/covariance 的忽略约定都进入一份 manifest。对于单帧区或无控制区应显式 `OUTSIDE_SUPPORT` 或选经验证的帧级常数退化；不能在高阶样条的自然外推值上无提示地生产科学权重。

## 3 重建算子与可校准参数

设控制点 `(x_i, SNR_i, sigma_i)`，正值字段可在 `log V_ref` 或 `log SNR_ref` 空间插值，避免常规插值产生负方差；但 `exp(E[log V])` 不等于 `E[V]`，应在预测偏差中登记 Jensen 效应。正值变换不能自动保证精度场无偏；需要和在线性方差、对数方差、对数精度三个表示空间分别对拍。

候选基线：
- 常数 `frame_reconstruct`：不声称有空间信息，作为稀疏不足时的参照。
- 分块/双线性重建：局部且易限制支持域，可作为几何粗场对照。
- IDW：`q(x)=sum_i d(x,x_i)^(-p) q_i / sum_i d(x,x_i)^(-p)`，定义精确控制点重合、零距和边界规则，比较 `p=1` 与 `p=2`，禁止全仓默认不一致。
- 自然三次样条/自然边界：在足够控制点与良好网格支持的域内适用；天然无单调或局部极值保持性质。对任意 `[0,2,0,0]` 等非单调节点可产生超过最大节点值的过冲；如产品声称不越界，须显式夹逼或使用真正形状保持算子，且计算夹逼所致预测偏差。
- 直接密集 `dense`：如果来自当前真实生产噪声场，可作高成本参照；**它不必在所有场型上是 oracle**，因为生成链自身可能带结构污染和模型偏差。

复杂度按控制点数、输出查询数、内存峰值、节点支撑和缓存策略报告。生产选用算法必须先冻结评价指标，不能选择实验后最漂亮的一臂作为主结果。

## 4 严格的空间交叉验证和误差预算

| 组 | 测试场/对照 | 独立检验 |
|---|---|---|
| P4-A 解析平稳噪声场 | 常数场、线性缓变、平滑梯度、弯曲及局部突变；控制点均匀/不均匀 | 留出 RMSE、相对偏差、`V_pred/V_true`、零空间变化负例 |
| P4-B 控制点缺失 | 中心空洞、边缘半环、两个断开的簇、2×2/3×3 稀网格 | 支持域占比、域外查询比例、`OUTSIDE_SUPPORT` 的失败关闭 |
| P4-C 插值强约束 | 样条过冲 `[0,2,0,0]`、负值临界、零距、NaN、极端异方差 | 过冲幅度、钳制次数与偏差、无数据/退化状态 |
| P4-D 模型与目标错配 | 源项光子噪声开/关，固定 `F_ref` 与场景 `F_scene` 两套真值；扩展源/点源 | 参考 SNR 与场景 SNR 定义是否混淆、最终权重对正确被估量的效率 |
| P4-E 叠加传播 | 同一观测世界，oracle `V` 与重建 `Vhat` 对比，与 P5 联合 | integrated flux bias、实际方差与预测之比、亮度/深度偏差、接缝和低频保真 |
| P4-F 真实与生产 | 当前 `lib/**` 内读写 `sparse_snr_layer` 的构建调用，M42 合格帧 | 稀疏生产者存在、控制点读回、manifest、随机/空间留出、可复现调用 |

训练/验证应做空间 block CV 和跨帧 CV，不能对同一局部栅格用紧邻点作训练与验证，造成空间泄漏。另以随机控制点丢弃率、星密度、真实 PSF 和 SNR 动态范围分层。重建误差需报有符号偏差、绝对误差、对数误差、分位数和极端失效数，不能只有总体 RMSE。

## 5 现有证据与未决冲突

代理报告称，在一种“结构场”模拟中 `E_dense=0.577` 而 `E_cell=0.00903`。必须回查 E 的误差定义、标准化和被比较的是同一真值；该对照至少否定“`dense` 模式必定最佳”的无条件断言。代理报告还发现 `idw_power=1.0` 的文档终裁与生产 Phase1 若干使用点的 `2.0` 分裂；以及 2×2 与 3×3 查询时支持域外占比高但 `prepare` 成功。**证据等级：AGENT_REPORTED，相关命令与运行摘要尚需固定。**

此外 `[0,2,0,0]` 的自然样条超出节点最大值已从方法学上排除“自然样条保证不上冲”的错误推论；具体超出 `2.0113` 的数值仍需独立脚本复算。若 `sparse_snr_layer` 没有生产者，只验证插值 Python 脚本不能形成 P4 整条证据链。

## 6 结论和发表条件

P4 可辩护的研究贡献是“物理估计量不变 + HEALPix 稀疏支持域清晰 + 显式重建偏差传播”，不是“样条或 IDW 作为新算法”。在 `F_ref` 目标、生产者、负例和下游应用没有闭合前，“绝对 SNR 最优权重可在全域重建”处于 **UNVERIFIED**。需要完成 P4-A～F 的独立 oracle 与真实生产验证，再给出实际可接受场型、控制点最低信息量和运行复杂度。
