# P4｜稀疏参考信噪比场的稠密重建：估计目标、空间插值与不确定性校准

> 本篇区分信噪比参考场与真实场景源通量 SNR，并将“插值表现好”与“生产权重科学正确”分开判定，按最低图表集登记独立 oracle、生产探针读数与适用域。逐格读数、脚本与输入哈希台账见 `REPORT_experiment.md` §9、`docs/S06_P4_evidence.json` 与本单元 `code/s06/`。

## 摘要

为避免在每个天球像元都执行昂贵的 PSF 与噪声建模，ACSD 拟从逐帧稀疏控制点重建空间连续的参考信噪比场，并在多帧马赛克时现场得到相应精度权重。本文先对“稠密 SNR”的统计被估量进行约束：固定 `F_ref` 时，空间变化可由背景、PSF、覆盖与响应导致的参考通量估计标准差 `sigma_F(x)` 表达；若被估量换成实际天体场景的逐像素强度，则分子也必须变成位置相关的 `F_scene(x)`，不能继续把 `SNR²/F_ref²` 认作精确逆方差。本文以解析噪声场、结构场与生产真实控制点组成六臂留出交叉验证，并单独检验过冲、无控制区外推与退化状态。实测确认：`[0,2,0,0]` 节点上的自然三次样条越出节点最大值 `+1.1326e-2`（生产靠**显式值域钳制**而非样条性质）、`2×2`/`3×3` 控制网格分别有 `55.56%`/`43.75%` 的查询点落在支持域外而 `prepare` 仍成功、值域钳制**不是无偏**（咬合像素偏差 `−0.0411` 对非咬合 `+0.0082`）、规整稀疏层**无法表达空洞**（NaN 控制点被静默最近填充，偏差 `+0.5621`）。生产有效 `idw_power` 为 `2.0` 而规范默认 `1.0`，两者分裂仍是活的。留出方差比 `var_ratio = E_eff + 1` 是**分布型**判据、对控制点空间置换不敏感，必须与水平型判据（如 `dex_rmse`）成对报告。

**关键词**：稀疏到稠密；信噪比场；异方差；自然三次样条；插值过冲；外推；交叉验证；逆方差权重。

## 1 科学问题与先例

自然/平滑样条属于成熟的统计数值方法，Wahba [R08] 对拟合平滑程度和偏差-方差权衡有系统论述；Fritsch 与 Carlson [R14] 已提出单调三次插值的具体限制条件；Hyman [R09] 所讨论的形状保持三次 Hermite 插值**不是**一般自然三次样条的无过冲保证。Zackay & Ofek [R05] 对叠加估计目标和噪声特性构成背景。P4 不能以“发明稀疏插值”主张原创；需要实证的贡献是：将固定参考通量的 SNR 对象在 HEALPix 稀疏/稠密表示间转换，在非均匀分布与支持域缺失时使物理单位、误差判据及低内存现场求值保持一致。

本文独立研究四个问题：Q1 究竟重建什么物理量；Q2 哪类场和采样几何下哪些插值法误差最小；Q3 外推与钳制引入何种统计偏差；Q4 重建误差会怎样改变下游 P5 权重与产品的真实误差。

**表 1 相关工作与本文区别**

|---|---|---|---|
| Wahba [R08] | 样条模型的平滑程度、偏差-方差权衡与留出准则 | 不重做样条理论；本文把生产算子（自然双三次 + 显式值域钳制）的语义、支持域状态与失败关闭作为被检验对象，并给出留出方差比与水平型判据的成对口径 | 不主张新的样条或平滑理论 |

引文为书目级核验；正文不含须逐页核对的式号断言。

## 2 固定参考通量与信号相关方差的边界

令每帧 k 的参考通量 `F_ref,k` 在对应滤镜和参考星等档 `m_ref` 下固定，控制点 x 的参考通量预测方差为 `V_ref,k(x)>0`，定义：

```text
SNR_ref,k(x) = F_ref,k / sqrt(V_ref,k(x))
W_ref,k(x)   = SNR_ref,k(x)^2 / F_ref,k^2 = 1/V_ref,k(x)
```

两式是定义和代数恒等式，只有在 `F_ref,k` 保持同一参考口径、`V_ref` 真是要加权的**同一个被估量的方差**时，才有下游统计最优性。若噪声包含源泊松项，控制点上的 `V_ref` 须声明使用的是 `F_ref` 对应的参考 PSF 还是实际场景 `F_scene(x)`；不能同时假设 `F_ref` 固定、源项由实际 `F_scene` 改变且仍称同一个严格参考统计量。

定义场景 SNR 另为 `SNR_scene(x)=F_scene(x)/sqrt(V_scene(x;F_scene))`；这是不同对象。后者用于天体局部检测/诊断时，不能直接替代参考 SNR 承载相同下游权重。对弥散源面亮度，权重必须根据该面亮度估计量的像素方差定义，参见 P2 小论文 `../absolute-snr/REPORT_paper.md`。

**几何支持是物理对象的一部分**：控制点的球面位置、分辨率、nside、mask 与有效半径、参考星等和 PSF、标度类别及 `variance`/covariance 的忽略约定都进入一份 manifest。对于单帧区或无控制区应显式 `OUTSIDE_SUPPORT` 或选经验证的帧级常数退化；不能在高阶样条的自然外推值上无提示地生产科学权重。

## 3 重建算子与可校准参数

设控制点 `(x_i, SNR_i, sigma_i)`，正值字段可在 `log V_ref` 或 `log SNR_ref` 空间插值，避免常规插值产生负方差；但 `exp(E[log V])` 不等于 `E[V]`，应在预测偏差中登记 Jensen 效应。正值变换不能自动保证精度场无偏；需要和在线性方差、对数方差、对数精度三个表示空间分别对拍。

候选基线：
- 常数 `frame_reconstruct`：不声称有空间信息，作为稀疏不足时的参照。
- 分块/双线性重建：局部且易限制支持域，可作为几何粗场对照。
- IDW：`q(x)=sum_i d(x,x_i)^(-p) q_i / sum_i d(x,x_i)^(-p)`，定义精确控制点重合、零距和边界规则，比较 `p=1` 与 `p=2`。规范默认 `p=1`，但生产 Phase1 路径写入的块内显式值为 `p=2` 并覆盖兜底 ⇒ **生产有效值仍为 `p=2`**，分裂未修（见 §5.4）。
- 自然三次样条/自然边界：在足够控制点与良好网格支持的域内适用；天然无单调或局部极值保持性质。对任意 `[0,2,0,0]` 等非单调节点可产生超过最大节点值的过冲；如产品声称不越界，须显式夹逼或使用真正形状保持算子，且计算夹逼所致预测偏差。
- 直接密集 `dense`：如果来自当前真实生产噪声场，可作高成本参照；**它不必在所有场型上是 oracle**，因为生成链自身可能带结构污染和模型偏差。

复杂度按控制点数、输出查询数、内存峰值、节点支撑和缓存策略报告。生产选用算法必须先冻结评价指标，不能选择实验后最漂亮的一臂作为主结果。

### 5.4 适用域与诚实限制（必须同读）

1. **`idw_power` 生产有效值 `2.0` ≠ 规范默认 `1.0`，分裂是活的。** Phase1 估计器写入的块内显式值覆盖 drizzle 侧的 `1.0` 兜底，最终经编排器序列化并**显式传参**给 `build(..., idw_power)`，因此兜底永不触发。该分裂未修（改动 `lib/**` 不在本篇写入面），任何“默认已统一为 `1.0`”的引用不成立。
2. **`E_eff`/`var_ratio` 是分布型判据，对控制点空间置换不敏感。** 实测置换后 `var_ratio` 变化仅 `1.05–8.58×`，而 `dex_rmse` 变化 `2.04–114.4×`；在“Δ 格不可表示”的场上判别力更弱（`dex` 比值约 `2.0`）。因此**必须成对给出水平型判据**（如 `dex_rmse`）并按可表示性分层报告，不得只报 `var_ratio`。
3. **规整稀疏层无法表达空洞。** NaN 控制点被静默最近填充（偏差 `+0.5621`），NaN mask 像素被静默插补（偏差 `−0.2154`）；生产 `prepare` 对零/负/全 NaN 控制值与非法查询坐标 fail-closed，但**已填好的规整网格无法承载“空洞”这一状态**。这是产品合同层面的缺口，不是插值精度问题。
4. **值域钳制不是无偏。** 咬合像素偏差 `−0.04115`、非咬合像素 `+0.00815`；`[0,2,0,0]` 平移模式下上侧咬合 `3.125%`、下侧咬合 `50%`。生产的上界由**显式钳制**保证，不能把越界抑制写成样条性质，也不能把钳制后结果当无偏。
5. **真实帧端到端 `NOT_RUN`。** 本篇 C 臂是 MAD² 代理；`sparse_snr_layer` 的真实生产者、真实控制点读回与按有效帧枚举的合格输入未跑；下游 `P5` 权重的绝对效率因此不可宣称。
6. 六臂 CV 只覆盖 `Δ=16/32`（`Δ≥32` 时粗训练网格 ≤3 节点，逐行已有告警）与 **iid** 噪声世界；相关噪声（`k_corr`）下的绝对效率、控制点空间相关性未标定。
7. 本篇 `dense` 臂使用生产 MAD² 估计器；在部分腿（`REPORT_experiment.md` §6）稠密臂脚本未施加生产钳制语义，同场景按生产语义复算可使量级差四个数量级（定性结论不变）。跨口径引用时必须注明算子状态。

### 5.5 跨篇误差传递反例（P2/P3 → P4）

按统一实验协议的第四条证据腿，P4 应消费上游对象并证明下游判据能判红。**本篇 `NOT_RUN`。** 现有的 P4 内部反例（域外 `55.56%/43.75%`、过冲越界、钳制非无偏）只证明 P4 自身判据能判红。缺什么：① 由 P3 修复前后各算一次的映射协方差（尚未做，`k_corr`/相关噪声归 P2 单元）；② 按有效帧枚举口径产出的真实稀疏控制点（P4-F 真实臂）；③ P1 标度偏差注入后 P4 支持域/权重判据与 P5 接缝判据的预声明红灯读数。三者缺一，跨篇链路无法给出。

## 6 结论和发表条件

P4 可辩护的研究贡献是“物理估计量不变 + HEALPix 稀疏支持域清晰 + 显式重建偏差传播”，不是“样条或 IDW 作为新算法”。本篇实测把三条结论钉死：自然三次样条**不**保证形状保持（越上界 `+1.1326e-2`，生产靠显式钳制）；稀疏网格的域外占比可高达 `55.56%/43.75%` 而 `prepare` 仍成功，静默外推偏差可超 `2%`；钳制**不是**无偏、规整网格**不能**表达空洞。`idw_power` 的生产有效值与规范默认仍分裂。在 `F_ref` 目标、真实生产者、跨篇负例与下游应用没有闭合前，“绝对 SNR 最优权重可在全域重建”处于 **UNVERIFIED**；已闭合的是方法定义、解析/合成世界上的算子比较与若干已判红的失败域。
