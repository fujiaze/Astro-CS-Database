# docs/derivations.md — P4 支撑推导（理论腿）

本文件是论文与实验报告中标注 [推导] 的承载件。全部推导自足，不依赖仓库科学文档的中间结论；符号与 NOISE_MODEL/CONTROL_WEIGHT_SNR 口径一致（SNR = F_ref/σ_F，g = 1.3 e⁻/ADU）。

## §1 定权恒等式与 γ=2 的唯一性

**定义**：控制点 k 处 SNR_k ≡ F_ref/σ_{F,k}，权重 w_k = (SNR_k/F_ref)²（逐帧 F_ref 为该帧参考通量；帧集内为公共尺度因子时记单帧口径）。

**恒等式**：w_k = SNR_k²/F_ref² = (F_ref/σ_{F,k})²/F_ref² = 1/σ_{F,k}²。代数恒等，无近似——float64 下机器精度成立（四路实测 ≤5.6e-16）。

**最优性（Cauchy–Schwarz）**：对独立无偏 x_k ~ N(μ, v_k)，加权均值 Var[μ̂_w] = Σw_k²·v_k/(Σw_k)²。由 (Σw_k)² = (Σ (w_k·√v_k)(1/√v_k))² ≤ (Σw_k²·v_k)(Σ1/v_k)，故 Var[μ̂_w] ≥ 1/(Σ1/v_k)，等号当且仅当 w_k·√v_k ∝ 1/√v_k，即 w_k ∝ 1/v_k。对独立观测，逆方差权即 GLS/Aitken [文献:refs.md 条目8，标注级] 的对角特例。将 v_k = σ_{F,k}² = F_ref²/SNR_k² 代入：**w_k ∝ SNR_k²**——幂次 γ=2 是“平方 SNR = 逆方差”的推论，不是自由参数。γ=1（w∝SNR）与等权的相对效率为 >1 的纯几何量（2 dex 动态范围下 3.73 与 104.58，路线3 MC 复现解析值）。

**负例判据**：全部 v_k 相等时各正权方案 Var[μ̂_w] 恒等——方案差度量必须精确归零（路线1/3 实测 0.005 与精确 0）。

## §2 平面条件数判据 λlo/λhi ≥ 1/16

控制点云 {p_i}（去均值）的 2×2 散布矩阵 M = Σ(p_i−p̄)(p_i−p̄)ᵀ。沿单位向量 u 的梯度估计方差 ∝ uᵀM⁻¹u，最坏方向 = 最小特征值方向，放大因子 κ = √(λhi/λlo)。κ 即点云长短轴比：把各向同性点云沿主轴压缩 s 倍，λhi/λlo = 1/s²，κ = 1/s = 轴比（路线1 实测偏差 ≤0.03%）。阈值 λlo/λhi ≥ 1/16 ⇔ κ ≤ 4 ⇔ 最坏方向 SE 放大 ≤4×：**保守良态守卫（fail-closed 门），非锐利物理边界**。实测放大 1.007/2.025/3.956/7.980（理论 1/2/4/8）；注意必须沿 M 的特征向量方向测量，沿坐标轴会严重低估（路线2 初版教训）。

## §3 收敛阶

光滑场 f ∈ C⁴、节点距 h：自然三次样条内部误差 O(h⁴)；双线性 O(h²)。路线3 实测：双线性内部阶 −1.93/−1.98（理论 −2）、样条 −3.97/−4.18（理论 −4）。自然边界条件 S″=0 在端点层与真值曲率不符 → 端点层阶退化（−3.88/−4.13）且绝对误差增大——规范相关的真实性质，非实现缺陷。Keys 三次卷积核（−a=−0.5）与样条同为 O(h⁴) 量级 [文献:refs.md 条目4]。

**Δ² 偏置律**：对曲率 q 的场（f ≈ q·x²/2），cell 中心采样 + 线性/样条重建的确定性偏置 ∝ q·Δ²/8：零噪偏置比 Δ₂/Δ₁ → (Δ₂/Δ₁)²。实测 128/64 = 4.06（理论 4）、256/16 = 280（理论 256）。Δ 不进入物理模型，其后果是确定性插值误差、由 Δ/ℓ 与曲率承载（route2/exp_P4R2_03）。

## §4 IDW 极限行为与 γ 门

IDW 权 w_i = d_i^(−p) / Σ_j d_j^(−p)（K 近邻）。p→∞ 时全部权重收缩到最近点——退化为最近邻算子（实测偏差序列 0.302 → 3.3e-3 → 5.5e-9 → 0，p = 30/100/300/1000，对数归一化防溢出）。p 小 → 权趋平（K 点均值，邻域平均压噪）；p 大 → 权趋尖（插值保真，放大控制点噪声）。含噪控制点下最优 p 由“偏差-方差”权衡决定：噪 0% 时 p=2 最优、2–6% 时 p≈0.5–1（route2/exp_P4R2_02 全扫）。γ 门：d < γ 时以 1/γ^p 替代 1/d^p 防 0^p 上溢；γ ≪ d_min 时 w 逐位不变（γ=1e-10 vs 1e-6 偏差 8.3e-10），γ ~ d^p 才实质改算子（γ=1e4 偏差 0.635）——数值守卫，非科学量。

## §5 白性恒等式 −1/2

白噪声 x_i（Var σ²，互不相关）。一阶差分 Δ_i = x_{i+1} − x_i：Cov(Δ_i, Δ_{i+1}) = Cov(x_{i+1}−x_i, x_{i+2}−x_{i+1}) = −σ²，Var(Δ) = 2σ² ⇒ lag-1 自相关 = −1/2（精确解析恒等式）。实测 −0.5007/−0.4995/−0.4984（高斯/量化/泊松）与 −0.49963 ± 0.00078（route3/exp06）。用途：判“噪声实现空间白”是**实现**的性质；方差图相对散布跟随电平场（σ²∝S ⇒ 比 1；σ²∝S² ⇒ 比 2）是**场**的性质——两者二分，P4 重建的稠密 σ 场只能承载后者。

## §6 Moffat4 FWHM/σ 闭式

Moffat I(r) ∝ (1+r²/α²)^(−β)，β=4：FWHM = 2α·√(2^(1/4)−1)；2D rms 半径口径 σ² = ⟨r²⟩/2 = α²/2（β=4 时积分收敛）。⇒ FWHM/σ = 2·√2·√(2^(1/4)−1) = 1.2303077；数值径向积分 1.2303078；登记 1.230310（相对差 1.79e-6）。同口径高斯 = 1.6651（≠ 教科书逐轴口径 2.3548）——常数随轮廓族与 σ 口径双重变化，判据非退化。
