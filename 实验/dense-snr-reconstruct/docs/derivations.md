# docs/derivations.md — P4 支撑推导（理论腿）

本文件是论文与实验报告中标注 [推导] 的承载件。全部推导自足，不依赖仓库科学文档的中间结论；符号与 NOISE_MODEL/CONTROL_WEIGHT_SNR 口径一致（SNR = F_ref/σ_F，g = 1.3 e⁻/ADU）。

## §1 定权恒等式与 γ=2 的唯一性

**定义**：控制点 k 处 SNR_k ≡ F_ref/σ_{F,k}，权重 w_k = (SNR_k/F_ref)²（逐帧 F_ref 为该帧参考通量；帧集内为公共尺度因子时记单帧口径）。

**恒等式**：w_k = SNR_k²/F_ref² = (F_ref/σ_{F,k})²/F_ref² = 1/σ_{F,k}²。代数恒等，无近似——float64 下机器精度成立（四路实测 ≤5.6e-16）。

**最优性（Cauchy–Schwarz）**：对独立无偏 x_k ~ N(μ, v_k)，加权均值 Var[μ̂_w] = Σw_k²·v_k/(Σw_k)²。由 (Σw_k)² = (Σ (w_k·√v_k)(1/√v_k))² ≤ (Σw_k²·v_k)(Σ1/v_k)，故 Var[μ̂_w] ≥ 1/(Σ1/v_k)，等号当且仅当 w_k·√v_k ∝ 1/√v_k，即 w_k ∝ 1/v_k。对独立观测，逆方差权即 GLS/Aitken [文献:refs.md 条目8，标注级] 的对角特例。将 v_k = σ_{F,k}² = F_ref²/SNR_k² 代入：**w_k ∝ SNR_k²**——幂次 γ=2 是“平方 SNR = 逆方差”的推论，不是自由参数。γ=1（w∝SNR）与等权的相对效率为 >1 的纯几何量（2 dex 动态范围下 3.73 与 104.58，路线3 MC 复现解析值）。

**负例判据**：全部 v_k 相等时各正权方案 Var[μ̂_w] 恒等——方案差度量必须精确归零（路线1/3 实测 0.005 与精确 0）。

## §2 平面条件数判据 λlo/λhi ≥ 1/16

控制点云 {p_i}（去均值）的 2×2 散布矩阵 M = Σ(p_i−p̄)(p_i−p̄)ᵀ。沿单位向量 u 的梯度估计方差 ∝ uᵀM⁻¹u，最坏方向 = 最小特征值方向，放大因子 κ = √(λhi/λlo)。κ 即点云长短轴比：把各向同性点云沿主轴压缩 s 倍，λhi/λlo = 1/s²，κ = 1/s = 轴比（路线1 实测偏差 ≤0.03%）。阈值 λlo/λhi ≥ 1/16 ⇔ κ ≤ 4 ⇔ 最坏方向 SE 放大 ≤4×：**保守良态守卫（fail-closed 门），非锐利物理边界**。实测放大 1.007/2.025/3.956/7.980（理论 1/2/4/8）；注意必须沿 M 的特征向量方向测量，沿坐标轴会严重低估（路线2 初版教训）。

## §3 收敛阶

光滑场 f ∈ C⁴、节点距 h：自然三次样条内部误差 O(h⁴)；双线性 O(h²)。路线3 实测：双线性内部阶 −1.93/−1.98（理论 −2）、样条 −3.97/−4.18（理论 −4）。自然边界条件 S″=0 在端点层与真值曲率不符 → 端点层阶退化（−3.88/−4.13）且绝对误差增大——规范相关的真实性质，非实现缺陷。Keys 1981 的 4 抽头三次卷积核属另一族插值核，其通行截断误差阶为 O(h²)，**与样条不同阶**，只作算子形式与方法学参照 [文献:refs.md 条目4]；本节两条阶数一律由路线3 实测与样条理论承担，不由该引用背书。

**Δ² 偏置律**：对曲率 q 的场（f ≈ q·x²/2），cell 中心采样 + 线性/样条重建的确定性偏置 ∝ q·Δ²/8：零噪偏置比 Δ₂/Δ₁ → (Δ₂/Δ₁)²。实测 128/64 = 4.06（理论 4）、256/16 = 280（理论 256）。Δ 不进入物理模型，其后果是确定性插值误差、由 Δ/ℓ 与曲率承载（route2/exp_P4R2_03）。

## §4 IDW 极限行为与 γ 门

IDW 权 w_i = d_i^(−p) / Σ_j d_j^(−p)（K 近邻）。p→∞ 时全部权重收缩到最近点——退化为最近邻算子（实测偏差序列 0.302 → 3.3e-3 → 5.5e-9 → 0，p = 30/100/300/1000，对数归一化防溢出）。p 小 → 权趋平（K 点均值，邻域平均压噪）；p 大 → 权趋尖（插值保真，放大控制点噪声）。含噪控制点下最优 p 由“偏差-方差”权衡决定：噪 0% 时 p=2 最优、2–6% 时 p≈0.5–1（route2/exp_P4R2_02 全扫）。γ 门：d < γ 时以 1/γ^p 替代 1/d^p 防 0^p 上溢；γ ≪ d_min 时 w 逐位不变（γ=1e-10 vs 1e-6 偏差 8.3e-10），γ ~ d^p 才实质改算子（γ=1e4 偏差 0.635）——数值守卫，非科学量。

## §5 白性恒等式 −1/2

白噪声 x_i（Var σ²，互不相关）。一阶差分 Δ_i = x_{i+1} − x_i：Cov(Δ_i, Δ_{i+1}) = Cov(x_{i+1}−x_i, x_{i+2}−x_{i+1}) = −σ²，Var(Δ) = 2σ² ⇒ lag-1 自相关 = −1/2（精确解析恒等式）。实测 −0.5007/−0.4995/−0.4984（高斯/量化/泊松）与 −0.49963 ± 0.00078（route3/exp06）。用途：判“噪声实现空间白”是**实现**的性质；方差图相对散布跟随电平场（σ²∝S ⇒ 比 1；σ²∝S² ⇒ 比 2）是**场**的性质——两者二分，P4 重建的稠密 σ 场只能承载后者。

## §6 Moffat4 FWHM/σ 闭式（两个 σ 约定，禁止混用）

Moffat I(r) ∝ (1+r²/α²)^(−β)，β=4：
- 半高：`(1+r²/α²)^(−4) = 1/2 ⇒ r_half = α·√(2^{1/4}−1)`；`FWHM = 2α·√(2^{1/4}−1) = 0.8699589·α`
  （一手出处：Trujillo, Aguerri, Cepa & Gutiérrez 2001, MNRAS 328, 977, Eq.(1)，arXiv:astro-ph/0109067；
  Moffat 1969 原文只给 (R, b) 两参数、无 σ/无 FWHM；photutils/astropy/GalSim 同式）。
- 二阶矩（可复算；未检索到一手文献逐字写出）：`∫rI dr = α²/6`、`∫r³I dr = α⁴/12`
  ⇒ `⟨r²⟩ = ∫r³I/∫rI = α²/2`（β>2 收敛）。

**σ 约定（生产唯一口径 = 模型参数口径，= PSF.md §16）**：
`Q = 0.5·r²/σ² = r²/α² ⇒ 2σ² = α² ⇒ σ² = ⟨r²⟩ = α²/2 ⇒ σ = √⟨r²⟩ = α/√2 = 0.7071068·α`
⇒ `FWHM/σ = 2√2·√(2^{1/4}−1) = 1.2303076525901024`；数值径向积分 **1.2303077**
（route2 exp09 订正版）；登记值 1.230310（相对差 **1.91e-6**，即该常数六位小数圆整量）。

**他域口径（同二阶矩高斯逐轴；生产禁用）**：`σ_g² = ⟨r²⟩/2 = α²/4 ⇒ σ_g = α/2`
⇒ `FWHM/σ_g = 4·√(2^{1/4}−1) = 1.7399178387`。两口径**恒差 √2**；生产参数化
`(1+r²/(2σ²))^{−4}` 只在 σ 口径下自洽（σ=FWHM/1.230310 时剖面在 r=FWHM/2 处 = 0.5，
残差 1.2e-6；代入 1.7399178 得 0.2770、反解 FWHM 短 29.3% ⇒ 判红）。

**订正注记（P4-B01 独立复核）**：本节旧版写「2D rms 半径口径 σ² = ⟨r²⟩/2 = α²/2」，
该等式链自相矛盾（⟨r²⟩/2 = α²/4），源于把两个约定的 σ 混写；1.2303077 只在
`σ = √⟨r²⟩`（= 模型参数口径）下成立，`σ² = ⟨r²⟩/2` 口径对应 1.7399178。证据：
`run/FINAL-07/审核包/科研审查/P4_订正/evidence/V1_moffat4_E_convention.out`。

常数随轮廓族与 σ 口径双重变化（判据非退化）：高斯轮廓同口径
`FWHM/σ = 2√(2 ln2)/√2 = 1.6651092223`（逐轴口径 2.3548200450，IRAF implot.hlp:148）。

## §7 效率判据 E 的唯一口径（P4-B02 定案）

**定义（本单元唯一权威口径，记 `E_eff`）**：某像素的真 SNR 为 S、重建估计为 Ŝ，帧参考通量 F_ref，则

```
v_k = σ_true,k² = (F_ref/S_k)²            真方差
w_k = (Ŝ_k/F_ref)² = 1/σ̂_k²               重建逆方差
Var_w   = Σ w_k² v_k / (Σ w_k)²           该权重下加权均值的方差
Var_opt = 1 / Σ (1/v_k)                   同批像素的逆方差可达下界
E_eff   = Var_w / Var_opt − 1
```

**为何唯一（两条依据，缺一不可）**

1. **定义域**：E 被用作「效率损失」⇒ 必须 ≥ 0。由 `(Σw)² = (Σ w√v·1/√v)² ≤ (Σw²v)(Σ1/v)`
   （Cauchy–Schwarz）得 `E_eff ≥ 0`，这是定理而非经验；且 `E_eff = 0 ⟺ w ∝ 1/v`（权形状正确）。
2. **不变性**：`w → λw` 不改变加权均值，Var_w 与 Var_opt 同步 ⇒ `E_eff` 对 σ̂ 的乘性缩放
   **严格免疫**（探针实测偏差 ≤1.3e-14）。⇒ 乘性偏差是判据的**已知盲区**，E 必须与 dex
   水平判据成对使用（论文 §4.6）。

**成立前提（缺一即降级为形状判据）**：以上两条依据都建立在**同批像素噪声互不相关**
（`Σ = diag(v)`）之上。

- `Var_opt = 1/Σ(1/v)` 是**逆方差可达下界**，只在独立噪声下成立。噪声相关时真正可达的
  最小方差是 `1/(1ᵀΣ⁻¹1) > Var_opt`：以 256 像元、拖尾指数型相关（`Σ_ij = √(v_i v_j)·ρ^{|i−j|/3}`）
  盲复算，GLS 可达方差 / `Var_opt` = 1.00（ρ=0）、1.31（ρ=0.1）、1.67（ρ=0.3）、1.72（ρ=0.6）。
  ⇒ 相关噪声下 `E_eff = 0` 只保证**权形状正确**，**不保证已达最优**；E 的绝对数值不再是
  真实效率损失。本单元对相关体制（真实 drz 噪声已相关化）的读数一律只作**相对序**，
  绝对效率外推由「不可用」登记（见 `REPORT_experiment.md` §4.1 的判据取舍表 E4）。
- `Var_w = Σw²v/(Σw)²` 同式只对**独立**像素成立；生产 P2b 方差面
  （`phase2_integrate/variance_propagation.h` 的 `Var(corrected) = Σ_j(δ_ij−H_ij)²σ_j²`）
  同样以 `Σ = diag(σ²)` 为前提。

**被否口径（登记为无效定义，只作负例锁定）**：`E_prop = Var_w/(1/Σw) − 1 = Σw²v/Σw − 1`。
Σw 不是可达下界（Cauchy–Schwarz 不适用）⇒ `E_prop` 可判负——纯乘性缩放 `σ̂ = 3.17·σ_true`
时 `E_prop = −0.9004866`（实测），且对 `w → λw` 不同步（同数据偏差达 O(10)）⇒ 无「损失」语义。

**机器核对（本单元 19 个脚本逐行抽取 var_opt 定义行）**：8 个脚本显式写 `Var_opt = 1/Σ(1/σ_true²)`，
**0 个**用 `1/Σw`；审查基线 e7407f7e 与现行工作树逐行一致。核查脚本与输出：
`run/FINAL-07/审核包/科研审查/P4_订正/evidence/F2_metric_E_caliber.py`（同名 .out 落 `run/FINAL-07/logs/`）。

**两口径不可互比**：同一异质场上二者无固定比例（自建同构场实测双线性臂 E_eff = +0.0244 而
E_prop = −0.1055，符号相反；`w=1/v^p` 扫描下比值从 −0.5 到 +305 连续变化）——任何「两定义
差 k 倍」的陈述都不是普适关系，只能逐场复算。
