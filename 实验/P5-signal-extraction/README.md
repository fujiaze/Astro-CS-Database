# P5 信号提取：共模增强与差模抑制

本单元回答负责人提出的问题：**真实的公共信号怎么提取出来**。前提是每帧的信号部分已被归一到同一强度，
剩下的帧间差异是加性天光与系统误差。

本单元把 **43 帧真实 M42 实拍单帧产物**（`run/PHOT-FIX/p1_rerun/{t2,t3}/`，`cleaned_*` 与
`photoapplied_*` 两臂）按其 WCS 直接投到**生产成品的同一网格**（`output_phase3.fits`，
6208×4352、1.8″/px，见 `docs/10_PRODUCTION_GRID.md`），然后：

1. 在**帧间差分**上拟合逐帧「偏移 + 平面 + 粗格场」（路径 A 差模对齐），只扣逐帧项、不动公共分量；
2. 用接缝判据（覆盖边界上的有符号台阶 ÷ 局部背景，逐边改善/恶化计数）与结构保留度判定；
3. 与生产成品在同一批边上复算的读数对照。

**当前有效结论以 §13.1 生产网格重做版（第三轮）为准**（`docs/10_PRODUCTION_GRID.md` + `docs/11_FINDINGS.md`）：
网格逐项对齐生产成品 `output_phase3.fits`，43 帧真实 M42 实拍帧直接投到该网格上，不自建网格。

| 口径 | 接缝中位（相对台阶） | 逐边改善占比 |
|---|---|---|
| raw（原生计数臂） | 0.1195 | — |
| 路径 A 差模对齐 | **0.0544** | 67.1% |
| raw（P1 已归一臂） | 0.2240 | — |
| 路径 A 差模对齐 | **0.0965** | 68.2% |
| 生产成品（同一批边上复算） | **0.0101** | — |

**路径 A 在生产网格上仍然有效**（接缝中位 −54%/−57%，逐帧系统电平从 ±40% 收到 ±13%，结构电平保留
0.96–0.99、噪声下降约 12%），**但达不到生产成品的水平**（差约 5 倍），且 p95 变差。

此前在自建网格上做的四路径读数（差模对齐 / 接缝驱动 LSQ / 天光样点拟合 / 权重设计）与成品已判不合格，
移入 `results/rejected/`。
