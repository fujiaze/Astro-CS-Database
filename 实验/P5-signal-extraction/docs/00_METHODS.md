# 信号提取路径的原理与判据

被测对象是创新点五的加性天光模型：每帧的信号部分已在单帧标准化里归一到同一强度上，剩下的帧间差异是
**加性天光与系统误差**。要回答的是「真实的公共信号怎么提取出来」——即怎样把帧间差异扣掉，而**不动公共信号**。

## 1 口径与不变量

联合模型在产物自己的并集网格上（40 个 order-12 HiPS 瓦片、每瓦片 512²、叶像素 nside 2²¹、
0.1007″/px，含 10 485 760 个像素）给出逐帧修正

```text
corrected_k(p) = raw_k(p) − δ_k(p)，   δ_k = δ_poly,k + F_k
raw_k(p) = corrected_k(p) + δ_k(p)                          （由产物反解，δ_poly 取联合解的低阶项、F_k 取逐帧格点场）
```

一切路径都从 `raw_k` 出发，修正只作用在**逐帧项**上。守住的不变量是：**公共面与覆盖集无关**
（科学正本把「公共面」「残差场跨帧公共模」「逐位置公共模」三词分列，其中只有前两者是生产口径；
`Σ_k w_k δ_k ≡ 0` 的逐位置口径是被否决的构造——它让修正退化为恒等操作）。本单元因此对每条路径都检查
「修正是否真的改变了叠加结果」，并禁止用覆盖相关的堆栈去定义公共分量。

判据三条，都定义在并集网格上、不插值：

| 判据 | 定义 | 为什么用它 |
|---|---|---|
| 接缝 | 瓦片内 4 邻接对 (p,q)，两侧**都有数据**且**覆盖帧集不同**；有符号台阶 `Δ = stack(p) − stack(q)`，相对读数 `Δ / bg`（bg = 该边中点的 33×33 局部背景中位数） | 与科学正本「帧足迹边界两侧的电平有符号台阶 ÷ 局部背景电平」一致；只计两侧都在数据内部的帧边界，足迹外缘不计入 |
| 逐边界结算 | 按「离开/进入的帧」归并同一批边，给逐帧的**有符号平均相对台阶**（边内平均把噪声压掉）与标准误；另给逐边改善/恶化计数 | 逐帧系统电平差是接缝的物理量；均值+标准误能把 0.5% 的确定性偏移与 2% 的噪声分开 |
| 帧间一致性 | 覆盖 ≥2 的像素上 `s(p) = sqrt(Σ_k w_k (x_k − μ_p)² / Σ_k w_k)` 的中位数 | 直接问「同一位置的帧间是否真的对齐」，与接缝互为独立证据 |
| 结构保留 | 结构掩膜由**未校正堆栈**冻结（`> p99.9` 膨胀 2 px）；电平保留 `L = median(stack_path/stack_raw)`；起伏保留 `B = rms(带通 81 px 中值以上)/同量`；另报非结构区高通噪声 | 「信号提取」不能以抹掉结构为代价 |

## 2 路径 A：差模对齐（共模增强的可行形式）

**原理。** 公共信号在同一位置跨帧**相干**，天光是**逐帧**的。把逐帧加性项 `m_k(p)`（偏移 + 平面 +
粗格场）只用**帧间差分**拟合：在任意两帧的重叠区上，公共信号在 `raw_k − raw_l` 里精确消掉，剩下的是
`m_k − m_l` 加噪声。先解 12 个低阶参数（逐帧偏移与平面），再在 64 px 粗格上按对帧残差的中位数做
若干轮 Jacobi 平均（每轮后逐格扣掉跨帧加权均值，保证格点场只含**差模**）。

**公式。**

```text
目标： min_{m} Σ_{k<l} Σ_{p∈Ω_kl} [ (raw_k(p) − raw_l(p)) − (m_k(p) − m_l(p)) ]²
规范： Σ_k w_k m_k ≡ 0（逐格）；公共分量落在零空间，永不被减
施加： corrected_k = raw_k − m_k
```

**判据。** 接缝（逐帧系统电平、逐边改善计数）、帧间一致性、结构保留三条同时看；A 的修正不得含公共分量。

## 3 路径 B：接缝驱动的最小二乘

**原理。** 干脆把「覆盖边界台阶」当目标函数：参数化逐帧加性修正，直接让边界台阶最小。因为叠加是线性的，
边界台阶对参数是**线性**的，可以一次性解出。公共分量按构造落在零空间（对每个基函数列施加 `Σ_k θ_k = 0`），
所以它不可能吸收公共信号。

**公式。** 取逐帧逐格常数基（格边长 64 px；一像素宽的边界只约束「阶」不约束「斜率」，故不用平面基）：

```text
stack(p) = S_raw(p) − g(p)·Θ(p)，  Θ(p) = Σ_k w_k(p) θ_k / Σ_k w_k(p)
step_e   = d_e − Σ_k [ (w_k(p)/W_p) θ_{k,c_p} − (w_k(q)/W_q) θ_{k,c_q} ]，  d_e = S_raw(p) − S_raw(q)
解：  min_θ ‖A θ − d‖² + λ‖L θ‖² + damp‖θ‖²     （L 为同瓦片内 4 邻格 Laplacian）
```

**判据。** 与 A 同一套，但重点看**代价**：接缝是唯一目标函数时，帧间一致性与结构保留会不会被牺牲。

## 4 路径 C：天光样点上的结构保护拟合

**原理。** 只用天光控制点（3 624 个稀疏样点）拟合逐帧低阶面，样点先过结构筛（落在结构掩膜内的剔掉），
结构保护完全由筛子承担——这是科学正本里「掩掉源与高结构区再拟天光面」这类做法的直接实现。

**公式。** 逐帧 `value_i ≈ a_k + b_k·u_i + c_k·v_i`，Huber IRLS（δ = 1.345）加权 `control_ivar`；
规范取逐帧常数的覆盖加权均值为零。施加同上。

**判据。** 除了三条判据，另报被筛掉的样点数与拟合残差——它检验「稀疏天光样点能不能支撑信号提取」。

## 5 路径 D：权重设计（隔离「权重引发台阶」）

**原理。** 修正沿用生产 δ（即直接用 `corrected`），只改叠加权重：逐像素逆方差、逐帧常数权重
（覆盖无关）、逆方差截顶到 p90、权重 9×9 平滑。若接缝部分来自「权重在覆盖边界跳变」，改权重应能改善。

**判据。** 同一批边上的接缝读数；若三条判据都变差，说明权重不是接缝的杠杆。

## 6 接缝成因归因

三条互相独立的证据，用来回答「接缝是掩膜不一致、乘性残差、还是加性天光」：

```text
① 加性天光量级： raw 堆栈的边界台阶 vs 生产校正后的边界台阶 ⇒ 加性模型消掉了多少
② 乘性残差： 在**已校正**帧上做稳健直线拟合 corrected_l = s·corrected_k + c，报 s−1（乘性残差）
             与 c/level（加性残差）——若加性天光已被扣干净，两帧应满足 s=1, c=0
③ 掩膜一致性： 同一批帧在「星掩膜开 / 关」两个产物上的逐帧合法掩膜差异、覆盖差异与接缝读数
```
