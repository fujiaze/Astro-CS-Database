# 乘性残留：归属（P1）与 P5 的鲁棒性职责

## 1 设计依据（实读）

| 出处 | 原文要点 |
|---|---|
| `docs/ACSD_DESIGN.md` §2.1 第 99–100 行 | `I_photo = k_photo · m(x,y) · I_cal`；`k_photo` 是**帧级线性标度**，`m(x,y)` 是**低阶乘性空间增益场**，阶数由配置请求、缺省恒等，**数据不足以约束时降阶并写明原因** |
| `docs/ACSD_DESIGN.md` §2.5 第 140 行 | 「**乘性空间响应归 normalize 处理，mosaic 只做加性校正**」 |
| `docs/science/sky/UPM.md` 第 9 行 | 非目标：「**不处理乘性尺度差（本期口径为纯加性）**」 |
| `docs/science/sky/UPM.md` 第 64 行 | 「**乘性残留归单帧校准处理**」 |
| `docs/science/photometry/PHOTOMETRY.md` 第 15 行 | 空间乘性场 `m(x,y)` 是正路；`m≡1` 只允许两种退化：**可辨识性不足**（星数少于阶数所需、秩亏、`kappa` 超限）或**样本几何不足**（星点强烈中心聚集）；「**星点铺开块数不足不构成退化理由**」 |

⇒ 归属明确：**乘性项归 P1（归一化阶段）**，其载体是 `k_photo`（帧级标量）+ `m(x,y)`（低阶空间场）；
**P5 设计上只做加性校正**，对乘性残留的职责是**鲁棒**，不是吸收。本单元据此把上一轮"路线①（天光拟合侧吸收）"作废。

## 3 ①`s−1` 是不是 `k_photo` 的帧级标度误差

**判定：不是主导项。** 证据两条：

1. **量级可比但方向不符**：`k_photo` 的帧级离散（剔除粗大离群后 max/min = 1.70，即约 ±20%）与
   观测到的逐帧边界系统电平量级相当（cleaned 臂 −0.194…+0.491、photoapplied 臂 −0.181…+0.364），
   所以"标度误差可以贡献这一量级"是成立的；
2. **但把 `k_photo·m(x,y)` 施加之后，边界系统电平几乎没变**：`photoapplied` 臂（P1 已施加，
   `n_spatial_applied=16/16`、`photometry_applied=true`）的逐帧边界系统电平范围 **−0.181…+0.364**，
   与 `cleaned` 臂（未施加）的 **−0.194…+0.491** 基本同量级、接缝中位也从 0.01837 只变到 0.01968。
   若残余主要来自 `k_photo` 的帧级误差，施加后应显著缩小——**没有**。
   ⇒ 残余的主载体是**空间变化**的量（§2 的 `m` 场幅度 7%–37% 与观测范围同量级），
   而不是帧级标量。

**未给出的一张表**：逐帧、逐半径带的 `s_k ± se`。原因：上一轮用粗格均值的比值估计量已被证明被
「格内结构采样差异 + 共格集合随帧对变化」污染（`docs/17_MULTIPLICATIVE.md` §1），
本轮的 `g_k`（0.009…38.7）无效、不得引用。正确估计量必须是**像素级、局地差分**的：
在两帧共有的同一批天球像素上，取同一帧内邻近像素对的差分（加性偏置与平滑面在局地差分里消掉），
再做 `s_ij = Σ Δx_i Δx_j / Σ (Δx_j)²`。这一步需要逐帧像素级重跑（约 6 分钟/臂），**本轮未做**。

## 4 ③ P1 侧"阶数是否足够"的证据（本轮唯一可执行的 P1 改进项）

- **不足的证据**：场后空间残差 0.012–0.027 dex（3%–6%）是噪声底（0.0012–0.0052 dex）的
  **4.7–9.9 倍**。按设计口径，阶数充足的判据应是残差落到噪声底量级；现状差一个量级。
  保留项：该残差里含有**逐星散度**（非纯空间结构）成分，故"4.7–9.9 倍"是空间结构未拟合量的**上界**，
  下界需按星点分块残差再做分离——本轮未做。
- **不属于允许的两种退化**：49 帧全部 `degraded_reason` 为空、`identifiable=1`、`kappa` 1.42–2.52、
  星数 431–972 ⇒ 既不是可辨识性不足，也不是样本几何不足，**降阶理由不成立**（与 §1 末行的规定一致）。
- **建议改动**（未实施，属 P1 管线）：把 `m(x,y)` 升阶（order 2 → 3/4）或在 `m` 中加入
  **电平相关项**，再核 `场后残差/噪声底` 是否落到 ~1；若升阶后 `kappa` 超限或残差不再下降，
  则按设计登记降阶理由。
- **未做的读数**：`s_k` 前后、逐帧标度一致性、P1 自身判据（星等残差散度两口径）。
  原因：需要改 P1 的标度拟合并重跑 `normalize`，本单元为只读消费方。

## 5 ④ P5 侧：鲁棒性（实测的失效 + 未测的敏感度曲线）

**已有实测证据（P5 现有方案不鲁棒）**：在 `photoapplied` 臂（P1 已把帧间电平归一，
该臂帧中位 spread 相对仅 ~1e-3）上，现有「加性差模对齐」的逐帧系统电平**发散**：
frame1 −0.6274、frame4 +0.5975、frame5 +0.5758，而 raw 只有 +0.003…+0.12。
即：**当加性差模信号被上游压到很小时，现有无约束的逐帧粗格场会把修正堆到个别帧上**
（1.05e6 个自由度对几乎为零的信号），接缝中位同时"变好"（0.0197→0.0059）却与帧间电平的恶化并存
⇒ 池化中位不能单独作判据。`cleaned` 臂有界化后未见此失效（见 `docs/16_ROUND3.md`）。

**未做的敏感度曲线（派单要的 B-1）**：按实测量级注入 5%/10%/20% 的逐帧标度误差，
测接缝与结构保留的退化曲线，报"在多大残留下仍满足判据"。原因：注入必须在**逐帧像素级**做，
需要重跑逐帧投影与累积（约 6 分钟/臂）并另写注入开关，本轮预算内未完成。**不给未做的读数。**

**建议的鲁棒化措施（未测，按现有失效证据排序）**：
1. **对逐帧项加幅度上界**（以帧级天光/电平量级为限，本轮 `cleaned` 臂已验证 cap 有效：
   6.1% 格值被裁、格场 RMS 降到天光的 24%）；
2. **差分用稳健统计**（中位数/截尾均值替代最小二乘，避免少数亮结构主导解）；
3. **判据改为逐边计数为主、池化中位为辅**（本轮已证：池化中位可在帧间电平发散时"变好"）；
4. **先判"是否还需加性修正"**：把帧间差分幅度与噪声界比较，差模不显著时**输出零修正**
   （对已被上游归一的数据，这本身就是正确行为）；
5. 规范显式钉零（修掉 `docs/16_ROUND3.md` 记录的 +1811 ADU 常数自由度）。
**这五条都不改 P5 的设计口径**：P5 仍只做加性校正，不引入乘性修正。

## 6 ④ 哪条有效 / 无效

| 项 | 判定与依据 |
|---|---|
| 乘性项归属 P1（`k_photo` + `m(x,y)`）、P5 只做加性 | **有效**（设计原文 + 产物读数一致） |
| `s−1`「就是 `k_photo` 帧级标度误差」 | **不成立**（施加 `k_photo·m` 前后边界系统电平与接缝基本不变） |
| P1 的 `m(x,y)` 阶数足够 | **不成立**（场后残差是噪声底的 4.7–9.9 倍；且不属两种允许退化）⇒ 建议升阶或加电平相关项 |
| 逐帧逐带 `s_k ± se` | **未给出**（粗格估计量已证无效；像素级局地差分估计量未跑） |
| P5 现有加性方案对乘性残留鲁棒 | **不鲁棒**（photoapplied 臂逐帧系统电平发散到 ±0.63） |
| P5 敏感度曲线、鲁棒化前后读数 | **未测**（需逐帧像素级重跑；措施已按失效证据排序列出） |
