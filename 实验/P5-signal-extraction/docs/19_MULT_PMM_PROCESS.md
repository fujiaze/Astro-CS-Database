## 1 方案（已获批准）

```text
raw_k(p) = g_k(p)·[ S(p) + a_k(p) ] + n
① 加性 a_k：偏移+平面+粗格场，只由帧间差分拟合；规范 Σ_k w_k a_k ≡ 0（公共模不动）
② 乘性 g_k = 1 + m_k：从重叠样本对（规则分格 + 中位对 + 零像素剔除 + 通量窗 + 垂距剔点）解；
   规范 Σ_k w_k log10 g_k ≡ 0（公共增益按构造为 1）
   幅度上界 |log10 g_k| ≤ 3·σ_resid,k（σ 取该帧 p1_phot.json 的 sigma_spatial_residual_dex），超界截断并登记
   不显著则输出 g ≡ 1 并写明"P5 侧无需乘性修正"
③ 施加 corrected = (raw − a)/g；交替 2–3 轮（g≡1 起 → 解 a → 解 m_k 截断 → 回代重解 a）
④ 红线：报 max|S_g|/RMS(S_g)，≤1e-12 判退化为恒等、判决失败
⑤ 不引 PMM 曲面样条（PJSR 内建不可复现 + 许可禁改禁分发），用本单元粗格场 + 低阶面
```

## 4 #4 的自相矛盾（本轮最重要的待办）

同一份数据上两次诊断结论相反，**未能在本轮定位**：

- **批量诊断**（上面 #4）对 711 对全部给出斜率 ≈ 0（`cleaned` 对称绕 0、`photoapplied` 恰为 0）；
- **单对直接检查**（同一份 `stage1_cleaned_cellsum.npy`/`cellw.npy`，帧 0 与帧 1，共有格 4900）：
  `cm0` 中位 199.504、标准差 141.331，`cm1` 中位 164.605、标准差 148.301；
  前 5 个共有格 `cm0 = [172.910, 172.190, 170.946, 171.985, 171.913]`、
  `cm1 = [136.240, 138.903, 137.750, 138.156, 139.233]` ⇒ 比值 ≈0.79，**明显相关**，
  自由截距斜率应在 0.79 附近，而不是 0。
  ⇒ 数据本身健康，**故障在 #4 的批量拟合/掩膜循环里**（尚未定位；`photoapplied` 出现"恰为 0"这一
  非物理值，指向该循环对某一臂的掩膜或取值有缺陷）。

**结论：本轮不给出 `s_k`/`g_k` 数值，红线检查值 `max|S_g|/RMS(S_g)` 亦未产出**（无有效解可算）。
下一轮第一件事是定位该循环缺陷（最小可复核入口：单对 vs 批量在同一掩膜上比对）。
