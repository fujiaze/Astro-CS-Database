# 乘性残留：诊断尝试、可得结论与两条路线的设计（未测部分如实标注）

## 1 诊断尝试与其失败模式（如实登记）

**做法**：从已保存的逐帧粗格均值（57.6″ 格，43 帧 × 24 321 格）出发，按 6 个半径带先**带内去均值**
（去掉加性偏置），再解零截距稳健比值 `s_ij = Σx_i x_j / Σx_j²`，最后按 `log s_ij = log g_i − log g_j`
（规范 `Σ_i log g_i = 0`，按 `1/se²` 加权）解逐帧、逐带增益 `g_k`。

**结果（无效）**：`g_k` 中位 1.000 但范围 **0.009…38.7**，带间极差中位 **15.3**，se 中位 3.6e+01。
这不是增益，是噪声。

**失败原因（可复核）**：
1. **格内结构采样差异**：格边长 57.6″，而各帧的抖动落点不同 ⇒ 同一格里两帧覆盖的**子区域不同**；
   在 M42 星云这种强梯度上，格均值的差异远大于增益效应，估计量被结构梯度污染。
2. **共格集合随帧对变化**：一对帧能共用的格是两者足迹的交，交集不同 ⇒ 去均值后的方差比不再只含增益。
3. 星云强梯度使该比值估计量重尾，`se` 巨大而解出的 `g` 只反映少数亮格。

**结论：本轮的 `s_k` 不可用，不得引用**（`results/p5w/p5m_multiplicative_diag.json` 仅留档）。
正确估计量应是**像素级、局地差分**的比值：在两帧共有的**同一批天球像素**上，取同一帧内**邻近像素对**
的差分（加性偏置在局地差分里消掉、公共天光与平滑面也消掉），再做 `s_ij = Σ Δx_i Δx_j / Σ (Δx_j)²`；
抖动观测正是为了让同一片天落在**不同的帧像素**上，这才是增益信息的来源。这需要逐帧像素级重跑
（约 6 分钟/臂），本轮预算内未做。

## 2 现有证据支持的结论（分层定性）

已有读数（`docs/16_ROUND3.md`，掩码已修）可以回答「主导层不是哪一层」，依据如下：

| 证据 | cleaned 臂（P1 归一**前**） | photoapplied 臂（P1 归一**后**） |
|---|---|---|
| 逐帧**全球**中位电平 spread | 204.6 ADU（相对天光 218 ADU ⇒ **94%**） | 1.74e-14（相对 ~1e-3，即 **0.1%**） |
| 逐帧**边界**系统电平范围（同一批边、有符号平均） | −0.194 … +0.491 | −0.181 … +0.364 |
| 接缝相对台阶中位 | 0.01837 | 0.01968 |

**结论**：P1 的归一化把**全球标量**电平差压掉了 **~940 倍**（94% → 0.1%），但**逐帧边界系统电平**
在归一前后几乎不变（±0.19…+0.49 对 ±0.18…+0.36），接缝中位也基本不变（1.84% 对 1.97%）。
⇒

- **主导层不是 P1 的逐帧标量归一**：它已经做到了它该做的（全球电平 0.1%），而残余差**不随它改变**；
- 残余差是**空间变化**的（同一帧在不同边界上的系统电平从 −19% 到 +49%），且**与电平标量无关**
  （归一前后同量级）⇒ 与「平场残差」和「天光扣除后的电平相关残差」这两类**场型**乘性项更相符；
- **仓内目前无法把这两者分开**：需要 §1 末尾的像素级局地差分估计量，或把逐帧平场的径向剖面
  （本轮未取到该帧平场读数）与解出的 `g_k(半径)` 对照。**占比数字本轮给不出来，不编。**

## 3 路线 ②（P5 侧吸收乘性残留）：设计已定，未测

按派单口径，把差模对齐从「只有加性项」扩为「加性 + 乘性联合」：

```text
模型： raw_k(p) = g_k(x_p, y_p) · [ S(p) + a_k(p) ] + n
      g_k = 1 + m_k，m_k 建在 48–64 px 粗格上（差分模式，Σ_k w_k m_k ≡ 0，公共增益按构造不动）
求解： 以 log 域线性化： log raw_k − log(Ŝ + â_k) ≈ m_k
      与加性项 a_k（偏移 + 平面 + 粗格场）**同时**解；初值取现有加性解，交替 2–3 轮
施加： corrected_k(p) = (raw_k(p) − a_k(p)) / g_k(p)      ← 只扣差模
规范： 加性项再显式钉一次「加权均值置零」（修掉上一轮 +1811 ADU 的常数自由度）
```

**为什么未测**：`g_k` 与 `m_k` 的求解与施加都必须在**像素级**做（格均值已被证明不可用，见 §1），
需要重跑逐帧投影与累积（约 6 分钟/臂），本轮预算内无法完成。**不给未做的读数。**

## 4 路线 ①（天光拟合侧吸收）：属于哪一条，怎么改

已读该侧正本（本会话已通读 `docs/science/sky/UPM.md` 与 `docs/science/algorithms/mosaic/` 的
`PHASE2_UPM_IMPL.md`、`UPM_SOLVER.md`）：天光模型现为**纯加性** `value = B_ref(p) + δ_poly,k(p) + F_k(p)`，
而**乘性差异被该侧的显式非目标排除**（正本写明乘性标度差异由单帧标准化 `normalize` 负责，本周期不处理）。

因此路线 ① 的落点很明确：**改「天光模型」这一条**——把逐帧天光模型从
`sky_k(x,y) = a_k(x,y)` 扩为含**自缩放项**的形式

```text
sky_k(x,y) = a_k(x,y) + b_k(x,y) · L_k          L_k = 该帧自身电平/天光量级（帧级标量，取自控制点或产品读数）
或等价地：  value = B_ref(p)·(1 + c_k(p)) + δ_poly,k(p) + F_k(p)   （c_k 为乘性场，与 F_k 同格点族）
```

它与现有 `F_k` 共用格点族与规范（逐格跨帧加权均值为零），不新增自由规范；
归零/判红对照臂仍可沿用（`L_k` 置零 ⇒ 退回纯加性）。**该侧属于「天光拟合」创新点的模型口径**，
改动会影响其下游（P5 的 δ_k 与逐帧残差场）⇒ 需同步改生产者/消费者声明。

**未测原因**：该侧的联合解在 `mosaic` 的生产管线里，本单元只读产物、不重跑 `mosaic`；
仓内 M42 腿也没有可用的天光样点产物（`p2_samples.json` 只在另一天区的 `LAMBDA-ROLLBACK` 里）。
故只给设计，不给读数。

## 6 下一轮的最小可执行步骤（按序，给得出数字）

1. 逐帧投影时**同时**累积局地差分统计（同一帧内相邻像素对的差分乘积），解 `s_ij`（像素级）→
   逐帧、逐半径带 `s_k ± se`（这是本轮缺的那张表）；
2. 用同一套累积做加性+乘性**联合**解（§3 并联），施加后重测六项读数：`s_k` 前后、接缝逐边计数、
   p95、结构保留 L、噪声、绝对电平；
3. 取该帧平场的径向剖面（`master_refs.json` / 平场产物）与 `g_k(半径)` 对照，判定平场残差占比；
4. 路线 ① 在生产 `mosaic` 侧另开实验单元重跑联合解，判据同 P5 侧。
