## 摘要

测光校准之后，同一片天区的真实信号在帧间连续；叠加产品上残余的条带状接缝只能来自两处：被当成可加量处理掉的乘性帧间差，以及加性天光面在覆盖子集突变处的不连续。本文在统一测光模型（UPM）框架下给出加性天光去除与无接缝叠加的完整判据体系，并以三条独立实验路线与两个补充实验对其逐项检验。核心结论有四。其一，在参考面可表示域内，「逐帧梯度 δ_k 扣除＋公共背景 B_ref 保留」的施加语义把覆盖子集突变处的背景接缝中位从 4.80 e⁻ 压至 0.383 e⁻（12.5×）[实验:c1_additive.py]，而「全减背景」退化做法必须禁止——它在度量上看起来更好，实则把背景减掉并产生 48.4% 的负值像素 [实验:c1_additive.py]。其二，稀疏控制点定权公式 Var = k_corr·(π/2)·σ_bg²/N_retained 在 N≥65 域内成立（MC 偏差 <2%）[实验:route1/c1_median_variance.py]；N=5 处渐近式对中位数方差为高估 ≈9.5%（偏差保守），端到端口径 ≤±1.5%，生产链亮端裁剪臂低估 1.3–3.2%——原「N=5 低估 8.5%」方向词错误，按分歧台账 D-07 订正；k_corr 改为 k_shape×k_geo 两因子公式＋几何查表（查表由 P3 单元承载），冻结常数 1.4 在其声明域两端低估定权 32% 至约 2 倍（D-08）。其三，无接缝交付判据 max|rel_step| ≤ 1e-2 具有确定性下限 1.0050% [推导]（[实验:route1/c3_seam_gate.py] 闭合），其统计行为、多重性检出与两个结构性漏检面全部量化；判据面上仅存的两级锚是本接缝门与 Huber δ=1.345——rel_step_max=0.1 经前提改正后从判据面除名（A-P5-10），修复规格的 12 项系统性幻觉锚整段回炉（A-P5-03）。其四，猜想「无接缝 ⟺ 公共面可表示」成立，但其失效标度应改写：尺度扫描的端点比（原 ×5.07）不跨实现复现，跨实现稳健的是峰值/长尺度比 ≈8 与非单调形状、肘点 s≲2h≈256 px（A-P5-11）；残余接缝与不可表示分量 RMS 的线性关系成立，而斜率为 fixture 专属常数、不得迁移。

## 1. 引言

### 1.1 问题

ACSD 科学链的前四点建立了逐帧测光零点（P1）、跨帧绝对信噪比（P2）、平面到球面的通量守恒映射（P3）与稠密 SNR 场（P4）。第五点处理叠加阶段的最后两类系统误差：**加性天光**的帧间差异，以及叠加产品在覆盖子集突变处（coverage boundary）的**接缝**。与乘性误差不同，加性天光差不能靠零点传递吸收；它必须被显式建模、扣除并验证。

本单元的可证伪猜想是：**在纯加性天光世界，UPM 四要素——排除自身的参考面、阻尼 α≈0.5、拟合/堆叠权重同源、末端残差场扣除——能使任意覆盖子集上的加权阶跃恒为零，且产品保留公共背景 B_ref**；猜想的失效边界由参考面的表示能力给出。

### 1.2 与既有工作的关系

重叠帧相对定标的方法学先例是 SDSS ubercalibration [文献:Padmanabhan et al. 2008, arXiv:astro-ph/0703454]——该文处理的是乘性刻度，本文处理其残留：乘性差必须先在上游（Phase1）吸收，加性面才可分离。drizzle 类线性重建的输出像素噪声相关性质由 Fruchter & Hook 2002 [文献:PASP 114, 144, DOI 10.1086/338393] 给出，本文的控制点方差修正因子 k_corr 正是这一「输出像素非独立」论断在本管线几何下的定量后果；该文不含 k_corr 数值（D-08 全文检索确认），故 k_corr 一律按两因子查表引用而不挂文献数值。多帧叠加的稳健伪迹剔除先例见 SWarp [文献:Gruen et al. 2014, PASP 126, 158, DOI 10.1086/675080]——仅作伪迹剔除对照，不作背景匹配依据（A-P5-09 收窄）。稳健位置估计的 M-估计框架出自 Huber [文献:Ann. Math. Statist. 35, 73, DOI 10.1214/aoms/1177703732]；阈值 δ=1.345 的归属为 Holland & Welsch [文献:Comm. Statist. A6, 813, DOI 10.1080/03610927708827533]（A-P5-09 订正），其数值本文以闭式效率方程独立复算 [实验:route2/e5_huber_delta_1345.py]。χ² 期望的自由度公式取自 Andrae et al. [文献:arXiv:1012.3754，式(9) 逐字]。

### 1.3 贡献

1. 把「无接缝」从验收口号改写为**可判定命题**：无接缝 ⟺ 帧间天光差落在参考面表示空间内；给出失效标度的稳健统计量（峰值/长尺度比 ≈8、肘点 2h）。
2. 给出控制点定权公式的**完整三口径标定**（纯公式/端到端/生产链），并按 D-07/D-08 终裁把 k_corr 从冻结常数改为带引用义务的两因子查表。
3. 给出接缝门 1e-2 的**确定性下限推导**（1.0050%）、统计检出曲线、多重性放大与结构性漏检面，以及非退化验收判据（防「全减背景」伪通过）。
4. 以三路独立重做＋两个补实验收口全部历史争议：方向词订正（N=5、dof）、除名（rel_step_max=0.1）、改写（×5.07→峰值比 ≈8）、回炉（12 项幻觉锚）。

## 2. 方法

### 2.1 加性天光参数化与施加语义

UPM 把每帧天光分解为逐帧梯度 δ_k 与公共面 B_ref：产品取 `calibrated_k = raw_k − δ_k`，**只扣逐帧梯度、保留 B_ref**。多退少补（over/under-subtraction）语义要求 δ_k 的施加量在覆盖子集间守恒，使公共背景在产品中保留：端到端用例中产品中位 299.17 e⁻ ≈ B_ref 297.33 e⁻ [实验:c1_additive.py / c3_public_plane.py]。

纯加性前提是帧间乘性差已在上游吸收：星表引导的低阶归一 m̂ 把帧间乘性比偏离 1 从 0.560 压至 5.89e-4（P1 单元已验证产物，跨创新点引用）；未做该步时纯加性 UPM 后接缝 27.37 e⁻，做了之后 6.31 e⁻（4.33×）[实验:c2_multiplicative.py]。

「全减背景」（`raw − b_k`）是退化做法：它把产品背景减至 0.845 e⁻ 并在覆盖子集边界产生 48.4% 负值像素，且在接缝度量上**看起来更好**（退化臂中位 0.275 e⁻ < 正确臂 0.383 e⁻）——因为背景没了，帧间差自然为零。本文以非退化判据（保留背景＋off-locus 对照＋双边检测）量化此陷阱：退化判据对同一注入响应仅 0.09σ，非退化判据分离度 36.4σ，样本外假阳性 0/60 [实验:c4_seam_criterion.py]。

### 2.2 控制点定权与 k_corr 两因子查表

control 点取 patch 内稳健中位，σ_bg = 1.4826·MAD；定权公式（SCI-UPM-WEIGHT-001 合同式）：

```
Var(control) = k_corr · (π/2) · σ_bg² / N_retained
```

渐近核 π/2·σ²/N 为中位数方差的渐近式 [文献:Serfling 1980，书目级标注；Kendall Vol.1 Example 9.7，二手标注]，高斯渐近在 N_retained ≥ 65 时 MC 偏差 <2% [实验:route1/c1_median_variance.py]。

**N=5 三口径（按台账 D-07 定稿）**。纯公式口径：精确阶统计量积分给出 N=5 个标准正态的中位数方差 0.286834，渐近式 π/2/5 = 0.314159，比值 1.0953 ⇒ **高估 9.53%** [推导]（密度 f₍₃₎(x) = 5!/(2!2!)·Φ²(1−Φ)²·φ，数值积分）；三路独立 MC 与端到端腿一致 [实验:route1/c1_median_variance.py、route2/e1_control_variance_median.py、route3/q3_median_variance.json]；P2 补实验给出定稿三口径：纯公式 +9.5%、端到端 ≤±1.5%、生产链亮端裁剪臂低估 1.3–3.2%，κ 四点 rel −0.86%~+0.19% 均 MC 误差内 [实验:supp_control_variance/finiteN_control_variance.py 等]。方向**保守**（权重偏小），不构成过置信风险。原正本「N=5 低估 8.5%」方向词错误，按 D-07 订正。

**k_corr 两因子（按台账 D-08 终裁，负责人已批改表）**。k_corr 不含于任何外部文献；受控复现给出标定几何专属实测带 1.27–1.43（16 相位 × 8 seed：1.3445±0.0416），原 MC 1.3883 为该带内一次实现 [实验:P3 单元补实验-k_corr，固化 results/audit_rework/p3_kcorr/]。分解为

```
k_corr = k_shape × k_geo
```

k_shape（非高斯边际形状）在 N≥9 时 ≤±5%，可忽略 [推导]；k_geo（几何）随 (ρ=输出/源尺度比, pixfrac, 帧数/dither, patch 构成) 变化：紧凑 patch ≈1.27±0.03、全 touched ≈1.43–1.45、空间分散 ≈1.00、几何扫描全域 1.00–5.0、多帧 1/2/4 帧 = 1.424/1.338/1.328 [实验:p3_kcorr/g1–g4]。冻结 1.4 在其声明标定域内即不保守：N=5 紧凑端 k_corr≈2.05±0.09 ⇒ 低估定权 32%；源 583–600″/px 端 ⇒ 低估约 2 倍。因此任何引用必须声明：①标定元组；②N_retained 档位（N≤25 时 k_gauss(N)>1.08 不可忽略；N=5 紧凑 patch 须 ≥1.6、分散 1.54）；③几何不匹配时 fail-closed 拒绝或现场 MC 重标（秒级）。查表本体由 P3 单元承载（跨创新点引用已验证产物）。本单元历史正本 c3_public_plane.py 中取 1.4 属标定带内一次实现，其端到端结论不依赖 1.4 的普适性，维持有效。

### 2.3 接缝判据：确定性下限与统计行为

无接缝交付判据为 `max|rel_step| ≤ 1e-2`，rel_step 为对数口径的跨 patch 背景电平比。其确定性下限由对数–线性映射给出：|Δ|/L ≤ e^{1e-2}−1 = **0.0100503**，即线性台阶 **1.0050%** 以下判绿为确定性结论 [推导]（详见 docs/seam-gate-floor.md）。实验腿逐位闭合 [实验:route1/c3_seam_gate.py，seed=20260319]：Δ/L=1.0050% 恰在门上判红、1.0049% 判绿；H₀ 散布 σ_meas=1.151e-3 vs 判据量散布公式 1.187e-3（比值 0.970），门处虚警 0/4000；多重性检出（解析 1−∏Φ / MC 双口径）@Δ/L=1.05%：n_s=1/2/4 → 0.646/0.875/0.984 [文献:Clopper & Pearson 1934，DOI 10.1093/biomet/26.4.404，区间口径]。

两个**结构性漏检面**必须随门一并陈述（适用域声明，PHASE2_UPM §17.3）：(i) 平滑过渡——线性剖面下观察台阶按 2d/w 缩减（w=8/16/32 px → ×0.50/0.25/0.125），2% 名义台阶判绿 [实验:route1/c3_seam_gate.py]；(ii) 反号梯度相消——注入 1.005%＋反号梯度（2d·g=Δ）时 rel_step 读 0.06% 判绿（01 D-57：漏检面抬升 ≈1.73%），无梯度对照 1.09% 判红。负例（无台阶）median rel_step = 0、4000 次 MC 全绿——判据非恒真（真值无效应⇒度量归零）。

检出门限：注入响应线性（2/5/10/20/50 e⁻ → 0.798/2.325/4.386/8.885/22.425 e⁻），A=10 e⁻ 检出率 0.975，5σ 检测限 **6.98 e⁻** [实验:c4_seam_criterion.py]。另按台账 A-P5-05 限定：「f<1/2 中位数结构性失明」仅在**无噪极限**成立；M42 级噪声下 f=0.3、Δ/L=5% 读数已达 1.03e-2（到门）[实验:route3/exp01_seam_gate.py]。

**判据面收口**。模型级台阶的红位仅存于本接缝门与 Huber δ=1.345（见 §2.5）。原修复规格判据01 的 rel_step_max=0.1 按台账 A-P5-10 **除名**：它不是 IRLS 步长上限（仓库无该参数，grep 全仓库 rel_step 仅命中接缝判据面），按其真实身份（相邻 control 平滑性诊断）不可标定（B0=5 合法场景假红 45–60%、B0=1000 永不红）、判决规则自不自洽（「>20% 邻对判红」对局部缺陷结构性失明：单节点缺陷至多影响 4/112=3.6% 邻对，规格自带 ×10 注入配方实测不判红）、灵敏度比接缝门松约 20× [实验:supp_507_relstep/eb_relstep_calibration.py]。反事实扫描证明任何步长上限只改收敛轮数（20→130 轮）不改终解与判据值。修复规格的 12 项系统性幻觉锚（λ_bend、条件数门 1e12、α/β/h_abs_min、min_cluster_size=3、support_min 错位等）整段回炉，不得作修复依据（A-P5-03）[实验:route1/c10_anchor_forensics.py]。support_min=0.2 降级为出处未定的实现默认；min_cluster_size=3 随规格回炉删除。

### 2.4 诊断量的方差定义与正交性

方差比诊断量（var_ratio = MAD²(右)/MAD²(左)）对电平阶跃原理性失明：电平台阶下 var_ratio≈0.977 而 rel_step 判红；互补地，rel_step 对纯方差伪影失明（方差伪影下 rel_step 判绿、var_ratio≈3.96）[实验:route1/c4_variance_ratio.py]。两诊断量**正交**，方差比的引用面限定为渲染分块伪影粗筛，不进电平接缝判据面。

其适用性对**方差定义**敏感（按台账 A-P5-04）：逐侧方差下失明结论成立；合并窗口方差以 Δ²/4 泄漏（VR_pool = 1.25/2.01/5.03 @ Δ/σ = 1/2/4）[实验:route3/exp02_variance_ratio.py]；左右比形式对噪声放大也失明 [实验:route2/e4_variance_ratio_blindness.py]。诊断量条文必须写明方差定义。

### 2.5 稳健估计与自由度

Huber 位置 M-估计的阈值 δ 由「高斯渐近效率 = 95%」的闭式效率方程定义：δ(0.95)=1.3449975（二分解），MC 渐近效率 0.948（路线1）/ 0.9507（路线2）≈95% [实验:route1/c5_huber_efficiency.py、route2/e5_huber_delta_1345.py]；δ=1.345 的文献归属为 Holland & Welsch 1977 [文献]。σ_floor 主导域（σ_eff = max(σ, floor) ≫ σ）中估计量严格退化为 median（方差逐位等于 median 方差），95% 效率结论在该域失效——σ_eff 必须与观测同标度 [实验:route2/e10_sigma_floor_crossscale.py]。

自由度公式 E[χ²] = n_obs − r_eff 为 Andrae et al. 式(9) [文献:arXiv:1012.3754]；gauge 自由 fixture 判红（r_eff 24 < 32）、gauge 固定判绿、E[χ²] = 120 精确成立 [实验:route1/c6_identifiability_dof.py]。按台账 A-P5-01 订正正本方向词：秩亏时以 n_params 为分母使 χ²_red **高估**（实测 1.0714 / 1.0581），规则 4 本身（n−r_eff 为真分母）维持 [实验:route3/exp06_dof_rankeff.py]。H_solve 恒真门限定生产 λs 域：生产 0.1·mean(diag) 下 κ≈23 恒绿；λ=τ·mean(diag) 变体下 κ≈2.2e10 贴门不严格恒绿（A-P5-08）[实验:route3/exp07_rank_rtol.py、route2/e8_identifiability_rank_rtol.py]。

### 2.6 权重两级口径与豁免清单

份额式（Σw≈1）与绝对 ivar 口径的公共因子消去在 1.5e-16 成立；份额式的方差放大在异方差极端 fixture 达 ×2500；伪 ivar = 1.314e26 单观测独占解、ivar=0 正确剔除（负例）[实验:route1/c7_share_vs_abs_weight.py]。ivar 跨 control 变化时两口径差 **14.8%**（varying_ivar_max_rel_dtheta = 0.14830）[实验:route2/e6_quality_factor_share_weights.py]。zero_anchor_weight=1e-3 的「弱」性依赖份额式口径，绝对 ivar 权重面下偏置 100%——引用须连同权重口径声明（A-P5-07）[实验:route3/exp09_zero_anchor.py]。w∝SNR²（11_upm §4.4）与正本 §5/§10 禁令互斥，**禁令维持**；本几何下 snr² 泄漏仅比 ivar 高 18%（非正本 16.1.3 的 13×），幅度不可迁移（A-P5-06）[实验:route3/exp10_weight_arms.py]。

quality_factor_initial=0.5 为归一化规范非科学量：基准值精确抵消（max|Δθ| = 0.0）；科学量是比值 0.1/0.5 与 share/absolute 口径差 14.8%（A-P5-12）[实验:route2/e6、route3/exp12_quality_factor.py]。0.1/0.5 的取值为**项目约定，不注文献出处**（负责人已批）；同属豁免清单的还有 min_samples=5（合同常数）、IRLS tolerance/rtol（工程合同）、σ_floor=1e-3（数值防护，须以 ivar=0 fail-closed 替代语义）、max_nodes（资源参数）。

## 4. 结果

### 4.1 纯加性世界：猜想在可表示域内成立

产品取 `raw_k − δ_k` 时，覆盖子集突变处的背景电平接缝由 4.80 e⁻ 压至 0.383 e⁻（12.5×）；历史正本各用例压缩范围 12.5×–37.5×；产品中位 299.17 e⁻ ≈ B_ref 297.33 e⁻（背景保留而非剪掉）；δ_k 臂曲线平坦度 0.0087 e⁻；阶跃–注入幅度斜率比 0.975 [实验:c1_additive.py / c3_public_plane.py]。稀疏模型与稠密 cache 在 1,048,576 点上 max|Δ| = 3.1e-15，稀疏系数落盘 14,001 B vs 稠密 8,389,129 B（0.167%）[实验:c6_sparse_dense.py]。

尺度归一容差：scale_obs = 5.26e13 处 ULP = 0.0078125 = 7812×1e-6，绝对容差在该量级不可达，门 rtol=1e-12 充分；「实测 ΔC_max=2.22e-15 ≈ 1 ulp」为实现依赖声明（朴素累加 fixture 给 31 ulp），按 A-P5-02 订正表述 [实验:route1/c8_scale_tolerance.py]。

### 4.2 定权：三口径与查表义务

control_ivar 相对 uniform 的伪影漏入 0.0245 e⁻（uniform 0.0651、SNR² 0.3203，即小 2.7×/13×）；噪声 RMS 亦为三臂最小（1.532 < 1.674 < 2.069 e⁻）；但相对 uniform 的 8.5% 优势小于 NMC=20 的 MC 误差 ⇒ 噪声项上不可分辨，决定性优势只在偏差 [实验:c5_weights.py]。堆叠方差 = 1/Σw（端到端用例 0.05931）[实验:route2/e6_quality_factor_share_weights.py]。

w∝SNR² 与 ivar 的互斥在本几何下的泄漏为 18%（A-P5-06），**不得**以「正本写 13×」外推幅度。k_corr 查表义务见 §2.2；N=5 三口径见 D-07。

### 4.3 接缝门与验收判据

接缝门的确定性行为（1.0050% 地板）、统计行为（0.970 散布比、0/4000 虚警）、多重性行为（0.646/0.875/0.984）与两个结构性漏检面全部复现（§2.3）[实验:route1/c3_seam_gate.py、route2/e3_seam_gate_1e-2.py、route3/exp01_seam_gate.py]。非退化判据把退化判据的 0.09σ 响应放大到 36.4σ，样本外假阳性 0/60 [实验:c4_seam_criterion.py]。

### 4.4 失效边界：可表示性

当帧间天光差含「参考面不可表示且沿某方向相干」的分量时，残余接缝随该分量 RMS 线性增长（结构性主张成立），显著区间由节点间距控制：肘点在 s ≲ 2h ≈ 256 px（本单元 h=0.0355° ≈ 128 px）[实验:c1_additive.py、route1/c9_representation_boundary.py、route2/e9_node_spacing_representation.py、route3/exp08_node_spacing.py]。

**标度统计量按台账 A-P5-11 改写**。原「尺度 1600→50 px 使残余接缝 ×5.07」的端点比**不跨实现复现**：同口径独立复算得 2.95（带噪）/2.43（无噪），gauge 变体 1.78、RMS 口径 1.71——端点比值随实现条件漂移，且已发布序列本身非单调。跨实现稳健的统计量是**峰值/长尺度比 ≈8**（原 8.03 vs 复算 8.02、第三实现 9.21）与**非单调形状**（峰在 100 px、50 px 回落）、肘点 s≲2h [实验:supp_507_relstep/ea_507_scale_scan.py]。

线性关系的斜率为 **fixture 专属常数**：本单元 fixture 得 slope 0.798/Pearson 0.8964；路线1 独立 fixture（不同边界几何）得 slope 0.207/Pearson 0.8006 [实验:route1/c9_representation_boundary.py]；路线3 Q8 确认 0.80 落在相位区间内但数值不可迁移 [实验:route3/exp08_node_spacing.py]。常数不外推；可迁移的是线性结构、肘点 2h 与 λ⁻² 收敛（λ 倍增残差减半）。负例：常数分量（λ→∞）完全可表示 ⇒ 残余接缝精确为 0 [实验:route1/c9_representation_boundary.py]。

### 4.5 判据面收口与幻觉锚回炉

判据面上仅存的两级锚：接缝门 1e-2（§2.3）与 Huber δ=1.345（§2.5）。rel_step_max=0.1 除名（§2.3）；12 项幻觉锚回炉（A-P5-03）；support_min=0.2 降级；min_cluster_size=3 删除。修复规格不得再作为修复依据，直至回炉完成。

## 5. 结论

1. **猜想的最终形态**：「接缝为零」等价于「帧间天光差落在参考面的表示空间内」。可表示域内实测 12.5×–37.5× 压缩成立且背景保留；域外残余接缝与不可表示分量 RMS 线性相关，显著尺度由节点间距控制（肘点 2h ≈ 256 px），跨实现稳健的标度统计量是峰值/长尺度比 ≈8（非端点比）。
2. **定权体系**：control_variance 公式本体与 N≥65 渐近域成立；N=5 处渐近式高估 ≈9.5%（保守），端到端 ≤±1.5%，生产链亮端裁剪臂低估 1.3–3.2%（D-07）；k_corr 一律按 k_shape×k_geo 两因子查表并声明标定元组与 N 档（D-08，查表 P3 单元承载）；份额式与绝对口径差 14.8%，引用锚必须连同口径声明。
3. **判据体系**：接缝门 1e-2（确定性下限 1.0050%＋统计检出曲线＋两个已登记结构性漏检面）与 Huber δ=1.345 是判据面仅存的两级锚；rel_step_max=0.1 除名；方差比限定为渲染分块伪影粗筛且条文必须写明方差定义；rel_step 与方差比正交互补。
4. **前提链**：帧间乘性差必须先在 Phase1 吸收（残差 5.89e-4），否则接缝放大 4.33×；真实数据的分块回归截距不可辨识（动态范围 8.5 ADU），加性偏移必须由天光面承载。
5. **规格收口**：05_正向规格 §9/§10 的 12 项系统性幻觉锚整段回炉，不得作修复依据；判据面以本文明示的两级锚为准。

## 6. 诚实边界

1. **fixture 专属常数不得迁移**：失效边界斜率（0.207–0.80 跨 fixture）、Pearson（0.80–0.90）是边界几何的函数；不引用单一数值作验收依据。端点比 5.07 不复现，任何端点比统计量都不稳健。
2. **本节处理历史 UNRESOLVED 的终态**：N=5 方向词（D-07 已裁决）、k_corr（D-08 已裁决）、rel_step_max=0.1（A-P5-10 除名）、×5.07（A-P5-11 改写）、dof 方向词（A-P5-01 订正）、方差比定义（A-P5-04 限定）——均已裁决入正文；support_min=0.2（出处未定，降级为实现默认）、min_cluster_size=3（幻觉锚，随 05 回炉）、Tikhonov 1963 题录未核（不作依据）、Serfling/Kendall pinpoint（书目级/二手标注，结论由 MC 独立承担）——登记于 refs.md，不进正文引用面。
3. **11_upm §4.4 与正本 §5/§10 互斥**：w∝SNR² 禁令维持；本几何泄漏 18% 是几何实测，不得迁移为普适幅度（A-P5-06）。
4. **生产链语义待裁决项**（P2 链残留）：被估量 y 的合同语义（裁剪后中位数 vs 全样本中位数）由负责人裁决，不属本单元。
5. **k_corr 查表实施**：查表本体与生产接入由 P3 单元与变更流程承载；本单元仅锁定引用义务与两端失保守证据。
6. **平滑域**：smoothing_lambda=0 时 per-(frame,cell) 自由加性场恰好定解，公共场 M 只是规范选择，「拟合/堆叠权重同源」与「末端残差场扣除」在该域不可检验；final_gauge 在 m_full_frame=1 时近似 no-op（3.7e-3 e⁻）且不能修复子集依赖——这些域内的恒真 PASS 不得充作证据 [实验:c1_additive.py]。
7. **自适应 κ 重试的张力**：FIX-3 自适应重试增大 roughness_penalty（面更光滑）以压条件数，恰好降低表示能力，与失效边界方向相反；自适应必须同时审计接缝度量与 sky_plane_roughness_penalty_used，禁止把「κ 过关」当「面正确」。
8. **采样限制**：补实验实验 A 为独立 Python 求解器（非生产二进制，绝对值有实现差）；RMS 伪影口径在带噪臂被两次独立 Poisson 实现之差主导；信号模板为解析弱场替代 HST 真实模板；实验 B 为 2 帧全重叠玩具几何、IRLS 权重面未逐字复刻生产复合权。

## 7. 链条位置

### 上游接口

- **P1 → P5**：校准帧（ADU·sr⁻¹，BUNIT 冻结）；乘性 k_photo·m 已在 Phase1 吸收，残差 5.89e-4（P1 单元已验证产物）。
- **P2/P4 → P5**：control_variance → control_ivar，量纲链 σ_bg → (ADU·sr⁻¹)² → w (ADU·sr⁻¹)⁻²；N_retained ∈ [5, 289]；k_corr 按 D-08 两因子查表（须声明标定元组与 N 档）。
- **P4 → P5**：稠密 SNR 场 → per-observation 权重 w = qf·reliability·ivar；亮度携带决定 P5 效率上限（12×，P4 单元已验证产物）。

### 下游消费

- δ_k 施加量（多退少补语义，保留公共面 B_ref）；
- max|rel_step| ≤ 1e-2 无接缝判决（含适用域声明）；
- B_ref 可表示性判决（identifiable / rank_eff / κ）；
- stacked variance = 1/Σw（端到端用例 0.05931 [实验:route2/e6_quality_factor_share_weights.py]）。

### 精度约定

- 天光多项式阶数按 patch 配置；接缝门以左/右 patch 的 rel_step 计，**方差定义必须写明**（逐侧方差失明成立；合并窗口方差以 Δ²/4 泄漏，A-P5-04）；f<1/2 失明仅无噪极限（A-P5-05）。
- 豁免清单（项目约定，不注文献出处）：quality_factor 0.1/0.5、min_samples=5、IRLS tolerance/rtol、σ_floor=1e-3（须以 ivar=0 fail-closed 替代语义）、max_nodes。
- 接缝门 fixture 未含双线性亚像素方差因子与足迹多边形几何（正本 §17.4 实测相对差 4.5e-3 属二阶效应）。
