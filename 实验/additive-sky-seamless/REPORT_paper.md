# P5｜天文球面马赛克的联合加性背景、残余乘性标度与接缝可辨识性

> 科学论文修订稿。以生产现状“纯加性链”和最高设计“允许残余乘性差模”为两个不同状态；有关 MA 函数和 S9b 断连图的数值为 DeepSeek 报告提供的审计证据，尚未在本次连接独立重跑。旧 `REPORT_paper.md` 的历史执行流水可从 Git 历史和 `REPORT_experiment.md` 追溯。参考文献库在 `../shared/references/`。

## 摘要

宽场天文球面马赛克常出现帧间天光加性梯度、相对透过率/平场乘性残差、噪声和观测足迹变化共同导致的可见接缝。本文提出研究一个**可辨识性受限**的联合模型，将扣星背景采样用于加性相对对齐、匹配恒星通量用于乘性残差的独立约束，以重叠图每个连通分量固定规范，再在保留公共低频天体结构的限制下输出球面拼接。我们将相邻足迹接缝、恒星相对光度、扩展源低频保真和真实帧有效覆盖列为互不替代的检验。代理报告显示生产链仍只有加性施加，S9b 断连图第二分量的接缝约为 12.8%；乘性标量模型在真值为 1 的阴性对照中也会错误改善接缝。本文据此将“纯加性是否充足”“乘性是否必要”“生产是否实现”分别设为待裁判命题，而不宣称目前已验证全域无接缝。

**关键词**：马赛克；加性背景；乘性归一化；重叠图；规范自由度；光度保持；背景保真；PhotometricMosaic。

## 1 科学问题与已有工作

相对光度标定与重叠约束是成熟问题：Makovoz、Khan 与 Moshir [R15] 已给出重叠图中常量背景偏移的全局联合最小化先例，Padmanabhan 等 [R03] 的 ubercalibration 研究了多次重叠观测的相对零点与绝对锚；Huber [R10] 是稳健估计的基础；John Murphy 的 NormalizeScaleGradient（NSG）和 PhotometricMosaic（PMM）提供了可对照的生产工作流与软件文档 [R11]。PMM 不是已公开且由本文逐行核实的 ACSD 数学实现，不能声称本文重现了其内部具体算法或参数。ACSD P5 的可能论文贡献应是“在 HEALPix 观测足迹与 P1 标定限制下，联合差模规范和低频保真约束的可复现实证”；既不是发明加性背景去除，也不是发明任意亮度匹配。

研究四个问题：H1 连通重叠图内可区分相对加性差与共同真实背景；H2 帧间残余乘性项是否能由独立恒星光度证据辨识；H3 重叠分量规范和面表示能力是否充分覆盖合法几何；H4 接缝变小是否真的意味着科学信号未损失。

## 2 观测与估计目标

将第 i 帧投影到公共球面位置 x 的有效观测写成

```text
y_i(x) = g_i(x) * [P_i * S](x) + a_i(x) + epsilon_i(x)
```

其中 `S` 为真实天体表面亮度，`P_i` 为每帧的 PSF/重采样响应，`g_i>0` 为残余乘性响应，`a_i` 为加性天光/背景残差，`epsilon_i` 是随机误差。**在 PSF 未匹配时，重叠处不同帧像素并不严格应相等**；必须先定义相同估计目标（共同 PSF 或无星背景采样及星点积分通量）才能建立差约束。生产若仅执行 `y_i-delta_i`，其有效模型是 `g_i ≡ 1` 的硬先验，而不是“已经通过数据证明所有乘性残差为零”。

### 2.1 加性相对约束

在有效背景控制点、相同空间采样及一组固定权重上，给每帧低阶加性项 `a_poly,i` 和稳健残差场 `F_i`，施加 `d_i=a_poly,i+F_i`。理想重叠约束为

```text
(y_i - d_i)(x) - (y_j - d_j)(x) = 0
```

但有限维场、非零噪声、表示能力和正则化只能使该量最小，不能无条件满足逐像素相等。建议优化 `sum_{overlap samples} w_ij rho([(y_i-d_i)-(y_j-d_j)]/sigma_ij)+lambda||L d||²`；`w_ij` 应对应控制点的同一误差单位，`rho` 为鲁棒损失且明示参数。

施加逐帧场时可规定 `sum_{i in coverage(x)} w_i(x)F_i(x)=0` 作为同位置**差模**规范。该式仅说明在这些相同权重和覆盖支持下，残差场扣除不会改变对应加权平均；并不保证多项式项、覆盖突变、权重改变时总产品保持原均值，更不等价于恢复真实 `S` 的物理低频分量。共同背景与天体弥散结构若无外部空天区/标准锚，在数学上存在无法由纯重叠数据区分的共模自由度。

### 2.2 乘性残余与独立星光度锚

先由 P1 施加 `k_photo*m(x,y)`。P5 只允许拟合留存的**帧间残余差模**，避免把 P1 再算一次。第 1 阶段选择 `g_i=exp(eta_i)` 的帧级标量；用未饱和、非变星、未混叠且颜色差可控的匹配恒星积分通量，在背景已校正后形成独立观测：

```text
log f_is - log f_js ≈ eta_i - eta_j + color/PSF terms + noise
```

对每个重叠图连通分量固定 `sum_i u_i eta_i=0` 或指定有外部证据的光度锚；`eta=0` 是模型选取的阴性假设，**不是通过 gauge 约束得到的物理结论**。若估计的 `g_i` 定义为观测域的额外响应，则校正光度为 `(y_i-a_i)/g_i`，独立测量方差随校正变为 `V_i/g_i²`，并额外估计 `g_i` 不确定性引入的系统方差；不可对已经校正的信号再乘一次 `g_i`。

在参数可辨识与模型选择经独立检验前，输出 `g_i=1`、`NOT_APPLIED`，不是把“未试乘性”写成“乘性不存在”。空间变增益 `g_i(x)` 需要更强恒星密度和规范约束，本论文单独列作后续研究，不能与生产最小修复混作一个 PASS。

### 2.3 重叠图的连通分量与可辨识

设每帧是一个顶点，满足足够独立控制约束的重叠对形成边，图可有 C 个连通分量。对于任何单独分量内的加性整体偏置或 log 增益共模，在仅观察相对差的条件下均存在规范自由度；至少需要每分量一个规范，且**不同分量间没有重叠时不存在可由数据求得的相对天光零点**。因此 S9b 两个各含 2 帧的分量必须分别建立参考帧、数值秩检验、独立状态及接缝摘要，不能由全局 `ref_frame=0` 统一代表。若内部共享平滑样条跨分量产生虚假数值约束，正规矩阵即使形式满秩也可能不代表物理可辨识，须用雅可比可辨识检验和分量间扰动对照识别。

## 3 接缝与结构保真是两个不同统计检验

`rel_step` 可定义为足迹边缘两侧法向一定距离的有符号水平差除以局部背景水平；分母不稳定或背景接近零时必须返回 `UNDEFINED`，而非默认为零接缝。滑动窗里真实星云梯度将与足迹台阶混淆，必须用非边界对照位置及不同法向距离 d 的扫描识别：硬台阶项对 d 近似不变，平滑斜坡项在局部随 d 变化。将实际计算的边界数 `n_evaluated` 和可用但未测/数据不支持的边界数分别报告。

允许通过的指标至少包括：
- **重叠一致性**：留出重叠控制对的标准化差、稳健 MAD、边界相对阶跃的最大值/置信区间以及测量覆盖率；
- **星点光度**：校正前后匹配恒星的留出通量比、色差趋势、PSF/视宁度分层；
- **真实结构保真**：已知星云真值模板的面亮度平均、低空间频率功率谱、扩展源总通量与梯度；
- **不确定度**：修正系数方差、重采样协方差的忽略影响、结果残差统计；
- **物理非退化**：全减背景、过度羽化、用弥散源自身拟合加性偏差的伪最优臂必须在低频/通量门判红。

纯 feather/blending 只能减小视觉突变，并非取得一致零点的证据。任何调高模型自由度带来的“更无缝”均应同时报告天体结构丢失的代价。

## 5 当前证据等级与失败分析

交接报告称 `lib/algorithms/coverage/src/sky_plane.cpp` 生产路径只有全局 `model->ref_frame=0`；本次 GitHub 源码查看确认确有该赋值，但其对整条分量求解的全部影响仍以回归为准。报告的 S9b `compA≈1.6e-4`、`compB≈1.281e-1`、`identifiable=1` 是 **AGENT_REPORTED**，足以触发独立复测和科学合同的风险登记，不是独立重复试验证据。P5 乘性有研究求解器但未进入实际施加链，文档能力和生产能力不一致。

报告还指出“10 seed 中，阳性乘性世界的 A+G 在 10/10 改善 seam，而 `g_true=1` 阴性对照也有 8/10 改善”——在事先声明的因果识别判据下，这意味着**不能证明增益是接缝改善的特异原因**，因此生产应保持恒等直到独立星光度通过。真实帧控制样本 `chi²_red≈719.93` 且仅约 `9.65%` 控制点有多帧支持的数字也只作为待复验线索。历史 49 帧产品的接缝报告只评估 `114/196` 边界（另 82 边未测），不允许因此声称全域全部接缝达标。

## 6 结论与论文贡献边界

本文能提出数学模型和可复现验收架构，但当前没有证明“全域无接缝”或“乘性残余可由真实数据无偏恢复”。优先顺序是**分量规范/生产状态正确性 → 加性基线与局部检出 → 乘性阳性/阴性研究 → 真实星点与弥散源联合验证**。在没有外部天空基准或足够重叠之前，所有帧共同的低频加性项与真实星云背景之间存在固有不可辨识性；任何保护公共模的算法都只承诺相对保护，不应被命名为真实天光绝对恢复。

若完成 P5-A～F 且独立真值/真实留出实验均收敛，可发表的特色是“重叠拓扑约束 + 加乘性分离 + 模型显式退化 + 天体低频保真联合检验”，而不是孤立地把拼图接缝做平。
