# P5｜天文球面马赛克的联合加性背景、残余乘性标度与接缝可辨识性

> 本篇把加性规范固定与乘性增益判定分开：加性一侧给出逐连通分量的 gauge 修复与判红，乘性一侧给出在无真实增益世界中的伪改善反例，因此生产默认保持恒等。读数、脚本与输入哈希见 `REPORT_experiment.md` 附录 S03／S03-exec／S03-裁决、`docs/S03_P5_COMPONENT_evidence.json`、`docs/S03_P5_COMPONENT_evidence.exec.json`、`docs/S07_P5_GAIN_evidence.json` 与 `docs/S07_results/`；实测图见 `figures/`（逐图哈希见 `figures/P5_figures_manifest.json`）。

## 摘要

宽场天文球面马赛克常出现帧间天光加性梯度、相对透过率/平场乘性残差、噪声和观测足迹变化共同导致的可见接缝。本文研究一个**可辨识性受限**的联合模型：扣星背景采样用于加性相对对齐，匹配恒星通量用于乘性残差的独立约束，重叠图按**每个连通分量**固定规范，再在保留公共低频天体结构的限制下输出球面拼接。加性一侧的实测把结论钉死：按真实有效重叠边枚举连通分量、每分量固定自身锚帧后，两分量各 2 帧的场景 `compB` 的读数症状由 `0.1281497171821252` 降到 `0.0005981665755358275`（`214×`），而两个单连通分量场景的 `model_hash` 修前修后**逐字相同**，证明补丁只作用于断连图；故障注入 `global_anchor` 判红（`rc=7`），并暴露**判据分裂**——全图 `rank 256/256`、`identifiable=1`、`κ=3.89e9`（仍 `< 1/τ = 1e10`）全部读绿，只有逐分量判据抓到 `comp1 rank 118/127`、`n_unidentified=9`（`status=1` RED）。乘性一侧的实测给出**否定结论**：在无真实增益的阴性世界（10 seeds）里，加性+标量增益联合拟合仍把留出散度从 `0.05459` 降到 `0.04176`，差值中位 `+0.00968`、95% CI `[0.00681, 0.01740]`、`frac_pos=1.0`；而同一世界的 oracle 增益给出 `0.05459`（与纯加性逐位相同，差值中位恰为 `0.0`）。预声明判据“阴性世界 CI 须含 0”因此**不成立**，`status=FAIL`；生产默认保持**恒等**。修后产品仍有不可辨识的跨分量绝对零点（两分量间隙 `x∈(150,170)` 无重叠，电平差 `18.84 ADU（6.07%）`），且无外部锚，因此修后产品**不得**被引用为“已跨分量定标”。

**关键词**：马赛克；加性背景；乘性归一化；重叠图；规范自由度；光度保持；背景保真；PhotometricMosaic。

## 1 科学问题与已有工作

相对光度标定与重叠约束是成熟问题：Makovoz、Khan 与 Moshir [R15] 已给出重叠图中常量背景偏移的全局联合最小化先例，Padmanabhan 等 [R03] 的 ubercalibration 研究了多次重叠观测的相对零点与绝对锚；Huber [R10] 是稳健估计的基础；John Murphy 的 NormalizeScaleGradient（NSG）和 PhotometricMosaic（PMM）提供了可对照的生产工作流与软件文档 [R11]。PMM 不是已公开且由本文逐行核实的 ACSD 数学实现，不能声称本文重现了其内部具体算法或参数。ACSD P5 的可研究贡献是“在 HEALPix 观测足迹与 P1 标定限制下，联合差模规范、逐分量可辨识性与低频保真约束的可复现实证”；既不是发明加性背景去除，也不是发明任意亮度匹配。

研究四个问题：H1 连通重叠图内可区分相对加性差与共同真实背景；H2 帧间残余乘性项是否能由独立恒星光度证据辨识；H3 重叠分量规范和面表示能力是否充分覆盖合法几何；H4 接缝变小是否真的意味着科学信号未损失。

## 2 观测与估计目标

将第 i 帧投影到公共球面位置 x 的有效观测写成

```text
y_i(x) = g_i(x) * [P_i * S](x) + a_i(x) + epsilon_i(x)
```

其中 `S` 为真实天体表面亮度，`P_i` 为每帧的 PSF/重采样响应，`g_i>0` 为残余乘性响应，`a_i` 为加性天光/背景残差，`epsilon_i` 是随机误差。**在 PSF 未匹配时，重叠处不同帧像素并不严格应相等**；必须先定义相同估计目标（共同 PSF 或无星背景采样及星点积分通量）才能建立差约束。生产若仅执行 `y_i − delta_i`，其有效模型是 `g_i ≡ 1` 的硬先验，而不是“已经通过数据证明所有乘性残差为零”。

### 2.1 加性相对约束与逐分量规范

在有效背景控制点、相同空间采样及一组固定权重上，给每帧低阶加性项 `a_poly,i` 和稳健残差场 `F_i`，施加 `d_i = a_poly,i + F_i`。理想重叠约束为

```text
(y_i - d_i)(x) - (y_j - d_j)(x) = 0
```

但有限维场、非零噪声、表示能力和正则化只能使该量最小，不能无条件满足逐像素相等。建议优化 `sum_{overlap samples} w_ij rho([(y_i-d_i)-(y_j-d_j)]/sigma_ij) + lambda ||L d||²`；`w_ij` 应对应控制点的同一误差单位，`rho` 为鲁棒损失且明示参数。

设每帧是一个顶点，满足足够独立控制约束的重叠对形成边，图可有 C 个连通分量。对于任何单独分量内的加性整体偏置或 log 增益共模，在仅观察相对差的条件下均存在规范自由度；至少需要每分量一个规范，且**不同分量间没有重叠时不存在可由数据求得的相对天光零点**。因此本文的规范固定规则是：以**实际有效控制点**（而非名义重叠区）建立帧重叠图，枚举连通分量，**每分量取分量内最小 `frame_id` 作锚帧、`δ_anchor ≡ 0`**，并逐分量报告 `rank`、`n_unidentified`、`κ`、有效边数与支持比例。全局 `ref_frame` 降为兼容字段，不得充当全图统一规范；无重叠/无控制的孤立分量必须显式失败或标为未可定标（`docs/science/sky/UPM.md` §5「失效域」），不得伪称与其他分量可比；把孤立分量作为独立产品输出是登记的产品级替代分支（未实现）。

### 2.2 乘性残余与独立星光度锚

先由 P1 施加 `k_photo*m(x,y)`。P5 只允许拟合留存的**帧间残余差模**，避免把 P1 再算一次。第 1 阶段选择 `g_i = exp(eta_i)` 的帧级标量；用未饱和、非变星、未混叠且颜色差可控的匹配恒星积分通量，在背景已校正后形成独立观测：

```text
log f_is - log f_js ≈ eta_i - eta_j + color/PSF terms + noise
```

对每个重叠图连通分量固定 `sum_i u_i eta_i = 0` 或指定有外部证据的光度锚；`eta = 0` 是模型选取的阴性假设，**不是通过 gauge 约束得到的物理结论**。若估计的 `g_i` 定义为观测域的额外响应，则校正光度为 `(y_i − a_i)/g_i`，独立测量方差随校正变为 `V_i/g_i²`，并额外估计 `g_i` 不确定性引入的系统方差；不可对已经校正的信号再乘一次 `g_i`。

在参数可辨识与模型选择经独立检验前，输出 `g_i = 1`、`NOT_APPLIED`；**本文的阴性世界实测进一步给出不启用乘性的直接证据**（见 §5.1 第 12–14 行）：联合拟合在无增益世界也会产生统计显著的“改善”，而 oracle 增益给出严格为零的改善。空间变增益 `g_i(x)` 需要更强恒星密度和规范约束，本文单独列作后续研究，不与生产最小修复混作一个 PASS。

## 3 接缝与结构保真是两个不同统计检验

`rel_step` 定义为足迹边缘两侧法向一定距离的**有符号**水平差除以局部背景水平；分母不稳定或背景接近零时必须返回 `UNDEFINED`，而非默认为零接缝。滑动窗里真实星云梯度将与足迹台阶混淆，必须用非边界对照位置及不同法向距离 d 的扫描识别：硬台阶项对 d 近似不变，平滑斜坡项在局部随 d 变化。将实际计算的边界数 `n_evaluated` 和可用但未测/数据不支持的边界数分别报告。

允许通过的指标至少包括：
- **重叠一致性**：留出重叠控制对的标准化差、稳健 MAD、边界相对阶跃的最大值/置信区间以及测量覆盖率；
- **星点光度**：校正前后匹配恒星的留出通量比、色差趋势、PSF/视宁度分层；
- **真实结构保真**：已知星云真值模板的面亮度平均、低空间频率功率谱、扩展源总通量与梯度；
- **不确定度**：修正系数方差、重采样协方差的忽略影响、结果残差统计；
- **物理非退化**：全减背景、过度羽化、用弥散源自身拟合加性偏差的伪最优臂必须在低频/通量门判红。

纯 feather/blending 只能减小视觉突变，并非取得一致零点的证据。任何调高模型自由度带来的“更无缝”均应同时报告天体结构丢失的代价。**尤其不得只用一个“更平滑/更无缝”的标量指标选择乘性臂**：本文的阴性对照正是这一禁令的实测反例。

## 6 结论与论文贡献边界

本文能提出数学模型与可复现的验收架构，并给出两条互相独立的实测结论。加性一侧：按真实有效重叠边枚举连通分量、逐分量固定锚帧后，`S9b` 的规范失控读数由 `1.28e-1` 降到 `5.98e-4`，连通图逐位不变，故障注入判红并暴露“全图绿、逐分量红”的判据分裂；但其产品仍受不可辨识的跨分量绝对零点限制，需外部锚。乘性一侧：在无真实增益的阴性世界里，联合拟合给出 95% CI 不含 0 的伪改善，而 oracle 增益给出严格为零的改善 ⇒ 预声明判据 C3 不成立，生产默认保持恒等。因此当前没有证明“全域无接缝”或“乘性残余可由真实数据无偏恢复”；优先顺序是**分量规范/生产状态正确性 → 加性基线与局部检出 → 乘性阳性/阴性研究 → 真实星点与弥散源联合验证**。在没有外部天空基准或足够重叠之前，所有帧共同的低频加性项与真实星云背景之间存在固有不可辨识性；任何保护公共模的算法都只承诺相对保护，不应被命名为真实天光绝对恢复。

在原有阻断项不被复现澄清或修复之前，任何发布级主张不成立；本节可发表的特色是“重叠拓扑约束 + 加乘性分离 + 模型显式退化 + 天体低频保真联合检验”，而不是孤立地把拼图接缝做平。
