## 0. 摘要（结论先行）

1. **假说成立的部分**：在纯加性天光世界，生产链路 `p2_sky_plane_*`（平滑 B_ref 参考面 +
   逐帧低阶 δ_k，产品 `calibrated = raw − δ_k`，**保留 B_ref**）把覆盖子集突变处的背景电平
   接缝从 **4.80 e⁻ 压到 0.383 e⁻（12.5×）**，且产品中位 299.2 e⁻ ≈ B_ref 297.3 e⁻（背景被保留，
   不是「全减到零」）。同一世界下「把背景全减掉」的臂产品中位 0.845 e⁻ —— 这正是**退化**做法。
2. **假说失效的边界（本单元主要发现）**：无接缝 ⟺ **公共面可表示**。当帧间天光差含有
   参考面**不可表示**且**沿 y 相干**的分量时，残余接缝随该分量 RMS **线性增长**
   （slope 0.798，Pearson 0.896；按台账 A-P5-11 订正：端点比 ×5.07 不跨实现复现，跨实现稳健的是峰值/长尺度比 ≈8＋非单调，见 REPORT_paper.md §4.4）。
   该分量出现在 ≲2× 节点间距（≈256 px）的尺度上。
3. **乘性张力（关键）**：历史 1.56× 帧间乘性差若**不做 Phase1 归一**，纯加性 UPM 后接缝
   27.37 e⁻；做了 Phase1 归一后降到 6.31 e⁻（**4.33×**）。Phase1 的星表引导低阶 m̂ 把帧间
   乘性比从 0.560 的偏离压到 **5.89e-4**。基外高频乘性分量（1%@24 px）被分块 PSD 定位在
   预期空间频率（k=26 vs 预期 21.33，±6 bin；恢复幅度 0.693±0.005 为**下界**）；它对**电平**接缝的贡献有界（<50% 基线）。
4. **非退化判据**：把「减掉全部背景再看帧间差」证伪为**退化**（恒真反证，对注入接缝响应 0.09σ，
   即 120 次实现全部不翻红）；本单元的形式化判据（**保留背景 + off-locus 对照**）在
   同一注入下分离度 **36.4σ**，**双边**样本外假阳性 0/60，A=10 e⁻ 检出率 0.975，5σ 检测限 6.98 e⁻。
5. **权重**：`control_ivar` 的伪影漏入 0.0245 e⁻，比 uniform（0.0651）小 **2.7×**、
   比 SNR²（0.3203）小 **13×**；噪声 RMS 上 `control_ivar` 最优（1.532 < uniform 1.674 <
   SNR² 2.069），但相对 uniform 的优势 8.5% **小于 NMC=20 的 MC 误差**（见 §6 诚实边界）。
6. **稀疏现场求值**：生产 dense cache 与 sparse `calibrate_block` 在 1,048,576 点上
   max|Δ| = **3.1e-15**；稀疏模型 14,001 B vs 稠密 8,389,129 B（**0.167%**）；
   按需求值 64² 块峰值 RSS 11,688 kB < 稠密物化 512² 的 14,568 kB。
7. **真实数据（M42 M1 T3 Red，4 帧）**：帧间背景电平比 `level_ratio` 中位 **0.9805**
   （0.9386–1.0503）；乘性斜率中位 **0.995**（0.806–1.323，杠杆臂仅 8.5 ADU ⇒ 截距不可辨识）；
   真实样本上生产天光面 rc=0、rank=49=n_nodes、χ²_red 1.004；真实数据 + 人工覆盖图案的接缝（**excess**）21.84 → **0.583 e⁻（37.5×）**，
   相对度量 3.9e-4（<1%）。
8. **登记 3 项生产缺陷（FIX，不改代码）**：绝对容差 `tolerance=1e-6` 在 ~300 e⁻ 尺度不收敛；
   `converged` 只有 0/1 无法区分 max_iter 与 stalled（规范要求 0/1/2/3）；
   `kappa_max` 在真实数据上达 3.16e7（近奇异）。

## 1. 可证伪假说

### H1（主假说）
> 在纯加性天光世界（每帧天光 `b_k(x,y)` 为平缓梯度 + 散粒噪声，帧间差 δ_k 有限），
> 统一测光模型（UPM）的四要素 —— **排除自身的参考面**、**阻尼 α≈0.5**、**拟合/堆叠权重同源**、
> **末端残差场扣除** —— 使任意覆盖子集上的加权阶跃恒为零，且产品保留公共背景 B_ref。

**可证伪点**：
- 若「减去全部背景后再看帧间差」也能给出同样的零阶跃 ⇒ H1 的判据是**退化**的（本单元必须自证非退化）；
- 若存在某类帧间天光差使残余接缝不归零 ⇒ 必须给出**该分量的可测量预言量**并验证其标度关系；
- 若权重选择对结果无影响 ⇒ 「权重同源」要素在该域内不可检验（必须如实登记为边界，不得充作证据）。

### H2（张力假说）
> 若帧间存在乘性差（历史实测 1.56×），纯加性 UPM 不能消除接缝；其残余必须能被
> **Phase1 测光归一**吸收，若不能吸收则必须量化其**幅度、空间频率与来源**。

### H3（工程假说）
> 稀疏（按需、现场求值）与稠密数值表示等价，且内存随**节点/分块**而非像素增长。

## 2. 方法

### 2.1 世界构造（`code/sci_c_common.py`）

    raw_k(x,y) = Poisson( s(x,y) + b_k(x,y) ) + N(0, RN²)      # 电子域，gain = 1 e-/ADU
    b_k(x,y)   = 100 + off_k + pl_k·(u,v) + qu_k·(u²,uv,v²) + 正弦项   # 逐帧不同相位
    s(x,y)     = HST M16 F657N 真实星云/星点模板（σ=1.5 px PSF，掩膜外中位 200 e⁻）

覆盖图案：4 帧 x 向条带 `A:gx0-2 / B:gx2-4 / C:gx4-6 / D:gx6-7`（8×8 control cell / 512² tile），
覆盖子集在 cell 边界 `x = 128/192/256/320/384/448` 突变。固定 seed `SEED_BASE=20260923`，
`derive_rng(tag)` 为 SHA-256 派生（无时间/环境随机源）。

### 2.2 生产代码接口（只读链接，`code/{upm_probe,sky_probe}.cpp`）

静态链接 `build/libastrocs_phase2.a`，直接调用：
`p2_sky_plane_{default_config,build,info,eval,eval_block,eval_delta,eval_delta_block,frame_delta,residuals}`、
`p2_upm_control_variance`、`p2_upm_{build,info,calibrate_block,evaluate_c,convergence,materialize_dense,dense_read_block,save}`、
`p2_upm_ma_{build,info,solution,provenance,close}`。**不修改任何生产源码**。

### 2.3 接缝度量（非退化判据的核心）

    m(x)   = nanmedian_y mosaic(x,y)                       # 对星点/细结构稳健
    step(x_b) = median(残差右 halfwin 列) − median(残差左 halfwin 列)   # 残差 = 去 order-2 基线
    excess(x_b) = step(x_b) − median( step(x_b+δ), δ∈{±32,±64,±96} )  # off-locus 对照

- **保留背景**：产品是 `raw − δ_k`（含 B_ref），不是「全减背景」；
- **红/绿双向**：注入接缝必须翻红（检出率），真值无接缝必须不翻红（假阳性率）；
- **off-locus 对照**：真实结构（星云、M42）会在边界处造成**系统台阶**，用同一条带内
  偏离边界的对照线扣除；HST/真实数据上必须看 `excess`。

## 5. 可判定结论

### 5.1 猜想在什么条件下成立

**成立**（C1/C3/C7，实测 12.5× / 13.4× / 45× 接缝压缩）：
1. 帧间天光差可由**连续公共参考面**（B_ref 稀疏样条）+ 逐帧低阶 δ_k 表示；
2. 各帧只做**加性多退少补**（`calibrated = raw − δ_k`，保留 B_ref）—— 全减背景是退化的；
3. 覆盖子集突变处，公共面连续 ⇒ 加权阶跃 ≈ 0；
4. 权重取自**同一来源**（`control_ivar`），堆叠权重与拟合权重一致。

**失效**（C1 A10）：帧间天光差含**参考面不可表示且沿 y 相干**的分量时，
残余接缝与该分量 RMS 线性相关（结构性主张成立），尺度 ≲2× 节点间距（≈256 px）时显著；斜率 0.80 为 fixture 专属常数不迁移（路线1 独立 fixture 得 0.207），标度统计量按台账 A-P5-11 改用峰值/长尺度比 ≈8。

**前提**（C2 M4）：帧间乘性差必须先在 Phase1 吸收（本实验 5.89e-4）；否则纯加性 UPM 后
接缝放大 4.33×。

### 5.2 四要素的实测裁决

| 要素 | 裁决 | 证据 |
|---|---|---|
| 排除自身的参考面 | **必要** —— 依据是 **C3 B3/B4**（保留 B_ref 产品中位 299.17 e⁻ vs 全减 0.711 e⁻）与 **C4 N2/N3**（非退化判据 36.4σ、样本外 FP 0/60）。**不得**用 C4 N1 作依据（见 §6.10） | C3 + C4 |
| 阻尼 α≈0.5 | **本链路不需要**（α=1 也收敛，4 次迭代）—— 登记为边界，不充作证据 | C1 相邻门 |
| 拟合/堆叠权重同源 | **精确拟合域内不可检验**（0.02362 vs 0.02317 e⁻）；含噪域内 `control_ivar` 漏入小 2.7–13× | C1 A8b + C5 W1/W2 |
| 末端残差场扣除 | `m_full_frame=1` 时近似 no-op（0.00372 e⁻）—— 登记为边界 | C1 A9 |

### 5.3 工程结论

稀疏按需求值与稠密表示**数值等价**（3.1e-15）且体积 0.167%、峰值内存更低 ⇒
「按需现场求值」不牺牲正确性（C6）。

## 6. 诚实边界（不得当作证据的部分）

1. **A8b / A9 / 阻尼**：在 `smoothing_lambda=0` 的精确拟合域，per-(frame,cell) 自由加性场
   恰好定解 ⇒ 公共场 M 只是每 cell 的规范选择，子集不变性在 cell 内平凡成立；
   `final_gauge` 是每 cell 一个常数、对所有帧同减，**不能**修复子集依赖。
   因此「权重同源」与「末端扣除」两要素在本实验域内**不可检验**，已如实登记而非充作证据。
2. **W1 噪声项**：`control_ivar` 相对 `uniform` 的 RMS 优势 8.5% < NMC=20 的 MC 误差
   （std 0.698 e⁻）⇒ **不可分辨**；决定性优势只在**偏差漏入**（2.7× / 13×）。
3. **A10 的预测量选择**：横轴用 σ=64 px 一维高通作为「参考面不可表示」的代理，
   是**代理量**而非生产样条的实际零空间；它给出正确的标度关系（slope 0.80），
   但不应被读作精确的样条投影。
4. **C2 的乘性响应是注入的**：低阶多项式 + 正弦高频，非真实平场；
   真实平场残差的功率谱形状不同（C7 只给出量级）。
5. **C7 的覆盖图案是人工施加的**：真实 M42 帧本身不构成条带覆盖；
   接缝度量分布是「真实帧 + 人工覆盖」的混合实验。
6. **C7 R1 的斜率动态范围窄**（~10 ADU）⇒ 不确定度大（0.81–1.32）。
7. **C7 的目检裁图只作互证**，不作为无接缝的科学证据（判据是度量数字）。
8. **Galaxy Center T4 未纳入本版**（时间/范围），故与 VIS-401 的对照只做了 M42 一路。
9. **meta 级门**（W4 状态机、B2 恒等式、**C4 N1 退化反证**）不构成实现验证。
10. **C4 N1 是恒真反证**：退化臂减掉的是逐帧天光**真值**，而注入同时加进 `w["sky"]`，
    二者代数精确抵消 ⇒ 0.09σ 只是噪声。它说明"退化判据的定义"，不是"排除自身参考面必要"
    的经验证据；后者由 C3 B3/B4 与 C4 N2/N3 支撑。
11. **C4 检测器为双边**（|D−mu| > 5σ）；阈值按边界标定，mu=−5.10 e⁻ 本身是真实结构造成的
    系统偏置 ⇒ "样本外假阳性 0/60" 应读作"不把既有的 5 e⁻ 未校正接缝判红"。
12. **C2 M5 的恢复幅度 0.693 是下界**：分块（4 px）估计器对高频有 sinc 衰减、且比值是
    信号加权平均；1% 幅度下**未检出**（3σ 上界 0.069）。
13. **C2 M6 的原判据（Spearman>0.8）实测不成立**（ρ=0.50）：电平接缝沿 y 取中位，
    对 y 向细结构本就不敏感；现判据是"有界"，见 §11 判据变更登记。
14. **C5 W5 的 "stalled" 臂实际跑满 300 轮**，不是真 stall ⇒ FIX-2 目前只有**代码事实**
    （`upm.cpp:1527-1536` 只有 0/1），没有实验证据。
