# DISPUTES · P5 加性天光去除的逐单元裁决

本文件是科学链 P5（`实验/additive-sky-seamless`）的**逐单元裁决落点**。
跨单元裁决 `D-xx` 见 `实验/裁决台账.md`；改变科学正本公式、常数取值或判据口径的部分，
同步件见 `docs/science/DISPUTE_RESOLUTION.md`。

编号 `A-P5-xx` 是条款 ID，不是流水号：条款一经落定即以该 ID 被本单元正文引用，ID 不重排、不回收。
依据只写可核面；对账未给出可核锚的条目写「**依据未给，待补**」，不补造依据。

裁决一律按**现行条款**表述：写「终裁为 X」，不写变更过程。

## 条款清单

### A-P5-01 约化 χ² 的自由度分母

- **冲突**：正本括注称「秩亏时 (n_obs − n_params) 低估 χ²_red」；两路独立判该**方向词相反**。
- **终裁**：**`n_params` 作分母使 χ²_red 高估**（实测 1.0714 / 1.0581），不是低估。
  自由度规则本身正确：真分母取 **`n − r_eff`**（Andrae 式(9) 支持）。正本括注的方向词须订正。
- **依据**：实测 χ²_red 1.0714 / 1.0581（两路独立同判）；Andrae 2010 式(9)（arXiv 全文级）。

### A-P5-02 `ΔC_max = 2.22e-15 ≈ 1 ulp` 的性质

- **冲突**：正本称 `ΔC_max = 2.22e-15 ≈ 1 ulp` 为普适实测值；核验判其为**实现依赖**声明。
- **终裁**：`ΔC_max` 读数是**实现依赖**（朴素累加 fixture 给 **31 ulp**）；
  但门 `rtol = 1e-12` 的**充分性结论不变**。
- **依据**：朴素累加 fixture 实测 31 ulp（与 1 ulp 声明同族、不同实现）。

### A-P5-03 规格文本 §9/§10 判据锚的系统性幻觉

- **冲突**：认为规格文本判据锚可信；终裁判为**系统性**幻觉。
- **终裁**：**规格文本 §9 自校准栅栏与 §10 判据 01/05 整段回炉，不得作修复依据**。
  三路一致核出的失实项：`λ_bend`、`condition_number_max = 1e12`、`α = 0.7` / `β = 2.0` /
  `h_abs_min = 0.01°`、`min_cluster_size = 3`、`support_min` 错位、`rel_step_max = 0.1`、
  IRLS `1e-8`。
- **依据**：三路独立核验（路线 1 判 12 项证伪 vs 3 项证实；路线 2 独立核出上列各项；
  路线 3 逐节内容核实）。

### A-P5-04 方差比对电平阶跃的失明条件

- **冲突**：笼统称「方差比对电平阶跃原理性失明」；终裁要求限定方差定义。
- **终裁**：失明性**依赖方差定义**，条文必须写明：
  1. **逐侧方差成立**（可检出电平阶跃）；左右比形式对**噪声放大亦失明**；
  2. **合并窗口方差以 Δ²/4 泄漏**（实测 `VR_pool = 1.25 / 2.01 / 5.03` @ Δ/σ = 1/2/4）。
  诊断量条文必须写明所用方差定义。
- **依据**：实测 VR_pool 1.25 / 2.01 / 5.03 @ Δ/σ = 1/2/4（两路独立同判）。

### A-P5-05 `f < 1/2` 中位数失明的适用条件

- **冲突**：笼统称 `f < 1/2` 中位数结构性失明。
- **终裁**：**仅在无噪极限成立**。M42 级噪声下 `f = 0.3`、`Δ/L = 5%` 的读数已达
  **1.03e-2**（到门）⇒ 条文须补入该限定条件。
- **依据**：M42 级噪声实测 f = 0.3、Δ/L = 5% ⇒ 读数 1.03e-2（到门）。

### A-P5-06 `w ∝ SNR²` 与逆方差禁令的互斥与幅度

- **冲突**：正本禁令与详细层 `w ∝ SNR²` 互斥（方向成立）；幅度存在 13× 与 18% 两种读数。
- **终裁**：**方向采禁令**（`w ∝ SNR²` 与正本互斥，维持）；**幅度按几何实测取 18%** ——
  本几何下 `snr²` 泄漏仅比 ivar 高 **18%**。**18% 不可迁移**到其他几何。
- **依据**：本几何实测 18%（两路独立给出同一量级）。

### A-P5-07 `zero_anchor_weight = 1e-3` 的「弱」性

- **冲突**：认为该权重取值本身即「弱」。
- **终裁**：`1e-3` 的「弱」性**依赖份额式权重口径**（Σw ≈ 1）；在**绝对 ivar 权重面**下偏置 **100%**。
  引用该值必须**连同权重口径声明**。
- **依据**：两口径对比实测（份额式 vs 绝对 ivar 面偏置 100%）。

### A-P5-08 `H_solve` 恒真门的适用域

- **冲突**：认为该门恒真（恒绿）。
- **终裁**：`λ = τ·mean(diag)` 下**不严格恒绿**（κ ≈ 2.2e10 贴门）；
  **生产 `λs = 0.1·mean(diag)` 域内恒绿**（κ ≈ 23）⇒ 「恒真」的表述**限定生产 λs 域**。
- **依据**：κ ≈ 2.2e10（贴门）与 κ ≈ 23（生产域）两组实测。

### A-P5-09 文献引用的三处订正

- **冲突**：三处引用指向他文或归属错误。
- **终裁**（三处**全部采信**）：
  1. **Padmanabhan 2008** 的 arXiv 号为 **`astro-ph/0703454`**（`0805.2366` 是 LSST 综述）；
  2. **Gruen et al. 2014, PASP 126, 158** 实为 **SWarp 稳健叠加伪迹剔除**，
     **不得**作背景匹配依据（引用面收窄）；
  3. **`δ = 1.345` 归 Holland & Welsch 1977**，不归 Huber 1964。
- **依据**：arXiv 号逐字核对；PASP 126, 158 的实际内容判定（为 SWarp 叠加伪迹剔除）；
  δ 值归属的书目核对（两路独立同判）。

### A-P5-10 `rel_step_max = 0.1` 的身份与处置

- **冲突**：把 `rel_step_max = 0.1` 当作 IRLS 步长上限并列入判据面。
- **终裁**：
  1. **前提改正**：`rel_step_max = 0.1` **不是** IRLS 步长上限 —— 仓库**无此参数**（grep 级证据）；
  2. 按其真实身份（**平滑性诊断**）**不可标定**，且判决规则自不自洽；
  3. **从判据面删除**；如需保留，降级为**无阈值分布报告量**。红位保留在**接缝门 1e-2**。
- **依据**：仓库 grep 级证据（无此参数）；可标定性实测 —— `B0 = 5` 假红 45–60%、`B0 = 1000` 永不红；
  「> 20% 判红」对局部缺陷结构性失明（单节点缺陷 ≤ 4/112 邻对；规格自带 ×10 注入实测不红）；
  灵敏度比接缝门松 20×。

### A-P5-11 `×5.07` 端点比

- **冲突**：以 `×5.07` 作为端点比写入条文。
- **终裁**：**`×5.07` 端点比不复现**（端点比是实现条件依赖）。跨实现稳健的是
  **峰值/长尺度比 ≈ 8** 与**肘点**，以及**非单调形状**。三处条文按
  「峰值/长尺度比 ≈ 8」改写。
- **依据**：同口径复算 2.95（带噪）/ 2.43（无噪）/ gauge 1.78 / RMS 1.71（均不复现 5.07）；
  峰值/长尺度比 ≈ 8（8.03 vs 8.02 / 9.21）；肘点 `s ≲ 2h` 与非单调形状跨实现复现。

### A-P5-12 `quality_factor_initial = 0.5` 的归类

- **冲突**：把该值列为科学量「五件套常数」；两路同判其为**归一化规范**。
- **终裁**：**`quality_factor_initial = 0.5` 是归一化规范选择，不是科学量**（豁免）。
  基准值精确抵消 `max|Δθ| = 0.0`；真正的科学量是**比值 0.1/0.5** 与
  **share/absolute 口径**（ivar 跨 control 变化时两口径差 **14.8%**）。
- **依据**：基准值精确抵消实测（`max|Δθ| = 0.0`）；两口径差 14.8% 实测（两路同判）。
