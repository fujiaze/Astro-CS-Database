## 1. 公式与渐近域

稀疏控制点定权（SCI-UPM-WEIGHT-001 合同式）：

```
Var(control) = k_corr · (π/2) · σ_bg² / N_retained
```

- 高斯渐近内核在 **N_retained ≥ 65** 时成立（MC 偏差 <2%）[实验:route1/c1_median_variance.py]。
- 渐近核 π/2·σ²/N 是中位数方差的渐近式（Serfling 1980 书目级 [文献]；
  Kendall Vol.1 Example 9.7 二手标注）。
- 均匀/拉普拉斯边际对照 1.91×/0.335×；等相关下中位数敏感度低于均值
  ——按均值标定 k_corr 是近似（简报定量主数）。

## 2. D-07：N=5 三个口径的终裁（方向词订正）

正本原句「N=5 时渐近式**低估**方差 8.5%」方向词错误。终裁（四路一致，无分歧残留）：

> 渐近式 k_corr·(π/2)·σ_bg²/N 在 N=5 对 Var(median) 为**高估 ≈9.5%**（纯公式口径），
> 偏差方向**保守**（权重偏小）；端到端口径（σ_bg 由同 patch MAD 估计）偏差 ≤±1.5%；
> 生产链亮端裁剪臂**低估 1.3–3.2%**。公式本体与 N≥65 适用域（<2%）维持。

**[推导] 腿（精确阶统计量积分）**：N=5 个标准正态的中位数即次序统计量 x₍₃₎，
其密度

```
f₍₃₎(x) = 5!/(2!·2!) · Φ(x)² · (1−Φ(x))² · φ(x)
```

数值积分给出 Var(x₍₃₎) = **0.286834**；渐近式 π/2/5 = **0.314159**。
比值 0.314159/0.286834 = **1.0953** ⇒ 渐近式在 N=5 **高估 9.53%**。

## 3. D-08：k_corr 两因子查表（负责人已批）

### 3.1 身份终裁

k_corr=1.4（声称 MC 1.3883）**不是**普适常数、**不是**可跨几何复现的标定值，而是
**正本标定几何**（源 300″/px、nside=512→412.26″/px、pixfrac=0.8、全 touched patch
N≈225–251、逐实现 MAD 取跨实现中位）专属的**单次 MC 实测值**：受控复现
1.3445 ± 0.0416（16 相位 × 8 seed），range [1.273, 1.425] 含 1.3883（上沿）。
文献腿确认 k_corr 不含于 Fruchter & Hook 2002（全文子串级检索；F&H 唯一定量相关
噪声量 R=σc/σp=1.662 属不同估计量/几何，数值接近属巧合）。

k_corr = k_gauss(N_retained) × k_geo

### 3.3 冻结 1.4 的两端失保守

在其**声明标定域**（pixfrac∈[0.5,1] × 源 [300,600]″/px）内即不保守：
- N=5 端 k_corr(5,紧凑) ≈ 2.05 ± 0.09 ⇒ 1.4 低估 control_variance **32%**
  （标准误低估 14%；空间分散 1.54）；
- 源 583–600″/px 端 k_corr ≈ 2.5–3.0 ⇒ 低估约 **2 倍**。

### 3.4 P5 的引用义务（论文与文档统一）

凡引用 control_variance 公式，必须同时声明：
1. **k_corr 按 k_gauss(N_retained) × k_geo 两因子公式 + (ρ, pixfrac, 帧数/dither, patch 构成) 几何查表**（记号统一见 §3.2 订正）
   （查表 P3 单元承载）；
2. **标定元组**与 **N_retained 档位**（N≤25 时高斯有限样本因子 k_gauss(N) > 1.08 不可忽略；
   N=5 紧凑 patch 须 ≥1.6、分散 1.54）；
3. 几何不匹配时 **fail-closed 拒绝或现场 MC 重标**（秒级，补实验 code/ 可复用）；
4. 原「MC 1.3883」记述改写为「标定几何专属 MC 实测带 1.27–1.43（中心 1.34±0.04），
   1.3883 为该带内一次实现」。
