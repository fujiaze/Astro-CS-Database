# 接缝门 1e-2 的确定性下限 1.0050% —— 推导与实验闭合

**性质**：支撑推导（[推导] 腿），供 REPORT_paper.md §2.3 与 REPORT_experiment.md 引用。
判据与适用域的权威出处：`docs/science/PHASE2_UPM.md` §9a/§17；实验腿：
`code/audit_rework/route1/c3_seam_gate.py`（固化读数 `results/audit_rework/route1/c3_seam_gate.json`）。

## 1. 推导

接缝门的判定统计量 `rel_step` 取**线性差分比**口径（正本定义 `docs/science/PHASE2_UPM.md` §9a：`rel_step(e) = median(img[+d] − img[−d]) / bg(e)`；§17 同）：

```
rel_step = Δ / (L + Δ/2)      （Δ = 左右 patch 背景电平台阶，L = 电平）
```

门 `max|rel_step| ≤ 1e-2` 对应物理电平台阶的**确定性下限**（§17.3 线性硬界）：

```
rel_step = Δ/(L+Δ/2) = 1e-2  ⇒  Δ/L = gate/(1 − gate/2) = 0.0100503…（= 1.0050%）
```

即：无论统计涨落如何，只要线性台阶 **Δ/L ≤ 1.0050% 判绿是确定性的**（非概率行为）。
这 0.5 个千分点的超出量（1.0050% vs 名义 1%）来自 rel_step 分母的 (L+Δ/2) 口径，
不是判据的松弛。

## 3. 适用域声明

门是「**确定性地板 + 统计检出**」的复合判据：Δ/L = 1.00503% 只在梯度项为零时必红。
**三个结构性失效面必须随门一并陈述**（PHASE2_UPM §17.3 适用域声明）：
① 平滑过渡（w/8/16/32 px ⇒ 观察台阶 ×0.50/0.25/0.125 = 2d/w；2% 名义台阶判绿）；
② 反号梯度代数相消（注入 1.005%＋反相梯度 2d·g=Δ ⇒ rel_step 读 0.06% 判绿；无梯度对照 1.09% 判红）；
③ **光滑法向斜坡伪阳（本单元新增登记）**：判据量含梯度项 `rel_step = 2d·ρ + Δ/bg`（ρ = 边界处
**相对**法向斜率），真值无台阶时仍非零 ⇒ ρ ≥ gate/(2d) = **0.25%/px 单独即把判据推过门**；
合成夹具 ρ=0.26%/px ⇒ rel_step = 0.0104 判红（伪阳），ρ=0.10%/px ⇒ rel_step = 0.0040，
而 d 扫描诊断量 rel_step_d4x = 0.0160 已越门 1.6×。纯斜坡 d 扫描比值恒 4、真实台阶恒 1。
证据：`code/seam_gate_gradient_scan.py`（调用生产门本体 edge_metric/gate_decision，seed=20260928，
固化 `results/seam_gate_gradient_scan.json`，20 项断言全绿）。另按台账 A-P5-05 限定：
「f<1/2 中位数结构性失明」仅在**无噪极限**成立；M42 级噪声下 f=0.3、Δ/L=5%
读数已达 1.03e-2（到门）。

## 5. 精度约定

- 接缝门以**左/右 patch** 的 rel_step 计；方差定义必须写明——逐侧方差对阶跃失明成立，
  合并窗口方差以 Δ²/4 泄漏（VR_pool = 1.25/2.01/5.03 @ Δ/σ = 1/2/4，A-P5-04）。
- 检出率区间口径挂 Clopper & Pearson 1934（DOI 10.1093/biomet/26.4.404）[文献]。
- 本推导的 fixture 未含双线性亚像素方差因子与足迹多边形几何（正本 §17.4 实测
  max|rel_step| 相对差 4.5e-3 属该二阶效应）。
