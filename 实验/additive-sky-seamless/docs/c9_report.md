## 0. 一句话结论

**多尺度低频 cS16T20（σ=16px + 高阈 2.0 + 结构保护 mask）最好**：它是唯一在四项上
同时站住的曲面——缝抑制 80%（L1）/82%（L2 真实缝带）、星系核心泄漏 <0.8%、亮星 <0.2%、
云丝 <1%、PN 结 <4%、方差膨胀 <0.04%、真实结构区不动（m42s sup≈0）、代价与样条同量级。
全局平面（a）保信号但缝抑制只有 55–66%，且在真实缝带上 sup 为负（加重缝）；
样条 b32/b64 缝抑制最高（86–99% L1 / 51–66% L2）但云丝泄漏 5.6–5.9%、PN 结 2.5–3.5%，
且在真实结构区大面积吃结构（m42s sup 0.73–0.90，判负）。

## 4. 为什么是 cS16T20：§4 失效边界的解释

REPORT_paper §4：无接缝 ⟺ 帧间差落在公共面表示空间内；肘点 s ≲ 2h；
残余接缝随不可表示分量 RMS 线性增长（斜率 fixture 专属，不迁移）。

- **a 族（全局 1–2 阶）**：表示空间 = 全场多项式。局地缝差（RERUN3 haloU 同窗台阶
  4.24e-05，平面失配 9.17e-05/3.37e-04）**不可表示** ⇒ 残余大（L1 残余 3.2–4.1e⁻，
  L2 真实缝带加重）。§4 在此的预言是“残余大”，实测一致。
- **b 族**：节点 step 即表示基频 h。b64（h=64px）对 8e⁻ 台阶表示能力最强（sup 99%），
  但同一基频把云丝（宽 ~2.5–40px）与 PN 壳层（环宽 ~3px、环径 16px）也表示进去了——
  **表示能力无选择性**：无 mask 的样条分不清“缝差”与“梯度突变信号”，
  靠节点稀疏保护信号的代价是缝也吃不掉（b128 sup 44%），靠节点加密吃缝的代价是
  信号泄漏（b16 云丝 8.6%）。肘点 2h 在此具象化：b128（h=128px，2h=256px=全场）
  台阶相对全场是高频不可表示分量 ⇒ sup 崩盘。
- **c 族（Siril 式）**：表示空间同样是低频（σ=16px ⇒ 2h 类比 ~32px 特征尺度），
  但**选择性来自结构保护 mask**（高阈 veto），不是来自节点稀疏。
  mask 把核心/亮星/云丝/PN 结逐出拟合样本 ⇒ 低频面在信号区由周围天光插值，
  信号保留（云丝 0.8% vs b32 的 5.9%）；缝差不在 mask 内 ⇒ 正常表示（sup 80%/82%）。
  σ 过小（8px）把 PN 壳层（环径 16px ≈ 2σ）当低频吃掉（−5.8%）；
  σ 过大（32px）对局地缝差欠拟合（sup 60%）；阈值过低（0.5）mask 杀伤正常天光样本
  ⇒ 拟合退化（sup 45%）。**σ=16 + 高阈 2.0 是表示能力与选择性的平衡点**。

## 5. 参数推荐

- **推荐**：多尺度低频，σ=16px（本实验网格口径；生产按像素尺度换算为角度，
  实验网格 1.0″/px ⇒ σ≈16″，生产 0.9404″/px 需同角度换算），
  高阈 tolerance=2.0（`median + 2.0×1.4826×MAD` veto，与 Siril `tolerance` 同形态），
  施加语义 `raw − (S − median(S))`（保留 B_ref，与 Siril `+= background_mean` 同构）。
- **可调区间**：σ ∈ [12, 24]px（本网格）；σ 下探至 8 吃 PN 壳（−5.8%），
  σ 上探至 32 缝抑制跌至 60%；阈值 ≥1.5（0.5 即过保护负例 sup 45%）。
- **禁用**：全减背景（degen_full 中位 −1.1e⁻、云丝泄漏 204%，证伪）；
  无保护多尺度（degen_plane PN 结 −33%，证伪低阈/无 mask 的危害）；
  节点 ≥128px 样条（sup 44%，不可表示负例）；阈值 ≤0.5（sup 45%，过保护负例）。
- **代价**：cS16T20 单次拟合 0.023s（256² 场，Python 未优化口径；相对比较有效，
  绝对值不迁移）、有效参数 ~41（相对量级：a 族 3–6、b32 64、b64 16）。
  生产代价需按 tile/帧数另行测算，本实验只给相对排序。

## 6. 诚实边界

1. 合成缝是单场 8e⁻ 台阶（单帧类比），非多帧覆盖缝；斜率/比值不迁移（§4 fixture 专属）。
   可迁移的是排序与机制（表示能力 + mask 选择性）。
2. M2 暗回归绝对值（+3~+12e⁻）含天光梯度欠拟合成分，不作验收阈值用；稳健的是排序。
3. L1 残差对照线本底（−0.03/−1.2e- 两线）含中位噪声与信号翼拾取，只作横向比较，
   新缝风险由 L2 dark/m42s 切块承担。
4. L2 是 1D profile 代理（非逐帧 2D 减法），行为级证据，不证明生产多帧链路；
   拟合排除 guard 带 ±40 列，防循环论证。
5. 方差腿证明“确定性加法不改方差”（恒等式 + MC ±0.3%），RERUN3 slim 无 VARIANCE HDU，
   方差链不动由恒等式承担（与 C8 S4 同口径）。
6. Siril 代码只读（GPL-3.0 不复制），本实验高斯尺度空间为独立实现；行号为引用锚，
   非行为等价声明。
7. 本实验不改生产代码、不构成生产建议；生产接入（逐帧 δ_k + 公共面 B_ref 的具体落点）
   须走变更流程。
