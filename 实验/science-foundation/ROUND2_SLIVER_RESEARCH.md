# 极窄真实叶交叠的独立解析复核

本记录是研究证据，定义以五份 foundation 候选规范为准。没有改旧生产代码、没有改原 A/B 求解器。本轮明确区分数学区域推导、依赖区间库的数值包含、有限输入的实跑结果和真实观测物理假设。

## 1. 新的可解析真值族

在 Nside=1 北 face0 的底顶点取局部 `theta=RA−45°`、`z=sin(dec)`。真实 HEALPix 边界为 `z=k|theta|, k=8/(3pi)`，不是测地四角。令切点 `(45°,0°)` 的 TAN 坐标为 `(X,Y)`，源矩形 `X∈[−h,h], Y∈[d−2h,d]`，所有量按真实 header 的 binary64 值精确定义。

`d<0` 时源全在 z<0，严格无交叠；`d=0` 时仅 `(theta,z)=(0,0)` 接触，交叠面积严格零。`d>0` 时，顶边为

```
ztop(theta) = d cos(theta) / sqrt(1+d² cos²(theta)).
k theta* = ztop(theta*), theta*>0.
a = 2 asin(d sin(theta*) / sqrt(1+d²)) − k theta*².
```

这是对 `dOmega=dtheta dz` 的直接积分。根函数严格递增，二分每个端点用 100 位 `mpmath.iv` 符号确认。另保留一个严格位于交叠内部的小矩形给独立正下界。这里的“区间”依赖库的包含原语，不声称完成机器形式证明。

在 `CD=diag(2°,2°)` 的新四构型中：

| 输入 | 解析真实 a / sr | A 叶0区间 / sr | B 叶0区间 / sr |
|---|---:|---:|---:|
| 严格无交叠 | 0 | [0,0] | [0,0] |
| 纯顶点切触 | 0 | [0,3.901115e−9] | [0,5.810116e−10] |
| 小正交叠 d≈2e−4 | 4.712388704684012e−8 | [2.340669e−8,5.851672e−8] | [4.008980e−8,5.461509e−8] |
| 极窄正交叠 d≈1e−7 | 1.178097245050320e−14 | [0,3.901115e−9] | [0,5.810116e−10] |

每个完整 A/B 各实跑 12001 节点；其他叶的全源误差导致全局 `budget_exhausted`，不能将它写为全几何收敛。结果 `round2_sliver_budget_pilot.json` 与原脚本快照永久保留。`round2_sliver.json` 对这些完全相同的求解记录做解析与科学量再处理，文件显式记录复用证据路径、hash、原求解器 source hash；默认不加 `--reuse-pilot` 也可完整重跑。

对 f=1 的单源积分量 x，`F=a x/Omega` 按 a 和 Omega 区间作有符号传播。极窄例 x=1 时，A 的预测半宽约 `1.6020444e−6 L`，已经小于 `.01 L` 科学容差，可以保留有界未决贡献；它没有被宣布正支持。相同几何 x=±1e12 时，真实 F≈±9.67602424 L，而原 A 半宽约 `1.6020444e6 L`，必须细化或返回科学未收敛。使用上述独立解析精细求解后半宽约 `4.44e−15 L`，才满足相同科学容差。亮度影响极大，不能用统一“面积相对百分比”决定科学可用性。

## 2. 原 tiny_boundary_sliver 的真实答案

原叶282与293是 face4、N=8 的对称下角小三角区域。原 header 不是精确切触。令 `d0=CRVAL2*pi/180`、`h=.03*pi/360`，`theta=|RA|`，真实叶界仍为 `z=k theta`。

源底边有 `t=(sin d0−h cos d0)/(cos d0+h sin d0)`、`zlo=t cos theta/sqrt(1+t² cos² theta)`；源右边有 `A=sin theta−h cos d0 cos theta`、`zright=A/sqrt(A²+(h sin d0)²)`。两源边在 `thetac=atan(h/(cos d0+h sin d0))` 相交。分别二分 `k theta−zlo=0`、`zright−k theta=0` 得 `thetal<thetac<thetau`，积分其分段下包络：

```
a = k(thetau²−thetal²)/2
    − [Ilo(thetac)−Ilo(thetal)]
    − [Iright(thetau)−Iright(thetac)],
Ilo(theta) = asin(t sin theta/sqrt(1+t²)),
Iright(theta) = −asin((cos theta+h cos d0 sin theta)/sqrt(1+h²)).
```

各叶的真实面积区间为

```
[1.7943443981693295e−14, 1.7943443981693300e−14] sr.
```

独立的高精度直接 `mp.quad` 积分被积函数也与解析反导数相符约 80 位；它只是交叉检查，不作为确定包围来源。

`round2_original_sliver_refine.py` 真正再次运行完整旧源：A 请求全源绝对 `1e−11 sr`、15001节点后 `budget_exhausted`，叶282/293各 `[0,4.762103122614453e−13]`；B 请求每叶绝对 `1e−16 sr`，在31941节点实际收敛，各

```
[1.7920708298562244e−14, 1.7966119907953488e−14] sr.
```

B 下界严格正且夹住解析真值，中点真实误差上界约 `2.987844e−20 sr`。同一次正式复算 A 约8.04s、B约39.48s；早先独立试跑 B 约51.73s，时间不能当跨机器承诺。全源 A 的边界预算会花在其他大面积叶上，证明应针对下游量和目标叶分配工作，不能通过调宽全域容差伪装细片已解决。

## 3. C++ 微原型的独立复核范围

独立审查指出原 affine-strip 代码的半径用普通 `(x1−x0)/2`，可能漏掉中点舍入的不对称位移；spill 质量也只在普通多算子运算后扩一次 ulp。主研究员已修为逐算子外包半径/质量，原源码与初始性能记录已保留、撤销其 bound 证据资格。

`round2_affine_independent_review.py` 另用 `CD=.002°` 的天文小像元构型，与上述解析真值和独立 A/B 对拍。它从标准数学定义构造输入，不从原型输出拟合真值。结论和锁定源码身份在对应 JSON。这里仍不是整个 MPFR/GMP/编译器栈的形式认证，也不代表全域性能或真实 HST/M42 模型已通过。

三例中严格无交叠三者均报告叶0精确零；纯切触 C++ 区间 `[0,4.20554e−29] sr`；极窄正交叠解析 `[1.1780972450961583e−14,1.1780972450961587e−14] sr`，C++ 为 `[1.1780971107204457e−14,1.1780973803246274e−14] sr`，A/B 也各有正下界并夹住真值。C++ 在全源绝对宽 `1e−18 sr` 下约3089–3153节点、706–741ms，全部 bounded；A/B 在各12001节点、全源宽 `1e−12 sr` 请求下仍 budget_exhausted。这是苛刻预算的独立微型案例，不应宣称常规数据也都需要约0.7s/像元。

再以 `round2_affine_sip_review.py` 构造全新非对称二阶 SIP：`X=c(u+.07v²),Y=cv`。其行列式恒1且有显式全局多项式逆，所以无 fold。交叠内 `0≤Y≤d`，由区间验证 `h−tan(theta*)−.07 d²/c>0`，可严格证明弯曲侧边不接近该 sliver，故同一解析真值继续适用。这不是将任意 SIP 都假定不改变真值。新 C++/A/B 三者均正且包含独立真值；实际 C++ 区间 `[1.1780789183474861e−14,1.178115571295304e−14] sr`。但 C++ 在8001节点、约1.776s后全源宽仍 `1.2290e−16 sr`，没有满足 `1e−18 sr` 请求，明确 `budget_exhausted`；局部正下界不能冒充全源收敛。输入、side-inactive 下界、三个完整求解结果与源码身份保存在独立 JSON。

## 4. 最终候选、索引与按叶预算复核

Windows `long` 的32位范围不足以容纳 N=2²⁹ 的 `4*N`、`5*N`。候选数量的直接乘积也会溢出。研究员已改 int64_t 与除法上限检查，并精确排除赤道区 `|j−k|>N` 的不可能格，防止给松包围的无效组合分配伪叶索引。最终源码 hash 为 `8406ca359565b4e1fe2842b4d71032140966128ea6d96558c19762edad3dcebd`；各此前输入／范围修正前的源码和评审数据仍独立保存。

`round2_affine_final_recheck.py` 用最终 C++ 再运行上述4个解析输入；A/B 输入和源码 hash 先与保留的完整实跑记录核对，仅复用未改变的 A/B 数据，不声称重新运行它们。C++ 四例的默认面积区间与修候选前逐 bit 相同、都包围解析真值；两个 `*_final.json` 的复用来源、hash 与新 C++ 运行身份均显式记录。旧审核记录仍绑定保存的源码快照。

`round2_high_order_focus_review.py` 另独立检查：

1. **N=2²⁹ 真叶内小像元**：从外部 HEALPix 真叶中心构造 `1e−5 arcsec` TAN方像元，25个独立 WCS/成员点都为叶 `2113689425112565134`。C++ 只需1节点、约250us；其该叶区间包围高精度解析总面积 `2.3504430539097889e−21 sr`。独立 B 也用同一精确归一化 WCS，包围同一解析真值。
2. **N=2²⁹ 巨量候选**：1°源像元在1节点工作预算下不枚举天文数量的叶；返回 `budget_exhausted`、正 all-sky spill 约 `3.0461742e−4 sr`。该 spill 还实际包围解析总面积，无崩溃、溢出或假空支持。所有返回索引都检查属于 `[0,12N²)`。
3. **按叶精度请求**：二阶 SIP tiny例用 `--leaf 0`、`1e−20 sr` 请求，385节点约0.10s，所请求叶正下界与解析真值相容，宽≤请求；其他叶仍保留原始区间，全叶宽约 `5.18e−12 sr`。`bounded` 仅表示明示的该叶预算满足，`focused_leaf=0` 与 `all_leaf_width_sr` 同时报告，绝不能解释为全源收敛。

还找到一个输入身份反例：`WCS(Header(dict))` 的 FITS 卡序列化把 `2.777777777777778e−9` 写成 `2.77777777777777E−9`，再由 WCSLIB 解析，改变 CD 原 binary64 值约3e−15相对。极紧误差时，这足以让两个**不同输入模型**的区间不交。初始现象与脚本快照保留在 `round2_high_order_focus_header_serialization_failure.json`；最终对照通过公共 WCS 字段直接赋值，先确认 CD 与 C++ 输入逐 bit 一致，再验证 B 和解析真值。不得把卡序列化前的内存数值与解析后的 WCS 假称同一个严格数学模型。

## 5. 输入数值域与资源上限负例

独立构造近奇异 CD `[[1.740755848013471,.819144672764259],[1.9137791654017695,.9005639762607065]] deg/pixel`，精确 binary64 行列式约 `4.635139105904548e−16 deg²` 为正，但 binary64 区间行列式跨零。旧原型假定 `−det_interval` 总能代表负号分支的 absdet，导致全源面积上界约 `1.304321448e−21 sr` 小于独立高精度 spherical-triangle 真值 `1.4115048601862064e−19 sr`。旧运行是 `budget_exhausted`，**不是假报收敛**；缺陷是连资源耗尽后的 bound 都没有包含真值。

`round2_cd_domain_underbound.json` 和原源码保留，最终 `round2_cd_domain_review.json` 确认此输入明确 `returncode=2 / unsupported_cd_determinant_sign`。拒绝含义是该精度下无法证明 CD 非奇异，不是数学上矩阵必奇异。上游 WcsModel 必须提供同一数值精度下的准入证书。

`round2_numeric_admission_review.py/json` 实际验证 NaN CD、NaN pixfrac、超 TAN 数值域、未能通过 SIP 单射充分条件、超范围赤纬均返回具名拒绝。cache 开启且 `max_nodes=1` 时，最终原型实测只处理1节点、0次额外 retry；不能将 cache 试探悄悄排除在工作预算之外。上述是有限负例，不声称通用文本解析器或全 C++ 栈形式验证。

## 6. 可执行高精度 fallback 的独立复核

`round2_mp_affine_fallback.py` 是另外实际执行的任意精度条带算法，scope 仅限本记录明确的 Nside1/leaf0、45°赤道切点、等对角 CD、可选二阶 shear。其余叶约束通过整域 `−1<fminus`、`fplus<1`、`|z|<2/3` 的区间证明确实不活跃；目标仍是真叶，不是四角替代。

独立审查确认：局部区间端点转为精确 Fraction；多边形裁剪和面积／一阶矩均精确；对梯度的包含型均值余项覆盖整块；块面积结果以精确整数 floor/ceil 外包到共用 `2^−256` 格，再作精确总账和停止判定。没有在误差决定之前把端点回转 double。独立100个正负有理区间核查外包及额外宽度 `<2*2^−256`，未见违反。

归一化 A 也有独立包含积分。为避免同代码自证，本复核进一步在 u 方向使用密度的解析反导数，将 A 化为不同的一维积分：

```
k=CD*pi/180, t=u+q*v², D=1+k²v²,
integral_u g du = k² t/[D sqrt(D+k²t²)].
```

70位、110位直接求积相符（绝对差 `<1e−75 sr`），TAN／SIP 两个独立 A 值都落在候选报告的 A 区间内。这只是高精度数值核查；确定界仍来自声明的包含算法前提。

`round2_mp_fallback_independent_review.py/json` 实际重跑 TAN 精细解，仅33节点；SIP 的14089节点昂贵解只读取并逐文件核对 source hashes，明确不声称由本复核重新运行。两者的目标 sliver 区间都包含独立解析真值。对 `x=±1e12 L`：TAN 与 SIP 的独立真通量中点误差分别约 `.00029828057` 与 `.00000993298 L`，均小于各自预测界 `.0022216194`／`.0025752145 L`，也均小于 `.01 L` 科学目标。此结果闭合了“高对比 tiny 边缘不可忽略时实际继续细化”的可执行例子，而不是仅调用解析答案替代待研究的求解器。
