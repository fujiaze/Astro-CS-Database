# 新 Export reference 的独立数值闭环

本记录执行新的科学参考消费者，不是旧生产 Export 的端到端验收，也没有修改其 C++。脚本 [export_independent.py](../oracles/export_independent.py)，结果 [export_independent.json](export_independent.json)，4 个面积接口结果另存在 [export_overlap_cache.json](export_overlap_cache.json)，复算统计与协方差可直接复用。

## 定义与独立真值

真实 HEALPix 叶 p 内的信号是常数 `I_p`，单位 L/sr。目标像元 j 的实际球面像 `W(Q_j)` 与叶 p 的真实交叠面积是 `a_jp`。显式支持集合 `S` 决定哪些叶有观测，零信号叶仍可有效支持：

`D_j=Σ_{p∈S}a_jp [sr]`，`F_j=Σ_{p∈S}a_jp I_p [L]`，`μ_j=F_j/D_j [L/sr]`。

`μ` 是支持域内的面积均值；缺覆盖不能以零补满整个像元。`D=0` 时均值未定义，JSON 返回 null。支持积分 F 与支持均值 μ 是不同估计量，不能互换。

被测接口使用 `chart_overlap.solve_overlap` 的逐叶面积包含区间，消费者按信号正负用包含算术传播分子、分母与比值。四个目标像元为 2×2 偶数尺寸图，CRPIX=(1.37,1.12)，CRVAL=(359.8°,5.2°)，镜像非对角 CD；7 个叶包含 −2、0、+3 L/sr。相同面积表分别用于全支持和部分支持，未重复求几何。

独立真值每像元抽取 1,000,000 个 detector 均匀点，使用 Astropy 完整 `all_pix2world(origin=0)` 与 astropy-healpix 天球成员；未调用 A 的分类、面积积分或 Jacobian。无 SIP 的 TAN 密度独立写为

`g(q)=|det(CD_rad)|/(1+ξ_rad²+η_rad²)^(3/2)`。

其整个像元的解析上界 `M=|det(CD_rad)|` 由独立包含算术向外取值。单个样本分母 `g1_S∈[0,M]`、分子 `gI1_S∈[−2M,3M]`。设 `η=√[log(2K/δ)/(2n)]`，Hoeffding 半宽分别为 `Mη`、`5Mη`。对四像元、两支持集合、分子/分母共 K=16 个量取 Bonferroni，联合失败概率至多 δ=10⁻⁶；分母下界为正时以比值区间传播均值。统计一致性不是确定性的逐叶几何证明，外部浮点 WCS/成员库的精度仍是数值假设。

## 实测结果

- 4 份面积接口结果均达到声明的总未决面积界 `3×10⁻⁴ sr`，分别处理约 7900–8100 个节点；几何区间完整保留。最初要求 `2×10⁻⁵ sr` 的尝试有像元在 60000 节点内未满足预算，失败及证据限制保存在 [失败记录](export_initial_precision_failed.json)，没有将其记为通过。
- 四百万个独立点的全支持/部分支持面积、积分与均值置信区间，全部与参考区间相交。
- 部分支持像元 (0,1) 的中点支持面积比例约 30.08%。支持域内只有 −2 信号，所以正确均值是 −2 L/sr；误用全像元面积作分母得到 −0.6015 L/sr，直接暴露缺覆盖稀释。
- 零信号仍作为全支持模式下的有效观测进入分母；空支持边界返回 null 均值，没有制造信号或精度。

## 同一算子的协方差

固定几何中点时，均值算子 `R_jp=a_jp/D_j`，积分算子 `T_jp=a_jp`。若输入叶协方差为 `C [L²/sr²]`，则均值协方差 `RCRᵀ [L²/sr²]`、积分协方差 `TCTᵀ [L²]`。几何区间误差另保留，未伪装成已包含在 C 的随机误差。

验证使用正定小矩阵 C（非均匀对角噪声加共享秩一项）。将每个同叶系数人为拆成 0.35/0.65 两条记录，再按叶身份合并；矩阵传播与逐记录双和相差至多 `5.55×10⁻¹⁷`。200000 次独立 Gaussian 实现的样本输出协方差，相对其解析抽样标准误的最大差为 2.36。若错误地把同叶两条贡献当独立噪声，白噪声方差会乘 `0.35²+0.65²=0.545`，是可直接复算的反例。

## 结论边界

**INDEPENDENTLY_TESTED**：此有限构型的新 Export reference、区间传播、独立统计比较与固定同一算子的协方差。

**ASSUMPTION**：输入真实叶内可视为分段常数、单位/科学响应兼容、C 是具有指定来源的有效输入协方差；不存在未表达的叶内结构。

**REQUIRES_REAL_DATA**：真实 HST/M42 的 PSF/响应、细尺度天空结构、天测不确定度、实际协方差校准，以及旧或新生产 Export 的完整执行。研究 Agent 的这些自检不构成最终独立验收。
