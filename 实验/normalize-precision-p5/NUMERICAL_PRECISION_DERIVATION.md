# 参考精度数值误差的集中推导问题

本记录由前台整理问题，并集中请求一次数学复核。审查代码基线为 f41cc1c2b；未在此运行产品或数值实验。正式定义来自[噪声正本](../../docs/science/noise_snr/NOISE_SNR.md)与[PSF 正本](../../docs/science/psf/PSF.md)，已有实现复核见[第二批独立复核](ROUND2_INDEPENDENT_REVIEW_633FFC31.md)。这里不改变参考源、输出产品或阶段二权重。

## 问题一：数值子空间误差怎样影响通量信息

固定完整观测域、源协方差 D>0 和源设计 A=[P,Z]。Q=R D^(1/2)，W=D^(-1/2)A，J 是 Q 行空间的正交投影，信息矩阵为 WᵀJW。在正交行空间基中，通量列为 t、背景列为 Z_w，通量信息 I=‖(I−Π_Z)t‖²，V_F=1/I。

生产 `sparse_reference.cpp` 的 PivotedQr 对 Qᵀ 作列主元 Householder QR，以最大残余列范数相对初始最大列范数截断；随后以 ‖t‖²−Σ(tᵀq_i)² 算 I。程序同时用同一个 rel_tol 判断 I>rel_tol‖t‖²，主元范数比平方作为条件估计。源码位置为 `lib/algorithms/noise_snr/cpp/src/sparse_reference.cpp` 的 PivotedQr 与 complete_spherical_reference。

已知结论不需重复证明：QR 主元门限不是奇异值门限；Gram 的特征值尺度是奇异值平方；直接相减存在消去误差；主元比平方不是谱条件数。需要进一步推导：

1. 给出最小解析反例，说明仅有 ‖δQ‖ 很小不能保证 I 或 V_F 相对误差很小，尤其涉及秩截断和通量接近背景空间时。
2. 若已获得通量残差算子的误差界 ‖δE‖≤ε，E=(I−Π_Z)J 在源白化坐标表达，或采用等价投影表示，推导 I、V_F、SNR 的可复核绝对/相对误差界，并明确维数与固定量。若 E 写法需调整，先纠正再推导。
3. 说明可辨识性阈值、Q 的秩阈值和允许的相对精度为何要分开；给出基于残差范数和误差上界的数值可信条件，不提出无依据通用常数。

## 问题二：像元积分自检怎样连接到参考精度

单位总通量椭圆 Moffat4 密度 p(x)=3(1+xᵀMx)^(-4)/(2πs_xs_y)，P_j=∫pixel_j p。生产采用固定阶张量 Gauss–Legendre，order=n 与 n+1 的逐像元最大绝对差记录为 estimated_error；相关实现是 `lib/algorithms/psf/src/pixel_integrated_psf.cpp::pixel_integrated_moffat4_profile`。没有给任意 s_min、相位、椭率规定一个已验证的统一下界或上界域。

1. 对固定有限节点集合，构造 s_x=s_y→0、中心在像元内部且避开两阶全部求积节点的反例，判断两阶差趋零是否能与真实像元积分趋1同时发生。区分数学反例与已经测得的生产失败。
2. 固定 R、背景空间和 C，若模板误差为 δh=RδP，推导通量残差信息与 SNR 的误差控制条件；说明只有逐像元最大差时还缺哪些量才能得到整体保证。
3. 若 C 本身包含与 P 成比例的冻结源泊松项，给出同时控制模板与协方差误差的充分条件，例如相对 Loewner 界或白化算子范数界；明确不能将固定 C 的结果直接套入 C(P) 的情况。

## 推导复核结果

同一批请求首次因传输中断无返回，重试后收到 Astra 的代数推导。前台逐式复核下列投影、反例与不等式后收录；没有读数测量、产品执行或实验通过结论。这里只证明所列条件下的数学关系，不提供生产误差证书。

### 1. 统一源空间中的残差投影

令源白化空间维数为 m，Q∈R^(k×m)，w=D^(-1/2)P∈R^m，B=D^(-1/2)Z∈R^(m×b)。必须先将背景投影到保留行空间：
\[
 J=\Pi_{\operatorname{range}(Q^T)},\quad
 \Pi=\Pi_{\operatorname{range}(JB)},\quad
 E=(I_m-\Pi)J=J-\Pi,\quad I=\|Ew\|_2^2.
\]
不能把未投影的 range(B) 直接放进 Π。因为 range(JB)⊂range(J)，JΠ=ΠJ=Π，故 E 对称且 E²=E，是同一 m 维空间中的正交投影。取行空间基 U∈R^(m×r)，等价地 E=U(I_r−Π_range(UᵀB))Uᵀ。即使两次计算保留秩不同，也能在这个共同源空间比较算子。

两个最小构型说明小矩阵扰动没有无条件的相对信息保证：

- 无背景、w=e₂，Q_ε=diag(1,ε)，Q₀=diag(1,0)。矩阵差范数为 ε→0，但 ε>0 时 I_ε=1，I₀=0；删去小奇异方向可以丢掉全部通量信息。
- 固定 m=3、B=e₁、w=e₁+e₃，令 Q_θ 两行为 e₁ᵀ 和 (cosθ e₂+sinθ e₃)ᵀ。非零奇异值恒为1，但 I_θ=sin²θ。比较 Q_θ 与 Q_(θ²)，矩阵差趋零，I_(θ²)/I_θ→0，V_(θ²)/V_θ→∞。这次秩和非零奇异谱稳定，退化来自投影通量趋近背景空间。

### 2. 残差误差到信息、方差及 SNR

固定 w，若已证明 ‖Ê−E‖₂≤ε，记 a=‖Ew‖₂、d=ε‖w‖₂。反三角不等式给出
\[
 (\max(0,a-d))^2\le\widehat I\le(a+d)^2,
 \qquad |\widehat I-I|\le2ad+d^2.
\]
当 a>0、η=d/a<1，固定非零参考通量并令 S=|F_ref|√I，有
\[
 (1-\eta)^2\le\widehat I/I\le(1+\eta)^2,
 \quad (1+\eta)^{-2}\le\widehat V/V\le(1-\eta)^{-2},
 \quad 1-\eta\le\widehat S/S\le1+\eta.
\]
相对误差上界分别为 2η+η²、(1−η)^(-2)−1、η。模板也变化时，可取 d≤ε‖w‖₂+‖Ê‖₂‖δw‖₂。该界包含全部残差误差时才有数值意义；小 δQ 并不自动提供小 ε，Q 和 JB 的相关秩稳定性仍须另证。

后验地，若算得 â，且 d 是包含浮点计算误差的有效界，则 a∈[max(0,â−d),â+d]。â>d 才能由该界证明信息严格为正；再传播区间到 V、S，判断是否满足指定精度。观测秩截断、通量可辨识性与允许相对误差是三个不同问题，不共用未经论证的常数。

### 3. 两阶求积同时漏掉窄核

取像元内部中心 c，避开两阶全部有限求积节点，圆形单位总通量密度为
\[
 p_s(x)=\frac3{2\pi s^2}
 \left(1+\frac{\|x-c\|^2}{2s^2}\right)^{-4}.
\]
一般椭圆形式中的 M 需满足 detM=1/(4s_x²s_y²)，不能独立指定 M 与归一化系数。有限节点与 c 的最小距离严格为正，每个节点的密度为 O(s⁶)，故两个固定阶数的求积值及其差均趋零。另一方面，取包含在像元内、以 c 为中心的半径 ρ>0 的圆，有
\[
 0\le1-P_{\rm pixel}
 \le\left(1+\frac{\rho^2}{2s^2}\right)^{-3}\longrightarrow0.
\]
因此真实像元积分趋1，两阶自检差趋0，而两阶的实际绝对误差都趋1。这是有限节点指标缺乏全域保证的严格反例，不声称已在生产输入复现；限定宽度、相位、椭率有效域后仍可另外验证该域。

### 4. 固定协方差下的模板误差

固定 R、正定输出 C 与输出背景 H，定义
\[
 K=(I-\Pi_{\operatorname{range}(C^{-1/2}H)})C^{-1/2},
 \quad h=RP,\quad a=\|Kh\|_2.
\]
若 ‖KRδP‖₂≤d，直接使用上一节 η=d/a 的全部界。若确有真实逐像元误差界 ‖δP‖∞≤e，输入有 N 个像元，则
\[
 d\le\|KR\|_{\infty\to2}e
 \le\|KR\|_2\sqrt N\,e.
\]
两阶最大差不是这里的 e。整体保证还需真实积分误差界、完整像元集合与窗外截断处理、传播算子尺度及 a 的正下界；不能假定误差自行抵消。这控制条件信息的数值变化，不是模板失配后通量估计偏差的独立上界。

### 5. 模板与冻结源泊松协方差同时变化

若协方差也变化，要求共同正定观测支持，并有
\[
 \|C^{-1/2}(\widehat C-C)C^{-1/2}\|_2\le\gamma<1,
 \quad (1-\gamma)C\preceq\widehat C\preceq(1+\gamma)C.
\]
用原 C 下的模板误差控制 η=d/a<1。由
\[
 I(h,C)=\min_\beta(h-H\beta)^TC^{-1}(h-H\beta)
\]
及 Loewner 序的逆序性质，对每个 β 成立的二次型界取最小，得到
\[
 L=\frac{(1-\eta)^2}{1+\gamma}
 \le\widehat I/I\le
 U=\frac{(1+\eta)^2}{1-\gamma}.
\]
于是 V̂/V∈[1/U,1/L]，Ŝ/S∈[√L,√U]；允许白化后的背景投影随协方差改变。示例单位约定下若 C(P)=C₀+F₀R diag(P)Rᵀ、固定 F₀≥0，则
\[
 \gamma\le F_0\|C^{-1/2}R\|_2^2\|\delta P\|_\infty.
\]
实际 gain/标度存在时要在对应源方差算子中保留，不能将此简化示例直接作生产公式。支持或秩改变时以上正定界不适用，须在共同支持重推或处理精确约束。所有界都依赖有效的 d、γ；本记录没有替生产实现测出它们。
