本轮唯一既有红项 `quantization.s12.statistic_vs_spec_threshold`（p95
`0.0194794437321 > 0.018`，超界 1.08×）已定位为**测试规格 / 总体不匹配**，
不是量化实现缺陷；门限值未改。

## 1. 红项与判据全貌

- 夹具：固定种子 `20260906`，4096 条 × 343 样本 = 1,404,928 个残差；`flux_min = 0`
  （相对残差最坏情形），通量在 `[0, 255·Δ]` 均匀。

  `median = 1/510`、`p95 = 1/51 = 0.0196078…`；该用例**通过**。
- 阈值层（本次红项）：把 `GAIA_QUERY.md §2.9.1` 的真实星表读数
  `median 0.21% / p95 1.8%` 当门限，对上面这个最坏夹具逐项判 ⇒ p95 越界。

## 2. 独立证据（`code/verify_round7_quantization_s12.py`）

### A. 闭式核算：编码器与推导一致（无缺陷）

| 量 | 实测 | 解析闭式 | 偏差 | 3σ 分位数容差 |
|---|---|---|---|---|
| median | 0.0019583508 | 1/510 = 0.0019607843 | 2.43e-6 | 4.96e-6 |
| p95 | 0.0194794437 | 1/51 = 0.0196078431 | 1.28e-4 | 2.16e-4 |

两项都在事前冻结的 3σ 渐近分位数容差内 ⇒ 8-bit 编码/解码按设计工作。
同时，夹具的**精确** p95 = 1.9608% 比门限 1.8% 高 8.93% ⇒ 该门限在这个夹具上
**按构造不可满足**。

### B. 总体敏感性：1.8% 是总体相关读数

同一编码器、不同 `flux_min/Δ`（真实 DR3SP 星表的 `flux_min > 0`）：

| flux_min/Δ | median | p95 | ≤1.8%? |
|---|---|---|---|
| 0.0 | 0.00196186 | 0.01958916 | NO |
| 0.5 | 0.00195277 | 0.01895252 | NO |
| 1.0 | 0.00194694 | 0.01826322 | NO |
| 2.0 | 0.00193130 | 0.01713710 | yes |
| 5.0 | 0.00188885 | 0.01433146 | yes |
| 50.0 | 0.00140848 | 0.00497005 | yes |

由解析 CDF 反解：`p95 = 0.018` 对应 `flux_min/Δ ≈ 1.144`。另外，零 `flux_min`
但通量分布偏向高码（`sqrt` 偏斜）时 p95 = 0.00506 ≤ 1.8%。
⇒ 读数取决于总体（`flux_min` 与通量分布），**不是夹具无关的上界**。

## 3. 订正（不放宽门限）

`tolerances.GAIA_QUANT`（`median 0.0021 / p95 0.018`）**保持冻结**不动；修改的是
测试规格，使比较同总体：

1. 在测试文件内新增独立解析 CDF `_s12_closed_form_p(m, x)`（含 `flux_min = mΔ`
   的一般情形）与 `_s12_min_flux_floor_for_p95(target)`（对解析 CDF 二分反解
   `m*`，不调用被测编码器）；
2. 用例 `quantization.s12.statistic_vs_spec_threshold` 分两层断言：
   - **(1) 最坏夹具**：`|p95_A − 1/51| ≤ 3σ` —— 编码器与其精确闭式一致；
     并把 `p95_A > 1.8%` 作为「门限不适用」的具名反例登记进 evidence；
   - **(2) 门限适用总体**：`flux_min = m*·Δ` 时断言
     `median ≤ 0.0021` 且 `p95 ≤ 0.018`（门限原值），即门限在其总体条件下成立。
3. 用例的 `intent`/`expected`/`source` 写明总体条件与证据路径。

结果：单元层 `160 通过 / 0 红`（改动前 159/160），且未触碰任何门限数值。
