## 2. 光度标定（一手，非反推）

`PHOTFLAM` / `PHOTPLAM` 是 STScI 发布的**一手绝对流量标定**，直接给出星等零点：

```
ZP_ST = -2.5*log10(PHOTFLAM) + PHOTZPT            (PHOTZPT = -21.10，头内自洽)
ZP_AB = -2.5*log10(PHOTFLAM) - 5*log10(PHOTPLAM) - 2.408
m_AB  = -2.5*log10(rate_e_per_s) + ZP_AB
```

| 波段 | ZP_AB | ZP_ST | 20 等星速率 | 25 等星速率 |
|---|---|---|---|---|
| F657N | 22.6350 | 23.0297 | 11.32 e/s | 0.1132 e/s |
| F673N | 22.5649 | 23.0245 | 10.62 e/s | 0.1062 e/s |
| F502N | 22.2889 | 22.0960 | 8.233 e/s | 0.08233 e/s |

（`zp_ab_from_st` 独立换算与 `zp_ab` 互校：F657N 22.63506 vs 22.63501，差 5e-5 等，
已在 `m16_scene.py --selftest` 的 V1 判据中锁死。）

> **禁止**用 `k = g·h·c·λ/(A·t)` 之类物理闭合式反推口径/增益（`GAP_AUDIT` §9.42）。
> 上表全部来自头部关键字，是**定义式**，不含任何仪器参数闭合。

## 3. 有效域掩膜（判据与统计）

位标志（`<band>_flags.fits`，uint8）：

| 位 | 名称 | 判据 | 是否置无效 |
|---|---|---|---|
| 0 (1) | NONFINITE | NaN / Inf | ✅ |
| 1 (2) | ZERO | 值 == 0.0 | ✅ |
| 2 (4) | NEGATIVE | 值 < 0 | ✅ |
| 3 (8) | EDGE | 与画幅边框 **4-连通**的 (ZERO\|NONFINITE) 连通域 | ✅ |
| 4 (16) | EXTREME_NEG | `v < bg − 20·σ_blk`（64 px 块稳健 MAD） | ✅ |
| 5 (32) | SPIKE | `(v−bg) > 10·σ_blk` 且 `(v−max8)/(v−bg) > 0.80` | ❌ **仅标记** |

`valid = 1` ⟺ 前五位全 0。

| 统计 | F657N | F673N | F502N |
|---|---|---|---|
| 有效域占比 | **0.89748** | **0.89748** | **0.89755** |
| zero（含边缘无覆盖） | 10.2504% | 10.2486% | 10.2443% |
| 非有限值 | 0.000% | 0.000% | 0.000% |
| 负值 | 0.00148% | 0.00382% | 0.00071% |
| **画幅内部** zero 像素 | **0** | **0** | **0** |
| 最外 1 px 边框 zero | 85.04% | 85.02% | 85.04% |
| 最大全有效**足迹矩形** | 7637×7050 | 7636×7050 | 7637×7051 |
| SPIKE（可疑，未剔除） | 185 | 305 | 328 |
| EXTREME_NEG（互斥归因） | 91 | 0 | 0 |

**EDGE 的定义与实测**：三帧的零填充构成**单一**与边框连通的连通域
（`n_edge_components_touching_border = 1`），即**一整块旋转（ORIENTAT = −35°）的
WFC3/UVIS 双芯片足迹之外的区域** —— 与「拼接边界」一致；零像素 100% 落在该连通域内，
画幅内部**没有任何零像素**，故 `EDGE` 与 `ZERO` 在计数上重合（互斥归因把全部
6,884,155 个零像素记在 `ZERO` 名下）。

⇒ **SPIKE 检出的主体是逐帧瞬变**（宇宙线幸存者 / 瞬变热像素），**不是**固定坏点图样；
这三帧上的固定坏点至多 **1** 个像素。

**极端负值**：F657N 最负 −444,234 e/s、F502N −7,578 e/s、F673N −0.0159 e/s；
全部位于**画幅内部**（距边框 145–2789 px），**不是**拼接边缘效应 ⇒
判为 drizzle 权重/CR 残差的灾难性离群，由 `EXTREME_NEG` 位剔除。

## 5. 使用边界（必须随用随声明）

1. **只有 SCI HDU**（PrimaryHDU 单 HDU，1437 张头卡）：**没有** `_wht` 权重帧、
   **没有** DQ 帧（头里 `D001OUWE` 指向的 wht 文件未随数据提供）
   ⇒ 覆盖信息只能由**零值几何反推**，无法区分「无覆盖的零」与「真零通量」；
2. **drz 合成品**（NDRIZIM=32，`D001OUUN = cps`）：噪声已被 32 次曝光 + drizzle
   压低并**相关化**，**不是**独立泊松样本 ⇒
   **只能当结构模板**，噪声必须按 §9.41 前向重建；**不得**用本数据标定噪声相关长度类判据；
3. **SPIKE 判据是坏点下界**：在星云丝状结构上 σ_blk 被结构抬高 ⇒ 灵敏度下降；
4. 掩膜对「星云真实的零通量像素」会**过度剔除**（保守方向，安全）；
5. **不做物理闭合反推**（§9.42）：`PHOTFLAM` 只用于建立**星等尺度**。
