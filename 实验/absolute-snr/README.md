## 0. 一句话结论

**帧级 SNR = F_signal/σ_F 在物理 Monte Carlo 真值下成立（26+29 个扫描点全部落在 3σ 内），天光只经散粒噪声进 σ_F：固定源通量抬升天光时 SNR 单调下降、天光主导段 log-log 斜率 −0.49/−0.50（理论 −1/2）、B=10⁶ e⁻/px 时降到 B=0 的 2.1%（亮源）/1.1%（暗源），而"信号含天光"的传统口径在同一天光范围内上升 3 个数量级（失真判红）。**

三口径没有全局最优：地面视宁度受限真实数据上 dense(P=32) 最准、sparse(Δ=64) 全部胜出帧级标量（0.041–0.083 vs 0.051–0.169）；HST 高对比结构上帧级标量最好（0.0485 vs sparse 0.0994 / dense 0.0896），且 cell 稳健 MAD 偏差随 Δ 从 +0.029 增到 +0.301 dex。稠密口径 4096² 需 **67.11 MB/帧（64 MiB）＝ 1 MiB 预算的 64 倍**，复核"稠密超门"结论成立。

逆方差集成对拍全部通过：`SNR_combined²=ΣSNR_k²`（2.2e-16）、Q/W 对解析解（Var 1275 vs 1260）、拟合权重与堆叠权重分离（用 1/σ² 堆叠含杠杆的拟合值使方差高 52.3%，预测 50.4%；Huber 把 5%×10σ 离群的截距偏差从 0.426 压到 0.084）。

**审查出两处需要登记的问题**：① 生产路径在"经验总 σ_sky（含读噪）+ (RN/g)²"组合下**双计读噪**（σ_F 高估，基准点 +12.8%、最坏 +34.0%，闭式预言与实测臂比值差 ≤1.25 pp）；② EXP-205 的误差预算常数 `c_est=1.44` 被当作 **dex** 阈值使用，而 `NOISE_MODEL.md:86` 的 1.44/√N 是**相对**标准误 ⇒ 噪声项高估 ln10=2.303 倍。二者均已写入 `results/DOC_CORRECTIONS.md`，转 FIX/DOC 处理，本单元不改生产码与噪声文档。

## 2. 方法

### 2.1 物理前向仿真（最高设计 §12.2 第 1/2 类数据）

电子域完整物理链：源 `F_e` 按离散归一化 Moffat4 β=4 轮廓分布 → 与天光 `B`、暗流 `D` 一起做 **Poisson** → 电子域 **Gaussian 读出噪声** RN → 除以增益 `g` 得 ADU（可选量化）。
冻结坐标（声明量，不做物理闭合反推）：`g=1.3 e⁻/ADU`、`RN=10 e⁻`、`D=0.5 e⁻/px`、`σ_PSF=1.5 px`（Moffat4 FWHM=1.230310σ=1.845 px）、61×61 stamp、背景环带 r∈[10,30] px（N_sky=2600）。
每个扫描点 **N_MC=1000 帧**独立实现；真值 = 逐帧最优提取通量 F̂ 的经验散度 `std(F̂)`；定义式 = `F_adu/σ_F^theory`。
`code/sci_b_common.py` 是唯一公共库（仿真、Moffat4 网格、Horne 提取、生产口径镜像、稳健统计、效率损失）。

### 2.2 三条 SNR 口径（本单元操作定义）

| 口径 | 构造 | 用途 |
|---|---|---|
| `dense` | 逐 32 px patch 稳健 MAD σ 场（1.4826×MAD + 5σ×2 裁剪） | 精度基准/论文对照；**存储 67.11 MB/帧** |
| `sparse_reconstruct(Δ)` | Δ×Δ cell 稳健 MAD → 规则网格双线性重建 | **默认**（Δ=64） |
| `frame_reconstruct` | 帧级标量 = patch σ 场中位数（另设"整帧未裁剪 MAD"错误构造作对照） | 单帧级对照 |

评价量：`RMSE(log10 ρ)`（两侧中位数归一）、`level_bias=median log10(σ̂/σ_true)`、**权重效率损失** `E=Var_w/Var_opt−1`（非退化判据：E=0 ⇔ σ̂∝σ_true，全局尺度相消）、存储字节/帧、重建时间。
真实数据面（testdata）用 **1 px 棋盘 hold-out**（`fam=(y+x)%2`；每个 32×32 评价 cell 内恰好 512 个真值像素）：估计量只用族 0 像素、真值只用族 1 像素（零像素重叠），并报告真值自身噪声 `eps_ref=1.166/ln10/√512=0.0224 dex`（1.4826×MAD 的渐近相对标准误 1.166/√N 换算到 dex）与扣除后的 RMSE。

### 2.3 判据与非退化设计（阈值唯一来源 = 解析误差预算或 MC 置信区间）

- 定义式 vs MC：\|z\|≤3（z 用 χ² 的 std 标准误），并要求 95% CI 覆盖率 ≥0.90（多重比较下允许 ≤2/26 点出界）；
- 生产臂 vs MC：`z=(mean(σ̂_arm)−σ_F,mc)/√(SE_arm²+SE_mc²)`；
- 单调性：秩相关 + 相邻 95% CI + 大天光段显著性；
- **真值无效应 ⇒ 度量归零**（代数恒等，仅作回归哨兵，**不计入非退化证据**）：算术常数臂 ΔSNR≡0（6.7e-16；因"扣局部背景"对该变换是解析恒等，判别力≈0）；平坦 σ 场时帧级臂 RMSE≡0；等杠杆拟合时堆叠权重损失≡0；ZP 散度=0 时 F_ref 错配损失≡0；σ̂∝σ_true 或整体乘常数时 E≡0（尺度相消）。
- **双向可假（真正的非退化证据）**：故障注入必须翻红——天光泄漏 β=1e-3、**中位分半 ±10% 乘性偏差**（E 对**均匀**电平误差按设计不敏感）、打乱场、静默降级。
- **缺数据不得当阴性（独立审稿 B1/I4 修正）**：任何 (面,Δ) 臂缺失 ⇒ `skipped=true` 显式记录，并由硬门 `N2_no_arm_skipped` 判红；`delta_star.status ∈ {crossed, no_crossing, not_computed}`，`not_computed` 由 `N3_delta_star_all_computed` 判红。
- **门的证据等级分类**（避免把恒真/定义型门当证据）：① *定义型/代数恒等（哨兵）*：`H1_identity_*`、`H5_identity_*`、`H2_uniform_scale_cancels`、`H2_null_proportional_zero`、`H4_equal_leverage_loss_zero`、`H5_mismatch_zero_spread_zero_loss`、`H3_e11_dex_constant_overestimates`（恒为 ln10）、`G5_arith_null_exact_zero`（判别力≈0）、`G1_strict_monotone_def`（σ_F 对 B 的构造性质）；② *元证据（刻意展示恒真性）*：B6 `H1_tautology_*`；③ *规范转写自检（非实现对拍）*：B6 `H4_*`；④ *MC 收敛检查*：B5 `H1_band_lt_0p10`/`H1_diag_ratio_mc_over_analytic`；⑤ *恒真门（已改名，不作证据）*：`DEGENERATE_flat_field_*`；⑥ *携带数据信息的判据*：其余全部（B1 `G1_emp/G2/G3/G4/G6/G7`、B2 `G1–G5`、B3 `N2/N3` 与各面 RMSE 对比、B4 `H2/H3/H4/H5` 的方差-预言对拍与注入、B5 `H2/H3`、B6 `H2_*_red`）。

### 2.4 数据（三类齐备）

1. **HST 真实信号模板 + 完整物理仿真**：`testdata/HST_M16/hlsp_heritage_hst_wfc3-uvis_m16_f657n_v1_drz.fits`（只读），2048² 中心裁剪，缩放到中位 200 e⁻ 后加天光 200 e⁻/px、暗流、读出噪声与增益；真值 σ 逐像素解析已知（含源泊松项）。
2. **纯解析代数合成**：SE(ℓ) GRF 调制的 σ 场 `σ=10^(s·g)`（ℓ 与 s 由构造已知）+ 异方差高斯噪声；s=0 为"真值无空间效应"负例。
3. **testdata 真实数据**：M42 T2/M1·M2·M4 Red 300 s 三帧（只读），2048² 中心裁剪，hold-out 真值。

## 3. 结果（真实数字 + 不确定度 + 对照）

### 3.1 天光无关性（核心，`results/b1_sky_scan.json`，图 `figs/fig1_sky_scan.png`）

天光扫描 B = 0 … 10⁶ e⁻/px（亮源 F=3000 e⁻；暗源 F=100 e⁻）：

|---|---|---|---|---|---|
| 0 | 43.320 | 43.207 [41.31, 45.10] | 43.337 | 38.467 | 38.89 |
| 10³ | 23.514 | 22.950 [21.94, 23.96] | 23.519 | 22.764 | 105.92 |
| 10⁵ | 2.8805 | 2.9549 [2.825, 3.084] | 2.8804 | 2.8784 | 987.12 |
| 10⁶ | 0.9131 | 0.9082 [0.868, 0.948] | 0.9131 | 0.9148 | 3123.08 |

- **单调下降**：定义式严格单调；MC 秩相关 ρ=−0.956（亮）/ −0.994（暗），p<1e-6；B≥1000 段相邻 CI 不重叠。
- **趋零**：天光主导段 log-log 斜率 **−0.4879（亮）/ −0.4972（暗）**，理论 −1/2（15% 带内）；SNR(10⁶)/SNR(0) = **2.11% / 1.07%**。
- **真值一致性**：定义式与 MC 最大相对偏差 4.4%，最大 \|z\|=2.06（亮）/1.79（暗），95% CI 覆盖 24/26 与 13/13。
- **负例 1（算术常数 +200 ADU、无散粒噪声）**：ΔSNR 最大 **6.7e-16**（机器零）——真值无效应 ⇒ 度量归零。
- **负例 2（传统"信号含天光"）**：单调上升，B=10⁶ 时相对真值 **×3419（亮）/×1.0e5（暗）**；不扣背景的帧级臂 **×8040（亮）/×2.4e5（暗）**。失真方向与幅度都被如实判红。
- **故障注入**：把天光泄漏进信号项 `F_signal += β·b̂·n_pix`，β=1e-3（0.1%）即让单调性门翻红 ⇒ 门有牙齿。
- **背景估计偏差边界**：灵敏度 dF̂/dδB=10.79（=1/ΣP²）；**1% SNR 偏差对应 δB*=2.78 e⁻（解析：1%/(10.789/1000 e⁻)=2.78 e⁻）**，实测在 δB=1 e⁻ 时 −0.02%、δB=3 e⁻ 时 −0.83%，1% 交叉 = 3.44 e⁻ = B=1000 e⁻/px 的 0.28–0.34%。对称环带对**线性天光梯度**一阶不敏感（g 到 30 e⁻/px² 仍 <1%）；环带中心偏 2 px 时 g*=2.01 e⁻/px²。

### 3.2 σ_F 噪声项组成与生产口径对拍（`results/b2_noise_terms.json`）

5 条扫描（读噪 0–50 e⁻、暗流 0–1000 e⁻/px、PSF σ 0.8–5 px、增益 0.5–4 e⁻/ADU、源强 10–10⁴ e⁻）共 29 点：

- **定义式对 MC 真值**：最大 \|z\|=**2.68**，全部 ≤3σ（H2 成立）。
- **天空受限极限**：源泊松项不主导（dominance<5%）的 2 个点上，σ_F 与 `σ_pix/√ΣP²` 最大相对差 **1.08%**。
- **生产 C++ 逐点对拍**：`lib/algorithms/noise_snr/cpp/src/snr_science.cpp` 经 `code/prod_snr_driver.cpp` 直接链接（只读），40 个随机参数点上 snr_optimal/σ_F/孔径 SNR/ΣP²/f_in 与 Python 镜像的最大相对差 **2.24e-14**（容差 1e-12）。
- **发现（登记，不改生产码）**：生产头文件设计意图是 `σ_i²=σ_sky,散粒²+(RN/g)²+F·P_i/g`；但调度器 `module_adapters.cpp:4258` 把**经验空天总 rms**（含读噪，`noise_sigma`）填进 `sigma_sky_adu`，同时 `snr.gain_e_per_adu/read_noise_e` 可配置（`module_adapters.cpp:3944-3945`）⇒ 读噪被加两次。闭式预言 `σ_F(emp+RN)/σ_F(correct)−1` 与实测臂比值最大差 **1.25 pp**；基准点（F=1000 e⁻, B=100, RN=10, g=1.3）σ_F 高估 **+12.8%**（SNR 低估同量级）；最坏点 **+36.6%**（B1 暗源 F=100 e⁻、B=0），B2 的 RN 扫描最坏 +34.0%（RN=50）；天光主导时偏差 <1%（亮源 −0.72%；暗源 −1.29%，3σ 内）。PSF 行路径（`snr_estimator.cpp:83`，gain 未知不加 RN 项）与"天光散粒 σ + RN 项"路径都与真值一致。

### 3.6 退化门审查与 fail-closed（`results/b6_gates_audit.json`，图 `figs/fig3_negatives_gates.png`）

- **恒真门确认**：`RMSE(常数场, 中位归一真值场)` 在数学上等于真值场 `log10` 的中位归一离散度，故 `RMSE ≤ K·s_field`（K=1.25，EXP-205 的 τ_A(frame)）对**任意**真值场恒绿——三种场（平滑 GRF、对抗打乱、平坦）全部绿；对抗打乱场下帧级口径的权重效率损失达 **7.17**（科学上完全不可用）门仍绿 ⇒ **该门不携带信息、不得充当证据**。
- **替代判据（本单元）**：权重效率损失 E。双向可假：无偏 ⇒ E=0 绿；σ̂∝σ_true（纯尺度）⇒ E=0（尺度相消）；+10% 电平偏差 ⇒ E=0.0274 红；打乱场 ⇒ E=0.877 红；平坦场帧级臂 RMSE≡0 归零。
- **误差预算常数单位审查**：`NOISE_MODEL.md:86` 的 `1.44/√N` 是**相对**标准误（实测 N=1024 时相对 SE=0.0362，与 Rousseeuw-Croux 1.166/√N=0.0364 一致；文档常数偏保守 23%）；换算到 dex 应为 `1.44/ln10/√N=0.0195`，而 EXP-205 直接把 1.44 当 dex 常数用（0.045）⇒ **高估 2.303 倍**，其 τ_A 精度门与 τ_B 偏差门相应放宽 2.3 倍（与 EXP-205 自报"偏差门灵敏度不足"一致）。
- **fail-closed 路径语义自检（非实现对拍）**：稀疏层在且有效 ⇒ `sparse_reconstruct`；无稀疏层 ⇒ 按帧级执行但**显式**记 `snr_path_effective=frame_reconstruct` + 计数；稀疏层损坏 ⇒ 显式失败（`FZ-SNR-SPARSE-CORRUPT`）；dense 路径无稠密数据 ⇒ 显式失败；5/5 用例符合预期；**静默降级变体被判红**。**范围声明（按独立审稿 I2 降级）**：`path_state_machine` 是本单元按 `07_noise_snr.md` §4.2 **转写**的状态机，`lib/` 实现侧目前**没有**对应符号（`grep -rn "sparse_reconstruct|snr_path_effective|FZ-SNR" lib/` 无实现命中），因此这只证明"规范转写自洽 + 缺臂可判红"，**不构成对实现的验证**，也不得据此外推实现行为。

## 5. 诚实边界与未决

1. **仿真坐标是声明量**：`g=1.3 e⁻/ADU`、`RN=10 e⁻` 等取自 EXP-205 同口径，不代表任何真实相机；本单元不反解物理参数（符合设计 §2.1）。
2. **真实数据面没有解析真值**：testdata 用 1 px 棋盘 hold-out，真值本身带 0.0224 dex 噪声（1.166/ln10/√512）；校正后的 RMSE 只是"扣掉真值噪声后的上界"，且**没有触零**（见 §3.3 修正后的括号列）——估计量仍高于真值噪声地板。
3. **ℓ 估计量是测量量**：合成面用构造 ℓ（已知），真实面用平面去趋势 ACF 的 1/e 交叉（合成面上系统性偏高 1.3–1.6×）⇒ 真实面的 Δ/ℓ 有该量级系统不确定度；因此本单元以"Δ*（px）+ 机制"陈述边界，Δ/ℓ 只作辅助。
4. **B5 的 Frobenius 比较受 MC 噪声限制**：对角元 0.2% 精确，5×5 带内 7.5%（元素级噪声 √((C_iiC_jj+C_ij²)/(n−1)) 主导）；未做更大 N_MC 的收敛性验证。
5. **Q/W 集成的"公共 PSF 堆叠"对照是保守近似**：未实现真正的卷积/重采样到公共 PSF 的完整流程，只做了"窄帧配宽 PSF"的失配惩罚对照。
6. **双计读噪的结论依赖调用约定**：只有在 `snr.gain_e_per_adu>0` 且 `sigma_sky_adu` 填经验总 rms 时才成立；若上游改为填"天光+暗流散粒"则无偏差（本单元两种口径都测了）。生产默认 gain=0 走 PSF 行路径，不受影响。
7. **EXP-205 的 c_est 单位问题**是文档/实验层面的复算结论，本单元未改 `NOISE_MODEL.md`（不在文件域），已登记 `results/DOC_CORRECTIONS.md`。
