# SCI-B 数据指针（只读声明）

本单元**不新增、不复制、不修改**任何数据文件；全部数据以只读方式引用仓内既有资产，缺件时脚本显式失败（fail-closed），不做静默降级或自动下载。

## 1. HST 真实信号模板（第 1 类：真实模板 + 完整物理前向仿真）

| 项 | 值 |
|---|---|
| 路径 | `testdata/testdata/HST_M16/hlsp_heritage_hst_wfc3-uvis_m16_f657n_v1_drz.fits` |
| 用途 | B3 的 `hst_m16` 面：以真实高对比结构作为 σ 场载体 |

## 2. 纯解析代数合成（第 2 类，含"真值无效应⇒归零"负例）

不依赖任何外部文件，由 `code/sci_b_common.py` 现场生成，seed=20260921：

- B1/B2/B4：电子域 Poisson + Gaussian 读噪 + 可选量化的合成帧（参数逐点声明）；
- B3 `synthetic_grf` 面：SE(ℓ) 高斯随机场调制的 σ 场 `σ(x)=10^(s·g(x))`（ℓ、s 由构造**已知**，作为横轴真值）+ 异方差高斯噪声；`s=0` 即"真值无空间效应"负例（帧级臂 RMSE≡0）。
