## 1. 结论摘要

1. **四臂解析 Oracle 全部跑通**（纯 numpy，不链接生产库）：
   - 臂 A（白噪+光子，背景已知）解析条件方差成立：`sd(F_hat)/sigma_F = 0.9929–1.0095`，
     68/90/95% 覆盖率分别 0.6769–0.6914 / 0.8957–0.9049 / 0.9473–0.9531，
     135 次 Wilson 检验中 5 次不含标称（期望 6.75，符合标称）。
   - 臂 B（自由背景 GLS）代价 `E = 0.0185–0.0816`；用已知背景 σ 标准化自由背景估计时
     **24/24 方向欠覆盖**（16/24 统计显著），符号与先声明方向一致。
   - 臂 C（线性 R 重采样）对角近似在 rho<1.3 显著低估：`E_diag` 最负 **−0.4858**；
     35 个 `E_diag<−1%` 构型中 33 个 68% 覆盖率 Wilson 全落在标称之下。
   - 臂 D（点源 vs 弥散源）两向效率损失闭式对称（最大差 3.6e-15），
     `E = N_ap·Σ_maskP²/(Σ_maskP)² − 1`；`E>10%` 的孔径阈 ≈ 0.5–0.75 FWHM。
2. **`k_corr` 单位已核实**：`scale_arcsec` 是**源（输入）帧像元角尺度 [arcsec/px]**，
   不是输出叶尺度。表轴单位正确，但物理驱动量是尺度比 `rho = 叶/源`，
   而 `kcorr_lookup` **不接收 nside** ⇒ 表隐含固定 `tile_order=0`。
3. **冻结回退值 1.4 在生产真帧几何下不保守**：生产默认帧 `tile_order=9`（叶 0.805″）、
   真帧源尺度 0.9666″/px ⇒ `rho≈0.83`；本独立 MC 给 `k_corr = 2.33`，
   生产球面权重探针给 `2.05–2.06`，均 > 1.4。⇒ 该域标 **`UNCALIBRATED`**，
   不得声称 1.4 是通用保守上界。标定几何（源 300″/px、nside 512）下本模型给
   `k_corr = 1.339`，与记录值 1.3883 相对差 **−3.5%**（模型自校验通过）。
4. **117 星复核已重新测量**（不引用、不乘 2.7928）：自建测光得 **2195** 颗共同星
   （训练 1108 / 留出 1087，不重叠），CRVAL 两两最大 **1.69″**（容差 36″，PASS）。
   实测 `sd(dmag)/median(sigma_analytic) = 3.37`（empirical 口径 2.73）——复现了 2.8–3.4 的量级，
   但**分离显示**：解析 σ 只在暗端（低 SNR）与实测散度相当；亮端由**与 SNR 无关的系统项地板**支配
   （分 SNR 层 `sigma_sys = 0.036–0.070 mag`，全局 0.0485 mag）。
   加入该经验地板后留出集覆盖率 68.27%→**0.861**、90%→**0.944**、95%→**0.960**，`z_rms = 1.028`。
5. **`sparse_snr_layer` 生产者未落地**：消费面存在且被审计夹具跑通过，但 `lib/**` 内
   **无任何生产写点**（`ACSD_SPARSE_SNR_LAYER` 只有读侧），端口注册表 0 命中 ⇒
   生产 Phase1 判 `NOT_IMPLEMENTED`（设计图不得当已落地）。
6. **P3 修复前后 covariance 已对照**：完备性 `epsilon_max` 顶点构型 `3.52e-3 → 1.62e-9`、
   生产几何 `5.69e-7 → 2.86e-11`；但对**噪声协方差**影响极小
   （生产几何权重最大差 3.6e-7、叶方差相对变化 2.3e-10、`k_corr` 相对变化 +0.36%），
   全部小于 P2 MC 对 `k_corr` 的分辨率（2.24%）⇒ **P3 的几何变化不可能被误当成 P2 的随机噪声**；
   反之 P2 的随机噪声也不会伪装成 P3 几何缺陷（后者是确定性、位置局域的）。

### 2.4 臂 D 点源 / 弥散源两种被估量

弥散被估量取孔径内面亮度平均；在同一孔径内重归一 PSF 权重以保证无偏。
`E = N_ap·Σ_maskP²/(Σ_maskP)² − 1`。

| 量 | 分母 | 读数 |
|---|---|---|
| `E(点源权重→弥散)` vs `E(弥散权重→点源)` 的最大差 | 全部构型 | **3.6e-15**（闭式对称，与闭式最大偏差 1.8e-15） |
| `E` 随孔径 | FWHM=1.5/2.0/3.0 px | 0.37→0.72→…（孔径 1.0 FWHM 时 0.72/0.94/0.87） |
| `E>10%` 的孔径阈 | 半径 [FWHM] | **0.5（FWHM 2.0）、0.75（FWHM 1.5/3.0）** |
| 零效应 | 孔径内 PSF 逐位平坦（A_NEA,ap=1） | `E = 0.0`（逐位） |

⇒ 可直接进正本的一句：**以点源最优权重（含 `A_NEA`）当弥散源面亮度合并权重，只在
"孔径内 PSF 近平坦（A_NEA,ap→1）" 时等价；否则有 `N_ap/Σ…−1` 量级的效率损失。**

## 3. `k_corr` 单位、标定域与域外行为（`results/kcorr_units.json`）

### 3.1 单位结论（源码行号证据）

`scale_arcsec` = **源（输入）帧像元角尺度 [arcsec/px]**。链条：

1. `lib/algorithms/drizzle/healpix_drizzle/hp_drizzle_api.cpp:1112-1113`
   `meta.fits_meta["src_pixel_scale_arcsec"] = std::to_string(std::fabs(img.wcs.cd[0]) * 3600.0);`
   —— 输入帧 CD 主元绝对值 × 3600。
2. `astro_sphere_sink.cpp:143-157` 读同一键并 `aio_hips_set_drizzle_provenance(ps, config.pixfrac, scale_arcsec)`；
   `aio_hips_writer.cpp:2096-2101` 写 `ACSD_DRIZZLE_SCALE_ARCSEC`。
3. `sampler.cpp:136-146` 读回同键 → `kcorr_lookup(pf, sc)`；`sampler.cpp:88-94` 注释亦写"源像素角尺度"。
   ⇒ **表轴单位没有错标**（不用改 0.3–0.6，D-05 的红线未被触碰）。

**但结构性问题**：`kcorr_lookup` 只收 `(pixfrac, scale_arcsec)`，不收输出 nside；
而物理驱动量是 `rho = 叶尺度/源尺度`。标定件（`run/P1-CONCURRENCY-CALIB-01/wsrc/.../control_median_mc_test.cpp:47-70`
与 `kcorr_matrix_test.cpp:28-31`）把输出固定在 `NSIDE=512`（叶 412.258″，即 `tile_order=0`），
扫描 `scale∈{300,600}″`、`pixfrac∈{0.5,0.8,1.0}`，N_retained=251 ⇒ 表只对 `tile_order=0` 有效。
冻结常数出处亦同：`k_corr_empirical=1.3883` 是**源 300″/px × nside 512** 的单点 MC。

### 3.2 域外行为 MC（可分离方格模型 + 生产估计量口径）

估计量严格按生产：迭代亮端裁剪（`background_clip_sigma=3.0`、`iters=3`）→ `median` → MAD 尺度，
`k_corr = Var(median)/[(π/2)·E[σ_MAD²]/N_retained]`（`provenance.h:98`）。
窗口取 16×16=256 叶（生产 N_retained=251 的最近邻档）。

| 源尺度 | tile_order=0 (nside 2⁹) | 3 (2¹²) | 5 (2¹⁴) | **9 (2¹⁸)** | 12 (2²¹) |
|---:|---:|---:|---:|---:|---:|
| 0.3″ | 0.999 | 1.036 | 1.015 | 1.169 | 9.404 |
| **0.9666″** | 0.991 | 1.013 | 1.033 | **2.327** | 39.80 |
| 1.0″ | 0.989 | 1.013 | 1.002 | 2.134 | 38.08 |
| 3.0″ | 1.002 | 1.059 | 1.082 | 12.19 | 1e16† |
| 30″ | 1.032 | 1.250 | 5.68 | 1e16† | 1e16† |
| 300″ | **1.339** | 28.2 | 1e16† | 1e16† | 1e16† |
| 600″ | 2.868 | 1e16† | 1e16† | 1e16† | 1e16† |

† 该构型保留集 MAD = 0（所有叶完全相关）⇒ 生产公式分母为 0，`k_corr` 无有限上界；显式记 inf。

- **标定几何自校验**：`tile_order=0`、300″、pf=0.8 → 本模型 **1.339** vs 记录值 1.3883（**−3.5%**）；
  600″ → 2.797 vs 表值 2.8971（−3.5%）。方向与量级一致，模型可用。
- **生产真帧几何**：0.9666″/px × `tile_order=9` ⇒ `rho=0.833` ⇒ 模型 **2.33**。
- **pixfrac 扫描**（生产几何 rho=0.833）：pf=0.5/0.8/1.0 → 2.09/2.35/2.49。
- **窗口 N 扫描**（生产几何 rho=0.833）：N=9→1.02、25→1.30、49→1.91、81→**2.38**、121→2.32、
  169→2.09、289→1.86 ⇒ 生产 `N_ret≈251` 落在 1.9–2.1 档，仍 > 1.4。
- **裁剪比例扫描**（亮端污染比例 fc=0→0.4，保留比例 0.996→0.89）：生产几何 2.12–2.35，量级不变。
- **生产球面权重交叉核对**（探针 `probe_s05_kcorr`，直接调用生产
  `spherical::compute_overlap_area_g_ctx`）：在生产几何 48×48 drop 上取最近 6×6=36 叶窗口
  → `k_corr = 2.054`；10×10=100 叶窗口 → **2.058**；与可分离模型差 +13%/−16%。
  标定几何 300″/px → 1.529（模型 1.283，−16%）；rho=2.58 → 1.231（模型 1.122，−9%）。
  ⇒ 模型与真实 HEALPix 叶几何一致到 ±16%，而**两者都远大于 1.4**。

### 4.2 测量

- 检测：匹配滤波（高斯 σ=1.2 px）+ 41 px 大尺度背景扣除（去星云梯度），阈值 8×MAD，
  形状筛选（FWHM 1.2–5.5 px、圆度<0.35、核心集中度>0.30、S/N>5、峰值<60000 ADU）。
- 测光：4 px 圆孔径，8–14 px 环带中位背景；噪声按正本 §3.3（`shot_noise_only`），
  `sky = 环带中位 − 暗区底（全帧 2 分位）`（原始 light 含 ~33940 ADU 偏置底；
  暗区逐像素散度实测 7.34 ADU ≈ 读噪主导，与 `RN=8.59 e-` 自洽）。
- 被估量：`dmag = m_R(t1) − m_R(t2)`（同一共同星）；`z = (dmag − trend)/sigma_dmag`，
  `sigma_dmag = (2.5/ln10)·sqrt((σ_F1/F1)²+(σ_F2/F2)²)`。
- 训练/留出：按 `SHA256(seed:star_index)` 奇偶切分，**不重叠**：训练 **1108** / 留出 **1087**，
  共同星 **2195**（远多于 T05 的 117，因为本轮用自建检测器且不限制到最亮孤立星）。
  趋势模型（常数 + 星等 + 颜色(G−R，同夜 Green 帧) + x + y + r²）**只在训练集拟合**。

## 6. P3 修复前后 covariance 对照（防把 P3 几何当 P2 噪声）

同一二进制（HEAD 的 `spherical_overlap.cpp`，SHA256 `49cf726d…`），用负例开关
`ACSD_DRZ_P3_FAULT=legacy_cross_normal` 同时回退 P3-NORM-01/02，导出的生产权重矩阵逐对比较。

| 构型 | `eps_max` 固定 | `eps_max` legacy | 权重最大差 | 协方差相对差（max / 中位） | 叶方差相对变化 | `k_corr` 相对变化 | P2 MC 分辨率 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 顶点构型（scale 0.04″，nside 8192，8×8） | 1.62e-9 | **3.52e-3** | 3.51e-3 | 2.05e-3 / 1.36e-3 | −5.7e-7 | −1.41% | ±2.24% |
| 生产真帧几何（0.9666″，nside 2¹⁸，48×48） | 2.86e-11 | 5.69e-7 | 3.59e-7 | 1.79e-3 / 0（多数为 0） | −2.3e-10 | +0.36% | ±2.24% |
| 标定几何（300″，nside 512，16×16） | 1.35e-7 | 1.35e-7 | 8.0e-11 | 7.4e-9 / 0 | +2.9e-12 | +3.30% | ±2.24% |

结论：
1. P3 的两处近简并修复把逐 drop 完备性误差压低 4–6 个数量级（顶点构型 3.52e-3 → 1.62e-9）；
   生产几何下亦从 5.69e-7 降到 2.86e-11（对通量守恒有意义）。
2. 对**噪声协方差**的影响是**确定性、位置局域**的：生产几何下权重最大差 3.6e-7、
   叶方差相对变化 2.3e-10、`k_corr` 变化 +0.36%，全部小于 P2 MC 对 `k_corr` 的 2.24% 分辨率。
3. 因此：**P3 的几何变化不可能被误当成 P2 的随机噪声**（幅度小且非随机）；
   P2 的随机噪声读数也不会伪装成 P3 缺陷（后者只在顶点/叶角构型显著，且是系统性偏移）。
4. 唯一需要留意的是：若有人在 **S02 顶点构型**上做 P2 的方差评估，legacy 路径的
   0.35% 完备性缺陷会以"看似多出来的方差"出现——三个构型的 `cov_rel_diff_max` ≈ 2e-3
   正是这一量级。生产几何下不存在该混淆（4 个数量级差距）。

## 8. 未决 / 分歧

1. **`k_corr` 冻结值方向性缺陷（需负责人裁）**：生产默认帧几何下真实 `k_corr≈2.0–2.3 > 1.4`，
   控制点方差被低估 ⇒ 逆方差权重被高估约 1.5 倍。修法选项：(a) 把 `1.4` 改为按
   `rho`（需把 nside 传入查表）标定；(b) 显式把该域标 `UNCALIBRATED` 并降级权重新言；
   (c) 用两因子 `k_gauss(N)·k_geo(rho,pixfrac)` 落配置。**本轮不改 `lib/**`**，只给证据与适用域。
2. **与 `REPORT_paper.md` 现行口径的差异**：论文摘要写"117 颗真实共同星…2.79 倍"。
   本轮独立重测得 2195 颗共同星、比值 3.37（shot-only）/2.73（empirical）；
   **方向与量级一致**，但样本与分母口径不同，且本轮证明多余散度主要由**与 SNR 无关的系统项**
   贡献（亮端 z_rms 达 10），而不是"独立像素噪声低估 2.79 倍"。建议论文把
   "2.7928 倍"改成"该帧组上正/负偏差并存的分层读数"，并补入经验地板层与适用域。
   **按纪律：先回报分歧，未改 `实验/absolute-snr/REPORT_paper.md`（不在本轮写域）。**
3. **本帧测量无平场/暗场改正**：`sigma_sys` 含平场残差与孔径-PSF 耦合，不能单独归因；
   需要 masters（testdata 仅提供 XISF 母版，未解析）才能进一步分解。登记为待办。
4. **HI 暴露的另一处口径**：`run/STARMASK` 实测存在 `tile_order=12`（叶 0.1006″）产品，
   其 `k_corr` 在该域 >38；若这类产品进入生产，`1.4` 回退的偏差更大。需要产品分级声明。
5. **可分离方格模型 vs 真实 HEALPix 叶**：偏差 ±16%（已用生产权重核对）。
   若要把 `k_corr(rho)` 写进合同，建议用生产权重做最终标定表（本轮的探针已经给出方法）。
