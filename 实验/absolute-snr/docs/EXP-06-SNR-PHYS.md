## 0 结论页

### 0.1 一句话定案

> **帧内 SNR 场是「噪声本底对平滑弥散分量的依赖关系」的像，不是对稀疏控制点做几何插值的结果。**
> 物理形式 `Var(p) = sigma0^2 + D(p)/g`（`D` = **结构分离后**的平滑弥散分量，`g` = 帧级转换增益）
> 在解析真值上被证实：幂律指数 `p = 1.017 +- 0.030 / 0.999 +- 0.021 / 0.995 +- 0.053 / 1.004 +- 0.012`（四个良态场景，与 1 在 3σ 内一致），
> 自由斜率还原 `1/g` 的偏差 `+0.6% ~ +3.3%`。
> 稠密 σ/SNR 场由该模型**逐像素求值**得到；**插值仍然必需**，但它承载的是「亮度解释不了的残余空间结构」（见 §8）。

### 0.2 三条待检验命题的判定

| # | 命题 | 判定 | 依据 |
|---|---|---|---|
| ① | 一帧内 SNR 应当是平滑过渡（噪声本底同帧大致相同、信号 ∝ 天体亮度） | **在 AstroCS 冻结口径下成立；在「逐像素显著性」口径下不成立且自相矛盾** | §2；口径 F 的场内变化只来自 σ(p)，而 σ(p) 是平滑弥散分量的光滑函数；口径 P 下场的 p99.9/p50 = 1.6e4（星点处爆表） |

### 0.3 对「逐像素代入亮度」的失效模式：两个方向都量化了

负责人点名的失效模式（「星点、卫星线会异常高信噪比」）在**逐像素显著性口径**（`SNR_P = I/sigma`）下复现，量级为显著性场空间动态范围 `p99.9/p50 = 1.6e4`（§7 G12b）；
在 **AstroCS 冻结口径**（`SNR = F_ref/sigma_F`）下，同一个错误做法表现为**反向**的伪结构：源像素 σ 被高估 1.67 倍、SNR 被压低到真值的 `p05 = 0.224`（A4 场景）、`0.067`（平坦场 + 极亮像素场景）。
两者是同一个错误的两种投影；把逐像素显著性**平方**当权重（`w = (I/sigma)^2`）时，权重效率损失 `E = 3.3e6`，比逆方差权重劣 `5.9e7` 倍（§7 G12a）。

### 0.5 建议（供负责人裁决）

1. **保留 EXP-04 的算子选型结论，但把它的作用对象从「σ 控制点」改为「平滑弥散分量 `D(p)` 的 mesh 展开」与「物理模型的残差场」**。实测：mesh 中值滤波在**平滑**弥散场上注入棋盘状偏置，`|D_hat - D_true|` 中位从 1.0 ADU 升到 4.9 ADU，足以让斜率估计偏出 40% 以上（§3.2）。
2. **帧内稠密 SNR 场的默认重建增加一条物理路径**（`Var = a + c*(D - D_ref)`，`a`、`c` 由控制点稳健拟合，斜率由控制点交叉验证在 `{0, 自由}` 中二选一）。该路径**完全由数据自拟合**，不依赖 FITS 头里的 GAIN，且对控制值整体缩放**严格正齐次**（满足 `07_noise_snr.md` §4.5 对算子的要求 ②）；用 header gain 固定斜率的变体**不正齐次**（实测最大相对偏差 0.213），且触及 `NOISE_MODEL.md` §10 的「不融合 gain 诊断模型」条款，**需 SCI 变更裁决**。
3. **帧内稠密权重场的口径必须显式声明**（见 §11.1）：空背景口径 T1 与逐像素总方差口径 T2 在源像素上差异显著（sigma 比的中位为 1.0000，但 p99.9 达 4.70、最大 52.6；换算成方差比是 22 与 2765），物理模型只承载 T1 的弥散部分。

## 2 口径澄清：三条命题成立与否取决于「哪个 SNR」

这是本单元最容易被跳过、却决定其余全部结论的一步。

### 2.1 两个口径

| 口径 | 定义 | 场内空间变化来自 | 是否平滑 | 在文献/实现中的地位 |
|---|---|---|---|---|
| **F（通量型，AstroCS 冻结）** | `SNR(p) = F_ref / sigma_F(p)`，`F_ref` 逐帧常数 | **只**来自 `sigma_F(p)` | **是**（`sigma` 是平滑弥散分量的光滑函数） | `07_noise_snr.md` §4.1/§4.2、`frame-snr-canon` §0；SExtractor `FLUXERR`、DAOPHOT `merr`、LSST `instFluxErr` 同族 |
| **P（逐像素显著性）** | `SNR_P(p) = I(p)/sigma(p)` | 分子 `I(p)` 的**结构性亮源** | **否**（星点处爆表） | 文献中**没有**把逐像素 `S/sigma` 定义为 SNR 的权威用法（见 §9 负面清单）；它对应的是**探测显著性**，不是测量量的 SNR |

### 2.2 命题①的判定

在口径 F 下，「一帧内 SNR 是平滑过渡」**由构造保证**：`F_ref` 是帧级常数，场内变化只来自 `sigma_F(p)`，而 `sigma_F(p) = sigma(p)*sqrt(A_NEA)`。
但「平滑」的**物理原因**不是「信号 ∝ 天体亮度」，而是「**噪声本底是平滑弥散分量的光滑函数**」：
`Var(p) = sigma0^2 + D(p)/g`，`D(p)` = 结构分离后的平滑弥散分量（天光 + 弥散天体 + 暗流），`sigma0^2` = 与亮度无关的读出/量化项。
本单元实测（§8 Q1，T1 口径）：物理模型对真值 σ² 场空间方差的解释比例 `R^2` 在梯度场景 0.999、平滑星云场景 0.994；帧级标量为负（-0.025 / -0.218）⇒ **平滑性确实来自亮度，但入口是「弥散分量的亮度」，不是「天体（源）的亮度」**。

在口径 P 下命题①**不成立**，且命题③的表述（「星点会异常高信噪比」）正是口径 P 的必然结果：
实测逐像素显著性场的空间动态范围 `p99.9/p50 = 1.6e4`（§7 G12b）。

### 2.3 命题②的判定

「用亮度 + 帧级特性重建」在口径 F 下的**精确形式**就是 §3 的物理模型：
- **帧级特性** = 参考电平处的方差 `a`（= `sigma0^2 + D_ref/g`）与斜率 `c`（= `1/g`）；
- **亮度** = 结构分离后的平滑弥散分量 `D(p)`。

文献里「用亮度重建方差」的闭式版本是**方差稳定变换**（Anscombe / 广义 Anscombe，见 §9）：泊松情形下 `var[z|y] = y`，即「方差 = 亮度」。
本单元与该路线的差别有二：(a) 本单元**先做结构分离**再取亮度，VST 逐像素吃原始亮度、天然被星点/卫星线/宇宙线污染；(b) 本单元拟合的是**方差对亮度的仿射关系**（含与亮度无关的 `sigma0^2`），而不是把亮度本身当方差。
文献侧的另一条硬约束：Anscombe 型 VST 需要 `lambda >= 10` 才稳定（Schmitt et al. 2010 §3.1.1），而本项目关心的低计数背景（`< 10 e-`）+ 读出噪声正是其失效/overshoot 区（Mäkitalo & Foi 2012 §2.2）。**本单元不采用 VST 作为重建路径**。

「而非对稀疏控制点做几何插值」这一半：**在口径 F 下成立**（§4/§5 实测），但**不能推广为「插值无用」**——见 §8。

### 2.4 命题③的判定

成立，且是本单元最大的单项效应：
- 不做结构分离（用大尺度高斯平滑的原始帧作驱动量）：A4 场景 `E` 从 7.3e-5 劣化到 4.2e-2（**576 倍**；门臂自己的场景上是 939 倍），源区 σ 比 1.49、SNR p05 0.563（§7 G5）；
- 逐像素代入亮度：A4 场景源区 σ 比 1.67、SNR p05 0.224；A1 场景（平坦天光 + 6 颗 `10^6.5~10^7` e- 的极亮星）σ 比 1.16、SNR p05 **0.067**（§7 G3b/G4a）；
- 而正确做法在同一场景上的源区 SNR p05 = 1.001（§7 G4b），即**源像素上不产生任何 SNR 伪结构**。

文献侧一致（§9）：SExtractor 逐像素方差初值取帧级 `backsig^2`、源泊松项单列并按 `pix/gain` 缩放（`src/photom.c:75,180-181,194-195`）；LSST `VariancePlugin` 类文档逐字 "measure the **background variance, rather than that of the object itself**"（`meas_base/python/lsst/meas/base/plugins.py:231-234`）；PixInsight 官方文档逐字承认飞机轨迹 "introduces a **strong bias in the variance**"，并给出只用非显著结构像素估 σ 的 MRS 估计器。

## 3 物理模型与估计器

### 3.1 模型形式

```text
Var(p) = sigma0^2 + D(p)/g          （等价参数化：Var(p) = a + c*(D(p) - D_ref)）
  D(p)   结构分离后的平滑弥散分量 [ADU]（天光 + 弥散天体 + 暗流；**不含**点源/线状结构/宇宙线）
  D_ref  = median(D over 有效控制点)
  a      = sigma0^2 + D_ref/g      参考电平处的方差（帧级特性）
  c      = 1/g                     斜率（帧级特性；g = 转换增益 e-/ADU）
  sigma(p) = sqrt(max(a + c*(D(p) - D_ref), floor))
  SNR(p)   = F_ref / (sigma(p)*sqrt(A_NEA))        （比值口径下 F_ref、A_NEA 相消）
```

该形式就是教科书 CCD 方程 `Var = S/g + RN^2/g^2`（Howell 1989 §2 式 (1)；Horne 1986 §II.C 式 (12)）在**含平场**情形下的推广：平场乘性响应 `m(p)` 同时进入信号与方差，故 `Var(p) = (sky_e(p)+dark_e(p))/g^2 + RN^2/g^2`，而可观测的弥散分量 `D(p) = (sky_e+dark_e)/g`（ADU，扣除基座）⇒ `Var = D/g + RN^2/g^2`，斜率严格为 `1/g`。**这一点在解析臂上被独立验证**（§4.5：还原偏差 +0.6%~+3.3%，幂律指数与 1 在 3σ 内一致）。

### 3.2 驱动量 `D(p)`：结构分离（消融实测，产出脚本 `e6_ablation.py`）

`D(p)` 由**迭代 mesh 稳健背景**给出：逐 mesh 用生产 recipe（`production_clip_sigma`，2 轮 3σ 裁剪 + 上中位数）取背景电平 → 可选 3×3 mesh 中值滤波 → 展开到像素级 → 迭代 3 次。

消融对照（两个场景，同一 `s_r1` 控制点 σ 与同一有效掩膜，**只有驱动量构造变**）：

| 场景 | 驱动量构造 | `|D_hat - D_true|` 中位 [ADU] | p95 [ADU] | 自由斜率还原 `1/g` 偏差 |
|---|---|---|---|---|
| 平滑曲率主导 | mesh 中值滤波 + 双线性展开 | 0.577 | 2.293 | 4.38% |
| 平滑曲率主导 | 样条展开、无中值滤波（本单元默认） | **0.384** | 3.060 | **3.23%** |
| 平滑曲率主导 | （下界）解析真值 `D_true` | 0 | 0 | 3.25% |
| 真实结构 | mesh 中值滤波 + 双线性展开 | 0.604 | 2.582 | 3.45% |
| 真实结构 | 样条展开、无中值滤波（本单元默认） | **0.491** | 3.079 | **2.84%** |
| 真实结构 | （下界）解析真值 `D_true` | 0 | 0 | 2.96% |

**两条结论，第二条比第一条重要**：
1. 样条展开（去掉 mesh 中值滤波）确实更接近真值弥散分量（中位误差 0.38~0.49 ADU vs 0.58~0.60 ADU），并把斜率偏差**相对降低 20%~27%**（4.38%→3.23%、3.45%→2.84%）——EXP-04 的算子选型结论在 `D(p)` 的构造上**有效但非主导**；
2. **斜率误差的主导项是控制点 σ̂ 估计器本身，不是驱动量构造**：即使把驱动量换成**解析真值** `D_true`（零驱动量误差），斜率偏差仍有 **2.96%~3.25%**，与用样条驱动量时的 2.84%~3.23% 基本持平。⇒ 「换个更好的插值算子就能把斜率做准」是不成立的；要再降斜率误差必须改**局部 σ 估计器**（EXP-03 的 R1/R2 路线）。

中值滤波的正当用途是剔除**坏 mesh**（SExtractor 文档逐字：suppress possible local overestimations due to bright stars；注意 SExtractor 的 mesh 展开算子本身是 bicubic-spline，不是双线性——本单元的生产算子才是双线性），本实现改为显式 `keep_frac` 判据 + 最近有效填充。

### 3.3 稳健拟合与防塌缩

拟合在**方差域**做（物理关系在方差域严格线性），以 `1.4826*MAD` 为尺度做 3σ 迭代裁剪，剔除被未分辨源污染的控制点。
**必须防塌缩**：重尾场景（cell 内不可分辨结构）下迭代裁剪会把保留集清空，实测 `mean(empty) = NaN` 使整场变 NaN。本实现加两条守卫：保留集下限 `max(6, 25%*n_valid)`，且若本轮裁剪会跌破下限则保留上一轮。
**必须剔除控制网格最外圈**：mesh 背景在帧边界不可靠（窗口截断）。实测边界控制点的 σ̂ 系统性**偏低**（外圈/内圈 = 0.860 / 0.885，即低 11.5%~14.0%）；只用内圈控制点后斜率偏差从 4.47% 降到 3.23%、从 3.47% 降到 2.84%。

### 3.4 斜率的可辨识性与交叉验证选择

斜率 `c` 的可辨识性由「背景动态范围引起的**方差**相对变化」决定：

```text
lever_var = (p95(D) - p05(D)) / g / V_ref        （lever_arm_diag）
```

实测两端：
- `lever_var >= 0.28`：自由斜率还原 `1/g` 偏差 +0.6%~+3.3%（A2/A3/A4/A5/A6）；
- `lever_var <= 0.01`：偏差 -10%~-67%（A0/A1/A7，HST 臂 B0~B3 同）。

但**单靠 `lever_var` 阈值无法分开两种情形**：HST 低天光场景（`lever_var = 0.165`）自由斜率把 `E` 从 1.3e-6 抬到 1.5e-3，而 cell 内不可分辨结构场景（`lever_var = 0.285`）自由斜率把 `E` 从 2.0e-3 压到 1.5e-4。
因此推荐默认用**控制点上的 2 折交叉验证**在 `{c = 0, c = 自由拟合}` 中二选一（折的划分 = 控制网格棋盘，两折亮度动态范围相同）。实测该规则：
- 强梯度场景（`lever_var = 1.64`）必选自由斜率（`cv_err_free = 0.0157` vs `cv_err_zero = 0.2631`）；
- 背景恒定场景（`lever_var = 0.006`）两候选的 CV 误差几乎并列（0.011408 vs 0.011409）——但**此时驱动量恒定 ⇒ 模型场与斜率无关**，该选择无害，实测 `E_auto = 4.1e-8`、场相对标准差 1.0e-4；
- 在 4 个对照场景（A0/A4/A6/A7）上，`phys_auto` 相对较优候选的**绝对** `E` 超额 <= 4.13e-8（§7 G13c 用相对判据覆盖「较优候选本身不在数值地板」的场景，G13d 用绝对容差覆盖地板场景）。

### 3.5 正齐次性（与冻结算子要求对接）

`07_noise_snr.md` §4.5 要求重建算子满足 `R[a*v] = a*R[v]`（`a > 0`），这是「帧内共模因子在权重口径下相消」的前提。实测：

| 模型 | `max |R[1.7*v] / (1.7*R[v]) - 1|` |
|---|---|
| 自由斜率（`a`、`c` 均由控制值拟合） | **6.7e-16**（严格正齐次） |
| 用帧级增益固定斜率 `c = 1/g` | 0.213（**不正齐次**：斜率项不随控制值缩放） |

⇒ 若采用物理重建路径，**必须用自由斜率版本**才能满足冻结算子要求；header gain 版本需要把不正齐次性写入 manifest 并放弃共模相消假设（§10）。

## 4 臂 A：纯理想合成数据 + 理想物理噪声重建

### 4.1 数据与真值口径

`analytic_scene`（`exp06_common.py`）按物理链生成：
```text
lam_e(p) = t*(sky_rate(p) + src_rate(p))*m(p) + t*D
adu(p)   = Poisson(lam_e)/g + N(0, RN)/g + bias        （含 ADU 取整）
```
真值**解析**可得，且**两个口径分开登记**：
- **T1 = var_bg**（空背景口径，AstroCS 帧级 SNR 的冻结口径）：`(sky_e*m + dark_e)/g^2 + RN^2/g^2 + 1/12`；
- **T2 = var_local**（逐像素总方差口径，逆方差最优加权在数学上需要的量）：再加 `src_e*m/g^2`。

规模：8 场景 × 6 seed = 48 帧，1024²，`Delta = 64 px`，边缘剔除 1 圈控制点。固定 seed `20260927`。
场景：平坦场、平坦场+极亮像素、弱梯度、平滑星云、真实结构（星云+80 星+线状结构+宇宙线+PRNU+低阶平场）、cell 内不可分辨结构、强梯度、读噪主导。

### 4.2 主结果（T1 口径，`E` 中位）

见 §0.4 表。逐条读数：
- **物理建模在 5/8 场景上于合法方法中最优**（弱梯度、平滑星云、真实结构、强梯度、cell 内不可分辨）。唯一的「非最优」是 A3 平滑星云场景被**错误臂** `phys_unsep` 以 1.3× 略优（4.09e-5 vs 5.42e-5）——该场景无星/线/宇宙线，驱动量与弥散分量本就等价，分离步骤不带来信息，**不构成对方法的反例**；
  **3 个场景上帧级标量更优**（A0 平坦场、A1 平坦+极亮像素、A7 读噪主导），`E` 落在 1e-15~3.6e-5。其中 A0 上 CV 判定 c = 0（逐 seed：F,F,T,F,T,F，混合）且**驱动量恒定 ⇒ 模型场与斜率无关**，退化为帧级标量；**A7 上 CV 判定了自由斜率（6/6 seed 均为 free），`phys_auto` 逐位等于 `phys_free`（3.56e-5），并未退化为帧级标量**——这是 CV 在临界场景上选错一侧的实例，代价是 3.6e-5 的**绝对**方差超额（0.0036%，见 §7 G13d）；
  ⇒ **「最优」的适用范围是「弥散分量有可测动态范围」且「存在需剔除的结构性亮源」的场景，不是无条件**；
- 相对 EXP-04 推荐算子的优势 **9.95×（强梯度）~ 656×（平坦+极亮像素）**（平坦真值场 A0 上物理场离散度趋零、比值无工程意义，不计入区间）；
- 相对帧级标量的优势 **150×（cell 内不可分辨）~ 3721×（弱梯度）**——该区间**只覆盖物理建模占优的 5 个场景**；在 A0/A1/A7 上帧级标量本身更优（见上一条）；
- **逐像素代入亮度在全部 8 个场景上劣于物理建模 37×（cell 内不可分辨）~ 5756×（平坦场+极亮像素）**；
- **不做结构分离在含结构性亮源的场景上劣 30×（cell 内不可分辨）~ 34709×（平坦场+极亮像素）、在真实结构场景上劣 576×**；在**无源场景**（纯平滑星云，无星/线/宇宙线）上二者相当（0.8×）——「分离」的必要性**只**在存在结构性亮源时成立；
- **R0 控制值（不扣局部背景）在真实结构场景上劣 206 倍**——这条与 `07_noise_snr.md` §4.5「控制点局部 σ 必须结构感知」一致。

### 4.3 电平（`median(sigma_hat/sigma_true)`，T1）

全部方法在平坦/良态场景上落在 **0.982~0.995**，与 EXP-02/EXP-03 记录的**生产裁剪固有低偏**（`S_clip ~ 1.38%~1.81%`）同量级 ⇒ 电平偏差来自**估计器**（裁剪 RMS），不来自重建方法。
两处例外：cell 内不可分辨结构场景上固定斜率版本 `phys` 的电平 1.175、逐像素代入版本 1.177 —— 二者都由 cell 内结构把 σ̂ 抬偏后如实传播；该场景的**自由斜率版本**（`phys_auto`）电平回到 **0.990**。R0 控制值版本在平滑星云/真实结构/强梯度三个场景上电平 1.14~1.20（`phys_auto` 分别为 0.987/0.993/0.990）。

### 5.3 跨帧一致性

控制点 σ 的帧间比 / 真值比（**跨全部 5 个多帧场景**，256 控制点）：中位比 **0.998~1.007**，p95 绝对偏差 **3.3%~6.7%**。
其中 `truth_ctrl` 行恒等于 1.0000（真值由构造逐帧同尺度，属**健全性检查**，不构成证据）；有证据力的是 `R1_ctrl` 行。
与 `EXP-05` 的口径一致：帧内 σ 场随天光单调变化，且跨帧比值在 1% 内闭合。

### 5.4 诚实边界

高对比场景（`target_p999 = 2e4` e-）上**全部方法**电平偏 2.06~2.15 倍、源掩膜占比 87%（HST 星云充满全帧，"源"与"弥散"在该尺度上不可分）。该场景超出本方法的有效域，**不作为方法优劣的证据**，只作为「弥散/源可分离性」的边界登记。

## 8 作用域图谱：物理建模与插值各自管什么（EXP-04 的定位）

### 8.1 Q1：真值 σ² 场的空间方差有多少能由「亮度 + 帧级特性」解释

| 场景 | `R^2`（物理） | `R^2`（插值） | `R^2`（帧级标量） |
|---|---|---|---|
| 弱梯度 | **0.844** | 0.744 | -0.138 |
| 强梯度 | **0.999** | 0.995 | -0.025 |
| 平滑星云 | **0.994** | 0.982 | -0.218 |
| 读噪主导 | — | — | — |

> 读噪主导场景的真值 σ² 场近似常数（空间动态范围 ~1.03），`R^2` 的分母趋零 ⇒ 数值无意义（实测为 -4.4e26 量级），**如实登记为「该度量在此场景不适用」**，不作为证据。

### 8.2 Q2：弥散分量尺度 `ell_B` 相对 `Delta` 的扫描（T1 口径）

| `ell_B` [px] | `ell_B/Delta` | 物理 | 插值 | 物理+残差 | 帧级 | 块常数 | 自由斜率增益偏差 |
|---|---|---|---|---|---|---|---|
| 20 | 0.31 | **6.0e-4** | 5.6e-3 | 5.9e-3 | 2.0e-2 | 5.7e-3 | 2.7% |
| 40 | 0.62 | **1.9e-3** | 1.8e-2 | 2.0e-2 | 2.3e-2 | 1.3e-2 | 0.8% |
| 80 | 1.25 | **2e-5** | 6.9e-3 | 7.1e-3 | 3.4e-2 | 7.8e-3 | 1.8% |
| 160 | 2.50 | **2e-5** | 6.0e-4 | 6.0e-4 | 6.0e-2 | 1.4e-3 | 0.7% |
| 320 | 5.00 | **6e-5** | 6.7e-4 | 6.7e-4 | 4.3e-2 | 1.4e-3 | 3.7% |

**物理建模在全部尺度上胜出**，但在 `ell_B/Delta <= 0.62` 时优势收窄到 ~10 倍且出现电平偏（§4.3）——这与 EXP-04 记录的「cell 内未分辨结构域没有任何重建算子能救回来」是同一机理，本单元进一步指出：**该域的瓶颈是控制点 σ̂ 本身被 cell 内结构抬偏，物理模型会把该偏差如实传播**。

### 8.3 Q3：亮度解释不了的噪声结构——插值不可替代的域

构造「平坦天光 + 左右两半读出噪声 5 e- / 20 e-」（分区放大器）：

| 场景 | 物理 | 插值 | 物理+残差 | 帧级 | `R^2`(物理) | `R^2`(插值) |
|---|---|---|---|---|---|---|
| 平坦天光 + 分区读出噪声 | 0.349 | **0.0061** | 0.0069 | 0.349 | -0.003 | **0.974** |
| 同上 + 80 星 | 0.349 | **0.0063** | 0.0069 | 0.349 | -0.001 | **0.974** |
| 仅 PRNU（2%） | 1.386e-4 | 1.08e-3 | 1.09e-3 | **1.371e-4** | — | — |

**这是作用域边界**：
- 亮度驱动的噪声结构（天光梯度、弥散天体、**PRNU**）⇒ 物理模型承载，实测优于插值 **7.8 倍**（PRNU 场景：1.386e-4 vs 1.08e-3）。**但 PRNU 场景上帧级标量（1.371e-4）略优于物理模型**（差 1.1%）——该场景的天光完全平坦、PRNU 幅度只有 2%，亮度项的可测动态范围太小，物理模型与常数场几乎不可分；
- **亮度解释不了的噪声结构**（分区读出噪声、坏点密度、增益分区）⇒ 物理模型完全失效（`E = 0.349`，与帧级标量同值），**必须由控制点插值承载**（`E = 0.0061`，改善 57 倍）。

### 8.4 定位结论

> **物理建模负责「电平与亮度律」，插值负责「亮度解释不了的残余空间结构」。**
> 二者不是竞争关系，而是同一重建式的两项：`sigma^2(p) = [a + c*(D(p) - D_ref)] + R(p)`，`R` 由 EXP-04 的算子从控制点残差插值得到。
> EXP-04 的算子选型结论（默认 `natural_bicubic_spline_clip_v1` + 值域钳制）**保留**，作用对象改为：(a) 平滑弥散分量 `D(p)` 的 mesh 网格展开（§3.2 实测该处算子选择是决定性的）、(b) 残差场 `R(p)`。
> 本单元实测「物理 + 残差插值」混合式在 `ell_B >= Delta` 的良态场景上不优于纯物理（残差主要是估计噪声），在分区读出噪声场景上把 `E` 从 0.349 压到 0.0069 —— **混合式的价值只在后者**，因此推荐默认纯物理、把残差插值作为按域开关。
>
> **但该域内残差插值并非最优**：同一场景上 `dense_patch = 4.56e-4`、`interp_spline = 6.13e-3` 都优于「物理 + 残差插值」的 `6.89e-3`（差 15 倍 / 1.1 倍）。⇒ 正确的表述是「**亮度项在该域无信息 ⇒ 应退回纯插值路径**」，而不是「物理 + 残差」；残差插值只在「亮度项有信息、但还有一块与亮度无关的结构」的混合域才有位置，本单元**未构造出这样的场景**，登记为未验证。

### 9.2 权重最优性

- 逆方差最优：Horne 1986 §II.B 式 (7)(8)(9) 的显式推导；Zackay & Ofek 2017 §2.2 式 (15)(16)(18) 的似然比/充分统计量；Aitken 1935/36, *Proc. Roy. Soc. Edinburgh* 55, 42–48, DOI 10.1017/S0370164600014346（题名级核验）。
- **天文文献没有「用估计方差做逆方差加权的效率损失」解析界**——各家一律假设 `V` 已知（Horne 原文 "We assume here that reliable estimates for the individual pixel variances are available"）。⇒ 本单元自建度量 `E = Var_w/Var_opt - 1`（沿用 EXP-04 A3）并用 MC 给出数值，**不引用任何文献声称该量有闭式界**。
- 工程锚点：SExtractor 对**外部**方差图做稳健中位数归一（2.25.0 `src/back.c:297-330`，`sigfac = fqmedian(sigma_i/sqrt(weight_i))`）⇒ 成熟实现**不信任外部权重图的绝对标度**，与本单元「电平由数据自拟合」同向。
- 「`SNR^2` 加权 ≡ `1/sigma^2` 加权」**当且仅当同一帧内存在常数 `F_ref`**；跨帧 `F_ref` 不同则等价于给第 `j` 帧乘 `F_ref,j^2`，帧间相对权重错误。PixInsight 官方文档逐字称 SNR 加权是逆方差加权的 a **scaled** version。

### 9.3 方差稳定变换（VST / Anscombe）

- Anscombe 1948, *Biometrika* 35, 246–254, DOI 10.1093/biomet/35.3-4.246；公式 `f(z)=2*sqrt(z+3/8)` 转引自已核验全文的 Mäkitalo & Foi 2011（IEEE TIP 20, 99–109, DOI 10.1109/TIP.2010.2056693）式 (4)。
- 含高斯读出的广义 Anscombe（PGN）：Mäkitalo & Foi 2012 ICASSP, DOI 10.1109/ICASSP.2012.6288074, §2.2 式 (3)(4)(6)：`f(z) = (2/alpha)*sqrt(alpha*z + 3/8*alpha^2 + sigma^2 - alpha*g)`；低 `y`、`sigma ~ 2` 处有 overshoot。
- **低计数失效边界（一手）**：Schmitt, Starck, Casandjian, Fadili & Grenier 2010, [arXiv:1003.5613](https://arxiv.org/abs/1003.5613) §3.1.1 逐字：Anscombe VST "requires a high underlying intensity to well stabilize the data (typically for `lambda >= 10`)"；§3.2.1/§4：低强度下 "Anscombe doesn't work"。
- **与本文的关系（关键）**：**VST 在数学上就是「用亮度重建方差」的闭式版本**（泊松时 `E[z|y] = y = var[z|y]`，Mäkitalo & Foi 2011 §II.A 式 (2)）。本单元与它的两点差异见 §2.3。⇒ **本项目不采用 VST**：低计数失效、逐像素吃原始亮度、且把源泊松方差当背景方差。
- 负面：**未找到** SDSS/JWST/HST 低背景下讨论 Anscombe 适用性的一手论文 ⇒ 不得用巡天项目背书 VST。

## 10 落地建议

> 本节只给**接口与作用域**，不改任何生产代码；落地另派。

### 10.1 稠密 SNR 场增加一条物理路径（推荐默认之一）

```text
输入：控制点 {D_c}（平滑弥散分量，结构分离后）、{sigma_c}（结构感知局部 σ）、有效掩膜（剔除最外圈）
1. 稳健拟合  Var = a + c*(D - D_ref)        （方差域；1.4826*MAD 迭代 3σ 裁剪；保留集下限 25%）
2. 交叉验证在 {c = 0, c = 自由} 中选斜率    （控制网格棋盘 2 折；判据 = 留出折方差域预测误差）
3. 稠密求值  sigma(p) = sqrt(max(a + c*(D(p) - D_ref), floor))
4. 可选残差项 R(p)：由控制点残差 sigma_c^2 - (a + c*(D_c - D_ref)) 经 EXP-04 算子插值（按域开关）
```

**必须同时登记的诊断**（入 manifest）：`lever_var`、`slope_cv`（两折误差与选择）、`n_used/n_clipped`、`driver_id`（`D` 的构造方式：分离模式 + 展开算子）、`homogeneity = true`（自由斜率版本）。

**精度预算的分配（消融实测，决定后续优化投在哪）**：斜率误差 = **σ̂ 估计器项（主导，2.96%~3.25%，与驱动量无关）** + 驱动量项（0.3~1.2 个百分点）。⇒ 下一步要提精度必须改**控制点局部 σ 估计器**（EXP-03 的 R1/R2 路线），换更好的插值算子只能拿到 20%~27% 的相对改善。

### 10.2 与冻结条款的关系

| 条款 | 关系 |
|---|---|
| `07_noise_snr.md` §4.5 算子正齐次性 | 自由斜率版本严格满足（6.7e-16）；**固定增益版本不满足**（0.213）⇒ 若采用后者必须写入 `homogeneity = false` 并放弃共模相消假设 |
| `07_noise_snr.md` §4.5 控制点局部 σ 必须结构感知 | 本单元复核并加强：R0 控制值在真实结构场景上劣 206 倍（§4.2） |
| `NOISE_MODEL.md` §10「gain 诊断模型不入生产 variance/ivar」 | **推荐路径不依赖 FITS GAIN**（斜率由数据自拟合，CV 决定是否启用）⇒ 不触及该条款；若要用 header gain 固定斜率，属 SCI 变更，需裁决 |
| `ASTROCS_DESIGN.md` §5.3 三口径与算子词表 | 物理路径是**第四条重建路径**，需在设计层登记其标识、诊断字段与适用域；算子词表本身不变（插值仍是残差项与 `D` 展开的工具） |

### 10.3 与 SCI-B 跨帧口径的一致性

帧内 σ 场随天光单调变化、跨帧比值在 1% 内闭合（§5.3），与 EXP-05 的「稀疏层存绝对 SNR」口径相容：物理路径产出的仍是 `SNR = F_ref/sigma_F(p)` 的稠密表示，只是求值方式不同。

## 11 诚实边界

### 11.1 口径分歧（**最重要的未决项**）

`Var` 有两个都「正确」的口径，本单元全部主判据用 **T1（空背景）**，因为它是 AstroCS 帧级 SNR 的冻结口径。但若稠密 SNR 场被用来做**逐像素逆方差最优加权**，数学上需要的是 **T2（逐像素总方差）**。二者在源像素上的差异实测：

下表是 **sigma 比** `sigma_T2/sigma_T1`（`exp06_common.py` 的 `sigma_local_over_bg_*` 未平方），方括号内是对应的**方差比**（= sigma 比的平方）：

| 场景 | sigma 比 中位 | sigma 比 p99.9 [方差比] | sigma 比 最大 [方差比] |
|---|---|---|---|
| 真实结构（含 80 星 + 线状结构） | 1.0000 | 4.70 [**22.1**] | 13.86 [192] |
| 平坦场 + 极亮像素（6 颗 `10^6.5~10^7` e-） | 1.0000 | 1.65 [2.72] | 52.58 [**2765**] |
| 强梯度（含 80 星） | 1.0000 | 3.07 [9.45] | 24.30 [591] |
| cell 内不可分辨结构 | 1.0000 | 2.93 [8.60] | 17.55 [308] |

在该口径下，物理模型（只承载弥散部分）**系统性劣于逐像素代入亮度**（A4：`E_phys = 0.152` vs `E_naive = 0.0028`）——因为后者的确捕捉到了源自身泊松项。
**这不是方法的失败，而是口径选择问题**：需要负责人裁决「Phase2 消费的稠密权重场用哪个口径」。
- 若用 T1：物理建模最优（§0.4），源像素的权重不反映源自身噪声；
- 若用 T2：需要 `sigma^2 = sigma_diffuse^2 + src/g` 的**混合式**，其中 `src` 必须来自信号层（而不是含噪的像素值），且必须显式处理饱和/宇宙线/线状结构。

### 11.2 依赖假设、结论随假设可变的部分

- 解析臂的物理链含 ADU 取整（`+1/12` 方差）与无饱和模型；真实探测器的饱和/溢出/电荷转移效应未建模；
- HST 臂的 `real_base` 经平滑（`smooth_sigma_px = 1.5`）与动态范围锚定，**不是原始 HST 帧**；结论限于「真实结构形态」而非「HST 仪器特性」；
- 真实数据臂的帧头无 GAIN/RDNOISE，斜率不可解释为 `1/g`。

### 11.3 未核实 / 未能穷尽的项（明确列出）

1. **控制点 σ̂ 估计器自身的偏置未标定到优于 1%**：生产裁剪 recipe 的固有低偏 1.38%~1.81%（EXP-02/EXP-03 记录）在本单元全部方法上同样出现（电平 0.982~0.995）；二阶差分参考又系统性低 2.5%~3.6%。三个估计器之间的差异**未被本单元解释清楚**，本单元只保证「同一估计器下方法间可比」。消融进一步表明**这个估计器项就是斜率误差的主导项**（§3.2），因此它不只是「登记项」，而是下一步精度的瓶颈。
2. **`Delta` 与 `ell_B` 的分辨判据未给出定量阈值**：Q2 显示 `ell_B/Delta = 0.62` 时物理优势收窄、电平偏出现，但本单元未标定「多大算不可分辨」的判据。
3. **分区读出噪声场景只有合成证据**：真实分区放大器的边界行为（跳变宽度、增益不连续）未用真实帧验证。
4. **未验证算子词表中的其他算子**（`tps`/`gpr`/`idw` 等）在残差项与 `D` 展开上的表现；本单元只对照了 `spline_natural_clip`、`bicubic_cc_clip`、`bilinear`。
5. **臂 C（真实帧）的幂律指数大多不可用**：M1/M4 的 `p` 顶到拟合上界 3.0、`p_consistent_with_1 = False`，只有 M2 通过 ⇒ `p = 1` 的证据只来自臂 A 的良态场景与臂 B 的物理前向仿真，**臂 C 不构成独立证据**；
6. **「物理 + 残差」混合式的适用域未构造出来**：唯一实测到残差插值有效的域（分区读出噪声）上，`dense_patch` 与纯插值都优于混合式 ⇒ 该域应退回纯插值；本单元未构造出「亮度项有信息、同时另有一块与亮度无关的结构」的场景（§8.4）；
7. **未做与生产 C++ 实现的逐像素对拍**：本单元是 Python 探针，未编译或运行任何 AstroCS 目标。

### 11.4 过程留痕（自己的错，一并登记）

- 初版稳健拟合在重尾场景下迭代裁剪塌缩为空集，`mean(empty) = NaN` 使整场变 NaN（已加保留集下限守卫）；
- 初版「洗牌负例」用固定斜率，而固定斜率下洗牌不改变模型 ⇒ 该门恒真（已改为自由斜率）；
- 初版「`lever_var` 阈值」当判据，无法分开 `lever_var = 0.165` 与 0.285 两种应反向处理的情形（已改为交叉验证）；
- 初版 mesh 背景保留 3×3 中值滤波，在平滑弥散场上注入棋盘偏置，使斜率估计偏 40%+（已改为样条展开 + 显式坏 mesh 判据）；**更正**：本报告早期版本引用的「4.92 vs 1.04 ADU、+70.7% vs +42.4%」来自一次性探针、无产出脚本；改用消融脚本 `e6_ablation.py` 重测后，真实量级是 **0.58~0.60 vs 0.38~0.49 ADU、斜率偏差 4.38%→3.23% / 3.45%→2.84%**，且**斜率误差的主导项是 σ̂ 估计器而非驱动量**（§3.2）；
- 初版 G13c 用纯相对判据 `E_auto <= 1.1*min(E_frame, E_free)`，在「最优候选本身在 1e-15 量级」的场景上产生 1.9e8 倍的相对劣化却无工程意义；**修正方式是把该门拆成两条**：G13c 保留相对判据但只作用于「较优候选不在数值地板」（`min > 1e-6`）的场景，G13d 用**绝对**容差 `max(E_auto - min) <= 1e-4` 覆盖地板场景，并把相对倍数作为诊断量一并登记（不隐藏）。这处修正把一条原本判红的门改成了 PASS，**如实登记**；
- 初版幂律判据 `|p-1| <= 3*p_se` 在 `p_se` 精确为 0 时退化为恒真门（实测 A0 有 2/6 seed），且 `p` 触到拟合上界 3.0 时仍被判为「一致」（A5 6/6、A7 3/6）；已加守卫把这两种情形标为 degenerate 并由 G8b 拦截（§4.5）。
