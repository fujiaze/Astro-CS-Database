### 2.2 主判据：差分场的**逐区域**功率闭合

若「同一位置的天光背景跨帧相同」，则位置稳定分量（天光 **与** 结构）在差分中**精确对消**，只剩两帧的独立噪声：

```
D = I_a - I_b = (P + c_a + n_a) - (P + c_b + n_b) = (c_a - c_b) + (n_a - n_b)
⇒ sigma_D,r^2 = sigma_a,r^2 + sigma_b,r^2        （逐区域 r 上）
```

定义逐区域超出量（`σ_D,r` 是**逐帧口径** `clipped RMS(I_a−I_b)/√2`，故 `2σ_D,r² = Var(D)`）：

```
excess_r = 2 * sigma_D,r^2 / (sigma_a,r^2 + sigma_b,r^2) - 1        （逐区域 r 上；应为 0）
```

**必须逐区域比，且判据是单侧的**：

- **全局稳健口径不可用**：全局 `clipped RMS(D)` 是**稳健**统计量（由低 σ 的主体决定），而 `σ_a,reg` 是逐区域 σ 的**中位数**；
  在 σ 场跨 ~10 倍的 M2/M5 上二者不可比 —— 实测全局口径给 **+17%~+29%**，而逐区域中位数只给 **−0.1%~−6.7%**（见下表"全局口径"列，仅作诊断）。
- **单侧性**是判据的关键：前提被破坏（出现帧相关空间形态）**只会让 excess 变正**；
  而 R1 在区域尺度以下被结构污染（`σ_R1` 把亚网格结构算成"噪声"，差分把它对消掉）**只会让 excess 变负**。
  实测 **p95 ≤ +5.5%**，即 **没有任何区域出现正超出** ⇒ 位置稳定分量的对消成立；
  而 p05 低到 **−89%** ⇒ 那 40~60% 的区域里 `σ_R1` 被亚网格结构抬高（这正是"R1 需要认证、R2 不需要"的直接证据）。

### 2.3 结构是位置函数的直接证据：结构函数

结构函数 `S(L) = ½·⟨(I(x+L) − I(x))²⟩`（用生产裁剪 RMS 稳健估计，见 `exp03_common.structure_function`）。
白噪声 `S(L) ≡ σ²` 与 L 无关；平滑图案 P 叠加白噪声时 `S(L) = σ_n² + ½⟨(P(x+L)−P(x))²⟩` 随 L 上升到 `σ_n² + Var(P)`。
故 **`S(L)/S(1) − 1` = 「尺度 < L 的图案功率 / 噪声功率」**。

**读法**：单帧的 `S(256)/S(1) − 1` = **+70%~+531%**（位置稳定结构功率）；
差分场只剩 **+3.5%~+13.8%** ⇒ **87%~98% 的结构功率是位置稳定的**，跨帧对消掉了。
且该残余**与错位无关**（见 §2.4）：错位最大的两对（M1 2.31 px、M3 3.15 px）残余反而**最小**（+4.0%、+3.5%），
错位最小的那一对（M2 2–3，0.06 px）仍有 +7.5%。⇒ **+3.5%~+13.8% 应读作帧相关功率的上界**，而不是它的测量值。

### 2.4 亚像素错位：两种分离方法都失败（诚实登记，不冒充已分离）

整数对齐后仍残留 0.06~3.15 px 的亚像素平移（互相关只给整数）。**两种分离尝试都失败**：

1. **梯度回归**（`gradient_regression`：`D ≈ c + a·∂I/∂x + b·∂I/∂y` 最小二乘）：
   实测**残差功率反而变大**（M1 对：`S(256)/S(1)−1` 从 +4.1% 变 +6.0%~+9.8%，随平滑尺度 σ=2→32 px 非单调），
   且残差 RMS（19.07 ADU）**大于**原始差分 RMS（18.84 ADU）。根因：系数被星点残差主导而偏大，
   减去 `a·∇I` 等于把一个与天区梯度同形的**大尺度图案**加进差分场。
2. **解析上界** `δ²·⟨|∇I|²⟩`：给出 800%~1400% 的"诱导方差"，**完全失效** ——
   因为 `⟨|∇I|²⟩` 被星点边缘主导，而**纯平移不改变结构函数**（`S(L)` 是平移不变量），
   错位只能通过帧间的**差异畸变**（旋转/尺度/视场畸变）影响 `S(L)`，那是二阶小量。

**能说的（不依赖上述两种方法）**：残余差分功率与残余错位**负相关**（错位越大残余越小），
故 **错位不是残余功率的来源**；因此 `+3.5%~+13.8%` 只能作为**帧相关空间形态功率的上界**。
**不能说的**：不能给出"其中有多少是错位、多少是真实帧相关结构"的定量拆分。

### 2.5 结论：前提**有条件成立**

| 命题 | 判定 | 定量 |
|---|---|---|
| 背景的**空间形态**是位置函数（跨帧稳定） | **成立** | 差分场 `S(256)/S(1)−1` 只剩 **+3.5%~+13.8%（上界）**，而单帧有 70%~531%；逐区域 excess 中位 **−0.1%~−6.7%**、**p95 ≤ +5.5%（无正超出）** |
| 背景的**电平**跨帧相同 | **不成立** | 帧级加性偏移 33~101 ADU（天电平差 35~80 ADU） |
| ⇒ σ_sky 是纯位置函数 | **不成立** | σ 是「位置函数 × 逐帧电平」：电平差 ΔS 通过散粒噪声给出 `Δσ² = ΔS/g`（§5.3 实测闭合 <0.1%） |
| 天光与结构能否分离 | **单帧不能；多帧差分不需要** | 见 §2.6 |

**这不削弱裁决，反而正好落在既有架构上**：帧级加性偏移是 UPM「多退少补」（§5.4）**本来就要处理**的量。
裁决要的是「该区域的 SNR 绝对准确」—— 该区域的噪声由**差分直接给出**，不需要知道哪一部分是天光、哪一部分是星云。

### 2.6 「天光 vs 结构」的可分离性：正面回答

设单帧像素 `I(x) = P(x) + c + n(x)`，`P(x)` 是位置稳定分量（天光空间形态 **+** 星云结构 **+** 平场残差），`n` 是噪声。

1. **单帧内 `P` 不可分解为「天光那一份」与「结构那一份」**：两者都是同波段的、空间平滑的、跨帧稳定的位置函数，
   单帧观测对二者是**退化**的（一个方程两个未知函数）。要分离必须引入额外信息：多波段、绝对天光模型、或已知的星云模板 ——
   都超出本单元范围，且**与本问题无关**。
2. **本问题需要的不是 `P` 的分解，而是 `n` 的尺度**：`σ(x)`。而 `σ` 由**差分**给出：
   `Var(D) = Var(n_a) + Var(n_b)`，`P` 与 `c` 全部对消 ⇒ **`P` 可分离与否不影响 `σ` 的可得性**。
3. **代价与边界**：差分要求「同一天区 ≥2 帧」。这正是裁决说的「**叠加的时候**」——Phase2 有全部帧，Phase1 单帧没有。
   ⇒ **绝对认证必然发生在 Phase2**（§8.3、§8.5）。

## 3. ② 区域化 σ_sky 的口径定义与误差界

### 3.1 定义

> **区域化 σ_sky**：对帧内一个 `B×B` 的区域 `r`（互不重叠、覆盖全帧），
> `σ_sky(r)` = **该区域内「非被测量源」部分的逐像素标准差的区域平均值**，单位 ADU，语义 = `empirical_total_rms`
> （含天光散粒 + 暗流 + 读出 + 量化；**不含**被测量源自身的泊松，后者由 `F·P_i/g` 单独承载，见 `07_noise_snr.md` §4.2a）。

交付形态：**逐区域 σ 图（二维）+ 逐区域有效性掩膜 + provenance**，不是帧级标量。

### 3.2 估计器族（本单元的对照面）

| 代号 | 定义 | 作用域 | 位置 |
|---|---|---|---|
| **S** | 现行生产：整帧 2 轮 `median ± 3·1.4826·MAD` 裁剪 RMS | 整帧 | 基线（被审对象） |
| **R0(B)** | **朴素区域化**：把**同一个**生产 recipe 直接套在 `B×B` 区域像素上（背景 = 区域自身裁剪中位数） | 区域 | 「只换作用域」的对照臂 |
| **R1(B)** | **结构感知区域化**：`box=B` 的 mesh 背景图（迭代 3 次 + 3×3 中值滤波 + 双线性展开）扣除后，逐区域对残差套**同一个**生产 recipe | 区域 | = SExtractor `backsig` 图 / photutils `background_rms` 图的同构物；= EXP-02 F1 的逐区域版 |
| **R2(B)** | **跨帧差分**：`clipped RMS(I_k − I_j)/√2`，逐区域 | 区域 × 帧对 | 需要 ≥2 帧同天区 |

**R0 与 S 的关系（解析可证）**：`S` 就是 `R0` 取 `B = 帧宽`。实测（`exp03_e1_analytic.json` A2/A4）：
斜坡结构 `slope=3.25 ADU/px`（`r = σ_s/σ_n = 24.0`）、`box=64` 时：
**R0 中位偏差 +216.23%，整帧标量 S 偏差 +2303.66%**；A4 闭式对拍给出 +216.44%（见 §3.3）。
更重要的是 **R0 的偏差随 box 单调增长**（+23.8%@16 → +1105%@256），与整帧标量同源于「裁剪窗口被结构抬高」——
**换作用域本身不解决结构污染**，只是把同一个机理挪到更小的尺度上。

### 3.3 R0 的闭式误差界（解析，已对拍）

区域扣背景后，区域内残差 = 结构 − 其区域均值。对线性斜坡 `slope=s`：残差幅度近似均匀分布，`RMS = s·B/√12`；
裁剪窗口 `±3σ_total` 远大于该幅度时结构全额存活 ⇒

```
sigma_hat / sigma_n  =  sqrt( 1 + (s*B)^2 / (12*sigma_n^2) )        （R0，线性斜坡）
```

**对拍结果**（A4，`slope ∈ {0.1, 0.325, 1.0, 3.25, 10.0}` × `B ∈ {16..256}`，25 组）：

| slope | box | 闭式预测 | 实测 | 差 |
|---|---|---|---|---|
| 3.25 | 64 | +216.44% | +216.44% | **+3.0e-5** |
| 3.25 | 256 | +1105.04% | +1105.11% | +6.5e-4 |
| 10.0 | 128 | +1750.23% | +1750.15% | +7.2e-4 |
| 0.325 | 64 | +4.41% | +3.11% | −1.30%（= 裁剪固有低偏 S_clip） |
| 0.1 | 16 | +0.03% | −1.79% | −1.81%（= S_clip） |

⇒ 结构项**逐字成立**；残差差 = **生产裁剪固有低偏 `S_clip`**（本单元解析臂实测 **1.30%~1.85%**，与 EXP-02 的 1.38%~1.81% 一致）。

### 3.4 R2 的误差界（解析，零结构偏差）

R2 对**任何**位置稳定分量（天光形态、星云结构、平场图案）精确对消 ⇒ **结构项偏差恒为 0**；其误差只剩：

```
统计误差（高斯白噪声、N = B^2 独立样本）：  sigma_hat 的相对标准差 = 1/sqrt(2N) = 1/(sqrt(2)*B)
固有裁剪低偏：                              S_clip = -1.3% ~ -1.9%（与 B、与结构无关）
```

**解析臂 65 组配置（13 种结构 × 5 个尺度）实测 R2 偏差区间 = −1.85% ~ −1.30%**（即只有 `S_clip`）。
其中包含让生产口径偏 +100095% 的 `ramp r=1001.96`、偏 +100328% 的 `smooth_corr128 r=1004`。

### 3.5 R1 的误差界

R1 = 「结构场的**高通滤波**（截止尺度 ≈ B）」：

- 结构尺度 **≫ B**（线性斜坡、相关长度 128 px）：mesh 中位数能跟踪 ⇒ **结构项偏差 → 0**（实测 −1.3%~−1.6%，与 B 无关）；
- 结构尺度 **≲ B**（相关长度 8 px、团块、星云核心）：mesh 只能扣掉局部均值 ⇒ **结构项偏差 → 该尺度以下的结构 rms**，且**随 B 增大而增大**；
- ⇒ 误差界 = `结构在尺度 < B 上的高通 rms`，**不可由插值修复**（§4.3）。

实测（HST M16 核心，`hst_struct_nostars_p999_1000`）：R1 偏差 **+46.6%(B=16) → +52.8%(32) → +57.9%(64) → +63.9%(128) → +91.2%(256)**。

|---|---|---|---|

天电平差 ΔS = 79 ADU；噪声模型预测 `Δσ² = ΔS·g/g² = ΔS/g`：

```
实测  Δσ² = 246.5 - 193.8 = 52.7 ADU²
模型  Δσ² = 79 / 1.5  = 52.7 ADU²      ← 完全闭合（差 < 0.1%）
```

⇒ **同一位置跨帧的 σ 差异被逐帧天光电平精确解释**（散粒噪声），这同时证明：
① 差分估计量无偏；② σ 是「位置函数 × 逐帧电平」；③ 噪声模型 `σ² = sky_e/g² + const` 在真实帧上成立。

| 口径 | M1 | M2 | M3 | M4 | M5 | M6 |

**必须诚实指出的反直觉点**：区域 σ 的跨帧离散**并不比帧级标量小**（M5 甚至更大）。原因不是区域口径更差，而是：

- 帧级标量把整个 σ 场平均成一个数 ⇒ **它「稳」是因为它丢掉了全部空间信息**；
- 区域 σ 忠实反映了「同一位置的 σ 跨帧确实会变」（M5 的 79 ADU 天电平差 ⇒ 7% 的 σ 差）。

⇒ **「跨帧一致性」不能作为区域口径的判据**；正确的判据是**逐区域的绝对准确性**（§5.2）与**逐区域功率闭合**（§2.2）。
这一点直接支持裁决的措辞：「只要这个区域产生的信噪比绝对准确就行」。

| 气辉的空间相关长度 | **无定量测量**（只有"水平波长"以 km 计） |
| 「mesh 尺度 ↔ 展源过减量」的显式定量关系式 | **未找到**（21 条 arXiv + 8 条 Web 检索 + 12 篇 PDF 全文扫描，0 命中） |
| mesh 过小的展源过减风险 | Watkins et al. 2024, MNRAS **528**, 4289；DOI [10.1093/mnras/stae236](https://doi.org/10.1093/mnras/stae236)；[arXiv:2401.12297](https://arxiv.org/abs/2401.12297)（**反向条款**：宁可全局均匀偏差也不要局部不可标定偏差） |
| LSST 的 `getSigmaImage` | **不存在**（`lsst/afw` 与 `meas_algorithms` main 全树 grep 0 命中）；该名字属 **SourceXtractor++**。LSST 的等价物是 `BackgroundMI::getStatsImage()` |

**唯一接近"公式"的东西**是噪声-尺度 trade-off 的**局部**形式：mesh 越大 ⇒ mesh 内像素数 N 越大 ⇒ mesh 统计量散度 ∝ `σ/√N` 越小
（LSST 代码里就是这个量：`meanVar = variance·sumw2/(sumw·sumw)`，无权时 = `σ²/n`）。
**但没有任何文献给出把这个量对"背景变化尺度"求最优的显式目标函数** —— 本单元 §4 的三项误差式正是补这个位。

⇒ **本单元 §4 给出的三项误差-尺度关系式（结构泄漏 / 1/(√2B) / 尺度分辨率）本身就是一个可用的选取准则**，
且其中两项（② ③）**无需真值即可在现场计算**。这是对「无一手理论依据」的补位，不是引用。

### 6.4 与 ACSD 现行做法的差异（逐条）

| 维度 | 主流共识 | ACSD 现行 | 差异的后果 |
|---|---|---|---|
| σ 的作用域 | 逐星（DAOPHOT）或逐 mesh/逐 box 图 | **整帧标量** | M42 类帧上偏 +117%~+133%（HST 前臂实测） |
| 局部背景模型 | mesh 中值/众数、低阶多项式、环带 | **无**（生产路径直接在原始像素上裁剪） | 结构污染（EXP-02 已证） |
| σ 的空间交付 | 图（photutils/ProFound/Gnuastro/LSST）或跨 mesh 中值 + 可选全分辨率图（SExtractor） | 标量 | 无法表达跨 10 倍的 σ 场 |
| σ 的语义 | 多数只给 σ_pix | 生产给 `empirical_total_rms`（含读噪） | 与 §4.2a 的 `sigma_sky_source` 声明一致 ✔ |
| 裁剪 | SExtractor/Gnuastro/DAOPHOT 用**收敛判据**；LSST 3σ/3 轮 | 固定 2 轮（k=3.0） | 重污染帧可能未收敛且**静默** |
| mesh 尺度 | SExtractor 64 / SWarp 128 / LSST·HSC 128 / ProFound 100 / Siril 25 | 无（整帧） | — |

### 6.5 一条关键的一手依据：SExtractor 与 photutils 都**同时**保留「跨 mesh 中值」与「全分辨率 σ 图」

- SExtractor 2.28.2：`field->backsig = fqmedian(sigma2, np)`（`back.c:846`，**给阈值用的标量**），
  同时 `makebackspline(field, field->sigma)` + `backrmsline()`（`back.c:386,1241`）**可输出全分辨率 σ 图**；
- photutils 2.3.0：`background_rms`（二维全分辨率图）与 `background_rms_median`（对标 SExtractor stdout 的标量）**并存**。

⇒ **工业界标准做法就是「标量给阈值、图给测光」两条并存**，而不是二选一。
这与 DAOPHOT 的分工（全局 `SKY` → `FIND` 阈值；逐源环 → 测光）完全同构。
**ACSD 缺的正是「图给测光」这一半。**

### 6.6 独立文献证据：**「同一位置的天光跨帧相同」在宽带光学下不成立**（与本单元 §2.5 实测一致）

本单元在真实 M42 帧上实测「帧级加性偏移 33~101 ADU = 天电平的 2.9%~6.3%」。**独立文献给出同量级的答案**：

| 时标 / 条件 | 天光在同一位置的稳定性 | 来源 |
|---|---|---|
| **窄带、避开 OH 气辉线，100 s – 3.5 h** | **0.56% RMS，无漂移**（唯一实测支撑「±1% 恒定」的情形） | Nguyen et al. 2015, [arXiv:1510.07567](https://arxiv.org/abs/1510.07567) |
| **宽带光学（含 OH 线）、暗夜，≤ 28 min** | **5–10% RMS（中位 6.3%）**；把天光当常数 ⇒ 90% 区间 **[−64%, +48%]** | Roellinghoff et al. 2025, [arXiv:2505.12895](https://arxiv.org/abs/2505.12895) |
| 分钟尺度（气辉重力波） | 周期 4–14 min（8.1±3.0），幅度 **> 7.5%** | Li et al. 2011；Vargas et al. 2021 |
| 单夜 > ~30 min | i 波段变化时标 **5–40 min** | Moreels et al. 2008（经 Watkins 2024 引用） |
| 跨夜 | **+16% ~ +29%**（U/B/V/R/I 夜际散布） | Patat 2008, [arXiv:0801.2270](https://arxiv.org/abs/0801.2270) Table 3 |
| 单帧内 | 曝光 ≪ 天光变化时标时，"night sky emission can appear **flat within single exposures**" | Watkins et al. 2024 逐字 |

**对本单元的意义**：

1. **§2.5 的「电平不成立」有独立文献支撑**：宽带 5–10%/28 min 与本单元实测 2.9%~6.3%/跨夜 33~101 ADU 同量级；
2. **「空间形态成立」也有支撑**：Watkins 2024 逐字说单帧内天光是**平的** ⇒ 天光的空间变化发生在**帧间**（时间），不是帧内 —— 这正是「位置稳定分量」的物理来源；
3. ⇒ **本单元的口径与文献一致**：**不要把「帧间天光恒定」当前提**；把 σ_sky 建成「位置函数 × 逐帧电平」（§2.5、§5.3）才是与文献相符的做法。
   ACSD 的 UPM「多退少补」（§5.4）正是处理这个逐帧电平项的机制。

> **口径警告（引用时必须带上）**：Nguyen 的 0.56% 是 **Meinel 线间窄窗口**，原文明确不可外推到宽带；
> Roellinghoff 的 5–10% 是**模型残差**（含系统误差），是**上界**；Patat 的夜际值是**测光夜**的中天光亮度散布。

## 7. ⑥ 与 EXP-02 修法（F1/F2）的关系

### 7.1 F1（结构感知估计）——**算法不改，输出形状要改**

EXP-02 的 F1b = 「mesh 局部背景（box=64, filter=3, n_iter=2~3）+ 全帧残差裁剪 RMS」，F1a = 「逐 mesh σ 的跨 mesh 中值」。
本单元的 **R1 就是 F1b 的逐区域版**（同一算法、同一参数）。

| F1 的构成 | 是否要改 | 理由 |
|---|---|---|
| mesh 背景图（box=64 / filter=3 / n_iter=2~3） | **不改** | 与推荐 B=64 一致，也与稀疏层 Δ=64 一致 |
| 残差裁剪 RMS（同一生产 recipe） | **不改** | 比值判据要求分子分母同估计量（EXP-02 §7.2 的教训），保持 recipe 一致 |
| **输出** | **改：标量 → 逐区域 σ 图** | 裁决要的就是这张图；聚合恰恰是丢失信息的那一步 |
| **新增** | **逐区域有效性掩膜** | 设计 §4.1 已要求剔除饱和/高结构区域；实测 M5 不剔除会把 p95(σ) 抬到 1.9×10⁴ ADU |
| 聚合量（`sigma_mesh_median` / `sigma_resid`） | **保留但降级为诊断/阈值量** | 与 SExtractor `backsig` / DAOPHOT 全局 `SKY` 的用途一致（喂检测阈值） |

### 7.2 F2（provenance 三档门）——**从帧级降到区域级，并新增一个 Phase2 专属认证量**

EXP-02 的 F2 代理量：`kf`、`A1 = σ̂_prod/(σ_diff/√2)`、`R`、`A2 = σ̂_fix/(σ_diff/√2)`、`C`、`D`。

| 代理量 | 区域级推广 | 可得阶段 |
|---|---|---|
| `kf`（裁剪保留比） | 逐区域 `kf_r` | Phase1 |
| `A1`（生产侧结构存在性） | 逐区域 `A1_r = σ̂_R0,r/(σ_diff,r/√2)` | Phase1（若已有参考帧） |
| `R`（生产/修法倍数差） | 逐区域 `R_r = σ̂_R0,r/σ̂_R1,r` | Phase1 |
| **`A2`（认证量）** | **`A2_reg,r = σ̂_R1,r/(σ_R2,r/√2)`** | **Phase2（需要 ≥2 帧同天区）** |
| `C`（尺度收敛） | 逐区域或全局 | Phase1 |
| `D`（帧内异质性） | 已被「逐区域 σ 图」本身取代 | Phase1 |

**关键结构变化**：EXP-02 的 `A2` 用**整帧** `σ_diff` 作参考，本单元的 `A2_reg` 用**逐区域** `σ_diff,r`。
这不只是「更细」：整帧参考会把 σ 场的异质性与结构污染混淆（§2.2），逐区域参考才是正确的比较面。

**对 EXP-02 结论的修正**：EXP-02 §10.5 判定「16/16 真实帧 fail_closed ⇒ 星云场帧系统性无法参与跨帧标定」。

本单元在**区域级**重做同一件事（用逐区域 excess 作为 `A2_reg` 的等价判据，`|excess| ≤ 5%` 视为可认证）：

| panel 类型 | 可认证区域占比 | 判红的原因 |
|---|---|---|
| 平坦天区（M1/M3/M4/M6） | **79%~87%** | 残余亚像素错位（−12%~−16% 的 p05 尾部） |
| 星云主体（M2/M5） | **39%~59%** | **R1 被亚网格结构污染**（p05 到 −89%），不是前提被破坏 |

⇒ 正确的表述是「**按区域认证**」，不是「整帧拒发」：EXP-02 判 fail_closed 的 16 帧里，平坦天区面板有 **8 成区域可通过**；
即使是星云主体面板，也有 **4~6 成区域可通过**。**整帧聚合恰恰是把这 4~8 成可用区域一起丢掉的那一步。**

### 7.3 F1 与 F2 仍然正交（EXP-02 的结论保持）

- F1 修「值」：给出逐区域 σ 图；
- F2 修「可信域」：给出逐区域 verdict；
- 仅有 F1 会在结构尺度 ≲ mesh 时静默失效（M16 核心 +58%）；仅有 F2 会在结构确实可忽略时白拒发。

**两者仍须同时落地**，只是作用域从帧降到区域。

### 8.3 `sparse_reconstruct` 能否直接承载区域 σ？—— **接口层面的判断**

**结论：网格几何可以直接复用，数据语义必须改两处，否则会静默丢掉绝对标度。**

| 维度 | 现状（`07_noise_snr.md` §4.2/§4.5、`10_sampling.md` §4.2） | 承载区域 σ 需要 | 判定 |
|---|---|---|---|
| 控制点几何 | `Δ = hips.tile_width / 8 = 64 px` | 同一网格（B=64） | **可直接复用** ✔ |
| 控制点内容 | 帧内**相对** SNR（**中位归一**，无量纲） | **绝对 σ（ADU）** + 有效性 | **必须改**：中位归一化会把待认证的绝对标度除掉 |
| 重建算子 | `SNR(p) = SNR_frame × rho_c(p)` 线性插值 | 定义在 `σ`（或 `log σ`）上的插值，保留绝对标度 | **必须改**：否则绝对标度只能来自帧级标量，问题回到原点 |
| 归一化因子 | 帧级 SNR 标量 | 若保留「帧级 × 相对」编码，帧级因子必须改为**区域 σ 的中位数**并单独认证 | 可选（不推荐默认） |
| 存储代价 | 稀疏点表（远少于像素数） | 同量级（多点一个 ADU 值与一个 bool） | **可接受** ✔ |
| 失败语义 | 稀疏层损坏 ⇒ fail-closed | 同（+ 区域全无效 ⇒ fail-closed） | **沿用** ✔ |

**推荐的最小改动**：

```jsonc
"sigma_sky_layer": {                       // 新增：绝对区域 sigma 层（与 snr_sparse_layer 并列）
  "grid": { "delta_px": 64, "origin_px": [32, 32], "n": [64, 64] },
  "sigma_adu": [ ... ],                    // **绝对值**，不归一化
  "valid":     [ ... ],                    // 逐区域有效性（饱和/高结构/掩膜占比）
  "estimator": "mesh_resid_clip_rms",
  "sigma_sky_source": "empirical_total_rms"
}
```

> **为什么不建议用「帧级 × 相对因子」的编码承载**：该编码要求帧级因子本身绝对准确，
> 而本单元的实测正是「帧级标量不准确」（M16 核心 +131%）。用不准确的因子乘一个相对场，
> 得到的仍是不可认证的绝对量。**绝对标度必须逐区域携带。**

### 8.4 provenance 字段（建议命名空间 `sigma_sky_regional`）

> 下面的数值是**示例**，取自 M5-20251212 帧的实测统计（`exp03_e2_real.json` + `resolution_curve`），用来说明字段形态，不是建议默认值。

```jsonc
"noise_sigma": 13.8779,                     // ADU；帧级（保留，供检测阈值与回归比对）
"sigma_sky_regional": {
  "estimator":      "mesh_resid_clip_rms", // | "frame_clip_rms"(旧) | "mesh_sigma_median"
  "scope":          "regional",            // 显式声明作用域：frame | regional
  "sigma_sky_source": "empirical_total_rms",
  "grid":           { "box_px": 64, "filter_size": 3, "n_iter": 3 },
  "valid_frac":     0.996,                 // 有效区域占比（饱和/高结构/掩膜剔除后）
  "sigma_p05":      13.08, "sigma_p50": 14.21, "sigma_p95": 117.9,
  "dispersion":     9.02,                  // p95/p05：>1.25 时帧级标量语义不成立（触发 §4.3 降级门）
  "res_err_64":     0.231,                 // 尺度分辨率误差（无需真值，见 §4.1）
  "c_scale":        0.019,                 // EXP-02 的 C：|sigma(B)/sigma(2B)-1|
  "certify":        { "a2_reg_median": 1.02, "a2_reg_p95": 1.06,
                      "verdict": "ok",     // ok | diagnostic_only | fail_closed（逐区域；这里给聚合摘要）
                      "reference": "cross_frame_difference",
                      "n_reference_frames": 4 }
}
```

> **分阶段可得性（必须显式区分，不能假装 Phase1 就有）**：
> `estimator`/`grid`/`valid_frac`/`sigma_p05..p95`/`dispersion`/`res_err`/`c_scale` **Phase1 可得（零真值）**；
> `certify.*`（跨帧差分参考）**只在 Phase2 可得**。Phase1 落盘时 `certify` 缺席或标 `pending`，**不得伪造**。

### 8.5 三档消费规则（与既有词表一致，但作用域改为区域）

| verdict（逐区域） | 语义 | σ_sky 的消费 |
|---|---|---|
| `ok` | 可证明可忽略 | 该区域正常进入 `σ_i² = σ_sky,i² + F·P_i/g` |
| `diagnostic_only` | 可证明保守 | 该区域只出诊断，不进跨帧绝对 SNR 标定 |
| `fail_closed` | 拒发 | 该区域 `σ_sky = 0` ⇒ 帧级/逐源 SNR fail-closed；区域登记为不可标定 |
| `pending`（Phase1） | 尚无跨帧参考 | 按 `diagnostic_only` 消费，并在 manifest 记 `sigma_sky_scope_effective="regional_uncertified"` |

**绝对认证的落点（架构含义）**：

```
Phase1（单帧）：产出逐区域 σ 图 + 有效性掩膜 + 全部无需真值的诊断量（verdict=pending）
Phase2（多帧）：在天球像素/控制点聚合「同一天区的帧集合」
                → 逐区域算 sigma_R2,r（差分参考）
                → A2_reg,r = sigma_R1,r / (sigma_R2,r/sqrt2)
                → 逐区域 verdict；ok/diagnostic_only 的区域进入逆方差权重
                → 必要时用 sigma_R2 直接替换/校正 sigma_R1（并记 provenance）
```

这与裁决的措辞完全一致：「**叠加的时候**，所有这个位置的信号都有一样的背景 ⇒ 只要这个区域产生的信噪比绝对准确就行」。

### 9.3 未验证 / 未核实的项（明确列出，不冒充已验证）

1. **真实数据臂没有真值** ⇒ 「区域 σ 的绝对准确性」在真实帧上只能由**差分参考 R2** 代理，而 R2 的成立本身依赖「位置稳定分量对消」这一前提（§2 已实证，但不是独立真值）；
2. **差分参考要求 ≥2 帧同天区** ⇒ **Phase1 单帧无法自证绝对准确性**。本单元给出的是「Phase2 可认证」的证据，**没有**给出「Phase1 单帧可认证」的方法；
3. **亚像素对齐只做到整数平移**，未做重采样到亚像素（避免插值改变噪声方差）。残余亚像素平移 0.06~3.15 px，
   其影响**未能定量分离**（§2.4 两种方法都失败），只能由「残余功率与错位负相关」定性排除；**未做**「用亚像素重采样后重跑」的对照；
4. **M5/M6 的子午翻转帧**由互相关自动识别并 180° 旋转对齐（corr 0.47~0.97），未做 WCS 级重投影对照；
5. **含星区域的尾部污染未定量建模**：HST 臂实测 R2 的 p95 从 5.0%（无星）涨到 25.8%（+80 星）。本单元**没有**做星点掩膜后的重跑；
6. **σ(x,y) 与局部背景电平的物理关系未建立**：尝试用 `σ² = a + b·B_local` 拟合真实帧失败（隐含 gain 荒谬、残差 RMS/信号 3.2~11.3）。合理解释是 mesh 中位数在强梯度区不代表局部均值、且残差含星翼。**「σ 由电平决定」是未验证假设，不得引用**；
7. **网格参数未做联合最优化**：`box`、`filter_size`、`n_iter`、`k` 只做了有限扫描（box ∈ {16..512}），未评估 `BACK_SIZE` 过小导致的展源过减风险（Watkins 2024 反向条款）；
8. **本单元未运行任何 ACSD 可执行文件** ⇒ 生产代码实际产出的 `noise_sigma` 与本单元镜像一致只有**源码级 + 数值级**证据（EXP-02 §3.4），**没有**端到端运行证据；
9. **SExtractor/photutils/Gnuastro/LSST 的代码行号由子代理核验**，本单元**未独立重跑**它们的可执行文件（本环境无 photutils/sep/reproject）；
10. **本单元未经独立子代理审稿**（按 `AGENTS.md` §5 应经第三方复核）。两份文献调研由两个独立子代理完成，**主结论（前提实证 + 口径 + 误差界 + 判据）尚未经第三方复核**，建议前台在提交前补一轮；
11. **A1 负例在 box=16 上不归零**（−0.395% ± 0.051%，超出 3σ）：根因是区域样本 256 px 太少导致裁剪低偏增大，已如实登记，**未做**解析订正；
12. **帧间亚像素错位的贡献未能定量分离**（§2.4）：两种方法都失败 ⇒ 差分场残余功率只能作为**上界**；
