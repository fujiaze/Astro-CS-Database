# EXP-06 上呈摘要：帧内 SNR 的物理建模与重建

> 完整报告：`实验/absolute-snr/docs/EXP-06-SNR-PHYS.md`；证据：`实验/absolute-snr/results/exp06_e{1..5}_*.json`、`EXP06_TABLES.md`。

## 一、结论

**帧内 SNR 场是「噪声本底对平滑弥散分量的依赖关系」的像，不是对稀疏控制点做几何插值的结果。**
物理形式 `Var(p) = sigma0^2 + D(p)/g`（`D` = **结构分离后**的平滑弥散分量，`g` = 帧级转换增益）在解析真值上被证实：

- 幂律指数 `p = 1.017±0.030 / 0.999±0.021 / 0.995±0.053 / 1.004±0.012`（四个良态场景，与 1 在 3σ 内一致）；
- 自由斜率还原 `1/g` 偏差 **+0.6% ~ +3.3%**；背景动态范围不足时由控制点交叉验证自动退化为常数场；
- 权重效率损失 `E`（逆方差叠加的方差超额，越小越好）：真实结构场景 **7.3e-5（物理）vs 2.0e-3（EXP-04 推荐算子）vs 5.8e-2（帧级标量）vs 1.6e-2（逐像素代入）**；
  适用范围要说清：**4/8 场景严格最优**；无源平滑星云场景上「不做分离」臂以 1.3× 略优；平坦场/读噪主导场景上交叉验证把它退化为帧级标量（`E` 与帧级同量级，最大超出 3.6e-5）；
- **完全由数据自拟合**（不依赖 FITS 头的 GAIN），且对控制值整体缩放**严格正齐次**（6.7e-16，满足 `07_noise_snr.md` §4.5 冻结算子要求 ②）。

## 二、对三条直觉的验证

| # | 直觉 | 判定 |
|---|---|---|
| ① | 一帧内 SNR 应是平滑过渡（噪声本底相同、信号 ∝ 亮度） | **在 AstroCS 冻结口径下成立，但原因要改写**：口径 F（`SNR = F_ref/σ_F`）的场内变化**只**来自 σ(p)，而 σ(p) 是**平滑弥散分量**的光滑函数——不是「天体（源）的亮度」。在「逐像素显著性」口径下该命题不成立且自相矛盾（场的 p99.9/p50 = 1.6e4，星点处爆表）。 |
| ② | 可用「亮度 + 帧级特性」重建，而非几何插值 | **成立且更优**（T1 口径上优于 EXP-04 推荐算子 9.9~116 倍），但**不能取消插值**：亮度解释不了的噪声结构（分区读出噪声）物理模型完全失效（`E=0.349`），插值把它压到 0.0061。 |
| ③ | 不能逐像素代入亮度；必须先分离平滑弥散分量与结构性亮源 | **成立且是决定性的一项**：不做分离在真实结构场景劣 576 倍、在平坦场+极亮像素场景劣 34709 倍；逐像素代入在源区产生 SNR 伪暗洞（p05 = 0.224 / 0.067）。 |

**关于「星点异常高信噪比」**：该失效模式在**逐像素显著性口径**下复现（显著性场动态范围 1.6e4），把它的平方当权重时 `E = 3.3e6`，比逆方差权重劣 5.9e7 倍；在 **AstroCS 冻结口径**下同一错误表现为**反向**伪结构（源像素 SNR 被压低到 p05 = 0.224）。两者是同一错误的两种投影，都不是「口径 F + 结构分离驱动」的产物（该做法在源区 SNR p05 = 1.001）。

## 三、是否建议替换 EXP-04 框架

**不建议替换，建议重新划分作用域。**
EXP-04 的算子选型结论（默认 `natural_bicubic_spline_clip_v1` + 值域钳制）**保留**，作用对象从「σ 控制点」改为：
(a) 平滑弥散分量 `D(p)` 的 mesh 网格展开——实测该处算子选择**是决定性的**（SExtractor 语义的 3×3 mesh 中值滤波在平滑弥散场上注入棋盘偏置，`|D̂−D|` 中位 4.9 ADU vs 样条展开 1.0 ADU，足以让斜率估计偏 40%+）；
(b) 物理模型的残差场 `R(p)`（按域开关：在分区读出噪声场景把 `E` 从 0.349 压到 0.0069）。

统一式：`sigma^2(p) = [a + c*(D(p) − D_ref)] + R(p)`——**物理定电平与亮度律，插值定亮度解释不了的残余结构**。

## 四、未决项（需裁决）

1. **稠密权重场的口径**（最重要）：空背景口径 T1 与逐像素总方差口径 T2 在源像素上差异显著（T2/T1 的 p99.9 达 4.7、最大 52.6）。物理模型承载 T1 的弥散部分；若 Phase2 需要 T2，必须用「弥散项 + 信号层的源项」混合式，并显式处理饱和/宇宙线/线状结构。本单元主判据用 T1（冻结口径），T2 结果一并存档。
2. **是否允许用 header GAIN 固定斜率**：该变体精度更稳但**不正齐次**（0.213）、且触及 `NOISE_MODEL.md` §10「不融合 gain 诊断模型」。推荐路径不需要它（斜率由数据自拟合），故本单元建议**不启用**。
3. **`Delta` 与弥散分量尺度 `ell_B` 的分辨判据阈值**未标定：实测 `ell_B/Delta = 0.62` 时物理优势收窄到 ~10 倍且出现电平偏，但「多大算不可分辨」尚无定量门。
4. **控制点 σ̂ 估计器自身的偏置未标定到优于 1%**：生产裁剪 recipe 固有低偏 1.4%~1.8%，二阶差分参考又低 2.5%~3.6%；三个估计器之间的差异本单元未解释清楚。

## 五、证据强度与边界

- **21 条门全部 PASS**，含「错误做法必须判红」类（逐像素代入、不做分离、洗牌控制点、常数驱动量、错误增益、caliber P 权重）与「真值无效应必须归零/判退化」类（平坦场、零噪声）；门自身修正过两处退化（如实登记在报告 §7）。
- 三类数据齐备：解析真值（臂 A，48 帧）、HST 真实模板 + 完整物理前向仿真（臂 B，6 场景）、testdata 真实帧（臂 C，M42 三帧，棋盘 hold-out + 二阶差分双独立参考）。
- **诚实边界**：HST 臂上天光/读出主导、弥散结构弱 ⇒ 最优答案就是帧级标量，物理路径正确地退化为它（插值反而劣 60~11500 倍）；真实帧为归一化产品，斜率不可解释为 `1/g`；本单元为 Python 探针，未与生产 C++ 实现逐像素对拍。
