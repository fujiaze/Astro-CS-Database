# EXP-06 上呈摘要：帧内 SNR 的物理建模与重建

> 完整报告：`实验/absolute-snr/docs/EXP-06-SNR-PHYS.md`；证据：`实验/absolute-snr/results/exp06_e{1..6}_*.json`、`EXP06_TABLES.md`；端到端复跑 `code/exp06/run_all.sh`（日志末行 `END_TO_END_ALL_PASS = True`，25 门 + 12 消融门全绿）。
> 已过独立子代理对抗性复核（独立复算全部关键数字 + 抽查 7 条文献引用）；本摘要与报告已按复核意见修正 16 处。

## 一、结论

**帧内 SNR 场是「噪声本底对平滑弥散分量的依赖关系」的像，不是对稀疏控制点做几何插值的结果。**
物理形式 `Var(p) = sigma0^2 + D(p)/g`（`D` = **结构分离后**的平滑弥散分量，`g` = 帧级转换增益）在解析真值上被证实：

- 幂律指数 `p = 1.017±0.030 / 0.999±0.021 / 0.995±0.053 / 1.004±0.012`（四个良态场景，与 1 在 3σ 内一致；不可辨识场景的诊断会失效，已加守卫并由门拦截）；
- 自由斜率还原 `1/g` 偏差 **+0.6% ~ +3.3%**；背景动态范围不足时由控制点交叉验证退化为常数场；
- 权重效率损失 `E`（逆方差叠加的方差超额，越小越好）：真实结构场景 **7.3e-5（物理）vs 2.0e-3（EXP-04 推荐算子）vs 5.8e-2（帧级标量）vs 1.6e-2（逐像素代入）**；
- **完全由数据自拟合**（不依赖 FITS 头的 GAIN），且对控制值整体缩放**严格正齐次**（6.7e-16，满足 `07_noise_snr.md` §4.5 冻结算子要求 ②）。

**适用范围要说清**：5/8 场景上于合法方法中最优；另外 3 个场景（平坦场、平坦+极亮像素、读噪主导）由**帧级标量**胜出，物理路径的绝对超额 <= 3.6e-5（0.0036% 的方差超额）。相对**插值**则在全部 8 个场景上都更优。

## 二、对三条直觉的验证

| # | 直觉 | 判定 |
|---|---|---|
| ① | 一帧内 SNR 应是平滑过渡（噪声本底相同、信号 ∝ 亮度） | **在 ACSD 冻结口径下成立，但原因要改写**：口径 F（`SNR = F_ref/σ_F`）的场内变化**只**来自 σ(p)，而 σ(p) 是**平滑弥散分量**的光滑函数——不是「天体（源）的亮度」。在「逐像素显著性」口径下该命题不成立且自相矛盾（场的 p99.9/p50 = 1.6e4，星点处爆表）。 |
| ② | 可用「亮度 + 帧级特性」重建，而非几何插值 | **成立**（全部 8 个场景优于插值，良态场景优 9.95~656 倍），但**不能取消插值**：亮度解释不了的噪声结构（分区读出噪声）物理模型完全失效（`E=0.349`），插值把它压到 0.0061。 |
| ③ | 不能逐像素代入亮度；必须先分离平滑弥散分量与结构性亮源 | **成立且是决定性的一项**：不做分离在真实结构场景劣 576 倍、在平坦场+极亮像素场景劣 34709 倍；逐像素代入在源区产生 SNR 伪暗洞（p05 = 0.224 / 0.067）。 |

**关于「星点异常高信噪比」**：该失效模式在**逐像素显著性口径**下复现（显著性场动态范围 1.6e4），把它的平方当权重时 `E = 3.3e6`，比逆方差权重劣 5.9e7 倍；在 **ACSD 冻结口径**下同一错误表现为**反向**伪结构（源像素 SNR 被压低到 p05 = 0.224）。正确做法在源区 SNR p05 = 1.001，且**全帧最大 SNR 比 <= 1.03**（新增上界门 G4c 锁定）。

## 三、是否建议替换 EXP-04 框架

**不建议替换，建议重新划分作用域。**
EXP-04 的算子选型结论（默认 `natural_bicubic_spline_clip_v1` + 值域钳制）**保留**，作用对象从「σ 控制点」改为：
(a) 平滑弥散分量 `D(p)` 的 mesh 网格展开——消融实测：样条展开比「mesh 中值滤波 + 双线性」更接近真值弥散分量（中位误差 0.38~0.49 vs 0.58~0.60 ADU），并把斜率偏差**相对降低 20%~27%**；
(b) 物理模型的残差场 `R(p)`。

统一式：`sigma^2(p) = [a + c*(D(p) − D_ref)] + R(p)`——**物理定电平与亮度律，插值定亮度解释不了的残余结构**。

**一条重要的负面结论**：把驱动量换成**解析真值**（零驱动量误差）后斜率偏差仍有 2.96%~3.25%，与用样条驱动量的 2.84%~3.23% 持平 ⇒ **斜率误差的主导项是控制点 σ̂ 估计器本身，不是驱动量构造**；要再降误差必须改局部 σ 估计器（EXP-03 的 R1/R2 路线），换插值算子无用。

## 四、未决项（需裁决）

1. **稠密权重场的口径**（最重要）：空背景口径 T1 与逐像素总方差口径 T2 在源像素上差异显著（σ 比 p99.9 = 4.70、最大 52.6；换成**方差比**是 22 与 2765）。物理模型承载 T1 的弥散部分；若 Phase2 需要 T2，必须用「弥散项 + 信号层的源项」混合式，并显式处理饱和/宇宙线/线状结构。
2. **是否允许用 header GAIN 固定斜率**：该变体精度更稳但**不正齐次**（0.213，破坏 `07_noise_snr.md` §4.5 的共模相消前提）、且触及 `NOISE_MODEL.md` §10「不融合 gain 诊断模型」。推荐路径不需要它（斜率由数据自拟合），故建议**不启用**。
3. **`Delta` 与弥散分量尺度 `ell_B` 的分辨判据阈值**未标定：实测 `ell_B/Delta = 0.62` 时物理优势收窄到 ~10 倍且出现电平偏，但「多大算不可分辨」尚无定量门。
4. **控制点 σ̂ 估计器自身的偏置未标定到优于 1%**：生产裁剪 recipe 固有低偏 1.4%~1.8%，二阶差分参考又低 2.5%~3.6%；三个估计器之间的差异本单元未解释清楚（§3.2 已证明它是斜率误差的主导项）。
5. **混合式的适用域未构造出来**：分区读出噪声场景上 `dense_patch`（4.56e-4）与纯插值（6.13e-3）都优于「物理+残差」（6.89e-3）⇒ 该域应**退回纯插值**；「亮度项有信息但另有一块与亮度无关的结构」的场景本单元未构造，登记为未验证。

## 五、证据强度与边界

- **25 条门 + 12 条消融门全部 PASS**（`END_TO_END_ALL_PASS = True`），含 6 类「错误做法必须判红」（逐像素代入、不做分离、洗牌控制点、常数驱动量、错误增益、caliber P 权重）与 2 类「真值无效应必须归零/判退化」（平坦场、零噪声）；门自身修正过 3 处退化（洗牌用固定斜率而恒真、`lever_var` 阈值当判据、`|p-1|<=3*p_se` 在 `p_se=0` 时恒真），全部如实登记在报告 §11.4。
- 三类数据齐备：解析真值（臂 A，48 帧）、HST 真实模板 + 完整物理前向仿真（臂 B，6 场景）、testdata 真实帧（臂 C，M42 三帧，棋盘 hold-out + 二阶差分双独立参考）。
- **诚实边界**：HST 臂上天光/读出主导、弥散结构弱 ⇒ 最优答案就是帧级标量，物理路径正确地退化为它（插值反而劣 60~11500 倍）；真实帧为归一化产品，斜率不可解释为 `1/g`；臂 C 的幂律指数大多不可用（M1/M4 触界），`p = 1` 的证据来自臂 A 良态场景与臂 B；本单元为 Python 探针，未与生产 C++ 实现逐像素对拍。
