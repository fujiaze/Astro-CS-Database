## 0. 摘要（结论先行）

### 问题一：δ 的证据性取值

1. **裁剪低偏的真实量级是 1.38%~1.43%（负号），不是 0.77%。** 三类数据一致：
   纯解析 MC（N=1.6e7，生产 recipe 逐字镜像）**−1.3847% ± 0.0035%**；
   HST 真实模板 + 完整物理前向仿真（无底图无星）**−1.428%**；
   HST 配对差（两次独立噪声实现之差，结构逐位抵消）**−1.167%**；
   单轮 ±3σ 截断高斯的解析值 **−1.342%**。
   ⇒ `run/SCI-SNR-01` §4.2 表中 (b) 项的 "0.77%（星场）" **未被本单元复现**；本单元复现的是"无源"口径的 1.38%~1.43%（**负号**）。
   追查：该 0.77% 是 `star_detector.cpp:44` 的**代码注释值**（SCI-SNR-01 §7 自述），且为**正号**；
   本单元实测**源污染是正项且随源密度单调增长**（0 星 −1.428% → 80 星 −0.532% → 320 星 **+5.022%**）
   ⇒ 注释值作为**净值**并非不可能，但它是源密度相关的量，**不能**作为预算项。
   **负例（真值无效应 ⇒ 归零）**：不裁剪时低偏 = **−0.0046% ± 0.0060%**（3σ 内归零）✔

2. **天光估计的统计误差被高估了 1.83 倍。** 生产 `noise_sigma` 是**裁剪后 RMS**，其实测相对标准误
   `SE(σ̂)/σ = 0.7555/√N`（常数由 N=9216/1e5/1e6 三点拟合得 75.55/76.62/76.82 %·√N；
   N=9216 处实测 **0.7870%** vs 文档值 1.44/√N = 1.5000%）；
   `NOISE_MODEL.md` §5a 的 `1.44/√N` 是 **MAD 类尺度估计量**的常数，用错了对象。
   两种分解不要混用：**同 N 下"裁剪 vs 不裁剪"**是 +5.7%（0.7401% → 0.7825% @ N=9216）；
   **"裁剪后实测常数 vs 1/√2"**是 +6.8%~+8.6%（75.55~76.82 vs 70.71 %·√N）。两者都说明"裁剪抬高了 SE"。
   真实帧棋盘分半实测 SE 0.0034~0.0061（N=32768，预测 0.0039）⇒ 同量级 ✔

3. **T3 界在档 1 适用域内几乎紧致，不是"很松"。** 在 δ 的整个候选网格上，
   保守支实际偏差与界之比 = **0.905（δ=1.4%）~ 0.963（δ=0.5%）**（取 F_ref 处），
   全通量网格最坏 0.972~0.990。`run/SNR-REVIEW-01` 测到的"界很松"（1.1157 vs 1.2247 = 0.911）是在 **ρ=0.5**，
   已**超出档 1 的适用域**（档 1 要求 ρ ≤ 0.02 量级）。**在档 1 内 δ ≈ 实际接受的误差。**

4. **δ 决策（运行前冻结规则）**：`δ* = max{δ : δ ≤ S_sys_max 且 A_eff(δ) ≤ S_sys_max}`，
   `S_sys_max` = 其余**不可约且已刻画**系统项的最大值 = **1.4279%**（HST 本征裁剪低偏）
   ⇒ **δ* = 1.4%**。
   - δ = 1.0%：歧义项允许值**低于**主导系统项（1.43%）⇒ **次主导、偏保守、安全** ✔
   - δ = 1.4%：与裁剪低偏**同量级（parity）** ✔（规则给出的上界）
   - δ ≥ 2.0%：歧义项**变成主导项** ⇒ 不满足规则，**不可取** ✘
   ⇒ **现有主张 δ=1% 的取值本身可接受（略保守），但它的理由写错了对象**：
   1% 不是"与 0.77% 同量级"，而是"低于实测 1.43% 的裁剪低偏、因而次主导"。

5. **【最重要的操作性发现】δ 取多少对真实数据几乎不起作用 —— 档 1 在真实数据上大面积不可满足。**
   用**两套独立帧集**的实测 σ 反解 ρ = (RN/g)²/(σ² − (RN/g)²)（详见 §2.6）：
   - **16 帧 run/PERF-401 产物（σ = 18.3~38.2 ADU）**：`rn_adu` ≥ 5.38 ADU ⇒ **δ=1% 时 0/16 通过**（δ 需 3.5%~256%）；
     rn_adu=5.00 → 4/16；3.00 → 7/16；**1.50 → 16/16**。
   - **8 帧 testdata M42 T2 中心裁剪（σ = 15.6~64.0 ADU，含 4 帧星云亮帧）**：rn_adu ≥ 11.5 ⇒ 0/8；
     rn_adu = 7.69 / 5.38 / 5.00 / 3.00 → **4/8**（通过的恰是 4 帧 M2 亮帧）；**1.50 → 8/8**。
   ⇒ **δ 的具体数值不是安全性的瓶颈；瓶颈是"必须拿到 provenance，否则 fail-closed"**（与 SCI-SNR-01 档 3 一致）。

### 问题二：A 与 B 的判定

6. **判定：方案 A（SNR 路径改用 PSF 解析通量 `2πA·sx·sy/3`）在科学上更正确**，但**方差公式必须补一个拟合膨胀因子**。
   逐条：
   - **(a) 配对性**：B 的配对实测 **0.985~1.030**（盒和 + 盒和方差）；A 用**现行** `1/Σ(P²/V)` 方差时只有 **0.495~0.866**（欠报 σ 1.15~2.02 倍）——
     因为生产 PSF 拟合是 **6~7 参数**拟合，而 `1/Σ(P²/V)` 是"形状已知、只拟合幅度"的 CRLB；
     实测拟合膨胀因子（全参数拟合 std / 固定形状拟合 std）= **1.95（F=300）/ 1.33（F=1000）/ 1.18（F=10000）**；
     **解析 CRLB 独立复核 = 1.45 / 1.32 / 1.09**（§3.2），故该结论**不依赖拟合器实现**。
     若改用**固定形状最优加权和**，A 的配对 = **0.966~1.018**（精确配对），但在 PSF 失配下偏差达 −20%。
     ⇒ **A 需要把方差乘以拟合膨胀因子（下界 = 解析 CRLB 1.09；F≥1000 实测 1.18~1.33；低 SNR 端 1.45~3.2）；
     B 的方差形式天然精确。**
   - **(b) 正性截断**：现行盒和的 `v<=0` 截断是**有偏**的 —— 偏置随通量：F=100 ADU 时 **+97.1%**、F=300 **+24.0%**、F=1000 **+4.1%**、F=3000 **+0.45%**、F≥1e4 可忽略；
     方差被压低到 0.460/0.594/0.760/0.930/0.994（同序）。**负例**：去掉截断后偏置 z = **−1.30**（3σ 内归零）✔；截断口径 z = **+88.2**（判红）✔。
     ⇒ B **必须**同时处理截断（去掉截断或改用截断矩），否则 B 的"配对"也不成立；A **完全不碰**这个偏置。
   - **(c) 跨帧可比（决定性）**：同一真值通量、seeing 从 FWHM_det 1.6 → 3.9 px：
     * 解析臂：**盒和通量/真值 的跨 seeing 离散 = 7.18%**（E_B 0.9992→0.9323）；**A = 0.00%**（构造上就是总通量）；
     * HST 前向仿真臂（150 颗注入星，其中 **144 颗**落在 stamp 内可测）：**盒和 = 9.98%**；**A（PSF 拟合通量）= 2.69%**；带 HST 真实底图时 9.97% vs 3.07%；
     * testdata 真实产物臂：固定"PSF 解析通量"口径下，**盒和/PSF 通量比逐帧漂移 24.3%**（0.760→0.944，16 帧）；
     * **负例**：同帧恒等对照**严格 0.000**✔；同 seeing、不同噪声实现 z ≈ 0.01（3σ 内归零）✔。
     ⇒ 盒和口径给出的是 `E_B(seeing)·F_true`，**不是源的测光通量**，逐帧乘性偏差 7%~24%，
       直接违反 `ASTROCS_DESIGN.md` §3.1「权重只能来自纯净信号与噪声之比 / 绝对标定 / 不基于参考帧」。
   - **(d) 帧级 `reference_snr_f`**：生产帧级路径（`snr_frame_science.cpp`）用
     `ref_row.flux_adu = cfg.reference_flux_adu`（**模型总通量**）+ `snr_optimal`
     ⇒ **它已经是方案 A 的口径**。若改成盒和口径，同一 F_ref 的帧级 SNR 会偏移 **−0.08%（FWHM=1.6）~ −6.77%（FWHM=3.9）**。
     ⇒ A 消除"逐源口径 ≠ 帧级口径"的内部矛盾；B 会引入**第三套**口径。
   - **代价（必须如实登记）**：方案 A 把样本缩到 **PSF 拟合成功子集**。真实产物实测：
     `n_psf_valid/n_sources` = **0.05%~1.9%（中位 0.42%，473/174030）**，且子集偏向最亮源（其中相当比例已饱和，
     16% 的配对落在 box/PSF ∈ [0.5,2] 物理带之外）。

7. **一句话建议**：**采用方案 A**，并同时做两件事：
   ① 把 `sigma_f_adu` 乘以实测/解析的**全参数拟合膨胀因子**（或改用全参数 Fisher 信息），使配对成立；
   ② 明确 `fwhm_px` 的**跨块列口径**：PSF 块的 `fwhm_x = 1.230310·sx`（实测逐帧 1.23031，逐位一致），
      而 SNR 路径的输入列是**检测块高斯 FWHM**（`σ = fwhm/2.3548`）——
      直接把 PSF 块 Moffat FWHM 填进去会**差 1.914 倍**（DISP-STAR-007 类错误）。

## 3. 问题二：A 与 B 的判定

### 3.1 候选定义与判据

| 候选 | flux | sigma_f_adu |
|---|---|---|
| **CUR 现行** | 5×5 **正性截断**盒和 | `1/Σ(P_i²/V_i)`（61×61 网格） |

### 3.2 (a) 配对性 —— MC 实测（每点 500 次实现，FWHM_det=3，σ_sky=12.62 ADU，g=1.3，RN=10 e⁻）

## 7. 诚实边界与未核实项

**解析可证（不依赖仿真假设）**
1. 三候选的 E[flux]/Var(flux)/报告 σ 的解析式（截断正态矩、Horne 方差、盒和方差 + 背景电平项）；
2. 阈值口径 `ρ_tol(δ)` 与 `B_e/RN² ≥ 1/ρ_tol` 的等价性（δ=1% ⇒ 49.751244）；
3. T3 界在 ρ→0 时的紧致度与"ρ=0 ⇒ 两支逐像素方差逐点相同 ⇒ 偏差恒为 0"（负例）；
4. 跨块 FWHM 列口径的换算（`fwhm_x = 1.230310·sx` ⇒ 差 1.914 倍）；
5. 弹性 `f` 的解析式（数值微分复核）。

**依赖仿真假设（HST 前向仿真臂）**
6. 使用 `实验/shared/synthetic/render.py` 的 `stamp`（**双线性**亚像素平移）：该插值会把核**略微展宽**，
   在小 σ（FWHM_det ≤ 2 px）时可能带来百分之几的模型失配 ⇒ 仿真臂的小 seeing 端结果偏保守；
7. 本单元的 PSF 拟合器是**独立重写的 6 参数 TRF 最小二乘**，**不是**生产 `dpsf_fit_batch_f64`：
   两者同为 Moffat4(β=4)、同为幅度+质心+尺度（生产另含 θ），但收敛准则/边界/权重可能不同。
   **但"膨胀因子 > 1"这一结论不依赖拟合器**：§3.2 的 CRLB 解析复核对 F=1000/FWHM=3 给出 1.316，
   与 MC 的 1.332 差 1.2%。**依赖实现的是低 SNR 端**（F=300 时 MC 1.951 vs CRLB 1.452，多出的是收敛损失）
   ⇒ 落地前应用生产拟合器复核定**数值表**，而不是复核"要不要修正"；
8. 仿真用**圆对称** PSF（不含 θ）与不含宇宙线（`cr_rate=0`）；生产帧含 CR 与热像素（裁剪会处理它们）。

**未核实**
9. **testdata 真实帧的增益与读出噪声真值**：`p1_sources.json` 不含；`run/**` 未见 `snr` 配置块；
   ⇒ §2.6 的可满足性是**假设 (g, RN) 的参数化结论**，不是实测 ρ；
10. 生产 `dpsf_fit_batch_f64` 的实际协方差结构（本单元用独立拟合器近似）；
11. **PSF 轮廓失配项 (f) 未定量**：真实产物只能给出经验线索（box/PSF 比 0.760~0.944、16% 落带外），
    它把"真实 PSF 比 Moffat4 更宽"与"饱和/拟合失败"混在一起，未分离；
12. `reference_flux_adu` 的 `group_median` 回退分支：**已按代码判定为可达**
    （`module_adapters.cpp:4393-4423` 的 else 分支在 config 与 fixed_magnitude 都不可用时进入；
    且 FREF-BASELINE-001 优先用 fixed_magnitude）⇒ 该分支给出的 F_ref **也是 seeing 相关**的（§3.5）；
13. **本单元的生产镜像不是逐位镜像**（独立审稿 S11 实测，影响可忽略但必须登记）：
    (i) `production_clip_sigma` 用 `np.median`（偶 n 取两中值平均），生产 `nth_value` 取**上中位**
        ⇒ 对裁剪低偏的影响 ~0.004 pp；
    (ii) MAD==0 时本单元 `break`，生产用 `3e-9` 兜底阈值（该边界在真实数据上不可达）；
    (iii) `box_slice` 以**网格中心**取 5×5，生产 `detect` 以**峰值像素**为中心
        ⇒ 解析臂的 E_B 是"几何能量份额"，HST 臂才带亚像素相位效应（§3.4 两臂的差即来自此）；
14. **§2.6 的帧集归属**：A 套来自 `run/PERF-401`（**性能轮**产物，非专门科学取证产物），
    已在该节与 §2.6 表头登记 provenance；两套帧集的通过数**不可混用**；
13. 逐源 `snr_f`/`sigma_f_adu` 的**全部下游消费者**未穷尽；
14. 本单元**未做端到端注入-回收**（不运行程序），所有结论均为解析 + 独立重写实现 + 真实产物只读分析；

19. 盒和方差里的中位数协方差项：原写作 `Cov(d_i,b̂) = V_i·√(2π)σ_b/(2n_sky)`，量纲为 ADU³/n，
   与 Cov 应有的 ADU² 不符（偏差因子 `1.2533·σ_b`）。中位数影响函数的精确结果是
   `Cov(d_i,b̂) = V_i/n_sky`、`Var(b̂) = (π/2)σ_b²/n_sky`。

**对既有报告结论的影响（不迁就、也不越界）**
16. D1~D4 是**数值与推导层面的分歧**，不推翻 SCI-SNR-01 的三档判据与"必须 fail-closed"的结论；
