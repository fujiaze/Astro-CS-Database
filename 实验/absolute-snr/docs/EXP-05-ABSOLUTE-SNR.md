## 0 结论页（先给判定）

| # | 问题 | 判定 | 证据锚 |
|---|---|---|---|

**一句话**：**绝对表示正确，而且是被测的两种表示中唯一自洽的那一种**——它把物理定义原样落盘；
相对表示是一个**有损**的再参数化，它的数值语义依赖一条未经证明、且实测不成立的隐含假设 `median(SNR_c) ≡ frame_snr`。
「共模免费」是**真的**，但它是**单帧归一化加权**这一受限下游下的定理，**不能**用来支持相对表示在绝对电平与跨帧场景下的正确性；
而且它对两种表示**同样成立**，因此**没有区分能力**（详见 §3.5）。

## 1 ① 两个表示的定义式与隐含假设

### 1.1 物理定义（权威正本，不是本单元发明的）

```text
SNR(x,y) = F_signal(x,y) / sigma_F(x,y)                        [无量纲]        (1.1)
  * F_signal 已扣**局部**背景；天光**只作噪声项**进 sigma_F；
  * 点源（PSF）口径，不是面亮度口径；
  * sigma_F^2 = 1 / sum_i (P_i^2 / sigma_i^2)   （Horne 1986 最优提取，对角/白噪声近似）
  * 生产 gain<=0 分支（天空受限）：sigma_F = sigma_sky * sqrt(A_NEA)，A_NEA = 1/sum_i P_i^2

帧级：  SNR_frame,k = F_ref,k / sigma_F,k                          (1.2)
  F_ref,k = 10^(-0.4*(m_ref - ZP_k))，m_ref = 6.0（**逐帧**参考通量，公共锚 F0 = F_ref,k * k_photo,k）
权重：  w(x,y) = 1/sigma_F(x,y)^2 = SNR(x,y)^2 / F_ref,k^2        (1.3)
```

（1.1）是 `docs/plugins/algorithms_phase1/07_noise_snr.md` §4.1 的**红线**，也是
`实验/absolute-snr/docs/frame-snr-canon.md` §0/§2 的定案；（1.3）只在**通量型（一次方比）** SNR 下严格成立，
这正是 ACSD 不采用 PixInsight 式[18] 功率比口径的原因。

### 1.2 绝对表示（现行设计）

```text
落盘：  v(p) = SNR_c(p) = F_ref,k / sigma_F(p)        # 控制点 p 处的**绝对**通量型 SNR
重建：  SNR_abs(x,y) = R[v](x,y)                      # R = 显式声明的重建算子
权重：  w(x,y) = SNR_abs(x,y)^2 / F_ref,k^2           # 与 (1.3) 逐字一致
```

**需要什么输入才成立**：

1. 一个**局部**（逐控制点）的 `sigma_F` 估计器 —— 控制点值必须是**该点的**噪声，不是整帧标量的复本；
2. 一个**显式声明**的重建算子 `R`（算子标识入 manifest，节点精确复现，越界 fail-closed）；
3. 与帧级**同一**的逐帧参考通量 `F_ref,k`（只为权重换算 (1.3) 所需；**比值判据与它无关**）。

**隐含假设：无。** 绝对表示就是定义 (1.1)(1.2) 的直写；唯一的经验内容是「控制点处的 `sigma_F` 估计量准不准」，
那是**估计器**问题，不是**表示**问题（§5.2 分开讨论）。

### 1.3 相对表示（SNR-DESIGN-01 之前的设计）

```text
落盘：  rho(p) = v(p) / median_q(v(q))                # 中位归一，median(rho) == 1，与 F_ref 无关
重建：  SNR_rel(x,y) = SNR_frame,k * R[rho](x,y)       # 「帧级 × 帧内相对因子」
```

**隐含假设（三条，缺一不可）**：

| 编号 | 假设 | 它是什么 | 若它不成立会怎样 |
|---|---|---|---|
| **A1** | **锚定恒等式**：`SNR_frame,k ≡ median_p(SNR_c(p))` | 声称「帧级标量是该帧局部 SNR 的中位代表」 | 重建场的**绝对电平**整体偏移 `c_k`（§2） |
| **A2** | **算子正齐次**：`R[a*v] = a*R[v]`（a>0） | 缩放可以穿过算子 | 两表示之差**不再是共模常数**（§3.2 反例） |
| **A3** | **下游只消费帧内归一化量** | 不读绝对电平、不做跨帧绝对加权、不跨帧比较 | 共模因子不再相消（§3.3） |

**A1 是本变更争点的全部**。注意它不是「一个近似」：相对表示**强制** `median(SNR_recon) ≡ SNR_frame`
（中位归一的定义），于是任何 `median(SNR_c) ≠ SNR_frame` 的差异都被**原样写进**重建场的电平。

### 1.4 两个表示的**精确**代数关系（帧内共模因子）

设 `R` 正齐次（A2）。相对表示的重建可以逐字改写：

```text
SNR_rel(x,y) = SNR_frame,k * R[v/median_p(v)](x,y)
             = SNR_frame,k / median_p(v) * R[v](x,y)          # 用 A2 把 1/median 提出算子
             = SNR_abs(x,y) * c_S,k                          # 定义 c_S,k = SNR_frame,k / median_p(SNR_c)

=>  sigma_rel_eff(x,y) = sigma_c(x,y) / c_S,k = sigma_c(x,y) * c_k
    c_k  ≡ sigma_frame,k * median_p(1/sigma_c)               # **精确**的帧内共模因子（sigma 空间）
```

**关键性质**：`c_k` **与 (x,y) 无关**（同一帧所有像素同一个常数）—— 这是「共模」的严格含义。
因此：**两个表示的全部差别就是一个逐帧常数** `c_k`。整场推导因此归约为一个标量问题：`c_k` 是否等于 1？

**二阶口径歧义（本单元新发现，已登记）**：相对表示在 **SNR 空间**做中位归一，所以它的锚点是 `median_p(1/σ_c)`，
而**不是** `1/median_p(σ_c)`。二者只在 σ 场无空间离散时相等（Jensen 型不等式）。
旧稿常写的 `c ≈ σ_frame/median(σ_c)` 只是**一阶近似**；实测一帧上两者相差 4.3e-7 相对
（判据 `G5d_sigma_space_vs_snr_space_median_ambiguity`，表 D）。量级小，但说明相对表示的「基准」本身
在两种空间里就**不是一个定义**。

### 1.5 哪一个是**定义**、哪一个是**约定**？

| | 绝对表示 | 相对表示 |
|---|---|---|
| 落盘值是不是 (1.1) 的 SNR？ | **是**（`v(p) = F_ref/σ_F(p)`） | **不是**（`rho(p) = SNR_c/median(SNR_c)`，无量纲、中位为 1、与 `F_ref` 无关） |
| 定义式 (1.1) 是否**直接**成立于落盘值？ | **成立** | **不成立**；只有重建后 `SNR_frame × rho` 才（在 A1 成立时）等于物理量 |
| 性质 | **定义**的直接承载 | **约定**（把 SNR 分解成「帧级标量 × 归一化形状」的一种写法） |
| 违反哪条现行规范？ | 无 | `ASTROCS_DESIGN.md` §3.1「**全程只有 SNR**，HiPS 里存的是帧级 SNR 与稀疏控制点上的绝对 SNR」；`07_noise_snr.md` §4.6「权重不落盘」的同类精神：**落盘的必须是物理量本身** |

### 1.6 信息论视角：相对表示是**有损编码**

```text
绝对量 {v(p)}  可以导出：rho(p) = v(p)/median(v)、median(v)、任意统计量；
相对量 {rho(p)} 加上（另一个对象）SNR_frame 只能导出：v(p) * (SNR_frame/median(v))；
⇒ 要**无损**恢复绝对场，必须额外知道 median_p(v) —— 而它**没有被任何对象承载**。
```

⇒ **绝对表示严格占优**：`{rho} ⊂ {v}`（相对场是绝对场的确定性函数），反之不成立。
任何只想要相对场的下游，都可以在消费时由绝对量现场派生 `rho`（一次中位归约），**不需要**把绝对电平丢掉。

**唯一可能反转这条结论的情形**：如果 `median_p(v)` 本身**不可靠**（例如控制点太少、估计器退化），
那么把它写进产品反而是把一个坏数字固化下来。本单元的实测（§4）显示真实帧上 `median_p(σ_c)` 的**中位**
是稳的（1024 个控制点，中位的标准误 ≈ 1.1%/√1024 ≈ 0.03%），所以这条反转不成立。

## 2 ② 第一性原理推导：`c_k` 是否等于 1？

### 2.1 问题归约

由 §1.4，两个表示只差一个**逐帧常数** `c_k`。于是「绝对表示是否正确」这一问题**完全等价于**：

```text
c_k = sigma_frame,k * median_p(1/sigma_c(p))  =?  1
```

`c_k = 1` 意味着：**帧级标量恰好等于该帧局部 SNR 的（调和型）中位代表**。
这不是一条物理定律，而是两个**独立估计量**在**不同足迹**上的一次数值巧合。下面把它分解开。

### 2.2 `c_k` 的三因子分解（本单元的核心分解）

```text
令   sigma_true(p)  = 控制点 p 处的**真值**逐像素噪声（patch 口径：sqrt(mean(sigma^2))）；
     Sigma_RMS     = sqrt(mean_p sigma_true(p)^2)      # 整帧平方聚合（帧级估计量的目标量）
     Sigma_MED     = median_p sigma_true(p)            # 控制点中位聚合

     b_f = sigma_hat_frame / Sigma_RMS                 # **帧级估计器偏差**（整帧裁剪 RMS vs 真值 RMS）
     b_c = median_p(sigma_hat_c) / Sigma_MED           # **局部估计器偏差**
     c_agg = Sigma_RMS / Sigma_MED                     # **聚合口径错配**（纯定义性，与估计器无关）

则   c_k = c_agg * b_f / b_c          （一阶；精确式见 §1.4）
     |                     |
     |                     +-- 结构污染 / 裁剪偏置：帧级足迹上的经验偏差
     +-- 帧级是**平方聚合**、控制点中位是**中位聚合**：只要 sigma 场有空间离散，两者就不同
```

于是两个表示的电平误差分别是：

```text
绝对表示：  sigma_abs = sigma_c                     ⇒ 电平误差 = b_c          （只有**局部**估计器的误差）
相对表示：  sigma_rel = sigma_c * c_k = c_agg*b_f*sigma_c/Sigma_MED
                                                    ⇒ 电平误差 = c_agg * b_f （**帧级**估计器误差 × 聚合错配）
```

⇒ **相对表示把「帧级估计器的误差」乘到「局部估计器」头上**，而这两者的误差来源、足迹、污染机理**完全不同**。
除非 `c_agg·b_f = b_c`，否则相对表示的电平误差与绝对表示无关。

### 2.3 `frame_snr` 到底是怎么估的（只读核实链，按符号名定位）

| 步 | 符号 / 位置 | 事实 |
|---|---|---|
| 1 | `StarDetector::estimate_background`（`lib/algorithms/star_detection/wrapper_phase1/star_detector.cpp`） | **整帧**像素 → 2 轮 `median ± 3·1.4826·MAD` 裁剪 → 保留像素的**总体 RMS**（串行求和）⇒ `StarCatalog::noise_sigma` |
| 2 | `module_adapters` 写 `f_frame[fi]` 的 `"noise_sigma"` | 写入 `p1_sources.json` |
| 3 | `module_adapters` 的 `p1_op_noise`：`cfg.sigma_sky_adu = src_frame->value("noise_sigma", 0.0)` | 帧级 SNR 的 σ 入参 |
| 4 | `snr_source_snr_f64`（`lib/algorithms/noise_snr/cpp/src/snr_science.cpp`）的 `gain<=0` 分支 | `var_f = sigma_sky^2 / sum_p2` ⇒ `sigma_F = sigma_sky·sqrt(A_NEA)` |
| 5 | `snr_frame_science` → `astro_sphere_sink` → `aio_hips_set_frame_snr` | `SNR_frame = F_ref/sigma_F` 写入 HiPS 头键 `ASTROCS_FRAME_SNR` |

⇒ **`frame_snr` 的 σ = 整帧 2 轮裁剪 RMS**。三点推论：

1. **作用域是整帧**：它包含该帧全部结构（星云/梯度/未分辨结构）；
2. **聚合是平方型**：它的目标量是 `RMS(σ)` 而不是 `median(σ)`；
3. **污染是整帧级**：`EXP-02` 已定案「大尺度结构在整帧像素分布里不是离群点而是分布主体，裁剪在原理上就剔除不掉它」——
   实测 `keep_frac = 99.8%`、σ 由真值 10 涨到 18.7（+87%）。

### 2.4 `frame_snr` **不是**无偏的中位代表（三条独立理由）

**理由 1（聚合口径）**：`RMS ≥ median` 恒成立，只要 σ 场有空间离散。这是纯定义性的，与估计器好坏无关。
本单元解析臂实测 `c_agg` 最高到 **1.0997**（`vary_no_struct`），HST 前向臂到 **1.3137**。

**理由 2（结构污染）**：整帧足迹把大尺度结构当噪声。本单元**机理核对**（真实数据、无需真值，表 E）：
同一 recipe 在「原始像素」与「减去 64px mesh 局部背景后的残差」上的读数之比为

```text
M1: x1.164 ~ x1.201      M2: x3.414 ~ x3.650
M4: x1.189 ~ x1.304      M5: x2.444 ~ x2.645
```

⇒ 在 M2/M5 这类星云面板上，**帧级 σ 有 2/3 以上来自结构而不是噪声**。这不是「估计器不够好」，
而是「用整帧足迹估局部噪声」这件事本身在结构场里没有意义（`EXP-03` 已把该现象固化为门
`analytic.scalar_cannot_track_varying_sigma`）。

**理由 3（跨帧不一致）**：污染倍数**随帧的天光电平变化**（同一结构、不同噪声 ⇒ 相对污染不同）。
解析臂 `diff_level` 实测 `c = (1.8098, 1.3428)`，两帧相差 **35%**；真实 M5 面板 `c = (2.937, 2.940, 2.704)`。
⇒ 该偏差**不是帧内共模的跨帧常数**，因此也**不会**在多帧组合中相消。

### 2.5 一处必须登记的**归因订正**：`1.3127 ⇒ 帧级 SNR 偏低 23.8%` 不成立

`run/SNR-DESIGN-01/REPORT.md` §6C 与 `实验/absolute-snr/docs/snr-propagation-design.md` §1019 记：
「生产整帧未裁剪 MAD 相对裁剪 RMS 高 31.27% ⇒ 帧级 SNR 偏低 23.8%」。

**核实结果（只读）**：该比值 `1.3127` 出自 `snr-propagation-design.md` §2.5 的 EXP-3 Part A，其分子是
`p1_snr.json.frames[].variance` 隐含的 σ（**整帧 MAD**，来自逐像素噪声模型 A 的 `robust_sigma`），
分母是 `p1_sources.json.frames[].noise_sigma`（帧级 SNR 实际使用的裁剪 RMS）。

而 §2.3 的核实链显示：**`frame_snr` 用的就是后者（裁剪 RMS）**。
⇒ `1.3127` 度量的是**同一产品里两个生产者（variance 面 vs 帧级 SNR 面）互相矛盾约 1.3×**，
**不是** `frame_snr` 相对真值的偏差。由它推出「帧级 SNR 偏低 23.8%」是**归因错误**。

**`frame_snr` 的真实电平偏差必须直接测**——本单元实测（表 A）：在真实 M42 帧上，
`frame_snr` 的 SNR 电平相对 hold-out 真值**偏低 15% ~ 77%**（取决于面板的结构含量），
比 23.8% 大得多，且**逐面板不同**。

**附带登记**：`module_adapters.cpp` 中 `cfg.sigma_sky_source = SNR_SIGMA_SKY_EMPIRICAL_TOTAL_RMS` 上方注释写
「noise_sigma 来自 noise_model 的空天稳健尺度 (1.4826*MAD)」，与实现（`StarDetector` 的整帧裁剪 RMS）**不符**。
该注释的**结论**（声明为含读噪的经验总 rms、不再叠加 `(RN/g)^2`）仍然正确（裁剪 RMS 同样含读噪），
但**provenance 描述错误**，应订正。

### 2.6 推导结论（进入实验前）

1. `c_k = 1` 需要 `c_agg·b_f = b_c` —— 三个来源不同的量恰好抵消，**没有理由**成立；
2. 实测三个因子都明显偏离 1（表 A：`c_agg` 至 1.31、`b_f` 至 1.84、`c_k` 至 4.27）；
3. 因此**相对表示的电平不可信**，而**绝对表示的电平只受局部估计器支配**；
4. 这条推导**不依赖任何仿真**：它只用到 (1.1) 的定义、`frame_snr` 的生产估计链（只读源码核实）与算术。

## 3 ③ 权重视角：共模相消的证明与反例

### 3.1 定理（帧内共模相消）—— **证明**

**设定**：一帧内 K 个控制点上的重建权重 `w_abs(p) = SNR_abs(p)^2/F_ref^2`；相对表示给出
`SNR_rel(p) = SNR_abs(p)/c`（c 为帧内常数，§1.4），故 `w_rel(p) = w_abs(p)/c^2`。

**(a) 归一化加权均值严格不变**

```text
mean_rel = sum_p w_rel(p) y(p) / sum_p w_rel(p)
         = sum_p [w_abs(p)/c^2] y(p) / sum_p [w_abs(p)/c^2]
         = (1/c^2) sum_p w_abs(p) y(p) / [ (1/c^2) sum_p w_abs(p) ]
         = mean_abs                                                    ∎（与 y 无关，逐位相同）
```

**(b) 权重效率损失严格不变**

```text
E(w) = Var_w/Var_opt - 1，  Var_w = sum_p w(p)^2 var(p) / (sum_p w(p))^2，  Var_opt = 1/sum_p (1/var(p))
E(c^2 w) 的分子含 (c^2)^2 = c^4、分母含 (c^2)^2 = c^4 ⇒ c^4 相消；Var_opt 与 w 无关
⇒ E(c^2 w) = E(w)                                                    ∎（尺度不变）
```

**数值验证**（判据 G1a–G1d，表 C1）：三个正齐次算子（最近邻 / 双线性 / 类 kriging）的尺度等变性最大相对偏差
`1.5e-16 / 6.0e-16 / 2.3e-15`；单帧归一化加权均值两表示相对差 `2.2e-16`；`E` 两表示绝对差 `8.9e-16`。

### 3.2 定理的条件 C2（正齐次）**不是自动成立**的 —— **反例**

定理的全部内容都建立在 A2（`R[a·v] = a·R[v]`）上。**带数据无关先验均值的重建算子不正齐次**：

```text
pred(x) = m0 + k(x)^T K^-1 (v - m0*1)          # m0 是**固定常数**，不随输入缩放
R[a*v](x) = m0 + a * k^T K^-1 (v - m0*1)  !=  a * R[v](x)        （除非 m0 = 0）
```

实测非共模残差（`max |R[a·v]/a − R[v]| / |R[v]|`，判据 G2a/G2b，表 C3）：

| 算子 | 非共模残差 max | rms |
|---|---|---|
| `kriging_like`（无先验均值，正齐次） | 6.8e-16 | 1.7e-16 |
| `kriging_fixed_mean_1.0` | **2.551e-01** | 5.073e-02 |
| `kriging_fixed_mean_5.0` | **5.041e-01** | 1.597e-01 |

⇒ 若重建算子含**固定**先验均值 / 向固定值的收缩正则，则「两表示只差一个共模常数」**不再成立**，
连「共模免费」这条唯一的辩护也失效。现行文档（`07_noise_snr.md` §4.5）只要求「显式声明算子、节点精确复现、越界 fail-closed」，
**没有**正齐次性要求 ⇒ 登记为需补强项（§6）。

### 3.3 定理**不覆盖**的两个下游：绝对电平与跨帧

| 下游 | 共模因子 `c_k` 是否相消 | 为什么 |
|---|---|---|
| 单帧**归一化**加权均值 | **严格相消**（定理） | c^-2 在分子分母同时出现 |
| 权重效率 `E`（单帧） | **严格相消**（定理） | E 尺度不变 |
| **绝对 SNR 电平**（报告值、m5 深度、阈值判据、论文数字） | **完全不相消** | 电平就是 `SNR_abs/c_k` |
| **跨帧组合**（`SNR_comb² = ΣSNR_k²`，CONTROL_WEIGHT_SNR §8a 第 3 条） | **只消掉 c 的公共部分**；`c_k` 的**离散**全额进入 | 每帧的 c_k 不同 ⇒ 帧间权重比被 `(c_j/c_k)²` 污染、组合电平被 `ΣS²/Σ(S/c)²` 污染 |
| **跨帧可比性**（同一位置跨帧比值） | **只有 `c_k` 全同才相消** | 比值被 `c_k/c_j` 污染 |

### 3.4 跨帧反例（闭式 + 实测）

**闭式**：K 帧、真值方差 `var_k`、相对表示的权重 `w_k ∝ 1/(c_k² var_k)`，则

```text
权重效率损失  E = [sum_k w_k^2 var_k / (sum_k w_k)^2] * sum_k (1/var_k) - 1
              K=2 且等 var 时：E = 2(c_1^4 + c_2^4)/(c_1^2 + c_2^2)^2 - 1     （数值与闭式对拍 <= 4.5e-16，判据 G9a）
组合 SNR 偏差  sqrt(sum S_k^2)/sqrt(sum (S_k/c_k)^2) - 1
```

**实测**（用 e3 真实帧实测的 `c_k`，表 C2）：

| 来源 | `c_k` | 权重效率损失 E | 组合 SNR 偏差（总） | 共模项 | 跨帧项 |
|---|---|---|---|---|---|
| M1 | 1.175 / 1.206 | 0.0007 | +19.04% | +19.07% | −0.03% |
| M2 | 3.937 / 4.164 / 4.265 / 4.240 | 0.0042 | **+314.54%** | +315.16% | −0.15% |
| M4 | 1.232 / 1.317 / 1.199 | 0.0059 | +24.64% | +24.93% | −0.23% |
| M5 | 2.937 / 2.940 / 2.704 | 0.0065 | +185.37% | +186.03% | −0.23% |

⇒ **定量结论（必须分开说，不能混）**：

1. **权重效率**：共模因子**零代价**；`c_k` 的离散只带来 **0.07% ~ 0.65%** 的方差效率损失 —— 这是**二阶**效应；
2. **绝对电平**：共模因子**全额收费**，组合 SNR 偏差 **+19% ~ +315%** —— 这是**一阶**效应，且是「相对表示不可接受」的主因；
3. **跨帧可比性**：`c_k` 的离散全额进入比值（表 B 实测 +2.5% ~ +36.8%）。

### 3.5 EXP-1 的 `ratio = 1.000000` 的正确定位

`实验/absolute-snr/docs/snr-propagation-design.md` §2.1/§13 记：「**共模权重误差完全免费**（实测 ratio = 1.000000）」，
并据此写下「**这是「稀疏层可以只做相对、共模尺度误差无害」的定量依据，也是本设计能被接受的前提**」（同文 §2.1）。

**本单元的判定**：

1. 该实测值 **正确**，但它是 §3.1 **定理的必然结果**，不是经验发现 —— 任何正齐次算子、任何数据都会给出机器零；
2. 它**对两种表示同样成立**（绝对表示根本不产生这个因子），因此**没有区分能力**，不能作为「选相对表示」的依据；
3. 该文自己在 §12/§13 已经写明：「**各帧空间形状相同时帧标量即最优**（共模退化场景），
   **形状不同时结论反转**（马赛克/不同夜晚/不同指向/不同气团）。**不得把共模退化场景的结论当普适。**」
   —— 而 SCI-B 的目标场景（跨帧绝对 SNR、马赛克叠加）**正是**「形状不同」的那一类；
4. 该文 §2.1 的「本设计能被接受的前提」这一措辞应订正为：**「共模退化场景下单帧加权效率不受影响」**，
   它**不足以**支持「稀疏层只存相对值」。

## 5 ⑤ 明确结论

### 5.1 绝对表示是否正确？

**正确。** 四条理由，逐条可核验：

1. **定义层**：绝对表示是 `SNR = F_signal/σ_F`（`07_noise_snr.md` §4.1 红线）的直写；相对表示的落盘值 `ρ` **不是** SNR，
   物理量只有在乘回**另一个对象**（帧级标量）之后才出现 ⇒ 违反 `ASTROCS_DESIGN.md` §3.1「全程只有 SNR」；
2. **信息层**：`ρ` 是绝对场的确定性函数（`ρ = v/median(v)`），反之不成立；绝对表示**严格占优**（§1.6）；
3. **误差层**：相对表示把**帧级估计器**的误差乘进局部场（`c_k = c_agg·b_f/b_c`），而 `c_k = 1` 是三个独立量的巧合（§2.2）；
4. **实测层**：三类数据齐备，绝对表示电平偏差 **≤0.25%**（真实数据 ≤0.19%）；相对表示在**结构污染**场景 **−9% ~ −77%**，
   在无结构场景与绝对相当（−1% ~ +2%）⇒ 判据的区分力来自**结构污染**这一真实存在的物理事实（表 A）；
   跨帧比值绝对 **≤0.22%** vs 相对 **+2.5% ~ +36.8%**（表 B）。

### 5.2 在什么条件下成立、什么条件下不成立

| | 条件 | 说明 |
|---|---|---|
| **绝对表示成立**（作为正确载体） | 控制点值是**该点的局部** σ_F；算子**显式声明**；与帧级共用同一逐帧 `F_ref,k` | 这三条是 `07_noise_snr.md` §4.2/§4.5 已写明的约束 |
| **绝对表示准确**（数值上） | 局部 σ 估计器必须**结构感知** | 这是**估计器**问题，与表示正交：`EXP-03` 实测 HST 结构域上朴素 patch 估计器（R0）偏 +46%~+91%，结构感知（R1）偏 +58%（patch 内未分辨结构），跨帧差分（R2）偏 −1.6%；本单元真实 M42 帧上 R0 偏差 ≤0.2%、R1 ≤1.9% |
| **相对表示可接受** | 仅当三条同时成立：A1（`median(SNR_c) ≡ frame_snr`）+ A2（算子正齐次）+ A3（下游永不消费绝对电平、永不跨帧） | A1 实测不成立（`c_k` 达 4.27）；A2 对固定先验均值算子不成立（残差 50%）；A3 与 SCI-B 的目标直接冲突 |
| **两表示等价** | `c_k ≡ 1` 且算子正齐次 | 测度为零的巧合；负例实测 gap 7.7e-5（`flat_no_struct`） |

**若"既不是纯相对也不是纯绝对"是候选答案**：本推导的答案是 —— **落盘必须绝对**（物理定义与跨帧可比性的唯一载体），
**相对场按需派生**（消费时一次中位归约，零信息损失）。即「绝对落盘 + 相对视图」，
而**不是**「相对落盘 + 绝对还原」——后者在 `c_k ≠ 1` 时**不可逆**。

### 5.3 归一化基准应该是什么？

* **不应该是 `frame_snr`**：它是一个**估计量**（整帧裁剪 RMS 口径），不是一条尺度基准；
  把它当作稀疏层的锚点，等于把它的全部偏差（结构污染 + 聚合错配）乘进每一个控制点。
* **不需要"归一化基准"**：绝对量本身就是自己的基准。
* **若产品确实需要一个尺度锚**，它应是**同一物理口径下的逐帧参考通量 `F_ref,k`**（`m_ref = 6.0` 的公共锚，
  合同载体 = `frame_snr.schema.json#reference_baseline`）—— 它保证跨帧可比，且**不引入任何噪声估计偏差**。
* **若产品需要一个"帧级代表值"**，正确方向是 **`sparse → frame`**：
  `frame_level := median_p(SNR_c(p))`（或按足迹加权的摘要），而**不是** `sparse := frame × 相对场`。

### 5.4 与 `frame_snr` 的关系应如何定义

1. **保留为独立科学量**（`CONTROL_WEIGHT_SNR.md` §8a 第 7 条已定案「相互独立、不作尺度基准、不参与还原」）——**本推导支持该定案**；
2. 二者是**同一物理量在两个不同足迹上的两个估计**（整帧 vs 控制点），因此**不应互相强制相等**；
3. 若未来要两者一致，方向必须是 **`frame_snr := 稀疏层的摘要`**（由绝对控制点导出），**不得反向**；
4. `frame_snr` 自身的口径缺陷（整帧裁剪 RMS 的结构污染，实测真实帧上 σ 被撑大 1.16×~3.65×）
   是**独立缺陷**，应在帧级路径上另行修复（`EXP-02` 的 F1/F2、`EXP-03` 的区域化 σ），与稀疏层表示无关。

## 9 ⑨ 诚实边界

### 9.1 本单元**能**证明的（不依赖仿真假设）

1. 两个表示的**精确**代数关系 `SNR_rel = SNR_abs·c_S`（`c` 逐帧常数）—— 由定义与 A2 直接推出，**并已数值验证**（G5c）；
2. **共模相消定理**（单帧归一化加权均值、权重效率）—— 代数证明 + 机器精度验证（G1a–G1d）；
3. **反例**：固定先验均值算子不正齐次 ⇒ 共模论证失效（G2a）；
4. **跨帧闭式** `E = 2(c₁⁴+c₂⁴)/(c₁²+c₂²)²−1` 与数值一致（G9a）；
5. **信息论占优**：`{ρ} ⊂ {v}`，反之需要额外信息 `median_p(v)`（§1.6）；
6. `frame_snr` 的生产估计链（整帧 2 轮裁剪 RMS）—— **只读源码逐符号核实**，不是推测（§2.3）；
7. `1.3127` 的分子分母来源 —— 只读核实（§2.5）。

### 9.2 依赖假设、结论随假设可变的部分

| 结论 | 依赖的假设 | 若假设不成立会怎样 |
|---|---|---|
| 真实数据臂的 `c_k`（1.18 / 3.94 / 1.20 / 2.70 等） | 棋盘 hold-out 的 fam1 像素与该 patch 的噪声同分布（**无位置相关缺陷**） | 若探测器有与棋盘同周期的图案（实际不可能），真值会被污染 |
| 真实数据臂的「绝对表示偏差 ≤0.2%」 | 估计器（fam0 patch 裁剪 RMS）与真值（fam1 patch 裁剪 RMS）**同 recipe** | ⇒ 该臂测的是**锚点**，**不是**估计器的固有偏差（裁剪低偏、patch 内结构泄漏在比值中相消）。估计器固有偏差由臂 A/B 用**解析真值**覆盖 |

## 附录 C 一页纸回答（给负责人）

```text
问：稀疏层存「绝对 SNR」在科学上对不对？

答：对。

1) 物理定义 SNR = F_signal/sigma_F 的落盘值只能是绝对量；相对量 rho = SNR/median(SNR) 不是信噪比，
   它把物理量推迟到「乘回帧级标量」之后才出现 —— 违反「全程只有 SNR」。

2) 两个表示**恰好**只差一个逐帧常数 c_k = sigma_frame * median(1/sigma_c)。
   「相对表示可用」等价于假设 c_k == 1，即「帧级标量 = 该帧局部 SNR 的中位代表」。
   这个假设一般不成立：c_k = c_agg * b_f / b_c，三个因子来源不同，实测 c_k 达 4.27。

3) 「共模 ⇒ 一阶免费」是**真的**，但它只是**单帧归一化加权**下的定理：
   权重效率 E 与归一化加权均值对共模因子严格不变（实测 8.9e-16 / 2.2e-16）。
   它**管不住**绝对电平（一阶收费：组合 SNR 偏差 +19%~+315%）与跨帧可比性（+2.5%~+36.8%）。
   而且它对两种表示同样成立 ⇒ 不能用来支持选相对表示。

4) 实测（三类数据齐备，全部对真值）：
   绝对表示 SNR 电平偏差  <= 0.25%（真实数据 <= 0.19%）；
   相对表示 SNR 电平偏差  -9% ~ -77%（真实数据 -15% ~ -77%）；
   跨帧比值偏差：绝对 <= 0.22%，相对 +2.5% ~ +36.8%。

5) 顺带订正两处：
   a) SNR-DESIGN-01 6C 引用的 1.3127 不是 frame_snr 的偏差（分子来自另一条路径），
      「帧级 SNR 偏低 23.8%」不成立；frame_snr 的真实偏差实测为偏低 15%~77%（随帧结构含量变化）。
   b) frame_snr 的 sigma 是**整帧 2 轮裁剪 RMS**，在 M42 星云面板上被结构撑大 2.4~3.7 倍（机理核对，无需真值）。

6) 需要补强（不是回退）：重建算子补**正齐次性**要求；局部 sigma 估计器必须**结构感知**；
   若要帧级与稀疏层一致，方向必须是 frame := 稀疏层摘要。
```
