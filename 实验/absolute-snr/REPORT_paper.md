# P2｜跨观测帧参考信噪比的物理定义、协方差传播与真实覆盖率检验

> 科学论文修订稿。原 `REPORT_paper.md` 中大量 Python 自检不等价于调用生产实现，本稿据此重列可检验主张；原始步骤与历史数字保留于 Git 历史、`REPORT_experiment.md` 和本单元 `code/`。本次未独立重跑服务器真帧。共用文献见 `../shared/references/CORE_REFERENCES_VERIFIED.md`。

## 摘要

本文考察天文图像标准化与叠加链中“跨帧绝对信噪比”的可比较意义。首先定义固定参考通量和 PSF 下的条件通量方差，建立已知背景、自由背景与相关噪声三种口径之间的转换，再将参照源的 SNR 与图像逐像素/点源的叠加权重区分。我们提出以独立真值合成、物理前向和重复真实帧构成的验证方案，使方差预测与经验覆盖率接受相互独立的检验。代理报告中，117 颗真实共同星的帧间散度为 0.037978 mag，对应解析预测 0.013599 mag，约 2.79 倍；这表明旧观测域中的`sigma_F`不能未经修正直接解释为实测总误差，却尚不足以把多余散度单独归因于噪声模型。本文的“绝对”指明确定义的物理刻度，而不是不附假设的普适置信度证明。

**关键词**：信噪比；CCD 噪声；点源 Fisher 信息；背景拟合；协方差；叠加；经验覆盖率。

## 1 问题及文献基准

Newberry [R04] 已处理天光扣除 CCD 测光的内部随机误差，Zackay & Ofek [R05] 讨论在背景主导极限下科学目的明确的最优合并及其噪声性质；这些并非 ACSD 的原创发明。本文聚焦科学合同是否能兑现：`frame_snr` 与 `sparse_snr_layer` 何时代表同一被估量、映射前后 covariance 如何改变、参考点源噪声是否可以被误用成弥散面亮度的最佳叠加权重。

假说：H1 已知独立噪声与固定 PSF 的解析 `sigma_F` 能在合成样本上达到标称覆盖率；H2 估计背景/引入像素协方差后必须传播新增不确定性；H3 真帧预测误差经独立重复观测校准后具备指定适用域；H4 点源信息权重与面亮度逐像素权重一般不相同。

## 2 统计观测模型与条件 SNR

观测像素向量 `y=F P + b 1 + e`：`F` 为源积分通量 ADU，`P` 为归一化 PSF（sum P=1），`b` 为背景 ADU/pixel，`e` 的协方差矩阵 `C` 单位 ADU²。假设 PSF 和背景都已知，若 `C` 正定且固定，与 F 无关，则广义最小二乘 (GLS) 的幅度方差

```text
sigma_F^2 = 1 / (P^T C^-1 P)
SNR_ref   = F_ref / sigma_F
```

独立噪声 `C=diag(sigma_i²)` 时 `sigma_F^-2 = sum P_i²/sigma_i²`。若背景 `b` 同时待估，设 `A=[P,1]`，应使用 `Cov([F,b])=(A^T C^-1 A)^-1` 的 `FF` 元素；含天空多项式时还应加入相应设计列。估计背景的相同样本可能引入额外协方差；“已扣背景”不自动等于背景真值已知。

噪声尺度中，若增益 `g` 定义为 e-/ADU，源、天空和暗流散粒项的 ADU² 方差各自为电子计数除以 `g²`，读噪 `RN_e²/g²`。将 ADU 计数 `S_ADU` 代入泊松式时其分量 `S_ADU/g` 单位为 ADU²；`g` 的反约定（ADU/e-）不能沿用这个式子。校准/测光尺度 `alpha` 的确定性变换为 `y'=alpha y`、`C'=alpha² C`，故 SNR 的无量纲比值在同一个 alpha 下不变；**alpha 自身估计误差会引入跨像素/跨帧共同系统项，不应作为独立像素噪声消失**。

对于依赖未知 F 的泊松方差，`C(F)` 不再固定，上式仅是指定参考通量 `F_ref` 下的局部/条件计算：需要说明本帧参考星等、响应尺度、PSF、像素尺寸和使用的源光子项；不能直接把它解释成任意明亮源的全局 Fisher 下界。

## 3 重采样相关噪声与合并目标

定义线性重采样算子 `R`，则完整输出协方差 `C_out=R C_in R^T`。仅保留 `diag(C_out)` 后，孔径/PSF 通量误差中的非对角贡献一般仍存在。对于任意确定的线性统计量 `a^T y`，真实方差为 `a^T C a`，不是 `sum a_i² C_ii`，除非交叉项恰好为零。若由于数值低秩导致 `C_out` 奇异，不能直接数值求逆并当作“零噪声方向有无限信息”；必须在原始观测的支持子空间内求解或显式定义额外独立噪声与正则。

**估计量分立：** 对固定点源通量，最优权重由相应 PSF-协方差信息决定；对于同一球面位置的**弥散源面亮度**，若各帧对该量有无偏像素估计，其独立帧权重为该估计量方差的逆。不能从 `SNR_ref²/F_ref²` 的点源恒等式推断像素级面亮度的完整最优权重；需验证二者的估计目标与方差口径完全相同。若帧间存在共同校准误差，独立帧逆方差不再自动最优。

## 4 实验设计

| 组 | 数据与正/负对照 | 统计量及可证伪命题 |
|---|---|---|
| P2-A 独立高斯/泊松 | 已知 PSF、已知背景，控制增益及电子/ADU 双向换算；负例故意混用 g 定义 | 解析 `sigma_F` 比 MC 标准差，68/90/95% 覆盖，误差分位数；要求随 MC 次数给置信区间 |
| P2-B 自估背景 | 同一随机图像，已知 b/拟合 b/背景多项式三臂；改变孔径与背景像素数 | `Var(Fhat)`、偏差、覆盖率差，明确估计背景代价 |
| P2-C drizzle 协方差 | `C=R V R^T` 并注入显式独立底项；比较完整 C、仅对角和有限支撑模型 | 方差比、实际覆盖、最小特征值、空间噪声相关长度；负例故意丢交叉项 |
| P2-D 点源与弥散源 | 点 PSF、渐扩张星系/星云/均匀面亮度的共同真值图 | 针对点源 F 与扩展源亮度分别计算方差和效率比；不得混用两种被估量 |
| P2-E 真实重复帧 | 按帧 ID 交叉识别 117 星（或实际合格样本），独立训练/验证帧，分星等/颜色/位置 | paired z-score 分布、1σ/2σ 覆盖率、sigma 实测/解析比、共模去除前后 |
| P2-F 消费链 | 真正调用 `normalize`→`mosaic` 的构建产物，对比生产帧头与稀疏层 | 对象存在、单位一致、用到了谁、错误状态能否判红 |

P2-A～D 需要不同随机种子和至少一组未参与调参的冻结数据；P2-E 不能把同一恒星的多次重复观测错误地当作独立样本。若 `sparse_snr_layer` 仅被文档声明而无生产者，P2-F 必须判 `NOT_IMPLEMENTED`，而不是因纯 Python 重演公式通过而判生产通过。

## 5 现有观测证据与解释

代理报告的 G1 解析条件臂显示 `sd(Fhat)/sigma_F=0.9880–1.0110`，仅在背景已知及前向世界成立；G2 相关噪声臂表明忽略协方差后可产生明显乐观偏差；G3 点源/弥散源用错被估量可带来巨大效率损失。G4 真实帧以 117 颗共同星报告 `sigma_emp=0.037978 mag`、`sigma_pred=0.013599 mag`、比值 `2.7928`、标称 1σ 覆盖 `57.3%`。**以上均为 AGENT_REPORTED，而非本次复跑结果**；G4 的标准化 z-RMS、覆盖率分母和同源配对误差模型须随原始证据复核，且不能把“比值约 2.79”一律解释成独立像素随机噪声低估 2.79 倍。

待分离误差包括空间平场、测光零点、色差、PSF/孔径漂移、源变化以及重采样相关。必须对配对差先用独立留出锚校正共同零点与颜色项，并把“条件统计噪声”和“校准系统误差”分列，而非通过全局乘常数直接掩盖失败。

## 6 当前科学结论及发表条件

P2 的解析式有严格、可复算的成立域，**但真实帧绝对误差校准未闭合**。在真实帧 coverage 验证通过之前，对外只能称“参考观测模型下的条件/标度 SNR”，不得称“所有帧的置信标准差已经绝对校准”。下一阶段的验收标准是：同一 `F_ref`、固定 PSF 与已记录背景状态下，三类数据各有独立协方差/系统项误差预算；真实星配对报告各子样本置信区间；生产端存在可读写的 `frame_snr` 与 `sparse_snr_layer` 证据链。
