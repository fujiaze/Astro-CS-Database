# P2｜跨观测帧参考信噪比的物理定义、协方差传播与真实覆盖率检验

> 本篇区分参考观测模型下的**条件**通量方差与实测总残差散度，把“公式成立”与“真实帧覆盖率合格”分开判定，按最低图表集登记独立 oracle、生产探针读数、真实帧覆盖与适用域。逐项读数、脚本与输入哈希台账见 `REPORT_experiment.md` 的噪声/协方差/真实覆盖复验专节、`docs/S05_P2_evidence.json`、`docs/S05_REPORT.md` 与本单元 `code/s05/`；四张实测图见 `figures/`。

## 摘要

本文考察天文图像标准化与叠加链中“跨帧绝对信噪比”的可比较意义。先定义固定参考通量和 PSF 下的**条件**通量方差，建立已知背景、自由背景与相关噪声三种口径之间的转换，再把参照源的条件 SNR 与图像逐像素/点源的叠加权重区分。本文以独立真值合成、生产球面权重探针与真实重复帧构成验证方案，使方差预测与经验覆盖率接受相互独立的检验。实测把四条结论钉死：其一，白噪+光子条件下的解析条件方差在合成样本上自洽（`sd(F_hat)/sigma_F = 0.9929–1.0095`，68/90/95% 覆盖率与标称一致，135 次 Wilson 检验 5 次不含标称、期望 6.75），但换成自由背景或线性重采样后必须另计代价与协方差（对角近似最负 `E_diag = −0.4858`）；其二，`k_corr` 查表的物理驱动量是尺度比 `rho = 叶/源`，而查表只收 `(pixfrac, scale_arcsec)`、不收输出 nside，标定件把输出固定在 `tile_order=0`；生产默认帧 `tile_order=9`、源 `0.9666″/px` 时 `rho≈0.83`，独立 MC 给 `k_corr = 2.33`、生产球面权重探针给 `2.054–2.058`，而冻结回退只有 `1.4` ⇒ 控制点方差被低估、逆方差权重被高估约 `1.5×`，该域标 **`UNCALIBRATED`**；其三，真实帧独立配对测得 **2195** 颗共同星、`sd(dmag)/median(sigma_analytic) = 3.37`（empirical 口径 `2.73`），但分层显示低 SNR 端解析 σ 与实测散度同量级（`z_rms 1.86–2.11`）、亮端 `z_rms 5.09–10.34`，多余散度由**与 SNR 无关的系统项地板**支配（`sigma_sys = 0.036–0.070 mag`），加地板后留出集 68.27% 覆盖率 `0.8611`、`z_rms = 1.028`（过覆盖 ⇒ 残差厚尾）；其四，`sparse_snr_layer` 的**生产写点缺失**（`lib/**` 零写点、端口注册表零命中、生产运行 `declared=0`），只能判 `NOT_IMPLEMENTED`。本文的“绝对”指明确定义的物理刻度与条件刻度，而不是不附假设的普适置信度证明。

**关键词**：信噪比；CCD 噪声；点源 Fisher 信息；背景拟合；协方差；叠加；经验覆盖率。

## 1 科学定位和先前工作

Newberry [R04] 与 Horne [R13] 分别奠定扣天空后 CCD 噪声估计与轮廓加权最优提取的经典基础，Zackay & Ofek [R05] 进一步讨论背景主导极限下科学目的明确的最优合并，Fruchter & Hook [R06] 给出可变像元重采样与相关噪声的处理框架。这些都不是 ACSD 的原创发明。本文聚焦科学合同能否兑现：`frame_snr` 与 `sparse_snr_layer` 何时代表同一被估量、映射前后 covariance 如何改变、参考点源噪声是否可以被误用成弥散面亮度的最佳叠加权重，以及真实帧上的预测散度差是否已被独立校准。

假说：H1 已知独立噪声与固定 PSF 的解析 `sigma_F` 能在合成样本上达到标称覆盖率；H2 估计背景/引入像素协方差后必须传播新增不确定性；H3 真帧预测误差经独立重复观测校准后具备指定适用域；H4 点源信息权重与面亮度逐像素权重一般不相同。

## 2 统计观测模型与条件 SNR

观测像素向量 `y = F P + b 1 + e`：`F` 为源积分通量 [ADU]，`P` 为归一化 PSF（`sum P = 1`），`b` 为背景 [ADU/pixel]，`e` 的协方差矩阵 `C` 单位 ADU²。假设 PSF 和背景都已知，若 `C` 正定且固定、与 `F` 无关，则广义最小二乘（GLS）的幅度方差

```text
sigma_F^2 = 1 / (P^T C^-1 P)          (ADU^2)
SNR_ref   = F_ref / sigma_F           (dimensionless)
```

独立噪声 `C = diag(sigma_i^2)` 时 `sigma_F^-2 = sum_i P_i^2 / sigma_i^2`。若背景 `b` 同时待估，设 `A = [P, 1]`，应使用 `Cov([F,b]) = (A^T C^-1 A)^-1` 的 `FF` 元素；含天空多项式时还应加入相应设计列。估计背景的相同样本可能引入额外协方差；“已扣背景”不自动等于背景真值已知。

**`sigma_F` 的边界必须写明：它是给定 PSF、背景已知、噪声模型与独立性假设下的条件方差。** 自由背景、估计天空多项式、光度零点系统误差与重采样引入的协方差各有自己的口径，不可互相冒名：`variance_bg`（背景拟合项）、`variance_w`（逐像素权重项）、光度系统误差与重采样协方差必须分列，任何一项都不能被另一项吸收后仍自称同一被估量。

噪声尺度中，若增益 `g` 定义为 e-/ADU，源、天空和暗流散粒项的 ADU² 方差各自为电子计数除以 `g²`，读噪 `RN_e²/g²`。将 ADU 计数 `S_ADU` 代入泊松式时其分量 `S_ADU/g` 单位为 ADU²；`g` 的反约定（ADU/e-）不能沿用这个式子。校准/测光尺度 `alpha` 的确定性变换为 `y' = alpha y`、`C' = alpha² C`，故 SNR 的无量纲比值在同一个 `alpha` 下不变；**`alpha` 自身估计误差会引入跨像素/跨帧共同系统项，不应作为独立像素噪声消失**。

对于依赖未知 `F` 的泊松方差，`C(F)` 不再固定，上式仅是指定参考通量 `F_ref` 下的**局部/条件**计算：需要说明本帧参考星等、响应尺度、PSF、像素尺寸和使用的源光子项；不能直接把它解释成任意明亮源的全局 Fisher 下界。本单元登记的两项仪器常数——`gain = 1.333 e-/ADU`、`read_noise = 8.59 e-`——**帧头没有 `GAIN`/`RDNOISE` 关键字**，取自仓内既有外部实测档，来源标 **`UNVERIFIED`**；使用它们推出的任何方差都继承该状态。

## 3 重采样相关噪声与合并目标

定义线性重采样算子 `R`，则完整输出协方差 `C_out = R C_in R^T`。仅保留 `diag(C_out)` 后，孔径/PSF 通量误差中的非对角贡献一般仍存在。对于任意确定的线性统计量 `a^T y`，真实方差为 `a^T C a`，不是 `sum a_i² C_ii`，除非交叉项恰好为零。若由于数值低秩导致 `C_out` 奇异，不能直接数值求逆并当作“零噪声方向有无限信息”；必须在原始观测的支持子空间内求解或显式定义额外独立噪声与正则。

**估计量分立：** 对固定点源通量，最优权重由相应 PSF-协方差信息决定；对于同一球面位置的**弥散源面亮度**，若各帧对该量有无偏像素估计，其独立帧权重为该估计量方差的逆。不能从 `SNR_ref² / F_ref²` 的点源恒等式推断像素级面亮度的完整最优权重；需验证二者的估计目标与方差口径完全相同。若帧间存在共同校准误差，独立帧逆方差不再自动最优。

生产链在重采样后对控制点方差使用放大因子 `k_corr`（`control_variance = k_corr·(pi/2)·sigma_bg²/N_retained`）。该因子的物理驱动量是输出叶尺度与源像元角尺度之比 `rho`；生产查表只收 `(pixfrac, scale_arcsec)`，**结构上无法表达 `rho`**，因此其标定域必须随产品几何逐次声明，否则只能回退到冻结单数。

### 5.4 适用域与诚实限制（必须同读）

1. **`k_corr` 方向性缺陷（阻断项）。** `scale_arcsec` 的量纲核对**正确**（源帧像元角尺度 `[arcsec/px]`），但驱动量是 `rho = 叶/源`，查表只收 `(pixfrac, scale_arcsec)`、**不收 nside**，标定件把输出固定在 `tile_order=0`。生产默认 `tile_order=9`（叶 `0.805″`）、真帧源 `0.9666″/px` ⇒ `rho≈0.83`；独立 MC + 生产球面权重探针给模型 `2.33` / 生产权重 `2.054–2.058`，而冻结回退只有 `1.4` ⇒ **控制点方差被低估、逆方差权重被高估约 `1.5×`**。保守域仅 `rho ≳ 1.3`；该域逐帧权重要标 **`UNCALIBRATED`**，不得声称 `1.4` 是通用保守上界。
2. **历史比值必须改写为分层读数。** 独立重测得 **2195** 星、比值 `3.37`（shot-only）/`2.73`（empirical），且多余散度由**与 SNR 无关的系统项**支配（低 SNR 端 `z_rms 1.86–2.11`，解析 σ 基本够用；亮端 `5.09–10.34`）。**不得**写成“独立像素噪声低估 `2.79` 倍”；须给分层读数、经验地板层（`sigma_sys = 0.036–0.070 mag`）与适用域。加地板后留出集 68.27% → `0.8611`、`z_rms = 1.028`（**过覆盖** ⇒ 残差厚尾）；空间共模超额 `37.9×`、有效独立样本数保守 **64 块**（星数 2195）。
3. **`sparse_snr_layer = NOT_IMPLEMENTED`。** 消费面在 `module_adapters.cpp:12106-12140`，但 `lib/**` 无生产写点、端口注册表 0 命中、生产运行 `declared = 0`；唯一 `declared = 2` 来自审计夹具手写 sidecar。**不得把设计图当落地。**
4. **`sigma_F` 是条件方差。** 它是给定 PSF/背景/噪声模型与独立性假设下的条件量；留出真实帧校准须另立一层并给适用域与有效样本数；`variance_bg`/`variance_w`/光度系统误差/重采样协方差**不得互相冒名**。
5. **四臂 Oracle 读数**（表 4 第 1–8 行）只在各自的合成世界成立：臂 A `sd(F_hat)/sigma_F = 0.9929–1.0095`；臂 B 负例 24/24 方向欠覆盖、16/24 显著；臂 C 对角近似最负 `E_diag = −0.4858`、35 个有效应构型中 33 个判红；臂 D 两向闭式对称差 `3.6e-15`。合成世界为逐像素独立噪声，**不得**外推为真实数据结论。
6. **登记常数来源 `UNVERIFIED`。** `gain = 1.333`、`read_noise = 8.59` 在帧头**没有 `GAIN/RDNOISE` 关键字**，属仓内实测档登记，不是一手外部常数；由它们推出的任何方差继承 `UNVERIFIED`。
7. **本帧测量无平场/暗场改正；4 px 孔径未做孔径改正。** `sigma_sys` 因此含平场残差与孔径-PSF 耦合，不能单独归因；`tile_order=12` 产品域的 `k_corr` 达 `39.80`（`k>38`），若该类产品进入生产，`1.4` 回退的偏差更大。
8. **`NOT_RUN` 与显式不可用：** `snr_path=dense` 在生产显式 fail-closed（`SNR_PATH_DENSE_UNAVAILABLE`）、Windows 侧复算、`p2_sample_controls` 端到端生产跑一律 `NOT_RUN`；FP32 生产实例与多帧/多块产品级回归未做。上述数据只支持到已扫域（`rho`、`pixfrac`、标定几何），不得外推。

### 5.5 跨篇误差传递反例（P2 → P4/P5）

按统一实验协议的第四条证据腿，P2 应证明“上游噪声/协方差缺陷传播到下游、下游判据能判红”。**本篇 `NOT_RUN`。** 现有反例只能证明 P2 内部判据能判红（臂 B/C 的欠覆盖、臂 A 的 `g` 约定反转、真实帧的 0.10 mag 与 +0.05 mag 注入）。缺什么：① 一条同天区、同滤镜的 P2→P4→P5 数据链，且先冻结被估量是点源还是弥散源；② P3 修复前后各算一次的映射协方差与 P4 消费该协方差时的支持域/权重判据读数（本篇只给出“P3 几何对 P2 噪声幅度小于 MC 分辨率”的单向结论，见 §5.1 第 21 行与图 5）；③ P2 侧 `k_corr`/相关噪声在**生产默认几何**下的逐帧权重，当前标 `UNCALIBRATED`。三者缺一，跨篇链路无法给出。

## 6 结论与可主张贡献

P2 的解析式有严格、可复算的成立域：在已知背景与固定 PSF 的合成世界上，条件方差与标称覆盖率自洽，自由背景与线性重采样各自的代价与欠覆盖可被量化并以阴阳对照判红；`scale_arcsec` 的量纲核对正确，但 `k_corr` 的生产几何落在其标定域之外，逆方差权重被高估约 `1.5×`，该域只能标 `UNCALIBRATED`；真实帧独立配对给出 2195 星、比值 3.37/2.73，并证明多余散度由与 SNR 无关的系统项地板支配，加地板后 68.27% 档过覆盖、残差厚尾；`sparse_snr_layer` 生产者缺失，判 `NOT_IMPLEMENTED`。

因此可论文陈述的贡献是：**一套把参考 SNR 定义为条件刻度、把背景/协方差/系统项分层并给出适用域与阴阳对照的验证方案**，而不是“所有帧的置信标准差已经绝对校准”。在真实帧 coverage 与生产权重域闭合之前，对外只能称“参考观测模型下的条件/标度 SNR”。在原有阻断项不被复现澄清或修复之前，任何发布级主张不成立。
