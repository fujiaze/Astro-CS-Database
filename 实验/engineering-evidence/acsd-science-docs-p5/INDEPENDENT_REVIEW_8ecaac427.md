## 2 生产源码核验：已修与未过发布门

### P3
- `spherical_overlap.cpp` 的 `build_drop_geometry_into` 采用 `c×(α2−α1)+α1×α2` 减少近简并叉积；`compute_intersection` 采用 `(dS·E−dE·S)/(dS−dE)` 的稳定形式。算法方向数学合理。
- 报告的同构型 `ε_j`：`−3.209422e-3 → −8.370272e-10`，1500 构型破 `1e-6` 门 **218→0**。该结果可由已提交的实验探针/摘要追溯，但尚未经本审查独立执行；不得外推到 FP32、MSVC、未扫的大尺度/叶分支。
- 仍留有失稳 `den` 时**回退旧叉积**的分支；建议注入退化几何，确认不会 silently 输出 NaN/任意面积；如果数学上该分支不存在，应写显式诊断与失败关闭而不是假设安全。
- 受 `ACSD_DRZ_P3_FAULT=legacy_cross_normal` 环境变量控制的故障注入路径**直接编进生产源码**。这有科学数据完整性风险：被误设置的运行环境可重新启用已知错误实现。发布构建需通过测试专用编译宏隔离/拒绝该环境变量，或强制在 provenance 标明故障注入，默认非测试发行不可进入。

### P5
- `sky_plane.cpp` 已基于实际有效控制点枚举图，按分量取锚并用 `is_anchor` 进入求解与 Schur 块，附逐分量秩检验和错误状态；结构修复方向成立。
- S9b 报告：compB 指标 `0.1281497 → 0.0005982`，compA `0.0001565 → 0.0003932`（另一个分量数值略变差）；最大诊断量改善约 214×。但**修前分母 bg=−5988.917、判据混入斜坡**，`0.128` 不能读作“物理接缝 12.8%”；此改善仅是失控规范诊断症状。跨两个不重叠分量仍有 `18.84 ADU / 6.07%` 未定标绝对零点。
- `S9`、`S13` 修后 `rc=7` 是更保守的显式失败关闭，属于产品能力边界，不应再列“零回归”；要不要输出独立分量产品应另获授权。
- per-component 调试 JSON 的 `cross_component_comparable = (cg.frame_ids.size()>=2)` 容易误导读者：“分量内至少两帧可比较”**不等于不同分量间可比较**。虽然顶层另有 `cross_component_absolute_zero_identifiable=0`，建议把组件字段改名为 `within_component_relative_comparable`，提供 schema 向后兼容，不要让消费端误读。
- `ACSD_SKY_P5_FAULT=global_anchor` 同为生产编译的坏算法开关。正式产品需禁用或显式测试模式约束；`ACSD_SKY_COMPONENT_DUMP` 是可选诊断旁路，不能替代正式 manifest 中的分量状态与可比较范围。
