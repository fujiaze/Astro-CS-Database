# 文档整理工具

本目录保存清单、路径迁移和结构检查脚本；工具不评价科学正确性，也不代替逐篇阅读。

inventory.py 固定原始 Git 基线生成逐文件清单，区分已重写、保留精读、归并、附录迁移和未完成阅读。check_documentation.py 检查当前索引、链接、模块保留内容、仅字符串的机器元数据更新，以及来源档案的原始字节/对象身份；不执行科学程序。

rewrite_*.py 是分主题的一次性整理载体，先保存原文再重写，带来源档案的脚本拒绝覆盖已有档案。不要把全部脚本当可反复运行的构建流程；重复执行旧迁移可能覆盖后续正文。各脚本内定义仅供inventory登记时导入，不在导入时写文件。
