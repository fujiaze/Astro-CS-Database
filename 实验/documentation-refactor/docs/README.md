# 整理与研究问题

本目录保留文档重构中的科学、数学与证据问题，以及从正式设计移出的过程记录。

[待推导问题](SCIENTIFIC_QUESTIONS.md)保存原文、分歧、影响和后续所需证据；[逐文件清单](ORIGINAL_FILES.tsv)固定原始基线并记录阅读/处置范围，[检查结果](CHECK_RESULTS.json)只代表声明的结构核对。

各主题的 *_SOURCE.txt 按原始字节保留重写前正文，带提交、Git对象和字节长度；PUBLIC_API与资源记录使用各自保存格式。来源正文中的旧任务指令、模式、阈值、运行状态和“已完成”声明属于历史，不能重新成为当前实施授权或验收事实。观察附录与计算示例按原条件保留，未运行就不称本轮复算。
