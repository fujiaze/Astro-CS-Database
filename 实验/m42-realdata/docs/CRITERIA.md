## C1 SCI-A：测光星等坐标系

### C1-G1 逐帧残差散度 vs EXP-04 量级（**主判据，判红**）

- **规范**：`ASTROCS_DESIGN.md:120-128`（k_photo 是线性乘性标度，每帧独立标定到同一测光星等
  坐标系）；判据形态与数值 band 见 `实验/photometric-magnitude/REPORT_paper.md:71-80`（双边界）、
  `:147-149`（三帧物理前向仿真 `sigma_obs` = 0.045344 / 0.057457 / 0.051718 mag）、
  `:213`（真实 testdata 帧 n=157、`sigma_obs` = 0.026520 mag）；
  `sigma_residual` 定义见 `lib/algorithms/photometry/cpp/src/star_matcher.cpp:612-621`
  （`MAD(r_inliers)/0.6744897501960817`，`r = log10(F_instr/F_syn)`）。
- **判据**：`2.5·sigma_residual_dex ≤ 0.057457 mag`（EXP-04 band 上界）。
- **实测**：49 帧中位 **0.44746 mag**，min 0.33280、max 0.56886、std 0.06699；
  `n_matched` 中位 295（min 175 / max 555）。**49/49 帧超界，中位为 band 上界的 7.8 倍。**
- **能绿证明（正例控制 `C1-G1c`）**：把 MAD 注入到 EXP-04 真实帧量级（0.02652 mag）后，
  同一估计器（400 次 MC）返回中位 **0.03904 mag ≤ 0.057457** ⇒ 判绿。
  即**该门是可以过的**，红不是门本身造成的。
- **能红证明（负例控制 `C1-G1d`）**：MAD 放大 4 倍 → **0.33769 mag** ⇒ 判红。
- **差异来源分析**（诚实，不冒充结论）：
  1. **样本选择**：EXP-04 的真实帧测试用 `magG < 16`、`chi2 < 4` 得到 157 颗星
     （`实验/photometric-magnitude/code/step8_real_frame.py`）；生产 `star_matcher` 用的是
     同一帧的全部 matched 星（本数据 175–555 颗），**没有星等/chi2 截断**。
     M42 核心区星云弥散背景强、恒星密集，暗星 PSF 测光在强梯度背景上偏差大 ⇒
     把暗端并入拟合会把 MAD 抬高一个量级。
  2. **空间自由度**：EXP-04 的真实帧测试额外拟合了 `m_degree = 2` 的**空间增益场**；
     生产每帧只拟合**一个标量** `k_photo`。平场残差在 2° 视场内以百分比量级存在，
     对应 ~0.01–0.05 mag，不足以解释 0.42 mag 的差距，但方向一致。
  3. **已排除的假设（做过实验，不成立）**：解析 PSF 通量域与数值 `flux` 域不一致
     ——实测比值中位 0.0、MAD 0.0（无域差）；星云污染经由 `background` 可辨
     ——不成立（`p1_flux.json` 背景 p05/p50/p95 = 179.3/195.0/225.0 ADU）。
  4. **样本量不是原因**：EXP-04 在**同一帧**上用 n=157 就达到 0.0265 mag，而本数据
     n 中位 295、min 175 ⇒ 统计量本身够用。
- **诚实边界**：本单元**没有**独立复现 EXP-04 的选星口径（缺 per-star `r` 值，产品未落盘），
  因此"差异来源 1"是**基于已知口径差异的推断**，不是被本单元直接证明的结论。

### C1-G3 零点平移不变量（退化对照）与 k≡1 对照

- **规范**：`实验/photometric-magnitude/REPORT_paper.md:85`（`sigma_residual` 对全局乘性
  平移不变）。
- **数值演示（`C1-G3b`）**：`r` 整体平移 0.6 dex（等价整帧乘 10^0.6）后，
  MAD 由 `0.07474694162221036` 变为 `0.07474694162221047`，差 **1.11e-16**（≤1e-12 门，判绿）。
- **k≡1 对照（`C1-G3`）**：k≡1 时残差散度**不变**，但帧间有效零点差变成
  **0.9276 mag（T2）/ 1.8059 mag（T3）**（= `2.5·log10(kmax/kmin)`）。
  这正是"真值无效应 ⇒ 归零"的对照形态：**k_photo 的全部可观测效应都在帧间零点上，
  不在帧内散度上**。
- **组内散度独立复算（`C1-SPREAD-RECOMPUTE`）**：`log10(kmax/kmin)` 复算与落盘值
  **逐位一致（差 0.0）**：T2 = 0.3710387326687012、T3 = 0.7223431688187283。
  散度**如实记录**；`photscale_spread_gate = "none (owner ruling 9.49: frame-independent)"`
  （`lib/infrastructure/scheduler/src/module_adapters.cpp:4826-4838`），本单元**不改该裁决**。

### C1-DIAG 跨帧乘性一致性：登记 UNDECIDABLE（诚实边界）

- **做法**：逐叶对在共同覆盖叶上拟合 `S_i = a·S_j + b`（稳健 OLS）与中位比值 `median(S_i/S_j)`，
  再用加权最小二乘解逐帧对数零点 `o_i`（规范 `o_0 = 0`），报告 `max|o_i − median(o)|`。
  为剥离"各夜天光辐射亮度差"这一**真实加性差**，样本限定为
  `S > 3·(k·bg/A_pixel)`（source-dominated）。
- **对照臂**（判绿，证明估计器对 k 有响应）：
  | 臂 | T2 `max|o|` | T3 `max|o|` |
  |---|---|---|
  | 标定（OLS） | 0.2631 dex | 0.2726 dex |
  | 标定（中位比值） | 0.2125 dex | 0.1672 dex |
  | **不标定 k≡1**（OLS） | **0.0568 dex** | 0.5655 dex |
  | **不标定 k≡1**（中位比值） | **0.0549 dex** | 0.5319 dex |
  | k 随机置换（OLS） | 0.3517 dex | 0.6769 dex |
- **为什么登记为不可判定**：T2 上**两个估计器都**给出"不标定反而更一致"（差 −0.2063 / −0.1576 dex），
  T3 上**两个估计器都**给出"不标定更差"（差 +0.2929 / +0.3648 dex）——方向相反，
  且估计器间分歧 0.0487 / 0.0719 dex 与待测效应同量级。
- **混淆项量化（`sky_confound_diagnostic`）**：帧 `signal` 平面的中位电平 / 天光等效电平
  `(k·bg/A_pixel)`：T2 中位 **1.0190**（min 0.9358 / max 1.6545）、T3 中位 **1.0342**
  （min 0.9521 / max 1.5045）⇒ **帧信号平面被天光主导**，帧间差异主要来自各夜天光辐射亮度，
  不能读作标定失败。
- **结论**：本单元**不宣称**"生产标定不一致"，也**不宣称**"生产标定一致"；
  登记为"用本产物不可判定"，并把可判定的对照臂（置换 k 严格更差）留作估计器有效性证据。

## C2 SCI-B：跨帧绝对 SNR

### C2-G1 产品 variance 平面的噪声律（**判红**）

- **规范**：`ASTROCS_DESIGN.md:131-137`（跨帧绝对 SNR 传递链）；
  `docs/science/PHASE2_UPM.md`、`docs/science/SNR_CHAIN.md`；
  噪声律 `Var(p) = sigma0² + D(p)/g` 的 EXP-06 实测指数带 **0.995–1.017**
  （`实验/absolute-snr/docs/EXP-06-SUMMARY.md`、`results/exp06_e1_analytic.json`）。
- **判据（非退化设计）**：`log10(Var)` 对 `log10(signal)` 的加权最小二乘斜率
  必须 **= 1 ± 0.05**，**且** 400 次自助的 95% CI 半宽 **≤ 0.05**（后者防止"CI 宽到
  必然包含 1"的恒真门）。
- **实测**：斜率 **−0.01174**，95% CI **[−0.04616, 0.02027]**（半宽 0.0332，
  信号跨 0.36 dex）；`corr(signal, variance) = 0.0007`，逐帧相关
  0.0030 / 0.0018 / −0.0002 / −0.0015；variance 中位 `1.0350e9`、robust scale `3.3680e8`。
  ⇒ **方差几乎与信号无关（平坦），判红。**
- **能绿/能红控制**：合成 `Var ∝ D` → 斜率 1.00244（绿）；合成平坦方差 → 0.00206（红）。
- **差异来源分析（未定论，登记）**：帧 HiPS `variance` 平面单位不是 `signal²`
  （variance 中位 1.0350e9 与 signal 中位 ~2e-4 相差 13 个数量级；`ivar·variance = 1.0` 精确成立），
  其量级更接近"帧级标量天光 + 读出噪声"的量级。**是否因为 Phase-1 输入的逐像素 variance
  用了帧级标量天光而非逐像素局部信号，本单元未定位**；已登记为生产侧待查项。

### C2-G2 独立经验噪声律（T2 绿 / T3 红）

- **做法（独立于产品 variance 平面）**：对共同覆盖叶上的帧对，取
  `(x_i − x_j)²/2` 作为该叶噪声方差的无偏估计，按信号分 24 箱取中位，
  再做 `log10(V)`–`log10(D)` 回归。判据：斜率 = 1 ± 0.15。
- **实测**：**T2 = 0.97432**，95% CI [0.19037, 1.61583]（44,653 个叶样本）⇒ **判绿**；
  **T3 = 2.36037**，95% CI [0.09206, 4.25669]（72,400 个叶样本）⇒ **判红**。
- **解读与边界**：T2 的经验噪声律与 `Var ∝ D¹` 相容；T3 超线性，说明 T3 的帧间散度
  被**系统项**主导（T3 跨更多观测夜，`k_photo` 散度 0.7223 dex 也更大）。
  CI 较宽（自助半宽 0.71 / 2.08）⇒ 本判据只能做**分块定性**结论，不能给指数的高精度值。
- **偏差方向**：该代理把帧间系统差计入噪声 ⇒ 斜率被**高估**（偏向 >1）。

### C2-G3 权重效率损失 E（**判红**）

- **规范与定义**：`实验/absolute-snr/code/exp05/exp05_common.py:393-408`
  （`E = Var_w/Var_opt − 1`，`Var_w = Σw²·var_true/(Σw)²`，`Var_opt = 1/Σ(1/var_true)`）；
  EXP-06 参考（scene A4_realistic，6 seed，中位）：`phys_auto` **7.33589e-05**、
  `interp_spline` 2.00861e-03、`frame_scalar` 5.81691e-02、`naive_pixel` 1.60982e-02、
  `phys_unsep` 4.22290e-02。
- **真值方差场来源**：`E` 需要 `var_true`；EXP-06 的真实数据臂因此**没有算 E**
  （`results/exp06_e3_real.json` 中 `eff_loss` 出现 **0** 次）。本单元用 §C2-G2 的
  **跨帧配对差**在 24 个信号箱上的中位作为 `var_true`，产品权重取帧 HiPS `ivar`
  （`p2_integrated.json: weight_basis = "per_sample_ivar"`）在同一批箱上的中位。
- **实测**：
  | 臂 | E |
  |---|---|
  | 产品 `per_sample_ivar` | **1.143239** |
  | 常数权重（`frame_scalar` 型） | **1.143239** |
  | `w = 1/var_true`（退化对照） | −2.22e-16 |
  | 合成 `w ∝ var_true^-0.997`（正例控制） | 8.87e-06 |
  | 合成 `w ∝ var_true^-0.9`（对照） | 9.95e-03 |
  `var_true` 跨 **49.34 倍**，产品权重的 `max/min = 1.0`（在信号维上**完全不变**）。
- **判红**：`E(product) = 1.1432` 比 EXP-06 推荐方法（7.336e-5）差 **4 个数量级**，
  且 `E(product)/E(常数权重) = 1.000000` ⇒ **产品的权重没有利用"噪声随信号变化"这一信息**。
- **边界**：`var_true` 是代理，偏差方向为**高估 E**；但 `E(product) = E(常数)` 这一
  **恒等式**不依赖代理（只依赖"权重在信号维上是常数"这一可直接观测的事实）。

## C3 SCI-C：加性天光与无接缝

### C3-SELFTEST 判据本体逐位一致

- 本单元 `code/seam_criterion.py` 是 `实验/additive-sky-seamless/code/sci_c_common.py:356-411`
  的逐字副本；SELFTEST 在 4 组随机 512×512 输入上比较 `step/excess/rel`，
  最大绝对差 **0.0**。

### C3-G1 / C3-G1b 导出图接缝（朴素判红 → 行块判别后判绿）

- **几何说明**：p3 导出图是 TAN 重投影，**512 块网格与 HiPS tile 网格不对应**；
  本单元在与渲染器 `vis_report.json` **同一块网格**（4096/512 = 8×8）上复算权威判据，
  做同几何对照。
- **朴素判据（`C3-G1`，14 条边界合并）**：最大 `|excess − mu|` = **4.50131e-06**，
  off-locus 零假设 `sigma = 2.981e-07`、阈值 `5σ = 1.496e-06` ⇒ **判红**。
  超界的是 x=2048（−3.573e-06）与 y=2560（−4.496e-06）。
- **行块一致性判别（`C3-G1b`）**：把同一判据本体套在 4 个 1024 行块的列剖面上
  （`steps_on_profile`，仍调用 `_step_at` + off-locus 对照）。
  真接缝应在各块同号同量级；天体结构不会。
  结果：**列向仅 1/7、行向仅 1/7 边界在 4 块上同号**；一致边界的最大 `|excess|` =
  **5.916e-07 < 1.496e-06 ⇒ 判绿**。不一致者列向
  x=512(6.2e-08)、x=1024(2.5e-08)、x=1536(9.5e-07)、x=2048(−7.6e-07)、x=2560(4.8e-07)、
  x=3072(−5.3e-08)；行向 y=512(−5.0e-07)、y=1024(−5.6e-07)、y=1536(−2.0e-07)、
  y=2048(−2.8e-06)、y=2560(1.4e-07)、y=3072(−5.6e-07)。
- **结论**：`C3-G1` 的红是 **M42 星云纤维结构造成的假阳性**，不是加性天光接缝。
  这是"朴素判据在真实天区上不可直接用"的可判定证据。
- **检测限标定（负例注入 `C3-N1`）**：在最干净的边界 x=1024 注入已知加性阶跃
  `A`，**A* = 2e-06**（阈值 1.491e-06）；`A = 0` 时 excess = 3.446e-07 ⇒ 判绿
  （假阳性控制 `C3-N1b`）。注入响应近似线性：
  A=1e-6 → 1.06e-6、A=1e-5 → 5.67e-6、A=1e-4 → 8.76e-5。
- **与渲染器度量的对照**：`vis_report.json` `seam_ratio = 1.00961`（门 1.5，
  即"无接缝"），其 `seam_v = 2.004e-06` / `inner_v = 1.985e-06`。渲染器度量是
  **块内方差比**，与权威判据的 **off-locus 台阶**不同量；本单元给出的是后者的实测值与检测限。
  渲染器 verdict 仍为 FAIL，原因是另一条发现：`covered_but_nonfinite_px = 466515`（2.78%）。

### C3-G2 加性合成 vs 算术平均 / 取最大 / 取最小

- **规范**：`docs/science/PHASE2_UPM.md:186-190`（纯加性 `calibrated_f = raw_f − C_f`）、
  `lib/algorithms/coverage/src/integrate.cpp:75`（`signal = Σw·x/Σw`）。
- **做法**：抽样 16 个输出 tile，用 `p2_corrected_*.bin`（fp64）+ 帧 HiPS `ivar` +
  `p2_rejection_sample_mask.bin` 重建，与 `p2_integrated_signal.bin` 逐叶比。
  **顺序约定经实测确认**：`p2_integrated_signal` 与 corrected bin 在 **FITS 序**下与帧
  HiPS tile 相关系数 +0.96…+0.99，在 NESTED-local 序下 ≈0。
- **实测（最大相对残差）**：加性加权和 **0.0**（判绿）；算术平均 **1.159**、
  取最大 **9.194**、取最小 **1.607**（三负例全判红）。

### C3-G3 天光保留（非全减背景）

- **规范**：`ASTROCS_DESIGN.md:139-145`（保留公共天光平面、多退少补）、
  `p2_corrected.json` 的 `additive_mode_effective = "delta"`、`c_subtracted = false`、
  `sky_plane_mode = "delta_to_B_ref"`。
- **判据**：`corrected 样本电平 / 帧自身天光等效电平 (k·bg/A_pixel) > 0.3`。

- **含义**：产品确实做的是"减 δ 保留 B_ref"，不是"全减背景"。

  `cand = 0` 的叶 14,866,270（= `nused = 0` 的叶，完全一致）。
- **负例注入**：`nused+1` → 137,101,312 叶判红；`candidates//2` → 122,235,042 判红；
  `candidates→0` → 122,235,042 判红；`nrej→0` → 14,109,343 判红。

### C4-G2 / C4-G3 三方交叉核对

- **掩码 vs nused（`C4-G2`）**：24 个抽样 tile 上，由 `sample_mask` 逐 slot 计数得到的
  accepted 数与 `nused` **逐位一致（不一致叶数 0）**；抽样合计
  `Σ mask_ones = Σ nused = 50,136,578`。
- **输入侧 support（`C4-G3`）**：`candidates(p) == #{帧 k : support_k(p) > 0}`
  （`geometric_n_source = "frame_support_gt0"`）在 24 个抽样 tile 上**不一致叶数 0**
  （`geom_total = cand_total = 50,905,958`）；`geom < cand` 的叶数 0。
- 含义：**没有重复计入、没有丢失**；逐样本掩码、输出计数、输入几何三者互相闭合。

### C4-G4 层级面积守恒

- `Σ_p support·A_cell(order)` 在 order 0..9 上相对差 **8.754e-09**
  （= `eps_fp32` 的 **7.3%**）；order0 总面积 **3.644293e-04 sr** = 2.391468e+07 个叶面积
  （`A_cell = 1.523873e-11 sr`）。
- **阈值设定说明（不是放松判据）**：`support` 产品是 **FP32**，单值相对表示误差
  `≤ eps_fp32 = 1.19e-07`；`Σ support·A_cell` 的精度不可能优于该地板。
  原拟阈值 1e-9 **低于 FP32 可表示地板 2 个数量级**，属**阈值设定错误**（不是数据错误）。
  现取 **1e-6**（≈8.4×`eps_fp32`），并配负例：把 order5 的 support 整体乘 (1+1e-5)
  → 偏离 9.991e-06 > 1e-6 ⇒ **判红**（证明阈值仍可红）。

### C4-G5 EXP-07 极区/接缝缺陷域**不显现**的实测确认

- **来源**：`实验/healpix-polar/docs/EXP-07-POLAR.md:412`（14 个 face 角点 =
  2 极点 + 8 三角点 dec=±41.810315° + 4 赤道角点 dec=0°）、`:650-657`（`u+v=1` 接缝地板，
  触发条件 `A_drop ≤ 1.4e-10 sr ⇔ 像元尺度 ≤ 2.4″/px`）、`:670-673`（小 drop 未定位共同地板）、
  `:677`（未覆盖清单）。
- **做法**：用 `p2_samples.json` 的 33,472 个控制点（每 tile 64 个，覆盖 tile 内部）
  作为天区样本，外扩 **tile 半对角 0.0810°**（= `256·√2·hp_res`）得到天区包络，
  再算到各奇点的实测角距。
- **实测**：
  | 量 | 实测 | 阈值/域 | 判定 |
  |---|---|---|---|
  | `|z|` 范围 | **[0.06657, 0.12223]** | 极冠 `|z| > 2/3 = 0.66667` | 极冠叶数 **0** ⇒ RC1/RC2a 不适用 |
  | 到最近极点 | **82.898°** | RC3 域 ≈ 切点距极点 ≤ 40″ | 不适用（差 4 个数量级） |
  | 到最近 `|z|=2/3` 接缝圆 | **34.708°**（南）/ **45.546°**（北） | 接缝地板域 = drop 跨 `u+v=1` | 不适用 |
  | 到 `z=0` 线（face 4–7 的 `u+v=1`） | **3.736°** | 需视场在 dec 方向跨 > 7.5° | 不触及（且该线 EXP-07 从未实测） |
  | 像元尺度条件 | `A_drop(0.967″/px) = 2.198e-11 sr` | 接缝地板触发上限 1.4e-10 sr（2.4″/px） | **尺度条件成立** |
- **关键措辞**：`|z| ≤ 0.122 ≪ 2/3`、`dec ∈ [−7.021°, −3.817°]`，落在**赤道带**
  （face 4–7 或 face 8–11 的赤道三角）。"缺陷不显现"是**"天区远离接缝/极点" ∧ "尺度满足"**
  的合取结果——**不是因为尺度条件不满足**。这一点必须写清楚，否则会被误读为
  "像元太粗所以看不出"。
- **残留风险（登记，未验证）**：EXP-07 §7 登记了一条**与极点无关、与 nside 基本无关、
  机制未定位**的"小 drop 共同地板"（HST 原始指向 dec=−13.8415°、0.04″/px 下最坏
  1.744e-04 / oracle 2.212e-04）。本单元**没有验证**它在 0.967″/px、dec=−5° 下是否存在。
- **另一条边界**：EXP-07 已证明**闭合判据对 RC1 近乎失明**（纯弦裁剪下恒为 0），
  因此"在 −5° 通过 1e-6 门"**不能**证明该处几何正确。本单元**没有**在 M42 天区重跑
  逐叶面积闭合探针（那是 EXP-07 的域），只做适用域距离测量。
