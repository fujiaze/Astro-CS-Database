# M42 真实数据上的四创新点复核：第三类数据腿的独立判据与三条判红

**实验单元**：`实验/m42-realdata`（第五单元，真实数据腿）
**数据**：M42 真实数据端到端运行 `run/RELEASE-05`（49 帧 = T2 16 + T3 33；马赛克 523 tile /
137,101,312 叶；导出 4096²）。**不重跑三命令**，只读既有产品。
**代码**：`code/c1..c4*.py`，固定 seed，`code/run_all.sh` 一键复跑。
**判据台账**：`results/c1..c4.json` 的 `gates.rows[]`（`id/desc/value/ok/source/level/note`）。

---

## 摘要

四个创新点的第三类数据腿（真实数据）在 M42 端到端产物上得到 **49 条判据**
（`data` 18、`external-consistency` 3、`control` 2、`positive-control` 4、`negative-control` 17、
`degenerate-control` 3、`honest-boundary` 2），其中 **6 条判红**。三条判红是本单元的**主结果**：

1. **测光星等坐标系（SCI-A）**：49 帧的 Gaia 残差散度中位 **0.44746 mag**，是 EXP-04
   已发表量级上界（0.057457 mag）的 **7.8 倍**，49/49 帧超界；该判据经 MC 正/负例证明能绿能红。
2. **跨帧绝对 SNR（SCI-B）**：产品 `variance` 平面对信号的 log-log 斜率 **−0.01174**
   （95% CI [−0.04616, 0.02027]，与 1 不相容）；权重效率损失 **E = 1.143239**，
   与"完全不用权重"**逐位相同**（比值 1.000000），比 EXP-06 推荐方法（7.336e-5）差 4 个数量级。
   独立测量（跨帧配对差）给出经验噪声律斜率 T2 **0.97432**（与 1 相容）、T3 **2.36037**（超线性）。
3. **加性天光与无接缝（SCI-C）**：朴素接缝判据在导出图上判红（4.501e-6 vs 5σ=1.496e-6），
   但**行块一致性判别**表明该红是 M42 星云纤维结构的**假阳性**（一致边界最大 5.916e-7 ⇒ 判绿）；
   加性合成与天光保留两条判据判绿（负例对照全部判红）。

**创新点四（HEALPix 原生重叠分配）14/14 全绿**：逐 leaf 覆盖重数守恒在全部 137,101,312 叶上
**零违反、零最大差**；逐样本掩码、输出计数、输入几何三方交叉一致；层级面积守恒到 FP32
表示地板（8.754e-9 = eps_fp32 的 7.3%）。

## 1 引言与方法

四创新点的前四单元（`photometric-magnitude`、`absolute-snr`、`additive-sky-seamless`、
`healpix-polar`）已用 HST 真实信号模板 + 物理前向仿真、纯解析合成两类数据给出结论。
`ASTROCS_DESIGN.md` §12.2 要求三类数据齐备；本单元补齐**第三类：真实数据**，
载体是已经跑完的 M42 端到端运行。

方法上的三条硬约束：

1. **只读产品、不重跑**。因此所有判据必须能在落盘产品上直接定义；
2. **判据必须非退化**。凡"真值无效应时度量不归零"的度量（例如对加性平移不变的散度、
   对斜率无约束的区间判据）一律降级为 `degenerate-control` 并明确写"无证据资格"；
3. **权威判据本体逐字复用**。SCI-C 的接缝判据不是本单元新写的，而是
   `实验/additive-sky-seamless/code/sci_c_common.py:356-411` 的逐字副本，
   并用逐位 SELFTEST 锁定（最大差 0.0）。

## 2 结果

### 2.1 SCI-A：测光星等坐标系

`k_photo` 是线性乘性标度（`ASTROCS_DESIGN.md:120-128`），故
`S_i = k_photo,i · I_cal,i = c·(N + sky_i)`：正确标定下帧间只差一个**加性**天光项，
乘性比应为 1。本单元据此给出三组测量。

**(a) 逐帧残差散度（主判据，判红）**。`sigma_residual = MAD(r)/0.6745`，
`r = log10(F_instr/F_syn)`（`star_matcher.cpp:612-621`）。49 帧的
`2.5·sigma_residual_dex`：中位 **0.44746**、min 0.33280、max 0.56886 mag；
`n_matched` 中位 295。EXP-04 band 上界 0.057457 mag ⇒ **49/49 超界**。
MC 正例（注入 EXP-04 真实帧量级）回 0.03904 mag（绿）；负例（4 倍）0.33769 mag（红）。

**(b) 零点平移不变量（退化对照）**。数值演示：`r` 整体平移 0.6 dex 后 MAD 差 **1.11e-16**。
故 `sigma_residual` 对"绝对窗口"零信息；k≡1 时残差散度不变，但帧间有效零点差变成
**0.9276 mag（T2）/ 1.8059 mag（T3）**。这正是"真值无效应 ⇒ 归零"的对照：
**k_photo 的全部可观测效应在帧间零点上**。`log10(kmax/kmin)` 独立复算与落盘值逐位一致
（0.3710387326687012 / 0.7223431688187283）；两块 `photscale_spread_warn=true`，
`spread_gate = "none (owner ruling 9.49: frame-independent)"`——**如实记录，不改裁决**。

**(c) 跨帧乘性一致性：登记 UNDECIDABLE**。为剥离真实天光差，样本限定为
`S > 3·(k·bg/A_pixel)`；两种估计器（稳健 OLS 斜率、中位比值）解出的逐帧对数零点散度：
T2 标定 0.2631/0.2125 dex vs 不标定 0.0568/0.0549 dex；T3 标定 0.2726/0.1672 vs
不标定 0.5655/0.5319。**两块方向相反**，估计器分歧 0.0487/0.0719 dex 与待测效应同量级。
混淆项量化：帧 `signal` 平面中位电平 / 天光等效电平 = 1.0190（T2）/ 1.0342（T3）
⇒ **信号平面被天光主导**，帧间差异主要是各夜天光辐射亮度这一真实加性差。
结论：**不宣称一致、也不宣称不一致**，登记"用本产物不可判定"。

**差异来源分析（推断，非本单元结论）**：EXP-04 真实帧测试用 `magG<16`、`chi2<4` 取 157 颗星
并拟合 `m_degree=2` 空间增益场；生产每帧只拟合一个标量、且不做星等/chi2 截断（本数据
175–555 颗）。M42 核心区强梯度背景上的暗星 PSF 测光偏差可解释量级差。已排除的假设：
解析 PSF 通量域与数值域不一致（比值中位 0.0、MAD 0.0）、星云污染可经 `background` 辨认
（不成立）。

### 2.2 SCI-B：跨帧绝对 SNR

**(a) 产品 variance 平面（判红）**。判据取"斜率 = 1 ± 0.05 **且** 自助 CI 半宽 ≤ 0.05"
（后半条用于排除"CI 宽到必然包含 1"的恒真门）。实测斜率 **−0.01174**，
CI **[−0.04616, 0.02027]**（半宽 0.0332，信号跨 0.36 dex），`corr(signal,variance)=0.0007`。
控制：合成 `Var ∝ D` → 1.00244（绿）；合成平坦 → 0.00206（红）。

**(b) 独立经验噪声律（分块不一致）**。用跨帧配对差 `(x_i−x_j)²/2`（完全独立于产品
variance 平面），按信号分 24 箱回归：T2 斜率 **0.97432**（CI [0.19037, 1.61583]）判绿；
T3 **2.36037**（CI [0.09206, 4.25669]）判红。偏差方向：该代理把帧间系统差计入噪声 ⇒ 高估。

**(c) 权重效率损失 E（判红）**。E 需要真值方差场——EXP-06 的真实数据臂因此没有算 E
（`exp06_e3_real.json` 中 `eff_loss` 出现 0 次）。本单元以 (b) 的 24 箱中位作 `var_true` 代理，
产品权重取帧 HiPS `ivar`（`weight_basis="per_sample_ivar"`）：

| 臂 | E |
|---|---|
| 产品 `per_sample_ivar` | **1.143239** |
| 常数权重 | **1.143239**（比值 1.000000） |
| `w = 1/var_true`（退化对照） | −2.22e-16 |
| 合成 `w ∝ var_true^-0.997`（正例） | 8.87e-06 |
| EXP-06 `phys_auto`（参考） | 7.33589e-05 |

`var_true` 跨 49.34 倍而产品权重 `max/min = 1.0` ⇒ **产品权重在信号维上完全不变**，
等价于"不用权重"。`E(product)/E(常数) = 1.000000` 这一恒等式**不依赖代理**。

### 2.3 SCI-C：加性天光与无接缝

**(a) 权威判据本体逐位一致**：`seam_steps` 与 `sci_c_common.seam_steps` 最大差 **0.0**。

**(b) 朴素接缝判据判红 → 行块判别后判绿**。在与 `vis_report` 同一 512 块网格（8×8）上，
14 条边界最大 `|excess − mu|` = **4.50131e-06**，off-locus 零假设 `σ = 2.981e-07`、
阈值 1.496e-06 ⇒ 判红（x=2048 与 y=2560 超界）。把同一判据本体套在 4 个 1024 行块上：
**列向 1/7、行向 1/7 边界在 4 块上同号**；一致边界最大 **5.916e-07 < 1.496e-06 ⇒ 判绿**。
⇒ 朴素判据的红是**星云纤维结构假阳性**。负例注入标定检测限：在最干净边界 x=1024 注入
已知阶跃，**A* = 2e-06**；A=0 时 3.446e-07（假阳性控制判绿）。
渲染器 `seam_ratio = 1.00961`（门 1.5）是块内方差比，与台阶量不同量；渲染器 FAIL 的原因是
另一条发现 `covered_but_nonfinite_px = 466515`（2.78%）。

**(c) 加性合成**。抽样 16 个 tile，用 `p2_corrected_*.bin` + 帧 `ivar` + 逐样本掩码重建，
与 `p2_integrated_signal.bin` 比：加性加权和最大相对残差 **0.0**；算术平均 **1.159**、
取最大 **9.194**、取最小 **1.607**（负例全判红）。顺序约定经实测确认（FITS 序相关系数
+0.96…+0.99，NESTED-local 序 ≈0）。

**(d) 天光保留**：`corrected 电平 / 帧天光等效电平` 中位 **1.1336**、最小 **0.5245 > 0.3**
⇒ 判绿；负例（整体减掉公共平面）判红。产品语义字段
`additive_mode_effective="delta"`、`c_subtracted=false`、`sky_plane_mode="delta_to_B_ref"`
与之一致。

### 2.4 创新点四：HEALPix 面坐标原生重叠分配

**(a) 逐 leaf 覆盖重数守恒（全量零容差）**：137,101,312 叶，
`nused + nrej == candidates` **违反叶数 0、最大差 0**；
`Σnused = 1,141,247,607`、`Σnrej = 17,329,578`、`Σcand = 1,158,577,185`。
四条负例（`nused+1`、`cand//2`、`cand→0`、`nrej→0`）全部判红。

**(b) 三方交叉核对**：24 个抽样 tile 上，掩码计数 == `nused`（不一致叶数 0，
`Σ = 50,136,578`）；`candidates == #{帧 k : support_k > 0}`（不一致叶数 0，
`Σ = 50,905,958`）。⇒ 无重复计入、无丢失。

**(c) 层级面积守恒**：order 0..9 上相对差 **8.754e-09** = `eps_fp32` 的 7.3%；
order0 总面积 **3.644293e-04 sr**。阈值取 1e-6（≈8.4×`eps_fp32`，因为 `support` 是 FP32，
1e-9 低于可表示地板）并附负例（order5 乘 1+1e-5 → 9.991e-06 判红）。

**(d) EXP-07 缺陷域实测确认**：用 33,472 个控制点 + tile 半对角 0.0810° 得
`|z| ∈ [0.06657, 0.12223] ≪ 2/3`（极冠叶 **0** ⇒ RC1/RC2a 不适用）；
到最近极点 **82.898°**（RC3 域 ≈ 40″ ⇒ 不适用）；到最近 `|z|=2/3` 接缝圆 **34.708°**
（接缝地板 ⇒ 不适用）；到 `z=0` 线 **3.736°**（不触及）。
**但尺度条件成立**：`A_drop(0.967″/px) = 2.198e-11 sr ≤ 1.4e-10 sr`（地板触发上限 2.4″/px）。
⇒ 结论必须写成 **"天区远离奇点" ∧ "尺度满足" 的合取**，不是"像元太粗看不出"。

## 3 讨论：三条判红的共同结构

三条判红（C1-G1、C2-G1/C2-G3、C2-G2-t3）都指向同一件事：
**生产链在真实数据上的"帧间系统项"没有被物理模型吸收**。
测光残差散度 0.45 mag、variance 平面与信号无关、权重效率等价于不用权重、
T3 经验噪声律超线性——四者互相印证：真实数据的帧间差异由**未被建模的系统项**主导，
而当前 `variance`/`ivar` 平面并未把它表达出来。

与之对照，**创新点四的分配几何 14/14 全绿且是零容差恒等**：面积分配这一侧在真实数据上
是精确闭合的。这给出一个清晰的定位：**问题在"噪声/权重/测光的绝对标定"，
不在"面积交叠分配的几何"**。

## 4 诚实边界

- 未独立验证：EXP-04 的选星口径（缺 per-star `r`）、EXP-06 的五个 E 数值本身、
  EXP-07 的任何缺陷数值（本单元只做适用域距离测量）、帧 `support` clamp 的性质、
  帧 drizzle 面积与 WCS 名义面积 1.17% 差的来源。
- 偏差方向已知：C2 的 `var_true` 代理把系统差计入噪声 ⇒ E 被高估。
- 单一天区（M42，赤道带），无第二真实天区做交叉。
- 未改 `lib/**`、`docs/**`、`eng/**`；未重跑三命令；未做 git 写操作；
  未放宽阈值（两处阈值调整均附可表示精度依据与仍可红的负例）。
