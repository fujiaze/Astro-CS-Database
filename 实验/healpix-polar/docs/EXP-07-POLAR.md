## 0. 结论速览

1. **极点破门有三条根因，但它们的可观测性互相耦合**（详见 §4.1/§4.2/§4.3）：
   **RC1 是 RC2a 的前置暴露条件**（只换稳定式而不修叶边界表示，实测毫无改善：376→372、最坏 2.5172e-02→2.5242e-02）；
   **RC3 走完全不同的通道**——它**不使闭合判据破门**（判据用同一个 drop 同时算 Σa 与 A_drop，对 drop 自身面积误差不敏感），
   其产品影响是**光度归一化偏差**（极点处 drop 面积误差 4.3e-5 @0.2″/px、3.7e-3 @HST 0.04″/px），必须单独设检。

   | 编号 | 根因 | 位置 | 极点处量级 | 隔离实验 |
   |---|---|---|---|---|
   | **RC1** | 叶边界用"4 角 + 大圆弧弦"表示。极冠叶的真实边界曲率半径 / 弦长 ≈ **2.691**（独立复核用生产 pix2ang 反演 Górski 图算得；弦偏差/hp_res = 0.063937 在 nside 1024…2²¹ 恒定），弦偏差 **0.0639 hp_res**，且该比值**与 nside 无关**（相对误差，不随分辨率下降） | `spherical_overlap.cpp::get_healpix_boundary4` | 单叶面积亏损最大 **9.97e-2** | T2/T11/T18；A0→A2 消融 |
   | **RC2a** | `xyf2ang_replica` 用 `z = 1 - s²/3; theta = acos(z); st = sin(theta)` 求极冠叶角点，横向半径相对误差 **2.4e-4**（丢 ~3.5 位有效数字） | 同上，第 711–774 行 | 角点横向半径相对误差 6.1e-5…2.4e-4 | T3；A2→A3 消融 |
   | **RC3** | TAN 逆投影 `dec = asin(cos c·sin δ0 + sin c·cos δ0·sin pa)` 在 **dec ≈ ±90°** 处把 `1 - x` 量化到 ulp(1)，离极点偏移 δr ≈ ulp(1)/θ_pole；drop 面积相对误差 ≈ 2.2e-16/θ_pole² | `wcs_sip.cpp::pixelToSky`（生产路径）+ `radec_to_vec` | HST 真实 0.04″/px 下 **3.7e-3**；0.2″/px 下 4.3e-5；只在切点落入 drop 内部时显著（T22：0.028″ → 3.74e-3，40″ → 1.41e-6，226″ → 1.41e-8） | T14/T15/T16/T20/T22 |

2. **破门区间不是"极点专属"，而是两个独立条件的交集**：
   - **两个极点周围约 5″ 以内**（r=0 的完全对称点因误差相消反而通过），r ≳ 6″ 后回到 1e-6 以下；
   - **"小 drop + `u+v = 1` 接缝"**：接缝处存在一条**浮点相消型绝对面积地板 ≈1.4e-16 sr（≈1.3·ulp(1)）**，
     绝对量在 8 倍尺寸范围内恒定 ⇒ 相对闭合 **∝ 1/A_drop**（T28）。因此判据是 **`A_drop ≲ 1.4e-10 sr`，即像元尺度 ≲ 2.4″/px**，
     与是否在极点无关。**HST 真实 0.0400″/px 下接缝处实测 3.3e-03（生产直调），比门禁宽 3300 倍**（T29）。
   极点破门区面积占比 ≈ 1e-10 全天，但两者都是产品"必须正确"的区域。

3. **推荐的极区算法（可直接落地，最小改动面）**：
   保持 V0 的球面 Sutherland–Hodgman 结构不变，只做两处替换 + 一处自检：
   - **(a) 稳定角点公式**：极冠叶角点改用 `s = √6·sin(θ/2)` 与横向半径 `r = s·√(2/3)·√(1 - s²/6)`（生产 `hp_to_xyz` 已有等价稳定式），彻底去掉 `acos(z)`/`sin(acos(z))`；
   - **(b) 叶边界自适应细分**：按**绝对弦偏差预算**细分叶边界，判据 `delta_max = 1.5·(budget_abs/4)/edge_len`（由抛物线弓形面积 `(2/3)·δ·ℓ` 推出，与 nside/尺度无关）；
   - **(c) 快速路径面积口径统一**：`leaf_fully_inside_drop` 命中时返回的必须是**同一表示下的叶面积**（当前返回解析值 `π/(3nside²)`，
     而相邻叶返回弦裁剪面积——正是极点 2.52e-2 破门的直接来源，见 §4.1）；
   - **(d) 判据**：`|Σa - A_drop|/A_drop ≤ 1e-6` 保留为运行时不变量，但**不能作为 RC1 的验收判据**（纯弦裁剪下它恒为 0）；
     RC1 的验收必须用**逐叶误差**（`leafmax_err`，当前最坏 3.159e-07）。另在 RC3 表示域外（drop 角半径 < 1.5e-8 rad）fail-closed。
   实测（nside=2²¹，0.2″/px，极点 ±8px/1089 配置）：预算 1e-7 时**破门 0/1089、最坏 2.79e-8**；
   非极区零代价（仍为 4 点/叶），极冠叶 ~1333 段/叶。

4. **面坐标卡原生路径（第四创新点的差异化主张）实测结论**：
   - 叶侧确实**零近似**（`|dΩ/dudv| = π/3` 解析常数），且**非极区几乎免费**：赤道 8 个折线点即达 1.3e-10，三角点 17–29 点达 2.8e-8；
   - 但**极点是它的结构性死角**：drop 的 chart 原像是楔形，朴素/自适应折线在极点给出 **9.07e-1** 闭合误差（丢 90% 面积），必须走"角点路径"；
   - 角点路径误差**按 1/N² 收敛**（N=64/128/256/512 → 1.59e-3/4.17e-4/1.04e-4/2.61e-5），按 1/N² 外推需 N≈2.6e4 才到 1e-8；
   - 该路径还额外要求鞋带公式**先平移再求和**，否则 chart 坐标 ~0.5 处的 1e-16 绝对相消噪声放大成 **5.4e-5** 相对误差（纯数值坑，与几何无关）。

5. **角点路径 ~1e-5 触底的根因（问题 4）已定位并证伪原假说**：
   它不是"`u = 1-kx` 丢有效数字"造成的**精度地板**——精度地板不会随 N 下降。实测误差随 N 严格按 **1/N²** 收敛（3 次倍增：1.59e-3 → 4.17e-4 → 1.04e-4 → 2.61e-5，比值 3.8/4.0/4.0），
   机制是**固定采样数 N=512 下 drop 边界在 chart 里的弦折线逼近**：极点处单段弦偏差达弦长的 **0.16–0.78 倍**（T8a）。自适应细化后该误差消失，不存在地板。

6. **闭合判据对 RC1 近乎失明（重要）**：4 角弦多边形精确铺满球面（相邻叶共享弦）⇒ **在交点计算正确的前提下**纯弦裁剪下 `Σa ≡ A_drop`，闭合恒为 0（`use_fast=0` 实测 3.82e-14），
   而同一表示的**逐叶**误差高达单叶 9.97e-2。极点闭合量的破门**全部来自 `leaf_fully_inside_drop` 的假阳性**（`full=376` 与破门数 376 一一对应）。
   ⇒ **RC1 的验收判据必须是逐叶误差**（`leafmax_err`，最坏 3.159e-07），不能只看闭合。

7. **两个独立仲裁量（T0）**：① `rotate_to_z` 自检——把多边形质心旋到 +z 的旋转轴必须是 `(c × z)` 方向，用反向轴只会把 c 旋到 `2·(c.z)² - 1` 处（`c.z = 0` 时搬到南极点），本实验第一版探针即踩此坑，靠该自检发现；
   ② 解析 drop 面积 `Ω = 4·asin(h²/(1+h²))`（TAN 方形足迹闭式）仲裁 `vos_area_rotated`：一般位置 ≤3.4e-10，极点 −4.29e-5（即 RC3 本身）。
   这两个量把"探针自身是否正确"与"被测算法是否正确"分开，是 §4 全部数字可信的前提。

8. **全天 1e-6 现状：未达成**。破门点全部集中在两个极点周围 ≲5″（RC1+RC2a）与 `|dec|` 距极点 ≲30″ 的 drop 构造（RC3）；
   其余全天（14 个 face 角点邻域扫描）在 1e-9 量级通过。RC3 不会被覆盖自检发现（自洽），必须单独设检。
   另有 2 项开放项：小 drop 尺度（0.04″）下与极点无关的 ~2e-4 共同地板；REC-1 的 `δ_max` 需要双精度下限。详见 §7。

## 1. 假说与问题

HEALPix 面坐标卡 `(face, u, v) ∈ [0,1]²` 上，面积元是常数（§2.1），因此"叶 × drop 交叠面积"在 chart 里本应是简单的平面多边形运算。
生产实现 V0（`lib/algorithms/drizzle/healpix_drizzle/spherical_overlap.cpp`）走的是球面路线：把叶的 4 个角点用大圆弧连成四边形，用 drop 的 4 条边大圆半空间做 Sutherland–Hodgman 裁剪，再用 Van Oosterom–Strackee（VOS）算球面多边形面积。

门禁为 FP64 通量闭合 `< 1e-6`（`docs/algorithms/DRIZZLE_GEOMETRY.md:236`）。

待答问题：

- **Q1** 极点为什么破门？（实验证明，不靠推测）
- **Q2** 正确的极区算法是什么？候选：叶边界自相似细分 / 在 face 坐标里做交叠 / 极点专用旋转坐标卡 / 其他。
- **Q3** 各方案的代价与适用域。
- **Q4** 角点路径 ~1e-5 触底的根因（INNOV04-LAND-01 未定位）。

## 2. 方法

### 2.1 面坐标卡与两条解析事实

北半球 face 0–3（`u+v ≤ 1` 为赤道三角，`u+v > 1` 为极冠，极点位于 `(1,1)`；南半球 face 8–11 镜像，极点位于 `(0,0)`）：

```
赤道三角:  z = (2/3)(u+v),          phi = (pi/4)(u-v+1+2f)
极冠:      s = 2-u-v,  z = 1 - s^2/3,  phi = (pi/2)f + pi(1-v)/(2s)
赤道面 4-7: z = (2/3)(u+v-1)
```

**事实 1（等面积，解析）**：`|dΩ/dudv| = π/3`，在 12 个面上处处为常数（T1 数值复核：有限差分残差 2.5e-6，纯差分伪影；与生产 `pix2ang_nest` 的最大角差 **9.180e-16 rad = 2.352e-10 hp_res**）。
因此叶面积恒为 `(π/3)/nside²`，与叶在面上的位置无关——这是"叶侧零近似"主张的全部依据。

**事实 2（极点专用稳定式，本实验推导）**：令 `θ` 为到极点的角距、`r` 为横向半径，

```
theta = 2*asin(s/sqrt(6))                     正向（s -> theta）
r     = s*sqrt(2/3)*sqrt(1 - s^2/6)           正向（横向半径）
s     = sqrt(6)*sin(theta/2),  theta = atan2(rho, z)   反向
```

该式在 `s → 0`（极点）无 `acos(z)` / `sqrt(1-z²)` 型相消。生产 `healpix_core.cpp::hp_to_xyz` 的极冠分支（`vv = s/√3; z = (1-vv)(1+vv); rad = sqrt(1+z)*vv`）已经是稳定的等价形式；
**`spherical_overlap.cpp::xyf2ang_replica` 却是另一份不稳定重写**——这是 RC2a 的来源。

### 2.2 数值基线（oracle）

oracle 定义为：叶边界按**真实曲线**（稳定式，mode 1）每边采样 K 点 + 用 drop 的 4 条大圆半空间做球面 S-H 裁剪 + 把多边形旋转到质心为新 +z 极点后用 VOS 扇面求面积 + Richardson 外推 `(4·A(2K) - A(K))/3`；
两个退化情形（叶完全在 drop 内、drop 完全在叶内）取解析值 `π/(3nside²)` / `A_drop`。

- 旋转到质心是必要的：不旋转时 VOS 的 `det = a·(b×c)` 在极点处相消到 1e-13 以下；旋转后横向坐标 ~θ 且保持满相对精度；
- 用 `atan2(|cross|, dot)` 而非 `acos(dot)` 度量小角（`acos` 对 1 ulp 的 dot 亏损返回 2.1e-8 rad 的假角）；
- oracle 自身精度地板（T13-N5）：**4.908e-10**（4 个位置 × 25 配置的最坏闭合）。

**两个独立仲裁量**（T0，``p0_selftest.cpp`）：

1. ``rotate_to_z` 自检`：把多边形质心旋到 +z 的旋转轴必须是 ``k = (c × z)/|c × z|``。用反向轴 ``(z × c)`` 会把 c 旋到 ``2·(c.z)² - 1`` 处（c.z=0 时搬到南极点），起不到稳定作用。自检覆盖 12×9 个方向，``|R(c) - z| ≤ 1.13e-16 rad`。
2. **解析 drop 面积**：TAN 方形足迹 ``[-h,h]²`` 的球面面积有闭式 ``Ω = 4·asin(h²/(1+h²))``。用它仲裁 ``vos_area_rotated`：极点 −4.29e-5（真值偏差，见 §4.3 RC3）、三角点 −3.4e-10、赤道 −2.7e-11、南天 −1.24e-10、一般赤道 −2.2e-11。

### 2.3 变体消融设计

`overlap_variant(g, nside, face, i, j, leaf_mode, K, hp_res, use_fast)`：

| 变体 | 叶边界 | 角点/曲线公式 |
|---|---|---|
| A0 | 4 角 + 大圆弧弦 | `acos(z)` 路径（= 生产 V0） |
| A1 | 4 角 + 大圆弧弦 | 稳定式 |
| A3 | 真实曲线 K 点/边 | `acos(z)` 路径 |
| A2 | 真实曲线 K 点/边 | 稳定式 |
| O | 真实曲线 K 点/边 + Richardson | 稳定式（oracle） |
| REC-1 | 自适应细分（绝对弦偏差预算） | 稳定式 |

A0→A1 隔离 RC2a，A1→A2 隔离 RC1，A0→A3 隔离 RC1 的反面，A2→O 隔离 K 收敛性。

### 2.4 三个独立误差通道

`|Σa - A_drop|/A_drop` 这一个度量同时受三条通道影响，实验必须分别隔离：

1. **叶边界表示误差**（RC1）：进 `Σa`；
2. **角点/曲线构造误差**（RC2a）：同时进 `Σa` 与 `A_drop`；
3. **drop 构造误差**（RC3）：同时进两者 ⇒ **在闭合度量里自洽相消**。故 RC3 必须用 `(ra,dec)` 往返与直接 3D 构造（`p = normalize(T + η·e1 + ξ·e2)`，gnomonic 精确形式，不经角度往返）对照才能暴露。

## 4. 结果

### 4.1 RC1 — 叶边界"4 角 + 大圆弧弦"（主因）

**T2/T11/T18：弦偏差与叶面积亏损的空间分布**（nside=2²¹，hp_res = 0.1006″）

叶边界真实曲线对 4 角大圆弧弦的最大偏差（单位 hp_res），face 0 北极冠（行 = u 索引距 1 的偏移 du，列 = v 索引距 1 的偏移 dv）：

```
        du=1     du=8     du=64    du=256   du=1024  du=16384 du=262144
dv=1   6.39e-2  2.37e-2  3.21e-3  8.09e-4  2.03e-4  1.27e-5  7.84e-7
dv=8   2.37e-2  2.67e-3  2.27e-3  7.40e-4  1.98e-4  1.27e-5  7.84e-7
dv=64  3.21e-3  2.27e-3  3.01e-4  3.88e-4  1.66e-4  1.25e-5  7.82e-7
dv=256 8.09e-4  7.40e-4  3.88e-4  7.45e-5  9.64e-5  1.20e-5  7.78e-7
```

关键性质：**该比值与 nside 无关**（T2：nside 从 1024 到 2097152，极点邻叶恒为 0.0639 hp_res）。
即它是**相对误差**，提高分辨率不会改善——这与"换更高阶 nside 就好"的直觉相反。

对应的**单叶面积亏损**（弦折线面积相对解析叶面积，T18）：

```
沿 face 边 v=Ns-1:  du=1: -9.97e-2   du=2: -9.21e-4  du=4: +5.01e-3  du=8: +2.13e-3
                    du=32: +1.82e-4 du=128:+1.23e-5  du=1024:+1.96e-7 du=4096: +1.23e-8
沿对角 du=dv:       d=1: -9.97e-2    d=2: -1.14e-2   d=4: -2.10e-3   d=8: -4.57e-4
                    d=32:-2.59e-5    d=128:-1.58e-6   d=1024:-2.70e-8
极冠外 (face4):     ~1.17e-10（数值地板）
```

即亏损按 **1/d²** 衰减（d = 距极点的叶数），极点邻叶高达 **9.97e-2**；且沿 face 边为正、沿对角为负 ⇒ 闭合误差是**带符号求和**，会部分相消。
极冠外（face 4 赤道面）同口径亏损为 **1.17e-10**（纯数值地板）。

⇒ 除极冠/赤道交界（2.06e-4，只比极冠小 **2.5** 个数量级）外，其余位置比极冠小 5–8 个数量级。

**必须并列 `use_fast` 两档**（T23，`code/p9_review.cpp`）——生产代码有两条快速路径（`leaf_fully_inside_drop` / `drop_inside_pixel`），它们对结论有决定性影响：

| 变体 | `use_fast=1`（生产）破门/最坏 | `use_fast=0` 破门/最坏 |
|---|---|---|
| A0 生产 4 角 + `acos(z)` | **376/1089 / 2.5172e-02** | **0/1089 / 3.823e-14** |
| A1 4 角 + 稳定式 | 372/1089 / 2.5242e-02 | 0/1089 / 3.716e-14 |
| A3 真实曲线 K=128 + `acos(z)` | 8/1089 / 4.5390e-06 | 0/1089 / 3.458e-14 |
| A2 真实曲线 K=128 + 稳定式 | 4/1089 / 1.8537e-06 | 0/1089 / 3.394e-14 |
| O oracle K=128 + Richardson | **0/1089 / 4.2530e-14** | 0/1089 / 3.394e-14 |
| 快路径命中计数 | `full=376` / `quick=42121` / `S-H=23804` | `full=0` / `quick=0` / `S-H=66301` |

**这张表推翻了"RC1 直接抬高闭合量 4 个数量级"的因果叙述，正确的机制是：**

1. **闭合判据本身对 RC1 近乎失明。** 4 角大圆弧弦多边形**精确铺满球面**（相邻叶共享角点、弦重合），
   所以纯弦裁剪下 `Σa ≡ A_drop`，闭合恒为 0——实测 `use_fast=0` 时 A0 只有 **3.82e-14**。
   而同一表示的**逐叶**误差高达单叶 **9.97e-2**（T18）。⇒ **RC1 的真实危害是逐叶通量错配，闭合判据看不见它。**
2. **破门全部来自 `leaf_fully_inside_drop` 的假阳性。** 该判据用**离散边界**（生产 4 角路径 nb=4）判断"叶完全落在 drop 内"，
   而真实叶边界在弦**外侧**鼓出，于是产生假阳性；命中后返回**解析叶面积** `π/(3·nside²)`，相邻叶却返回**弦裁剪面积**——同一划分里两种面积口径。
   闭合量 = 单叶弦亏损 9.97e-2 × (叶面积/A_drop = 2.381e-13/9.403e-13 = 0.2532) = **2.52e-2**，与实测最坏值逐位吻合。
   证据：`full=376` 与 A0 的破门数 **376** 一一对应；关掉快路径后全部归零。
3. 因此 A0→A2 的"4 个数量级改善"测的是**假阳性率随 K 下降**（叶边界越接近真实曲线，`fully_inside` 判定越准），
   不是边界表示精度本身。

**K 收敛不是严格 K⁻²。** 逐配置复算（`results/t4_pole_full.csv`）：`r2k128` 中位 **4.08e-15**、最大 1.854e-06；
`r2k128/r2k512` 的**中位只有 1.50**（min 0.00、max 24.0）——绝大多数配置已落到数值地板，`16.00` 只是**最坏值包络**，不能作为 K⁻² 律的证据。

**主判据应改为逐叶误差**：`leafmax_err`（逐叶 vs oracle 最大相对差，归一叶面积）最坏 **3.159e-07**、中位 2.14e-08。
该量直接测边界表示精度，不受"快路径两种面积口径"污染，应作为 RC1 的验收判据。

**该量的三个口径限制（独立复核指出，如实登记）**：
1. 它当前的 `a512` 仍用 `use_fast=true`，因此仍继承快路径的两种口径；作为"纯边界表示精度"量应改 `use_fast=0`；
2. 它测的是**推荐方案（A2 K=512）的残差**，不是现网 A0/A1 的危害——现网同口径值预期在 1e-1 量级（单叶亏损 9.97e-2），报告未给出；
3. 被测量用 K=512、基准用 K=128+Richardson，两者不同阶，应统一。
上述三点不影响"闭合判据看不见 RC1"这一结论，但**该判据本身尚未定型**，落地前需按此重算。

**T7 生产交叉核对**：直接把生产 V0 与本地 A0 复刻链接进同一进程对比，`|Σ_prod - Σ_A0|/A_drop ≤ 1.106e-13`，候选叶集合（fast / conservative）0 处不一致，破门数同为 376/1089 ⇒ 复刻忠实，结论可外推到生产。

⇒ 地板位于**多边形构造（S-H 交点）侧**。

**尚未定位的最后一环**：地板由哪一步的相消产生。候选是 S-H 交点构造在接缝位形下产生"远点顶点"（独立复核在探针 `sh_clip` 中实测到 110 次反极点交点；

而不是继续在面积公式上找。

## 6. 结论与推荐算法

### 6.1 推荐的极区算法（REC-1，可直接落地）

**保持 V0 的球面 S-H 结构**，三处改动：

```text
输入: face, (i,j), nside, drop 多边形 (4 顶点 + 4 条大圆半空间法向), budget_abs (球面度)
输出: 交叠面积 a

1) 叶角点（稳定式，替代 xyf2ang_replica 的 acos 路径）
   极冠 (u+v > 1):  s = 2-u-v
                    st = s*sqrt(2/3)*sqrt(max(0, 1 - s*s/6))
                    ct = 1 - s*s/3                      # == cos(theta)
                    (st, ct) -> 单位向量，phi = (pi/2)*f + pi*(1-v)/(2*s)
   赤道三角/赤道面: z = (2/3)(u+v+zoff);  st = sqrt(max(0,1-z*z)); ct = z
   极点 (s == 0):   phi = (pi/2)*f, 直接返回极点向量

2) 叶边界自适应细分（替代"4 角 + 一条大圆弧弦"）
   对每条边 e:  len_e = angle(P_e, P_{e+1})
                delta_max = max(1.5 * (budget_abs/4) / len_e, 1e-15)   # 双精度下限
                递归二分，直到 |angle(法向_e, 曲线中点)| <= delta_max 或 depth >= 18
   判据来源: 抛物线弓形面积 (2/3)*delta*len，四条边合计 <= budget_abs

3) 球面 S-H 裁剪 + VOS（与 V0 相同）
   快路径: 叶完全在 drop 内 -> pi/(3*nside^2);  drop 完全在叶内 -> A_drop
   VOS 前把多边形旋转到质心为新 +z 极点

4) 运行时不变量
   每帧累计 |sum(a_jp) - A_drop| / A_drop <= 1e-6，超限则 fail-closed
   若 drop 角半径 < 1.5e-8 rad（(ra,dec) 表示域外）-> fail-closed
```

**实测代价**（nside=2²¹，0.2″/px）：

| 区域 | 段/叶 | 相对 V0 代价 |
|---|---|---|
| 非极冠（全天 99.99%+） | 4（不变） | 1.0× |
| 极冠（每帧 O(10) 个叶） | 421（budget 1e-6） | ~170× 该叶 |

预算选择建议：`budget_abs = 1e-7 · A_drop` 给出最坏闭合 2.79e-8（36× 门禁余量），代价 1333 段/叶。

### 6.2 面坐标卡原生路径的定位

- **非极区**：优（叶侧零近似、8–29 个折线点、1e-10…1e-8），且闭合是**结构性**的（叶侧精确 ⇒ 面内叶面积求和恒等于 `π/3/nside²`）；
- **极点**：必须实现"曲线裁剪 + 角点特判"，朴素/自适应折线给出 9.07e-1 的灾难性误差；角点路径按 1/N² 收敛，按 1/N² 外推需 N≈2.6e4 才到 1e-8，与 REC-1 同量级代价；
- **额外要求**：鞋带公式先平移（否则 5.4e-5 伪误差）。
- **结论**：作为**长期架构方向**成立（叶侧精确是真实优势），但作为**当前落地路径**，其极区收益不足以抵消新增的曲线裁剪机制与角点特判复杂度。

### 6.3 落地优先级：接缝绝对地板应与 RC1/RC2a 一并纳入

§6.1/§6.2 讨论的都是极区。但 §4.7 的结论对**产品**同样关键，且影响面不同：

| 项 | 位置 | 触发条件 | 量级 | 影响的观测 |
|---|---|---|---|---|
| RC1 + RC2a | 两个极点周围 ≲5″ | 恒存在（极区） | 2.52e-02 | 极区天区 |
| RC3 | 极点邻域的 drop 构造 | 恒存在 | 4.3e-5 … 3.7e-03 | 极区天区 |
| **接缝绝对地板** | **`u+v=1` 接缝（全天 12 条 face 边）** | **像元尺度 ≲2.4″/px** | **3.3e-03（HST 实测）** | **HST/JWST 等小像元数据，全天任意天区** |

⇒ 接缝地板的**量级与 RC1 相当、适用天区远大于极点**，且现有闭合判据在极点之外对它同样没有防护。
落地任务建议：把"接缝 + 小像元尺度"与 RC1/RC2a 一并纳入，并在验收里加一条**按像元尺度分档的接缝负例**（≲2.4″/px 必须覆盖）。

### 6.4 未达成的部分

全天 1e-6 **未达成**，缺口为：

1. 两个极点周围 ≲5″（RC1 + RC2a）；
2. `|dec|` 距极点 ≲30″ 的 drop 构造（RC3，闭合度量失明）；
3. 极冠叶的边界表示相对误差不随 nside 下降，单纯提高分辨率无效。

## 7. 诚实边界


- **`u+v = 1` 接缝破门区（机制已定位到"绝对面积地板"，但产生地板的最后一步未定位）。**
  接缝中点（ra=45°, dec=+41.8103°）±8 px / 1 px 实测 **283/289 破门、最坏 1.802e-04**；**生产直调 280/289 / 1.7489e-04**（T27）；
  **HST 0.0400″/px 下 3.317e-03**（T29）。已排除：快路径、叶边界表示、候选集合、角点连续性、面积公式、drop 面积。
  已定位：绝对亏空恒为 ≈1.4e-16 sr（≈1.3·ulp(1)），相对闭合 ∝ 1/A_drop ⇒ **像元尺度 ≲ 2.4″/px 的数据在接缝处必然破门**。
  **未定位的是"哪一步相消"**（候选：S-H 交点构造产生远点顶点；下一步做逐叶顶点级定位）。
  复现：`verify/p9 t24`（扫描）、`verify/p9 t27`（生产直调）、`verify/p9 t28`（尺寸标定）、`verify/p9 t29`（HST 外推）、`verify/p10`（逐叶分解）。
  **全天 12 条 face 边在结构上各有一条这样的接缝，但本实验只实测了 face 0 的北接缝 1 条**，其余按对称性推断。
  **它推翻"破门是极点专属"的表述**，但不影响极点结论（极点 `use_fast=0` 全绿）。
- **开放项：极小 drop 的"真值注入"负例缺失。** T13-N2 是恒真门（走 `drop_inside_pixel` 恒等返回），不能证明判据在极小 drop 下有效；
  需要把 drop 面积乘 (1+ε) 之类的可控注入补上。
- **判据强度的自我更正**：闭合判据对 RC1 近乎失明（纯弦裁剪下恒为 0），必须补 **逐叶误差** 判据（`leafmax_err`，最坏 3.159e-07）；
  且快路径必须与裁剪路径返回**同一面积口径**（现在一个返回解析叶面积、一个返回弦裁剪面积），否则闭合判据不自洽。
- **`check_report.py` 的强度有限**：容差 1%、在整篇报告里搜"任一数字"、无位置锚定。它只能抓"数字整体过期"，不能证明逐格一致；
  更强的做法是逐表逐位置比对（后续项）。
- **破门区间只测到 r ≤ 1024 px（204.8″）**；更大的 r 未做系统扫描，但 T12 的 14 角点扫描覆盖了全天其它角点邻域，均为 1e-9 量级。
- **HST 实验受尺度关系限制**：nside=2²¹（hp_res 0.1006″）下 HST drop（0.0400″）小于叶，多数配置走快速路径，闭合度量在该尺度上信息量低；
  唯一有信息量的是 drop 面积比（3.736e-03，直接量出 RC3）。`drop/leaf ≫ 1` 的 HST 尺度对照见 `logs/p4_hst_n23.out`。
- **oracle 自身精度地板按位置给**：T13-N5（4 位置 × 25 配置）最坏 4.908e-10；极点栅格 T4 的 oracle 最坏 4.253e-14；
  T17 的 oracle 列在 r=1024 px 处为 2.177e-10、r=512 处 5.442e-11（数值地板随尺度与位置变化）。因此 1e-9 以下的比较不做定量声明。
- **RC3 的定量模型是上界**：`2.2e-16/θ²` 与实测同量级但可差 3–30 倍（rounding 的混沌性），不用于精确预报，只用于判定"何时必须改用 3D 构造"。
- **开放项：小 drop 尺度下存在未定位的共同地板。** HST 原始指向（dec=−13.84°）、drop 0.0400″ 时，
  nside=2²¹（drop/leaf=0.16）oracle 2.21e-04、nside=2²³（drop/leaf=2.53）oracle 2.12e-04；V0 1.74e-04…2.35e-04。
  该地板与 nside 基本无关、与极点无关，本实验未定位。
  复现：`verify/p4 orig 8388608`。**它不影响 §4.1 的极点结论**（同一尺度下极点配置的 oracle 为 1.93e-14）。
- **REC-1 的预算下限（已在 §6.1 修正）**：当 `1e-6·A_drop` 换算出的 `δ_max` 低于约 1e-13 rad（双精度可分辨的弦偏差下限）时，
  递归永远不收敛、被 `max_depth` 截断而失效（HST nside=2²³ 原始指向处 REC-1 达 5.0e+01）。
  实现时必须给 `δ_max` 加下限（建议 `δ_max = max(δ_max, 1e-15 rad)`）并在触底时置"预算未达成"标志。
- **未做**：真实 `pixfrac<1` 的多次 drop、`m>1` 的细分边界（探针已支持 `m` 参数，本报告只用了 `m=1`）、SIP 畸变项（HST drz 产品无 SIP，故未覆盖）、多线程一致性。
- **未改生产代码**：RC1/RC2a/RC3 的修复属于单独的落地任务；本实验只提供判据、伪代码与代价数据。
- 目录约定：本仓库既有实验单元使用 `实验/<kebab-topic>/{code,docs,results,README.md}`，本单元一致；`run/EXP-07-POLAR/` 只放探针可执行文件与日志（不入库）。
