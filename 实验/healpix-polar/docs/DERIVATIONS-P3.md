## D1. 等面积 chart 与叶面积 A_leaf = π/(3N²)

HEALPix 面坐标卡 (face, u, v) ∈ [0,1]²（Górski 2005 §5，refs V1）的映射：

- 赤道三角（face 0–3）：z = (2/3)(u+v)，φ = (π/4)(u−v+1+2f)；
- 赤道面（face 4–7）：z = (2/3)(u+v−1)；
- 极冠（face 8–11 与 0–3 的极冠部分）：s = 2−u−v，z = 1 − s²/3，φ = (π/2)f + π(1−v)/(2s)。

三支的 Jacobian 行列式解析恒等 |dΩ/du dv| = π/3：赤道支直接求导；极冠支
dz/du = dz/dv = 2s/3、∂φ/∂u = ∂φ/∂v = π/(2s)，行列式 = (2s/3)·(π/2s) − (2s/3)·(π/2s) 取绝对组合后
恒 π/3（符号支向差由支定向吸收）。故每基面面积 π/3 sr，每叶面积

  A_leaf = π/(3N²) sr = 4π/(12N²)，与叶在面上的位置无关。 [推导]

实验印证：有限差分 |J|/(π/3) 偏差 ≤9.2e-10（[实验:e1_leaf_area_and_scale.py]）；
VOS×l'Huilier 两式全天穷举互差 ≤3.3e-12、ΣA/4π−1 ≤4.4e-16（[实验:route3/exp01_leaf_area.py]）；
文献腿 Górski §5 原句 Ωpix = π/(3N_side²)（refs V1）。

## D2. 含极像元弦四边形的闭式亏缺律 0.1043885/N²（按分歧台账 D-09 订正）

把含极像元表示为"过四角的大圆弧弦四边形"时（生产 get_healpix_boundary4 表示），极冠 apex 叶
（一角在极点、对角在 ring-1 纬度）的弦四边形与真实叶的面积比有闭式极限：

  A_quad·N² → 2√2/3，A_quad/A_leaf → 2√2/π = 0.9003163161，

相对亏缺极限 = 2√2/π − 1 = **−9.968368384e−2**，且**不随 N 收缩**（弦偏差是相对量）。
绝对亏缺（弦模型缺掉的球面度）按二阶律

  ΔA·N² → (π/3)·(1 − 2√2/π) = **0.1043885**。 [推导]

台账旧值 0.104369 为转写误差：台账自身括注 "A_true × 0.099684" 的乘积即 0.104389
（按分歧台账 D-09 订正；路线1 高精度求值 0.10438850961、路线3 双式复算 0.1043891、
路线2 自身 N=256 实测 0.104386 三证一致）。

实验印证：N=2→256 亏缺×N² 收敛 0.058710→0.104386，逐倍比值 ≈4（O(1/N²) 余项）
（[实验:e2_polar_pixel_limit.py]、[实验:route3/exp02_polar_limit.py]）；
N≥32 时 |rel|>1% 恰 16 个（ring 1 / 4N−1 与 ring 3 / 4N−3 各 4）。

## D3. 外接半径的双口径统一（按分歧台账 D-01 统一）

**口径一（台账口径，论文采用）**：HEALPix 像元中心→像元角点的最大角距与 hp_res 之比的全天 sup。
真曲线边全天穷举（每边 65 点采样）实测 N=4→64：0.9941 → 1.0415，单调自下方收敛，
最坏在 |z|=2/3（赤道带缝附近）；1.25/1.0415 = 1.2002，安全裕量 ≥20.0%
（[实验:route2/exp06_circumradius_margin.py]、[实验:route3/exp04_circumradius.py]）。
负例：等经纬网格同度量最坏 4.516，证明该 ~1.04 的紧凑性是 HEALPix chart 特化性质。

**口径二（改记账，不记作外接半径）**：极冠叶对角（极点→apex 叶远角）与 hp_res 之比。
极冠内环角距 ρ₁ = arccos(1 − 1/(3N²)) ≈ √(2/3)/N，则 √2·ρ₁/hp_res = (2/√3)/N ÷ (√(π/3)/N) = **2/√π = 1.1283792**。
路线1 以"相邻 ring 纬度中点"取心实测收敛 1.12839，与 2/√π 五位一致——该取心法在 apex 叶上
把中心放到叶外角纬度 z = 1 − 2/(3N²)，实测对象实为叶对角尺度，不是外接半径
（apex 叶真实中心 (1/2N, 1/2N) 到边界最远约 0.69·hp_res，不构成更坏点）。
（按分歧台账 D-01：路线1 的 1.1284 改记为几何常数 2/√π；路线2/3 的 1.0415 为台账口径。）

两口径下 1.25 均安全（1.0415 或 1.1284 均 < 1.25 ≪ 经纬格 4.516），豁免结论三路一致：
HP_CIRCUMRADIUS_FACTOR=1.25 是结构性安全缓冲（决定候选集大小，不进入信号/方差数值），非科学量。

## D4. 极冠边矢高、细分深度与 1e-6·hp_res 预算（按分歧台账 D-02 统一）

真曲线叶边（Górski §5.3 曲线族：赤道带 cos θ = a + bφ，极冠 cos θ = a + b/φ²，refs V1）
对其大圆弦的最大矢高，极冠边以极冠内环角距 ρ₁ = arccos(1−1/(3N²)) ≈ 0.8165/N 为自然单位：

  sag0 = 8.094e-2·ρ₁ ≈ 0.066·hp_res。 [推导]

（台账旧标注 "8.094e-2·hp_res" 的单位错标为 ρ₁ 笔误，按分歧台账 D-02 订正；
两路实测 0.0630–0.0639·hp_res 与该换算一致：
[实验:route2/exp07_polar_sagitta_ladder.py] 实测 0.08012·ρ₁ = 0.0639·hp_res，
[实验:route3/exp05_sagitta_subdiv.py] 实测 6.383e-2…6.393e-2·hp_res，尺度不变性 0.15%。）

边矢高对细分层数 k 的解析律为逐层 ÷4（二分时弦偏差平方收敛）：
depth_needed = log(sag0/预算)/log 4 = log(0.066/1e-6)/log 4 ≈ 7.97。
故 **max_depth ≥ 9 才能稳妥清偿 1e-6·hp_res 极冠矢高预算**：

- 名义读数（统一单位后）：depth=8 残差 = 1.153e-6·hp_res，超预算约 15%（[实验:route3/exp05_sagitta_subdiv.py]）；
- 保守上界（路线2 梯子早期层收敛比 3.65 慢于解析 1/4）：depth=8 残差 3.15e-6·hp_res（[实验:route2/exp07_polar_sagitta_ladder.py]）。

生产事实：spherical_overlap.cpp:857 的 WCS_ADAPTIVE_MAX_DEPTH = 12（cpp 是行为事实源）；
12 ≥ 9 ⇒ 生产实现已满足矢高预算，需订正的是文档（05 §11 写 8 应改 12）而非代码（A-P3-08）。
若维持 depth=8，须把预算放宽至 2e-6·hp_res 并如实登记（D-02 终裁）。

## D5. 量化界的方向判决（按 A-P3-05）

coverage/量化存储 q = round(255·S)（half away from zero）下有两个互逆的"补偿口径"：

- **补偿口径** sig = S·(255S/q)（信号除以量化支撑）：严格界 |r| = |sig/S − 1| ≤ 0.5/q 精确成立
  （整数舍入不等式；全枚举 1025 样本 + 2×10⁶ 细扫最大越界 1.86e-17，纯浮点噪声；
  [实验:e4_flux_conservation.py 第6节]、[实验:route3/exp07_quantization.py]、[实验:route2/exp08_coverage_quantization.py]）；
- **反方向** sig = S·q/(255S)：界被违反，S → 0.5/255⁺ 处 r → −1（S = 1/510 ⇒ −50% 确认）。

05 §5.2 曾把两方向倒置，按 A-P3-05 判决订正为补偿口径（严格界成立、worst −0.5 @ S=1/510）。
最坏点方差效应 (1+r)²−1 = −0.75（SNR 减半）；S < 1/510 ⇒ q=0 域 r 无定义，实现必须特判；
banker's rounding 在同一 S 静默丢像素（语义风险，文档须写明半远离零）。

## D6. gnomonic 逐点律与 drop 级预算（按 A-P3-03 统一表述）

TAN/gnomonic 投影（C&G 2002 式(54)，refs V5）的局部面积元定律：

  dA_plane = dA_sphere · sec³ρ = dA_sphere·(1 + (3/2)ρ² + O(ρ⁴))，符号恒正（平面高估）。 [推导]

- **逐点律 +3ρ²/2 精确**（[实验:e5_projection_budgets.py]：pointwise/(1.5ρ_max²) = 1.000000 全段）；
- **drop 级偏差依赖几何**：对方形/圆盘 drop 积分，bias/ρ_max² ∈ [0.5, 1.5]（居中 ≈ +0.5，偏置可达 +1.4，圆盘级 +0.75；
  [实验:route2/exp05_projection_budgets.py]）。路线3 给出全段精确闭合
  ratio − 1 = (1+ρ_c²)^{3/2} − 1 + θ²/4 + O(ρ²θ²)（残差 ≤1.4e-8，[实验:route3/exp06_projection_budget.py]）。
- 统一表述（A-P3-03）：逐点写 +3ρ²/2（精确）；drop 级写区间 [0.5, 1.5]·ρ_max² 并注明符号恒正；
  "注释系数错 3 倍"的旧表述撤回——错在把几何依赖量写成单一常数。

## D7. 切平面正交支偏差：约定依赖（按 A-P3-02/A-P3-04）

生产 planar_polygon_area_n（正交切平面支，max_angular_radius_for_tan=1e-3）的单向下偏：

- 路线1（盘状/方形 drop，θ=最远顶点角距）：实测律 −0.2512·θ²，θ=1e-3 ⇒ −2.51204e-7（[实验:e5_projection_budgets.py]）；
- 路线2（复现生产构造，θ_max 约定，200 随机取向全负）：−θ_max²/2，θ_max=1e-3 ⇒ −5.0e-7（[实验:route2/exp05_projection_budgets.py]）；
- 路线3（dev = 0.4167·h²，h=切平面半边长）：h=1e-3 ⇒ 4.163e-7（[实验:route3/exp06_projection_budget.py]）。

三路方向一致（恒负、单向下偏）；数值差异来自 θ 约定与投影构造不同，非矛盾。
订正口径（A-P3-04）：按**生产实现的 θ_max 约定**取 −5.0e-7 @1e-3 并写明约定；
代码注释 "<4e-8" 错误（实际 ~4.2e-7，低约 10 倍）且缺符号，须改注释。

## D8. k_corr 两因子分解（D-08 终裁；本单元是 k_corr 归属单元）

control_variance = k_corr·(π/2)·σ_bg²/N_retained 中的 k_corr 分解为：

  **k_corr = k_shape × k_geo**

- **k_gauss(N)**（iid 高斯有限 N 修正，"正本估计器口径"＝逐实现 MAD→跨实现中位）：
  N=5: 1.637、N=9: 1.316、N=17: 1.144、N=25: 1.083、N=49: 1.046、N≥121: ≈1.00
  （[实验:kcorr/direct_char.py] 400k 直接定征；与 drizzle 无关——恒等几何直接定征）。
- **k_geo(几何)**（drizzle 输出像素相关的纯几何因子）：随 (ρ=输出/源尺度比, pixfrac, 帧数/dither, patch 构成) 变化：
  正本几何紧凑 patch ≈1.27±0.03、全 touched ≈1.43–1.45、空间分散 ≈1.00、几何扫描全域 1.00–5.0
  （[实验:kcorr/run_scan.py] g3/g4/g5）。
- 非高斯边际形状效应 ≤±5%（N≥9），可忽略（H3 否证）；k_corr 强依赖 N 与几何（H1 否证）；
  正本几何受控复现 1.3445±0.0416（16 相位×8 seed，range [1.273, 1.425] 含 1.3883 上沿）⇒ H2 成立：
  **1.3883 是标定几何专属的单次 MC 实测值，不是可解析常数，也不含于 F&H 2002**（refs V2 子串检索）。

**冻结 1.4 的失保守判决**（负责人已批改表）：声明标定域（pixfrac∈[0.5,1] × 源 [300,600]″/px）内
N=5 端 k_corr(5,紧凑) ≈ 2.05±0.09 ⇒ 1.4 低估 control_variance 32%（标准误低估 14%；空间分散 1.54）；
源 583–600″ 端 k_corr ≈ 2.5–3.0 ⇒ 低估约 2 倍。消费规则（供 P5 引用的正确表述）：
k_corr 改 **k_shape × k_geo 两因子公式＋(ρ, pixfrac, 帧数/dither, patch 构成) 几何查表**；
任何引用必须同时声明 ① 标定元组、② N_retained 档位（N≤25 时 k_gauss(N)>1.08 不可忽略；N=5 须 ≥1.6）；
几何不匹配时 fail-closed 拒绝或现场 MC 重标（秒级，code/audit/kcorr/ 可复用）。

## D9. 接缝绝对面积地板（EXP-07 正本）

u+v=1 接缝（全天 12 条 face 边）在小 drop 位形下存在浮点相消型绝对面积地板：

  |δA| ≈ 1.2–1.7e-16 sr ≈ 0.6·ulp(1)（= 1.3·u，u = eps/2），

8 倍 drop 尺寸范围内恒定 ⇒ 相对闭合 ∝ 1/A_drop；超过 1e-6 门禁的条件为
A_drop ≲ 1.4e-10 sr，即**像元尺度 ≲ 2.4″/px**（[实验:p9_review.cpp T28/T29]、[实验:p10_seam.cpp T26]）。
HST 真实 0.04″/px 实测接缝闭合 3.3e-3（生产直调），比门禁宽 3300 倍。
机制定位到 S-H 交点构造侧（两种独立面积公式同值 5.251e-5、三种边界表示同向偏离），最后一步相消未定位——见诚实边界。

## D10. 绝对坐标求积的 ~1e5 倍舍入放大（工程建议，A-P3-12）

drop 多边形顶点在 O(0.75) 绝对坐标下做 O(1e-5) 尺度求积时，shoelace 与 S-H 边界插值
（t = sp/(sp−sc)）把双精度舍入放大 ~1e5 倍（链路残差实测 1.16e-5）；
shoelace 前平移到质心＋裁剪在质心坐标系进行后残差 4.4e-16
（[实验:route2/exp10_chain_usecase.py]）。生产 shoelace/球面求积存在同型放大风险，
可用该贯通用例直接回归检验（列入工程回归建议；EXP-07 的 chart 原生路径 T8b 独立复现同型坑：不平移则 5.4e-5 伪误差）。
