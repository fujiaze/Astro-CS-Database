# P3｜平面探测器像元到 HEALPix 球面的通量守恒映射：面积分割、极区几何与局部误差审计

> 科学论文修订稿。把数学守恒恒等式与实际几何算法的浮点/边界误差严格分开。历史 `REPORT_paper.md` 的推导与数值表在 Git 历史及 `REPORT_experiment.md`、`docs/DERIVATIONS-P3.md`、`docs/audit/KEY_RESULTS.md` 保留溯源。本稿中的异常测量来自 DeepSeek 交接报告，尚待独立 oracle 复算。

## 摘要

本文研究平面天文 CCD/CMOS 图像的积分通量如何经有限面积 drop 被分配至 HEALPix NESTED 球面像元，并在同时保证常量面亮度不被调制的条件下给出几何和噪声误差预算。方法用源像元未收缩球面面积 `A_pixel,j`、drop 足迹面积 `A_drop,j` 与每个目标叶的交叠 `a_jp`，分离“数学核的总通量守恒”与“实际叶边界近似/候选搜索的完备性”。HEALPix 像素化和 Drizzle 面积法各已有先例 [R07][R06]；可研究的新问题是其特定组合在 HEALPix 跨 face、极区、顶角以及实际生产 nside 下的误差上界。代理报告指出特定 face 中心与 drop 压叶顶角构型可能出现约 `-3.209e-3` 的完备性偏差，与现有论文的小残差声明冲突。本稿把该结果登记为待复核反例，拒绝以全局总和掩盖局部几何失效。

**关键词**：HEALPix；Drizzle；球面多边形；通量守恒；几何裁剪；极区；协方差传播。

## 1 科学定位和先前工作

Fruchter & Hook [R06] 将可变像元的面积交叠与有效加权用于欠采样图像重建；Górski 等 [R07] 提供 HEALPix 层级球面像素结构。ACSD 不独创两种基础对象。本研究主张待验证的是：在给定 WCS/失真模型和 HEALPix NESTED 网格下，是否能够提供可计算的**分配闭合、常量场保真、边界完备性与产品误差**。以下四个命题不可混为同一个“守恒”指标：

- S1 每个源 drop 的分配权重之和 `sum_p w_jp=1`；
- S2 全产品积分通量 `sum_p F_p=sum_j x_j`；
- S3 常数球面面亮度输入导致每个有效目标像元输出相同 `B0`；
- S4 映射后的逐像元方差与相邻像元 covariance 按线性算子传播，所有物理量单位一致。

S1 的点对点偏差可能在全局求和中与别的符号抵消，从而令 S2 漂亮而 S1 失败；S3 也不能代替 S1。S4 影响后续 SNR 并不由 S1–S3 推出。

## 2 映射算子与几何闭合

源像元 j 含积分通量 `x_j` [ADU]，其未收缩球面面积为 `A_pixel,j` [sr]。设 drop 映射的球面足迹 `D_j` 面积为 `A_drop,j`，交叠 `a_jp=area(D_j intersect H_p)` [sr]。将每个源的积分通量分配到叶 p：

```text
w_jp = a_jp / A_drop,j            (dimensionless)
F_p  = sum_j x_j * w_jp           (ADU)
N_p  = sum_j A_pixel,j * w_jp     (sr)
B_p  = F_p/N_p                    (ADU/sr, defined only N_p>0)
```

在**交叠确实分割完整、面积分母一致**的理论算子下，`sum_p a_jp=A_drop,j`，从而 `sum_p w_jp=1`、`sum_p F_p=sum_j x_j`。若输入是相同面亮度 B0，则 `x_j=B0*A_pixel,j`，故输出 Bp=B0。数学恒等式不提供有限精度分割器的误差数值；实际实现需基于**同一个** `A_drop` 与累计 `a_jp` 对拍独立几何 oracle。

注意：`A_drop,j` 与 `pixfrac²*A_pixel,j` 在非等面积投影和 WCS 畸变下并不总是精确相等。源 drop 在局部切平面作线性尺寸缩放，球面 Jacobian 的变化引入高阶偏差。生产不得在输出通量核的分母混用两个不同物理面积并仍宣称精确闭合。

将 `c_jp=w_jp/N_p`（单位 sr^-1）定义为作用在源积分通量上的线性组合系数，则在源像元独立、方差为 vj [ADU²] 的前提下

```text
Var(B_p)       = sum_j c_jp^2 * v_j              (ADU²/sr²)
Cov(B_p,B_q)   = sum_j c_jp * c_jq * v_j          (ADU²/sr²)
```

同一源像元同时作用多个叶，通常会产生非零跨叶相关。若输入本已相关，则应使用 `C_out=R C_in R^T`，而不能再次假设独立。ACSD 可以只存对角方差面，但必须将省略协方差的影响列入使用限制。

## 3 HEALPix chart、边界与误差来源

HEALPix face 可用局部参数化寻址，等面积 chart 的 Jacobian 性质有助于几何处理；但真实 HEALPix 小像元在球面上的边界一般并非两顶点的大圆短弧。算法若用叶的四角弦近似球面曲边，局部交叠偏差和漏候选可能在 drop 压叶顶点、face 中心、极区与面缝附近被放大。需要分别排查：

1. WCS 像元足迹的球面映射与角点顺序；drop 缩放中心和局部畸变；
2. 球面曲边到折线/弦的细分误差，边界交叉时是否缺符号；
3. HEALPix NESTED face→leaf 的多分支寻址和圆极点附近的数值条件；
4. 候选叶包围半径是否足够，不能把“遍历了已枚举候选”当作“没有漏选”；
5. `A_drop` 与 `sum a_jp` 使用何种面积定义、不同精度及退化阈值；
6. 多重几何容差是否把极细交叠错误删除。

不得把求和中的泄漏“强行归一化到 1”当作完全修复：强归一能在数值上满足 S1/S2，却可能改变局部目标面亮度、PSF 形状或真实面积贡献，必须用独立的 S3/S4 及逐叶真值检验识别。

## 4 验证实验：四条正交判据与位置扫描

| 编号 | 试验与 independent oracle | 冻结变量/扫描范围 | 核心验收量 |
|---|---|---|---|
| P3-A 代数闭合 | 人工构造交叠有理面积与积分通量真值；独立于生产裁剪器 | 1 drop 对 1/2/4/多叶；常量/脉冲场 | 单 drop `epsilon_j`、全通量比、常量 B 偏差、variance/covariance |
| P3-B 曲边与顶角 | 足够精细的球面边界积分+全量候选枚举，对生产弦-多边形算法 | RA=45° face 中心、叶顶角/边中、face 角点两侧、极面与赤道边界；`nside=512..16384` | 面积相对误差、`max_abs(epsilon_j)`、漏候选数、`max_abs(B-Boracle)` |
| P3-C 投影与像元尺度 | WCS/畸变几何高精度数值积分或符号小角展开 | `pixfrac=0.5/0.8/1`，像素角尺度从小到大、旋转、负 parity、SIP | 球面面积比、误差随角尺度幂律、正反变换一致性 |
| P3-D 物理天区仿真 | HST 星云+星点已知通量的前向合成图；源真值积分 | 多星等、扩展源、非零背景、实测 PSF | aperture flux bias、扩展源面亮度、PSF 形状、关联噪声 |
| P3-E 生产回归 | 真正调用当前 `lib/**` 路径并与 P3-B 对拍 | CPU 构建位深、nside、单帧 HiPS 与多帧 | S1–S4 全链不变量及显式失败状态 |

其中单 drop 完备性 `epsilon_j=sum_p(a_jp/A_drop,j)-1` 与报告里的“逐叶残差”需先检查**量是否相同**。相同后才能说 `-3.209e-3` 超过 `1e-6` 门约 3209 倍；若不同，则两者分别建量纲及分母字段。试验同时要给绝对与相对误差、分母接近零时的处理规则、错误分位数与最大值。不要只报告均方 RMS 掩盖局部尖峰。

## 5 现有读数、冲突与科学判定

交接报告指出：在 `0.04 arcsec` 的源像元尺度、`nside=8192`、RA=45° 对应的面中心与叶顶角相关位置，某守恒读数达到 `-3.209e-3`，相近构型还有 `-1.002e-3`、`-1.779e-3`；现行正本报告了 `6.6e-12` 的另一测试位置集结果。**证据等级：AGENT_REPORTED。** 尚未获得独立几何 oracle、同物量证明与完整坐标真值，不可据此武断选择“实现错”或“数学理论错”，也不能以测试域未扫 face 中心就排除这个生产合法构型。

对可能的 `0.10438849/nside²` 顶角弦亏缺经验律，应报告拟合系数、理论推导、残差和范围；局部 `~0.3%` 的异常显然不能用 64 位浮点舍入误差解释，可能体现曲边近似/候选拓扑/几何分母口径的更大问题。只有按 P3-B 与 P3-E 对拍后才可定性。

## 6 结论与可主张贡献

目前可论文陈述的是：一套结合球面面积分割、HiPS/HEALPix 层级存储、显式单位和误差传播的**待验证数值方案**。数学上的全通量闭合、常量场不调制有明确证明，但实际实现的全参数域局部守恒尚未通过独立反例。出版前必须证明每一合法位置构型内 S1–S4 的误差有统一界限，或**明确收缩产品适用域并使代码失败关闭**；不能仅凭历史位置集低误差宣称“全域精确”。
