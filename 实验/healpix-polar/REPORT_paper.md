# P3｜平面探测器像元到 HEALPix 球面的通量守恒映射：面积分割、极区几何与局部误差审计

> 本篇把数学守恒恒等式与实际几何算法的浮点/边界误差严格分开，并按最低图表集登记独立几何 oracle、生产三臂读数与适用域。推导、逐格矩阵与过程记录见 `REPORT_experiment.md`、`docs/DERIVATIONS-P3.md` 与 `docs/audit/KEY_RESULTS.md`；可复跑脚本见本单元 `code/`（图由 `figures/make_figures.py` 从真实读数生成）。

## 摘要

本文研究平面天文 CCD/CMOS 图像的积分通量如何经有限面积 drop 被分配至 HEALPix NESTED 球面像元，并在同时保证常量面亮度不被调制的条件下给出几何和噪声误差预算。方法用源像元未收缩球面面积 `A_pixel,j`、drop 足迹面积 `A_drop,j` 与每个目标叶的交叠 `a_jp`，分离“数学核的总通量守恒”与“实际叶边界近似/候选搜索的完备性”。HEALPix 像素化和 Drizzle 面积法各已有先例 [R07][R06]；可研究的新问题是其特定组合在 HEALPix 跨 face、极区、顶角以及实际生产 nside 下的误差上界。在 `RA=45°` 的叶公共顶点构型上，逐 drop 完备性 `ε_j` 实测 `−3.2094e-03`，超出 `1e-6` 门三千余倍；独立几何 oracle 证明连续极限下 `ε_j ≡ 0`（四角弦叶恰铺满 drop），据此定位到**两处近简并叉积条件数缺陷**（drop 边法向、球面裁剪交点）并修复，同一构型降至 `−8.37e-10`，300 格受控矩阵与 1500 格独立矩阵均无格破门，注入缺陷的旁路开关可逐位复现原缺陷。**修复后仍有 `60″–290″` 档的叶四角弦/切平面-球面分支残差（峰值 `3.29e-7`）未修**，但其量值不破 `1e-6` 门；本篇据此给出适用域而非“全域精确”的主张。

**关键词**：HEALPix；Drizzle；球面多边形；通量守恒；几何裁剪；极区；协方差传播。

## 1 科学定位和先前工作

Fruchter & Hook [R06] 将可变像元的面积交叠与有效加权用于欠采样图像重建；Górski 等 [R07] 提供 HEALPix 层级球面像素结构。ACSD 不独创两种基础对象。本研究主张的是：在给定 WCS/失真模型和 HEALPix NESTED 网格下，提供可计算的**分配闭合、常量场保真、边界完备性与产品误差**，并以独立几何 oracle 与位级负例界定其成立范围（见第 5 节适用域）。以下四个命题不可混为同一个“守恒”指标：

- S1 每个源 drop 的分配权重之和 `sum_p w_jp=1`；
- S2 全产品积分通量 `sum_p F_p=sum_j x_j`；
- S3 常数球面面亮度输入导致每个有效目标像元输出相同 `B0`；
- S4 映射后的逐像元方差与相邻像元 covariance 按线性算子传播，所有物理量单位一致。

S1 的点对点偏差可能在全局求和中与别的符号抵消，从而令 S2 漂亮而 S1 失败；S3 也不能代替 S1。S4 影响后续 SNR 并不由 S1–S3 推出。

## 2 映射算子与几何闭合

源像元 j 含积分通量 `x_j` [ADU]，其未收缩球面面积为 `A_pixel,j` [sr]。设 drop 映射的球面足迹 `D_j` 面积为 `A_drop,j`，交叠 `a_jp=area(D_j intersect H_p)` [sr]。将每个源的积分通量分配到叶 p：

```text
w_jp = a_jp / A_drop,j            (dimensionless)
F_p  = sum_j x_j * w_jp           (ADU)
N_p  = sum_j A_pixel,j * w_jp     (sr)
B_p  = F_p/N_p                    (ADU/sr, defined only N_p>0)
```

在**交叠确实分割完整、面积分母一致**的理论算子下，`sum_p a_jp=A_drop,j`，从而 `sum_p w_jp=1`、`sum_p F_p=sum_j x_j`。若输入是相同面亮度 B0，则 `x_j=B0*A_pixel,j`，故输出 Bp=B0。数学恒等式不提供有限精度分割器的误差数值；实际实现需基于**同一个** `A_drop` 与累计 `a_jp` 对拍独立几何 oracle。

注意：`A_drop,j` 与 `pixfrac²*A_pixel,j` 在非等面积投影和 WCS 畸变下并不总是精确相等。源 drop 在局部切平面作线性尺寸缩放，球面 Jacobian 的变化引入高阶偏差。生产不得在输出通量核的分母混用两个不同物理面积并仍宣称精确闭合。

将 `c_jp=w_jp/N_p`（单位 sr^-1）定义为作用在源积分通量上的线性组合系数，则在源像元独立、方差为 vj [ADU²] 的前提下

```text
Var(B_p)       = sum_j c_jp^2 * v_j              (ADU²/sr²)
Cov(B_p,B_q)   = sum_j c_jp * c_jq * v_j          (ADU²/sr²)
```

同一源像元同时作用多个叶，通常会产生非零跨叶相关。若输入本已相关，则应使用 `C_out=R C_in R^T`，而不能再次假设独立。ACSD 可以只存对角方差面，但必须将省略协方差的影响列入使用限制。

## 3 HEALPix chart、边界与误差来源

HEALPix face 可用局部参数化寻址，等面积 chart 的 Jacobian 性质有助于几何处理；但真实 HEALPix 小像元在球面上的边界一般并非两顶点的大圆短弧。算法若用叶的四角弦近似球面曲边，局部交叠偏差和漏候选可能在 drop 压叶顶点、face 中心、极区与面缝附近被放大。需要分别排查：

1. WCS 像元足迹的球面映射与角点顺序；drop 缩放中心和局部畸变；
2. 球面曲边到折线/弦的细分误差，边界交叉时是否缺符号；
3. HEALPix NESTED face→leaf 的多分支寻址和圆极点附近的数值条件；
4. 候选叶包围半径是否足够，不能把“遍历了已枚举候选”当作“没有漏选”；
5. `A_drop` 与 `sum a_jp` 使用何种面积定义、不同精度及退化阈值；
6. 多重几何容差是否把极细交叠错误删除。

不得把求和中的泄漏“强行归一化到 1”当作完全修复：强归一能在数值上满足 S1/S2，却可能改变局部目标面亮度、PSF 形状或真实面积贡献，必须用独立的 S3/S4 及逐叶真值检验识别。

## 5 结果、证据级别与适用域

### 5.1 缺陷复现、根因与修复

`RA=45°`（`dec=asin(2/3)`）的叶公共顶点构型上，drop 边长 `0.032″`、`nside=8192`、`pixfrac=0.8`，逐 drop 完备性 `ε_j = −3.209422e-03`，超门 `3209×`；相近构型在 `RA=135°`、`225°` 分别给出 `−1.002136e-03`、`−1.779342e-03`。独立几何 oracle 首先排除了几何表示本身：精确切平面 2D 凸裁剪给 `ε = +1.33e-15`，drop 内 4001² 网格对四角弦叶的半空间测试四叶分数和为 `1.000000`，真叶成员判定确认铺满 ⇒ **四角弦叶恰铺满 drop，既非曲边近似也非候选漏选**。

根因是两处近简并叉积条件数缺陷，均在**同一生产调用路径**上：

| 臂 | 顶点构型 `ε` | 是否破 `1e-6` 门 |
|---|---|---|
| 修复前 | `−3.209422e-03` | 是（`3209×`） |
| 只修 drop 边法向 | `+5.499704e-05` | 是（`55×`） |
| 法向 + 球面裁剪交点两项合用 | `−8.370272e-10` | 否 |

- **drop 边法向**：`normalize(cross(C_j,C_{j+1}))` 中 `|cross|≈θ` 而分量为 O(1) 乘积之差 ⇒ 法向角误差 `~ε_mach/θ`、平面位置相对误差 `~2ε_mach/θ²`。实测四条边平面偏移 `n·c` 由 `[7.760822e-08, 7.725840e-08, 7.760172e-08, 7.734707e-08]`（最大偏差 `0.45%`）变为四个**逐位相同**的 `7.757019e-08`。
- **球面裁剪交点**：原用 `cross(cross(S,E), n_clip)`；迭代后出现边长 `~1e-7 rad` 的 subject 边时同样近简并。改为弦-平面零点并在 `d_S`、`d_E` 异号时归一化，保留分母近零的叉积回退。

方法学订正（一并留档）：微小多边形的面积相消**不是** `l'Huilier` 公式的固有缺陷，而来自用 `acos(dot)` 求边角（`0.032″` 正方程形相对误差 `+9.26e-04`）或用 VOS 三重积（`−6.17e-04`／另一读数 `+1.51e-04`）；`l'Huilier` + `atan2(|u×v|, u·v)` 给 `+1.11e-09`。微小面积一律推荐切平面投影式，但不得以“`l'Huilier` 不稳”否定以 `atan2` 求角的实现。

### 5.5 适用域与未跑域（必须同读）

1. **`60″–290″` 档的叶四角弦表示与切平面/球面面积分支残差未修。** 修后该段 `max|ε_j|` 峰值 `3.29e-7`（在 `290″`），虽**不破 `1e-6` 门**（余量约 `3×`），但它是未建模的叶侧项，不得声称已修或已覆盖。`290″` 附近的峰与 `max_angle = 1e-3`（drop 边长 `291.70″`）的硬分支切换同源，切平面与球面两种面积分支在 `a_jp` 与 `A_drop` 间不完全相消。
2. 已扫描到 `3600″`；**更粗像元域、生产 FP32 实例、`HP_CIRCUMRADIUS_FACTOR` 的全天穷举一律 `NOT_RUN`**，不得由已验证读数外推。
3. 极点位置类修前修后**逐位相同**，破门只来自 drop 压叶公共顶点/叶边两类；因此“跨 face/极区已遍历”不等于“全位置类已闭合”。
4. 大 drop 路径**不再逐位零回归**：两项补丁对 `max_angle≥1e-3` 的构型改变量级为 `max|Δε|=5.70e-11`、`max|Δflux/flux|=3.91e-12`。若要求“大 drop 逐位零回归”，必须放弃交点补丁，而那样顶点构型修不好。
5. 真实帧腿（P3-C/D）与多帧 HiPS 产品级回归尚未运行。

### 5.6 跨篇误差传递反例（P3 → P4/P2）

按统一实验协议的第四条证据腿，P3 应向下游提供一条“上游缺陷传播到下游、下游判据必须能判红”的可复算用例。**本篇 `NOT_RUN`。** 现有反例只能证明 P3 内部判据能判红（注入缺陷使 48/300 与 218/1500 格重新破门，且与修前逐位等价）。缺什么：① P3 修复前后各算一次的映射协方差，以及 P4 消费该协方差时的支持域/权重判据读数；② 一条同天区、同滤镜的 P3→P4 数据链（点源或弥散源被估量需先冻结）；③ P2 侧对同一映射的 `k_corr`/相关噪声标定（归 P2 单元）。因此下游是否“判红”在本篇无法给出。

## 6 结论与可主张贡献

数学上的全通量闭合与常量场不调制有明确证明；实际实现中，逐 drop 完备性在小尺度叶顶点/叶边类上的缺陷已被独立 oracle 复现、定位到两处近简并叉积条件数缺陷并修复：`ε_j` 由 `−3.2e-3` 量级降到 `1e-8` 量级，误差律由 `ε_mach/θ²` 降到 `ε_mach/θ`，300 格与 1500 格矩阵均无格破门，注入缺陷可逐位回退。因此可论文陈述的贡献是：**一套结合球面面积分割、HiPS/HEALPix 层级存储、显式单位与误差传播，并带独立几何 oracle 与位级负例的数值方案**。

同时必须限定：数据只支持到已扫域（`0.02″–3600″`、`nside 512…16384`、`pixfrac 0.5…1`、CPU FP64），`60″–290″` 的叶弦/分支残差未修，FP32、更粗像元域与全天穷举未跑；跨 face 与极区“已遍历”不能替代全位置类闭合。不得据已验证读数宣称“全域精确”，也不得据未跑域外推。
