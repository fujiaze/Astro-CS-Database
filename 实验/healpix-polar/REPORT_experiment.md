## 1. 假说

三路审计与补实验共同检验的假说组：

- **H-守恒**：drop 归一权重 w_jp = a_jp/A_drop 使 Σ_p F_p = Σ_j x_j 构造性精确（与 pixfrac 无关）；A_leaf = π/(3N²) 解析恒等。负例：A_pixel 归一（Σ_p w′ = pf²）、覆盖分母 D_p（+1/pf²−1）、π/(4N²) 候选（度量 0.25）、chart 扰动注入（ε=5e-4 ⇒ 度量 5.000e-4）。
- **H-几何**：球面近似的系统性偏差有闭式——极像元弦亏缺 −9.968368384e-2 与 0.1043885/N²（D-09 订正）；gnomonic 逐点 +3ρ²/2、drop 级 [0.5,1.5]ρ_max²；切平面正交支单向下偏（θ_max 约定 −5.0e-7 @1e-3）；矢高 sag0 = 8.094e-2·ρ₁（D-02 订正单位）、逐层 ÷4。
- **H-封装**：外接半径全天 sup ≈ 1.0415·hp_res（1.25 裕量 ≥20%）；细分深度 ≥9 清偿 1e-6·hp_res；量化 |r| ≤ 0.5/q（补偿口径）。
- **H-k_corr**：k_corr 是几何与估计器口径的条件量（配置说 H2），非普适常数（H1）、非边际形状伪影（H3）；可分解为 k_gauss(N) × k_geo。
- **H-判据**：恰保总量注入下求和型判据失明、逐叶判据有效；弦表示下闭合判据对 RC1 失明、破门由快路径假阳性主导。

**M1 / M3 / NC-B / ρ=0 是本腿的有效守恒证据**：它们对精确面积原语的取法不敏感——该原语不进入
`w_jp`（分母是 chart 面积），分子分母共用它，误差抵消。取指数 2（错）与 3/2（对）两版原语复跑，

⇒ **指数改正不塌掉守恒读数**，这一腿作为"守恒在物理前向信号面上仍成立"的证据站得住。

**图表侧几何项（真实存在的那一项）**：把"chart 直线多边形 vs 真 drop（大圆四边形）"隔离出来，
按足迹尺度 0.2/0.8/3.2/12.8 px（角半径跨 64×，ρ 扫到 10000″）实测为
**3.40e-09 / 7.48e-10 / 2.03e-10 / 7.31e-11**——**随足迹缩小单调下降**，是与叶侧弦亏缺同类的
弦–曲线效应。对 ρ² 的斜率 −1.22e-09，即**不存在 ρ² 项**。精确立体角由 gnomonic 积分给出，
被积函数 `dΩ = dξdη/(1+ξ²+η²)^{3/2}`；指数由 gnomonic 圆盘解析值 `2π(1−1/√(1+r²))` 定标：
指数 3/2 在 r = 0.1/0.5/1/2 处相对误差 +3.8e-15 / −2.2e-16 / +4.4e-16 / 0.0，
指数 2 则为 −2.5e-03 / −5.3e-02 / **−1.46e-01** / −2.8e-01。

**面归属必须按 (z, phi) 定，不能只按方位角。** 面 4-7 的菱形**不单独铺满** \|z\| ≤ 2/3 的带：
给定 s = u+v = 1+1.5z，面 f 的方位角窗口是 \|phi − axis_f\| ≤ 45°·min(s, 2−s)，\|z\| 越远离 0 窗口越窄；
窗口之外的方位角归入面 0-3（z>0）或面 8-11（z<0）的赤道带分支。实测（z = −0.24）：
phi = −85.4° 属面 7、phi = −60.4° 与 −30° 属面 11；z = +0.20 时 phi = 10° 属面 4、phi = 40° 属面 0。
按方位角选面会在这些方位角挑错面、逆映射给出 u<0 或 v>1 的点，逐 drop 权重于是静默全 0。
本腿改为对**每个角点**独立定面（12 面候选取 (u,v) 落在 [0,1] 内的唯一者），四角同面才参与守恒求和，
否则 fail-closed 剔除并计数。

**M5「视场跨面界」构造用例。** M16 视场只有 22.5″ 宽、面界在数度之外，永远触不到面界路径，
故另造一段跨面界的视场：z 由 −0.26 扫到 −0.22，方位角在面 7 / 面 11 的界
`phi_edge(z) = −90° + 45°·(1+1.5z)` 两侧各 3°（A 段），以及方位角**恰在**界上（B 段）。
546 个 drop 中 520 个留在求和内并落在面 7 与面 11 上，Σ_p w_jp − 1 最大 **1.75e-10** ≤ 地板；
26 个 drop 的四角分属两面，被 fail-closed 剔除并计数。**判据能红**：同一构造改用只按方位角选面的
旧规则时，**260 个 drop 的 Σ_p w_jp 静默变成 0**（\|Σw−1\| 最大 1.0），且不被任何计数捕获。

**NC-A 改为「面积归一自洽」判据，不再要求归零。** 残差定义里的 `+0.5·<ρ²>_p` 修正项恰是被测原语
自身的指数误差展开首项（`√(1+ρ²)−1 ≈ ½ρ²`），属循环负例，已整体撤掉——残差里现在不含任何几何补偿项。
平坦真值下 `S_p/B − 1` 恒等于逐叶内 `(π/3)A_chart/A_exact − 1` 的面积加权平均，即 chart 侧的
弦–曲线几何项本身，与信号场无关，**本就不该归零**。判据改为「逐叶残差 ≤ 逐像元面积比的最大值」
（4.847e-10 ≤ 9.239e-10）：该上界成立当且仅当每个叶权重非负且分割完备，权重为负或漏归一化时立刻破。
撤去补偿项后该读数同时落在读数地板 9.743e-10 之内，但这一条不再作为判据。

**M4 只作防恒真检查。** 把指数由 2 改为 3/2 后读数 2.47361/0.374672 保持 9 位不变 ⇒ M4 对几何零
**不敏感**，其数值就是物理前向信号场自身的对比度。它检验算子对结构场的响应不退化，
**不**测几何零，不作守恒判据。

**VOS 在 HST 尺度 drop 上不可作精确面积 oracle**（行列式相消，相对误差 ~1e-16/(张角)²，实测
0.16″ drop 上 1.7e-6，缩小 100 倍后 4.6e-2）；本腿因此把精确面积判据建在 gnomonic 积分上。

**生产侧面积口径（已审计）**：`spherical_overlap.cpp` 按 drop 尺度分档——角半径 < 1e-3 rad ≈ 206″ 用
切平面 2D 面积、其余用球面 VOS，且分母 `g.drop_area`（`:1099-1101`）与分子逐叶交集
（`:1336-1340` 凸四边形、`:1379-1384` 细分边界）用**同一阈值同一例程**，分档内部自洽。差异两处：
① 逐三角形 `tri_inside` 快路径（`:1370`）无条件用球面 VOS，与该分档不一致，仅在"微小 drop × 细分边界"

## 5. 结论

1. P3 的守恒是构造性精确（Σw=1 逐位、全局 8.2e-15、A_leaf 双式互证 3.3e-12），不是数值凑出的良好残差；验收必须逐叶（求和判据失明 14.88 个数量级）。
2. 球面几何偏差全部闭式化并可回溯：亏缺律 0.1043885/N²（D-09）、矢高 8.094e-2·ρ₁（D-02）、外接半径 1.0415（D-01，1.1284 改记账 2/√π）、量化 0.5/q（A-P3-05）、投影支按约定记账（A-P3-02/03/04）。
3. 工程封装常数豁免有据：1.25（裕量 ≥20%＋HEALPix 特化反例 4.516 / 1.6934，两路）、max_depth ≥9（生产 12 已满足，只改文档）、量化群（纯数学枚举）。
4. k_corr 归属本单元：两因子公式＋几何查表取代冻结 1.4（D-08 终裁，已批），正确表述已写入论文 §3.4 供 P5 引用。
5. **M16 物理前向仿真腿**（最高设计 §12.2 第 1 类数据）已接入：守恒在非退化的物理信号面上仍成立（全局闭合 5.995e-14、整叶内 drop 的 Σw 逐位 0、错分母报警 −0.36、rho=0 归零，且这四项对精确面积原语的取法不敏感）；图表侧真实几何项为弦–曲线效应，随足迹缩小单调下降（0.2→12.8 px 档 3.40e-09 → 7.31e-11），精确立体角原语的被积函数是 (1+xi^2+eta^2)^(-3/2)；面归属按 (z, phi) 解析定面并对跨面 drop fail-closed，另有 M5「视场跨面界」构造用例与旧规则的判红注入。NC-A 改为面积归一自洽判据（不再要求归零，残差不含几何补偿项），M4 只作防恒真检查（详见 §4.6）。
6. |---|---|

| `l'Huilier` + `atan2(|u×v|, u·v)` 求边角 | **`+1.11e-09`** |
| VOS `2·atan2(a·(b×c), 1+…)` 扇 | **`−6.17e-04`** |

`atan2` 稳定求出时精度可达 `~1e-9`。本单元早期一次 `−1.78e-3` 读数是该 `acos` 相消伪影，
**不是** `l'Huilier` 公式的固有缺陷。微小面积仍推荐切平面投影式（与生产
`planar_polygon_area_n` 同族、不引入角度求值的相对损失），但不得以「l'Huilier 不稳」为由
