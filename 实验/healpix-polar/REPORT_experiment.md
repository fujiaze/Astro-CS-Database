## 1. 假说

三路审计与补实验共同检验的假说组：

- **H-守恒**：drop 归一权重 w_jp = a_jp/A_drop 使 Σ_p F_p = Σ_j x_j 构造性精确（与 pixfrac 无关）；A_leaf = π/(3N²) 解析恒等。负例：A_pixel 归一（Σ_p w′ = pf²）、覆盖分母 D_p（+1/pf²−1）、π/(4N²) 候选（度量 0.25）、chart 扰动注入（ε=5e-4 ⇒ 度量 5.000e-4）。
- **H-几何**：球面近似的系统性偏差有闭式——极像元弦亏缺 −9.968368384e-2 与 0.1043885/N²（D-09 订正）；gnomonic 逐点 +3ρ²/2、drop 级 [0.5,1.5]ρ_max²；切平面正交支单向下偏（θ_max 约定 −5.0e-7 @1e-3）；矢高 sag0 = 8.094e-2·ρ₁（D-02 订正单位）、逐层 ÷4。
- **H-封装**：外接半径全天 sup ≈ 1.0415·hp_res（1.25 裕量 ≥20%）；细分深度 ≥9 清偿 1e-6·hp_res；量化 |r| ≤ 0.5/q（补偿口径）。
- **H-k_corr**：k_corr 是几何与估计器口径的条件量（配置说 H2），非普适常数（H1）、非边际形状伪影（H3）；可分解为 k_gauss(N) × k_geo。
- **H-判据**：恰保总量注入下求和型判据失明、逐叶判据有效；弦表示下闭合判据对 RC1 失明、破门由快路径假阳性主导。

**归零负例（三条）**：

- **NC-B 错分母**（w = a_jp/A_pixel，pf = 0.8）：全局守恒读数 **−0.35999999999940**，理论 pf²−1 = −0.36 ⇒ **报警**。
- **NC-C ρ = 0**（drop 中心恰在 gnomonic 切点）：偏差 2.49e-10 ≤ 地板 ⇒ **归零**。

**判读**：守恒构造在物理前向信号面上同样**构造性精确**（M1 5.06e-14）；新测得并三方印证的几何项是
(π/3)·A_chart/A_exact − 1 = ½ρ²，恰好落在既有 gnomonic drop 级预算带 [0.5, 1.5]·ρ_max² 的**下端点**，
且**与足迹大小无关**（不随分辨率收缩，系数散差 1.5e-07）——这是既有预算未登记的性质。

## 5. 结论

1. P3 的守恒是构造性精确（Σw=1 逐位、全局 8.2e-15、A_leaf 双式互证 3.3e-12），不是数值凑出的良好残差；验收必须逐叶（求和判据失明 14.88 个数量级）。
2. 球面几何偏差全部闭式化并可回溯：亏缺律 0.1043885/N²（D-09）、矢高 8.094e-2·ρ₁（D-02）、外接半径 1.0415（D-01，1.1284 改记账 2/√π）、量化 0.5/q（A-P3-05）、投影支按约定记账（A-P3-02/03/04）。
3. 工程封装常数豁免有据：1.25（裕量 ≥20%＋HEALPix 特化反例 4.516）、max_depth ≥9（生产 12 已满足，只改文档）、量化群（纯数学枚举）。
4. k_corr 归属本单元：两因子公式＋几何查表取代冻结 1.4（D-08 终裁，已批），正确表述已写入论文 §3.4 供 P5 引用。
5. **M16 物理前向仿真腿**（最高设计 §12.2 第 1 类数据）已接入：守恒在非退化的物理信号面上仍逐位成立（5.06e-14），并实测出新闭式 (π/3)·A_chart/A_exact − 1 = ½ρ²（分辨率无关），落在既有 gnomonic drop 级带 [0.5, 1.5]·ρ_max² 的下端点；三条归零负例（平坦真值 / 错分母 / ρ=0）分别给出归零、报警、归零。
6. "全天 1e-6"缺口由**三处**界定：极点（三根因耦合的快路径假阳性，最小改动面方案已清偿 0/1089、最坏 2.79e-8，非极区零代价）、`u+v=1` 接缝（逐叶求和相对 drop 面积 ~1e-3 量级、比门禁宽 3300 倍，机制部分定位、最后一步未定位）、原位大离轴指向的共同地板（本轮 3D 基准复跑档 1.1e-05…2.1e-04；2²³ 归档该块最坏 V0 2.353e-04 / oracle 2.124e-04，与 nside 基本无关，未定位）。REC-1 只作**带前提的建议**：前提 ① **须先修实验侧 REC-1 辅助实现 `code/variants.h::overlap_adaptive` 的缺陷（局限在该辅助实现内、未定位到叶）**——3D 一致基准下同格 REC-1 仍为 5.003e+01 而同格 V0 = 1.127e-05、oracle = 3.052e-05 均正常，且 a2d/a3d−1 仅 6.843e-11（该块 25 格 drop 面积比最坏 4.212e-09），**不是面积基准问题**；**判据预算阈值不是成因**（该档 δ_max ≈ 1.16e-13 rad、叶边自然矢高 1.86e-15 rad 小 62 倍 ⇒ depth 0 即满足；5.003e+01 ≈ 51×A_drop 提示有叶返回远超自身面积的贡献，快路径嫌疑最大但未逐叶打印证实）；修法 = 逐叶打印 `(ipix, 返回面积, 该叶解析面积)` 定位后修，**修好并加标志之前 REC-1 不得作为推荐落地路径**；前提 ② 该方案在归档中极点配置全部通过（nside=2²³ 极点栅格 0/121、全帧 9×9 0/81）。<!-- 订正: P3-02/03/08（归因经 3D 基准复跑更正） -->

- **同块 REC-1 的 5.003e+01 不属于上述地板，缺陷局限在实验侧 REC-1 的辅助自适应实现（读数可复现、位置未定位）**：`code/variants.h::overlap_adaptive` 在该格给出 5.003e+01，而同格生产口径 V0 = 1.127e-05、独立 oracle = 3.052e-05 均正常；3D 一致基准下 a2d/a3d−1 仅 6.843e-11 ⇒ **不是面积基准问题、也不是裁剪失败**。**判据预算阈值不是成因**：`code/variants.h:150` 的 `delta_max = 1.5·(budget_abs/4)/len` 在该档给出 δ_max ≈ **1.16e-13 rad**（budget_abs = 3.761e-20 sr、len = 1.22e-7 rad），叶边自然矢高 1.86e-15 rad 比它小 62 倍 ⇒ depth 0 即满足判据。5.003e+01 ≈ **51×A_drop** 提示有叶返回远超自身面积的贡献，`overlap_adaptive` 内"叶完全在 drop 内 ⇒ 返回整块 `g.drop_area`"的快路径**嫌疑最大但未逐叶打印证实**（登记为嫌疑，不作定论）。修法：在 `overlap_adaptive` 内逐叶打印 `(ipix, 返回面积, 该叶解析面积)` 定位后修；**该缺陷修好并加标志之前 REC-1 不得作为推荐落地路径**（见 §4.5）。<!-- 订正: P3-02/03/08（归因经 3D 基准复跑更正） -->
- EXP-07 leafmax_err 判据的三个口径限制（fast 路径继承、测的是推荐方案残差、K 阶不统一）落地前须按其 §4.1 重算（原文已登记）。
- depth=12 收敛性、生产跨面切点分布、N=2/4 平局构造口径：登记项，不阻成稿（台账 §4.2）。
- **M16 仿真腿的 ½ρ² 项是 chart 多边形口径的偏差，不是算子缺陷**：它对所有 drop 同号，因此在 Σ_p w_jp = 1 的分割完备性上**精确抵消**（M3 逐位 0.0），只体现在逐叶面亮度上（M4）。生产若改用测地线（大圆）边，项消失；本单元不改生产代码，只登记。
- **VOS 三角形立体角公式在 HST 尺度 drop 上不可用作精确面积 oracle**：其 det = a·(b×c) 由 O(1) 分量相消得到，而小三角形 det ~ (张角)²，顶点分量只精确到 1 ulp(O(1))，相对误差 ~1e-16/(张角)²；实测 0.16″ drop 上达 1.7e-6（实测：pf=0.8 → 1.74e-6；pf=0.008 → 4.6e-2），完全盖住要量的 ρ² ~ 1e-7。该病态即 refs.md 标注级条目 Kahan 2000 所述"针状三角形数值问题"。本腿的精确面积判据因此建在 **gnomonic 积分**（∫dξdη/(1+ξ²+η²)² 的 Gauss-Legendre 求积，5 阶，9 阶复核）上，并与 VOS 在 40 px 足迹上互校到 3.3e-10。生产 `spherical_overlap.cpp` 的面积口径**未审计**，登记为后续项。
- **M16 仿真腿的 32″ 视场远小于物理画布**：因此 ½ρ² 在物理裁切面上只有 ~1e-8 量级，rho 扫描的 60″–10000″ 段是**同一帧 WCS 的纯几何外推**（只用角点、不用像素内容），不构成信号面读数。
