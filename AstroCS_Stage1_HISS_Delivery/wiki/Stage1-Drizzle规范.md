# Stage1 Drizzle 规范

## 状态

- 精度、NSIDE 和禁止近似规则：**已冻结**
- support 是否存储及精度：**待确认**（见 Stage1-待确认事项）
- signal/support 的最终面积归一化公式：**需在 HISS 物理格式前完成冻结**

## 1. NSIDE

### 1.1 显式传入

合法的显式 NSIDE 默认接受：

- CLI 不发欠采样警报；
- CLI 不要求确认；
- CLI 不自动修改；
- CLI 只验证其是否为支持的 2 的幂和是否处于实现允许范围。

是否提示欠采样由 GUI 负责。

### 1.2 未传入

未传入 NSIDE 时，根据最终 WCS/SIP 的实际局部像素尺度自动选择。

选择原则：

- 输出 HEALPix 线性尺度不粗于输入图像最细有效局部采样；
- 选择满足条件的最小 2 的幂 NSIDE；
- 因相邻 NSIDE 相差 2 倍，默认结果形成约 1–2×线性过采样；
- 不允许通过降低 NSIDE 换取性能。

输入尺度不能只读取单一 CDELT。必须使用最终 WCS/SIP 在视场中心、边缘、角点及必要网格上的局部 Jacobian 评估。

## 2. 精度

| 对象 | 精度 |
|---|---|
| 输入校准图像 | float32 |
| WCS/SIP 计算 | float64 |
| 球面坐标 | float64 |
| 像素边界 | float64 |
| 球面交叠/面积 | float64 |
| signal 累积 | float64 |
| support 累积 | float64 |
| 归一化 | float64 |
| HISS signal | float32 |
| HISS support | 待确认 |

## 3. 数学正确性

Drizzle 必须：

- 使用完整 WCS/SIP；
- 正确映射源像素 footprint；
- 正确处理 pixfrac；
- 使用高精度球面几何；
- 保持已冻结的光度/能量语义；
- 累积 support（sumWeight），是否持久化待确认；
- 不将无覆盖区域写成零信号。

## 4. 禁止的性能捷径

正式输出禁止：

- 仅投影源像素中心；
- 最近邻替代面积投影；
- 用低阶 WCS 替代 SIP；
- 在明显影响精度时使用平面近似；
- 降低 NSIDE；
- 跳过小面积贡献；
- 低精度查表；
- float32 几何累积；
- 有损近似；
- 以“目视差不多”作为正确性依据。

性能优化只能改变执行方式，不能改变数学定义。

## 5. 允许的后续优化

功能冻结后允许研究：

- 批量 WCS/SIP；
- 多项式公共项复用；
- SIMD；
- Tile 级并行；
- thread-local 累积；
- 固定顺序归并；
- 内存池；
- 减少动态分配；
- 计算与压缩流水；
- 缓存不变参数。

当前阶段不实施这些优化。

## 6. Reference 与生产实现

必须保留可作为真值的 Reference 路径或 Reference 测试程序：

- float64 几何；
- float64 累积；
- 实现简单；
- 用于比对生产实现。

生产实现提交前必须比较：

- `ipix` 集合；
- signal；
- support；
- 总通量或等价守恒量；
- 质心；
- 边缘覆盖；
- 不同线程数；
- 重复运行。

优化不能以牺牲几何或光度精度换速度。
