# 10 Stage 2 真实数据验收

## 1. 入口条件

- 输入 HISS 全部由已通过的 Stage1 版本产生；
- HISS 兼容性检查完备；
- healpix_stack 源码与构建可追溯；
- 叠加算法有合成小样本单元测试。

## 2. 流程验证

1. 读取并验证全部 HISS；
2. 构建重叠图并报告连通分量；
3. 对不连通组明确拆分或失败，不得伪造统一梯度；
4. 球面梯度解有参考锚点、残差和条件数/稳定性诊断；
5. 每像素/分块先梯度修正，再稳健剔除，再 SNR² 加权；
6. 输出 HCSD 采用临时文件和重新读取验证。

## 3. 科学检查

- 重叠区接缝在校正后下降；
- 高 SNR 样本权重更高，缺 SNR 不得静默等权；
- 注入卫星线/热像素/异常帧时能被剔除；
- 单样本区域保持原值并标记覆盖数；
- 不同滤光片、nside、ordering、测光坐标系不能混合。

## 4. 输出检查

HCSD 的索引、offset、length、ipix 排序、有限值、metadata、输入清单与 hash 全部一致。浏览器读取只作为附加验证，不能替代格式级检查。
