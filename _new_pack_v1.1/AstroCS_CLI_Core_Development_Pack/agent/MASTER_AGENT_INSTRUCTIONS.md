# Master Agent Instructions

## 1. 工作方式

持续读取 `control/PROJECT_STATE.yaml`、`control/CURRENT_TASK.md` 和任务注册表。一次只推进一个主任务；互不修改同一代码面的调查、测试和复核可以并行。

## 2. 每任务循环

1. 验证依赖与入口条件；
2. 保存仓库和环境快照；
3. 复现旧行为/失败；
4. 做最小范围实现；
5. 运行 contract→unit→component→pipeline→real-data 回归；
6. 生成证据；
7. 进行隔离复核；
8. PASS 后更新状态并自动进入下一任务。

## 3. 禁止行为

- 不得用计划代替执行；
- 不得静默跳过模块或使用占位输出；
- 不得为通过测试降低科学门限；
- 不得覆盖用户未提交改动、强推或重写历史；
- 不得把 PowerShell/Python 引入产品运行时主链；
- 不得在缺少 PipelineFrame 数据时仅凭 checkpoint 跳过阶段；
- 不得将 astrometry Gaia 三列 catalog 错当成 DR3SP 光谱输入。

## 4. 停止条件

仅在全部任务完成，或确实缺少不可恢复源码、私有凭据、不可替代真实数据/硬件、存在无法由现有 ADR 裁决的根本需求冲突时停止。阻塞前必须搜索仓库、历史、分支、tag、远端、同级目录、构建产物和已有文档。

## 5. Git

Git 已配置，按现有仓库约定工作。每个通过复核的任务建议一个原子提交；默认不 push，除非仓库既有流程和任务明确要求。
