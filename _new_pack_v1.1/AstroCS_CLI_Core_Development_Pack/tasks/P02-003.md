# P02-003 PlateSolve 全量 A/B 与路径决策

- 阶段：P02
- 依赖：P02-002;P00-003
- Gate：G2

## 目标

对冻结的全部 TestData 比较原路径与共享 detections 候选路径，并按硬规则选择生产数据路径。

## 执行步骤

1. 逐例运行全部 TestData，不能只跑 canonical 子集。
2. 任何旧成功案例失败或质量超门限退化时，决策为 `PRESERVE_INTERNAL_DETECTION_EXPORT`。
3. 只有全部案例通过时，决策为 `UPSTREAM_SHARED_DETECTIONS`。
4. 生成 `PLATESOLVE_PATH_DECISION.md` 并更新 ADR；不得为了选择路径 A 放宽门限。

## 必需交付物

- 代码/文档差异与原子提交建议；
- 自动化测试和真实数据证据；
- 兼容性、回滚和残留风险；
- `evidence/P02-003/` 下四份标准报告。

## 验收

- 依赖任务均已通过；
- 本任务目标有可复现证据；
- 相关回归全部运行；
- 独立复核以 `VERDICT: PASS` 结束；
- 更新任务注册表、当前任务和项目状态。

## 通用执行规则

- 开始前记录 commit、工作树和入口条件。
- 先复现旧行为，再做最小修改。
- 外部进程、数据库和可能阻塞操作设置明确超时。
- 不覆盖用户未提交修改，不强推或重写历史。
- 所有接口/格式变更同步更新契约和测试。
- 产出 TASK_REPORT、TEST_REPORT、EVIDENCE_INDEX、REVIEW_REPORT。
