# P08-001 CLI Core v1 发布包

- 阶段：P08
- 依赖：P07-002;P04-003
- Gate：G8

## 目标

生成自包含运行包、版本清单、hash、默认配置与验证命令。

## 执行步骤

1. 发布包不得依赖用户安装 Python/PowerShell。
2. 从干净目录验证 capabilities、smoke、inspect。
3. 生成版本与 SHA-256 清单。

## 必需交付物

- 代码/文档差异与原子提交建议；
- 自动化测试和真实数据证据；
- 兼容性、回滚和残留风险；
- `evidence/P08-001/` 下四份标准报告。

## 验收

- 依赖任务均已通过；
- 本任务目标有可复现证据；
- 相关回归全部运行；
- 独立复核以 `VERDICT: PASS` 结束；
- 更新任务注册表、当前任务和项目状态。

## 通用执行规则

- 开始前记录 commit、工作树和入口条件。
- 先复现旧行为，再做最小修改。
- 外部进程、数据库和可能阻塞操作设置明确超时。
- 不覆盖用户未提交修改，不强推或重写历史。
- 所有接口/格式变更同步更新契约和测试。
- 产出 TASK_REPORT、TEST_REPORT、EVIDENCE_INDEX、REVIEW_REPORT。
