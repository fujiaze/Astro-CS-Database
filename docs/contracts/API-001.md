## 2. 错误模型

### 2.1 CLI 退出码（`lib/infrastructure/cli/exit_codes.h` 唯一源，冻结）

| 码 | 含义 |
|---|---|
| 0 | 成功，且所有请求门禁通过 |
| 2 | CLI 参数或配置错误 |
| 3 | 输入缺失、格式或 hash 错误 |
| 4 | 科学验证/数值不变量失败 |
| 5 | backend ABI/签名/CPU 特征/加载失败 |
| 6 | 计算执行失败 |
| 7 | I/O 失败 |
| 8 | 输出完整性/验证失败 |
| 9 | 用户取消或超时 |
| 10 | **磁盘写满 / 写盘失败**（`ASTROCS_DESIGN.md` §6.3：**一般性资源超限门已取消**——内存 / CPU / 线程**不设门**；原「资源利用率或内存增长门禁失败」措辞已作废） |
| 70 | 未分类内部错误（必须生成 crash report） |

### 2.2 Error domains（CORE-001 目标，错误码稳定）

- `CONFIG / DATA / SCIENCE_PRECONDITION / IO / RESOURCE / BACKEND / CANCELLED / INTERNAL`。
- 模块不得调用 `exit/abort`；异常只在内部转 `Result`，不能穿过 C ABI。
- `Result<T>` 支持 nested cause、serialization、cancel、错误码映射。

### 2.3 C ABI 规则

- 结构带 `size`/`version`；禁止跨 DLL 传 STL/异常/allocator 所有权。
- 固定宽度类型；显式 size/version 校验；坏 provider 拒绝且优雅 fallback。

## 3. 机器输出

- `--json` 输出 schema 固定；日志不得污染 stdout JSON。
- **运行事件流（唯一 schema，DOC-203 / Q6 前置裁决）**：实现正本 = `lib/infrastructure/cli/protocol.h`（`ValidateEventV1`，发送侧硬闸）+ `lib/infrastructure/cli/jsonl.h`（`JsonlEmitter`）；人类可读合同 = `docs/api/CLI_PROTOCOL_V1.md` §4；机器 schema = `contracts/schemas/jsonl_event_v1.schema.json`（**派生件**，字段/枚举/顺序键以 `protocol.h` + `jsonl.h` 为准）。必含字段 = `schema_version/event_id/run_id/timestamp_utc/sequence/kind/severity/phase/stage/message`，事件枚举键名 = **`kind`**（progress/resource/artifact/backend/final/stage_start/stage_end）。
- **原文留痕（已作废）**：`run/node/artifact/time/sequence/severity/type/metrics`（CORE-008）是**另一套字段名**，与唯一 schema 相反 ⇒ **不得**据此实现或验收（"不得两边并存"）。
- **不得与结构化日志混用**：`docs/architecture/observability/STRUCTURED_LOGGING_CONTRACT.md`（LOG-001，`astrocs.log.event.v1`）是**结构化日志**合同（人可读摘要 + 机器 JSONL 双通道同源），**不是**运行事件流；其事件键名 `event` 与运行事件流的 `kind` **不得混用**，两份流各用不同工件名。

## 4. 生命周期/线程安全/可重入/取消

- RunContext 只在节点执行期间有效；模块不得保留 context 到 execute 返回后。
- 公共对象 thread-safety 在 header 注释声明；所有权（borrow/shared/unique/persisted）
  按 DATA-001。
- 取消经 CancellationToken 传播；checkpoint 只在 Artifact 原子提交后写入。
