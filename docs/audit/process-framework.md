## 本轮交付

SYSTEM唯一拥有Host/registry、typed边界、生命周期、资源/线程/Storage/诊断与装配规则。22份process文档分别拥有算法、输入输出、工作单元/并行与误差/观测/反例，另有目录/模板。此前SYSTEM的科学细则和API逐算法表已移到所属模块；共用数值原语、命令编排及初始probe目录各有独立标准。六个根工程文件保留供现有工具导航，不再把所有科学算法塞进骨架。

删去上一轮新增的双reader、旧hash保持和显式产品迁移要求。当前格式校验、内容身份、同次运行的版本/租约/原子发布仍必需；它们不是历史兼容。保留Git提交和科学原始证据，不回滚远端已有实现。

只修改Markdown，未修改实现、头声明、schema、构建或测试数据。现有实现并未因文档修改自动变成标准process；后续按Host/registry→共用服务→逐模块CPU接入→工作流与独立验收落实。没有GPU后端、SDK或性能实跑声明。
