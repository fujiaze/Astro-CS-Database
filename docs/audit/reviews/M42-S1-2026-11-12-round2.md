## 14. 结论

Round-1 的主要科学修复是真实的：sky 加性拟合不再把乘性标度扣成天光（β 与暗天叶差同号
同量级、改正后帧差纯乘性）；饱和样本确实从 drizzle 剔除；absent 叶 NaN/零面积；溯源
从“算法名哈希/空 inputs”升级为真实 git 修订与两端可核对的 manifest 哈希。这些必须记功。

但 S1 仍 **FAIL**：mosaic 闭包仍不可重开（无 SkyFit/WeightSolution/区间/effective_response），
且 mosaic 仍以等权方式平均三帧，而三帧之间存在 15–23% 未应用的相对标度（叶口径
1.1506/0.9416、星口径 1.2264/0.9604）；产品把它具名了，但没有修正，也没有把可识别的
相对系数乘进 coadd。加上本轮新查出的“5 个全饱和叶从叶索引消失、NaN 被错误归因”和
单位/测光/资源/镜像的 PARTIAL，S1 不具备 `PASS` 条件，不得创建 S2 Issue。整改按 §12
顺序执行后，用同一批真实 4096² 输入重跑一次并重新冻结点，再进行第三轮独立复核。
