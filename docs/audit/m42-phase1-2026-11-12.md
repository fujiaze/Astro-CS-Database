## 3. 真实科学指标

### 3.1 天测（独立于生产 solver）

用 Gaia DR3 位置 + 头部 WCS 作初值、TAN+SIP(3)、40% 留出：

| 帧 | 入帧/1772 | 匹配 | 拟合 RMS | 留出 RMS | 留出中位 | >0.5 px 离群 |
|---|---|---|---|---|---|---|
| 20251212 | 1171 | 762 | 0.130 px = 0.125″ | 0.318 px = **0.307″** | 0.081 px | 8.0% |
| 20251224 | 1176 | 784 | 0.150 px | 0.338 px = **0.327″** | 0.084 px | 6.9% |
| 20251228 | 1172 | 699 | 0.150 px | 0.408 px = **0.394″** | 0.098 px | 9.0% |

- 头部 PinPoint WCS 拟合前中位偏 **5.2–5.7″**、四角 **23–27″**（缺 TR 畸变），不可直接作为 supplied_wcs。
- 三帧互检中位 0.087–0.096″，稳健 RMS 0.057–0.062″。
- 独立 C++ `tan_sip.cpp` 四角对拍 ≤5.1×10⁻¹¹″；astropy 四角 ≤1.6×10⁻¹⁰″；逆闭合 ≤3.9×10⁻⁷ px。
- 历史 #92 的 `0/2309` 根因是旧 `wcs_transform.cpp` 的 1e-7 px 残差门误杀一次式 AP/BP 逆，与本轮 Gaia 星表/WCS 无关；本分支已无该文件。本轮入帧 1171–1176、匹配 699–784，未重现 0。
- 证据：`run/m42-s1/inputs/gaia/fit_*.json`、`wcs_*.json`、`residuals_*.csv`、`run/m42-s1/review/astrometry/verify_*.json`。

### 3.2 独立孔径测光（低背景天区，非核心）

- 天区：frame1 像素 `(3392,576)` 起 128×128，5 颗 Gaia 星，背景中位 raw 1255 ADU。
- 同一天区在 frame2 的对应 sky 窗口 `(581,3385)` 起 128×128。
- 孔径 r=6 px，环 10–16 px，MAD 局部噪声；结果（ADU，定标后）：
  - frame1：flux 4.18e5 / 6.69e4 / 2.41e4 / 3.21e4；SNR 1641 / 293 / 110 / 165。
  - frame2：flux 5.31e5 / 8.79e4 / 2.93e4 / 4.11e4；SNR 1630 / 327 / 114 / 196。
- 4 颗共同星 `frame2/frame1` 通量比：1.283、1.214、1.270、1.312；中位 **1.2766**，星间 scatter ~4%。
- 解释：两夜之间存在 **~28% 相对测光零点差**（大气透过率/主平场/光路差），不是随机噪声；在正式 mosaic 前必须用同响应公共天光/测光标度处理。当前产品未施加该标度。
- 证据：`run/m42-s1/review/science/lowbg_photometry.json`。

### 3.3 噪声/SNR 与协方差

- 增益（GAIN）、读出噪声、SATURATE 关键字在 196/196 个 light 头中缺失；因此**物理电子噪声不可知**，不能把 Fisher/孔径 IVAR 冒充 scene variance。
- 独立孔径 SNR 来自局部 MAD（ADU），只代表该星在该窗口的经验信噪比，不是全产品协方差。
- 生产 Normalize/Mosaic 的 `noise=unknown`、`science=conditional`；`uncertainty.covariance` 在 unknown 状态拒绝 apply（与 D1 修复一致）。
- 未产出已知协方差；不得声称 SNR 已完整认证。

### 3.4 天光/接缝

- 2 帧 256² 核心区域的整幅差中位 −4325 ADU、MAD 5.7e3 ADU；该天区 32.8% 像素饱和且星云梯度极强，整幅差主要反映指向/梯度/饱和，不是可分离的接缝。
- 低背景 128² 窗口的星间通量比 scatter ~4%，说明相对平坦性尚可，但零点差 28% 是主导系统项。
- 没有完成“有向接缝图/连通分量/gauge/协方差”的正式裁决；正式 mosaic 未产出，不能报告 ΔB 或零接缝。

## 4. 本轮真正修复的生产缺陷

| 缺陷 | 修复 | 证据 |
|---|---|---|
| workflow 命令 scope 硬编码 1 GiB / 4e9 work，真实 4096/256 帧在第一个 process 前 `resource_exhausted` | `normalize`/`open_workflow_runtime` 从进程 Limits 继承（`rt::process_limits`） | 修复前 calibration 2.25 GB 被拒；修复后 calibrate/psf/measure/geometry 逐级通过 |
| PSF 联合拟合 work 估计只算 1 个 template/iteration，真实数据在第一次迭代耗尽 | `fit_work` 计入 4·S+128 个 template、backtracking/damping 与 2× 安全因子 | 256² 真实帧 fit_psf 由 `resource_exhausted` 变为 `ok` |
| PSF/measure 把所有 catalogue 星一起拟合，真实星云场不可控 | 仅取入帧、最亮、窗口互不重叠的 ≤4 颗星；PSF ≤4 | `src/workflows/normalize.cpp`、`src/sources/measure.cpp`（邻域阈值 2·window） |
| 原始 FITS 无 DQ，饱和核心被当作数据，测光出现负通量/1e6 ADU | CLI 读入时按 ADC 满量程 65535 标记 `kDqSaturated` | 饱和核心被 measure 跳过；真实星位由 WCS 投到 65535 峰 |

| CLI mosaic 不解析 explicit `sky.groups`/`gauge`，不同 PSF 身份的真实帧无法声明比较组 | 解析 groups/gauge；显式 response/kernel proof + conditional assumption | `apps/cli/commands.cpp`；2 帧 mosaic 配置已生成 |
| CLI 输出 stdout 协议/阶段不可见 | Normalize trace 每步 flush，并加 measure 起点 | `ACSD_NORMALIZE_TRACE` 实际定位到每次阻塞 |

## 5. 关键未闭合缺陷（本轮发现，未修）

1. **信号发布不一致（P0）**：exit 0 的 Normalize 产品 `signal` shape [122]、`support.index.size=122`，HiPS 信号 tiles 全 NaN；真实 256²/order-13 视场应有远大于 122 的叶/信号。必须修 `build_drizzle`→`SignalEstimate`→`publish` 的长度/内容一致性检查，并让 exit 0 在产品内容不自洽时失败。
2. **Mosaic 内存（P0）**：256² 单帧/双帧 mosaic 即达 11.6–12.6 GiB，超出本轮 12 GiB 账本/17 GiB 主机；需要流式/分块 mosaic 或降低产品规模，不能用降 tolerance 掩盖。
3. **Export 产品闭包（P0）**：`LinearAction:2e9d3aa4…` 被引用但未存，Export 以 `corrupt_product` 失败；需要动作子对象/数组的完整闭包测试。
4. **测光模型（P1）**：单窗口常数背景在 M42 亮星云导致 joint photometry `nonconverged`；应使用局部平面/二次背景或把星云梯度作为共同模型，不能用“图变光滑”代替。
5. **绝对定标未知（P1）**：GAIN/READNOISE/QE/滤镜实测曲线缺失；响应是参数化 3 nm top-hat，绝对通量与电子噪声保持 unknown。
6. **校准主帧时效/光路差（P1）**：master 比 light 老 1.5–4 个月，FOCALLEN 1877 vs 1917.6（+2.2%）；两夜 28% 零点差与此/大气有关，未校正。
