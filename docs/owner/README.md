# owner

本目录是面向负责人的 L0 汇总层：以一页篇幅复述架构、流程、科学与发布状态，并给出目标态设计细节的总入口。

## 职责边界

- 放：跨域汇总与总入口导航（架构总览、流程总览、科学总览、发布状态、项目细节规范）。
- 不放：各域的详细条款（在 docs/design/、docs/science/、docs/architecture/ 等）；合同正文（在 docs/contracts/）；验收标准（在 ACCEPTANCE_SPEC.md）。

## 内容

- `PROJECT_SPEC.md` —— 最高设计之下的目标态设计细节总入口，规定权威体系与文档分工。
- `ARCHITECTURE_OVERVIEW.md` —— 架构汇总层，给出架构文档的权威来源与状态词约定。
- `PIPELINE_OVERVIEW.md` —— 流程汇总层：三个命令与阶段间磁盘产品交换。
- `SCIENCE_OVERVIEW.md` —— 科学汇总层：核心科学方法各创新点的顶层复述。
- `RELEASE_STATUS.md` —— 发布状态汇总层，登记状态阶梯与状态词口径。
