# D0｜独立科学审查与证伪：从命题出发，不以 CI/测试数量代替推理

## 目的与独立性

ACSD 的每个科学结论由多个不同性质的证据支持，**不存在一个“所有测试都绿”的自动程序可以证明整个产品在真实天空中正确**。本任务建立严谨但不繁琐的科学与工程审查方法：由没有参与该实现的审查者优先读原始论文、五份 Foundation 与 Process 合同，自行重推命题，寻找反例，再看源码与实际观测。CI不使用；编译器、脚本、精确计算和测试只是在有明确科学问题时调用的实验手段。**不得让测试程序替代数学推导或让作者亲自运行的脚本作为唯一科学裁决**。

## 一、四种不同的证明对象，绝不可互相顶替

| 对象 | 可用严格证明或证据 | 合法结论 | 绝对不可声称 |
|---|---|---|---|
| 数学模型、代数性质 | 假设、完整推导、原论文定理/自证明、反例 | 在假设成立时命题成立 | 所有真实仪器都满足假设 |
| 数值算法与具体C++实现 | 算法不变量、向外舍入、终止与误差界、逐源代码推理、解析/高精度对照 | 在可认证数值域内包含真值/满足指定误差 | 有限随机样本足以证明所有输入 |
| 随机估计与统计选择 | 指定概率模型下解析方差、恰当Monte Carlo与二项置信区间、model misspecification实验 | 指定分布和选择条件下的bias/coverage/误拒约束 | 固定mask条件方差自动等于选择后coverage |
| 真实天文测量适用性 | 真实独立曝光、校准、HST/地面图像、外部仪器资料及科学对照 | 某仪器/时段/通带/天空结构具有观察支持 | 人类可以知道未观测高频真实天空或所有未知系统误差 |

对每个结论记录：所依赖的**数学前提、证据和反例**，没有获得的能力是什么，是否是确定性下界/统计区间/经验观察/外部假设。科学严谨不等于要求不可能的“宇宙真值全知”：不可辨识时应给出限制或合理失败。

## 二、从文档正向推导到源码的逐条审查程序

1. **问题冻结**：选择一个可陈述的科学命题，例如“给定已知C，输出面亮度方差是RCRᵀ指定泛函”，而不是“noise 模块能跑”。记录已知输入和拟被估计量、单位、数学域以及准许的失败状态。
2. **一手来源核对**：独立审核者从 DOI、标准、原论文页/公式和仓库原创研究手稿导出要验证的结果。对来源“论文没有覆盖但本项目借用了说法”的情况必须要求完整新增推导，不能任意外推。
3. **规范重推**：不看当前生产C++，从 Foundation 推出这条命题要使用的处理顺序、关键算子和误差传播；写出两三个能够推翻常见错误方法的反例，列出每一步前置条件与下游保证。
4. **代码符合性审查**：查看调用栈和关键实现，逐次回答“哪里实现了这个数学步骤、哪里检验输入前提、如何保存不确定度、什么时候终止、异常条件如何传播”；对于区间/迭代/候选算法检查真实循环不变量和内存/算术语义，不能停在函数名/设计注释。
5. **独立复现对照**：必要时用解析公式、精确有理数、MPFR、外部标准库或数学结构不同的参考算法造小尺寸Oracle；必须说明“独立”体现在哪些运算没有复用生产helper。测试记录原始输入/种子、算法/依赖身份、实际结果与此前预定比较命题。
6. **边界反证与错误模型**：不止正例，必须考虑域外、退化、数值非包含、未知量、预算不足、故障/取消、非法物理条件及混合未满足假设的输入。负例的预期结果可能是正确拒绝，而非输出数值。
7. **沿主链传播**：检查这一模块的条件结果进入下游时是否仍满足consumer的前置条件；重新访问共享随机根、相同 R、SkyFit、Selection/WeightSolution、GeometryRevision、持久化，防止因本地正确产生全链错误。
8. **挑战与裁决**：审查者明确写出尚能挑战的结论及反例，作者修订源码或科学假设，然后**另一个人重新独立验证变更**；原失败保留，不能在原报告中覆盖为通过。

## 三、实际实验的独立真值规则

- **解析精确型**：Gaussian erf像元积分、2x2有理矩阵、TAN简单面积、固定Rank、BLUE已知权；结果由外部纸面或独立库求得。目标是证伪错误代数或坐标实现。
- **确定性包围型**：MPFR/GMP/区间几何的上下界；一定保证真值在其中才允许CERTIFIED。两个求解器区间相交只是必要条件，不是充分证明；需要从原始定义审查各自包含算法。
- **随机置信型**：Poisson/read/shared latent，完整前向拟合到最终Export；给明示seed、假设、试验次数、覆盖比例及二项置信区间。Monte Carlo不产生确定的区间包含认证。
- **经验物理型**：真实HST和地面望远镜、重复曝光、同通带/异响应、真实大气/光学数据；需报告已知/未知物理参数、校准样本与保留样本、模型域以及无法解释的偏差。
- **实现/故障型**：资源额度、指针寿命、线程、I/O短写、终止、新进程恢复与外部读取；其“通过”只证明给定工程事实，不提升数学真值级别。

原始真值应从独立真实天空前向定义生成原始像元，而不是读取生产`R`/`PSF`/`SkyFit`后据此构造所谓truth。没有用户真实FITS时应完成全部能独立构造的数学/合成/工程论证，不能把科学理论问题都推迟到“以后实测”。

## 四、主线的必需命题和裁决

| 审核主题 | 必须由推导判断 | 判别性错误样例 |
|---|---|---|
| 坐标绝对准确 | PixelCenter0/FITS1/WCS/SIP与Gaia实际天球关系 | 同时+1的正逆仍roundtrip良好 |
| 真HPX面积 | 连续WCS下真实叶候选与包含性 | 四角/外部cone漏极细叶但总面积守恒 |
| PSF/测光 | 真实像元积分与有限窗/位置/背景联立 | 中心采样和错误背景列产生稳定系统偏差 |
| 光谱标度 | 已知响应可估、未知gain/SED不可辨识 | XP低分辨窄带线谱被宣称精确 |
| 随机与数值误差 | 同一root与算子的协方差、独立确定数值半径 | 将geometry bound加作Poisson variance |
| 天光与低频结构 | 相对差模、gauge、同数据P与可比较H | 真实星云坡度被错误当背景消掉 |
| Coadd选择和权 | BLUE/PSD/QP及统计前提 | N5平移不等变、shared floor无穷缩小 |
| Export | 真支持面积、Q/Cov同算子与外部WCS | partial用全像元分母、leaf拆分后假独立 |
| 产品恢复 | 科学对象闭包可从独立进程重建 | 新进程丢noise root或旧revision配方 |
| 资源与取消 | 不变量、所有权、死锁与原子发布 | 内存budget突破后仍显示成功 |

## 五、原始研究 R1–R5 的独立重审

按 [R1–R5 任务](../science/03-R1-R5-RESEARCH-EXPERIMENTS.md) 链接真正历史`main@adc7f33d`的`oracles/`和`evidence/`。分别核对：
- R1：100源模型/共享星谱条件与线宽/未知gain；
- R2：真曲边、极细正面积、有向C++几何微原型、漏叶/失败报告；
- R3：共享噪声、Fisher与scene差异、PSD约束、稀疏C∞ bump；
- R4：真实共同坡度保留、同数据Sky交叉协方差；
- R5：多点同时LOO造成错误coverage、单步最大LOO的限定结果、异通带有效核。
每个方向必须重新给出“文献先前成果 vs ACSD真正新增命题”比较。项目内的“独立审核”不是对原创性本身的外部学界审稿；原创性未知时不应包装为已被同行认可。

## 六、独立审查者签核报告最少内容（人读，不是模板解析器）

- 被审核SHA/实际文件/数学公式、研究原始输入hash、论文DOI+页/式号；
- 被验证的命题/真实输入前提、估计量/物理单位、证明方式与证明范围；
- 源码是否真的满足算法步骤、所有真实分支与正确失败；
- 至少一个自己构造的强判别性反例，实际结果，保留旧失败；
- 依赖哪些先前已认证数值性质、哪些是假设或不可辨识；
- 产品终值与中间值如何保持同一语义；
- 审核者没有亲自执行的实验逐条写“依赖他人记录”，不能冒称独立重跑；
- 尚未解决的具体阻碍、严重程度和最小纠正方案；
- 担任审核者的人不得同时作为自己所审内容的唯一实现者和最终批准者。

**决议不能只是PASS**：按科学设计、数学算法、生产代码、给定数值域、真实物理适用性、工程资源/跨平台、最终产品独立表达。此任务完成时应能从最终FITS具体一个像元反向追到输入采样、当前R/PSF/response、shared root、sky、weight、Q、论文/自研论证与程序路径，并准确说明哪里证据仍然是条件性的。
