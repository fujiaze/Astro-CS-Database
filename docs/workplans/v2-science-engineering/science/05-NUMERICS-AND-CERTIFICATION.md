# B1｜共享数值正确性、确定包含与科学证书的源代码重构

## 优先级

此任务是 SCIENCE_CERTIFIED 的硬前提，不是“某些单元测试失败”。`src/numerics/interval.cpp` 与 `linalg.cpp` 的当前源码仍有已知 P0/P1，见 `docs/audit/IMPLEMENTATION-STATUS.md` N-01..N-06。任何上游包含性已使用这些原语，则上游不得在其未经修复/核对时出具严格 certified。用户允许近似数值计算，但要诚实以 conditional/uncertified 表达，不把 nominal值标为确定包围。

## N1：区间原语逐式推导与实现

- 先定义闭实数集解释：输入 binary64精确二进制有理；字符串十进制需有外包解析；非法域/NaN/∞/空交的行为写清。数学正确性首先是所有真值被端点包含。
- **四则**：检查每个运算的真实舍入位置。当前 `down(a+b)` 的加法先在默认环境求值再更改 fenv，不能实现方向舍入；采用 MPFR/GMP有向原语或可证明/受控的编译环境表达式内运算，明确线程/编译器/浮点优化影响。以精确 Fraction 产生抵消、次正规、溢出、±0、巨大数值尺度反例。
- **sin/cos**：不能仅枚举 `k=-8..8`；证明极值相位是否落入任意区间，宽度≥2π直接粗包，未知相位判为粗界。以 `[1000,1002]` 等高相位、负角、极端大幅值验证。
- **pow**：一般正底 `[2,3]^[2,3]` 必须包住 `[4,27]`；区分过零、负底、整数与非整数幂的定义域；不能只用交叉的两个端点。
- **atan2**：处理原点、坐标轴、负实轴切线与角值主支，特别 `x∈[-2,-1], y∈[-1,1]`；四角采样不够。非法或无法单一区间表达的分支明确使用粗闭包/拒绝。
- **复杂超越**：exp/log/sqrt/erf/Bessel/积分以各自可认证库函数+区间范围算法证明，不因 `interval_primitive_status` 全局返回OK便认证所有数学函数。记录每个依赖原语的算术/域有效性。
- 对区间累加和取交/上下界序列化检查向外舍入；既有失败如半宽1ulp、FITS精度截断必须保留为反例。

## N2：矩阵分解、秩与优化证书

- 从 QR/SVD/eigen/PSD Cholesky 的数学原理推出实际残差界，分别界定 `||A-UΣVᵀ||`、`||UᵀU-I||`、输入矩阵区间半径、谱误差及 rank 阈值。所有界向外求；点精度 residual 不能只改字段名为 certified。
- 识别可估空间、真实结构零空间、数值近零模式和不可辨识方向；对 `rank_unresolved` 只允许升级精度或条件结果；禁止用 ridge 修改科学估计量来强行唯一。
- 共享线性 solve：白化 SPD/PSD、精确约束/KKT、稀疏 QR/LSMR/迭代停止；给出真实算子残差 `||Dᵀr||` 与目标科学泛函的误差界，不以迭代次数/exit0代替。
- 非线性 PSF/photometry：真实 pixel-integrated 模型的 Jacobian/Hessian 逐偏导核对，GN/Armijo/驻点/精度耗尽、边界与尾界；本分支历史曾发生PSF Jacobian 缺源flux、拟合模板退化。修复必须以函数差分+独立解析导数复算为证。
- 对 geometry→sky→weights 的矩阵扰动给出 `ρ<1` 充分条件与终值误差半径；分支改变/矩阵近奇异不能用固定名义解代替包含所有合法情况。

## N3：代码修订次序与证明闭环

1. 先以纸面/独立数学语言完成原语定理和失效域；列出一个具体错误旧代码反例，冻结期望，不允许代码拥有者倒改期望。
2. 只在 `src/numerics` 提供唯一原语实现，不引入模块局部 `almost_equal` 假证书，不散布不同的区间库。
3. 对代码完成静态正确性检查：表达式真实舍入、编译优化约束、库版本/调用分支、异常域、大小/溢出、C++对象所有权；说明“为何实现满足定理”。
4. 运行有限的独立精确小例和恶意反例，并拿已存档的真正失败作为反证；每类原语另有单独不能证明的域。
5. 返回上游逐项复核 WCS/overlap/Drizzle/PSF/measure/photo/sky/BLUE/Export 的证书路径；被修改的源身份造成下游证书失效时重算，不能继续复用旧缓存。
