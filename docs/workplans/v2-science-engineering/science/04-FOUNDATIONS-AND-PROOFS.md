# B0｜五份科学基础从物理模型到工程可实现的正向推导

## 文件归属

只在现有 `docs/science/foundation/` 五篇正本修订科学内容：`OBSERVATION_COORDINATES`、`GAIA_RESPONSE`、`SPHERICAL_DRIZZLE`、`STATISTICS_SKY_COADD`、`INDEPENDENT_ORACLES`。每篇只拥有自身数学定义；来源映射归 [02](02-LITERATURE-AND-PROVENANCE.md)，22个Process只说明使用与具体实现，不建立第三套同名定理。审查旧增补式段落中的相互冲突，合并为一个有效当前陈述，引用冻结旧报告以留历史。

## 必须正向推出的主线

1. **世界中的量**：真天空 `I_λ(ω,t)`、星 `f_{s,λ}`、源结构/不同 epoch、天光中已经计入 I 的部分；描述时空/波长依赖的光学、大气、响应 `T QE`、PSF/PRF，连续曝光到电子期望 `μ_{ki}`。对 gain、收光面积、光谱/仪器参数明确哪些能辨识，哪些只有乘积。
2. **真实观测**：电子计数 Poisson(μ) 与读噪/校准母版/IPC/非线性/饱和；原始 ADU 与校准 `x` 的单位、响应、dq和 shared root。明确扣掉 sky均值后其光子方差仍在；unknown不是零。
3. **坐标**：PixelCenter0/Edge0→FITS1一次变换，图像 `[y,x]`，ICRS/TAN[-SIP]、CD/PC、LONPOLE、极点、RA wrap、翻转/bin/Bayer/ROI；证明变换的复合顺序和逆问题的支持域；圆形/矩形 footprint 必须是收光定义而非采样步长猜测。
4. **点源/响应**：像元 PSF 积分 (不是中心采样)、有限窗尾，响应 photon 积分和 XP 有限分辨率；联合 Gaia latent photometry 的 likelihood、秩/参数协方差/空间应用 `α(u)`，不同 filter/PSF下的不可比较目标。
5. **几何**：`Ω_j,A_j,a_jp`、真叶成员、`w=a/A`、`F/N/R`、无支持/弱支持，面积包围与最终 `B` 界；证明同一 R 对所有线性载体的作用及哪些变换不交换。
6. **统计/sky/coadd**：区分 `V_F`、`V_B` 和 `V_ctrl`；共同 `H` 与相对加性差模、gauge，`P=I-EKT` 和同数据交叉项，Γ/BLUE/PSD/QP，选择后的条件分布及有效 `K_eff`。
7. **导出**：实际 leaf/目标像元交叠 `Q`、支持均值/支持积分、NaN无支持、合法负信号与零信号；HiPS层级不是独立曝光；输出不是自动恢复未知宇宙真场。

## 每个数学命题的标准正文写法

**符号、物理假设、具体可观察对象 → 提出命题 → 给出逐行推导或引用已逐式核对的原始定理 → 定义算法能够实现的有限域 → 明确边界/不可辨识反例 → 计算复杂度/数值可达条件 → 和下一数据边的前后条件**。随机统计区间、数值确定包围、物理系统偏差分列。不能先根据当前代码运行结果“反推”应有的公式。

### 必需非交换性推导
- 空间 `D_α` 与 WCS/PSF卷积/重组G一般不交换；`R D_α≠D_α R`；说明何时可简化为常数 α。
- 同一数据拟合 Sky 的 `P` 与先简单相加拟合参数协方差不等价；证明相关交叉项。
- 在相同响应、相同 PSF/物理目标和固定 mask 时才能称传统 coadd 的同均值 BLUE；不同响应的信号是定义了的混合，而非强制同一单色天空。
- `Q R` 在合法条件下保持线性，但改变 GeometryRevision、支持/权/sky 时不能以旧 `Q` 或旧参数“等价复用”。

## 不可推断边界（必须有明确反例）

1. 高 SNR 单星可定标 ≠ 认识物理gain和未知星云的窄线SED。
2. WCS 正逆 round-trip ~0 ≠ 与 ICRS/外部像素原点一致。
3. 常数场守恒/面积总和守恒 ≠ 每片真正 HEALPix 叶的成员正确。
4. `R C Rᵀ` 可精确算 ≠ 未给定完整 C 时已知真实观测方差。
5. rank 数值阈值下的近零模态 ≠ 已经证明精确物理零空间。
6. Sky 残差变小 ≠ 保留真星云/暗云；选择后的固定权公式 ≠ 无条件统计 coverage。
7. HST 合成图作为退化源 ≠ 无PSF、无噪声的宇宙真值。

## 出口

独立科学审查者仅拿五份 Foundation、原文和一组未见的新构型，自行重构 Normalize→Mosaic→Export 的数学估计量与四种误差/未知语义；写出至少一个能使旧模型失败的新反例。只有完成正向推导并说明每个前提在实际输入中如何识别，才授权相应 Process 的科学实现升级。
