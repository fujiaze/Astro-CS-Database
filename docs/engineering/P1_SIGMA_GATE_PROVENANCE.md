## 0 结论（先行）

1. **口径自洽**：σ_obs 0.026520 与 σ_ceiling 0.020561 可由归档 JSON 逐项复算，判红不是算错；
2. **判红含义**：红的是「本帧测光标定散度超出本帧误差预算上界」，**不是**「生产测光链在真实数据上已确认缺陷」；

## 2 计算口径（逐式复核，实测复算）

`σ_obs     = 2.5 · MAD(r_inliers) / 0.6744897501960817`  [mag]（MAD→σ 的解析常数 = Φ⁻¹(3/4)）
`ρ_lo      = 1 − 3·1.166/√n ,  ρ_hi = 1 + 3·1.166/√n`（1.166 = √1.361，MAD 尺度估计量的相对标准差因子）
`σ_floor   = ρ_lo · σ_fit(白)        σ_ceiling = ρ_hi · sqrt(Σ 预算项²)`
`PASS ⟺ σ_floor ≤ σ_obs ≤ σ_ceiling`

实测复算（`n_inliers = 151`）：

| 量 | 归档值 | 复算 |
|---|---|---|
| ρ_hi | — | 1.284663202878 |
| ρ_lo | — | 0.715336797122 |
| σ_ceiling | 0.020560838265260225 | 1.284663202878 × 0.0160048472 = **0.020560838** ✓ |
| σ_floor | 0.0060077521784322315 | 0.715336797122 × 0.0083984945 = **0.006007752** ✓ |
| sqrt(Σ预算项²) | — | 0.016004847（其中 σ_psfsys 0.013668、σ_flat 0.0007、其余（光子+量化）0.008297） |
| σ_obs/σ_ceiling | — | **1.2898**（超 28.98%） |

**口径要点（易错处）**：

- 包络因子用的 `n = n_inliers = 151`，**不是** 匹配星总数 157。用 157 会得 ρ_hi=1.279171、σ_ceiling=0.020473（仍判红，方向不变）；
- σ_flat 取**权威预算表**值 0.0007（同帧族，独立于被测样本）——见变更 claim `PHOT-SIGMAFLAT-INDEP-001`；
- `delta_after_m` = 0.019561 **只作诊断、不进预算**（与被测统计量同源，进上界会让判据惰性恒通过）。

## 3 判红含义（这一条最容易被读错）

**判红的字面含义**：本帧 157 颗匹配星（151 内点）的测光残差散度 0.026520 mag，**超过**「本帧误差预算 × 3σ 抽样允差」给出的上界 0.020561 mag。

**它不蕴含**：

- 不蕴含「生产测光链有缺陷」。同单元的仿真腿（G1：三帧 0.045344 / 0.057457 / 0.051718 全部 PASS）与解析腿全绿；
- 不蕴含「判据不可用」。单元自身的负例面（N1–N6）证明判据非退化：注入多性残差 3.52×、天光抬升 2.91× 都单调上升并判红，真值无效应时归零判红。

**它确实蕴含的（本档口径下的真实缺口）**：真实帧腿的 σ_ceiling **不完整且偏严**——
σ_color（通带失配）、σ_gaia（参考侧定标）、平场大尺度残差三项在真实帧**不可自算**，按 fail-closed **不加**。因此这条红同时携带两种可能：**(a)** 预算里缺了真实存在的系统项（≈13 mmag 量级即可翻转）；**(b)** 确有未建模的系统残差。

**边际性（实测扫描，归档在 `sigma_flat_sweep`）**：

| σ_flat (mag) | σ_ceiling | 判定 |
|---|---|---|
| 0.0 | 0.020541 | ABOVE_CEILING |
| 0.0007（现取值） | 0.020561 | ABOVE_CEILING |
| 0.005 | 0.021522 | ABOVE_CEILING |
| 0.010 | 0.024228 | ABOVE_CEILING |
| **0.013057（翻转阈值）** | 0.026520 | **PASS** |
| 0.020 | 0.032895 | PASS |

⇒ **一条 13 mmag 的未建模系统项就能决定这条红绿**。任何「P1 测光红」的对外表述都必须带上这句，否则把「预算不完整」误读成「生产链缺陷」的风险极高。

**与既有 49 帧读数的关系**：`06_photometry.md` §4.1 记录 L4 49 帧「PASS 1/49、未消系统项 0.0442 mag」，
本单元 G7 自述与它**同归因**（未消系统项超预算）。两处是同一族现象，不是两个独立缺陷。
