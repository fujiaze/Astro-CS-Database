# 未决登记

上游：最高设计的验证体系与版本与发布权两章；登记面的交付形状见文档治理规范。

## 1 本面的定位

本面登记**需项目负责人裁决**的事项，每条给四项：内容、为什么必须由负责人裁、阻塞哪个交付面、
现有证据或倾向。本面不承担裁决，不写过程流水、责任归属与变更轨迹；裁决结论落回相应正本后，
该条从待裁层移入已裁层。

判据本身不因执行面更换而失效：执行面是人读对抗性审核与实验单元复算，判据的内容（判什么、
判到哪一档、证据须可复算）一条不废。
