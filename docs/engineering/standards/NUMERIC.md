# 数值、单位与浮点标准

本标准依据[最高设计](../../ACSD_DESIGN.md)的精度归属及[数据语义](../../science/unified/DATA_SEMANTICS.md)，规定科学量的单位、标度、有限域和浮点处理。统计模型由[噪声分册](../../science/noise_snr/NOISE_SNR.md)定义；信号算子由[Drizzle分册](../../science/drizzle/DRIZZLE.md)定义。实现与证据状态集中见[科学实施差异](../architecture/SCIENCE_IMPLEMENTATION_DELTA.md)。

## 1. 科学量的声明

每个科学浮点字段同时声明单位、坐标系、归一化、精度要求和有效有限域。方差的单位为被估计量单位的平方，逆方差为其负二次幂；面积相关量必须携带sr的幂。单位与数据的真实标度相符，FITS的BUNIT按标准解释[1]。

| 标度 | 含义 | 单位 |
|---|---|---|
| raw_adu | 有来源的原生探测器计数，存储值先按BSCALE/BZERO解码 | ADU |
| calibrated_adu | 偏置、暗流、平场处理后的计数 | ADU |
| photo_scaled | 已实际施加逐帧或空间光度标度 | 由标度定义的linear_unit |
| surface_brightness | 积分线性量除以实际立体角 | linear_unit/sr |
| synthetic_flux | 已声明响应、积分与归一约定的合成量 | 由积分式推导，不固定为谱密度 |

若f_λ为W m⁻² nm⁻¹且效率R无量纲，∫f_λR dλ为W m⁻²；∫f_λRλdλ为W m⁻² nm；后者再除∫Rλdλ才是带平均谱密度。波长换算为与h、c相容的单位并除hc后可得到光子率面密度。曝光、口径、增益是否包含在响应中须分别说明，不能重复换算。详细约定见[测光分册](../../science/photometry/PHOTOMETRY.md)。

数值大面默认FP32；WCS、稀疏控制、标定系数与元数据保留FP64。几何、分解和累加的内部精度按误差预算选择，不能用产品位深推断所有中间量也用相同精度。尺寸、索引和字节数采用检查溢出的整数运算。

## 2. 线性标度与面积幂次

确定性标量α使x′=αx、Var(x′)=α²Var(x)。空间标度为C′=D_α C D_αᵀ；由数据估计的标度另含参数及交叉协方差[2]。跨帧合并前将信号、方差、参考通量和模板转换到配对单位。α=0是非可逆变换，不能据它定义可用的逆方差。

代数上，先统一标度再计算1/(α²V)，与按配对换算定义的权重相同；不同运算顺序、FMA、舍入、溢出或下溢可造成浮点差异。代数恒等不保证逐位相等。仅当实现冻结了运算序、数据类型和环境并有相应证据时才宣称逐位复现。

对于F/A的面亮度，Var(F/A)=Var(F)/A²。HEALPix叶面积与nside的关系[3]给出

\[
 A_{\rm leaf}=\frac{4\pi}{12nside^2},\qquad
 \frac1{A_{\rm leaf}^2}=\left(\frac{12}{4\pi}\right)^2nside^4,
\]
\[
 \log_{10}(1/A_{\rm leaf}^2)
 =4\log_{10}(nside)-2\log_{10}(4\pi/12).
\]

nside翻倍时因子增加16倍，即1.20411998266 dex；2¹⁸与2¹⁶相差256倍，即2.40823996531 dex。示例：

| nside | A_leaf [sr] | 1/A_leaf² [sr⁻²] | log₁₀(1/A_leaf²) |
|---|---|---|---|
| 2¹⁸ | 1.5239×10⁻¹¹ | 4.306×10²¹ | 21.634 |
| 2¹⁶ | 2.4382×10⁻¹⁰ | 1.682×10¹⁹ | 19.226 |

该式描述同一积分量到面亮度的单位换算。改变实际重采样分辨率还会改变算子、支持与相关性，不能由nside⁴单独预测输出随机方差。

## 3. 地板、次正规数与逆方差

数值地板必须与数组同单位、同标度，并在实际dtype可表示；它是算法约定，不能把未知或负预测方差变成物理上已测得的精度。协方差正则化改变模型，其来源、偏差与状态须明确。

IEEE二进制FP32的最小正次正规数为2⁻¹⁴⁹，最小正正规数为2⁻¹²⁶[4]。若最终正实数t以round-to-nearest、ties-to-even转换为FP32，保留渐进下溢且未提前舍入，则

\[
 0<t\le 2^{-150}\quad\Longrightarrow\quad \operatorname{fl}_{32}(t)=0.
\]

恰好2⁻¹⁵⁰是0与2⁻¹⁴⁹的中点，ties-to-even选择0；只有严格大于该中点才可能得到非零结果。FTZ会把次正规结果清零，DAZ会把次正规输入作为零；它们与渐进下溢的边界不同，测试记录实际环境、数据类型及发生转换的位置。中间运算已在FP32完成时，不能再以无限精度t的单次转换代替整条路径。

以原生方差地板v₀=10⁻¹² ADU²为算术示例，应用标度α后的实数地板为t=v₀α²。对应的实数标尺为：

| 条件标尺 | α的正值 |
|---|---|
| t=2⁻¹⁵⁰ | 2.64697796017×10⁻¹⁷ |
| t=2⁻¹⁴⁹ | 3.74339213057×10⁻¹⁷ |
| t=2⁻¹²⁶ | 1.08420217249×10⁻¹³ |
| 1/t=FP32最大有限值 | 约5.42101102399×10⁻¹⁴ |

这些是示例v₀的换算标尺，不是所有噪声模型的常数。临界附近的可用性须对实际已舍入值计算；倒数溢出的舍入边界也不能直接以实数不等式代替。非零方差仍可能产生无穷逆方差，因此两者分别校验。α=1只是正常可表示的一个例子，并非唯一情形。

## 4. 有效值、掩膜与归一

有效信号可以为负或为零；无覆盖或不可计算的浮点信号用NaN，Inf不作为科学信号。JSON未知数用null和状态，不能写NaN/Inf。输入非法、缺支持和合法信号但precision unavailable分别表达，损坏的方差文件不伪装成正常缺项。

固定输入有效集合后，Drizzle的分子、分母及协方差使用同一信号算子：

\[
 w_{jp}=a_{jp}/A_{\rm drop,j},\quad
 N_p=\sum_jw_{jp}\Omega_j,\quad
 S_p=\frac{\sum_jw_{jp}x_j}{N_p},\quad R_{pj}=w_{jp}/N_p,
\]
\[
 C_{\rm out}=RC_{\rm in}R^T.
\]

独立输入时V_p=Σ_jR_pj²v_j。N_p的单位为sr；累计drop面积D_p=Σ_ja_jp也是sr，却一般不是同一数值，不能替换N_p。D_p亦不是去重覆盖并集。对输入值掩膜时，同步从信号分子、归一和算子中剔除对应贡献，记录有效集合。

方差可用性与信号有限性分开。没有完整噪声模型的合法信号可以保留；此时输出精度状态不可用，不能只漏掉未知方差项后仍把部分和标作完整Var。方差0的机器编码若用于unavailable，必须有明确状态，不能解释为物理无噪声或无限信息。

Mosaic的统计归一是权重和W=Σw_B；Export几何插值的归一是其几何系数和。两者不等同N或D，系数单位、目标量和缺覆盖政策分别声明。有效集合为空或归一无定义时返回具名状态，不制造有限伪信号。

## 5. 精度、权重与相关性

参考通量信息I_F=SNR_ref²/F_ref²=1/V_F；实际场景面亮度精度w_B=1/V_B；背景控制精度1/V_ctrl。这三个对象分名。相同位置、相同协方差条件下T=V_B/V_F才给出w_B=I_F/T；reference-source条件不能直接替代actual-scene条件。

几何drop系数、Export插值系数、统计逆方差和支持分数不共用无语义的weight。一般归约器允许零权重表示不贡献，负权重是否允许由具体估计器声明；简单正权平均不接受负数。全零权重是无有效权重，与损坏NaN/Inf输入分开。共享母版或校准参数的相关误差不能按独立帧衰减；排异后的方差须考虑后选择。

## 6. 数值复核

容差同时有单位、输入域和依据。除零、非有限值、尺寸溢出和不满足协方差定义的输入显式报告。矩阵秩在参数尺度归一后判定，检查分解残差和可估计性，不以任意epsilon制造信息。

观测秩截断、通量可辨识性及允许的相对误差使用不同判据。近背景子空间的通量优先以显式残差求平方范数；只有残差误差界小于已计算的残差范数，才能据该界确认信息正值，并进一步评价 V_F 与 SNR 的相对误差。相邻求积阶数差、QR 主元比和分解完成状态都不是通用精度证书。条件误差界及共同观测支持要求由[噪声分册](../../science/noise_snr/NOISE_SNR.md)定义。

确定性验证固定随机种子、算术类型、求和顺序与浮点环境；跨worker和不同后端按事先声明的科学容差比较。FP32产品与FP64参考分别评价舍入、下溢、归一、几何近似及模型误差，不能用一个相对误差覆盖全部零点附近情况。
