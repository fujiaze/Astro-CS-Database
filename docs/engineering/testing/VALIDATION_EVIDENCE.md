# 验证证据与结论范围

本文规定[最高设计](../../ACSD_DESIGN.md)要求的独立证据如何组织、解释与复核。测试实现见[测试规范](TEST.md)，资源量见[性能模型](../resources/PERFORMANCE_MODEL.md)，产品身份见[溯源](../data/PROVENANCE.md)，记录与文档归属见[文档维护](../governance/DOCUMENT_GOVERNANCE.md)。验证服务于科学和工程判断，项目不设研发审批门。

## 主张、对象与独立真值

每条结论先点名估计量、单位、条件与被测入口，再说明证据能排除哪些错误。解析代数、高精度计算、独立参考实现、前向成像和真实观测互相补充；它们验证的域不同，不能简单相加成统一“通过率”。实现存在、静态可达、构建、实际运行、独立科学支持分别陈述。

独立 oracle 不调用待测近似制造期望，不读生产输出反推所谓真值。合法的自生成仿真由独立模型和已知参数建立，区别于从待测产品拷贝答案。HST 处理成品可作结构模板，其原噪声与重采样不能充当天然探测器真值。真实观测缺绝对真值时，报告重复性、交叉比较与相应系统局限，不能只由视觉或退出码断言无偏。

每项对照说明生产接口与实际对象。独立库可使用，须解释方法差异和共同假设；不设只准某个 Python 库的伪独立性白名单。相同算法的不同线程、全量重算、自写自读、schema 验证和缓存命中分别是执行一致性或工程证据。

## 三条科学路径

| 路径 | 需要独立观察的主要量 |
|---|---|
| Normalize | 校准、求解、响应/尺度、空间 PSF、条件噪声、球面算子、controls 与能力状态 |
| Mosaic | 输入身份与单位、图连通和规范、空间精度/传递因子、背景和低频保真、排异、最终 signal |
| Export | 输入层级/支持、WCS、核、裁剪、有效域、单位与平面科学值 |

合成科学、规模化性能、小批量真实端到端和全量视觉评价是不同证据层面。按问题和依赖安排验证：没有上游可信产品就不能宣称其下游科学成立，但可以独立研究下游算法或测量性能。不要把旧 L1→L4 流程变成禁止正常开发的审批阶梯。

性能记录 CPU、内存、I/O、工作集、线程扩展与缓存条件；实际采样和请求某个基准判定分开。磁盘写满及 I/O 失败明确报错，资源观测不新增 CPU/内存/线程的科学输入拒绝门。跨机器、构建和数据的比较说明条件，摘要相同并不自动证明二进制和环境相同。

## 实验身份与持久记录

实验以所属单元保存命令、脚本、代码/构建身份、配置和输入清单、轻量结果、错误与失败尝试，不覆盖过程。帧集从运行清单枚举，从实际产品取几何，核对 run_id、帧身份与天区；缺几何逐帧登记，天区不符的分析无效。真实 FITS 不上传 Git。

内容哈希支持完整性和身份比较，不自行证明来源可信、采集真实或科学独立。指针带路径、摘要与解释；目录不存在、文件为空、解析失败与零对象需明确记录。结果件能让他人复算对象计数和统计量，不能只有 PASS 标签。

| 结果字段 | 含义 |
|---|---|
| 主张与范围 | 估计量、假设、单位、参数/几何/数据域、入口与所用层级 |
| 身份 | 源码、构建/二进制、依赖、输入、配置、随机种子和运行标识 |
| 实算对象 | 计划、实际求值、接受、拒绝、未求值及原因，统计分母 |
| 比较 | 独立真值来源、误差/阈值及依据、适用/排除对象、正负例 |
| 过程 | 完整命令、退出码、日志、墙钟、资源条件、失败尝试 |
| 产物与局限 | 可复查路径、摘要、未覆盖项、系统误差及结论限制 |

## 计数与中止

按声明集合核对 accepted + rejected + not_evaluated = planned，并说明 evaluated 的定义。首帧失败中止不是全批帧失败；all_failed 只适用于全部实际求值并拒绝。未尝试、显式排除、不适用、环境跳过、无效分析和实际失败各记原因，不合并成通过或失败数。

覆盖指标分别报 total_px、covered_px、finite_px，分子分母和有效条件明确；像素数不能替代逐帧统计。接缝指标给足迹、边界采样、局部背景/噪声、有效边数和逐边排除理由。无有效对象不能支持“无接缝”主张，背景接近零时相对台阶指标的含义仍需科学分册限定。

子集证据只支持该子集；“全量”须给全部输入和未求值对象。未求值不填虚构读数，unknown 精度不填零；合法信号与精度不可用并行报告。分类术语是报告说明，不因输出某个状态词自动获得科学保证。

## 判定手段与复核

判定器应读取真实声明对象，核对实算数量，保存比较值和正负例。正确对象可通过，注入相应缺陷可失败；适用域、白名单或降级分支存在时覆盖其边界。共用管道故障注入只能证明管道检出能力，不能宣称每条科学判据都经过缺陷注入。

复核先取得当前对象并独立计算，再对照旧结论；报告一致、偏松、偏严或证据不足及依据。允许待证，不强迫无证裁决。问题保留确认、降级、推翻或待证及来源，不删除失败历史。必要的独立交叉核对按问题安排，不把必须再找代理签字设为所有文档修改的前置条件。

检索零命中只适用于明确路径集、模式与版本，不能单凭一个字符串证明生产不可达。静态缺陷说明触发路径、调用者与缺失运行证据；“未实现”“未接线”“已退役”“未运行”分开。判据自身已知假阳/假阴、排除面和不适用条件随结果说明，缺证不能记绿。

## 图像评价与交付

视觉评价使用原科学 FITS、可复现显示拉伸、整幅预览和有坐标编号的局部图。检查孔洞、异常亮斑、重影、帧/块接缝、星点形态、背景结构、动态范围和几何。无覆盖与合法零/负值分别解释，显示 clipping 不能证明科学源值为零。视觉与光度、坐标、PSF、低频传递和统计效率的定量结果并列。

实际天区和帧集由运行清单决定，不硬编码旧轮次的 M42/银心数量、R 通道或筛选子集为永久产品合同。拒绝与失败不隐藏，重跑只使相应新运行产生新证据，旧记录保留。发布由负责人决定，文档重构和结构检查完成不等于科学产品验收。

旧验证规范的 mutation ID、P0/P1 门表、审计步骤、数值与用例矩阵完整保存于[来源档案](../../../实验/documentation-refactor/docs/TESTING_SOURCE.txt)。其中退役权重模式、绝对最优性、固定接缝阈值的适用域等问题见[Q28 与既有问题](../../../实验/documentation-refactor/docs/SCIENTIFIC_QUESTIONS.md)，不由本页另选模型或阈值。原有实验记录仍按原身份解释，历史通过声明不作为本轮执行证据。
