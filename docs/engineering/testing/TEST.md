# 测试规范

测试依据[最高设计](../../ACSD_DESIGN.md)与科学正本，用独立真值、正例和负例主动暴露缺陷。证据的范围与报告见[验证证据](VALIDATION_EVIDENCE.md)，数值类型和量纲见[数值标准](../standards/NUMERIC.md)。测试结果说明已检验对象和条件，不替代科学定义或发布决定。

## 测试面与独立性

测试代码独立于生产计算实现：模块测试可共址于模块 tests/，跨模块、合同和端到端测试位于 eng/tests/。公开接口单测、内部必要的不变量测试和真实命令端到端各有对象；不能要求每个局部检查都运行完整产品，也不能用局部替身证明生产链已经命中。

每项科学主张关联解析解、高精度参考、独立外部实现、真值前向仿真或真实重复观测，并解释该方法实际能验证的量。oracle 不调用待测算法来制造期望，不照搬同一实现的误差。共享源、往返、自写自读和全量重算只验证相应一致性。仿真生成器必须独立于待测近似，其 seed、模型、参数、噪声与系统项明确保存。

正例保证合法输入可通过，负例证明对应缺陷能被检出；测试判定器自身要避免恒真、空断言和全红。缺陷注入在隔离副本或受控测试对象上进行，不污染产品与留证。科学算法变更优先覆盖独立真值与失效域，纯导航修改不新增镜像实现的测试。

## 确定性与比较对象

固定种子、输入身份和配置，分别比较科学数据、科学元数据、结构状态和易变运行字段。时间戳、run_id 等不能参与不加说明的整文件逐字节确定性断言。完整性摘要与排除易变字段的规范产品摘要用途不同，见[CLI 协议](../contracts/CLI_PROTOCOL.md)。并行度和 ISA 比较保留整数、掩膜、索引、计数及选择结果的精确性，浮点按声明容差比较。

## 通用容差规则

下表保留既有项目比较配置，不将其提升为对全部算法和量级成立的数学保证。具体比较必须给估计量、单位、scale、绝对/相对组合方式、参考方向与适用域；专题已有更具体定义时引用专题。无合法误差模型时记未验证，不临时放宽到通过。

| 量类 | 既有比较配置 |
|---|---|
| 元数据、掩膜、计数、索引、端口与离散选择 | 精确一致 |
| FP64 非归约 | rtol=1e-12，atol=1e-13×scale |
| FP32 产品非归约 | rtol=5e-6，atol=1e-6×scale |
| 归约 | γ_n=n·u/(1−n·u)，预算形式 C·γ_n·Σabs(terms)+atol，C≤4 事前声明 |

最近邻舍入下的 unit roundoff 既有取值为 binary64 的 2⁻⁵³、binary32 的 2⁻²⁴。归约预算需解释真实项数、计算/累加 dtype、操作次序、舍入模式、溢出/下溢和条件；输出 dtype 不能单独决定所有运算的误差预算。C≤4 是项目配置，不是文献对所有算法的结论。固定树或分块可控制归约顺序，是否逐位可重现仍以实际执行为据。

旧文对“绝对容差至少 1 ULP”“超域只放宽”和通用归约界的断言存有待推导问题，见[Q27](../../../实验/documentation-refactor/docs/SCIENTIFIC_QUESTIONS.md)。本轮不调整既有数值、不建立新误差界，旧完整表和论证逐字节保留于[测试来源](../../../实验/documentation-refactor/docs/TESTING_SOURCE.txt)。已有测试的具体阈值需逐项留档，不能因正文整理静默重置。

## 非有限值、覆盖与能力状态

先按对象合同比较有效性、覆盖及能力状态，再比较有效有限值。覆盖不足、合法 NaN、错误产生的 NaN、正负无穷与缺精度模型分别解释，禁止先把它们填零再做有限比较。Export 无覆盖用 NaN，合法负值和有限零保留；测试不能另立“缺失绝不可用 NaN”的全局编码来推翻产品定义。未知误差不写零。预期非有限集合、符号与无效原因均需检查，只比较有限交集不足以证明整个产品正确。

## 执行范围与代价

按当前改动和真实依赖选择受影响验证：文档结构改动核对索引、链接和内容保留；接口/单位/坐标变动覆盖上下游；算法变动覆盖独立 oracle 与反例；调度/持久化变动覆盖实际集成；编译器/ISA变动覆盖相应平台与数值矩阵。说明基线、改动集、所选检查、未覆盖项和理由。遇到新失败或未解疑虑再扩大范围，不把全文档路径命中机械升级为全科学运行。

快速检查、集成、全量与真实性能测量按对象和代价区分。声明完整命令可运行必须实际启动对应程序；构建、测试、真实运行和科学验证分别报告。命令预算根据首次规模估计与同机器同数据历史读数制定，超时和中断保留证据，不自动当算法错误或通过。Windows/Linux、CPU能力和数据依赖不可用时记 skipped/not_run 并说明，不伪通过。

结果至少记录代码/构建、平台与依赖、命令、输入/配置身份、种子、比较量、阈值来源、实算分母、失败、墙钟、输出与适用域。没有选中检查或零实算对象不构成验证通过；合法空输入本身若是负例，其明确预期仍可检验。覆盖率说明统计集合与排除项，不混合测试数、帧数、像素数和科学主张数。

测试依赖可用 NumPy、Astropy/WCSLIB、astropy-healpix 等适合对象的参考工具，实际版本和独立性逐例说明；pytest、GoogleTest 是运行器而非 oracle。测试依赖不自动进入产品依赖。失败按具体对象、预期与实测报告，环境归因需要日志，不以测试名或历史绿灯替代当前证据。
