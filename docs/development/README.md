# development

本目录存放开发侧的简明规范：代码风格、配置 schema 一致性与测试入口说明。

## 职责边界

- 放：写代码/写配置/写测试时直接查阅的规则与入口说明。
- 不放：完整工程规范（在 ENGINEERING_SPEC.md）；配置合同正文（在 docs/contracts/CONFIG_CONTRACT.md）；测试与验收标准（在 ACCEPTANCE_SPEC.md）。

## 内容

- `CODE_STYLE.md` —— 语言版本、格式化工具与命名规则。
- `CONFIG_SCHEMA.md` —— 配置/schema 的单一事实来源与一致性规则。
- `TESTING.md` —— 测试入口与常用测试目标说明。
