# Mosaic 管线与数据交接

Mosaic 消费已发布的逐帧 HiPS，在球面网格上估计相对背景、排除异常样本并合成为一个 signal 科学图像通道。目标产品、统计量和适用域由最高设计、统一科学模型、噪声与背景分册规定 [1–4]；本页说明阶段内交接及其实现边界。

## 输入与被估计量

输入清单冻结帧身份、产品路径、坐标、实际光度标度及可用模型。不同设备和通带可以共同参与；响应差异通过逐帧记录、参考约定和输出混合响应说明表达。单位不可解释、几何损坏与文件损坏应报出具体原因。

聚合输入是同一网格上的线性面亮度。不同 PSF 或通带可能对应不同的已成像天空；像元逆方差平均的最优性只在共同被估计量及相应噪声假设下成立。跨通带组合的响应可能随位置和有效帧集变化，单个滤镜名称不能完整描述它。

阶段一的正式精度载体及读取合同由 Normalize 数据合同规定 [5]。Catalogue、规整 sparse_snr_layer 和帧头 SNR 按各自实际语义读取；名称相似不足以证明可互换。

## 节点与对象生命周期

| 节点 | 消费 | 产生与下游 |
|---|---|---|
| coverage | 输入清单、HiPS 几何和有效域 | 帧映射、目标阶和重叠关系，供采样与调度使用 |
| sample | 帧信号、掩膜与背景统计模型 | 带支持域和自身方差的背景控制观测，供拟合使用 |
| upm_fit | 控制观测、有效重叠图与背景基函数 | 各分量背景差模、规范和诊断，供校正使用 |
| upm_apply | 帧信号和背景模型 | 校正值及可用不确定性，供排异与集成使用 |
| reject | 同一位置的候选栈及资格 | 接受掩膜和理由，供集成使用 |
| integrate | 接受样本、面亮度精度与内部支持 | 合成信号、有效域和归约摘要，供 writer 使用 |
| write | 合成结果、实际单位和来源 | 单 signal HiPS 及运行摘要 |

实际依赖边由端口注册表与 Runtime 绑定实现 [6]。对象在其消费者完成后释放；必要缓存经统一 I/O 管理，绑定输入身份和对象版本。阶段间只交换已发布产品。

## 精度的生产与消费

参考点源精度 I_F=SNR_ref²/F_ref² 是积分通量的逆方差，面亮度聚合需要 w_B=1/V_B；两者通过同条件、同支持域的 T=V_B/V_F 联系。参考源条件协方差不能直接充当任意实际星空的像元方差 [3]。背景拟合使用背景控制统计量自己的方差。

稀疏重建在输出位置求值，携带参考、模型、支持域及外推状态；有限预测值不等于有测量支持。无法确定精度传递时，应说明可使用的基线及其能力边界。

当前 p2_op_integrate 优先消费已声明可用的校正方差，其次使用已有像元 ivar 或 SNR 兼容链。snr_path_requested 与 snr_path_effective 记录请求和实际路径；当前 dense 请求有明确不可用错误。兼容公式存在，不等于条件参考控制到面亮度精度的生产转换已得到科学验证。具体差异在实施地图维护 [7]。

## 背景、排异与聚合

背景差模仅由有效重叠约束，各连通分量分别固定规范。分量间绝对背景差需要外部锚；正则化选择解，不增加观测信息。恒星颜色差、星云通带差和 PSF 差不自动属于可扣除的加性天空 [4]。

排异决定资格，集成对接受样本归约。路由的样本量、阈值和小样本处置由算法与配置说明，本页不复制数值表。数据驱动排异及同数据背景拟合带来选择和拟合依赖，输出方差不能普遍写为 1/Σw [3,8]。

内部支持描述覆盖或归一，不代替精度。无有效贡献写 NaN，有限零与负信号保留。背景台阶应结合真实足迹边界测量，同时检查星点光度、星云低频和未测边界；视觉平滑不能单独证明信号保真。

## 写出与实现边界

当前 p2_op_write 使用 AIO_HIPS_PRODUCT_SIGNAL，通过已有 writer 接口传入内部覆盖分母。分母仍参与信号归一，不发布 support 图像层也不能删除它。分辨率层级、properties、坐标和摘要不是额外科学图像通道。

产品记录实际光度单位、响应分布、输入身份、有效域与算法来源。writer 调用、统一 I/O 事务能力和真实运行结果分别核对，不由设计目标推断原子发布或科学验收已完成 [7,9]。
