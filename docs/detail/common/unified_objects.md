# 统一数据对象登记

跨阶段公共机制之一，对应最高设计数据对象条目。工程侧的统一对象合同登记在工程统一对象页，本页只记录细节层消费该合同的方式。

## 定位与对应一级条目

细节层不定义新对象。对象的身份、单位、无效值、精度归属与可否作权重的判定，以统一观测模型页的数据对象与字段歧义消解一节为准。工程统一对象页登记对象到规范模式的对照关系。

## 数据对象与块的读写

各模块按端口合同读写具名对象：信号与其方差、信噪比族、有效性族、来源链。裸写的无前缀字段名不进入端口。块的生命周期遵循内存管线纪律：读已声明块、写新块、消耗旧块，不私藏大块长期副本。

## 接口签名

对象的机器形态以工程统一对象页登记的规范模式为准，细节层不复制字段表。模块登记页逐模块列出本模块消费与产出的对象名。

## 处理步骤与分支

对象本身不规定处理步骤，步骤由各管线页与模块登记页规定。跨帧可比性只在同一参考档内成立，并与帧间测光标度不确定度一并计入误差预算。

## 配置项与默认值来源

对象定义不含可调配置。参考电平等约定随产品落盘，取值通道由各管线页的配置一节交代。

## 与相邻模块的关系

全部管线模块通过本对象集交换语义：单帧标准化管线生产对象，马赛克管线消费并产出马赛克对象，导出管线消费球面对象并产出平面文件。对象集是三条管线唯一的公共语言。

## 调试与验证入口

对象语义的疑问先查统一观测模型页，再查工程统一对象页的对照表。独立验证入口见各模块登记页。
