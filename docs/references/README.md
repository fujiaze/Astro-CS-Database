# references

本目录存放外部标准与文献档案：项目采用的科学与格式依据统一在此登记，作为科学断言的佐证锚。

## 职责边界

- 放：文献与外部标准清单、文献综述存档。
- 不放：公式与验收口径（在 docs/science/ 与各 SCI/ALG 条款）；逐题深查的研究包（在 docs/research/）；标准条款的冻结注册表（在 docs/standards/STANDARDS_REGISTRY.md）。

## 内容

- `SCIENTIFIC_REFERENCES.md` —— 科学与格式参考文献档案，按主题登记出处与用途。
- `PHOTOMETRY_LITERATURE_REVIEW_ARCHIVE.md` —— 测光文献综述存档。
