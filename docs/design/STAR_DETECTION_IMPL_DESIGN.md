## 3. 三条冻结合同定案

1. **DISP-STAR-006（float 归一化上界）**：检测侧动态范围常量取 `65535.0f`（float 字面量，
   不是整型 65535 提升后的 double 比较）。所有动态范围/饱和占比分母（O4、O13 的饱和豁免）
   以此为唯一上界。重写不得改为整型语义。
2. **DISP-STAR-007（拟合母函数唯一）**：检测侧拟合母函数**唯一**为椭圆高斯
   A·exp(−½[(x'/σx)² + (y'/σy)²]) + B（主轴角 θ 旋转坐标系）。
   不引入 Moffat / Lorentzian / 双高斯备选；模型选择不进入拟合回路。
3. **输出合同**：检测输出序列 = 拟合后去重（post-fit dedup）→ 按 mag 升序 stable 排序（防错⑪；单帧域与 SNR 序等价）
   → NaN 质量参数置尾 → 上限截断。合同字段与序语义冻结；重写不改变字段名、类型、排序稳定性
   与 NaN 置尾规则。

> 通用符号：I(x,y) 输入图（float，上界 65535，DISP-STAR-006）；σp PSF 像素 sigma；

### 5.1 O1 背景噪声统计 —— [Project-defined：文献无出处，引用时不注文献出处]

现行构造（重写逐位保持）：整图行内相邻差分 d(x,y) = I(x+1,y) − I(x,y)，方差
Var(d) = 2σ²(1−ρ)（ρ 为相邻像素噪声相关系数，未补偿时按 ρ≈0 解析），故

    σ ≈ std(d) / √2

std 用 3×5σ 迭代裁剪（初始 median/MAD，最多 5 轮，MAD 系数 1.482602218505602）。
解析推导就地给出：若 I(x,y) = S + ε(x,y)，ε 平稳且相邻协方差 γ(1)，
则 Var(d) = 2(σ² − γ(1))；行内取差分使慢变背景 S 与行间增益差一阶消去，
这是选行差分而非全域 std 的工程理由（ALG §2 的 Var(d)=2σ²(1−ρ) 声明同源）。
适用域：平稳背景；强梯度过帧 ALG 已另有动态区域背景路径，不归 O1。

### 5.2 O2 高斯平滑（YvV 递归 IIR）—— [论文锚定]

构造出处：Young & van Vliet 1995, *Recursive implementation of the Gaussian filter*,
Signal Processing 44(2), 139–151（引文已按 Crossref 核实；净室规格中 "IEEE SPL 2(10)" 为笔误，见 §8-4）。
边界条件：Triggs & Sdika 2006, *Boundary conditions for Young-van Vliet recursive filtering*,
IEEE Trans. Signal Processing 54(6), 2365–2367（同上已核实，非 "IEEE TIP"，见 §8-4）。

数学规格（与现行冻结实现逐项对应，`sdet_image.cpp` float/double 双变体）：

1. 精度参数 q：
       q = 3.97156 − 4.14554·√(1 − 0.26891·σs)          （σs < 2.5）
       q = 0.98711·σs − 0.96330                          （σs ≥ 2.5）
2. 递归系数（多项式组）：
       b0 = 1.57825 + 2.44413·q + 1.4281·q² + 0.422205·q³
       b1 = 2.44413·q + 2.85619·q² + 1.26661·q³
       b2 = −(1.4281·q² + 1.26661·q³)
       b3 = 0.422205·q³
       B  = 1 − (b1 + b2 + b3)/b0，随后 b1,b2,b3 ← b_i/b0
   **冻结说明**：q² 项取现行实现值 **1.4281**（行为冻结锚；文献通行复现记 1.4251，
   差异的量化影响与处置见 §8-1 存疑）。
3. 递归（每行/列双向）：前向 w(n) = B·x(n) + b1·w(n−1) + b2·w(n−2) + b3·w(n−3)，
   反向同系数逆序；首三样用常信号种子（w(0) = x(0)·(B+b1+b2+b3) 等，Triggs–Sdika 2006 §2
   边界矩阵 M 构造），行末镜像取值。float/double 两变体算术各自冻结。
4. 直通域：σs ≤ 0.5 或 W < 4 或 H < 4 时不平滑直通。
5. 生产参数：σs = 2.0（冻结）。

**适用域量化（本设计实测，重写须复现）**：合成 δ 冲激经真实实现（W=4001, H=9, σs=2.0）：
DC 增益 1.0000002，零相位对称；核心区 |d|≤3 与解析 σ=2 高斯偏差 ≤8%（峰比 1.023、
d=2 比值 0.915）；尾部显著重于解析高斯（d=8 处 17.2×）；二阶矩等效宽度
σeff(±100 px) = 2.2666。
含义：ALG §2 以解析 σ=2 高斯写的 κ ∝ (1 + σs²/σp²) 朴素式低估有效平滑；
以 σeff 代入在 σp=1 处给出 ≈1.25×，量级上对上 ALG §11.4 未定位的 κ 1.25× 残差
（§8-5，仅作成因参考，不进验收判据）。

### 5.3 O3 检测阈值 —— [论文锚定]

构造出处：Bertin & Arnouts 1996, *SExtractor: Software for source extraction*,
A&AS 117, 393 — §3（检测阈值化：对「模板帧」（原图与所选卷积核的即时卷积结果）做单遍
连通域提取）。模板帧在本实现中即 O2 平滑图（平滑核对点源检测最优，B&A96 §3 引 Irwin 1985 结论）。

规格：候选像素 = 平滑图 S 中

    S(x,y) > κ·σn

其中 κ 按 σ_psf 分档取 ALG §11.4 冻结召回阈表反推的检测侧阈值表（冻结，不重推）。
阈值量纲声明随 ALG §2：阈值作用于平滑图时按 σsm·‖k‖₂ 折算（σs=2.0 时 ‖k‖₂ 折算系数
35.45/σsm 声明项）。论文锚定说明：B&A96 §3 给出的是「阈值+连通域」构造本身；
κ 表为本项目按召回验收独立标定的项目参数（ALG §11.4），两者分层，不混注。

### 5.4 O4 饱和预标记 —— [Project-defined：文献无出处，引用时不注文献出处]

现行构造按作用层如实分立为两算子（重写保持）；两者为不同层算子，共用 0.7/0.1 系数家族，
量纲一律为 dynrange 相对式，**不得**写为 0.7·65535 绝对值式：float 定标帧上
0.7·65535 ≠ 0.7·dynrange，dynrange = min(max(img), 65535) − bg，bg = median(img)
（ALG §2 冻结定义），float 字面量 65535.0f（DISP-STAR-006）只是归一化上界；
float 定标帧上 dynrange 退化为「帧自身 max 与 65535 的较小者减帧中位」，
不等于探测器饱和电平（ALG §2 域退化条款）。

- **O4a 检测段饱和岛预标记**（全帧级；标记结果供 O6 饱和中心行走与饱和星测光消费）：
  sat_threshold = bg + 0.7·dynrange 单阈二值化（pixel > sat_threshold 置 1）→ 4-连通域
  提取饱和候选岛；岛级几何过滤：面积 > 1 像素、外接盒长宽比 ≤ 3；每岛以亮度加权重心为
  行走起点走 edge-walking 得等效中心，等效半径 r = √(面积/π)。无第二阈值、无占比式
  （检测段 dynrange 按帧内实际最大值计，行为级如实登记）。
- **O4b 拟合段候选饱和判定**（逐峰级；供 O5/O6 通道选择与 O13 饱和豁免消费）：
  对每个过阈局部极大峰，取 3×3 邻域内高于检测阈值的像素（中心像素除外）统计均值
  meanhigh 与最小值 minhigh；饱和 ⇔ meanhigh − bg ≥ 0.7·dynrange **且**
  pixel0 − minhigh ≤ 0.1·dynrange（pixel0 为峰中心原图像素值；邻域高像素计数 < 3 的峰
  直接剔除；此处 dynrange 取 min(max(img), 65535) − bg 全式）。

注：Stetson 1987（PASP 99, 191, §II FIND）亦有「饱和像素从核拟合中剔除」条款，但本算子族的
单阈岛标记与 3×3 双条件形式均为本项目构造（0.7/0.1 为工程标定值，冻结），不注文献出处。

### 5.5 O5 质心（一阶导过零） —— [Project-defined：文献无出处，引用时不注文献出处]

现行构造（重写保持）：检测峰位处沿 x/y 两方向用平滑图一阶差分线性内插过零点作亚像素质心，
输出 (x0, y0)。解析依据：对称单峰轮廓的过零内插收敛到真中心（就地推导，
不注文献出处）。O12 拟合中心是最终质心；O5 值作初值与独立诊断列。

### 5.6 O6 饱和中心行走 —— [Project-defined：文献无出处，引用时不注文献出处]

现行构造（重写保持）：O4 标记的饱和岛内，从检测峰出发沿亮度梯度行走至岛内最大 3×3

### 5.7 O7 宽度/振幅门读数（二阶导） —— [Project-defined：文献无出处，引用时不注文献出处]

现行构造（重写保持）：峰位处沿 x/y 取平滑图二阶差分，由 ∂xxS = S''max 与高斯
S ∝ exp(−x²/2σx²) 的 √e 恒等式（S(x=σx) = S(0)/√e ⇒ σx = √(−S(0)/S''max(0))）
解析得到 (σx, σy, A) 门读数，供 O9 拟合盒、O10 形状预门与 O13 五码门消费。**O12 的 (σx, σy, A) 初值不走本恒等式**——按 ALG（初始化＝halfA 边界搜索）由拟合器自求；中心初值相对候选中心（O5/O6 产出）零偏移。恒等式为解析事实，构造本身不注文献出处。（防错⑭：本条订正旧文「产出 LM 初值」的断言。）

### 5.8 O8 局部极大扫描 —— [论文锚定]

构造出处：Stetson 1987, PASP 99, 191 — §II「FIND」：在核卷积响应图上找局部极大
H(i0,j0) > Hmin 且大于规定半径内所有邻值，半径由星像 FWHM 推出（原文 §II.2）。
本实现以 O2 平滑图替代 DAOFIND 的零积分核响应图 H（O3 已按平滑图量纲冻结阈值表，
两者在点源检测上同构——B&A96 §3 同样以 PSF 形状核为点源最优），扫描半径与邻域语义为项目参数。

规格细节（重写修正项）：现行扫描内层 xx∈{3,4} 存在越界读（读 y± 邻行越界列），
重写修复为钳位访问。**等价性论证**：召回阈表标定用 256² 居中单星，检测窗不触及图像右/上边带，
该列带内的越界读不影响标定值，故阈表不移动、无需重标定。等价性论证的适用域即该 256² 居中单星标定域；标定域外的真帧边缘带行为变化由现行实现的回归锚承载（M42 真帧检测统计锚与回归监视基线，§2 统计锚条款）。

### 5.9 O9 拟合盒半径 R —— [Project-defined：文献无出处，引用时不注文献出处]

R = σp·√(2 ln 1000) = σp·3.71692）加工程钳位 R ≤ 200。

### 5.10 O10 形状预门（对称性） —— [Project-defined：文献无出处，引用时不注文献出处]

现行构造（重写保留，**不**替换为 DAOFIND 门）：以 dA/dSr/dSc 三个对称性统计（拟合盒内象限
差分）在 LM 前剔除非星形状。理由（判据级）：DAOFIND 的 roundness/sharpness 门
（Stetson 1987 §II：0.2 < sharp < 1.0、−1.0 < round < 1.0 默认域，论文 §II.F 明示）
要求以零积分核响应图 H 为输入，切换输入图即移动 O3 阈值表的量纲（ALG §2 的 ‖k‖₂ 折算
随核改变），触发全表重标定（§4 条款）；现行对称门在冻结阈表下已达标。
切换路径完整规格见 §6.3，作为谱系化备置，不在本次重写实施。

### 5.11 O11 多星去重（曼哈顿式）→ 替换为 SExtractor 多阈值 deblending 树 —— [替换为论文构造]

现行构造为「曼哈顿距离 + SNR 优先」的拟合后去重（项目自有，无文献出处）。
本设计决定替换为文献构造：

- **替换规格**（Bertin & Arnouts 1996, A&AS 117, 393 — §4）：
  对每个 8-连通检出组分，在检测阈值与峰值之间取 **30 个指数间隔阈值**
      t(i) = tdet · (Smax/tdet)^(i/30)，i = 1..30
  重建亮度树；自枝叶向根，在任一结点阈值 t(i) 处，若某枝满足
  (1) 该枝高于 t(i) 的积分流量 > δc × 组分总流量，且
  (2) 同层至少另有枝同样满足 (1)，
  则判为独立成分（B&A96 §4.1 双准则，原文建议 δc = 5×10⁻³）。
  两项操作化规则（B&A96 §4.1–4.2 语义）：
  - **未存活枝归父**：任一枝在结点 t(i) 不满足双准则时不生成独立成分，其像素并入其父枝，
    父枝以并入后的积分流量继续沿树向根参与上层双准则评估；直至树根仍单枝的组分即单星，
    全组分像素归该成分。
  - **双变量高斯重分配（argmax）**：组分最终分裂为 k ≥ 2 个成分后，对低于最终分离阈值的
    每个像素 p，按各成分的双变量高斯模型计归属概率
    P_c(p) ∝ exp(−½ (p−μ_c)ᵀ Σ_c⁻¹ (p−μ_c))（μ_c 为成分内像素的峰值位置，Σ_c 由成分
    面积/二阶矩估计），判归 argmax_c P_c(p)；概率按浮点严格比较，平局判归树中登记序
    靠前的成分（确定性规则，项目定义）。
  上述两式为按 B&A96 §4.1–4.2 语义的操作化转述；编码时以原文 §4.1–4.2 提取件为准，
  显式公式若有出入按原文订正并登记 §8。
- **适用极限**（B&A96 §4.3）：双星可分离极限为存在鞍点（高斯轮廓下间隔 < 2σ 不可分）。
- **接入位置**：替换 O3 连通域之后、O5/O7 初值之前（deblending 属检测段），
  取代现 O11 的「拟合后曼哈顿去重」在多组分检出场景的职责。
- **合同衔接**：孤立单星域（召回阈表标定域）deblending 不触发，阈表不移动；
  §3 输出合同的 post-fit dedup 对去混合后仍共点的亚阈值组分保留现行为
  （O15 承接，冻结）；F2 饱和优先语义由 O15 保持。
- **验收影响**：M42 多星统计锚须在新构造下重取（统计锚，非门）；阈表不移动（见上）。
- 注：SExtractor 软件参数文档记 DEBLEND_NTHRESH 默认 32，与论文正文「30 levels」不一致；
  本设计按论文正文 30 层实现，差异登记 §8-3。层数按论文正文记 30；B&A96 原文页码级核验
  未达（出版商/ADS/存档/检索四路均不可达，过程与软件侧旁证随批存档于净室任务证据件
  ba96_deblend_layers_evidence.md），软件默认 32 见存疑清单；若后续原文确认 32，
  按 §4 条款重标定后全链改写。

### 6.1 CLEAN 门（B&A96 §5）

出处：Bertin & Arnouts 1996 — §5「Filtering the detections」：对邻星贡献做高斯外推
（邻星轮廓宽 × 系数 1.0–2.0），扣除邻星贡献后均值面亮度仍高于检测阈值方可入表。
用途：低阈值档（σ_psf=1.0 的 [52,65] 过渡区）抑制亮星翼内噪声峰误检。
规格备置：邻星贡献 Δμ = Σj [ Aj/(2π·sj²) · exp(−rj²/(2·sj²)) ]，
sj = c·FWHMj/2.3548，c ∈ [1.0, 2.0) 项目待标定；
判定 μ̄_residual > κ·σn。

### 6.3 DAOFIND roundness / sharpness 门

出处：Stetson 1987 — §II FIND：sharpness = (H(i0,j0) − d)/H(i0,j0) 族
（d 为中心像素与拟合区邻域均值之差、H 为零积分核响应峰高；原文 §II.E）；
roundness 由 x/y 两个一维高斯拟合峰高 hx, hy 构成（原文 §II.E–F；
OCR 未复得显式公式，按 DAOPHOT 语义补全 round = 2(hx − hy)/(hx + hy)——
坏行/坏列特征值 ±2 与星像 ≈0 与原文一致，§8-2）；
默认接受域论文明示 0.2 < sharp < 1.0、−1.0 < round < 1.0（原文 Fig. 2 caption）。
切换合同：以 O2 平滑图复算 sharp/round 需先按新核量纲重标定 O3 阈值表，再定双门域；
不接受在旧阈表上直接叠加新门。

## 8. 诚实边界与存疑清单

1. **[存疑-系数] YvV95 q² 项 1.4251（文献通行复现）vs 现行实现 1.4281**：
   未取到 Signal Processing 44(2) 原文页核对。本设计以真实实现做了量化探针（δ 冲激，
   σs=2.0，两变体各编一版独立实测）：峰值差 0.56%，|d|≤3 差 0.2–0.5%，d=4 差 1.1%，
   尾部随距离增大（d=8 10.6%、d=20 23.6%、d=60 84%），
   σeff(±100) 2.2666 vs 2.2919（差 1.1%）。**这不是无害笔误，是两个不同滤波器**。
   处置：重写**保持现行 1.4281**（行为冻结锚优先于引文值）；若后续原文核对确认论文为 1.4251，
   换系数属行为变更，须按 §4 重标定后再改。M42 等依赖平滑核逐位值的统计锚随重写新基线重取。
2. **[存疑-引文] Stetson 1987 roundness 显式公式**：PASP 99, 191 原文该式在 OCR 转述中缺失，
   本设计按 DAOPHOT 语义补全 2(hx − hy)/(hx + hy)，以原文「坏列 round≈±2、星像 ≈0」
   特征值旁证；sharpness 构造（d、H 定义与 0.2–1.0 默认域）为原文直得。
3. **[存疑-引文] DEBLEND_NTHRESH 32 vs 论文 30 层**：按论文正文 30 层实现；B&A96 原文
   页码级核验未达（出版商全文、ADS 扫描、存档快照、检索镜像四路均不可达；SEP/STScI 等

   ba96_deblend_layers_evidence.md 证据件）。软件默认 32 的差异不影响本设计的判据级验收
