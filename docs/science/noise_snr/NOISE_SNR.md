# 噪声、信噪比与不确定度

本册回答三个问题：逐像素的随机噪声怎么估；一个不依赖参考帧、跨帧可比的绝对信噪比怎么定义；不确定度怎么跨守恒映射、集成与投影导出传播。三者共用同一条物理口径，构成分册 P2（跨帧绝对信噪比）与 P4（重建稠密信噪比）的科学基础。

本册的量纲约定、跨阶段数据对象与科学目标分层在统一科学模型中给出 [17][18]；测光标定、星点检测与 PSF 建模由各自的分册负责；守恒映射的几何与积分由对应分册负责。本册只写物理口径、公式、参数与判据。

---

## 1 主题与目标与非目标

### 1.1 承载的物理量

本链同时承载**两个用途不同、量纲相同**的方差面，以及由它们派生的**一个绝对信噪比**与**一条协方差传播律**：

| 对象 | 含义 | 主要消费者 |
|---|---|---|
| 背景方差面 `variance_bg` | 空背景随机分量的逐像素方差（天光散粒、暗流散粒、读出、量化、偏置残差） | 天光建模、误差报告、诊断 |
| 加权方差面 `variance_w` | 该像素的总方差，额外含源光子散粒项 | 叠加与拟合的最优加权 |
| 绝对信噪比 `SNR = F_ref/σ_F` | 帧级标量与帧内稀疏控制点共用的量 | 稠密重建、逆方差定权 |
| 协方差传播律 `C_out = R C_in Rᵀ` | 线性重采样与积分下的不确定度传播 | 守恒映射、投影导出 |

两个方差面**各自独立、取值互不代用**：把背景方差面当加权方差面会系统性低估源受限像素的噪声、把权重抬高；把加权方差面当背景方差面会丢失「空背景随机分量」这一物理语义，使天光建模失去依据。

### 1.2 与创新点的对应

- **P2 跨帧绝对信噪比**由本册的绝对信噪比定义与逐源通量不确定度公式承载；
- **P4 重建稠密信噪比**消费本册的方差面与信噪比定义，把稀疏控制点重建为稠密场，重建算子与误差属算法分册；
- **P3 守恒映射**消费本册的方差与协方差传播律；
- **P5 加性天光去除**消费本册的方差面与其逆方差权重。

### 1.3 非目标

- 不估计测光零点残差散度、PSF 拟合质量、天体测量质量——这些是各自分册的量；
- 不生产完整协方差矩阵作为产品：产品面只发布方差对角线，完整协方差的适用边界见「协方差传播」一节；
- 不把 PSF 拟合质量代理、帧级质量权重、相对质量倍率写成科学叠加权重；
- 不为覆盖级不足、单帧不可分解等结构性缺口提供回退路径：遇到就是显式降级并具名登记。

## 2 物理模型

### 2.1 逐像素参考分解

校准后像素的测量值按物理来源分解为

```text
I = O + N_e/g + N_read ,      N_e = N_src + N_sky + N_dark
```

`I` 是像素测量值，`O` 是偏置，`N_e` 是光电子总数，`N_src`/`N_sky`/`N_dark` 分别是目标源、天光与暗电流贡献的光电子数，`N_read` 是读出噪声在 ADU 标度上的贡献，`g` 是增益。

**增益约定**：本链一律用 **e⁻/ADU**，`ADU = N_e/g`。文献里同一物理关系常写成 `I = O + g'·N_e + N_read` 的倒数形式，那里 `g'` 的单位是 ADU/e⁻ 且 `g' = 1/g`。两种约定各自具名；混用会让源项差 `g²` 倍。引用文献公式时先确认其约定并换算。

单帧只提供均值与方差两个可观测量，待分离的物理来源多于两个，因此单帧上的「分解」不成立为统计可辨识的分解，只能作为**归因**：把可观测量按物理来源指派到各项。分离的可行性依赖显式支撑先验（暗帧、平场、可信增益）与支撑先验之外的可辨识结构，二者的代数边界见「单帧可辨识性」一节。

### 2.2 噪声项分类学

**首要分类轴是时间**：每一项都必须是固定图案（帧间相关）或时变（逐帧独立）。**次要分类轴是信号依赖**，它给出可测的指纹：散粒项正比于信号、乘性项正比于信号平方、其余为常数项。三者在 log-log 斜率上分别对应 1、2、0，这是判别噪声项类型的唯一可执行判据，且必须配「真值无该项效应 ⇒ 斜率退化到预期值」的对照臂。

| 项 | 物理来源 | 方差形式（ADU²） | 帧内空间尺度 | 帧间相关性 | 随信号 | 落在背景方差面 | 落在加权方差面 |
|---|---|---|---|---|---|---|---|
| 源光子散粒 | 源光子到达的泊松统计 | `F·P(x,y)/g` | 逐像素（PSF 尺度） | 逐帧独立 | ∝ S | 否 | 是 |
| 天光光子散粒 | 夜天光（气辉、黄道光、月光散射、光污染）与光学散射 | `S_sky(x,y)/g` | 方差图大尺度；实现逐像素 | 逐帧变（月相、太阳角、气辉） | ∝ S_sky | 是 | 是 |
| 暗电流散粒 | 硅晶格热激发载流子 | `N_dark/g` | 方差图近常数；实现逐像素 | 逐帧变（温度、曝光） | 常数 | 是 | 是 |
| 读出噪声 | 输出放大器复位与源跟随器热噪声、低频漂移 | `(RN/g)²` | 方差图常数（多通道为分区常数） | 白噪声分量逐帧独立；低频分量帧间相关 | 常数 | 是 | 是 |
| 量化噪声 | ADC 均匀量化 | 常数项 | 方差图常数 | 逐帧独立 | 常数 | 是 | 是 |
| 偏置与本底残差 | 母版偏置平均后的残余、overscan 校正残余 | 常数项加确定性低频结构 | 常数加低频结构 | 帧间相关（同一母版） | 常数 | 是 | 是 |
| 暗电流非均匀（DSNU） | 暗流在像素间的非均匀 | 系统性项 | 固定图案 | 帧间相关 | ∝ 暗流 | 否 | 否 |
| 乘性响应（PRNU、平场残差） | 像素间量子效率差异、尘埃影、照明不均、母版平场自身噪声与拟合残差 | `(ε·S(x,y))²` | 逐像素白成分加低频成分 | 帧间相关（固定图案） | ∝ S² | 否 | 否 |
| 列固定图案 | 干涉条纹、时钟馈通 | 系统性项 | 高频周期 | 帧间相关 | ∝ S | 否 | 否 |
| 重采样相关 | 几何重采样与守恒映射权重核 | `C_out = R C_in Rᵀ` | 核尺度 | 由几何决定 | — | 已传播 | 已传播 |

**不属于方差项的量**：宇宙线、热像素、饱和、响应非线性是污染与确定性截断，由掩膜与裁剪处置，不能记进方差表。低频读出漂移只有定性描述，没有可引用的解析方差式。

`var ∝ mean` 的关系在高通量端不普适：近饱和处有效方差低于低通量斜率的外推，且相邻像素相关。把它当作全域成立的判据会低估近饱和像素的噪声。

天光扣除之后仍留在图像里的信号与噪声关系，其经典讨论见 [10]；该讨论的落点是扣除后的剩余项构成，不改变本册「分子只含源」的定权口径。

### 2.3 单帧可辨识性

取模型 `μ = t·(S + D + B)`、`V = f(μ)`，`f` 是均值的确定性函数。对 `θ_i ∈ {S, D, B}` 有 `∂μ/∂θ_i = ∂V/∂θ_i = t`，因而 Fisher 信息矩阵 `I = c·ones(3,3)`，**恒为秩 1**。零空间 `span{(1,−1,0), (1,1,−2)}` 上的移动不改变期望与方差。

由此得到四条硬边界：

- **多帧、已知增益、已知读噪方差、大幅改变曝光时长都不能打破该简并**；
- 唯一能把秩提到 2 的方式是改变**成分的相对比例**（加暗帧令源为零）；第二个不同曝光的暗帧不再提升秩；
- 源的分离依赖**支撑先验**（暗帧、平场、可信增益），不依赖任何单帧统计量；
- 单帧不可分离「天光」与「源」（同波段、同为位置函数）；多帧差分也不可（两者一起对消，只留噪声）。以低频背景网格作天光代理是近似，不是分离。

取模型 `V = σ₀² + S/g`（`σ₀²` 是全部常数项之和）时是 2 个未知量、1 个观测量：有亮源提供杠杆臂时可同时辨识 `1/g` 与 `σ₀²`。获取绝对增益需要平场对或可信的帧头增益，并且**平场对之前必须先扣除偏置**，否则斜率与截距同时有偏。

### 2.4 三条「缓变」谓词

「慢变」不是单一陈述，必须按谓词分开判决，每个谓词各自具名：

| 谓词 | 判决 | 依据 |
|---|---|---|
| 方差图 `σ²(x,y)` 在帧内可当常数 | 成立 | 逐像素估计自身有有限精度，方差图的结构由电平场的结构决定 |
| 噪声实现可当空间平滑 | 不成立（对全部随机项） | 各随机项的空间 lag-1 自相关在零附近 |
| 帧内常数或平面模型能把噪声移除 | 不成立 | 平面拟合只作用于方差图，不作用于噪声实现 |

**解析律**：方差图的相对散布等于电平场的相对散布；乘性响应项的方差正比于信号平方，其相对散布是该比例的两倍。**方差图的平滑度是它所跟随的电平场的性质，不是噪声自身的性质。**

据此，空间结构由控制点上的方差与一个低阶平面场承载；空间方差结构的判据是方差图的梯度，不是噪声实现的平滑度。

## 3 公式与推导

### 3.1 背景方差面：空背景稳健方差

估计在像素域进行，坐标为内部 0 基像素坐标，帧身份随帧产品唯一。

**稳健尺度**。空背景样本取中位绝对偏差并一致化到标准正态尺度：

```text
sigma_bg = MAD * kappa ,      kappa = 1 / Phi^{-1}(3/4) = 1.482602218505602
MAD      = median( | x - median(x) | )
```

`Phi^{-1}(3/4) = 0.6744897501960817`，在 IEEE 754 双精度下 `1/0.6744897501960817` 与 `1.482602218505602` 是同一个二进制浮点数（逐位相等）。四位截断写法 `0.6745` 与全精度值相对差 `1.52e-05`，只允许出现在「约等于」语境并标注该偏差。它与 10–90% 截尾均值到标准差的换算因子定义域不同（后者属 PSF 分册），两者不可互换。

**掩膜半径的物理导出**。掩膜的唯一目的是让天空样本「无源」。半径由「掩膜边缘的残余面亮度不超过 `k·sigma_bg`」导出：

```text
Gaussian:  r_local = sigma_p * sqrt( 2 * ln( F / ( 2 * pi * sigma_p^2 * k * sigma_bg ) ) )
Moffat β:  r_local = alpha * sqrt( ( F*(beta-1) / (pi*alpha^2*k*sigma_bg) )^(1/beta) - 1 )
           alpha = FWHM / ( 2 * sqrt( 2^(1/beta) - 1 ) )

r_i = clip( r_local(F_i, FWHM_i, k*sigma_bg), r_min, r_hard )
```

「掩膜半径与星亮度解耦」作为物理陈述不成立：同一半径下把最亮星通量提高两个量级，无偏所需半径按对数律增长。正确口径是**逐星半径**由源通量、PSF 尺度与天空预算导出。

半径下界 `r_min` 保证覆盖 PSF 核心；硬上界 `r_hard` 是保大 PSF 重翼的上限，不是操作默认半径。逐星通量或 PSF 尺度缺失时按两级回调降级：第一级用 `4·FWHM_i`，第二级退回统一硬上界，并在帧产品中置掩膜降级诊断标。

**天空预算**。掩膜后必须同时满足合格控制块数下限与天空样本数下限。合格度由 MAD 尺度的相对标准误控制，其渐近系数由下式给出。

设 `Y = |X|`，`X ~ N(0, σ²)`。`Y` 的中位数 `R` 满足 `P(Y ≤ R) = 2Φ(R/σ) − 1 = 1/2`，故 `R = d·σ`，`d = Phi^{-1}(3/4)`；`Y` 在该点的密度为 `f_Y(R) = 2·phi(d)/σ`。样本中位数的渐近方差为 `Var(R) ≈ 1/(4N f_Y(R)²) = σ²/(16 N phi(d)²)`。以 `sigma_bg = R/d` 代入，MAD 尺度估计量的相对标准误为

```text
SE(sigma_bg)/sigma_bg = c_se / sqrt(N) ,    c_se = 1 / ( 4 * phi(d) * d ) = 1.1663872874444212
```

`phi` 为标准正态密度。Monte Carlo 复核（标准正态样本、`N = 4096`）给出 `c_se·sqrt(N) = 1.1627`，随 `N` 增大收敛到解析值。

于是天空预算是

```text
SE(sigma_bg)/sigma_bg = c_se / sqrt(N_sky)  <=  target   =>   N_sky >= ( c_se / target )^2
```

`target` 是本链的**设计选择**而非物理常数，落配置；由此推出的天空样本数下限阈值同样落配置，其取值必须与所用 `target` 一致并随帧产品登记。本链默认阈值对应 `target ≈ 1.2%`。把这一系数以 dex 表述时必须除以 `ln 10 = 2.302585`：`SE_dex ≈ c_se/(ln10 · sqrt(N))`，两种口径相差 `ln 10` 倍，混用会把预算判据放大两倍以上。

**空间方差场**。控制点是合格块的方差，拟合一个低阶平面场：

```text
variance_bg(x, y) = a + b*x + c*y
```

三条约束保证「合格」二字的含义是可执行的：

- **控制点自校准**。块的 MAD 尺度必须量的是噪声而不是空间结构。判据取 `R = sigma_MAD / sigma_white-equiv`，其中 `sigma_white-equiv` 是相邻像素一阶差分的稳健尺度按 `1/sqrt(2)` 折算（差分把独立白噪声放大 `sqrt(2)` 倍）。纯噪声输入的 `R` 理论值为 1，这是恒等式而非标定值。`R` 显著大于 1 的块其「方差」被空间结构污染，进入拟合的是 `R` 不显著大于 1 的块。剔除用序统计量：取最大的 `k` 使 `ln R` 的相邻跳变超过保留主体自身的极差，剔除 `R` 最大的若干块；不存在这样的 `k` 时一个也不剔。块数不足以自校准时判据不武装，登记而不剔除。
- **结构非负**。线性函数在控制点凸包上的最小值在顶点取到，顶点是控制点子集，因此「对全部控制点非负」等价于「凸包内恒非负」。实现口径是**相对误差加权**（权重取 `(v_med/v_i)²`）加凸包非负硬约束；凸包外才是真正的边缘外推。
- **可审计性**。凸包内出现预测非正的面积占比必须严格等于 0 才是可审计的；0 是「结构非负」约束的定义值，不是可调阈值。

**几何退化判据**。空间场只在控制点数达下限且控制点几何张成二维时启用。判据取中心化点云 Gram 矩阵特征值比 `λ_lo/λ_hi ≥ 1/16`，等价于点云相对条件数 `κ = sqrt(λ_hi/λ_lo) ≤ 4`（无量纲）。不满足时退化为全局常量场，其触发面是**几何退化或合格控制点不足**，不是平面拟合缺陷。

**数值地板与三态**。产品面 `(variance, ivar)` 只有两态：**可用**（`variance > 0`、`ivar = 1/variance`，在输出精度内有限）与**不可用**（`variance = 0` 且 `ivar = 0`）。凡预测非正、或换算后的地板在该输出精度下不可表示、或方差下溢为 0 而逆方差上溢为非有限的像素，一律取不可用态，`(0, +inf)` 这类自相矛盾的对不在发布面上。地板的量纲是方差单位，其作用只是数值保护（保证可用方差的逆方差有限），不是物理常数；生效地板及其来源必须随帧产品登记。地板随数据标度换算时由消费侧承担：帧像素被线性缩放后方差按标度的平方换算，地板必须同时按同一因子换算。

**饱和电平**。达到饱和电平的像素是确定性截断，不是方差项，必须在进入空白背景统计前剔除。电平来源按优先级显式声明：配置显式值优先，其次是帧头的图像极值关键字 `DATAMAX`（FITS 标准定义的数组最大有效物理值 [16]）。`SATURATE` 之类的帧头约定关键词不在 FITS 标准正文中，只能作为显式声明来源使用。**未提供电平与「无饱和」是两种状态**，前者必须显式降级并具名登记，不能当作后者处理：5σ 裁剪的崩溃点是样本中位数，饱和核与源翼一旦占据多数控制块，裁剪与掩膜会同时失效。

**标度不变性**。像素值按 `x' = alpha · x` 线性缩放时，方差按 `alpha²` 换算、逆方差按 `alpha⁻²` 换算。该关系与守恒映射的归一化权重求和是同一件事的加权形式；守恒映射的归一分母与像素面积同量纲且与像素方差无关，因此缩放律在任一标度类别上都成立。

### 3.2 加权方差面：含源项的总方差

```text
variance_w(x, y) = variance_bg(x, y) + S_src(x, y) / g
```

`S_src(x,y)` 是该像素上源贡献的信号电平（ADU 标度，不含天光），由星点测光给出的源通量与 PSF 轮廓导出：

```text
S_src_hat(x, y) = sum_i  F_hat_i * P_i(x, y)
```

源项是本面与背景方差面的唯一区别。乘性与系统性项（DSNU、PRNU、列固定图案）不进入本面：它们属系统误差面，不是本层的随机加权方差。

**增益与读噪的来源按优先级显式声明**，取值面是多来源：

1. **本帧自估**。对帧内像素做 `V = sigma_0² + S/g` 的斜率–截距回归。这是 2 未知量、1 个观测量，**必须有跨足够宽信号量程的亮源杠杆臂**才能同时辨识；杠杆臂不足时回归不可辨识，必须判为不可得，弱杠杆臂上的拟合值属不可得态。回归前必须先扣除偏置。
2. **帧头关键字**。存在增益与读噪关键字时作独立交叉校验与可选覆盖。
3. **显式配置覆盖**。由调用方给出并随帧产品登记来源。

输入数据不保证提供增益与读噪关键字，因此**自估路径是主路径**，帧头读数是可选交叉校验。任一来源都不可得时本面必须显式降级并具名登记，退化为背景受限口径；降级状态随帧产品落溯源，与背景方差面的两态登记正交。可用状态的判据是数值路径实际读取该键，而不是「配置里有这个键」。

### 3.3 绝对信噪比

**逐源通量不确定度**。在 PSF 加权最优提取下，逐像素方差取加权方差面，对 PSF 轮廓加权求和：

```text
sigma_F^{-2} = sum_i  P_i^2 / sigma_i^2
SNR          = F_ref / sigma_F
```

`F_ref` 是该帧的参考通量，`sigma_F` 是同帧同源的 PSF 加权通量不确定度。它由星点测光产出：分子 `F` 与分母 `sigma_F` 必须来自同一份星点绑定行与同一个 PSF 模型。信噪比的标定基准只来自星点——PSF 与孔径测光的精度离散程度，以及 PSF 加权最优提取给出的 `sigma_F`；「从信号里把噪声分离出来」不成立，理由见「单帧可辨识性」。

**逐像素方差组装**。逐像素方差按 ADU 标度组装为

```text
sigma_i^2 = sigma_sky^2 + (RN/g)^2 + F * P_i / g
```

其中天空项的语义必须二选一并显式声明：

- `shot_noise_only`：只含天光与暗流的散粒噪声，此时叠加 `(RN/g)^2`；
- `empirical_total_rms`：是经验总均方根、已含读噪噪声，此时**不再叠加** `(RN/g)^2`。

声明与实际来源不一致时显式失败。把含读噪的经验总均方根填进散粒项、又在增益可用时叠加读噪项，是双重计数，会高估通量不确定度。

**信号经独立局部背景估计与扣除**，天光只通过其散粒噪声进入噪声项。在探测器未饱和、噪声估计由天光散粒主导的成立域内，固定源通量下天光越亮信噪比越低并趋于零：分母随天光开方增长而分子不变。

**逐像素信噪比**是上式在像素粒度上的形式：

```text
I(x,y)            = S_src(x,y) + S_sky(x,y) + N_local(x,y)
variance_slow(x,y) = Var[N_local] + S_sky(x,y)/g
variance_w(x,y)    = variance_slow(x,y) + S_src(x,y)/g
SNR(x,y)           = S_src(x,y) / sqrt(variance_w(x,y))
```

**分子只有源**：天光只经散粒噪声进入分母。把天光电平或观测电平计入分子，就得到一个随天光上升的量，与信噪比的定义相反。该逐像素模型的有效域由「源稀疏」先验划定：源必须能被有限个 PSF 模板张成、天光必须落在参考面的张成空间内、背景采样点必须落在源掩膜之外，三条同时成立。延展发射不在点源张成空间内，该域必须显式声明模型不适用。

**帧级科学基准**。唯一允许的帧级科学摘要是 5σ 点源深度

```text
m_5 = ZP - 2.5 * log10( 5 * sigma_F(ref) )
```

其中 `sigma_F(ref)` 必须显式绑定参考轮廓、孔径、背景估计域与像素标度。它由信噪比定义与星等定义直接导出：令 `SNR = 5` 解出 `F` 再换算星等。空间变化时应给深度图而非单标量。

**帧级标量与稀疏控制点是两个独立对象**，共用同一定义与同一逐帧参考通量；帧级标量不作为稀疏层的尺度基准，也不参与稀疏层的还原。

### 3.4 定权：逆方差与信息量

**叠加权重是消费时现场换算的派生量**，不是预先算好落盘的字段。三个重建方式（帧内稠密、稀疏控制点重建、帧级标量铺满）产出的都是同一个物理量 `SNR = F_ref/sigma_F` 的稠密表示，只是来源不同；它们都走同一条定权式：

```text
w = SNR^2 / F_ref^2  =  1 / sigma_F^2
```

这个换算是**代数恒等**：`SNR` 的分子就是 `F_ref`，平方后除以 `F_ref²` 恰好约掉。它是定义式重述，恒成立、零鉴别力，**不承担实现正确性判据**。把指数写成 `w = SNR^gamma/F_ref^gamma` 时，`gamma = 2` 由这条恒等式唯一确定，不是待标定参数；`gamma ≠ 2` 等于放弃广义最小二乘的最优性。

归一化因子 `F_ref²` 必须显式带上：裸 `SNR²` 不是权重。

**严格信息量口径**。在统一线性模型 `d_k = A_k x + n_k`、`Cov(n_k) = C_k` 下，点源通量的最优估计与信息量为

```text
Q_k = a_k * P_k^T * C_k^{-1} * d_k
W_k = a_k^2 * P_k^T * C_k^{-1} * P_k
F_hat = sum_k Q_k / sum_k W_k ,      Var(F_hat) = 1 / sum_k W_k
```

白噪声与平坦权重的近似下 `W_k = a_k^2 / (sigma_pix,k^2 * A_NEA,k)`，`A_NEA,k = 1 / sum_p P_k,p^2` 是噪声等效面积。`W_k` 就是 `1/sigma_F,k^2`：定权式取的是同一物理量，只是从信噪比一侧写。

**组合律**。独立帧时 `Q`、`W`、`F_hat`、`Var` 逐帧求和；相关帧必须使用联合协方差阵，简单求和系统性偏乐观。

**关于「信噪比平方之和」这一形式**。把它拆成两种参考通量口径，可以看清它为什么不能当判据：

- 在**组公共参考通量**口径下（各帧 `F_ref` 取同一值），`sum_k SNR_k^2 = F_ref^2 * sum_k W_k`，而 `Var(F_hat) = 1/sum_k W_k`。所以该式就是组合律的定义式重述，对任何可达输入恒成立，结构上不可能给出判决。
- 在**逐帧参考通量**口径下（本链的生产口径，`SNR_k` 的分子是各帧自己的参考通量），组内没有公共锚，`sum_k SNR_k^2` 不对应任何单一绝对信噪比的平方，没有定义、无法计算、无法判定。

两种口径下它都不能充当实现正确性判据。承载证据的判据是**点源信息量**：`Var(F_hat) = 1/sum_k W_k` 与实测通量散度对拍，参照量取自权重之外，因而有鉴别力。

**跨帧可比性的硬约束**。`w` 对参考星等不变当且仅当 `sigma_F` 与 `F_ref` 无关。由于逐像素方差含源光子散粒项，`sigma_F` 是被加权量亮度的函数：在天光受限臂上权重对参考电平漂移在机器精度级，在源主导臂上则随参考电平单调变化。**漂移是被加权量随源亮度变化的结果，不是归一相消被破坏。** 跨帧比对必须限定在同一参考电平档内，天光受限档与源主导档不可混比。

**拟合权重与堆叠权重是两个量**。带杠杆 `h` 的拟合值方差为 `sigma² h`，不能按 `1/sigma²` 当独立测量堆叠；等杠杆时两者严格等价。稳健拟合（Huber 迭代重加权）在离群下显著压低偏差，干净数据上不损失。

**口径边界**（以下写法不成立）：

- 用 `signal²` 反算或校验产品方差：数值等式 `variance = signal²` 只在纯泊松散粒主导、且信号以期望计数表述时成立；完整噪声模型含与信号无关的常数项，信号趋零时方差不趋零；
- 在未登记增益来源与降级状态的帧上，声称加权方差面是「绝对」口径；
- 把无量纲的质量复合量写入逆方差面；
- 以检测到多少颗星一类偶然因素参与定权。

### 3.5 协方差传播

重采样与积分都是线性算子 `R`，不确定度按二次型传播：

```text
C_out = R * C_in * R^T
```

**逐像素方差是这一传播在对角输入下的特例**。守恒映射中源像素 `j` 对输出像素 `p` 的权重记作 `w_jp`，输出方差为

```text
variance_p = sum_j  v_j * w_jp^2  /  N_p^2
```

`N_p` 是归一分母，量纲与面积同阶且与像素方差无关 [19]。这一写法有两个等价参数化：分母用 `N_p²`，或等价地写成 `sum_j v_j * w_jp^2 * k² / D_p²`（`k = D_p/N_p`，`D_p = sum_j a_jp` 为命中面积）。两者数值相同；漏掉 `k²` 会把方差压低 `pixfrac⁴` 倍。

**相邻输出像素不严格独立**。守恒映射自身的噪声与像素相关讨论见 [9]。同一源像素贡献多个输出像素时

```text
Cov(S_p, S_q) = sum_j  c_jp * c_jq * v_j
```

产品面只发布方差对角线，完整协方差矩阵不作为产品交付。因此：

- 用产品方差做孔径或测量误差时**必须显式加入协方差项**。孔径方差不等于逐像素方差之和；
- 只按 `sum_k c_k^2 u_k` 计算，等价于假设输入协方差对角，系统性低估输出方差。设参与重叠的有效像素数为 `M_eff`，近邻近似下偏差因子为 `1 + rho*(M_eff - 1)`（四抽头核对应 `M_eff = 4`）；
- `sum_k c_k² ≠ 1` 是正确物理：重采样对独立像素方差有降噪作用，但引入相邻相关，输出方差的归一因子因此不为一。

**控制点估计量的方差**。天光平面的控制估计量是干净背景块上的中位数，其方差不是单叶像素方差。设样本独立同分布、中位数邻域密度连续可微，则样本中位数的渐近方差为 `1/(4 N f(m)^2)`；对高斯边际 `f(m) = 1/(sigma*sqrt(2*pi))`，代入得 `Var(median) = pi*sigma^2/(2 N)`。控制点方差因此写作

```text
control_variance = k_corr * (pi/2) * sigma_bg^2 / N_retained
control_ivar     = 1 / control_variance
```

其中 `N_retained` 是裁剪后保留的样本数。相关校正因子 `k_corr` 表征有效样本量小于保留样本数，由有限样本的中位数估计器偏置与守恒映射造成的输出像素相关两部分构成，取值域严格大于 1；因子分解式与查表的证据由守恒映射实验单元承载 [20][23]。`k_corr` 等于 1 等价于忽略相关，必须显式拒绝。该式的适用域与 `sigma_bg` 的前提一致：样本独立同分布且块内无未分辨空间结构。前提被违反时 `sigma_bg` 量的是空间结构而非随机分量，`control_variance` 与 `control_ivar` 一并失真，该块必须显式降级并登记。

**无覆盖与缺数**。无覆盖、无有效样本、输入方差缺项时输出取 NaN，不以 0 或无穷冒充；输入方差非有限属产品损坏，显式失败。零权重的哨兵值在阶段间的语义不同：阶段一产品面把零逆方差定义为不可用并强制成对方差为零，投影导出读入时把同一值读作零权重，输出取 NaN 传播态。

## 5 判据与误差

### 5.1 判据必须能红

每条判据都配正例（真值有效应）与负例（注入对应缺陷）两臂，且负例必须真的把门变红。以下是本层不可省的四组。本层判据的仓内实验证据与全部读数由绝对信噪比实验单元承载 [21]。

- **空白背景恢复**。高斯合成空背景上，稳健尺度在冻结容差内复现注入的标准差。
- **方差场恢复**。注入低阶平面方差场，拟合系数在容差内复现。逐像素真值必须显式含块内电平梯度项，否则对强梯度帧过严。
- **源污染**。注入带星帧，检查掩膜后稳健尺度偏差在容差内，且合格块数与天空样本数满足预算。负例：固定过小半径而源足够亮时必须判红；半径对源通量与 PSF 尺度不单调时必须判红。
- **饱和域**。注入饱和平台，检查权场中位数方差下降、帧平均逆方差上升。负例：未提供饱和电平时必须存在显式降级声明，声明本身要可读、两种状态必须可区分。

### 5.2 判据不得恒真

空间权重与尺度场的精度判据用**权重效率损失**

```text
E = Var_w / Var_opt - 1
```

`E = 0` 当且仅当估计的尺度正比于真值尺度，全局尺度相消。该判据对「帧级标量对空间场的均方根不超过常数倍尺度场」一类说法具有鉴别力，后者对任意真值场恒真。

**`E` 对整体乘性偏差完全免疫**，因为它由权重比值定义。两条臂可以有完全相同的 `E` 而水平偏差相差数倍。因此选型与验收**必须同时报告 `E` 与水平偏差**，「`E` 相同」只允许推出「`E` 相同」。

「各臂必须收敛」类判据在某些臂上恒真、在另一些臂上恒假，不携带信息。真值无源时的归零判据必须逐臂书写：完整臂与漏源项臂在无源帧上应逐位相同，且源项估计归零；天光被双重计入的臂**不收敛**，这正是它确实双计的证据，不是判据失效的证据。每个归零判据都必须配一个在有源帧上显著偏离的对照臂，否则没有证据资格。

### 5.3 适用域与失效域

- 背景方差面以天空为主的控制块为前提。帧含大面积未分辨结构、强梯度或弥散源时，块尺度量的是结构而不是随机噪声，该域必须走空间场或显式降级，标量场限于其适用域。
- 加权方差面的绝对性依赖增益来源；未登记来源与降级状态时只能声称背景受限口径。
- `var ∝ mean` 在近饱和端不成立；该域的权重须由实测标定或显式降级给出。
- 逐像素信噪比模型在延展发射域不适用；端到端误差由分子侧（检测完备性与 PSF 尺度）主导，分母侧的方差模型在该情形下仍成立。
- 孔径误差、面亮度统计与深度估计都不在产品方差面内，须显式叠加协方差项或另行建模。

### 5.4 误差传播的登记面

每帧必须落盘的噪声面观测量：生效的尺度与地板及其来源、掩膜降级状态、饱和过滤状态、控制点方差动态范围、平面系数、凸包内预测非正的面积占比、被剔除的块数与 `R` 的分布、退化触发原因。缺任一项，该帧的方差面不可审计，按显式失败处置。

## 6 与上下游的关系

### 6.1 输入

| 来自 | 贡献 |
|---|---|
| 校准分册 | 偏置、暗流、平场的扣除结果与母版不确定度 |
| 星点检测与 PSF 分册 | 星点位置、逐星通量与 PSF 尺度（掩膜半径、源面 `S_src` 的输入） |
| 测光分册 | 统一测光坐标系下的信号标度与零点 |
| 帧头与配置 | 增益、读噪、饱和电平、掩膜与预算阈值 |

### 6.2 输出

| 对象 | 交付形态 | 消费者 |
|---|---|---|
| `variance` / `ivar` | 帧级与球面产品的方差面与逆方差面 | 天光平面拟合、集成、导出 |
| `frame_snr` | 帧级绝对信噪比标量，写入产品头 | 帧级重建口径、帧级摘要 |
| `sparse_snr_layer` | 帧内稀疏控制点处的绝对信噪比 | 稠密重建 |
| `point_information` | 点源通量估计的逆方差 | 点源目标的严格权重 |
| `depth_m5` | 5σ 点源深度（空间变化时给深度图） | 帧级质量摘要、筛选 |

权重不是输出对象：它在集成时由绝对信噪比与参考通量现场换算，标准化与投影导出两阶段都不产生、不消费权重。

三种重建方式各有适用域，同时有效：稀疏重建在方差图有空间结构、源污染低的域上占优，帧级标量在高对比结构域上占优，帧内稠密是精度基准。三者的取舍与存储代价由重建实验单元承载 [22]。

### 6.3 精度归属

方差与覆盖面等稠密大面默认单精度；帧级信噪比、WCS 解、星表匹配、测光定标与运行清单全程双精度。JSON 显式指定位深时以 JSON 为准。逐像元不确定度的数值路径本身全程双精度。

### 6.4 质量面与信息面的分离

帧级质量权重、PSF 拟合质量代理、相对质量倍率是**质量面**的量，无量纲，只作采样与诊断；`1/Var(F_hat)`、点源信息量与逆方差是**信息面**的量，承载科学权重。两面各自的量不得互相冒充，也不得相互代用。同名字段必须分别命名：`frame_snr` 指产品头里的科学量（未加权原始信噪比），质量面的对应量另有其名。
