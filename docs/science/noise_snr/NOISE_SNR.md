# 噪声、信噪比与不确定度

本册回答三个问题：逐像素的随机噪声怎么估；一个不依赖参考帧、跨帧可比的绝对信噪比怎么定义；不确定度怎么跨守恒映射、集成与投影导出传播。三者共用同一条物理口径，构成分册 P2（跨帧绝对信噪比）与 P4（重建稠密信噪比）的科学基础。

本册的量纲约定、跨阶段数据对象与科学目标分层在统一科学模型中给出 [18][19]；测光标定、星点检测与 PSF 建模由各自的分册负责；守恒映射的几何与积分由对应分册负责。本册只写物理口径、公式、参数与判据。

---

## 1 主题、目标与非目标

### 1.1 承载的物理量

本链同时承载**两个用途不同、量纲相同**的方差面，以及由它们派生的**一个绝对信噪比**与**一条协方差传播律**：

| 对象 | 含义 | 主要消费者 |
|---|---|---|
| 背景方差面 `variance_bg` | 空背景随机分量的逐像素方差（天光散粒、暗流散粒、读出、量化、偏置残差） | 天光建模、误差报告、诊断 |
| 加权方差面 `variance_w` | 该像素的总方差，额外含源光子散粒项 | 叠加与拟合的最优加权 |
| 绝对信噪比 `SNR = F_ref/σ_F`（无量纲；分子分母同取帧面 ADU 标度，数值仅在同一 `m_ref` 档内可比） | 帧级标量与帧内稀疏控制点共用的量 | 稠密重建、逆方差定权 |
| 协方差传播律 `C_out = R C_in Rᵀ` | 线性重采样与积分下的不确定度传播 | 守恒映射、投影导出 |

两个方差面**各自独立、取值互不代用**：把背景方差面当加权方差面会系统性低估源受限像素的噪声、把权重抬高；把加权方差面当背景方差面会丢失「空背景随机分量」这一物理语义，使天光建模失去依据。量纲数值声明：本册方差面量纲为 ADU²，通量与标准差量纲为 ADU，`SNR` 无量纲，像素坐标取内部 0 基像素计，计数类阈值无量纲。

### 1.2 与创新点的对应

- **P2 跨帧绝对信噪比**由本册的绝对信噪比定义与逐源通量不确定度公式承载；
- **P4 重建稠密信噪比**消费本册的方差面与信噪比定义，把稀疏控制点重建为稠密场，重建算子与误差属算法分册；
- **P3 守恒映射**消费本册的方差与协方差传播律；
- **P5 加性天光去除**消费本册的方差面与其逆方差权重。

### 1.3 非目标

- 不估计测光零点残差散度、PSF 拟合质量、天体测量质量——这些是各自分册的量；
- 不生产完整协方差矩阵作为产品：产品面只发布方差对角线，完整协方差的适用边界见「协方差传播」一节；
- 不把 PSF 拟合质量代理、帧级质量权重、相对质量倍率写成科学叠加权重；
- 不为覆盖级不足、单帧不可分解等结构性缺口提供**静默**回退路径：存在可行收缩的按收缩后正常产出，收缩后仍不满足的显式降级并具名登记，无可行收缩的整帧显式失败；三档的判据见「背景方差面」一节。

## 2 物理模型

### 2.1 逐像素参考分解

校准后像素的测量值按物理来源分解为

```text
I = O + N_e/g + N_read ,      N_e = N_src + N_sky + N_dark
```

`I` 是像素测量值，`O` 是偏置，`N_e` 是光电子总数，`N_src`/`N_sky`/`N_dark` 分别是目标源、天光与暗电流贡献的光电子数，`N_read` 是读出噪声在 ADU 标度上的贡献，`g` 是增益。

**增益约定**：本链一律用 **e⁻/ADU**，`ADU = N_e/g`。文献里同一物理关系常写成 `I = O + g'·N_e + N_read` 的倒数形式，那里 `g'` 的单位是 ADU/e⁻ 且 `g' = 1/g`。两种约定各自具名；混用会让源项差 `g²` 倍。引用文献公式时先确认其约定并换算。

**本链约定的一手对照与版本敏感**。同一物理关系在独立实现中有两种写法，其量纲都由实现方写死：LSST `ip_isr` 的 `updateVariance` 逐字作 `var /= gain` 后 `var += (readNoise/gain)**2`，docstring 记 `gain` 单位 electron/adu、`readNoise` 单位 electron/pixel [14]；photutils 的 `calc_total_error` 逐字作 `sqrt(bkg_error^2 + source_variance)`，其中 `source_variance /= effective_gain`，docstring 记 `sigma_tot² = sigma_bkg² + I/g_eff` [13]。**引用必须钉版本**：`ip_isr` 的全部正规 release（10.0–17.0）用的是 `var += readNoise**2` 且 `readNoise` 单位为 ADU/pixel，与上式差一个 `g²`。背景项与总误差方程的经典推导见 [10]。

单帧只提供均值与方差两个可观测量，待分离的物理来源多于两个，因此单帧上的「分解」不成立为统计可辨识的分解，只能作为**归因**：把可观测量按物理来源指派到各项。分离的可行性依赖显式支撑先验（暗帧、平场、可信增益）与支撑先验之外的可辨识结构，二者的代数边界见「单帧可辨识性」一节。

### 2.2 噪声项分类学

**首要分类轴是时间**：每一项都必须是固定图案（帧间相关）或时变（逐帧独立）。**次要分类轴是信号依赖**，它给出可测的指纹：散粒项正比于信号、乘性项正比于信号平方、其余为常数项。三者在 log-log 斜率上分别对应 1、2、0，这是判别**信号依赖**这一维的唯一可执行判据（判别**时间相关性**这一维用帧内空间尺度的指纹：读噪白分量 lag-1 自相关趋零、列固定图案是高频周期、DSNU 是固定图案），且必须配「真值无该项效应 ⇒ 斜率退化到预期值」的对照臂。

**随机方差项**（进入方差面，量纲 ADU²）：

| 项 | 物理来源 | 方差形式（ADU²） | 帧内空间尺度 | 帧间相关性 | 随信号 | 落在背景方差面 | 落在加权方差面 |
|---|---|---|---|---|---|---|---|
| 源光子散粒 | 源光子到达的泊松统计 | `F·P(x,y)/g` | 逐像素（PSF 尺度） | 逐帧独立 | ∝ S | 否 | 是 |
| 天光光子散粒 | 夜天光（气辉、黄道光、月光散射、光污染）与光学散射 | `S_sky(x,y)/g` | 方差图大尺度；实现逐像素 | 逐帧变（月相、太阳角、气辉） | ∝ S_sky | 是 | 是 |
| 暗电流散粒 | 硅晶格热激发载流子 | `N_dark/g²` | 方差图近常数；实现逐像素 | 逐帧变（温度、曝光） | 常数 | 是 | 是 |
| 读出噪声 | 输出放大器复位与源跟随器热噪声、低频漂移 | `(RN/g)²` | 方差图常数（多通道为分区常数） | 白噪声分量逐帧独立；低频分量帧间相关 | 常数 | 是 | 是 |
| 量化噪声 | ADC 均匀量化 | 常数项 | 方差图常数 | 逐帧独立 | 常数 | 是 | 是 |
| 偏置与本底残差 | 母版偏置平均后的残余、overscan 校正残余 | 常数项 | 常数加确定性低频结构 | 帧间相关（同一母版） | 常数 | 是 | 是 |

**系统误差项**（不进入方差面，以方差代理或结构描述给出）：

| 项 | 物理来源 | 方差代理（ADU²） | 帧内空间尺度 | 帧间相关性 | 随信号 | 处置 |
|---|---|---|---|---|---|---|
| 暗电流非均匀（DSNU） | 暗流在像素间的非均匀 | 暗流的面密度起伏，量纲为「相对暗流比例² × 暗流电平」 | 固定图案 | 帧间相关 | ∝ 暗流 | 平场校正 / 逐像增益 |
| 乘性响应（PRNU、平场残差） | 像素间量子效率差异、尘埃影、照明不均、母版平场自身噪声与拟合残差 | `(ε·S(x,y))²` | 逐像素白成分加低频成分 | 帧间相关（固定图案） | ∝ S² | 平场校正 / 增益图 |
| 列固定图案 | 干涉条纹、时钟馈通 | 条纹幅度平方，逐列常数 | 高频周期 | 帧间相关 | ∝ S | 列向去周期 |
| 重采样相关 | 几何重采样与守恒映射权重核 | `C_out = R C_in Rᵀ` | 核尺度 | 由几何决定 | — | 已传播 |

**不属于方差项的量**：宇宙线、热像素、饱和、响应非线性是污染与确定性截断，由掩膜与裁剪处置，不能记进任何一张表。低频读出漂移只有定性描述，没有可引用的解析方差式。掩膜是本层**按源通量与 PSF 尺度派生**出来的对象而非独立输入，其半径导出式、降级档与生效参数必须随帧产品落盘，下游据此才能回溯掩膜是否生效。

`var ∝ mean` **不是全域判据**，本链只在**非饱和、线性响应、且已扫区间内的信号量程**域内用它做外推，已扫区间指绝对信噪比实验单元实际注入的信号量程，区间外不作外推断言；外推必须配负例：注入带饱和平台的帧，若该域内有效方差低于低通量斜率的外推**且**相邻像素出现正相关，两项都被观测到时该帧的 `var ∝ mean` 外推判为失效，按显式降级处置并登记。在该负例给出实测读数之前，此失效域只作待证断言，不得当作已验证的结论。

天光扣除之后仍留在图像里的信号与噪声关系，其经典讨论见 [10]；该讨论的落点是扣除后的剩余项构成，不改变本册「分子只含源」的定权口径。

### 2.3 单帧可辨识性

取模型 `μ = t·(S + D + B)`、`V = f(μ)`，`f` 是均值的确定性函数。对 `θ_i ∈ {S, D, B}` 有 `∂μ/∂θ_i = ∂V/∂θ_i = t`，因而 Fisher 信息矩阵 `I = c·ones(3,3)`，**恒为秩 1**。零空间 `span{(1,−1,0), (1,1,−2)}` 上的移动不改变期望与方差。

由此得到四条硬边界：

- **多帧、已知增益、已知读噪方差、大幅改变曝光时长都不能打破该简并**；
- 唯一能把秩提到 2 的方式是改变**成分的相对比例**（加暗帧令源为零）；第二个不同曝光的暗帧不再提升秩；
- 源的分离依赖**支撑先验**（暗帧、平场、可信增益），不依赖任何单帧统计量；
- 单帧不可分离「天光」与「源」（同波段、同为位置函数）；多帧差分也不可（两者一起对消，只留噪声）。以低频背景网格作天光代理是近似，不是分离。

取模型 `V = σ₀² + S/g`（`σ₀²` 是全部常数项之和）时是 2 个未知量、1 个观测量：有亮源提供杠杆臂时可同时辨识 `1/g` 与 `σ₀²`。获取绝对增益需要平场对或可信的帧头增益，并且**平场对之前必须先扣除偏置**——但扣除偏置的原因是**截距**有偏，不是斜率有偏。设未扣偏置的测量电平为 `X = O + S`，则

```text
V = sigma_0^2 + (X - O)/g = (1/g)·X + ( sigma_0^2 - O/g )
```

即 `dV/dX = 1/g` **严格不变**，只有截距从 `σ₀²` 平移到 `σ₀² − O/g`。因此**增益估计不受加性偏置扣除精度影响**，而读出噪声基准 `σ₀²` 受 `O/g` 的扣除残差直接影响。只有当偏置误差是**乘性**的、工作点接近饱和或响应非线性、或裁剪阈值依赖于被偏置抬高的样本中位数时，斜率才会被偏置。

### 2.4 三条「缓变」谓词

「慢变」不是单一陈述，必须按谓词分开判决，每个谓词各自具名：

| 谓词 | 判决 | 依据 |
|---|---|---|
| 方差图 `σ²(x,y)` 在帧内可当**缓变场** | 成立 | 逐像素估计自身有有限精度，方差图的结构由电平场的结构决定；因此要判的不是「帧内是否常数」，而是「是否可由低阶平面场忠实承载」 |
| 噪声实现可当空间平滑 | 不成立（对全部随机项） | 「lag-1 趋零」是**读噪白分量**的指纹，不是对全部随机项的断言：列固定图案是高频周期、暗流非均匀是固定图案、乘性响应是空间缓变场，三者的 lag-1 都不趋零。判读须在逐项实测的自相关曲线上取，不得以「方差图的结构来自电平场」替代 |
| 帧内常数或平面模型能把噪声移除 | 不成立 | 平面拟合只作用于方差图，不作用于噪声实现 |

**解析律**：在方差**正比于**电平的域内（散粒项主导，即 `(RN/g)²` 与量化项可忽略），方差图的相对散布等于电平场的相对散布；乘性响应项的方差正比于信号平方，其相对散布是该比例的两倍。背景方差面含 `(RN/g)²` 常数项时该律不再成立：设 `var = a + b·S`（`a > 0`），则

```text
sd(var)/mean(var) = b·sd(S)/( a + b·mean(S) )  <  sd(S)/mean(S)
```

即常数项使方差图的相对散布**严格小于**电平场的相对散布。**方差图的平滑度是它所跟随的电平场的性质，不是噪声自身的性质。**

据此，空间结构由控制点上的方差与一个低阶平面场承载；空间方差结构的判据是方差图的梯度，不是噪声实现的平滑度。

## 3 公式与推导

### 3.1 背景方差面：空背景稳健方差

估计在像素域进行，坐标为内部 0 基像素坐标，帧身份随帧产品唯一。

**稳健尺度**。空背景样本取中位绝对偏差并一致化到标准正态尺度：

```text
sigma_bg = MAD * kappa ,      kappa = 1 / Phi^{-1}(3/4) = 1.482602218505602
MAD      = median( | x - median(x) | )
```

`Phi^{-1}(3/4) = 0.6744897501960817`，在 IEEE 754 双精度下 `1/0.6744897501960817` 与 `1.482602218505602` 是同一个二进制浮点数（逐位相等）。四位截断写法 `0.6745` 与全精度值相对差 `1.52e-05`，只允许出现在「约等于」语境并标注该偏差。它与 10–90% 截尾均值到标准差的换算因子定义域不同（后者属 PSF 分册），两者不可互换。

**掩膜半径的物理导出**。掩膜的唯一目的是让天空样本「无源」。半径由「掩膜边缘的残余面亮度不超过 `k·sigma_bg`」导出。该判据在**电平侧**记账：残余电平 `S_res = k·sigma_bg`（ADU）自身贡献的泊松方差是 `S_res/g = k·sigma_bg/g`，相对背景尺度的占比为 `k/(g·sigma_bg)`——**不是 `k²`**，因为 `k·sigma_bg` 是电平、`k²·sigma_bg²` 是把电平再平方；

```text
Gaussian:  r_local = sigma_p * sqrt( 2 * ln( F / ( 2 * pi * sigma_p^2 * k * sigma_bg ) ) )
Moffat β:  r_local = alpha * sqrt( ( F*(beta-1) / (pi*alpha^2*k*sigma_bg) )^(1/beta) - 1 )
           alpha = FWHM / ( 2 * sqrt( 2^(1/beta) - 1 ) )

r_i = clip( r_local(F_i, FWHM_i, k*sigma_bg), r_min, rmax )
```

两支都用**总通量归一**：令 `∫ 2πr·profile(r) dr = F` 解出峰值系数。Gaussian 支的系数 `(2πσ_p²)⁻¹` 满足 `∫(2πσ²)⁻¹ exp(−r²/2σ²) dA = 1`；Moffat 支的峰值系数是 `F(β−1)/(πα²)`，由 `∫₂πr·C(1+(r/α)²)^{−β} dr = C·πα²/(β−1) = F` 解出。两支约定一致。

`r_local` 的**定义域逐支给出**：Gaussian 支要求 `F > F_crit = 2·pi·sigma_p²·k·sigma_bg`；Moffat 支要求 `F > F_crit = pi·alpha²·k·sigma_bg/(beta−1)`，它随 `alpha²` 增大、随 `beta` 减小，与 Gaussian 支**不是同一个量**。`F ≤ F_crit` 时该支无实解，实现必须在 `r_local` 内以显式判据返回不可解标记，不得让 `NaN` 进入 `clip`（`clip` 不吸收 `NaN`）。该情形取 `r_min`——此时残余面亮度在任何半径下都已满足判据，`r_min` 只是 PSF 核心覆盖下限——并置独立于「逐星通量缺失」「PSF 尺度缺失」两级回调的**第三种**降级诊断标。

「掩膜半径与星亮度解耦」作为物理陈述不成立：同一 PSF 尺度下把最亮星通量提高两个量级，无偏所需半径随 `F` 单调增大——Gaussian 支为 `sqrt(2 ln F)` 的形式（Moffat 支为 `F^{1/(2β)}`，`β = 2.5` 时是 `F^{0.2}` 的幂律）。正确口径是**逐星半径**由源通量、PSF 尺度与天空预算导出。

半径下界 `r_min` 保证覆盖 PSF 核心；硬上界 `rmax` 是保大 PSF 重翼的上限，不是操作默认半径。逐星通量缺失、PSF 尺度缺失、或 `F_i ≤ F_crit` 三种情形各置**一档具名降级诊断标**：前两级回调为第一级用 `4·FWHM_i`、第二级退回统一硬上界；`F_i ≤ F_crit` 的一级直接取 `r_min`。掩膜半径的降级状态随帧产品落盘。

天空样本预算不足时的处置分三档，不得由「一律降级」一语覆盖：存在可行收缩（逐块收紧掩膜半径并复检）时按收缩后结果正常产出；收缩生效后仍不满足下限时本帧显式降级并具名登记；**不存在可行收缩时整帧显式失败**，不得带着不足的天空样本继续产出方差面。

**天空预算**。掩膜后必须同时满足合格控制块数下限与天空样本数下限。合格度由 MAD 尺度的相对标准误控制，其渐近系数由下式给出。

设 `Y = |X|`，`X ~ N(0, σ²)`。`Y` 的中位数 `R` 满足 `P(Y ≤ R) = 2Φ(R/σ) − 1 = 1/2`，故 `R = d·σ`，`d = Phi^{-1}(3/4)`；`Y` 在该点的密度为 `f_Y(R) = 2·phi(d)/σ`。样本中位数的渐近方差为 `Var(R) ≈ 1/(4N f_Y(R)²) = σ²/(16 N phi(d)²)`。以 `sigma_bg = R/d` 代入，MAD 尺度估计量的相对标准误为

```text
SE(sigma_bg)/sigma_bg = c_se / sqrt(N) ,    c_se = 1 / ( 4 * phi(d) * d ) = 1.1663872874444212
```

`phi` 为标准正态密度。Monte Carlo 复核取标准正态样本、`N = 4096`、每档 `R = 4000` 次重复，读数是 `c_se` 本身的蒙特卡洛估计：

```text
读数 = sqrt(N) · sd( sigma_bg ) / sigma        （sd 取 R 次重复的样本标准差，不是均值的标准误）
```

固定随机种子 20240901–20240904 得 `1.14684 / 1.16790 / 1.16411 / 1.17040`，四档均值 `1.16231`，落在解析值 `c_se = 1.1663872874444212` 的种子间散布 `c_se/sqrt(2R) = 0.0130`（`R = 4000`）之内，随重复数增加收敛到该解析值。注意均值的标准误给出的是 `c_se/sqrt(N) ≈ 0.0182`，与本读数差 `sqrt(R)` 倍，二者不可混用。

于是天空预算是

```text
SE(sigma_bg)/sigma_bg = c / sqrt(N_sky)  <=  target   =>   N_sky >= ( c / target )^2
```

这里必须区分**两个系数**。`c_se` 是上式的渐近系数；生产口径用的是**有限 N 的复合系数** `c = c(N_sky)`，由 `N_sky` 处的直接测量给出。把这一系数以 dex 表述时必须除以 `ln 10 = 2.302585`：`SE_dex ≈ c_se/(ln10 · sqrt(N))`。两种口径的相对标准误相差 `ln 10 ≈ 2.3026` 倍；作用在**平方形式**的样本数预算上时相差 `ln² 10 ≈ 5.3019` 倍，混用会把预算判据放大约五倍。

`target` 是本链的**设计选择**而非物理常数，落配置；由此推出的天空样本数下限阈值同样落配置。二者**互为反算**，必须同批冻结：给定冻结阈值 `N_sky` 反算出的 `target` 与配置中的 `target` 不一致时，以阈值为准并改正配置，不允许两处各记一个数。

**空间方差场**。控制点是合格块的方差，拟合一个低阶平面场：

```text
variance_bg(x, y) = a + b*x + c*y
```

三条约束保证「合格」二字的含义是可执行的：

- **控制点自校准**。块的 MAD 尺度必须量的是噪声而不是空间结构。判据取 `R = sigma_MAD / sigma_white-equiv`，其中 `sigma_white-equiv` 是相邻像素一阶差分的稳健尺度按 `1/sqrt(2)` 折算（差分把独立白噪声放大 `sqrt(2)` 倍）。纯噪声输入的 `R` 理论值为 1，这是恒等式而非标定值。进入拟合的判据是两条**同时**成立的绝对门限：`R ≤ R_max`（离群门限）且剔除比例不超过 `f_max`（总量上限），`R_max` 与 `f_max` 均落配置。`R_max` 单独使用时不足：一条自指规则「剔除到 `ln R` 的相邻跳变不再超过保留主体自身的极差为止」在平滑铺开的 `R` 上会持续剔除到主体塌缩，因为「保留主体自身的极差」本身随剔除收缩而变小。主体宽度的稳健量改用**不随剔除变化的固定分位区间宽度**（固定分位点的 `ln R` 极差），使判据不含自指。
- **结构非负**。线性函数在控制点凸包上的最小值在顶点取到，顶点是控制点子集，因此「对全部控制点非负」等价于「凸包内恒非负」。实现口径是**相对误差加权**（权重取 `(v_med/v_i)²`）加凸包非负硬约束；凸包外才是真正的边缘外推。
- **可审计性**。凸包内预测非正的**面积占比**必须为零才算可审计；零是「结构非负」约束的定义值，不是可调阈值。**判定在浮点上以 `占比 ≤ 0` 执行**，即要求该占比按输出精度取整后为零；浮点解在凸包内仍可能给出 `-1e-18` 量级的负值，等号比较不可执行，须按占比阈值判。

**零方差分支**。稳健尺度经 `MAD → sigma_bg` 之后可能恰为零（块内常量像素占比超过约 0.40 时裁剪窗塌缩、`RMS` 归零）。该分支必须**与 fill 路径的零方差处置分立**并给出**绝对**门限：常量像素占比达到告警阈时该块显式失败并登记，占比更高时整块拒收，不得让估计器静默落到数值地板上继续产出信噪比。告警阈与拒收阈落配置。

**几何退化判据**。空间场只在控制点数达下限且控制点几何张成二维时启用。判据取中心化点云 Gram 矩阵特征值比 `λ_lo/λ_hi ≥ 1/16`，等价于点云相对条件数 `κ = sqrt(λ_hi/λ_lo) ≤ 4`（无量纲）。不满足时退化为全局常量场，其触发面是**几何退化或合格控制点不足**，不是平面拟合缺陷。

**数值地板与三态**。产品面 `(variance, ivar)` 与跨阶段数据语义统一取**三态**，三者在数据面上互斥、不以数值巧合混同：

| 态 | `variance` | `ivar` | 语义 |
|---|---|---|---|
| 可用 | `> 0` | `1/variance`，在输出精度下有限 | 该像素有可信方差 |
| 无方差信息（有覆盖但方差不可得：预测非正、数值地板不可表示） | `0` | `0` | 方差值不存在 |
| 输入缺项（无覆盖、无有效样本、方差字段缺项或非有限） | `NaN` | `NaN` | 缺项以 `NaN` 为唯一表示 |

两态无效值不混同：产品面写 `variance = 0 ∧ ivar = 0` 的成对零，投影导出读入时把同一个零逆方差读作**零权重哨兵**并输出 `NaN` 传播态。两者是同一数值在不同阶段的两种约定。`0` 与 `±Inf` 在**信号**通道一律读作有效数值，在**方差**通道则按上表判可用性；该差别属数据语义分册，本册不自立。`(0, +inf)` 这类自相矛盾的对不在发布面上。

数值地板只作用于**可用方差**（`max(var, floor)`），不作用于无效态；生效地板的配置默认是 `1e-12`（ADU²），落 `noise.variance_floor`。地板的量纲是方差单位，作用只是数值保护（保证可用方差的逆方差有限），不是物理常数；生效地板及其来源必须随帧产品登记。**地板只保证可用方差的逆方差有限，不保证 `sigma_F = 0` 的控制点可估计**：该控制点不可估计，不进稀疏层，按缺项态输出。

**饱和电平**。达到饱和电平的像素是确定性截断，不是方差项，必须在进入空白背景统计前剔除。电平来源按优先级显式声明：配置显式值优先，其次是帧头的图像极值关键字 `DATAMAX`（FITS 标准定义的数组最大有效物理值 [16]）。`SATURATE` 之类的帧头约定关键词不在 FITS 标准正文中，只能作为显式声明来源使用。**未提供电平与「无饱和」是两种状态**，前者必须显式降级并具名登记，不能当作后者处理：5σ 裁剪以 `median ± 5σ` 定窗，样本中位数一旦被饱和核与源翼主导，裁剪窗与掩膜半径会同时失效。该断言须由注入饱和平台的负例给出实测越界比例，在负例给出读数之前只作待证断言。

**标度不变性**。像素值按 `x' = alpha · x` 线性缩放时，方差按 `alpha²` 换算、逆方差按 `alpha⁻²` 换算。数值地板随数据标度换算时由消费侧承担：帧像素被线性缩放后方差按标度的平方换算，**地板必须同时按 `alpha²` 换算**，否则缩放后的可用方差可能被地板错误截断。该关系与守恒映射的归一化权重求和是同一件事的加权形式；守恒映射的归一分母与像素面积同量纲且与像素方差无关，因此缩放律在任一标度类别上都成立。

### 3.2 加权方差面：含源项的总方差

```text
variance_w(x, y) = variance_bg(x, y) + S_src(x, y) / g
```

`S_src(x,y)` 是该像素上源贡献的信号电平（ADU 标度，不含天光），由星点测光给出的源通量与 PSF 轮廓导出：

```text
S_src_hat(x, y) = sum_i  F_hat_i * P_i(x, y)
```

源项是本面与背景方差面的唯一区别。乘性与系统性项（DSNU、PRNU、列固定图案）不进入本面：它们属系统误差面，不是本层的随机加权方差。

**增益与读噪的来源按优先级显式声明**，取值面是多来源：

1. **本帧自估**。对帧内像素做 `V = sigma_0² + S/g` 的斜率–截距回归。这是 2 未知量、1 个观测量，**必须有跨足够宽信号量程的亮源杠杆臂**才能同时辨识，且斜率臂与截距臂必须拆分登记：斜率臂只给 `1/g`，截距臂只给 `sigma_0²`，两臂各自带自己的杠杆臂判据与降级分支，不得共用同一通过性结论。杠杆臂的判据取信号量程的方差占比

   ```text
   lever_var = Var(S) / mean(S²)      （对参与回归的像元取，无量纲）
   ```

   `lever_var` 低于绝对门限时回归不可辨识，`1/g` 与 `sigma_0²` 不可分离，斜率臂上的拟合值属不可得态。回归前必须扣除偏置，其必要性只来自截距（见「单帧可辨识性」）。该回归的前提是**已知源轮廓**（`S` 来自星点检测与测光），因此它是**支撑先验下的两参数标定**，不是无先验的本帧自估；把它当作无先验自估会重复计入先验强度。
2. **帧头关键字**。存在增益与读噪关键字时作独立交叉校验与可选覆盖。
3. **显式配置覆盖**。由调用方给出并随帧产品登记来源。

三条来源并列，任一都不可得时本面必须显式降级并具名登记，退化为背景受限口径；降级状态随帧产品落溯源，与背景方差面的三态登记正交。**「自估是主路径」不成立**：帧头读数缺失时配置键存在不等于数值路径读取该键，可用状态的判据是数值路径实际读取该键；杠杆臂门限不满足时必须走降级分支，不得默认落在自估上。

### 3.3 绝对信噪比

**逐源通量不确定度**。在统一线性模型 `d_i = F·P_i + n_i`、`P_i` 是归一 PSF 轮廓（`sum_i P_i = 1`）、`Cov(n_i) = sigma_i²` 下，广义最小二乘估计 `F̂ = (PᵀC⁻¹P)⁻¹ PᵀC⁻¹ d` 的方差是广义最小二乘信息量的倒数：

```text
sigma_F^{-2} = sum_i  P_i^2 / sigma_i^2
SNR          = F_ref / sigma_F
```

`sigma_F` 是**帧面通量**的不确定度（ADU），不含测光标度因子；它就是 PSF 加权最优提取给出的通量不确定度——该式的最优性推导与逐源信息量口径见 [1][2][3][4]，其作为最小二乘最优权重组合的最初来源见 [5]。`F_ref` 是参考通量（ADU），`SNR = F_ref/sigma_F` 是无量纲比值。信噪比的标定基准只来自星点——PSF 与孔径测光的精度离散程度，以及 PSF 加权最优提取给出的 `sigma_F`；「从信号里把噪声分离出来」不成立，理由见「单帧可辨识性」。

**参考通量的闭式与跨帧可比性**。参考通量由**固定参考星等档** `m_ref` 与本帧测光零点共同确定，同时另有一个与帧无关的**物理公共锚**：

```text
ZP_k    = ZP_syn - 2.5 * log10( k_photo,k )        [mag] ,   mag = ZP_k - 2.5*log10(F_adu)
F_ref,k = 10^( -0.4 * ( m_ref - ZP_k ) )            [ADU]
F0      = 10^( -0.4 * ( m_ref - ZP_syn ) )          [F_syn]  与帧无关的物理公共锚
F_ref,k = F0 / k_photo,k        ⇔  a_k := F_ref,k / F0 = 1 / k_photo,k
```

`m_ref` 是组内公共的**固定参考星等档**，不是「本帧能测到的星」；`k_photo,k` 是帧 `k` 的**测光标度因子**（帧面 ADU 与统一测光坐标系之间的乘性标度，`F_sys ≡ k_photo,k · F_adu`）；`ZP_syn` 是由 Gaia DR3 XP 绝对谱经本帧滤光片与 QE 曲线正向合成的合成零点，只依赖 `(filter, QE, 天区星族)`，故 `F0` 跨帧恒定。`k_photo,k` 带量纲 `[F_syn]/ADU`，因此 `F_ref,k` 在帧面 ADU 标度、`F0` 在合成系通量标度，`a_k := F_ref,k/F0` 的单位是 `ADU/F_syn`；`F0` 与 `k_photo,k` 同在帧面上做比值没有意义，两个通量不确定度因此必须分名：

```text
sigma_F^{frame,k}                     帧面通量不确定度（ADU），即上式的 sigma_F
sigma_F^{sys,k} = k_photo,k · sigma_F^{frame,k}      统一测光坐标系下的通量不确定度
SNR_k = F_ref,k / sigma_F^{frame,k} = F0 / sigma_F^{sys,k}
```

`k_photo,k` 在上式中**整除消去**，故 `SNR` 对测光标度因子无条件不变——跨帧可比性是这条代数恒等式的推论，不依赖任何附加假设。`k_photo,k` 与其倒数不得混名：由 `F_sys ≡ k_photo,k · F_adu` 可知，把统一测光通量映射到帧面 ADU 的**前向亮度因子是 `1/k_photo,k`**（即 `a_k`），`k_photo,k` 本身是帧面 → 统一测光坐标系的正向标度；任何把 `k_photo,k` 直接当作前向亮度因子的写法方向相反，本册后续公式一律按 `1/k_photo,k` 书写。

`m_ref` 档与 `F0` 随产品落盘：`SNR` 数值只有配上参考星等档才有物理含义，档的记录义务见跨阶段数据语义分册 [20]。跨帧比较必须限定在同一 `m_ref` 档内，不同档之间必须先把 `SNR` 换算到同一参考星等再比较。`m_ref` 是**绝对标度基准**，不是相对倍率。

**逐像素方差组装**。逐像素方差按 ADU 标度组装为

```text
sigma_i^2 = sigma_sky^2 + (RN/g)^2 + F * P_i / g
```

其中天空项的语义必须二选一并显式声明：

- `shot_noise_only`：只含天光与暗流的散粒噪声，此时叠加 `(RN/g)^2`；
- `empirical_total_rms`：是经验总均方根、已含读噪噪声，此时**不再叠加** `(RN/g)^2`。

声明与实际来源不一致时显式失败。把含读噪的经验总均方根填进散粒项、又在增益可用时叠加读噪项，是双重计数，会高估通量不确定度。

**信号经独立局部背景估计与扣除**，天光只通过其散粒噪声进入噪声项。在探测器未饱和、噪声估计由天光散粒主导的成立域内，固定源通量下天光越亮信噪比越低并趋于零：分母随天光开方增长而分子不变。

**逐像素信噪比**是上式在像素粒度上的形式：

```text
I(x,y)            = S_src(x,y) + S_sky(x,y) + N_local(x,y)
variance_slow(x,y) = Var[N_local] + S_sky(x,y)/g
variance_w(x,y)    = variance_slow(x,y) + S_src(x,y)/g
SNR(x,y)           = S_src(x,y) / sqrt(variance_w(x,y))
```

**分子只有源**：天光只经散粒噪声进入分母。把天光电平或观测电平计入分子，就得到一个随天光上升的量，与信噪比的定义相反。该逐像素模型的有效域由「源稀疏」先验划定：源必须能被有限个 PSF 模板张成、天光必须落在参考面的张成空间内、背景采样点必须落在源掩膜之外，三条同时成立。延展发射不在点源张成空间内，该域必须显式声明模型不适用。

**帧级科学摘要**。帧级科学摘要只有三个量：`frame_snr`（帧级绝对信噪比标量）、`depth_m5`（5σ 点源深度）与 `point_information`（点源通量估计的逆方差）。三者语义不同、不得互相代用，其中只有 `depth_m5` 是**帧级质量摘要**：

```text
m_5 = ZP_k - 2.5 * log10( 5 * sigma_F^{frame}(ref) )
```

`ZP_k` 是与 `sigma_F` 同标度的本帧测光零点（单位 mag），满足 `mag = ZP_k - 2.5*log10(F_adu)`；`sigma_F(ref)` 必须显式绑定参考轮廓、孔径、背景估计域与像素标度。缺测光零点时深度键写空，不以默认零点替代。`m_5` 由信噪比定义与星等定义直接导出：令 `SNR = 5` 解出 `F` 再换算星等；系数 `2.5` 是十进星等制的定义值（`−2.5·log10`），三处引用必须同系数。空间变化时应给深度图而非单标量。

**帧级标量与稀疏控制点是两个独立对象**，共用同一定义与同一参考星等档；帧级标量不作为稀疏层的尺度基准，也不参与稀疏层的还原。

### 3.4 定权：逆方差与信息量

本册的三个定权量必须分名，任何一处都不得把它们混称为「权重」：

| 记号 | 含义 | 所在标度 |
|---|---|---|
| `ivar` | 逐像元逆方差 | 方差面（ADU⁻²） |
| `w` | 逐源科学叠加权重 `= SNR²/F0² = 1/sigma_F^{sys,2}` | 统一测光坐标系下为 `F_syn` 通量的逆二次方 |
| `ivar = 0` | 阶段间哨兵：产品面读作不可用，投影导出读作零权重并输出 `NaN` 传播态 | 按阶段分读 |

守恒映射的核权重 `w_jp` 是第四个量，与 `w` 无任何关系，不得同名列写。

**叠加权重是消费时现场换算的派生量**，不是预先算好落盘的字段。三个重建方式（帧内稠密、稀疏控制点重建、帧级标量铺满）产出的都是同一个物理量 `SNR` 的稠密表示，只是来源不同；它们都走同一条定权式：

```text
w = SNR^2 / F0^2  =  1 / sigma_F^{sys,2}  =  sum_i P_i^2 / sigma_i^2 / k_photo,k^2
```

**归一化因子必须取公共锚 `F0`，不能取该帧的 `F_ref,k`。** 因为 `SNR = F_ref,k/sigma_F^{frame,k} = F0/sigma_F^{sys,k}` 两个写法给出同一个数：

- 用 `F0` 归一：`SNR²/F0² = 1/sigma_F^{sys}² = W_k`，正是信息量；
- 用逐帧 `F_ref,k` 归一：`SNR²/F_ref,k² = W_k·k_photo,k²`，逐帧被该帧的测光标度**二次缩放**，`sum_k` 不再等于 `1/Var(F_hat)`。

这是逐帧参考通量口径下唯一真实的失效面，也是它必须带落盘义务的原因。把指数写成 `w = SNR^gamma/F0^gamma` 时，`gamma = 2` 由这条恒等式唯一确定，不是待标定参数；`gamma ≠ 2` 等于放弃广义最小二乘的最优性。裸 `SNR²` 不是权重。

**严格信息量口径**。在统一线性模型 `d_k = (1/k_photo,k)·F_sys,k·P_k + n_k`、`Cov(n_k) = C_k` 下（`k_photo,k` 是帧面 ADU 与统一测光通量之间的乘性标度，故把统一测光通量送进帧面 ADU 的前向亮度因子是 `1/k_photo,k`），点源通量的最优估计与信息量为

```text
Q_k = (1/k_photo,k) * P_k^T * C_k^{-1} * d_k
W_k = P_k^T * C_k^{-1} * P_k / k_photo,k^2
F_hat = sum_k Q_k / sum_k W_k ,      Var(F_hat) = 1 / sum_k W_k
```

白噪声与平坦权重的近似下 `W_k = 1 / (k_photo,k^2 * sigma_pix,k^2 * A_NEA,k)`，`A_NEA,k = 1 / sum_p P_k,p^2` 是噪声等效面积；该式即 `W_k = 1/sigma_F^{sys,k}²` 的闭式。`1/sigma_F^{frame,k}²` 与 `W_k` 相差因子 `k_photo,k²`，二者只在 `k_photo,k ≡ 1` 时同值，引用时必须带标度名。`W_k` 的二次型与统一科学模型给出的点源信息量式同形 [19]；作为最小二乘最优权重组合的来源见 [5]；相关帧的联合协方差口径见 [3][4]。

**关于「信噪比平方之和」这一形式**。`SNR_k² = W_k·F0²` 是**定义式恒等式**（两式来自同一定义），于是

```text
sum_k SNR_k^2  =  F0^2 * sum_k W_k  =  F0^2 / Var(F_hat)
```

对任何可达输入恒成立，结构上不可能给出判决——它既不随实现变化，也不可能变红。把它当作正确性判据，等于把定义抄了一遍当作证据。该式唯一会被误用的形态是改掉归一化：各帧用逐帧 `F_ref,k` 作分母时 `SNR²/F_ref,k² = W_k·k_photo,k²`，平方和里混入了各帧的测光标度，此时它连 `F0²/Var(F_hat)` 都不是。承载证据的判据是**点源信息量**：`Var(F_hat) = 1/sum_k W_k` 与实测通量散度对拍，参照量取自权重之外，因而有鉴别力。

**跨帧可比性的硬约束**。`w = SNR²/F0²` 对参考星等不变**当且仅当** `sigma_F` 与 `F_ref` 无关：定权恒等式本身只保证分子分母同源约掉，不保证分母不随被测星亮度变。由于逐像素方差含源光子散粒项 `F·P_i/g`，而 `SNR` 是在**参考星自身**上取的（`F` 与 `F_ref` 是同一个量），`sigma_F` 是被加权量亮度的函数：在天光受限臂上该源项可忽略，权重对参考电平的漂移被 `F/S_sky` 压低（典型 `1e-4`–`1e-3` 量级，仍是物理量而非数值零）；在源主导臂上则随参考电平单调变化。**漂移是被加权量随源亮度变化的结果，不是归一相消被破坏。** 跨帧比对必须限定在同一参考星等档 `m_ref` 内，天光受限档与源主导档不可混比；参考电平漂移与帧间测光标度不确定度必须一并计入误差预算。

**拟合权重与堆叠权重是两个量**。带杠杆 `h` 的拟合值方差为 `sigma²·h`，不能按 `1/sigma²` 当独立测量堆叠；等杠杆时两者严格等价。稳健拟合（Huber 迭代重加权）在离群下显著压低偏差（`N = 20`、单点 `+12σ`：均值偏差 `0.600 → 0.086`，压低约 7 倍；`0.600` 是解析值 `12/N`），代价是干净数据上相对最小二乘损失约 5% 的渐近效率（调谐常数 `c = 1.345` 时相对效率解析值 `0.95`，这正是该取值的来源 [17]）；该损失随调谐常数增大而减小（`c = 1.0/1.345/2.0/3.0` 对应 `0.90/0.95/0.99/1.00`），调谐常数落配置。**该 5% 是位置估计量口径**：含斜率的两参数拟合在残差按中位绝对偏差标定时效率只有 57%–62%，引用该数必须连估计量类别一起给出。

**口径边界**（以下写法不成立）：

- 用 `signal²` 反算或校验产品方差：纯泊松下 `Var[N] = N`（电子域）或 `Var[signal] = signal/g`（ADU²），与 `signal²` 只在每像元 1 个光电子的单点偶然相等；完整噪声模型还含与信号无关的常数项，信号趋零时方差不趋零；
- 在未登记增益来源与降级状态的帧上，声称加权方差面是「绝对」口径；
- 把无量纲的质量复合量写入逆方差面；
- 以检测到多少颗星一类偶然因素参与定权。

### 3.5 协方差传播

重采样与积分都是线性算子 `R`，不确定度按二次型传播：

```text
C_out = R * C_in * R^T
```

**逐像素方差是这一传播在对角输入下的特例**。守恒映射中源像素 `j` 对输出像素 `p` 的权重记作 `w_jp`，输出方差为

```text
variance_p = sum_j  v_j * w_jp^2  /  N_p^2
```

`N_p` 是归一分母，量纲与面积同阶且与像素方差无关 [21]。这一写法有两个等价参数化：分母用 `N_p²`，或等价地写成 `sum_j v_j * w_jp^2 * k_area² / D_p²`，其中

```text
k_area := D_p / N_p = pixfrac²         （D_p = sum_j a_jp 为命中面积，pixfrac 为 drop 半径比）
```

两者数值相同。**`k_area² = pixfrac⁴` 位于分子**，漏掉它使方差**抬高** `1/pixfrac⁴` 倍（`pixfrac = 0.8` 时约 2.44 倍），不是压低；只有 `pixfrac = 1` 时两种写法同值。方向不可写反：这是负例注入臂的设计依据，写反会让验收把「方差被抬高」误判为合格。

**相邻输出像素不严格独立**。守恒映射自身的噪声与像素相关讨论见 [9]。同一源像素贡献多个输出像素时

```text
Cov(S_p, S_q) = sum_j  c_jp * c_jq * v_j
```

其中 `c_jp := w_jp / N_p = a_jp / (A_pixel,j·D_p)` 是作用在 `x_j` 上的组合系数，**单位 `sr⁻¹`**（`w_jp` 无量纲而 `N_p` 单位为 sr），与参数化方式无关，是唯一真正决定输出的量 [21]。注意它与守恒映射正本给出的**面亮度**归一交叠系数 `a_jp/D_p`（无量纲、`sum_j` 恰为 1、作用在 `B_j` 上）**不是同一个量**，两者差一个 `A_pixel,j`；本册此后一律指带 `sr⁻¹` 的这一支。产品面只发布方差对角线，完整协方差矩阵不作为产品交付。因此：

- 用产品方差做孔径或测量误差时**必须显式加入协方差项**。孔径方差不等于逐像素方差之和；
- 只按 `sum_k c_k² u_k` 计算，等价于假设输入协方差对角，系统性低估输出方差。设输入协方差近等相关（各抽头独立分量为 `u`、两两相关系数 `rho`），偏差因子为 `1 + rho*(M_eff − 1)`，其中

  ```text
  M_eff ≡ (sum_k c_k)^2 / sum_k c_k^2      （系数向量的尺度不变逆参与比）
  ```

  该式对任意系数向量成立：代入一般式 `1 + rho·[(sum_k c_k)² − sum_k c_k²]/sum_k c_k²` 后直接塌成上式，与抽头剖面是否等权无关。**必须用这一支**：守恒映射的 `c_jp` 满足 `sum_j c_jp = 1/A_pixel,j`（对源像元求和，量纲 `sr⁻¹`，不等于一），若改用不带 `sum` 的 `1/sum_k c_k²` 得到的量带面积量纲，会把「系统性低估输出方差」算成降噪。当系数向量是行归一的线性组合（`sum_k c_k = 1`，平面重采样的抽头核即属此类）时，本定义退化为 `1/sum_k c_k²`，其取值域为 `[1, K]`；`M_eff` 只在**平坦**抽头核上等于抽头个数（平坦四抽头核 `M_eff = 4`；非平坦核如 `[0.4,0.3,0.2,0.1]` 给 `M_eff = 3.33`、因子 `1 + 0.35·(3.33 − 1) = 1.817`，该读数对应示例取值 `rho = 0.35`）。把 `M_eff` 误记为抽头数会系统性高估偏差因子；
- `sum_k c_k² ≠ 1` 在行归一（`sum_k c_k = 1`）域内是正确物理：重采样对独立像素方差有降噪作用，但引入相邻相关，输出方差的归一因子因此不为一；守恒映射的 `c_jp` 因量纲为 `sr⁻¹`，其平方和本就不等于 1，二者不可混读；

**控制点估计量的方差**。信号面的控制估计量是干净背景块上的中位数，其方差不是单叶像素方差。设样本独立同分布、中位数邻域密度连续可微，则样本中位数的渐近方差为 `1/(4 N f(m)^2)`；对高斯边际 `f(m) = 1/(sigma*sqrt(2*pi))`，代入得 `Var(median) = pi*sigma^2/(2 N)`。控制点方差因此写作

```text
control_variance = k_corr * (pi/2) * sigma_bg^2 / N_retained
control_ivar     = 1 / control_variance
```

其中 `N_retained` 是裁剪后保留的样本数。相关校正因子 `k_corr := N_retained / N_eff` 表征有效样本量小于保留样本数（守恒映射使输出像素相关，从而 `N_eff ≤ N_retained`），其**公式面是两因子乘积**：

```text
k_corr = k_gauss( N_retained ) * k_geo( 几何 )
```

- `k_gauss(N)` 是**有限 `N` 的修正项**，唯一机制是 **MAD 尺度估计器的小样本偏置**：`sigma_bg = MAD·kappa` 在有限 `N` 上**系统性低估** `sigma`（高重复蒙特卡洛实测 `E[MAD·kappa]/sigma` 在 `N = 3/5/9/25/64/121` 处为 `0.673 / 0.822 / 0.909 / 0.969 / 0.987 / 0.994`，取中位口径时 `N = 5` 为 `0.746`），补偿因子是它的倒数平方 `1/median(MAD·kappa)²`。两个有限 `N` 因子之积（渐近中位数方差因子 × 上述补偿因子）在 `N = 5/9/17/25/49/121` 处为 `1.65 / 1.26 / 1.12 / 1.08 / 1.03 / 1.01`，与统一信号面分册登记的表值 `1.637 / 1.316 / 1.144 / 1.083 / 1.046 / ≈1.00` 在 0.5%–4% 内一致。**对称分布的样本中位数在各 `N` 下精确无偏**（对称性使 `E[median]` 等于中心），它不是偏置来源；样本中位数自身的**方差**对渐近基线的有限 `N` 比值恒 `≤ 1`（实测 `0.86 / 0.92 / 0.98 / 0.98`，`N = 3/5/25/64`），该因子使 `k_corr` 偏小、不构成其大于 1 的来源。
- `k_geo` 是守恒映射输出像素相关的纯几何因子，随源/输出尺度比、`pixfrac`、帧数与 patch 构成变化。

因此 `k_corr > 1` 的两个来源都是**大于** 1 的项，其乘积在有限 `N` 下严格大于 1；`k_corr = 1` ⇔ 忽略相关，显式拒绝。**冻结单值只是实现记录、不是普适常数**：声明标定域内冻结单值在其两端分别低估 `control_variance` 约 32% 与约 2 倍，禁止外推；所用因子、`N_retained` 与标定元组必须随帧产品登记，域外帧显式回退并具名登记 [22][25]。因子分解式与查表的证据由守恒映射实验单元承载；该查表的判门 `|k_corr − 1| < 0.06` 在有限 `N` 下**恒红**（`N = 5` 时 `k_corr ≈ 1.77`），且其结果表整行被脚本硬编码为通过，因此该门只作形态指示，不作通过判据。

该式的适用域与 `sigma_bg` 的前提一致：样本独立同分布且块内无未分辨空间结构。**有限 `N` 口径必须随引用给出**：纯公式口径（`sigma_bg` 已知）下渐近式对真方差**高估**（`N = 5` 时 +9.53%，1% 边界在 `N ≈ 45`–`49`）；同一 patch 的 plug-in 口径（`sigma_bg` 由同 patch 的 MAD 估出）中 MAD 平方偏置与上项反号，净偏差 `≤ ±1.5%`；偶数 `N_retained`（中位数取两中央均值）另使端到端高估。前提被违反时 `sigma_bg` 量的是空间结构而非随机分量，`control_variance` 与 `control_ivar` 一并失真，该块必须显式降级并登记。

**无覆盖与缺数**。无覆盖、无有效样本、输入方差缺项时按「数值地板与三态」的缺项态输出 `NaN`，不以 0 或无穷冒充；输入方差非有限属产品损坏，显式失败。`ivar = 0` 在阶段间的读法按上文分名：产品面读作不可用并强制成对方差为零，投影导出读入时把同一值读作零权重哨兵，输出取 `NaN` 传播态。`sigma_F = 0` 的控制点不可估计，不进稀疏层。

| 饱和电平 | 落配置（配置默认 0 表示未提供） | ADU | 优先级见「背景方差面」；「未提供」与「无饱和」是两态 |
| 控制点空间场基 | `a + b·x + c·y` | ADU², ADU²/pixel | 低阶平面，可表达电平场的线性倾斜 |
| 天空样本裁剪判据 | 5σ，轮数 ≤ 2 | σ, 轮 | 设计取值，轮数上界防止过度剔除。作用于**控制块内的稳健尺度估计**；帧级标量 `sigma` 另由检测层的整帧裁剪均方根给出，两条路径作用域不得混用 |
| 加权方差源项 | `S_src/g` | ADU² | 泊松统计；`g` 单位 e⁻/ADU |
| 逆方差权重 | `1/sigma_F^{sys,2}` | `F_syn` 通量的逆二次方 | 广义最小二乘的最优组合权重 [5]；点源信息量口径 [1][2][3][4]。与帧面量 `1/sigma_F^{frame,2}` 相差 `k_photo,k²` |
| 组合方差 | `1/sum_k W_k` | — | 独立帧组合律；相关帧须用联合协方差 [3][4] |

**没有来源的经验值不写入本表**。表中每一行要么是可解析的数学恒等式，要么给出推导，要么明确标注为设计选择并落配置。

**开源对照**（按域取用，非等价声明）：SExtractor 的背景网格在 `backguess()` 中用 `2.5·median − 1.5·mean` 作稳健位置统计，在二维网格上逐格估计背景与均方根 [6][12]——该式是四分支之一，只在「离散度非零」且「均方根与中位数自洽」且「`|mean − median| < 0.3·sigma`」三重守卫下取用；同项目的方差累加按 `WEIGHT_GAIN` 与测光类型分三条路径 [12]：`WEIGHT_GAIN` 为真且非孔径测光时按 `sum_p var_pix*(1 + F_pix/(gain·backnoise2))` 汇总；`WEIGHT_GAIN` 为假且非孔径测光时按 `sum_p var_pix + F_tot/gain` 汇总；孔径测光路径的主项是按测光标度归一后的 `sum_p var_pix`，**不做** `F_tot/gain` 聚合项。分支开关由「权图存在」与 `WEIGHT_GAIN`（默认 `Y`）取合取，二者缺一即走另一支。三条路径的主项不同，本链只作方法学对照。photutils 的 `calc_total_error` 返回 `sqrt(bkg_error² + data/effective_gain)`，即 `sigma_tot² = sigma_bkg² + I/g_eff` 的逐像元形式——其源项对信号**线性**而非平方 [13]。多尺度小波稳健噪声估计是另一条可选路线 [11]，本链未采用，只作选型对照。这些是方法学对照：本链的背景方差面以 8×8 控制块上的 MAD 尺度加低阶平面场为基，与上述网格、尺度估计器和场基都不同，**不等价**。LSST 的孔径校正以 `doSaturation` 配置字段（默认掩膜名 `SAT`）控制饱和像元判定 [14]。商业软件另有以 PSF 信号权重与 PSF 信噪比为核心的图像加权方法学 [15]，其归一常数标定集与量纲口径与本链不同，本链只作方法学对照，不复制其常数。

## 5 判据与误差

### 5.1 判据必须能红

每条判据都配正例（真值有效应）与负例（注入对应缺陷）两臂，且负例必须真的把门变红。容差一律落配置并写进本册参数面，不以「冻结容差」一语带过。以下是本层不可省的四组，每组给正负两臂。本层判据的仓内实验证据与全部读数由绝对信噪比实验单元承载 [23]；引用该证据时须同带其分级（解析腿、自检腿、生产绑定腿），自检腿不构成对生产实现的判别力。

- **空白背景恢复**。高斯合成空背景上，稳健尺度在容差内复现注入的标准差。**负例①**：注入非高斯重尾或宇宙线污染的空背景，稳健尺度的相对偏差必须越出同一容差。**负例②**：把源项从逐像素组装式中漏掉，方场绝对电平判据必须转红。
- **方差场恢复**。注入低阶平面方差场，拟合系数在容差内复现。逐像素真值必须显式含块内电平梯度项，否则对强梯度帧过严。**负例**：注入使平面在凸包内预测非正的场，凸包内预测非正面积占比必须由 0 变为正并触发结构非负硬约束。
- **源污染**。注入带星帧，检查掩膜后稳健尺度偏差在容差内，且合格块数与天空样本数满足预算。**负例①**：固定过小半径而源足够亮时必须判红；**负例②**：半径对源通量与 PSF 尺度不单调时必须判红；**负例③**：把天空样本数下限抬高到不可达值时必须由「显式降级」升级为「整帧显式失败」，不得静默继续。
- **饱和域**。注入饱和平台，检查权场中位数方差下降、帧平均逆方差上升。**负例**：未提供饱和电平时必须存在显式降级声明，声明本身要可读、两种状态必须可区分。

**判据的基准必须声明**：绝对量（ADU、像素、计数）、无量纲量、还是相对量；相对量必须同报一个绝对伴随量。本层现有的 `0.1`、`5σ`、`1/16`、`λ` 比值等全部是相对量或无量纲量，随输入标度变化，不得被读成绝对常数。

### 5.2 判据不得恒真

空间权重与尺度场的精度判据用**权重效率损失**

```text
E = Var_w / Var_opt - 1
```

`E = 0` 当且仅当估计的尺度正比于真值尺度，全局尺度相消。该判据只度量**形状**（权重相对最优权重的效率比），能区分「尺度估计的形状对」与「尺度估计的幅度错」；只要求「估计尺度与真值尺度之比不超过某个常数倍」的判据对任意真值场恒真，不携带形状信息。

**`E` 对整体乘性偏差完全免疫**，因为它由权重比值定义。两条臂可以有完全相同的 `E` 而水平偏差相差数倍。因此选型与验收**必须同时报告 `E` 与水平偏差**，「`E` 相同」只允许推出「`E` 相同」。

要求「各臂必须收敛」这类判据在某些臂上恒真、在另一些臂上恒假，不携带信息。真值无源时的归零判据必须逐臂书写：完整臂与漏源项臂在无源帧上应逐位相同，且源项估计归零；**天光被双重计入的臂在归零判据上照样通过**——空间常数项的双计只平移拟合截距、与斜率正交，源项估计仍为 0。它由**绝对电平判据**（空白背景恢复）转红：常数双计使无源区读到的方差相对真值偏高。两个判据各管各的缺陷面，必须都配。天光双计臂的绝对电平偏离量随天光电平线性增长，负例注入须使该偏离越出容差。每个归零判据都必须配一个在有源帧上显著偏离的对照臂，否则没有证据资格。

### 5.3 适用域与失效域

- 背景方差面以天空为主的控制块为前提。帧含大面积未分辨结构、强梯度或弥散源时，块尺度量的是结构而不是随机噪声，该域必须走空间场或显式降级，标量场限于其适用域。判据是**结构 rms 与天光噪声 rms 之比**：该比值接近或超过 1 时估计器对天光的单调性开始衰减，超过 2 时必须改区域化口径、超过 3 时整帧标量口径不适用（读数与口径见绝对信噪比实验单元 [23]）。该比值必须随帧产品登记所选口径。
- 加权方差面的绝对性依赖增益来源；未登记来源与降级状态时只能声称背景受限口径。
- `var ∝ mean` 在近饱和端不成立；该域的权重须由实测标定或显式降级给出。
- **校准层的母版方差不传播进校准结果**，母版自身不确定度与母版—科学帧共享的系统项在下游方差中未建模：母版帧数少或平场形状误差大的域上，下游信噪比在母版主导的系统项上偏乐观。
- 逐像素信噪比模型在延展发射域不适用；端到端误差由分子侧（检测完备性与 PSF 尺度）主导，分母侧的方差模型在该情形下仍成立。
- **信噪比场值域非负是重建算子的公理的一部分**：负信噪比不可发布。守恒映射侧的自然样条求值器在胞内含源时**恒停在控制点最大值**（可分离样条不外插出控制点之上的值），此时重建峰退化为空间常数、亮区被过度加权，误差方向是**乐观**而非保守；无值域钳制时在对抗构型上可出现显著为负的场。因此非负性**不能只靠钳制保证**，还要求控制点自身非负，越界比例与所选口径归重建算子分册 [24]。
- 孔径误差、面亮度统计与深度估计都不在产品方差面内，须显式叠加协方差项或另行建模。

### 5.4 误差传播的登记面

每帧必须落盘的噪声面观测量：参考通量基准（逐帧 `F_ref,k` 与其参考星等档 `m_ref`、星等制、作用域，以及与帧无关的公共锚 `F0`）、生效的尺度与地板及其来源、掩膜降级状态（含通量低于临界那一档）、饱和过滤状态、控制点方差动态范围、平面系数、凸包内预测非正的面积占比、被剔除的块数与 `R` 的分布、退化触发原因。缺任一项，该帧的方差面不可审计，按显式失败处置。

其中控制点方差动态范围、平面系数、凸包内预测非正的面积占比、被剔除块数与 `R` 的分布由机器强制清单逐字段判定，缺任一字段即在产品中点名缺项并按显式失败处置；其余观测量已随帧落盘但尚未纳入该清单，在纳入前其缺失按显式降级并具名登记。

## 6 与上下游的关系

### 6.1 输入

| 来自 | 贡献 |
|---|---|
| 校准分册 | 偏置、暗流、平场的扣除结果。母版方差按校准层的冻结口径**不传播进校准结果**，其下游后果见「适用域与失效域」 |
| 星点检测与 PSF 分册 | 星点位置、逐星通量与 PSF 尺度（掩膜半径、源面 `S_src` 的输入） |
| 测光分册 | 统一测光坐标系下的信号标度 `k_photo,k` 与测光零点 `ZP_k` |
| 帧头与配置 | 增益、读噪、饱和电平、掩膜参数与预算阈值 |

### 6.2 输出

| 对象 | 交付形态 | 交付状态 | 消费者 |
|---|---|---|---|
| `variance` / `ivar` | 帧级与球面产品的方差面与逆方差面 | 已交付，三态编码 | 信号面拟合、集成、导出 |
| `frame_snr` | 帧级绝对信噪比标量，写入产品头 | 口径冻结；电平存在**逐帧共模偏差**，真实带结构帧实测偏低 15%–77%，多帧叠加不消 ⇒ 不得单独作为选帧或定权依据 [23] | 帧级重建口径、帧级摘要 |
| `sparse_snr_layer` | 帧内稀疏控制点处的绝对信噪比 | 口径与合同已冻结、消费面已接线并红绿验证；**生产者侧写者与载体发布者尚未落地**，在产者到位前不得由下游直接消费 [23] | 稠密重建 |
| `point_information` | 点源通量估计的逆方差 | 已交付 | 点源目标的严格权重 |
| `depth_m5` | 5σ 点源深度（空间变化时给深度图） | 已交付；缺测光零点时写空 | 帧级质量摘要、筛选 |

科学叠加权重 `w` 不是输出对象：它在集成时由绝对信噪比与公共锚 `F0` 现场换算，标准化与投影导出两阶段都不产生、也不消费 `w`（导出侧读的是 `ivar`，并把 `ivar = 0` 读作零权重哨兵）。

三种重建方式各有适用域，**无一在全域最优**：稀疏重建在方差图有空间结构、源污染低的域上占优；帧级标量在无空间结构、逐像素开销可忽略的域上占优；帧内稠密**不是精度基准**——逐像素重建自身的噪声与欠冲使它在含结构域上劣于控制格粒度铺满（结构场的权重效率损失 0.577 对 0.00903）[24]。逐像素稠密权重只在方差场能被控制格忠实表示时才是有效口径，该有效域由重建实验单元承载。

### 6.3 精度归属

方差与覆盖面等稠密大面默认单精度；帧级信噪比、WCS 解、星表匹配、测光定标与运行清单全程双精度。JSON 显式指定位深时以 JSON 为准。逐像元不确定度的**计算**全程双精度，但**逐像素信噪比场的交付位深是单精度**：守恒映射侧的稀疏信噪比求值器输出单精度场（约 1e-7 相对量化误差），该接口的返回类型无条件是单精度，即使走双精度控制点路径亦然 [24]。因此本册的数值容差只在双精度下有定义，**不得据以推断单精度交付面合规**；跨位深的传递误差须单独计入预算。

### 6.4 质量面与信息面的分离

帧级质量权重、PSF 拟合质量代理、相对质量倍率是**质量面**的量，无量纲，只作采样与诊断；`1/Var(F_hat)`、点源信息量与逆方差是**信息面**的量，承载科学权重。两面各自的量不得互相冒充，也不得相互代用。同名字段必须分别命名：`frame_snr` 指产品头里的科学量（未加权原始信噪比），质量面的对应量另有其名。
