# DISPUTE_RESOLUTION —— 科学正本层的分歧终裁同步件

本文件是**科学正本层**的分歧终裁同步件。凡跨单元裁决（`D-xx`，见 `实验/裁决台账.md`）与
逐单元裁决（`A-Px-xx`，见各实验单元 `docs/DISPUTES.md`）中，**改变科学公式、常数取值或判据口径**
的部分，其「裁决 → 正本节」的对应关系在本文件登记。

## 收录判据

一条裁决进入本件，当且仅当它满足下列之一：

- 给出或订正了科学正本中的**公式**（含近似律、系数、约定）；
- 给出或订正了科学正本中的**常数取值**；
- 给出或订正了科学正本中的**判据口径**（门的方向、分母定义、适用域、豁免与否）。

只涉及文献题录、锚点定位、行号漂移、计数与代码整洁的裁决不进本件（留在
`实验/裁决台账.md` 与各单元 `docs/DISPUTES.md`）。

## 读法

- **终裁**列写现行取值与口径，是可直接被正本引用的表述；
- **依据**列只写一手文献 / 上游开源实现 / 仓内实测可核面；
- **正本落点**列写该取值当前在科学正本中的位置与状态。
  状态取值：`已一致` / `部分一致（待补 X）` / `无落点（待同步）`。
- 本件**不改写**正本正文。正本需增补的项在「待同步」中列明，由正本维护方落笔。

## §7 `k_corr` 的身份与两因子查表（D-08）

- **终裁**：
  1. **身份**：`k_corr = 1.4` 是**标定几何专属的单次 MC 实测值**；
     现行表述为「标定几何专属 MC 实测带 1.27–1.43（中心 1.34±0.04），1.3883 为该带内一次实现」。
  2. **公式面**：`k_corr = k_gauss(N_retained) × k_geo(几何)` ＋
     (ρ, pixfrac, 帧数/dither, patch 构成) 几何查表。**代码默认 1.4 是实现记录，不是普适常数。**
  3. **声明标定域**（pixfrac ∈ [0.5,1] × 源 [300,600]″/px）内冻结 1.4 不保守：
     N = 5 紧凑端低估 control_variance **32%**（标准误低估 14%；空间分散 1.54）；
     源 583–600″/px 端低估约 **2 倍**。
  4. **引用义务**：声明 ① 标定元组与 N_retained 档位（N ≤ 25 时 `k_gauss(N) > 1.08` 不可忽略；
     N = 5 紧凑 patch 须 ≥ 1.6、分散 1.54）；② 几何不匹配时 **fail-closed 拒绝或现场 MC 重标**。
- **依据**：Fruchter & Hook 2002 全文子串级检索无 1.3883 / 1.4 / k_corr（该文唯一定量相关
  噪声量为 `R = σc/σp = 1.662`）；受控复现（16 相位 × 8 seed）1.3445 ± 0.0416，
  range [1.273, 1.425]；`k_geo` 扫描全域 1.00–5.0；多帧 1/2/4 帧 = 1.424 / 1.338 / 1.328。
- **正本落点**：`docs/science/noise_snr/NOISE_SNR.md` §3.5「控制点估计量的方差」（两因子式与全表）、
  `docs/detail/registry/acsd.phase2.sample.md`（DATA-P2-SMP 端口的 `control_k_corr` 行与 control estimator 方差冻结式，
  含公式面、适用域与引用义务）、`docs/science/PHASE2_UPM.md`（`k_gauss` 表）—— **已一致**。

## §27 `m_ref` 的定位（A-P4-06）

- **终裁**：`m_ref` 只作**记录参考电平约定**，不是需标定的量 ——
  权重换算式 `w = SNR²/F_ref² = 1/σ_F²` 是**代数恒等**，在任意噪声组成下都精确成立
  （分子 `F_ref` 与分母 `σ_F` 随 `m_ref` 同步变化，归一在 `SNR` 中相消）。
  但 `w` **不是**对 `m_ref` 不变的量：逐像素方差含源光子散粒项 `σ_i² = σ_sky² + F·P_i/g`，
  故 `σ_F² = 1/Σ(P_i²/σ_i²)` 是 `F_ref` 的函数，`w = 1/σ_F²` 随参考电平单调变。
  天光受限臂（`gain = 0`，`σ_i²` 与 `F` 无关）实测 `w` 逐位不变（相对偏差 4.44e-16）；
  源主导臂（`gain = 1.3`）实测 `m_ref` 档漂移 3.83%（档区间读数 1.9%–4.2%）。
  漂移是**被加权量随源亮度变化**的结果，不是恒等式破裂。
  ⇒ 跨帧比较必须限「同一 `m_ref` 档」，且该档随产品落盘。
- **依据**：恒等式的两项独立复算均落在浮点舍入量级——`SNR` 与 `F_ref/σ_F` 逐位相同（相对误差 0），
  `SNR²/F_ref² ÷ 1/σ_F² − 1` 最大 1 ulp；天光受限臂 `mref_drift_rel = 4.44e-16`、源主导臂 `0.0383`
  （`实验/absolute-snr/code/audit/route3/exp04_refmag_chain.py`；
  该脚本把配对恒等式自标 `is_tautology: true`、`evidence_eligible: false`，故恒等式本身不承载证据，
  漂移量由跨帧比值给出而非由恒等式给出）；同件 `sigma_F_adu` 随 `F_ref` 由 14044.18 降到 1408.98
  （99.35×），与 `F_ref` 的 100.00× 同量级，直接印证 `σ_F` 的源亮度依赖；
  档漂移区间读数正本 = `实验/absolute-snr/REPORT_experiment.md` §精度约定。
- **正本落点**：`docs/science/noise_snr/NOISE_SNR.md` §3.4「跨帧可比性的硬约束」（`m_ref` 档限定）。
