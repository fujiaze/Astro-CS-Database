# ACSD 科学范围、适用域与不可辨识量

本分册依据[最高设计](../../ACSD_DESIGN.md)和[统一科学模型](UNIFIED_SCIENCE_MODEL.md)，说明模型假设、可辨识域与产品边界。完整阶段一因果链见[Normalize科学正本](../normalize/NORMALIZE_SCIENCE.md)。

## 1. 系统范围

ACSD 从 CCD/CMOS 天体观测构建天球线性成像信号：Normalize 对每帧校准、使用 IPV/或有来源的 WCS、Gaia XP 光度、PSF、噪声/参考 SNR 与球面 Drizzle 生成单帧 HiPS；Mosaic 从已发布的单帧数据重建适当统计精度和相对背景、排异并合成最终**单科学信号通道 HiPS**；Export 由此 HiPS 生成普通平面 WCS FITS。阶段间使用产品交换，不把运行时/调试缓存当作正式科学数据。

## 2. 用户决定如何合并设备与通带

**合法的不同相机、望远镜、曝光、滤镜和带宽可以由用户自由选择进入 Mosaic。** 同一 Normalize 命令可有多个校准/模型 block；校准组或逐帧光度模型的分离是物理条件，不得反向变成 Mosaic 的设备/滤镜字符串准入。输出科学解释由真实观测响应 R_k 与约定的目标/混合响应 R_0 决定。

按 Gaia DR3 XP 恒星光谱可校准在恒星颜色/SED 支持域内的标度及色项；没有逐位置 SED 时，不保证不同 Hα/[N II] 或宽窄带发射线云气能通过一个比例系数无偏变成相同辐亮度。用户可以追求高 SNR 混合，也可以为高精度限制相同设备，但这是**用户的组合选择**而非软件的隐藏门槛。真实通带误差和未知响应保留在 product provenance/系统误差解释中，不让天光拟合把真实星云差异随便消掉。

## 3. WCS 原始输入与解算域

原始帧含有完整 FITS WCS 只是一个可观察的文件属性，**不是 Normalize 才能使用的先验条件**。IPV 可在粗指向/板尺度、Gaia 星表和实际像元的基础上独立检测求解。初始中心指向只提供 hint，不能冒充已解 WCS；只有真实求解或独立有来源、完整经验证的 explicit WCS 才能用于 Drizzle。unsolved 帧不能虚构球面位置。文件头普查不测量IPV成功率或失败率。

## 4. 线性信号单位与有效域

数据传递为 raw/calibrated 的线性积分量，经明确的逐帧 photometric scaling，再除以球面像元立体角得到 surface brightness。若校准量仍是 ADU，则 BUNIT 可为 ADU/sr；若变成模型参考光度单位，则必须按该模型单位声明。星等是派生对数，不参与球面加权信号求和。负值是合法天空扣除后的信号；NaN/validity/no_data 等状态不以真零替代。

## 5. 随机噪声、共同母版与系统项

在增益 g=e-/ADU 有已知来源时，可以描述光子散粒、读噪、暗流与校准主版方差；无 gain 时明确记录条件近似和适用域，不能假设 g=1。输入 master bias/dark/flat 有限不确定性和共享相关性时应由校准雅可比与条件协方差表示；未计算或缺输入时记录unmodelled，不把它写成“按物理定律不需要”。

在已有光度标度 α 下随机噪声协方差按 C'=D_α C D_αᵀ；α 本身的估计不确定性、星云未知响应、跨帧系统项单独讨论，不能假装都是独立像元白噪。Drizzle 与 HiPS 重采样会引入相关噪声，邻叶不一定独立。

## 6. 参考 SNR 和像元精度不是同一个对象

对固定参考 SED/光度约定和局部 PSF，Phase1 可估计 SNR_ref=F_ref/√V_F、真实逐源 source_snr、帧级 frame_snr_ref，三者必须分名。空间 canonical sparse controls 承载局部条件 F_ref,k、V_F、PSF/背景/支持域和估计状态，不由实际源 SNR 中位数或 (A−B)/MAD 无条件替代。只有正确变换到相同球面面亮度被估计量，Phase2 的 V_B 才与 V_F 通过 T=V_B/V_F 联系；不能用 SNR²/F_ref² 不加转换地声称扩展源像元逆方差最优。

## 7. 背景和科学失败域

局部平稳背景是假设，不是一切星云/拥挤场的真实性前提。用星点掩膜及独立背景控制判断结构污染；当 patch 样本不足或含强低频扩展源时，不可把空间结构的 RMS 无条件当传感器白噪方差。源泊松噪声依赖非负**期望电子计数**，不能拿天空扣除后负数直接代入。局部参考 SNR 不可辨识时如实标 unavailable/conditional，允许保留可用信号而不冒充已计算精度。

Mosaic 的重叠背景差只能在相对观测约束连通分量内辨识。无外部锚的断连背景零点不可强行恢复。不同通带的结构差异、PSF 差异及加性天光必须分离；提高显示平滑度不自动意味着物理无缝或高精度。

## 8. 阶段产品、开发模式与非目标

阶段一保留每帧正式 signal HiPS 和必要的响应/PSF/WCS/稀疏控制/可辨识统计模型，允许有科学依据的单帧辅助 variance/ivar；阶段二**最终只发布 signal 科学图像通道**（多分辨率 HiPS 层级不算其它科学通道）；阶段三平面 FITS 仅含普通 signal 图像，不凭空推导已经丢失的最终绝对方差。

ACSD_DEV_MODE 只决定是否编入被动开发中间快照/详细性能探针；所有正常科学算法的输入来源、数值与发布产品一致。纯开发缓存不是被估计量，也不属于正式科学输出。

完整协方差巨矩阵、未知逐像素 SED、精确无卷积天空、对所有仪器都成立的通带变换以及自动从单幅图恢复未知探测器增益**不是已承诺可获得的科学产物**。它们可以通过经检验的局部核、外部校准、限定目标或明确估计误差近似，但不能依靠文档措辞变为已知。
