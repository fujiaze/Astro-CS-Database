# 统一科学模型

> 上游：《ACSD 最高设计》（docs/ACSD_DESIGN.md）的「核心科学方法：五个创新点」与「数据对象与配置」两章

## 1 主题与目标

本分册给出贯穿三个命令的**同一个物理世界观**：一次观测是什么、图像上的一个数代表什么、什么量可以用作组合权重、什么量不能。它回答四个问题：

- 观测数据与待估量之间的**统一线性模型**是什么；
- 不同科学目标下**最优统计量**分别是什么，为什么它们互不等价；
- 全链共同使用的**数据对象**各自是什么量、能否作权重；
- 每条口径的**适用域与失效域**在哪里。

本分册是 P1 通量积分拟合、P2 跨帧绝对信噪比、P3 守恒映射算子、P4 稠密信噪比重建、P5 加性天光去除这五个创新点的共同前提：P1 与 P2 建立信号平面与噪声平面，P3 搬运它们，P4 由它们重建稠密表示，P5 用它们定权与去天光。任何一条创新点的口径若与本分册冲突，以本分册为准。

具体量值、系数与容差由各主题分册承载：测光在 photometry 分册，噪声与信噪比在 noise_snr 分册，映射算子在 drizzle 分册，信号面在 sky 分册，排异与集成在 integration 分册。本分册只给它们共用的骨架。

## 2 物理模型

### 2.1 统一线性观测模型

一切观测数据处理都可以写成同一个形式。第 `k` 帧的数据向量 `d_k`、待估的科学量 `x` 与噪声 `n_k` 满足

```text
d_k = A_k x + n_k ,        Cov(n_k) = C_k
```

`A_k` 是第 `k` 帧的线性前向算子，它同时包含光度响应、点扩散函数（PSF, Point Spread Function）、像素响应、世界坐标系（WCS, World Coordinate System）映射与重采样；`C_k` 是噪声协方差，包含所有随机分量以及可表达的相关分量。`A_k` 与 `C_k` 的乘积分解不唯一，选择哪一组取决于要回答的科学问题：面亮度重建、点源检测、点源测光与天体测量各自取不同的 `A_k` 分解。

这个模型是**陈述性的**（declarative），不是实现承诺。它规定的是每个处理步骤都应当能说清"我改了 `A_k` 的哪一部分，或者我近似了 `C_k` 的哪一部分"，从而使误差可归因。任何把某个环节简化的做法——例如把重采样写成加权平均、把重采样噪声当作独立同分布——都是在削减 `A_k` 或 `C_k` 的表达能力，其成立条件必须由独立证据给出，而不是默认成立。

### 2.2 科学目标分层

"最好的图像"不是一个可判定的单一目标。至少存在五个互相冲突的目标：

| 目标 | 判据类型 | 最优统计量族 |
|---|---|---|
| 扩展源（面亮度）的无偏重建 | 无偏性 + 方差最小 | 广义最小二乘解 |
| 点源检测功率最大化 | 检测概率 | 似然比充分统计量 |
| 点源通量估计方差最小化 | `Var(F̂)` 最小 | 匹配滤波（逆方差加权） |
| 天体测量精度 | 位置残差 RMS | 几何定标解的协方差最小化 |
| 视觉与筛帧质量 | 主观 + 稳健统计 | 无解析最优式 |

同一份数据在这些目标下的最优权重不同：面亮度重建关心逐像素同点采样，点源测光关心 PSF 加权的投影范数。因此每一个产品、每一处权重声明都必须标明它服务于哪个目标。本分册后续给出的两条式子（扩展源与点源）在这五个目标里分属不同分支，**不得互相替代**。

### 2.3 假设与适用域

模型（2.1）成立的物理前提是：探测器在未饱和区线性响应；天体源在天区上稀疏；背景在局部尺度上平稳；噪声的随机分量可由一个协方差矩阵描述且各帧之间近似独立。这四条前提各自有失效域：饱和区使 `A_k` 非线性；源密集使背景估计与源分离不可分；背景梯度使局部平稳失效；跨帧共模（如同一平场母版、同一大气视宁度）使 `C_k` 不再块对角。第四条是本链最容易低估的一条：共享母版校准带来的系统项在逐帧方差中不出现，但它对最终通量与深度的影响是同量级的。

## 3 公式与推导

### 3.1 点源最优统计

取点源模型 `d_k = a_k F P_k + n_k`，其中 `F` 是待估的标量通量，`P_k` 是第 `k` 帧的 PSF 响应模板（作为向量归一化），`a_k` 是该源在第 `k` 帧的相对亮度因子（可并入 `P_k`，此处单列以便对照）。定义两个标量

```text
Q_k = a_k P_kᵀ C_k⁻¹ d_k
W_k = a_k² P_kᵀ C_k⁻¹ P_k
```

`W_k` 是该源在该帧上的 Fisher 信息量，`Q_k` 是与之配对的线性充分统计量。最小二乘解与它的方差为

```text
F̂_k = Q_k / W_k
Var(F̂_k) = 1 / W_k
```

这是加权最小二乘的直接结论：令残差对 `F` 的导数为零即得 `F̂ = Q/W`；由 `Var(F̂) = (PᵀC⁻¹P)⁻¹` 得 `Var = 1/W`。光学成像的最优提取公式取同一形式 [1]，成像测光的最优提取式由 Naylor 给出 [2]，多帧组合的最优权重由 Zackay 与 Ofek 从加权随机变量叠加的似然比推导 [3]：在独立测量 `θ_j = μ_j T + ε_j`、`Var(ε_j) = σ_j²` 下，似然比关于 `T` 线性，其充分统计量与方差为

```text
S = Σ_j (μ_j / σ_j²) · θ_j            似然比线性于 T，其权重是 μ_j/σ_j²，不是 1/σ_j²
I = Σ_j μ_j² / σ_j²                   S 在 H0 下的方差
T̃  = ( Σ_j μ_j θ_j / σ_j² ) / ( Σ_j μ_j² / σ_j² ) = S / I        最大信噪比估计量
```

分母 `I` 不可省：它把 `S` 归一成对 `T` 无偏的估计量，去掉分母得到的量随 `T` 线性放大，不是估计量。这与上式在"权重 = 逆方差乘以响应"上一致——`μ_j` 正是一个待估源在第 `j` 帧的相对响应，`a_k P_kᵀC_k⁻¹P_k` 是同一形状。

多帧合并时，若各帧噪声独立，

```text
Q = Σ_k Q_k ,   W = Σ_k W_k ,   F̂ = Q / W ,   Var(F̂) = 1 / W
```

**帧间噪声相关时不能简单求和**：此时联合协方差不再块对角，写成一般分块矩阵 `C = [C_ij]`（`C_kk = C_k`，跨块元 `C_ij ≠ 0` 承载帧间相关），必须一次性求逆 `C⁻¹` 后按 `W = a² Pᵀ C⁻¹ P` 计算、`Q = a Pᵀ C⁻¹ d` 同理；此时 `W` 一般**不等于** `Σ_k W_k`，直接相加会系统性地低估方差。反之若 `C = blockdiag(C_1..C_K)`（各帧独立），`C⁻¹` 仍块对角，`Pᵀ C⁻¹ P = Σ_k P_kᵀ C_k⁻¹ P_k` 恒成立，此时简单求和才是精确的。这一点是 P2 与 P4 存在的理由：控制点上的绝对信噪比只有在显式承认共享母版与共享信号面带来的相关性时才是可跨帧比较的量。

### 3.2 绝对信噪比与逆方差权重

定义绝对信噪比

```text
SNR = F_ref / σ_F ,        σ_F = sqrt( Var(F̂) ) = 1 / sqrt(W)
```

`F_ref` 是**该帧的参考通量**，即定义 SNR 分子所用的固定标度；`F_ref` 不同，`SNR` 的数值就不同，因此只有携带同一个 `F_ref` 约定的 SNR 才能跨帧比较。由上式立即得到本链的核心恒等式

```text
SNR² = F_ref² · W
w = SNR² / F_ref² = W = 1 / σ_F²
```

**`w` 是已归一的逆方差，不是裸的 `SNR²`。** 两者只有在约定 `F_ref ≡ 1` 时才数值相同。任何跨帧或跨路径的代入都必须显式携带 `F_ref²`，否则得到的权重会随该帧的参考通量二次缩放，这是把绝对信噪比误当权重的最常见失效方式。

由此得到一条判别力上的重要结论：`SNR_combined² = Σ_k SNR_k²` **不是独立断言**，而是上式在"各帧 `F_ref` 同值"时的条件推论；在逐帧 `F_ref` 的口径下各帧的 SNR 没有公共锚，平方和不构成任何单一绝对信噪比。因此它不能作为实现正确性判据——它在两种口径下要么恒真、要么无定义。

### 3.3 扩展源最优统计

对待估量为一个像元值向量的面亮度估计，广义最小二乘解与协方差为

```text
x̂ = (Aᵀ C⁻¹ A)⁻¹ Aᵀ C⁻¹ d
Cov(x̂) = (Aᵀ C⁻¹ A)⁻¹
```

该式出自高斯观测下线性模型的经典极大似然与最小方差估计，原始出处为 Aitken 在 1936 年记录的最小二乘与线性组合论文 [4]。只有当三个条件同时成立时，它才退化为逐像元的逆方差加权平均：输出量与输入量在同一像元上一一对应（`A` 退化为同点采样）、`A` 无 PSF 卷积、`C` 为对角阵。**满足条件时的逐像元 ivar 平均不是本式的推广，而是它在极强假设下的特例**，因此不能用它来论证"逐像元 ivar 平均对所有目标都最优"。

### 3.4 重采样与算子传播

重采样是一个线性算子 `R`，它对协方差的作用是

```text
C_out = R C_in Rᵀ
```

Drizzle 的核心贡献正在于把卷积算子 `P`（PSF）与采样算子 `T` 写成线性重建形式，并证明用逆方差图作为输入权重时统计上最优 [5]。由此得到两条硬要求：

- 输出若只存对角方差，就**必须另存相关核或可重建的算子摘要**；否则 `R C_in Rᵀ` 的非对角部分被静默丢弃，后续任何依赖空间结构的估计都会偏乐观。
- 核权重必须满足归一 `Σ_p c_p = 1` 与通量守恒，两者共同进入方差传播。常数面亮度场与总积分通量是两个互补的解析 Oracle：前者检验归一，后者检验守恒。

## 4 参数与常数

### 4.1 权威数据对象与能否作权重

本表是最高设计的数据对象集在物理含义、单位与权重资格三列上的投影，不是第二份正本；对象名携带全名，端口只接同一种对象，裸写 `weight` 或 `snr` 不指代下表任何一行。

| 对象 | 物理含义 | 单位 | 能否作权重 |
|---|---|---|---|
| `signal` | 声明单位与像素语义的科学估计量，本链为面亮度 | `ADU/sr` | 否，是被估计量 |
| `variance` / `ivar` | 同一 `signal` 估计量的方差及其倒数（本行两个对象，端口分立） | `ADU²/sr²` / `sr²/ADU²` | 对同一估计目标可以 |
| `source_snr` | `F̂/σ_F`，依赖被测源亮度 | 无量纲 | 否，只作诊断 |
| `depth_m5` | 固定参考 PSF 与孔径下的 5σ 深度 [6, 7] | mag | 否，摘要量 |
| `frame_snr` | 帧级标量的绝对信噪比，携带该帧 `F_ref` | 无量纲 | 否，与 `source_snr` 同为原始量 |
| `sparse_snr_layer` | 稀疏控制点处的绝对信噪比 | 无量纲 | 否，是 P4 重建的输入 |
| `point_information` | `a² Pᵀ C⁻¹ P = 1/Var(F̂)` | `ADU⁻²` | 是，点源目标的严格权重 |
| `support` | 有效输入或面积贡献度 | 无量纲 [0,1] | 否，只作门 |
| `coverage` | 几何或数据有效域 | 无量纲 [0,1] | 否，只作门 |
| `validity` | 坏点、缺失、越界等状态 | 布尔 | 否，是门不是权重 |
| `rejection` | 污染样本对推断的影响 | 门或概率 | 否，与 `coverage` 分属两面 |
| `provenance` | 单位、坐标、标度、算法标识、实际后端的声明 | — | 否，是消费前提 |

本表两族的量纲由 `d_k` 所在的承载面决定：`d_k` 取面亮度面时 `variance` / `ivar` 为 `ADU²/sr²` 与 `sr²/ADU²`；`d_k` 取帧面点源面时 `W = a² Pᵀ C⁻¹ P = 1/Var(F̂)` 为 `ADU⁻²`，与数据语义分册的点源族口径一致。两者分属不同量族，同式内不得混用。

关键的语义切分有两条。第一，**信息量面与质量面分属不同对象**：`point_information = 1/Var(F̂)` 属于信息量面，PSF 拟合残差、视宁度、support 与 coverage 属于质量面；把后者代入权重在语义上不成立。第二，**权重是消费时派生的量**：它由 `SNR` 与该帧的 `F_ref` 现场换算得到，数据层不存、不选、不传权重模式；因此链上不存在"选择哪一种权重口径"这个概念，也不存在与权重口径相关的版本键。

### 4.2 系统误差与随机误差的分面

光度零点、背景电平、天文定标、PSF 模型参数与母版校准参数都有不确定度。它们在链上有三个互不替代的出口：

- **独立随机项**进入 `variance` / `ivar`；
- **共享系统项**（同帧集共用同一母版、同一过滤面带来的共模误差）进入低秩协方差与 `provenance`，它们在逐像元方差中**不出现**；
- **模型偏差**（例如把非泊松的读出噪声按泊松处理）进入 `validity` 与系统误差预算，与随机 `ivar` 分属两个面。

把第三类塞进第一类，或宣称第二类已被第一类覆盖，都会让最终深度偏乐观。

## 5 判据与误差

### 5.1 正确性判据

- 每个科学模型有独立的解析解、高精度参考实现或 Monte Carlo 参考，不以本链程序自身的输出充当唯一期望值；
- 注入源的恢复在偏置、方差与覆盖三面上分别可测；
- 在同一图像上改变星表亮度分布，只应改变 `source_snr` 摘要，不应改变 `point_information`；
- 存在协方差时，朴素求和产生的过度乐观可被检出；
- 点源目标与扩展源目标分别相对各自基线证明无损或改善；
- 每一条近似都有能使其失效的注入方式。

### 5.2 口径边界

下列判断只在所列附加条件成立时有效，条件不成立时结论自动失效：

| 口径 | 成立条件 |
|---|---|
| `w = 1/σ_F²` 是点源最优权重 | `C_k` 已知且所用 `P_k` 与真实 PSF 一致 |
| 逐像元 `ivar` 平均对扩展源最优 | `A` 退化为同点采样、无 PSF 卷积、`C` 对角 |
| 帧间简单求和 `Σ_k Q_k` | 各帧噪声独立；共享母版引入的相关项已被显式建模 |
| `variance` 完整描述了重采样后噪声 | 相关核或可重建算子摘要与 `variance` 同存 |
| 逐帧 SNR 在帧内为常数 | 由实测显式验证，不作为默认假设 |

### 5.3 空间量压成标量的条件

PSF、背景、逐像元方差、光度响应与点源信息量在物理上都是**空间量**。把它们压成帧级标量会丢失信息，且损失量随场景变化。只有在三条同时成立时压成标量才是可接受的：空间残差与趋势低于给定容差；该压法对最终通量偏置、方差与检测功率的损失低于给定容差；输出同时给出标量值、分布分位数、采样覆盖率、模型误差与适用域。不满足时保存映射、模型或控制点。信息量优先于存储便利。

### 5.4 跨阶段最小合同

```mermaid
flowchart LR
    N["normalize 产物"] -->|signal·variance·frame_snr·sparse_snr_layer·WCS·validity·provenance| M["mosaic 消费"]
    M -->|signal·variance·effective PSF·coverage·rejection·provenance| E["export 消费"]
    N -.兼容 HiPS 可直接.-> E
```

normalize 到 mosaic 的最小交接面是：信号与其单位、方差或相关核、光度响应、WCS、有效性与质量标记、点源信息量、深度摘要、来源链。mosaic 到 export 的最小交接面是：面亮度或点源产品族、方差或相关核、有效 PSF、覆盖与排异标记、天光参考面、来源链。export 接受任意兼容 HiPS，但所选输出模式所需的层必须齐全，否则显式判为不可用。
