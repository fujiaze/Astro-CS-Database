# 候选栈排异与选择效应

本分册依据[统一科学模型](../unified/UNIFIED_SCIENCE_MODEL.md)，定义同一球面位置的异常样本选择。排异产生接受掩膜与理由，由[集成](INTEGRATION.md)归约；背景模型和权重分别由[UPM](../sky/UPM.md)、[噪声](../noise_snr/NOISE_SNR.md)拥有。实际路由和接口见[Mosaic 模块](../../detail/mosaic/modules.md#reject)。

## 1. 目标、输入与假设

输入为同位置、已作相对背景校正且单位可比较的候选栈，包含信号、有效支撑、具名权重与帧身份。输出分别记录逐样本接受/拒绝理由和栈级状态。排异不合并数值、不重投影、不重新估计天空或噪声权重。

模型使用近似对称的噪声及可解释的稳健位置/尺度；帧相关、异方差、PSF 差异和未知通带差可能使简单单位置阈值失配。单帧无重叠时没有跨帧排异证据。异常检测也不能保证区分宇宙线与真实瞬变或移动天体，帧身份与理由应保留。

基本决策逐候选栈独立，结构生长另用帧内邻域。不能将其数学行为混同为完全逐像元算法；是否开启及有效参数由实际配置/实现记录。

## 2. 规划、资格与方法

AUTO 是规划策略，根据已定义的标称几何可贡献样本量选择显式方法，不因局部有效数量变化再次隐式重选。标称数、资格过滤后的有效数和实际接受数各自记录。显式指定方法使用其适用条件和参数，路由确定性不表示统计最优。

候选收集保持原帧映射，检查信号、支撑、权重与先验模型。非法数据/配置属于错误；样本不足导致欠定时采用明确保守政策，不猜测异常身份。全拒绝后的处置按方法和小样本政策说明，不能无声改成成功全接受。

| 方法族 | 核心量和处理 |
|---|---|
| sigma / median-sigma | 以声明的位置与尺度比较偏离 |
| winsorized / averaged | 缩尾或迭代更新位置/尺度，阈值外样本按核定义处理 |
| linear-fit | 在排序秩轴拟合趋势，再按残差选择 |
| generalized ESD | 以显著性水平与最大异常数作多离群检验[2] |
| percentile-band | 相对电平比例带，不是噪声标准差判据 |
| minmax | 按固定秩拒绝两端，同时满足最少保留政策 |
| robust Chauvenet | 方法规定的多阶段稳健选择及有限样本修正[1] |

成像伪影的 clipped-mean 应用可与[3]对照。方法名称只定位算法族，实际位置估计、尺度修正、迭代停止与小样本语义必须在实现说明中明确。

## 3. 电平比例带的统计边界

记中位数为 m、候选为 x，比例带为
\[
 x\notin[m-p_{\rm low}|m|,\ m+p_{\rm high}|m|]
 \quad\Longrightarrow\quad\text{拒绝}.
\]
p_low、p_high 无量纲，其带宽随 |m| 变化，不能解释为相同数值的 sigma 阈值。背景相对噪声很大时可能对异常惰性；m 接近零时带宽趋零，连续噪声样本可能大量被拒，恰等于中位数的样本仍可能保留。实际结果还取决于样本量、离散值和容错分支。

在固定背景/噪声比下可以标定等效显著性，但不能外推到其它背景或噪声。偏态、非对称分数及数据预处理另行标定；不对称阈值本身不证明偏态已被校正。负信号是否合法与某样本被判低侧异常是两件事。

## 4. 参数来源与状态

下表保留方法参数的项目示例，便于识别既有定义。它不构成所有方法的共同默认值或普适物理常数，实际生效配置由运行来源与对应实现给出。

| 参数组 | 示例 |
|---|---|
| 均值型低/高阈值、迭代上限 | 4.0、3.0、8 |
| 线性拟合型低/高阈值、迭代上限 | 5.0、3.5、8 |
| ESD 显著性、最大异常数 | 0.05、10 |
| 比例带低/高分数 | 0.2、0.1 |
| minmax 低/高拒数、最少保留 | 1、1、4 |

库、工具和 CLI 的结构生长默认值不能相互代用，当前差别见[模块接口](../../detail/mosaic/modules.md#reject)。阈值或路由改变后需重新评价误拒、漏拒和信号偏差；本轮不选择新阈值。

逐样本理由与栈状态分别表示。欠定、全拒绝、非法输入、非法配置/方法和内部故障具有不同原因；非有限输入不能被吞掉后当有效样本。排异不返回集成的 NO_CANDIDATES 或 ZERO_VALID_WEIGHT 来代替自己的状态语义。

## 5. 后选择误差与结构保真

接受集合 E(y) 由观测决定，使最终合成成为非线性估计器。把已经观测到的掩膜固定，再套未选择分布的协方差，只是条件计算近似；真正条件于被接受的分布已经截断。无污染的噪声场也会有误拒，不能以“没有异常真值”要求零误拒。

独立评价分别覆盖：

- 干净随机场中的误拒、均值偏差与区间覆盖。
- 宇宙线、卫星线、热像元及真实时变源的漏拒与可分性。
- PSF、通带或乘性差异造成的真实星核/扩展结构误拒。
- 近零、正/负背景及不同局部有效数量的路由。
- 结构生长在边界、分块及紧凑源上的额外影响。

低频天空与未知通带差不因被选择就自动成为可剔除伪影。最终阶段二仍只发布 signal HiPS，逐帧理由和诊断可保留在内部或运行记录。方差和选择效应见[噪声分册](../noise_snr/NOISE_SNR.md)，本轮未执行误拒或覆盖实验。
