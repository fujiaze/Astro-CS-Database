# 信号面

本分册固定多帧**相对加性背景差模**的科学定义：在同一重叠连通分量内，以固定规范的联合模型降低帧间背景差，并明确哪些公共低频分量无法凭内部重叠观测辨识。跨分量绝对背景零点及真实天体低频信号恢复不由这个模型单独保证。它回答：加性校正场如何表示、控制权重如何定义、求解器如何固定规范自由度、什么条件下无接缝成立。

本分册承载创新点 P5 的加性分量，消费 P1 的线性测光坐标和 P2/P4 声明统计被估量的控制方差；残余乘性相对标度是**单独受恒星光度证据约束**的设计扩展。它是排异与集成的上游：候选栈先经本分册相对归一，而非强制扣去所有公共天光。

## 1 主题与目标

目的：在多帧覆盖并集上建立唯一的联合加性光度模型，消除逐帧背景与零点差，提供控制权重与持久化帧标识绑定。非目标：不处理帧内乘性尺度差（平场残差一类归单帧校准）；帧间残余乘性差模只有在独立恒星光度、阳性和恒等阴性对照中可辨识时，才可在加性校正之外施加；其对数增益在每个重叠连通分量内固定规范。无证据、尚未评估或未具生产施加路径时保持恒等并登记相应状态，不把恒等规范错读成观测到的增益值；不做映射方差估计；不做最终加权积分与排异判定；不跨滤镜统一。本分册三处结论（联合模型唯一性、无接缝成立、控制权重可比）各自带假设前提：唯一性要求连通分量内规范固定已生效；无接缝要求帧间差落在参考面表示域内；权重可比要求同一参考星等档与同一标度类别。前提不成立时对应结论自动失效，不得跨前提引用。

本分册在像素域控制格网上工作，无天球坐标参与；帧绑定唯一由稳定帧标识决定。

## 2 物理模型

加性校正关系为：校准后样本等于校准前样本减去该帧的加性偏差 δ_k = δ_poly,k + F_k。δ_poly,k 是公共面表示里属于该帧的低阶项；F_k 是该帧在**拟合残差**上的逐帧场，构建时已扣除跨帧公共模（每个格点 Σ_k w_k F_k ≡ 0）。残差本就是联合拟合没解释掉的部分，故 F 与低阶项相加不构成重复扣除；去公共模在同一组权重、同一坐标与采样、同一规范约定下保证扣除只把各帧电平互相拉齐、不动公共信号。公共面与逐帧场由**块坐标迭代**联合求解：解 (公共面, 低阶项) → 残差建 F（去公共模）→ 样本扣 F → 重解，迭代层数是配置项。F 的格点基频决定能表示多细的帧间差，不改变纯加性模型。

科学权重分两级，两者禁止混名。绝对式用于任何需要绝对精度的消费面，等于质量因子乘以控制逆方差。份额式用于求解器内归一约定，无量纲，同一控制格点内归一再乘以该格点可靠性。控制逆方差为控制方差的倒数，控制方差由相关校正因子、背景方差与保留样本数给出，其精确形式为中位数估计量的渐近方差。相关校正因子的定义域严格大于一：等于一意味着忽略相关，小于一意味着有效样本量大于样本数，两者都显式拒绝。

求解采用稳健迭代重加权与控制点逆方差，在按**真实有效重叠边**枚举图连通分量之后，对每个分量单独选最小 frame_id 参考帧并实施规范固定；跨分量相对零点不可由分量内部重叠数据求得。加弱零锚只约束数值规范，不制造独立物理观测。收敛判据必须随观测尺度归一，禁止绝对容差：生产观测为面亮度量级，绝对小容差在该尺度上不可达，生产必须走相对判据。

表示能力边界：参考面只能表示尺度不小于两倍节点间距的分量；节点间距由输入几何导出，不是标定常数。当帧间天光差含参考面不可表示且沿向相干的分量时，残余接缝与该分量线性相关。公共面表示能力是减少接缝的必要条件之一，但不足以保证有限噪声下所有边界无缝；还须有有效重叠支持、连通分量正确求解、PSF/标度同口径、充分检测覆盖及适当判据。结论必须与边界一同引用；其适用域收缩为已扫几何区间（实验单元实际覆盖的指向间距与重叠带宽组合），区间外不宣称无接缝。

## 3 公式与推导

校正与权重公式如下：

```text
calibrated = raw − δ_k，δ_k = δ_poly,k + F_k：F_k 为拟合残差上的逐帧场（已去跨帧公共模，Σ_k w_k F_k ≡ 0）
w_abs = quality × control_ivar
w_cell = w_abs / Σ w_abs × reliability，同一格点内归一，格点内权重之和等于该格点可靠性
control_variance = k_corr × (π/2) × σ² / N_retained
control_ivar = 1 / control_variance
```

中位数方差的精确形式为样本中位数估计量的渐近方差，成立条件为独立同分布、近似高斯、无结构分量。有限样本修正与生产链裁剪语义使发布方差在小样本与偶数样本下有可观偏差，方向与量级由实验单元承载，正文只登记存在性。非高斯域该式不成立，结构主导像块的偏差比有限样本修正大一到两个量级。

重叠区一致性：对任意两帧 i、j 在其重叠区内同一天区位置 x，理想无噪声模型在模型可表达条件下的期望值一致，corrected_i(x) = corrected_j(x)。记每帧在该位置的扣除量为 D_i(x)，即 corrected_i(x) = raw_i(x) − D_i(x)，代入即得该一致性对扣除量的等价形式 D_i(x) − D_j(x) = raw_i(x) − raw_j(x)：扣除量之差复现校准前帧间差。实际求解最小化按噪声加权的重叠残差，不逐点强制相等：帧含独立噪声，逐点相等会把噪声拟合成校正面；有限基函数、正则化与求解精度也不保证控制点处严格相等。该条件因此只作理想模型的一致性目标，实际残余受随机噪声、参考面表达能力、采样与求解精度共同限制，按表示能力边界与判据面解释，不以收敛名义豁免。

联合解在模型期望意义上逼近该一致性：扣除量 δ_k = δ_poly,k + F_k，其中 F 由拟合残差构建并已去跨帧公共模，两帧扣除量之差复现校准前帧间差至表示能力与正则化所限的残余。**逐帧场在同一位置的加权和恒为零**（Σ_k w_k F_k ≡ 0）：该式是在同一组权重、同一坐标与采样、同一规范约定下成立的公共模保持恒等式，它保证扣除只把各帧电平互相拉齐、不改变产物在该位置的加权平均电平。加权平均电平不变不等于无偏恢复真实天体低频辐射：只有当真实低频结构落在公共面表示空间内、且帧间差与公共信号在给定规范下可分辨时，产物保留的低频才可与真实低频对应；若低频结构在采样或参考面拟合中已与帧间场混淆，去公共模不能把它恢复。当提高逐帧场 F 的空间频率能力时，必须同时检验真实星云低频结构的偏差以及星点/扩展源污染；不能只凭收紧格点间距就断言不需要源结构保护 mask。多尺度派生场是另一条路：它的施加语义只扣起伏、保留公共面，即 raw − (S − median(S))，减中位操作把帧间共模与台阶的可吸收部分去掉；离线对比中高频保护臂与全采样臂修正量差异 haloU 为 1.91e-07 量级，而缝带配对控制点 M4−M1 帧间差中位为 5.16e-05（最大 +9.51e-05）、成品缝为 4.24e-05，两者相差两个量级以上，多尺度场的量级只能解释纹波，不能解释台阶。判据面（§5）引用本约束时以本节定义为准，不另立口径。

规范自由度处理：加性场对全局常数存在规范自由，以连通分量独立规范固定；弱零锚为弱岭型锚定向全局零。可辨识性首先由有效重叠图的**每个连通分量**和规范自由度判定，再对各分量未正则化、列均衡的数据雅可比/信息矩阵进行秩与条件数检验。`κ<1/τ` 只是指定数值阈值下的近似秩判定，不能把近奇异但形式满秩的系统声明成可达到目标科学精度；还须报告参数扰动敏感性、留出边残差及缺覆盖状态。在正则化后矩阵上设门为恒真门，对原问题是否可辨识零信息，只能作求解稳定性诊断。UPM 默认衔接规则：未显式指定规范固定方式时一律走连通分量独立规范固定，不得静默回退到全局单一规范。

接缝指标为帧足迹边界两侧的电平有符号台阶，沿边界法向取差分并除以局部背景电平。判据量是相对口径，可跨产品比较。门槛为既有实验定义值，不是对所有数据集成立的误差预算反解阈值；其虚警率、可检出下限、法向斜坡伪阳/漏检与未评估边界数由实验单元承载。适用域：只有两侧都在数据内部的帧边界计入判据；足迹外缘不计入，但逐条落盘。

## 5 判据与误差

常量场不变量：各帧同值常数输入时模型回到公共面、校正场为零，不写校正场等于输入的形态。空控制不传播：无合格控制时不产伪校正场。帧标识绑定幂等：持久化往返后映射不变。相关校正缩放：控制方差随其线性缩放，有效样本量反比缩放。两级权重的三条性质：同一格点内两观测的权比在两式下一致；任何公共精度因子在份额式内严格消去；份额式丢弃跨格点精度，换绝对权等于换估计量，须先重标定。

失效域：无重叠或无控制时显式失败；控制逆方差非法时显式拒绝；稳健尺度为零意味着无尺度信息，控制逆方差必须为零；单帧区由调和延拓填充；判据判红走节点间距自适应并登记所走方向。收敛未达时产出机器可检警告，不静默阻塞。

## 6 与上下游的关系

上游是测光标定与噪声估计：帧已在同一测光体系，控制方差由噪声链提供，帧内乘性残留归单帧校准处理；帧间残余乘性差的差模由本模型在加性项之外一并吸收，幅度以单帧校准的场后残差为界，不显著时不施加。下游是排异与集成：校准后样本进入候选栈，控制权重进入叠加权重链。本分册不定义逐算法的输入输出与步骤细节，那些在算法分册的 mosaic 部分。
