# 跨设备球面背景、接缝与科学信号保真模型（UPM / Mosaic）

> 科学正本；上游 docs/ACSD_DESIGN.md §2.1、§2.5、§5；统一观测和精度语义见 docs/science/unified/UNIFIED_SCIENCE_MODEL.md、docs/science/noise_snr/NOISE_SNR.md。重写日期：2026-10-14。
>
> 本文解决**哪些误差可以由相对背景校正消除、哪些属于真正不可辨识的天体信号或通带/PSF 失配**。目标模型不同于当前生产中某个具体“UPM”分支的实现状态；审计见 engineering/architecture/SCIENCE_IMPLEMENTATION_DELTA.md。

## 1. 用户可以合并任意设备与通带

阶段二允许来自不同望远镜、相机、曝光、滤镜和带宽的观测参与一个马赛克。ACSD 不设一致设备/一致通带的准入条件；用户为高信噪比可广泛合并，为高精度可选择一致设备。算法不预先决定用户的取舍。

但必须避免用“能写出一个信号 HiPS”推断“所有输入都是同一物理通带上的无偏辐射观测”。Gaia XP 星光谱锚定的是校准恒星及其受检响应域。对响应 R_k 与参考响应 R_0，即便所有参考恒星经颜色项校正，
\[
 \int L_\lambda(\omega)R_k\,d\lambda
 \quad \text{一般仍不等于}\quad
 c_k\,\int L_\lambda(\omega)R_0\,d\lambda
\]
对每个未知扩展源光谱均成立。Hα 3 nm 与 7 nm、不同厂商 R 及复杂星云发射线尤其明显。此项不能无外部 SED 信息时按“天空背景”扣除；只能保留作为混合响应的系统解释限制。

## 2. 输入状态、分量和被估计量

在同一个 HEALPix 天区位置 p，写出归一化后第 k 帧的球面面亮度：
\[
 y_k(p)= H_k B_0(p)+ a_k(p)+ r_k(p)+n_k(p),
\]
其中：
- B_0 是选定参考响应/科学场的目标信号；
- H_k 是已知/近似已知的有效 PSF、色彩响应及像素积分算子，若经处理可近似 I，须给出条件；
- a_k 是可估计的**加性相对背景**；
- r_k 是未被 H_k 描述的通带系统差、残余乘性响应、平场/非线性和采样误差；
- n_k 是随机噪声，按球面位置与空间相关核描述。

不应通过加法补偿任意 r_k。背景分离的统计前提是多个实际观测的重叠区提供了关于 a_i−a_j 的独立约束；若没有这种约束，模型外推或正则化不能凭空制造绝对背景信息。

## 3. 重叠图与规范自由度

每帧是图节点，满足真实有效重叠、可用控制估计量并符合空间匹配条件的帧对形成边。图必须按**有效观测边**求连通分量，而不是按“天区近似相邻”或空记录凑边。设图有 C 个连通分量，所有相对平衡关系只在各自分量内确定。

理想差模约束：
\[
 y_i(p)-y_j(p)\approx a_i(p)-a_j(p)+
 [H_i-H_j]B_0(p)+[r_i-r_j](p)+n_i(p)-n_j(p).
\]
若忽略模型不一致项，就可能把真实天体颜色/PSF 结构拟合成加性差。

对每个连通分量 \(\mathcal C\)，背景相对差对公共偏置自由：
\[
 B_0(p)\to B_0(p)+g_{\mathcal C}(p),\quad
 a_k(p)\to a_k(p)-g_{\mathcal C}(p).
\]
g 的可辨识函数空间取决于背景基函数与共同参考面，**不只是一个常数**。需要按模型参数空间判定可辨识秩与零空间，并为每个分量固定规范（例如相对参考帧、或在有共同支持的位置加权校正和为零）。指定某个参考帧为 0 是坐标选择，不是该帧物理背景恰好为 0 的观测证明。

两个无相连有效重叠边的分量，彼此绝对背景差不能从这两组数据内部恢复。弱正则锚只选一组平滑解，不产生真值。允许为用户继续生成图像，但必须保留此科学限制，不能制造“跨分量已统一”的陈述。

## 4. 联合背景和逐帧差模

用有噪声意义的背景控制观测 \(z_{kc}\)，在每个连通分量上求公共天空与逐帧差：
\[
 \min_{B,\{\alpha_k\}}
 \sum_{(k,c)\in{\cal O}}
 \rho\!\left(\frac{z_{kc}-[HB]_{kc}-
                  [A_k\alpha_k]_{c}}{\sigma_{kc}}\right)
 +{\cal R}_B(B)+\sum_k {\cal R}_{a,k}(\alpha_k).
\]
A_k 是逐帧低阶多项式/样条基，\rho 是稳健损失，σ_kc 是与**背景控制统计量**同对象的标准差，不可直接用参考恒星 SNR 反推而不建立模型。

若在拟合残差上构建逐帧场 F_k，必须保证：
- F_k 解释的是联合解未解释的**差模**，不得再次作为独立绝对公共面扣除；
- 去公共模操作 Σ_k u_k(p)F_k(p)=0 使用相同的有效帧集合、坐标和权重，且权重一旦迭代变化需要一致更新；
- 即便这条代数恒等式成立，保存的是该加权平均量，并不自动等于无偏真实的星云低频信号；
- 额外背景自由度只能在有效控制/重叠和独立验证支持的空间尺度上添加，不能单纯靠“缝更少”决定网格越密越好；
- 在单帧区没有数据驱动的相对场约束时，只能按选定延拓/恒等约定处理并标记外推的影响。

同时求解公共场与差模，通常比先把每一帧各自高阶拟合、再对高频结果修补接缝更能保留大尺度信号。

## 5. 背景控制点与空间相关

一个背景 patch 的测量值可以是中位数、稳健位置或其他已定义估计量。其方差不等于单像元方差。对 iid 高斯，样本中位数渐近有 Var(median)≈(π/2)σ²/N；有 Drizzle 相关、剪裁、非高斯结构和天体污染时，这一公式需要额外估计。实测的 k_corr 需按精确的 patch 统计量、HEALPix leaf/source 尺度、pixfrac 与相关模型重新标定。

尤其：
- 参考点源 SNR/PSF 信息量属于星测光估计量；
- 背景 control_ivar 属于背景位置估计量；
- 最终像元 w_B 属于面亮度合成估计量。

三种精度的分子、支持域和协方差都不同。不能因为它们都有 “1/variance” 的形式就在 API 中共享一个语义不明的 weight 字段。

控制点应区分真正近似空背景的区域与包含复杂星云/暗云结构的区域。高 SNR 亮星、衍射/光晕、彩色星云和 PSF mismatch 对背景估计的影响，不能只凭简易星表附近否决就认定已经消失。可使用鲁棒模型、显式污染标志、跨尺度诊断和扩展源结构保留检验，而不是用高阶拟合强行消去不符合“平滑天空”假设的信号。

## 6. 加性差、光度增益和 PSF 不同的处理职责

**P1 光度归一**先从 Gaia XP 合成星光谱/实际响应获得可解释线性标度 k_photo；有数据支持时拟合空间乘性场 m_k(x)。阶段二不能把该校准再次盲乘。

**P5 相对背景**用真正空背景控制、重叠差模和各分量规范调整加性场 a_k(x)。不能用背景模型吸收星点比例偏差，不能用只在暗场成立的结果保证所有星云纹理无缝。

**残余乘性差**如果有真实独立证据，才考虑
\[
 y_k^{\rm corr}(p)=(y_k(p)-a_k(p))/g_k(p).
\]
若 g_k 未实施、未识别或数据不足，使用恒等 g=1 作为**保守模型选择**；不写成已实验证明所有增益等于 1。共同点源星等比的残差须在颜色、天区位置和 PSF/孔径校正分层后估计，避免把色差冒充增益。g 的不确定性是跨位置系统量，不能作为纯独立白噪随叠加消失。

**PSF/采样差异**通过响应建模、适当的有效 PSF 对照与采样方法处理；必要时允许用户为科学精度主动做 PSF matching，但不默认强行把所有图像退化到最差设备 PSF，以免损失高分辨率数据。用于背景控制的共同采样尺度与最终图像最佳保真尺度可以不同。

过去 P5 阴性实验证明：零增益差的合成世界中，乘性求解仍能得到统计意义上的“改善”；故降低接缝 RMS 不能作为采用非恒等增益的唯一证据。生产当前 g=1 的事实与物理确认是两种不同状态。

## 7. 接缝评估必须同时估计真实信号损失

真正的无缝不是“输出表面没有任何梯度”，因为许多天区本就含真实大尺度梯度。

评估的空间对象：
1. **有符号台阶**：跨输入足迹边界两侧的局部差值，随跨界距离 d 做扫描；硬台阶与连续星云坡度应区分。分母小/近零的相对台阶不可定义，不能自动算为零。
2. **重叠一致性**：同一天区、不同帧的留出独立观测差及误差标准化，按颜色、PSF、支持域和相对曝光分层。
3. **星点光度**：校正前后 matched stars 通量、色差残差、FWHM、周围背景。
4. **扩展源保真**：已知真值结构、模拟低频功率、扩展源总通量、梯度与局部颜色。
5. **覆盖事实**：输入足迹真实边界共多少、实际测量多少、遗漏原因是什么。不得把未测边界归入“没有接缝”。
6. **随机效率**：使用独立观测/模拟比较同一输出球面信号的散度，而不是仅观察最终图像的局部样本方差。

羽化、平滑和补零可以使视觉接缝消失，但如果牺牲低频真实结构就不构成科学意义的成功。应保留“无校正”“仅加性”“含独立乘性证据”“保真优先”的明确对照，报告差异而非人为追求某个单一得分最小。

## 8. 阶段二图像输出

对每个 HEALPix 叶 p，先完成有效样本资格、背景/标度校正和异常样本剔除，再用 NOISE_SNR.md 定义的像元面亮度权重求最终 signal。没有合法数据时标 NaN，不以 0 假冒暗天区。内部支持度、精度、控制点、参数协方差和诊断可以存在于计算缓存或运行报告，但最终**一个 signal HiPS 科学图像子产品**，不自动发布 support/variance/ivar 产品层。

不同通带数据即使被纳入一个 HiPS，物理响应/混合规则仍应在标准允许的元数据/随运行清单说明中如实记录；不能仅以“R 滤镜”简写精确的等效 bandpass。阶段三只重投影这个信号产品，不能从它恢复原始多设备测光差模。
