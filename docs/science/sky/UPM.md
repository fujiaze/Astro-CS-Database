# 跨设备球面背景、接缝与科学信号保真模型（UPM / Mosaic）

本分册依据[最高设计](../../ACSD_DESIGN.md)与[统一科学模型](../unified/UNIFIED_SCIENCE_MODEL.md)，定义球面相对背景、规范自由度及信号保真。精度语义见[噪声分册](../noise_snr/NOISE_SNR.md)，实现状态见[科学实施差异](../../engineering/architecture/SCIENCE_IMPLEMENTATION_DELTA.md)。

## 1. 用户可以合并任意设备与通带

阶段二允许来自不同望远镜、相机、曝光、滤镜和带宽的观测参与一个马赛克。ACSD 不设一致设备/一致通带的准入条件；用户为高信噪比可广泛合并，为高精度可选择一致设备。算法不预先决定用户的取舍。

但必须避免用“能写出一个信号 HiPS”推断“所有输入都是同一物理通带上的无偏辐射观测”。Gaia XP 星光谱锚定的是校准恒星及其受检响应域。对响应 R_k 与参考响应 R_0，即便所有参考恒星经颜色项校正，
\[
 \int L_\lambda(\omega)R_k\,d\lambda
 \quad \text{一般仍不等于}\quad
 c_k\,\int L_\lambda(\omega)R_0\,d\lambda
\]
对每个未知扩展源光谱均成立。Hα 3 nm 与 7 nm、不同厂商 R 及复杂星云发射线尤其明显。此项不能无外部 SED 信息时按“天空背景”扣除；只能保留作为混合响应的系统解释限制。

## 2. 输入状态、分量和被估计量

在同一个 HEALPix 天区位置 p，写出归一化后第 k 帧的球面面亮度：
\[
 y_k(p)= H_k B_0(p)+ a_k(p)+ r_k(p)+n_k(p),
\]
其中：
- B_0 是选定参考响应/科学场的目标信号；
- H_k 是已知/近似已知的有效 PSF、色彩响应及像素积分算子，若经处理可近似 I，须给出条件；
- a_k 是可估计的**加性相对背景**；
- r_k 是未被 H_k 描述的通带系统差、残余乘性响应、平场/非线性和采样误差；
- n_k 是随机噪声，按球面位置与空间相关核描述。

不应通过加法补偿任意 r_k。重叠观测的相对定标需要处理公共模与参数规范[1]。背景分离的统计前提是多个实际观测的重叠区提供了关于 a_i−a_j 的独立约束；若没有这种约束，模型外推或正则化不能凭空制造绝对背景信息。

## 3. 重叠图与规范自由度

每帧是图节点，满足真实有效重叠、可用控制估计量并符合空间匹配条件的帧对形成边。图必须按**有效观测边**求连通分量，而不是按“天区近似相邻”或空记录凑边。设图有 C 个连通分量，所有相对平衡关系只在各自分量内确定。

理想差模约束：
\[
 y_i(p)-y_j(p)\approx a_i(p)-a_j(p)+
 [H_i-H_j]B_0(p)+[r_i-r_j](p)+n_i(p)-n_j(p).
\]
若忽略模型不一致项，就可能把真实天体颜色/PSF 结构拟合成加性差。

对每个连通分量 \(\mathcal C\)，背景相对差对公共偏置自由：
\[
 B_0(p)\to B_0(p)+g_{\mathcal C}(p),\quad
 a_k(p)\to a_k(p)-[H_k g_{\mathcal C}](p).
\]
这里g必须属于共同退化空间：每个H_k g均可由该帧允许的背景基表示，且满足实际控制观测的相同变换。仅在H_k≈I及其近似适用时才简写a_k→a_k−g。共同零空间取决于响应、背景基和有效重叠，不能把任意空间函数都当作规范；它可能不只包含常数。需要按模型参数空间判定可辨识秩与零空间，并为每个分量固定规范（例如相对参考帧、或在有共同支持的位置加权校正和为零）。指定某个参考帧为 0 是坐标选择，不是该帧物理背景恰好为 0 的观测证明。

两个无相连有效重叠边的分量，彼此绝对背景差不能从这两组数据内部恢复。弱正则锚只选一组平滑解，不产生真值。允许为用户继续生成图像，但必须保留此科学限制，不能制造“跨分量已统一”的陈述。

## 4. 联合背景和逐帧差模

用有噪声意义的背景控制观测 \(z_{kc}\)，在每个连通分量上求公共天空与逐帧差：
\[
 \min_{B,\{\alpha_k\}}
 \sum_{(k,c)\in{\cal O}}
 \rho\!\left(\frac{z_{kc}-[HB]_{kc}-
                  [A_k\alpha_k]_{c}}{\sigma_{kc}}\right)
 +{\cal R}_B(B)+\sum_k {\cal R}_{a,k}(\alpha_k).
\]
A_k 是逐帧低阶多项式/样条基，\rho 是稳健损失，σ_kc 是与**背景控制统计量**同对象的标准差，不可直接用参考恒星 SNR 反推而不建立模型。

若在拟合残差上构建逐帧场 F_k，必须保证：
- F_k 解释的是联合解未解释的**差模**，不得再次作为独立绝对公共面扣除；
- 去公共模操作 Σ_k u_k(p)F_k(p)=0 使用相同的有效帧集合、坐标和权重，且权重一旦迭代变化需要一致更新；
- 即便这条代数恒等式成立，保存的是该加权平均量，并不自动等于无偏真实的星云低频信号；
- 额外背景自由度只能在有效控制/重叠和独立验证支持的空间尺度上添加，不能单纯靠“缝更少”决定网格越密越好；
- 在单帧区没有数据驱动的相对场约束时，只能按选定延拓/恒等约定处理并标记外推的影响。

同时求解公共场与差模，通常比先把每一帧各自高阶拟合、再对高频结果修补接缝更能保留大尺度信号。

### 4.1 正确的共模消元、联合加性场拟合与 rank 判据（2026-10-17 推导）

先限制为**物理响应可共同解释**且增益/噪声/样本资格已冻结的一个有效重叠连通分量。将像元/控制点观测堆叠为 `y=H_g S+A\alpha+\epsilon`；`H_g` 含逐帧有效 PSF、几何及当前残余增益，`A` 由加性曲面的**实际求值基函数**装配，`W=C^{-1}\succ0`。在线性参数下，对固定 `α` 可将 S 精确按 GLS profile out：

\[
Q_H=I-H_g(H_g^TWH_g)^+H_g^TW,\qquad
Q_HH_g=0,\quad WQ_H=Q_H^TW\succeq0,
\]

\[
L_{\rm prof}(\alpha)=(y-A\alpha)^T WQ_H(y-A\alpha)
+\lambda_a\|L_a\alpha\|^2 .
\]

这**只在 H_g 对被保护公共场描述充分**时删除共同天体结构；其结果是识别相对加性参数，不是恢复绝对背景。对于 `H_k=I`，同一像素处 `H_g=g=(g_1,\ldots,g_K)^T`，退化为局部 `Q_g=I-g(g^TWg)^{-1}g^TW`。不同 PSF/通带应使用真正的 `H_g` 和 SED 模型；无共同物理场时，应按响应组估计独立的 S，不得在跨滤镜组强行相减。

在**明确固定每个连通分量的 gauge 后**，`Q_H A` 对待估参数列满秩，才可能由观测唯一识别相对加性场。规范可由具名参考帧/系数空间零均值确定；其取值是坐标约定，不代表物理天空为零。若无星/外部锚，额外自由增益 `g_k=\exp(\Phi_k\eta_k)` 的 Jacobian `J_\eta=\operatorname{diag}(g_k H_kS)\Phi`，若与 `H_g` 和 A 的列空间重合，就不能从图像自身分别识别 g、S、a；应加入独立未饱和 matched-star 相对光度及颜色/PSF/孔径模型，只在保留样本的真实秩充足时更新 η。

**数值实现的具体修订**：现行 `sky_plane.cpp::sky_make_residual_fields` 按 `floor(u/step)` 将一个 residual 分配给唯一格点，但后续 `sky_own_eval` 用四结点双线性基求值。这个 F-step 并非对应真实作用算子的精确最小二乘，不能由“分箱均值更新”推导每轮优化收敛。应从**同一 sky_own_eval 四结点 basis**构造稀疏设计行 `B_{tj}`，以 `r_{kt}=y_{kt}-[H_gS+A_{\rm base}\alpha_{\rm base}]_{kt}` 解当前实际掩膜/权重的
\[
\min_{f,S_c}\sum_{k,t}w_{kt}
\left[r_{kt}-\sum_j B_{tj}f_{kj}-[H_gS_c]_{kt}\right]^2
+\lambda_f\sum_k\|L_ff_k\|^2,
\]
并将每个分量 gauge 和实际支持域显式编码。可用白化稀疏 QR/LSQR 求解，或在条件数/秩可诊断时使用带检查的正规方程；floor-bin 只做可选初始值，不能取代精确 F-step。每次更新必须按**同一冻结目标、同一完整拟合/评价 basis**比较 `L_before/L_after`，若没有改善则拒绝这次更新。稳健 IRLS 改权后重新定义目标，单步下降不能自动推出跨 IRLS 目标下降。多轮要明确可识别域、参数尺度、收敛与不收敛；不需把“迭代多次”当创新点。

对于正半定 W 与正半定惩罚矩阵，固定 g 下正规矩阵 `D^TWD+L^T\Lambda L` 必为 PSD。若精确消去的是 SPD 主块，对应 Schur 补仍 PSD；只有剩余规范自由度已固定且可辨识时才严格 SPD。因此 [#80](https://github.com/fujiaze/Astro-CS-Database/issues/80) 的 reduced not-SPD：数值上近零特征值与真实 gauge/未支持方向一致；明显负特征值提示有效权、装配/Schur 消去或计算精度问题；若实现用非线性完整 Hessian 而不是正权最小二乘 Gauss–Newton 正规矩阵，则 Hessian 可真不定，须独立辨别。**禁止单凭增加 ridge 便宣布模型可识别**。

本解法属于 additive-only 生产替代候选；乘性 A+G 联合扩展可参照 Golub–Pereyra variable projection [DOI:10.1137/0710036](https://doi.org/10.1137/0710036)，以外部星点证据与留出负例决定是否增加 η，当前没有生产与真实 E2 支持，不冒称已部署。

**数值实现语义（生产已装，2026-10-18）**：求解矩阵 \(A=H_{\rm red}+\lambda_{\rm numerical}D^\top D\) 的直接 Cholesky 失败时，只在**惩罚零空间候选基** \(Q\subseteq\ker D\) 上加极小 Tikhonov 锚 \(A_\alpha=A+\alpha QQ^\top\)，再用精确 deflation \(X=A_\alpha^{-1}Q\)、\((I-\alpha Q^\top X)w=\alpha Q^\top A_\alpha^{-1}b\)、\(B=A_\alpha^{-1}b+Xw\) 把锚偏置扣回（该式恒有 \(AB=b\)，旧 Q-only 形式一般不满足，已退休）。回退分支以「\((I-\alpha Q^\top X)\) 的 Cholesky 成功」为 \(A\) 数值正定的判据——因 \(A\succ0\) 时该矩阵恒等于 \((I+\alpha Q^\top A^{-1}Q)^{-1}\in(0,I]\)——并以原方程 normwise 后向误差与算术门 \(\tau_{\rm floor}=\max(n_{\rm obs},n_{\rm free})\epsilon\) 复核。\(Q\) 只是 \(\ker D\) 的候选子集（掩膜把支撑切成多个 stencil 连通块时 \(\ker D\) 维数大于四），覆盖不足或方向不可分辨时返回具名 `P2_SKY_PLANE_NOT_IDENTIFIABLE` 与读数，**不**加任意 ridge、不降低阈值、不丢像元。算法、反例、独立 oracle 与真实 A/B 见 [Phase2 sky-plane 算法](../algorithms/mosaic/PHASE2_UPM_IMPL.md) §3.1/§6 与 `实验/issue80-p5-a1-production-fix/REPORT.md`。

### 4.1.1 相对增益图的可辨识性、误差与循环闭合（2026-10-17）

仅当已配准并通过 PSF/颜色/孔径修正的**同一恒星**提供独立观测时，才将帧间 log 通量比用作增益测量。对每个有效重叠边 `e=(i,j)` 的统计量 `d_e`，模型是
\[
d=B\eta+e,\qquad B_{e,i}=1,\ B_{e,j}=-1,\qquad\operatorname{Cov}(e)=\Sigma_e\succ0.
\]
`B` 是取向任意但冻结的重叠图关联矩阵；不同边可共享恒星、测光标定、背景参数，因此其协方差通常**不是**自动对角。独立边条件下 `W_e=\operatorname{diag}(1/\sigma_e^2)`，信息矩阵为图拉普拉斯 `L=B^TW_eB`；一般有相关边则是 `L=B^T\Sigma_e^{-1}B`。

在全部边权正且对应真实约束的前提下：
\[
\eta^TL\eta=\|\Sigma_e^{-1/2}B\eta\|^2,\quad
\ker L=\ker B=\operatorname{span}\{\mathbf1_{\mathcal C_1},\dots,
\mathbf1_{\mathcal C_C}\},\quad \operatorname{rank}L=K-C .
\]
**证明**：二次型为零当且仅当每条有效边两端参数相等；沿每个连通分量传递，只能留下每分量一个常数。这是严格的可辨识性定理，不依赖星点通量有多亮。对每个分量取 `Σ_{k∈C}η_k=0` 的**坐标规范**时，GLS 的最小范数估计 `\widehat\eta=L^+B^T\Sigma_e^{-1}d`；相对参数协方差在上述线性高斯/已知 Σ 条件下是 `L^+`。对可识别差值 `c=e_i-e_j`（i、j 同分量），
\[
\operatorname{Var}(c^T\widehat\eta)=c^TL^+c,
\]
即图中的**有效电阻**；单一桥边或弱星约束会放大该方差。若跨分量，`c` 不属于行空间，公式 `c^TL^+c` 的有限数值**不能解释成真实跨分量误差条**，因为相对零点根本不可识别；须标 `unavailable`。独立外部标准星可额外连接绝对零点，但误差传播应含锚不确定性。

循环中 `d_{ij}+d_{jk}+d_{ki}` 理论期望为0（方向一致），标准化残差使用完整边协方差检验；显著非零可能来自 PSF/颜色/时变透明度系统项、关联误差或不正确的统计独立性，不自动归结为真正残余 gain。参数数超过图 rank，或者低阶 `η_k(p)` 的空间场基与现有星点位置不匹配时，**图连通本身不保证空间增益场可辨识**，仍需对实际 `J_\eta` 做秩诊断。

独立可运行数学参考（非 production）：[graph_and_affine_oracles.py](../../../实验/innovation-closure/code/graph_and_affine_oracles.py)，含连通/断连分量、正定加权、规范及相对协方差的解析对照；实验预注册见 [#76](https://github.com/fujiaze/Astro-CS-Database/issues/76)。本节不声称生产已装入该参数求解器。

### 4.2 加性/增益校正后的完整线性化误差

对`z_k=(y_k-a_k)/g_k`、`g_k=e^{\eta_k}`，
\[
\delta z_k=g_k^{-1}\delta y_k-g_k^{-1}\delta a_k-z_k\delta\eta_k,
\qquad C_z=J\,\operatorname{Cov}(y,a,\eta)\,J^T .
\]
同数据拟合产生的 `Cov(y,a)`、不同帧共享 Gaia/Master/背景锚引起的交叉项及低频参数系统项均须计入。仅当 a、g 是固定已知外参，`SNR(z)` 才在正的确定性增益除法下保持配对不变；sky shot noise 已在光子读出时产生，扣除其均值不能消去 shot-noise。若残余场只从同一组 y 估计，则 `C_z` 可能含负的交叉协方差、相关核及真实天体泄漏，不能一律简单把拟合方差加到像元方差，也不能声称“共模增强不损失任何 SNR”。背景差分若有无法识别的低频共模，应当保留该模式及其相对零点不确定性，而非将平滑结果误当真值。

## 5. 背景控制点与空间相关

一个背景 patch 的测量值可以是中位数、稳健位置或其他已定义估计量。其方差不等于单像元方差。对 iid 高斯，样本中位数渐近有 Var(median)≈(π/2)σ²/N；有 Drizzle 相关、剪裁、非高斯结构和天体污染时，这一公式需要额外估计。实测的 k_corr 需按精确的 patch 统计量、HEALPix leaf/source 尺度、pixfrac 与相关模型重新标定。

尤其：
- 参考点源 SNR/PSF 信息量属于星测光估计量；
- 背景 control_ivar 属于背景位置估计量；
- 最终像元 w_B 属于面亮度合成估计量。

三种精度的分子、支持域和协方差都不同。不能因为它们都有 “1/variance” 的形式就在 API 中共享一个语义不明的 weight 字段。

控制点应区分真正近似空背景的区域与包含复杂星云/暗云结构的区域。高 SNR 亮星、衍射/光晕、彩色星云和 PSF mismatch 对背景估计的影响，不能只凭简易星表附近否决就认定已经消失。可使用鲁棒模型、显式污染标志、跨尺度诊断和扩展源结构保留检验，而不是用高阶拟合强行消去不符合“平滑天空”假设的信号。

## 6. 加性差、光度增益和 PSF 不同的处理职责

**P1 光度归一**先从 Gaia XP 合成星光谱/实际响应获得可解释线性标度 k_photo；有数据支持时拟合空间乘性场 m_k(x)。阶段二不能把该校准再次盲乘。

**P5 相对背景**用真正空背景控制、重叠差模和各分量规范调整加性场 a_k(x)。不能用背景模型吸收星点比例偏差，不能用只在暗场成立的结果保证所有星云纹理无缝。

**残余乘性差**如果有真实独立证据，才考虑
\[
 y_k^{\rm corr}(p)=(y_k(p)-a_k(p))/g_k(p).
\]
若 g_k 未实施、未识别或数据不足，使用恒等 g=1 作为**保守模型选择**；不写成已实验证明所有增益等于 1。共同点源星等比的残差须在颜色、天区位置和 PSF/孔径校正分层后估计，避免把色差冒充增益。g 的不确定性是跨位置系统量，不能作为纯独立白噪随叠加消失。

**PSF/采样差异**通过响应建模、适当的有效 PSF 对照与采样方法处理；必要时允许用户为科学精度主动做 PSF matching，但不默认强行把所有图像退化到最差设备 PSF，以免损失高分辨率数据。用于背景控制的共同采样尺度与最终图像最佳保真尺度可以不同。

乘性模型须包含真值g=1的阴性对照；拟合降低接缝RMS也可能来自额外自由度、噪声过拟合或真实结构损失，不能单凭这一读数证明增益可辨识。具体对照见[增益与边界实验](../../../实验/additive-sky-seamless/docs/S07_REPORT.md)。

## 7. 接缝评估必须同时估计真实信号损失

真正的无缝不是“输出表面没有任何梯度”，因为许多天区本就含真实大尺度梯度。

评估的空间对象：
1. **有符号台阶**：跨输入足迹边界两侧的局部差值，随跨界距离 d 做扫描；硬台阶与连续星云坡度应区分。分母小/近零的相对台阶不可定义，不能自动算为零。
2. **重叠一致性**：同一天区、不同帧的留出独立观测差及误差标准化，按颜色、PSF、支持域和相对曝光分层。
3. **星点光度**：校正前后 matched stars 通量、色差残差、FWHM、周围背景。
4. **扩展源保真**：已知真值结构、模拟低频功率、扩展源总通量、梯度与局部颜色。
5. **覆盖事实**：输入足迹真实边界共多少、实际测量多少、遗漏原因是什么。不得把未测边界归入“没有接缝”。
6. **随机效率**：使用独立观测/模拟比较同一输出球面信号的散度，而不是仅观察最终图像的局部样本方差。

羽化、平滑和补零可以使视觉接缝消失，但如果牺牲低频真实结构就不构成科学意义的成功。应保留“无校正”“仅加性”“含独立乘性证据”“保真优先”的明确对照，报告差异而非人为追求某个单一得分最小。

## 8. 阶段二图像输出

对每个 HEALPix 叶 p，先完成有效样本资格、背景/标度校正和异常样本剔除，再用[噪声分册](../noise_snr/NOISE_SNR.md)定义的实际场景面亮度权重求最终 signal。没有合法数据时标 NaN，不以 0 假冒暗天区。内部支持度、精度、控制点、参数协方差和诊断可以存在于计算缓存或运行报告，但最终**一个 signal HiPS 科学图像子产品**，不自动发布 support/variance/ivar 产品层。

不同通带数据即使被纳入一个 HiPS，物理响应/混合规则仍应在标准允许的元数据/随运行清单说明中如实记录；不能仅以“R 滤镜”简写精确的等效 bandpass。阶段三只重投影这个信号产品，不能从它恢复原始多设备测光差模。
