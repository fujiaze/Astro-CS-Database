# 天体测量与世界坐标系

> 上游：《ACSD 最高设计》（docs/ACSD_DESIGN.md）的「normalize：单帧标准化」节点流程与「输出合同」两章

## 1 主题与目标

天体测量层的职责是：给定一帧图像与一个近似指向，解出该帧的世界坐标系，使像素坐标与天球坐标之间可追溯。它是三件事的共同前提——测光拟合需要在像元域解算出的位置、残差，面亮度守恒映射算子需要天球坐标定义每个像元的球面足迹，信号参考面需要天球重叠图。

本分册固定四件事：

- **坐标约定与桥接**——内部 0-based、FITS 1-based、参考像素三者的唯一换算点；
- **投影与畸变模型**——切平面投影加低阶简单多项式畸变（SIP, Simple Imaging Polynomial）的正逆向定义；
- **不变量**——与解算结果无关、必须恒成立的关系；
- **验证口径**——用第三方独立实现对拍的判据，以及必须能被检出失败的负向注入。

**非目标**：不保证超出 SIP 阶数的畸变残差（残差进入质量报告）；不做大气折射与色差的高阶修正；不提供超越单次切平面投影的广视场拼接模型。

## 2 物理模型

### 2.1 坐标参考系

天球参考系是 **ICRS / J2000 赤道系**，与 Gaia DR3 星表同系 [4]。天球坐标以度为单位，`RA ∈ [0, 360)`、`Dec ∈ [−90, 90]`。内部球面计算用弧度，跨库接口一律用度。

### 2.2 投影与畸变的分工

天测解算分成两个独立的几何环节：

- **投影**把（已去畸变的）切平面坐标映射到天球。切平面投影（TAN, Gnomonic / Tangent Plane）是本链的唯一投影：视场内所有方向到大圆为直线，畸变只由切平面畸变引入。它在天测中是最古老的投影，几何关系由 FITS WCS 标准的第二篇给出。
- **畸变**由 SIP 多项式刻画 [3]。SIP 的多项式自变量是**像元偏移**（相对参考像素 `CRPIX`），不是中间世界坐标；系数与像元偏移同量纲（`pixel^(1−i−j)`），先与偏移相加、再与线性变换矩阵相乘，才给出角度偏移 [1, 2, 3]。

把两者分开是必要的：投影是精确的（给定切平面坐标到天球是闭式），畸变是近似的（多项式截断有残差）。混在一起会让"残差来自投影还是来自畸变"无法归因。

### 2.3 像元坐标约定与桥接

内部像素坐标是 0-based 的数组下标；FITS 输出用 1-based。FITS 标准的像素映射是

```text
q_i = Σ_j m_ij · ( p_j − r_j ) ,        r_j = CRPIX_j
```

其中 `q_i` 是无量纲的中间像元偏移，`r_j` 是由 `CRPIX_j` 给出的参考像元坐标元素 [1]。标准同时规定**整数像元号指像元中心**，例如第一个像元在每个轴上从像元号 0.5 到 1.5 [1]。

**桥接口径**：每一个 0-based 的量在它自己的输出边界上恰好施加一次"下标 → FITS 1-based"换算，`+1` 在整链中只施加一次。双重桥接与桥接缺失都会产生恒定 1 像元的系统偏移，且**必须在第三方对拍中被检出**——这是本层最有价值的负向注入。

本链上真正需要施加 `+1` 的只有两个量：检出目录的整数数组下标，与导出产品的网格下标。它们是同一"下标 → FITS"换算在不同域各一次，与天测求解器内部的口径无关。求解器内部的拟合自变量取**像元中心的 FITS 坐标**：0-based 数组下标 `k` 对应 FITS 第 `k+1` 号像元，其中心坐标为 `k + 1`。偏移量取 `像元中心 − w/2 = (k + 1) − (w/2 + 0.5) = k + 0.5 − w/2`，而 `CRPIX = w/2 + 0.5`，因此该偏移量**恰好就是标准式中的 `q`**；迭代反演的输出 `偏移量 + CRPIX` 返回的已经是 1-based 的 FITS 像元坐标。求解器输出侧**不再叠加** `+1`。把这一层的输出标注为 0-based 属于标签错误，不是约定差异。

### 2.4 切平面投影的原生坐标

切平面投影的原生球面坐标取 `(φ₀, θ₀) = (0°, 90°)`，即天球北极为投影原点，此时参考天球坐标（`CRVAL`）就是天球北极的坐标 [2]。`LONPOLE` 的缺省取值规则是"当 `δ₀ ≥ θ₀` 时取 0°，否则取 180°"，因此**在天顶投影族里缺省恒为 180°**（除非 `δ₀ = 90°`）[2]。

投影本身为

```text
R_θ = (180°/π) · cot θ                     θ 为原生余纬
θ   = arctan( 180° / (π R_θ) )              逆投影
```

[2]。切平面投影在原生余纬 `θ = 0` 处发散，即在离切点大距 90° 的那条大圆上发散；对天顶投影族（`(φ₀, θ₀) = (0°, 90°)`）这条大圆就是原生赤道。因此参考点只能取在切点所在的半球内、必须避开投影地平线——原生纬度取 `90°` 正是为了让参考点落在原生极点（此处即天球北极）上，而不是因为天球北极本身发散 [2]。

### 2.5 极区的保守剪枝

星表锥与像元矩形的相交判定在极区会退化。解算器对 `|Dec| > 45°` 进入极区分支，对更高纬度采取更保守的判定：`|Dec| ≤ 85°` 时，锥球心距与半径构成的平面盘与节点矩形不相交即可安全剪枝，剪枝常数取 `π/2`（与 `π/2 ≈ 1.5708` 同量）与 `π/(2√2) ≈ 1.1107` 两档，保守档用于高纬。赤道经度环绕（`ΔRA > 180°`）按 `360° − ΔRA` 取短弧并以赤纬余弦缩放。

## 3 公式与推导

### 3.1 正向与逆向

```text
正向（像元 → 天球）:
  xp = x + 1 ,  yp = y + 1
  (ξ, η) = CD · [ (xp − CRPIX) + SIP_A/B(xp − CRPIX) ]
  (RA, Dec) = TAN⁻¹( ξ, η ; CRVAL )

SIP 前向系数（解析）:
  A[i][j] = cd_inv · trans.x_ij ,   B[i][j] = cd_inv · trans.y_ij
  cd_inv = inv(trans 的线性项)

SIP 逆向系数（最小二乘）:
  UV   = cd_inv · IWC
  AP/BP = argmin ‖ UV − [ (u,v) + SIP_A/B(u,v) ] ‖²      在采样网格上
  约定 AP[1,0] −= 1 , BP[0,1] −= 1                        剔除单位线性

Y-up → Y-down（FITS 1-based 输出）:
  cd12, cd22 取反
  A′[i][j] =  A[i][j] · (−1)^j ,   B′[i][j] = −B[i][j] · (−1)^j
  AP/BP 同规则 ;  CRVAL / CRPIX 不变 ,  |det(CD)| 不变
```

线性变换矩阵 `trans.linear` 的量纲是弧秒每像元，`CD = trans.linear / 3600` 的量纲是度每像元；畸变多项式系数与**像元偏移同量纲**（`pixel^(1−i−j)`），先与偏移相加、再乘 `CD`，合出度 [1, 2]。`cd_inv = inv(trans.linear)` 的量纲是像元每弧秒，**不得写成度每像元**——写成度每像元会让畸变项与线性项量纲不一致；其数值后果是 `inv(L/3600) = 3600·inv(L)`，畸变项被**放大 3600 倍**（逐元素口径），只有行列式口径才是 `3600²` 倍。

本链的 A/B 系数采用的就是 SIP 定义的像元域量纲 `pixel^(1−i−j)`：多边形项与像元偏移 `u, v` 相加后才作用 `CD`，中间世界坐标（度）是这一步的落点而不是系数的定义域 [3]。因此本链系数与 SIP 标准同口径，读侧不需要额外的 CD 换算；写侧与读侧都必须按这一顺序实现，否则会丢掉 `CD` 的作用位置。

### 3.2 尺度与残差的换算

残差必须分两个量纲各自命名：

```text
rms_px     = rms_arcsec / s0 ,      s0 = 3600 · sqrt( |det(CD)| )   [arcsec/pixel]
```

`s0` 是**线性**标度，不含 SIP 的局部标度。用"像元/角秒"作为残差单位会被读成"每角秒的像元数"，与像元残差相差 `s0²` 倍——这是必须避免的写法。

### 3.3 畸变多项式的逆

正向畸变多项式的逆不是解析的，只能用两种方式之一得到：迭代反演，或对逆向多项式做最小二乘拟合。逆向多项式的拟合需要一张覆盖整幅像元的采样网格；网格点过少会使逆多项式在边缘严重失真。本链的前向畸变阶数为 2–3，逆向多项式的拟合阶数更高（生产实现为 5 与 7 两档），采样网格相应为 41×41 与 81×81。

**这是本层最重要的适用域之一**：逆向多项式的表示误差比迭代反演的收敛误差大若干个量级，因此在边缘畸变可达数十像元的仪器上，用逆向多项式去要求与迭代反演相同的往返精度是不成立的。判据必须分层给出，不得用同一个数同时服务三条路径。

## 5 判据与误差

### 5.1 不变量

四条不变量与解算结果无关：

- **参考像元不变量**：`CRPIX = w/2 + 0.5, h/2 + 0.5` 恒成立；
- **行列式不变量**：Y-up → Y-down 转换只重排符号，`|det(CD)|` 不变；
- **畸变逆一致性**：以迭代反演为准，往返残差在**独立于拟合采样的密集域**上测量（中心 90% 区域、四边、四角，加上不少于 1000 个随机点），不得在拟合用的自网格上测量——自网格上的残差按构造为零，鉴别力为零；
- **极区保守性**：`|Dec| ≤ 85°` 时剪枝不得产生假阴性。

### 5.2 桥接门：两个用途不同的门

桥接判据必须分成两个门，因为它们的适用域不同、判别力也不同：

- **全域保守门** `1e-6` 像元**：覆盖所有像元尺度。保守性下界取 `1.79e-3` 角秒/像元（实测常数）与 `2.93e-3` 角秒/像元（设计常数），比任何真实仪器的像元尺度还小一到两个量级。代价是判别力弱：在亚角秒/像元量级处相对解析包络的余量约两个数量级，`1e-7` 量级的缺陷会被放过。
- **特定尺度下的紧门 `1e-8` 像元**：适用域是像元尺度不低于 `0.9` 角秒/像元。两个余量各自独立：解析包络口径的余量不低于 `5.0` 倍（`0.9″/px ÷ 0.179″/px`，即上门的实测常数）；独立区间算术包络口径的余量不低于 `2.8` 倍（该包络在 `0.18″/px` 处为 `1.78e-8` 像元，按 `1/s` 外推到 `0.9″/px` 得 `3.56e-9` 像元，`1e-8 / 3.56e-9 = 2.81`）。**尺度低于适用域下限时该门不适用**，报"超出适用域"而不是判红——判红会误拒：在远低于该尺度的区域，独立区间算术包络本身就大于 `1e-8` 像元。

两个门都在九宫格（中心、四角、四边中点）加密集域扫描上测量，并与标准式给出的独立第三方参考对拍。**负向注入必须产生至少 1 像元偏差并使对拍失败**：移除桥接（`xp = x`）与错置桥接（`xp = x + 2`）在 x、y 两个方向各偏 1 像元，合成偏差为 `√2` 像元。

**误差来源的推导**：切平面投影的正逆向互为闭式，复合恒等于恒等映射，投影本身不引入截断误差；因此桥接门的误差 100% 来自双精度舍入，主项为

```text
ε ≈ C_env · u · sec²Δ / s_rad
u = 2⁻⁵³        C_env = 78（一阶包络实测最大值）/ 128（本链采用的设计常数）
sec²Δ = 1 + (FOV_rad/2)² ≤ 1.03046      对应导出平面视场 FOV ≤ 20°，即离切点角距 γ_max ≈ 9.90°
```

以 `s_rad` 取弧度每像元（`s = 0.9″/px` 即 `s_rad = 4.364e-6`）代入：紧门适用域下 `C_env = 128` 给 `ε ≈ 3.36e-9` 像元，与 `1e-8` 相差 `2.98` 倍；同一组常数在全域保守门下界 `s = 1.79e-3″/px` 处配 `C_env = 78` 给 `ε ≈ 1.03e-6` 像元，与 `1e-6` 恰好同量级。三处取值互锁，因此门值、`C_env` 与适用域下限必须成组引用，不得单独摘用其中一个。合成规则取**最坏情况包络线性相加**，不用均方根——包络与均方根的比值由分母口径决定，两者不互为替代。

### 5.3 往返门的分层

往返精度判据分三层，数值相差五到九个量级，**同一个数不能同时服务它们**：

| 路径 | 门 | 性质 |
|---|---|---|
| 迭代反演（生产路径） | 收敛容差乘以收紧系数 | 该路径的收敛地板，与双精度地板同量级 |
| 全链冻结门 `1e-4` 像元 | 判据力弱 | 实测最坏值比它小约四个量级；它是**冻结门**而不是双精度地板门 |
| 逆向多项式表示门 | 边缘畸变预算的一定比例 | 在边缘畸变可达数十像元时，多项式逆达不到 `1e-4` 像元 |

### 5.4 极区剪枝门

对 `|Dec| > 45°` 的人工锥与全量星表节点做暴力比对，假阴性必须为零。这一门的鉴别力来自"暴力"一侧：只用剪枝器自身无法证明它不漏。

### 5.5 外部闭环指标

闭环指标的定义是：**一帧真实数据的检出星子样本，经解算出的 WCS 前向映射到天球后，与星表一最近邻星的真实大圆角距，取不超过 1 角秒者的中位数。**

指标必须与下面四项**同报**，缺任一项即不可解释：

| 项 | 规定 |
|---|---|
| 检出星样本 | 目录中坐标有限、且峰值信噪比高于给定门限的子样本 |
| 样本上限 | 按通量降序的前 N 个；超限时必须记录是否截断与被计入的星数 |
| 星表样本 | 本地 Gaia DR3 XP 星表的单锥搜索，给定星等上限 |
| 匹配半径 | 固定 1.0 角秒，并写入记录 |
| 统计量 | 中位数，同时报 p95、最大值、匹配数与匹配率 |
| 像元尺度换算 | `中位角距 / s0`，`s0 = 3600·sqrt|det(CD)|`，必须同报 |
| 残差定义 | 一最近邻选择用切平面近邻树，最终距离用**真实大圆角距**，不用平面近似代替 |
| 独立性 | 只用第三方天文库从产物文件重建 WCS 与星表解码，不导入本链实现、不读内部结果文件 |
| 复现容差 | 同输入同口径两次运行，中位数与匹配数完全相等 |

**判读纪律**：该指标**不是**天测精度本身——它同时含检出星质心误差、星表系统差、投影与畸变模型残差以及错配长尾。它必须与解算内部的残差统计和匹配数联合判读；中位数与匹配率分开看都没有意义，因为中位数只描述"已匹配的那些星"。

**阈值必须按像元尺度分档给定**：不同像元尺度的两档之间不可互推。分档阈值的数值面是**待标定**的——标定的输入条件是母版标度问题修复之后的帧，标定完成前这些读数一律不得当作判据。

### 5.6 不可接受的变化

- 改变参考像元的冻结公式或 1-based 与 0-based 的换算；
- 在导出边界之外再施加一次桥接，或在该边界处缺失桥接——两者都产生恒定 1 像元系统偏移；
- 把逆线性变换的量纲写成度每像元；
- 省略 Y 翻转的 `cd12`/`cd22` 符号反转或畸变系数的 `(−1)^j` 因子；
- 在极区移除保守剪枝。

### 5.7 失效域

| 条件 | 显式后果 |
|---|---|
| 检出星不足以约束解（数量少或几何退化） | 返回无解，不写 WCS，不产生伪 WCS |
| 线性变换奇异 | 拒绝畸变推导，返回参数错误 |
| 查询矩形为空或越界 | 告警，不产生伪解 |
| 极区锥跨越天顶或跨越 `±45°` | 不剪枝，退化为遍历 |
| 经度环绕 `±180°` | 取短弧并按赤纬余弦缩放判交 |
| 视场跨越切平面投影的发散区（离切点大距接近 90°，即接近原生赤道 `θ = 0`） | 参考点必须取在投影域内，落在发散区时拒绝 |

## 6 与上下游的关系

上游是最高设计的 normalize 流程与输出合同。下游：面亮度守恒映射算子用解出的 WCS 定义每个像元的球面足迹；信号参考面的重叠图用天球坐标判定；测光与 PSF 拟合用像元域残差作诊断。

本分册对外提供的三条约束：内部像元中心约定（下标 + 0.5）；参考像元冻结公式；桥接在每个量上恰好一次。

Astronomy & Astrophysics, 2002, 395(3): 1061–1075. https://doi.org/10.1051/0004-6361:20021326（预印本 [arXiv:astro-ph/0207407](https://arxiv.org/abs/astro-ph/0207407)；逐字核对第 2.1.1 节式 (1) `q_i = Σ_j m_ij (p_j − r_j)` 与 `r_j` 由 `CRPIX_j` 给出，以及第 2.1.4 节整数像元号指像元中心、第一个像元从 0.5 到 1.5 的约定）

[2] Calabretta M. R., Greisen E. W. Representations of celestial coordinates in FITS. Astronomy & Astrophysics, 2002, 395: 1077–1122. https://doi.org/10.1051/0004-6361:20021327（预印本 [arXiv:astro-ph/0207413](https://arxiv.org/abs/astro-ph/0207413)；逐字核对天顶投影族 `(φ₀, θ₀) = (0°, 90°)`、`LONPOLE` 缺省为 180° 的规则，以及切平面投影式 (54) `R_θ = (180°/π)·cot θ` 与逆式 (55)）

[3] Shupe D. L., Moshir M., Li J., Makovoz D., Narron R., Hook R. N. The SIP Convention for Representing Distortion in FITS Image Headers. Astronomical Society of the Pacific Conference Series, 2005, 347: 491–495.（已取全文逐字核对第 492 页式 (1)–(3)：`u, v` 是以 `CRPIX` 为原点的相对像元坐标，`x, y` 是以 `CRVAL` 为原点、以度为单位的中间世界坐标，`f(u,v) = Σ A_pq u^p v^q` 先与 `u` 相加、再由 `(x,y)ᵀ = CD·(u+f, v+g)ᵀ` 作用 CD）

[4] Gaia Collaboration, et al. Gaia Data Release 3. Astronomy & Astrophysics, 2023, 674: A1.（书目级核验；本链只消费该星表的数值，不引用其方法）

参考代码：WCSLIB（LGPL-3.0，<https://www.atnf.csiro.au/people/mcalabre/WCS/>）与 astropy 的 `astropy.wcs`（BSD-3-Clause，<https://github.com/astropy/astropy>）是解算与对拍的独立第三方实现；ERFA 是球面坐标变换的独立实现；astrometry.net（GPL-3.0-or-later，<https://github.com/dstndstn/astrometry.net>）提供四叉匹配与视场验证的对照口径；SCAMP（GPL-3.0，<https://github.com/astromatic/scamp>）提供多帧天体与光度联合校准的对照口径。四者均为宽松或记录型许可，只作行为对照，不复制入仓。
