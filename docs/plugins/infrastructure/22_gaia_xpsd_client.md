# 插件文档：gaia_xpsd_client（外部星表查询）

## 1. 职责与边界

- **职责**：查询 Gaia（及 XPSD 等外部服务）星表数据，管理网络、缓存、坐标/历元语义与版本，供 platesolve 等消费。
- **不是**：不做解算（platesolve）；不做科学权重；外部服务不可用时降级策略显式（不静默假数据）。

## 2. 权威依据

- 最高设计 `ASTROCS_DESIGN.md` §3.3（输入合同：Gaia/离线星表输入及版本）
- `docs/plugins/algorithms_phase1/05_platesolve.md`（消费方）
- Gaia 数据模型（外部标准）

## 3. 输入/输出数据合同

- **输入**：查询请求（天区、视场、星等范围、历元）、星表版本、配置。
- **输出**：星表行（位置、自行、parallax、光度、误差）、来源标识、缓存命中信息。
- 参考：`contracts/schemas/catalog_query.schema.json`。

## 4. 算法与公式要点

- 查询：按 WCS/天区发起，匹配视场约束；
- 缓存：按天区/版本缓存（磁盘+内存），缓存不改变数据语义；
- 坐标/历元：自行/parallax 传播到观测历元，语义显式；
- 版本必须随查询结果记录（星表版本影响下游，版本缺失 → fail-closed）；
- 离线星表输入与在线查询等价合同。

## 5. 配置项

| 字段 | 默认 | 单位 | 说明 |
|---|---|---|---|
| `catalog` | `gaia` | —— | gaia/离线 |
| `catalog_version` | —— | —— | 版本（必填） |
| `cache_dir` | —— | —— | 缓存目录 |
| `query_limit` | —— | —— | 单次查询上限 |
| `timeout` | —— | s | 网络超时 |

## 6. 接口/ABI

- entrypoint：查询请求 → 星表结果；
- platesolve 通过本模块获取匹配输入。

## 7. 错误与边界

- 网络不可用 + 无缓存 → 明确失败（可降级到离线星表，但需显式配置）；
- 版本缺失/不一致 → fail-closed；
- 缓存损坏 → 重新查询，不返回坏数据；
- 长时查询 → 超时与取消。

## 8. 测试与 Oracle

- 已知天区星表 → 与独立星表源交叉（位置/星等）；
- 缓存命中与失效正确性；
- 自行/历元传播正确性；
- 离线星表与在线等价测试；
- 网络失败降级策略测试。
