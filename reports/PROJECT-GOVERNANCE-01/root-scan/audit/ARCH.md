## 轴级收口建议（迁移顺序与机器门）

1. 迁移顺序（以 docs/modules/MODULE_MAP.yaml 为唯一 id/target 清单）：① ARCH-4 修 16 个 entrypoint 声明（纯声明面，先行）→ ② ARCH-1+2 建 target_dir 骨架并逐模块 STATIC→SHARED（每模块一 commit：目录+target+install 白名单+contract 四点同步）→ ③ ARCH-3 拆三 session 为节点级 entry → ④ ARCH-9 基建 git mv 归位 → ⑤ ARCH-7 唯一入口改名收口。
2. 机器门（不重复建设）：扩展既有三件套——check_module_map.py 的 M2 加「SHARED target 数=23 且 install 白名单 ⊇ 映射表」断言；check_abi_boundary.py 语料改由 MODULE_MAP 派生（ARCH-5）；CON-BUILD-GRAPH 加「无引用/游离构建文件对账」（ARCH-6）。每条门配负例 fixture（能红能绿，docs/ci/03_GATES §1）。
3. 审计局限：未执行 cmake configure/ninja（只读约束+并行线构建面抖动）；SHARED 计数为源码级 add_library 实数，若 configure 后 file-api 与源码不符，以 CI 实测为准。
