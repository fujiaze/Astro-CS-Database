- 问题说明: M4 独立按 :95-108 逐语句重算：pf=0.8 → wi=(0.8−0.5)/(1.0−0.5)=0.6 → i0=1.2 → c0=(size_t)min(1.2,2.0)=1、c1=2、fx=0.2 → 表格节点被替换为「列1 与列2 的 0.2 线性混叠」。sc=300：1.3925+0.2×(1.4980−1.3925)=**1.4136**（冻结表值 1.3925，**+1.52%**）；sc=600：2.8971+0.2×(3.2035−2.8971)=**2.9584**（冻结表值 2.8971，**+2.12%**）。pf=0.5/1.0 两端恰 exact（wi=0/1、fx=0），掩盖中段系统性错位；scale 轴 r0=(600−sc)/300 经复核无错。角点语义结论：「表节点 pf=0.8 × sc∈{300,600} 返回表外值」成立；「九角点」中两角失真。正确形式=两段分段线性（0.5–0.8、0.8–1.0 各自归一）或网格节点直接命中表值。生产可达性独立核实：①Phase1 写侧 provenance 落 properties（lib/core/src/astrocs_phase2_writer.cpp 复核时点 :927-928 ASTROCS_DRIZZLE_PIXFRAC，%.6f）；②采样侧读回（sampler.cpp:112-135,:547-555）pf>0 即 kcorr_lookup(pf,sc)，**scale 未知时固定 300 档（:554）恰命中失真值 1.4136**，比冻结保守值 1.4 还高；③「0.8 生产默认」独立于 :80 注释另有两处：lib/orchestrator/cpp/src/json_config.cpp:711-713（CFG-001，pixfrac 省略→0.8；其测试 test_orchestrator_cli.cpp:905-924 断言同值）、lib/drizzle/README.md:114；④生产链：astrocs phase2 run 的 sample 节点唯一入口 p2_sample_controls_cached（module_adapters.cpp :2774/:2784 → sampler.cpp:1138 → p2_sample_controls_impl :463 → :552-554 → cvar :840）。
