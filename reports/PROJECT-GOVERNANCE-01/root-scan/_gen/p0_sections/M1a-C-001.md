- 问题说明（复核时点，四段独立可验）:
  (1) **口径割裂**：SCI §5:57、§9:125 与 ALG §4/符号表均把逆向拟合钉为"7×7 网格"，实现无任何 7×7 网格（41×41 阶5；WCS-003 另加 81×81 阶7）→ 冻结文本描述的对象不存在。
  (2) **门与路径错配**：SCI §11 的 astropy 第三方交叉门（1e-4 px）与 §15:172 的"Oracle 全过"宣称，本轮复核确认其达成者是**迭代反演**（:514-521 自述"由迭代反演达成；一步法不达标"），而测试正是走该路径（apbp:267-313 用 `closure_rt`/`invert_point`；bridge 交叉测试用 `x_it` 与 **APx 阶 7** 系数）。
  (3) **导出能力缺**：C ABI 可导出的逆向面是 `AP[36]`（阶 ≤5、36 项）；APx/BPx[100]（阶 7）**不经该结构导出**，下游唯一 WCS 消费者 `wcs_transform.cpp:46-50` 硬要求 `sip_order ∈ [0,5]` → 被用于达标的那组系数在链路上不可达。
  (4) **残余一步精度**：真正可导出的一步法 AP/BP 误差在 F2 病态 fixture 上 ~7.6 px（代码自证），测试侧只设 50 px"非验收观察线"（apbp:256-257）。
  → 综合：SCI 的 1e-4 px 不变量在**产品可消费的导出口径上不成立**，且该"数学不可达"事实以注释形式挂起、未升为偏差登记。
- 影响: 天测逆向精度在产品消费面失真（一步逆变换残差可达像素级）；验收门给出与消费面不同的口径的"全过"结论；负责人裁决项未入台账（另见 M1a-B-001）。
- 建议处置: ①订正 SCI §5:57/§9:125 与 ALG 为"41×41 阶5（APx 81×81 阶7）"；②明确 1e-4 px 门的**适用路径**（若只约束迭代反演，须在合同写明"导出的一步 AP/BP 不受该门约束"并给一步门数值）；③把"需负责人裁决"升为正式偏差登记（DISP-WCS-006 描述订正）；④若要求导出面达标，则扩 C ABI 到 APx 并同步放宽 wcs_transform 的 [0,5] 校验（须裁决）。
