### M2b-B-02 Moc.fits 缺 MOC Table 3 强制键 ORDERING=NUNIQ / COORDSYS=C，注册表仍判 CONFORMANT
- 类别: B_STD_MISMATCH
- 建议优先级: P0
- 位置: lib/astro_image_io/src/hips/aio_hips_writer.cpp::write_moc_fits；docs/standards/STANDARDS_REGISTRY.md::D.hips 清单行 5 与偏差表 DISP-HIPS-005；runtime/io/hips_core.c::hips_parse_moc（旁证：读侧不校验强制键）
- 证据摘录:

  >     char* tform[1] = {(char*)"K"};

  - 注册表（原文）：「| §4.4.1（all-sky map 与 MOC 关系） | 覆盖由 MOC 表达；低阶像素=子像素聚合 | CONFORMANT | … | DISP-HIPS-005（moc_order 静默 clamp；低阶 UNIQ 对自家 reader 无效，Moc.fits 为 optional hint） |」
  - IVOA REC-MOC 2.0 §6「FITS keywords」Table 3 强制列（实测取回，列序 = Keyword | Definition | MOC1.1 | MOC2.0）：
  > ORDERING | The packaging method used. It is either NUNIQ (V1.1 or V2.0 SMOC) or RANGE (V2.0). | mandatory | mandatory
  > COORDSYS | The coordinate system in use. The value must be 'C' for SMOC (ICRS). | mandatory | mandatory
  > MOCVERS | … | NA | mandatory ；MOCDIM | … | NA | mandatory
  - 同节正文（原文）：「Since MOC 1.1 … the PIXTYPE = "HEALPIX" keyword/value is no longer required, and should be omitted. The keyword MOCORDER is no longer required either, but it can be used for backwards compatibility if required.」
  - URL: https://www.ivoa.net/documents/MOC/20220727/REC-MOC-2.0-20220727.html
- 权威依据: IVOA REC-MOC 2.0 §6/Table 3（ORDERING、COORDSYS 对 MOC1.1 与 MOC2.0 均 mandatory）；IVOA HiPS 1.0 §4.4.2（Moc.fits 须遵循 IVOA MOC 标准）；STD-REG-001 §1.2/§1.4；宪章 §12.3-10、§17.11
- 问题说明: 自家 Moc.fits 有 TTYPE1=UNIQ 与 MOCORDER，但**全仓 NUNIQ 命中 0、MOC 头里 COORDSYS 命中 0**，即两个真正的强制键缺失；写入的 MOCORDER 标准已声明「不再需要（可作兼容保留）」。注册表以「自家 reader 能读」判 CONFORMANT：hips_core.c::hips_parse_moc 与 aio_hips_reader.cpp 的 MOC 解析段对 ORDERING/COORDSYS 一概不检查，属循环论证。同一行还把 DISP-HIPS-005（低阶 UNIQ 对自家 reader 无效）挂在 CONFORMANT 行上——开放缺陷与符合性结论并存（见 M2b-B-08）。
- 影响: 每个子产品（signal/support/variance/ivar/snr）各一份 Moc.fits 对外都不是合规 MOC；mocpy / Aladin / MOC TAP 等第三方消费者按标准判非法或无法解包。moc_order 入参 > tile_order 时 min() 静默降阶，写出的低阶父 cell 被自家 reader 按 order 不符整表丢弃 → 覆盖枚举静默为空。
- 建议处置: ① Moc.fits 补 ORDERING='NUNIQ'、COORDSYS='C'（并按目标 MOC 版本决定是否加 MOCVERS/MOCDIM）；② 注册表该行改判 PARTIAL/NON_CONFORMANT 并挂新增偏差 ID；③ reader 对强制键缺失返回显式错误而非「当作无 MOC」；④ 以外部 MOC 解析器作独立符合性 Oracle 取代「自家能读」。
- 置信度: 高
