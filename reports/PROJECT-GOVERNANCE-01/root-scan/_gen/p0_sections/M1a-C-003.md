- 权威依据: FITS WCS Paper I §2.1.1（xp = x + 1）；SCI-WCS-001 §5a/§10:137；宪章 §12.3-15（像素语义显式）、§12.3-4
- 问题说明: `WcsTan` 的头注释钉死 CRPIX 为 1-based、映射按 `dx = x − crpix1`，即其"x"必须是 1-based 像素值；调用方喂的是 **0-based 数组下标**（x∈[0,W)）。后果两条：①该环产出的 `p1_wcs.json` samples 的像素列与天球列配对**相对标准口径整体平移 1px**，而该 JSON 内 `wcs` 块由 `r.crpix`（1-based）写出、其**生产消费端**（wcs_transform.cpp:190-191 `dx = x-(crpix1-1)`）按 0-based 解读 → 同一工件内部两套原点；②两条验收门（往返 rt 与"独立前向参考解"交叉）都建立在**同一个被平移的原点**上（参考解同样做 `u = x − crpix1`），因此任何常数原点平移在两门上恒为零 —— 门对该缺陷类的判别力为零，而 :1832 的门面文字宣称"绝对正确性"。
- 影响: 天测验证工件的像素-天球配对带恒定 1px 系统偏差（按 s_out≈0.5″/px 即 0.5″），且被两道"全过"的门掩盖；下游按 samples 做星表配对/残差统计者继承该偏差。SCI §10 明文禁止的第二种情形（边界之外缺失 +1 桥接）正在发生。
- 建议处置: ①`pts.emplace_back(x + 1, y + 1)`（或在 pix2sky/sky2pix 调用处桥接），与 Phase3 单点桥接同一裁决；②p1_wcs.json 增显式像素语义键（`pixel_origin: "0-based array index"` 或 "FITS 1-based"）；③为原点平移加**必败负向用例**（注入 ±1 必须使门失败，参照 p3_wcs_test.cpp:289-298 的九宫格+双桥必败模式）；④参考解改用真正独立的 Paper I 形式（xp = x+1）以恢复交叉门的判别力。
