  - IVOA 原文（§4.1 HiPS directory structure，实测取回）：
  > The tiles used by a HiPS must be visible as a collection of files in a directory tree … the tiles must be grouped by 10,000 items, using the subdirectory prefix "Dir". Formally, the tile index N in order K is located in the HiPS directory structure by this rule: Tile N in order K → Norder K/Dir D/Npix N{.ext} where D=( N/10000)*10000 (integer division) … Example: the tile … HEALPix cell index 10302 at the order 6 will be stored in the file Norder6/Dir10000/Npix10302 {.ext}
  - URL: https://www.ivoa.net/documents/HiPS/20170519/REC-HIPS-1.0-20170519.pdf （§4.1）
- 权威依据: IVOA REC-HIPS-1.0 §4.1；STD-REG-001 §1.2（禁止按实现反推标准）/§1.4；宪章 §12.3-10、§19
- 问题说明: 标准中 Dir = 分组起始下标 (N/10000)*10000（Dir0/Dir10000/Dir20000），文件名带完整 tile 号；实现把商与余数互换。N<10000 时数值巧合相同，N≥10000 时目录名与文件名同时错。注册表未登记偏差，反而把实现算式写成「标准要求」放进偏差列，并以「与读侧同一合同」作符合依据——读侧同为错式，属自证闭环。IO_002 §3.3 进一步把错式标注「IVOA HiPS 目录约定」，将错误固化进内部输入合同。
- 影响: 计数口径已在上方清单给出（13 处 = 3 生产 + 6 测试夹具/Oracle + 4 浏览器/工具，另 IO_002 §3.3、ALG §10、注册表 :93、lib/hips/README 与 memory 等文档面）。
- 影响: tile_order ≥ 6（叶级 nside ≥ 32768）产品中 ipix≥10000 的 tile 全部落非标准路径且错命名；Aladin / CDS hipsgen 按标准拼路径取不到 tile（404）→ 对外不可消费、不可浏览。Phase1 write_hips、Phase2 write_mosaic、astro_sphere_sink 三条生产写链共用同一 tile_rel_path，全部受影响。
- 建议处置: ① tile_rel_path / hips_tile_rel / reader tile_path 同批改 D=(ipix/10000)*10000、文件名 Npix{ipix}；② 注册表清单行 1「标准要求」订正为标准算式并挂 §4.1，收敛前挂真实偏差 ID；③ IO_002 §3.3 同步订正；④ 补标准示例锚回归用例（10302 → Norder6/Dir10000/Npix10302.fits）。
