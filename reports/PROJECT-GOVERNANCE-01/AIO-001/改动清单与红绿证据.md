## 3. 改动 2 — `aio_hips_product_begin` 校验 nside 为 2 的幂且 ≤2^29（条目 M2b-A-01, P0）

**改动前**（`aio_hips_writer.cpp:481-486`，等价逻辑）：

```cpp
if (!out_dir || !*out_dir || nside < 512 || tile_width != 512 || ...) { ... }
ps->leaf_order = ilog2_u64(nside);   // 向下取整 ⇒ 600 被静默夹逼为 2^9
```

**改动后**：

```cpp
const bool nside_is_pow2 = (nside & (nside - 1u)) == 0u;
if (!out_dir || !*out_dir || nside < 512 ||
    nside > (1u << 29) || !nside_is_pow2 || tile_width != 512 || ...) { ... }
```

## 4. 改动 3 — `properties` 原子落盘 + 失败传播（条目 M9-G-6, P1）

**改动前**：

```cpp
void write_properties(const std::string& path, const std::vector<std::pair<std::string,std::string>>& kv) {
    FILE* f = std::fopen(path.c_str(), "wb");
    if (!f) return;                       // 静默吞掉
    for (const auto& p : kv) std::fprintf(f, "%s=%s\n", ...);   // 不查返回值
    std::fclose(f);                       // 不查返回值
}                                         // 直写正式路径, 无 tmp/fsync/rename
```

**改动后**：内容先在内存拼装 → `aio_atomic::write_file_atomic()`（同目录 `<path>.tmp.<pid>.<seq>` → `fwrite` → `fflush` → `fsync`/`_commit` → `MoveFileExW(REPLACE_EXISTING|WRITE_THROUGH)`/`rename(2)`；任一环节失败即清理临时文件并返回 `false`）→ 两个调用点 `if (!write_properties(...)) return false;` 按子产品错误码 −3..−8 上报。
