## 0 最终归因（TL;DR）

**接缝 = 帧子集变化处「逐帧残余背景电平（零点）差」的跳变；其因果源头是 sky_plane 的逐帧项 `δ_k`。**

| 假设 | 判定 | 量化（H1top / H1bot，NEW） |
|---|---|---|
| (b) 排异差异 | **否定（次要）** | 排异贡献仅 **≈3.6–5.2%**（J_prod 与 J_geom 之差） |
| (a) 残余零点差（逐帧电平） | **成立，近因/主项** | 从 corrected 帧中扣除**逐帧常数**后台阶被消除 **98.2% / 76.1%** |
| (c) 天光面残差（逐帧 `δ_k`） | **成立，因果源头** | H1top：模型逐帧项 `mean_S δ_k` 的台阶 = **+4.22e11**，而**原始帧**（扣天光面前）的台阶仅 **+0.93e11**；净台阶 −3.54e11 主要由 `−δ_k` 项产生 |
| (d) 其他 | 残余 | 逐帧**梯度**再解释 H1bot 的 ~22%（H1top ~2.6%）；余下为高阶/噪声/真实天光梯度 |

**一句话**：sky_plane 把**全局**天光面拉平了（quiet_TL vs quiet_BR 14.0%→0.43%），但它用**逐帧全局平面 `δ_k`** 去消除逐帧背景差；在 n 变化的帧子集边界上，进入/退出帧的 `δ_k` 子集均值不连续，扣掉后就在马赛克上留下台阶。**近因是逐帧残余零点差，源头是天光面逐帧模型。**(b) 与 `large_scale` 均**不是**成因。

**新版水平带1上缘为何变差 2.2–2.7×（第 5 问）**：**不是单纯「暴露」旧台阶，而是 sky_plane 的 `δ_k` 项主动注入了一个更大的台阶。** H1top 边界处进入子集是 8 个 **M5 帧**（f11/12/13/38–42），模型给它们的 `δ_k` 常数高达 **+3.6…+7.3e12**；原始帧在该边界的实际电平差仅 **+0.93e11**，模型却按 `δ_k` 子集均值 **+4.22e11** 去扣，净台阶 −3.54e11。OLD 无天光面，只有原始帧台阶 +1.30e11。故 H1top 是**天光面逐帧模型的局部过校正（回归）**，同时整体平坦度净改善。

## 1 方法与数据（可复现）

### 1.1 权威事实（代码）
- 生产 mosaic = 对「finite ∧ support>0 ∧ accepted=1 ∧ sample_mask=1」的帧做**等权平均**（`module_adapters.cpp:5980-6092`，weight_mode=1 → w=1）。
- `p2_corrected_*.bin` 是**扣天光面之后**的逐帧值，NaN = support≤0（已逐 tile 用 support FITS 校验：`finite == (support>0)`，mismatch=0）。
- `p2_sky_plane.bin` 实为 **JSON**（`sky_plane.cpp:1199-1248`），含 `B_ref` 系数、每帧 `δ_k` 系数、gauge、网格；可在 Python 中直接复算 `b_k(x)=B_ref(x)+δ_k(x)`（`analysis6.py`）。

### 1.2 自校验（先证明工具可信）
| 校验 | 结果 |
|---|---|
| 由 `p2_corrected` 逐 slot 重构马赛克 vs `p2_integrated_signal` | `max\|cnt−nused\|=0`；相对差中位 **2.6e-8** |
| 由 bin 映射到 p3 vs `p3_r_vis_fixed/output_phase3.fits`（H1top 箱） | 相关 **0.9935**，数值同量级（差异来自面积平均 vs bilinear 点采样） |
| NEW 反算「扣天光面前」raw=c+model vs OLD 马赛克（H1top 箱） | 相关 **0.991**，中位差 1.29e12（OLD/NEW 接受子集不同，预期） |

> 注：本轮一度因 extract 脚本把 **HiPS local** 与 **FITS row-major** 索引混用导致相关≈0；已定位并修正（`extract_seam.py` 用 `L._F2L`），修正后相关 0.99+。这也解释了历史上「读不出 bin」的困难。

### 1.3 台阶度量
- 在 p3 网格上用由 `nused` 最陡跳变确定的**倾斜边界轨迹**，对两侧各 K=25 px 窄带逐行线性拟合外推到边界，`J = 右侧 − 左侧`（消除线性背景梯度，只留不连续；与 VISUAL-B `stage16_locus.py` 同法）。
- 归一化分母统一取 OLD 同位置扣除前天光水平 `1.056e13`。
- 与 VISUAL-B 的绝对值差异（如 H1top NEW：本文 −3.54e11 vs 报告 −2.52e11）来自轨迹/基线口径；**符号、量级、方向一致**。

## 2 逐假设证据

### 2.1 假设 (b) 排异差异 —— **否定**

对比「生产接受子集」与「几何子集（support>0，不排异）」重构的台阶：

| 边界 | J_prod | J_geom（不排异） | 排异贡献 Δ | 占比 |
|---|---|---|---|---|
| H1top NEW | −3.54e11 | −3.36e11 | −1.85e10 | **5.2%** |
| H1bot NEW | −2.67e11 | −2.58e11 | −9.6e9 | **3.6%** |

排异只影响 ~4%，无法解释 1–3% 台阶。**结论：与接缝基本无关。**

### 2.2 假设 (a) 残余零点差 —— **成立，近因主项**

对 corrected 帧扣除**逐帧常数**（安静背景带内 `o_f=median(c_f−c_{f0})`）后重建马赛克，同一轨迹测台阶：

| 边界 | J_prod | J_zp（扣逐帧常数后） | 零点差解释比例 |
|---|---|---|---|
| H1top NEW | −3.54e11 | **+6.4e9** | **98.2%** |
| H1bot NEW | −2.67e11 | **−6.4e10** | **76.1%** |
| H1top OLD | +1.30e11 | +2.30e10 | 82.3% |
| H1bot OLD | −2.32e11 | −3.37e10 | 85.5% |

逐帧 corrected 电平散差（安静带，ref=f0）：NEW H1top **σ=7.9e11**、H1bot **σ=1.14e12**；OLD 分别 **2.49e12 / 2.42e12**（sky_plane 把散差压小 3.2× / 2.1×）。

进一步按空间阶数扣逐帧残差（全局多项式，安静带）：

| 边界 | prod | 扣常数(ord0) | 扣平面(ord1) | 扣二次(ord2) |
|---|---|---|---|---|
| H1top NEW | −3.354% | 0.142%（**95.8%**） | −0.054%（98.4%） | 0.115%（96.6%） |
| H1bot NEW | −2.307% | −0.567%（**75.4%**） | 0.066%（97.1%） | 0.147%（93.6%） |

⇒ 台阶近因是**逐帧残余电平（零点）差**；H1bot 另需 ~22% 的逐帧**梯度**项才归零，H1top 几乎全是常数项。

### 2.3 假设 (c) 天光面残差 —— **成立，且是因果源头**

天光面模型结构（`p2_sky_plane.bin`）：`b_k(x)=B_ref(x)+δ_k(x)`，其中
- `B_ref`：**全帧共享**的双三次 B 样条，nx=ny=6、节点距 1.0°、36 系数 ⇒ **全局光滑且所有帧相同** ⇒ 子集变化处**不产生台阶**（实测 `step(B_ref)≈−2e10`，可忽略）；
- `δ_k`：**逐帧平面**（order=1，3 系数）；常数项 std **2.16e12**、x 项 1.65e12、y 项 3.62e12 ⇒ **逐帧大不同**。

对每个 leaf 复算模型 `δ_k`，按生产接受子集求 `mean_S δ_k` 并测其台阶（`analysis6.py`）：

| 边界 | J_prod | J_raw（扣天光面前） | J_dmean=`step(mean_S δ_k)` | step(B_ref) |
|---|---|---|---|---|
| H1top NEW | −3.54e11 | **+0.93e11** | **+4.22e11** | −2.1e10 |
| H1bot NEW | −2.67e11 | −1.91e11 | +1.25e10 | ~0 |

恒等式 `mean_S raw = mean_S c + B_ref + mean_S δ_k` 成立（逐点精确；表中中位数差来自 median 非线性，误差 ~5e10）。

**H1top 的机制实证**（x≈1200 列）：nused 由 9（上）→17（下）。进入子集 = 8 个 M5 帧：

| 进入帧 | `δ_k` 常数（模型） |
|---|---|
| f11 M5_T2_20251212 | +3.81e12 |
| f12 M5_T2_20251224 | +3.73e12 |
| f13 M5_T2_20260108 | +7.33e12 |
| f38 M5_T3_20251127 | +3.58e12 |
| f39 M5_T3_20251128 | +6.07e12 |
| f40 M5_T3_20251211 | +4.15e12 |
| f41 M5_T3_20251213 | +6.12e12 |
| f42 M5_T3_20251228 | +4.19e12 |

上子集(n=9) `mean δ_k` 常数 = 1.78e12，下子集(n=17) = 3.23e12，差 **+1.46e12**（归一化坐标下的常数项；leaf 处实际 `δ_k` 的 p16..p84 = −2.42e12..+2.31e12）。即**进入的 M5 帧被模型赋予系统性正 `δ_k`**，扣除后使边界下侧马赛克整体偏低 ⇒ 观测到负台阶。

**判断**：`b_k(x)` 对**每一帧**都是连续光滑的（无几何错位/无重影，与 VISUAL-B 一致）；**不连续出现在「帧子集上的平均」**——`mean_S δ_k` 在 n 变化处跳变。模型本身没有空间不连续，但马赛克的「逐帧项平均」不连续。

### 2.4 假设 (d) 其他 —— 残余
- 逐帧梯度：H1bot 扣平面后残 0.066%（解释 97.1%，比只扣常数多 21.7pp）；H1top 只多 2.6pp。
- 高阶/噪声/真实天光梯度：余下 ~0.1–0.6% 旧背景。
- 无证据支持几何错位、重影或覆盖掩膜差异。

## 3 第 4 问：`p2_large_scale_apply` 是否相关？—— **不相关**

代码事实：
- `p2_large_scale_apply`（`rejection.cpp:2336`）是 **`astrocs.large_scale_rejection.v1` 的连通域生长**：把**已拒绝**的 low/high 掩膜向外扩张，用于补齐拖线/大尺度结构的漏检像素。
- 调用点只有：`lib/algorithms/coverage/tools/stage2.cpp:1744`（工具）与 `tests/unit/v6_p2_rej/`、`coverage/tests/synthetic_gate.cpp`。**生产调度路径 `module_adapters.cpp` 中 `large_scale` 出现次数 = 0**；`rejection.cpp:1180` 默认 `enabled=0`。
- 它作用于**排异掩膜**，与逐帧背景电平/零点无关；本轮已证排异对台阶只贡献 ~4%。

**结论：即使接线并启用 `large_scale`，也不会改变接缝**（对 TRAIL 残留仍可能有用，属另一分片）。若启用，属**科学默认变更，需 claim + 回归**。

## 4 第 5 问：为何新版水平带1上缘变差 2.2–2.7×？

- OLD（无天光面）：J = **+1.30e11**（≈原始帧台阶 J_raw=+0.93e11）。
- NEW（天光面生效）：J = **−3.54e11**；其中 `−J_dmean = −4.22e11` 占主导，`+J_raw=+0.93e11` 只抵消一部分。

即：**sky_plane 的逐帧 `δ_k` 项在 H1top 边界的子集均值跳变（+4.22e11）比它要消除的原始帧台阶（+0.93e11）大 4.5×**，扣除后净台阶反而放大并反号。这是**天光面逐帧全局平面在帧边缘/子集边界的局部过校正**（回归），而非「天光面归零后暴露了原本被掩盖的台阶」——因为原始帧本身在该边界几乎没有台阶。整体上天光面仍净改善（大尺度平坦度 14.0%→0.43%），但**接缝是它引入的副作用**。

## 5 修复方向（算法/接线）与预期

> 均为方向；涉及冻结科学默认值/SCI 定义的须走 `ENGINEERING_SPEC §3` 变更 claim + 一致性回归。本轮未改任何代码。

1. **改进 sky_plane 逐帧项（治本，首选）**
   - 现状 `δ_k` 是**全局 order-1 平面**；进入/退出帧（M5）被赋予 +3.6…+7.3e12 的大常数，而原始帧在边界实际只差 ~2e11 ⇒ 全局平面对逐帧背景的**空间变化**表达不足。
   - 方向：提高 `frame_gradient_order`（如 2）或降低 `node_spacing_deg` / 放宽 `roughness_penalty`，让逐帧项能跟随背景的空间变化；同时检查 gauge（`gauge_mode`）、样本掩膜与稳健权重（`rms_weighted=3.37e12`、`chi2_red=6268`、rank=30/174、kappa=2.8e5，拟合质量本身偏弱）。
   - 预期：逐帧残差电平散差 0.8–1.1e12 进一步下降 ⇒ 台阶按比例下降；若散差降到 ~2e11，台阶应降到 ≲0.7e11（<0.7% 旧背景）。
   - **科学默认变更，需 claim + 回归**。
2. **帧子集边界羽化/加权过渡（缓解，可选）**
   - 在 n 变化处对进入/退出帧做几像素的权重渐变，把测光台阶转成平滑斜坡（不改全局定标）。
   - 预期：视觉与局部梯度显著改善，但会轻微改变边界处的有效 PSF/噪声；**属产品语义变更，需 claim + 回归**。
3. **逐帧相对光度的独立归一（与 TRAIL 分片同向）**
   - 在排异/积分前用重叠区做逐帧电平（及必要时增益）归一；可同时改善 TRAIL 残留与接缝。
   - 属科学默认变更，需 claim + 回归。
4. **不建议**：把 `weight_mode=2` 当接缝修复（零点差是**偏差**不是噪声，逆方差权重不针对该机制）；把 `large_scale` 当接缝修复（见 §3）。
