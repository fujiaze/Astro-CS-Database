## 2 ★ 决定性发现：生产组合 `raw − C_k − δ_k` 是有害的双重扣除

### 2.1 机理

UPM 自由 C 场（`smoothing_lambda=0`）在**每个 control 节点**上是逐帧独立加权 LS：
`C_k(c) = Σ w (value − M) / (Σ w + anchor)`，故 `value_k(c) − C_k(c) ≈ M_c`（残差仅帧内样本散布，中位 0.083%）。
⇒ **C 已把每帧对齐到公共面 M**。

生产随后再减 `δ_k`（`module_adapters.cpp:4937-4955`）：
`corrected_k(c) = value_k(c) − C_k(c) − δ_k(c) ≈ M_c − δ_k(c)`。
⇒ 各帧被重新拉开 `δ_k` 的差距。**δ_k 是加在已对齐场上的第二次逐帧加性扣除。**

### 2.2 数值证据（脚本 `which_correction.py`，29336 个 ≥2 帧覆盖的 control，M>1e11）

| 组合 | 帧间 std / M（中位） | 留一台阶 / M（中位） |
|---|---|---|
| `raw`（完全不校正） | 13.454% | 8.113% |
| `raw − δ_k` | 2.799% | 2.100% |
| `raw − C_k` | **0.131%** | **0.098%** |
| `raw − C_k − δ_k`（**生产**） | **13.974%** | **9.479%** |

**读法**：
- **C 单独**把帧间差从 13.45% 压到 0.13%（≈100×）；
- **δ 单独**压到 2.80%（≈4.8×，说明帧间差确实主要是低阶加性梯度——与负责人方向一致）；
- **两者相加**反而回到 13.97%，**比完全不校正还差**。

### 2.3 δ_k 是独立加性场，不是乘性残余（脚本 `delta_seam_cause.py`）

```
rms(C) = 2.454e12 ; rms(δ) = 3.225e12      ⇒ δ 达 C 的 131%
corr(δ_k, M) 中位 = +0.002 ; slope 中位 = +0.0000   ⇒ δ 与天图无关（纯加性）
逐 control std(δ_k) 中位 = 14.24% of M ; 留一台阶中位 9.33% / p90 15.85%
```

⇒ 生产的帧间失配量（9.5–14%）与实测接缝量级（2–6%，加权叠加后按帧子集平均会缩小）一致。**接缝的主因就是这次多余的 δ_k 扣除**，与 `fix-gk-report.md §5`（接缝与方案 B 无因果、驱动项在帧间差）互为印证。

### 2.4 与前台接缝表的自洽

OLD（bitref_16w，C=0，减 `b_k=B_ref+δ_k`）帧间差 = `raw_k − raw_j − (δ_k−δ_j)`（含全部未校正帧间差）；NEW（upmfix_out，减 C+δ）帧间差 = `−(δ_k−δ_j)`。两者实测接缝同量级（§6），说明**接缝由 δ_k 的帧子集跳变主导**，与 C 是否复活关系不大。

## 3 ① N 帧情形下「真实信号面」应如何构造

### 3.1 模型与正确目标

加性模型（负责人口径）：`y_i(x) = s(x) + g_i(x) + ε_i(x)`，`i=1..N`，`s` 为公共真实面，`g_i` 为逐帧光滑梯度。
正确的估计量是**联合加权最小二乘**：

```
min_{s, {g_i}}  Σ_i Σ_{x∈i} w_i(x)·[ y_i(x) − s(x) − g_i(x) ]²  +  λ·Σ_i R(g_i)
```
其法方程为 `s = Σ_i w_i (y_i − g_i) / W`，`y_i − g_i = s`，即**不动点 `c_i ≡ s`（所有帧的校正值相等）**。这正是设计文档 §1.2「加权叠加结果平滑」的数学形式。

### 3.2 对四个候选的独立判断（不照搬旧文档）

| 候选 | 判断 |
|---|---|
| (a) 其他帧 SNR 加权平均（排除自身） | **不是独立估计量**，而是上述不动点的 **Gauss-Seidel 迭代**。收敛解同样满足 `c_i ≡ c`（公共常数）；与联合 LS 同解。**但旧文档 §3.2 写的更新式 `g_i = TPS(diff_i)` 是错的**：首轮 `g_i=bg_i−ref_i` ⇒ `c_i=ref_i`；次轮 `diff_i=(bg_i−g_i)−ref_i=0` ⇒ `g_i→0`，**振荡**。正确形式是 `g_i += TPS(diff_i)`（或 `g_i = g_i + TPS(diff_i)`）。 |
| (b) 现有 UPM 的 `M` / sky plane 的 `B_ref` | UPM 自由 C 的交替 LS **同解**（不动点 `c_i ≡ M`，实测 0.13%），所以 `M` 是合法公共面。**但 `M` 的更新只用参考帧**（`upm.cpp:719-741`，`if frame_index != rf continue`），即 `s = y_ref`，方差大、且把参考帧的结构/噪声变成共模。sky plane 的 `B_ref` 是样条联合拟合，更接近正确做法。 |
| (c) 迭代自洽 | 与 (b) 不动点等价；实现上就是 UPM 的交替 LS。**推荐**，但 M-update 要改成全帧加权。 |
| (d) 其他 | 见 §3.3：真正缺的是**堆叠平滑目标**，而非又一个面。 |

### 3.3 数值结论：公共面构造**不是**当前瓶颈

自由 C 场在 control 节点上已把帧间差压到 **0.131%**（§2.2）。也就是说，**当前 UPM 的公共面已经足够好**；接缝不是「面构造错了」，而是「δ_k 在面已对齐后又被减了一次」。

⇒ 对 Q1 的裁决：**采 (c)（= (b) 的正确形式），即全帧 SNR 加权公共面 + 单一 gauge；把 M-update 从「只用参考帧」改为「全帧加权」。但这不是接缝的首要修复项。**

## 4 ② gauge 应该是什么——代数证明

### 4.1 设定

设第 i 帧校正值 `c_i = y_i − ĝ_i`，像素 p 处参与帧集合 `S(p)`，堆叠
`M(p) = Σ_{i∈S(p)} w_i(p)·c_i(p) / W(p)`，`W(p)=Σ_{i∈S(p)} w_i(p)`。

### 4.2 gauge 自由度

模型 `y_i = s + g_i` 在变换
`(s, g_i) → (s + c₀, g_i − c₀)` 下不变（c₀ 为任意常数），
等价地 `ĝ_i → ĝ_i + c₀`（所有帧共享同一常数）。此时 `c_i → c_i − c₀`，且因 `Σ w_i/W = 1`：
`M(p) → M(p) − c₀`（**逐像素同一个常数**）。

### 4.3 接缝不变性（核心命题）

覆盖边界处，帧子集由 `A` 突变为 `B`，台阶
`Δ(p) = M_B(p) − M_A(p)`。
gauge 平移下 `M_B → M_B − c₀`、`M_A → M_A − c₀`，故
**`Δ(p) → Δ(p)`——接缝对 gauge 严格不变。∎**

### 4.4 推论

1. 「全局加权均值为零」（`Σ_i w_i·ḡ_i / W = 0`）与「参考帧 `δ_ref ≡ 0`」**只差输出图的一个全局常数**，接缝完全相同。
2. 旧文档 §1.2 的目标 `Σ w_i g_i/W → 0` **只能全局成立（一个常数），不可能逐像素成立**——gauge 只有一个自由度。接缝由 `Σ w_i g_i/W` 的**空间变化**驱动，gauge 动不了它。
3. 要逐像素压低 `Σ w_i g_i/W` 的跳变，必须改**拟合目标**（在目标函数里加「堆叠平滑/边界连续」项，即设计文档 §1.3「权重耦合、联立求解」），**不是改 gauge**。
4. gauge 真正影响的是：(i) 输出图的绝对电平；(ii) 公共面 `s` 的**方差**——参考帧 gauge：`Var(s)=σ_ref²`；均值零 gauge：`Var(s)≈σ²/W`（N 帧平均）。

### 4.5 裁决

**采用「全局加权均值为零」作为规范**（方差更小、无单帧锚定、与旧文档一致），**但明确它不修接缝**；接缝修复靠 §2 的单一校正 + §6 的堆叠平滑目标。

## 5 ③ SNR 如何正确传播

### 5.1 校正值的真实方差

线性平滑器下 `ĝ = H·y`（H 为帽子矩阵），则
`c = y − ĝ = (I − H)·y = P·y`（**残差制造者**），
`Var(c) = P·Σ·Pᵀ`，`Σ = diag(σ_i²)`，即
**`Var(c_i(p)) = Σ_j P_{i(p),j}² · σ_j²`**。

关键：**不是** `σ_i² + Var(ĝ_i)`。因为 ĝ 由同一批数据拟合，`Cov(y, ĝ) = Σ Hᵀ ≠ 0`，展开为
`Var(c) = Σ − 2ΣHᵀ + HΣHᵀ`；而朴素式只给 `Σ + HΣHᵀ`，**漏掉交叉项 `−2ΣHᵀ`**。

### 5.2 对 UNC-PROP 公式的核对

`UNC-PROP`：`Var(corrected) = [σ²_y + J_out C_θ J_outᵀ] / g²`。加性情形 `g=1`、`J_out C_θ J_outᵀ = HΣHᵀ`（LS 参数协方差），故它给出的是 `Σ + HΣHᵀ`——**朴素式，缺 `−2ΣHᵀ`**。

最简例子（N 帧、`ĝ_i = ȳ`）：正确 `Var(c_i)=σ²(1−1/N)`；UNC-PROP 给 `σ²(1+1/N)`。N=8 时高估 **1.29×**。

### 5.3 对「高 SNR 帧不被降权」的裁决

- 若各帧 σ 相同，高估因子对所有帧相同 ⇒ 只是权重的公共缩放，不改相对权重；
- 若 σ_i 不同，`H` 把低 SNR 帧的噪声经公共面 `s` 灌进**每一帧**的 `Var(c_i)`。此时若用朴素式（把 `Var(ĝ_i)` 直接相加而不减交叉项），**高 SNR 帧会被系统性降权**——正是要避免的。
- **正确配方**：
  1. **拟合** `ĝ_i`：权重 `w_fit = 1/σ_i²`（+Huber 鲁棒），即 PMM 的样本权重 / 旧文档「SNR 加权」；
  2. **堆叠**：`w_stack = 1/Var(corrected_i)`，`Var` 用 5.1 的残差制造者形式，并含梯度拟合的参数协方差；
  3. **不得**把拟合权重直接当堆叠权重；**不得**在 `σ²` 上无条件加 `Var(ĝ)`；
  4. `Var(ref)`：不动点下 `c_i ≡ s`，故**所有帧共享公共面方差** `Var(s)≈(Σ_j w_j²σ_j²)/W²`——「参考帧」不是低噪声锚点；
  5. `Var(g_i)`：经梯度拟合的 `C_θ` 进入，符号必须按 5.1 取（残差形式）；
  6. 校正后各帧经 `s` 相关，严格 BLUE 是 GLS（`V=PΣPᵀ`）；对角近似可用，但相关性应登记。

每轮仅降 ~0.7%；即使改**相对**判据，当前 `rel_dM≈1.3e-4` 仍远大于 `1e-6` ⇒ **tolerance 数值本身也要重定**。

### 7.4 最小改法（`upm.cpp:903`）
```cpp
double scale_M = 0.0, scale_C = 0.0;
for (double v : M) scale_M = std::max(scale_M, std::fabs(v));
for (const auto& row : m->C)
  for (double v : row) scale_C = std::max(scale_C, std::fabs(v));
if (max_dM <= cfg.tolerance * std::max(scale_M, 1.0) &&
    max_dC <= cfg.tolerance * std::max(scale_C, 1.0)) { m->converged = 1; break; }
```
配套：`tolerance` 语义由绝对变相对，冻结值须重定（建议相对门 **1e-3**，约 1–2 轮可达；或改用目标函数相对变化判据）。属科学行为变更，须负责人批。
> 注：`upm.cpp:2142` 的 `if (maxstep < cfg.tolerance) break;` 是 MA 求解器路径，生产链未走。
