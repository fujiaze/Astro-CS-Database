### 2.2 判据（写死在 `MaskConfig`，逐条给数值）

| 位 | 名称 | 判据 | 置无效？ |
|---|---|---|---|
| 0 (1) | `NONFINITE` | `~isfinite(v)` | ✅ |
| 1 (2) | `ZERO` | `v == 0.0` | ✅ |
| 2 (4) | `NEGATIVE` | `v < 0` | ✅ |
| 3 (8) | `EDGE` | 与**画幅边框 4-连通**的 `(ZERO\|NONFINITE)` 连通域 | ✅ |
| 4 (16) | `EXTREME_NEG` | `v < bg − 20·σ_blk`（64 px 块稳健中位/1.4826·MAD，逐像素上采样） | ✅ |
| 5 (32) | `SPIKE` | `(v − bg) > 10·σ_blk` **且** `(v − max8(v)) / (v − bg) > 0.80` | ❌ **仅标记** |

`valid = 1` ⟺ 前五位全 0。

**为什么 `EDGE` 用「与边框连通的零域」而不是「矩形」**：
实测有效域是一个**旋转（`ORIENTAT = −35°`）的 WFC3/UVIS 双芯片足迹**，不是矩形
（见 §2.4 的 ASCII 足迹图）。用最大内接矩形会把足迹四角的**有效像素白白剔除**
（首版即如此：最大全有效矩形只占 19.9%，因为罕见的离群像素把矩形切碎）。
改用「边框连通域」后，`EDGE` 精确等于「drizzle 无覆盖区」，且**画幅内部零像素 = 0**。

**为什么 `SPIKE` 不置无效**：HST 在 0.04″/px 下**严重欠采样**，真实星点本身就是尖峰。
判据用 PSF 自身的几何上界：对任何 FWHM ≥ 1.2 px 的 PSF，峰值像素相对其最亮邻像素的
「超额占比」`r = (v − max8)/(v − bg)` 有上界（数值标定见 §2.5），
而单像素坏点/宇宙线的邻域与背景同亮 ⇒ `r → 1`。**保守取向：宁可不剔，不可把真星当坏点。**
下游可用 `real_base.exclude_spike=true` 启用剔除。

## 3. ② 场景模板前向渲染接口

### 3.1 模块与复用关系（**不另起炉灶**）

```

├── noise_model.py     ← 复用（DATA-TYPE-MATRIX 分片）：物理噪声链唯一事实源
├── render.py          ← 复用（同上）：PSF 核 psf_kernel / 星点叠加 stamp / 场景 IO
├── m16_mask.py        ← **本分片新增**：有效域掩膜生成器 + 读回接口
└── m16_scene.py       ← **本分片新增**：M16 前向渲染接口（真实底 + PHOTFLAM 星等尺度 + 掩膜）
```

`m16_scene.py` **不重写**任何物理公式：它只做三件 M16 特有的事 ——
真实 drz 帧 → 期望率面、PHOTFLAM → 星等尺度、掩膜随帧落盘；
噪声采样一律调用 `noise_model.expose()`。

### 3.2 物理噪声链（§9.41 逐项）

```
lam_e = t · (src_rate + sky_rate) · m(x,y)  +  t · D(T) · hot(x,y)     [e-]
n_e   = Poisson(lam_e) + Normal(0, σ_R·√stack_n) + CR                  [e-]
adu   = round(n_e / g + bias)  ，硬钳位到满阱                                    [ADU]
invalid 像素 → 0（与真实 drz 零填充一致），并写入 HDU 1 MASK
```

> **噪声制度（STACKN32-001，2026-09-20）**：`stack_n` **默认值 = 32**（`m16_scene.M16_DEFAULTS` 的 `stack_n`；
> 4 个场景 JSON 同值）⇒ 叠加等效读出噪声 `σ_R = √32 × 3.1 = 17.5362 e⁻`。
> 落盘证据：FITS 头 `STACKN=32`、`RDNOISE=17.53624817342638`；`*_f00.meta.json` 的
> `stack_n=32`、`detector_read_noise_before_stack_e=3.1`、`detector.read_noise_e=17.53624817342638`
> （`run/reverse_verify/data_matrix/m16_*/`、`run/reverse_verify/m16_scene/frames/m16_*/`）。
> 物理依据：真实 drz 产品 `NDRIZIM=32`（§1 表）。**单次**读出 `read_noise_e=3.1` 未改。

| §9.41 要求项 | 实现 | 可配置键 |
|---|---|---|
| 源 Poisson（电子域） | ✅ `rng.poisson(lam_e)`，lam 含源项 | `exposure_s`、`real_base.flux_scale` |
| 天光 Poisson（电子域） | ✅ **天光逐像素进同一个泊松**，B↑ ⇒ σ↑ | `sky.{level,grad_*,moon_*}` |
| 暗流 Poisson | ✅ `D(T)=D_ref·2^((T−T_ref)/T_double)` | `detector.dark_*`、`temp_c` |
| 读出 Gaussian（电子域） | ✅ `+ N(0, σ_R√stack_n)`（`stack_n` 默认 **32** ⇒ σ_R = **17.5362 e⁻**） | `detector.read_noise_e`（**单次**读出 = 3.1）、`stack_n`（默认 **32**） |
| 增益量化（ADU） | ✅ `round(n/g+bias)` + 饱和硬钳位 | `detector.gain_e_per_adu`、`full_well_e` |
| 平场乘性响应 | ✅ PRNU + 低阶倾斜 + 渐晕（几何均值归一） | `flat.*` |
| 天空梯度 | ✅ 线性（任意方位角）+ 二次 + 月光晕 | `sky.grad_*`、`sky.theta_deg` |
| 宇宙线/热像素 | ✅ 冲激电荷 + 热像素暗流倍率 | `artifacts.*` |
| **有效域掩膜** | ✅ 掩膜内期望面用最近有效邻元填充、输出置 0、MASK 落盘 | `real_base.{mask_dir,exclude_spike}` |
| 禁纯加性天光 | ✅ 提供 `mode="additive"` **显式负例臂**（配对同种子 ⇒ 度量恒 0） | `mode` |

**「速率 vs 计数」处理**：`BUNIT = ELECTRONS/S` ⇒ 真实帧像素值是**速率**。
合成时先 `lam_e = t · rate`（乘曝光时间得电子数）**再**泊松。
因此同一场景换曝光时，源的**率**不变、**计数**随 t 线性变、噪声随 √t 变。
真实帧的 `EXPTIME`（9600/14400/16000 s）**只用于解释底图速率**，
不等于合成曝光时间（逐帧写入 `REALEXP` 与 `EXPTIME` 两个不同头键）。

### 3.3 PHOTFLAM 星等尺度（§9.42 合规）

ZP_ST    = -2.5·log10(PHOTFLAM) + PHOTZPT    （PHOTZPT = -21.10，头内自洽）
ZP_AB    = -2.5·log10(PHOTFLAM) - 5·log10(PHOTPLAM) - 2.408
m_AB     = -2.5·log10(r) + ZP_AB

### 4.1 判据来源

## 6. 诚实边界（**必须随用随声明**）

### 6.1 drz 合成品在噪声建模上的**固有局限**

1. **像素间噪声相关（最重要）**：真实 drz 的噪声经 32 次曝光 + drizzle 重采样后是**相关**的
   （相关长度 ~ drizzle 核）。本接口生成的是**逐像素独立**泊松/高斯噪声 ⇒
   **合成帧的噪声功率谱与真实 drz 不同**。凡对相关长度敏感的判据
   （稀疏 SNR 控制点间距 Δ=64 px、UPM 平滑尺度 λ、drizzle 协方差）**不得**用合成帧定标。
   **（STACKN32-001 补充）** 合成帧的**噪声水平**已与真实 drz 对齐：`stack_n` 默认 **32**
   ⇒ σ_R = √32 × 3.1 = **17.5362 e⁻**（落盘头键 `STACKN=32` / `RDNOISE=17.53624817342638`），
   与真实 drz 的 `NDRIZIM=32` 一致 ⇒ **局限只剩「噪声相关长度」**（读出噪声不再偏乐观 √32 ≈ 5.66×）。
2. **底图残余噪声**：真实帧被高斯平滑成期望面，残余方差份额 `1/(4πσ_k²)`
   （σ_k = 2 px ⇒ **1.99%**），逐帧登记。该残差**不是**白噪声，且**未**计入合成帧。
3. **两套 PSF 并存**：平滑同时展宽真实星点 ⇒ 底图特征有效 PSF = `√(PSF_real² + σ_k²)`；
   注入星点用**配置 PSF**（不受平滑影响）。同一帧里两套 PSF，逐帧登记。
4. **无权重、无 DQ**：只有 SCI HDU（PrimaryHDU 单 HDU，1437 张头卡），**没有** `_wht`、**没有** DQ
   ⇒ 覆盖信息只能由零值几何反推，**无法区分**「无覆盖的零」与「真零通量」；
   本掩膜对星云真实的零通量像素会**过度剔除**（保守方向，安全）。
5. **底图天光已含在基座里**：默认 `sky.mode="from_real"` ⇒ 基座 = 真实帧的 p5 分位，
   源结构通量守恒、星等尺度不变；若显式改 sky 水平，则是模拟「不同天光条件下的同一天区」，
   此时星云弥散分量的一部分被重新归类为天光（**定义性选择**，已登记）。
6. **未建模**：溢出/辉散、非线性、CTE、fringing、云、导星漂移、drizzle 相关噪声、
   真实 WFC3 几何畸变残差、SIP（本数据纯 TAN）。
