## 一、两个真缺陷：定位并修复

### 1. 天光面在生产链上**从未生效** → 已修复
现象：每次 mosaic 都 `[sky_plane] build FAILED rc=6`（`reduced normal matrix not SPD`）→ 回退 UPM C 场。

**根因（纠正了第一版归因）**：不是 3 维 gauge 零空间，而是**惩罚自身的 4 维 bilinear 零空间** `{1, ix, iy, ix·iy}`；
且**惩罚 trace 0.228 vs 数据 trace 1.80e-18（差 1.27e17）**，浮点舍入淹没零空间曲率 ⇒ `H_solve` 失去正定。

**修法**：先走原直接 Cholesky（常规量级档**逐位不变**），仅失败时对零空间加 `α·QQᵀ` 极小 Tikhonov 锚，
再用 **deflation** `B = B_a + Q·G⁻¹(Qᵀrhs − QᵀH_red B_a)` **精确扣回锚偏置**；只锚零空间，不全矩阵加 jitter。

**验证**：修后 `rank=174/174`（满秩）、`κ=2.845e5`，与独立 stacked-QR 一致到 2.8e-7；
**实测新版 `sky_plane FAILED` 计数 = 0**，`[sky_plane] ok n_used=277234 n_frames=49`。

**效果**：大尺度天光平坦度 **14.0% → 0.43%**（33×）；卫星线残留 **4.45% → 0.50%**（**≈9×**，1.86σ → 0.29σ）。

### 2. 权重链 F_ref 约定混用 → 已修复
`weight_mode=2` 在真实数据上 fail-closed（stderr 中文被 locale 吞成 `?????`）。
**裁决（推导+文档+代码+文献四方）**：`SNR_f = a_f·F_ref/σ_f ⇒ SNR_f²/F_ref² = a_f²/σ_f² = w_f`，
**成立当且仅当分母 F_ref 与定义 SNR 时用的是同一个** ⇒ **必须组内公共**；实测混用偏差 **3.5×**。
**修法**：删逐帧中位数回退 ⇒ fail-closed；整块取一个公共 F0；闸门**保持 fail-closed**。

## 五、接缝与天光面：**三个分片接力定位到真缺陷**

1. **TRAIL**：卫星线残留是真缺陷（非采样稀释）。排异 kernel **能**拒绝且逐位复现生产 `nrej`（12599/12599），
   但只在 **69.6%** 的拖线像素拒绝 —— 因 M1 八帧背景失配 **1.56×** 使散差 MAD **10.9%**（归一后 4.5%），
   拖线只值 ~5σ。**决定性反事实：逐帧归一后源拒绝率 0.696 → 0.985**。
2. **SEAM**：接缝 = 帧子集变化处**逐帧残余零点差**跳变；**因果源头是 sky_plane 的逐帧项 `δ_k`**。
   H1top 原始帧台阶 `+0.93e11`，模型逐帧项台阶 `+4.22e11` ⇒ **δ_k 主导并放大台阶（局部过校正）**；
   排异差异**否定**（仅 3.6–5.2%）；`p2_large_scale_apply` 与接缝**无关**。
3. **SKY-FIT**：**`rank=30/174` 是诊断口径错误**（只测 B_ref 约化矩阵）；**全 174 维实际满秩 174/174，cond=5.05e6**。
   **真缺陷：`λ=1e-3` 是为 O(1) 权重标定的，而生产权重是逆方差 `~1e-21`** ⇒ 惩罚相对数据被放大 **1.26e17**，
   **`B_ref` 被钉死在 bilinear**（投影残差 2.75e-16）⇒ B_ref 形状 100% 由惩罚决定。
   `chi2_red=6268` 不正常（应 ≈1），根因 **M42 场天光样本被真实星云结构主导**，模型无法表达。

**治本方案（排序，均需 claim）**：
① `frame_gradient_order` 1→2（台阶 −3.54e11 → **−2.01e11**）；
② **`roughness_penalty` 按数据尺度归一**（→ **−2.91e11**，**且是正确性修复**）；
③ **帧子集边界羽化**（**唯一**能把可见台阶压到 ≲0.7e11 的手段）；④ 重叠区逐帧 DC 归一。
**单靠模型改动到不了 ≤0.7e11**（order2 最好 ~2.0e11）。

**与成熟实现差距**：DrizzlePac/SWarp/Siril/SCAMP 普遍是**逐帧局部独立背景 + 重叠成对匹配 + 边界羽化**；
我们是**全局共享 B_ref + 逐帧平面联合拟合**，无显式重叠匹配、无羽化 ⇒ 在强结构场放大接缝。
