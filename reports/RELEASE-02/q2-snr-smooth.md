## 1 合成设计与真值

脚本：\`run/RELEASE-02/q2-snr-smooth/synth_q2_v3.py\`（主）、\`pollution_q2.py\`（污染）、\`weight_consistency_q2.py\`（自洽）。
真值全部由构造给出：

- **网格** 512×256；**公共天光** \`S = 1000 + 3U + 1.5V + 0.8U² + 0.5UV − 0.4V²\`（ADU，U/V 归一化到 [−1,1]）。
- **4 帧 A/B/C/D**，x 向条带：A[0,192) B[128,320) C[256,448) D[384,512)。
  覆盖集合沿 x 依次为 {A} / {A,B} / {B} / {B,C} / {C} / {C,D} / {D}；
  **覆盖突变边界 x = 128,192,256,320,384,448**（含单覆盖区与 2 帧重叠区）。
- **逐帧加性梯度** \`b_k\`：二阶多项式，**各帧二次项不同**（这正是 plane-δ 模型无法吸收的部分）。
- **乘性响应与噪声**：gain \`g=[1.0,2.0,0.8,1.0]\`，原始噪声 \`σ_raw=[1.0,2.6,2.0,5.0]\`。
  归一化帧 \`z_k = raw_k/g_k = S + b_k + N(0,σ_norm²)\`，\`σ_norm=σ_raw/g=[1.0,1.3,2.5,5.0]\`。
- **残差场** \`g_k = b_k − c_k\`；**马赛克残差** \`R(p)=Σ_{k∈S(p)} w_k g_k / W_S\`；阶跃 = 边界两侧 R 的中位数差。
- 各 formulation 的**模型容量一致**（每帧二阶多项式；production-like 的 (a) 另加全局二阶 B + 逐帧 plane δ），因此差异来自 **gauge/一致性**，不是单纯拟合能力。

**能红能绿对照**：(b) 对 (a)、反权对 SNR 权、naive α=1 迭代对阻尼迭代、(d) 对 (c)、raw 无校正对所有 formulation。

## 2 权重序验证（是否翻转）

| 帧 | g | σ_raw | σ_norm | w_raw=1/σ_raw² | w_norm=1/σ_norm² |
|---|---|---|---|---|---|
| A | 1.0 | 1.0 | 1.0 | **1.000** | **1.000** |
| B | 2.0 | 2.6 | 1.3 | **0.148** | **0.592** |
| C | 0.8 | 2.0 | 2.5 | 0.250 | 0.160 |
| D | 1.0 | 5.0 | 5.0 | 0.040 | 0.040 |

- 排序：**w_raw ⇒ A > C > B > D**；**w_norm ⇒ A > B > C > D**。**Kendall τ = 0.667，序翻转。**
- A/B 权重比：**6.76（raw） vs 1.69（norm）**——用归一化前权重把 g=2 的高响应帧压低 **4×**（≈1/g²）。

  ⇒ 两项都必须进方差：**÷g² 与 J C_θ Jᵀ 缺一不可**。

## 3 SNR 加权 vs 等权：梯度面误差与低 SNR 污染

脚本 \`pollution_q2.py\`。两帧 H（σ_norm=1）与 L（σ_norm=10）重叠，共享二阶背景；
L 带**系统加性伪影** Δ（20 ADU 高斯，模拟未扣净的平场残差）。公共场用加权二阶最小二乘估计。

**系统偏差漏入公共梯度面**（测量 = 有伪影解 − 无伪影解，重叠区中位）：

| 权重 | w_L/(w_H+w_L) | 实测漏入 | 占伪影幅度 |
|---|---|---|---|
| SNR 正确 (1/σ²) | 0.0099 | **+0.081 ADU** | **0.4%** |
| 等权 | 0.5000 | +4.092 ADU | 20.5% |
| 反权（负例） | 0.9901 | +8.104 ADU | 40.5% |

漏入比 **1 : 50 : 100**，与 w_L/(w_H+w_L) 完全一致。⇒ **等权时低 SNR 帧把高 SNR 帧的光度抬高约半个伪影幅度；正确 SNR 权把它压到 ~1/100。**

**噪声驱动误差**（200 次 Monte-Carlo，无伪影，公共场常数项）：

| 权重 | MC RMS |
|---|---|
| SNR 正确 | **0.0130 ADU** |
| 等权 | 0.0645 ADU（**5.0×**） |
| 反权 | 0.1146 ADU（8.8×） |

⇒ 结论：**低 SNR 帧确实污染梯度面并抬高高 SNR 帧光度；按归一化方差（含 ÷g²）加权可同时把系统污染压 ~50×、噪声误差压 ~5×。**

## 4 四种 formulation 的阶跃对比（代数 + 数值）

### 4.1 代数

记覆盖集合 \`S(p)\`、\`W_S=Σ_{k∈S}w_k\`、残差 \`g_k\`。
马赛克残差 \`R(p)=Σ_{k∈S(p)} w_k g_k/W_S\`；**阶跃 ⟺ 跨边界 R 跳变**。

**充分条件**：若 \`g_k(p)=ḡ(p)\` 对所有 k 成立（公共场），则 \`R(p)=ḡ(p)·Σw/W=ḡ(p)\`，与覆盖子集、权重面**无关** ⇒ 无阶跃。

- **(c) 排除自身**：不动点 \`g_k = Σ_{j≠k} w_j g_j / W_{-k}\`。代入 \`ḡ=R\`：
  \`W_{-k} g_k = Σ_{j≠k} w_j g_j = W ḡ − w_k g_k\` ⇒ \`(W_{-k}+w_k) g_k = W ḡ\` ⇒ **\`g_k = ḡ\`（公共场）**。∎
- **(d) 含自身**：不动点 \`g_k = Σ_j w_j g_j/W = ḡ\`，代数上同样公共。
- **(a) 参考帧 gauge**：\`g_k = b_k − δ_k\`，δ_k 为逐帧模型，无任何等式迫使 g_k 相等 ⇒ 一般不公共。
- **(b) 全局加权均值为零**：\`g_k ← g_k − c\`（c 为全局标量）。常数平移**不改变任何空间阶跃** ⇒ 与 (a) 的阶跃**逐位相同**。

严格说，「使 \`Σ w_i g_i/W → 0\`」在无 gauge 时不可达（公共场与真实天光简并）；可达且必要的是**覆盖不变（→ 公共场 ḡ）**，再加**最终全局场 gauge**（扣 ḡ）即为 0。

### 4.2 数值（合成，残差场最大阶跃 ADU；噪声 = 0 / 有噪 SNR 权）

| formulation | 无噪 NF | 含噪 N1 (SNR) | 含噪 N2 (等权) | 公共场帧间散差 (N1) |
|---|---|---|---|---|
| (a) 参考帧 gauge | 0.2093 | 0.2598 | 0.2243 | 0.368 |
| (b) 全局均值为零 | **0.2093（=a）** | **0.2598（=a）** | **0.2243（=a）** | 0.368 |
| **(c) 排除自身** | **0.0352** | **0.0603** | **0.0622** | 1.09 |
| (d) 含自身 | 4.9147（发散） | 4.9289（发散） | 3.1749（发散） | 42.7 |

- **(b) 与 (a) 逐位相同**：证明全局标量 gauge 对空间阶跃**完全无效**（负例成立）。
- **(c) 比 (a) 小 4–6×**，且残差场更接近公共（无噪散差 0.13 ADU）。
- **(d) 发散**：含自身时，单覆盖区的 target 退化为帧自身当前校正 \`c_k\`，形成自反馈；实测帧间散差从 11 涨到 40+（\`debug_gs.py\`）。
- **迭代稳定性（重要缺陷）**：naive Gauss-Seidel（α=1）在**链式/二部覆盖图**上有特征值 **−1**（例：4 帧链，(1,−1,1,−1) 是特征向量），呈**周期 2 振荡、永不收敛**（散差恒 9–12，150 轮不降）。**加阻尼 α=0.5 后收敛**（散差 → 0.13）。这与早期设想文档「Gauss-Seidel 通常收敛」相反，是该 formulation 必须实现的修正。

## 5 权重与校正自洽方案

脚本 \`weight_consistency_q2.py\`。把帧 B 的叠加权重在 x>256 处改 ×5：

| 方案 | 叠加阶跃 maxabs (ADU) |
|---|---|
| (a) 基线权重 | 0.5485 |
| (c) 基线权重 | 0.4215 |
| (a) 用基线权重做最终 gauge、再用映射权重叠加 | 0.4285（阶跃重现） |
| (c) 用基线权重做最终 gauge、再用映射权重叠加 | 0.4285（阶跃重现） |
| **(a) 用「叠加权重本身」做最终全局场 gauge** | **0.0000** |
| **(c) 用「叠加权重本身」做最终全局场 gauge** | **0.0000** |

**自洽方案（推荐）**：

1. 每像素方差 \`Var(corrected_k)=[σ²_y,k + J_out C_θ J_outᵀ]/g_k²\`，权重 \`w_k=1/Var\`（乘性项必进；禁止权重反推方差）。
2. **同一组 w 同时用于拟合与叠加**（拟合权重 = 叠加权重）。
3. 用**(c) 排除自身的加权耦合 + 阻尼（α≈0.5）**求解逐帧校正；或等价地直接解公共场 \`ḡ\`。
4. **最终全局场 gauge**：用**叠加权重本身**计算残差场 \`R(p)=Σ_{k∈S(p)} w_k (z_k−c_k)/W_S\`，把 R 作为**单一全局光滑场**从每帧扣除（\`c_k ← c_k + R\`）。
   则 \`Σ w_k g_k/W ≡ 0\`，**对任意覆盖子集、任意权重面都无阶跃**（上表 0.0000）。
5. 若把 gauge 用的权重与叠加权重解耦，阶跃会重现（上表 0.4285）⇒ **权重必须同源**，这是「权重与校正自洽」的硬条件。

> 注：步骤 4 扣掉的是叠加自身的背景残差场（与生产一致：bitref_16w 已是扣基座产物，全局中位 4.65e10 vs OLD 9.4e12）；它只移除**光滑背景场**，不损失小尺度结构。

## 7 明确结论：如何正确传播 SNR 且保持平滑

1. **方差/权重公式（必须两项齐全）**
   \`Var(corrected_k(p)) = [σ²_y,k(p) + J_out,k(p) C_θ J_out,k(p)ᵀ] / g_k²\`，
   \`w_k(p) = 1/Var(corrected_k(p))\`。
   乘性项 **÷g²** 是硬要求：缺它高响应高 SNR 帧被压低 ≈1/g²、权重序可翻转（§2）；参数项 \`J C_θ Jᵀ\` 是合同要求（\`11_upm.md §4.1\`），病态档主导（\`unc-prop-audit.md §2.2\`）。禁止用 \`1/W_psfsw\` 或权重标量反推方差。
2. **权重同源**：拟合权重与叠加权重必须同一组 w_k(p)。
3. **用排除自身的加权耦合 formulation (c)** 求解公共场；**必须阻尼**（naive α=1 在二部覆盖图上有特征值 −1，周期 2 振荡）。不要用含自身的 (d)（单覆盖区自反馈、发散）。**参考帧 gauge (a) 与全局标量 gauge (b) 都不够**：(b) 与 (a) 逐位相同。
4. **最终全局场 gauge（决定性的平滑保证）**：用**叠加权重本身**计算残差场 \`R=Σ w_k(z_k−c_k)/W\` 并从每帧扣除。则 \`Σ w_k g_k/W ≡ 0\`，**任意覆盖子集、任意权重面下阶跃恒为 0**（数值 0.0000）。这是「让权重与校正自洽」的充分方案。
5. **真实数据现状**：生产 (a) 在 H1top/H1bot 有真实 3.5%/2.6% 台阶，upmfix 未修复；样本重拟合证明 (c) 可把边界跳变比从 2.10 降到 1.62，(b) 无改善。
6. **数据面阻塞**：真实样本 \`ivar/snr\` 全为 0 stub，权重链 \`SNR²/F_ref²\` 无法从样本读出；必须改用 \`1/uncertainty²\` 或让 Phase1 正确写出（与 \`unc-prop-audit.md\` M3 一致）。
