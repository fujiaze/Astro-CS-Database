## 二、按优先级四条主线看“做了什么”

### 2.1 科学性（最高优先）
- **坐标/投影**：B2-A1（WcsTan）、B2-A4/A5（投影）修复；坐标审计报告；
- **相位相关**：B2-A2（PSF compact）、B2-A3（reject collapse）；
- **定标**：B2-A6（calibration ×10）、暗场 K 由 EXPTIME 推导（禁硬编码）；
- **P1 数据语义**：B2-A12/A13/A14/A16（`precision_mode`、测光 provenance `PHOTAPPL/PHOTSCAL/PHOTDEGRADE`、禁硬编码）；
- **nside 合规**（P17）：缺省即“1x-2x 自动过采样”，显式才强制并告警；T4=65536@3.2201″、T2/T3=262144@0.8052″；
- **drizzle 确定性**（P15a/P15b）：固定条带/固定归约序 ⇒ 产物与线程预算无关；
- **P23 · HISS 退出生产路径**：p1 链改为 `hp_drizzle_run_phase1_hips` → `write_hips_phase1`，**标准 HiPS 树（signal/+support/）**为唯一正式产品；字节等价验证（T2 366 tile / T4 792 tile）；
- **P27 · IPV 配置面权威清点**：实证“**生产路径没有任何把配置/CLI 写进 `IpvParams` 的路径**”（24 字段全为编译期默认）⇒ 凡“改 IPV 参数做对照”的实验两臂相同、结论不成立；已加机器锁防误用；
- **P25 · SNR 样本真值研究**：无真实帧源数 <5000；限量取样会改变样本成分（`median_snr` +120%~+1157%、m5 跨帧变号）⇒ 全面样本 + 外挂判定；
- **P33 · 帧级单一 SNR 系数（负责人新口径）**：选型结论 **采用 PSF SNR 族中位数 median(SNR_F)**（即既有 median_snr）——与**图像侧独立参考**（孔径测光 SNR，背景取图像下半分位宽，不依赖 PSF 模型/目录方差）在 5 个背景主导帧上一致到 **1.12×**，增量成本为 0，且不改动任何既有科学标量；
  - **测光不确定度路线被否**：这 6 帧没有测光定标残差、不可评估，且其语义是**定标散度**而非逐源探测 SNR；
  - **像素背景路线被否**：尺度不同（逐像素 vs 逐源）且帧内极不均匀（CV 0.08-3.47）；
  - **“一帧一个系数”的边界**：帧级成立，**分区级不成立**（512 px 分区相对帧系数偏离 p50 **8.3%-26.3%**）⇒ 合同必须写死“这是帧级度量，不得冒充局部 SNR 场”；
  - **反证材料（早期稀疏实验未浪费）**：稀疏控制点 + IDW（K=64-256）可把同类分区误差从 13%-78% 降到 **2.6%-8.7%**（3-10× 精度差）；若将来需要分区级精度，该数据仍有效；
  - **存储**：删除逐源数组后 p1_snr.json 从 **18.0-77.0 MB/帧 → 约 4-8 KB/帧**（**4000-20000×**）；落位 frames[].snr_coefficient（DATA-P1-SNR-COEF/1），HiPS 侧键作为消费者批次合同；
  - **P25-F2 缺陷已修**：上游帧匹配由“精确名 join + 静默全 null”改为按 stem 归一化 + 显式处置。

## 三、drizzle 算法：从“1.3×”更正到“1.8-1.95×”

**更正过程**（前台两次判断被实测推翻，已在裁决记录 §39/§41 留痕）：
1. 起初按 P34 研究口径以为可拿 1.4-1.6×；
2. P35 落地实测 K1 整段仅 1.034×、合计 ≈1.3×；
3. P34 二轮用引擎 fine profile 做**代码级证明**：四个分段数**不是不相交段而是两层嵌套括号**（`accum ⊇ geom ⊇ (cand+overlap)`）⇒ 我此前“后两段 67%”是**重复计数、作废**；
4. 真实不相交占比：**候选枚举 48.3% + 重叠求值 48.8% + 其余 2.9%**。

**可落地收益（全部保序、零数值影响）**：
| 改动 | 实测 | 占引擎 |
|---|---|---|
| K2 候选枚举增量复用 | **3.14×**（252k 源像素候选集合逐像素全等） | **33.0%** |
| K1 切平面 2D 裁剪 | **0.63×**（背靠背原语 24.5→15.4 µs/src） | 8.7-14% |
| 几何缓存 O(1)（去 O(cap) 扫描） | 1.3-1.5×【推断】 | 3-5% |
| **合计** | | **1.7-1.9× 单核**（全帧 fine-profile 复核：K2 省 32.7%、K1 若覆盖整个裁剪+拒绝段省 14.6%） |

> **K1 的收益取决于覆盖率**：全帧数据 sh_frac=0.656（65.6% 的重叠调用走球面 S-H），而 K1 当前只替换 nb==4 && max_angle<1e-3 一个分支 ⇒ 已要求 P35 测分支覆盖率并对账；覆盖率低则扩展适用面（每扩一类给误差界）。

**负结果（已排除）**：scatter→gather（上限 <1.5% 且破坏 bitwise 归约序）、几何复用重排（整个缓存只值引擎 4.6%）、融合（已做完）、亚像素查表（需 6.3 亿表项）。


### 3.1 最终结论：**三态消融已把风险切干净**

| 状态 | 对比结果 |
|---|---|
| ① baseline ↔ ② **仅 K2** | **BITWISE_IDENTICAL**（0 tile / 0 JSON / 0 properties） |
| ② ↔ ③ **K2 + 缓存 O(1)** | **BITWISE_IDENTICAL** |
| ③ ↔ ④ 全部（含 K1） | **183 个 tile 不同** ⇒ 差异 **100% 归因于 K1** |

- **K2 可安全冻结**：逐位不变，**整节点省 43.4%**；**端到端干净 A/B 已完成**（同批交替 2 轮、`taskset -c 8`、load 3.7-6.5）：**wall 333.26 s → 219.94 s = 1.515×**、user CPU 1.523×、峰值 RSS +4.6%，且**科学产物与 baseline 逐位相同**（单核与四核各直跑）。含 K1 时为 1.524× ⇒ **K1 对总收益贡献≈0**（其节点级只有 1.7-3.4% 且会改产品）；
- **缓存 O(1) 可安全冻结**：逐位不变，收益 0.15-3%；
- **K1 的真实收益比研究预期小得多**：它覆盖 S-H 主路径 100%（进裁剪 98.70%、切平台成功 100%、回退 0），但因**候选枚举占了超段的 66%**，整节点只省 **约 1.7-4%**；
- **K1 的产物代价**：183 tile / 31.9M px 里 55.6% 的像素有差异，rel **p50 6.7e-8（约 1 个 float32 ULP）**、p99 2.4e-7、**max 3.1e-5**（仅 **31 个像素** >1e-5，0 个 >1e-4）；权重层 max|Δw|=1.79e-8 ≪ 1e-5、守恒残差 4.68e-10（**优于**旧路径自身 4.84e-8）；尾部来自加权累加对亮离群像素的放大；
- **线程预算无关性**：补丁在绑核 1/4/8 核下科学面 **BITWISE_IDENTICAL**（基线亦然）；`p1_final.json` 的差异只是输出目录路径，归一化后为 0，**非确定性缺陷**。

⇒ **前台建议（现已量化）：K1 用 2-4% 的速度换产品数值变化，不值得；冻结 = K2 + 缓存 O(1)。**
