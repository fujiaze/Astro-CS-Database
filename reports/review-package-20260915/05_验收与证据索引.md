## 四、口径纪律（本轮新增，所有性能证据适用）
1. `OMP_NUM_THREADS` 会被 Runtime 覆盖 ⇒ **只有 `taskset` 能改线程预算**（P28）；
2. 本机 `CLOCK_THREAD_CPUTIME_ID` 是 **syscall**（0.5-1.4 µs）⇒ **禁用细粒度逐像素计时**，必须整段单时钟 + 差分 + 同进程交错 A/B（P34）；
3. 本机 load 16-36 时同 mode 漂移可达 **2.2×** ⇒ **只采信同批背靠背比值**，跨 run 绝对时间不可比（P34）；
4. **禁止把“子段比值”当“整段/整节点收益”**汇报，必须标注测量边界（前台 §39.2）。
