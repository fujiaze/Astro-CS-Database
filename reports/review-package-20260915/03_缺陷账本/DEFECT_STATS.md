## 四、与 INDEX.md 的对账（81 / 306 / 133 → 520）

**结论：INDEX v4 的 520 是 2026-09-14 的快照，当前 findings 树已增长到 785 条；520 是 785 的真子集，不是同一集合的另一口径。**

- `INDEX.md` §一 汇总：`A 95 / B 25 / C_DOC 93 / D 48 / E 46 / F 62 / G 82 / H 25 / I 44 = 520`（P0 81 / P1 306 / P2 133）；§二 产出方只列 `M1a..M9 + FD + L28b..L28e`，文件规模“224 份定稿件”。

- **剩余 264 条** = `V*`(188) + `W*`(71) + `SA*`(5) 的验证波条目，`INDEX.md` §二完全未列；该波新增了 `C_ALG_IMPL`(69) 与 `J_FS_PUBLISH`(8) 两个类别，并在既有类别内补录。

> 因此 `INDEX.md` 的 81/306/133 **不是**当前树的口径；本账本按 785 条全量落点，INDEX 的 520 条全部包含在内（同口径子集 521 条 ⊇ 520 条，唯一净增为 `FD-F-003`）。
