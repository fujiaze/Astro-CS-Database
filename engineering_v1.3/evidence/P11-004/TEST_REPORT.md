## 1. 测试方法

### 1.1 双层闭环架构（AUTONOMOUS_ENTRY.md §2）

| 层 | 数据来源 | 工具 | 用途 |
|----|----------|------|------|
| A 层（Solver Internal） | `IPVSolver.get_last_inliers()` | C++ SolveInlierCache | 验证求解器内部 TRANS 预测与 detector 坐标一致性（对照） |
| B 层（Serialized WCS Hard Gate） | `astropy.wcs.WCS(header)` | 标准 WCS+SIP | 用 Gaia 星回投到像素，与 detector 坐标比较（**硬 Gate**） |
| C 层（Blind Catalog） | 全星表 kd-tree | 重匹配 | 仅作二级诊断（本测试**禁止**启用） |

### 1.2 独立性保证

- **A 层**：直接调用 C++ 求解器导出 inlier，不重新匹配
- **B 层**：仅使用 FITS Header 中的 CRPIX/CRVAL/CD/CTYPE/SIP，不读取 IpvWcsResult，不调用 PlateSolve 的 transform
- **C 层禁止**：按 AUTONOMOUS_ENTRY.md §2 第 4 条，`--authoritative-pairs` 模式禁止启用 C 层

### 1.3 坐标系转换

solver U 坐标系（图像中心原点, Y 轴向上）↔ astropy 0-based pixel（角落原点, Y 轴向下）：

```python
crpix_0based = wcs.wcs.crpix - 1.0   # FITS 1-based → 0-based
pixel_x = U_x + crpix_0based[0]
pixel_y = crpix_0based[1] - U_y       # Y 方向相反
```

> v3.4 修复：`wcs.wcs.crpix` 返回 FITS 1-based 原始值，需 -1 转换为 0-based。之前误用导致 B 层残差系统性偏移 ~1px。
